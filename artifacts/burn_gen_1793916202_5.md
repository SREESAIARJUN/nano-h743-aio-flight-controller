# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original spec for Job #28, so the design below rests on stated assumptions. Each one is marked **[A]** so you can substitute your hardware values. Everything is parameterized in the code.

| Item | Assumption |
|---|---|

## 1. Loop Architecture

```
            1 kHz                     4 kHz                    20 kHz
 θ_ref ─►[Angle P + rate FF]─► ω_ref ─►[Velocity PI]─► iq_pi ─┐
   ▲                                     ▲                     ▼
   │ θ_cam (Mahony, dual IMU)            │ ω_gyro (axis-proj.) (+)◄─ iq_cog(θ_m)  [anti-cogging FF]
   │                                     │                     ▼
   └──────── Dual ICM-42688-P ── notch/LPF bank ──┘        iq_ref ─►[Current PI d/q + decoupling]─►SVPWM─►Motor
                                                                      ▲ θ_e = p·θ_m (encoder)
```

Each inner loop runs about 4–10× faster in bandwidth than the loop wrapped around it:

- Current loop: ω_c ≈ 2π·1.5 kHz
- Velocity loop: ω_v ≈ 2π·100 Hz
- Angle loop: ω_θ ≈ 2π·20 Hz

## 2. FOC Current Loop (20 kHz)

**Electrical angle.** Here θ_m is the encoder angle and θ_off is the electrical offset found during calibration.

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$i_d = i_\alpha\cos\theta_e + i_\beta\sin\theta_e,\qquad i_q = -i_\alpha\sin\theta_e + i_\beta\cos\theta_e$$

**Plant** (surface PMSM, L_d ≈ L_q = L; λ is the flux linkage and ω_e = p·ω_m):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

**PI controller with decoupling feedforward:**

$$v_d = K_p e_d + K_i\!\int e_d - \omega_e L i_q,\qquad v_q = K_p e_q + K_i\!\int e_q + \omega_e(L i_d + \lambda)$$

**Pole-zero cancellation tuning.** The resulting closed loop is first-order with bandwidth ω_c. Keep ω_c ≤ 2π·f_pwm/10.

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

**Voltage limiting and anti-windup.**

- Magnitude limit: |v_dq| ≤ V_bus/√3, which is the linear SVPWM limit.
- Saturation priority: d-axis first, then q-axis gets the remaining headroom, √(V_max² − v_d²).
- Anti-windup uses back-calculation:

$$I_{k+1} = I_k + T_s\left[K_i e_k + K_b(u_{sat}-u)\right],\qquad K_b \approx 1/T_s \cdot 0.1$$
