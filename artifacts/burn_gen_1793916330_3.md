## 0. Architectural Ground Truth

Two corrections shape the rest of the document.

**1. The H743 does not commutate the motors.** ArduPilot contains no ESC firmware. Bidirectional DShot implies a separate ESC MCU on the far end of each signal line that decodes frames and returns eRPM.

| Function | Device |
|---|---|
| Flight control | STM32H743VIH6 (or VIT6) running ArduPilot |
| ESC control | 4× AT32F421K8U7 (or STM32G071) running AM32, one per motor |
| Gate drive | 4× FD6288Q three-phase gate drivers |
| Power stage | 24× N-channel MOSFETs: 6 per motor, 3 half-bridges |

The 48 kHz switching frequency is set in AM32 (`PWM_FREQUENCY`), not in ArduPilot.
