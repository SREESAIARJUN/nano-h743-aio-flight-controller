# Job #44: STM32H743 Nano AIO with 4-in-1 ESC, Analysis Package

**Scope.** This package covers four areas:

1. Conduction and switching loss model at 80 A burst and 48 kHz.
2. Transient thermal model.
3. ArduPilot bidirectional DShot600 timer and DMA allocation on the H743.
4. Reference netlists for the power stage, ESC MCU, and FC motor/DMA nets.

**Architecture.** The STM32H743 is the flight controller running ArduPilot. Each motor channel has its own small ESC MCU (STM32G071 class, running AM32) that does commutation. The H743 does not commutate motors. The H743 talks to the ESCs over bidirectional DShot600.
