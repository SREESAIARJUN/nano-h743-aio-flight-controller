# STM32H743 Nano AIO with 4-in-1 80A ESC: System Architecture Package (Job #11)

## 0. Scope, Assumptions and Feasibility

I have no prior context for "Job #11", so this package fixes a baseline that you can override. Every derived number traces back to the parameter table in §0.2, so substituting your real BOM values recomputes the whole chain.

### 0.1 Architecture decision

The STM32H743 cannot commutate four BLDC motors directly at 48 kHz. Every production 4-in-1 design uses a split architecture, and this design follows it:

```
LiPo 6S ─┬─ Bulk caps ─┬─ ESC1: AT32F421 (AM32) ─ FD6288Q ─ 6×MOSFET ─ Motor1
         │             ├─ ESC2 ... ESC4 (identical, designator offset +100)
         │             └─ Buck 12V (gate drive) / Buck 5V / LDO 3.3V
         └─ Current shunt (bus) ─ INA ─ H743 ADC
STM32H743 (ArduPilot) ── 4× bi-directional DShot600 ──► ESC MCUs
```
