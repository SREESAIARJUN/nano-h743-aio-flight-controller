## 1. Field-Oriented Control: the Inner Current Loop

### 1.1 Transforms

The electrical angle is computed from the mechanical angle, the pole-pair count and a calibrated offset:

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model and Decoupling

The motor's d/q voltage equations are:

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q\dot i_q + \omega_e(L_d i_d + \lambda)$$

The cross-coupling and back-EMF terms are cancelled with a feedforward:

$$v_d^{ff} = -\omega_e L_q i_q,\qquad v_q^{ff} = \omega_e(L_d i_d+\lambda)$$

After this cancellation, each axis behaves as a simple first-order plant:

$$G_i(s) = \frac{1}{Ls+R}$$

### 1.3 Current PI Tuning by Pole-Zero Cancellation

The PI controller is

$$C_i(s) = K_p + \frac{K_i}{s}$$

Choosing

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

places the PI zero (at K_i/K_p = R/L) exactly on the plant pole. The open-loop transfer function then reduces to ω_c/s, so the closed loop is first order with bandwidth ω_c. Keep ω_c ≤ 2π·f_pwm / 10.

**Discrete form with anti-windup:**

1. Compute the error: e[k] = i* − i
2. Compute the unsaturated output: u = K_p·e + I[k] + v^ff
3. Saturate: u_sat = sat(u)
4. Update the integrator with back-calculation: I[k+1] = I[k] + K_i·T_s·e + K_aw·(u_sat − u)

Use K_aw = 1/K_p·K_i·T_s, or equivalently conditional integration.

**Voltage vector limit (circular):**

$$\sqrt{v_d^2+v_q^2} \le V_{max} = \frac{V_{dc}}{\sqrt3}\cdot 0.95$$

Priority goes to v_d: v_q is limited to $\sqrt{V_{max}^2 - v_d^2}$.
