# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

**Scope note:** I don't have the Job #19 specification, so the hardware values below are placeholders. Every value marked `// [ASSUME]` must be replaced with measured or specified values before deployment. The assumed hardware is:

- **Motors:** 3× gimbal BLDC, 12N14P (7 pole pairs). Rs ≈ 5.6 Ω, Ls ≈ 2.2 mH, Kt ≈ 0.12 N·m/A.
- **Encoders:** 14-bit absolute magnetic encoder per joint (AS5048A/MT6701-class), read synchronously with the PWM.
- **MCU:** Cortex-M4F/M7 (STM32G4/H7-class) with a single-precision FPU.
- **IMUs:** 2× ICM-42688-P on the camera plate. They are on separate SPI buses, sampled at 8 kHz with FIFO and timestamps.
- **Axis order:** yaw (base) → roll → pitch (camera). Camera frame: x forward, y right, z down.

## 1. Timing Architecture

| Loop | Rate | Target bandwidth | Input | Output |
|---|---|---|---|---|
| Current (FOC, d/q PI) | 20 kHz (PWM center ISR) | 1.5 kHz | i_a, i_b, θ_e | v_α, v_β → SVPWM |
| Encoder PLL + cogging FF | 20 kHz | PLL 300 Hz | θ_m | ω̂_joint, i_q,ff |
| IMU filter chain + fusion | 8 kHz → decimated to 4 kHz | — | 2× gyro/accel | ω_cam, a_cam |
| Rate (velocity) loop | 4 kHz | 120 Hz | ω_cam (gyro) | τ_cam* → J^T → i_q* |
| Attitude (angle) loop + AHRS | 1 kHz | 15–20 Hz | q̂_cam | ω_cam* |

Rule of thumb applied: each outer loop runs at a bandwidth ≤ ¼–⅕ of the inner loop. This separation means the inner loop can be treated as unity gain when tuning the outer loop.
