## 0. Scope, Architecture Decisions, and Stated Assumptions

**Architecture.** This is a two-board stack:

- **FC:** STM32H743VIT6 (LQFP100) running ArduPilot.
- **ESC:** a 4-in-1 board with one ESC MCU per motor (AT32F421 running AM32). The ESC MCUs run the 48 kHz complementary-PWM commutation.

The H743 does not drive gates directly. It sends bidirectional DShot600 and receives eRPM telemetry. A single H743 cannot do sensorless BEMF commutation for 4 motors at 48 kHz alongside ArduPilot's scheduler, so that option was rejected.

No MOSFET part number was specified, so I've defined a representative 40 V DFN3.3×3.3 device. **Every number below scales from this table. Re-run the equations with your chosen part's datasheet before committing to layout.**
