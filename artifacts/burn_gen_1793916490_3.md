**Timescale separation.** Each loop's bandwidth should be about 4–10× higher than the loop outside it:

- Current loop: f_c ≈ 1.5–2 kHz
- Rate loop: f_v ≈ 150–250 Hz
- Angle loop: f_p ≈ 30–50 Hz

**Feedback sources.**

- **Rate loop:** uses the **inertial gyro rate projected onto the motor axis**, not encoder velocity. This is what makes a gimbal reject base motion.
- **Encoder:** used only for commutation (θ_e) and for cogging-table indexing (θ_m).

## 2. Field-Oriented Control (Current Loop, 20 kHz)

### 2.1 Transforms

Electrical angle from mechanical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \mod 2\pi$$

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park is the transpose of this matrix.

### 2.2 Plant model

For a surface PMSM (L_d = L_q = L), in the rotor frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

where λ_m = K_t / (1.5 p).

### 2.3 Decoupled PI current control with pole-zero cancellation

$$v_d^* = \Big(K_p + \tfrac{K_i}{s}\Big)(i_d^* - i_d) - \hat\omega_e L i_q$$
$$v_q^* = \Big(K_p + \tfrac{K_i}{s}\Big)(i_q^* - i_q) + \hat\omega_e (L i_d + \lambda_m)$$

Choose the gains so the PI zero cancels the electrical pole at R/L:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The closed loop then becomes first-order:

$$\frac{i}{i^*} = \frac{\omega_c}{s + \omega_c}$$

**Numbers:** with ω_c = 2π·1500, K_p = 22.6 V/A and K_i = 52.8 kV/(A·s).

**Delay constraint.** The PWM plus computation delay is roughly 1.5·T_s = 75 µs at 20 kHz. Requiring ω_c·1.5T_s < 0.6 rad gives ω_c < 8 krad/s, so 9.4 krad/s is marginal. **Use ω_c = 2π·1200** for about 55° of phase margin.

### 2.4 Voltage limiting and SVPWM

The linear modulation limit is |v_dq| ≤ V_dc/√3.

- Saturate circularly, giving priority to v_d.
- Feed the clipped amount back to the integrators (back-calculation anti-windup, Section 3.3).

SVPWM is implemented as min/max zero-sequence injection:

$$v_0 = -\tfrac12\big(\max(v_a,v_b,v_c) + \min(v_a,v_b,v_c)\big)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$
