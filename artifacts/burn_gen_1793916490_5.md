## 0. System Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 10 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A **[ASSUMPTION]** |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), SPI |
| MCU | STM32G4 / H7 class with an FPU, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, gyro and accel ODR = 8 kHz, SPI |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

### Loop Rates and Bandwidths

Use a 5–10× separation between cascaded loop bandwidths.

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (i_d, i_q) | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| Velocity | 4 kHz | ω_v ≈ 2π·150 rad/s |
| Angle / attitude | 1 kHz | ω_θ ≈ 2π·20 rad/s |
| IMU filtering | 8 kHz in, decimated to 1 kHz | — |

## 1. FOC Inner Loop Equations

### 1.1 Electrical Angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

`θ_off` is found at commissioning by applying `v_d` at θ_e = 0 and recording where the rotor settles.

### 1.2 Clarke Transform (Power-Invariant Form Not Used; Amplitude-Invariant)

Assuming balanced phases, $i_a + i_b + i_c = 0$:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$
