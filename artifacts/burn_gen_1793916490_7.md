# FOC Control Loop and Sensor Fusion for the 3-Axis Gimbal

I don't have the Job #18 specification, so the baseline below uses typical brushless-gimbal values. Every constant is a named parameter, so you can substitute the real ones.

## 0. Baseline Assumptions

| Item | Value |
|---|---|
| Motor | GBM2804-class, 12N14P, so pole pairs p = 7 |
| Phase constants | R = 5.6 Ω, L ≈ 1.6 mH, λ_m ≈ 0.012 Wb (phase-to-phase quantities must be converted per phase) |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A) |
| MCU | STM32G4 class, FPU |
| PWM / current loop | 20 kHz, center-aligned |
| Velocity loop | 4 kHz (÷5) |
| Attitude/angle loop | 1 kHz (÷20) |
| IMU A (payload) | ICM-42688-P on the camera plate. It is the attitude feedback sensor. |
| IMU B (base) | ICM-42688-P on the handle or airframe. It provides the vibration reference and the base-rate feedforward. |
| IMU ODR | 8 kHz, gyro ±500 dps, accel ±4 g |

Cascade structure:
```
θ_ref ─►[Attitude PI (IMU A, 1 kHz)]─► ω_cmd ─(+ base-rate FF from IMU B)─►[Velocity PI (encoder, 4 kHz)]
        ─► i_q,ref (+ cogging FF) ─►[dq Current PI + decoupling (20 kHz)]─► SVPWM
```

## 1. FOC Current Loop (20 kHz)

**Electrical angle.** θ_e = p·θ_m − θ_offset, where θ_offset is found at calibration by aligning the rotor to the d-axis.

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c
