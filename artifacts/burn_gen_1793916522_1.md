# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the specification sheet for Job #59, so this design rests on the assumptions in §0. Every parameter that depends on them is a named constant in the code, so you can substitute the real values without restructuring anything.

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A, MT6701 or similar) per axis |
| Inverter | 3-phase, center-aligned PWM at 20 kHz, 2 low-side shunts |
| Axis order | Yaw (outer) → Roll → Pitch (inner, carries the camera) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class) with a single-precision FPU |

### Loop-rate hierarchy

```
 20 kHz  : ADC → Clarke/Park → current PI (d,q) → inv-Park → SVPWM
 20 kHz  : cogging feedforward lookup (inside the current ISR)
  8 kHz  : IMU read (both) → per-IMU notch/LPF → fusion
  4 kHz  : velocity PI (per axis) using gyro rate mapped to joint space
  1 kHz  : attitude estimator (Mahony) + angle P/PI loop + setpoint shaping
```

### Bandwidth separation rule

Each outer loop runs at roughly one quarter to one fifth of the bandwidth of the loop it drives:

$$\omega_{c,i} \approx 2\pi\cdot 1.5\text{ kHz},\quad \omega_{c,v}\approx 2\pi\cdot 80\text{ Hz},\quad \omega_{c,\theta}\approx 2\pi\cdot 15\text{ Hz}$$

## 1. FOC Current Loop

### 1.1 Transforms

The electrical angle comes from the encoder angle, the pole-pair count and a calibrated offset:

$$\theta_e = p\,\theta_m - \theta_{\text{off}} \pmod{2\pi}$$

**Clarke transform** (amplitude-invariant, using $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant model (surface PMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32 p\lambda_m i_q \equiv K_t i_q$$

### 1.3 Decoupled PI with feedforward

The PI output is summed with cross-coupling and back-EMF terms:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e L i_d + \hat\omega_e\hat\lambda_m$$

After decoupling, each axis plant is $1/(Ls+R)$. Placing the PI zero on the plant pole by internal-model control gives:

$$K_{p,i} = L\,\omega_{c,i},\qquad K_{i,i} = R\,\omega_{c,i}$$

The resulting closed loop is first-order:

$$\frac{i}{i^*} = \frac{\omega_{c,i}}{s+\omega_{c,i}}$$
