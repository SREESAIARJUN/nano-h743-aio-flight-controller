# STM32H743 AIO Flight Controller with 4-in-1 ESC (Job #19): Power-Stage, Thermal, and Bidirectional DShot Architecture

## 0. Architecture Review Findings

These findings drive the rest of the document.

1. **The H743 does not commutate the motors.** On every production 4-in-1 design, each motor has its own ESC MCU running AM32 or BLHeli_32 (for example STM32G071, AT32F421, or GD32). The H743 runs ArduPilot and sends bidirectional DShot600 to those ESC MCUs. The 48 kHz switching frequency is an ESC-firmware setting (AM32 `PWM_FREQ`), not an ArduPilot parameter. The model below follows that split.
2. **"80 A burst" on a nano (20×20 or 25.5×25.5 mm) board is only feasible for about 1–2 s with all four motors loaded simultaneously.** Section 3 derives this. With 80 A on four channels, the board dissipates more than 120 W. Treat 80 A as a single-motor transient rating, or move to a 30.5×30.5 mm board with 5×6 mm FETs.
3. **The netlist is a reference-design netlist.** Part values are representative. MOSFET, driver, and capacitor parameters must be replaced with the selected vendors' datasheet values and re-run through these equations before layout sign-off.

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12} = 6400 + 6.4 \approx 6406\ \text{A}^2$$
