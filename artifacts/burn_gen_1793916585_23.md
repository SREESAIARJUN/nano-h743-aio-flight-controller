# STM32H743 Nano FC + 4-in-1 ESC (Job #46): Loss, Thermal and Bi-Directional DShot600 Architecture

## 0. Scope and Assumptions

No component set was specified, so every number below rests on the assumptions in this section. The equations are general. Replace the parameter table with your actual datasheet values and the model re-solves.

**Architectural correction.** In a stack like this, the STM32H743 is the **flight controller**. It does not commutate the motors. Each ESC channel runs its own low-cost MCU, such as an AT32F421 or STM32G071 running AM32, or an EFM8 running BLHeli_S/Bluejay. DShot600 is the link between the two. If Job #46 really intends the H743 to drive all 24 FETs directly, the timer budget in §6 becomes infeasible, because 4×3 complementary PWM pairs plus commutation and BEMF sensing would need roughly 4 advanced timers and ADCs. That combination would need a separate study.

## 1. System Architecture

```
6S LiPo ──┬── Bulk electrolytic + per-channel MLCC bank
          ├── 4× [ESC MCU (AM32) → 3-phase gate driver (FD6288Q class) → 6× N-FET → motor]
          ├── Common shunt + current amplifier → ESC CURR pin → FC ADC
          └── 10 V BEC (gate drive) / 5 V / 3.3 V LDO for ESC MCUs

FC (STM32H743 @ 400 MHz in ArduPilot):
   4× timer channels → series 33–100 Ω → ESC signal pins (bidirectional DShot600)
   ADC ← ESC current/voltage; UART ← optional ESC telemetry
```

## 2. Conduction Loss Model

**Current path.** In six-step commutation, two phases conduct at any instant. One leg is PWM-switched with complementary drive and the other leg is held on. With synchronous rectification, the phase current always flows through exactly **two FET channels**: one high side and one low side. This holds during both the PWM on-time (HS of leg A plus LS of leg B) and the off-time (LS of leg A plus LS of leg B). The duty cycle therefore drops out of the result, except during dead time (§3).

**Per-channel conduction loss:**

$$P_{cond}=2\,I^2\,R_{ds}(T_j),\qquad R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)]$$

At an assumed T_j = 115 °C:

$$R_{ds}=0.90\,[1+0.0055\cdot90]=1.35\text{ mΩ}$$

$$P_{cond}=2\cdot80^2\cdot1.35\times10^{-3}=\mathbf{17.3\ W\ per\ channel}$$

**Per-FET average.** Each FET carries current about 1/3 of the electrical period (120°), so:

$$P_{FET}\approx\frac{I^2R_{ds}}{3}\cdot2\approx\mathbf{2.9\ W\ average}$$

The instantaneous peak is 8.6 W. At electrical frequencies above about 500 Hz this ripple is filtered by the die and package thermal capacitance (τ of roughly ms), so the average governs.

**Parasitic copper.** Each 80 A path also crosses copper, solder joints and the motor pads. A realistic 0.3 mΩ of path resistance adds:

$$P_{Cu}=80^2\cdot0.3\text{ mΩ}\approx1.9\text{ W per channel}$$

A shunt, if used, adds I²·R_shunt. For example, 0.25 mΩ adds 1.6 W per channel, or proportionally less on a common shunt measuring average current.

## 3. Switching Losses at 48 kHz

Only the PWM leg switches. That is one HS/LS pair per channel.

| Term | Equation | Value per channel |
|---|---|---|
| Hard-switching V·I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·30 ns·48 kHz | **1.45 W** |
