# STM32H743 AIO Flight Controller + 4-in-1 ESC: Engineering Design Package (Job #16)

## 0. Scope and Ground Rules

### Architecture clarification

An STM32H743 does not commutate motors in any production 4-in-1 ESC. The workable architecture is:

- **Flight controller:** STM32H743 running ArduPilot. It sends bi-directional DShot600 to the ESC section.
- **ESC section:** 4 × AT32F421 (or STM32G071) running AM32. Each runs the 48 kHz PWM, 6-step commutation and eRPM telemetry.
- **Power stage:** 4 × 3 half-bridges, 24 MOSFETs, plus 3-phase gate drivers.

Driving 12 bridge legs at 48 kHz from the H743 would compete with ArduPilot's scheduler, sensor DMA and DShot DMA. No supported firmware does it.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right]$$

At T_j = 110 °C:

$$R_{DS}(110) = 1.5 \times (1 + 0.0065 \times 85) \approx 2.33\ \text{m}\Omega$$

### 1.2 Six-step commutation with synchronous rectification

At any instant, current flows through exactly one high-side path and one low-side path in series. During the off-time, the complementary FET carries the current instead of the body diode. So the motor current always passes through two R_DS(on) regardless of duty cycle:

$$P_{cond,ch} = I^2 \cdot 2R_{DS}(T_j)$$

Per FET, averaged over an electrical cycle (each FET carries current for 1/3 of the period, split between active and freewheel intervals):

$$P_{cond,FET} \approx \frac{P_{cond,ch}}{6}$$

The approximation holds because the electrical period (about 1 ms at 60k eRPM) is much shorter than the junction thermal time constant.

### 1.3 Numbers at 80 A, T_j = 110 °C

$$P_{cond,ch} = 6400 \times 2 \times 2.33\times10^{-3} = 29.8\ \text{W}$$

$$P_{cond,FET} \approx 5.0\ \text{W}$$

The "×2" assumes perfect synchronous rectification. If the ESC firmware runs non-complementary PWM, a body diode carries the freewheel current instead. Adding that diode drop gives:

$$P_{diode} = V_f I (1-D) = 64(1-D)\ \text{W}$$

This is far worse, so complementary PWM is mandatory. In AM32 this is the default; do not disable "complementary PWM".

### 1.4 Electro-thermal convergence

R_DS depends on T_j, and T_j depends on R_DS. Iterate:

$$T_j^{(k+1)} = T_{ref} + Z_{th} \cdot P\big(R_{DS}(T_j^{(k)})\big)$$

This converges in 3–4 iterations if

$$\frac{\partial P}{\partial T} \cdot Z_{th} = I^2 \cdot 2R_{25}\alpha \cdot Z_{th} < 1$$

At 80 A that loop gain is 6400 × 3 mΩ × 0.0065 × Z_th = 0.125·Z_th, using Z_th in K/W at the board level. For the whole-board steady state (Z_th ≈ 12 K/W, §4.2), the gain exceeds 1. **Thermal runaway is mathematically possible for sustained 80 A operation.** It is only acceptable as a time-limited burst.

## 2. Switching Loss Model at 48 kHz

In complementary 6-step, only the PWM-ing FET hard-switches, one per active phase pair. The synchronous partner switches at near-zero V_DS, so it is soft.

### 2.1 Gate current during the Miller plateau

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_{g,tot}} = \frac{7}{5} = 1.4\ \text{A}$$

$$I_{g,off} = \frac{V_{pl}}{R_{g,tot}} = 0.6\ \text{A}$$

### 2.2 Transition times

$$t_r = \frac{Q_{sw}}{I_{g,on}} = 6.4\ \text{ns}$$

$$t_f = \frac{Q_{sw}}{I_{g,off}} = 15\ \text{ns}$$

### 2.3 Loss components per motor channel

| Mechanism | Formula | Value |
|---|---|---|
| V–I overlap | ½·V_bus·I·(t_r + t_f)·f_sw = ½·25.2·80·21.4n·48k | 1.04 W |
| Coss discharge | ½·C_oss,er·V²·f_sw | 0.014 W |
| Reverse recovery | Q_rr·V_bus·f_sw | 0.036 W |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw = 0.8·80·200n·48k | 0.61 W |
| Gate drive (driver dissipation) | 2·Q_g·V_drv·f_sw | 0.029 W |
| **Total switching-related** | | **≈ 1.73 W** |

### 2.4 Design levers

- **Turn-off dominates.** Use a split gate path: a 2 Ω turn-off resistor through a Schottky (BAT54) paralleled with a 5 Ω turn-on resistor. This cuts t_f to about 6 ns and saves roughly 0.4 W per channel.
- **Watch ringing.** Faster switching increases dV/dt ringing, so you must add an RC snubber (§5).
- **Dead time:** 100 ns costs 0.61 W. AM32's dead-time setting must match the driver's propagation skew; about 60 ns is achievable with matched drivers.
- **Frequency scaling:** P_sw ∝ f_sw. At 24 kHz switching loss halves, but current ripple and audible noise rise. At 48 kHz switching loss is only about 5% of the total, so 48 kHz is justified.
