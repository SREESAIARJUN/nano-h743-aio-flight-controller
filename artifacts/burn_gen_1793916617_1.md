# STM32H743 AIO Flight Controller with 80A 4-in-1 ESC: System Architecture Model (Job #25)

## 0. Scope and Ground Truth

Two architectural facts constrain everything below. Getting either wrong invalidates the rest of the model.

1. **The H743 does not commutate the motors.** On every production 4-in-1 design, each ESC channel runs its own small MCU (AT32F421 / STM32G071 / EFM8 running AM32 or BLHeli_32/S). The H743 runs ArduPilot and emits bidirectional DShot600. The 48 kHz PWM is generated by the ESC MCUs, not the H7. The architecture below reflects that.
2. **"80A burst" on a nano-class board is a transient, thermally limited rating, not a continuous one.** The math in §3 shows roughly 100 W of dissipation at 4×80A. A 30–36 mm board cannot reject that in steady state. The real deliverable is a **burst time budget**, and §3 derives it.

## 1. Conduction Loss Model

### 1.1 Topology
The design uses a 3-phase bridge with 6-step trapezoidal commutation and **synchronous (complementary) PWM**, which is the AM32/BLHeli_32 default.

- During each 60° electrical sector, phase X is PWM'd and phase Y is held low.
- **On-time:** current flows HS_X → motor → LS_Y.
- **Off-time:** current freewheels LS_X → motor → LS_Y.

In both intervals the current passes through exactly **two FETs in series**. Conduction loss is therefore independent of duty cycle:

$$P_{cond,ESC} = 2\,I_{rms}^2\,R_{ds}(T_j)$$

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha(T_j - 25)]$$

Interpreting the current rating matters. If "80A" means **battery** current, the phase current is I_phase ≈ I_batt / D. At partial throttle the phase current is larger, which makes this case worse. Here I take 80A as the phase current at near-full throttle, where the two definitions converge.

### 1.2 Solving for T_j
The loss depends on T_j, so the solution is a fixed-point iteration:

$$T_j^{(n+1)} = T_{board} + P_{FET}\!\left(T_j^{(n)}\right)\cdot R_{\theta,j\text{-}board}$$
