# STM32H743 AIO Flight Controller + 4-in-1 ESC: Systems Architecture Package (Job #13)

**Scope:** 80A burst thermal model, 48 kHz switching losses, ArduPilot bidirectional DShot600 DMA and timer plan, reference netlists.

> **Engineering caveat (read first).** An 80A-per-motor burst on a nano (20×20 mm) board is at the edge of physical feasibility. The model below shows it is achievable only as a short burst of about 1 s. Realistic continuous current is about 15–20 A per motor unless the board is heatsinked. All component parameters are representative assumptions, marked **[A]**. Replace them with datasheet values for the parts you actually select before freezing the design.

## 1. System Partitioning

```
 6S LiPo ──┬─ Bulk cap (external, 470µF–1000µF low-ESR) ── VBAT bus
           │
           ├─ 4× ESC power stage (6× N-MOSFET each = 24 FETs)
           │     ▲ gate drive (3-phase driver ×4, e.g. FD6288Q-class)
           │     │
           │  4× ESC MCU (AT32F421 / STM32G071-class, AM32 or BLHeli_32)
           │     ▲ DShot600 bidirectional (single wire per motor, inverted)
           │     │
           └─ STM32H743 FC (ArduPilot), 400 MHz core
```

The H743 does **not** commutate the motors. It sends bidirectional DShot to the four ESC MCUs. Each ESC MCU runs 48 kHz complementary PWM with synchronous rectification.
