# STM32H743 Nano FC + 4-in-1 ESC: Design Model and Allocation Package

This package covers the ESC loss model, transient thermal model, ArduPilot BDShot600 timer and DMA plan, netlists, and validation steps.

## 0. Key Findings

1. **The STM32H743 does not drive the 48 kHz bridge.** In any viable 4-in-1 design, each motor channel has its own ESC MCU (AT32F421, running AM32 or BLHeli_32-class firmware) that generates the 48 kHz complementary PWM. The H743 only sends DShot600 and receives bidirectional eRPM telemetry. The loss model below applies to the ESC MCU's bridge, not to the H743.
2. **80 A per channel is a burst rating, not continuous.** On a 20×20 mm "nano" board, the model below shows roughly 98 W total at 4×80 A. That is about 1 to 1.5 s of headroom from a 40 °C board start. Continuous capability is roughly 30–35 A per channel. Any "80 A" label must state a burst duration (≤1 s recommended).
3. **The MOSFET parameters below are representative, not from a specific datasheet.** Every equation is parameterized. Substitute your selected part's values before releasing the design.

## 1. Conduction Loss Model (6-step trapezoidal, synchronous rectification)

### 1.1 Current paths
In each 60° commutation sector, two phases are active. One leg is PWM'd complementarily (HS on for D, LS synchronous rectifier for 1−D). The other leg's LS is held on. At every instant, current flows through exactly **two** MOSFETs in series.

### 1.2 RMS current with ripple
PWM ripple (peak-to-peak), worst case at D = 0.5:

$$\Delta I = \frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}} = \frac{25.2 \times 0.25}{20\mu \times 48k} = 6.56\ \text{A}$$

$$I_{rms}^2 = I_{ph}^2\left(1 + \frac{(\Delta I/I_{ph})^2}{12}\right) = 6400\,(1.00056) \approx 6404\ \text{A}^2$$

Ripple adds well under 0.1% at 80 A, so it can be neglected at burst current.

### 1.3 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C: R = 1.2 mΩ × 1.4675 = **1.76 mΩ**.

### 1.4 Bridge conduction loss per motor channel

$$P_{cond,ch} = 2\, I_{rms}^2\, R_{ds}(T_j) = 2 \times 6404 \times 1.76\text{m} = \mathbf{22.5\ W}$$

Averaged over an electrical cycle, each of the 6 FETs carries 1/3 of this load:

$$P_{cond,FET} = \frac{I_{rms}^2 R_{ds}}{3} \approx 3.76\ \text{W (average per FET)}$$

At high eRPM (commutation in the kHz range), this per-FET averaging is valid on thermal time constants above about 10 ms.

### 1.5 Thermal runaway stability criterion
Conduction loss rises with temperature, which raises temperature further. The loop is stable only if:

$$\frac{\partial P}{\partial T_j}\, R_{th,ja} < 1 \;\Rightarrow\; 2 I^2 R_{25}\,\alpha\, R_{th,ja} < 1$$
