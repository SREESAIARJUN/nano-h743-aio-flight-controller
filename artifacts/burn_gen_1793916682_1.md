## 1. FOC Current Loop

### 1.1 Transforms

The electrical angle is θₑ = p·(θₘ − θ_offset).

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and current PI design

The surface-PMSM model in the dq frame is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

With decoupling feed-forward terms

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m,$$

each axis reduces to the first-order plant 1/(Ls + R).

**Pole-zero cancellation.** Choose

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,$$

so that the PI zero cancels the electrical pole at R/L. The closed loop becomes ω_c/(s + ω_c). A typical choice is ω_c = 2π·1.5 kHz, which is below f_PWM/10.

**Discrete PI with back-calculation anti-windup** (sample time T_s):

$$u_k = K_p e_k + I_k,\qquad \bar u_k=\text{sat}(u_k),\qquad I_{k+1} = I_k + K_i T_s e_k + K_{aw}(\bar u_k - u_k)$$

Use K_aw ≈ 1/T_s·(K_i/K_p)·T_s = K_i/K_p, scaled per step as in the code.

**Voltage limit.** Space-vector modulation gives a linear range of |v| ≤ V_bus/√3. When saturating, the d-axis has priority:

$$v_q^{\max} = \sqrt{(V_{bus}/\sqrt3)^2 - v_d^2}$$

**Voltage-mode fallback.** High-resistance gimbal motors often have no current shunts. In that case set

$$v_q = R\,i_q^* + \omega_e\lambda_m,\qquad v_d = 0.$$

The code supports both modes.

### 1.3 SVPWM (min-max zero-sequence injection)

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
