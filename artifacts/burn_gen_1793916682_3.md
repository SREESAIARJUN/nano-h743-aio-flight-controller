# FOC Motor Control and Dual-IMU Sensor Fusion: 3-Axis Gimbal (Job #42)

## 0. Assumptions

I don't have the Job #42 specification, so the design rests on the assumptions below. Every value is a named constant, so you can swap in the real ones.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, center-aligned PWM, synchronous ADC |
| Motors | Gimbal BLDC, 24N22P (p = 11 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the payload CoM |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, camera) |
| Loop rates | Current/FOC: 20 kHz. Velocity: 4 kHz. Angle/attitude: 1 kHz. IMU ODR: 8 kHz |
