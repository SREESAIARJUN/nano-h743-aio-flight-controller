# FOC Motor Control & Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #46, so this design uses the assumptions below. Every value lives in one `Config` struct, so you can substitute your real numbers.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| PWM / current loop | 20 kHz, center-aligned, synchronous ADC sampling |
| Velocity loop | 4 kHz (÷5) |
| Angle loop | 1 kHz (÷20) |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the plate centroid, 8 kHz gyro ODR, 1 kHz accel ODR |
