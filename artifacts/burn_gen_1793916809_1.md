# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the original Job #36 specification, so the design is built on the baseline below. All parameters live in config structs, so substitute your actual hardware values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 class (Cortex-M4F at 170 MHz, single-precision FPU) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7, slots S = 12), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.08 N·m/A |
| Driver | 3-phase half bridge, 20 kHz center-aligned PWM, 2 low-side shunts or inline sensing |
| Rotor encoder | 14-bit magnetic encoder (AS5048A / MT6701) |
| IMUs | 2× ICM-42688-P on the camera plate, mounted point-symmetric about the plate centroid, SPI at 24 MHz, gyro/accel ODR 8 kHz |

### Loop rates

| Loop | Rate | Feedback source |
|---|---|---|
| Current (FOC) | 20 kHz | Shunts + encoder angle |
| Velocity | 4 kHz | Fused gyro (inertial rate) |
| Angle | 1 kHz | Fused attitude (Mahony) |
| IMU acquisition | 8 kHz | Filtered, then decimated to 4 kHz |

Each outer loop runs at roughly 5–10× lower bandwidth than the loop inside it.

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle: θ_e = p·(θ_m − θ_offset)

**Clarke transform (amplitude-invariant):**
- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**
- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park transform:**
- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Plant and decoupled PI controller

The dq-frame plant is:
- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ_m

Choose the PI zero to cancel the electrical pole at R/L:
- K_p,i = L·ω_c
- K_i,i = R·ω_c

This gives a closed-loop response of i/i* = ω_c / (s + ω_c).

**Choosing ω_c.** Pick ω_c ≈ 2π·1.5 kHz. This keeps ω_c·(1.5·T_pwm) < 0.3 rad, so the PWM and computation delay costs less than about 17° of phase margin.

**Decoupling feedforward** (added to the PI outputs):
- v_d,ff = −ω_e·L·i_q
- v_q,ff = ω_e·(L·i_d + λ_m)

### 1.3 Voltage limiting and SVPWM

**Circular voltage limit.** The magnitude is bounded by |v_dq| ≤ V_dc/√3. Give the d-axis priority:
- v_q,max = √(V_max² − v_d²)

**Min-max zero-sequence injection** (equivalent to SVPWM):
- v_0 = −(max(v_a, v_b, v_c) + min(v_a, v_b, v_c)) / 2
- duty_x = ½ + (v_x + v_0) / V_dc
