# Job #49: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

## 0. Assumptions

I don't have the Job #49 spec sheet. The design below uses typical values for a camera gimbal of this class. Every assumption is a named constant in the code, so you only need to change those to match your hardware.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 (Cortex-M4F/M7, single-precision FPU) |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| Current sense | 2-shunt low-side, synchronous ADC sampling at PWM center |

| Velocity (rate) loop | 4 kHz, driven by gyro data-ready |
| Angle (attitude) loop | 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz gyro / 4 kHz accel |
| Gimbal order | Base → Yaw → Roll → Pitch → Camera |

## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

Here $\theta_{m,0}$ is found at calibration by aligning the d-axis with $V_d>0,\ V_q=0$.

Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant model (SPMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 1.3 Current PI with decoupling

Feed-forward cancels the cross-coupling and back-EMF terms:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m)$$

What remains is a first-order plant $1/(Ls+R)$. Pole-zero cancellation with target bandwidth $\omega_c$ gives

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; \frac{I(s)}{I^*(s)} = \frac{\omega_c}{s+\omega_c}$$

Choose $\omega_c \le 2\pi f_{PWM}/20$. At 20 kHz this means $f_c \approx 1$ kHz.

Discrete form (forward Euler, $T_c = 1/f_{PWM}$), with back-calculation anti-windup:

$$u_k = K_p e_k + I_k + v^{ff}$$
$$\bar u_k = \mathrm{sat}(u_k)$$
$$I_{k+1} = I_k + K_i T_c e_k + K_{aw}(\bar u_k - u_k)$$

Use $K_{aw} = 1$ in normalized form, i.e. the integrator is clamped by the excess.
