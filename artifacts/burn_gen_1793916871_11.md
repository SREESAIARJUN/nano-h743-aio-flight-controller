# STM32H743 Nano AIO with 80 A Burst 4-in-1 ESC: Design Reference (Job #18)

**Scope:** Electrothermal loss model, ArduPilot bidirectional DShot600 timer and DMA allocation, reference netlists, and thermal budget.

---

## 0. Architecture Corrections and Assumptions

Two points about the brief need correcting before the math.

1. **The H743 does not commutate the motors.** In every production 4-in-1 design, each motor channel has its own ESC MCU running AM32 or BLHeli_32. Typical choices are the AT32F421 or STM32G071. The 48 kHz PWM is generated there. The H743 runs ArduPilot and sends bidirectional DShot600 to the four ESC MCUs. This document models both domains on that basis.

2. **80 A is only a burst rating at nano size.** On a 20×20 or 30.5×30.5 board, 80 A per channel is thermally a burst rating of a few seconds, never a continuous one. Section 3 quantifies this. Treat 80 A as a ≤3–5 s rating with all four motors loaded. Market it as "80 A burst / 45–55 A continuous with airflow."

## 1. Conduction Loss Model

### 1.1 Current Path

In each 60° commutation sector, one phase leg is PWM-switched and one leg is held static (low-side on). With complementary PWM, current always flows through exactly **two MOSFET channels**, regardless of duty D:

- **During the D interval:** HS(switching leg) and LS(static leg) conduct.
- **During the 1–D interval:** LS(switching leg, synchronous rectification) and LS(static leg) conduct.

### 1.2 Per-Channel Conduction Loss

```
P_cond = I_rms² · [2·R_ds(T_j) + R_pcb]
R_ds(T_j) = R_ds,25 · [1 + α·(T_j − 25)]
I_rms² = I_dc² + ΔI²/12        (inductor ripple term)
```

**Ripple term.** Motor phase-to-phase inductance L_pp is about 20 µH for a 2306–2810 class motor. Worst case is D = 0.5:

```
ΔI = V_bus·D·(1−D) / (L·f_sw) = 25.2 · 0.25 / (20e-6 · 48e3) = 6.6 A
ΔI²/12 = 3.6 A²
```

This is negligible next to 6400 A².

### 1.3 Electrothermal Fixed Point

Iterate to a self-consistent junction temperature:

| T_j (°C) | R_ds (mΩ) | P_cond per channel (W) |
|---|---|---|
| 25 | 1.20 | 6400 · (2.40 + 0.30)e-3 = **17.3** |
| 100 | 1.61 | 6400 · 3.52e-3 = **22.5** |
| 125 | 1.74 | 6400 · 3.78e-3 = **24.2** |

**Design value:** P_cond ≈ 24 W per channel at 80 A, hot. That is about 97 W for all four channels.

Instability check: the loop is stable if dP/dT · Z_th < 1. The derivative is dP/dT = 6400 · 2 · 1.2e-3 · 0.0045 = 0.069 W/K, which is stable for any realistic Z_th below about 14 K/W.

### 1.4 Per-FET Distribution

Averaged over a full electrical revolution, each of the six FETs carries about 1/6 of the channel loss:

```
P_FET,avg ≈ 24 / 6 = 4.0 W
```

The **sector-peak** dissipation matters at low eRPM. In that regime the static low-side FET carries the full I²R for an entire 60° sector:

```
P_FET,peak = 6400 · 1.74e-3 = 11.1 W
```

The low-eRPM, high-current condition (punch-out from hover, prop strike) therefore sets the transient junction stress, not the average.

## 2. Switching Loss Model at 48 kHz

Only the switching leg contributes. One HS/LS pair per channel is hard-switched at a time.

### 2.1 Loss Components

**(a) V–I overlap loss in the HS FET:**

```
P_ov = ½ · V_bus · I · (t_r + t_f) · f_sw
     = 0.5 · 25.2 · 80 · 30e-9 · 48e3 = 1.45 W
```

**(b) Dead-time body-diode conduction in the LS FET** (two transitions per period):

```
P_dt = V_f · I · 2·t_dead · f_sw
     = 0.8 · 80 · 200e-9 · 48e3 = 0.61 W
```

**(c) Reverse recovery** (LS diode recovered by HS turn-on):

```
P_rr = Q_rr · V_bus · f_sw = 40e-9 · 25.2 · 48e3 = 0.048 W
```

Q_rr scales with I and di/dt. Budget 2× margin: 0.10 W.

```
P_oss = ½ · C_oss · V_bus² · f_sw · 2 = 1e-9 · 635 · 48e3 = 0.03 W
