# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power, Thermal, and DShot Architecture

## 0. Scope, Assumptions, and a Feasibility Warning

The original request contains no device datasheets or board stackup, so every number below comes from stated, editable assumptions. Treat the netlists as a reference topology. They need verification against the actual BOM before layout release.

**Architecture split.** On an AIO board the STM32H743 does not drive the MOSFETs. It runs ArduPilot and emits bidirectional DShot600. Each ESC channel has its own small MCU (e.g., AT32F421 running AM32, or EFM8/BLHeli_S-class). That MCU owns the 48 kHz PWM, the gate drivers, and commutation. The model below is built on that split.

**Feasibility warning.** An 80 A per-channel burst on a 20×20 or 25.5×25.5 mm board is physically aggressive. As derived in §1, the board dissipates about 100 W at full burst. The result is a burst limited to roughly 1–2 s, with continuous capability far lower. Any datasheet claiming "80 A" on this form factor should be read as a short burst into thermal capacitance.

## 1. Loss Model (per ESC channel)

### 1.1 Current Topology

In six-step commutation, two phase legs conduct at any instant:

- **PWM leg.** HS is ON for D·T_sw and LS is ON for (1−D)·T_sw. Synchronous rectification means the leg always carries I_ph through one FET.
- **Return leg.** The LS FET is ON continuously, carrying I_ph.

Battery current relates to phase current by I_bat = D·I_ph. The "80 A" rating is interpreted as phase current.

### 1.2 Conduction Loss

Temperature-dependent resistance:

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)]$$

Per channel, two legs conduct I_ph at all times, ignoring dead time:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{ds}(T_j)$$

Each FET conducts for 1/3 of the electrical period. Averaged over a commutation cycle, the per-FET loss is:

$$P_{cond,FET} = \frac{P_{cond,ch}}{6}$$

The worst instantaneous per-FET loss is I²·R. Because the electrical frequency is several kHz, this ripple is thermally averaged by the junction's thermal time constant.
