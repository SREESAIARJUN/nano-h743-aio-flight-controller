# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #7): Power-Stage Loss Model, Thermal Analysis, ArduPilot Bi-Directional DShot600 Timer/DMA Plan, and Reference Netlists

## 0. Scope, Architecture, and Stated Assumptions

**Architecture.** The STM32H743 does not commutate the motors. It runs ArduPilot and emits bi-directional DShot600. Four dedicated ESC MCUs drive the power stage:

- **MCU options:** AT32F421 running AM32, or STM32G071 running BLHeli_32/AM32.
- **Drive scheme:** each ESC MCU drives a 3-phase gate driver and six N-channel MOSFETs, arranged as 3 half-bridges per motor.

**Parameterization.** No MOSFET part number was specified, so every equation below is parametric. The worked numbers use a representative 40 V, 3.3×3.3 mm dual-N half-bridge class device. **Substitute the real datasheet values before release.**

| Symbol | Meaning | Assumed value |
|---|---|---|
| V_bus | 6S, full charge | 25.2 V |
| I_burst | Per-motor phase current, burst | 80 A |
| f_sw | PWM frequency | 48 kHz |
| R_ds(on),25 | Per switch, V_GS = 10 V | 1.0 mΩ |
| α | R_ds temperature coefficient | 0.005 /K (≈1.5× at 125 °C) |
| t_r, t_f | Effective V–I overlap times, driver-limited | 20 ns each |
| t_dt | Dead time, each edge | 200 ns |
| V_SD | Body-diode forward voltage at 80 A | 0.8 V |
| Q_rr | Reverse-recovery charge | 50 nC |
| Q_g | Total gate charge at 10 V | 50 nC |
| C_oss(er) | Energy-related output capacitance | 2 nF |
| R_cu | Copper/via resistance per conduction path | 0.5 mΩ |
| T_amb | Ambient temperature | 40 °C |

**Feasibility warning.** On a 20×20 or 25.5×25.5 mm "nano" board, 80 A per motor can only be a **seconds-long burst**, never a continuous rating. Section 3 quantifies this.

## 1. Conduction Loss Model

### 1.1 Current paths

The model assumes trapezoidal (6-step) commutation with synchronous complementary PWM:

- At any instant, current flows through two phases.
- During the ON interval, it flows through HS(a) and LS(b).
- During the OFF interval (synchronous rectification), it flows through LS(a) and LS(b).

So the motor current always passes through exactly **two MOSFET channels in series**, independent of duty cycle D. The only exception is the dead-time intervals (Section 2.3).

With phase current I_ph and small ripple, the RMS current equals I_ph. Including ripple:

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12}, \qquad \Delta I_{pp} = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

For a typical 5–7" motor, L_ph is about 10–30 µH. Ripple then adds under 1% at 80 A, so it is ignored below.

### 1.2 Temperature-coupled R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

$$P_{cond} = I_{ph}^2 \,[\,2R_{ds}(T_j) + R_{cu}\,]$$

### 1.3 Worked numbers per ESC channel at 80 A

| T_j | R_ds | P_cond = 6400 × (2R_ds + 0.5 mΩ) |
|---|---|---|
| 25 °C | 1.0 mΩ | **16.0 W** |
| 100 °C | 1.375 mΩ | **20.8 W** |
| 125 °C | 1.5 mΩ | **22.4 W** |

The I² dependence means that halving the current to 40 A cuts conduction loss to ¼.

## 2. Switching Loss Model at f_sw = 48 kHz

Only one switch per motor is hard-switched per PWM period: the HS of the PWM'd phase, with its LS partner as the synchronous rectifier.

### 2.1 V–I overlap loss

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 40\text{ns} \times 48\text{k} = \mathbf{1.94\ W}$$

Refined form using driver-limited transition times:

$$t_r \approx \frac{Q_{gd} + Q_{gs2}}{I_{G,on}}, \qquad I_{G,on} = \frac{V_{DRV} - V_{plateau}}{R_{G,ext} + R_{G,int} + R_{drv,on}}$$

### 2.2 Reverse recovery and C_oss

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.06\ W}$$

$$P_{oss} = \tfrac12 C_{oss(er)} V_{bus}^2 f_{sw} \times 2 = \mathbf{0.06\ W}$$

### 2.3 Dead-time body-diode conduction

There are two dead-time intervals per period:

$$P_{dt} = V_{SD} I_{ph} (2 t_{dt}) f_{sw} = 0.8 \times 80 \times 400\text{ns} \times 48\text{k} = \mathbf{1.23\ W}$$

This term is often neglected, but here it is **about 60% of the V–I loss**. Cutting dead time to 100 ns, if the driver and MOSFET permit, saves about 0.6 W per channel.

### 2.4 Gate drive

This loss is dissipated mostly in the driver and gate resistors, not the MOSFET:

$$P_g = Q_g V_{GS} f_{sw} \times n_{switching}$$

With 2 switching FETs: 50 nC × 10 V × 48 kHz × 2 = **0.05 W** per channel. This is negligible thermally but matters for the 10 V regulator budget: ≈5 mA per channel, 20 mA total.

### 2.5 Per-channel total at 80 A, T_j ≈ 125 °C

| Term | Loss (W) |
|---|---|
| Conduction | 22.4 |
| V–I switching | 1.94 |
| Dead-time diode | 1.23 |
| Q_rr + C_oss | 0.12 |
| Gate | 0.05 |
| **Per ESC channel** | **≈ 25.7 W** |
| **4-in-1, all four at burst** | **≈ 103 W** |

Plus the input path, which is **ESR-dependent and must be measured**:

- Bulk capacitor ripple loss.
- Battery pad/shunt loss: about 6–10 W at 320 A total through 0.1 mΩ.
