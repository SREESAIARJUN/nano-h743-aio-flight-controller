# STM32H743 AIO "Nano" FC + 4-in-1 ESC: Engineering Model (Job #12)

## 0. Scope, Assumptions, and Architectural Corrections

**Architectural corrections**

1. **The H743 does not run the ESC.** The STM32H743 is the flight controller running ArduPilot. Commutation and the 48 kHz PWM run on separate ESC MCUs, typically one AT32F421 or STM32G071 per channel running AM32 or BLHeli_32. The H743 only generates DShot600 and receives eRPM telemetry.
2. **"80 A burst" on a nano board is thermally a few-second rating.** Section 3 derives the actual time limit. The figures below show it is achievable only for about 4–5 s from cold, and only with prop wash.

## 1. Conduction Loss Model

**Conducting devices.** In 6-step commutation with synchronous rectification, current always flows through exactly two FET channels:

- **PWM on:** HS(phase A) + LS(phase B)
- **PWM off:** LS(phase A) + LS(phase B) (synchronous freewheel)

So, independent of duty cycle:

$$P_{cond,ch} = 2\, I^2\, R_{DS(on)}(T_j)$$

**Temperature coefficient:**

$$R_{DS(on)}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.0045\ /\mathrm{K}$$

At T_j = 110 °C: R ≈ 1.0 mΩ × 1.38 ≈ **1.4 mΩ**.

$$P_{cond,ch} = 2 \times 80^2 \times 1.4\,\text{m}\Omega = \mathbf{17.9\ W}$$

**Copper loss.** Take an effective path resistance of ~0.5 mΩ per channel (phase pours + bus share + pads):

$$P_{Cu,ch} = 80^2 \times 0.5\,\text{m}\Omega = \mathbf{3.2\ W}$$

**Thermal runaway check.** The loop gain is dP/dT_j × R_th,eff. It stays below 1 in Section 3, so the operating point is stable but highly sensitive.
