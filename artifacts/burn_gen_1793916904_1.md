## 0. Architecture and Assumptions

I don't have the original specification for Job #48, so this package uses the explicit, conservative baseline below. All equations are parametric. Substitute your real MOSFET datasheet values and PCB stack-up and the numbers update directly.

### 0.1 Architectural correction

The H743 does not switch the MOSFETs. A 48 kHz 6-step or FOC commutation loop must run on dedicated ESC MCUs. The control chain is:

```
STM32H743 (ArduPilot) ──DShot600 bidir (1-wire ×4)──► 4× ESC MCU (AT32F421 / AM32, PWM 48 kHz)
                                                         └─► 3-ph gate driver ─► 6× N-FET per motor
```
