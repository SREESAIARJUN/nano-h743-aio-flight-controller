# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the Job #17 specification, so this design states its assumptions explicitly. Every parameter is in one config struct, so you can substitute your real motor, encoder and MCU values.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC, 12N14P, pole pairs p = 7, R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) over SPI, sampled each PWM cycle |
| Current sensing | 2- or 3-shunt, inline or low-side, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, mirrored mounting |
| PWM | 20 kHz center-aligned |

**Loop timing**

```
 Attitude (IMU fusion)   2 kHz ─┐
 Angle loop  (P/PI)      2 kHz  │  ω_ref + ω_ff
 Rate loop   (PI+D)      4 kHz  │  i_q_ref
 Anti-cogging FF         20 kHz │  + i_cog(θ_m)
 Current loop (PI dq)    20 kHz ┘  → SVPWM
```

**Bandwidth separation rule.** Each outer loop should be at least 5× slower than the loop inside it:

ω_c,i ≈ 2π·1.5 kHz, ω_v ≈ 2π·60–120 Hz, ω_θ ≈ 2π·10–25 Hz.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform**, using electrical angle θ_e:

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Electrical angle with transport-delay compensation.** The PWM update lands about 1.5 periods after sampling, so the angle is advanced accordingly:

θ_e = p·θ_m − θ_off + 1.5·T_s·ω_e, where ω_e = p·ω_m

### 1.2 Plant model (surface PMSM, L_d ≈ L_q = L)

- v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
- v_q = R·i_q + L·di_q/dt + ω_e·L·i_d + ω_e·λ

Torque:

τ = K_t·i_q, with K_t = (3/2)·p·λ

### 1.3 Current PI controller with decoupling

Pole-zero cancellation of the R/L plant gives a first-order closed loop with bandwidth ω_c:

- K_p,i = L·ω_c
- K_i,i = R·ω_c

Control law:

- v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
- v_q* = PI_q(i_q* − i_q) + ω_e·(L·i_d + λ)

The reference is i_d* = 0 (no field weakening on gimbal motors).

**Voltage-vector limiting with anti-windup.** The voltage vector is limited to |v| ≤ V_max = V_bus/√3 (the linear SVPWM region). Priority goes to d, and v_q gets the remainder:

v_q,max = √(V_max² − v_d²)

Anti-windup uses back-calculation on each integrator I:

I[k+1] = I[k] + T_s·( K_i·e + K_aw·(u_sat − u) ), with K_aw ≈ K_i / K_p

### 1.4 Voltage-mode fallback

High-R gimbal motors without current sensors can use a voltage-mode fallback:

v_q = R·i_q* + ω_e·λ, with v_d = −ω_e·L·i_q*

### 1.5 SVPWM by min-max zero-sequence injection

Equivalent to 7-segment SVPWM:

- Inverse Park:
  - v_α = v_d·cos θ_e − v_q·sin θ_e
  - v_β = v_d·sin θ_e + v_q·cos θ_e
- Phase voltages:
  - v_a = v_α
  - v_b = −½·v_α + (√3/2)·v_β
  - v_c = −½·v_α − (√3/2)·v_β
- Zero-sequence offset: v_0 = −½·( max(v_a, v_b, v_c) + min(v_a, v_b, v_c) )
- Duty cycle for each phase x: D_x = ½ + (v_x + v_0) / V_bus

## 2. Cascaded Rate and Angle Control

### 2.1 Mechanical plant

J·dω/dt = K_t·(i_q + i_cog) − τ_cog(θ) − B·ω − τ_d

Here τ_d is the disturbance from base motion, cable drag and imbalance. The anti-cogging term i_cog cancels τ_cog (Section 3).

### 2.2 Rate feedback: which ω to use

- **Stabilization mode.** ω is the inertial angular rate of the payload projected onto the joint axis, taken from the fused gyro:
  - ω_meas = ê_jᵀ·R_jc·ω_cam
  - The joint-axis vector ê_j is expressed in the camera frame through the downstream joint rotations.
  - For pitch (the innermost joint) this reduces to the camera-frame y-axis.
  - For roll and yaw, use the gimbal Jacobian: ω_cam = J(q)·q̇ + R_cbᵀ·
