# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the specification for "Job #56", so this design rests on the explicit assumptions in §0. Every motor, IMU and timing constant is a parameter, so you can substitute your real values without changing the structure.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC, 12N14P, so pole pairs p = 7. R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), 16384 counts/rev |
| Current sense | 2 or 3 inline/low-side shunts, synchronous ADC |
| PWM | 25 kHz center-aligned |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, gyro/accel ODR 8 kHz, shared CLKIN |
