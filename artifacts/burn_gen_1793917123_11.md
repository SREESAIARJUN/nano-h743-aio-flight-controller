# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #41): Power, Thermal, and DShot Architecture Model

## 0. Scope and Ground Rules

**Architecture.** In any ArduPilot-compatible 4-in-1 design, the STM32H743 does not generate the 48 kHz gate PWM. The H743 runs ArduPilot and emits bidirectional DShot600. Four dedicated ESC MCUs run AM32 or BLHeli_32 and generate the 48 kHz complementary PWM into the gate drivers. The model below follows that split:

```
LiPo ─┬─ Bulk C ─┬─ ESC1..4 power stages (6× N-FET each, 3-phase driver)
      │          └─ ESC MCU ×4 (AT32F421 / STM32G071 class, AM32/BLHeli_32)
      │                 ▲ DShot600 bidir (1 wire each)
      └─ BEC 5V/3V3 ─ STM32H743 (ArduPilot) ─ TIM1 CH1-4
```

**Unverified values.** Every component value marked † is a placeholder. It must be replaced with figures from the selected part's datasheet before release. The equations are the deliverable; the numbers show the method and expose the design risks.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

The ESC uses trapezoidal six-step commutation with synchronous (complementary) PWM. During any 60° sector, phase A is PWM-switched and phase B is held low:

- **On-time (D):** current flows through HS_A, the motor, then LS_B.
- **Off-time (1−D):** current flows through LS_A (synchronous rectification), the motor, then LS_B.

LS_B conducts 100% of the time. Phase A's two FETs share the conduction between them.

### 1.2 Equations

Temperature-corrected on-resistance:

$$R_{ds}(T_j) = R_{ds,25}\left[1+\alpha(T_j-25)\right] \approx R_{ds,25}\,k_T$$

Conduction loss per ESC:

$$P_{cond} = I^2 R_{ds}(T_j)\left[\underbrace{D}_{HS_A} + \underbrace{(1-D)}_{LS_A} + \underbrace{1}_{LS_B}\right] = 2\,I^2 R_{ds}(T_j)$$

This result is independent of duty cycle. That is the key property of synchronous rectification.

### 1.3 Numbers

- R_ds,hot = 1.5 mΩ × 1.6 = 2.4 mΩ
- P_cond = 2 × 80² × 0.0024 = **30.7 W per ESC**
- Worst single FET (LS_B, 100% duty): 80² × 0.0024 = **15.4 W**

### 1.4 Shunt and copper losses

The DC-link current is approximately D·I, with RMS ≈ I√D. At D = 0.8:

- P_shunt ≈ 80² × 0.8 × 0.0005 ≈ **2.6 W**
- Add PCB trace and via loss, P_Cu = I²·R_trace. A 2 oz, 10 mm × 3 mm trace is about 0.8 mΩ, giving roughly **5 W**. Budget at least 2–3 W per ESC even with heavy copper and solder-flooded pads.

## 2. Switching Loss Model (48 kHz)

Switching losses accrue per switched leg (phase A), once per PWM period.

### 2.1 Hard-switching V-I overlap

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 35\text{e-}9 \times 48\text{e}3 = \mathbf{1.69\ W}$$

### 2.2 Reverse recovery (LS body diode recovered by HS turn-on)

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\text{e-}9 \times 25.2 \times 48\text{e}3 = \mathbf{0.048\ W}$$

The Q_rr current spike also adds to HS turn-on loss. A conservative engineer can add about 1·Q_rr·V·f again.

### 2.3 Output capacitance

$$P_{oss} \approx \tfrac12 Q_{oss} V_{bus} f_{sw} = \mathbf{0.018\ W}$$
