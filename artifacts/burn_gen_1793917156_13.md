## 0. Architecture Clarification

The STM32H743 does **not** commutate the MOSFETs. In a 4-in-1 AIO design it runs ArduPilot and sends bi-directional DShot600 to **four independent ESC MCUs** (AT32F421 running AM32 here). Each ESC MCU runs its own 48 kHz PWM, gate driver, and back-EMF commutation. The losses in §2–§4 come from the ESC side. The H743 work in §6 concerns DShot generation and eRPM capture only.

```
6S LiPo ──┬── Bulk caps ──┬── 4× [AT32F421 → FD6288Q → 6× N-MOSFET] → M1..M4
          │               └── Current shunt → INA → H743 ADC
          └── Buck 10V (gate drive) / Buck 5V → LDO 3.3V → STM32H743 FC
H743 TIM1 CH1..4 ──(bi-dir DShot600, 1 wire per motor)──> ESC1..4 signal pins
```
