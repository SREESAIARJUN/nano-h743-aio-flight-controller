## 0. Scope and Assumptions

No MOSFET part number, layer stack, board size or battery voltage was specified, so this model is fully parameterized. A worked example uses representative values. **Replace the starred (★) values with datasheet and stack-up data before sign-off.**

### 0.1 Architecture

The STM32H743 does not commutate the motors. It runs ArduPilot and talks to the ESCs over bi-directional DShot600. Each motor channel has its own ESC MCU running AM32 or BLHeli_32, for example an AT32F421 or STM32G071. Having the H743 commutate the motors directly is not supported by ArduPilot.

### 0.4 Commutation scheme

The model assumes six-step trapezoidal commutation with synchronous rectification (complementary PWM). This is the AM32/BLHeli_32 default.

## 1. Conduction Loss Model

### 1.1 Current paths

In any commutation sector, two phases conduct:

- **Leg A (PWM leg):**
  - High-side switch HS_A is on for duty D.
  - Low-side switch LS_A is on for (1 − D), carrying freewheel current via synchronous rectification.
- **Leg B (return leg):** LS_B is on 100 % of the sector.
- **Leg C:** floating.
