# 3-Axis Gimbal: FOC Motor Control, Cogging Compensation, and Dual-IMU Fusion

I don't have the Job #25 specification, so this design assumes the following typical hardware. Each assumption is parameterized in the code, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motors, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoders | 14-bit absolute magnetic encoder per joint (e.g., AS5048A / MT6701) |
| MCU | Cortex-M7 with FPU (STM32H7 class) |
| PWM | 20 kHz center-aligned, 3-shunt current sensing |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, 8 kHz ODR, data-ready interrupt |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

## 1. Loop Architecture and Timing

```
                 ┌───────────────── 1 kHz ─────────────────┐  ┌──── 4 kHz ────┐  ┌──── 20 kHz ─────┐
q_ref ─► Attitude │ q_err → e_body → J⁻¹(θ) → θ̇_ref (joint) │─►│ Velocity PI   │─►│ Current PI (d,q)│─► SVPWM ─► Motor
         error    └──────────────────────▲──────────────────┘  │ + accel FF    │  │ + decoupling    │
                                         │                     │ + cogging FF  │  │ + BEMF FF       │
   IMU A ─┐ 8 kHz  AAF → notch → LPF     │ q̂ (Mahony)          └──────▲────────┘  └──────▲──────────┘
   IMU B ─┴─► rotate → lever-arm → fuse ─┴─► ω̂_cam ──► J⁻¹ ─► θ̇_joint ─┘ (blended w/ encoder)  │ i_abc, θ_enc
```

Each loop should run at least 5× slower than the loop inside it:

- **Current loop:** f_bw ≈ 1.5–2 kHz, executed at 20 kHz.
- **Velocity loop:** f_bw ≈ 150–250 Hz, executed at 4 kHz.
- **Attitude loop:** f_bw ≈ 25–40 Hz, executed at 1 kHz.

## 2. FOC Current Loop

### 2.1 Transforms

Electrical angle, where p is the number of pole pairs and θ_off is found by alignment at startup:

$$\theta_e = p\,(\theta_m - \theta_{off})$$

Clarke transform (amplitude-invariant; with 3 shunts you can use i_c to reject offset):

$$i_\alpha = \tfrac{2}{3}i_a - \tfrac{1}{3}(i_b+i_c), \qquad i_\beta = \tfrac{1}{\sqrt3}(i_b - i_c)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
