# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the spec for Job #44, so the design below states its assumptions explicitly (§0). Every motor and IMU parameter is collected in config structs, so you can substitute your actual hardware values.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7 class: Cortex-M4F/M7, single-precision FPU, CORDIC optional |
| Motors | 3× gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A/MT6701 class) |
| Current sense | 2- or 3-shunt, sampled at the PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz gyro ODR |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries the camera) |
| Disturbances | Prop/rotor vibration at 50–400 Hz with harmonics, plus frame structural modes |
