# STM32H743 Nano FC + 80 A 4-in-1 ESC: Power-Stage, Thermal and DShot/DMA Design Package

## 0. Scope and Assumptions

I don't have prior context for "Job #4," so this package is built on the assumptions below. Every equation is parameterized, so you can substitute your actual BOM values.

### 0.1 Architecture

The STM32H743 runs ArduPilot on the flight controller. Each motor channel on the 4-in-1 ESC needs its own commutation MCU (AT32F421 or STM32G071 running AM32/BLHeli_32). The H743 does not commutate the motors. It generates bidirectional DShot600 and captures the eRPM telemetry that comes back.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

The total on-path resistance per FET is:

$$R_{on}(T_j) = R_{25}\,[1+\alpha(T_j-25)] + R_{pcb}$$

R_pcb is about 0.15 mΩ per FET path (copper plus solder). At an initial guess of T_j = 110 °C:

R_on = 0.70 × 1.383 + 0.15 = **1.118 mΩ**

### 1.2 Six-step current-sharing derivation

Over one electrical cycle, each phase spends 120° in each of three states:

- **High (PWM leg):**
  - The high-side FET conducts for a fraction D.
  - The low-side FET conducts for (1 − D) as the synchronous rectifier.
- **Low (return leg):** the low-side FET is fully on.
- **Floating:** neither FET conducts.

Averaging these states gives the loss per FET:

$$P_{HS} = \tfrac{1}{3}D\,I^2R_{on}$$

$$P_{LS} = \tfrac{1}{3}(1-D)\,I^2R_{on} + \tfrac{1}{3}I^2R_{on}$$

$$P_{cond,channel} = 3(P_{HS}+P_{LS}) = 2\,I^2R_{on}\quad\text{(independent of D)}$$

### 1.3 Numerical values

With I²R_on = 6400 × 1.118 mΩ = 7.16 W:

| Element | Loss |
|---|---|
| P_HS | 0.30 × 7.16 = **2.15 W** |
| P_LS | (0.0333 + 0.3333) × 7.16 = **2.62 W** |
| P_cond per channel | **14.3 W** |
