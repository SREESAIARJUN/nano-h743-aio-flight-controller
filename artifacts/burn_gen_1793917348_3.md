# FOC Motor Control and Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #42, so this design is built on the **assumptions in §0**. Each assumption is a single constant in the code. Change them to match your hardware before you tune anything.

---

## 0. Assumed Hardware and Loop Rates

| Item | Assumption |
|---|---|
| MCU | STM32G4 / H7 class (FPU, ≥170 MHz), center-aligned PWM |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Rotor encoder | 14-bit magnetic encoder (AS5047P / MT6835 class), SPI |
| Current sense | 2- or 3-shunt, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI chip-selects, 8 kHz ODR, data-ready interrupt or FIFO |
| Rates | Current loop 20 kHz · Velocity loop 4 kHz · Angle loop / AHRS 1 kHz · IMU 8 kHz |

**Timescale-separation rule used throughout:**

$$\omega_{c,i} \ge 10\,\omega_{c,v} \ge 40\,\omega_{c,\theta}$$

Each inner loop must be at least about 4–10× faster than the loop around it.
