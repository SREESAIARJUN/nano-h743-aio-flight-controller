## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class (FPU, ≥170 MHz), single-precision `float` |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs *p* = 7), R ≈ 5–15 Ω, L ≈ 1–4 mH |
| Driver | 3-phase, center-aligned PWM 20 kHz, 2- or 3-shunt current sensing |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, separated by lever arm **d** |
| Topology | Yaw (outer) → Roll → Pitch (inner/camera) |
