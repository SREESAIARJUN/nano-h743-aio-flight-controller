# STM32H743 Nano FC with 80 A 4-in-1 ESC: System Model (Job #46)

## 0. Scope and Assumptions

I don't have the Job #46 BOM or prior design notes, so this model is fully parameterized. Every number marked **[A]** is an assumption. Replace it with your datasheet value and the equations still hold.

There is one architectural point to settle first. The H743 does not drive the MOSFET bridges. In a 4-in-1 stack, each motor has its own ESC MCU, such as an AT32F421 running AM32 or BLHeli_32, plus a 3-phase gate driver. That ESC MCU generates the 48 kHz PWM. The H743 only sends bidirectional DShot600 and receives eRPM telemetry back. The model below is split along that boundary.

**Feasibility flag:** 80 A/channel on a true 20×20 mm nano footprint is not thermally sustainable. The numbers below show it is burst-only (seconds), even on a 30.5×30.5 mm board. Treat "80 A" as a transient rating and derive the continuous rating from §3.

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step commutation with synchronous rectification, consider sector A+/B−:
- **PWM on-time (D):** current flows through HS_A and then LS_B.
- **PWM off-time (1−D):** current flows through LS_A (synchronous freewheel) and then LS_B.

So exactly **two FETs are in series at all times**, independent of duty cycle.

### 1.2 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R = 1.0 × 1.5 = **1.5 mΩ**.

### 1.3 Bridge conduction loss

$$P_{cond,bridge} = 2\,I_{rms}^2\,R_{ds}(T_j)\left(1 + \frac{\Delta i_{pp}^2}{12\,I^2}\right)$$

With ripple neglected (phase inductance is large enough at 48 kHz):

$$P_{cond,bridge} = 2(80)^2(1.5\times10^{-3}) = \mathbf{19.2\ W\ per\ motor}$$

### 1.4 Per-FET distribution

Each FET conducts for 1/3 of the electrical cycle, so the bridge loss is shared as follows:
- **Instantaneous** per conducting FET: I²R = **9.6 W**.
- **Averaged** per FET: 19.2 / 6 = **3.2 W**. This average is valid only when the electrical period is much shorter than the die thermal time constant (roughly ms). That holds at any normal eRPM.
- **Low-RPM or stall** is the worst case. One FET can sit at 9.6 W for several milliseconds, which is the desync/stall-burn mechanism.

### 1.5 Self-consistent junction temperature

R_ds depends on T_j, and T_j depends on loss, so solve the fixed point:

$$T_j = T_{ref} + R_{\theta}\,I^2 R_{25}[1+\alpha(T_j-25)] \;\Rightarrow\; T_j = \frac{T_{ref} + R_\theta I^2 R_{25}(1-25\alpha)}{1 - R_\theta I^2 R_{25}\alpha}$$

The denominator defines thermal runaway: the device runs away if

$$R_\theta \, I^2 R_{25}\, \alpha \ge 1$$

At 80 A that gives R_θ ≥ 31 K/W. That is only reachable with no copper at all, so single-FET runaway is not the practical limiter. Board heat capacity is (see §3).
