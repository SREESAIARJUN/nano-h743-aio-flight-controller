# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #39): Systems Architecture Package

## 0. Assumptions and Feasibility Finding

I don't have a Job #39 spec sheet, so I've built the model on explicit assumptions. Every equation is parameterized so you can substitute real datasheet values.

| Parameter | Assumed value | Basis |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max, 22.2 V nominal | Typical for 80 A-class ESCs |
| Burst current | 80 A per motor channel, all 4 simultaneously (worst case) | "80 A burst" |
| PWM frequency | f_sw = 48 kHz, complementary (active freewheel) | Spec |
| MOSFET | 40 V N-channel, PDFN5x6, R_DS(on),25 = 1.0 mΩ @ V_GS = 10 V, Q_g = 50 nC, Q_oss = 40 nC, Q_rr = 30 nC, R_θJC = 1.0 K/W | Representative class (e.g., Toshiba/Infineon/Onsemi 40 V parts) |
| Topology | 3 half-bridges per channel, N_p MOSFETs in parallel per switch | N_p = 1 (nano) or 2 (30×30) |
| ESC MCU | 4× AT32F421 or STM32G071 running AM32 | The H743 is the FC; it does not commutate motors |
| Gate driver | FD6288Q (3-phase, 1.5/1.8 A sink/source) per channel | Common AIO choice |
| Max allowed T_J | 125 °C design limit (150 °C absolute) | Derating practice |

> **⚠ Feasibility finding:** A true "nano" (20×20 mm) board **cannot** sustain 4 × 80 A for more than about 1–2 seconds. Section 3 shows the derivation. 80 A burst per channel is realistic only on a **30×30 mm board with paralleled MOSFETs (N_p = 2)**, and even then only for about 5–10 seconds. I recommend you formally choose between:
> - **(a)** Re-rating the nano board to ~45 A burst / 35 A continuous, or
> - **(b)** Moving to a 30×30 form factor for 80 A burst.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_J) = R_{DS,25}\,\big[1 + \alpha\,(T_J - 25)\big],\qquad \alpha \approx 0.005\ \text{K}^{-1}$$

The effective switch resistance with N_p paralleled FETs (ignoring current-sharing imbalance) is:

$$R_{sw} = \frac{R_{DS}(T_J)}{N_p}\cdot k_{share},\qquad k_{share}\approx 1.1 \text{ for } N_p=2$$

### 1.2 Bridge conduction (trapezoidal / 6-step, complementary PWM)

In each 60° commutation sector, current flows through two phase legs:

- **PWM'd phase:** the high-side conducts for D·T_sw. The low-side synchronously rectifies for (1−D)·T_sw. This always amounts to one switch-equivalent in the path.
- **Return phase:** the low-side is held ON for the full sector. This is a second switch-equivalent.

Therefore, independent of duty cycle (with sync rectification):

$$\boxed{P_{cond,ch} = 2\,I^2\,R_{sw}(T_J)}$$

Averaged over the electrical cycle, each of the 6 switch positions carries 1/3 of the time-integrated I²R load:

$$P_{cond,FET} = \frac{P_{cond,ch}}{6\,N_p}$$

### 1.3 Numbers (I = 80 A, T_J = 125 °C → R_DS = 1.5 mΩ)

| Case | R_sw | P_cond per channel | ×4 channels | Per FET |
|---|---|---|---|---|
| Nano, N_p = 1 | 1.50 mΩ | 2·6400·1.5e-3 = **19.2 W** | 76.8 W | 3.2 W |
| 30×30, N_p = 2 | 0.825 mΩ | **10.6 W** | 42.2 W | 0.88 W |

### 1.4 Additional copper and shunt conduction

Trace and plane resistance, assuming 2 oz copper and about 0.3 mΩ effective per channel path:

$$P_{Cu} = I^2 R_{Cu} = 6400\cdot 0.3\text{e-}3 \approx 1.9\ \text{W/channel}$$

This is a non-trivial loss. Use 3 oz outer copper with stitched inner planes.

## 2. Switching Losses at 48 kHz

Only the PWM'd leg (HS + its sync-rectifier LS) switches in each sector.

### 2.1 V-I overlap

$$P_{VI} = \tfrac12\,V_{bus}\,I\,(t_r + t_f)\,f_{sw}$$

With t_r + t_f ≈ 20 ns (FD6288Q, R_g ≈ 4.7 Ω, N_p = 1):

$$P_{VI} = 0.5\cdot25.2\cdot80\cdot20\text{e-}9\cdot48\text{e}3 = 0.97\ \text{W}$$

For N_p = 2, the doubled Q_g slows the edges to about 30 ns, giving **1.45 W**.

### 2.2 Output capacitance

$$P_{oss} = Q_{oss}\,N_p\,V_{bus}\,f_{sw} = 40\text{e-}9\cdot25.2\cdot48\text{e}3 = 0.048\ \text{W}\ (\times N_p)$$

### 2.3 Reverse recovery

$$P_{rr} = Q_{rr}\,N_p\,V_{bus}\,f_{sw} = 30\text{e-}9\cdot25.2\cdot48\text{e}3 = 0.036\ \text{W}\ (\times N_p)$$
