# Job #34: STM32H743 Flight Controller with 4-in-1 80A ESC

## Engineering Design Package, Rev A (Architecture and Analytical Model)

> **Scope note:** This is an analytical architecture package. All MOSFET, driver and PCB parameters are representative values chosen for the model and are flagged **[ASSUMED]**. Before layout freeze, substitute the selected part datasheets and validate with thermocouple and IR testing.
>
> **Architecture finding:** The model shows that **80A per motor is only achievable as a burst of about 5–9 s**, and only on a ≥30.5 mm-pattern board with forced airflow. It is not achievable on a 20×20 "nano" footprint. See §3.4.

## 1. System Architecture

```
          ┌────────────────────── FC BOARD ──────────────────────┐
 6S LiPo  │  STM32H743VIT6 @400 MHz (ArduPilot)                  │
 ──┬──►   │   TIM3_CH3 ─┐                                        │
   │      │   TIM3_CH4 ─┤ Bidirectional DShot600 (1-wire, inv.)  │
   │      │   TIM5_CH1 ─┤ ─────────────── 8-pin JST-SH ─────────┐│
   │      │   TIM5_CH2 ─┘                                       ││
   │      └─────────────────────────────────────────────────────┘│
   │      ┌────────────────────── ESC BOARD ────────────────────┐│
   └──►   │ 4 × AT32F421K8U7 (AM32 firmware), one per motor  ◄──┘│
          │ 4 × FD6288Q 3-phase gate driver                      │
          │ 24 × 40V N-MOSFET (DFN5×6), 1 FET per switch         │
          │ Phase PWM 48 kHz, synchronous rectification          │
          └──────────────────────────────────────────────────────┘
```

The H743 does **not** commutate the motors. Each motor has its own ESC MCU, and the H743 only generates and decodes DShot. This is the standard and only practical topology. Commutating 4 motors at 48 kHz from the FC MCU while also running the EKF is not viable in ArduPilot.

## 2. Electrical Loss Model (Per Motor)

### 2.1 Conduction Losses

The commutation is 6-step trapezoidal with complementary (synchronous) PWM. At any instant exactly **two switches** carry the full phase current: one high-side or its complementary low-side, plus the low-side of the return phase. This holds independent of duty D.

$$R_{DS,hot} = k_T \cdot R_{25} = 1.5 \times 0.80 = 1.20\ \text{m}\Omega$$

$$P_{cond} = 2\, I_{pk}^2\, R_{DS,hot} = 2(80)^2(1.2\times10^{-3}) = \mathbf{15.36\ W}$$

Each FET conducts for 120° of the electrical cycle, so the per-FET average is:

$$P_{cond,FET} = \frac{P_{cond}}{6} = 2.56\ \text{W}$$

Parasitic copper and shunt losses add to this. The phase copper is assumed at R ≈ 0.15 mΩ per path with two paths, and the battery shunt at 0.25 mΩ carries I_bat = D·I:

$$P_{Cu} = 2(80)^2(0.15\text{m}) = 1.92\ \text{W}, \qquad P_{shunt}\big|_{D=1} = 1.60\ \text{W}$$

### 2.2 Switching Losses at 48 kHz

Only one half-bridge is PWM-switching at a time. The other active leg is static.

**Hard-switching V-I overlap:**
$$E_{sw} = \tfrac12 V_{bus} I_{pk}(t_r+t_f) = \tfrac12(25.2)(80)(40\text{ns}) = 40.3\ \mu\text{J}$$
$$P_{sw} = E_{sw} f_{sw} = 40.3\mu \times 48\text{k} = \mathbf{1.94\ W}$$

**Reverse recovery:**
$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 60\text{n}(25.2)(48\text{k}) = 0.073\ \text{W}$$
