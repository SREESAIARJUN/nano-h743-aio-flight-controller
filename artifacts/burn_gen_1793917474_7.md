# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #23): Power-Stage, Thermal, and Bi-Directional DShot600 Design Package

## 0. Architecture and Assumptions

**The H743 does not commutate the motors.** In any practical AIO, the STM32H743 runs ArduPilot and emits bi-directional DShot600. Four ESC MCUs (or one per two channels) run AM32 or BLHeli_32-class firmware and generate the 48 kHz complementary PWM. The derivation below covers both domains.

```
 6S LiPo ──┬── Shunt (Isense) ──► 4× 3-phase bridges (24 MOSFETs)
           │                            ▲ gate drive
           │                    4× FD6288Q-class drivers
           │                            ▲ 6× PWM each @ 48 kHz
           │                    4× ESC MCU (AT32F421 / STM32G071 class, AM32)
           │                            ▲ BDShot600 (1 wire each, bidirectional)
           └── BEC 5V/3V3 ──► STM32H743VIT6 (ArduPilot) TIM1 CH1–CH4
```

**Baseline parameters.** These are representative 40 V, 3.3×3.3 mm DFN-class values. Substitute your actual datasheet numbers.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S fully charged (worst-case switching) |
| I_ph | 80 A | Burst phase current per channel |
| R_ds(on),25 | 1.2 mΩ | @ V_gs = 10 V |
| α | 0.0045 /K | R_ds tempco |
| t_r, t_f | 20 ns each | Gate-resistor dependent (verified in §2.2) |
| Q_g / Q_gd / Q_rr | 40 / 8 / 30 nC | Total gate, Miller, and reverse-recovery charge |
| C_oss | 1.0 nF | MOSFET output capacitance (Coss) |
| V_SD | 0.8 V | Body diode forward voltage |
| t_dt | 100 ns | Dead time per edge |
| f_sw | 48 kHz | Switching frequency |
| V_drv | 10 V | Gate drive voltage |
| Rth_jc | 1.5 K/W | Junction-to-case |

> **Engineering flag:** 80 A burst on a 20×20 mm board is achievable only for sub-second to ~1 s events. The math below shows why. Treat "80 A" as a transient rating, never a continuous one.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step with synchronous rectification

At any instant, two phases carry I_ph:
- **Leg A (PWM leg):** the high-side (HS) conducts during D·T and the complementary low-side (LS) during (1−D)·T.
- **Leg B (return leg):** the LS is held on for the full 60° sector.
