# Job #79: STM32H743 AIO Flight Controller with 4-in-1 ESC (Nano Form Factor)
## Electro-Thermal Model, Bidirectional DShot600 DMA Allocation, and Reference Netlist

## 0. Architecture Assumptions

The H743 does not commutate the motors directly. Industry-standard AIO boards use the H743 as the flight controller running ArduPilot. It sends bidirectional DShot600 to four independent ESC MCUs (AM32 on AT32F421 or STM32G071). Each ESC MCU drives a 3-phase gate driver and six N-FETs. This model follows that topology.

| Parameter | Symbol | Value (baseline) |
|---|---|---|
| Bus voltage (6S) | V_bus | 25.2 V max / 22.2 V nom |
| Burst phase current per motor | I_pk | 80 A, DC-equivalent of 6-step block current |
| PWM frequency | f_sw | 48 kHz |
| Duty at burst | D | 0.95 |
| MOSFET (40 V, DFN5×6 class) | R_ds,on(25 °C) | 1.0 mΩ at V_GS = 10 V |
| R_ds,on temperature coefficient | α | 0.006 /K (fits ×1.6 at 125 °C) |
| Rise / fall time (driver at about 1 A) | t_r / t_f | 15 ns / 12 ns |
| Body-diode Q_rr | Q_rr | 40 nC |
| Effective C_oss (energy-equivalent) | C_oss,er | 1.5 nF |
| Total gate charge | Q_g | 60 nC |
| Dead time | t_dt | 100 ns |
| Body-diode V_f at 80 A | V_f | 0.8 V |
| Current shunt (per ESC) | R_sh | 0.25 mΩ |

**Every numeric result below scales directly with these values.** Substitute the selected FET's datasheet numbers before freezing the design.

## 1. Conduction Loss Model

### 1.1 Six-step conduction pattern with complementary (synchronous) PWM

In each 60° sector, one leg PWMs (HS at duty D, LS at 1−D) and one leg's LS is held on. Each leg spends 120° as the PWM leg, 120° as the static-low leg, and 120° floating.

Per-device RMS current, as fractions of the electrical period:

$$
I_{HS,rms} = I_{pk}\sqrt{\frac{D}{3}}, \qquad
I_{LS,rms} = I_{pk}\sqrt{\frac{(1-D) + 1}{3}} = I_{pk}\sqrt{\frac{2-D}{3}}
$$

### 1.2 Temperature-dependent R_ds(on)

$$
R_{ds}(T_j) = R_{25}\,[1+\alpha (T_j-25)]
$$

### 1.3 Conduction loss per device

$$
P_{c,HS} = I_{pk}^2 R_{ds}(T_j)\frac{D}{3}, \qquad
P_{c,LS} = I_{pk}^2 R_{ds}(T_j)\frac{2-D}{3}
$$

**Worked example** at T_j = 110 °C, where R_ds = 1.0 × (1 + 0.006·85) = 1.51 mΩ:

- I²R = 6400 × 1.51 mΩ = 9.66 W
- P_c,HS = 9.66 × 0.95/3 = **3.06 W**
- P_c,LS = 9.66 × 1.05/3 = **3.38 W**
- Per leg: 6.44 W. **Per motor: 19.3 W.**

### 1.4 Shunt and copper

- Shunt: P_sh = I²_pk · R_sh = 6400 × 0.25 mΩ = **1.6 W per ESC**.
- Copper trace: R_Cu = ρ_Cu(T) · ℓ / (w·t), with ρ_Cu = 1.72×10⁻⁸ [1 + 0.00393(T−20)] Ω·m.
  - A 10 mm × 3 mm path on 2 oz (70 µm) copper at 80 °C is about 0.98 mΩ. That equals one more MOSFET's worth of loss.
  - Mitigation: stitch phase pours on all layers. Target ≤ 0.3 mΩ for the battery-to-FET-to-pad path.
