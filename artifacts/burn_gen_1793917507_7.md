# STM32H743 AIO Flight Controller + 4-in-1 ESC: Reference Architecture (Job #59)

**Scope:** Power-stage loss model, thermal model, DShot600 bidirectional DMA/timer plan for ArduPilot, and reference netlists.

**Status:** This is an engineering reference derivation. All part numbers, pin maps, and numeric results must be verified against current datasheets, the ArduPilot `hwdef` documentation, and bench measurements before fabrication.

---

## 0. Feasibility Constraints

These constraints shape every number that follows.

1. **The H743 does not drive the MOSFETs.** Commercial 4-in-1 ESCs use one dedicated MCU per motor running AM32 or BLHeli_32, typically an AT32F421 or STM32G071. The 48 kHz figure is the PWM frequency set in those ESC MCUs. The H743 only generates DShot600 and decodes eRPM telemetry. The architecture below follows this split.

2. **80 A is a burst rating, not a continuous one.** On a 20×20 mm nano footprint, 80 A per motor is thermally impossible beyond about 1 s. The model below is built on a **30.5×30.5 mm, 8-layer, 2 oz copper** board. Even at that size, 4×80 A is roughly a **2–4 second** event (Section 3). For a 20×20 mm board, plan for about 25–35 A burst.

3. **6S maximum (25.2 V) is assumed.** The MOSFETs are rated 40 V, which leaves margin for ringing. 8S would require 60 V devices and a different gate driver.

| Symbol | Meaning | Value |

| α | R_DS(on) temperature coefficient | 0.005 /K |

| Q_rr | Body-diode reverse-recovery charge | 50 nC |

| V_SD | Body-diode forward voltage | 0.8 V |

### 2.2 Conduction Loss

The drive uses 6-step trapezoidal commutation with complementary (synchronous) PWM. At every instant, the current path is battery → one high-side or low-side switch on the PWM leg → winding → the low-side switch on the return leg. That means **exactly two R_DS(on) are always in series**, regardless of duty cycle D:

$$P_{cond} = 2\,I_{ph}^2\,R_{ds}(T_j), \qquad R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

Distribution within one commutation sector (60° electrical):

- PWM leg high-side: I²·R·D
- PWM leg low-side (synchronous rectification): I²·R·(1−D)
- Return-leg low-side: I²·R·1

Each phase occupies each role for one third of the electrical cycle, so the per-FET average is P_cond/6. However, the **instantaneous hot device is the return-leg low-side**, which carries full current for 120° electrical. Size the thermal design against that device.

**Numeric results at 80 A:**

| T_j | R_ds | P_cond per ESC |
|---|---|---|
| 25 °C | 1.0 mΩ | 2 × 6400 × 1.0 m = **12.8 W** |
| 125 °C | 1.5 mΩ | 2 × 6400 × 1.5 m = **19.2 W** |

**Copper and shunt losses** are additional. A 0.25 mΩ shunt adds 1.6 W. Allow roughly 0.3 mΩ for the copper path, which adds about 1.9 W more.

### 2.3 Switching Loss (PWM Leg Only)

Only the PWM leg hard-switches. The return leg commutates at the electrical frequency, which is negligible.

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·40n·48k | **1.94 W** |
| Reverse recovery | Q_rr·V·f_sw = 50n·25.2·48k | **0.06 W** |
| C_oss | ½·C_oss,er·V²·f_sw ×2 FETs | **0.06 W** |
| Dead-time diode | V_SD·I·2·t_dt·f_sw = 0.8·80·2·50n·48k | **0.31 W** |
| Gate drive (mostly in driver) | 2·Q_g·V_drv·f_sw | **0.06 W** |
| **Total switching** | | **≈ 2.4 W** |
