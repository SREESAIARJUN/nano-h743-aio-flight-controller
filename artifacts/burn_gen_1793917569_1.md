## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

Use the amplitude-invariant Clarke transform:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant and decoupling

$$v_d = Ri_d + L\dot i_d - \omega_e L i_q,\qquad v_q = Ri_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

where λ_m = Kt / (1.5·p).

The feed-forward terms cancel the cross-coupling and back-EMF:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m)$$

### 1.3 PI design by pole-zero cancellation

Choose the closed-loop current bandwidth ω_c (here 2π·1.5 kHz, below f_PWM/10):

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

This gives a first-order closed loop, i(s)/i*(s) = ω_c/(s + ω_c).

### 1.4 Discrete PI with back-calculation anti-windup

$$u_k = K_p e_k + I_k,\qquad \bar u_k = \mathrm{sat}(u_k)$$

$$I_{k+1} = I_k + T_s\big[K_i e_k + K_{aw}(\bar u_k - u_k)\big],\qquad K_{aw}=K_i/K_p$$

### 1.5 Voltage-vector limit

The SVPWM linear region is a circle of radius V_bus/√3. The d-axis has priority:

$$v_d \leftarrow \mathrm{clamp}(v_d,\pm V_{max}),\qquad |v_q| \le \sqrt{V_{max}^2 - v_d^2}$$

with V_max = 0.95·V_bus/√3.

### 1.6 SVPWM by min-max zero-sequence injection

$$v_{a,b,c} \text{ from inverse Clarke},\qquad v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical plant (per axis)

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

The inner current loop is approximately 1 from the outer loops' viewpoint, because ω_c ≫ ω_v.

### 2.2 Velocity PI (4 kHz)

The velocity estimate blends the gyro (low noise, absolute inertial rate) with encoder differentiation. The encoder rate is relative; for a stacked gimbal, the IMU rate projected onto the joint axis is used for stabilization.

$$\hat\omega = \alpha\,\omega_{gyro,axis} + (1-\alpha)\,\omega_{enc},\qquad \omega_{enc} = \mathrm{LPF}\left(\frac{\mathrm{wrap}(\theta_k-\theta_{k-1})}{T_v}\right)$$

Design for a velocity bandwidth ω_v (here 2π·60 Hz) with PI zero at ω_v/4:

$$K_{pv} = \frac{J\,\omega_v}{K_t}\ \ [\text{A/(rad/s)}],\qquad K_{iv} = K_{pv}\,\frac{\omega_v}{4}$$

The control law, including acceleration feedforward:

$$i_q^* = \underbrace{K_{pv}e_\omega + \textstyle\int K_{iv}e_\omega}_{\text{PI, anti-windup as §1.4}} + \frac{J}{K_t}\dot\omega_{ref} + \hat i_{cog}(\theta)$$

The velocity output passes through structural notch(es) (§4.4) before becoming i_q*.
