# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #36)

This document covers the FOC current loop, the cascaded angle/velocity controller, anti-cogging feedforward, and dual ICM-42688-P vibration rejection. It gives the equations first (§1–§7) and then a complete C++17 reference implementation (§8).

I don't have Job #36's parameter sheet, so all numbers are **explicit assumptions**. Replace them with your measured values. Every gain in the code is derived from physical parameters, not hand-typed magic numbers.

## 1. Field-Oriented Control Equations

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with `i_a + i_b + i_c = 0`):

```
i_α = i_a
i_β = (i_a + 2·i_b) / √3
```

**Park transform** (with electrical angle `θ_e = p·θ_m − θ_offset`):

```
i_d =  i_α·cos θ_e + i_β·sin θ_e
i_q = −i_α·sin θ_e + i_β·cos θ_e
```

**Inverse Park transform:**

```
v_α = v_d·cos θ_e − v_q·sin θ_e
v_β = v_d·sin θ_e + v_q·cos θ_e
```
