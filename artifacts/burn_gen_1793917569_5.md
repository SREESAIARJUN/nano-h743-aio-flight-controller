# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual-IMU Vibration Rejection

**Assumptions:** I don't have the Job #45 specification, so this design uses the defaults below. Every value is a named parameter. Change it in one place if your hardware differs. Register values are from the ICM-42688-P datasheet (DS-000347). Verify them against your datasheet revision before flashing.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s≈5\,Ω$, $L_s≈1.5\,\text{mH}$, $K_t≈0.08$ N·m/A |
| Joint encoders | 14-bit absolute magnetic (AS5048A / MT6701 class) |
| IMUs | 2× ICM-42688-P on the camera stage, SPI at 24 MHz, ODR 8 kHz each, FSYNC/CLKIN shared |
| Kinematics | Yaw (outer) → Roll (middle) → Pitch (inner, carries camera) |
| MCU | Cortex-M4F/M7 with FPU |

**Loop rates:**

| Loop | Rate |
|---|---|
| Current (FOC) | 20 kHz |
| Velocity | 4 kHz |
| Angle | 1 kHz |
| Attitude estimator | 1 kHz |
| IMU front-end | 8 kHz × 2, interleaved to 16 kHz |
| Cogging LMS | 4 kHz (gated) |
