## 1. Conduction Loss Model (80 A Burst)

### 1.1 Topology current paths

In 6-step commutation with synchronous rectification, at any instant one leg is PWM-switching (HS on for D, LS on for 1−D) and one leg is statically low (LS on 100%). The third leg floats.

Conduction loss per motor:

```
P_cond,PWM-leg  = I²·R_DS(Tj)·D + I²·R_DS(Tj)·(1−D) = I²·R_DS(Tj)
P_cond,static   = I²·R_DS(Tj)
P_cond,motor    = 2·I²·R_DS(Tj)        ← independent of duty cycle
```

This assumes ideal sync rect. Dead-time diode conduction is handled separately in §2.

### 1.2 Temperature-dependent R_DS(on)

```
R_DS(Tj) = R_DS(25) · [1 + α·(Tj − 25)],   α ≈ 0.0055 /K (typical Si trench, 40 V)
```

Solve self-consistently with Tj. Iteration from Tj,guess = 110 °C:

```
R_DS(110) = 1.2 mΩ · (1 + 0.0055·85) = 1.2 · 1.4675 = 1.76 mΩ
P_cond,motor = 2 · 80² · 1.76e-3 = 22.5 W
```

§4 converges at a hottest-FET Tj of ≈105–115 °C for a 5 s burst, so 1.76 mΩ is self-consistent.

### 1.3 Ancillary conduction losses (per motor, at 80 A)

| Element | R | Loss |
|---|---|---|
| Phase pad + trace copper (2 oz, inner layers paralleled, ~0.15 mΩ effective, ×2 legs) | 0.3 mΩ | 1.9 W |
| Battery bus share (main bus 0.1 mΩ, I_bat = D·I; at D = 0.8 → 64 A per motor, 256 A total) | — | 6.6 W total board |
| Current-sense shunt (0.2 mΩ, total battery current, D = 0.8) | 0.2 mΩ | 13 W total ⚠ |

**Design flag:** a single 0.2 mΩ shunt at 256 A burst dissipates about 13 W. Use either a 0.1 mΩ 4-terminal shunt (6.5 W, burst-rated 3 W/2512 parts ×3 in parallel) or a Hall sensor (e.g. ACS7xx / CT4xx class).

### 1.4 Board-level conduction total

```
P_cond,total = 4 · (22.5 + 1.9) + 6.6 + 6.5 ≈ 110.7 W   (all four motors at 80 A burst)
```

## 2. Switching Loss Model @ 48 kHz

Only the PWM leg switches (2 FETs per motor per PWM period). Commutation events (~6 per electrical revolution) are negligible compared with 48 kHz.

### 2.1 Hard-switching V-I overlap (HS turn-on and turn-off)

```
P_VI = ½ · V_bus · I · (t_r + t_f) · f_sw
     = 0.5 · 25.2 · 80 · 30e-9 · 48e3
     = 1.452 W
```

### 2.2 Reverse recovery of the LS body diode (after dead time)

```
P_rr = Q_rr · V_bus · f_sw = 40e-9 · 25.2 · 48e3 = 0.048 W
```

Q_rr rises with di/dt and Tj. Derate ×2 to be conservative, giving **0.10 W**.

### 2.3 Output capacitance

```
P_oss = ½ · Q_oss · V_bus · f_sw = 0.5 · 60e-9 · 25.2 · 48e3 = 0.036 W
```

### 2.4 Dead-time body-diode conduction (2 dead-times per period)

```
P_dt = V_SD · I · 2·t_dt · f_sw = 0.8 · 80 · 200e-9 · 48e3 = 0.614 W
```
