## 0. Architecture Clarifications

These points shape the rest of the design:

1. **The STM32H743 does not drive the power stage.** On every production AIO and 4-in-1 design, each motor channel has its own ESC MCU running AM32 or BLHeli_32-class firmware, plus a 3-phase gate driver. The H743 runs ArduPilot and sends **bi-directional DShot600** to the four ESC MCUs. The 48 kHz switching frequency is set in the **ESC MCU firmware**, not on the H743.
2. **"80 A burst" on a nano-format board is a transient rating, not a thermal steady state.** The model below shows that at 80 A the board heats at roughly 20 K/s with all four channels loaded. The burst window is about 2 to 3 seconds unless the board is heatsinked. Section 5 quantifies this so the spec sheet stays defensible.
3. **Assumed component values must be verified.** All MOSFET, driver, and PCB parameters below are representative values for the device class. Before release, replace them with datasheet values for the parts you actually procure. Pin-level port assignments must also be checked against the exact H743 package ballout.
