# STM32H743 Nano FC + 4-in-1 ESC (Job #27): Architecture, Loss Model, DShot/DMA Allocation and Netlist

## 0. Assumptions and Scope

**Architecture.** The H743 does not switch the MOSFETs. It runs ArduPilot and emits 4× bi-directional DShot600. Each ESC channel has its own MCU, for example an AT32F421 running AM32. That MCU generates the 48 kHz complementary PWM through a 3-phase gate driver into six N-FETs. The loss model applies to the ESC power stage. The DMA model applies to the H743.

**Numbers.** Values marked *[ex]* are example datasheet values chosen to be representative of 40 V PQFN 3.3×3.3 FETs. Substitute the real datasheet values before sign-off. The equations are the deliverable; the numbers demonstrate them.

**Reality check, stated up front.** "80 A burst per channel on a nano 4-in-1" is achievable only as a seconds-long transient. It is not a thermal steady state. The math below shows why and sets the burst-duration limit.

## 2. Conduction Loss Model

### 2.1 Topology

Six-step trapezoidal drive with synchronous rectification (complementary PWM) applies. In each commutation sector, two phases carry current:

- **PWM leg:** the HS FET conducts for D and the LS FET for (1−D). Losses are I²R·D + I²R·(1−D) = I²R, independent of duty cycle.
- **Return leg:** the LS FET conducts continuously, giving I²R.

$$P_{cond,ch} = 2\,I_{rms}^2\,R_{ds}(T_j)$$

### 2.2 Ripple Correction

The phase current carries a triangular ripple ΔI:

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}, \qquad \Delta I \approx \frac{(V_{bus}-E)\,D}{L_{ph}\,f_{sw}}$$

Take a typical 5" motor with L_ph ≈ 20 µH, operating near D ≈ 0.9 with E ≈ 20 V:

- ΔI ≈ (5.2·0.9)/(20e-6·48e3) ≈ 4.9 A
- ΔI²/12 ≈ 2 A², which is negligible against 6400 A².

The ripple term only becomes significant on low-inductance motors at low f_sw. That is one argument for the 48 kHz choice.

### 2.3 Temperature Coupling (Electro-Thermal Fixed Point)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)]$$

$$T_j = T_{ref} + R_{\theta}\,P(T_j)$$

This equation has a stable solution only if:

$$\frac{\partial P}{\partial T_j}R_\theta = 2I^2R_{ds,25}\,\alpha\,R_\theta < 1$$

At 80 A this gives 2·6400·0.001·0.005·R_θ = 0.064·R_θ.

- **Stability limit:** R_θ < 15.6 K/W per channel, otherwise thermal runaway follows.
- **Margin requirement:** design for R_θ < 5 K/W (gain < 0.3).
