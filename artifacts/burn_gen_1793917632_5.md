# STM32H743 4-in-1 ESC + Flight Controller (Job #19): Design Model

## 0. Architecture and Assumptions

### 0.1 Partitioning

The H743 cannot run ArduPilot and also perform four channels of 48 kHz commutation with sub-µs dead-time control. The model therefore uses this split:

| Domain | Device | Role |
|---|---|---|
| FC | STM32H743VIH6 (480 MHz rated; ArduPilot runs it at 400 MHz) | ArduPilot, bidirectional DShot600 master |
| ESC ×4 | AT32F421K8U7 or STM32G071 (AM32 firmware) | Six-step commutation, 48 kHz PWM, eRPM telemetry |
| Power stage | 24× N-MOSFET, 4× FD6288Q gate drivers | 3-phase bridges |

## 1. Conduction Loss Model

### 1.1 Current Distribution (Six-Step, Synchronous Rectification)

Each phase leg conducts for 120° of every 360° electrical period. Within a 60° sector:

- The PWM'd high-side FET conducts for a fraction D of the sector.
- Its complementary low-side FET conducts for 1 − D (synchronous freewheel).
- The opposite leg's low-side FET is held on for 100%.

Per-FET RMS current is:

$$I_{rms,HS} = I_{pk}\sqrt{\tfrac{D}{3}},\qquad I_{rms,LS} = I_{pk}\sqrt{\tfrac{1}{3}\cdot\tfrac{1 + (1-D)}{2}}$$

The worst case for total loss is D → 1, where every FET sees:

$$I_{rms} = \frac{I_{pk}}{\sqrt{3}} = \frac{80}{1.732} = 46.2\ \text{A}$$

### 1.2 Temperature-Dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right]$$

At T_j = 125 °C:

$$R_{DS} = 1.2\ \text{mΩ} \times (1 + 0.006 \times 100) = 1.92\ \text{mΩ}$$

### 1.3 Conduction Loss

Per FET:

$$P_{cond,FET} = I_{rms}^2 \, R_{DS}(T_j) = 46.2^2 \times 1.92\times10^{-3} = 4.10\ \text{W}$$

Per channel (two FETs always in series, so this cross-checks against the per-FET figure):

$$P_{cond,ch} = I_{pk}^2 \cdot 2R_{DS} = 6400 \times 3.84\times10^{-3} = 24.6\ \text{W}$$

**Four channels: 98.3 W.**

### 1.4 Electrothermal Feedback

R_DS(on) depends on T_j, and T_j depends on loss, so the operating point must be found by iteration:

$$T_j = T_{pcb} + P(T_j)\,R_{\theta jc}$$

Iterate until it converges; this takes about 3 iterations. Thermal runaway occurs if:

$$\frac{\partial P}{\partial T}\,R_{\theta} \ge 1$$

Here:

$$\frac{\partial P}{\partial T}R_\theta = I_{rms}^2 R_{25}\,\alpha\,R_{\theta jc} = 2133 \times 1.2\times10^{-3} \times 0.006 \times 1.2 \approx 0.018$$
