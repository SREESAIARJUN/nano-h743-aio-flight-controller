# STM32H743 + 4-in-1 ESC Nano Stack: Loss Model, Thermal Budget, DShot DMA Plan, Reference Netlist

## 0. Scope, Assumptions, and Corrections

**Architecture correction.** The STM32H743 runs ArduPilot and *generates* DShot. It does not commutate the motors. Each ESC channel needs its own commutation MCU running AM32 or BLHeli_32, for example an AT32F421 or STM32G071. The H743 never sees the 48 kHz PWM. That rate belongs entirely to the ESC MCUs. This document covers both sides.

**Feasibility flag.** Before the math, note what the numbers below show: **80 A on all four channels at once (≈320 A battery current) cannot be sustained by any nano-class (20×20 / 30.5×30.5 mm) board.** The connector, battery leads, and copper cannot carry it, and the thermal capacity is too small. "80 A burst" is only defensible as:
- a per-channel rating,
- for a few seconds,
- with board-level thermal derating in firmware.

**Status of the numbers.** The device parameters below are representative assumptions, not a specific BOM. Every result is given symbolically so you can substitute datasheet values. Treat the netlist as a reference architecture. It is not a validated layout and needs schematic review, SPICE of the gate loop, and thermal test before fab.
