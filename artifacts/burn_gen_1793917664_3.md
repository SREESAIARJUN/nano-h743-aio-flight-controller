## 0. System Architecture Clarification

The STM32H743 is the flight controller MCU. It does not commutate the motors. Each motor is driven by an ESC MCU running AM32 or BLHeli_32 firmware, typically an AT32F421 or STM32G071, with a 3-phase gate driver.

| Function | Device | Notes |
|---|---|---|
| Flight control, DShot master | STM32H743 @ 400 MHz | ArduPilot ChibiOS |
| Motor commutation (×4) | AT32F421 / STM32G071 ⟨assumed⟩ | AM32, 48 kHz PWM |
| Gate driver (×4) | FD6288Q-class 3-phase driver ⟨assumed⟩ | Bootstrap high side |
| Power stage | 24 N-ch FETs (6 per motor) | 40 V class, for 6S |
| Supply | 6S LiPo, V_bus,max = 25.2 V | |
