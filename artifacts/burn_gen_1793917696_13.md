# STM32H743 Nano FC + 4-in-1 ESC (Job #64): Power-Stage Loss Model, Thermal Budget, and Bidirectional DShot600 Timer/DMA Allocation

## 0. Architecture Notes and Assumptions

**Who generates the 48 kHz PWM.** The STM32H743 does not switch the MOSFETs. It sends DShot600 to four ESC MCUs (for example AT32F421 or STM32G071 running AM32 or BLHeli_32). Each ESC MCU generates the 48 kHz complementary PWM through a 3-phase gate driver. The loss model below therefore applies to the ESC power stage, and the timer/DMA model applies to the H743.

**Nominal parts.** Every number below derives from the parameters in this table. Substitute your actual datasheet values and re-run the equations.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge, worst case) | V_bus | 25.2 V |
| Burst phase current per motor | I_ph | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, PDFN 3.3×3.3) | R_ds,on @25 °C | 0.9 mΩ |
| R_ds,on temperature coefficient | α | 0.0045 /K |
| Gate charges | Q_g / Q_gs2 / Q_gd | 50 / 5 / 8 nC |
| Output charge / reverse-recovery charge | Q_oss / Q_rr | 40 / 40 nC |
| Body-diode forward voltage | V_SD | 0.8 V |
| Gate drive (FD6288-class driver) | V_drv, I_src, I_sink | 12 V, ~0.3 A, ~0.45 A (effective at plateau) |
| Dead time | t_dt | 100 ns |
| Junction-to-case thermal resistance | R_θJC | 1.5 K/W |
| Board | | 30×30 mm, 8-layer, 2 oz on all layers |

**Commutation scheme.** The model assumes 6-step trapezoidal drive with synchronous rectification. At any instant, one leg PWMs the high side (HS) and one leg holds its low side (LS) on. Each leg is active for 240° of every 360°.
