## 0. Architecture Clarification and Assumptions

**The STM32H743 does not drive the MOSFET bridges.** In every production 4-in-1 design, the H743 runs ArduPilot and emits DShot. Four independent ESC MCUs each run a motor-control firmware such as AM32 and generate the 48 kHz PWM.

The architecture is:

```
LiPo 6S ──┬──► 4× [ESC MCU ─► 3-ph gate driver ─► 6× N-MOSFET ─► motor]
          │          ▲  bidirectional DShot600 (1 wire each, half-duplex)
          └─► buck ─► STM32H743 (ArduPilot) ── TIM1 CH1..4 + DMAMUX
```

| Parameter | Value used | Notes |
|---|---|---|
| Battery | 6S, V_bus = 25.2 V max (22.2 V nominal) | Worst-case switching uses 25.2 V |
| Burst current | 80 A per motor (phase/DC-link equivalent) | **Burst only. Continuous is far lower (see §3).** |
| PWM | 48 kHz, complementary (synchronous rectification), 6-step | Typical AM32 config |
| MOSFET | 40 V, PDFN 3.3×3.3, R_DS(on),25 = 1.5 mΩ @ V_GS = 10 V | Representative class for a 25.5 mm board |
| Q_g / Q_gd / Q_rr | 45 nC / 8 nC / 40 nC | Datasheet-class values |
| Gate driver | FD6288Q-class, ~1.0 A source / 1.5 A sink at 10–12 V | |
| Board | 25.5 × 25.5 mm, 8-layer, 2 oz all layers | |
| Ambient | 40 °C with prop wash | |

**Feasibility warning (stated up front).** 80 A per channel on a nano-class board is a transient rating. The math below shows the thermal limit is set by board heat capacity, not by the silicon. That distinction should drive the spec sheet.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,\big[1+\alpha\,(T_j-25)\big],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 125 °C: R_DS = 1.5 mΩ × 1.60 = **2.40 mΩ**.

### 1.2 Current path in 6-step with complementary PWM

In each 60° sector, current always flows through exactly two MOSFETs:

- **During PWM-on (fraction D):** HS of the PWM leg + LS of the sinking leg.
- **During PWM-off (1−D):** synchronous LS of the PWM leg + LS of the sinking leg. Dead-time body-diode conduction is handled in §2.

**Total bridge conduction loss** is therefore independent of duty:

$$P_{cond,bridge} = 2\,I^2\,R_{DS}(T_j)$$

**Per-device split.** Over one electrical period, each leg spends 120° as the PWM leg, 120° as the sinking low side, and 120° floating:

$$P_{HS} = \frac{I^2 R_{DS}\,D}{3},\qquad P_{LS} = \frac{I^2 R_{DS}\,\big[1 + (1-D)\big]}{3}$$

### 1.3 Numbers at 80 A, T_j = 125 °C

I²R = 6400 × 2.4 mΩ = **15.36 W**

| Duty D | P_HS per FET | P_LS per FET | Bridge total (6 FETs) |
|---|---|---|---|
| 1.00 | 5.12 W | 5.12 W | 30.7 W |
| 0.75 | 3.84 W | 6.40 W | 30.7 W |
| 0.50 | 2.56 W | **7.68 W** (hottest) | 30.7 W |

**Design insight:** at partial throttle the low-side FETs are the hot spot. Place them nearest the heaviest copper and thermal vias.
