# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original spec for Job #47, so the parameters below are typical values for this class of gimbal. Everything is parameterized: replace the values in §0 with your measured motor and mechanical data, and the equations and code still apply.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (e.g. GBM2804-class), pole pairs $p=7$ |
| Phase R / L | $R_s \approx 5\ \Omega$, $L_s \approx 2\ \text{mH}$ (measure these) |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| MCU | STM32G4 / H7 class with FPU and center-aligned PWM |
| IMUs | 2× ICM-42688-P on separate SPI buses, mounted symmetrically about the camera CoM |
| Bus | $V_{dc}$ = 12–16 V |
