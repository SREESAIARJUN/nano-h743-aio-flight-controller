# Job #43: 3-Axis Gimbal FOC Motor Control and Dual-IMU Sensor Fusion

**Assumptions.** I have no specification for Job #43, so the design below uses typical gimbal values. Every value tagged **[P]** is a parameter you must identify or replace on the real hardware:

- **Motors:** BLDC gimbal motors, 12N14P (Z_s = 12 slots, N_pp = 7 pole pairs).
- **Encoders:** 14-bit absolute magnetic encoder per joint (AS5048A or MT6701 class).
- **IMUs:** two ICM-42688-P.
  - IMU-C is rigidly mounted on the camera platform. It provides the inertial feedback.
  - IMU-B is mounted on the handle/base. It provides the disturbance reference.
- **MCU:** STM32G4/H7-class with an FPU and a center-aligned PWM timer that triggers the ADC.
