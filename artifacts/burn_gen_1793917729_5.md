## 0. Assumptions and Loop Rates

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (e.g. GBM2804), p = 7 pole pairs, R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), on the motor shaft |
| Current sense | 2-shunt inline or low-side, sampled at the PWM center |
| MCU | STM32G4 / H7 class with FPU (CORDIC optional) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz |

**Rate structure:**

```
 PWM 20–40 kHz ─► Current loop (FOC)        f_i = 20 kHz   (ISR, ADC-triggered)
                  Encoder PLL + cogging FF   f_i = 20 kHz
 IMU DRDY 8 kHz ─► Dual-IMU fusion + filters f_s = 8 kHz
                  Velocity (rate) loop       f_v = 4 kHz    (decimated by 2)
                  Angle (attitude) loop      f_a = 1 kHz
                  AHRS (Mahony)              f_a = 1 kHz
```

As a rule of thumb, keep each loop bandwidth at about 1/10 of its sample rate. Each inner loop should be at least 4–5× faster in bandwidth than the loop outside it.
