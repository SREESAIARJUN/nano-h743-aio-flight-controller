# Job #22: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

I don't have the original Job #22 specification, so the design below states every hardware assumption explicitly. Each parameter is isolated in a config struct, so the math and code adapt directly if your motors, encoders, or MCU differ.

---

## 0. Assumed Hardware and Loop Architecture

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC (GM4108-class), 12N14P → **p = 7 pole pairs**, R ≈ 10 Ω, L ≈ 4 mH, K_t ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701) per axis |
| MCU | STM32G474 @ 170 MHz, FPU, 3 motors on one MCU (HRTIM / TIM1/TIM8/TIM20) |
| Kinematic order (base → camera) | Yaw (z) → Roll (x) → Pitch (y): **R = R_z(ψ) R_x(φ) R_y(θ)** |
| IMUs | 2× ICM-42688-P on the camera platform, mounted **point-symmetric about the payload rotation centre**, on separate SPI buses |

The control architecture runs at four rates:

```
 8 kHz  IMU ISR ──► per-IMU notch/LPF ──► dual fusion ──► gyro ω_p
                                                │
 1 kHz  Attitude loop: q_d, q̂ (Mahony) ──► ω_d (body)
                                                │
 4 kHz  Rate loop: PI(ω_d − ω_p) ──► τ_body ──► Jᵀ(q) ──► τ_joint
