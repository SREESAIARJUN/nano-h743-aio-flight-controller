## 1. FOC Core Equations

### 1.1 Clarke transform (amplitude-invariant)

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\left(i_a + 2 i_b\right)\quad (\text{using } i_a+i_b+i_c=0)
$$

### 1.2 Park transform

With electrical angle $\theta_e = p\,\theta_m - \theta_{off}$:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

The inverse Park transform uses the transpose of this matrix.

### 1.3 PMSM dq model

$$
v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad
v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q
$$

### 1.4 Current PI with decoupling

The design uses pole-zero cancellation to give a first-order closed loop with bandwidth $\omega_{c}$:

$$
K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{PWM}}{10}
$$

$$
v_d^* = PI_d(i_d^*-i_d) - \omega_e L_q i_q,\qquad
v_q^* = PI_q(i_q^*-i_q) + \omega_e (L_d i_d + \lambda_m)
$$

The voltage vector is limited to $|v| \le V_{bus}/\sqrt3$, which is the linear SVPWM region. Anti-windup is applied to each integrator.

> **Gimbal note:** High-R gimbal motors are often run in *voltage mode* with $v_q = R\,i_q^* + \omega_e\lambda_m$ when there is no current sense. The code supports both modes via `kUseCurrentLoop`.

### 1.5 SVPWM (min-max zero-sequence injection)

$$
v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta
$$

$$
v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad
d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}
$$
