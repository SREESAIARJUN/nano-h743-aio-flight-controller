# Job #35: FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

This document covers the complete control design and a full C++17 reference implementation. It targets embedded MCUs with no dynamic allocation and no exceptions. The design is meant for bench bring-up. Validate the gains and safety limits on hardware before flight.

---

## 0. Design Assumptions

Change these if your hardware differs. Every gain below is derived from them symbolically.

| Item | Value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7, slots Nₛ = 12), R ≈ 5.6 Ω, L ≈ 2.1 mH (phase), Kₜ ≈ 0.10 N·m/A |
| Encoder | 14-bit absolute magnetic, one per axis, sampled at the current-loop rate |
| MCU | STM32G4/H7 class (FPU, ≥170 MHz), center-aligned PWM at 20 kHz, ADC triggered at the PWM center |
| Payload IMU (IMU-P) | ICM-42688-P on the camera plate. Provides rate and attitude feedback. |
| Base IMU (IMU-B) | ICM-42688-P on the frame. Provides the vibration reference and base-motion feedforward. |
| Axis order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
