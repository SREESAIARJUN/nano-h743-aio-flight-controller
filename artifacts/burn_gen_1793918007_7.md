# STM32H743 Nano FC + 4-in-1 80A ESC (Job #38): Architecture, Loss Model, DShot DMA Plan, and Reference Netlists

## 0. Scope, Assumptions, and Design Risks

This is a first-principles engineering model. Every number depends on the assumptions in the table below. **Replace them with the selected MOSFET's datasheet values and lab measurements before freezing the design.** The netlists are reference topology, not a verified layout-ready schematic.

**Architectural clarification:** In a 4-in-1 stack, the STM32H743 runs ArduPilot on the flight controller. The ESC board has its own MCU running AM32 or BLHeli_32, for example an AT32F421 or STM32G071. The H743 only generates bidirectional DShot600 and decodes eRPM telemetry. It does not commutate the motors.

**Design risks to accept up front:**
1. **80A cannot be a continuous rating on a nano (≈30×30 mm) board.** Section 3 shows steady-state dissipation of about 70 W. 80A is a **burst rating, bounded to a few seconds**.
2. **Bidirectional DShot is incompatible with complementary timer outputs (CHxN).** Motor pins must use primary CHx outputs.

## 1. Conduction Loss Model (80A Burst)

### 1.1 Temperature-corrected on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)] = 0.80\,(1+0.006\cdot75) = 1.16\ \text{m}\Omega$$

### 1.2 Six-step commutation with synchronous rectification

At any instant, two phases conduct:
- **PWM leg:** the high-side (HS) FET conducts for duty D, and the low-side (LS) FET synchronously rectifies for (1−D).
- **Return leg:** the LS FET is fully on.

$$P_{cond} = I^2R\,[D + (1-D)] + I^2R = 2I^2R_{ds}(T_j)$$

Including current ripple:

$$I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12}$$

The ripple depends on motor inductance:

$$\Delta I_{pp} \approx \frac{V_{bus}D(1-D)}{L_{ph}\,f_{sw}}$$

For L_ph = 20 µH, ΔI_pp is about 6.6 A, which adds only about 0.06% and is negligible.

$$P_{cond} = 2(80)^2(1.16\times10^{-3}) = \mathbf{14.85\ W\ per\ channel}$$

### 1.3 Per-FET share

Each FET conducts during about 1/3 of the electrical cycle, so the average per FET is about 2.5 W. The instantaneous peak is 7.4 W while that FET is the "fully on" device.

The thermal time constant of the FET package (Z_th,jc settles in roughly 10 ms) is shorter than the commutation period only at low eRPM. **At low RPM with high current (stall or punch-out from hover), use the 7.4 W peak, not the 2.5 W average.**

## 2. Switching Loss Model (48 kHz)

Only the PWM-leg HS FET hard-switches. The LS FET turns on with near-zero voltage after dead time.

### 2.1 Transition times

$$t_r = \frac{Q_{gs2}+Q_{gd}}{(V_{drv}-V_{pl})/R_{g,on}} = \frac{18\,\text{nC}}{1.3\,\text{A}} = 13.8\ \text{ns}$$

$$t_f = \frac{18\,\text{nC}}{V_{pl}/R_{g,off}} = \frac{18\,\text{nC}}{1.4\,\text{A}} = 12.9\ \text{ns}$$

Common-source inductance and layout parasitics typically stretch these. Use t_r + t_f ≈ **40 ns** as the design value and verify with a double-pulse test.

### 2.2 Loss components (V = 25.2 V, I = 80 A, f = 48 kHz)

| Mechanism | Equation | Result |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f | ½·25.2·80·40n·48k = **1.94 W** |
| Reverse recovery | V·Q_rr·f | 25.2·50n·48k = **0.06 W** |
| Dead-time diode conduction | V_f·I·2t_dt·f | 0.8·80·200n·48k = **0.61 W** |
| C_oss | ½·C_oss,er·V²·f | ½·2n·635·48k = **0.03 W** |
| Gate drive (2 FETs, mostly in driver) | 2·Q_g·V_drv·f | **0.06 W** |
| **Switching subtotal** | | **≈ 2.70 W** |

### 2.3 Totals and frequency sensitivity

Total per channel: P_ch = 14.85 + 2.70 ≈ **17.6 W**.

Four channels: **P_ESC ≈ 70 W** at simultaneous 80A burst. This excludes shunts, copper, and the bus capacitor ESR, which add roughly another 3–6 W.

Frequency-dependent losses scale linearly with f_sw:

$$\frac{\partial P}{\partial f_{sw}} \approx 56\ \text{µW/Hz}$$

- At 24 kHz, losses drop by about 1.35 W per channel.
- At 96 kHz, they rise by about 2.
