# STM32H743 Nano AIO (FC + 4-in-1 ESC), Job #36: Architecture, Loss Model, DShot DMA Plan and Netlists

## 0. Feasibility Findings (Read First)

These findings set the boundaries for everything that follows.

1. **The H743 does not commutate the motors.** ArduPilot is a flight-control stack. It outputs DShot and has no FET-commutation firmware. The correct architecture is:
   - STM32H743 runs ArduPilot and sends bidirectional DShot600 to four ESC MCUs.
   - Each ESC MCU (STM32G071 or AT32F421, running AM32 or BLHeli_32-class firmware) produces the 48 kHz complementary PWM.
   - "48 kHz switching" is therefore an ESC-MCU parameter. It is not an H743 timer allocation.
2. **"80 A burst" on a 20×20 mm nano board is not thermally credible** beyond a sub-second to roughly 1 s window. Section 3 derives this. The physical constraints are:
   - 24 power FETs plus 4 drivers plus 4 MCUs only fit on 20×20 if the FETs are in 3.3×3.3 mm DFN packages, at about 2–3 mΩ.
   - 5×6 mm (1 mΩ) FETs would need about 720 mm² of footprint. Even using both sides, that leaves nothing for drivers, MCUs or capacitors.
   - The rating is ultimately junction-limited, not board-limited.
3. **Recommendation:** rate the product **35–40 A continuous-burst (≤5 s, single motor) / 25 A sustained**, or move to a 30.5×30.5 mm format with 5×6 FETs if 80 A is a hard requirement.

All numbers below are parametric, so you can substitute datasheet values.

## 1. System Architecture

```
 6S LiPo (25.2 V max) ──┬── TVS + 2×470µF low-ESR (off-board) + 4×10µF/35V MLCC per ESC
                        │
        ┌───────────────┼──────────────────────────────┐
        │  ESC 1..4: MCU (G071/AT32F421) → FD6288Q → 6× N-FET 3x3 DFN → motor
        │       ▲ DShot600 bidir (single wire, 3.3 V, open-idle-high)
        └───────┼──────────────────────────────────────┘
                │
 STM32H743VIH6 (TFBGA100) @ 400 MHz, ArduPilot
   TIM1 CH1-4 → M1-M4 (bidir DShot)
   SPI1 → IMU (ICM-42688-P), SPI4 → OSD (AT7456E), I2C2 → baro (DPS310)
   SDMMC1 → microSD, USART1/2/3/6/UART4/7 → peripherals
```

## 2. Loss Model per ESC Channel

### 2.1 Operating Assumptions

| Symbol | Value | Note |
|---|---|---|
| V_bus | 25.2 V | 6S full charge (worst case for switching losses) |
| I_ph | 80 A | Burst phase current |
| f_sw | 48 kHz | Center-aligned complementary PWM |
| R_ds(on),25 | 2.5 mΩ | Typical 30–40 V, 3.3×3.3 DFN |
| k_T | 1.5 | R_ds(on) multiplier at T_j ≈ 125 °C |
| t_r + t_f | 15 ns | With FD6288Q at ~1 A source / 1.5 A sink, R_g = 0
