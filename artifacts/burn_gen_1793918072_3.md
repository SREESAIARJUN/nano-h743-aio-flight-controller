# STM32H743 Nano FC with 4-in-1 ESC (Job #62): Design Analysis

## 0. Architecture Findings

Three issues change the shape of this design. They need to be resolved before anyone commits to a layout.

| # | Finding | Consequence |
|---|---|---|
| A1 | The H743 has only two advanced timers (TIM1, TIM8) with complementary outputs, which is enough for 2 motors. HRTIM can't cleanly cover the rest, and ArduPilot doesn't run ESC commutation anyway. | We need 4 dedicated ESC MCUs (e.g. AT32F421 running AM32). The H743 runs ArduPilot and sends bi-directional DShot600 to them. |
| A2 | "80A burst" on a nano (20×20 mm) board is thermally possible only for about 1 s with all 4 motors loaded (derived in §3). | Spec it as "80A for 1 s, single motor or all four." Continuous rating will be far lower. |
| A3 | Electrical numbers depend on the MOSFET you choose. | All parameters are listed below. Substitute your datasheet values and the model still holds. |

## 1. Conduction Loss Model (6-step trapezoidal, complementary PWM)

In each 60° commutation sector, one phase's high side PWMs at duty D. Its complementary low side synchronously rectifies for (1−D). A second phase's low side conducts continuously. Current therefore always flows through exactly 2 FETs.

**Temperature-dependent on-resistance:**

$$R_{ds}(T_j)=R_{ds25}\,[1+\alpha(T_j-25)]\quad\Rightarrow\quad R_{ds}(125^\circ C)=1.2\times1.55=1.86\ \text{m}\Omega$$

**Per-motor conduction loss:**

$$P_{cond,motor}=2\,I^2R_{ds}(T_j)=2(6400)(1.86\times10^{-3})=\mathbf{23.8\ W}$$

**Per-FET breakdown.** Each phase is active for 1/3 of the electrical cycle on each rail.

$$P_{HS}=\tfrac{1}{3}D\,I^2R_{ds},\qquad P_{LS}=\tfrac{1}{3}I^2R_{ds}+\tfrac{1}{3}(1-D)I^2R_{ds}$$
