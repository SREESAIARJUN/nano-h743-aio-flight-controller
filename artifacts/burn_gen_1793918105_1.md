## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7). R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Bus | 12 V. Inline/low-side shunt current sensing. 3-phase driver (e.g., DRV8313) |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on each joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, gyro ODR 8 kHz, accel 1 kHz |
| Loop rates | Current 20 kHz → Velocity 4 kHz → Angle 1 kHz → Attitude fusion 1 kHz |

**Bandwidth separation rule:** each outer loop should be ≥ 5–10× slower than the loop inside it:
- Current loop ωc,i ≈ 2π·1500 rad/s
- Velocity loop ωc,v ≈ 2π·150 rad/s
- Angle loop ωc,θ ≈ 2π·20 rad/s

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

**Electrical angle**, with encoder zero offset θ₀ found at calibration:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Motor Model (Surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 1.3 Current PI with Decoupling and Pole-Zero Cancellation

The plant per axis is $1/(Ls+R)$. Choose PI gains so the PI zero cancels the plant pole:

$$K_{p,i}=L\,\omega_{c,i},\qquad K_{i,i}=R\,\omega_{c,i}$$

The closed loop then becomes a first-order lag $\omega_{c,i}/(s+\omega_{c,i})$.

Control law with decoupling feedforward:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e(L i_d + \lambda_m)$$
