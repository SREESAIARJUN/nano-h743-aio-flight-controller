# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions and Architecture

"Job #51" has no attached specification, so this design uses the following reference platform. Every parameter is a named constant in the code, so you can substitute your own values.

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (p = 7 pole pairs), R_s = 5.0 Ω, L_s = 2.0 mH (per phase, line-neutral), K_t ≈ 0.06 N·m/A |
| Bus voltage | 12–16 V |
| Encoder | 14-bit magnetic absolute encoder (AS5048A or MT6701), SPI, sampled synchronously with PWM |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| IMUs | 2 × ICM-42688-P on the camera plate (IMU-A and IMU-B), SPI, ODR 8 kHz |
| Loop rates | Current (FOC) 20 kHz · Velocity 4 kHz · Angle 1 kHz · IMU fusion 4 kHz (8 kHz in, decimated by 2) |

### Signal flow per axis

```
         ┌─────────── 1 kHz ───────────┐ ┌──────── 4 kHz ────────┐ ┌────────── 20 kHz ──────────┐
θ_ref ─►(Σ)─► Angle P/PI ─(+ω_ff)─►(Σ)─► Velocity PI ─(+τ_ff)─►(Σ)─► i_q* ─► d/q PI ─► SVPWM ─► Inverter
         ▲                          ▲                           ▲        ▲
         │ θ_joint (fused attitude) │ ω_joint (fused gyro)       │        └─ i_a,i_b (ADC), θ_e (encoder)
         │                          │                           └─ cogging FF τ_cog(θ_m)/K_t
```

The two IMUs on the stabilized plate measure **inertial** rate and attitude. These signals close the stabilization loops. The encoder is used for commutation and cogging compensation, and it provides a high-bandwidth fallback velocity signal.
