# STM32H743 FC + 80 A 4-in-1 ESC (Nano Stack): Electrical, Thermal and DShot Model

## 0. Architecture Correction

**The STM32H743 should not drive the power stage directly.** ArduPilot is flight-control firmware and contains no FOC or 6-step commutation engine. The architecture used below is the one every production board in this class uses:

```
STM32H743 FC (ArduPilot) --4x bidir DShot600--> 4x ESC MCU (AM32 / BLHeli_32-class)
                                                  e.g. STM32G071 / AT32F421
                                                       |
                                     4x 3-phase gate driver --> 24 MOSFETs
```

**Realism flag.** "80 A burst" on a nano (20×20 or 30.5×30.5 mm) 4-in-1 is only survivable for short durations. Section 3 shows that the limit is board heat capacity, not the MOSFET datasheet. All device parameters below are **stated assumptions**. Substitute your actual BOM values into the equations.

## 2. Loss Model (per ESC channel)

### 2.1 Conduction Loss

In 6-step operation with synchronous rectification, two phases are active:

- **PWM leg:** the high-side FET conducts for duty D, and the complementary low-side conducts for (1 − D).
- **Return leg:** the low-side FET conducts 100 %.

$$P_{cond} = I^2 R_{ds,hot}\,[D + (1-D) + 1] = 2\,I^2 R_{ds,hot}$$

The result is independent of D, which is a useful property of synchronous 6-step.

$$P_{cond} = 2 \times 80^2 \times 0.0018 = \mathbf{23.0\ W}$$

The **hottest single FET** is the 100 %-conducting return low-side:

$$P_{FET,max} = I^2 R = 6400 \times 0.0018 = \mathbf{11.5\ W}$$

The FET temperature coefficient creates a temperature-dependent feedback loop:

$$R_{ds}(T_j) = R_{25}\,[1+\alpha(T_j-25)],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

Solve it iteratively alongside Section 3. Thermal runaway occurs if $\partial P/\partial T_j \cdot Z_{th} \ge 1$.

Copper loss:

$$P_{cu} = 2I^2R_{cu} = 2(6400)(0.0005) = \mathbf{6.4\ W}$$

The factor of 2 is there because two phase paths carry the current. This loss is often larger than designers expect.

### 2.2 Switching Loss (hard-switched PWM leg only)

Gate currents through the Miller region:

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{g,on}} = \frac{7}{5} = 1.4\ \text{A}, \qquad I_{g,off} = \frac{V_{pl}}{R_{g,off}} = 1.0\ \text{A}$$

Transition times:

$$t_r = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = \frac{13\text{ nC}}{1.4} = 9.3\text{ ns}, \quad t_f = \frac{13\text{ nC}}{1.0} = 13\text{ ns}$$

V-I overlap loss:

$$P_{sw} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5(25.2)(80)(22.3\times10^{-9})(48\,000) = \mathbf{1.08\ W}$$

### 2.3 Secondary Switching Terms

| Term | Formula | Value |
|---|---|---|
| Output capacitance | $\tfrac12 C_{oss}V^2 f_{sw}$ | 0.023 W |
| Reverse recovery | $Q_{rr}V_{bus}f_{sw}$ | 0.048 W |
| Body-diode dead time | $V_f\,I\,(2t_{dt})\,f_{sw}$ | **0.61 W** |
| Gate charge (2 FETs, dissipated in driver/R_g) | $2Q_gV_{drv}f_{sw}$ | 0.038 W |

Dead-time loss is the second-largest switching term. Trimming t_dt from 100 ns to 50 ns saves about 0.3 W per ESC, provided shoot-through margin is verified on the scope.

### 2.4 Totals at 80 A Burst

| | Per ESC | ×4 (all motors at 80 A) |
|---|---|---|
| MOSFET conduction | 23.0 W | 92.0 W |
| Switching + Coss + Qrr + dead time + gate | 1.80 W | 7.2 W |
| Copper / shunt | 6.4 W | 25.6 W |
| **Total** | **≈ 31.2 W** | **≈ 125 W** |

Efficiency at D ≈ 1: P_out ≈ 2016 W per ESC, so η ≈ 98.5 %. The power stage is efficient, but 125 W into a board of a few grams is the problem.

**Frequency sensitivity:** only about 1.8 W scales with f_sw. Moving from 24 kHz to 48 kHz costs about 0.9 W per ESC, which is negligible compared with I²R. 48 kHz is justified for low-inductance motors (lower current ripple) and quieter operation.
