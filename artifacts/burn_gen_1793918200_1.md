## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC (e.g. GBM2804), 12N14P → `p = 7` pole pairs, `N_s = 12` slots, R ≈ 10 Ω, L ≈ 3 mH |
| Encoder | 14-bit magnetic (AS5048A / MT6701) on each joint, SPI |
| MCU | STM32G4 / H7 class, FPU, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz, FIFO + timestamps |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |

The loops form a cascade. Each loop runs on its own clock:

| Loop | Rate | Role |
|---|---|---|
| Current (FOC) | 20 kHz, ISR | Synchronized to PWM, ADC triggered at the counter apex |
| Joint velocity | 4 kHz | Inner speed loop |
| IMU fusion + attitude / rate | 2 kHz | Decimated from 8 kHz after filtering |
| Trajectory / user command | 200 Hz | Setpoints |

Bandwidth separation should be ≥ 4–10× between nested loops:

- Current loop ω_c ≈ 2π·1500 rad/s
- Velocity loop ω_v ≈ 2π·120 rad/s
- Attitude loop ω_θ ≈ 2π·20 rad/s

## 1. Field-Oriented Current Control

**Electrical angle with delay compensation.** PWM update delay plus ZOH is about 1.5 T_s:

$$\theta_e = p\,(\theta_m - \theta_{off}) + 1.5\,T_s\,\omega_e,\qquad \omega_e = p\,\omega_m$$

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

**PMSM dq model:**

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L \dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
