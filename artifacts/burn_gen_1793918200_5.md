# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #38)

## 0. Assumptions

I don't have the Job #38 specification, so the design uses typical brushless gimbal parameters. Every value lives in a `constexpr` config block, so you can substitute your real numbers there.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, about 170 MHz or more |
| Motors | 3× BLDC gimbal motors, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (MT6701/AS5047 class), sampled every PWM cycle |
| PWM / current loop | 20 kHz centre-aligned, T_i = 50 µs |
| Velocity loop | 5 kHz (every 4th PWM cycle) |
| Attitude/angle loop | 1 kHz |
| IMUs | 2× ICM-42688-P on separate SPI buses, gyro ODR 8 kHz, accel ODR 1 kHz, hardware-synchronised |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera; IMUs mounted on the camera plate |
