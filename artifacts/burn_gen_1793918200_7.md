# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #0 specification, so this design uses the representative assumptions below. Every value is a named constant in the code, so you can substitute your real parameters.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs $p=7$, slots $N_s=12$), $R_\phi \approx 10\,\Omega$, $L_\phi \approx 3\,\text{mH}$ |
| Commutation sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) on each axis |
| MCU | STM32G474 / H7 class with FPU and 3× advanced timers (center-aligned PWM) |
| Current sensing | 2 inline or low-side shunts per motor. A voltage-mode fallback is given in §2.6. |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, ODR 8 kHz, FIFO-less register burst read |
| Gimbal order | Yaw (Z, base) → Roll (X) → Pitch (Y, camera) |

**Loop rates**

| Loop | Rate | Trigger |
|---|---|---|
| PWM | 25 kHz | Center-aligned timer |
| Current (FOC) | 25 kHz | ADC injected EOC |
| IMU read + filtering | 8 kHz | INT1 data-ready |
| Velocity (inertial rate) | 4 kHz | Software divider |
| Attitude/angle | 1 kHz | Software divider |
| Cogging adaptation | 4 kHz | Inside the velocity loop |

**Bandwidth separation rule.** Each outer loop should be ≥ 5× slower than the loop inside it:
$\omega_{c,i} \approx 2\pi\cdot1.5\,\text{kHz}$, $\omega_{c,v}\approx 2\pi\cdot 120\,\text{Hz}$, $\omega_{c,\theta}\approx 2\pi\cdot 15\,\text{Hz}$.

## 1. Control Architecture

```
 attitude setpoint q_ref ──►[Angle P + FF]──ω_ref──►[Velocity PI + FF]──i_q,ref──►[FOC current PI]──►SVPWM──►Motor
          ▲                       ▲                       ▲    ▲                            ▲
          │                 joint mapping J⁻¹(θ)          │    └── i_cog(θ_m)  (anti-cogging FF)
   Mahony attitude q̂ ◄── fused gyro/accel ◄── notch/LPF ◄── Dual ICM-42688-P
                                                  │
                         encoder θ_m ──► PLL ──► θ_e (commutation), ω_m (fallback/aux)
```

The loops use different feedback signals:

- **The velocity loop feeds back the *inertial* rate.** This is the gyro, projected onto each joint axis. Base vibration then appears as a disturbance the loop actively rejects.
- **The encoder is used for commutation, cogging phase, and joint kinematics.**
