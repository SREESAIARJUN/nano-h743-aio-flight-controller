# STM32H743 AIO Flight Controller with 4-in-1 ESC: Systems Architecture Package

**Scope:** loss model (conduction and switching at 48 kHz), transient thermal model for an 80 A burst, ArduPilot bidirectional DShot600 timer and DMA allocation, and reference netlists.

**Status:** These are engineering derivations with stated assumptions. MOSFET parameters are representative values for a 40 V shielded-gate 3.3×3.3 mm device. Before release, replace them with the datasheet values of your selected part and verify on the bench with thermocouple and IR data.

---

## 0. Architecture Decision

The H743 should not commutate the motors directly.

- ArduPilot has no native 4-motor sensorless BLDC/FOC drive.
- DShot is meaningless if the FC and the ESC are the same MCU.

The architecture is therefore:

```
                 ┌────────────────────── AIO PCB (stack or single board) ──────────────────────┐
 VBAT 6S ──► Bus caps ──► 4× [AM32 ESC MCU (AT32F421) ─► 3× half-bridge driver ─► 6× MOSFET]
                 │                    ▲ DShot600 bidir (1 wire each)
                 │                    │
                 └─► Buck 5V/3V3 ─► STM32H743 (ArduPilot) ── IMU/Baro/OSD/SD/UARTs
```

**Form-factor reality check.** The H743 is only available in LQFP100
