# STM32H743 Nano FC + 4-in-1 ESC: Power-Stage, Thermal, and Bidirectional DShot Design Package

**Scope:** Electro-thermal loss model at 80 A burst and 48 kHz switching, transient thermal analysis, ArduPilot bidirectional DShot600 timer and DMA allocation, and reference netlists.

## 0. Architecture and Assumptions

### 0.1 Architecture correction

The STM32H743 does not commutate the motors. A 4-in-1 ESC needs one dedicated motor MCU per channel because each runs its own 48 kHz PWM, BEMF zero-cross detection, and timing loop. The system therefore has two boards:

- **FC board:** STM32H743 running ArduPilot. It produces 4× bidirectional DShot600 and receives eRPM telemetry.
