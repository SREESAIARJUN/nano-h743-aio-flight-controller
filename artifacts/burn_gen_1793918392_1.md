# High-Rate FOC Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the original Job #6 specification. The design below therefore uses the common 3-axis gimbal configuration listed in §0. Any of these values can be changed through `constexpr` parameters in the code.

## 0. System Assumptions

| Item | Value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, single-precision FPU), 170 MHz |
| Motors | Gimbal BLDC, 12N14P (e.g. GM4108): pole pairs $p=7$, $R_s\approx 10\,\Omega$, $L_s\approx 4\,$mH |
| Rotor sensor | AS5048A 14-bit magnetic encoder over SPI, one per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, ODR 8 kHz each, sampled staggered by $T/2$ |
| PWM / current loop | 20 kHz center-aligned, current sampled at the PWM midpoint |
| Velocity loop | 4 kHz |
| Angle loop | 1 kHz |
| Axis order (base→camera) | Yaw (Z) → Roll (X) → Pitch (Y) |

## 1. Plant Model (per axis)

$$
J\ddot\theta = \tau_m - b\,\dot\theta - \tau_{cog}(\theta) - \tau_{fric}(\dot\theta) + \tau_d,
\qquad \tau_m = K_t\, i_q,\quad K_t = \tfrac{3}{2}p\,\lambda_m
$$

Electrical dynamics in the rotor (dq) frame, with $\omega_e = p\,\dot\theta$:

$$
\begin{aligned}
v_d &= R i_d + L\frac{di_d}{dt} - \omega_e L i_q\\
v_q &= R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m
\end{aligned}
$$

## 2. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 2.1 Transforms

**Clarke transform** (amplitude-invariant, using $i_a+i_b+i_c=0$):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park transform**, with $\theta_e = p(\theta_{enc}-\theta_{off})$:

$$
\begin{bmatrix}i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}
$$

**Delay compensation.** The voltage computed at sample $k$ is applied on average at $k+1.5$ PWM periods. The inverse Park transform therefore uses a predicted angle:

$$
\theta_e^{*} = \theta_e + 1.5\,\omega_e T_s
$$

### 2.2 Current PI with Decoupling (Pole-Zero Cancellation)

The plant per axis is $G(s)=\frac{1}{Ls+R}$. Choose the zero of the PI controller to cancel the plant pole:

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c
\;\;\Rightarrow\;\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}
$$

Select $\omega_c \le 2\pi f_{pwm}/20$. At 20 kHz this gives $\omega_c \approx 2\pi\cdot 1\,$kHz.
