# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Fusion

I don't have the Job #28 spec sheet, so this design uses the stated assumptions. Each one is a single `constexpr` in the code, so it is easy to change.

## 0. Assumptions and Loop Rates

| Item | Value |
|---|---|
| MCU | STM32G4 / H7-class, single-precision FPU |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit magnetic (MT6701/AS5047), SPI, read every current-loop tick |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |
|
