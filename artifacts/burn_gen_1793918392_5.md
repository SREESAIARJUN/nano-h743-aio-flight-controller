# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have Job #49's hardware specifics, so this design states its assumptions explicitly. Every constant lives in one config struct so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motor, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kt = 0.08 N·m/A |
| Commutation sensor | 14-bit magnetic encoder per joint (e.g., AS5048A / MT6701) |
| Current sensing | 2-phase low-side or inline shunts, synchronous ADC |
| MCU | Cortex-M7 / M4F with single-precision FPU (STM32G4/H7 class) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, shared CLKIN |
| Joint order | base → yaw (ψ) → roll (φ) → pitch (θ) → camera |
