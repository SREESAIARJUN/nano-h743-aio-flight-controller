# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

I don't have the original specification for Job #23, so this design states every hardware assumption explicitly. Each assumption is collected in a config struct, so changing the hardware means changing parameters, not rewriting equations.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Commutation sensor | 14-bit absolute magnetic encoder (MT6701/AS5048-class) per axis |
| Current sense | Optional. Both a current-mode and a voltage-mode path are provided. |
| MCU | Cortex-M4F/M7 or STM32G4-class with an FPU. All math is single precision. |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, shared 32 kHz CLKIN |
| PWM | 20 kHz center-aligned, SVPWM |

**Loop rates (timescale separation ≥ 5× between nested loops):**

```
 20 kHz PWM ─┐
 10 kHz  : FOC current/voltage loop + cogging FF          (ISR, highest priority)
  8 kHz  : IMU ODR (both sensors), FIFO-read in DMA bursts
  2 kHz  : IMU filter chain + fusion + velocity loop       (ISR)
  1 kHz  : attitude estimator + angle loop                 (ISR)
 100 Hz  : mode logic, cogging-table learning, telemetry   (task)
```

**Key architectural point for a stabilizer.** The encoder is used only for commutation and the cogging phase. The stabilization loops (angle and velocity) close on the **camera's inertial attitude and rate from the fused IMUs**. Base disturbances are rejected through the gyro-rate loop, not through the encoder.
