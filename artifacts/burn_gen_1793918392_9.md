# Job #43: 3-Axis Gimbal FOC Control Loop and Dual ICM-42688-P Sensor Fusion

**Design summary.** This document covers the high-rate control stack of a 3-axis brushless gimbal:

- A field-oriented current loop
- A cascaded inertial angle → rate → torque controller with kinematic decoupling
- An adaptive Fourier-series anti-cogging feedforward
- A dual-IMU front end that does lever-arm cancellation, fault voting, and adaptive notch filtering

All equations are given in continuous and discrete form. The C++17 implementation is header-only, heap-free and MCU-portable.

---

## 0. Assumptions

These are baseline assumptions. Change the constants in `config.hpp` (§6.1) if your hardware differs.

| Item | Value |
|---|---|
| MCU | STM32G474 / H7-class, single-precision FPU, 170+ MHz |
| Motors | GM4108-class, 12N14P (pole pairs `p = 7`), R ≈ 10 Ω, L ≈ 4 mH |
| Encoders | 14-bit absolute magnetic encoder (AS5048A / MT6701) per joint |
| Inverter | 3-phase, low-side shunts, 20 kHz center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera plate, mirrored about the pitch axis, SPI at 24 MHz, ODR 8 kHz, shared external CLKIN
