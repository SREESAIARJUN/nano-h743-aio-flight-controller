## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Here θ_off is found at commissioning: inject $V_d$ at $\theta_e = 0$, let the rotor align, then record θ_m.

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)\quad(\text{assuming } i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 PMSM model in the dq frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q \quad (\text{SPM: } L_d = L_q = L)$$

### 1.4 Current PI design (pole-zero cancellation)

The plant per axis, after decoupling, is $G_i(s) = \dfrac{1}{Ls + R}$.

With $C(s) = K_p + K_i/s$, place the PI zero on the plant pole:

$$\boxed{K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}}$$

The closed loop then reduces to a first-order system, $\dfrac{\omega_{ci}}{s+\omega_{ci}}$.

- Choose $\omega_{ci} \le 2\pi f_{pwm}/10$. At 20 kHz that gives $\omega_{ci} \approx 2\pi\cdot1500$ rad/s.
- Account for the 1.5-sample delay: with $T_d = 1.5T_s$, phase margin ≈ $90^\circ - \omega_{ci}T_d\cdot\frac{180}{\pi} \approx 74^\circ$.

**Decoupling and back-EMF feedforward:**

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e (L i_d + \lambda_m)$$

**Voltage limiting:** use a circular limit $\sqrt{v_d^2+v_q^2} \le V_{dc}/\sqrt3$. Give $v_d$ priority (it holds $i_d = 0$), and $v_q$ gets the remainder:

$$v_{q,\max} = \sqrt{(V_{dc}/\sqrt3)^2 - v_d^2}$$

### 1.5 Voltage-mode fallback (no current sensing)

Gimbal motors are high-R and low-speed, so open-loop voltage FOC is common:

$$v_q^* = R\,i_q^* + \omega_e\lambda_m,\qquad v_d^* = -\omega_e L\, i_q^*$$

The code supports both modes via `kUseCurrentSensing`.

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\quad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_a,v_b,v_c) + \min(v_a,v_b,v_c)\right)$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}},\quad x\in\{a,b,c\}$$

This is mathematically identical to sector-based SVPWM, and it is branch-light.

## 2. Cascaded Angle/Velocity Control

### 2.1 Mechanical plant per axis

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

Assuming the current loop is ideal at the velocity bandwidth, the plant is $G_\omega(s) = \dfrac{K_t}{Js + B} \approx \dfrac{K_t}{Js}$.

### 2.2 Velocity PI (symmetric-optimum style)

Target crossover $\omega_{cv}$, with the PI zero a factor $a$ below it ($a = 3$–$4$):

$$\boxed{K_{p,\omega} = \frac{J\,\omega_{cv}}{K_t},\qquad K_{i,\omega} = K_{p,\omega}\frac{\omega_{cv}}{a^2}}$$

The resulting phase margin is $\arctan\!\frac{a^2-1}{2a} \approx 53^\circ$ at $a=3$.
