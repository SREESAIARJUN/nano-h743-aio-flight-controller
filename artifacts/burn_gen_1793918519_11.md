# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

**Scope note:** I don't have the Job #49 specification, so the motor, encoder, MCU and timing parameters below are representative values for a BLDC gimbal: a 2804/4108-class motor, a 14-bit magnetic encoder, and a Cortex-M7 at about 480 MHz. Every hardware-dependent value is isolated in one config struct and marked `// PROJECT`. Register values for the ICM-42688-P are taken from datasheet DS-000347. **Verify them against your silicon revision before flashing.**
