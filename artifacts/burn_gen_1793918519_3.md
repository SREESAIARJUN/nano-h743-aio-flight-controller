# 3-Axis Gimbal FOC Control and Dual-IMU Fusion: Design Specification and Reference Implementation

I don't have the Job #20 specification, so this design uses the assumptions below. Every assumption is a named constant in the code, so you can change them in one place.

| Parameter | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 3 mH |
| Encoder | 14-bit magnetic encoder (AS5048A or MT6701), one per joint |
| MCU | STM32G4/H7 class with FPU; 3-shunt or inline current sensing |
| Bus voltage | V_dc = 12–16 V |
| IMUs | Two ICM-42688-P on the camera plate, mirrored about the plate center, gyro and accel ODR = 8 kHz |
| Kinematics | Yaw → Roll → Pitch (base to camera) |

The control loops run at these rates:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC, d/q PI) | 20 kHz (PWM-synced) | ~1.5 kHz |
| Velocity PI + cogging FF | 4 kHz | ~80–150 Hz |
| Attitude/angle P(+I) | 1 kHz | ~15–30 Hz |
| IMU fusion (filters at 8 kHz, AHRS at 1 kHz) | 8 kHz / 1 kHz | – |

Two rules govern the bandwidths:
- Adjacent loops are separated by at least 5–10×.
- The total phase lag of the IMU filters at the velocity crossover is kept below about 15°.

## 1. FOC Inner Loop: Equations

### 1.1 Transforms

The electrical angle comes from the mechanical angle, the pole-pair count, and a calibrated offset:

$$\theta_e = p\,\theta_m - \theta_{\text{off}} \pmod{2\pi}$$

**Clarke transform** (amplitude-invariant; with a 3-shunt measurement, enforce $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** is the transpose of the same rotation matrix.

### 1.2 Plant and Current PI (pole–zero cancellation)

The surface-PM motor model in the dq frame is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Choose the PI zero to cancel the electrical pole at $R/L$:

$$C_i(s)=K_p+\frac{K_i}{s},\quad K_p = L\,\omega_{ci},\quad K_i = R\,\omega_{ci}$$

The closed loop is then first order, $I/I^* = \omega_{ci}/(s+\omega_{ci})$.

Apply decoupling and back-EMF feedforward to the PI outputs:

$$v_d^* = \text{PI}_d - \omega_e L i_q,\qquad v_q^* = \text{PI}_q + \omega_e L i_d + \omega_e \lambda_m$$

**Voltage limiting:** apply circular limiting at the linear SVPWM limit $|v_{dq}| \le V_{dc}/\sqrt3$, prioritizing $v_d$.

**Anti-windup:** use back-calculation with gain $K_{aw} = 1/K_p$.

**Torque relation:** torque per amp is $K_t = \tfrac32 p\lambda_m$, so

$$i_q^* = \tau^*/K_t$$
