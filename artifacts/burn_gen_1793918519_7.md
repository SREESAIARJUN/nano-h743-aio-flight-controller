# Gimbal Control Design: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #32 specification, so this design uses the assumptions in the table below. Each one is a named constant in the code, so you can substitute your values.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), used for commutation and cogging indexing |
| IMUs | 2 × ICM-42688-P, both rigidly mounted on the camera plate at offsets r₁ and r₂ from the pitch axis, on separate SPI buses |
| MCU | Cortex-M4F/M7 with FPU and center-aligned PWM |
| Current loop | 20 kHz, synchronous ADC sampling at PWM center |
| IMU and filters | 8 kHz ODR, filtered at 8 kHz |
| Velocity loop | 4 kHz |
| Angle loop | 1 kHz |

Signal flow for each axis:

```
θ_ref ─►[Angle P + FF]─ω_ref─►[Velocity PI]─i_fb─►(+)─iq_ref─►[FOC PI_dq]─►SVPWM─►Motor
          ▲                    ▲                    ▲
     q (attitude→joint)   q̇ (gyro→joint)     i_cog(θ_m) + J·α_ref/Kt
          ▲                    ▲
   Mahony AHRS ◄── Dual-IMU fusion ◄── lever-arm comp, consistency, adaptive notches, LPF
```
