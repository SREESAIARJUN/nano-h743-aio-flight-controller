# STM32H743 FC + 4-in-1 ESC (Job #41): Thermal, Switching and Bi-Directional DShot Design Package

## 0. Scope, Assumptions and Key Findings

I don't have the actual Job #41 schematics, BOM or stackup. Everything below is a **parametric reference model**. Each assumption is stated so you can substitute your real part values. Items marked **[VERIFY]** need checking against datasheets or your ArduPilot tree before release.

**Architecture assumption.** The STM32H743 runs ArduPilot as the flight controller. Each ESC channel runs its own motor MCU (AM32 or BLHeli_32 class, e.g. AT32F421) driving a 3-phase bridge. ArduPilot does not commutate motors itself, so "48 kHz switching" is an ESC-firmware parameter and DShot600 is the FC→ESC link.

| Parameter | Value used |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V (max), 22.2 V (nominal) |
| Burst current | 80 A per motor (phase/DC-link average during burst) |
| MOSFET | 40 V, R_DS(on) = 0.9 mΩ @ 25 °C, PDFN 3.3×3.3, Q_g ≈ 30 nC, Q_rr ≈ 30 nC, Q_oss ≈ 40 nC |
| Commutation | 6-step trapezoidal, synchronous complementary PWM |
| f_sw | 48 kHz, dead time 100 ns |
| Gate driver | FD6288Q-class 3-phase driver, ~10 V gate drive |
| Board | "Nano" class, 20×20 mm mounting, 30×30 mm max outline, 6-layer, 2 oz outer copper |

> **Feasibility finding:** an 80 A *continuous* per-motor rating is not physically achievable on a nano-format 4-in-1. The model below supports 80 A only as a **~1.5–2 s adiabatic burst** from a warm start. This must appear in the product spec, enforced by firmware current limiting, or the board will be field-returned.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,\big[1+\alpha\,(T_j-25)\big],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C: R_DS = 0.9 × 1.5 = **1.35 mΩ**. For margin, use 1.44 mΩ (×1.6, typical datasheet curve).

### 1.2 Current path in 6-step synchronous PWM

At any instant, current flows through exactly **two FETs in series**:
- the PWM leg (HS during on-time, LS during off-time via synchronous rectification), and
- the fixed leg's LS (or HS).

So the conducted loss is independent of duty cycle, apart from dead-time:

$$P_{cond,motor} = I^2 \cdot 2\,R_{DS}(T_j) = 80^2 \times 2 \times 1.44\,\text{m}\Omega = \mathbf{18.4\ W}$$

### 1.3 Per-FET average

Each of the 6 FETs carries current for about 1/3 of an electrical revolution:

$$P_{cond,FET} \approx \frac{18.4}{6} \approx \mathbf{3.1\ W}\ \text{(average)},\qquad 9.2\ \text{W instantaneous while conducting}$$

### 1.4 Copper losses (often forgotten, significant at 80 A)

The current path runs bus → FET → phase pad → return. Assume about 1.5 mΩ total (2 oz, short pours, vias).

$$P_{Cu} = 80^2 \times 0.0015 \approx \mathbf{9.6\ W\ per\ motor}$$

**Copper is a heat source comparable to the FETs.** Use 3 oz inner power planes and via-stitch phase pads; this is your cheapest loss reduction.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. Its HS and LS form a synchronous pair.

| Term | Formula | Value |
|---|---|---|
| V–I overlap (hard switching on HS) | ½·V·I·(t_r+t_f)·f, with t_r+t_f = 40 ns | ½·25.2·80·40n·48k = **1.94 W** |
| Body-diode conduction in dead time | V_F·I·2·t_dt·f = 0.8·80·2·100n·48k | **0.61 W** |
| Reverse recovery (LS body diode) | V·Q_rr·f = 25.2·30n·48k | **0.04 W** |
| Output capacitance | ½·Q_oss·V·f | **0.02 W** |
| Gate charge (dissipated in driver/R_g) | 2·Q_g·V_GS·f | **0.03 W** |
| **Total switching, per motor** | | **≈ 2.6 W** |

Sensitivity:
- **Overlap loss scales linearly with f_sw.** At 24 kHz it falls to about 1.3 W total switching.
- **Dead time is the second-largest term.** Tighten it toward ~50 ns only after measuring shoot-through margin.
