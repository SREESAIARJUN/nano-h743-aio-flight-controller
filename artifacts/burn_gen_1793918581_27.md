# STM32H743 Nano FC + 4-in-1 ESC: Power Stage and DShot Design Model

**Job #35 Design Basis, Rev A**

## 0. Scope and Assumptions

### 0.1 Partitioning

The H743 does not commutate the motors. In any 4-in-1 stack the FC (STM32H743) generates bi-directional DShot600. The ESC's own MCU (typically AT32F421 or STM32G071 running AM32/BLHeli_32) runs the 48 kHz PWM and commutation. The model below is split accordingly:

- **Part A:** ESC power stage, covering losses and thermal behavior.
- **Part B:** FC-side ArduPilot timer and DMA allocation.
- **Part C:** Netlists.

### 0.2 Concerns to Resolve Before Layout

1. **"80 A burst" must be defined.** If it means 80 A per motor, the stack draws 320 A from the battery. That exceeds an XT60 (about 60 A continuous) and any realistic 20×20 board copper. Section 3 shows it is only survivable for about 2 to 3 seconds.
   - I model it as 80 A per motor and flag where it breaks.
   - If the spec actually means 80 A total, divide all conduction losses by about 16.
2. **All MOSFET and driver parameters are representative, not from a selected BOM.** Substitute datasheet values into the equations; the equations are the deliverable.

## Part A: Loss Model

### A.1 Conduction Losses

In 6-step synchronous PWM, two phases are active per sector. At any instant, exactly one FET per active phase conducts: high-side during t_on, low-side during t_off. The motor current therefore always passes through two FET channels in series.

**Temperature-dependent R_ds,on:**

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha_R (T_j - 25)]$$

**Phase current vs. battery current:**

$$I_{ph} = \frac{I_{bat}}{D}$$

At burst, D → 0.95 to 1, so I_ph ≈ I_bat. This is why low-throttle, high-torque operation is worst for conduction loss per battery amp.

**Conduction loss per motor:**

$$P_{cond} = 2\, I_{ph}^2\, R_{ds}(T_j) \qquad \text{(ripple neglected; add } \Delta I^2/12 \text{ term if } L_{ph} \text{ is small)}$$

At T_j = 110 °C, R_ds = 1.0 × (1 + 0.006 × 85) = 1.51 mΩ:

$$P_{cond} = 2 \times 80^2 \times 1.51\,\text{m}\Omega = \mathbf{19.3\ W/motor}$$

**Thermal runaway check.** Because P_cond rises with T_j, solve the fixed point:

$$T_j = T_{ref} + R_{\theta}\cdot 2I^2 R_{25}[1+\alpha(T_j-25)]$$

$$\Rightarrow\; T_j = \frac{T_{ref} + K(1-25\alpha)}{1 - K\alpha}, \quad K = 2I^2R_{25}R_\theta$$

Stability requires Kα < 1, i.e. R_θ < 1/(2I²R₂₅α) = 1/(2·6400·1e-3·0.006) ≈ **13 K/W per motor channel**. The board-level R_θ must sit well below this, which steady-state 80 A cannot achieve on 20×20 (see A.4).

### A.2 Switching Losses at 48 kHz

Only the PWM'd phase switches. The other active phase is held statically. That gives one switching half-bridge per motor.

| Term | Equation | Value |
|---|---|---|
| V·I overlap | ½·V·I·(t_r + t_f)·f_sw | ½·25.2·80·30 ns·48k = **1.45 W** |
| C_oss | Q_oss·V·f_sw | 40 nC·25.2·48k = **0.05 W** |
| Reverse recovery | Q_rr·V·f_sw | 30 nC·25.2·48k = **0.04 W** |
| Dead-time diode | V_f·I·2t_dt·f_sw | 0.8·80·400 ns·48k = **1.23 W** |
| Gate drive* | 2·Q_g·V_gs·f_sw | 2·60 nC·10·48k = **0.06 W** |
| **Total P_sw** | | **≈ 2.8 W/motor** |

\*Gate drive loss is dissipated in the driver and R_g, not in the FET.

Design notes on switching loss:

- **Dead-time is the largest switching term.** Reducing t_dt from 200 to 100 ns (if the driver and shoot-through margin allow) saves about 0.6 W per motor.
- **D = 1 removes the switching terms.** At true 100 % duty, AM32 stops switching and P_sw → 0. The 2.8 W figure applies to about 95 % duty.

### A.4 Thermal Model

**Network:** junction → case → PCB (lumped C) → ambient (prop wash). Per FET R_θjc ≈ 1.5 K/W and R_θc-pcb ≈ 4 K/W (thermal vias under pad).

**FET temperature rise.** Each phase is active 2/3 of the electrical cycle. Per-FET average dissipation is therefore about 22 W / 6 ≈ 3.7 W:

$$\Delta T_{j-pcb} \approx 3.7 \times (1.5+4) \approx 20\ \text{K}$$
