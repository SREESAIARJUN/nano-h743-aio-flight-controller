## 0. Architecture Decisions and Assumptions

**The STM32H743 does not commutate the motors.** The H743 runs ArduPilot and generates DShot. Each of the four ESC channels has its own ESC MCU running AM32, which performs commutation and 48 kHz PWM. This is the only architecture that lets ArduPilot bi-directional DShot work unmodified.

```
6S LiPo ──┬── Bulk caps ── 4× [AT32F421 ESC MCU → 3-ph gate driver → 6 MOSFETs → motor]
          │                        ▲ DShot600 bidir (1 wire per motor)
          └── 5V/3V3 BEC ── STM32H743 (ArduPilot) ── IMU, baro, OSD, UARTs
```

**Design basis.** These values are representative, not tied to a specific datasheet. Replace them with your selected MOSFET's values and re-run the equations.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current Path
In six-step (trapezoidal) commutation with synchronous complementary PWM, current at any instant flows through two conducting devices: one high-side or its synchronous complement, plus one low-side. Including the shunt and copper:

$$R_{path} = 2\,k_T R_{25} + R_{shunt} + R_{Cu}$$

### 1.2 MOSFETs Only

$$R_{DS,hot} = 1.5 \times 0.90 = 1.35\ \text{m}\Omega$$

$$P_{cond,ch} = I_{pk}^2 \cdot 2R_{DS,hot} = 6400 \times 2.70\text{m} = \mathbf{17.28\ W}$$

### 1.3 Per-MOSFET Average
Each of the six FETs carries current for 120° of the 360° electrical cycle. The two FETs that conduct at any instant share the 17.28 W equally (8.64 W each), so each FET's average is:

$$P_{cond,FET} = \frac{1}{3} \times 8.64 = 2.88\ \text{W}$$

### 1.4 Shunt and Copper
Assume a 0.25 mΩ shunt (or none if you use R_DS sensing) and about 0.3 mΩ of 2 oz copper path:

$$P_{shunt+Cu} = 6400 \times 0.55\text{m} = 3.52\ \text{W per channel}$$

This loss heats the PCB, not the FET dies. Keep it in the board budget.

### 1.5 RMS Correction for PWM Ripple
The phase inductance (L_ph ≈ 15 µH, typical of a 5" motor) produces ripple:

$$\Delta I = \frac{(V_{bus}-V_{bemf})\,D}{L\,f_{sw}} \approx \frac{12.6 \times 0.5}{15\mu \times 48k} = 8.75\ \text{A}_{pp}$$

$$I_{rms}^2 = I_{pk}^2 + \frac{\Delta I^2}{12} = 6400 + 6.4$$

The correction is +0.1%, so it is negligible at 48 kHz. This is one benefit of the high PWM frequency.

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate-Drive Transition Time
Driver source/sink about 1.5 A/1.8 A, with gate voltage V_drv ≈ 9.3 V after bootstrap droop:

$$I_g = \frac{V_{drv} - V_{plateau}}{R_{g,ext} + R_{g,int}} = \frac{9.3 - 3.5}{4.7 + 1.2} = 0.98\ \text{A}$$

$$t_{r} \approx \frac{Q_{gd}}{I_g} = 12.2\ \text{ns}$$

Use **t_r = t_f = 20 ns** to account for Q_gs2 and common-source inductance.

### 2.2 Loss Components (per channel, only one leg PWM-switching at a time)

| Loss term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r + t_f)·f_sw = ½·25.2·80·40n·48k | **1.935 W** |
| C_oss charge | Q_oss·V·f_sw = 60n·25.2·48k | 0.073 W |
| Reverse recovery | Q_rr·V·f_sw = 50n·25.2·48k | 0.060 W |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw = 0.8·80·200n
