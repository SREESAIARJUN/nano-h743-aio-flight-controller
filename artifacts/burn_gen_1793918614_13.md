# STM32H743 AIO Flight Controller + 4-in-1 ESC: Systems Architecture Package (Job #40)

## 0. Scope, Assumptions, and Early Findings

No MOSFET, gate driver, stack-up, or board size was specified, so this package uses representative parameters. Every number below is a function of those inputs. **Re-run the model with datasheet values for the parts you actually procure.**

### 0.1 Architectural clarification

The STM32H743 cannot practically commutate four BLDC motors at 48 kHz while also running ArduPilot. The architecture is therefore split:

| Block | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIH6 @ 400 MHz | ArduPilot; emits bi-directional DShot600 |
| ESC MCUs (×4) | AT32F421K8U7 or STM32G071 class, running AM32 | 6-step commutation, 48 kHz complementary PWM, eRPM telemetry |
| Gate drivers (×4) | FD6288Q (3-phase, 250 V-class, bootstrap) | High-side and low-side drive |
| Power stage | 24× N-MOSFETs, 40 V, DFN3.3×3.3 | 4 channels × 3 legs × 2 FETs |
