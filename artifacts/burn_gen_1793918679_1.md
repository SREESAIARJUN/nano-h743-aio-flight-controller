# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original spec for "Job #3", so this design states its assumptions explicitly (§0). Every equation is parameterized, so you can substitute your actual motor, encoder and MCU values.

## 0. Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU, CORDIC) or equivalent |
| Motors | Gimbal BLDC, e.g. GBM2804: 12N14P, so pole pairs p = 7, R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Driver | 3-phase with low-side shunts (e.g. DRV8313 / TMC6300) |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on each motor |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, data-ready interrupts |
| Joint order | Yaw (z, base) → Roll (x) → Pitch (y, camera) |

**Loop rates:**

| Loop | Rate | Notes |
|---|---|---|
| Current (FOC) | 20 kHz | Center-aligned PWM, sampling synced to the PWM center |
| Velocity | 4 kHz | Decimated by 5 |
| Attitude/angle | 1 kHz | Fusion runs at the 8 kHz IMU rate, decimated to 1 kHz for the angle loop |

**Bandwidth separation rule:**

$$\omega_{c,i} \ge 5\,\omega_{c,v} \ge 25\,\omega_{c,\theta}$$

Typical targets: current loop 1.5–2 kHz, velocity loop 150–300 Hz, angle loop 20–40 Hz.

## 1. Field-Oriented Control (innermost loop)

### 1.1 Transforms

With electrical angle $\theta_e = p\,\theta_m - \theta_{off}$:

**Clarke** (amplitude-invariant, using $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and current PI tuning

The PMSM in the rotor frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

PI regulators with cross-coupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L\, i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L\, i_d + \omega_e\lambda_m$$

Pole-zero cancellation of $1/(Ls+R)$ gives a first-order closed loop of bandwidth $\omega_{c,i}$:

$$K_{p,i} = L\,\omega_{c,i},\qquad K_{i,i} = R\,\omega_{c,i}$$

Gimbals run at low speed, so the $\omega_e$ terms are small. They are kept for fast slews.

### 1.3 Voltage limiting and SVPWM

Circular limit: $\sqrt{v_d^2+v_q^2} \le V_{bus}/\sqrt3$. Priority goes to $v_d$, and $v_q$ gets the remainder.

SVPWM is implemented by min-max (zero-sequence) injection:

$$v_{abc} = \text{invClarke}(v_\alpha,v_\beta),\qquad v_0 = -\tfrac12(\max v_{abc}+\min v_{abc})$$

$$d_x = \frac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.4 Torque

$$\tau = \tfrac32\,p\,\lambda_m\, i_q = K_t\, i_q$$
