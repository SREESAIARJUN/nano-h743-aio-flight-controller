# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #42)

## 0. Design Assumptions

I don't have the Job #42 specification, so the design below rests on assumptions. Every one of them is a single constant in the code; change it to match your hardware.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7, slots Nₛ = 12), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.06 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class) |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| Current sense | Inline or low-side, 2-phase, synchronous to PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, placed symmetric about the plate centroid |

### Loop rates

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz, PWM-synchronous ISR | ≈ 1.5 kHz |
| Velocity | 4 kHz | ≈ 150 Hz |
| Angle / attitude | 1 kHz | ≈ 30 Hz |
| IMU ODR | 8 kHz (gyro and accel) | — |
| Fusion and filtering | 8 kHz pre-filter, 1 kHz attitude | — |

Each loop has at least 5× bandwidth separation from the next, which is required for the cascade to stay decoupled.

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$
θ_off is found at calibration: align the d-axis with V_d > 0, V_q = 0, then read the encoder.
