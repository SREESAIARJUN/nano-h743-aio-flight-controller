# 3-Axis Gimbal FOC Control & Dual-IMU Fusion: Design Specification

**Scope:** current-loop FOC, cascaded angle/velocity control, anti-cogging feedforward, dual ICM-42688-P vibration rejection and fusion.

---

## 0. Baseline Assumptions

I don't have the Job #64 hardware specification, so the design uses typical gimbal values. Every value below is a `constexpr` or a config field in the code, so you can replace it once the real hardware is known.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, single-precision FPU, CORDIC unit) |
| Motor | Gimbal BLDC, 12N14P → pole pairs p = 7, R_s ≈ 5.6 Ω, L_s ≈ 2.1 mH |
| Encoder | 14-bit absolute magnetic encoder (MT6701 / AS5048A), SPI |
| Bus voltage | 4S Li-ion, 12–16.8 V |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Current loop | 20 kHz (center-aligned PWM, sampling synchronized to PWM) |
| Velocity loop | 4 kHz |
| Angle loop | 1 kHz |
| Attitude estimator | 1 kHz (Mahony, using the fused IMU) |

Required bandwidth separation, with ω_c the current-loop bandwidth, ω_v the velocity-loop crossover and ω_θ the angle-loop crossover:

$$\omega_c \;\ge\; 8\text{–}10\,\omega_v,\qquad \omega_v \;\ge\; 4\text{–}5\,\omega_\theta$$
