## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (7 pole pairs), R ≈ 10 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit magnetic absolute (AS5048A / MT6701 class), SPI |
| Driver | 3-phase, low-side shunt sensing, V_bus = 12–16 V |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| IMUs | 2 × ICM-42688-P on camera plate, SPI, FIFO + timestamps, symmetric about the plate centroid |

### Loop rates

```
PWM / current loop (FOC)       20 kHz    ISR, center-aligned PWM, ADC-triggered
Velocity loop (per axis)        4 kHz    every 5th current ISR
IMU read + vibration filters    4 kHz    ODR 8 kHz, FIFO drain at 4 kHz (2 samples/read)
Attitude estimator (AHRS)       1 kHz
Angle loop                      1 kHz
Cogging LMS adaptation          1 kHz    (background, optional online)
```

### Bandwidth separation

Each outer loop runs at roughly 5–10× lower bandwidth than the loop it drives:

- ω_c (current) ≈ 2π·1500 rad/s
- ω_v (velocity) ≈ 2π·150 rad/s
- ω_θ (angle) ≈ 2π·20 rad/s

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Coordinate transforms

Electrical angle from the mechanical encoder angle, where p is the number of pole pairs and θ_off is the calibrated offset:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Motor model in the dq frame (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q,\qquad \omega_e = p\,\omega_m$$

### 1.3 Current PI with decoupling and back-EMF feedforward

The control law is:

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

After decoupling, each axis reduces to the plant 1/(Ls + R).
