# Job #57: 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

## 0. Design Basis and Assumptions

No hardware specification was attached, so the design uses these baseline parameters. Every one of them is a named constant in the code, so you can substitute your own values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU) or equivalent |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.11 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per joint (MT6701 / AS5048A class) |
| Inverter | 3-phase, 24 V bus, center-aligned PWM at 20 kHz, 3-shunt sensing |
| IMUs | 2× ICM-42688-P
