# Job #26: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

## 0. Assumptions

These are stated up front so the gains and filters can be re-derived for your hardware. Replace the numbers, not the structure.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R = 10 Ω, L = 2.0 mH, K_t = 0.11 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class) |
| MCU | STM32G4/H7-class FPU, center-aligned PWM |
| Loop rates | Current 20 kHz → Rate 4 kHz → Attitude 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate (IMU-A, IMU-B), SPI, ODR 8 kHz, ±2000 dps, ±16 g |
| Gimbal order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
| Vibration source | Drone props: fundamental ~80–250 Hz plus harmonics, frequency known from ESC telemetry or estimated |

The two IMUs are both used as feedback sensors. They give redundancy and noise reduction, and each has its own independent vibration-rejection chain.
