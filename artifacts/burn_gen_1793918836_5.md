# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #48, so this design states its assumptions explicitly. Every parameter is a named constant that you can replace with your measured values.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (GBM2804-class): 12N14P → pole pairs `p = 7`, `R ≈ 5.6 Ω`, `L ≈ 2.1 mH`, `Kt ≈ 0.075 N·m/A` |
| Position sensor | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701), SPI |
| MCU | STM32G474 class: Cortex-M4F, 170 MHz, single-precision FPU |
| IMU-P | ICM-42688-P on the **payload** (camera plate): feedback sensor |
| IMU-B | ICM-42688-P on the **base** (handle or airframe): vibration reference and base-rate feedforward |
| Inertia (per axis, reflected) | `J ≈ 2.0e-4 kg·m²` (identify, see §2.4) |

### Loop rates

| Loop | Rate | Ts |
|---|---|---|
| Current / FOC (PWM-synchronous ADC ISR) | 20 kHz | 50 µs |
| IMU sampling and vibration filters (IMU DRDY) | 8 kHz | 125 µs |
| Inertial rate (velocity) loop | 4 kHz | 250 µs |
| Attitude (angle) loop and AHRS | 1 kHz | 1 ms |

### Signal flow

```
 q_ref ──►[Attitude P (+I)]──ω_ref──►(+)──►[Rate PID]──τ_cmd──►(+)──► i_q* ──►[FOC current PI]──►SVPWM──►Motor
            ▲                       ▲ ▲                         ▲
            │ q̂ (Mahony)  base-rate FF │ ω̂_payload (cleaned)      │ anti-cogging i_ff(θ_m)
            │                           │                          │
 IMU-P ──►[AAF on-chip]──►[NLMS canceller ◄── IMU-B ref]──►[Notch]──►[LPF]
```

A key design decision follows from this flow. The velocity loop closes on **inertial rate from the payload gyro**, not encoder rate, because stabilization is an inertial problem. The encoder serves three purposes only:

- commutation,
- anti-cogging indexing,
- soft-limit and frame kinematics.

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

`θ_off` is found at calibration: inject `i_d = I_align`, `i_q = 0`, let the rotor settle, then record `θ_m`.
