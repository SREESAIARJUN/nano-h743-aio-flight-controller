## 0. Scope, Assumptions, and Corrections

Several points must be fixed before any number below is meaningful.

1. **The H743 does not commutate the motors.** In every production AIO design, the H743 runs ArduPilot and sends DShot600 to four dedicated ESC MCUs. Those MCUs (for example AT32F421 or STM32G071 running AM32/BLHeli_32) generate the 48 kHz PWM. A single H743 cannot practically run four sensorless FOC/6-step loops alongside ArduPilot, and ArduPilot has no ESC firmware path for that. This document models that two-tier architecture.
2. **"80 A burst" on a nano (20×20 or 25.5×25.5 mm) board is a seconds-scale rating, not continuous.** Section 3 shows it is thermally bounded to about 2–4 s with all four channels loaded.
3. **The MOSFET parameters are placeholders** (a representative 40 V, 3.3×3.3 mm DFN part). Re-run every equation with the datasheet values of the part you actually select, using hot Rds(on) and real gate charge.
4. **No Job #46 design files were provided.** The netlist is a reference topology with generic designators, not a release-ready netlist.

## 1. Conduction Loss Model (6-Step, Complementary PWM)

### 1.1 Who conducts when

In 6-step trapezoidal commutation, each 60° sector has one high-side FET PWMing at duty D and one low-side FET of another phase held on. With synchronous rectification, the complementary low-side of the PWMing leg carries the freewheel current during (1 − D).

Averaged over one electrical cycle, each phase spends 1/3 of the cycle in each role:

| FET | Fraction of electrical period carrying I |
|---|---|
| High-side | D/3 |
| Low-side | (1 − D)/3 + 1/3 = (2 − D)/3 |
| Per leg total | 2/3 |

So the per-motor conduction loss is independent of D. Exactly two FETs are in series with the phase current at all times:

$$P_{cond,ch} = 2\,I^2\,R_{ds}(T_j), \qquad R_{ds}(T_j) = R_{ds25}\,[1 + \alpha (T_j - 25)]$$

The worst-case single FET is the low-side at low throttle (D → 0), with duty fraction 2/3:

$$P_{cond,LS,max} = \tfrac{2}{3}\, I^2 R_{ds}(T_j)$$

### 1.2 Closed-form junction temperature (Rds feedback)

Write the FET loss as P = k[1 + α(T_j − 25)], where k = c·I²·R_ds25 and c is the conduction duty fraction. With T_j = T_b + P·R_th:

$$T_j = \frac{T_b + k R_{th}(1 - 25\alpha)}{1 - k\,\alpha\,R_{th}}$$

The stability (thermal runaway) criterion is **k·α·R_th < 1**. Treat this as a hard design check.

### 1.3 Numbers at 80 A

- R_ds at 125 °C: 1.5 mΩ × 1.45 = **2.18 mΩ**
- Channel conduction loss: P_cond,ch = 2 × 6400 × 2.18 mΩ = **27.9 W**
- Worst-case low-side FET:
  - k = (2/3)(6400)(1.5 mΩ) = 6.4 W
  - R_th = 9.5 K/W
  - k·α·R_th = 0.274, which satisfies the < 1 criterion
  - With the board at 60 °C: T_j = (60 + 6.4 × 9.5 × 0.8875) / 0.726 = **157 °C** in steady state

**Conclusion: 80 A is not sustainable.** It is acceptable only as a transient, governed by the thermal capacitance in Section 3.

Copper loss must be added on top of the FET loss. For a 2 oz trace (0.07 mm thick) with about 0.5 mΩ effective phase path and 0.3 mΩ shared bus:

$$P_{Cu} \approx I^2 (0.5\text{m}\Omega) \approx 3.2\ \text{W per channel}$$
