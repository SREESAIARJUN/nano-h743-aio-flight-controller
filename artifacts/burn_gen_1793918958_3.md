# STM32H743 AIO Nano FC + 4-in-1 ESC: 80 A Burst, 48 kHz, BDShot600 Architecture

## 0. Scope, Assumptions, and Three Early Findings

### Partitioning

The STM32H743 does **not** generate the 48 kHz power-stage PWM. In a 4-in-1 design:

- **The H743** runs ArduPilot and emits bidirectional DShot600.
- **Four ESC MCUs** do the commutation and generate the 48 kHz PWM. Typical choices are AT32F421 or STM32G071 running AM32/BLHeli_32.

The math below is split along that boundary.

### Baseline Parameters

These are representative, not vendor-locked. Replace them with your actual datasheet values.

| Symbol | Value | Note |
|---|---|---|
| V_bus | 25.2 V | 6S full charge (worst case for switching loss) |
| I_ph | 80 A | Burst, per ESC channel |
| f_sw | 48 kHz | Complementary (synchronous) PWM |
| R_ds(on),25 | 1.2 mΩ | 40 V MOSFET, 3.3×3.3 or 5×6 DFN |
| α_R | ≈ 0.6 %/K | R_ds(on) tempco |
| t_r + t_f | 40 ns | At the driver strength chosen |
| t_dt | 50 ns | Dead time per edge |
| V_SD | 0.8 V | Body diode forward drop |
| Q_rr | 30 nC | Q_oss = 40 nC, Q_g = 40 nC at V_gs = 10 V |
| R_th,jc | 1.5 K/W | Per FET |

### Headline Findings

1. **80 A burst is a transient rating, not a thermal operating point.** On a 20×20 mm board the burst is limited to about 1–2 s with all four channels loaded (Section 3).
2. **Bulk capacitor ripple current, not the FETs, is often the first failure mechanism.** It reaches about 40 A RMS per channel at D = 0.5 (Section 4).
3. **On the H743, DMA streams are not the constraint (DMAMUX).** Timer channel pairing for input capture is the constraint (Section 5).

## 1. Conduction Loss Model

### 1.1 Commutation Topology

The ESC uses 6-step trapezoidal drive with synchronous complementary PWM. At any instant, two phases carry I_ph:

- **PWM leg:** the high-side (HS) conducts for duty D; the low-side (LS) synchronous-rectifies for (1−D) minus dead time.
- **Return leg:** the LS is held on for 100% of the sector.

The per-channel conduction loss is therefore:

```
P_cond = I_rms² · R_ds(Tj) · [D + (1−D)] + I_rms² · R_ds(Tj)
       = 2 · I_rms² · R_ds(Tj)
```

This expression is independent of D, to first order, because synchronous rectification is used.

### 1.2 Ripple Correction

Phase inductance L_ph is typically 5–20 µH for small BLDC motors. The peak-to-peak ripple and resulting RMS current are:

```
ΔI_pp = (V_bus − E_bemf) · D / (L_ph · f_sw)
I_rms² = I_avg² + ΔI_pp² / 12
```

**Example:** L_ph = 10 µH, D = 0.5, back-EMF = 12 V.

- ΔI_pp = 13.2 · 0.5 / (10e-6 · 48e3) = 13.75 A
- Ripple term = 13.75² / 12 = 15.8 A²
- This is +0.25% on 6400 A², so it is negligible at 80 A.

### 1.3 Temperature Dependence (Self-Consistent)

```
R_ds(Tj) = R_ds,25 · [1 + α_R · (Tj − 25)]
```

At Tj = 125 °C: R_ds = 1.2 mΩ × 1.60 = **1.92 mΩ**.

```
P_cond,ch = 2 · 80² · 1.92e-3 = 24.6 W   (per ESC channel)
P_cond,4ch = 98.3 W                       (all four at burst)
```

At Tj = 25 °C the per-channel figure would be 15.4 W. The thermal-electrical feedback adds +60%, so it must be iterated (Section 3.4).

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. Its HS and LS each see one hard turn-on or turn-off per PWM cycle.

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½ · V · I · (t_r + t_f) · f_sw | ½·25.2·80·40e-9·48e3 = **1.94 W** |
| Body diode, dead time | V_SD · I · 2·t_dt · f_sw | 0.8·80·100e-9·48e3 = **0.31 W** |
| Reverse recovery | Q_rr · V · f_sw | 30e-9·25.2·48e3 = **0.04 W** |
| C_oss | Q_oss · V · f_sw | 40e-9·25.2·48e3 = **0.05 W** |
| Gate drive (2 FETs) | 2 · Q_g · V_gs · f_sw | 2·40e-9·10·48e3 = 0.04 W (mostly in driver/R_g) |
| **Total, per channel** | | **≈ 2.35 W** |

### Sensitivities

- **Frequency:** P_sw scales linearly with f_sw. At 96 kHz it is about 4.7 W per channel. At 24 kHz it is about 1.2 W, at the cost of audible noise and more ripple.
- **Dead time:** dead-time loss scales with t_dt. Cutting it to 25 ns saves about 0.15 W. Do not go below the driver's propagation skew plus margin.
- **Layout:** overlap time is dominated by commutation-loop inductance. See Section 4.3.

### Per-Channel and Per-FET Totals

```
P_ch(80A, 125°C) = 24.6 + 2.35 ≈ 27.0 W
```

The electrical period is much shorter than any thermal time constant. Above ~1000 eRPM, losses rotate across all 6 FETs:

```
P_FET,avg ≈ 27.0 / 6 ≈ 4.5 W
ΔT_jc = 4.5 · 1.5 ≈ 6.8 K
```

**Low-eRPM exception:** at startup or stall, a single sector can persist for milliseconds. Use transient Z_th,jc(t) from the datasheet for that FET. The worst case is a locked rotor: 2 FETs carrying the full 27 W for the stall time.

## 3. Thermal Model: Why 80 A Is a Burst Rating

### 3.1 Board Heat Capacity

Assumptions: 20×20 mm ESC board, 8 layers at 2 oz (70 µm), 1.6 mm FR4.

| Mass | Calculation | Heat capacity |
|---|---|---|
| Cu | 400 mm² · 8 · 0.070 mm = 0.224 cm³ → 2.0 g · 0.385 J/gK | 0.77 J/K |
| FR4 | 0.64 cm³ → 1.18 g · 1.1 J/gK | 1.30 J/K |
| 24 FETs, caps, solder | ≈ 0.4 J/K | |
| **C_th, total** | | **≈ 2.5 J/K** |

### 3.2 Convective Path

Assume both faces cooled by prop wash, h ≈ 100 W/m²K (optimistic), over 800 mm² of area.

```
R_th,sa = 1 / (100 · 8e-4) = 12.5 K/W
τ = R·C ≈ 31 s
```

Steady-state capability at ΔT = 70 K (40 °C ambient to a 110 °C board) is **about 5.6 W total**. That is roughly 20 A continuous across all four channels, or about 35 A on one.

### 3.3 Burst Duration

The burst is far shorter than τ, so the board is approximately adiabatic.

```
t_burst ≈ C_th · ΔT_allow / P_total
```

| Scenario | P_total | t to +70 K |
|---|---|---|
| 4 × 80 A | 4 · 27 = 108 W | **≈ 1.6 s** |
| 1 × 80 A, 3 × 20 A | 27 + 3·2.1 ≈ 33 W | ≈ 5.
