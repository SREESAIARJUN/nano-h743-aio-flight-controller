**Architecture note:** The STM32H743 does **not** commutate the motors. It is the flight controller running ArduPilot. Each motor channel has its own ESC MCU (an AT32F421 or STM32G071 running AM32/BLHeli_32), which generates the 48 kHz PWM. The H743 talks to the ESC MCUs over bidirectional DShot600. Merging both roles into one H743 is technically possible but is not supported by ArduPilot and would break real-time isolation.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,[1+\alpha(T_j-25)],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C, the multiplier is 1.5, giving R_DS(on) ≈ **1.5 mΩ**.

### 1.2 RMS current including ripple

$$I_{rms}^2 = I_{DC}^2 + \frac{\Delta I_{pp}^2}{12},\qquad \Delta I_{pp}=\frac{V_{bus}\,D(1-D)}{L_{ph}\,f_{sw}}$$

Worst-case ripple occurs at D = 0.5. With a typical 5" motor, L_ph ≈ 15 µH (line-to-line, two phases in series, so 30 µH effective):

$$\Delta I_{pp}=\frac{25.2\times0.25}{30\mu\text{H}\times48\text{kHz}}=4.4\text{ A}$$

The ripple term is ΔI²/12 = 1.6 A². This is negligible against 6400 A². The 48 kHz switching frequency is doing its job.

### 1.3 Loss distribution in 6-step commutation

At any instant, one high-side path (high-side FET or its synchronous complement) and one low-side FET carry the full current. Each of the 6 FETs conducts for 1/3 of the electrical cycle.

$$P_{cond,FET} = \frac{I^2 R_{DS(on)}}{3},\qquad P_{cond,ch} = 2\,I^2 R_{DS(on)}$$

**At 80 A, 125 °C:**
- Per FET: 6400 × 0.0015 / 3 = **3.2 W**
- Per channel: **19.2 W**
- All 4 channels: **76.8 W**

### 1.4 Copper and shunt losses

| Element | Resistance | Loss per channel |
|---|---|---|
| Phase copper, 2 oz, ~15 mm × 4 mm pour, 2 layers in parallel | ≈ 0.25 mΩ | 1.6 W |
| Shared 0.25 mΩ current shunt, carrying the total current | 0.25 mΩ | 25.6 W total at 320 A |

The shared shunt loss is a serious problem. **Recommendation:** use a 0.1 mΩ shunt (10.2 W at 320 A) or per-channel sensing.

## 2. Switching Loss Model at 48 kHz

In 6-step operation, only one half-bridge is hard-switched at a time. The relevant voltage is V = 25.2 V and current is I = 80 A.

| Loss term | Equation | Value per channel |
|---|---|---|
| V-I overlap (t_r = t_f = 20 ns) | ½·V·I·(t_r+t_f)·f_sw | 0.5·25.2·80·40n·48k = **1.94 W** |
| Reverse recovery | Q_rr·V·f_sw | 50n·25.2·48k = **0.06 W** |
| Output capacitance | ½·C_oss·V²·f_sw | 0.5·1.5n·635·48k = **0.02 W** |
| Dead-time body-diode conduction (t_dt = 50 ns) | V_f·I·2t_dt·f_sw | 0.8·80·100n·48k = **0.31 W** |
| Gate drive (2 FETs active, dissipated in driver/R_g) | 2·Q_g·V_GS·f_sw | 2·50n·10·48k = **0.05 W** |
| **Total switching** | | **≈ 2.4 W** |

### 2.1 Total burst loss

| Scope | Conduction | Copper | Switching | Total |
|---|---|---|---|---|
| Per channel | 19.2 W | 1.6 W | 2.4 W | **23.2 W** |
| 4 channels | | | | **92.8 W** |
| + shunt (0.1 mΩ) and BEC | | | | **≈ 105 W** |

At 80 A, conduction dominates by about 8:1. **The lever is R_DS(on) and copper, not f_sw.** Doubling to 96 kHz would add only about 2.4 W per channel.

Efficiency check: P_in = 4 × 80 × 25.2 = 8064 W, so total loss is about 1.3%. Efficiency is fine; heat density is the problem.

## 3. Thermal Model

### 3.1 Steady state (why 80 A is burst-only)

Per FET dissipation is (3.2 + 2.4/2 switching share + copper share) ≈ **4.5 W** worst case for the switching FET.

The thermal path:
- R_θJC ≈ 1.0 K/W
- R_θ(case→PCB→air), 30×30 board, 4-layer, 2 oz, vias under the pad, propwash airflow ≈ 6 m/s: ≈ **12 K/W effective per FET**. This accounts for mutual heating from the 24 FETs sharing a ~9 cm² board.

$$T_j = T_a + P\,(R_{\theta JC}+R_{\theta CA}) = 40 + 4.5\times13 = 98.5\ ^\circ\text{C (airflow)}$$

That figure is only valid if board-level heat removal keeps up. The board-level balance is:

$$R_{\theta,board-air} = \frac{1}{hA},\quad h\approx 60\ \text{W/m}^2\text{K (forced)},\ A = 2\times 9.3\ \text{cm}^2 \Rightarrow R\approx 9\ \text{K/W}$$

$$\Delta T_{board} = 105\ \text{W}\times 9\ \text{K/W} = 945\ \text{K}$$

**Conclusion:** 80A×4 continuous is physically impossible on this footprint. The sustainable continuous rating is:

$$I_{cont} = \sqrt{\frac{\Delta T_{max}/R_{board}}{4\cdot 2R_{DS}\cdot k}}$$

With ΔT_max = 70 K, this gives roughly **27–30 A per channel** with airflow. That matches real-world 30×30 "55–65 A" marketing ratings, which are burst ratings.
