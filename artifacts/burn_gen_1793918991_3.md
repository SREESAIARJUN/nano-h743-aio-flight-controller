## 0. Baseline Assumptions and an Architecture Correction

**Architecture correction.** The STM32H743 should **not** run the ESC commutation. The standard and supportable architecture is:

| Function | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100) @ 480 MHz | ArduPilot (ChibiOS) |
| ESC ×4 | 4× AT32F421K8U7 or STM32G071 (QFN32) | AM32 or BLHeli_32 |
| Gate drive ×4 | FD6288Q (3-phase, bootstrap, 20 V) | n/a |
| Power stage ×4 | 6× N-MOSFET per channel (24 total) | n/a |

The H743 talks to the ESC MCUs over **bi-directional DShot600**.

**Operating assumptions:**

| Parameter | Symbol | Value |
|---|---|---|
| Battery | V_bus | 6S, 25.2 V max / 22.2 V nominal |
| Burst phase current per channel | I | 80 A (≤ 5 s) |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, 5×6 or 3.3×3.3) | R_ds(on),25 | 1.2 mΩ @ V_gs = 10 V |
| R_ds(on) temp coefficient | α | ≈ 0.0055 /K (normalized ≈1.46× at 110 °C) |
| Gate charge / Miller charge | Q_g / Q_gd | 40 nC / 10 nC |
| Output charge, reverse-recovery charge | Q_oss / Q_rr | 40 nC / 50 nC |
| Effective edge times | t_r, t_f | 15 ns each |
| Dead time | t_dt | 50 ns per edge |
| Body diode V_f @ 80 A | V_f | 0.9 V |
| Board | n/a | 36×36 mm (30.5 mm mount), 8-layer, 2 oz all layers |
| Ambient | T_a | 40 °C |

**On the "nano" claim.** A true 20×20 board cannot carry 24 FETs rated for 80 A burst. The thermal math in §3 shows why. This package assumes a 30.5 mm mount.
