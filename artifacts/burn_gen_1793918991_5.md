# STM32H743 FC + 4-in-1 ESC (Nano), Job #21: System Architecture and Mathematical Model

## 0. Architectural Correction

The STM32H743 does not drive the gates or run commutation. The correct partitioning is:

| Domain | Device | Function |
|---|---|---|
| Flight controller | STM32H743VIT6 (400/480 MHz) | ArduPilot, bidirectional DShot600 master, eRPM telemetry consumer |
| ESC (×4 channels) | AT32F421 / STM32G071 running AM32 (or one MCU per channel) | Commutation, 48 kHz PWM, DShot slave, GCR eRPM reply |
| Power stage | 3× half-bridge per channel, 24 N-MOSFETs total | Conduction and switching losses |

The 48 kHz switching loss model therefore belongs to the ESC MCU domain. The DShot/DMA model belongs to the H743 domain. Both are derived below.
