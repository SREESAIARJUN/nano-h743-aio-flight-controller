# STM32H743 AIO + 4-in-1 80A ESC: Engineering Model (Job #101)

## 0. Scope, Assumptions, and Corrections

**Architecture.** The H743 does not drive the gates. Every production design of this class uses one small MCU per ESC channel (AT32F421 or STM32G071 running AM32/BLHeli_32). That MCU runs commutation and the 48 kHz PWM. The H743 runs ArduPilot and talks to each ESC MCU over bidirectional DShot600. The model below follows that split.

**Parameters.** No MOSFET or driver part numbers were specified, so I use representative values for 40 V, 3.3×3.3 mm DFN parts typical of 6S nano 4-in-1 ESCs. **Replace them with real datasheet values before sign-off.**

| Symbol | Value | Meaning |
|---|---|---|

| R_ds(on),25 | 1.2 mΩ | at V_gs = 10 V |

**80 A rating.** This model treats 80 A as phase current per motor during a burst. It is not a continuous rating. Section 3 shows that the burst is limited to roughly 1–2 s.

## 1. Conduction Loss Model

**Six-step trapezoidal drive with synchronous rectification.**

- In every commutation sector, current flows through two conducting FETs:
  - the PWM leg, where either the high-side or the low-side FET conducts;
  - the return leg, where the low-side FET conducts.
- Total conduction loss per motor is therefore independent of duty cycle D:

  P_cond,motor = 2 · I_rms² · R_ds(T_j)

**Temperature-corrected resistance.**

R_ds(T_j) = R_ds,25 · [1 + α(T_j − 25)]

At T_j = 125 °C: R_ds = 1.2 mΩ × 1.45 = **1.74 mΩ**

**Ripple contribution.** Worst case is at D = 0.5:

ΔI_pp = V·D(1−D) / (L·f) = 25.2 × 0.25 / (20 µH × 48 kHz) = **6.56 A**

I_rms² = I² + ΔI²/12 = 6400 + 3.6 ≈ 6404 A². Ripple adds only 0.06%, so it is negligible.

**Result per motor at 80 A:**

- P_cond = 2 × 6404 × 1.74 mΩ = **22.3 W**
- Average per FET (6 FETs, sectors rotate): ≈ **3.7 W**
- Instantaneous per conducting FET: I²R = **11.1 W**
  - This matters at low eRPM or stall, where one sector dwells for a long time.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. Each loss term is listed in the table below.

| Loss term | Formula | Value |
|---|---|---|
| Hard switching (V-I overlap) | ½·V·I·(t_r + t_f)·f = ½ × 25.2 × 80 × 40 ns × 48 kHz | **1.94 W**
