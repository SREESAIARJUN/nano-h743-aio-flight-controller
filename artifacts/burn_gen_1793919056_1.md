## 1. Field-Oriented Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, with electrical angle $\theta_e = p\,(\theta_m - \theta_{\text{off}})$:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI Design

**Plant in the dq frame:**

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L \dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

**PI gains by pole–zero cancellation.** The goal is a closed loop of $\frac{\omega_c}{s+\omega_c}$:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

With the assumed parameters: $K_{p,i} = 0.002\cdot 9425 = 18.85\ \text{V/A}$ and $K_{i,i} = 47\,100\ \text{V/(A·s)}$.

**Discrete PI with decoupling and back-EMF feedforward** (forward Euler, step $k$):

$$e_x[k] = i_x^* - i_x,\qquad x\in\{d,q\}$$

$$v_d^{u} = K_{p,i} e_d + I_d - \omega_e L i_q$$

$$v_q^{u} = K_{p,i} e_q + I_q + \omega_e L i_d + \omega_e\lambda_m$$

**Voltage-vector saturation.** Linear SVPWM limits the vector magnitude:

$$|v|_{\max} = \frac{V_{bus}}{\sqrt3}\cdot m_{\max}$$

The unsaturated vector $v^u$ is scaled to $v$ if it exceeds this limit.

**Back-calculation anti-windup:**

$$I_x \leftarrow I_x + T_c\left[K_{i,i}e_x + K_{aw}(v_x - v_x^{u})\right],\qquad K_{aw}\approx \frac{K_{i,i}}{K_{p,i}}$$

### 1.3 SVPWM (Min–Max Zero-Sequence Injection)

1. Apply the inverse Park and inverse Clarke transforms to get $v_a, v_b, v_c$.
2. Compute the zero-sequence offset: $v_0 = -\tfrac12(\max + \min)$.
3. Compute each phase duty:

$$D_x = \frac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically identical to sector-based SVPWM and gives 15.5% more linear range than sine PWM.

### 1.4 Encoder Velocity via PLL

Differentiating a 14-bit encoder at 20 kHz is very noisy. A type-II PLL is used instead:

$$e = \operatorname{wrap}_{\pi}(\theta_m - \hat\theta)$$

$$\hat\omega \leftarrow \hat\omega + T\,k_i e$$

$$\hat\theta \leftarrow \hat\theta + T(\hat\omega + k_p e)$$

with gains $k_p = 2\zeta\omega_n$, $k_i = \omega_n^2$, $\zeta = 0.707$, and $\omega_n \approx 2\pi\cdot 400$ Hz.
