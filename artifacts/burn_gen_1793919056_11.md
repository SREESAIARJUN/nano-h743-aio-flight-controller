# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #47, so this design rests on the assumptions listed in §0. Every value that depends on your hardware is a named parameter, and §9 explains how to identify each one.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, e.g. 12N14P (pole pairs p = 7), low Kv, high R |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701 class) on each motor shaft |
| Current sensing | 2 inline shunts per motor. A voltage-mode fallback is given in §2.6 |
| IMUs | 2× ICM-42688-P on the camera plate, each on its own SPI bus, sharing a CLKIN reference |
| MCU | STM32G4/H7 class with an FPU |

| Loop | Rate | Input | Output |
|---|---|---|---|
| Current (FOC) | 20 kHz | i_a, i_b, θ_e | PWM duty |
| Rate (velocity) | 4 kHz | fused gyro ω | i_q* |
| Angle | 1 kHz | AHRS attitude / encoder | ω* |
| AHRS + cogging adaptation | 1 kHz | fused gyro + accel | q̂ |
| IMU sampling | 8 kHz ODR | SPI burst read | raw samples |
