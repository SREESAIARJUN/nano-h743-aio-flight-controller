## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Transforms

**Electrical angle.** $\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$

**Clarke transform** (amplitude-invariant, using $i_a + i_b + i_c = 0$):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform** is the transpose of the matrix above.

**SVPWM** uses min-max zero-sequence injection. This is equivalent to 7-segment SVPWM:
$$v_{x}^{*} = v_x - \tfrac12\big(\max(v_a,v_b,v_c) + \min(v_a,v_b,v_c)\big),\qquad d_x = \tfrac12 + \frac{v_x^*}{V_{bus}}$$
The linear range is $|v_{dq}| \le V_{bus}/\sqrt3$.

### 1.2 Plant and decoupling (SPM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

With feedforward decoupling
$\;v_d = u_d - \omega_e L i_q,\; v_q = u_q + \omega_e(L i_d + \lambda_m)$,
each axis reduces to $\frac{I(s)}{U(s)} = \frac{1}{Ls + R}$.

### 1.3 Current PI tuning (pole-zero cancellation)

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}\;\Rightarrow\; \frac{I}{I^*} = \frac{\omega_{ci}}{s + \omega_{ci}}$$

- Choose $\omega_{ci} \le 2\pi f_{pwm}/20$.
- At 20 kHz this gives $\omega_{ci} \approx 2\pi\cdot 1\,\text{kHz}$.
- The one-sample computation delay plus ZOH adds a phase lag of $1.5\,T_s\,\omega_{ci} \approx 27^\circ$, which is acceptable.

### 1.4 Voltage limiting

Apply a circular limit on $(v_d, v_q)$ with d-axis priority:
$$v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$$

## 2. Cascaded Control (angle → rate → current)

For a gimbal, the **rate loop uses the camera-mounted IMU gyro, not the encoder**. This directly rejects base motion. The encoder is used for:
- commutation ($\theta_e$),
- the cogging-table index,
- base-rate feedforward.
