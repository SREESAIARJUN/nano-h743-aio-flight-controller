# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

I don't have the Job #40 specification, so this design uses the assumed parameters listed below. Every gain is computed from these values in `init()`, so you can change them in one place.

**Before integrating, verify these items:**
- **ICM-42688-P register addresses and AAF coefficients.** I reproduced them from the datasheet (DS-000347). Check them against your datasheet revision, especially the bank-1/bank-2 static filter registers.
- **Electrical-angle convention.** Confirm it against your encoder zero offset. Run an open-loop alignment with `θ_e = 0` and V_d > 0, then store the offset.
- **Motor data.** Tune or measure R_s, L_s, K_t, and J on hardware.

## 0. Assumed System Parameters and Loop Architecture

| Item | Value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU |
| Motor | 12N14P gimbal BLDC (GBM2804-class): p = 7 pole pairs, R_s ≈ 5.6 Ω, L_s ≈ 1.8 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit magnetic (AS5048A / MT6701), absolute |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, mounted symmetrically about the plate centroid |
| Supply | 12–16 V, three-phase gate driver with low-side shunt sensing |

Loop rates follow a 5–10× bandwidth separation rule:

```
 PWM / current loop  20 kHz   (ISR, ADC-triggered)     BW_i  ≈ 1.5 kHz
 IMU acquisition      8 kHz   (DRDY → SPI DMA)
 Velocity loop        4 kHz   (decimate /5)            BW_ω  ≈ 150 Hz
 Attitude + angle     1 kHz   (decimate /20)           BW_θ  ≈ 20–30 Hz
```

```
θ_ref ─►(+)─► Angle PI+FF ─ω_ref─►(+)─► Velocity PID ─i_q*─►(+)─► Current PI (d,q) ─► SVPWM ─► Motor
        ▲ θ_cam (IMU fusion)       ▲ ω_cam (gyro)          ▲ i_q,ff (anti-cogging)
```

For stabilization, both the angle and velocity loops are closed on the **camera-frame** (IMU) quantities. The encoder supplies the commutation angle θ_e, the cogging phase θ_m, and joint limits.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

Park transform, with θ_e = p·θ_m − θ_offset:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$
