# Job #56: 3-Axis Gimbal FOC Control Loop and Dual-IMU Fusion

## 0. Assumptions

I don't have the Job #56 specification sheet, so this design uses a common gimbal configuration. Every assumption below is a parameter in `GimbalConfig`. Change those values, not the code structure.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, ≥170 MHz |
| Motors | 3× BLDC gimbal motor, 12N14P
