# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no project files for "Job #13," so this design assumes a typical brushless camera gimbal. Section 0 lists every assumption. Change those parameters to match your hardware; the equations and code are written in terms of them.

---

## 0. Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P, so pole pairs p = 7 and slots Ns = 12 |
| Phase parameters | R ≈ 5–15 Ω, L ≈ 1–3 mH, Kt ≈ 0.05–0.15 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), SPI |
| IMU A | ICM-42688-P on the camera plate. Used for stabilization feedback. |
| IMU B | ICM-42688-P on the base/handle. Used for disturbance feedforward and as the vibration reference. |
| PWM / current loop | 20 kHz, center-aligned, inline or low-side shunts |
| Velocity (rate) loop | 8 kHz, synchronized to IMU ODR |
| Attitude loop | 1 kHz |
| Vibration sources | Propeller/motor harmonics, roughly 80–400 Hz, time-varying |

## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

Here θ_off is found at startup. Apply a d-axis voltage V_d with θ_e = 0, let the rotor settle, and read the encoder.

To compensate for computation and PWM latency (about 1.5 T_s), extrapolate the angle:
$$\hat\theta_e = \theta_e + p\,\omega_m\,(1.5\,T_s)$$

### 1.2 Clarke and Park transforms (amplitude-invariant)
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$
$$i_d = i_\alpha\cos\theta_e + i_\beta\sin\theta_e,\qquad i_q = -i_\alpha\sin\theta_e + i_\beta\cos\theta_e$$

### 1.3 Plant and current PI design
The d/q voltage equations are:
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Use a PI controller with pole-zero cancellation and a target current-loop bandwidth ω_c of about 2π·1.5 kHz (keep ω_c ≤ ω_s/10):
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\;\Rightarrow\;\; \frac{I(s)}{I^*(s)} = \frac{\omega_c}{s+\omega_c}$$

Add decoupling and back-EMF feedforward:
$$v_d^* = \text{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

Limit the voltage vector, giving the d-axis priority. Here m_max is the maximum modulation index:
$$|v_d^*| \le V_{max},\qquad |v_q^*|\le\sqrt{V_{max}^2 - v_d^{*2}},\qquad V_{max} = \tfrac{V_{bus}}{\sqrt3}\,m_{max}$$
