**Architecture, Loss Model, DShot DMA Plan, Netlist, Thermal Budget**

## 0. Architecture Corrections and Assumptions

Three issues must be fixed before modeling, because they change the math.

1. **The STM32H743 does not commutate the motors.** ArduPilot has no 6-step or FOC motor-control path. The working topology is:
   - The H743 runs ArduPilot and emits bidirectional DShot600.
   - Four per-motor ESC MCUs run AM32 or BLHeli_32 and perform commutation at 48 kHz PWM. AT32F421 or STM32G071 are typical.
   - The ESC MCUs drive gate drivers, which drive 24 MOSFETs.

2. **"Nano" and 80 A burst are not compatible.** A 20×20 mm 4-in-1 realistically sustains 35–45 A per motor. 80 A burst requires a 30.5×30.5 mm board (≈36×36 mm outline) with heavy copper. Two options:
   - Keep the nano FC (20×20 H743) stacked on a 30.5 ESC.
   - Derate to ~45 A burst on a 20×20 ESC.

   The model below uses the 30.5 ESC.

3. **The 80 A rating is defined as motor phase current**, not battery current. Battery current is I_bat = D·I_ph.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full) | V_bus | 25.2 V |
| Burst phase current per motor | I_ph | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, PQFN 3.3×3.3) R_DS(on) @25 °C, V_GS=10 V | R₂₅ | 1.2 mΩ |
| R_DS(on) temperature coefficient | α | 0.0045 /K |
| Target max junction temperature | T_j | 100 °C (125 °C abs) |
| Rise / fall time (2 A driver, R_g ≈ 2–4 Ω) | t_r, t_f | 15 ns each |

| Body diode V_F @80 A | V_F | 0.8 V |
| Q_rr / Q_oss / Q_g | | 40 nC / 30 nC / 40 nC |
| Copper path resistance per motor (pads, vias, phase pad) | R_cu | 0.4 mΩ |
| Ambient (inside frame, prop-washed) | T_a | 40 °C |

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

$$R_{DS}(100^\circ C) = 1.2\,\text{m}\Omega \times (1 + 0.0045 \times 75) = 1.605\ \text{m}\Omega$$

(A linear α underestimates above ~110 °C. Use the datasheet normalized
