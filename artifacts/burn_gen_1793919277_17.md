# STM32H743 Nano FC + 4-in-1 80A ESC: System Architecture Package, Rev A

This is an engineering baseline. Component values are representative of a 6S, 30×30 mm, 80A burst class design. Before release, verify every part number, pin function, and Rθ value against the chosen datasheets and against the current ArduPilot `hwdef` documentation.

---

## 0. Architecture Clarification (Read First)

The STM32H743 does not commutate the motors. ArduPilot has no BLDC/FOC motor-control path. The stack is partitioned as follows:

| Domain | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 / VIH6 (480 MHz, rev V) | ArduPilot, IMU, bidirectional DShot600 master |
| ESC MCUs (×4, or ×1 dual-core variant) | AT32F421K8U7 or STM32G071 | AM32 / BLHeli_32 firmware, 6-step synchronous commutation, 48 kHz PWM |
| Gate drivers (×4) | FD6288Q (3-phase, bootstrap, 20 V VCC max) | High-side and low-side drive |
| Power stage | 24 MOSFETs (N = 2 parallel per switch position, 48 FETs total) or 24 high-current FETs | 80A burst per motor |

**Burst definition used throughout:** 80 A phase current, 10 s, 6S nominal (V_bus = 25.2 V max), all four motors simultaneously (worst case), ambient 35 °C, with prop-wash airflow.

## 1. Power Stage Loss Model

### 1.1 Assumed MOSFET Parameters (40 V class, PQFN 3.3×3.3 / 5×6)

| Parameter | Symbol | Value |
|---|---|---|
| On-resistance @ 25 °C, V_GS = 10 V | R_ds25 | 1.0 mΩ |
| R_ds temperature coefficient | α | 0.0045 /K |
| Total gate charge | Q_g | 50 nC |
| Reverse recovery charge | Q_rr | 40 nC |
| Output charge energy | E_oss | 0.3 µJ @ 25 V |
| Body diode forward voltage | V_f | 0.8 V |
| Rise / fall time (with chosen R_g) | t_r / t_f | 20 / 15 ns |
| Junction-to-case thermal resistance | Rθ_jc | 1.5 K/W |
| Parallel FETs per switch position | N | 2 |

### 1.2 Conduction Loss

In 6-step complementary (synchronous) PWM, the current path always traverses two switch positions:
- the PWM-ing leg (high side for D, synchronous low side for 1−D), and
- the static-on low side of the return phase.

$$R_{ds}(T_j) = R_{ds25}\,[1+\alpha(T_j-25)]$$

$$I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12},\qquad \Delta I_{pp}=\frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}}$$

$$P_{cond,motor} = 2\cdot\frac{I_{rms}^2\,R_{ds}(T_j)}{N}$$

**Ripple** (worst case at D = 0.5, L_LL = 30 µH):

ΔI_pp = 25.2·0.25 / (30 µH·48 kHz) = 4.38 A

I_rms² = 6400 + 1.6 = 6401.6 A². Ripple is negligible at 48 kHz.

**Conduction loss** at the assumed T_j = 110 °C:

- R_ds(110) = 1.0·(1 + 0.0045·85) = 1.38 mΩ
- P_cond = 2·6401.6·1.38 mΩ / 2 = **8.84 W per motor**

### 1.3 Switching Loss at 48 kHz

Hard switching occurs only on the PWM leg, one transition pair per period.

Switching transition loss:

$$P_{sw}= \tfrac12 V_{bus} I (t_r+t_f) f_{sw}$$

= 0.5·25.2·80·35 ns·48 kHz = **1.69 W
