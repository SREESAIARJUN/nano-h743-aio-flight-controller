# STM32H743 Nano FC + 4-in-1 ESC: Electro-Thermal and DShot Timer Model (Job #3)

## 0. Architecture Assumptions

These constraints shape the rest of the model:

1. **The H743 does not drive the bridge.** In a 4-in-1 ESC stack, the H743 is the flight controller running ArduPilot. Each ESC channel (or a shared ESC MCU) runs AM32 or BLHeli_32 on something like an STM32G071 or AT32F421. The 48 kHz PWM and the switching losses belong to the ESC MCUs. The DShot timer/DMA allocation belongs to the H743.
2. **No specific MOSFET was given.** I use a parameterized representative 40 V DFN3.3×3.3 device. Swap in your datasheet values; the equations stay the same.
3. **80 A burst is interpreted as per motor channel**, which is how the industry rates these boards. Section 3 shows this is only thermally possible as a short transient on a nano (20×20 mm) board.
4. All netlists below are reference designs. They need layout review, DRC/ERC, and bench validation before fabrication.
