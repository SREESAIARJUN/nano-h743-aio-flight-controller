# STM32H743 AIO Flight Controller + 4-in-1 80A ESC: System Architecture Package (Job #37)

---

## 0. Scope, Architecture Decision, and Assumptions

### 0.1 Architecture decision: the H743 cannot commutate four motors itself

The H743 runs ArduPilot only. Each motor gets a **dedicated ESC MCU** (AM32 class: AT32F421 or STM32G071) commanded over bidirectional DShot600.

The H743 cannot drive the bridges directly. Four motors need 24 complementary PWM outputs with dead-time insertion, and the H743 has only two advanced timers (TIM1, TIM8). ArduPilot also has no sensorless BLDC commutation stack.

```
VBAT 6S ──┬── Bulk/ceramic caps ──┬── 4× [Gate driver → 6× MOSFET bridge] → Motors
          │                       └── 4× ESC MCU (48 kHz PWM, BEMF sensing)
          └── Buck 5V/3V3 ── STM32H743 ── TIM1 CH1–4 (BDShot600) ──► ESC MCUs
                                     ◄── eRPM telemetry (GCR, same wire) ──┘
```
