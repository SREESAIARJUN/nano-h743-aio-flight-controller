# Job #45: STM32H743 Nano FC + 4-in-1 80A ESC Engineering Model

## 0. Scope, Architecture Clarification, and Assumptions

**Architecture split.** The STM32H743 is the flight controller (FC) MCU running ArduPilot. It does not generate the 48 kHz bridge PWM. Each ESC channel runs its own ESC MCU, assumed here to be an AT32F421 or STM32G071 running AM32/BLHeli_32, which commutates the bridge at 48 kHz. The H743 only sends bi-directional DShot600 and receives eRPM telemetry. The model below is partitioned accordingly.

**Two sanity flags before the math:**
1. A true 20×20 mm "nano" 4-in-1 cannot sustain 4 × 80 A. This model assumes a **30.5×30.5 mm**, 6-layer, 2 oz copper board.
2. "80A burst" is interpreted as **per motor**. Four motors at 80 A simultaneously means **320 A from the battery**, which dominates everything (see §3.4).

## 1. Conduction Loss Model

### 1.1 Commutation Pattern

The ESC uses 6-step trapezoidal commutation with complementary (synchronous-rectified) PWM. At any instant, one phase leg is PWM-high, one is held low, and one floats.

For a given leg, over one electrical cycle:
- **High-side FET** conducts for a fraction D/3 of the time.
- **Low-side FET** conducts for (1−D)/3 + 1/3 of the time. The first term is synchronous rectification during the PWM-off time; the second is the leg's sustained-low 120° interval.

### 1.2 Channel Conduction Loss

Exactly two FET channels carry the current I at all times (ignoring dead time), so:

$$P_{cond,ch} = 2\,I^2 R_{hot} = 2(80^2)(1.5\times10^{-3}) = \mathbf{19.2\ W}$$
