# STM32H743 AIO Flight Controller + 80A 4-in-1 ESC: Design Model (Job #23)

## 0. Architecture Clarification and Assumptions

The STM32H743 runs ArduPilot as the flight controller. It does **not** commutate the motors. A 4-in-1 ESC at 48 kHz PWM needs one dedicated ESC MCU per channel, because six-step commutation, back-EMF zero-crossing detection and bidirectional DShot decode are hard real-time tasks that run on each ESC MCU.

| Block | Selection (representative) | Rationale |
|---|---|---|
| FC MCU | STM32H743VIT6 (LQFP100), 400 MHz in ArduPilot | Native ArduPilot target class, DMAMUX |
| ESC MCU ×4 | AT32F421K8U7 running AM32 | Supports 48 kHz PWM and bidirectional DShot |
| Gate driver ×4 | FD6288Q (3-phase, bootstrap) | Standard AM32 reference part |
| MOSFET ×24 | 40 V N-ch, PDFN 5×6, R<sub>DS(on)</sub> 1.0 mΩ max at 25 °C | Example class: Infineon OptiMOS 6 40 V |
| Input | 6S Li-ion/LiPo, V<sub>bus</sub> = 25.2 V max | Calculations use worst case |
| Board | 30.5×30.5 mm, 8-layer, 2 oz on all layers | "Nano" form factor |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current Path in Six-Step with Synchronous Rectification

In each 60° commutation sector, two phase legs carry current:
- **Active PWM leg:** the high-side FET conducts for duty D. Its complementary low-side FET (synchronous rectification) conducts for (1−D).
- **Return leg:** one low-side FET conducts for the whole sector.

So at any instant, current I flows through exactly two FET channels:

$$P_{cond,ch} = I^2 \cdot \left[R_{DS,HS}(T_j)\cdot D + R_{DS,LS}(T_j)\cdot(1-D) + R_{DS,LS}(T_j)\right] = 2 I^2 R_{DS}(T_j)$$

This assumes matched high-side and low-side FETs. The result is independent of D, which is a useful property of synchronous six-step drive.

### 1.2 Temperature-Dependent R<sub>DS(on)</sub>

$$R_{DS}(T_j) = R_{DS,25}\left[1 + \alpha (T_j - 25)\right], \quad \alpha \approx 0.0055\ /\mathrm{K}\ \text{(Si trench, 40 V class)}$$

At T<sub>j</sub> = 115 °C: R<sub>DS</sub> = 1.0 mΩ × (1 + 0.0055 × 90) ≈ **1.5 mΩ**.
