# STM32H743 Nano AIO with 4-in-1 ESC (Job #39): Power-Stage Loss Model, Thermal Budget, and ArduPilot BDShot600 Allocation

## 0. Architecture and Assumptions

**Architecture.** The H743 runs ArduPilot. It cannot practically run four sensorless BLDC commutation loops, and ArduPilot has no support for doing so. The ESC section therefore uses one small MCU per channel, running AM32 firmware with 48 kHz PWM. The H743 drives these MCUs over bidirectional DShot600.

```
H743 (ArduPilot) ──BDShot600 x4──► 4× AT32F421 (AM32) ──► 4× FD6288Q ──► 24× N-MOSFET ──► 4 motors
        ▲                                                                      │
        └────── ADC: VBAT, IBAT (shunt amp) ◄──────────────────────────────────┘
```

**Design parameters (all are variables; substitute datasheet values):**

## 1. Conduction Losses (6-step, synchronous rectification)

During each 60° commutation sector, two legs are active:

- **Leg A (PWM leg):** the high side conducts for D·T and the low side conducts for (1−D)·T. The current flows continuously through one FET or the other.
- **Leg B (return leg):** the low side conducts for 100% of the sector.

Hot resistance:

$$R_{hot} = k_T R_{ds,25} = 1.45\ \text{m}\Omega$$

**Per-channel conduction loss:**

$$P_{cond} = I^2 R_{hot}\,[D + (1-D)] + I^2 R_{hot} = 2I^2R_{hot}$$

$$P_{cond} = 2(80)^2(1.45\times10^{-3}) = \mathbf{18.56\ W}$$

**Copper loss:**

$$P_{cu} = I^2 R_{cu} = 6400 \times 0.3\times10^{-3} = \mathbf{1.92\ W}$$
