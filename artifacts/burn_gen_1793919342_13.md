# STM32H743 Nano FC + 4-in-1 ESC (Job #64): Engineering Design Package

## 0. Scope, Assumptions, and Up-Front Findings

**Architecture clarification.** The STM32H743 runs ArduPilot on the flight-controller side. It does not commutate the motors. Each of the four ESC channels has its own small MCU (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32), which generates the 48 kHz PWM. The H743 talks to those MCUs over bidirectional DShot600. The model below follows that split.

**Baseline assumptions.** Replace these with your BOM's datasheet values before release.

| Parameter | Symbol | Value |
|---|---|---|
| Battery | V_bus | 6S, 25.2 V max (worst case) |
| Burst phase current per channel | I_m | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, DFN3.3) | R_ds(on),25 | 0.9 mΩ |
| R_ds(on) tempco | α | 0.006 /K |
| Gate charges | Q_g / Q_gs / Q_gd | 50 / 15 / 10 nC |
| Output capacitance / reverse recovery | C_oss / Q_rr | 1.5 nF / 40 nC |
| Body diode forward voltage | V_f | 0.8 V |
| Dead time | t_dt | 50 ns per edge |
| Junction-to-case thermal resistance | R_th(j-c) | 1.2 K/W |
| Board | — | 20×20 mm "nano", 6-layer, 2 oz |

**Headline findings:**

- 80 A per channel on a 20×20 board is a **sub-second burst rating, not a continuous rating**. With good prop-wash airflow, sustainable continuous current is about **20 A per channel**.
- With all four channels at 80 A, the board reaches its thermal limit in about **0.9 s** (Section 3).
- DShot DMA buffers must **not** be placed in DTCM. DMA1 and DMA2 on the H743 cannot reach it.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At the design point T_j = 110 °C:

$$R_{ds} = 0.9 \times 1.51 = 1.36\ \text{m}\Omega$$

### 1.2 Six-step commutation with synchronous rectification

In each 60° sector, one phase is PWM'd high (HS for D, complementary LS for 1−D) and one phase is held low (LS at 100%). Motor current therefore always flows through exactly two channel resistances:

$$P_{cond,ch} = I_{rms}^2\,R_{ds}\,[\underbrace{D + (1-D)}_{\text{PWM leg}} + \underbrace{1}_{\text{sink leg}}] = 2\,I_{rms}^2\,R_{ds}$$

The ripple correction depends on motor inductance L:

$$I_{rms}^2 = I_m^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{V_{bus}\,D(1-D)}{L\,f_{sw}}$$
