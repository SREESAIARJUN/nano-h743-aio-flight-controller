# STM32H743 Nano AIO (FC + 4-in-1 ESC): 80 A Burst Thermal, 48 kHz Switching, and Bidirectional DShot600

**Job #76: Architecture and Analysis Package, Rev A**

## 0. Architecture Corrections Before the Math

Three points in the brief would cause design errors if taken literally.

| Brief statement | Engineering reality | Resolution |
|---|---|---|
| "STM32H743 4-in-1 ESC" | The H743 runs ArduPilot as the flight controller. It does not commutate motors. Each ESC channel needs its own MCU running AM32 or BLHeli_32 to do 48 kHz PWM and BEMF zero-cross detection. | Use H743 (FC) + 4× AT32F421 or STM32G071 (ESC MCUs) + gate drivers. The interface between them is bidirectional DShot600. |
| "80 A burst" on a nano form factor | This is thermally achievable only for about 1–3 s. The continuous rating works out to about 20–25 A per channel (see §3). | Specify the rating as **80 A / 2 s burst, 25 A continuous**, and say so in the datasheet. |
| 48 kHz switching | This is set in the ESC firmware (AM32 `PWM_FREQ`), not in ArduPilot. | The switching-loss model in §2 applies to the ESC stage. |

## 2. Loss Model (per ESC channel)

### 2.1 Conduction Loss

In 6-step commutation with synchronous rectification, two current paths are active in each 60° sector:

- **Switching leg:** the high-side (HS) FET conducts for D, and the complementary low-side (LS) FET conducts for (1−D).
- **Return leg:** the LS FET is on continuously.

$$P_{cond} = I^2 R_{DS}\,[D + (1-D)] + I^2 R_{DS} = 2 I^2 R_{DS(on),T_j}$$

$$P_{cond} = 2 \times 80^2 \times 1.5\,\text{m}\Omega = \mathbf{19.2\ W}$$

Each FET is active for 1/3 of the electrical cycle. Averaged, the conduction loss per FET is 19.2 / 6 = **3.2 W**.
