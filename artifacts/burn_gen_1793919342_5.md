# STM32H743 FC + 80A 4-in-1 ESC Stack (Job #52): Loss Model, Thermal Budget, Bi-directional DShot600 DMA Plan, and Netlists

## 0. Architecture Clarification and Assumptions

### 0.1 What the H743 does, and what it does not do

The STM32H743 is the flight controller (FC). It does not commutate the motors. Each motor channel on the 4-in-1 ESC has its own small MCU (AT32F421 or STM32G071 running AM32) and its own 3-phase gate driver.

The 48 kHz PWM is an ESC-side parameter. DShot600 and its bi-directional telemetry form the FC↔ESC link.

### 0.2 The 80A burst rating forces a real board size

80A burst on a true 20×20 mm nano board is not physically credible. Section 3 shows the thermal capacitance math. This design therefore assumes:

| Parameter | Value | Note |
|---|---|---|
| ESC board | 30.5×30.5 mm, 8-layer, 2 oz all layers | "Nano" refers to FC/ESC stack height, not 20×20 |
| Bus voltage | 6S, V_bus,max = 25.2 V | Worst case for switching loss |
| MOSFET (×24) | 40 V, PDFN 5×6 class | R_ds(on),25 = 0.75 mΩ, Q_g = 60 nC, Q_gd = 12 nC, C_oss,eq ≈ 1.5 nF, Q_rr = 50 nC, V_SD = 0.8 V |
| Gate driver | FD6288Q-class 3-phase half-bridge driver | V_drv = 10 V, R_drv,src ≈ 2 Ω, R_drv,snk ≈ 1 Ω |
| External gate resistor | R_g,ext = 4.7 Ω | R_g,int ≈ 1 Ω |
| ESC firmware | AM32 | Complementary PWM, 48 kHz, dead time 100 ns |
| Current shunt | 0.25 mΩ per channel | Plus ~0.3 mΩ of copper path |
| Burst definition | 80 A phase current, ≤ 3 s | All four motors loaded simultaneously, worst case |

## 1. Conduction Loss Model (80A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 125 °C: R_ds = 0.75 × 1.45 ≈ **1.09 mΩ**. Use 1.1 mΩ for design.

### 1.2 Current-path topology in 6-step trapezoidal commutation

- **Leg A (PWM leg):** the high-side FET conducts for duty D. With synchronous rectification, the low-side FET conducts for 1−D.
- **Leg B (static leg):** the low-side FET is fully on.
