# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

**Assumptions:** I don't have the Job #22 spec sheet, so I've assumed typical BLDC-gimbal values. Swap in your numbers wherever a parameter is marked `// [CFG]`:

- Hollow-shaft gimbal BLDC with 12 slots and 14 poles (7 pole pairs).
- 14-bit absolute magnetic encoder on each motor.
- Inline or low-side shunts (3 shunts, or 2 with reconstruction of the third).
- Two ICM-42688-P IMUs on the camera plate, read over SPI at 8 kHz ODR.
- 32-bit MCU with an FPU, such as an STM32G4 or H7.

## 1. Loop Architecture and Timing

```
             1 kHz               4 kHz                  20 kHz (PWM ISR)
θ_ref ──►[Angle P + FF]──ω_ref──►[Velocity PI]──iq_ref──►(+)──►[Current PI d/q]──►[SVPWM]──► Motor
              ▲                       ▲                   ▲            ▲
         θ_inertial              ω_gyro(axis)       iq_cog(θm)     id,iq ◄─Park◄─Clarke◄─ ia,ib,ic
       (Mahony, dual IMU)    (notched, fused)      (anti-cogging LUT)       θe = p·θm
```

| Loop | Rate | Feedback | Typical bandwidth |
|---|---|---|---|
| Current (d,q) | 20 kHz | Shunts + encoder | 1.0–1.5 kHz |
| Velocity | 4 kHz | Fused, notched gyro projected onto the motor axis | 80–150 Hz |
| Angle | 1 kHz | IMU attitude (inertial) or encoder (follow mode) | 15–30 Hz |
| IMU pipeline | 8 kHz in, 4 kHz out | 2× ICM-42688-P | — |

Two separation rules keep the cascade stable:
- Each inner loop should be **at least 4–5× faster** than the loop wrapped around it.
- Each loop's sample rate should be **at least 10× its bandwidth**.

## 2. Field-Oriented Control Equations

### 2.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

- $p$ is the number of pole pairs.
- $\theta_{\text{off}}$ is found at startup by applying a fixed $v_d$ vector and reading the encoder (alignment).

### 2.2 Clarke transform (amplitude-invariant)

Using the third phase (3-shunt):
$$i_\alpha = \tfrac{2}{3}\left(i_a - \tfrac12 i_b - \tfrac12 i_c\right),\qquad i_\beta = \tfrac{1}{\sqrt3}(i_b - i_c)$$

Using two shunts, with $i_a+i_b+i_c=0$:
$$i_\alpha = i_a,\qquad i_\beta=\tfrac{1}{\sqrt3}(i_a+2i_b)$$

### 2.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.4 PMSM model in the d-q frame

$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q\dot i_q + \omega_e (L_d i_d + \lambda_m)$$

For a surface PMSM ($L_d=L_q=L$), torque is:
$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 2.5 Current PI by pole-zero cancellation

The current plant is $G_i(s)=\dfrac{1}{Ls+R}$. Choose the PI controller $C(s)=K_p + \dfrac{K_i}{s}$ with
$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

Then $C\cdot G = \omega_c/s$, so the closed loop is first-order:
$$\frac{i}{i^*}=\frac{\omega_c}{s+\omega_c}$$

Choose $\omega_c \le 2\pi f_{\text{pwm}}/15$, which accounts for the 1.5-sample PWM and computation delay. At 20 kHz this gives $f_c \approx 1.3$ kHz.

The discrete form uses back-calculation anti-windup:
$$u_k = K_p e_k + I_k,\qquad I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(\text{sat}(u_k)-u_k)$$
with $K_{aw} = 1/K_p \cdot K_i T_s$, a typical choice.

### 2.6 Decoupling feedforward

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m)$$
