# 3-Axis Gimbal: FOC Motor Control, Cogging Compensation, and Dual-IMU Fusion (Job #57)

I don't have the Job #57 specification sheet, so this design rests on the assumptions in Section 0. Every value is a named constant, so you can substitute your actual motor, encoder, and MCU parameters without changing the structure.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Current sensing | 2 or 3 low-side shunts (voltage-mode fallback provided) |
| Encoder | 14-bit magnetic (AS5048A / MT6701), one per joint |
| IMUs | 2× ICM-42688-P on SPI at 8 kHz ODR, on the camera plate |
| Joint order | Yaw (outer) → Roll → Pitch (inner, carries camera) |
