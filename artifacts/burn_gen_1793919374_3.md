# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original spec for Job #38, so the design rests on the assumptions in §0. Every parameter tied to them is a named constant in the code, so you can substitute your real values.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class (FPU, ≥170 MHz), CMSIS-style HAL |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit magnetic encoder per axis (AS5048A / MT6701) |
| Camera IMUs | 2 × ICM-42688-P on SPI, mounted symmetrically about the camera CoM |
| Gimbal order | Base → **
