# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #37, so this design is built on the reference hardware listed in §0. Every gain and frequency is derived from symbols rather than hard-coded. To re-target the design, change the parameter struct.

---

## 0. Reference Platform and Loop Timing

| Item | Value (assumed) |
|---|---|
| MCU | STM32G474 @ 170 MHz, FPU, CORDIC |
| Motors | 3 × gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Rotor encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, 8 kHz ODR, FIFO timestamps, shared CLKIN |
| PWM | 20 kHz center-aligned, synchronous ADC sampling at the PWM valley |

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ω_c ≈ 2π·1000 rad/s |
| Velocity (inertial rate) | 4 kHz | 250 µs | ω_v ≈ 2π·80 rad/s |
| Attitude (angle) | 1 kHz | 1 ms | ω_θ ≈ 2π·15
