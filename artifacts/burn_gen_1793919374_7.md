# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

I don't have a spec for "Job #7", so this design states its assumptions explicitly. Every assumption is a named constant in the code, so you can substitute your real values.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7-class Cortex-M with FPU, single-precision float |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Current sensing | 2-phase low-side or inline shunts |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| IMUs | 2× ICM-42688-P, gyro and accel ODR 8 kHz, SPI with DRDY interrupt |

The control rates are arranged so that each loop runs well below the one inside it:

```
 20 kHz  ISR  : ADC → Clarke/Park → PI(id,iq) + decoupling + cogging FF → SVPWM
  8 kHz  IMU  : 2× ICM-42688-P → align/lever-arm → ANF notch → LPF → fusion
  4 kHz  VEL  : encoder PLL + gyro rate → velocity PI(D) → iq*
  1 kHz  ATT  : Mahony attitude → per-axis angle P(+FF) → ω*
```

The bandwidth separation rule is ω_c,i ≥ 5·ω_c,ω ≥ 25·ω_c,θ. Typical targets are:

- Current loop: 1.5 kHz.
- Velocity loop: 150–250 Hz.
- Angle loop: 30–50 Hz.
