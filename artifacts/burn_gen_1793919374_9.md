## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, `arm_math` optional |
| Motors | Gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 8 Ω, L ≈ 3 mH, Kt ≈ 0.08 N·m/A |
| Commutation sensor | 14-bit absolute magnetic encoder per joint (AS5048 / MT6701) |
| Current sensing | 2-shunt inline or low-side per motor |
| IMUs | 2 × ICM-42688-P on the camera plate, mirrored about the camera center of mass (r₂ = −r₁), SPI at 24 MHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries camera) |

Loop rates:

```
PWM / current loop (FOC) : 20 kHz   (ADC-triggered ISR)
IMU sample + filtering   :  8 kHz   (ICM-42688 ODR = 8 kHz, DRDY / FIFO)
Velocity loop            :  4 kHz
Attitude estimator       :  1 kHz
Angle (attitude) loop    :  1 kHz
Anti-cog LMS adaptation  :  4 kHz   (gated)
```

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$
