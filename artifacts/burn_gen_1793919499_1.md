## 1. FOC Inner Loop (Current / Torque)

### 1.1 Transforms (amplitude-invariant)

With θ_e = p·θ_m − θ_offset:

- **Clarke:**
  - i_α = i_a
  - i_β = (i_a + 2 i_b)/√3
- **Park:**
  - i_d = i_α cos θ_e + i_β sin θ_e
  - i_q = −i_α sin θ_e + i_β cos θ_e
- **Inverse Park:**
  - v_α = v_d cos θ_e − v_q sin θ_e
  - v_β = v_d sin θ_e + v_q cos θ_e

### 1.2 PMSM model in the dq frame

- v_d = R i_d + L_d di_d/dt − ω_e L_q i_q
- v_q = R i_q + L_q di_q/dt + ω_e (L_d i_d + λ_m)
- τ_e = (3/2) p [λ_m i_q + (L_d − L_q) i_d i_q] ≈ K_t i_q, with K_t = (3/2) p λ_m

Gimbal motors are surface-mount PMSMs, so L_d ≈ L_q = L and the reference is i_d* = 0.

### 1.3 Current PI by pole-zero cancellation

Choose:

- K_p,c = L·ω_c
- K_i,c = R·ω_c

The plant is 1/(Ls + R). Cancelling its pole gives the closed loop i/i* = ω_c/(s + ω_c), a first-order response with bandwidth ω_c.

Cross-coupling decoupling feedforward:

- v_d,ff = −ω_e L i_q
- v_q,ff = ω_e (L i_d + λ_m)

Additional measures:

- **Delay compensation.** Use θ_e,pwm = θ_e + 1.5·ω_e·T_s, which accounts for the ADC sample plus one PWM period of transport delay.
- **Voltage limit.** Limit the voltage vector to |v_dq| ≤ V_bus/√3, which is the linear SVPWM region. Use d-axis priority:
  - v_q,max = √(V_max² − v_d²)
- **Anti-windup.** Use back-calculation:
  - İ = K_i e + K_aw (u_sat − u_unsat), with K_aw ≈ 1/K_p.

### 1.4 SVPWM by min-max zero-sequence injection

1. Inverse Clarke:
   - v_a = v_α
   - v_b = −½v_α + (√3/2)v_β
   - v_c = −½v_α − (√3/2)v_β
2. Zero-sequence offset: v_0 = −(max(v_a, v_b, v_c) + min(v_a, v_b, v_c))/2
3. Duty cycle per phase: D_x = ½ + (v_x + v_0)/V_bus

This is mathematically identical to sector-based SVPWM and needs no sector logic.

## 2. Cascaded Velocity and Angle Control

### 2.1 Plant

For each joint:

J θ̈ = K_t i_q − b θ̇ − τ_cog(θ_m) − τ_dist

Seen from the velocity loop, the current loop is ≈ 1 because ω_c ≫ ω_v. The plant is then:

P_v(s) = K_t / (J s + b)

### 2.2 Velocity PI (with optional D)

i_q* = K_p,v e_ω + K_i,v ∫e_ω dt + i_q,ff,acc + i_q,cog

Gain design for crossover ω_v, ignoring b:

- K_p,v = J ω_v / K_t
- K_i,v = K_p,v · ω_v / 4

Placing the PI zero at ω_v/4 gives roughly 60° phase margin at crossover.

**Rate feedback source.** The velocity measurement is a blend of the IMU gyro (camera-frame rate) and the encoder differentiated rate:

ω̂ = gyro-based joint rate (Section 4.6) + K_enc · LPF(θ̇_enc − gyro-based rate)
