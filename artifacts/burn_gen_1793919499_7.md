# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

## 0. Baseline Assumptions

I have no details on "Job #35" beyond this request. The design below is built on these representative assumptions. Every one of them is a parameter in the code.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 (Cortex-M4F, 170 MHz, FPU), center-aligned PWM |
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A/MA730 class) per axis |
| IMU A | ICM-42688-P on the camera plate (primary, stabilized) |
| IMU B | ICM-42688-P on the base/handle (disturbance reference) |
| Kinematic order | base → yaw (z) → roll (x) → pitch (y) → camera |

Loop rates:

| Loop | Rate | Period |
|---|---|---|
| Current loop (FOC) | f_i = 20 kHz | T_i = 50 µs |
| IMU ODR and rate loop | f_v = 8 kHz | T_v = 125 µs |
| Attitude loop | f_θ = 1 kHz | T_θ = 1 ms |
