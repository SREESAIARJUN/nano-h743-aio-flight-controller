## 0. Architecture and Assumptions

**Topology assumption.** An STM32H743 does not commutate four motors directly. Standard practice, which ArduPilot and AM32/BLHeli_32 assume, is:

- **H743**: runs ArduPilot and sends bidirectional DShot600 to the ESC section.
- **4× ESC MCUs**: AT32F421K8U7 running AM32, one per channel. Each runs 6-step synchronous PWM at 48 kHz into a 3-phase gate driver and 6 MOSFETs.

The rest of this document assumes that topology.

## 1. Conduction Loss Model

### 1.1 Current path in synchronous 6-step commutation

In any commutation sector, phase A is PWM-driven high and phase B is held low:

- **HS_A** conducts for a fraction D of each PWM cycle.
- **LS_A** conducts for the remaining (1 − D) of the cycle (complementary synchronous rectification).
- **LS_B** conducts for 100 % of the sector.

### 1.2 Bridge conduction loss

$$
P_{cond} = I^2 R_{ds}(T_j)\,[D + (1-D) + 1] = 2\,I^2 R_{ds}(T_j)
$$

With synchronous rectification, conduction loss is **independent of duty cycle**. Dead-time diode conduction is handled separately in §2.4.

### 1.3 Temperature-corrected on-resistance

$$
R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)] = 1.2\,\text{mΩ} \times 1.6 = 1.92\,\text{mΩ}
$$
