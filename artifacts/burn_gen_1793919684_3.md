# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #36): System Architecture & Analysis

This design has three problems that the analysis below quantifies:

1. **The STM32H743 does not generate the 48 kHz motor PWM.** In every practical 4-in-1 design, each motor has its own ESC MCU running AM32 or BLHeli_32. In this design that is an AT32F421 per motor. The H743 runs ArduPilot and sends DShot600 to those four MCUs. Everything below follows this split.
2. **"80 A burst" must be time-limited.** On a 30.5×30.5 mm board, four motors at 80 A can last about **2 s**. On a 20×20 mm "nano" board, about **1 s** (Section 3).
3. **Component parameters are representative assumptions, not a specific datasheet.** Before release, replace them with the values for the MOSFET and driver you select.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha\,(T_j - 25)]$$

At the design point T_j = 110 °C:

$$R_{ds}(110) = 1.2\,\text{m}\Omega \times 1.34 = 1.61\ \text{m}\Omega$$

### 1.2 Current path in 6-step commutation
