# STM32H743 FC + 80A 4-in-1 ESC (Job #73): Loss Model, DShot DMA Plan, and Reference Netlist

## 0. Scope, Assumptions and One Architectural Correction

I have no prior project data for Job #73, so every parameter below is an explicit assumption. Substitute your real BOM values into the equations, which are written to be parameter-driven.

**Architectural correction.** The STM32H743 is the *flight controller*. The 48 kHz PWM, commutation and bidirectional-DShot *response* run on a separate ESC MCU per motor (or one for all four), for example an AT32F421 or STM32G071 running AM32 or BLHeli_32. The H743 only:
- generates the DShot600 frames, and
- input-captures the GCR telemetry replies.

The loss model therefore applies to the ESC power stage. The DMA model applies to the H743.

## 1. Conduction Loss Model

In 6-step commutation, current at any instant flows through two legs:
- **Leg A (PWM leg):** the high-side FET for duty D, then the complementary low-side for (1−D), synchronously rectified.
- **Leg B:** the low-side FET is held on for the full commutation interval.

Leg A therefore always contributes one conducting R_ds, regardless of D. So:

$$P_{cond,motor} = 2\,I^2\,R_{ds}(T_j), \qquad R_{ds}(T_j) = R_{25}\,[1+\alpha (T_j-25)]$$

with α ≈ 0.006 /K, which gives the ≈1.6× factor at 125 °C.

**At 80 A, T_j = 125 °C:**
- P_cond = 2 · 6400 · 1.6 mΩ = **20.5 W per motor**
- Copper path: I²·R_cu = 6400 · 0.5 mΩ = **3.2 W**
- Shunt: 6400 · 0.25 mΩ = **1.6 W**

**Electrothermal feedback.** Because R_ds rises with T_j, solve iteratively:

$$T_j^{(n+1)} = T_{pcb} + R_{th,j\text{-}pcb}\cdot P_{FET}\big(R_{ds}(T_j^{(n)})\big)$$

This converges in about 3 iterations. If the loop gain α·R_th·P_FET approaches 1, you are in thermal runaway territory.

## 2. Switching Loss Model @ 48 kHz

Only the PWM leg switches in each interval. Per motor:

| Term | Equation | Value |
|---|---|---|
| V·I overlap | ½·V_bus·I·(t_on + t_off)·f_sw = ½·25.2·80·35 ns·48 kHz | 1.69 W |
| Reverse recovery | V_bus·Q_rr·f_sw = 25.2·60 nC·48 kHz | 0.07 W |
| Output charge | Q_oss·V_bus·f_sw | 0.03 W |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw = 0.8·80·200 ns·48 kHz | 0.61 W |
| Gate drive (2 FETs, dissipated in driver/R_g) | 2·Q_g·V_drv·f_sw | 0.04 W |
| **Total P_sw** | | **≈ 2.4 W** |

**Edge-time derivation.** Using the Miller plateau:

$$t_{vr} \approx \frac{Q_{gd}}{I_g}, \qquad I_g = \frac{V_{drv}-V_{plateau}}{R_{drv}+R_g}$$

Ideal values are ≈5–10 ns. The 20/15 ns I used includes the source inductance penalty (L_s·di/dt). Measure t_on and t_off on your board at 80 A with a double-pulse test and replace them.
