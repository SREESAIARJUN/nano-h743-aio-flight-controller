## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU |
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7) |
| Example motor constants | R = 5.6 Ω, L = 2.1 mH, Kt = 0.11 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) |
| Gimbal IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Kinematic order | Yaw (base) → Roll → Pitch (camera) |
