# Job #43: 3-Axis Gimbal FOC, Cascaded Control, Anti-Cogging and Dual-IMU Fusion

## 0. Assumptions

I have no prior context for Job #43, so this design uses the typical brushless-gimbal parameters below. Every one is a `constexpr` or config field in the code, so you can substitute your own values.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per axis (MT6701/AS5048 class) |
| Current sense | 2-phase inline shunts, synchronous to PWM centre |
| Drive | 24 kHz center-aligned PWM, V_bus = 12–16 V |
| IMUs | 2× ICM-42688-P on camera plate, SPI, gyro ODR 8 kHz, ±2000 dps, accel ±16 g |
| Loop rates | Current 24 kHz, velocity 4 kHz, angle/attitude 1 kHz |

## 1. System Architecture

```
            ┌───────────── 1 kHz ─────────────┐ ┌──── 4 kHz ────┐ ┌──── 24 kHz ────┐
θ_ref ─►(+)─► Angle P + ω_ff ─► (+)─► Velocity PI ─►(+)─► iq_ref ─► Current PI (d,q)
         ▲                          ▲                ▲                  │ decoupling
         │ θ̂ (Mahony, dual IMU)     │ ω̂ (fused gyro) │ iq_cog(θ_m)      ▼
         │                          │ notch+LPF      │ (anti-cogging)  SVPWM ─► inverter
         └──── attitude fusion ◄────┴─ dual ICM-42688-P               ▲
                                                     encoder θ_m ─────┘ (commutation)
```

The two feedback paths have distinct roles:

- **The encoder provides commutation.** It supplies the electrical angle θ_e = p·θ_m − θ_offset.
- **The IMU provides stabilization feedback.** The camera-frame rate is projected onto each joint axis and used as the velocity-loop feedback. The camera-frame attitude closes the angle
