# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for "Job #5," so this design states its assumptions explicitly. Every assumed value is a single constant in the code, so you can substitute your real motor, encoder and MCU parameters directly.

---

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (e.g., GM4108-class), R ≈ 10 Ω, L ≈ 4 mH, K_t ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701), one per joint, read over SPI |
| MCU | STM32G4 / H7-class Cortex-M with FPU, 3-shunt current sensing |
| Kinematic chain | Base → Yaw → Roll → Pitch → camera |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the payload centre of rotation, with orthogonal orientations, on separate SPI buses |
| Loop rates | Current 20 kHz · Velocity 4 kHz · IMU 8 kHz ODR · Attitude/Angle 1 kHz |
