## 0. Architectural Ground Rules

These boundary conditions shape everything that follows.

1. **The H743 does not commutate the motors.** It is the flight controller. Each ESC channel has its own commutation MCU running AM32 or BLHeli_32-class firmware, typically an AT32F421 or STM32G071. The FC-to-ESC interface is four bidirectional DShot600 lines plus current sense and telemetry. This keeps the commutation loop out of the H743 scheduler and is how every production 4-in-1 stack works.
2. **"80A burst" means 80A per channel phase/DC current for a bounded duration, not continuous.** The math below proves that continuous 80A is thermally impossible on a nano (20×20 or 25.5×25.5) footprint. The deliverable is therefore a **burst-time envelope**, not a rating.
3. **The MOSFET parameters are representative values for a 40V DFN3.3×3.3 class device.** Replace every value marked **[DS]** with the selected part's datasheet values before release. Every equation is written parametrically so the substitution is mechanical.

## 1. Conduction Loss Model

### 1.1 Topology Assumption

The model assumes six-step trapezoidal commutation with complementary (synchronous) PWM, which is the AM32/BLHeli default. In each commutation sector:

- **PWM leg:** the high side conducts for duty D and the low side (synchronous rectifier) for 1−D.
- **Return leg:** the low side conducts 100% of the sector.
- **Floating leg:** off, used for back-EMF sensing.

### 1.2 Per-Channel Conduction Loss

$$P_{cond} = I^2 R_{ds}(T_j)\big[D + (1-D)\big] + I^2 R_{ds}(T_j) = 2\,I^2 R_{ds}(T_j)$$

Synchronous rectification makes conduction loss **independent of duty**. This is a key design insight: throttle position does not relieve conduction loss at a given current.

Temperature dependence:

$$R_{ds}(T_j) = R_{ds25}\,\big[1 + \alpha\,(T_j - 25)\big]$$

At the design point T_j = 115 °C:

$$R_{ds}(115) = 1.2\,\text{m}\Omega \times (1 + 0.0045 \times 90) = 1.686\,\text{m}\Omega$$

$$P_{cond} = 2 \times 80^2 \times 1.686\times10^{-3} = \mathbf{21.6\ W\ per\ channel}$$
