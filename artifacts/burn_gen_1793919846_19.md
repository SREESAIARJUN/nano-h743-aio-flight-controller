## 0. Architecture and Assumptions

### 0.1 Architectural Clarification

The STM32H743 does not commutate the motors. It runs ArduPilot and generates DShot600 frames. Each of the four ESC channels has its own commutation MCU (AT32F421 or STM32G071 running AM32). The 48 kHz PWM frequency is an ESC-side parameter. The FC never sees it.

```
6S LiPo ─┬─ Bulk caps ─┬─ 4× [ESC MCU → 3φ gate driver → 6× MOSFET] → Motors
         │             └─ Current shunt → ESC ADC
         └─ 12V buck (gate drive) ─ 5V/3V3 LDO (MCUs)
STM32H743 (ArduPilot) ── 4× bidirectional DShot600 (TIM1 CH1–4) ──> ESC MCUs
```

## 1. Conduction Loss Model

### 1.1 Commutation Topology

The ESC uses 6-step trapezoidal commutation with synchronous rectification (complementary PWM). In each 60° sector, two phases carry current:

- **PWM leg:** current alternates between HS (duty D) and LS (duty 1−D). Both conduct through an R_DS(on), so the leg resistance is R_DS regardless of D.
- **Fixed leg:** one LS (or HS) is held fully on.

$$P_{cond,ch} = I_{ph}^2 \cdot R_{DS}(T_j) \cdot \underbrace{\left[D + (1-D)\right]}_{\text{PWM leg}} + I_{ph}^2 \cdot R_{DS}(T_j) = 2\,I_{ph}^2\,R_{DS}(T_j)$$

(Dead-time intervals are moved to the diode term in §2.)

### 1.2 Temperature Dependence

The coupling between temperature and resistance must be solved iteratively:

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right], \quad \alpha \approx 0.005\ \text{K}^{-1} \;\Rightarrow\; 1.5\times \text{ at } 125\,°C$$
