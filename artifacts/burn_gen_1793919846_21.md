# STM32H743 FC + 4‑in‑1 ESC (Nano AIO): Power‑Stage Thermal Model, 48 kHz Switching Losses, and Bidirectional DShot600 DMA Allocation

**Job #39: Architecture Reference, Rev A (draft)**

> **Scope and assumptions.** I don't have the Job #39 BOM, stackup, or layout, so this document uses **declared, representative parameters**. Each one is tagged `[A#]` so it can be replaced with datasheet values. The equations are general. The numbers are only as good as the inputs.
>
> **Architectural note.** On production 4‑in‑1 ESCs, the H743 does not commutate the motors. It is the flight controller running ArduPilot. Each ESC is driven by a dedicated small MCU, here AT32F421 or STM32G071 running AM32/BLHeli_32, through a 3‑phase gate driver. This document models it that way. If Job #39 really intends the H743 to drive the gate drivers directly, Section 4 changes substantially. Flag that early.
