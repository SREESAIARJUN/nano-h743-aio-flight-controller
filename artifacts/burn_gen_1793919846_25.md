# STM32H743 Nano FC + 80 A 4-in-1 ESC: Systems Architecture & Mathematical Model

**Job #45, Rev A (Design Basis)**

This is a design-basis document. Every device parameter marked **[A]** is an assumed representative value for a 40 V, 5×6 mm PDFN power MOSFET class and a 6S system. Before layout freeze, replace each [A] value with datasheet maximums from your selected parts and re-run the equations. The equations themselves are general.

---

## 0. Architecture Clarification

The STM32H743 does **not** drive the power stage directly. The partition is:

```
 ┌──────────────── FC board (STM32H743) ────────────────┐      ┌──────────── 4-in-1 ESC board ────────────┐
 │ ArduPilot: attitude loop, notch filter, DShot600 TX  │ M1-4 │ 4× ESC MCU (AT32F421 / STM32G071 class)  │
 │ bidir eRPM capture → harmonic notch / RPM telemetry  ├──────►│ AM32 / BLHeli_32: 6-step / FOC commutation│
 │ ADC: VBAT, CURR (from ESC shunt amp)                 │◄─────┤ 48 kHz PWM → 3-phase gate driver → 6 FETs │
 └──────────────────────────────────────────────────────┘ eRPM └───────────────────────────────────────────┘
```

- The 48 kHz switching and 80 A conduction analysis applies to the ESC power stage.
- The DMA and timer allocation applies to the H743.
