# STM32H743 Nano FC + 4-in-1 ESC: Power, Thermal & Bi-Directional DShot Design Package

## 0. Scope and Assumptions

I have no prior context for "Job #3", so this document fixes the assumptions below. Change any of them and the equations still hold; only the numbers move.

| Parameter | Assumed value | Note |
|---|---|---|
| Form factor | 20×20 mm (M2 mounting), stacked FC + ESC | "Nano" class |
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal | Requires 40 V FETs |
| Burst current | 80 A per motor channel | See §3.6: this is a sub-second rating |
| ESC PWM frequency | 48 kHz, complementary (synchronous) PWM | AM32 supports 24/48/96 kHz |
| Commutation | 6-step trapezoidal | FOC variant noted where it differs |
| ESC MCU (×4) | AT32F421K8U7 or STM32G071 running AM32 | |
| FC MCU | STM32H743VIH6, TFBGA100 8×8 mm | Runs ArduPilot |
| Ambient / board start temperature | 40 °C | |
| Maximum junction temperature | 150 °C design limit (175 °C absolute) | |

**Architectural clarification.** The H743 does not switch the MOSFETs. It runs ArduPilot and sends DShot600 frames, then receives eRPM telemetry back over the same wire. Four independent ESC MCUs on the 4-in-1 board generate the 48 kHz PWM. The power and switching math therefore belongs to the ESC board, and the DMA/timer math belongs to the H743.
