# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the Job #45 spec sheet, so this design uses the assumptions listed in §0. Each of them is a named parameter, so you can substitute your real values without changing the structure.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P → pole pairs $p=7$, slots $N_s=12$ |
| Phase R / L | 5.0 Ω / 2.0 mH (measure yours) |
| Flux linkage $\lambda_m$ | 0.010 V·s → $K_t = 1.5\,p\,\lambda_m = 0.105$ N·m/A |
| Rotor encoder | 14-bit magnetic (AS5048A / MT6701), read at the current-loop rate |
| Bus | 12–16 V, center-aligned PWM, 3 low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate (IMU-B rotated 180° about Z), SPI, ODR = 4 kHz |
| MCU | STM32G4/H7-class, single-precision FPU |

**Loop rates and bandwidth separation:**

```
                 1 kHz                    4 kHz                      20 kHz
 Attitude ref ──►[Attitude P + FF]──ω*──►[Rate PI (gyro)]──iq*──►[Current PI d/q]──►SVPWM──►Motor
                     ▲  q̂                   ▲ ω̂ (filtered)        ▲ id,iq   ▲ θe
                 [Mahony AHRS]◄── accel  [Dual-IMU fuse+notch/LPF]  [ADC]   [Encoder+PLL]
                                                                 + Cogging FF (iq_ff)
```

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q) | $f_s = 20$ kHz | $\omega_c \approx 2\pi\cdot1500$ rad/s |
| Rate / velocity | 4 kHz | $\omega_v \approx 2\pi\cdot 60$–$120$ Hz (limited by structural modes and notch phase) |
| Attitude | 1 kHz | $\omega_\theta \approx \omega_v/4$ to $\omega_v/6$ |
