# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Fusion

The "Job #7" specification isn't available to me here, so §0 lists every assumed parameter. Each one is a single constant in the code (§8.1). Replace them with your real hardware values before tuning.

---

## 0. Assumed System Parameters

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5.6 Ω, L ≈ 2.2 mH, Kt ≈ 0.08 N·m/A |
| Driver | 3-phase bridge with inline/low-side shunt current sensing; V_bus = 12 V |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) per axis |
| IMUs | 2× ICM-42688-P on the camera stage, SPI at 24 MHz, sharing a 32.768 kHz CLKIN |
| Loop rates | PWM/current 20 kHz · velocity 4 kHz · angle/attitude 1 kHz · IMU ODR 8 kHz |
| Kinematic chain | base → yaw (z) → roll (x) → pitch (y) → camera |

If your drivers have no current sensing (common on cheap gimbal boards), see §2.5 for the voltage-mode fallback. Everything else is unchanged.
