# Job #52: 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

**Assumptions.** I don't have the Job #52 spec sheet, so I've used typical values for a brushless gimbal. Every hardware-dependent value is a named parameter, so you can substitute your measured numbers.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal PMSM, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoders | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| MCU | Cortex-M4F/M7 with FPU, 3 complementary PWM pairs per axis or 3 independent drivers, synchronous ADC |
| Topology | Yaw (outer) → Roll → Pitch (inner, camera) |
| IMU-P | ICM-42688-P on the camera payload. Measures the inertial rate to be stabilized. |
| IMU-B | ICM-42688-P on the base/frame, upstream of the vibration dampers. Measures the vibration *reference*. |

## 1. Architecture and Timing

```
               1 kHz            4 kHz                    20 kHz
θ_ref ──►[Angle P + ω_ff]──►[Rate PI]──► i_q,fb ──(+)──►[Current PI d/q]──►[SVPWM]──► Motor
              ▲                ▲                   ▲            ▲
       attitude q̂          ω_axis (clean)    i_q,cog(θ_m)   i_d,i_q (Park)
              │                │                   │            │
          Mahony AHRS ◄── Vibration rejection ◄─ IMU-P      encoder θ_m
                          (AAF→ANC(IMU-B)→dyn notch→LPF)
```

- **Bandwidth separation.** Each outer loop should have no more than about 1/5 of the bandwidth of the loop inside it:
  - ω_c,i ≈ 2π·1.5 kHz (current)
  - ω_c,v ≈ 2π·150 Hz (rate)
  - ω_c,θ ≈ 2π·15–25 Hz (angle)
- **IMU data rate.** Both IMUs run at 8 kHz ODR, decimated to 4 kHz after filtering.
- **Hardware sync.** Both IMUs must be time-aligned. Drive their CLKIN from one MCU timer, or route their FSYNC to the same timer. This keeps them sampled within about 1 µs of each other. Without it, the adaptive canceller in §5.3 loses coherence above about 200 Hz.

## 2. FOC Current Loop

### 2.1 Electrical model (surface PMSM, L_d ≈ L_q = L)

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac{3}{2}\,p\,\lambda_m\, i_q = K_t\, i_q,\qquad \theta_e = p\,\theta_m - \theta_{off}
$$

### 2.2 Transforms (amplitude-invariant)

**Clarke:**

$$
i_\alpha = i_a,\quad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

This form assumes i_a + i_b + i_c = 0.

**Park:**

$$
i_d = i_\alpha\cos\theta_e + i_\beta\sin\theta_e,\quad
i_q = -i_\alpha\sin\theta_e + i_\beta\cos\theta_e
$$

**Inverse Park:**

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\quad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 2.3 PI tuning by pole-zero cancellation

Each axis plant is $G(s) = \dfrac{1}{Ls+R}$. Use the PI controller

$$
C(s) = K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_{c,i},\quad K_i = R\,\omega_{c,i}
$$

The PI zero at $K_i/K_p = R/L$ cancels the plant pole. The closed loop is then first order: $\dfrac{\omega_{c,i}}{s+\omega_{c,i}}$.

**Decoupling plus back-EMF feedforward:**

$$
v_d^* = PI_d(e_d) - \hat\omega_e \hat L i_q,\qquad
v_q^* = PI_q(e_q) + \hat\omega_e \hat L i_d
