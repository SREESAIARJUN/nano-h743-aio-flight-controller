# STM32H743 Nano FC + 4-in-1 80A ESC: System Design Package (Job #3)

## 0. Scope, Architecture, and Assumptions

Several requirements cannot be closed numerically without part numbers, so this package states every assumption explicitly. Replace the parameters marked ⟨P⟩ with datasheet values; the equations stay the same.

**Architecture.** The STM32H743 does not generate the 48 kHz bridge PWM. That runs on each ESC's own MCU. The H743 sends DShot600 setpoints and receives bidirectional eRPM telemetry.

```
STM32H743 FC ──DShot600 bidir (4 lines)──► 4-in-1 ESC: 4× [MCU (AM32/BLHeli32) + FD6288-class driver + 6 FETs]
            ◄──CURR/VBAT analog, ESC TELEM UART─┘
```
