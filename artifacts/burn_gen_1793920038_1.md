## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset), wrapped to [0, 2π).

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant Model (Surface PMSM, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Torque is τ = (3/2)·p·λ_m·i_q = K_t·i_q.

### 1.3 Current PI Design (Pole-Zero Cancellation)

The per-axis plant is G(s) = 1/(Ls + R). Choose a PI controller C(s) = K_p + K_i/s with the zero placed at R/L:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Pick ω_c ≤ 2π·f_pwm/20, so f_c ≈ 1 kHz at 20 kHz PWM. This keeps phase loss from the 1.5-sample delay (compute plus PWM update) under about 30°.

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m)$$

**Voltage limiting:** clamp the vector magnitude so that |v_dq| ≤ V_bus/√3 (the SVPWM linear limit), giving priority to v_d. Integrators use back-calculation anti-windup:

$$x_{I}[k+1] = x_I[k] + T_s\left(K_i e[k] + K_{aw}(u_{sat}-u_{unsat})\right),\qquad K_{aw}\approx K_i/K_p$$

### 1.4 SVPWM via Min-Max Zero-Sequence Injection

This is equivalent to sector-based SVPWM:

$$v_{0} = -\tfrac12\left(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\right),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

## 2. Cascaded Angle/Velocity Control

### 2.1 Velocity Estimation: Type-II PLL on Encoder Angle (20 kHz)

Raw differentiation of a 14-bit encoder at 20 kHz gives 0.38 rad/s quantization noise, which is unusable. A PLL avoids this:

$$e = \mathrm{wrap}_\pi(\theta_{meas}-\hat\theta),\quad \hat\omega \mathrel{+}= T_s K_{i,pll} e,\quad \hat\theta \mathrel{+}= T_s(\hat\omega + K_{p,pll} e)$$

The closed loop is 2nd-order with ω_n = √K_i and ζ = K_p/(2√K_i). Recommended: ω_n = 2π·300 rad/s and ζ = 0.9, so K_p = 2ζω_n and K_i = ω_n².

### 2.2 Velocity PI (5 kHz)

$$i_q^* = \mathrm{sat}_{I_{max}}\Big(K_{pv}e_\omega + x_{Iv}\Big) + i_q^{cog}(\theta_m) + i_q^{ff},\qquad e_\omega=\omega^*-\hat\omega$$

The plant is J/K_t·s + B, and the current loop can be treated as unity because it is about 5× faster.

For a target velocity crossover ω_v (≈ 2π·150 rad/s):

$$K_{pv} = \frac{J\,\omega_v}{K_t},\qquad K_{iv} = K_{pv}\frac{\omega_v}{4}$$

This places the PI zero one quarter-decade below crossover, giving ≈ 76° phase margin before delays.

Add a 2nd-order low-pass on the output (≈ 4·f_v) to attenuate PLL noise injected into i_q.
