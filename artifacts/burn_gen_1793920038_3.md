# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #11)

## 0. Assumptions

I don't have the Job #11 spec sheet, so the design uses common gimbal hardware. Every value marked **[P]** is a parameter you should replace with your measured values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, single-precision FPU, CORDIC available |
| Motors | Gimbal BLDC, 24N22P (p = 11 pole pairs), R = 5.6 Ω **[P]**, L = 2.1 mH **[P]**, λ = 0.0105 Wb **[P]** |
| Encoder | AS5048A / MT6701, 14-bit, read every PWM cycle |
| PWM / current loop | 20 kHz center-aligned, inline or low-side shunts |
| IMUs | 2 × ICM-42688-P on the payload, SPI @ 24 MHz, ODR 8 kHz, FIFO off, data-ready (DRDY) interrupt |
| Loop rates | Current 20 kHz → Rate 4 kHz → Angle 1 kHz → Attitude estimate 4 kHz |
| Kinematic order | Yaw (z) → Roll (x) → Pitch (y), payload is the last link |

### 1.1 Transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform, with electrical angle θ_e = p·θ_m − θ_off:
