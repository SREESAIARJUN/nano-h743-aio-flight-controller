# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #47 specification, so the design is built on the **stated assumptions in §0**. Every equation is parameterized, so only the constants need changing when your actual motor, encoder, MCU and frame data are available. Register addresses for the ICM-42688-P are from the public datasheet (rev 1.x). Check them against your silicon revision before flashing.

---

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω (phase), L = 1.8 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI, read every current-loop tick |
| Current sense | 2-shunt low-side, sampled at PWM center |
| MCU | STM32G4 / H7-class Cortex-M4F/M7 with single-precision FPU |
| Bus | V_bus = 12–16 V |
| IMUs | 2 × ICM-42688-P on separate SPI buses, gyro ODR 8 kHz, accel ODR 1 kHz |

**Loop rates:**

```
PWM / Current loop (FOC)   : 20 kHz   Ts_i = 50 µs   (ISR, ADC-triggered)
Velocity loop              :  4 kHz   Ts_v = 250 µs  (every 5th current tick)
Angle / attitude loop      :  1 kHz   Ts_a = 1 ms
IMU gyro sampling          :  8 kHz   (FIFO-drained at 4 kHz, decimated by 2)
```

**Control topology for one axis** (×3 axes):

```
θ_ref ─►(+)─► P/PI_θ ─►(+)─► PI_ω ─►(+)─► i_q,ref ─► PI_iq ─► v_q ─┐
        ▲(-)          ▲ ω_ff  ▲(-)   ▲ i_cog,ff              ▲(-)   ├─► inv-Park ─► SVPWM ─► motor
        │             │       │      │ (anti-cogging)        │      │
     θ_IMU (fused)  slew    ω_IMU    └── f(θ_mech)          i_q ◄─ Park ◄─ Clarke ◄─ i_a, i_b
                                     (gyro, notched)        i_d,ref = 0 ─► PI_id ─► v_d ─┘
```

For a gimbal, the **outer loops close on IMU attitude and rate, not on the encoder**. The encoder is used only for commutation (θ_e) and for cogging-phase lookup (θ_m).

## 1. FOC Current Loop Equations

### 1.1 Electrical angle

$$
\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi
$$

Here θ_{m,0} is the encoder offset found at calibration: apply V_d along α, let the rotor settle, and record the reading.

### 1.2 Clarke transform (2-shunt, power-invariant scaling off; amplitude-invariant)

$$
i_\alpha = i_a, \qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt 3}
$$

### 1.3 Park transform

$$
\begin{bmatrix} i_d \\ i_q \end{bmatrix}
=
\begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}
$$

### 1.4 Plant in the dq frame

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

with λ_m = K_t / (1.5 p) and ω_e = p ω_m.
