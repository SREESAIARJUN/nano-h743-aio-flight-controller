# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging and Dual-IMU Vibration Rejection

I don't have the Job #22 specification, so this design states its assumptions explicitly in Section 0. Every hardware-dependent constant is a named parameter that you replace with your values.

---

## 0. Assumptions and System Architecture

| Item | Assumed value | Notes |
|---|---|---|
| MCU | STM32G474 / H7 class, FPU, 170+ MHz | Any Cortex-M4F/M7 works |
| Motors | Hollow-shaft gimbal BLDC, 12N14P (p = 7 pole pairs) | GM3506/GM4108 class |
| Winding | R_s ≈ 5–15 Ω, L_s ≈ 2–5 mH | Measure per motor |
| Current sensing | 2-shunt low-side or inline (e.g. INA240) | Voltage-mode fallback given in Section 2.4 |
| Encoder | 14-bit magnetic (AS5048A / MA732) on each axis | Absolute mechanical angle θ_m |
| IMU_C | ICM-42688-P on the camera plate | Primary attitude sensor |
| IMU_B | ICM-42688-P on the gimbal base / frame | Vibration reference and base-rate feedforward |
| Axis order | Base → Yaw (ψ) → Roll (φ) → Pitch (θ) → camera | Typical handheld/drone gimbal |

### Loop rates (rate-monotonic, interrupt-driven)

```
PWM 25 kHz (center-aligned) ──► ADC trigger ──► Current loop  25 kHz   (ISR, highest priority)
                                                Encoder read + PLL      25 kHz
IMU DRDY (8 kHz ODR, both IMUs) ──► Filters ──► Velocity loop  4 kHz    (IMU-rate decimated by 2)
                                                Anti-cogging FF 25 kHz (lookup) / 1 kHz (adaptation)
Attitude estimator + Angle loop                           1 kHz
Dynamic-notch frequency tracker                           100 Hz (background)
```

### Control structure for one axis

```
            ┌─────────── base-rate FF (IMU_B) ─────────────┐
 θ_ref ─►(Σ)─► Angle P ─►(Σ)─► Velocity PI(+LPF/notch) ─►(Σ)─► iq_ref ─► Current PI (d,q) ─► SVPWM ─► Motor
           ▲               ▲                             ▲
       θ̂ (Mahony,      ω̂ axis (IMU_C, filtered,      iq_cog(θ_m) anti-cogging FF
        IMU_C)          LMS-cleaned, projected)
```

## 1. Notation

- θ_m: mechanical rotor angle (encoder). θ_e = p·θ_m − θ_off is the electrical angle.
- ω_m: mechanical speed in rad/s.
- K_t = (3/2)·p·λ_m: torque constant in N·m/A (peak-amplitude-invariant Clarke). λ_m is the PM flux linkage.
- J: reflected inertia of the axis (motor rotor + downstream payload about that axis).
- T_s: sample period of the loop being discussed.
