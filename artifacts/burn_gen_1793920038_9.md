I have no project documents for Job #25, so this design rests on the baseline below. Every parameter is a named constant, and §8 lists what must be re-derived if your hardware differs.

## 0. Loop Architecture and Rate Plan

```
 ┌────────── 1 kHz ──────────┐ ┌──── 4 kHz ────┐ ┌───────── 20 kHz ISR ─────────┐
 q_ref ─►[Attitude P + ω_ff]─►[J⁻¹]─►q̇_ref ─►[Vel PI]─►(+)─►iq_ref─►[Current PI + decoupling]─►SVPWM
   ▲                                    ▲       ▲   iq_ff(θm)│           ▲
   │ q̂ (fused attitude)                 │ ω̂_joint     [Anti-cogging]     │ id,iq ◄ Park ◄ Clarke ◄ ADC
 [Mahony AHRS]◄─[accel lever-arm cancel]│              ▲  LMS             │ θe = p·θm − θ0
   ▲                                    │              │                  │
 [Dual ICM-42688-P: HW AAF → SW dynamic notch bank → LPF → inverse-variance fusion + χ² FDI]
                                                  θm ◄── encoder (20 kHz)
```

**Bandwidth separation.** Each loop's crossover is at least 4–5× below the one inside it, so the inner loop looks like unity gain to the outer loop:

| Loop | Rate | Crossover target |
|---|---|---|
| Current | 20 kHz | ω_c ≈ 2π·1.5 kHz |
| Velocity (inertial rate) | 4 kHz | ω_v ≈ 2π·60 Hz |
| Attitude | 1 kHz | ω_θ ≈ 2π·12 Hz |

## 1. Field-Oriented Control Equations

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (two measured phases, with i_a + i_b + i_c = 0):

  i_α = i_a
  i_β = (i_a + 2 i_b) / √3

**Park transform**, with electrical angle θ_e = p·θ_m − θ_0:

  i_d = i_α cos θ_e + i_β sin θ_e
  i_q = −i_α sin θ_e + i_β cos θ_e
