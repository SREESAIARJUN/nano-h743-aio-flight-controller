## 0. Architecture Decision and Assumptions

**The H743 does not commutate the motors.** A single H743 cannot reliably run 4× sensorless 48 kHz commutation (BEMF zero-cross per motor) alongside ArduPilot's EKF, scheduler and logging. The architecture is therefore:

```
STM32H743 (ArduPilot)  ──4× Bi-Dir DShot600──►  4× ESC MCU (AT32F421 / AM32)
                                                    │ 6× PWM @ 48 kHz
                                                    ▼
                                         3-ph gate driver ─► 6× N-MOSFET per motor
```

## 1. Conduction Loss Model

### 1.1 Current path in 6-step synchronous PWM
In any commutation sector, the current flows through two devices:
- **Active (PWM) leg:** the high-side switch during D·T_sw, then the synchronous low-side switch during (1−D)·T_sw.
- **Return leg:** the low-side switch, which is on for 100 % of the sector.

So the current always passes through exactly **two R_ds(on) in series**, regardless of duty cycle:

$$P_{cond,ch} = I_{rms}^2 \cdot \left(2\,R_{ds(on)}(T_j) + R_{cu}\right)$$

Ripple adds a small term:

$$I_{rms}^2 = I_{DC}^2 + \frac{\Delta I_{pp}^2}{12}$$

At 48 kHz with a typical 5″ motor (L_phase ≈ 15 µH), ΔI_pp is a few amps. That adds less than 0.1 % at 80 A, so it is neglected.

### 1.2 Temperature dependence (self-consistent)

$$R_{ds(on)}(T_j) = R_{ds,25}\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.005\ /\mathrm{K}$$

This gives about 1.5× at 125 °C. Iterate together with the thermal model in §3. For the worst-case budget, use the hot value of 1.5 mΩ.

### 1.3 Numbers at 80 A

$$P_{FET,cond} = 80^2 \times 2 \times 1.5\,\mathrm{m\Omega} = 6400 \times 0.003 = \mathbf{19.2\ W}$$

$$P_{Cu} = 6400 \times 0.5\,\mathrm{m\Omega} = \mathbf{3.2\ W}$$

Each FET conducts for 1/3 of the electrical cycle on average. The time-averaged loss per FET is therefore about 19.2 / 6 ≈ **3.2 W**. Low-side devices run slightly hotter at low duty because synchronous rectification adds to their conduction time.

## 2. Switching Loss Model at 48 kHz

Only the active leg's high-side/low-side pair switches hard in each sector. Losses per channel:

### 2.1 V–I overlap (hard switching, inductive load)

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\,\mathrm{ns} \times 48\,\mathrm{kHz} = \mathbf{0.97\ W}$$

Estimate the overlap from gate current:

$$t_{sw} \approx \frac{Q_{gd}}{I_g},\qquad I_g = \frac{V_{drv} - V_{plateau}}{R_{g,ext} + R_{g,int} + R_{drv}}$$

### 2.2 Output capacitance

$$P_{oss} = Q_{oss} V_{bus} f_{sw} = 50\,\mathrm{nC} \times 25.2 \times 48\,\mathrm{k} = \mathbf{0.06\ W}$$

### 2.3 Reverse recovery

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\,\mathrm{nC} \times 25.2 \times 48\,\mathrm{k} = \mathbf{0.05\ W}$$
