## 0. System Partitioning

This architecture has two separate processors, and the requirements split cleanly between them:

| Function | Where it lives |
|---|---|
| ArduPilot, DShot600 generation, bidirectional eRPM capture | **STM32H743** on the FC board |
| 48 kHz PWM commutation, MOSFET drive | **ESC MCU** (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32), one per channel or a shared quad MCU |

**The 48 kHz PWM frequency is an ESC firmware parameter.** ArduPilot does not set it. ArduPilot only sends throttle over DShot and reads back eRPM.

### Baseline assumptions

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, V_bus,max = 25.2 V **[A]** |
| MOSFET | 40 V, R_ds(on) = 1.5 mΩ @ 25 °C (V_gs = 10 V), PDFN 5×6 **[A]** |
| R_ds(on) tempco | ×1.5 at T_j = 100 °C → R_hot = 2.25 mΩ **[A]** |
| Switching times | t_r + t_f = 20 ns at ~1.5 A gate drive **[A]** |
| Q_g = 60 nC, Q_rr = 50 nC, Q_oss = 45 nC, body diode V_f = 0.8 V | **[A]** |
| Dead time | t_dt = 100 ns per edge **[A]** |
| Topology | 6 FETs per channel, 24 total; trapezoidal 6-step, complementary (synchronous) PWM on the high side |
| Board | 30.5 × 30.5 mm, 6-layer, 2 oz copper |

**Form-factor flag:** 80 A per channel on a 20×20 "nano" board is not physically credible, even for bursts. The numbers below assume 30×30. Section 2.4 shows why.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current distribution

In 6-step commutation, two phases conduct at any instant: one high-side FET and one low-side FET. With I_DC defined as the phase current during conduction:

- Each FET conducts for 1/3 of the electrical period (120°).
- High-side FET RMS current: I_HS,rms = I · √(D/3)
- Low-side FET RMS current (synchronous rectification fills the off-time): I_LS,rms = I · √(1/3)

At burst, D ≈ 1, so every FET sees the same RMS current:

$$I_{FET,rms} = \frac{80}{\sqrt{3}} = 46.2\ \text{A}$$

### 1.2 Per-FET conduction loss

$$P_{cond,FET} = I_{rms}^2 \cdot R_{ds(on)}(T_j) = 46.2^2 \times 2.25\,\text{m}\Omega = 4.80\ \text{W}$$

### 1.3 Per-channel and total

$$P_{cond,ch} = 6 \times 4.80 = 28.8\ \text{W}$$

Cross-check: two FETs are always on, so 2 · I² · R = 2 × 6400 × 2.25 mΩ = 28.8 W. ✔

$$P_{cond,4ch} = 115.2\ \text{W}$$

### 1.4 Electrothermal feedback

R_ds(on) depends on junction temperature, so the loss is self-reinforcing:

$$R(T_j) = R_{25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.0067/\text{K}$$

$$T_j = T_{pcb} + P(T_j) \cdot R_{th,j\text{-}pcb}$$

Solving these together gives the steady-state junction temperature:

$$T_j = \frac{T_{pcb} + I_{rms}^2 R_{25}(1 - 25\alpha)\,R_{th}}{1 - I_{rms}^2 R_{25}\,\alpha\, R_{th}}$$

With R_th,j-pcb = 1.0 (jc) + 3.0 (solder/via/spreading) = **4 K/W [A]** and T_pcb = 90 °C:

- The denominator is 1 − 2134 × 0.0015 × 0.0067 × 4 = **0.914**. This is the runaway margin; it must stay well above 0.
- Result: **T_j ≈ 112 °C**, P ≈ 5.1 W per FET.

### 1.5 Copper and shunt losses (often forgotten)

- **Shunt:** 0.25 mΩ, 80 A → **1.6 W per channel**, only if the shunt is in the DC path. Many 4-in-1 boards use a single shared shunt. At 320 A total through 0.25 mΩ that becomes **25.6 W**, which is unacceptable. Use a 0.1 mΩ shunt or a Hall sensor for the total-current measurement.
- **Traces:** for 2 oz copper, R_sq = 0.25 mΩ/□. A 10 mm × 5 mm phase run on 3 paralleled layers has R ≈ 0.17 mΩ → about 1.1 W per phase at 80 A peak.

## 2. Switching Loss Model at 48 kHz

### 2.1 Components per channel

At any time, only the PWM'd high-side FET hard-switches. The low-side FET switches with ZVS-like behavior after dead time.

| Loss | Formula | Value @ 80 A, 25.2 V |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw | ½·25.2·80·20 ns·48 kHz = **0.968 W** |
| Reverse recovery | Q_rr·V·f_sw | 50 nC·25.2·48k = **0.060 W** |
| Output capacitance | ½·Q_oss·V·f_sw | **0.027 W** |
| Dead-time body diode | V_f·I·2t_dt·f_sw | 0.8·80·200 ns·48k = **0.614 W** |
| Gate drive (dissipated in the driver/R_g) | 2·Q_g·V_gs·f_sw | **0.058 W** |
| **Total** | | **≈ 1.73 W/channel** |

### 2.2 Duty-cycle dependence

Switching loss only exists while the FET is actually modulating. At D = 100% there are no PWM edges.

$$P_{total}(D) = I^2 R\,(1+D)\cdot\tfrac{2}{3}\cdot\tfrac{3}{2}\cdot\tfrac{1}{2}\ \ldots$$

That expression simplifies to approximately:

$$P_{total}(D) \approx 2I^2R + k_{sw}\cdot \mathbb{1}[D<1]\cdot I\cdot V$$

where k_sw = 1.73 / (80 × 25.2) = 8.6×10⁻⁴.
