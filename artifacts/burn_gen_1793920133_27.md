# STM32H743 AIO with 4‑in‑1 ESC: Power‑Stage, Thermal, and Bi‑Directional DShot Design Package (Job #41)

---

## 0. Architecture Assumptions

I have no prior context for Job #41, so I fixed the assumptions below. Change any of them and the equations still hold; only the numbers move.

| Item | Assumption |
|---|---|
| Topology | AIO board: STM32H743 flight controller plus 4× independent ESC channels |
| ESC control | One AT32F421 (or STM32G071) per motor running AM32. The H743 does **not** commutate motors. It sends DShot600 and receives eRPM telemetry. |
| Bus | 6S LiPo. Analysis uses V_bus = 25.2 V; design rating is 30 V transient. |
| MOSFETs | 40 V N‑ch, PDFN 3.3×3.3. R_ds(on) = 1.5 mΩ typ / 2.0 mΩ max at 25 °C, V_gs = 10 V. Q_g = 30 nC, Q_gd = 6 nC, Q_gs2 ≈ 5 nC, C_oss,eff ≈ 1.5 nF, Q_rr ≈ 40 nC, V_SD ≈ 0.8 V |
| Gate driver | FD6288Q (3‑phase, bootstrap, 1.5 A source / 1.8 A sink), V_drv ≈ 10–12 V |
| f_sw | 48 kHz PWM, complementary (synchronous rectification), dead time 100 ns |
| Commutation | 6‑step trapezoidal, with high‑side PWM and low‑side complementary |
| Burst | 80 A phase current per motor, all 4 motors simultaneously (worst case) |
| Board | 30.5×30.5 mm, 1.6 mm, 6‑layer, 2 oz outer / 1 oz inner, no heatsink |
