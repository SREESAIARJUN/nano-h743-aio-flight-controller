# STM32H743 AIO Flight Controller + 4-in-1 ESC: Architecture Reference

## 0. Scope, Assumptions, and Design Risks

No MOSFET, board size, battery, or burst duration was specified, so this document fixes a **representative baseline**. Every equation is parametric, so you can substitute real datasheet values.

| Parameter | Baseline value | Notes |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max | 40 V FET class required |
| Burst current | 80 A per motor, 5 s | Phase current, trapezoidal |
| PWM frequency | 48 kHz | Set in ESC firmware (AM32 supports this) |
| MOSFET | 40 V, R_DS(on),25 = 0.9 mΩ, Q_g = 60 nC, Q_gd = 10 nC, Q_rr = 50 nC, C_oss,eq = 1.5 nF, R_θJC = 1.0 K/W | Typical 5×6 mm DFN class |
| FETs | 6 per motor, 24 total | Single FET per switch position |
| Board | 30.5×30.5 mm, 8-layer, 2 oz outer / 1 oz inner | "Nano" form factors (20×20) are not viable at 80 A; see §2.5 |
| T_ambient | 40 °C | Inside the frame |

**Architecture decision.** The H743 should **not** commutate the motors. Running four 48 kHz six-step controllers with BEMF zero-cross detection on top of ArduPilot's scheduler is not realistic. The standard partition is:

- **H743 (flight controller)** sends bidirectional DShot600 to 4× dedicated ESC MCUs.
- **ESC MCUs** are AT32F421 or STM32G071 running AM32.

All ESC-side math below applies to the AM32 MCUs. All timer/DMA math applies to the H743.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.0045\ \text{K}^{-1}$$

| T_j | R_DS(on) |
|---|---|
| 25 °C | 0.90 mΩ |
| 100 °C | 1.20 mΩ |
| 125 °C | 1.31 mΩ |

### 1.2 Six-step commutation with synchronous (complementary) PWM

In each 60° sector:

- **PWM on (fraction D):** current flows HS_A → motor → LS_B (2 FETs).
- **PWM off (fraction 1−D):** current flows LS_A (synchronous rectification) → motor → LS_B (2 FETs).

Current therefore always flows through exactly two channels, independent of D:

$$P_{cond,motor} = 2\,I^2\,R_{DS(on)}(T_j)$$

Each FET conducts current for 120° of every 360° electrical. The per-FET electrical-cycle average is therefore:

$$P_{cond,FET} = \frac{2 I^2 R}{6} = \frac{I^2 R}{3}$$

The instantaneous load is concentrated, however. The full 2I²R sits on two FETs for each sector. At low eRPM (e.g., punch-out from hover, or a stalled prop), sectors last milliseconds. The die thermal time constant is about 1–10 ms, so **you must design for the instantaneous value, not the average.**

### 1.3 Numbers at 80 A, T_j = 100 °C

$$P_{cond,motor} = 2 \times 80^2 \times 1.20\,\text{m}\Omega = \mathbf{15.36\ W}$$

- Per FET, cycle average: **2.56 W**
- Per FET, instantaneous at low eRPM: up to **7.68 W**

### 1.4 Dead-time body-diode conduction

$$P_{DT} = 2\,V_F\,I\,t_{dt}\,f_{sw} = 2(0.8)(80)(50\,\text{ns})(48\,\text{kHz}) = \mathbf{0.31\ W}$$

### 1.5 Copper and shunt conduction

| Element | Resistance | Loss at 80 A |
|---|---|---|
| Phase path (pad → FET → pad), 2 oz | ≈ 0.25 mΩ | 1.60 W |
| Shunt (shared bus, see below) | 0.25 mΩ | 1.60 W |
| Bus plane share | ≈ 0.15 mΩ | 0.96 W |

The shunt current is the bus current, I_bus ≈ D·I_phase. At full throttle with D ≈ 1, assume I_bus ≈ 80 A.

## 2. Switching Loss Model at 48 kHz

### 2.1 Hard-switching V–I overlap (one switching transition pair per PWM period)

Gate driver: 1.5 A peak with R_G = 2.2 Ω.

$$t_{sw} \approx \frac{Q_{gd}}{I_G} = \frac{10\,\text{nC}}{1.5\,\text{A}} \approx 6.7\ \text{ns}$$

Derate to t_r = t_f = 15 ns to account for layout inductance and ringing.

$$P_{VI} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = \tfrac12(25.2)(80)(30\,\text{ns})(48\,\text{kHz}) = \mathbf{1.45\ W}$$

### 2.2 Reverse recovery (sync-rectifier body diode)

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\,\text{nC}\times25.2\times48\,\text{k} = \mathbf{0.06\ W}$$

Diode-side recovery loss is roughly the same order again; this is negligible.

### 2.3 Output capacitance

$$P_{oss} = \tfrac12 C_{oss,eq} V^2 f_{sw} = \tfrac12(1.5\,\text{nF})(25.2^2)(48\,\text{k}) = \mathbf{0.023\ W}$$

### 2.4 Gate drive (dissipated in the driver and R_G, not in the FET)

$$P_G = 2\,Q_g V_{GS} f_{sw} = 2(60\,\text{nC})(10\,\text{V})(48\,\text{k}) = \mathbf{0.058\ W}$$
