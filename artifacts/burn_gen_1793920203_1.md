## 1. Conduction Loss Model (80 A Burst)

### 1.1 Conduction path
In 6-step drive with complementary PWM, at any instant exactly **two MOSFET channels** carry motor current:

- the **static leg**, where the LS (or HS) FET is held on for 120°, and
- the **PWM leg**, where current alternates between HS (during D) and LS (during 1−D) via synchronous rectification.

The current therefore always sees R_DS(on) in two series FETs, independent of duty cycle (dead time excepted, see §2):

$$P_{cond,motor} = I_{rms}^2 \cdot 2R_{DS(on)}(T_j) + I_{rms}^2 R_{Cu}$$

### 1.2 Temperature dependence

$$R_{DS(on)}(T_j) = R_{DS(on),25}\left[1+\alpha (T_j - 25)\right],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

Using max datasheet R at T_j = 110 °C:

$$R_{DS(on)} = 0.9\,\text{m}\Omega \times (1 + 0.005\times85) = 0.9 \times 1.425 \approx 1.28\ \text{m}\Omega$$

### 1.3 Ripple correction

$$I_{rms}^2 = I_{avg}^2 + \frac{\Delta I_{pp}^2}{12},\qquad \Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{ph-ph}\, f_{sw}}$$

For a typical 5" motor (L_ph-ph ≈ 20 µH), at D = 0.5, 25.2 V and 48 kHz:

$$\Delta I_{pp} = \frac{25.2 \times 0.25}{20\,\mu\text{H}\times 48\,\text{kHz}} = 6.6\ \text{A} \;\Rightarrow\; \frac{\Delta I^2}{12} = 3.6\ \text{A}^2$$

This is negligible against 6400 A², so I_rms ≈ 80 A. Low-inductance motors (<5 µH) change this, so re-check if you use them.

### 1.4 Copper loss
Round-trip trace/plane resistance per motor (bus plane → HS → phase pad → motor → phase pad → LS → GND plane) is estimated at R_Cu ≈ 0.30 mΩ for a 2 oz, 8-layer stack with stitched planes.
