## 0. Assumptions & Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, 170+ MHz |
| Motors | 3 × gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A) per axis |
| Current sense | 2-phase inline shunts (a voltage-mode fallback is included) |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetric about the plate's center of rotation |
| Kinematics | Yaw (outer) → Roll → Pitch (inner) |

**Loop rates (rate-separated cascade):**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| PWM / current (FOC) | 20 kHz | ω_ci ≈ 2π·1500 rad/s |
| Velocity (body rate) | 4 kHz | ω_cv ≈ 2π·120 rad/s |
| Angle (attitude) | 1 kHz | ω_cθ ≈ 2π·15 rad/s |
| IMU ODR | 4 kHz (both chips, interrupt-synced) | — |

The rule is roughly a 5–10× bandwidth ratio between adjacent loops. Each loop rate should be at least 20× its bandwidth.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Angles

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at calibration. Apply V_d > 0 with V_q = 0, let the rotor align, and record θ_m.

### 1.2 Clarke Transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park Transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM Model in the dq Frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32\,p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.5 Current PI with Decoupling and Back-EMF Feedforward

Pole–zero cancellation (Ki/Kp = R/L) gives a first-order closed loop of bandwidth ω_ci:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

Discrete form (sample period T_i), using a forward-Euler integrator with back-calculation anti-windup:

$$u_q^* = K_{p,i}e_q + I_q + \underbrace{\omega_e L i_d + \omega_e\lambda_m}_{\text{feedforward}}$$

$$I_q[k{+}1] = I_q[k] + T_i\big(K_{i,i}e_q + K_{aw}(\text{sat}(u_q^*) - u_q^*)\big)$$

Use K_aw ≈ K_i/K_p. The d-axis is analogous, with feedforward −ω_e L i_q and reference i_d* = 0.

**Voltage limit (circle).** Use V_max = V_bus/√3 for SVPWM linear range. d-axis has priority:

$$|v_d|\le V_{\max},\qquad |v_q|\le\sqrt{V_{\max}^2 - v_d^2}$$

### 1.6 Inverse Park and SVPWM (min–max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to 7-segment SVPWM and needs no sector logic.

### 1.7 Delay Compensation

Sample at the PWM center. The applied voltage lags by about 1.5 T_i, so use θ_e + 1.5 ω_e T_i in the inverse Park.
