# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

## Design Specification, Equations, and C++17 Reference Implementation

"Job #35" carries no hardware context here, so this design rests on the assumptions in §0. Every parameter that depends on hardware is a named constant. Swap in your values and the equations and code still apply.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), read every PWM cycle |
| Current sense | 2-phase low-side or inline shunts |
| IMU-C | ICM-42688-P on the camera plate. Inertial feedback: attitude and rate. |
| IMU-B | ICM-42688-P on the handle/base. Disturbance feedforward: base rate. |
| Joint order | Base → Yaw (ψ) → Roll (φ) → Pitch (θ) → Camera |

**Multi-rate schedule.** Each loop runs about 4–5× slower than the one inside it.

```
 20 kHz  PWM ISR : encoder read → Clarke/Park → current PI (d,q) → inv-Park → SVPWM
  8 kHz  IMU DRDY: SPI burst both IMUs → scale → AAF'd data → adaptive notches → biquad LPF
  4 kHz  Rate    : Jacobian mapping → velocity PI (per joint) → + anti-cog FF → iq*
  1 kHz  Attitude: Mahony fusion → angle P + rate FF → ω* (camera body rates)
```
