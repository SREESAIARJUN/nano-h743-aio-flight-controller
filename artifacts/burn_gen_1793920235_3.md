# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

I don't have the Job #33 specification, so this design rests on the assumptions in §0. Every hardware-dependent number is a named constant in the code, so you can substitute your real values in one place.

---

## 0. Baseline Assumptions

| Item | Assumed value | Change in |
|---|---|---|
| MCU | Cortex-M4F/M7 or STM32G4 class with single-precision FPU, ≥170 MHz | — |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH | `MotorParams` |
| Inverter | 3-phase, center-aligned PWM 20 kHz, 2 or 3 low-side shunts | `FocConfig` |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) via SPI | `EncoderPll` |
| IMUs | 2× ICM-42688-P on SPI, gyro/accel ODR 8 kHz, gyro ±2000 dps, accel ±16 g | `Icm42688` |
| Supply | 12–16 V (3–4S) | `vbus` measured each cycle |

### Loop Timing (rate-group architecture)

| Loop | Rate | Trigger | Content |
|---|---|---|---|
| Current / FOC | 20 kHz (Ts = 50 µs) | ADC injected-conversion ISR, PWM-synchronized | Clarke, Park, PI_d/PI_q, inverse Park, SVPWM |
| Velocity | 4 kHz (÷5) | Same ISR, decimated | Encoder PLL, gyro blend, velocity PI, cogging FF |
| IMU | 8 kHz | IMU DRDY → DMA | Dual-IMU fusion, notches, LPF |
| Angle / attitude | 1 kHz | Timer | Mahony AHRS, angle P + rate feedforward |

**Bandwidth separation rule:** each outer loop is ≥ 5–10× slower than the loop it commands.

- ω_c,current ≈ 2π·1500 rad/s
- ω_c,vel ≈ 2π·120 rad/s
- ω_c,angle ≈ 2π·15–25 rad/s

## 1. FOC Core Equations

### 1.1 Clarke transform (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)\qquad (i_a+i_b+i_c=0)$$

With 3 shunts, choose the two phases with the lowest duty in the current sector. Those phases have the longest low-side on-time, so their sampling window is valid. Reconstruct the third phase from the sum constraint.

### 1.2 Park transform

With electrical angle $\theta_e = p\,\theta_m - \theta_{\text{off}}$:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.3 Plant model (surface PMSM, $L_d = L_q = L$)

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m
$$

$$\tau_e = \tfrac{3}{2}\,p\,\lambda_m\, i_q = K_t\, i_q,\qquad J\dot\omega_m = \tau_e - \tau_{cog}(\theta_m) - B\omega_m - \tau_{load}$$

### 1.4 Current PI with decoupling and back-EMF feedforward

The PI uses pole-zero cancellation of the electrical pole $R/L$:

$$K_{p,i} = L\,\omega_{c,i},\qquad K_{i,i} = R\,\omega_{c,i}$$

This gives a closed-loop current response $\approx \dfrac{\omega_{c,i}}{s+\omega_{c,i}}$.

Discrete form (forward Euler on the integrator) plus decoupling:

$$
\begin{aligned}
e_x[k] &= i_x^{*}[k]-i_x[k] \\
I_x[k] &= I_x[k-1] + K_{i,i}T_s\,e_x[k] + K_{aw}\,T_s\,(v_x^{sat}[k-1]-v_x^{unsat}[k-1]) \\
v_d^{unsat} &= K_{p,i}e_d + I_d - \hat\omega_e \hat L\, i_q \\
v_q^{unsat} &= K_{p,i}e_q + I_q + \hat\omega_e \hat L\, i_d + \hat\omega_e\hat\lambda_m
\end{aligned}
$$

- **Anti-windup:** back-calculation with $K_{aw} \approx K_{i,i}/K_{p,i} = R/L$.
