**Bandwidth separation rule.** Each inner loop should be at least 4–5× faster than the loop that wraps it. The loop rate should be at least 10× the bandwidth of the loop it runs:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current | 20 kHz | 1.5–2 kHz |
| Velocity | 4 kHz | 150–300 Hz |
| Attitude | 1 kHz | 20–50 Hz |

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

With θₑ = p·θₘ + θ_offset, where p is the number of pole pairs:

**Clarke (amplitude-invariant):**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\qquad (i_a+i_b+i_c=0)$$

**Park:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and Decoupled PI Design

In the dq frame:

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$

Inject the cross-coupling and back-EMF terms as feedforward:

$$v_d^{ff} = -\omega_e L_q i_q,\qquad v_q^{ff} = \omega_e (L_d i_d + \lambda_m)$$

Each axis then reduces to the first-order plant G(s) = 1/(Ls+R).

**Pole-zero cancellation design** for a closed-loop bandwidth ω_ci:

$$K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}\quad\Rightarrow\quad \frac{I}{I^*} = \frac{\omega_{ci}}{s+\omega_{ci}}$$

**Discretization.** Use backward Euler integration with sample time T_s. Account for the 1.5·T_s computation-plus-PWM delay by keeping ω_ci ≤ 0.2·(2π/T_s)/… in practice, use ω_ci ≈ 2π·(f_s/10–f_s/15).

The torque relation (surface PMSM, i_d* = 0) is:

$$\tau = \tfrac32\,p\,\lambda_m\,i_q = K_t\,i_q$$

### 1.3 Voltage Limiting and Anti-Windup

The linear SVPWM limit is $|v_{dq}| \le V_{dc}/\sqrt3$.

Prioritize d over q:

$$v_d^{sat} = \mathrm{clip}(v_d,\pm V_{max})$$
$$v_q^{sat} = \mathrm{clip}\!\left(v_q,\ \pm\sqrt{V_{max}^2 - (v_d^{sat})^2}\right)$$

**Back-calculation anti-windup:**

$$x_{k+1} = x_k + T_s\left[K_i e_k + K_{aw}(u^{sat}_k - u_k)\right],\qquad K_{aw}\approx K_i/K_p$$
