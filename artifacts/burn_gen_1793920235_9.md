## 0. Assumptions

I don't have the Job #11 spec, so the design rests on the assumptions below. Every value lives in one config struct, so any of them can be changed.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | 12N14P gimbal BLDC (GBM2804-class): p = 7 pole pairs, R ≈ 10 Ω, L ≈ 2 mH, Kt ≈ 0.06 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis, read via SPI at 20 kHz |
| Current sense | Low-side shunts with 3-phase current feedback. A voltage-mode fallback is included for drivers without sensing. |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, both slaved to a shared 32 kHz CLKIN |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates and bandwidths**

| Loop | Rate | Closed-loop bandwidth | Source |
|---|---|---|---|
| Current | 20 kHz | ~2 kHz | ADC, center-aligned PWM |
| Velocity | 4 kHz | ~150–250 Hz | Fused gyro and encoder PLL |
| Angle | 1 kHz | ~20–40 Hz | Mahony attitude and kinematics |
| IMU ODR | 8 kHz | – | AAF on-chip, notches in software |

The bandwidth ratio between nested loops is kept at 5× or more, so each inner loop looks like unity gain to the loop around it.

## 1. FOC Current Loop

### 1.1 Transforms

With electrical angle θe = p·θm − θoffset:

**Clarke transform** (amplitude-invariant, assumes ia + ib + ic = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

**SVPWM** (min/max injection, which is mathematically equivalent to sector-based SVPWM):

$$v_{a,b,c}^* = \text{invClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12\big(\max(v^*)+\min(v^*)\big),\quad d_x = \tfrac12 + \frac{v_x^*+v_0}{V_{bus}}$$

The linear range is |v_αβ| ≤ V_bus/√3. Beyond that, the vector is scaled down while preserving its angle.

### 1.2 Plant and PI design

The dq-frame model of the motor is:

$$L\frac{di_d}{dt} = v_d - R i_d + \omega_e L i_q,\qquad L\frac{di_q}{dt} = v_q - R i_q - \omega_e L i_d - \omega_e \lambda_m$$

**PI with feed-forward decoupling.** The controller output is the PI term plus decoupling terms:

$$v_q = \text{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m,\qquad v_d = \text{PI}_d(e_d) - \omega_e L i_q$$
