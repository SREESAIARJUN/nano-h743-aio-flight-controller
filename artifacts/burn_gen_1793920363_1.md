## 1. Timing Architecture

```
ISR @ 20 kHz (PWM centre, ADC trigger)
 ├─ Read ia, ib, encoder → θm, θe
 ├─ Current PI (d, q) + decoupling → SVPWM
 └─ Every 5th tick (4 kHz):
      ├─ Pull IMU samples (DMA, 8 kHz FIFO, 2 samples/tick)
      ├─ Per-IMU: AAF (on-chip) → dynamic notches → PT2 LPF
      ├─ Dual-IMU inverse-variance fusion + fault check
      ├─ Mahony attitude update
      ├─ Velocity PI (rate loop) + cogging FF → iq*
      └─ Every 4th (1 kHz): angle loop → ω*
```

Each loop runs 5–10× faster than its inner loop's closed-loop bandwidth. Target bandwidths:

- Current loop: ≈ 2 kHz
- Rate loop: ≈ 150–250 Hz
- Angle loop: ≈ 20–40 Hz

## 2. Field-Oriented Control Equations

### 2.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

The offset θ_off is found at startup by forcing v_d at θ_e = 0 and reading θ_m.

### 2.2 Clarke transform (amplitude-invariant, 2 shunts, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 2.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.4 Motor model in the dq frame (SPM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
$$\tau = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 2.5 Current PI with decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Pole-zero cancellation tuning, with the plant 1/(Ls+R) and target bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

### 2.6 Voltage limiting

Limit the voltage vector to the linear SVPWM region, prioritising q:

$$|v| \le V_{dc}/\sqrt3$$
$$v_d \leftarrow \text{sat}(v_d, \pm V_{\max})$$
$$v_q \leftarrow \text{sat}\!\left(v_q, \pm\sqrt{V_{\max}^2 - v_d^2}\right)$$
