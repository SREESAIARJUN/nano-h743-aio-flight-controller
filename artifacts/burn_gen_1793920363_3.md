## 0. Assumptions and Timing Architecture

| Item | Value (per axis) |
|---|---|
| Motor | Gimbal BLDC, 12N14P (N_s = 12 slots, p = 7 pole pairs), R = 5.6 Ω, L = 2.1 mH, K_t ≈ 0.08 N·m/A |
| Load inertia | J ≈ 2.5×10⁻⁴ kg·m² (motor + camera about the axis) |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), read over SPI |
| Current sense | 2-phase inline shunts (a voltage-mode fallback is given) |
| PWM | 20 kHz center-aligned, V_bus = 12 V (actual rail is measured) |
| IMUs | 2× ICM-42688-P on separate SPI buses, gyro and accel ODR = 8 kHz |

| Loop | Rate | Feedback |
|---|---|---|
| Current (d/q PI) | 20 kHz (PWM ISR) | Shunts + encoder angle |
| Velocity PI | 4 kHz | Fused gyro rate, projected onto the axis (encoder PLL as fallback) |
| Angle P + feedforward | 1 kHz | Fused attitude (Mahony), projected onto the joint |
| IMU acquisition | 8 kHz, decimated by 2 with averaging (not dropping) to 4 kHz | — |

Two bandwidth separation rules apply. Each outer loop's crossover should be at most 1/4 to 1/5 of the inner loop's. Each loop's crossover should be at most f_s/10 of its own sample rate.
