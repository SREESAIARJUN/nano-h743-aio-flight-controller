# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #31): Power-Stage, Thermal, and Bi-Directional DShot Design Package

## 0. Architecture Assumptions

The STM32H743 does **not** commutate the motors. In every production AIO, the H743 runs ArduPilot and emits DShot600 to four dedicated ESC MCUs. The ESC MCUs (AT32F421 / STM32G071 running AM32 or BLHeli_32) generate the 48 kHz PWM. This package models that partition.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance
$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R_DS = 0.9 mΩ × 1.60 = **1.44 mΩ**.

### 1.2 Six-step commutation with synchronous rectification
At any instant, current flows through exactly one high-side path and one low-side path. Each path is either the active FET or its synchronously rectifying complement. The bridge therefore always presents 2·R_DS in series:

$$P_{cond,bridge} = 2\,I_{rms}^2\,R_{DS}(T_j)\left(1+\frac{r^2}{12}\right)$$

Here r = ΔI_pp / I is the ripple ratio. The motor inductance and the 48 kHz switching frequency give r ≈ 0.15, so the ripple term is 1.0019, which is negligible.

$$P_{cond,bridge} = 2 \times 80^2 \times 1.44\text{ mΩ} \times 1.0019 = \mathbf{18.47\ W}$$

Averaged over an electrical revolution, each of the six FETs conducts 1/3 of the total:

$$P_{cond,FET} = 18.47/6 = \mathbf{3.08\ W\ (average)},\quad 6.16\ \text{W instantaneous while conducting}$$

### 1.3 Copper and shunt losses (per channel)

| Element | R | P @ 80 A |
|---|---|---|
| Phase pad → motor wire (2 oz, 3 layers paralleled) | 0.15 mΩ | 0.96 W |
| Battery plane share | 0.10 mΩ (shared ×4, see §3) | 0.64 W |
| Current shunt (if per-channel, 0.25 mΩ) | 0.25 mΩ | 1.60 W |

**Recommendation:** use a single 0.25 mΩ shunt on the common battery return, not per-channel shunts. That gives 320 A² × 0.25 mΩ = 25.6 W at full 4×80 A burst, which is unacceptable. Use a Hall sensor (e.g. ACS-class) or a 0.1 mΩ shunt (10.2 W at 320 A) instead.

## 2. Switching Loss Model at f_sw = 48 kHz

Only the PWM-modulated leg hard-switches during each 60° sector. The other active leg is static. Losses are therefore computed for **one leg** per channel.

### 2.1 V-I overlap loss
The Miller plateau sets the transition times:

$$t_{on} \approx \frac{Q_{gd}}{(V_{DRV}-V_{pl})/R_{g,on}} + t_{i,rise},\qquad t_{off}\approx\frac{Q_{gd}}{V_{pl}/R_{g,off}}+t_{i,fall}$$

- Turn-on: I_g = (10 − 4.5)/5 = 1.1 A, so t_v = 9.1 ns. Adding t_i ≈ 5 ns gives **≈ 14 ns ideal**.
- Turn-off: I_g = 4.5/2.5 = 1.8 A, so t_v = 5.6 ns. Adding t_i ≈ 3 ns gives **≈ 9 ns ideal**.

Common-source and loop inductance (≈ 1–2 nH realistic) slow the di/dt. **Design value: t_on + t_off = 40 ns.**

$$P_{VI} = \tfrac12 V_{bus} I (t_{on}+t_{off}) f_{sw} = 0.5 \times 25.2 \times 80 \times 40\text{n} \times 48\text{k} = \mathbf{1.94\ W}$$

###
