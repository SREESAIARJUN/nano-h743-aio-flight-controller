## 0. Architecture Baseline and Feasibility Flags

### 0.1 System partitioning

The STM32H743 does **not** commutate the motors. ArduPilot on the H743 sends bi-directional DShot600 to four dedicated ESC MCUs, which run the 48 kHz PWM and commutation loops.

```
          ┌──────────────────────────── FC section ─────────────────────────────┐
 VBAT ──► │ STM32H743VIH6 (480 MHz)  ── TIM1 CH1-4 ── bidir DShot600 ──┐         │
          │  IMU (SPI1), Baro (I2C2), OSD/Flash (SPI2/3), UARTs        │         │
          └───────────────────────────────────────────────────────────┼─────────┘
          ┌──────────────────────────── ESC section ──────────────────┼─────────┐
          │ 4× [ AT32F421K8U7 (AM32) → FD6288Q driver → 6× 40 V N-FET ] ◄┘        │
          │ shunt current sense, VBAT divider, bulk + MLCC decoupling           │
          └─────────────────────────────────────────────────────────────────────┘
```
