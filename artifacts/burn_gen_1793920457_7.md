## 0. Scope, Assumptions and Feasibility Flags

Several decisions were made where the brief was ambiguous. Each one changes the numbers, so they are stated here first.

| # | Assumption | Why it matters |
|---|---|---|
| A1 | **6S LiPo**, V_bus = 25.2 V max, 22.2 V nominal | Sets switching loss and the FET voltage class (40 V) |
| A2 | **80 A = per-channel phase current burst**. Battery current = D·80 A. | Some vendors quote battery current. That rating would be gentler. |
| A3 | **Burst = ≤ 5 s**, all four channels simultaneous (worst case, e.g. a punch-out) | Drives the transient thermal model |
| A4 | **Architecture: the H743 does not drive the gates.** Each ESC channel has its own MCU (AT32F421 running AM32). The H743 sends bidirectional DShot600 to these MCUs. | This is how every production AIO works. An H743 running FOC for 4 motors plus ArduPilot is not a supported configuration. |
| A5 | **48 kHz = ESC PWM carrier frequency**, 6-step (trapezoidal) commutation with synchronous rectification | Sets the switching-loss equations |
| A6 | Representative MOSFET: 40 V, DFN5x6/3x3 class | No specific part was specified. Substitute datasheet values for the real part. |
| A7 | Board: **36 × 36 mm, 30.5 mm mount, 8-layer, 2 oz all layers** | See the feasibility flag below |
