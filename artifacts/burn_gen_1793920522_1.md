## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

- $p$ is the number of pole pairs.
- $\theta_{\text{off}}$ is found by aligning the rotor with a d-axis current vector.

### 1.2 Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau = \tfrac32 p \lambda_m i_q \equiv K_t\, i_q$$

### 1.5 Current PI with decoupling and back-EMF feedforward

Gains (pole-zero cancellation, closed-loop bandwidth $\omega_c$):

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

Typical choice: $\omega_c = 2\pi\cdot 1.5\text{ kHz}$, which is below $f_{\text{PWM}}/10$.

Control law:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L\, i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L\, i_d + \omega_e\lambda_m$$

With decoupling, each axis reduces to $\dfrac{I}{I^*} = \dfrac{\omega_c}{s+\omega_c}$.

**Voltage limiting.** The vector is saturated to the linear SVPWM hexagon's inscribed circle, $|v| \le V_{dc}/\sqrt3$. The d-axis has priority:

$$|v_q| \le \sqrt{V_{\max}^2 - v_d^2}$$

**Anti-windup.** Back-calculation is used:

$$\dot x_I = K_i e + K_{aw}(u_{\text{sat}} - u)$$
