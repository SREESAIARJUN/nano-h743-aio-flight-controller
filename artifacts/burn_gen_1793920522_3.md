# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original Job #42 specification, so this design is built on the assumptions below. Every numeric parameter is a `constexpr` or configuration field, so you can substitute the real values without changing the structure.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class: single-precision FPU, CORDIC optional |
| Motors | Gimbal BLDC, 12N14P (pole pairs *p* = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| Kinematics | Yaw (z) → Roll (x) → Pitch (y) → camera |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, ±2000 dps, ±16 g |
| Current loop | 20 kHz, synchronized to center-aligned PWM |
| Rate loop / IMU filtering | 4 kHz (IMU samples decimated 2:1 after filtering) |
| Attitude / angle loop | 1 kHz |

## 1. System Architecture

```
            1 kHz                     4 kHz                       20 kHz
 q_target ─► Attitude ─► ω_ref ─► Rate PI ─► i_q,ref ─(+)─► Current PI (d,q) ─► SVPWM ─► Inverter
             P-PI (joint)  (joint)  (per axis)   ▲        ▲          ▲
                ▲                    ▲           │        │ θ_e     │ i_a,i_b,i_c
                │ q̂                  │ ω_joint   │i_q,cog │         │
          Mahony AHRS ◄── fused ω, a ◄─┘    Anti-cogging   Encoder ──┘
                ▲                          (Fourier LMS)
      Dual-IMU fusion (inverse variance + fault vote)
                ▲
      Per-IMU: on-chip AAF → rotation to body → LPF → tracked notch bank (motor harmonics)
```

## 2. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 2.1 Electrical angle with latency compensation

$$
\theta_e[k] = p\,(\theta_m[k] - \theta_{off}) + \hat\omega_e[k]\,T_{lat},\qquad T_{lat} \approx 1.5\,T_s
$$

The 1.5 T_s term accounts for one sample of computation delay plus half a PWM period of zero-order-hold delay.

### 2.2 Clarke and Park transforms (amplitude-invariant)

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad (i_a+i_b+i_c=0)
$$

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 2.3 Plant and current PI with decoupling

The dq-frame plant is:

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q
