## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset).

**Clarke** (power-variant, assuming i_a + i_b + i_c = 0):

  i_α = i_a
  i_β = (i_a + 2 i_b)/√3

**Park:**

  i_d = i_α cos θₑ + i_β sin θₑ
  i_q = −i_α sin θₑ + i_β cos θₑ

**Inverse Park:**

  v_α = v_d cos θₑ − v_q sin θₑ
  v_β = v_d sin θₑ + v_q cos θₑ

### 1.2 Plant in the dq frame

  v_d = R i_d + L di_d/dt − ωₑ L i_q
  v_q = R i_q + L di_q/dt + ωₑ L i_d + ωₑ λ_m

Electromagnetic torque (surface PM, L_d = L_q):

  τ_e = K_t i_q,  with K_t = (3/2) p λ_m

### 1.3 Current PI by pole–zero cancellation

Choose the PI zero to cancel the electrical pole R/L. The closed loop then becomes first order with bandwidth ω_c:

  K_p,i = L ω_c,  K_i,i = R ω_c   (continuous-time integral gain)

Choose ω_c ≤ 2π·f_s/20. At 20 kHz this gives f_c ≈ 1 kHz.

Decoupling and back-EMF feedforward:

  v_d* = PI_d(e_d) − ωₑ L i_q
  v_q* = PI_q(e_q) + ωₑ L i_d + ωₑ λ_m

### 1.4 Voltage limiting and SVPWM

Circular limit: |v_dq| ≤ V_dc/√3. Give v_d priority, then clamp v_q to √(V_max² − v_d²).

Min-max (zero-sequence injection) SVPWM, which is equivalent to classic sector SVPWM:

  v_off = −½ (max(v_a, v_b, v_c) + min(v_a, v_b, v_c))
  duty_x = ½ + (v_x + v_off)/V_dc

## 2. Cascaded Attitude → Rate → Current Control

### 2.1 Structure

```
θ* ─►[Attitude P(+I), 1 kHz]─ω*─►[Rate PI, 4 kHz]─i_q*─►(+ i_q,cog,ff + i_q,acc,ff)─►[FOC PI, 20 kHz]
        ▲ θ̂ (fused IMU)              ▲ ω̂_joint (gyro → joint rate)
```

For a gimbal, the rate feedback should come from the **gyro**, mapped into joint space. Do not use a differentiated encoder signal for rate. The encoder is used only for commutation and for cogging-table indexing.

**Joint-rate mapping.** With camera body rate ω_b and joint angles (yaw ψ → roll φ → pitch ϑ), use the gimbal Jacobian:

  q̇ = J(φ, ϑ)⁻¹ ω_b

Regularize near gimbal lock (|φ| → 90°) with damped least squares:

  J⁺ = Jᵀ (J Jᵀ + λ² I)⁻¹

### 2.2 Rate loop

Mechanical plant: J_m ω̇ = K_t i_q − B ω − τ_cog(θ) − τ_dist.

Treat the closed current loop as the lag 1/(s/ω_c + 1). For rate-loop bandwidth ω_v ≈ ω_c/5…10:

  K_p,v = J_m ω_v / K_t
  K_i,v = K_p,v ω_v / 4   (PI zero one octave below crossover, ~60° phase margin)

### 2.3 Attitude loop

The rate loop looks like ≈1/(s/ω_v + 1). For ω_θ ≈ ω_v/4…6:

  K_p,θ = ω_θ   (rad/s per rad)

An optional small K_i,θ removes steady-state error from residual imbalance. Rate feedforward ω_ff = θ̇* tracks smoothly during user pans.
