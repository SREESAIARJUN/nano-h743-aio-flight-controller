# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #24)

I don't have the Job #24 specification, so this design uses the **baseline assumptions** below. Every assumption is a parameter in the code, so you can substitute your real values without changing the structure.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (GBM2804-class): p = 7 pole pairs, R ≈ 5–10 Ω, Kt ≈ 0.04–0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A), one per axis |
| Drive | 3-phase half-bridge at 20 kHz PWM with center-aligned (inline or low-side) phase current sensing |
| IMU | 2× ICM-42688-P on the camera plate, separate SPI chip selects, sampled at 8 kHz |
| MCU | Cortex-M4F/M7 (STM32G4/H7-class) with single-precision FPU |

**Loop rates**

| Loop | Rate |
|---|---|
| Current (FOC) | 20 kHz |
| Velocity | 4 kHz |
| Angle | 1 kHz |
| IMU acquisition and filtering | 8 kHz |
| AHRS | 1 kHz |
