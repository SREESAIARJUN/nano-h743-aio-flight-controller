# Job #44: STM32H743 Nano FC + 4-in-1 ESC, 80 A Burst
## Thermal, Switching-Loss, and Bi-Directional DShot600 Design Package (Rev A)

## 0. Architecture Decisions and Assumptions

### 0.1 Architectural correction

The STM32H743 should not commutate the motors directly. ArduPilot does not run sensorless six-step or FOC commutation on the flight controller. The correct partition is:

```
[STM32H743 FC] --4× bi-dir DShot600--> [4× ESC MCU (AM32 / BLHeli_32-class)] --> [4× 3-phase bridge]
       ^                                          |
       +------- eRPM (GCR, same wire) <-----------+
```

- **ESC MCU per channel:** AT32F421K8U7 or STM32G071 running AM32. Each runs a 48 kHz complementary PWM.
- **Board stack:** 20×20 mm FC stacked on a 20×20 mm 4-in-1 ESC. A single-board AIO is possible but thermally worse, as shown in §3.
