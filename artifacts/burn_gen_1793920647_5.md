# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

**Assumptions.** I don't have the Job #40 specification, so this design uses common gimbal hardware. All values below are parameterized, so you can replace them with your own:

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class, FPU, 170+ MHz |
| Motors | 12N14P gimbal BLDC (GBM2804-class), pole pairs p = 7, R ≈ 10 Ω, L ≈ 3 mH |
| Phase-current sensing | 2-shunt inline or low-side sensing on each axis |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701), one per joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Kinematics | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |

**Loop rates:**

| Loop | Rate | Purpose |
|---|---|---|
| Current (FOC) | 20 kHz | PWM-synchronous |
| Velocity (rate) | 4 kHz | Gyro + encoder feedback |
| Attitude | 1 kHz | Quaternion error → rate command |
| Fusion and notch filters | 8 kHz input, decimated to 4 kHz | IMU processing |
