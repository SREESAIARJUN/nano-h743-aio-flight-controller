**Rate hierarchy:** current loop bandwidth ω_c ≫ velocity bandwidth ω_v ≫ angle bandwidth ω_p. Use a separation ratio of at least 4–5× at each level.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform** at electrical angle θ_e = p·θ_m − θ_offset, where p is the number of pole pairs:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model (Surface PMSM, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau_e = K_t\, i_q,\qquad K_t = \tfrac{3}{2}p\lambda_m$$

### 1.3 Current PI Controller with Pole-Zero Cancellation

After decoupling, each axis is a first-order plant:

$$G(s) = \frac{1}{Ls + R}$$

Choose the PI as follows:

$$C(s) = K_p + \frac{K_i}{s},\qquad K_p = \omega_c L,\quad K_i = \omega_c R$$

The closed loop is then exactly first-order: $\frac{\omega_c}{s+\omega_c}$.

Keep ω_c ≤ 2π·f_pwm/15 to stay well clear of the sampling and PWM delay (≈1.5 T_s). At 20 kHz this gives about 2π·1.3 kHz.

**Decoupling and back-EMF feedforward:**

$$v_d^* = \text{PI}_d(e_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Voltage vector limit** (with the d-axis given priority):

$$|v_{dq}| \le \frac{V_{dc}}{\sqrt3}\cdot m_{max},\quad m_{max}\approx 0.95$$

### 1.4 SVPWM via Min-Max Zero-Sequence Injection

This is equivalent to sector-based SVPWM and is cheaper to compute:

$$v_a = v_\alpha$$
$$v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta$$
$$v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_a,v_b,v_c) + \min(v_a,v_b,v_c)\big)$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

> **Voltage-mode fallback:** many gimbal motors (R ≈ 5–15 Ω) are run without current sensing. In that case, set v_q = R·i_q* + ω_e·λ_m and v_d = −ω_e·L·i_q*. The cascade above this layer is unchanged; only the current-loop tracking becomes open-loop.

## 2. Cascaded Angle / Velocity Control

### 2.1 Mechanical Plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

With the current loop treated as unity gain, this reduces to:

$$G_v(s) = \frac{K_t}{Js + B}$$

### 2.2 Velocity PI Controller (Symmetric-Optimum Style Placement)

$$i_q^* = K_{pv}\, e_\omega + K_{iv}\!\int e_\omega\,dt + i_{q,ff}$$

Gain selection:

$$K_{pv} = \frac{J\,\omega_v}{K_t},\qquad K_{iv} = K_{pv}\,\frac{\omega_v}{a},\qquad a\in[3,5]$$

The PI zero sits at ω_v/a, giving about 45–55° of phase margin. A typical starting point is ω_v ≈ ω_c/8.

**Velocity measurement:** encoder differencing combined with a first-order LPF (or a PLL observer, below), with ω_f ≈ 3–5·ω_v.
