**Three architecture corrections need sign-off before layout:**

1. **The H743 should not drive the FETs directly.**
   - The H743 has only two advanced timers with complementary outputs and dead-time insertion (TIM1, TIM8). HRTIM is possible but conflicts with FC peripherals.
   - Four motors need 12 complementary pairs plus 4 BEMF comparator channels.
   - Bi-directional DShot is by definition a protocol between the FC and separate ESC MCUs.
   - **Recommended topology:** H743 (ArduPilot) → 4× bidirectional DShot600 lines → 4× ESC MCUs (AT32F421 / STM32G071, AM32 firmware) → 3-phase driver → 6 FETs per motor.
2. **80 A on four channels simultaneously is a burst rating of about 1–3 s, not a continuous rating.** The math in §2 proves this.
3. **Specify the DShot rate correctly.** "DShot600" is the FC→ESC command rate. The bidirectional telemetry reply runs at 750 kbit/s (5/4 × 600k). Both appear in §4.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step synchronous PWM

In any commutation sector, one leg is PWM-switched (HS/LS complementary) and one leg is held on. The phase current therefore always flows through exactly **two FETs**, independent of duty cycle D:

- **During the on-interval (D·T):** HS of the PWM leg conducts, plus the static LS of the other leg.
- **During the off-interval ((1−D)·T):** LS of the PWM leg conducts (synchronous rectification), plus the static LS of the other leg.

The per-channel conduction loss is therefore:

$$P_{cond,FET} = I_{ph}^2 \cdot 2R_{ds(on)}(T_j)$$

Shunt and copper losses add to this:

$$P_{cond,total} = I_{ph}^2\left[2R_{ds}(T_j) + R_{shunt} + R_{Cu}\right]$$

Note that a low-side common-return shunt only carries current while a LS FET is in the path. Treating it as always conducting is the worst case, and that is what this model does.

### 1.2 Temperature dependence of R_ds(on)

$$R_{ds}(T_j) = R_{25}\left[1+\alpha(T_j-25)\right],\qquad \alpha \approx 0.0055\ \text{K}^{-1}$$

This gives roughly 1.5× at 110 °C, consistent with typical normalized-R_ds curves.

### 1.3 Self-consistent junction temperature (closed form)

With P = I²R₂₅[1 + α(T_j − 25)] and T_j = T_a + P·R_th:

$$T_j=\frac{T_a + I^2R_{25}R_{th}(1-25\alpha)}{1-I^2R_{25}\,\alpha\,R_{th}}$$

**Thermal runaway criterion:** a steady state exists only if

$$I^2 R_{25}\,\alpha\,R_{th} < 1$$

Treat this as the hard design limit for any continuous rating.

### 1.4 Numbers at 80 A, T_j = 110 °C

| Term | Value | Loss |
|---|---|---|
| R_ds(110 °C) = 1.0 × 1.47 | 1.47 mΩ × 2 FETs = 2.94 mΩ | 6400 × 2.94 m = **18.8 W** |
| R_shunt | 0.5 mΩ | **3.2 W** |
| R_Cu (phase pad → FET → bus, both paths) | ≈ 0.3 mΩ | **1.9 W** |
| **Conduction per channel** | | **≈ 23.9 W** |

The per-FET peak loss (the static LS FET, which carries current 100 % of the sector) is about **9.4 W**.
