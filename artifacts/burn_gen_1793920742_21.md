# STM32H743 Nano FC + 4-in-1 ESC (Job #42): Power-Stage, Thermal, and DShot Architecture

## 0. Architectural Corrections

Three issues in the brief change the math below.

1. **The H743 cannot directly commutate the motors under ArduPilot.** ArduPilot does not run ESC firmware. Bi-directional DShot means the H743 (running ArduPilot) sends DShot to four separate ESC MCUs, which run AM32 or BLHeli_32. Typical ESC MCUs are the AT32F421 or STM32G071. The architecture is therefore an FC+ESC stack or single-board "AIO" with 1 + 4 MCUs. All netlists below assume this.
2. **"Nano" (20×20 mm) and 80 A per channel are physically incompatible.** Section 3 shows the board's thermal capacitance supports 80 A on all four motors for only about 1–2 s. I model a **30.5×30.5 mm, 8-layer, 2 oz** board as the smallest credible option. If 20×20 is a hard requirement, derate to about 35–40 A burst.
3. **"80 A" must be defined as a phase current.** I treat it as **80 A per motor phase current**. Battery current is roughly D·I_ph.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent Resistance

$$R_{ds}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 115 °C: R = 1.1 × 1.495 ≈ **1.65 mΩ**.

### 1.2 Six-Step Conduction Topology

During each 60° commutation step, two legs carry the phase current I_ph:

- **PWM leg:** the high-side (HS) FET conducts for D. The low-side (LS) FET conducts for (1−D) as a synchronous rectifier.
- **Static leg:** the LS FET is fully on.

Per motor, at any instant:

$$P_{cond,motor} = I_{ph}^2 R_{ds}\,[D + (1-D)] + I_{ph}^2 R_{ds} = 2\,I_{ph}^2\,R_{ds}(T_j)$$

Synchronous rectification makes this loss **independent of duty cycle**. That is why ESCs run hot even at partial throttle under heavy load.
