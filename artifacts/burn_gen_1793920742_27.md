## 0. Architecture Corrections and Assumptions

### 0.1 The H743 needs dedicated ESC MCUs

DShot is a link between a flight controller and separate ESC MCUs. If the H743 drove the gate drivers directly, it would run all four FOC/6-step loops itself and DShot would not exist. This design therefore assumes:

- **FC side:** STM32H743VIH6 running ArduPilot. It generates DShot600 and receives bidirectional eRPM telemetry.
- **ESC side:** 4 × AT32F421K8U7 (or STM32G071) running AM32. Each generates 48 kHz complementary PWM to its own 3-phase gate driver.

If your intent was H743-native motor control, the DShot section does not apply, and the H743 timer budget changes completely.
