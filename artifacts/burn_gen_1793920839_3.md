# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #37)

## 0. Design Assumptions

I don't have the Job #37 specification, so the design below uses typical gimbal parameters. Every one of them is a named constant in the code, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor encoder | 14-bit mag
