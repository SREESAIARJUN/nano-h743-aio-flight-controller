# STM32H743 FC + 4-in-1 80A ESC (Job #23): System Architecture Model

## 0. Scope, Assumptions and Feasibility Flag

| Parameter | Value / Assumption |
|---|---|
| FC MCU | STM32H743VIT6 (LQFP100), 400 MHz SYSCLK, APB1/APB2 timer clocks 200 MHz |
| ESC MCUs | 4× AT32F421 (AM32 or BLHeli_32-class), one per channel |
| Gate driver | FD6288Q (3-phase, bootstrap) per channel |
| MOSFETs | 40 V N-ch, PDFN 5×6 or 3.3×3.3. R_DS(on),25 = 1.0 mΩ @ V_GS = 10 V. Q_g = 60 nC, Q_rr = 50 nC, C_oss ≈ 1.5 nF, R_θJC = 0.8 K/W |
| Bus | 6S LiPo, V_bus,max = 25.2 V (Li-HV 26.1 V). This is why 40 V parts are used. |
| Current | 80 A **per channel**, 10 s burst, trapezoidal 6-step commutation, complementary (synchronous) PWM |
| f_sw | 48 kHz |
| Dead time | t_dt = 100 ns per edge |
| Ambient | 40 °C. Limits: T_board ≤ 110 °C, T_j ≤ 150 °C |

> **Feasibility warning (read first).** The "nano" (20×20 mm) form factor and 4×80 A burst conflict thermally. Section 3.4 shows the board survives roughly 5 s, not 10 s, without a heatsink. Choose one of these before layout freeze:
> - move to a 30.5×30.5 mm board,
> - use R_DS(on) ≤ 0.7 mΩ parts, or
> - add a clamped Al heatsink.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\left[1 + \alpha\,(T_j - 25)\right], \qquad \alpha \approx 0.0055\ \text{K}^{-1}$$

At T_j = 115 °C: R_DS = 1.0 mΩ × 1.495 ≈ **1.5 mΩ**. This is the value used for the burst calculations below.

### 1.2 Per-device duty factors (6-step, synchronous PWM on the driven leg)

In each 60° sector, one leg PWMs: the HS switches at duty D and the LS of the same leg conducts for 1−D. A second leg's LS conducts continuously as the return path. Each leg spends 1/3 of the electrical period as the PWM leg and 1/3 as the return leg.

| Device | Conduction fraction δ |
|---|---|
| High-side | δ_HS = D / 3 |
| Low-side | δ_LS = (1−D)/3 + 1/3 = (2−D)/3 |
