# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

## 0. Assumptions

I don't have the specification for Job #15, so the design uses the typical values below. Each one is a named constant in the code, so you can substitute your own.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701), one per axis |
| Inverter | 3-phase, center-aligned PWM, 20 kHz, inline or low-side shunts |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro and accel ODR 8 kHz |
| Kinematics | Yaw (Z) → Roll (X) → Pitch (Y), i.e. motor order base → camera |

**Loop rates**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity (gyro-based) | 4 kHz | ~80–120 Hz |
| Angle (attitude) | 1 kHz | ~15–25 Hz |
| Attitude estimator | 4 kHz (gyro), 1 kHz (accel correction) | — |

Each loop's bandwidth is at least 5–10× below the loop inside it. This keeps the loops dynamically decoupled.

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle, with the offset θ_off found during alignment:

$$\theta_e = p\,\theta_m - \theta_{off} \pmod{2\pi}$$

Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
