## 0. Assumptions and Key Findings

No prior Job #22 requirements were supplied, so this design rests on the assumptions below. Every number derived later traces back to this table, so change an assumption and recompute.

| Parameter | Assumed value |
|---|---|
| Battery | 6S LiPo: 25.2 V max, 22.2 V nominal |
| Burst current | 80 A per channel |
| Continuous current | 45 A per channel (not verified here) |
| PWM frequency | 48 kHz, complementary (synchronous rectification) |
| Commutation | 6-step trapezoidal (AM32 class firmware) |
| Board size | "Nano AIO": 30.5 mm hole pattern, about 36 × 36 mm outline |
| PCB stackup | 8 layers, 2 oz (70 µm) copper on all layers |
| MOSFET | 40 V N-channel, DFN5x6 (DFN3x3 cannot carry 80 A) |
| MOSFET resistance | R_DS(on) = 0.95 mΩ maximum at 25 °C, V_GS = 10 V |
| MOSFET charges | Q_g = 60 nC, Q_gd = 10 nC, Q_rr = 50 nC, Q_oss = 40 nC |
| Body diode | V_SD = 0.8 V |
| MOSFET thermal | R_th(j-pcb) ≈ 2 K/W |
| Gate driver | FD6288Q-class 3-phase driver, about 1.5 A peak, 10 V V_CC |
