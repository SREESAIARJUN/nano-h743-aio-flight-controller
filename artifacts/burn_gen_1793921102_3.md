## 0. Architecture and a Feasibility Warning

**Topology.** The STM32H743 is the flight controller MCU. It does not commutate motors. The 4-in-1 ESC section uses four dedicated ESC MCUs (e.g., AT32F421 running AM32). Each ESC MCU generates its own 48 kHz complementary PWM, and the H743 sends bi-directional DShot600 to all four.

```
 6S LiPo ─┬─ TVS + bulk caps ─┬─ 4× 3-phase bridge (24 MOSFETs) ─ motors
          │                   └─ 4× ESC MCU (AT32F421, AM32) ─ gate drivers
          └─ 5V/3V3 BEC ─ STM32H743 ── DShot600 BiDir ──► ESC MCUs (×4)
```

**Feasibility.** 80 A per channel on a "nano" board (20×20 or 30.5×30.5 mm footprint) is a transient rating only. Section 3 shows that four channels at 80 A simultaneously cannot be sustained on any board this size. The usable figure is a time-limited burst. This document derives that limit explicitly and does not just assert the rating.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)]$$

At T_j ≈ 115 °C this gives R ≈ 1.0 × (1 + 0.0055 × 90) ≈ **1.5 mΩ**. Section 2.4 closes this value self-consistently.

### 2.2 Current path in six-step commutation

In each 60° sector, one phase is PWM-switched on the high side, one phase is held on the low side, and one phase floats. With synchronous rectification, phase current always flows through exactly two MOSFETs in series:

- PWM on: HS(a) and LS(b).
- PWM off: LS(a) and LS(b). The LS(a) path is freewheeling, with synchronous rectification active.

So the per-channel conduction loss does not depend on duty cycle:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{DS}(T_j)$$

Each phase spends 1/3 of the electrical cycle as the PWM leg and 1/3 as the held-low leg. This gives the per-device split:

$$P_{HS} = \tfrac{1}{3}\,I^2 R\,D \qquad P_{LS} = \tfrac{1}{3}\,I^2 R\,[(1-D) + 1]$$

### 2.3 Numbers at 80 A, D = 0.9, R = 1.5 mΩ

I²R = 6400 × 0.0015 = **9.6 W**

| Element | Expression | Result |
