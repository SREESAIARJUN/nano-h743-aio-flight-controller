# STM32H743 FC + 4-in-1 ESC: 80 A Burst Loss Model, Thermal Analysis, and Bidirectional DShot600 Allocation

## 0. Architecture Clarification and Key Finding

### Topology assumed
An STM32H743 cannot practically run 4× sensorless 6-step commutation under ArduPilot. ArduPilot has no ESC firmware, and 24 gate PWMs plus BEMF sensing is not a supported path. The standard and only sensible topology is:

```
STM32H743 (ArduPilot FC) ──bidir DShot600 ×4──► 4× ESC MCU (AT32F421 / STM32G071, AM32 firmware)
                                                 └─► 3-phase gate driver ─► 6× N-MOSFET per motor
```

The 48 kHz switching frequency is an AM32 PWM setting on the ESC MCUs. DShot timing is set by the H743.

### Key finding: 80 A is a burst rating, not a continuous one
On a 30.5 × 30.5 mm board, 4 × 80 A dissipates about 100 W. That is sustainable for only about 2–4 s (all channels) from a 40 °C start. Section 3 derives this. On a 20 × 20 mm nano board, 80 A per channel is not physically credible. The models below therefore assume a 30.5 mm board. Rescale area and thermal mass if your outline differs.

### Assumed parameters
These are representative 40 V, 3.3 × 3.3 mm class MOSFET values. Replace them with your datasheet values; every equation below is parametric.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S full charge (worst-case switching) |
| I_ph | 80 A | Phase current during conduction (burst) |
| R_ds(on),25 | 1.0 mΩ | At V_gs = 10 V |
| k_T | 1.6 | R_ds multiplier at T_j ≈ 125 °C |
| Q_gs2 + Q_gd | 4 + 8 nC | Switching charge |
| Q_g | 40 nC | Total gate charge |
| V_pl | 3.5 V | Miller plateau |
| V_drv | 10 V | Gate drive |
| R_drv + R_g | 5 Ω | Total gate loop resistance |
| C_oss(er) | 1.2 nF | Effective output capacitance |
| Q_rr | 30 nC | Body diode reverse recovery (hot) |
| V_f | 0.8 V | Body diode forward drop |
| t_dead | 100 ns | Dead time |
| f_sw | 48 kHz | PWM frequency |

> **Voltage margin warning:** 40 V FETs on 6S (25.2 V) leave about 15 V of headroom for ringing. At 80 A, layout inductance of a few nH × di/dt in the A/ns range eats that quickly. Strongly consider 60 V parts, or keep the hot loop under about 1 nH.

## 1. Conduction Loss Model

### 1.1 Six-step commutation with complementary PWM
- At any instant, exactly two legs carry the phase current: one high side (HS) and one low side (LS).
- With synchronous rectification, the PWM leg alternates between HS (duty D) and its own LS (1−D).
- Each FET's share of conduction time, per 360° electrical:

| Device | Conduction fraction |
|---|---|
| HS (PWM leg) | δ_HS = D/3 |
| LS (same leg, freewheel) | (1−D)/3 |
| LS (when leg is the return path) | 1/3 |
| LS worst case | δ_LS = (2−D)/3, which tends to 2/3 as D → 0 |

### 1.2 Equations

```
R_hot = k_T · R_ds,25 = 1.6 mΩ

P_cond,FET   = I_ph² · R_hot · δ
P_cond,chan  = 2 · I_ph² · R_hot            (two FETs always in path)
             = 2 · 6400 · 0.0016 = 20.5 W

Worst single LS FET (D→0):
P_LS,max = 6400 · 0.0016 · 2/3 = 6.83 W
```

### 1.3 Copper path loss
Assume about 0.5 mΩ total from pads, vias, and phase/bus pours on a 2 oz multilayer board:

```
P_Cu,chan = I_ph² · R_Cu = 6400 · 0.5 mΩ = 3.2 W
```

The current-sense shunt is not included. If you use a 0.25 mΩ shunt in the DC link, add I_bat² · R_sh.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. Its HS commutates against the LS body diode or channel.

### 2.1 Transition times
```
I_g,on  = (V_drv − V_pl)/R_G = 6.5/5 = 1.30 A
I_g,off =  V_pl/R_G          = 3.5/5 = 0.70 A
t_on  = (Q_gs2+Q_gd)/I_g,on  = 12 nC/1.30 = 9.2 ns
t_off = (Q_gs2+Q_gd)/I_g,off = 12 nC/0.70 = 17.1 ns
```

### 2.2 Loss components per channel

| Term | Expression | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_on+t_off)·f = ½·25.2·80·26.3 ns·48k | **1.28 W** |
| Reverse recovery | V·Q_rr·f = 25.2·30 nC·48k | 0.036 W |
| C_oss | ½·C_oss·V²·f = ½·1.2n·635·48k | 0.018 W |
| Dead-time diode | V_f·I·2·t_dead·f = 0.8·80·200 ns·48k | **0.61 W** |
| Gate drive (driver IC) | 2·Q_g·V_drv·f = 2·40n·10·48k | 0.038 W |
| **Total switching-related** | | **≈ 1.98 W** |

Q_rr also adds stress to the turn-on of the HS FET. Its loss is small here, but it worsens ringing.

### 2.3 Sensitivity to frequency
```
∂P_sw/∂f ≈ 41 µJ per cycle  →  each +10 kHz adds ≈ 0.41 W/channel
```
