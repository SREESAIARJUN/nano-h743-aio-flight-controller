# STM32H743 Nano FC + 4-in-1 80A ESC (Job #61): Power-Stage Loss Model, Thermal Budget, and Bi-Directional DShot600 Allocation

## 0. Scope and Assumptions

I don't have Job #61's actual BOM, stack-up, or layout files, so this model is parameterized. Every number below comes from a stated assumption, so you can substitute datasheet values for your parts. Verify all values flagged **[VERIFY]** against your parts before releasing to fab.

**Architecture clarification.** The H743 does not generate the 48 kHz power-stage PWM. In a 4-in-1 stack:

- **The FC's H743** runs ArduPilot. It emits DShot600 frames and receives bi-directional eRPM telemetry.
- **Four ESC MCUs** do the commutation and run the 48 kHz PWM. These are typically AT32F421 or STM32G071 running AM32, or EFM8/BB51 running BLHeli_S/Bluejay.

The loss model (Sections 1–4) belongs to the ESC board. The timer and DMA model (Section 5) belongs to the FC.

## 1. Conduction Loss Model

### 1.1 Current Topology

In 6-step commutation with synchronous rectification, two phases are active at any instant. One leg is PWM-modulated (high-side and low-side alternate). The other leg is held with one FET on. Outside the dead time, exactly two FETs carry the full phase current at all times, independent of duty cycle D.

### 1.2 Temperature-Dependent R_DS(on)

R_DS(on)(T_j) = R_25 · [1 + α · (T_j − 25)]

| T_j | R_DS(on) |
|---|---|
| 25 °C | 1.90 mΩ |
| 100 °C | 2.76 mΩ |
| 125 °C | 3.04 mΩ |
| 150 °C | 3.33 mΩ |
