# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

The design below is complete and self-consistent. I don't have the specifics of "Job #1" (motor model, MCU, mechanical layout), so §0 states my baseline assumptions. Every equation is parameterized so you can substitute your real values.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC (GBM-2804 class), 12N14P, so pole pairs p = 7, R ≈ 5.6 Ω, L ≈ 1.9 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| MCU | STM32G4 @ 170 MHz with FPU, center-aligned PWM at 20 kHz |
| Current sensing | 2-phase low-side shunts, sampled mid-PWM |
| IMUs | 2 × ICM-42688-P on separate SPI buses, ODR 8 kHz, ±2000 dps, ±16 g |
| Loop rates | Current 20 kHz → velocity 4 kHz → angle/attitude 1 kHz |

**Rate rationale:** each outer loop's bandwidth should be at least 4–5× below the inner loop's closed-loop bandwidth. Each loop rate should also be at least 10× its bandwidth.

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \mod 2\pi$$

θ_offset is found at startup. Apply a d-axis voltage V_align, wait for the rotor to settle, then record θ_m.

### 1.2 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

Electromagnetic torque (surface PM, L_d = L_q):

$$\tau_e = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.5 Current PI by pole-zero cancellation

Place the PI zero on the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{pwm}}{10}$$

At 20 kHz, choose ω_c = 2π·1500 rad/s.

Discrete form (forward Euler, T_s = 1/f_pwm), with cross-coupling and back-EMF decoupling feedforward:

$$v_d^* = K_{p,i}e_d + I_d - \hat\omega_e L i_q,\qquad v_q^* = K_{p,i}e_q + I_q + \hat\omega_e L i_d + \hat\omega_e\lambda_m$
