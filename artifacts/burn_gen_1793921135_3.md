# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification and C++ Reference Implementation

I don't have the Job #9 hardware details, so this design states its assumptions explicitly. Every parameter that depends on your hardware is a named constant you can change.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU (single-precision `float`) |
| Motors | Gimbal BLDC, 12N14P (pole pairs P = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701), one per axis |
| Current sense | Two low-side shunts per motor, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on SPI at 24 MHz: **IMU-A on the camera plate, IMU-B on the camera plate on the opposite side of the payload** (redundant, physically separated) |
| Joint order | Base → Yaw(z) → Roll(x) → Pitch(y) → Camera |
