# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #47 specification, so every motor, inertia, and placement parameter below is a **declared assumption**. Each lives in one config struct so you can substitute the real values. The equations stay valid either way.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | Cortex-M7 / M4F with single-precision FPU (e.g. STM32G4/H7) |
| Motor | BLDC gimbal motor, 12N14P (pole pairs p = 7, slots Ns = 12) |
| Phase resistance R / inductance L | 5.0 Ω / 2.0 mH (per phase, line-neutral) |
| Flux linkage λ | 0.008 V·s/rad(e) → Kt = 1.5·p·λ = 0.084 N·m/A |
| Bus | 16.8 V (4S) |
| Encoder | 14-bit absolute magnetic (e.g. AS5048A/MA730) |
| IMUs | 2× ICM-42688-P on the camera platform, SPI, ODR 8 kHz |
| Pitch-axis load inertia J | 4×10⁻⁴ kg·m² (tune per axis) |

| Loop | Rate | Trigger | Target bandwidth |
|---|---|---|---|
| Current (FOC, d/q PI) | 20 kHz | ADC end-of-conversion ISR | ~1.5 kHz |
| Velocity (PI + D-filter + FF + anti-cog) | 4 kHz | IMU data-ready, decimated 2:1 | ~60–100 Hz |
| Angle (P/PI) | 1 kHz | Velocity loop ÷4 | ~10–20 Hz |
| Attitude estimator (Mahony) | 4 kHz | With velocity loop | n/a |

The rule: each outer loop has at least 5–10× less bandwidth than its inner loop. Velocity feedback comes from the **fused gyro** (camera-frame rate), not from the differentiated encoder. Gyro feedback is what gives inertial stabilization.

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (two measured phases, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

**Park transform**, with electrical angle θₑ = p·θₘ − θ_offset:

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda$$

$$\tau_e = \tfrac{3}{2} p \lambda\, i_q = K_t\, i_q$$
