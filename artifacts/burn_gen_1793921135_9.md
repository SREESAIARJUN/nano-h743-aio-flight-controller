# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the specifications for Job #55, so this design is parameterized. Every hardware-dependent number is a named constant in `GimbalConfig`. The defaults assume:

| Item | Assumed default |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, ≥150 MHz |
| Motor | Gimbal BLDC (GBM 4108 class), 24 slots, 22 poles (11 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) per axis |
| Driver | 3-phase with inline or low-side shunts, 20 kHz center-aligned PWM |
| IMUs | 2 × ICM-42688-P on SPI, ODR 8 kHz, on the camera plate |
| Joint order | Yaw (base) → Roll → Pitch (camera) |

## 1. Loop Architecture and Timing

```
                  1 kHz              4 kHz                 20 kHz
 q_ref ──► [Attitude/Angle P] ─► ω_ref ─► [Velocity PI] ─► i_q* ─► [Current PI dq] ─► SVPWM
                 ▲                           ▲      ▲  +            ▲
                 │                           │      │  i_cog_ff     │ i_abc, θ_e
        Dual-IMU attitude (q̂)   gyro rate (filtered) │              │
                                             Anti-cogging LMS (θ_m) │
                                                            Encoder PLL (θ_m, ω_m)
```

**Bandwidth separation rule.** Each outer loop should be at least 4–10× slower than the loop inside it:

- ω_c (current) ≈ 2π·1500 rad/s
- ω_v (velocity) ≈ 2π·60–120 rad/s
- ω_p (angle) ≈ ω_v / 4

All loops run from one PWM-synchronous timer ISR with decimation (20 kHz / 5 = 4 kHz, / 20 = 1 kHz). IMU SPI reads are DMA-triggered on the IMU data-ready interrupt at 8 kHz, and their FIFO timestamps are aligned to the control tick.
