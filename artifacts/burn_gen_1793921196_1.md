## 0. Architecture Clarification and Assumptions

### 0.1 System partitioning

The STM32H743 does not commutate the motors. It is the flight controller. A 4-in-1 ESC uses four dedicated ESC MCUs that run the motor firmware. The architecture is:

```
[STM32H743 FC, ArduPilot] --4x bidir DShot600--> [4x AT32F421 running AM32] --> [4x FD6288Q driver] --> [4x 6-FET bridge]
```

AM32 is chosen because it natively supports bidirectional DShot (eRPM telemetry) and 48 kHz PWM.

### 0.2 Realism check: "80A burst" on a nano board

80A per channel on a nano-class board (20×20 or 25.5×25.5 mm mounting, about 30×30 mm PCB) is a **burst rating only**.

- Section 3 shows it is thermally limited to roughly **5 s**.
- The **true continuous rating is about 34 A per channel**.

Treat any "80A" label as a short-burst number, not a continuous one.
