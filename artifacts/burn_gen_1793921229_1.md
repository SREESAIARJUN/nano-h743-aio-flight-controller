# 3-Axis Gimbal: FOC Cascade, Anti-Cogging, and Dual ICM-42688-P Vibration Rejection

> **Scope note:** I don't have the Job #44 spec sheet, so every hardware-dependent number below is in **one config block (§0)**. That includes pole pairs, slot count, phase resistance and inductance, inertia, loop rates, and IMU placement. The equations are general. Fill in your values before tuning.

## 0. Assumed System Parameters

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7, slots Ns = 12), R = 5.0 Ω, L = 2.0 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MA730), per joint |
| PWM / current loop | 20 kHz center-aligned, current PI at 20 kHz |
| IMU | 2× ICM-42688-P at 8 kHz ODR, read over SPI |
| Velocity loop | 4 kHz |
| Angle loop | 1 kHz |
| Joint order (base→camera) | Yaw → Roll → Pitch |

**IMU topology:**

- **IMU-A** is on the camera/payload. It is the primary feedback sensor.
- **IMU-B** is on the base/handle. It provides:
  - the feed-forward of base motion,
  - the reference signal for adaptive vibration cancellation,
  - redundancy cross-checking.

**Rate hierarchy:** 20 kHz current → 8 kHz IMU filtering → 4 kHz velocity → 1 kHz angle/attitude.

## 1. FOC Inner Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \mod 2\pi$$

θ_off is found at commissioning by applying d-axis voltage and locking the rotor.
