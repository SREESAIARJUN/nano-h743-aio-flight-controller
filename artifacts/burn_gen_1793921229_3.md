## 0. Assumptions & Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| Current sensing | 2-phase inline or low-side shunts |
| IMU-P | ICM-42688-P on the **payload** (camera plate). Used for inertial feedback. |
| IMU-B | ICM-42688-P on the **base/handle**. Used for disturbance feedforward and vibration frequency tracking. |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Payload |

**Loop rates:**

```
 20 kHz  PWM ISR : ADC → Clarke/Park → PI_d, PI_q → decoupling → SVPWM
  8 kHz  IMU ISR : both ICM-42688 FIFOs (ODR 8 kHz) → AAF (on-chip) → adaptive notch
                   → LPF → joint-space rate PI → iq* (+ anti-cogging FF)
  1 kHz  Attitude: Mahony AHRS on IMU-P → quaternion attitude error → payload rate cmd
```

## 1. FOC Current Loop

### 1.1 Transforms

The amplitude-invariant Clarke transform, assuming $i_a + i_b + i_c = 0$:

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

The Park transform, with electrical angle $\theta_e = p\,(\theta_m - \theta_{\text{off}})$:

$$
\begin{bmatrix} i_d \\ i_q\end{bmatrix}
=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end
