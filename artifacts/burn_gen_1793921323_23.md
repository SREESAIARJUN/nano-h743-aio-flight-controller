# STM32H743 Nano FC + 4-in-1 ESC (Job #41): Power-Stage Loss, Thermal, and Bi-Directional DShot600 Architecture

## 0. Assumptions and Scope

Before the math, two architectural points need to be fixed:

1. **The H743 does not generate the 48 kHz motor PWM.** In every production 4-in-1 stack, each motor channel has its own ESC MCU running AM32 or BLHeli_32, typically an AT32F421 or STM32G071. That MCU produces the 48 kHz bridge PWM. The H743 running ArduPilot only produces bi-directional DShot600 and decodes the eRPM telemetry. The model below treats these as two separate domains.
2. **80 A burst per channel on a nano (20×20 / 25.5×25.5) board is at or beyond physical limits.** The model shows why. It is valid only for short bursts, and only with the MOSFET class assumed below. If you use 3×3 mm DFN FETs (≈2.5–4 mΩ), all conduction numbers scale up by roughly 2.3–3.6×.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C: R_DS = 1.1 × 1.5 = **1.65 mΩ**.

### 1.2 Six-step trapezoidal commutation with synchronous rectification

At any instant, current flows through exactly two FET channels:
- the PWM phase, through its high-side FET (during D) or its synchronous low-side FET (during 1−D), and
- the return phase, through its low-side FET.

So the per-channel bridge conduction loss is independent of duty:

$$P_{cond,ch} = 2\,I^2 R_{DS}(T_j) + I^2 R_{cu}$$

$$P_{cond,ch} = 2(6400)(1.65\times10^{-3}) + 6400(0.3\times10^{-3}) = 21.1 + 1.9 = \mathbf{23.0\ W}$$

Each FET carries current for about 1/3 of an electrical revolution. The average conduction loss per FET is therefore about 21.1 / 6 ≈ **3.5 W**.

### 1.3 Self-consistency

R_DS depends on T_j and T_j depends on loss, so iterate:

$$T_j^{(n+1)} = T_{board} + P_{FET}(T_j^{(n)})\cdot R_{\theta,jb}$$

With R_θ,jb ≈ 2 K/W (DFN5×6 into a 2 oz plane), this converges in about 2 iterations. Section 3 shows the result.
