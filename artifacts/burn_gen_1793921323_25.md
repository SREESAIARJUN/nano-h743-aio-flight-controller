# STM32H743 Nano AIO with 4-in-1 ESC (Job #23): Architecture, Loss Model, DShot/DMA Allocation, Netlist, and Thermal Budget

## 0. Design Review Findings

These three findings constrain everything that follows.

1. **The H743 cannot be the ESC commutation MCU.** ArduPilot runs on the H743, which cannot also do sensorless commutation for four motors at 48 kHz PWM. The industry-standard and only viable architecture is:
   - **H743 (ArduPilot)** sends bidirectional DShot600 to **4× ESC MCUs** (AT32F421 or STM32G071, running AM32).
   - Each ESC MCU drives a 3-phase gate driver and 6 MOSFETs.
2. **"Nano" vs. H743.** Even the TFBGA100 H743 (8×8 mm) plus a 4-in-1 power stage won't fit a single 20×20 mm board. The design is therefore a **20×20 mm two-board stack**:
   - FC board: H743, IMU, baro, OSD, BEC.
   - ESC board: 4 MCUs, 4 gate drivers, 24 FETs.
3. **80 A is a thermally transient rating only.** Section 3 shows that a 20×20 mm stack can sustain roughly 12–18 A per channel continuously. 80 A is achievable for about 1–2 s on all four channels simultaneously, starting from a warm board. The spec sheet must state this as "80 A burst (≤1 s, single/dual channel)" or it is misleading.

## 1. System Architecture

```
 6S LiPo (max 25.2 V) ──┬── Bulk cap (external, low-ESR 470–1000 µF)
                        ├── ESC board VBAT plane (4×, per-channel 2× 10µF/50V + 4× 100nF)
                        └── FC: VBAT divider → ADC, 5V/3A buck, 10V/2A buck (VTX)

 FC board (H743VIH6, TFBGA100, 480 MHz)
   ├─ SPI1: ICM-42688-P (gyro), DRDY → EXTI
   ├─ I2C2: DPS310 baro
   ├─ SPI2: AT7456E OSD
   ├─ SDMMC1: microSD (logging)
   ├─ UART1–UART7: GPS/RC/VTX/ESC-telem
   └─ M1–M4: bidirectional DShot600 → 8-pin JST-SH stack header

 ESC board (per channel n = 1..4)
   ESC MCU (AT32F421K8U7, QFN32, AM32) → FD6288Q-class 3-ph driver → 3 half-bridges
   (2× 40V N-MOSFET, PDFN3.3) → motor phases A/B/C
   Back-EMF comparators (internal COMP) + phase dividers, shunt/current sense amp
```

## 2. Mathematical Loss Model

### 2.1 Operating Assumptions (Baseline)

| Symbol | Value | Note |
|---|---|---|
| V_bus | 25.2 V | 6S full charge (worst case for switching loss) |
| I_ph | 80 A | Burst DC-link-equivalent phase current |
| f_sw | 48 kHz | AM32 PWM frequency setting |
| R_ds(on),25 | 1.2 mΩ | Typical 40 V PDFN3.3; **verify against selected part** |
| α | 0.0045 /K | R_ds tempco, typical for Si trench FETs |
| t_r, t_f | 20 ns each | At ~2 A gate drive with 2.2 Ω series gate resistor |
| Q_rr | 40 nC | Body diode reverse-recovery charge |
| C_oss(er) | 1.5 nF | Energy-related output capacitance |
| Q_g | 50 nC @ 10 V | Total gate charge |
| t_dt | 50 ns | Dead time (AM32 configurable) |
| V_SD | 0.8 V | Body-diode forward voltage at high current |
| R_shunt | 0.25 mΩ | Per channel |
| R_Cu,trace | 0.4 mΩ | Per conducting path (PCB copper + solder) |

Modulation is 6-step trapezoidal with synchronous rectification (complementary PWM). Exactly **two legs conduct** at any instant: one high-side and one low-side path. Each FET conducts for 120° electrical per cycle.
