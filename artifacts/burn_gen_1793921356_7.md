# STM32H743 FC + 80 A 4-in-1 ESC (Job #49): Reference Design Model

This is an engineering reference model, not a fab-ready release. Every part value, pin mapping and DMA stream assignment must be checked against current datasheets, the STM32H743 reference manual (RM0433), and ArduPilot's `hwdef` DMA resolver output before layout freeze. Each assumption is stated so you can substitute your real BOM numbers.

---

## 0. Architecture and Critical Assumptions

| Parameter | Assumed value | Note |
|---|---|---|
| Battery | 6S Li-ion/LiPo, V_bus,max = 25.2 V | Worst case for switching loss |
| Topology | 4 independent 3-phase bridges, 6 FETs each (24 total) | |
| ESC MCUs | 4× AT32F421 (or STM32G071) running AM32 | The H743 runs ArduPilot and does **not** commutate motors |
| FC↔ESC link | Bidirectional DShot600, 4 signal lines | |
| Form factor | 30.5 × 30.5 mm, 8-layer, 2 oz (70 µm) all layers | 80 A/channel is not credible on a true 20×20 "nano" board (see §3.5) |
| PWM | 48 kHz, complementary (synchronous rectification), 6-step | |
| MOSFET (generic 40 V, 5×6 / 3.3×3.3 class) | R_DS(on),25 = 1.
