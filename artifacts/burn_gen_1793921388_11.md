# STM32H743 AIO Flight Controller + 4-in-1 ESC: System Architecture (Job #58)

## 0. Scope and Assumptions

Two points about the architecture shape the rest of this document.

1. **The H743 does not commutate the motors.** On a 4-in-1 AIO board, the STM32H743 runs ArduPilot and produces bi-directional DShot600. Each ESC channel has its own commutation MCU running AM32 or BLHeli_32. This document assumes an AT32F421 or STM32G071 for that role. The 48 kHz PWM is generated by those ESC MCUs. The DShot DMA allocation lives on the H743.
2. **80 A per motor on a nano-format board is a burst rating, not a continuous one.** Section 3 quantifies the burst duration.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right]$$

| T_j | R_DS(on) |
|---|---|
| 25 °C | 1.40 mΩ |
| 100 °C | 1.90 mΩ |
| 125 °C | 2.07 mΩ |
| 150 °C | 2.24 mΩ |

Use 150 °C as the worst-case design point: **R_DS = 2.24 mΩ**.

### 1.2 Conduction path in 6-step with synchronous rectification

At any instant, two phase legs carry the motor current I.

- **During the on-time (D·T_sw):** current flows through the high-side FET of phase A, then the motor, then the low-side FET of phase B.
- **During the off-time:** current flows through the synchronous low-side FET of phase A, then the motor, then the low-side FET of phase B.

In both intervals exactly two channels are in series, so the conduction loss is independent of duty cycle:

$$P_{cond} = I^2 \cdot 2R_{DS}(T_j)$$
