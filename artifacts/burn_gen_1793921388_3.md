# STM32H743 Nano FC + 4-in-1 80A ESC: Systems Architecture Model (Job #66)

## 0. Architecture Assumptions

Two constraints shape the whole design, so they come first.

1. **The H743 does not commutate the motors.** ArduPilot has no 6-step or FOC ESC firmware. The standard and correct partition is:
   - The H743 flight controller runs ArduPilot and emits bi-directional DShot600.
   - Four dedicated ESC MCUs (AT32F421K8U7 running AM32) produce the 48 kHz complementary PWM, handle back-EMF zero-crossing, and return GCR eRPM telemetry.
2. **80 A is a burst rating, not a continuous one, on a nano footprint.** The math below shows continuous capability is about 28 A per channel. The 80 A figure holds for only a few seconds and depends on thermal mass.

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step synchronous PWM

In any commutation sector, two phases carry current:

- **Switching leg:** the high-side (HS) conducts for duty D, and the synchronous low-side (LS) conducts for 1−D.
- **Fixed leg:** the LS is on for the whole period.

The duty cancels out, so loss per channel is independent of throttle at a given current:

$$P_{cond} = I^2 R_{ds}(T_j)\,[D + (1-D)] + I^2 R_{ds}(T_j) = 2\,I^2 R_{ds}(T_j)$$

### 1.2 Temperature dependence

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)], \qquad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C:

$$R_{ds} = 0.90 \times 1.5 = 1.35\ \text{m}\Omega$$

### 1.3 Burst conduction loss at 80 A

$$P_{cond} = 2 \times 80^2 \times 1.35\times10^{-3} = \mathbf{17.3\ W/channel}$$

This is split between about 2 conducting FETs, so roughly 8.6 W per FET.

**Electrothermal feedback.** P_cond rises with T_j, which raises R_ds, which raises P_cond. Solve iteratively:

$$T_j = T_{board} + P_{FET}\,R_{\theta JC}$$

The loop converges when $2I^2R_{ds,25}\,\alpha\,R_{\theta JC} \ll 1$. Here that product is about 0.06, so the loop is stable.

## 2. Switching Loss Model at 48 kHz

### 2.1 Transition times (gate-charge method)

Turn-on gate current and rise time:

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_{drv,src} + R_{g,ext} + R_{g,int}} = \frac{12 - 4.5}{11} = 0.68\ \text{A}$$

$$t_r = \frac{Q_{sw}}{I_{g,on}} = 22\ \text{ns}$$

Turn-off gate current and fall time:

$$I_{g,off} = \frac{V_{pl}}{R_{drv,snk} + R_{g,ext} + R_{g,int}} = \frac{4.5}{9} = 0.50\ \text{A}$$

$$t_f = \frac{Q_{sw}}{I_{g,off}} = 30\ \text{ns}$$

### 2.2 Loss components (switching leg, per channel)

| Mechanism | Equation | Value @ 80 A |
|---|---|---|
| V–I overlap | ½·V_bus·I·(t_r + t_f)·f_sw | ½·25.2·80·52 ns·48 k = **2.52 W** |
| Reverse recovery | V_bus·Q_rr·f_sw | **0.048 W** |
| C_oss charge | ½·C_oss·V_bus²·f_sw × 2 | **0.046 W** |
| Dead-time body diode | V_f·I·2·t_dead·f_sw | 0.8·80·200 ns·48 k = **0.61 W** |
| Gate drive (6 FETs, dissipated in driver/R_g) | 6·Q_g·V_drv·f_sw | **0.21 W** |
| **Subtotal** | | **≈ 3.4 W** |

### 2.3 Channel and board totals

$$P_{ch}(80\,\text{A}) \approx 17.3 + 3.4 = \mathbf{20.7\ W}$$

$$P_{board} = 4 \times 20.7 + P_{FC,BEC} (\approx 2\ \text{W}) \approx \mathbf{85\ W}$$

### 2.4 Design levers

- **Switching frequency trade-off.** 48 kHz costs about 1.6 W per channel more than 24 kHz at 80 A. In exchange it gives lower current ripple and quieter small motors.
- **Dead time is the second-largest switching term.** AM32 dead-time tuning to about 50 ns saves roughly 0.3 W per channel.
