## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms (amplitude-invariant)

**Clarke transform**, assuming a balanced system where i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, with electrical angle θ_e = p·(θ_m − θ_offset):

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform** uses a delay-compensated angle. One PWM period of transport delay plus half a period of zero-order hold gives:

$$\hat\theta_e = \theta_e + 1.5\,\omega_e T_s$$

$$v_\alpha = v_d\cos\hat\theta_e - v_q\sin\hat\theta_e,\qquad v_\beta = v_d\sin\hat\theta_e + v_q\cos\hat\theta_e$$

### 1.2 SVPWM via min/max zero-sequence injection

This is mathematically equivalent to 7-segment SVPWM.

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
