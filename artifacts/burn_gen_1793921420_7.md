## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU and center-aligned PWM |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, sample-synchronous |
| Kinematics | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) |

```
          8 kHz IMU ISR                       20 kHz PWM ISR (per axis)
┌─────────────────────────────┐   ┌──────────────────────────────────────────┐
│ IMU A ─┐ calib→notch→LPF    │   │ encoder → PLL(θm, ωm)                    │
│ IMU B ─┴→ consistency/fuse  │   │ iq* = iq_vel + iq_cog(θm)                │
│        → Mahony AHRS        │   │ current PI (d/q) → inv.Park → SVPWM      │
└──────────┬──────────────────┘   └──────────────────────────────────────────┘
           │ 2 kHz                         ▲ iq_vel
┌──────────▼────────────────────┐          │
│ attitude err → angle P (cam)  │→ ω* →J⁻¹→ joint rate PI (gyro-mapped) ─┘
└───────────────────────────────┘
```

**Bandwidth separation** (each loop at least 4–5× slower than the loop inside it):

- Current loop: ω_c ≈ 2π·1.5 kHz
- Rate loop: ω_v ≈ 2π·60–120 Hz
- Angle loop: ω_θ ≈ 2π·15–25 Hz

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

Electrical angle: θ_e = p·(θ_m − θ_offset)

Clarke transform:
- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

Park transform:
- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

Inverse Park transform:
- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Plant and PI design (pole-zero cancellation)

Motor voltage equations:
- v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
- v_q = R·i_q + L·di_q/dt + ω_e·L·i_d + ω_e·λ

Choose:
- K_p = L·ω_c
- K_i = R·ω_c

The PI zero then cancels the electrical pole at R/L, and the closed loop
