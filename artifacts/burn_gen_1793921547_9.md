## 1. System Architecture

```
 Camera-frame IMU path (8 kHz)                              Per-axis motor path
 ┌─────────┐  AAF   ┌──────────────┐  ┌────────────┐
 │ICM #1   ├──────► │align+lever-  │  │ dyn. notch │   ω_cam,     ┌──────────────────┐
 │ICM #2   ├──────► │arm comp, LMS ├─►│ bank + PT2 ├──► q_cam ────►│ Mahony attitude  │
 └─────────┘        │ var. weighting│  └────────────┘              └────────┬─────────┘
                    └──────────────┘        ▲ f_notch from motor speed     │ q_err
                                            │                               ▼
 setpoint q_ref ──► [Attitude error → joint-space via gimbal Jacobian J(θ)^-1]  1 kHz
                          │ θ_err,j
                          ▼
                [Angle P(+I) + vel/accel FF]  ── ω_ref,j ──► [Velocity PI, 4 kHz] ── i_q* ─┐
                                                                                         │
                     cogging FF  i_q,cog(θ_m)  ───────────────────────────────────────►(+)
                                                                                         ▼
           encoder θ_m ─► PLL observer (θ̂, ω̂) ─► θ_e = p·θ_m − θ_off ─► [dq Current PI, 20 kHz] ─► SVPWM
```

Velocity feedback for stabilization comes from the gyro, mapped into joint space. This rejects base motion directly. The encoder PLL velocity is blended in at low frequency and used for commutation and cogging indexing.
