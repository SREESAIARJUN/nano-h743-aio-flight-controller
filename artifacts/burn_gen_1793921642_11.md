# STM32H743 Nano AIO with 4-in-1 ESC (Job #23): Power-Stage, Thermal and Bidirectional DShot Architecture

**Document scope:** analytical model plus reference netlists.
**Status:** design-basis draft. All device parameters are stated as explicit assumptions. Substitute the final datasheet values and confirm by bench test before layout freeze (see §7).

## 0. Architectural Reality Check (Read First)

Three points frame every number below.

1. **The H743 does not run the bridges.** In any practical 4-in-1 design, each motor channel has its own ESC MCU (e.g., AT32F421 running AM32, or EFM8/BLHeli_S). That MCU generates the 48 kHz PWM. The H743 runs ArduPilot and talks to the ESC MCUs over bidirectional DShot600. The model is therefore split:
   - **Power domain:** ESC MCU, gate driver, MOSFETs.
   - **Control domain:** H743 timers, DMA, DShot.
2. **"80 A burst" on a nano (≈20×20 to 30×30 mm) board is thermally extreme.** The math below shows it is only survivable as a **time-limited burst of a few seconds** with all four channels loaded. It is not a continuous rating. The burst limit must be specified as (current, duration, starting temperature).
3. **80 A per channel × 4 channels at full throttle implies up to ~320 A battery current.** That figure must be reconciled with:
   - the XT60/XT90 connector,
   - the pad and busbar design,
   - the battery C-rating.

   Battery current is I_bat ≈ D·I_ph per channel, so it only approaches 320 A at full duty with all motors loaded.
