## 0. Architectural Ground Truth

A common misconception is worth correcting first. **ArduPilot on the H743 does not commutate the motors.** The H743 runs ArduPilot and emits bidirectional DShot600. Each ESC channel has its own MCU running AM32 or BLHeli_32-class firmware, which handles 6-step/BEMF commutation at 48 kHz PWM.

```
VBAT ─┬─ 4× [ESC MCU (AT32F421K8) → 3-ph gate driver (FD6288Q) → 6× N-MOSFET] → Motor 1..4
      ├─ Buck 5V/2A → LDO 3.3V (FC) + per-ESC 3.3V LDO
      └─ H743 (ArduPilot) ── TIM3 CH1-4 ── bidir DShot600 ──→ ESC MCUs
                                        ←── GCR eRPM telemetry
```

## 1. Conduction Loss Model

### 1.1 Current Path in 6-Step Commutation with Synchronous PWM

In each commutation sector, two phases carry current:

- **PWM leg:** the high-side FET conducts for a fraction D of each period. The synchronous low-side FET of the same leg conducts for (1−D).
- **Return leg:** the low-side FET conducts continuously.

At every instant, therefore, exactly **two FETs** sit in series with the motor current.

### 1.2 RMS Phase Current with PWM Ripple

The ripple current is:

$$
\Delta I = \frac{V_{bus}\,D(1-D)}{L_{ph-ph}\, f_{sw}}
$$

The RMS current including ripple is:

$$
I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12}
$$
