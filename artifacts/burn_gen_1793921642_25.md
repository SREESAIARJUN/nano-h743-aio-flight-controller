# STM32H743 Nano FC + 4-in-1 80 A ESC (Job #44): System Architecture Package

## 0. Scope, Assumptions and Feasibility

I don't have a stored spec for "Job #44", so this package uses the baseline below. Every equation is parametric, so you can substitute your real values.

| Parameter | Assumed value | Notes |
|---|---|---|
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal | All loss calculations use 25.2 V as the worst case |
| Burst phase current | 80 A per motor, all 4 motors at once | This is the worst case |
| PWM frequency | 48 kHz, complementary (synchronous rectification) | Typical for AM32/BLHeli_32 |
| Topology | H743 flight controller plus 4 independent ESC MCUs (AM32 on AT32F421 or STM32G071) | See the note below |
| MOSFETs | 40 V, R_DS(on) = 0.9 mΩ at 25 °C, PDFN 5×6 or 3.3×3.3 class, 1 FET per switch position | 24 FETs total |
| Board | 30.5×30.5 mm mounting class (the "nano" stack), 8-layer, 2 oz copper | |
| Ambient | 40 °C, prop-wash airflow | |
| Junction limit | T_j(max) design target 125 °C | 150 °C absolute |

**Architecture note.** The H743 does not commutate the motors. Each motor gets its own small ESC MCU. The H743 runs ArduPilot and talks to those MCUs over bidirectional DShot600. This is how every production AIO/stack board works.
