## 1. Conduction Loss Model (80 A Burst)

### 1.1 Commutation topology
The ESC uses 6-step (trapezoidal) commutation with synchronous rectification. At any instant two phases carry the current I:

- **Phase A (PWM leg):** high-side on for duty D, synchronous low-side on for (1−D).
- **Phase B (return leg):** low-side on for 100 % of the sector.
- **Phase C:** floating, used for back-EMF (BEMF) sensing.

### 1.2 Per-channel conduction loss
Add up the three conducting paths:

$$P_{cond} = D\,I^2R_{HS} + (1-D)\,I^2R_{LS,sync} + I^2R_{LS,ret} = 2\,I^2R_{DS(on)}(T_j)$$

Because of synchronous rectification, this is independent of duty cycle.

The temperature dependence of R_DS(on) is:

$$R_{DS(on)}(T_j) = R_{25}\,[1 + \alpha(T_j - 25)]$$

At T_j = 125 °C: R = 1.3 mΩ × 1.40 = 1.82 mΩ.

$$P_{cond} = 2 \times 80^2 \times 1.82\times10^{-3} = \mathbf{23.3\ W\ per\ channel}$$

### 1.3 Per-device split (which FET sets the limit)
| Device | Loss expression | Value |
|---|---|---|
| Return-leg low-side | I²R | 11.6 W (worst case, 100 % of sector) |
| PWM high-side | D·I²R + P_sw | 5.8 W + 1.9 W at D = 0.5 |
| Sync low-side | (1−D)·I²R + P_dt | 5.8 W + 0.6 W |

The **return-leg low-side FET** sets the thermal limit. Commutation rotates this role through all six switches, so averaged over one electrical revolution each FET carries about one third of the sector-peak load. The thermal model below uses the sector peak, which is conservative.

### 1.4 Electro-thermal coupling
R_DS(on) rises with T_j, and T_j rises with loss, so the two must be solved together:

$$T_j = T_{board} + P(T_j)\,R_{\theta,j\text{-}b}, \qquad P(T_j) = I^2 R_{25}[1+\alpha(T_j-25)]$$

Solving for T_j:

$$T_j = \frac{T_b + I^2R_{25}(1-25\alpha)R_{\theta}}{1 - I^2R_{25}\,\alpha\,R_{\theta}}$$

**Stability criterion:** the loop runs away if I²·R₂₅·α·R_θ ≥ 1.

At 80 A with R_θ = 3 K/W: 6400 × 1.3e-3 × 0.004 × 3 = 0.10. This is well below 1, so the design is stable.
