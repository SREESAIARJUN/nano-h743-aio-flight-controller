## 0. Architectural Clarification (read first)

The 48 kHz commutation/PWM loop does **not** run on the STM32H743. The split is:

| Domain | Device | Function |
|---|---|---|
| Flight controller | STM32H743 (ArduPilot) | Attitude control. Emits bi-directional DShot600 and receives eRPM telemetry |
| ESC (×4) | AM32/BLHeli_32-class MCU, e.g. AT32F421 or STM32G071 | 6-step or sinusoidal commutation, 48 kHz PWM, BEMF sensing |
| Power stage (×4) | 3-phase gate driver + 6 N-MOSFETs | Power conversion |

Running four 48 kHz motor-control loops on the H743 alongside ArduPilot is not supported by the ArduPilot firmware. It would also couple ESC faults into the flight control loop.

**Assumptions used throughout:**

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max (22.2 V nominal) |
| Burst current | I = 80 A per ESC (phase current, motor side) |
| Switching frequency | f_sw = 48 kHz |
| Board size | 20×20 mm (nano), 8-layer, 2 oz outer / 1 oz inner copper |
| MOSFET (example class) | 30–40 V, 3.3×3.3 mm DFN, R_ds(on),25 = 1.2 mΩ at V_gs = 10 V |
| Q_g | 40 nC |
| Q_rr | 40 nC |
| Q_oss | 30 nC |
| R_θJC | 1.5 K/W |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM, dead time t_dt = 50 ns |

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,\big[1 + \alpha\,(T_j - 25)\big],\qquad \alpha \approx 0.0075\ \text{K}^{-1}$$

At T_j = 105 °C: R_ds = 1.2 × 1.6 = **1.92 mΩ**.

### 1.2 Current paths in one 6-step sector

In each 60° sector, phase X is PWM'd high and phase Y is held low.

| Device | Conduction fraction | Current |
|---|---|---|
| HS_X (high side, PWM'd) | D | I |
| LS_X (synchronous rectifier) | 1 − D | I |
| LS_Y (static low side) | 1 | I |

Including PWM ripple, the RMS-squared current is

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}$$

The conduction loss is then:

$$P_{cond} = I_{rms}^2 R_{ds}\,\big[D + (1-D) + 1\big] = 2\,I_{rms}^2\,R_{ds}(T_j)$$

**Key result:** with synchronous rectification, conduction loss is **independent of throttle duty**.

### 1.3 Ripple term

The ripple current is

$$\Delta I = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

The worst case is D = 0.5 with V_bemf ≈ V_bus/2. Taking L_ph = 15 µH (typical 2207 motor, line-to-line inductance halved):

$$\Delta I \approx \frac{12.6 \times 0.5}{15\times10^{-6} \times 48\times10^{3}} = 8.75\ \text{A}
\quad\Rightarrow\quad \frac{\Delta I^2}{12} = 6.4\ \text{A}^2$$

This is negligible against I² = 6400 A².

### 1.4 Numerical result at 80 A

$$P_{cond} = 2 \times 6406 \times 1.92\times10^{-3} = \mathbf{24.6\ W\ per\ ESC}$$

### 1.5 Parasitic conduction (often underestimated)

| Element | Resistance | Loss at 80 A |
|---|---|---|
| Phase pad + copper (2 paths) | ~0.3 mΩ each | 2 × 1.92 W = 3.8 W |
| Current-sense shunt (if per-ESC on GND return) | 0.25 mΩ | I_bat² R, see below |
| Battery input copper (shared) | ~0.2 mΩ | I_bat_total² R |

The shunt sees battery current, not phase current: I_bat ≈ D·I. At D = 0.9, I_bat = 72 A, so the shunt dissipates 72² × 0.25 mΩ = **1.3 W**.

**Recommendation:** use a 0.2 mΩ shunt, or a single shared shunt with per-ESC estimation.

## 2. Switching Loss Model at 48 kHz

Only the PWM'd leg (HS_X/LS_X) hard-switches. LS_Y is static within the sector.

### 2.1 V-I overlap (hard turn-on and turn-off of HS_X)

$$P_{VI} = \tfrac12\,V_{bus}\,I\,(t_r + t_f)\,f_{sw}$$

With t_r + t_f = 30 ns (driver capable of about 1.5 A source / 2 A sink):

$$P_{VI} = 0.5 \times 25.2 \times 80 \times 30\times10^{-9} \times 48\times10^3 = \mathbf{1.45\ W}$$

### 2.2 Body-diode reverse recovery (LS_X diode recovers at HS_X turn-on)

$$P_{rr} = Q_{rr}\,V_{bus}\,f_{sw} = 40\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.048\ W}$$

There is also an E_rr contribution into HS_X. It is included approximately in P_VI.

### 2.3
