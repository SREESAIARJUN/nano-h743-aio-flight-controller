I don't have Job #76's BOM, stack-up, or layout files. Everything below is therefore a **parametric model** populated with representative values. Each assumption is flagged so you can substitute datasheet and layout numbers directly.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path in 6-step with synchronous rectification

At any instant, two phases carry current. One leg is PWM'd with duty D and the other leg's low-side FET is held on.

- PWM leg: high-side (HS) FET conducts for D. The complementary low-side (LS) FET conducts for (1−D).
- Return leg: LS FET conducts 100%.

The current therefore always flows through exactly **two** channels (plus dead-time diode intervals, treated in §2). This gives:

$$P_{cond,motor} = 2\,I_{rms}^2\,R_{ds}(T_j)$$

$$R_{ds}(T_j) = R_{ds25}\,[1+\alpha(T_j-25)]$$

Phase-current ripple adds a small correction:

$$I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12}, \qquad \Delta I_{pp} \approx \frac{V_{bus}\,D(1-D)}{L_{ph}\,f_{sw}}$$

For a typical motor (L_ph ≈ 15 µH line-to-line, D = 0.5), ΔI_pp ≈ 8.75 A, so the correction is about 0.1%. It is negligible at 80 A.

### 1.2 Electrothermal fixed-point iteration

Solve T_j and P together, since R_DS(on) depends on T_j:

$$T_j^{(k+1)} = T_{ref} + Z_{th}\cdot P\big(R_{ds}(T_j^{(k)})\big)$$

It converges in 3–4 iterations. The converged result used below is T_j ≈ 120 °C, giving R_ds = 0.90 × (1 + 0.0045 × 95) = **1.28 mΩ**.

$$P_{cond,motor} = 2 \times 80^2 \times 1.28\times10^{-3} = \mathbf{16.4\ W}$$

Effect of paralleling (2 FETs per switch, i.e. 12 per motor):

$$P = 2\cdot80^2\cdot\tfrac{1.28}{2}\,\text{m}\Omega = 8.2\ \text{W}$$

### 1.3 Per-FET averaging

At burst eRPM (≥ ~20 k eRPM), the electrical period (≤3 ms) is shorter than the τ_jc time constant of a 5×6 package (≈5–20 ms). Each FET therefore sees approximately average power:

$$\bar P_{FET} \approx P_{cond,motor}/6 \approx 2.7\ \text{W (single FET per switch)}$$

**Caveat:** at low eRPM or stall, this does not hold. One HS/LS pair carries the full 8.2 W each. Stall/desync detection in the ESC firmware must cut current within about 100 ms.

## 2. Switching Loss Model at 48 kHz

Only the PWM'd leg hard-switches; the return leg is static. Per motor:

| Term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw | 0.5·25.2·80·40n·48k = **1.94 W** |
| Dead-time diode | V_SD·I·(2·t_dt)·f_sw | 0.8·80·200n·48k
