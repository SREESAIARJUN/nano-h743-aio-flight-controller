# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the original Job #9 specification, so this design uses the typical brushless-gimbal assumptions listed in Section 0. Every hardware-dependent number is a named constant, so you can replace each one with your real values.

---

## 0. Assumptions and Loop Rates

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Driver | 3-phase inverter with 2 or 3 low-side shunts |
| Joint encoder | 14-bit magnetic (AS5048A / MT6701), read every current-loop tick |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, mounted symmetrically about the plate centroid |
| Kinematics | Base → yaw (z) → roll (x) → pitch (y) → camera |

| Loop | Rate | Inputs |
|---|---|---|
| Current (FOC) | 20 kHz | shunts, encoder |
| Velocity (rate) | 4 kHz | fused gyro |
| Angle (attitude) | 1 kHz | Mahony quaternion |
| IMU fusion | 8 kHz | ICM-42688-P FIFO / DRDY |

$$\theta_e = p\,(\theta_m - \theta_0)$$
