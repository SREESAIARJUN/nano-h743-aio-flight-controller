## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, single-precision FPU, CORDIC) |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH |
| Position sensor | 14-bit magnetic encoder per joint (AS5048A / MT6701) |
| Current sense | 2- or 3-shunt, sampled center-aligned |
| IMU-A | ICM-42688-P on the **camera platform** (feedback sensor) |
| IMU-B | ICM-42688-P on the **base/handle** (disturbance reference) |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

### Loop rates

```
 20 kHz  ISR (PWM center) : encoder read, current loop (FOC), cogging/friction FF, SVPWM
  4 kHz  IMU data-ready   : dual-IMU filtering, adaptive notch, camera-frame rate loop (PI-D)
  1 kHz  task             : attitude estimator (Mahony), attitude P-loop, kinematics
 100 Hz  task             : notch frequency tracker update, cogging LMS bookkeeping, diagnostics
```

Each loop's bandwidth is set at roughly 1/5 to 1/10 of the next inner loop:
- Current loop: about 2 kHz
- Rate loop: about 150–250 Hz
- Attitude loop: about 15–30 Hz

## 1. Field-Oriented Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Here $\theta_{\text{off}}$ is found at calibration by driving $V_d$ with $\theta_e = 0$ and recording $\theta_m$.

### 1.2 Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$)

$$i_\alpha = i_a, \qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model in the rotor frame (SPM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q, \qquad v_q = R i_q + L \dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

### 1.5 PI with decoupling and back-EMF
