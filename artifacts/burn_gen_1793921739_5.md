## 0. Baseline Assumptions

| Item | Assumed value | Notes |
|---|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz | Code is portable C++17, with no heap and no exceptions |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7) | e.g. GBM2804-class, R ≈ 5–10 Ω |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) | Used for commutation and joint angle |
| Current sense | 2-phase low-side shunts | Section 1.3 covers the voltage-mode fallback |
| PWM / current loop | 20 kHz center-aligned, current loop at 20 kHz | |
| IMUs | 2× ICM-42688-P on SPI, 8 kHz ODR | **IMU-P** on the camera payload, **IMU-B** on the gimbal base/handle |
| Velocity loop | 4 kHz | |
| Angle/attitude loop | 1 kHz | |

**Role of the two IMUs.** I chose a payload IMU plus a base IMU over two redundant payload IMUs, because this arrangement gives the strongest vibration rejection:

- **IMU-P** measures the quantity being stabilized, the inertial rate and attitude of the camera.
- **IMU-B** measures the disturbance before it passes through the joints. That measurement drives a base-rate feedforward and an adaptive (LMS) vibration canceller.
