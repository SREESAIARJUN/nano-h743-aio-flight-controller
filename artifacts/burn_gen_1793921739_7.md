## 0. Assumptions and Architecture

| Item | Assumption |
|---|---|
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class), one MCU per axis or one for all three |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), wye, high-R winding |
| Encoder | 14-bit magnetic absolute (AS5048A / MT6701), SPI |
| IMU A | ICM-42688-P on the camera plate (primary attitude/rate) |
| IMU B | ICM-42688-P on the base/handle (vibration reference + base-motion feedforward) |
| PWM | 20 kHz center-aligned, 3-phase, low-side shunt current sensing |

### Loop rates and bandwidths

| Loop | Rate | Target bandwidth | Feedback |
|---|---|---|---|
| Current (d/q PI) | 20 kHz | ~1.5–2 kHz | Shunts |
| Encoder PLL | 20 kHz | ~300 Hz | Encoder |
| Rate (velocity PI) | 4 kHz | ~40–80 Hz | IMU A gyro (projected to joint axis) |
| Angle (P + FF) | 1 kHz | ~8–15 Hz | Fused attitude (IMU A) |
| IMU sampling | 8 kHz ODR | – | FIFO / DRDY |

Rule of thumb: each outer loop runs at ≥4× slower bandwidth than the loop it wraps. Each loop's sample rate is ≥20× its bandwidth.
