## 0. Assumptions and Feasibility Check

The H743 does not commutate the motors directly. In this architecture it runs ArduPilot and sends bidirectional DShot600 to four ESC MCUs (AT32F421 or STM32G071 class running AM32 or BLHeli_32). Those MCUs generate the 48 kHz PWM. All power-stage maths below apply per ESC channel.

| Parameter | Value used | Note |
|---|---|---|
| Supply | 6S, 25.2 V max (worst case), 22.2 V nominal | |
| Burst current | 80 A per motor phase current, all 4 motors | Worst case |
| PWM | 48 kHz, complementary (synchronous), 6-step trapezoidal | |
| MOSFET | 40 V, PDFN 5×6, R_DS(on) = 1.2 mΩ typical at 25 °C | |
| Gate charge and capacitance | Q_g ≈ 60 nC, Q_rr ≈ 40 nC, C_oss,eff ≈ 1.5 nF | |
| R_DS(on) temperature factor | k_T ≈ 1.5 at T_j ≈ 110 °C | |
| Gate driver | FD6288Q-class 3-phase bootstrap driver | |
| Effective V–I overlap time | t_r + t_f ≈ 50 ns | |
| Dead time | 100 ns per edge | |

These are representative values. Substitute your selected FET's datasheet values; every equation is parametric.

**Feasibility.** As the numbers below show, 4 × 80 A on a 20×20 or 25.5×25.5 mm board is a **burst-only rating of roughly 1–2 s**. It is not a continuous rating. Sustained 80 A per motor requires two parallel FETs per switch, a 30.5×30.5 mm footprint, and a heatsink. Any marketing claim for this board should be qualified accordingly.
