# STM32H743 AIO Nano FC + 4-in-1 ESC: Power-Stage Model, Bidirectional DShot600 Timer/DMA Plan, and Reference Netlist

## 0. Scope and Assumptions

No datasheet set or board stack-up was supplied for "Job #79", so this model uses **representative, parameterized values**. Every equation is written so you can substitute real datasheet numbers.

**Architectural correction (important):** ArduPilot does not run ESC commutation on the flight controller MCU. A production "H743 4-in-1 AIO" therefore uses:

- **FC side:** STM32H743 running ArduPilot. It sends 4× bidirectional DShot600 and receives eRPM telemetry.
- **ESC side:** 4× small MCUs running AM32 or BLHeli_32-class firmware, for example AT32F421 or STM32G071. One MCU per motor generates the 48 kHz complementary PWM.

The 48 kHz switching frequency is an ESC firmware setting. It is unrelated to the H743's DShot timers. The two halves are modeled separately below.

|---|---|---|

| Burst phase current per motor | I | 80 A |
