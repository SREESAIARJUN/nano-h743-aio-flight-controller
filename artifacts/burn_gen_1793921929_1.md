## 1. FOC Core Equations

### 1.1 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.2 Park transform

Electrical angle θ_e = p·θ_m − θ_offset.

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.3 Machine model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

Torque is τ = (3/2)·p·λ_m·i_q = K_t·i_q (surface PMSM, so L_d = L_q).

### 1.4 SVPWM (min-max zero-sequence injection)

This method is equivalent to classical 7-segment SVPWM.

1. Compute the inverse Clarke transform:
$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
2. Compute the common-mode offset:
$$v_0 = -\tfrac12(\max + \min)$$
3. Compute the duty cycles:
$$d_x = \tfrac12 + (v_x+v_0)/V_{bus}$$

The linear range is |v_αβ| ≤ V_bus/√3.

### 1.5 Current PI design (pole-zero cancellation)

The plant is G(s) = 1/(Ls + R). With

$$K_p = L\,\omega_{c},\qquad K_i = R\,\omega_{c}$$

the closed loop becomes first order: i/i* = ω_c/(s+ω_c).

- Choose ω_c ≤ 2π·f_s/20. At f_s = 20 kHz, this gives ω_c ≈ 2π·1 kHz.
- Decoupling feedforward:
$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m)$$

**Voltage-mode alternative.** High-R gimbal motors often lack usable current sensing. In that case, set v_q = R·i_q* + ω_e·λ_m and skip the inner loop. The code supports this via `kVoltageMode`.

### 1.6 Discrete PI with back-calculation anti-windup

$$\begin{aligned}
e_k &= r_k - y_k\\
u_k &= K_p e_k + I_k + u^{ff}_k\\
\bar u_k &= \mathrm{sat}(u_k)\\
I_{k+1} &= I_k + T_s\left[K_i e_k + K_{aw}(\bar u_k - u_k)\right]
\end{aligned}$$

Use K_aw ≈ K_i/K_p, i.e. the inverse of the integral time constant.

For the dq voltage vector, saturation is applied jointly. The d-axis gets priority, and the q-axis receives the remaining voltage:

$$v_q^{max}=\sqrt{V_{max}^2 - v_d^2}$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Velocity estimation (encoder PLL)

Raw encoder differencing at 4 kHz with 14 bits is very noisy (quantization of 2π/16384 / 250 µs ≈ 1.5 rad/s). A type-2 PLL observer solves this:

$$\begin{aligned}
e_k &= \mathrm{wrap}_{\pi}(\theta^{meas}_k - \hat\theta_k)\\
\hat\theta_{k+1} &= \hat\theta_k + T_s(\hat\omega_k + k_p e_k)\\
\hat\omega_{k+1} &= \hat\omega_k + T_s k_i e_k
\end{aligned}$$

Gains: k_p = 2ζω_n and k_i = ω_n². Use ζ = 1 and ω_n ≈ 2π·[300 Hz], which must be at least 3× the velocity-loop bandwidth.
