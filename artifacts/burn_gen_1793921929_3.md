# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for "Job #0", so this design rests on the assumptions in §0. Every parameter that depends on them is a `constexpr`, so you can retarget the design by editing constants.

---

## 0. Assumptions and Loop Architecture

| Item | Assumption |
|---|---|
| MCU | STM32G474 / H7 class, single-precision FPU (the G4 also has CORDIC for sin/cos) |
| Motors | Gimbal BLDC, e.g. GBM2804 / 12N14P (7 pole pairs). R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701), one per axis |
| Current sensing | Low-side shunts on 2 phases, sampled at the PWM valley |
| IMUs | 2 × ICM-42688-P on the camera plate on separate SPI buses, both driven by a shared CLKIN |
| Gimbal order | Yaw (pan) → Roll → Pitch (tilt), base to camera |

Control loops (each rate is a decimated sub-multiple of the one above):

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC, PI) | 20 kHz | ~1.5–2 kHz |
| Velocity (PI + cogging FF + base-rate FF) | 4 kHz | ~150–250 Hz |
| Angle (P + rate FF) | 1 kHz | ~20–40 Hz |
| IMU ingest + filters | 8 kHz ODR | — |
| Attitude estimator (Mahony on SO(3)) | 1 kHz | — |

The design rule is a separation factor of at least 5–10× between nested loop bandwidths:

$$\omega_{c,i} \ge 5\,\omega_{c,v} \ge 25\,\omega_{c,\theta}$$

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

The electrical angle is θₑ = p·(θₘ − θ_offset), where p is the number of pole pairs.

**Clarke transform**, assuming i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau = \tfrac32\, p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.3 PI with Decoupling and Back-EMF Feedforward

$$v_{d}^* = PI_d(i_d^*-i_d) - \hat\omega_e \hat L i_q$$

$$v_{q}^* = PI_q(i_q^*-i_q) + \hat\omega_e \hat L i_d + \hat\omega_e\hat\lambda_m$$

**Pole-zero cancellation tuning.** Choose the PI zero to cancel the electrical pole:

$$K_p = \hat L\,\omega_{c,i},\qquad K_i = \hat R\,\omega_{c,i}$$

With these gains the closed loop becomes first-order:

$$\frac{i}{i^*}= \frac{\omega_{c,i}}{s+\omega_{c,i}}$$
