## 0. Assumptions and Architecture

| Item | Assumption |
|---|---|
| MCU | STM32G474 / H7 class with FPU, single-precision `float` |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), inline phase-current sensing on 2 phases |
| Encoder | 14-bit absolute magnetic encoder (MT6701/AS5048A) on each joint |
| IMU-A | ICM-42688-P on the **camera payload**. It provides inertial feedback. |
| IMU-B | ICM-42688-P on the **gimbal base/handle**. It provides the base-motion feedforward and the vibration reference. |
| PWM | 20 kHz center-aligned. ADC is triggered at the counter peak. |
| Loop rates | Current 20 kHz · Rate (velocity) 4 kHz · Attitude (angle) 1 kHz · IMU ODR 8 kHz |

**Signal flow per axis:**

```
            ┌────────── Attitude loop 1 kHz ─────────┐ ┌──── Rate loop 4 kHz ────┐ ┌─ Current loop 20 kHz ─┐
q_ref ──► [quat err] ─► P(+I) ─► ω_ref ─(+)─► PI ─(+)─► i_q* ─► PI_dq + decoupling ─► SVPWM ─► motor
                                    ▲  ▲      ▲      ▲ i_q,cog (anti-cogging FF, from θ_m)
                         base-rate FF  │      │
                       (IMU-B)         │      └── ω_fb = payload gyro (IMU-A, filtered) projected on joint axis
q̂ (Mahony, IMU-A filtered) ◄───────────┘
θ_m (encoder) ─► PLL ─► θ_e for Park, ω_m for cogging adaptation
```
