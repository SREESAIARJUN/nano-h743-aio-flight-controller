## 0. Architecture and Assumptions

### 0.1 Architecture correction

The STM32H743 should **not** drive the power stage directly. ArduPilot is flight-control firmware. It does not commutate motors and has no FOC or 6-step ESC loop. The only workable partition is:

```
STM32H743 (ArduPilot) ──bidir DShot600 x4──► 4x ESC MCU (AM32 / BLHeli_32-class, e.g. STM32G071 / AT32F421)
                                              └─► 3-phase gate driver ──► 6x N-FET per motor (24 total)
```

The 48 kHz figure is therefore the **ESC MCU's PWM frequency**. The H743's job is DShot timing, DMA, and telemetry decoding.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At the design point T_j = 100 °C:

$$R_{ds} = 1.0 \times 1.375 = 1.375\ \text{m}\Omega$$

### 1.2 Six-step commutation with complementary PWM

In any commutation sector, three FETs carry current:

- the switching high side, for a fraction D of each period;
- its synchronous low side, for 1 − D;
- the return-phase low side, continuously.

So the conduction loss per motor is:

$$P_{cond,ESC} = I^2 R_{ds}\,[D + (1-D) + 1] = 2\,I^2 R_{ds}$$

This result is independent of D.

$$P_{cond,ESC} = 2 \times 80^2 \times 1.375\times10^{-3} = \mathbf{17.6\ W}$$

### 1.3 Per-FET share

Each FET is active in 1/3 of the electrical cycle:

$$P_{HS} = \tfrac{1}{3}I^2R\,D \qquad P_{LS} = \tfrac{1}{3}I^2R\,(1-D) + \tfrac{1}{3}I^2R$$

At D = 0.9:

- P_HS = 2.64 W
- P_LS = 3.23 W (low-side FETs are the hot spot)

### 1.4 Sinusoidal FOC comparison

For sinusoidal drive, with peak current Î = 80 A:

$$P_{cond} = 3\left(\tfrac{\hat I}{\sqrt2}\right)^2 R_{ds} = 1.5\,\hat I^2 R_{ds} = 13.2\ \text{W}$$

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate currents and transition times

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{drv,src}+R_{g,ext}+R_{g,int}} = \frac{6.5}{5.2} = 1.25\ \text{A}$$

$$I_{g,off} = \frac{V_{pl}}{R_{drv,snk}+R_{g,ext}+R_{g,int}} = \frac{3.5}{4.2} = 0.83\ \text{A}$$

$$t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = 6.4\ \text{ns} \qquad t_{off} = \frac{Q_{gs2}+Q_{gd}}{I_{g,off}} = 9.6\ \text{ns}$$

### 2.2 Loss components

Values are per motor, using a single hard-switched leg (6-step).

| Term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_on + t_off)·f_sw | 0.77 W |
| Reverse recovery | V·Q_rr·f_sw | 0.06 W |
| C_oss (HS + LS) | 2 × ½·C_oss·V²·f_sw | 0.02 W |
| Dead-time diode conduction | 2·V_f·I·t_dt·f_sw | 0.61 W |
| Gate drive (mostly dissipated in R_g and driver) | 2·Q_g·V_drv·f_sw | 0.03 W |
| **Total switching-related, P_sw,ESC** | | **≈ 1.5 W** |

### 2.3 Design note

At 48 kHz the switching losses are only about 8% of the conduction losses. The burst is limited by R_ds(on), not by f_sw.
