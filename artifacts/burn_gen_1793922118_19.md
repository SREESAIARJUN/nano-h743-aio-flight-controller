# STM32H743 AIO Nano Flight Controller + 4-in-1 ESC: Power-Stage Loss Model, Thermal Budget, and ArduPilot BDShot600 Timer/DMA Plan

**Document:** Job #46, Rev A (design baseline)
**Scope:** 4× 3-phase bridges (24 MOSFETs), 6S input, 80 A per-channel burst, 48 kHz PWM, ArduPilot bi-directional DShot600.

---

## 0. Architecture Corrections and Feasibility Flags

Several requirements conflict with physics or common practice. The rest of this document is built around these points.

| # | Issue | Resolution |
|---|---|---|
| 1 | The H743 does not drive the bridges directly. 48 kHz center-aligned 6-step PWM with back-EMF zero-cross sensing for 4 motors is done by dedicated ESC MCUs. | Use 4× AT32F421 or STM32G071 running AM32. The H743 runs ArduPilot and emits DShot600 to them. The 48 kHz figure is an ESC-MCU parameter (AM32 `PWM_FREQ`). |
| 2 | **80 A per channel on a 20×20 mm board is a transient rating only.** The model below shows roughly 130 W of total dissipation, with about 2–3 s to the thermal limit. | Specify the rating as "80 A / 2 s burst, 35 A continuous with airflow." Firmware current limiting is mandatory. |
| 3 | H743 package choice on a nano board. LQFP100 (14×14 mm) leaves almost no room on 20×20. | Use TFBGA100 (8×8 mm), or split into a stacked FC + ESC board pair. |
| 4 | DShot DMA buffers on the H7. | They must live in D2/AXI SRAM. DTCM is not DMA-reachable. ArduPilot handles this automatically. |

## 2. Conduction Loss Model

### 2.1 Current path in 6-step with synchronous complementary PWM

In each 60° sector, phase A is "high" (PWM'd) and phase B is "low" (fully on):

- **During the on-time (D):** current flows through Q_AH → motor → Q_BL.
- **During the off-time (1−D):** current flows through Q_AL (synchronous rectification) → motor → Q_BL.

The instantaneous conduction loss within a sector is therefore:

P_sector = I²R·D + I²R·(1−D) + I²R = **2·I²·R_DS**

This is independent of duty cycle. That is the key result: conduction loss scales only with current squared.

Ripple correction (motor inductance L ≈ 5–15 µH):

- ΔI = V_bus·D(1−D) / (L·f_sw)
- I_rms² = I² + ΔI²/12

With L = 10 µH and D = 0.5: ΔI ≈ 13 A, which adds only about 0.2% to the loss. Ripple is negligible at 80 A.

### 2.2 Per-FET average over one electrical cycle

Each leg spends 120° high, 120° low, and 2× 60° floating. Averaging gives:

- **High-side FET:** P_HS = (1/3)·D·I²R
- **Low-side FET:** P_LS = (1/3)·(1−D)·I²R + (1/3)·I²R

At the full-throttle burst (D → 1):

- P_HS = P_LS = I²R/3 = 6400
