# STM32H743 AIO Nano FC + 4-in-1 ESC: 80 A Burst Power-Stage and Bidirectional DShot600 Design Package (Job #16)

## 0. Scope and Assumptions

**Architecture.** ArduPilot does not commutate motors. The H743 is the flight controller. Each motor channel has its own ESC MCU (AT32F421 running AM32) doing 6-step complementary PWM at 48 kHz. The H743 talks to the ESCs over bidirectional DShot600. All "48 kHz switching" losses below therefore belong to the ESC power stage, not the H743.

**Parameters.** No MOSFET or layout was specified, so the values below are the design baseline. Every formula is parametric, so you can substitute datasheet values.

| Symbol | Value | Note |
|---|---|---|
| V_bus | 25.2 V | 6S full charge |
| I_burst | 80 A per motor | Phase/bus current at near-full duty |
| f_sw | 48 kHz | AM32 complementary PWM |
| MOSFET | 40 V N-ch, PDFN 3.3×3.3, 24 total | 5×6 parts will not fit 24× on a 20×20 board |
| R_ds(on),25 | 1.2 mΩ (max) | Aggressive for 3.3×3.3 |
| α (R_ds tempco) | 0.005 /K | Gives about 1.5× at 125 °C |
| Q_g / Q_gs2 / Q_gd | 50 / 4 / 8 nC | |
| Q_rr, C_oss(eff) | 40 nC, 1.5 nF | |
| R_θJC | 1.5 K/W | |
| Gate drive | 10 V, R_g,total = 5 Ω, V_plateau = 3 V | |
| Dead time t_dt | 100 ns | |
| V_f (body diode) | 0.8 V | |

**Reality check up front.** "80 A burst" on a nano-format 4-in-1 is a **sub-2-second** rating. It cannot be a continuous rating. Section 2 proves this.
