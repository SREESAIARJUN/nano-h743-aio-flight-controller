# Job #25: STM32H743 Nano AIO (FC + 4-in-1 ESC) System Architecture Model

## 0. Scope, Assumptions, and Design-Review Flags

### 0.1 Architectural Clarification

The STM32H743 is the **flight controller**. It does not commutate the bridges. Each ESC channel has its own MCU that generates the 48 kHz PWM and decodes DShot:

- **ESC MCU options:** AT32F421 (AM32) or STM32G071 / EFM8 (BLHeli_32, Bluejay).
- **Link:** the H743 talks to each ESC MCU over bidirectional DShot600.

The model is therefore split into three domains:

| Domain | Owner | Key model |
|---|---|---|
| Power stage (losses, thermal) | ESC MCU + gate driver + 24 MOSFETs | §1 to §4 |
| FC ↔ ESC link (BDShot600) | STM32H743 timers/DMA, ArduPilot | §5 |
| Hardware netlist | Whole board | §6 |
