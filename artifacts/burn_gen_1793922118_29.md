# STM32H743 Nano FC + 4-in-1 ESC (Job #20): Power-Stage, Thermal and Bi-Directional DShot Design Package

## 0. Architecture Assumptions

**Architectural decision.** The STM32H743 does not commutate the motors. In an ArduPilot system the H743 is the flight controller. It sends bi-directional DShot600 to four per-motor ESC MCUs (AM32 or BLHeli_32 class, for example STM32G071 or AT32F421). Each ESC MCU drives a 3-phase gate driver and 6 MOSFETs. Running six-step commutation for 4 motors directly from the H743 is not supported by ArduPilot. It would also violate the main-loop timing model, so this package assumes the split architecture.

**Parameter basis.** Values marked **[A]** are design assumptions. Before layout freeze, replace them with the selected MOSFET's datasheet values. All equations are kept symbolic so the numbers can be recomputed.

**Feasibility flag (read first).** "80 A burst" can only mean per motor, non-simultaneous, and short. Four motors at 80 A with throttle near 100 % draws roughly 320 A from the battery. That exceeds any XT60/XT90 connector, 6S nano-class pack, or practical current shunt. The model below shows what is physically achievable.

## 1. Conduction Loss Model

### 1.1 Six-step synchronous commutation

Six-step commutation with complementary (synchronous) PWM is assumed. At any instant, exactly one high-side and one low-side path carry the phase current. During the PWM off-time, the complementary FET of the PWM'd leg carries the freewheel current. The effective path is therefore always 2 × R_ds, independent of duty cycle.

$$P_{cond,motor} = I_{ph}^2 \cdot 2 R_{ds}(T_j), \qquad R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$
