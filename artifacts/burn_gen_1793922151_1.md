# Job #48: STM32H743 Nano FC + 4-in-1 ESC (80 A Burst, 48 kHz, Bi-Dir DShot600)

## 0. Architecture Assumptions

There is no project baseline on file for Job #48. All numbers below rest on the stated assumptions, so substitute your actual BOM values into the equations.

| Item | Assumption |
|---|---|
| Topology | H743 runs ArduPilot on the FC side. Each ESC channel has its own MCU (AT32F421 / STM32G071 running AM32). The H743 does **not** commutate the motors; it sends DShot and receives eRPM telemetry. |
| Form factor | 20×20 mm mounting pattern, ~26×26 mm board, 8 layers, 2 oz copper |
| Bus | 6S, V_bus = 25.2 V (full charge, worst case for switching loss) |
| MOSFET (24 total) | 40 V, 3.3×3.3 DFN, R_ds(on),25 = 1.3 mΩ @ 10 V, Q_g = 35 nC, Q_gs2+Q_gd ≈ 9 nC, Q_rr = 30 nC, Q_oss = 40 nC, R_θJC = 1.2 K/W |
| Gate driver | FD6288Q-class 3-phase driver, 10 V drive, R_g,ext = 2.2 Ω, dead time 100 ns |
| Modulation | 6-step trapezoidal, complementary (synchronous) PWM on the active high leg, f_sw = 48 kHz |
| Burst condition | 80 A per motor, D = 0.95, T_j = 125 °C assumed for R_ds |

> **Engineering flag:** 80 A per motor on a ~26 mm board is only achievable as a short burst lasting about 1–2 seconds. Section 3 quantifies this. Market the board as "80 A burst / ~35 A continuous," not 80 A continuous.
