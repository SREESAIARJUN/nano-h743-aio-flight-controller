# STM32H743 AIO Flight Controller + 80 A 4-in-1 ESC: Architecture Package (Job #11)

## 0. Architecture Clarification and Design Basis

**The STM32H743 cannot be the ESC commutation processor.** Conventional 4-in-1 ESCs run one small MCU per channel. Each ESC MCU (STM32G071, AT32F421 or similar, running AM32) handles commutation at 48 kHz. The H743 is the flight controller. It runs ArduPilot and talks to the four ESC MCUs over bidirectional DShot600. The models below follow that partition.

### Design basis

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal | Worst case uses 25.2 V |
| Burst current | 80 A per channel | Duration derived in §3; it is **not** unlimited |
| PWM frequency | 48 kHz, complementary (synchronous rectification) | Set in the AM32 configuration |
| Form factor | 30.5 × 30.5 mm ESC board plus 30.5 × 30.5 mm FC board | "Nano" is interpreted as a 30.5 mm stack |
| Gate drive | 10 V class | Integrated 3-phase driver |
