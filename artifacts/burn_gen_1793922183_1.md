# STM32H743 FC + 4-in-1 ESC (Job #51): Power, Thermal and Bi-Directional DShot Design Model

## 0. Scope and Assumptions

No MOSFET part number, board outline, or burst duration was specified, so I state assumptions explicitly. Every equation is parametric: substitute real datasheet values before committing to layout.

**Architecture clarification.** ArduPilot on the H743 never drives the bridge. The 4-in-1 ESC runs its own firmware (AM32 or BLHeli_32 on per-channel MCUs). That firmware owns the 48 kHz PWM, dead-time and commutation. The H743 only sends DShot600 frames and receives eRPM telemetry. The model therefore splits into an ESC power stage (Sections 1–3) and an FC timing/DMA layer (Section 4).

## 1. Conduction-Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,\big[1 + \alpha\,(T_j - 25)\big],\quad \alpha \approx 0.0045\text{–}0.006\ \text{K}^{-1}$$

At T_j = 110 °C with α = 0.0053:

R_ds ≈ 1.0 × 1.45 = **1.45 mΩ**

### 1.2 Six-step (trapezoidal) commutation, synchronous rectification

In any commutation sector two phase legs carry current:

- **PWM leg:** the high-side conducts for D, and the low-side synchronously rectifies for (1−D). Losses = D·I²R + (1−D)·I²R = I²R, independent of duty.
- **Return leg:** the low-side is on for the whole sector, contributing I²R.

$$P_{cond,ch} = 2\,I_{rms}^2\,R_{ds}(T_j), \qquad I_{rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12}$$

The ripple term ΔI_pp is small at 48 kHz with typical motor inductance (tens of µH), so it is neglected below:

$$P_{cond,ch} = 2 \times 80^2 \times 1.45\,\text{m}\Omega = \mathbf{18.6\ W\ per\ channel}$$

With FOC/sinusoidal drive, use P = 3·I_rms,phase²·R_ds with I_rms = I_peak/√2. The result is of similar magnitude at equal torque.

### 1.3 Electro-thermal fixed point

Because R_ds depends on T_j, iterate until T_j and P_cond agree:

$$T_j^{(k+1)} = T_a + P\big(T_j^{(k)}\big)\cdot R_{\theta JA}$$

The loop converges if P'(T)·R_θJA < 1, i.e. 2I²R₂₅α·R_θJA < 1. At 80 A with poor heatsinking (R_θJA per channel > ~1.5 K/W), **this inequality fails and thermal runaway is possible**. This is the first red flag for a nano-format 80 A design.

## 2. Switching-Loss Model (48 kHz)

Only the PWM leg hard-switches; the low-side turns on after its body diode is already conducting (soft switching).
