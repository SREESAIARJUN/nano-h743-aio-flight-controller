## 0. Architecture Correction (Read First)

The request implies the STM32H743 drives the motors directly. **That architecture is not viable**, for three reasons:

1. **Not enough complementary PWM.** The H743 has two advanced timers (TIM1, TIM8), each with 3 complementary pairs, so only **2 motors**. HRTIM adds 10 outputs. Four 3-phase bridges need 24 gate signals with dead-time insertion.
2. **ArduPilot does not commutate motors.** It outputs DShot to ESCs. There is no in-tree firmware path for running 6-step or FOC on four motors.
3. **Bidirectional DShot implies separate ESC MCUs.** BDShot is a protocol *between* an FC and an ESC. If the H743 drove the FETs, there would be nothing to talk to.

**Adopted architecture (industry standard, e.g., AIO/stack designs):**

```
                     ┌──────────────────────────────────────┐
  6S LiPo ──┬──────► │  4-in-1 ESC board (25.5×25.5, 20×20 M2) │
            │        │  4× AT32F421 (AM32, 48 kHz PWM)        │
            │        │  4× FD6288Q 3-ph gate driver           │
            │        │  24× 40 V N-MOSFET (PQFN 3.3×3.3)       │
            │        └───────▲──────────────────┬────────────┘
            │      BDShot600 │ (4 lines)        │ VBAT, CURR, GND
            │                │                  ▼
            │        ┌───────┴──────────────────────────────┐
            └──────► │  FC board: STM32H743VIT6 @ 400 MHz    │
                     │  ArduPilot, ICM-42688-P, DPS310, etc. │
                     └──────────────────────────────────────┘
```

The stack can be two boards, or a single "AIO" PCB with the same partitioning. The math below applies to either.

## 2. Conduction Loss Model

### 2.1 Current path in 6-step synchronous commutation

During any 60° sector, phase A is the PWM'd leg and phase B is held low. The current path depends on PWM state:

- **ON (duty D):** HS_A → motor → LS_B
- **OFF (1−D):** LS_A (synchronous rectification) → motor → LS_B

So the current always flows through exactly **two FETs in series**, regardless of duty cycle:

$$
P_{cond} = I_{rms}^2 \left[ D\,R_{HS} + (1-D)\,R_{LS_A} + R_{LS_B} \right] \;\approx\; 2\,I_{rms}^2\,R_{DS}(T_J)
$$

### 2.2 Temperature dependence

$$
R_{DS}(T_J) = R_{25}\,[1 + \alpha (T_J - 25)]
$$

At T_J = 110 °C:

$$
R_{DS} = 1.4\,\text{m}\Omega \times (1 + 0.005 \times 85) = 1.995 \approx 2.0\ \text{m}\Omega
$$

### 2.3 Ripple contribution

Phase inductance for typical 5" motors is L_ph ≈ 15–40 µH line-to-line. Take L = 20 µH ⚠ and worst-case D = 0.5:

$$
\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L\,f_{sw}} = \frac{25.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 6.56\ \text{A}
$$

$$
I_{rms} = \sqrt{I^2 + \frac{\Delta I^2}{12}} = \sqrt{6400 + 3.59} = 80.02\ \text{A}
$$

The ripple is negligible at 48 kHz. **This is the main benefit of 48 kHz over 24 kHz** (ripple halves).

### 2.4 Result

$$
P_{cond} = 2 \times 80^2 \times 2.0\,\text{m}\Omega = \mathbf{25.6\ W\ per\ motor}\quad(12.8\ \text{W per conducting FET})
$$

Add PCB copper: a phase-pad-to-bus path of ~0.3 mΩ at 2 oz (see §4.4) gives 80² × 0.3 m ≈ **1.9 W per motor**, dissipated in the board.
