## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s≈5\,\Omega$, $L_s≈1.5\,$mH, $K_t≈0.08\,$Nm/A |
| Encoder | 14-bit magnetic (AS5048A/MT6835 class), used for commutation only |
| MCU | Cortex-M4F/M7 with FPU (e.g., STM32G474 @ 170 MHz), center-aligned PWM at 20 kHz |
| Bus | $V_{dc}=12$ V, inline shunt current sensing on 2–3 phases |
| IMUs | 2× ICM-42688-P on the camera plate (IMU A and IMU B), on separate SPI buses, ODR 8 kHz |

Loop rates follow a 5–10× bandwidth separation rule:

```
 20 kHz  ISR (ADC-triggered):  Current loop (id/iq PI), SVPWM, cogging FF
  8 kHz  IMU DRDY ISR:         read IMU A/B, align, saturation check
  4 kHz  task:                 notches + LPF, fusion, gyro-rate (velocity) PI
  1 kHz  task:                 Mahony attitude, angle P loop, adaptive notch frequency → filter update
```

**Key gimbal-specific point:** the encoder is used for commutation and the cogging phase reference. The stabilization loops close on the inertial gyro rate and the IMU attitude. That is what rejects base motion.

## 1. FOC Current Loop

### 1.1 Angle and transforms

Electrical angle from the mechanical encoder angle $\theta_m$ and the calibrated offset $\theta_0$:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The **inverse Park transform** uses the transpose of this matrix.
