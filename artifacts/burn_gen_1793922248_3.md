# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #55 hardware specification, so this design uses common gimbal hardware. Every value marked **[A]** is an assumption. Replace it with your real value; the equations and code are parameterized so only constants change.

| Item | Assumed value |
|---|---|
| **[A]** MCU | STM32G4 / H7 class: Cortex-M4F/M7 with single-precision FPU, 170+ MHz |
| **[A]** Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| **[A]** Encoder | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| **[A]** IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, ±2000 dps, ±16 g |
| **[A]** Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates:**

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (FOC) | 20 kHz | 1.5–2 kHz |
| Velocity | 4 kHz | 150–300 Hz |
| Angle / attitude | 1 kHz | 20–40 Hz |
| IMU fusion | 8 kHz, gyro path decimated to 4 kHz | — |

Keep at least a 5–10× bandwidth separation between nested loops.
