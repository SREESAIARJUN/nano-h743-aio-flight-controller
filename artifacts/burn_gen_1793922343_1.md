## 1. Timing Architecture

| Loop | Rate | Trigger |
|---|---|---|
| PWM / current (FOC) | 20 kHz (Tₛ = 50 µs) | ADC end-of-conversion ISR, center-aligned PWM |
| Velocity (rate) loop | 4 kHz | Every 5th current ISR |
| IMU sampling | 8 kHz ODR, FIFO burst read | IMU data-ready interrupt (INT1) → DMA |
| Attitude estimator + angle loop | 1 kHz | Timer |
| Anti-cogging learning | 4 kHz (gated) | Runs inside the velocity loop |

**Bandwidth separation rule:** each outer loop should be 5–10× slower than the loop inside it.

- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·150 rad/s
- Angle loop: ω_p ≈ 2π·20 rad/s

## 2. Field-Oriented Control (Current Loop)

### 2.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

where p is the number of pole pairs (7 for a 14-pole motor) and θ_off is the encoder offset, found by aligning the rotor with d-axis voltage at calibration.

### 2.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

### 2.3 Park transform
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.4 Plant model (surface PMSM, L_d ≈ L_q = L)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 2.5 PI controllers
Gains are set by pole-zero cancellation. This gives a closed loop that behaves as a first-order system with bandwidth ω_c:
$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c\quad\Rightarrow\quad \frac{I(s)}{I^*(s)}=\frac{\omega_c}{s+\omega_c}$$

Each axis adds a decoupling term plus back-EMF feedforward:
$$v_d^* = \mathrm{PI}_d(0 - i_d) - \omega_e L i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Voltage limit.** The available voltage is limited to a circle of radius V_max = V_dc/√3. When saturated, d-axis voltage takes priority:
$$v_q^{max}=\sqrt{V_{max}^2-v_d^{*2}}$$

**Discrete anti-windup (back-calculation), with u_s = sat(u):**
$$I_{k+1} = I_k + T_s\big[K_i e_k + K_{aw}(u_{s,k}-u_k)\big],\qquad K_{aw}\approx K_i/K_p$$

### 2.6 Inverse Park and SVPWM (min-max zero-sequence injection)
First, rotate the voltage command back to the stationary frame:
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Then convert to three phase voltages:
$$v_a=v_\alpha,\quad v_b = -\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

Add the zero-sequence offset and compute duty cycles:
$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically equivalent to 7-segment SVPWM and gives a linear range up to V_dc/√3.
