# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the original specification for Job #4, so this design rests on the assumptions in §0. Every gain is derived symbolically, so you can substitute your real motor and frame parameters.

---

## 0. Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU, CORDIC optional) |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) via SPI |
| Current sense | 2-shunt low-side, sampled at PWM center |
| PWM | 20 kHz center-aligned, SVPWM |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Attitude/angle 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate (SPI, 24 MHz), ODR 8 kHz, gyro ±2000 dps, accel ±16 g |

Loop scheduling:

```
TIM1 update (20 kHz) ──► ADC inj. ──► FOC current loop          [every tick]
                                   ├► encoder PLL + velocity PI [every 5th tick]
                                   └► (flag)                     
IMU DRDY / 8 kHz  ─────► SPI DMA ─► filter bank + fusion         [8 kHz]
Main/RTOS 1 kHz   ─────► attitude estimator ─► angle loop ─► joint-rate cmds
```
