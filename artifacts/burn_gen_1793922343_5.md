# 3-Axis Gimbal Motor Control: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Fusion

I don't have the specification for Job #26, so this design is built on the assumptions below. Each one is a single constant in the code. Replace them with your actual motor, encoder and MCU data before use.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 24N22P (p = 11 pole pairs), R ≈ 5.6 Ω, L ≈ 2.0 mH, Kt ≈ 0.09 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A or MT6701 class) on each axis |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM, synchronous ADC |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (FOC, d/q PI) | 20 kHz (ADC ISR) | ω_c ≈ 2π·1500 rad/s |
| IMU acquisition and filtering | 8 kHz (DRDY → DMA) | none |
| Velocity (inertial rate) | 4 kHz | ω_v ≈ 2π·150 rad/s |
| Angle (attitude) | 1 kHz | ω_θ ≈ 2π·25 rad/s |
