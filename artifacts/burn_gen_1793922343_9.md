# Gimbal FOC Control Loop and Dual-IMU Sensor Fusion (Job #35)

## 0. Design Assumptions

I don't have the Job #35 spec, so these assumptions are explicit. Change the constants in `config.hpp` to match your hardware.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P, so pole pairs p = 7. Typical values: R = 5–12 Ω, L = 1–3 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A or MT6701) on each axis |
| Current sensing | Inline or low-side shunts. A voltage-mode fallback is provided for boards without current sensing |
| IMUs | 2 × ICM-42688-P on the camera plate, read over SPI at 8 kHz ODR |
| MCU | STM32G4/H7-class with an FPU |
| Loop rates | Current 20 kHz → Velocity 4 kHz → Attitude
