## 0. Architecture Assumptions (Read First)

An STM32H743 cannot practically run four sensorless BLDC commutation loops alongside ArduPilot. The architecture below is the one used in production AIO designs:

| Block | Device (candidate; verify availability) | Role |
|---|---|---|
| FC MCU | STM32H743VIH6 (TFBGA100) or VIT6 (LQFP100) | ArduPilot, 400 MHz |
| ESC MCUs | 4× AT32F421K8U7 (QFN32) | AM32 firmware, one per motor |
| Gate drivers | 4× FD6288Q (3-phase, 250 V-class bootstrap) | High-/low-side gate drive |
| Power stage | 24× 40 V N-MOSFET in PDFN3.3×3.3 | 6 per motor |
| Bus caps | Ceramic X7R/X6S array plus external low-ESR electrolytic | Ripple/decoupling |

**Design-envelope warning.** A "nano" footprint (20×20 or 25.5×25.5 mounting, about 35×35 mm board) **cannot sustain 4×80 A**. The analysis below shows that 80 A is a **≈1–1.5 s burst rating** with all four motors loaded, and that continuous current is about 30 A per motor with prop-wash cooling. The firmware current limits in §6 enforce this.

## 2. Conduction Loss Model (80 A Burst)

### 2.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C:

$$R_{ds} = 1.5 \times (1 + 0.0055 \times 85) = 2.20\ \text{m}\Omega$$

### 2.2 Six-step trapezoidal commutation with complementary (synchronous) PWM

During each 60° sector, one high-side and one low-side FET carry the phase current. With complementary PWM, the current alternates between the HS FET and the synchronous LS FET of the same leg, so the conducting path always contains two R_ds(on) in series.

Phase current relates to bus current by I_ph = I_dc / D. At full-throttle burst, D ≈ 1, so I_ph ≈ 80 A.

**Per-motor conduction loss:**

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{ds}(T_j) = 2 \times 80^2 \times 2.20\text{ m}\Omega = 28.2\ \text{W}$$

**Per-FET average.** Each FET conducts for 120° of every 360° electrical:

$$P_{cond,FET} = \tfrac{1}{3}\,I_{ph}^2\,R_{ds} = \tfrac{1}{3}\times 6400 \times 0.0022 = 4.69\ \text{W}$$

Commutation periods are tens to hundreds of µs, far shorter than the die thermal time constant (ms), so the average value governs junction temperature.

### 2.3 Self-consistency check

T_j depends on R_ds, which depends on T_j. Iterate using

$$T_j = T_{board} + P_{FET}\,(R_{\theta JC} + R_{\theta CB})$$

This converges in 2–3 iterations (worked in §4.2).

## 3. Switching Loss Model at 48 kHz

Losses occur in the PWM-switching leg only. The other active leg is static for the 60° sector.

**1. V–I overlap (hard switching):**

$$P_{VI} = \tfrac{1}{2} V_{bus} I_{ph}(t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\text{n} \times 48\text{k} = 0.968\ \text{W}$$

**2. Reverse recovery** (synchronous FET body diode):

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 30\text{n} \times 25.2 \times 48\text{k} = 0.036\ \text{W}$$

**3. Output capacitance:**

$$P_{oss} = \tfrac{1}{2} Q_{oss} V_{bus} f_{sw} = 0.018\ \text{W}$$

**4. Dead-time body-diode conduction** (two edges per cycle):

$$P_{dt} = V_{SD}\,I_{ph}\,(2 t_{dt})\,f_{sw} = 0.8 \times 80 \times 100\text{n} \times 48\text{k} = 0.307\ \text{W}$$

**5. Gate drive** (dissipated in the driver and R_g, not the FET die), per switching FET pair:

$$P_g = 2\,Q_g V_{GS} f_{sw} = 2 \times 40\text{n} \times 10 \times 48\text{k} = 0.038\ \text{W}$$

**Per-motor switching total:**

$$P_{sw,motor} \approx 0.968 + 0.036 + 0.018 + 0.307 = 1.33\ \text{W}$$
