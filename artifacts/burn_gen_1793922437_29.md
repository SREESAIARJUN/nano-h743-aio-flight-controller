## 0. Design Basis and a Feasibility Warning

The model is parametric, so you can substitute vendor datasheet values when parts are locked. The figures below are the baseline assumptions.

| Parameter | Symbol | Value | Note |
|---|---|---|---|
| Battery | V_bus | 6S, 25.2 V max / 22.2 V nom | Worst case uses 25.2 V |
| Burst phase current per motor | I_ph | 80 A | DC-equivalent during the 120° conduction interval |
| PWM frequency | f_sw | 48 kHz | Center-aligned, complementary (synchronous rectification) |
| Commutation | — | 6-step trapezoidal (AM32 / BLHeli_32 class) | Two legs active at any instant |
| ESC MCU (per channel) | — | STM32G071 / AT32F421 class running AM32 | The H743 is the **flight controller**, not the ESC MCU |
| Gate driver | — | 3-phase bootstrap driver (FD6288Q class), V_DRV = 10–12 V | |
| MOSFET (reference) | — | 40 V, R_DS(on) ≈ 1.0 mΩ @ 25 °C, 10 V gate, 5×6 PQFN | Example class: BSC010N04LS6-type. Verify the datasheet |
| Board | — | 30.5×30.5 mm mounting (≈36×36 outline), 8-layer, 2 oz all layers | |

> ⚠️ **Feasibility flag.** Four motors at 80 A on 6S means 320 A of battery current, about 7–8 kW. A nano-format board cannot carry that continuously. The PCB copper, battery pads, XT-class connector, and shunt are all limiting before the FETs are. This document treats 80 A strictly as a **transient burst**. Section 2.6 derives the time limit. If "nano" means a 20×20 board, the 80 A rating is not credible, and you should down-rate to roughly 35–45 A burst.

## 1. Power-Loss Model per Motor Channel

### 1.1 Current paths in 6-step synchronous PWM

During each 60° sector, one leg is PWM-switched (HS for duty D, LS synchronous for 1−D) and one leg's LS is held ON. Current therefore always flows through **exactly two FETs in series**:

- **PWM leg:** HS conducts for D·T, and LS conducts for (1−D)·T (minus dead time, when the body diode conducts instead).
- **Static leg:** LS conducts for the full T.

### 1.2 Conduction loss

With temperature-dependent R_DS(on):

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha\,(T_j-25)],\qquad \alpha\approx 0.0055\ /\mathrm{K}\ (\text{gives } \approx1.6\times \text{ at } 125^\circ\mathrm{C})$$

$$P_{cond} = I_{ph}^2 R_{DS}(T_j)\,\big[D + (1-D-2t_{dt}f_{sw})\big] + I_{ph}^2R_{DS}(T_j)\cdot 1 \;\approx\; 2\,I_{ph}^2 R_{DS}(T_j)$$

At T_j = 125 °C (R_DS = 1.6 mΩ):

$$P_{cond} = 2 \times 80^2 \times 1.6\times10^{-3} = \mathbf{20.5\ W}$$

The per-FET split is the static LS at about 10.2 W, with the PWM-leg HS+LS sharing about 10.2 W according to D.

**PCB copper loss.** Phase plus bus path is about 0.4–0.6 mΩ on 8L/2 oz. Taking 0.5 mΩ:

$$P_{Cu} = 80^2 \times 0.5\,\text{m}\Omega = \mathbf{3.2\ W}$$
