# STM32H743 AIO Flight Controller + 4-in-1 ESC: Engineering Model

## 0. Assumptions and Architecture

I don't have a stored spec for "Job #5," so every input below is stated explicitly. Swap in your real datasheet values and the equations carry through unchanged.

**Architecture.** The STM32H743 does **not** commutate the FETs. In every production AIO and 4-in-1 design, it runs ArduPilot and sends bidirectional DShot600 to four dedicated ESC MCUs (for example AT32F421 or STM32G071 running AM32 or BLHeli_32). Those ESC MCUs generate the 48 kHz PWM. This document models both domains on that basis.

| Parameter | Value (assumed) |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max, 22.2 V nominal |
| Burst phase current | I = 80 A per motor (all 4 motors, worst case) |
| MOSFET | 40 V N-ch, PDFN 3.3×3.3 or 5×6, R_DS(on) = 1.2 mΩ at 25 °C, V_GS = 10 V |
| R_DS(on) temperature coefficient | ×1.5 at T_j = 125 °C, so 1.8 mΩ |
| Switching times | t_r = t_f = 20 ns at 80 A (gate-driver limited) |
| Q_g / Q_rr / C_oss(eff) | 50 nC / 50 nC / 1 nF |
| Body diode V_f | 0.8 V at 80 A |
| Dead time | t_dt = 50 ns |
| Modulation | 6-step trapezoidal, complementary (synchronous) PWM, f_sw = 48 kHz |
| Board | 30.5×30.5 mm, 8-layer, 2 oz outer copper |

> ⚠️ **Feasibility flag.** "Nano" (20×20 or 25.5×25.5 mm) combined with 4×80 A is **burst-only** territory. The math below shows the board cannot sustain this thermally. It survives only for seconds. Any "80 A" label must carry a duration qualifier.

## 1. Conduction Loss Model

### 1.1 Base equations
In 6-step operation with synchronous rectification, exactly one high-side and one low-side FET carry the phase current at every instant. Dead-time diode intervals are handled in §2.

Temperature-dependent resistance:

$$R_{DS}(T_j) = R_{DS,25}\,\big[1 + \alpha\,(T_j - 25)\big],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

Per-motor conduction loss:

$$P_{cond,motor} = 2\,I^2\,R_{DS}(T_j)$$

Per-FET average (120° conduction, so 1/3 duty per device):

$$P_{cond,FET} = \frac{I^2 R_{DS}(T_j)}{3}\cdot 2 \cdot \tfrac{1}{2}= \frac{I^2 R_{DS}(T_j)}{3}$$

The high-side FET within its 120° window carries current during PWM on-time (D). The complementary low-side carries it during off-time (1−D). Summed over each half-bridge's pair this is still I²R. The 1/3 expression above is the worst-case upper bound used for sizing.

### 1.2 Numbers at 80 A, T_j = 125 °C

| Quantity | Result |
|---|---|
| I² | 6400 A² |
| P_cond per FET (avg) | 6400 × 1.8 mΩ / 3 = **3.84 W** |
| P_cond per motor | 2 × 6400 × 1.8 mΩ = **23.0 W** |
| P_cond, 4 motors | **92.2 W** |

### 1.3 Copper (PCB) conduction loss
The phase path runs from the battery pad, through the bus, the FET, and the phase pad. Assume 0.25 mΩ of effective copper per motor path:

$$P_{Cu} = I^2 R_{Cu} = 6400 \times 0.25\text{ mΩ} = 1.6\text{ W per motor} \;\Rightarrow\; 6.4\text{ W total}$$

Battery-side current is **not** 4×80 A. It is approximately:

$$I_{batt} \approx \sum_k D_k\,I_{phase,k} \quad \text{(e.g. } D = 0.8 \Rightarrow 256\text{ A)}$$

This still means XT60 and pad current far beyond rating, which is another reason 80 A is a burst figure.

## 2. Switching Loss Model at 48 kHz

Only the PWM-modulated high-side FET hard-switches. The complementary low-side commutates through its body diode during dead time.

### 2.1 Hard-switching overlap (V–I crossover)
$$P_{sw} = \tfrac{1}{2}\,V_{bus}\,I\,(t_r + t_f)\,f_{sw}$$

$$= 0.5 \times 25.2 \times 80 \times 40\text{ ns} \times 48\text{ kHz} = \mathbf{1.94\ W\ per\ motor}$$

### 2.2 Dead-time body-diode conduction
$$P_{dt} = V_f\,I\,(2\,t_{dt})\,f_{sw} = 0.8 \times 80 \times 100\text{ ns} \times 48\text{ kHz} = \mathbf{0.31\ W}$$

### 2.3 Reverse recovery
$$P_{rr} = Q_{rr}\,V_{bus}\,f_{sw} = 50\text{ nC} \times 25.2 \times 48\text{ kHz} = \mathbf{0.06\ W}$$

### 2.4 Output capacitance
$$P_{oss} = \tfrac{1}{2}\,C_{oss}\,V_{bus}^2\,f_{sw} = 0.5 \times 1\text{ nF} \times 635 \times 48\text{ kHz} = \mathbf{0.015\ W}$$

### 2.5 Gate charge
Most of this is dissipated in the driver and gate resistor, not the FET.

$$P_{gate} = Q_g\,V_{drv}\,f_{sw}\cdot N_{switching}$$

With one high-side and one complementary low-side switching per PWM cycle:

$$P_{gate} = 50\text{ nC} \times 10 \times 48\text{ kHz} \times 2 = \mathbf{0.048\ W\ per\ motor}$$

### 2.6 Switching summary

| Term | Per motor | ×4 |
|---|---|---|
| V–I overlap | 1.94 W | 7.74 W |
| Dead time | 0.31 W | 1.23 W |
| Q_rr | 0.06 W | 0.24 W |
| C_oss | 0.015 W | 0.06 W |
| Gate (driver) | 0.05 W | 0.19 W |
| **Total switching** | **≈2.37 W** | **≈9.5 W** |

**Frequency sensitivity:** switching loss is proportional to f_sw. Dropping to 24 kHz saves about 4.7 W total. Raising to 96 kHz costs about 9.5 W more, at roughly 10% of total loss at 80 A. At this current, conduction dominates, so 48 kHz is a reasonable choice. The FET selection lever is R_DS(on), not Q_g.
