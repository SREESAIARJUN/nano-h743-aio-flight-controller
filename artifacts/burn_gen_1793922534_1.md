## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

θ_offset is found at calibration by aligning the rotor to the d-axis: apply V_d with V_q = 0 and read θ_m.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model in the dq frame
$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda$$

Electromagnetic torque (surface PMSM, L_d = L_q):
$$\tau_e = \tfrac{3}{2}\,p\,\lambda\, i_q = K_t\, i_q$$

### 1.5 Current PI gains (pole-zero cancellation)
Choose the closed-loop bandwidth ω_ci. Cancelling the plant pole R/L gives:
$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

With f_i = 20 kHz, use ω_ci = 2π·1500 rad/s. This stays under f_i/10 to limit PWM-delay phase loss.

### 1.6 Decoupling and back-EMF feedforward
$$v_d^* = \text{PI}_d(e_d) - \omega_e L\, i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e L\, i_d + \omega_e \lambda$$

### 1.7 Voltage limit (circular, preserves the dq angle)
$$V_{\max} = \frac{V_{dc}}{\sqrt{3}}\cdot m_{\max},\qquad m_{\max}=0.95$$

Priority goes to v_d. Then:
$$v_q^{\text{lim}} = \text{sat}\!\left(v_q,\ \sqrt{V_{\max}^2 - v_d^2}\right)$$

### 1.8 Inverse Park and SVPWM (min-max zero-sequence injection)
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\right),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{dc}}$$

This is mathematically equivalent to sector-based SVPWM. It reaches a linear modulation index of 1.155 relative to SPWM.
