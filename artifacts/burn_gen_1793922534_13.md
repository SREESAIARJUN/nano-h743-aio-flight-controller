## 0. Design Assumptions

| Item | Value (default) |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs `p = 7`), `R = 5.6 Ω`, `L = 2.1 mH`, `Kt ≈ 0.09 N·m/A` |
| Load inertia (per axis, reflected) | `J ≈ 2.0e-4 kg·m²` |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), SPI |
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| PWM / current loop | 20 kHz, centre-aligned, low-side shunt sampling |
| Velocity loop | 4 kHz |
| Angle (stabilisation) loop | 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, 8 kHz ODR, ±2000 dps, ±16 g, mounted symmetrically about the camera centre of rotation |
| Gimbal kinematics | Yaw → Roll → Pitch (base to camera) |
