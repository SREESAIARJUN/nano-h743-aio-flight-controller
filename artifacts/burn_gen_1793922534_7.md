## 1. Loop Architecture and Timing

```
             1 kHz                 4 kHz                    20 kHz
 IMU att ─► [Attitude/Angle P(I)] ─► [Velocity PI + FF] ─► [Iq PI] ─► invPark ─► SVPWM ─► Motor
 setpoint      ▲  θ̂ (fused)             ▲  ω̂ (enc PLL ⊕ gyro)     ▲ id,iq
               │                        │  + i_ff(cogging, J·α)   │
 8 kHz dual-IMU fusion ─────────────────┘                        Clarke/Park ◄─ ADC
 (AAF → dynamic notch → static notch → LPF → weighted average)
```

| Loop | Rate | Target bandwidth | Rule |
|---|---|---|---|
| Current (d, q) | 20 kHz | ω_c ≈ 2π·1.5 kHz | ≤ f_s/10 |
| Velocity | 4 kHz | ω_v ≈ 2π·150 Hz | ≤ ω_c/8 |
| Angle / attitude | 1 kHz | ω_θ ≈ 2π·30 Hz | ≤ ω_v/4 |
| IMU fusion | 8 kHz | — | Decimated to 4 kHz and 1 kHz |

Each loop runs at least 4–10× slower in bandwidth than the loop inside it. This lets each inner loop be treated as unity gain when designing the loop around it.

## 2. FOC Current Loop

### 2.1 Transforms

**Clarke transform (amplitude-invariant):**

i_α = i_a, i_β = (i_a + 2i_b)/√3 (using i_a + i_b + i_c = 0)

**Park transform**, with θ_e = p·θ_m − θ_offset:

- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

### 2.2 Plant model in the dq frame

- v_d = R i_d + L di_d/dt − ω_e L i_q
- v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m

Electromagnetic torque (surface PM, L_d ≈ L_q):

τ_e = (3/2) p λ_m i_q = K_t i_q

### 2.3 PI with pole–zero cancellation

Choose the PI zero to cancel the electrical pole:

C(s) = K_p + K_i/s, with K_p = L ω_c and K_i = R ω_c

This makes the closed loop first order:

i/i* = ω_c/(s + ω_c)

**Feedforward decoupling and back-EMF compensation:**

- v_d* = PI_d(i_d* − i_d) − ω_e L i_q
- v_q* = PI_q(i_q* − i_q) + ω_e L i_d + ω_e λ_m

**Delay compensation.** PWM update plus sampling adds roughly 1.5·T_s of delay. Advance the inverse-Park angle accordingly:

θ_e,inv = θ_e + 1.5 ω_e T_s

### 2.4 Voltage limiting and SVPWM

Limit the voltage vector magnitude to V_max = V_bus/√3, prioritizing v_d:

v_q,max = √(V_max² − v_d²)

Use min–max (zero-sequence injection) SVPWM, which is equivalent to sector-based SVPWM:

1. v_a = v_α
2. v_b = −½v_α + (√3/2)v_β
3. v_c = −½v_α − (√3/2)v_β
4. v_0 = −(max + min)/2
5. Duty: d_x = ½ + (v_x + v_0)/V_bus
