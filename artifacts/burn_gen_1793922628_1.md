**Loop rates and bandwidths**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (d/q) | 20 kHz | 1.5–2 kHz |
| Velocity | 4 kHz | 80–150 Hz |
| Angle (attitude) | 1 kHz | 10–25 Hz |

**Bandwidth-separation rule:** each outer loop should be at least 5× slower than the loop it encloses (ω_c ≥ 5·ω_v ≥ 25·ω_θ). This keeps each inner loop approximately unity gain from the outer loop's point of view.

## 1. FOC Current Loop

### 1.1 Transforms
Electrical angle, using the encoder zero offset θ_off:

$$\theta_e = p\,(\theta_m - \theta_{off}) \pmod{2\pi}$$

Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant
The PMSM dq-frame voltage equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

After cancelling the cross-coupling and back-EMF terms with decoupling feedforward, each axis reduces to a first-order plant:

$$G_i(s) = \frac{1}{Ls + R}$$

### 1.3 PI design by pole-zero cancellation
Choose the PI zero to cancel the electrical pole at R/L:

$$C_i(s) = K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_c,\quad K_i = R\,\omega_c$$

The open loop then becomes ω_c/s, so the closed loop is a clean first-order lag:

$$T_i(s) = \frac{\omega_c}{s+\omega_c}$$

Discretized at T_s with an effective delay of about 1.5·T_s (computation plus PWM update), keep ω_c·1.5·T_s ≤ 0.2. At 20 kHz this gives ω_c ≤ 2π·2.1 kHz.

### 1.4 Decoupling feedforward

$$v_d^{*} = \mathrm{PI}_d(e_d) - \hat\omega_e \hat L\, i_q$$
$$v_q^{*} = \mathrm{PI}_q(e_q) + \hat\omega_e(\hat L\, i_d + \hat\lambda_m)$$

### 1.5 Voltage limiting and anti-windup
Limit the voltage vector to the linear SVPWM range:

$$|v_{dq}| \le V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{max},\qquad m_{max}\approx 0.95$$

d-axis priority is used: v_d is clamped first, and v_q receives whatever magnitude remains.

Anti-windup uses back-calculation:

$$\dot x_I = K_i e + K_{aw}(v_{sat} - v_{unsat}),\qquad K_{aw} = \frac{K_i}{K_p}$$

### 1.6 Inverse Park and SVPWM
Rotate back to the stationary frame:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Form phase voltages using min-max zero-sequence injection, which is equivalent to SVPWM:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

Duty cycles:

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.7 Voltage-mode fallback
High-resistance gimbal motors often lack current shunts. In that case set:

$$v_q = R\, i_q^{*} + \omega_e \lambda_m,\qquad v_d = -\omega_e L\, i_q^{*}$$

This is an open-loop current approximation. The code supports both modes.
