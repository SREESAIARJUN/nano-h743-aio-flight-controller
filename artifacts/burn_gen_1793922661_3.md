# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the original Job #5 specification, so this design states its assumptions explicitly. Every parameter is a named constant, so you can substitute your real hardware values.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), or any Cortex-M4F/M7 |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701), one per joint |
| IMUs | 2× ICM-42688-P on the camera plate, on separate SPI buses, sampled synchronously |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries camera) |

The loops run as a rate hierarchy. Each outer loop is at least 4× slower in bandwidth than the loop inside it.

| Loop | Rate | Closed-loop bandwidth | Feedback |
|---|---|---|---|
| Current (d/q) | 20 kHz | ~1.5 kHz | Phase shunts plus encoder angle |
| Rate (velocity) | 4 kHz | ~150 Hz | Fused gyro mapped to joint space |
| Attitude (angle) | 1 kHz | ~25 Hz | Fused quaternion |
| IMU ODR | 8 kHz, decimated to 4 kHz | — | — |

## 1. Field-Oriented Control Equations

### 1.1 Electrical angle

θ_e = p · (θ_m − θ_offset) mod 2π

### 1.2 Clarke transform (power-invariant form not used; amplitude-invariant form)

With i_a + i_b + i_c = 0:

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

### 1.3 Park transform

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

### 1.4 Motor model in the d/q frame

- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ
- τ = (3/2)·p·λ·i_q ≡ K_t·i_q, assuming a surface PMSM where L_d = L_q

### 1.5 Current PI controllers with decoupling and back-calculation anti-windup

For x ∈ {d, q}, with error e_x = i_x* − i_x:

- u_x = K_p·e_x + I_x + v_x,ff
- v_d,ff = −ω_e·L·i_q
- v_q,ff = ω_e·L·i_d + ω_e·λ
- I_x[k+1] = I_x[k] + K_i·T_s·e_x + K_aw·T_s·(u_x,sat − u_x)

**Pole-zero cancellation tuning**, where ω_c is the target current-loop bandwidth:

- K_p = L·ω_c
- K_i = R·ω_c
- K_aw = 1/K_p·K_i (approximately K_i/K_p = R/L)

The result is a first-order closed loop, i/i* = ω_c / (s + ω_c). Choose ω_c ≤ 2π·f_pwm / 10.

### 1.6 Voltage limiting (circular)

V_max = V_bus / √3 (the SVPWM linear range).

If √(u_d² + u_q²) > V_max:

1. Give d-axis priority: u_d = clamp(u_d, ±V_max).
2. Allocate the remainder to q: u_q = sign(u_q)·√(V_max² − u_d²).

### 1.7 Inverse Park and SVPWM via min-max (zero-sequence) injection

- v_α = u_d·cos θ_e − u_q·sin θ_e
- v_β = u_d·sin θ_e + u_q·cos θ_e
- v_a = v_α
- v_b = −½·v_α + (√3/2)·v_β
- v_c = −½·v_α − (√3/2)·v_β
- v_0 = −(max + min)/2 of (v_a, v_b, v_c)
- duty_x = ½ + (v_x + v_0)/V_bus

### 1.8 Encoder velocity: PLL observer

The PLL gives a smooth, lag-compensated velocity estimate:

- ε = wrap_π(θ_meas − θ̂)
- ω̂ ← ω̂ + K_i,pll·T_s·ε
- θ̂ ← θ̂ + T_s·(ω̂ + K_p,pll·ε)

Gains: K_p,pll = 2ζω_n and K_i,pll = ω_n², with ζ = 1 and ω_n ≈ 2π·300 rad/s.

## 2. Cascaded Attitude → Rate → Torque Control

### 2.1 Attitude error

Use quaternions, which have no gimbal-lock in the error computation:

- q_e = q_d* ⊗ q̂
- φ = 2·sgn(q_e,w)·q_e,xyz

φ is a rotation vector in the camera frame. The sign term enforces the short-path rotation.

### 2.2 Attitude loop (P plus feed-forward)

ω_c* = −K_θ·φ + ω_d,ff
