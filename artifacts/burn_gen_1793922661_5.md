## 0. Assumptions and Reference Hardware

| Item | Assumed value | Notes |
|---|---|---|
| Motors | 3× gimbal BLDC, 12N14P (e.g., GBM2804-class), p = 7 pole pairs | Gimbal-wound: R ≈ 5–12 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) | Used for commutation and joint angle |
| Current sensing | 2-phase in-line or low-side shunts | A voltage-mode fallback is given in §1.6 |
| PWM / current loop | 20 kHz center-aligned, current loop at 20 kHz | |
| Velocity (rate) loop | 4 kHz | Decimation 5 |
| Angle loop | 1 kHz | Decimation 20 |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro ODR 8 kHz, accel ODR 1 kHz | Shared CLKIN recommended |
| Gimbal kinematics | Yaw (outer) → Roll → Pitch (inner, camera) | |
