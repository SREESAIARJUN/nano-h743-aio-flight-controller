# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #26 specification, so the design below is fully parameterized. Every hardware-specific number sits in one config struct (§7.1). The baseline assumptions are listed so you can see what each derivation depends on.

| Item | Assumed baseline | Where it matters |
|---|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz | Loop rates |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH | Current PI, cogging order |
| Inverter | 3 low-side shunts or inline current sense, Vbus 12–16 V | FOC |
| Encoder | 14-bit absolute (AS5048A / MT6701) per axis | Commutation, joint angle |
