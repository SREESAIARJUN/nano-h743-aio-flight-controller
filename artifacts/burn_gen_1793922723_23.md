# STM32H743 Nano AIO FC + 4-in-1 ESC (Job #36): System Architecture & Mathematical Model

**Document scope:** Electrothermal model (conduction, switching, and parasitic losses at 80 A burst and 48 kHz), ArduPilot bi-directional DShot600 timer/DMA allocation, a representative netlist, and a thermal feasibility verdict.

---

## 0. Executive Summary and Feasibility Flags

The requirement as stated contains three conflicts. They should be resolved before layout.

| # | Issue | Consequence | Recommendation |
|---|---|---|---|
| 1 | **The STM32H743 does not commutate the motors.** In every production 4-in-1, each motor uses a dedicated ESC MCU (AT32F421 or STM32G071 running AM32/BLHeli_32). The H743 is the flight controller and generates DShot. | Architecture must be two-tier. | H743 (FC) → 4× ESC MCU → 4× FD6288Q-class 3-phase gate driver → 24 MOSFETs. |
| 2 | **80 A per channel on a "nano" (20×20 mm) board is not thermally sustainable.** The model below gives about 33 W per motor and about 130 W per board at 80 A. | The burst limit is about 2–3 s from a 40 °C start. | Rate it "80 A / 2 s burst, 45–55 A continuous with airflow," or move to a 30.5×30.5 mm board. |
| 3 | **4 × 80 A = 320 A of battery current** passes through nano-sized pads, an XT60/XT90 connector, and 2 oz copper. | Bus copper losses and IR drop rival the FET losses. | Use 3 oz outer / 2 oz inner copper, direct battery pad soldering, and current sense on the main bus. |

All component values below are **stated assumptions**, chosen to be representative of 40 V, 3.3×3.3 mm or 5×6 mm ESC MOSFETs. Substitute real datasheet values for your selected part. The equations are parameterized for this purpose.

## 1. System Architecture

```
 6S LiPo (25.2 V max) ──┬── TVS + 2× 470 µF low-ESR bulk + 12× 10 µF/50 V X7R per phase cluster
                        │
        ┌───────────────┴────────────────────────────────────────────┐
        │  ESC section (per motor ×4)                                │
        │  ESC MCU (AT32F421 / STM32G071, AM32)                      │
        │    ├─ 6× PWM (complementary, 48 kHz, dead-time)            │
        │    ├─ BEMF comparator inputs (3-phase + virtual neutral)   │
        │    └─ DShot input (bidirectional, single wire)             │
        │  FD6288Q 3-phase bootstrap gate driver (VCC ≈ 10 V)        │
        │  6× N-ch 40 V MOSFET (3 half-bridges)                      │
        └──────────────▲─────────────────────────────────────────────┘
                       │ 4× bidirectional DShot600 (via 33 Ω series R)
        ┌──────────────┴─────────────────────────────────────────────┐
        │  FC section: STM32H743VIH6 @ 480 MHz                       │
        │  IMU (SPI1), Baro (I2C), OSD (SPI2), Flash/SD, UARTs       │
        │  Bus current sense (shunt + INA) → ADC, VBAT divider → ADC │
        └────────────────────────────────────────────────────────────┘
```
