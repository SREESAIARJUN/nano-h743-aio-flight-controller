**Architectural correction (important).** The H743 does not drive MOSFETs. Each motor channel has a dedicated ESC MCU (e.g., AT32F421 or STM32G071 running AM32). That MCU generates the 48 kHz PWM and runs commutation. The H743 sends **bidirectional DShot600** commands and receives eRPM telemetry. So:

- The loss model (§1–3) belongs to the ESC power stage.
- The DMA/timer model (§4) belongs to the H743.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.0053\ /\mathrm{K}$$

At T_j = 125 °C: R_DS ≈ 1.2 mΩ × 1.53 ≈ **1.84 mΩ** (1.8 mΩ is used below).

### 1.2 Current path in 6-step complementary PWM

In each 60° commutation sector, two phases conduct:

- **PWM leg:** current flows through the high-side FET for duty fraction D. It flows through the low-side FET (synchronous rectification) for 1−D.
- **Return leg:** the low-side FET is held fully on.

So **two FETs carry the full phase current at all times** (ignoring dead time):

$$P_{cond,motor} = 2\,I^2\,R_{DS}(T_j)$$

$$P_{cond,motor} = 2 \times 80^2 \times 1.8\,\mathrm{m\Omega} = \mathbf{23.0\ W}$$
