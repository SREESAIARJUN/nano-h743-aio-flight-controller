## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU), 3 motors |
| Motors | Gimbal BLDC, 12N14P (Ns = 12 slots, p = 7 pole pairs), R ≈ 10 Ω, L ≈ 3 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit magnetic encoder (AS5048A or MT6701), one per joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, ±2000 dps, ±8 g |
| Joint order | Yaw (base) → Roll → Pitch (camera) |
| PWM / current loop | 20 kHz center-aligned PWM, current loop at 20 kHz |
| Velocity (rate) loop | 4 kHz |
| Attitude loop | 1 kHz (angle P with rate feed-forward) |
| AHRS | Updated at 1 kHz from the fused, filtered IMU stream |

**Bandwidth separation rule.** Each loop is kept at least 5× slower than the loop inside it. Here the current loop runs at about 1.5 kHz, the rate loop at about 150 Hz, and the angle loop at about 20–25 Hz.

## 1. FOC Current Loop (Inner Loop, 20 kHz)

### 1.1 Transforms

Electrical angle from mechanical angle, with calibrated offset θ₀:

$$\theta_e = p\,\theta_m - \theta_0 \pmod{2\pi}$$

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model and Decoupling

The PMSM model in the dq frame (surface-mount magnets, so L_d = L_q = L):

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

Here λ_m = (2/3)·K_t/p in amplitude-invariant scaling.

The controller applies a PI term plus decoupling feed-forward:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L i_d + \hat\lambda_m)$$

$$G_{ol}(s) = \frac{K_p s + K_i}{s}\cdot\frac{1}{Ls+R}$$
