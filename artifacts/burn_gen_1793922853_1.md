# 3-Axis Gimbal FOC Control and Dual-IMU Fusion Design

I have no record of Job #56's specifications, so I've designed around a typical high-performance brushless gimbal. **Every value marked ⚙ is an assumption you should replace with your measured hardware data.**

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), 3× independent half-bridge sets |
| Motors | GBM2804-class, 12N14P (p = 7 pole pairs) ⚙, R_s ≈ 5.6 Ω, L_s ≈ 2.0 mH ⚙ |
| Position sensor | 14-bit magnetic encoder (AS5048A/MT6701) per axis |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro 8 kHz ODR |
| Loop rates | Current 20 kHz, velocity 4 kHz, attitude 1 kHz |
| Kinematic chain | Base → Yaw (Z) → Roll (X) → Pitch (Y) → camera |

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

θ_off is found by aligning the rotor with a d-axis voltage at calibration.
