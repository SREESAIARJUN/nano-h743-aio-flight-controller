# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the spec sheet for Job #27, so this design states its assumptions explicitly. Every gain is derived from motor and plant parameters, so you can substitute your own values.

---

## 0. Assumed Hardware and Timing

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| MCU | STM32G474 / H7 (FPU, CORDIC optional) |
| Current sensing | 2-phase inline shunts (voltage-mode fallback given in §2.6) |
| IMUs | 2× ICM-42688-P on the camera plate, symmetric about the camera CoM, SPI, 8 kHz ODR |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle 1 kHz · Attitude 1 kHz |

The bandwidth separation between loops is ≥ 5× everywhere. This makes the cascade valid, because each inner loop looks like unity gain to the loop outside it.
