# STM32H743 Nano FC + 4-in-1 ESC: Power Stage, Thermal, and DShot Architecture

**Document:** Job #42 Architecture Baseline, Rev A

## 0. Scope and Assumptions

No Job #42 parameter set was supplied, so this document fixes a baseline. Every result below is a closed-form function of these parameters, so you can substitute vendor datasheet values directly.

Two architecture facts frame everything else:

1. **The H743 does not generate the 48 kHz PWM.** On a 4-in-1 stack, each ESC channel has its own MCU (typically STM32G071 or AT32F421 running AM32 or BLHeli_32). The H743 runs ArduPilot and sends **bidirectional DShot600** to those MCUs. The switching-loss model applies to the ESC side. The DMA model applies to the H743 side.
2. **"80 A burst" on a nano-format board is limited by heat capacity, not steady-state cooling.** The math in §3 shows this explicitly.
