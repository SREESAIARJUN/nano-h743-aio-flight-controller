## 0. Architecture Clarifications and Design Assumptions

### 0.1 Architectural corrections

Two points need settling before any math, because they change the design:

1. **The STM32H743 does not commutate the motors.** ArduPilot runs on the H743. Each motor channel needs its own ESC MCU running AM32 or BLHeli_32, which generates the 48 kHz PWM and decodes DShot. The baseline here is **4× AT32F421K8U7**. The H743-to-ESC interface is bi-directional DShot600 over four single-wire nets.
2. **"80 A burst" must be defined as phase current, per channel, for a stated duration.** If it meant battery current, a 4-in-1 would draw 320 A from the pack. No nano-format board, connector, or pigtail survives that. In this document:
   - **I_ph,burst = 80 A** per channel, for **t_burst ≤ 2 s**.
   - **I_ph,cont = 45 A** per channel.

## 1. Conduction Loss Model

### 1.1 Topology state

In 6-step trapezoidal drive with complementary (synchronous) PWM, during any 60° sector:

- **Leg A (PWM leg):** the high-side conducts for D·T_sw. The low-side conducts synchronously for (1−D)·T_sw, minus dead time.
- **Leg B (static leg):** the low-side is continuously ON.
- **Leg C:** floating (BEMF sensing).

Phase current I_ph flows through exactly two channels at all times. One is in Leg A, alternating HS/LS. The other is the static LS in Leg B.

### 1.2 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

### 1.3 Per-device and per-channel conduction loss

$$P_{cond,HS} = I_{ph}^2 \, R_{ds}(T_j)\, D$$

$$P_{cond,LS,sync} = I_{ph}^2 \, R_{ds}(T_j)\,\Big(1 - D - 2t_{dt}f_{sw}\Big)$$

$$P_{cond,static} = I_{ph}^2 \, R_{ds}(T_j)$$

$$\boxed{P_{cond,ch} \approx 2\, I_{ph}^2\, R_{ds}(T_j)}$$

This holds independent of D, to first order. Dead-time current is moved to the diode term in §2.

### 1.4 Numerical result (80 A, T_j = 125 °C)

R_ds(125 °C) = 1.0 mΩ × (1 + 0.005·100) = **1.5 mΩ**

$$P_{cond,ch} = 2 \times 80^2 \times 1.5\times10^{-3} = \mathbf{19.2\ W}$$
