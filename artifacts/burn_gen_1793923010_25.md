# STM32H743 Nano FC + 4-in-1 ESC (Job #20): Electro-Thermal Model, 48 kHz Switching Analysis, and Bidirectional DShot600 DMA Plan

## 0. Architecture and Key Findings

The STM32H743 does not commutate the motors. In every practical 4-in-1 design, each ESC channel has its own MCU, typically AT32F421 or STM32G071 running AM32/BLHeli_32. That MCU generates the 48 kHz complementary PWM. The H743 runs ArduPilot, sends bidirectional DShot600, and receives eRPM telemetry for the harmonic notch filters.

```
 VBAT ──┬─────────────── 4-in-1 ESC board (20×20, M3 or M2)────────────────┐
        │  ESC MCU ×4 (AM32) → FD6288-class 3-ph driver → 6× N-FET ×4 ch      │
        │        ▲ DShot600 bidir (1 wire per motor, open-drain-ish, 3V3)     │
 H743 FC ┴─ TIM3_CH3/CH4, TIM5_CH1/CH2 ── 8-pin JST-SH ──────────────────────┘
```

> **Key engineering finding (stated first because it drives everything else):** 80 A per channel on a 20×20 "nano" stack is a **burst rating limited by board heat capacity, not by steady-state heat dissipation**. The model below shows:
> - All four channels at 80 A can run for only **about 0.6–1 s**.
> - Continuous capability is roughly **15–25 A per channel**, depending on prop-wash airflow.
>
> Any marketing claim beyond that must be derated in firmware, using a current limit plus thermal foldback.

## 2. Conduction Losses (80 A Burst)

### 2.1 Temperature-dependent on-resistance

$$R_{ds}(T_j)=R_{ds25}\,[1+\alpha(T_j-25)]$$

### 2.2 Commutation topology

The ESC uses 6-step trapezoidal commutation with synchronous rectification (complementary PWM). In any 60° sector:

- **PWM leg:** the high-side FET conducts for duty D and the low-side FET for (1−D). One FET is always carrying I.
- **Return leg:** the low-side FET is fully on and carries I.

So the conduction loss per channel is independent of duty cycle:

$$P_{cond,ch}=I^2R_{ds}\,[D+(1-D)]+I^2R_{ds}=2I^2R_{ds}(T_j)$$

Averaged over an electrical revolution, each of the 6 FETs carries about one-sixth of this:

$$\bar P_{cond,FET}=\frac{I^2R_{ds}}{3}$$

This averaging is valid because the electrical frequency (≈1–3 kHz) is much faster than the die thermal time constant (≈ms).

### 2.3 Numbers at T_j = 100 °C
