## 0. Architectural Baseline and Assumptions

### 0.1 Architecture Correction

The STM32H743 should **not** commutate the motors directly.

- ArduPilot has no native sensorless BLDC commutation.
- A 400 MHz H7 running 4× field/6-step control alongside EKF3 is not a supported configuration.

The correct partition is as follows:

| Domain | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100), 400 MHz (ArduPilot default) | ArduPilot, sends bi-dir DShot600 |
| ESC MCU ×4 | AT32F421K8U7 (QFN32), running AM32 | Commutation, 48 kHz PWM, eRPM telemetry |
| Gate driver ×4 | FD6288Q (3-phase, 250 V-class, ~1.5 A src / 1.8 A sink) | Half-bridge drive, bootstrap |
| Power stage ×4 | 6× N-MOSFET, 40 V, PDFN 3.3×3.3 | 3-phase bridge |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Topology Current Paths

AM32 uses 6-step trapezoidal commutation with complementary (synchronous) PWM on the switching leg. In any 60° electrical sector, three devices are involved:

- **Switching leg:** HS conducts for fraction D, LS (synchronous rectifier) conducts for (1 − D), excluding dead time.
- **Return leg:** LS is fully on.
- **Floating leg:** off (BEMF sensing).

Current always flows through exactly two channels (one in the switching leg, one in the return leg):

$$P_{cond,ch}(T_j) = 2\,I_{ph,rms}^2\,R_{ds(on),25}\,\alpha_R(T_j)$$

Including PWM ripple ΔI_pp, approximated as triangular:

$$I_{ph,rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12}, \qquad \Delta I_{pp} = \frac{(V_{bus}-2E_{bemf})\,D}{2L_{ph}\,f_{sw}}$$
