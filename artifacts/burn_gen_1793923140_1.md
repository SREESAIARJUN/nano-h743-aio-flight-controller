# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design (Job #24)

I don't have the Job #24 specification, so this design uses the assumptions in §0. Every equation is written in terms of those parameters, so you only need to replace the constants once your actual motor, encoder and MCU are confirmed.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 1.9 mH, Kt ≈ 0.09 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) on the motor shaft |
| MCU | STM32G4 @ 170 MHz with FPU, center-aligned PWM, ADC triggered at the PWM valley |
| Bus voltage | 12 V |
| IMUs | 2 × ICM-42688-P on the camera plate, each on its own SPI bus, ODR 8 kHz |

The loops run at the following rates:

| Loop | Rate | Ts |
|---|---|---|
| PWM / current (FOC) loop | 20 kHz | 50 µs |
| IMU sampling (both sensors, DMA) | 8 kHz | 125 µs |
| Velocity loop | 4 kHz | 250 µs |
| Angle / attitude loop + Mahony filter | 1 kHz | 1 ms |
| Anti-cogging LMS adaptation | 4 kHz (only while gated) | — |
