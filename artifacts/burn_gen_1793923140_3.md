# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #44, so the design is parameterized and the numerical values below are typical gimbal values. Replace them with your measured motor and frame data. All equations are given in discrete form, ready to implement.

---

## 0. Assumed System Parameters

| Item | Assumed value | Symbol |
|---|---|---|
| Motor | 12N14P gimbal BLDC (e.g. GBM4108), R = 10 Ω, L = 4 mH (per phase) | p = 7 pole pairs |
| Encoder | 14-bit magnetic (AS5048A / MT6701) | θ_m |
| MCU | STM32G474 (FPU), center-aligned PWM 25 kHz | — |
| Current loop | 25 kHz (one per PWM period) | T_c = 40 µs |
| Velocity loop | 5 kHz | T_v = 200 µs |
| Angle loop | 1 kHz | T_θ = 1 ms |
| IMUs | 2 × ICM-42688-P on separate SPI buses, ODR 8 kHz, decimated to 5 kHz | — |
| Joint order | Yaw (z) → Roll (x) → Pitch (y) → camera | q = [ψ, φ, θ] |
