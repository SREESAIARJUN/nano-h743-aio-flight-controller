## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Electrical angle

θ_e = p · (θ_m − θ_offset) mod 2π

### 1.2 Clarke transform (amplitude-invariant)

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

This assumes i_a + i_b + i_c = 0.

### 1.3 Park transform

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

### 1.4 Plant (surface PMSM, L_d ≈ L_q = L)

- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ_m
- Torque: τ = (3/2)·p·λ_m·i_q = K_t·i_q

### 1.5 Current PI by pole-zero cancellation

Choose the target current bandwidth ω_c, then set:

- K_p = L·ω_c
- K_i = R·ω_c

This cancels the electrical pole at R/L, so the closed loop becomes ω_c / (s + ω_c).

Constraint: ω_c ≤ 2π·f_s / 10. At 20 kHz this gives ω_c ≤ 2π·2 kHz.

### 1.6 Decoupling and back-EMF feedforward

- v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
- v_q* = PI_q(i_q* − i_q) + ω_e·L·i_d + ω_e·λ_m

### 1.7 Voltage limiting (circle limit)

If |v_dq| > V_max = V_bus/√3 · m_max (with m_max ≈ 0.95), scale as follows:

- v_d is kept, but clamped to ±V_max
- v_q is limited to ±√(V_max² − v_d²)

The d-axis is prioritized so that the i_d = 0 regulation holds.

### 1.8 Inverse Park and SVPWM via min/max injection

1. Inverse Park:
   - v_α = v_d·cos θ_e − v_q·sin θ_e
   - v_β = v_d·sin θ_e + v_q·cos θ_e
2. Inverse Clarke:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
3. Common-mode injection: v_0 = −(max(v_abc) + min(v_abc)) / 2
4. Duties: D_x = ½ + (v_x + v_0) / V_bus

### 1.9 Angle delay compensation

The PWM update takes effect about 1.5·T_s after sampling. Use this angle for the inverse Park:

θ_e,pwm = θ_e + 1.5·ω_e·T_s

## 2. Cascaded Angle → Velocity Control

### 2.1 Structure and bandwidth separation

The cascade is: angle loop (1 kHz) → velocity loop (4 kHz) → current loop (20 kHz).

Keep each loop's bandwidth well below the one inside it:

ω_c,i ≥ 5·ω_c,ω ≥ 5·ω_c,θ

Typical gimbal values: 2 kHz → 150–300 Hz → 20–50 Hz.
