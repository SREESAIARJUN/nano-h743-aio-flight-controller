# FOC Control Loop and Dual-IMU Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #42 specification. The design below uses typical values for a gimbal of this class. Every assumption is a `constexpr` in the code, so you can substitute your actual hardware parameters.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | 3× gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| Current sensing | 2-shunt low-side, sampled at PWM center |
| PWM / current loop | 20 kHz, center-aligned |
| Velocity loop | 4 kHz (decimate ÷5) |
| Attitude/angle loop | 1 kHz (decimate ÷20) |
| IMUs | 2× ICM-42688-P on SPI, gyro/accel ODR 8 kHz, FIFO or DRDY sync |
| Gimbal order | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |
