# Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification (Job #39)

I don't have the Job #39 hardware spec, so this design uses the assumptions below. Every gain, filter and register setting is computed from these parameters, so you can substitute real values without changing the structure.

| Parameter | Symbol | Assumed value |
|---|---|---|
| MCU | — | STM32G4 @ 170 MHz (FPU + CORDIC) |
| Motor | — | Gimbal BLDC 12N14P (pole pairs $p=7$) |
| Phase resistance / inductance | $R, L$ | 5.0 Ω, 2.0 mH (line-to-neutral) |
| Torque constant | $K_t$ | 0.08 N·m/A |
| Axis inertia (motor + payload) | $J$ | 2.0×10⁻⁴ kg·m² |
| Rotor encoder | — | 14-bit magnetic (AS5048A / MA730 class) |
| PWM / current loop | $f_{pwm}, f_i$ | 20 kHz center-aligned, current loop 20 kHz |
| IMU ODR / filter rate | $f_{imu}$ | 8 kHz (ICM-42688-P ×2, SPI) |
| Velocity loop | $f_v$ | 4 kHz |
| Angle / attitude loop | $f_\theta$ | 1 kHz |

---

## 1. Timing Architecture

```
20 kHz  ADC-trigger ISR : encoder → θe, Clarke/Park, PI(id,iq), cogging FF, SVPWM
 8 kHz  IMU DRDY ISR    : 2× SPI burst, axis remap, dual notch, LPF, fusion, fault check
 4 kHz  velocity task   : decimate gyro(2:1 avg), velocity PI → iq_ref
 1 kHz  attitude task   : Mahony AHRS, joint-space angle error, angle P(+FF) → ω_ref
```
