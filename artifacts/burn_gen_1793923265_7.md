# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

I don't have a spec sheet for "Job #20," so this design uses the stated assumptions below. Every parameter is a `constexpr` or config field. Replace them with your measured motor and plant data before closing any loop on hardware.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class (FPU, ≥170 MHz). CORDIC is optional. |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) |
| Current sense | 2- or 3-shunt, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, common CLKIN |
| Rates | Current loop 20 kHz, velocity loop 4 kHz, angle loop 1 kHz, IMU 8 kHz |
