# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #18 specification, so this design states its assumptions explicitly (§0). Every numeric constant is a parameter, so you can substitute your actual hardware values.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC/PMSM, 12N14P (pole pairs $p=7$), SPM so $L_d \approx L_q = L$ |
| Electrical parameters | $R_s = 5.6\,\Omega$, $L = 2.0$ mH, $K_t = 0.06$ N·m/A, $J = 3\times10^{-5}$ kg·m² (motor + load about the axis) |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701), SPI |
| MCU | STM32G4
