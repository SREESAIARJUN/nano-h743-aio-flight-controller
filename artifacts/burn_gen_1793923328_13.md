# STM32H743 Flight Controller + 4-in-1 ESC: Loss Model, Thermal Budget, Bidirectional DShot600 DMA Allocation, and Netlists

## 0. Architecture Correction and Baseline Assumptions

**Architecture.** An STM32H743 does not run the ESC power stages. In every production 4-in-1 stack, the H743 is the **flight controller (FC)** running ArduPilot. The **ESC** carries four small MCUs, one per motor, typically AT32F421 or STM32G071 running AM32 or BLHeli_32. The ESC MCUs generate the 48 kHz complementary PWM. The FC talks to them over bidirectional DShot600. The model below follows that split.

No MOSFET, gate driver, or board stack-up was specified, so every number below rests on the stated assumptions. Swap in your actual datasheet values. All equations are parametric.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Battery | V_in | 6S, 25.2 V max (worst case for switching losses) |
| Burst phase current, per motor | I | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET R_DS(on) at 25 °C, V_GS = 10 V | R₂₅ | 1.0 mΩ (40 V class, 3.3×3.3 or 5×6 package) |
| R_DS(on) temperature factor at ~110 °C | k_T | 1.5 |
| Switching charge (Q_gs2 + Q_gd) | Q_sw | 15 nC |
| Total gate charge | Q_g | 60 nC |
| Output capacitance | C_oss | 1.0 nF |
| Body-diode reverse recovery charge | Q_rr | 50 nC |
| Body-diode forward voltage | V_f | 0.8 V |
| Gate driver | — | FD6288-class: source ~0.3 A, sink ~0.6 A |
| Rise / fall time (effective) | t_r / t_f | 50 ns / 25 ns |
| Dead time per edge | t_dt | 300 ns |
| Gate drive voltage | V_GS | 10 V |

**Reality check.** 80 A per channel on a 20×20 mm "nano" board is not physically sustainable. The numbers below show it works only as a **seconds-long burst**. A 30.5×30.5 mm board with 2 oz copper or heavier is the realistic minimum for this rating.

## 1. Conduction Losses

### 1.1 Conduction topology

The motor is driven with 6-step (trapezoidal) commutation and synchronous rectification using complementary PWM. At any instant, the phase current flows through exactly two FETs:
- one FET in the PWM-ing leg (the high-side FET or the low-side FET, depending on PWM state), and
- the low-side FET of the return leg.

As a result, conduction loss is independent of duty cycle:

$$P_{cond,ch} = 2\, I^2\, R_{DS(on)}(T_j), \qquad R_{DS(on)}(T_j) \approx R_{25}\,[1+\alpha (T_j-25)]$$

Here α ≈ 0.005–0.007 /K is the typical temperature coefficient for trench MOSFETs.
