# Job #41: STM32H743 Nano AIO (FC + 4-in-1 ESC) System Architecture

## 0. Architectural Ground Truth

Two corrections to the brief shape the rest of this document.

1. **The H743 does not commutate the motors.** In every production AIO, the H743 runs ArduPilot (the flight controller). Each ESC channel has its own small MCU running AM32 or BLHeli_32-class firmware, such as AT32F421 or STM32G071. That MCU generates the 48 kHz PWM and six-step commutation. The H743 talks to the ESC MCUs over bi-directional DShot600. The math below follows this partition.

2. **"80 A burst" on a nano (20×20 mm) board is thermally infeasible beyond about 2 s** without an external heatsink. Section 3 derives this. Treat it as a design-review finding, not a footnote.

**Stated assumptions.** Replace these with datasheet values once the BOM is frozen.

## 1. Conduction Loss Model

### 1.1 Six-step current distribution
With trapezoidal (120°) commutation, two phases conduct at any instant. Each phase leg carries current for 2/3 of the electrical period: high-side for 1/3 and low-side for 1/3. With complementary PWM at duty D, within its 1/3 window:

- PWM'd high-side FET conducts for fraction D.
- Its synchronous low-side partner conducts for fraction (1 − D).
- The static-side FET conducts for the full window.

Motor phase current relates to battery current approximately as I_ph ≈ I_bat / D, ignoring ripple.

### 1.2 Temperature-dependent resistance
```
R_DS(T_j) = R_25 · [1 + α(T_j − 25)],   α ≈ 0.006 /K  → R(100°C) ≈ 1.45 mΩ
```
Resistance and loss are coupled. Solve self-consistently by iterating T_j = T_board + P·R_θ until convergence. If dP/dT · R_θ ≥ 1, the device runs away thermally.

### 1.3 Per-FET conduction loss (worst case, D → 1 at full burst)
```
P_cond,FET = I_ph² · R_DS(T_j) · (1/3)
           = 80² · 1.45e-3 / 3
           = 3.09 W per FET
```
With ripple, use I_rms² = I_ph² · (1 + r²/12). At r = 30% ripple this adds 0.75%, which is negligible.

### 1.4 Copper and shunt losses (per channel)
| Element | Resistance | Loss @ 80 A, 2/3 duty per phase |
|---|---|---|
| Phase copper (2 oz, ~15 mm) | ~0.25 mΩ | 1.07 W per phase → 3.2 W |
| Shunt (if per-channel) | 0.25 mΩ | I_bat² · R ≈ 1.6 W |
| Bus copper | ~0.1 mΩ | 0.64 W |

### 1.5 Channel and board totals (conduction only)
```
P_cond,ch    = 6 FETs × 3.09 W (only 2 conduct at a time; the ⅓ factor already covers that)
             = 18.5 W FETs + ~5.4 W copper/shunt ≈ 23.9 W
P_cond,board = 4 × 23.9 ≈ 95.6 W   (all motors at 80 A simultaneously)
```

## 2. Switching Loss Model at 48 kHz

Switching occurs only in the PWM'd leg during its 1/3 window. At D = 1 there is no switching. **The worst-case switching point is high current at partial duty**, for example a punch-out or yaw transient at D ≈ 0.8 with I_ph still near 80 A.

### 2.1 Hard-switching V·I overlap
```
P_sw = ½ · V_bus · I_ph · (t_r + t_f) · f_sw · (1/3)
     = ½ · 25.2 · 80 · 40e-9 · 48e3 / 3
     = 0.645 W per switching FET
```

### 2.2 Output capacitance
```
P_oss = ½ · C_oss(er) · V_bus² · f_sw · (1/3)
      = ½ · 1e-9 · 635 · 48e3 / 3 = 5 mW   (negligible)
```

### 2.3 Dead-time body-diode conduction (in the synchronous FET)
```
P_dt = V_SD · I_ph · 2·t_dt · f_sw · (1/3)
     = 0.8 · 80 · 100e-9 · 48e3 / 3 = 0.102 W
```

### 2.4 Reverse recovery (charged to the high-side FET)
```
P_rr = Q_rr · V_bus · f_sw · (1/3) = 40e-9 · 25.2 · 48e3 / 3 = 16 mW
```

### 2.5 Gate drive (dissipated in the driver and R_g, not the FET die)
```
P_g = Q_g · V_GS · f_sw = 50e-9 · 10 · 48e3 = 24 mW per switching FET
→ ~0.1 W per channel in the driver
```

### 2.6 Switching summary per channel
```
P_sw,ch ≈ 2 legs active × (0.645 + 0.005 + 0.102 + 0.016) ≈ 1.5 W
```
**Conclusion:** at 48 kHz, losses are dominated by conduction (about 94%). Raising f_sw to 96 kHz would add only ~1.5 W per channel. Lowering R_DS(on) (for example, paralleling FETs) has roughly 10× more leverage than tuning the switching edges.

### 2.7 Combined loss envelope
| Condition | Per channel | Board (4 ch) |
|---|---|---|
| 80 A, D = 1 | ~24 W | ~96 W |
| 80 A, D = 0.8 | ~22 W | ~88 W |
| 30 A continuous, D = 0.6 | ~3.6 W | ~14 W |

## 3. Thermal Model

### 3.1 Network (Foster, per FET → board → ambient)
```
T_j ──R_jc(1.2 K/W)── T_case ──R_cb(0.8 K/W, vias+solder)── T_board ──R_ba── T_amb
                                                               │
                                                             C_board
```

### 3.2 Junction rise over board (fast time constant, τ ≈ ms)
```
ΔT_jb = P_FET · (R_jc + R_cb) = 3.7 W · 2.0 K/W ≈ 7.4 K
```
The die is not the problem. **The board's bulk heat capacity is the problem.**

### 3.3 Board thermal mass (20×20 mm, 8-layer, 2 oz outer, 1 oz inner)
| Material | Mass | c_p | C |
|---|---|---|---|
| Copper (~45% fill) | ~2.0 g | 0.385 J/g·K | 0.77 J/K |
| FR4 | ~1.3 g | 1.1 J/g·K | 1.43 J/K |
| Components (FETs, caps) | ~1.5 g | ~0.7 | 1.05 J/K |
| **Total** | | | **≈ 3.3 J/K** |

### 3.4 Convective path
Under prop wash (~5 m/s), h ≈ 40 W/m²K. With both faces of 4 cm²:
```
R_ba ≈ 1/(40 · 8e-4) ≈ 31 K/W   (plus some conduction into the frame and wires, call it ~20 K/W)
τ_board = R_ba · C ≈ 20 · 3.3 ≈ 66 s
```
