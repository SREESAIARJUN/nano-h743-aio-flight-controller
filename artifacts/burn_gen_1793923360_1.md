## 2. Conduction Loss Model (6-step, synchronous rectification)

### 2.1 Temperature-dependent on-resistance

```
R_ds(T_j) = R_25 · [1 + α·(T_j − 25)]
```

At the design point T_j = 110 °C: R_ds = 1.2 · 1.3825 = **1.66 mΩ**.

### 2.2 Per-FET conduction duty over one electrical cycle

Each phase leg spends its electrical cycle in three 120° states:

| Phase state | High-side FET | Low-side FET |
|---|---|---|
| PWM-high (120°) | conducts D | conducts (1−D) (sync rect) |
| Driven-low (120°) | off | conducts 100% |
| Floating (120°) | off | off |

This gives the per-FET losses:

```
P_HS = I² · R_ds · D/3
P_LS = I² · R_ds · [1 + (1−D)]/3
```

The current path always runs through exactly two FETs, so per motor channel:

```
P_cond,ch = 2 · I² · R_ds        (independent of D)
```
