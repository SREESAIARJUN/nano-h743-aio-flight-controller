## 0. Architecture Clarification and Key Assumptions

I don't have the Job #48 requirements package, so every input below is stated explicitly and the model is parametric. Replace the bold values with datasheet and requirements data. The equations remain valid.

**Architecture correction.** ArduPilot does not run ESC commutation. A "STM32H743 4-in-1 ESC" stack must therefore be built as follows:

- **FC domain:** STM32H743 running ArduPilot. It generates 4× bidirectional DShot600 and reads eRPM telemetry.
- **ESC domain:** 4× independent ESC MCUs (e.g., AT32F421 or STM32G071 running AM32, or EFM8 running Bluejay). Each drives its own 3-phase bridge with **48 kHz PWM**.

The 48 kHz figure is an ESC-firmware PWM setting. The H743 never generates it.
