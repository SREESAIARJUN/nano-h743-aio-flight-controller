# STM32H743 AIO (FC + 4-in-1 ESC) Design Package, Job #38

**Scope:** loss models, thermal model, DShot DMA allocation and a reference netlist for an STM32H743 flight controller running ArduPilot, integrated with a 4-in-1 ESC.

**Status:** engineering reference design. Every numeric result depends on the assumption table in §0. Before release, substitute your actual MOSFET datasheet values and verify all pinouts against the manufacturer's datasheets.

## 0. Architecture Clarification and Baseline Assumptions

### Architecture

The H743 does **not** commutate the motors. A production 4-in-1 runs one dedicated ESC MCU per motor (e.g., AT32F421 / STM32G071 running AM32 or BLHeli_32) driving a 3-phase gate driver. The H743 runs ArduPilot and talks to those ESC MCUs over bidirectional DShot600.

```
            ┌────────────── STM32H743 (ArduPilot) ──────────────┐
            │ TIM1_CH1..4 ── bidir DShot600 ──► 4× ESC MCU (AM32) │
            └──────────────────────────────────────────────────────┘
ESC MCU n ──► 3-ph gate driver ──► 6× N-MOSFET (3 half-bridges) ──► Motor n
```

> **Reality check:** "80 A" on a nano-class board is a **burst** rating only. As §3 shows, the board's thermal mass limits full 4×80 A operation to a few seconds.

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step trapezoidal drive with synchronous rectification

Within any 60° commutation sector, phase A is PWM'd high and phase B is held low:

- **PWM on (duty D):** current flows through HS_A and LS_B.
- **PWM off (1−D):** current flows through LS_A (synchronous rectification) and LS_B
