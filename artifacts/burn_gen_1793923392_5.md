## 0. Scope, Architecture, and Assumptions

### 0.1 Architecture

The STM32H743 does **not** drive the power stage directly. A real AIO board is partitioned like this:

```
 ┌──────────────────────────┐   4× bidir DShot600 (single wire, inverted)
 │ STM32H743VIT6 (FC)       │──────────────────────────────┐
 │ ArduPilot, 480 MHz       │                              │
 └──────────────────────────┘                              ▼
                                   ┌───────────────────────────────────────┐
                                   │ 4× ESC MCU (AT32F421K8U7 / STM32G071) │
                                   │ AM32 firmware, 48 kHz center-aligned  │
                                   │ complementary PWM + dead time         │
                                   └───────────────┬───────────────────────┘
                                                   ▼
                                   4× 3-phase gate driver (FD6288Q class)
                                                   ▼
                                   4× 6-FET bridge (24 MOSFETs total)
```

The 48 kHz PWM and commutation are generated by the ESC MCUs, not the H743. Keeping these separate preserves ArduPilot timer resources and isolates firmware failure domains.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent On-Resistance

$$
R_{ds}(T_j) = R_{ds,25}\,\big[1+\alpha\,(T_j-25)\big],\qquad \alpha=\frac{k_T-1}{100}=0.006\ \text{K}^{-1}
$$

At T_j = 125 °C:

$$
R_{ds} = 1.2 \times 1.6 = 1.92\ \text{m}\Omega
$$

### 1.2 Current Path (Six-Step with Synchronous Rectification)

At any instant, exactly two phases conduct. With complementary PWM:

- **PWM-on:** high-side FET of phase A plus low-side FET of phase B conduct.
- **PWM-off:** low-side FET of phase A (synchronous rectifier) plus low-side FET of phase B conduct.

In both states the current path contains **two** R_ds in series, so the instantaneous loss is independent of duty cycle (dead time excluded):

$$
P_{cond,ESC} = I_{rms}^2 \cdot 2R_{ds}(T_j)
$$
