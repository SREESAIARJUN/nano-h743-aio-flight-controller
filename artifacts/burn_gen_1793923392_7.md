## 0. Architecture Clarification and Baseline Assumptions

The STM32H743 runs **ArduPilot** as the flight controller. It does not commutate motors. Each ESC channel has its own commutation MCU running AM32 or BLHeli_32. This split is standard and is required for bi-directional DShot, because the FC sends DShot and the ESC MCU returns eRPM telemetry on the same wire.

```
6S LiPo ─┬─► 4-in-1 ESC power stage (4× [ESC MCU + 3-ph gate driver + 6 FETs])
         │        ▲  DShot600 bidir (1 wire/motor)
         └─► BEC ─┤
                  └── STM32H743 FC (ArduPilot) ── IMU / Baro / OSD / UARTs
```

## 1. Conduction Loss Model

### 1.1 Current path in 6-step synchronous commutation

In any commutation sector, two phases conduct. The PWM leg alternates between the high-side FET (duty D) and its complementary low-side FET (1−D, synchronous rectification). The return leg's low-side FET is held fully on. The motor current I therefore always flows through **exactly two R_DS(on)** in series:

$$P_{cond,ch} = 2\, I^2\, R_{DS(on)}(T_j)$$

This holds independent of D, because synchronous rectification replaces the freewheel diode with the complementary FET. Dead-time diode conduction is handled separately in §2.3.

### 1.2 Temperature dependence

$$R_{DS(on)}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

| T_j | R_DS(on) | P_cond @ 80 A (per channel) |
|---|---|---|
| 25 °C | 1.00 mΩ | 12.8 W |
| 75 °C | 1.23 mΩ | 15.7 W |
| 100 °C | 1.34 mΩ | 17.1 W |
| 125 °C | 1.45 mΩ | **18.6 W** |

### 1.3 Per-FET distribution

Each phase conducts for 2/3 of the electrical cycle. Averaged over a full electrical revolution, the six FETs share the loss approximately equally:

$$P_{FET,avg} \approx \frac{P_{cond,ch}}{6} \approx 3.1\ \text{W @ } 125\,°C$$
