## 0. Architecture Decisions and Assumptions

**Architectural constraint.** ArduPilot does not perform BLDC commutation. The H743 runs ArduPilot and sends bidirectional DShot600 to four dedicated ESC MCUs on the same PCB. Each ESC MCU (AT32F421K8U7 running AM32, or an equivalent BLHeli_32-class target) generates the 48 kHz PWM and handles commutation. This is the only partition that gives a supportable firmware stack.

## 1. Conduction Loss Model (6-Step, Synchronous Rectification)

### 1.1 Current path

In trapezoidal commutation, one high-side (HS) switch PWMs on phase A while the low-side (LS) switch on phase B is held on.

- **During the on-time (D):** current flows through HS_A and LS_B.
- **During the off-time (1−D):** current freewheels through LS_A (synchronous rectification) and LS_B.

Current therefore always flows through exactly two channel resistances in series, independent of duty cycle (dead time excluded).

### 1.2 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C: R_ds = 1.2 × (1 + 0.6) = **1.92 mΩ**

### 1.3 Per-ESC conduction loss

With n FETs paralleled per switch position:

$$P_{cond,ESC} = 2\cdot I^2\cdot\frac{R_{ds}(T_j)}{n} + I^2 R_{Cu}$$

| Configuration | Per-FET loss (hottest FET) | ESC total, FETs only |
|---|---|---|
| n = 1, 80 A, 125 °C | 6400 × 1.92 mΩ = **12.3 W** | **24.6 W** |
| n = 2, 80 A, 125 °C | 40² × 1.92 mΩ = **3.07 W** | **12.3 W** |

**Copper term.** Each ESC has about 0.3 mΩ of path resistance (2 oz inner layers, phase pads, shunt). This adds 80² × 0.3 mΩ = **1.9 W**.

**Shunt.** A 0.25 mΩ shunt dissipates 1.6 W at 80 A. That loss is included in R_Cu above.

**Decision: n = 2 is mandatory for 80 A burst.** With a single FET, 12.3 W in a 3.3×3.3 mm package gives ΔT_j-pcb ≈ 18 K above an already hot board, so there is no margin. The rest of this document assumes **n = 2** (24 FETs per ESC section, 48 total for 4 motors). That is a very dense two-sided layout.

### 1.4 Self-consistent junction temperature and thermal runaway

Because R_ds depends on T_j, the steady-state solution is:

$$T_j = \frac{T_{ref} + R_{th}\,P_{25}\,(1-25\alpha)}{1-\alpha\,R_{th}\,P_{25}}, \qquad P_{25}=I^2R_{ds,25}$$

**Runaway criterion:** α · R_th · P_25 ≥ 1.

**Worked example** (single FET at 40 A): P_25 = 1.92 W and R_th = 1.5 K/W. Then α · R_th · P_25 = 0.017, which is very stable at junction level. Runaway risk exists at the board level instead, where the effective R_th to ambient is roughly 3–6 K/W for the whole board. See §3.
