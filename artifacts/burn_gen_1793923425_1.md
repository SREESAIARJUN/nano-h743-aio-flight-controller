# STM32H743 AIO Flight Controller with 4-in-1 ESC: Job #68 Engineering Model

## Scope, Architecture and Feasibility Warning

**Read this first.** Any "80 A" rating on a nano-class (20×20 or 25.5×25.5 mm) board can only be a **short burst, roughly 2 s**. It cannot be continuous. Section 3 shows why from first principles. At full throttle, four motors at 80 A each draw about **290 A from the battery** and dissipate about **90 W** in a few grams of PCB. Treat every number below as a design model built on stated assumptions. Validate each one against the datasheets of the components you select and against thermocouple or IR testing.

### 0.1 System Partitioning

ArduPilot does not commutate motors. The H743 runs ArduPilot and sends bidirectional DShot600 commands. Separate ESC MCUs run the 48 kHz PWM and commutation.

```
 6S LiPo ──► VBAT bus ──┬─► 4× 3-phase bridge (24 FETs) ──► M1..M4
                        │        ▲ gate drive
                        │   4× FD6288Q (3-ph gate driver, internal LDO/bootstrap)
                        │        ▲ 6× PWM @ 48 kHz
                        │   4× AT32F421 / STM32G071 (AM32 or BLHeli_32)
                        │        ▲ bidir DShot600 (1 wire each, 3.3 V)
                        └─► Buck 5 V / LDO 3.3 V ──► STM32H743VIH6 (ArduPilot)
```

## 1. Conduction Loss Model

### 1.1 Per-Leg Operating States

In each electrical cycle, each half-bridge leg spends:
- **1/3 as the PWM leg:** the high-side FET conducts for D, the low-side (synchronous) FET for 1−D.
- **1/3 as the return leg:** the low-side FET is fully ON.
- **1/3 floating:** no conduction loss. This is where the BEMF zero-cross is sensed.

The hot on-resistance is:

$$R_{hot} = k_T \cdot R_{ds(on),25} = 1.6 \times 1.0\,\text{m}\Omega = 1.6\,\text{m}\Omega$$

### 1.2 Per-FET Average Conduction Loss

High-side FET:

$$P_{HS} = \tfrac{1}{3}\,D\,I^2 R_{hot} = \tfrac{1}{3}(0.9)(6400)(1.6\times10^{-3}) = 3.07\ \text{W}$$

Low-side FET:

$$P_{LS} = \tfrac{1}{3}(1-D)\,I^2R_{hot} + \tfrac{1}{3}I^2R_{hot} = 0.34 + 3.41 = 3.75\ \text{W}$$

The low-side FET is the thermal-limiting device. It carries the return current for a full 120°.

### 1.3 Per-Motor and Board Totals

At any instant, two R_ds paths are in series with the current:

$$P_{cond,motor} = 2 I^2 R_{hot} = 2(6400)(1.6\,\text{m}\Omega) = 20.5\ \text{W}$$

Check: 3 legs × (3.07 + 3.75) W = 20.5 W. ✓

$$P_{cond,board} = 4 \times 20.5 = 82\ \text{W}$$
