# Job #48: 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #48 spec sheet, so the design assumptions are listed below. Every constant that depends on hardware is a named parameter. Change the parameters, not the structure.

## 0. Design Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, K_t ≈ 0.04–0.1 N·m/A |
| Rotor sensor | 14-bit magnetic encoder (MT6701 / AS5047P) per axis |
| Current sensing | 2-shunt low-side, sampled at PWM center |
| IMU_C | ICM-42688-P on the camera plate (the controlled body) |
| IMU_B | ICM-42688-P on the base/frame (the disturbance reference) |
| Gimbal order | Base → Yaw → Roll → Pitch → Camera |

**Loop rates**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| Velocity | 4 kHz (gyro ODR 8 kHz, decimated by 2 after filtering) | ~150–250 Hz |
| Attitude | 1 kHz | ~20–40 Hz |
| Cogging adaptation | runs inside the current ISR at low gain | — |

Keep a bandwidth separation of at least 5–10× between adjacent loops. This allows each inner loop to be treated as unity gain when tuning the next outer loop.

## 1. Field-Oriented Control

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

The offset θ_off is found at startup by applying V_d alone at θ_e = 0 and reading the encoder once the rotor settles.

### 1.2 Clarke transform (power-invariant amplitude form, with i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$
