# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual-IMU Vibration Rejection

**Assumptions.** I don't have the original "Job #0" spec, so this design uses typical brushless-gimbal parameters. Every parameter is a constexpr or constructor argument, so you can substitute your values.

- **Motors:** gimbal PMSMs (e.g., GBM2804/4108 class), 7 pole pairs, 12N14P, high phase resistance (R ≈ 5–15 Ω).
- **Encoders:** 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class).
- **IMUs:** two ICM-42688-P on the camera plate, each on its own SPI bus, both clocked from a common CLKIN.
- **MCU:** single Cortex-M7 or M4F with FPU (STM32H7/G4 class).

## 1. Loop Architecture and Rate Plan

```
 Setpoint q_ref (camera attitude)
      │
      ▼
 ┌──────────┐ ω_ref ┌─────────────┐ iq_ref ┌─────────────┐ v_dq ┌───────┐
 │ Attitude │──────►│ Velocity PI │───────►│ Current PI  │─────►│ SVPWM │──► Inverter ──► Motor
 │ P + FF   │  1kHz │  (joint)    │  4kHz  │ (d,q) FOC   │ 20kHz└───────┘
 └────▲─────┘       └─────▲───────┘   ▲    └──────▲──────┘
      │ q̂ (Mahony)        │ ω_joint   │ +i_cog    │ i_abc, θ_e (encoder)
      │                   │           │           │
 ┌────┴───────────────────┴────┐  ┌───┴──────────┐│
 │ Dual ICM-42688-P fusion     │  │ Anti-cogging ││
 │ AAF → notch bank → LPF →    │  │ Fourier LMS  │◄── θ_m (encoder)
 │ lever-arm avg → Mahony      │  └──────────────┘
 └─────────────────────────────┘  8 kHz ODR
```

| Loop | Rate | Target bandwidth | Separation |
|---|---|---|---|
| Current (d/q) | 20 kHz | ω_c ≈ 2π·1500 rad/s | — |
| Velocity | 4 kHz | ω_v ≈ 2π·80 rad/s | ≈ 19× below current |
| Attitude | 1 kHz | ω_θ ≈ 2π·12 rad/s | ≈ 7× below velocity |
| IMU sample / filter | 8 kHz | — | — |

**Rule of thumb:** keep at least 5× bandwidth separation between nested loops, and keep each loop's bandwidth at or below f_s/10 of its execution rate.
