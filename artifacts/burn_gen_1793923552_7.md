# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have any project files for "Job #41", so this design rests on the explicit assumptions below. Every assumption is a named constant, so you can swap in your real hardware values.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| MCU | STM32G4 / H7 class, FPU, 3 timers with center-aligned PWM and ADC triggering |
| Current sense | 2- or 3-shunt low-side, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz |
| Gimbal order | Yaw (Z, base) → Roll (X) → Pitch (Y, camera) |

**Loop rates (each loop's bandwidth is separated from the next by 5–10×):**
