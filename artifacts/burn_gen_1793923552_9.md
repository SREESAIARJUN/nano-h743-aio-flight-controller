# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #43)

## 0. Design Assumptions

I don't have the Job #43 specification, so the design rests on the assumptions below. Every value that depends on them is a named constant in `GimbalConfig`. Swap in your measured values before tuning.

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motor, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 2–5 mH, Kt ≈ 0.05–0.1 N·m/A |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| IMUs | 2× ICM-42688-P on the camera plate, opposite sides of the pitch axis, SPI @ 24 MHz, ODR 8 kHz |
| MCU | STM32G474 class (Cortex-M4F, 170 MHz, FPU) |
| Gimbal order | base → yaw (z) → roll (x) → pitch (y) → camera |
| Loop rates | Current/FOC 20 kHz
