# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #61)

I don't have the Job #61 specification, so the design rests on the assumptions in §0. All parameters are `constexpr` or configuration fields, so you can change them without touching the algorithms.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 6 Ω, L ≈ 2 mH, K_t ≈ 0.05 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) per axis |
| Current sense | Two inline/low-side shunts per axis. A voltage-mode fallback is provided. |
| MCU | Cortex-M4F/M7 with FPU
