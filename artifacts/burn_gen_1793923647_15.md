## 0. Architecture Corrections

Two points in the brief need correcting before the math is meaningful.

1. **The STM32H743 does not commutate the motors.** In a 4-in-1 stack, the H743 runs ArduPilot and generates bi-directional DShot600. Each of the four ESC channels has its own small MCU running AM32 or BLHeli_32. Typical choices are the AT32F421K8U7 or the STM32G071. The 48 kHz PWM, dead-time and BEMF sensing all live on those ESC MCUs.

2. **"80 A burst" on a nano (20×20 mm) format is a time-limited rating, not a capability.**
   - Section 3 shows roughly 23 W of dissipation per channel at 80 A.
   - The board can survive this for about **1 to 2 s**, not continuously.
   - Four channels at 80 A means **320 A** from the battery. That is outside what XT30/XT60 connectors and nano-sized pads can carry.
   - Recommended: rate the product as 80 A *single-channel* burst for ≤1 s and 35 to 40 A continuous with airflow. If you need more, move to a 30.5×30.5 format.

3. **Package fit.** The H743 must be the **TFBGA100 (H743VIH6, 8×8 mm)**. An LQFP100 (14×14 mm) does not fit a 20×20 FC with M2 holes.

## 2. Conduction Loss Model

**Current path.** In 6-step drive, current always flows through two series devices: one high-side and one low-side. When the PWM is on, the path is HS(A) to motor to LS(B). When the PWM is off, the path is LS(A) as a synchronous rectifier to motor to LS(B). The current is the same in both states. So at any instant two channels' worth of R_ds,on carry I_ph.

**Temperature-dependent resistance:**

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C, R_ds = 1.0 mΩ × 1.65 = **1.65 mΩ**.

**Conduction loss per ESC channel:**

$$P_{cond} = I_{ph}^2 \cdot 2R_{ds}(T_j) = 80^2 \times 3.3\,\text{m}\Omega = \mathbf{21.1\ W}$$

**PCB copper loss.** Assume 2 oz copper, a phase path 10 mm long and 3 mm wide, and two parallel layers:

$$R_{Cu} = \frac{\rho L}{wt} = \frac{1.72\times10^{-8}\times0.010}{0.003\times70\,\mu m}/2 \approx 0.41\,\text{m}\Omega$$

The current passes through two phase paths, so P_Cu ≈ 80² × 0.82 mΩ ≈ **5.2 W**.

This term is significant. Use 3 oz copper or heavier, add solder-filled phase pads, and stitch vias.

**Self-consistency.** Because R_ds depends on T_j, solve iteratively:

$$T_j = T_{ref} + P(T_j)\cdot Z_{th}(t)$$

This is done in Section 4.

## 3. Switching and Ancillary Losses at 48 kHz

Only one leg is PWM-switching at a time.

| Loss term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·40 ns·48 kHz | **1.94 W** |
| Dead-time diode | V_SD·I·2t_dead·f_sw = 0.8·80·200 ns·48 kHz | **0.61 W** |
| Reverse recovery | V·Q_rr·f_sw = 25.2·50 nC·48 kHz | **0.06 W** |
| C_oss | ½·C_oss·V²·f_sw = 0.5·2 nF·635·48 kHz | **0.03 W** |
| Gate drive (2 FETs, dissipated in driver) | 2·Q_g·V_gs·f_sw | **0.06 W** |
| **Subtotal switching** | | **≈ 2.7 W** |

**Per-channel total at 80 A and T_j = 125 °C:**

$$P_{ch} = 21.1 + 2.7 + 5.2 \approx \mathbf{29\ W}$$

Without copper loss the total is 23.8 W.

**Design sensitivity:** ∂P_sw/∂f_sw ≈ 56 µW per Hz. Moving from 48 kHz to 24 kHz saves about 1.3 W per channel. Conduction loss dominates, so effort is better spent on R_ds,on and copper than on frequency.

## 4. Thermal Model

### 4.1 Network

The heat path is a two-level Foster/Cauer approximation:

```
Pj ──[Zth,jc]── Tcase ──[R_pcb-spread]── T_board ──[R_conv]── T_amb
                                             │
                                        C_board (lumped)
```

**[A] values:**

| Parameter | Value |
|---|---|
| Z_th,jc steady state (3.3×3.3 DFN) | 1.5 K/W |
| Z_th,jc time constant | ≈ 20 ms |
| R_case→board spreading, per FET | 8 K/W |
| Board mass | 3.5 g |
| c_p (composite: FR4, Cu, components) | ~0.7 J/g·K |
| C_board | ≈ 2.5 J/K |
| R_conv, board to air, prop-wash ~5 m/s | ≈ 6 K/W |
| R_conv, still air | ≈ 20 K/W |

### 4.2 Steady state (continuous rating)

Requirement: T_board ≤ 100 °C, T_amb = 35 °C.

- Allowable total power with airflow: 65 K / 6 K/W ≈ **10.8 W** for the whole board.
- Per channel (four channels): 2.7 W. Solving I²·3.6 mΩ + switching (scaled ∝ I) ≈ 2.7 W gives I ≈ **22 A continuous per channel with all four loaded**. This assumes R_ds ≈ 1.4 mΩ at the operating point plus copper.
- In real flight, current is far from evenly sustained. Duty-cycle averaging typically supports a "35 A continuous" marketing rating with margin only if average current is below about 22 A.
