## 0. Feasibility Findings

These are the most important results in this document:

1. **80 A per channel on a nano-class (20×20 / 30×30 mm) board is a transient (burst) rating only.** Steady-state, this board class can reject roughly 15–25 W total, which supports about **35–40 A continuous per channel**. The 80 A burst is thermally limited to about **5 s** from a 40 °C start (§3.4).
2. **At burst (D → 1), switching loss is small and conduction dominates.** 48 kHz is affordable, but it costs about 1.8 W per channel at mid-to-high duty.
3. **The H743 does not commutate the motors.** In a 4-in-1 architecture, the H743 sends DShot to four ESC MCUs (e.g., AT32F421 running AM32), and those MCUs generate the 48 kHz PWM. The DShot/DMA section therefore applies to the FC↔ESC link only.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R = 0.8 × 1.6 = **1.28 mΩ**.

### 2.2 Per-channel conduction loss

Phase current flows through exactly two FETs at any instant:

- **PWM leg:** HS conducts for D, sync-LS for (1−D). Loss = I²R[D + (1−D)] = I²R.
- **Static leg:** Loss = I²R.

$$P_{cond,FET} = 2\,I^2 R_{DS}(T_j) = 2(80)^2(1.28\,\text{m}\Omega) = \mathbf{16.4\ W}$$

### 2.3 Shunt and copper losses

The shunt carries DC-link current, so its RMS is I√D:

$$P_{sh} = I^2 D\, R_{sh} = 6400 \times 0.9 \times 0.5\,\text{m}\Omega = \mathbf{2.9\ W}\quad (D = 0.9)$$

$$P_{cu} = I^2 R_{cu} = \mathbf{1.9\ W}$$

### 2.4 Per-FET distribution

Each FET is active 1/3 of the electrical period. The average per FET is:

$$\frac{16.4\text{ W}}{6} \approx 2.7\text{ W}$$

The **instantaneous** dissipation is 8.2 W, though. This matters if the electrical frequency is low (startup, stalled prop), because Z_th(jc) will not average it.

## 3. Switching Loss Model (48 kHz, PWM leg only)

### 3.1 Hard-switching V·I overlap

Gate currents during the Miller plateau:

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_{on}} = 1.75\text{ A}, \qquad I_{g,off} = \frac{V_{pl}}{R_{off}} = 1.5\text{ A}$$

Transition times:

$$t_r = \frac{Q_{sw}}{I_{g,on}} = 13\text{ ns}, \qquad t_f = \frac{Q_{sw}}{I_{g,off}} = 15\text{ ns}$$

Overlap loss:

$$P_{VI} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw} = \tfrac{1}{2}(25.2)(80)(28\text{ ns})(48\text{ kHz}) = \mathbf{1.35\ W}$$
