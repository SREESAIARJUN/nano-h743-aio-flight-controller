## 0. Architecture Assumptions and Reality Check

**The STM32H743 does not drive the MOSFETs.** ArduPilot is flight-control firmware, not ESC firmware. The correct partition is:

| Block | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743VIH6 (TFBGA100) or VIT6 (LQFP100), 480 MHz | ArduPilot (ChibiOS) |
| ESC MCUs (×4) | AT32F421K8U7 or STM32G071GBU6, one per motor | AM32 (supports bi-directional DShot and EDT) |
| Gate drivers (×4) | FD6288Q (3-phase, 250 mA/500 mA source/sink typ.) | n/a |
| Power MOSFETs (×24) | 40 V N-ch, DFN3.3×3.3 class | n/a |

The H743 sends bi-directional DShot600 to the four ESC MCUs. Each ESC MCU generates 48 kHz complementary PWM and runs six-step (trapezoidal) commutation.

**Reference parameters.** These are representative of a 40 V DFN3.3 part. Substitute datasheet maximums for your chosen FET before signing off.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V | 6S fully charged (design at 6S max) |
| R_DS(on),25 | 1.3 mΩ (max, V_GS = 10 V) | |
| α | 0.006 K⁻¹ | R_DS(on) temperature coefficient |
| Q_g / Q_gs / Q_gd | 40 / 10 / 8 nC | Gate charges |
| V_pl | 3.5 V | Miller plateau |
| Q_rr | 40 nC | Body-diode reverse recovery charge |
| Q_oss | 50 nC | Output charge |
| V_F | 0.8 V | Body-diode forward voltage |
| R_thJC | 1.0 K/W | Junction-to-case (bottom) |
| f_sw | 48 kHz | PWM frequency |
| t_dt | 100 ns | Dead time per edge |
| I_ph | 80 A | Burst phase current |
| T_j,target | 110 °C | Design-point junction temperature |

> **Bottom line up front:** on a 20×20 or 25.5×25.5 mm nano board, 80 A per channel is a **sub-2-second burst rating only**. Sustainable continuous current is about **18–22 A per channel**. Section 3 derives this. Marketing "80 A burst" figures must be backed by a defined burst duration.
