# STM32H743 Nano FC + 4-in-1 ESC (Job #52): Architecture & Math Model

**Document scope.** This is a reference design model, not a production-released design. The FET choice, stackup and layout assumptions are stated explicitly so you can substitute vendor datasheet values. Every number marked **[A]** is an assumption to be replaced with measured or datasheet data before PCB release.

**A key architectural point up front.** The 48 kHz PWM and the switching losses belong to the **ESC MCU** (AM32/BLHeli_32 class), not the H743. The H743 runs ArduPilot and generates bidirectional DShot600. The model is therefore split into two domains:

- **Power stage (ESC):** sections 1–4.
- **Flight-controller timing and DMA (H743):** section 5.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,\left[1+\alpha\,(T_j-25)\right],\quad \alpha \approx 0.005\ \text{K}^{-1}\ \text{[A]}$$

At T_j = 125 °C: R_DS = 1.2 mΩ × 1.5 = **1.8 mΩ**.

### 1.2 Current path per commutation step

The bridge uses six-step trapezoidal commutation with complementary PWM on phase A, while the phase-B low side is held on:

| Device | Conduction fraction | Current |
|---|---|---|
| HS_A (PWM) | D | I |
| LS_A (synchronous rectifier) | 1 − D | I |
| LS_B (static on) | 1 | I |

Instantaneous loss per motor:

$$P_{cond} = I^2 R_{DS}\left[D + (1-D)\right] + I^2 R_{DS} + I^2 R_{Cu} = I^2\left(2R_{DS}(T_j) + R_{Cu}\right)$$

The result is **independent of duty cycle** because synchronous rectification is used. That is why burst loss is set by phase current, not by throttle position.

R_Cu covers phase copper, vias and solder joints. Assume **[A]** R_Cu = 0.4 mΩ per path.

Ripple correction: the phase current RMS is $I_{rms}=\sqrt{I^2+\Delta I_{pp}^2/12}$. With motor inductance L_ph ≈ 10 µH (line-to-line), the worst case is $\Delta I_{pp} = V/(4 L f) = 25.2/(4·10µ·48k) ≈ 13$ A. That adds only +0.9 % to I², which is negligible at 80 A.

### 1.3 Numbers at 80 A, T_j = 125 °C

$$P_{cond} = 80^2(2\times1.8 + 0.4)\,\text{m}\Omega = 6400 \times 4.0\,\text{m} = \mathbf{25.6\ W/motor}$$

Of this, the copper term is 2.6 W. The hottest single device is LS_B, at 100 % conduction:

$$P_{LS_B} = 80^2 \times 1.8\text{m} = \mathbf{11.5\ W}$$

The commutation sequence rotates which FET plays the LS_B role. Each low-side FET therefore averages roughly ⅓ to ½ of this over an electrical revolution, but the thermal time constant of the die (≈ ms) is shorter than a commutation step at low eRPM. Design to the 11.5 W instantaneous value.

## 2. Switching Loss Model at 48 kHz

Only HS_A hard-switches. LS_A commutates softly, with body-diode conduction during dead time.

### 2.1 V–I overlap loss

$$P_{VI} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 40\text{n} \times 48\text{k} = \mathbf{1.94\ W}$$

### 2.2 Reverse recovery loss

The LS_A body diode is recovered by the HS_A turn-on:

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\text{n}\times25.2\times48\text{k} = \mathbf{0.05\ W}$$

This is understated at high di/dt. Scale Q_rr by the datasheet di/dt curve.

### 2.3 Output capacitance loss

$$P_{oss} \approx Q_{oss} V_{bus} f_{sw} = 50\text{n}\times25.2\times48\text{k} = \mathbf{0.06\ W}$$

### 2.4 Dead-time diode loss

$$P_{dt} = V_{SD}\, I\, (2 t_{dt}) f_{sw} = 0.8\times80\times200\text{n}\times48\text{k} = \mathbf{0.61\ W}$$

### 2.5 Gate drive loss

This is dissipated in the driver and gate resistors, not in the FET:

$$P_g = 2\, Q_g V_{GS} f_{sw} = 2 \times 45\text{n}\times10\times48\text{k} = \mathbf{0.043\ W}$$

### 2.6 Switching summary per motor

$$P_{sw,tot} = 1.94 + 0.05 + 0.06 + 0.61 \approx \mathbf{2.66\ W}$$
