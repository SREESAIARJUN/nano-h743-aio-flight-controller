# STM32H743 AIO Flight Controller with 4-in-1 ESC (Job #59): Power-Stage, Thermal, and Bidirectional DShot Architecture

## 0. Feasibility Findings

These issues change the architecture, so they come first.

| # | Finding | Consequence |
|---|---|---|
| F1 | The STM32H743 runs ArduPilot (the flight-control side). It does not commutate motors. A 4-in-1 ESC needs 4 dedicated ESC MCUs running AM32 or BLHeli_32-class firmware. | The architecture is H743 (FC) plus 4× AT32F421 (AM32), linked by bidirectional DShot600. |

## 1. System Block Architecture

```
 6S LiPo (≤25.2 V) ──┬── Bulk caps (on-board + external 1000 µF low-ESR)
                     ├── Shunt (0.2 mΩ) → INA → ADC (H743 battery current)
                     ├── ESC ch1..4: AT32F421 ─ FD6288Q ─ 3× half-bridge (6 FETs)
                     └── Buck 5 V / 3.3 V → FC board (STM32H743VIT6)

 FC (STM32H743) ── TIM1_CH1..4 (PE9/PE11/PE13/PE14) ── bidir DShot600 ── ESC MCUs (PA2/TIM15 or equivalent AM32 input pin)
```

## 2. Conduction-Loss Model (80 A burst)

### 2.1 Commutation topology

AM32 uses 6-step trapezoidal commutation with complementary (synchronous) PWM. In any sector:

- **PWM on-time:** HS_A and LS_B conduct.
- **PWM off-time:** LS_A (synchronous rectification) and LS_B conduct.

Two FETs therefore always carry the phase current, independent of duty D (dead time is ignored here and handled in §3).

### 2.2 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha\,(T_j-25)]$$

Reference FET class: 40 V, R_DS,25 = 1.0 mΩ max at V_GS = 10 V, PDFN5×6 **[VERIFY]**. With α ≈ 0.005 K⁻¹ (typical for trench FETs):

| T_j (°C) | R_DS (mΩ) |
|---|---|
| 25 | 1.00 |
| 100 | 1.38 |
| 125 | 1.50 |

### 2.3 Per-channel conduction loss

With low current ripple in trapezoidal drive, I_rms ≈ I_ph = 80 A:

$$P_{cond,ch} = I^2 \cdot 2R_{DS}(T_j) = 6400 \times 2 \times 1.5\,\text{m}\Omega = \mathbf{19.2\ W}$$

### 2.4 PCB copper loss (not negligible at 80 A)

Sheet resistance is R_□ = ρ/t. For 2 oz (70 µm) copper, R_□ ≈ 0.245 mΩ/□ at 25 °C, rising to about 0.31 mΩ/□ at 90 °C (copper α = 0.0039 K⁻¹).

The current path per channel is battery pad → HS FET → phase pad → motor → phase pad → LS FET → GND. That is about 8 squares, split across 2 parallel layers:

$$R_{Cu} \approx \frac{8 \times 0.31}{2} \approx 1.24\ \text{m}\Omega \;\Rightarrow\; P_{Cu} = 80^2 \times 1.24\text{m} \approx \mathbf{7.9\ W}$$

Copper loss heats the board directly, so it counts toward the thermal budget in §4.

## 3. Switching-Loss Model at f_sw = 48 kHz, V_bus = 25.2 V

Only the PWM-switched FET (HS of the active phase) hard-switches. The synchronous LS commutates through its body diode during dead time.

| Term | Equation | Parameters **[VERIFY]** | Loss |
|---|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f | t_r = t_f = 15 ns | ½·25.2·80·30n·48k = **1.45 W** |
| C_oss discharge | Q_oss·V·f | Q_oss = 30 nC | **0.036 W** |
| Body-diode reverse recovery | Q_rr·V·f | Q_rr = 40 nC | **0.048 W** |
| Dead-time diode conduction | V_f·I·2t_dt·f | V_f = 0.8 V, t_dt = 100 ns | 0.8·80·200n·48k = **0.61 W** |
| Gate charge (mostly in driver) | 2·Q_g·V_GS·f | Q_g = 50 nC, 10 V | **0.048 W** |
| **Total switching per channel** | | | **≈ 2.2 W**
