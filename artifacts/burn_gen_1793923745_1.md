## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Transforms

Clarke transform (amplitude-invariant, with `i_a + i_b + i_c = 0`):

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

Park transform, with electrical angle `θ_e = p·(θ_m − θ_offset)`:

```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

Inverse Park transform:

```
v_α = v_d cos θ_e − v_q sin θ_e
v_β = v_d sin θ_e + v_q cos θ_e
```

### 1.2 PMSM Model in the dq Frame

```
v_d = R i_d + L_d di_d/dt − ω_e L_q i_q
v_q = R i_q + L_q di_q/dt + ω_e L_d i_d + ω_e λ_m
τ_e = (3/2) p λ_m i_q = K_t i_q          (surface PM, L_d = L_q)
```

### 1.3 Current PI by Pole-Zero Cancellation

The plant is `G(s) = 1/(L s + R)`. Choose a closed-loop bandwidth `ω_c`, typically ≤ 2π·f_pwm/20, i.e. about 2π·1 kHz:

```
K_p,i = L · ω_c
K_i,i = R · ω_c
```

The open loop then reduces to `ω_c / s`, and the closed loop to a first-order lag with time constant `1/ω_c`.

Add decoupling and back-EMF feedforward:

```
v_d* = PI_d(0 − i_d)    − ω_e L i_q
v_q* = PI_q(i_q* − i_q) + ω_e L i_d + ω_e λ_m
```

The voltage-vector limit is `|v_dq| ≤ V_bus/√3`. Prioritise `v_d`, then clamp `v_q` to `√(V_max² − v_d²)`.

### 1.4 SVPWM by Min-Max Zero-Sequence Injection

This is equivalent to sector-based SVPWM and needs no branches:

```
v_a = v_α
v_b = −½ v_α + (√3/2) v_β
v_c = −½ v_α − (√3/2) v_β
v_0 = −(max(v_a,v_b,v_c) + min(v_a,v_b,v_c)) / 2
d_x = ½ + (v_x + v_0) / V_bus          x ∈ {a,b,c}
```

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Structure

```
θ* ──►[P(+I) angle, 1 kHz]──ω*──►[PI velocity, 4 kHz]──i_q*──►[PI current, 20 kHz]──► SVPWM
        ▲  +ω_ff                    ▲  +i_ff (accel + cogging + friction)
        θ̂ (IMU attitude / encoder)  ω̂ (gyro projected on joint axis, or encoder PLL)
```

For gimbal stabilisation, the velocity loop is closed on the **camera gyro projected onto the joint axis**, not on the encoder. This rejects base motion at the full velocity-loop bandwidth. The encoder supplies commutation and joint-limit and kinematic information.

### 2.2 Mechanical Plant

```
J ω̇ = K_t i_q − B ω − τ_cog(θ) − τ_dist
```

Treating the closed current loop as unity (`ω_c ≫ ω_v`), the plant becomes `G_v(s) = K_t / (J s + B)`.

### 2.3 Velocity PI

Use a symmetric-optimum-style placement. Crossover is at `ω_v`, with the PI zero a factor `a` (typically 4) below it:

```
K_p,v = J ω_v / K_t
K_i,v = K_p,v · ω_v / a
```

Choose `ω_v ≤ ω_c / 5`. `ω_v ≤ 2π·f_v / 10` is a sampling-limited upper bound.

Discretise with backward Euler and back-calculation anti-windup (gain `K_aw ≈ 1/K_p` normalised):

```
e[k]   = ω*[k] − ω̂[k]
u_u[k] = K_p e[k] + I[k−1] + u_ff[k]
u[k]   = sat(u_u[k], ±I_max)
I[k]   = I[k−1] + T_s ( K_i e[k] + K_aw (u[k] − u_u[k]) )
```

The feedforward term is:

```
u_ff = (J α* + B ω* + τ̂_cog(θ) + τ̂_c sgn(ω*)) / K_t
```

### 2.4 Angle Loop

Use P plus an optional small I to remove gravity or imbalance bias:

```
e_θ = wrap(θ* − θ̂)             wrap to (−π, π]
ω*  = K_p,θ e_θ + K_i,θ ∫e_θ + ω_ff
K_p,θ = ω_θ,  with ω_θ ≤ ω_v / 4
```
