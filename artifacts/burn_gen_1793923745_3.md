# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #44", so this design states its assumptions explicitly. Every gain is computed from physical parameters, so you can substitute your measured values without changing the structure.

## 0. Assumptions and Timing Architecture

| Item | Assumed value | Notes |
|---|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz | CORDIC is useful for sin/cos |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH | Measure per axis |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A/MT6701 class) | Used for commutation and cogging |
| PWM | 20 kHz center-aligned, 3-phase, low-side shunts | |
| IMU | 2 × ICM-42688-P on the camera plate, SPI, synchronous sampling | Shared CLKIN/FSYNC recommended |

| Loop | Rate | Bandwidth target | Feedback |
|---|---|---|---|
| Current (d/q) | 20 kHz | ω_c ≈ 2π·1500 rad/s | Phase shunts plus encoder angle |
| Rate (inertial) | 4 kHz | ω_v ≈ 2π·120 rad/s | Fused, filtered IMU gyro |
| Angle (attitude) | 1 kHz | ω_θ ≈ 2π·20 rad/s | Fused attitude quaternion |
| IMU ODR | 8 kHz, decimated to 4 kHz | | |

Each loop is placed at least 5–10× slower than the loop inside it. This lets each inner loop be treated as ≈1 when designing the outer loop.

The stabilisation design choice is this: the rate loop closes on the **inertial gyro rate of the camera**, not on encoder speed. This is what rejects base motion. The encoder is used only for commutation, cogging compensation, and the joint-velocity estimate used in back-EMF decoupling.

## 1. Field-Oriented Current Control

### 1.1 Transforms

Electrical angle: θ_e = p·θ_m − θ_offset (θ_offset is found by alignment calibration).

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant (PMSM, surface magnets, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 1.3 Current PI with Decoupling

Add feedforward of the cross-coupling and back-EMF terms:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

After decoupling, each axis is the first-order plant 1/(Ls+R). Choosing the zero of the PI to cancel the plant pole (pole-zero cancellation) gives:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c\quad\Rightarrow\quad \frac{i}{i^*}=\frac{\omega_c}{s+\omega_c}$$

Practical bound: ω_c ≤ 2π·f_PWM/10, because of the PWM and computation delay (≈1.5 T_s).

### 1.4 Discretisation and Anti-Windup

Use forward Euler for the integrator with **back-calculation** anti-windup. The integrator sees the unsaturated output u, the saturated output u_sat, and is pulled back by the difference:

$$I_{k+1} = I_k + T_s\left[K_i e_k + K_{aw}(u_{sat,k}-u_k)\right],\qquad K_{aw}\approx \frac{K_i}{K_p}$$
