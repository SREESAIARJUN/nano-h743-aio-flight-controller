# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual-IMU Vibration Rejection

**Assumptions.** I don't have the original Job #32 specification, so the design rests on the assumptions below. Every one is a single constant in the code (§7.1).

| Item | Assumed value |
|---|---|
| MCU | STM32G474 class Cortex-M4F at 170 MHz, single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A or MT6701) |
| Inverter | 3-phase, 12 V bus, low-side current shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, FIFO/DRDY at ODR 8 kHz |
| Loop rates | current 20 kHz, velocity 4 kHz, attitude/angle 1 kHz, IMU 8 kHz |

## 1. System Architecture

```
          ┌──────────── 1 kHz ────────────┐ ┌──── 4 kHz ─────┐ ┌──────── 20 kHz ────────┐
 q_ref ──►│ Attitude error → joint angle  │ │ Velocity PI(D) │ │ iq PI ─► invPark ─► SVPWM ─► Inverter ─► Motor
          │ P + I, rate feed-forward      ├►│ + accel FF     ├►│ id PI    (decoupled)   │        │
          └───────────▲───────────────────┘ └───▲────────────┘ └──▲────────▲────────────┘        │
                      │ q̂ (Mahony)               │ ω_joint          │ i_abc  │ θ_e              │
            ┌─────────┴────────────┐             │                  │        │                  │
 IMU A ─►───┤ notch bank → LPF →   │             │       Cogging FF─┘ (iq_ff(θ_m))              │
 IMU B ─►───┤ lever-arm → fusion   ├─────────────┘                                               │
            └──────────────────────┘          Encoder ─► PLL observer (θ_m, ω_m) ◄───────────────┘
```

Two design rules govern the structure:

1. **Bandwidth separation.** Each outer loop has at least 5× lower bandwidth than the loop inside it:
   - current: 2 kHz
   - velocity: 150–300 Hz
   - angle: 20–40 Hz
2. **Sensor roles.** The encoder is used for commutation and anti-cogging. The IMU drives stabilization.
   - The camera-frame gyro is mapped to joint rates and closes the velocity loop.
   - IMU attitude closes the angle loop.

## 2. Field-Oriented Current Loop (20 kHz)

### 2.1 Transforms

Amplitude-invariant Clarke transform, assuming balanced phases ($i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with electrical angle $\theta_e = p\,\theta_m - \theta_{\text{off}}$:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
