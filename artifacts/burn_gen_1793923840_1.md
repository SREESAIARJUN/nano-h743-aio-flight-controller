# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #35): Design Model

**Scope:** 6S (25.2 V max), 80 A burst per channel, 48 kHz ESC PWM, ArduPilot with bi-directional DShot600.

---

## 0. Architecture and Assumptions

### 0.1 System partitioning

The H743 does **not** commutate the motors. A 4-in-1 ESC at 48 kHz needs per-motor closed-loop commutation with sub-microsecond deadtime control. That job belongs to dedicated ESC MCUs. The H743 runs ArduPilot and talks to them over bi-directional DShot600.

```
            ┌────────────────────── STM32H743VIH6 (ArduPilot) ─────────────────────┐
 IMU/Baro ──┤ SPI1/SPI4/I2C2                                                       │
            │ TIM3_CH3/CH4, TIM5_CH1/CH2 ── BDShot600 ──┐                          │
            └───────────────────────────────────────────┼──────────────────────────┘
                                                        │ 4× signal (+ series 100 Ω)
     ┌──────────────┬──────────────┬──────────────┬─────┴────────┐
  ESC MCU1       ESC MCU2       ESC MCU3       ESC MCU4      (STM32G071, AM32 firmware)
     │ 3-ph gate driver (FD6288Q class) ×4
     │ 6× N-MOSFET per channel (24 total)
     └── Motor A/B/C
```

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 110 °C: R_ds = 1.0 × (1 + 0.006 × 85) = **1.51 mΩ**

This is self-consistent with the thermal result in §3. Iterate if T_j changes.

### 1.2 Six-step commutation with complementary (synchronous) PWM

This is the AM32 default. In any 60° sector, phase X is PWM'd high-side and phase Y's low-side is held on:

| Device | Conduction fraction | Loss |
|---|---|---|
| HS_X | D | I² R_ds D |
| LS_X (synchronous rectification) | 1 − D | I² R_ds (1 − D) |
| LS_Y | 1 | I² R_ds |

$$P_{cond,ch}=I^2R_{ds}\,[D+(1-D)+1]=\boxed{2\,I^2R_{ds}(T_j)}$$

The result is independent of duty. With synchronous rectification there are always exactly two FETs in the current path.
