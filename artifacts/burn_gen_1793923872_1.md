          ▲                      ▲                ▲  iq_ff         ▲ i_a,i_b ADC              │

          │                      │        [Anti-cogging FF(θ_m, ω)]◄── θ_m encoder ◄─────────┘

**Bandwidth separation rule.** Each outer loop should be at least 4–5× slower than the loop inside it:

- Current loop: f_c,i ≈ 1.5–2 kHz
- Velocity loop: f_c,ω ≈ 150–300 Hz
- Angle loop: f_c,θ ≈ 30–60 Hz

## 2. FOC Inner Current Loop (20 kHz)

### 2.1 Transforms

The electrical angle is θ_e = p·(θ_m − θ_offset), where p = 7.

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 PMSM model in the d-q frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac{3}{2}p\lambda_m i_q = K_t i_q$$

### 2.3 PI control with decoupling and back-EMF feedforward

$$v_d^* = K_{p}e_d + K_i\!\int e_d\,dt \;-\; \omega_e L_q i_q$$
$$v_q^* = K_{p}e_q + K_i\!\int e_q\,dt \;+\; \omega_e (L_d i_d + \lambda_m)$$

**Gain selection by pole-zero cancellation.** Once decoupled, the plant is 1/(Ls + R). Choosing

$$K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}$$

gives a closed loop of ω_ci/(s + ω_ci).

- With ω_ci = 2π·1500 rad/s: K_p = 19.8 V/A and K_i = 52 800 V/(A·s).
- Keep ω_ci·T_s ≤ 0.5. Here 9425 × 50 µs = 0.47, which is acceptable.

**Delay compensation.** PWM update introduces a 1.5·T_s transport delay. Rotate the inverse Park transform by

$$\theta_e' = \theta_e + 1.5\,\omega_e T_s$$

### 2.4 Voltage limiting and anti-windup

Limit the voltage vector to the inscribed hexagon circle:

$$|v_{dq}| \le V_{dc}/\sqrt3$$

Give the d-axis priority, then let the q-axis use the remainder:

$$v_q^{max}=\sqrt{V_{max}^2 - v_d^2}$$

Use **back-calculation anti-windup**, with K_aw ≈ 1/K_p:

$$\dot x_I = K_i e + K_{aw}(v_{sat} - v_{unsat})$$

### 2.5 SVPWM by min-max zero-sequence injection

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$
