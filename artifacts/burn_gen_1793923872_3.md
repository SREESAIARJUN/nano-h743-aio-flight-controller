## 1. Loop Architecture and Rate Plan

```
                  ┌──────────── 1 kHz ────────────┐ ┌──── 4 kHz ────┐ ┌────── 20 kHz ──────┐
 q_ref ──► attitude │ e_q → joint-space angle err  │ │ velocity PI   │ │ id/iq PI + decouple│──► SVPWM ──► motor
          error ───►│ P + I (Jacobian mapped)      ├►│ + ω_ref ff    ├►│ + cogging ff       │
                  └───────────────▲───────────────┘ └──────▲────────┘ └──────▲─────────────┘
                                  │                        │                 │ θ_e (encoder), i_abc
              Mahony attitude ◄───┴──── fused gyro ◄───────┴─ dual ICM-42688-P (8 kHz ODR)
                                        (AAF → notch bank → vote/fuse → LPF)
```

**Bandwidth separation.** Keep a ratio of at least 4–5× between adjacent loops so each outer loop sees its inner loop as roughly unity gain.

| Loop | Rate f_s | Closed-loop bandwidth | Phase budget |
|---|---|---|---|
| Current (d/q) | 20 kHz | ω_c = 2π·1500 rad/s | ½-sample PWM delay + 1 sample compute |
| Velocity | 4 kHz | ω_v = 2π·120 rad/s | Includes the IMU filter group delay |
| Angle | 1 kHz | ω_a = 2π·25 rad/s | — |

## 2. FOC Current Loop: Equations

### 2.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Here θ_off is found at startup by forcing $v_d = V_{\text{align}},\ v_q = 0$ at θ_e = 0 and reading the encoder.

**Latency compensation.** The encoder sample is one period T_pwm old when the duty cycle is applied:

$$\hat\theta_e = \theta_e + p\,\hat\omega_m\,(1.5\,T_{pwm})$$

### 2.2 Clarke transform (amplitude-invariant, 2 shunts)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 2.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.4 Plant model and PI design (pole-zero cancellation)

The motor in the rotor frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

With decoupling feed-forward, the plant per axis reduces to $G(s) = 1/(Ls+R)$.

Choose $C(s) = K_p + K_i/s$ with:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \quad\Rightarrow\quad T(s) = \frac{\omega_c}{s+\omega_c}$$

With the assumed values (L = 2.1 mH, R = 5.6 Ω, ω_c = 9425 rad/s): **K_p = 19.8 V/A, K_i = 52 780 V/(A·s)**.
