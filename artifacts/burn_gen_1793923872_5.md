## 2. Field-Oriented Current Loop (20 kHz)

### 2.1 Clarke transform (amplitude-invariant)

```
i_α = i_a
i_β = (i_a + 2·i_b) / √3          (2-shunt, assumes i_a + i_b + i_c = 0)
```

With 3 shunts, choose the two phases with the largest low-side on-time to avoid sampling-window problems at high modulation.

### 2.2 Park transform

```
i_d =  i_α·cos θ_e + i_β·sin θ_e
i_q = −i_α·sin θ_e + i_β·cos θ_e
```

### 2.3 Plant model (surface PMSM, L_d ≈ L_q = L)

```
v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
v_q = R·i_q + L·di_q/dt + ω_e·L·i_d + ω_e·λ_m
τ_e = K_t·i_q
```

### 2.4 Current PI with decoupling, back-EMF feedforward and anti-windup

**Gains.** Use pole-zero cancellation with target current bandwidth ω_c. Set ω_c ≤ 2π·f_pwm/20, about 2π·1 kHz here.

```
K_p,i = L·ω_c
K_i,i = R·ω_c
```

The closed loop then reduces to the first-order system i/i* = ω_c / (s + ω_c).

**Discrete law.** Ts = 1/f_pwm, e_x
