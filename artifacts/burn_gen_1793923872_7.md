# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

**Note on scope:** I don't have the Job #28 specification document, so this design states its assumptions explicitly in §0. Every parameter that depends on your hardware is a named constant in the code. Replace those constants with the values from your spec and the tuning formulas in §2 still apply.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G474 / H743 class) |
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| Current sense | 2 or 3 low-side shunts, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetrically about the rotation center (r_B = −r_A), SPI, 8 kHz ODR |
| Kinematics | Yaw (base) → Roll → Pitch (camera) |

### Loop rates and bandwidths

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz | ~1.5 kHz |
| Velocity (PI + cogging feedforward) | 5 kHz | ~150 Hz |
| IMU filtering | 8 kHz | n/a |
| Attitude / angle (P + rate feedforward) | 1 kHz | ~20 Hz |

Each loop's bandwidth is at least 5–10× below the loop inside it. This keeps the cascade approximately decoupled, so each loop can be designed independently.

```
 IMU A ─┐   [AAF→Notch(ANF)→LPF]                     q_ref (stick/follow)
 IMU B ─┴─► lever-arm-cancel fuse ──► Mahony SO(3) ──► q_err ──► ω_cmd_cam
                                                                      │ J(q)^-1 (DLS)
 Encoder ─► PLL observer ─► ω̂_m, θ̂_m ──────────────────────► q̇_cmd (per joint)
                                                                      │
                     Velocity PI + cogging FF (LMS) ──► i_q* ──► FOC current PI ──► SVPWM
```
