## 0. Scope, Architecture, and Assumptions

### 0.1 System partition

In this architecture the STM32H743 is the **flight controller MCU**. It does not commutate the motors. Each ESC channel has its own MCU, which generates the 48 kHz PWM.

```
┌──────────────────────┐   DShot600 bidir (×4)   ┌──────────────────────────────┐
│ STM32H743 (ArduPilot)│◄──────────────────────►│ 4× ESC MCU (AT32F421 / AM32) │
│ TIM1 CH1–4 + DMA     │                         │ 48 kHz center-aligned PWM    │
└──────────────────────┘                         │ 4× 3-phase gate driver       │
                                                 │ 24× N-MOSFET (6 per motor)   │
                                                 └──────────────────────────────┘
```

## 1. Thermal and Loss Model, One ESC Channel

### 1.1 Commutation topology

The model assumes 6-step trapezoidal commutation, which is the AM32/BLHeli_32 default, with **complementary (synchronous) PWM**.

In each 60° sector, two phases conduct:

- **PWM leg:** HS and LS alternate. Duty D goes to the HS, and (1−D) goes to the LS as a synchronous rectifier.
- **Return leg:** LS is held fully on.

Because of synchronous rectification, current always flows through exactly one FET in each of the two active legs. The total channel conduction loss is therefore **independent of duty cycle**.

### 1.2 Conduction loss

Temperature-dependent on-resistance:

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

Channel conduction loss:

$$P_{cond,ch} = 2\,I^2\,R_{ds}(T_j)$$

Over a full electrical cycle, each of the 6 FETs conducts for 1/3 of the time at full current. Averaged per FET:

$$\bar P_{cond,FET} = \frac{P_{cond,ch}}{6} \cdot 2 = \frac{I^2 R_{ds}(T_j)}{3}\cdot 2 \;\Rightarrow\; \frac{P_{cond,ch}}{3}\ \text{(peak sector, active pair)}$$

For thermal sizing, use the cycle-averaged value P_cond,ch / 6 per FET. Use the sector-instantaneous value P_cond,ch / 2 per active FET only when transient Z_θ matters. At high eRPM, the sector period (≪ thermal τ) makes the average valid.

**Numbers at I = 80 A, T_j = 125 °C:**

- R_ds = 1.0 mΩ × (1 + 0.006 × 100) = **1.60 mΩ**
- P_cond,ch = 2 × 6400 × 1.6e-3 = **20.5 W**
- Per FET, cycle-average: **3.41 W**

### 1.3 Switching loss (48 kHz)

Only the PWM leg switches hard. The return leg is static.

**Hard-switching V·I overlap:**

$$P_{sw} = \tfrac12 V_{bus} I\,(t_r+t_f)\,f_{sw}$$

= 0.5 × 25.2 × 80 × 40 ns × 48 kHz = **1.94 W**

**Dead-time body-diode conduction** (two dead-time intervals per period):

$$P_{dt} = 2\,t_{dead}\,f_{sw}\,V_{SD}\,I$$

= 2 × 200 ns × 48 kHz × 0.8 × 80 = **1.23 W**

**Reverse recovery** (dissipated in the HS at turn-on):

$$P_{rr} = Q_{rr} V_{bus} f_{sw}$$

= 50 nC × 25.2 × 48 kHz = **0.06 W**

**Output capacitance:**

$$P_{oss} \approx Q_{oss} V_{bus} f_{sw}$$

= **0.06 W**

**Gate drive** (dissipated in the driver and R_g, not the FET junction):

$$P_g = 2\,Q_g V_{gs} f_{sw}$$

= 2 × 60 nC × 10 × 48 kHz = **0.06 W**

### 1.4 Channel and board totals

| Loss term | Per channel (W) |
|---|---|
| Conduction @ 125 °C | 20.48 |
| V·I switching | 1.94 |
| Dead-time diode | 1.23 |
| Q_rr + Q_oss | 0.12 |
| Gate | 0.06 |
| **Total** | **≈ 23.8 W** |
| **4 channels simultaneous** | **≈ 95 W** |

Observations:

- Conduction dominates at 86%.
- At 48 kHz, switching loss is minor. Reducing f_sw to 24 kHz saves only about 1.6 W per channel.
- Reducing t_dead (to ~100 ns, if driver propagation matching allows) saves about 0.6 W per channel.
- **R_ds,on is the primary lever.** Paralleling two FETs per switch halves conduction loss.

### 1.5 Electro-thermal fixed point and runaway criterion

Conduction loss depends on T_j, and T_j depends on dissipation, so the junction temperature is defined by a fixed point:

$$T_j = T_{pcb} + R_{\theta,J\text{-}PCB}\,\big[P_0 + k\,(T_j-25)\big]$$

where P_0 is the per-FET loss at 25 °C and k = (I²R_ds,25 α)/3.

Solving:

$$T_j = \frac{T_{pcb} + R_\theta (P_0 - 25k)}{1 - R_\theta k}$$

**Stability condition** (no thermal runaway):

$$R_\theta\,k < 1$$

At 80 A, k = 6400 × 1e-3 × 0.006 / 3 = 0.0128 W/K. With R_θ,J-PCB ≈ 9 K/W (1.0 K/W R_θJC plus about 8 K/W local spreading through a via array into 6-layer 2 oz copper):

- R_θ·k = 0.115, which is stable. The loop gain inflates ΔT by 1/(1−0.115) = 1.13×.
