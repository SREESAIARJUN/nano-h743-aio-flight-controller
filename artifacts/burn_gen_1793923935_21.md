## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\left[1 + \alpha\,(T_j - 25)\right], \quad \alpha \approx 0.0045\ \text{K}^{-1}\ \text{(40 V trench, typ.)}$$

| T_j (°C) | R_DS (mΩ) |
|---|---|
| 25 | 1.00 |
| 100 | 1.34 |
| 125 | 1.45 |
| 150 | 1.56 |

Use the datasheet max-at-25 °C value (typically ×1.2 to 1.3 over typ.) for worst-case analysis:

$$R_{DS,wc}(125^\circ C) \approx 1.3 \times 1.45 = 1.89\ \text{mΩ}$$

### 1.2 Six-step (trapezoidal) commutation with synchronous rectification

At any instant, two phases carry current I:

- **PWM leg:** the high-side FET conducts for duty D. The low-side FET conducts for (1 − D) as a synchronous rectifier, excluding dead time.
- **Static leg:** one low-side FET is held on for the full 60° sector.

Exactly two FET channels carry I at all times (ignoring dead time):

$$P_{cond,ch} = I^2 \left[D\,R_{HS} + (1-D)\,R_{LS} + R_{LS}\right] \approx 2\,I^2 R_{DS}$$

Each FET is active for 1/3 of the electrical cycle (120° of 360°), so the average loss per FET is:

$$\bar{P}_{cond,FET} = \frac{2 I^2 R_{DS}}{6} = \frac{I^2 R_{DS}}{3}$$

The instantaneous per-FET dissipation during its active sector is up to I²R_DS. This matters only at very low eRPM (stall or startup), where a sector lasts longer than the junction thermal time constant (§3.3).

### 1.3 Copper and interconnect losses

Copper path per channel (B+ → HS → phase pad → motor → phase pad → LS → shunt/GND):

| Element | Resistance |
|---|---|
| PCB planes (2× outer + 2× inner, 2 oz) | ≈ 0.25 mΩ |
| Phase solder pads and wire joints | ≈ 0.15 mΩ (×2) |
| Low-side shunt (if fitted) | 0.5 mΩ (or 0 with R_DS sensing) |
| **R_cu total** | **≈ 0.55 to 1.05 mΩ** |

$$P_{cu,ch} = I^2 R_{cu}$$
