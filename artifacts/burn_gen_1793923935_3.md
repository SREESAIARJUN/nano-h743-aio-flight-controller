# STM32H743 Nano AIO with 4-in-1 ESC: 80 A Burst Thermal, 48 kHz Switching, and Bidirectional DShot600 Design

## 0. Architecture Clarification and Assumptions

**The STM32H743 does not commutate the motors.** On real AIO and 4-in-1 boards, the H743 runs ArduPilot and sends bidirectional DShot600 to four independent ESC MCUs. Each ESC MCU (typically an AT32F421 or STM32G071 running AM32/BLHeli_32) handles six-step commutation at 48 kHz. Commutating four motors from the H743 is not supported by ArduPilot.

The design assumptions below should be replaced with your actual BOM values. All equations are parametric.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Burst phase current per motor | I_pk | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, DFN3.3×3.3 class) R_ds(on) at 25 °C | R_25 | 0.9 mΩ |
| R_ds(on) temperature coefficient | α | 0.0045 /K |
| Gate-drain charge / gate-source charge (post-threshold) | Q_gd / Q_gs2 | 10 nC / 5 nC |
| Total gate charge / reverse-recovery charge | Q_g / Q_rr | 50 nC / 80 nC (at 80 A) |
| Output capacitance (energy equivalent) | C_oss,eq | 1.5 nF |
| Miller plateau voltage | V_pl | 3.5 V |
| Gate drive voltage | V_drv | 10 V |

| Dead time | t_dt | 50 ns |
| Body-diode forward voltage | V_f | 0.8 V |

**Feasibility warning:** 80 A per motor on a nano-format board (20×20 or 25.5×25.5 mm) is only achievable as a short burst. The model below quantifies how short.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{25}\,(1+\alpha)^{(T_j-25)}$$

At T_j = 100 °C: R_ds = 0.9 × 1.0045^75 ≈ **1.26 mΩ**

### 1.2 Six-step commutation with synchronous (complementary) PWM

In each 60° commutation sector, current flows through two series paths:

- **PWM leg:** the high-side (HS) FET conducts for duty fraction D. The synchronous low-side (LS) FET conducts for (1 − D).
- **Return leg:** the LS FET conducts for 100% of the sector.

The current therefore always passes through exactly two channels. Conduction loss is independent of duty cycle:

$$P_{cond,motor} = 2\,I^2 R_{ds}(T_j)$$

At 80 A and 100 °C:

$$P_{cond} = 2 \times 6400 \times 1.26\text{ m}\Omega = \mathbf{16.1\ W\ per\ motor}$$

### 1.3 Per-FET distribution

Each FET conducts for 120° of the electrical cycle, so the average loss per FET is 16.1 / 6 ≈ **2.7 W**.

The instantaneous loss while conducting is I²R = **8.1 W**. This value drives junction ripple (Section 4.3).

### 1.4 Copper and interconnect loss

Assume about 1.5 mΩ of total path resistance per motor (bus planes, phase pads, and solder joints with 2 oz copper):

$$P_{Cu} = I^2 R_{path} = 6400 \times 1.5\text{ m}\Omega \approx \mathbf{9.6\ W\ per\ motor}$$

This term is frequently ignored and is often comparable to FET loss.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches hard. The return leg is static within a sector.

### 2.1 Gate current during transitions

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{g,tot}} = \frac{10-3.5}{4.7} = 1.38\text{ A} \qquad I_{g,off} = \frac{V_{pl}}{R_{g,tot}} = 0.74\text{ A}$$

### 2.2 Transition times

$$t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = \frac{15\text{ nC}}{1.38} = 10.9\text{ ns}$$

$$t_{off} = \frac{15\text{ nC}}{0.74} = 20.3\text{ ns}$$

### 2.3 Voltage-current overlap loss

$$P_{VI} = \tfrac12 V_{bus} I\,(t_{on}+t_{off})\,f_{sw} = 0.5 \times 25.2 \times 80 \times 31.2\text{ ns} \times 48\text{ kHz} = \mathbf{1.51\ W}$$

### 2.4 Reverse recovery

$$P_{rr} = V_{bus}\,Q_{rr}\,f_{sw} = 25.2 \times 80\text{ nC} \times 48\text{ kHz} = \mathbf{0.097\ W}$$

### 2.5 Output capacitance loss (both FETs in the leg)

$$P_{oss} = 2 \times \tfrac12 C_{oss,eq} V_{bus}^2 f_{sw} = \mathbf{0.046\ W}$$

### 2.6 Dead-time body-diode conduction

$$P_{dt} = V_f\,I\,(2t_{dt})\,f_{sw} = 0.8 \times 80 \times 100\text{ ns} \times 48\text{ kHz} = \mathbf{0.31\ W}$$
