# STM32H743 Nano FC + 80 A 4-in-1 ESC (Job #56): Power-Stage Loss Model, Thermal Budget, and Bi-Directional DShot600 DMA Plan

## 0. Scope, Architecture, and Assumptions

### 0.1 System partitioning

In production 4-in-1 stacks, the STM32H743 does **not** commutate the MOSFETs. ArduPilot runs on the H743 and sends bi-directional DShot600 to four ESC MCUs, which run AM32 or BLHeli_32. This document assumes that architecture:

```
┌──────────────────────── FC (STM32H743, ArduPilot) ───────────────────────┐
│ TIM1 CH1..CH4 ──(BDShot600, 1-wire, half-duplex)──► ESC MCU 1..4          │
│ ADC ◄── VBAT divider / CURR amp       UART ◄── (optional ESC telemetry)    │
└───────────────────────────────────────────────────────────────────────────┘
┌──────────────────────── 4-in-1 ESC board ────────────────────────────────┐
│ 4 × [AT32F421 (AM32) → FD6288Q 3-ph gate driver → 6 × N-MOSFET bridge]    │
│ Shared: 6S bus, bulk + MLCC bank, 0.1 mΩ shunt + INA186, 10 V & 3.3 V LDOs│
└───────────────────────────────────────────────────────────────────────────┘
```

If you intend a single-MCU design where the H743 drives all 12 half-bridges directly, Section 3 does not apply. That design would need 12 complementary PWM pairs and 4 BEMF/comparator paths. TIM1 and TIM8 provide only 3 complementary pairs each, so the H743 cannot natively drive 4 motors with hardware dead-time. This is the main reason the split architecture is standard.
