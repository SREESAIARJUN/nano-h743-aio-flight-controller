# Job #38: 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

## 0. Assumptions

Job #38 came without a hardware spec, so the design uses the assumptions below. Every one of them is a parameter in the code.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC (GBM2804-class), 12N14P → pole pairs `p = 7`, R ≈ 5.6 Ω, L ≈ 1.8 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| Inverter | 3-phase, center-aligned PWM, f_pwm = 20 kHz, V_dc = 12 V, inline or low-side current sensing |
| IMUs | 2× ICM-42688-P on the camera plate, mounted rotated
