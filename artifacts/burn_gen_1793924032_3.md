# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Vibration Rejection

## 1. FOC Inner Current Loop

### 1.1 Transforms
Use the electrical angle θ_e = p·(θ_m − θ_offset).

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and PI design by pole-zero cancellation
The d-q plant model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

With decoupling feedforward, each axis reduces to G(s) = 1/(Ls + R). Choose the PI zero to cancel the plant pole:

$$K_p = \omega_c L,\qquad K_i = \omega_c R \;\;\Rightarrow\;\; \frac{I}{I^*} = \frac{\omega_c}{s+\omega_c}$$

Pick ω_c ≈ 2π·1500 rad/s, which is below f_PWM/10 and accounts for the 1.5-sample PWM/ADC delay.

**Decoupling and back-EMF feedforward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda,\quad \lambda = \tfrac{2}{3}\frac{K_t}{p}$$

**Voltage limiting.** Apply a circular limit of |v_dq| ≤ V_dc/√3, giving d-axis priority. Use back-calculation anti-windup (§2.4).

### 1.3 SVPWM via min/max zero-sequence injection

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12\left(\max v + \min v\right)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically identical to sector-based SVPWM and gives 15.5 % more linear range than sinusoidal PWM.

## 2. Cascaded Velocity and Angle Control

```
θ* ─►[Angle P + FF]─ω*─►[Velocity PI + LPF]─τ*─►(+ cogging FF, + gravity FF)─► i_q*/K_t ─►[Current PI]─► motor
         ▲ θ̂ (IMU attitude → joint)   ▲ ω̂ (encoder PLL ⊕ gyro)
```

Keep each loop's bandwidth 4–10× apart: current 1.5 kHz, velocity ~150 Hz, angle ~20–30 Hz.

### 2.1 Velocity estimation with a type-2 PLL
Differentiating a quantized encoder angle produces noise of order Δθ_q · f_s. Use a PLL observer instead:

$$e_k = \operatorname{wrap}(\theta_{meas,k} - \hat\theta_k)$$

$$\hat\omega_{k+1} = \hat\omega_k + K_{i,pll}\,T\,e_k$$

$$\hat\theta_{k+1} = \hat\theta_k + T(\hat\omega_k + K_{p,pll} e_k)$$

To get a critically damped observer with bandwidth ω_pll, set K_p = 2ω_pll and K_i = ω_pll². Use ω_pll ≈ 2π·400 rad/s.

**Gyro blending.** For gimbal stabilization, feed back the camera-frame inertial rate, not the joint rate. A complementary blend gives better high-frequency fidelity:

$$\hat\omega_{fb} = \underbrace{\text{HPF}_{\omega_x}\{\omega_{gyro,axis}\}}_{\text{inertial}} \;+\; \text{LPF}_{\omega_x}\{\hat\omega_{enc} + \omega_{base,proj}\}$$

In the simplest robust form, the velocity loop tracks the inertial rate from the gyro mapped to the joint axis.

### 2.2 Velocity PI
For a rigid body with inertia J:

$$\frac{\omega}{\tau} = \frac{1}{Js}$$

$$K_{p,v} = J\,\omega_v,\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{4}\quad(\text{PI zero at } \omega_v/4,\ \approx 65°\text{ PM})$$

These gains output torque; divide by K_t to get i_q*.

Add a first-order torque-command LPF at ~5ω_v. If a structural resonance is identified (e.g. camera arm at 180 Hz), add a notch on τ*.

### 2.3 Angle loop (P with velocity feedforward, optional I)

$$\omega^* = K_{p,\theta}\,\operatorname{wrap}(\theta^* - \hat\theta) + K_{i,\theta}\!\int\! e_\theta\,dt + \dot\theta^*_{ff},\qquad K_{p,\theta}\approx \omega_v/5$$

A small K_i,θ removes static error from unmodeled friction and imbalance. Rate-limit and jerk-limit the setpoint θ* (smooth follow mode).
