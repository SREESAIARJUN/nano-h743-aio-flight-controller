# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

## 0. Design Assumptions

I don't have the Job #28 specification, so the design assumes typical values. Every value marked †in the table is a constructor parameter in the code and should be replaced with your hardware's values.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (7 pole pairs, p = 7)†, R = 5.6 Ω†, L = 2.1 mH†, Kt ≈ 0.08 N·m/A† |
| Position sensor | 14-bit absolute magnetic encoder (MT6701/AS5048A class) per axis |
| MCU | STM32G4 / H7 class, single-precision FPU |
| Current loop + SVPWM + cogging feedforward | 20 kHz (Ts_i = 50 µs) |
| IMU sampling, filtering and fusion | 8 kHz |
| Rate (velocity) loop | 4 kHz |
| Attitude (angle) loop | 1 kHz |
| IMUs | 2 × ICM-42688-P, both on the camera plate at different lever arms r₁ and r₂ |
| Gimbal axis order (base → camera) | Yaw (z) → Roll (x) → Pitch (y) |
