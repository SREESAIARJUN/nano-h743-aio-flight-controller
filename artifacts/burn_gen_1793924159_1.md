# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the spec sheet for Job #45, so this design is built on the assumptions listed in §0. Every assumption is a named constant in the code. Replace them with your real values before tuning.

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU). Single-precision `float` throughout. |
| Motors | 3× gimbal BLDC, 12N14P (12 slots, 14 poles, so p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), one per axis |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, shared CLKIN for sync |
| Current sense | 3-shunt, sampled center-aligned |

The control runs as nested loops at decreasing rates:

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (d/q PI) | 20 kHz (PWM-synchronous ADC ISR) | 50 µs | ω_c ≈ 2π·1500 rad/s |
| Velocity PI + cogging feedforward | 5 kHz | 200 µs | ω_v ≈ 2π·150 rad/s |
| Angle P(I) + attitude | 1 kHz | 1 ms | ω_θ ≈ 2π·30 rad/s |
| IMU filtering | 8 kHz (decimated to 1 kHz for attitude) | 125 µs | — |

Each loop's bandwidth sits roughly 5–10× below the loop inside it. That separation lets each outer loop treat the inner loop as an ideal unity gain within its own bandwidth.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical angle, with encoder offset θ_off found during alignment:

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.2 PMSM Model in the Rotor Frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$
$$\tau_e = \tfrac32 p\left[\lambda_m i_q + (L_d - L_q) i_d i_q\right] \approx K_t\, i_q,\qquad K_t = \tfrac32 p \lambda_m$$

### 1.3 Current PI With Decoupling (Pole-Zero Cancellation)

With the cross-coupling terms cancelled by feedforward, each axis reduces to the plant 1/(Ls + R). Choose the PI zero to cancel the electrical pole:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\Rightarrow\; \frac{I(s)}{I^*(s)} = \frac{\omega_c}{s+\omega_c}$$

Control law:

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L_q i_q,\qquad v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e(L_d i_d + \lambda_m)$$

Use i_d* = 0. Gimbal motors are surface-mount, so L_d ≈ L_q and there is no reluctance torque to exploit.

**Voltage limiting.** Limit the voltage vector to the inscribed circle of the SVPWM hexagon, |v| ≤ V_bus/√3. Give priority to v_d.

### 1.4 Space-Vector PWM (Min/Max Zero-Sequence Injection)

Apply the inverse Park transform to get v_α, v_β. Then compute the phase voltages:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Inject the zero-sequence component and convert to duty cycles:

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical Plant per Axis

$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$
