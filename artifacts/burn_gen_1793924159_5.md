# Job #46: 3-Axis Gimbal FOC Control and Dual-IMU Fusion

## 0. Assumptions

I don't have the Job #46 specification, so this design uses the defaults below. Replace the marked parameters with your hardware values.

| Item | Assumed value |
|---|---|
| Motors | Gimbal PMSM/BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701), read every current-loop tick |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM, ADC triggered at PWM center |
| Current sensing | 2 or 3 low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, shared CLKIN for sample sync |
| Joint order | Base → Yaw(z) → Roll(x) → Pitch(y) → Camera |

**Loop rates**

| Loop | Rate | Context |
|---|---|---|
| Current loop (FOC) | 20 kHz | ADC ISR |
| IMU acquisition and filtering | 8 kHz | Data-ready ISR / DMA |
| Velocity loop (inertial rate) | 4 kHz | |
| Attitude loop | 1 kHz | |
| Cogging learning | 1 kHz, background | Only in calibration mode |
