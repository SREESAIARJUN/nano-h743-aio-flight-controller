# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion (Job #42)

I don't have the Job #42 specification, so this design uses the assumptions below. Every assumption is a parameter in the code. Replace the values with your BOM before tuning.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | 3 × GBM2804-class, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Driver | 3-phase bridge, 2 low-side shunts per axis, V_bus = 12–16 V |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701) per joint, SPI |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro ODR 8 kHz |
| Kinematics | Yaw (base) → Roll → Pitch (camera) |

Loop rates (all integer-divided from the PWM timer ISR):

```
PWM / Current loop (FOC)   : 20 kHz   Ts_i = 50 µs
Velocity loop              :  4 kHz   Ts_v = 250 µs   (÷5)
IMU read + vibration filt. :  4 kHz   (two 8 kHz FIFO samples decimated ×2)
Attitude estimator         :  1 kHz   Ts_a = 1 ms     (÷20)
Angle loop                 :  1 kHz
Cogging LMS adaptation     :  1 kHz (background, optional)
```

The general rule is that each loop's bandwidth should be at most 1/4–1/5 of the loop inside it. Each sample rate should also be at least 10× the bandwidth of the loop it runs.
