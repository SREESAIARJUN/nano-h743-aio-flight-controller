# STM32H743 Nano FC + 4-in-1 ESC: Design Model (Job #30)

## 0. Scope and Assumptions

**Architecture.** The H743 is the flight controller. It does not commutate the motors. Each motor gets its own ESC MCU running AM32, which handles 48 kHz PWM, commutation and the bidirectional DShot reply. This is the only practical partition. AM32 on an STM32G071 or AT32F421 is the reference here. The H743 sends DShot600 and captures the eRPM telemetry.

## 1. Conduction Loss Model

**Conduction pattern.** In 6-step (trapezoidal) commutation with synchronous rectification, exactly two FETs carry the phase current at any instant:
- one in the high-side path, and
- one in the low-side path.

Complementary PWM only moves the current between the HS and LS FET of the switching leg. It does not change the number of conducting devices.

**Temperature-dependent R_DS(on):**

$$R_{DS}(T_j) = R_{25}\,[1+\alpha (T_j-25)] \quad\Rightarrow\quad R_{hot}=1.0(1+0.006\cdot85)\approx1.51\ \text{m}\Omega$$

**Per motor (instantaneous):**

$$P_{cond,motor} = I_{pk}^2 \cdot 2R_{hot} = 80^2 \cdot 3.02\,\text{m}\Omega \approx \mathbf{19.3\ W}$$

**Per FET (time-averaged).** Each FET conducts about 1/3 of the electrical cycle:

$$P_{cond,FET} = I^2 R_{hot}\cdot\tfrac{1}{3} = 9.66/3 \approx \mathbf{3.2\ W}$$

**Copper losses.** Add phase and bus copper. Example: 80 A through 0.25 mΩ of pour gives 1.6 W per motor. Budget roughly 1–2 W per motor.

**Electrothermal coupling.** R_hot depends on T_j, so iterate:

$$T_j^{(n+1)} = T_{pcb} + P(T_j^{(n)})\,R_{\theta JC}$$

The solution converges in 2–3 iterations. Runaway occurs if

$$\partial P/\partial T_j \cdot R_{\theta} \ge 1$$

## 2. Switching Loss Model at 48 kHz

### 2.1 Transition times

$$I_{g,on}=\frac{V_{drv}-V_{pl}}{R_{g,tot}}=1.3\text{ A},\qquad I_{g,off}=\frac{V_{pl}}{R_{g,tot}}=0.7\text{ A}$$

$$Q_{sw}=Q_{gd}+\tfrac12 Q_{gs}=16\text{ nC}\;\Rightarrow\; t_{on}=12.3\text{ ns},\; t_{off}=22.9\text{ ns}$$

### 2.2 Loss components (per motor; only one leg switches at a time)

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_on + t_off)·f_sw | ½·25.2·80·35.2 ns·48k = **1.70 W** |
| Reverse recovery | Q_rr·V·f_sw | **0.07 W** |
| C_oss | 2·½·C_oss·V²·f_sw | **0.05 W** |
| Dead-time body diode | V_f·I·2t_dt·f_sw | **0.31 W** |
| Gate drive (in driver/R_g) | 2·Q_g·V_drv·f_sw | 0.05 W |
| **Total switching** | | **≈ 2.1 W** |

### 2.4 Design levers

- **Overlap loss scales linearly with f_sw.** Dropping to 24 kHz saves about 0.85 W per motor. That is small next to conduction loss, so 48 kHz is acceptable.
- **The lever that matters is R_DS(on).
