# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #15): Architecture, Loss Model, DMA Plan, and Netlists

## 0. Architecture Corrections and Assumptions

Before the math, three points that change the design:

1. **The H743 cannot commutate the motors itself.** The H743 runs ArduPilot and emits bi-directional DShot600. Each of the four motor channels needs its own ESC MCU running AM32 or BLHeli_32. AT32F421K8 is the de-facto AM32 target. Commutation, the 48 kHz PWM, and dead-time live on those four MCUs. This guide treats the product as an AIO stack: one H743 plus four AT32F421 ESC cores.
2. **"80A burst" on a nano form factor is thermally bounded, not continuous.** Section 3 shows the board can carry 80A per motor for only a few seconds. Burst rating must be specified with a duration.
3. **The component values below are design placeholders.** They are representative of 40V, ~1 mΩ, 5×6/3.3×3.3 class parts. Re-run every equation with the datasheet values of the parts you actually procure.

## 1. Conduction Loss Model (6-step trapezoidal, synchronous rectification)

At any instant, two phase legs conduct: one high-side (HS) and one low-side (LS) path. The PWM leg alternates HS (duty D) and synchronous LS (1−D).

**Per-leg conduction loss:**

$$P_{cond,leg} = I^2 R_{on}\,D + I^2 R_{on}(1-D) = I^2 R_{on}$$

The result is independent of D because synchronous rectification removes the duty term.

**Per motor (two legs in series):**

$$P_{cond} = 2\,I^2 R_{on,hot} = 2(80)^2(1.35\times10^{-3}) = \mathbf{17.3\ W}$$

**Copper path (bus planes plus phase pours, ≈0.25 mΩ effective):**

$$P_{Cu} = I^2 R_{Cu} = 6400 \times 0.25\text{ m}\Omega \approx \mathbf{1.6\ W}$$

**Per-FET average.** Each FET conducts about 1/3 of the electrical cycle (120°):

$$P_{FET,avg} \approx \frac{I^2 R_{on}}{3} = 2.9\ W$$

**R_on temperature feedback.** For a closed-loop estimate, use:

$$R_{on}(T_j) = R_{25}\left[1+\alpha(T_j-25)\right],\quad \alpha\approx 0.005\ \text{K}^{-1}$$

Iterate this with T_j from §3. The ×1.5 factor above corresponds to T_j ≈ 125 °C.

## 2. Switching Losses at 48 kHz

Switching occurs on the PWM leg only.

**(a) V–I overlap (hard-switched):**

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5(25.2)(80)(20\text{n})(48\text{k}) = \mathbf{0.97\ W}$$

**(b) Output capacitance:**

$$P_{oss} = Q_{oss} V_{bus} f_{sw} = 40\text{n}\cdot25.2\cdot48\text{k} = 0.048\ W$$

**(c) Body-diode reverse recovery:**

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n}\cdot25.2\cdot48\text{k} = 0.060\ W$$

**(d) Dead-time body-diode conduction (two dead-times per period):**

$$P_{dt} = V_f\, I\, (2t_{dt})\, f_{sw} = 0.8\cdot80\cdot200\text{n}\cdot48\text{k} = \mathbf{0.61\ W}$$

**(e) Gate drive.** This loss is dissipated in the driver and gate resistors, not the FET:

$$P_g = Q_g V_{GS} f_{sw} = 60\text{n}\cdot10\cdot48\text{k} = 0.029\ W \text{ per switching FET}$$

**Switching subtotal per motor: ≈ 1.7 W**

### Per-motor and board totals at 80A burst

| Loss term | W/motor |
|---|---|
| FET conduction | 17.3 |
| Copper | 1.6 |
| Switching + dead-time + Q_rr + Q_oss | 1.7 |
| Gate drive, shunt (0.2 mΩ ⇒ 1.3 W if low-side shunt used), MCU | ~1.5 |
| **Total** | **≈ 22 W** |
| **4 motors** | **≈ 88 W** |

**Design lever: frequency.** Conduction dominates (~80%). Dropping to 24 kHz saves only ~0.85 W per motor. Conversely, 48 kHz is "affordable" thermally and buys quieter, smoother low-throttle behavior. The real lever is R_on: paralleling FETs halves conduction loss.

**Design lever: dead time.** With good layout and driver propagation matching, cutting t_dt from 100 ns to 50 ns saves ~0.3 W per motor.

## 3. Thermal Model

### 3.1 Lumped board model (first-order RC)

**Board heat capacity, 30.5×30.5 mm (A = 9.3×10⁻⁴ m²):**

- Copper: 8 layers × 70 µm → 5.2×10⁻⁷ m³ × 8960 kg/m³ = 4.67 g × 385 J/kg·K = **1.8 J/K**
- FR4: 1.6 mm → 1.49×10⁻⁶ m³ × 1850 kg/m³ = 2.75 g × 1100 J/kg·K = **3.0 J/K**
- FETs, caps, solder: ≈ **0.4 J/K**
- **Total: C_th ≈ 5.2 J/K**

**Board-to-air resistance under prop wash (h ≈ 100 W/m²K, both faces):**

$$R_{th,ba} = \frac{1}{h\cdot 2A} = \frac{1}{100\cdot1.86\times10^{-3}} \approx 5.4\ \text{K/W}$$

**Time constant:**

$$\tau = R_{th}C_{th} \approx 28\ \text{s}$$

### 3.2 Burst response

The step response is:

$$\Delta T(t) = P\,R_{th}\left(1-e^{-t/\tau}\right)$$

With P = 88 W, the steady-state asymptote is **475 K**. So 80A on all four motors is strictly a burst rating.

**Maximum burst duration** for a board rise of ΔT_max = 80 K (25 → 105 °C board):

$$t_{max} = -\tau\ln\left(1-\frac{\Delta T_{max}}{P R_{th}}\right) = -28\ln(1-0.168) \approx \mathbf{5.2\ s}$$

The adiabatic slope is 88 / 5.2 ≈ 17 K/s, which agrees with that figure.

**Continuous rating** (ΔT = 80 K steady): P_max = 80 / 5.4 ≈ 15 W total. Back-solving through the loss model gives:

$$I_{cont} \approx \sqrt{\frac{15/4 - 0.4}{2\cdot1.35\text{m}+0.25\text{m}}} \approx \mathbf{34\ A\ per\ motor}$$
