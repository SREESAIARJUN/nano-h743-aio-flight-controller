# STM32H743 Nano FC + 80A 4-in-1 ESC: System Architecture & Mathematical Model

**Document scope:** Job #11. Covers the power-stage loss model, thermal model, bidirectional DShot600 timer/DMA plan, and reference netlists.

## 0. Architectural Clarifications and Assumptions

Two architectural points shape everything below.

1. **48 kHz switching belongs to the ESC MCU, not the H743.** In a 4-in-1 stack, the H743 sends DShot frames. The ESC's own MCU (assumed AT32F421 running AM32) generates the 48 kHz complementary PWM. The loss model therefore applies to the ESC board, and the DMA model applies to the FC board.
2. **"80A burst" on a nano form factor is thermally marginal.** The model below gives a quantified burst duration, not an implied continuous rating.

**Baseline assumptions** (replace with datasheet values once the BOM is frozen):

## 1. Conduction Loss Model (80A Burst)

### 1.1 Commutation topology
With 6-step trapezoidal drive and complementary PWM, each 60° sector has two active phases:
- **Switching leg:** the high-side FET conducts for duty D; the synchronous low-side FET conducts for 1−D.
- **Static leg:** the low-side FET conducts for 100% of the sector.

At any instant, exactly two FETs carry the phase current I.

### 1.2 RMS current including ripple
$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 80^2 + \frac{8^2}{12} = 6405.3\ \text{A}^2$$

### 1.3 Temperature-dependent on-resistance
$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 100 °C: R_ds = 1.2 × 1.375 = **1.65 mΩ**.

### 1.4 Loss per motor bridge
$$P_{cond,bridge} = 2\,I_{rms}^2\,R_{ds}(T_j) = 2(6405.3)(1.65\times10^{-3}) = \mathbf{21.1\ W}$$

### 1.5 Loss per FET
- **Instantaneous** while conducting: I²R = 10.6 W.
- **Average:** each FET conducts about 1/3 of the electrical cycle, so the average is ≈ **3.5 W**.

At 80A and full throttle, the electrical frequency is in the kHz range. The junction thermal time constant is in the ms range, so averaging is valid.

### 1.6 Electrothermal coupling
R_ds depends on T_j, so solve iteratively:
$$T_j = T_{board} + P_{FET}(T_j)\,R_{th,jc}, \qquad P_{FET}=\tfrac{1}{3}I^2R_{ds,25}[1+\alpha(T_j-25)]$$

There is a closed form because the equation is linear in T_j. With R_th,jc = 1.5 K/W:
$$T_j - T_b = \frac{\tfrac13 I^2R_{25}(1+\alpha(T_b-25))R_{th}}{1-\tfrac13 I^2R_{25}\alpha R_{th}}$$

At T_b = 90 °C, this gives ΔT_jc ≈ 5.0 K. The denominator is 0.981, far from 0, so there is **no thermal runaway at the junction**. The board, not the junction, is the limiting element.

## 2. Switching Loss Model at 48 kHz

Only the switching leg's FET pair dissipates switching energy.

| Mechanism | Equation | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw | ½(25.2)(80)(35 ns)(48k) = **1.69 W** |
| Coss discharge | ½·Q_oss·V·f_sw | 0.5(40n)(25.2)(48k) = **0.024 W** |
| Reverse recovery | Q_rr·V·f_sw | (50n)(25.2)(48k) = **0.060 W** |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw | 0.8(80)(400 ns)(48k) = **1.23 W** |
| Gate drive (2 FETs, dissipated in driver/R_g) | 2·Q_g·V_gs·f_sw | 2(60n)(10)(48k) = **0.058 W** |
| **Total switching** | | **≈ 3.06 W / motor** |

**Design levers**
- **Dead time is the second-largest term.** Dropping t_dt from 200 ns to 100 ns saves about 0.6 W per motor. This is only safe if the gate driver's propagation mismatch is below 50 ns, which needs verification.
- **Overlap loss scales linearly with f_sw.** Running at 24 kHz halves it to 0.85 W, at the cost of higher current ripple
