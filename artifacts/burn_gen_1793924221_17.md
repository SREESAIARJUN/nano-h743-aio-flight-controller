# STM32H743 AIO (FC + 4-in-1 ESC): Power-Stage Loss, Thermal, and Bi-Directional DShot600 Reference Design

**Document scope:** Job #39, Rev A (engineering reference). The analysis uses stated assumptions. All component values must be re-verified against the actual BOM datasheets before layout freeze.

---

## 0. Architecture Clarifications

These points change the math, so they come first:

1. **The H743 does not commutate the motors.** In every production AIO of this class, each ESC channel has its own MCU (AT32F421 / STM32G071 running AM32 or BLHeli_32). The H743 sends DShot600 to those MCUs and receives eRPM telemetry back. The 48 kHz PWM is an **ESC-firmware setting**, not an H743 timer.
2. **80 A is a burst rating, not continuous.** On a 20×20 or 25.5×25.5 mm board, the thermal math below shows that 4×80 A is survivable for roughly 1–2 s. Continuous capability is about 22–33 A per channel, depending on airflow. The product datasheet must say this explicitly.
3. **Bi-directional DShot cannot run on complementary (CHxN) timer outputs.** Input capture is unavailable on N channels. All four motor pins must be non-N timer channels.

## 2. Conduction Loss Model

### 2.1 Junction-temperature-dependent resistance

$$R_{DS}(T_j) = R_{25}\left[1+\alpha\,(T_j-25)\right]$$

$$R_{DS}(110^\circ C) = 1.0\,\text{m}\Omega \times (1 + 0.0045\times 85) = 1.38\,\text{m}\Omega \approx 1.4\,\text{m}\Omega$$

### 2.2 RMS current including ripple

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12} = 6400 + 8.3 = 6408\ \text{A}^2$$

Ripple is negligible at this current level.

### 2.3 Six-step with synchronous rectification

At any instant, two legs carry the phase current. In the PWM'd leg, current alternates between the high-side FET (fraction D) and the low-side FET (fraction 1−D). The opposite leg's FET conducts continuously. The current path therefore always crosses exactly **two** R_DS(on), independent of duty:

$$P_{cond,ESC} = 2\,I_{rms}^2\,R_{DS}(T_j)$$

$$P_{cond,ESC} = 2 \times 6408 \times 1.4\times10^{-3} = \mathbf{17.9\ W}$$

Averaged over a full electrical cycle, each of the 6 FETs carries about 1/6 of this: **≈3.0 W per FET**.

### 2.4 PCB copper loss

Assume an effective copper path of 0.4 mΩ per phase loop (2 oz inner layers, via arrays):

$$P_{Cu} = 80^2 \times 0.4\,\text{m}\Omega = 2.6\ \text{W per ESC}$$

## 3. Switching Loss Model @ 48 kHz

Only the PWM'd high-side FET is hard-switched. The low-side FET turns on after dead time with its body diode already conducting, so it is ZVS.

**3.1 V–I overlap**

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f)f_{sw} = 0.5(25.2)(80)(40\text{n})(48\text{k}) = \mathbf{1.94\ W}$$

**3.2 Output capacitance (two FETs per leg)**

$$P_{oss} = 2\cdot\tfrac12 C_{oss}V_{bus}^2 f_{sw} = 1\text{n}\times 635\times 48\text{k} = 0.03\ \text{W}$$

**3.3 Reverse recovery**

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 40\text{n}\times 25.2\times 48\text{k} = 0.05\ \text{W}$$

**3.4 Dead-time body-diode conduction (2 edges per period)**

$$P_{dt} = 2\,V_F\,I_{ph}\,t_{dt}\,f_{sw} = 2(0.8)(80)(200\text{n})(48\text{k}) = \mathbf{1.23\ W}$$

Reducing dead time to 100 ns saves about 0.6 W, but must be verified against shoot-through margin on the scope.
