# STM32H743 Nano FC + 4-in-1 ESC (Job #40): Engineering Model

## 0. Scope, Assumptions, and Up-Front Findings

No component datasheets, stack-up, or layout were supplied. Every numeric result below therefore rests on the stated assumed parameters, and each formula is written so you can substitute real values. Treat this as an architecture-level model, not a signed-off design.

**Architecture assumption.** The STM32H743 runs ArduPilot as the flight controller. The 4-in-1 ESC uses four separate ESC MCUs (for example AT32F421 or STM32G071 running AM32/BLHeli_32). The H743 does not commutate motors, and nothing in ArduPilot supports that.

**Two critical findings:**
1. **80 A per channel on a nano (20×20 mm) board is a burst rating only, measured in seconds.** The model below predicts about 100 W of dissipation with all four channels at 80 A. On a board with roughly 2–3 J/K of thermal mass, that reaches the thermal limit in about 1–2 s. Continuous ratings must be derived separately (Section 3.4).
2. **The bulk capacitor requirement cannot be met on-board.** A low-ESR electrolytic on the battery leads is mandatory (Section 3.6).

## 1. Conduction Loss Model

### 1.1 Current Path

In any commutation sector, two phases conduct:
- On the PWM leg, the high-side FET conducts for D·T and the low-side FET synchronously rectifies for (1−D)·T.
- On the return leg, the low-side FET is held on.

The current therefore always passes through exactly two R_DS(on) in series, independent of duty cycle D.

### 1.2 Temperature-Dependent Resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At the design point T_j = 100 °C:

$$R_{DS}(100) = 1.2\,\text{m}\Omega \times (1 + 0.006 \times 75) = 1.74\ \text{m}\Omega$$

### 1.3 Channel Conduction Loss

$$P_{cond,ch} = I^2 \cdot 2R_{DS}(T_j) = 80^2 \times 2 \times 1.74\times10^{-3} = \mathbf{22.3\ W}$$

### 1.4 Per-FET Distribution

Each FET carries current for one-third of the electrical cycle on average.
- Average loss per FET: 22.3/6 ≈ **3.7 W**.
- Instantaneous loss in the held-on low-side FET: 80² × 1.74 mΩ = **11.1 W**, lasting one 60° sector.

At e-RPM above about 6,000 (sector times under 2 ms), the die thermal time constant smooths this, so the average value governs. At low-speed, high-torque operation (launch or stall), the per-sector peak governs. That is the worst case for burst rating.

### 1.5 Thermal Runaway Check

Loss rises with T_j. The coupled solution is:

$$T_j = T_{ref} + R_\theta \cdot I^2 R_{25}[1+\alpha(T_j-25)]$$

This is stable only if R_θ · I² · R₂₅ · α < 1 per device. Using the per-FET average (I_rms² ≈ I²/3, R_θ ≈ 4.5 K/W junction-to-board):

4.5 × 2133 × 1.2×10⁻³ × 0.006 = **0.069**

This is well below 1, so the device is stable. The board-level constraint (Section 3) dominates.

### 1.6 PCB Copper Loss

PCB copper loss is significant at 80 A and is often ignored. Assume a 0.3 mΩ effective path per phase (4 oz, short pours):

80² × 0.3 mΩ × 2 paths ≈ **3.8 W per channel**

Measure this path resistance with 4-wire probing on the first article.
