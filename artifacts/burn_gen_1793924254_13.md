# STM32H743 AIO 4-in-1 ESC Nano FC (Job #18): Power-Stage Electrothermal Model, Switching Losses, and Bidirectional DShot600 DMA Architecture

## 0. Feasibility Finding

On a 20 × 20 mm nano AIO, **80 A per channel is only survivable as a short burst lasting about 1 second**, not as a continuous rating. The model in §1–3 shows why. I recommend we spec this as:

- **80 A burst, ≤1 s, single-channel or diagonal-pair**
- **4 × 80 A simultaneous for ≤0.5 s**, gated by a thermal model running in firmware (§3.5)
- Continuous rating of roughly 25–35 A per channel, which is typical of the real 20 × 20 class

If marketing requires a true 80 A rating, the board must move to a 30.5 × 30.5 mm format with 5 × 6 mm FETs. The equations below still apply; only the parameters change.

**Parameters are assumptions.** All device values are placeholders for a 40 V, 3.3 × 3.3 mm PDFN MOSFET class part. Swap in the selected part's datasheet values and re-run the numbers before design freeze.

```

                 │                ▲  ▲
                 │       DShot600 │  │ eRPM (bidirectional, same wire)
                 ▼                │  │
      Buck 5V/3V3 ──► STM32H743 (ArduPilot) ── TIM1 CH1–4 ─┘
```

- Each ESC channel runs its own MCU (for example AT32F421 or STM32G071 running AM32). That MCU generates the 48 kHz PWM.
- The H743 only sends DShot frames and receives eRPM telemetry.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{DS25}\,[1 + \alpha\,(T_j - 25)]$$

| Parameter | Assumed value |
|---|---|
| R_DS25 | 1.2 mΩ |
| α | 0.006 /K |
| Design point T_j | 110 °C |

$$R_{DS}(110^\circ C) = 1.2 \times (1 + 0.006 \times 85) = 1.81\ \text{m}\Omega$$

### 2.2 Six-step commutation with complementary (synchronous) PWM

In every 60° sector, phase current flows through exactly two FET conduction paths:

- One leg alternates between its high-side FET (for duty D) and its synchronous low-side FET (for 1 − D).
- The return leg's low-side FET is fully on.

The loss is therefore independent of D:

$$P_{cond,ch} = 2\,I_{rms}^2\,R_{DS}(T_j)$$

### 2.3 PWM current ripple

$$\Delta I = \frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}}, \qquad I_{rms}^2 = I^2\left[1 + \frac{(\Delta I/I)^2}{12}\right]$$

Using V_bus = 25.2 V, D = 0.5, line-to-line inductance L_LL = 20 µH, and f_sw = 48 kHz:

- ΔI = 6.3 / 0.96 = **6.56 A**
- ΔI / I = 0.082, which raises RMS current by only **+0.06 %**

Ripple is negligible at 80 A. At 48 kHz with low-inductance motors (below 10 µH), check it again.

### 2.4 Result at 80 A

$$P_{cond,ch} = 2 \times 80^2 \times 1.81\,\text{m}\Omega = \mathbf{23.2\ W\ per\ channel}$$

Per-FET average is about 23.2 / 6 ≈ **3.9 W**.

Averaging per FET is valid here. A 2207 motor at 1950 KV on 6S with 7 pole pairs reaches about 4 kHz electrical frequency, so 60° sectors last about 40 µs. That is far shorter than the die thermal time constant (milliseconds).
