# STM32H743 AIO Flight Controller with 4-in-1 ESC: Power-Stage Loss Model, Thermal Budget, and Bi-directional DShot600 DMA Allocation

## 0. Scope, Architecture, and Assumptions

I don't have your Job #3 BOM, so the numbers below rest on a stated reference design. Every equation is parametric: substitute your datasheet values and the results scale directly. Values marked **[A]** are assumptions to replace.

**Architecture clarification.** In an ArduPilot system, the STM32H743 does not run the 48 kHz motor commutation. It is the flight controller and emits bi-directional DShot600. The 4-in-1 ESC carries its own MCU(s) running AM32 or BLHeli_32 at 48 kHz PWM. The model below treats the two as one board (AIO "nano" stack) with two domains:

```
 6S LiPo ──┬── 4-in-1 ESC power stage (4 × 3-phase bridges, 24 MOSFETs)
           │      ▲ gate drivers ◄── ESC MCU(s) (AM32 @ 48 kHz PWM)
           │      │                      ▲  bidir DShot600 (1 wire/motor)
           └── BEC 5V/3V3 ──► STM32H743 FC ─┘  + current-sense ADC, VBAT ADC
```

## 1. Conduction Loss Model (6-step trapezoidal, synchronous rectification)

### 1.1 Commutation structure

Each electrical cycle, every phase leg spends 120° in each of three states:

- **High:** the high-side FET is PWM'd at duty D, and the complementary low-side FET conducts for (1−D).
- **Low:** the low-side FET is on 100%.
- **Floating:** neither FET conducts.
