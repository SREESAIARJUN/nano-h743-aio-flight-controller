# STM32H743 Nano FC + 80A 4-in-1 ESC (Job #63): System Architecture, Loss Model and DShot Allocation

## 0. Scope and Assumptions

This architecture splits the work across two processors:

| Function | Processor | Notes |
|---|---|---|
| Flight control, ArduPilot, bi-directional DShot600 master | STM32H743 (480 MHz) | Generates DShot frames and decodes eRPM telemetry |
| 6-step commutation and 48 kHz PWM | 4× ESC MCUs (AT32F421 / STM32G071 class, running AM32 or BLHeli_32) | Each runs one motor |

The H743 never generates the 48 kHz PWM. It only talks DShot to the ESC MCUs. The loss model below therefore covers the ESC power stage, and the timer/DMA section covers the H743.

## 1. Conduction Loss Model (80A Burst)

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds25}\,[1+\alpha(T_j-25)]$$

| T_j | Multiplier | R_ds (max) |
|---|---|---|
| 25 °C | 1.00 | 1.20 mΩ |
| 85 °C | 1.27 | 1.52 mΩ |
| 125 °C | 1.45 | 1.74 mΩ |

### 1.2 Current path in 6-step drive with complementary PWM

In each 60° commutation sector, two phases carry current:

- **PWM'd phase:** current flows through the high-side FET (duty D) or the low-side synchronous FET (1 − D).
- **Static phase:** the low-side FET is on for the whole sector.

So at any instant, exactly **two R_ds(on) are in series**, independent of duty:

$$P_{cond,motor} = I^2 \cdot 2R_{ds}(T_j)$$

**Per motor at 80 A:**

| T_j | P_cond per motor |
|---|---|
| 25 °C | 6400 × 2.4 mΩ = **15.4 W** |
| 85 °C | 6400 × 3.04 mΩ = **19.5 W** |
| 125 °C | 6400 × 3.48 mΩ = **22.3 W** |

### 1.3 Per-FET distribution

Each FET conducts for 120° of the electrical cycle (scaled by D or 1 − D when it is the PWM'd device). The figures below use the hot (125 °C) R_ds.

- **Peak instantaneous loss per FET:** 6400 × 1.74 mΩ = **11.1 W**
- **Average per FET:** 22.3 / 6 ≈ **3.7 W**

The electrical period at 1 kHz electrical is 1 ms. Each 120° conduction window is therefore about 0.33 ms. Typical Z_th(j-c) at that pulse width is about 0.1 K/W, giving a junction ripple of roughly **1.1 K**, which is negligible. Junction temperature is dominated by the board's bulk temperature, not by per-FET ripple.
