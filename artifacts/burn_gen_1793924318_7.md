# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Sensor Fusion

I don't have the Job #25 specification, so this design uses typical brushless-gimbal assumptions, listed in §0. The design is parameterised: replace the constants with your motor, encoder, and frame data and the derivations still hold.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic encoder per axis (AS5047P / MT6701 class), SPI |
| Inverter | 3-phase, two low-side shunts, center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro and accel ODR 8 kHz |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |

**Loop rates (all phase-locked to the PWM timer):**

```
PWM / ADC trigger      20 kHz   (Ts_i = 50 µs)   current loop (FOC)       ISR priority 0
IMU DRDY / fusion       8 kHz → decimated to 4 kHz
Rate (velocity) loop    4 kHz   (Ts_v = 250 µs)                           ISR priority 1
Angle (attitude) loop   1 kHz   (Ts_a = 1 ms)                             ISR priority 2
Cogging LMS, telemetry  background
```

Each outer loop has a bandwidth 5–10× lower than the loop inside it. Indicative values:

- Current loop: ~1.5 kHz
- Rate loop: ~150–250 Hz
- Angle loop: ~20–40 Hz

## 1. FOC Current Loop

### 1.1 Electrical Angle

$$\theta_e = \mathrm{wrap}_{2\pi}\big(p\,\theta_m - \theta_{\text{off}}\big)$$

$\theta_{\text{off}}$ is found at commissioning: inject $v_d$ = const with $\theta_e = 0$, let the rotor settle, then record $p\,\theta_m$.

### 1.2 Clarke and Park Transforms

Two shunts are measured, and $i_c = -i_a - i_b$.

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix} \begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 PMSM Model in the dq Frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

$$\tau_e = \tfrac32\, p\,\lambda_m\, i_q = K_t\, i_q \qquad (\text{surface PM: } L_d = L_q = L)$$

### 1.4 PI Current Controller (Pole–Zero Cancellation)

The plant per axis is $G_i(s) = \dfrac{1}{Ls + R}$. Choosing

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

cancels the electrical pole $R/L$, leaving the open loop $\omega_{ci}/s$. The closed loop is therefore first order with bandwidth $\omega_{ci}$. Pick $\omega_{ci} \le 2\pi f_s / 10$ to tolerate one sample of computation delay plus half a sample of PWM delay.
