# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the specifics of Job #40, so this design rests on the assumptions in §0. Every parameter that depends on them is named and grouped in one config struct, so you can change them in one place.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7, single-precision FPU, ≥170 MHz |
| Motors | Gimbal BLDC, e.g. 12N14P (pole pairs `p = 7`, slots `Ns = 12`), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit magnetic encoder per axis (AS5048A / MT6701) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, placed point-symmetric about the plate's rotation center |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

**Loop rates**

| Loop | Rate | Ts | Trigger |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | PWM center-aligned ADC trigger |
| IMU sampling + filtering | 8 kHz | 125 µs | IMU INT1 / timer-locked |
| Velocity (inertial rate) | 4 kHz | 250 µs | Decimated from IMU |
| Angle (attitude) | 1 kHz | 1 ms | Decimated |
| Cogging LMS adaptation | 1 kHz | — | Background |
