# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the Job #11 specification, so this design rests on the assumptions in §0. Every equation is written symbolically, so you can substitute your real parameters. The values marked *(assume)* need confirmation.

## 0. System Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU, CORDIC) ×1 for all 3 axes |
| Motors | Gimbal BLDC, 12N14P (pole pairs *p* = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH *(assume)* |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| Current sense | 2-shunt low-side, 12-bit ADC, PWM-synchronous |
| IMUs | 2× ICM-42688-P on the camera plate, each on its own SPI bus, both clocked from a shared 32.768 kHz CLKIN |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

**Loop rates (multi-rate cascade).** Each loop runs at least 4× faster than the loop outside it, and each loop's bandwidth is at least 5× higher.

| Loop | Rate | Target bandwidth |
|---|---|---|
| PWM / current (FOC) | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| IMU sample + filtering | 8 kHz (ODR) | — |
| Velocity (rate) loop | 4 kHz | ω_v ≈ 2π·150 rad/s |
| Attitude fusion + angle loop | 1 kHz | ω_a ≈ 2π·25 rad/s |

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Motor model in the rotor (dq) frame

$$
v_d = R\,i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R\,i_q + L_q\frac{di_q}{dt} + \omega_e L_d i_d + \omega_e\lambda_m
$$

The electrical angle is θ_e = p·θ_m − θ_offset, and ω_e = p·ω_m.

For a surface-mount PMSM (L_d = L_q = L), the torque is:

$$
\tau_m = \tfrac{3}{2}\,p\,\lambda_m\, i_q \equiv K_t\, i_q
$$
