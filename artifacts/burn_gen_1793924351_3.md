# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual-IMU Sensor Fusion

I don't have the Job #17 specification, so this design uses common gimbal hardware as baseline assumptions. Every assumption is parameterized in the code (`AxisParams`, `ImuConfig`), so you can substitute your real values.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit magnetic absolute encoder (e.g. AS5048A or MT6701) on each joint |
| MCU | STM32G4/H7 class with FPU, center-aligned PWM, 3 shunts or 2 inline shunts |
| Loop rates | Current/FOC: 20 kHz. Velocity: 4 kHz. Angle/attitude: 1 kHz. IM
