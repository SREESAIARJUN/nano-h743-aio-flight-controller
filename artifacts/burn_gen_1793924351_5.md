# FOC Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Design Assumptions

I don't have the Job #41 specification sheet, so this design uses typical brushless-gimbal values. Every value is a named constant in the code, so you can substitute the real parameters.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5 Ω, L = 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), on the motor shaft |
| Bus | Vdc = 12–16 V, center-aligned PWM at 20 kHz |
| IMUs | 2 × ICM-42688-P on SPI at 24 MHz. ODR = 8 kHz, FIFO, gyro ±2000 dps, accel ±16 g |
| IMU placement | IMU-A on the camera plate (stabilization reference). IMU-B on the camera plate at a different lever arm, or rigidly on the same plate on its own damper. Both must be **rigidly coupled to the same body** for the gyro fusion below. |
