## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Current sense | 2-phase inline shunts (a voltage-mode fallback is provided) |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, common CLKIN/FSYNC, mounted symmetrically about a midpoint O |
| Gimbal order | Yaw (outer, z) → Roll (x) → Pitch (y, inner, camera) |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class), single-precision FPU |

| Loop | Rate | Sample time T | Closed-loop bandwidth target |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ω_c ≈ 2π·1500 rad/s |
| IMU sampling and filtering | 8 kHz | 125 µs | n/a |
| Velocity | 4 kHz | 250 µs | ω_v ≈ 2π·120 rad/s |
| Angle / attitude | 1 kHz | 1 ms | ω_θ ≈ 2π·25 rad/s |

Each loop is about 5–10× faster than the bandwidth of the loop outside it. That separation lets each inner loop be treated as unity gain when designing the outer one.

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant; assumes i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform.** The electrical angle is θ_e = p·θ_m − θ_off, where θ_off comes from the alignment procedure:

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

**Inverse Park** uses the transpose of the same matrix.

### 1.2 Plant and PI Design

The dq motor model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

**Decoupling feedforward.** The cross-coupling and back-EMF terms are cancelled explicitly:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m)$$

**Pole-zero cancellation.** After decoupling, each axis is the plant 1/(Ls + R). A PI controller with the gains below cancels the plant pole, giving a closed loop of ω_c/(s + ω_c):

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

**Discretisation.** The integrator uses forward Euler: x_{k+1} = x_k + K_i T e_k.

**Anti-windup by back-calculation.** The saturated output feeds back into the integrator:

$$x_{k+1} = x_k + T\left[K_i e_k + K_{aw}\left(u^{sat}_k - u_k\right)\right],\qquad K_{aw} = K_i / K_p$$

**Voltage limiting.** The voltage vector is limited to the linear SVPWM circle, |v_dq| ≤ V_bus/√3. The q-axis takes priority:

$$v_d \leftarrow \operatorname{clamp}\!\left(v_d,\ \pm V_{max}\right),\qquad v_q \leftarrow \operatorname{clamp}\!\left(v_q,\ \pm\sqrt{V_{max}^2 - v_d^2}\right)$$
