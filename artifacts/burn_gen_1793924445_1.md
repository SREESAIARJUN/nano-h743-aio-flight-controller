## 1. Control Architecture

```
                 1 kHz                       4 kHz                         20 kHz
 θ_ref ──►[Attitude P + FF]──ω_ref──►[Velocity PI + accel FF]──iq_ref──►(+)──►[Current PI dq]──►[SVPWM]──► Motor
              ▲                         ▲                              ▲  ▲          ▲
              │ q̂_cam (fused)           │ ω_fb (gyro ⊕ encoder)        │  │ i_d,i_q   │ θ_e (encoder)
         [Dual-IMU fusion]◄── 8 kHz ──[Vibration filters]              │  └─[Clarke/Park]
                                                                       │
                                           iq_cog(θ_m) ◄──[Anti-cogging FF (LMS-adapted Fourier series)]
```

**Bandwidth separation rule.** Each outer loop should have 5–10× lower bandwidth than the loop inside it:

ω_c,i ≈ 2π·1500 rad/s,  ω_c,v ≈ 2π·150 rad/s,  ω_c,θ ≈ 2π·20 rad/s

## 2. Field-Oriented Control (Current Loop, 20 kHz)

### 2.1 Electrical angle

θ_e = p · (θ_m − θ_offset)  mod 2π

`θ_offset` is found at calibration: apply a fixed d-axis voltage V_align with θ_e = 0, let the rotor settle, then record θ_m.

### 2.2 Clarke and Park transforms

The amplitude-invariant Clarke transform, assuming balanced currents (i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2 i_b) / √3

The Park transform rotates into the rotor frame:

- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

### 2.3 Plant model in the dq frame

- L_d · di_d/dt = v_d − R i_d + ω_e L_q i_q
- L_q · di_q/dt = v_q − R i_q − ω_e L_d i_d − ω_e λ_m

Here ω_e λ_m is the back-EMF term, with λ_m = (2/3)·Kt/p. Torque is then:

τ = (3/2) p λ_m i_q = Kt i_q   (for a surface PM motor, L_d = L_q)

### 2.4 PI with decoupling, back-EMF feedforward, and anti-windup

After removing the cross-coupling terms, the plant reduces to a first-order lag, G(s) = 1/(Ls + R).

**Pole-zero cancellation gains.** Choosing these gains cancels the plant pole and gives a closed loop of ω_c,i / (s + ω_c,i):

- K_p,i = L · ω_c,i
- K_i,i = R · ω_c,i

**Discrete control law** (sample time T_s, k-th sample). For the d axis:

1. e_d[k] = i_d,ref − i_d[k]
2. v_d* = K_p e_d + I_d[k] − ω_e L i_q
3. The q axis is analogous, with feedforward terms +ω_e L i_d + ω_e λ_m.

**Voltage limit (circular).** With V_max = V_bus/√3 (the SVPWM linear range):

- If ‖v*‖ > V_max, scale v_sat = v* · V_max / ‖v*‖.
- Give the d axis priority: |v_d| ≤ V_max, and |v_q| ≤ √(V_max² − v_d²).

**Back-calculation anti-windup:**

I[k+1] = I[k] + K_i T_s e[k] + K_aw (v_sat − v*)

with K_aw ≈ 1/K_p · K_i T_s, or simply K_aw ≈ T_s/T_i.

### 2.5 Inverse Park transform and SVPWM (min-max zero-sequence injection)

Inverse Park:

- v_α = v_d cos θ_e − v_q sin θ_e
- v_β = v_d sin θ_e + v_q cos θ_e

Phase voltages:

- v_a = v_α
- v_b = −½ v_α + (√3/2) v_β
- v_c = −½ v_α − (√3/2) v_β

Zero-sequence injection and duty cycles:

- v_0 = −½ (max(v_a,v_b,v_c) + min(v_a,v_b,v_c))
- D_x = ½ + (v_x + v_0) / V_bus

This is mathematically equivalent to 7-segment SVPWM and gives a 15.5% higher linear range than sine PWM.

> **Voltage-mode fallback.** High-R gimbal motors are often run without current sensing. In that case use i_q ≈ (v_q − ω_e λ_m)/R and set v_q = R·i_q,ref + ω_e λ_m. The code supports this through `kUseCurrentSensing`.
