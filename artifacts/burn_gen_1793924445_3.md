## Part 1: Mathematical Design

### 1.1 Field-Oriented Control (20 kHz)

**Electrical angle**

$$\theta_e = \big(p\,\theta_m - \theta_{e,0}\big) \bmod 2\pi$$

Here θ_e,0 is the electrical offset found during alignment: apply V_d with θ_e = 0, then read θ_m.

**Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**PMSM model in the dq frame**

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

**Current PI by pole–zero cancellation.** The plant per axis is G(s) = 1/(Ls + R). Choose:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

The closed loop then becomes first-order with bandwidth ω_ci. Choose ω_ci ≤ 2π·f_s/10, which gives about 2π·2 kHz at f_s = 20 kHz.

**Decoupling and back-EMF feedforward**

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e \lambda_m$$

The command is i_d* = 0 for SPM gimbal motors.

**Voltage limit (circular).** Under SVPWM the voltage magnitude must satisfy:

$$\sqrt{v_d^2+v_q^2}\le V_{max} = \frac{V_{bus}}{\sqrt3}$$

Priority is given to v_d. Then:

$$|v_q|\le\sqrt{V_{max}^2-v_d^2}$$

**SVPWM via min-max injection.** This is mathematically identical to sector-based SVPWM. First compute the phase voltages:

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

Then inject the common-mode term and compute duties:

$$v_{0} = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

**Discrete PI with back-calculation anti-windup (Tustin / forward Euler on the integrator)**

$$u_k = K_p e_k + I_k$$
$$u_k^{sat} = \mathrm{sat}(u_k)$$
$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(u_k^{sat}-u_k)$$

A typical choice is K_aw = K_i / K_p, which gives a tracking time constant equal to T_i.
