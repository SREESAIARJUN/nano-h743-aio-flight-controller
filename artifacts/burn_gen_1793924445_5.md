## 0. Assumed Hardware and Loop Timing

| Item | Assumption |
|---|---|
| MCU | STM32G4/H7-class, single-precision FPU, about 170 MHz or more |
| Motors | Gimbal BLDC 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 1–3 mH **[P]** |
| Position sensor | 14-bit magnetic encoder per axis (AS5048A/MT6701) |
| Current sense | 2-phase low-side shunts (FOC current loop enabled) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, gyro/accel ODR = 8 kHz |
| Gimbal kinematics | Yaw (base) → Roll → Pitch (camera) |

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (d/q PI) | 20 kHz (PWM-synchronous) | ω_c ≈ 2π·1.5 kHz |
| Inertial rate (velocity) PI | 4 kHz | ω_v ≈ 2π·60–120 Hz |
| Angle P (+ feedforward) | 1 kHz | ω_a ≈ 2π·8–15 Hz |
| Attitude fusion | 4 kHz | — |

Keep a bandwidth separation of at least 5× between adjacent loops (ω_c ≥ 5ω_v and ω_v ≥ 5ω_a). This lets each inner loop be treated as unity gain when tuning the loop outside it.
