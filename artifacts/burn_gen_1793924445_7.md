# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

I don't have the specification for "Job #15," so this design is built on the explicit assumptions below. Every equation is parameterized, so you can substitute your actual motor, sensor and timing numbers.

---

## 0. Design Assumptions

| Item | Assumed value | Parameter |
|---|---|---|
| Motor | Gimbal BLDC, 12N14P (e.g. GBM2804-class) | `Ns = 12`, `p = 7` pole pairs |
| Phase R / L | 5.6 Ω / 1.2 mH (line-to-neutral) | `R`, `L` |
| Torque constant | 0.045 N·m/A | `Kt = 1.5·p·λ_m` |
| Encoder | 14-bit magnetic (AS5048A / MT6701) | `θ_m` |
| Current sense | 2- or 3-shunt, inline or low-side | `i_a`, `i_b` |
| MCU | STM32G4 / H7, single-precision FPU (CORDIC optional) | — |
| PWM / current loop | 20 kHz / 20 kHz | `T_c = 50 µs` |
| Velocity loop | 4 kHz | `T_v = 250 µs` |
| Angle loop | 1 kHz | `T_θ = 1 ms` |
| IMUs | 2 × ICM-42688-P, 8 kHz ODR, separate SPI buses | IMU A, IMU B |
| Fusion / AHRS | 4 kHz (2:1 decimated from 8 kHz) | `T_f = 250 µs` |
| Vibration source | Airframe props, 80–400 Hz fundamental plus harmonics | — |
