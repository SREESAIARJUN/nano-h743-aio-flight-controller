# STM32H743 AIO Flight Controller with 4-in-1 ESC (Job #36): Reference Design Package

## 0. Architecture Corrections

Two points in the brief need correcting before any math is meaningful.

1. **The STM32H743 does not run the ESC.** In every viable 4-in-1 AIO design, the H743 is the flight controller MCU running ArduPilot. Each motor channel has its own ESC MCU (AT32F421 or STM32G071 running AM32/BLHeli_32-class firmware), which generates the 48 kHz complementary PWM. The H743's job is to emit bidirectional DShot600 and capture eRPM telemetry. This document models it that way.
2. **"Nano" and "80 A per channel" conflict.** A 20×20 mm board cannot thermally sustain 4×80 A. The math below shows 80 A is a roughly 1.4 s burst rating, with about 33 A continuous. I recommend a **30.5×30.5 mm** (or 25.5 mm whoop-pattern) board with honest labeling: *"33 A continuous / 80 A 1 s burst."* The calculations use a 30.5 mm board. A 20 mm board roughly halves the burst time.

## 1. Conduction Loss Model

In 6-step operation, two phases conduct at any instant:
- **Phase A** (PWM'd): the high-side FET conducts for duty D, and the low-side FET conducts synchronously for (1−D).
- **Phase B** (return): the low-side FET is on continuously.

$$P_{cond} = I^2 R_{DS}\,[D + (1-D)] + I^2 R_{DS} = 2\,I^2 R_{DS}(T_j)$$

The result is independent of D. This is a key point: the burst loss does not drop at partial throttle for a given current.

Temperature correction:

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha(T_j - 25)\right],\quad \alpha \approx 0.005\ /\text{K}$$

At 80 A with T_j = 125 °C:

$$P_{cond} = 2 \times 80^2 \times 1.5\,\text{m}\Omega = \mathbf{19.2\ W\ per\ channel}$$

PCB copper path loss (about 0.3 mΩ per channel, from pad to phase pad to battery plane):

$$P_{Cu} = 80^2 \times 0.3\,\text{m}\Omega = 1.9\ \text{W}$$

## 2. Switching Loss Model at 48 kHz

Only the PWM'd half-bridge switches.

| Term | Formula | Value @ 80 A |
|---|---|---|
| V–I overlap (hard switching) | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·30 ns·48 k | **1.45 W** |
| Dead-time body diode | V_F·I·2t_d·f_sw = 0.8·80·200 ns·48 k | **0.61 W** |
| Reverse recovery | Q_rr·V·f_sw = 50 nC·25.2·48 k | 0.06 W |
| C_oss | ½·C_oss·V²·f_sw | 0.02 W |
| Gate charge (mostly in driver) | 2·Q_g·V_gs·f_sw | 0.06 W |
| **Total** | | **≈ 2.2 W** |

Scaling rule: P_sw ≈ 0.0275 W/A × I, which is linear in current.

**48 kHz tradeoff.** Overlap loss scales linearly with f_sw. At 24 kHz you save about 1.1 W per channel at 80 A, but you get more audible noise and current ripple. 48 kHz is acceptable because switching is only about 10% of total loss; conduction dominates.

**Total per channel @ 80 A:** 19.2 + 2.2 + 1.9 ≈ **23.3 W**
**Four channels simultaneous:** **≈ 93 W**
