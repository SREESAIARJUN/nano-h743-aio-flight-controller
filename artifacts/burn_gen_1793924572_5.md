## 0. Architecture Decisions and Assumptions

ArduPilot cannot commutate motors. It runs on the H743 as the flight controller, and each ESC channel needs its own commutation MCU. The board therefore has three parts:

| Block | Device | Firmware | Role |
|---|---|---|---|
| FC | STM32H743VIT6 (LQFP100), 400 MHz rev Y / 480 MHz rev V | ArduPilot | Flight control, sends bidir DShot600 |
| ESC ×4 | AT32F421K8U7 (or STM32G071) | AM32 | 6-step commutation, 48 kHz PWM, eRPM telemetry |
| Gate drive ×4 | FD6288Q (3-phase half-bridge driver) | — | 12 FETs total per motor (6) → 24 FETs |

**Electrical assumptions.** Replace these with datasheet values before release.

| Parameter | Symbol | Value |
|---|---|---|
| Battery (6S full) | V_bus | 25.2 V |
| Burst phase current per motor | I_pk | 80 A |
| MOSFET (40 V, 3.3×3.3 mm DFN class) | R_ds(on),25 | 1.2 mΩ |
| R_ds tempco | α | 0.006 /K |
| Gate charge / Miller charge | Q_g / Q_gd | 50 nC / 10 nC |
| Effective output capacitance | C_oss,eff | 1.5 nF |
| Reverse-recovery charge | Q_rr | 40 nC |
| Body-diode forward drop | V_f | 0.8 V |
| Dead time | t_dt | 100 ns |
| Gate-drive current (FD6288 ≈ 1.0/1.5 A, with R_g) | I_g | ≈0.7 A effective |
| Switching frequency | f_sw | 48 kHz |
| Board | — | 30.5×30.5 mm, 8-layer, 2 oz all layers |

> **Scope flag:** A "nano" 4-in-1 board **cannot sustain 80 A on all four motors simultaneously** for more than about 2 seconds (see §3). "80 A burst" must be specified as a per-motor, time-limited rating. Otherwise the board must grow, or the thermal path must be upgraded.

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step synchronous commutation

At any instant in a commutation sector, two legs are active:
- **PWM leg:** current alternates between the HS FET (duty D) and the LS FET (1−D), using synchronous rectification.
- **Sink leg:** the LS FET conducts continuously.
