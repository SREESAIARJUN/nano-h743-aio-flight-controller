# STM32H743 Nano AIO (FC + 4-in-1 ESC): Design Model, Job #58

## 0. Architecture Decisions and Assumptions

| Parameter | Value | Note |
|---|---|---|
| FC MCU | STM32H743VIH6 (TFBGA100), 480 MHz | Runs ArduPilot |
| ESC MCUs | 4× AT32F421K8U7 running AM32 | See note below |
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal | 40 V MOSFETs required |
| MOSFET | 40 V N-ch, PDFN 3.3×3.3, R_DS(on) = 1.6 mΩ @ 25 °C, Q_g ≈ 50 nC, Q_oss ≈ 30 nC | Class-representative values. Replace with your chosen part's datasheet values. |
| Gate driver | FD6288Q (3-phase, bootstrap) ×4 | |
| PWM frequency | 48 kHz, synchronous rectification, 6-step commutation | |
| Board | 30.5×30.5 mm, 6-layer, 2 oz on all layers | "Nano" interpreted as a 30×30 mm mounting pattern |
| Burst spec | 80 A per motor, simultaneously on all four | Worst case |

**Why the H743 does not drive the gates directly:** the H743 does not commutate the motors itself. Four 3-phase bridges need 12 complementary PWM pairs plus BEMF comparators. The H743 has only TIM1/TIM8 (6 complementary pairs total), and ArduPilot has no in-tree 6-step/FOC motor control. The H743 therefore sends bidirectional DShot600 to four dedicated ESC MCUs.

**Feasibility warning:** 4 × 80 A = 320 A total, which is about 7.7 kW at 6S. An XT60 connector, typical battery leads, and a 30×30 board cannot sustain this. The analysis below shows that 80 A is a burst rating of about 1.5–2 s, not a continuous rating.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

R_DS(on)(T_j) = R_25 · (T_j / 298 K)^α, with α ≈ 2.0–2.3 for trench silicon.

Linear engineering approximation: R(T_j) ≈ R_25 · [1 + k(T_j − 25)], with k ≈ 0.005 /K.

At T_j = 125 °C: R_hot ≈ 1.6 mΩ × 1.5 = **2.4 mΩ**

### 1.2 Six-step with synchronous rectification

At any instant, the motor current flows through one high-side path and one low-side path. During PWM-off, the complementary FET carries the current instead of the body diode. Because exactly two FETs carry the full current at every moment, regardless of duty cycle:

P_cond,ESC = 2 · I_rms² · R_DS(on)(T_j)

At I = 80 A (trapezoidal phase current treated as DC during conduction):

P_cond,ESC = 2 × 80² × 2.4 mΩ = **30.7 W per ESC**

Each FET conducts for about 1/3 of the electrical cycle (sum of the high-side on-time and synchronous low-side share). Per-FET average:

P_cond,FET ≈ 30.7 / 6 ≈ **5.1 W**

### 1.3 Electrothermal coupling

R_DS(on) depends on T_j, so solve the loop iteratively:

T_j(n+1) = T_pcb + P_FET(T_j(n)) · R_θ,j-pcb

This converges in 2–3 iterations for the values used here. If dP/dT_j · R_θ ≥ 1, thermal runaway occurs. With the values here, dP/dT ≈ 0.026 W/K × 4.5 K/W ≈ 0.12, so the loop is stable.

## 2. Switching Losses at f_sw = 48 kHz

Only the PWM-ing leg switches. Each PWM period has one turn-on and one turn-off of the hard-switched FET.

| Term | Formula | Value @ 25.2 V, 80 A |
|---|---|---|
| V·I overlap | ½ · V_bus · I · (t_r + t_f) · f_sw, with t_r + t_f = 20 ns | ½ × 25.2 × 80 × 20 ns × 48 k = **0.97 W** |
| C_oss charge | Q_oss · V_bus · f_sw | 30 nC × 25.2 × 48 k = **0.04 W** |
| Dead-time body diode | V_F · I · 2·t_dt · f_sw, with t_dt = 50 ns, V_F = 0.8 V | 0.8 × 80 × 100 ns × 48 k = **0.31 W** |
| Q_rr (reverse recovery) | Q_rr · V_bus · f_sw, with Q_rr ≈ 40 nC | **0.05 W** |
| Gate drive (dissipated in driver, not the FET) | Q_g · V_GS · f_sw · 2 | 50 nC × 10 × 48 k × 2 = 0.05 W |
| **Total switching, per ESC** | | **≈ 1.4 W** |

Conduction dominates by about 22×. Raising f_sw to 96 kHz would cost only about 1.4 W more per ESC.

**Per-ESC total at 80 A: P ≈ 32.1 W. Four ESCs: ≈ 128 W.**

## 3. Thermal Model

### 3.1 Junction-to-board (per FET)

| Resistance | Value |
|---|---|
| R_θ,jc (PDFN 3.3×3.3, bottom pad) | ≈ 1.5 K/W |
| R_θ,c-pcb (solder + 9× 0.3 mm thermal vias, 2 oz) | ≈ 3.0 K/W |
| **R_θ,j-pcb** | **≈ 4.5 K/W** |

ΔT_j-pcb = 5.4 W × 4.5 = **24 K**

This assumes sharing-weighted switching loss on the active FETs.

### 3.2 Board as a lumped thermal capacitance (dominant for bursts)

| Component | Volume | Mass | c_p | Heat capacity |
|---|---|---|---|---|
| Copper (6 × 70 µm, 30×30 mm) | 0.378 cm³ | 3.39 g | 0.385 J/g·K | 1.31 J/K |
| FR-4 (1.6 mm) | 1.44 cm³ | 2.66 g | 1.1 J/g·K | 2.93 J/K |
| 24 FETs + components | | ≈ 1.5 g | ≈ 0.7 J/g·K | 1.05 J/K |
| **Total C_th** | | | | **≈ 5.3 J/K** |

Board-to-air resistance with prop-wash, R_θ,ba ≈ 6 K/W (both sides convective, h ≈ 80 W/m²K).

First-order thermal response:

T_pcb(t) = T_a + P · R_θ,ba · (1 − e^(−t/τ)),  where τ = R_θ,ba · C_th ≈ 32 s

For t ≪ τ, the heating is essentially adiabatic:

dT/dt ≈ P / C_th = 128 / 5.3 ≈ **24 K/s**

### 3.3 Burst duration limit

Constraints: T_a = 40 °C, T_j,max = 150 °C, derated target 125 °C.

T_pcb,max = 125 − 24 = 101 °C → ΔT_pcb = 61 K → **t_burst ≈ 61 / 24 ≈ 2.5 s**

With 30 % margin, **specify 80 A for ≤ 1.5 s (all four motors) or about 3 s (two motors).**

### 3.4 Sustainable continuous current

Steady state requires P = ΔT_pcb / R_θ,ba = 61 / 6 ≈ 10 W total for the board. Solving 4 · 2 · I² · R_hot ≈ 10 W gives **I_cont ≈ 23 A per motor** (without a heatsink). This is consistent with real 30×30 4-in-1 ratings.

**Mitigations:**
- An aluminium heatsink adds about 4 g, roughly +3.6 J/K of capacity and a lower R_θ,ba.
- Thicker copper, or 3 oz inner layers.
- Parallel FETs.

### 3.5 FC thermal isolation

The H743 is rated for T_j = 125 °C (V-grade; 105 °C for some variants). Measures:
- Place the MCU on a stacked or slotted region of the board.
- Use no shared copper pour with the power stage.
- Read the MCU's internal temperature and the ESC NTC via `ESC_TELEM`.
