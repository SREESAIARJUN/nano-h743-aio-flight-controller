## 0. System Architecture and Key Assumptions

The H743 does **not** drive the MOSFETs. It runs ArduPilot and sends bidirectional DShot600 to four ESC MCUs (AM32 or BLHeli_32 class, e.g. AT32F421 or STM32G071), one per channel. Those MCUs generate the 48 kHz PWM.

```
 6S LiPo ──┬── 4-in-1 ESC: 4 × [ESC MCU → 3-ph gate driver → 6 MOSFETs → motor]
           │        ▲ DShot600 bidir (1 wire/motor), CURR, VBAT
           └── FC: STM32H743 @ 400/480 MHz, ArduPilot
```

| Parameter | Symbol | Assumed value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Burst phase current per channel | I_pk | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, 5×6 or 3.3×3.3 DFN) | R_ds(on),25 | 1.2 mΩ |
| R_ds temperature factor @ T_j ≈ 110 °C | k_T | 1.4 |
| Switching charge (Q_gs2 + Q_gd) | Q_sw | 3 + 8 = 11 nC |
| Total gate charge | Q_g | 40 nC |

| Effective output capacitance | C_oss,tr | 1.5 nF |
| Gate plateau voltage | V_pl | 3.0 V |

> **Design flag (read first):** 80 A per channel is 320 A total and roughly 95 W of dissipation on a nano (20×20 mm) board. The analysis below shows this is a **seconds-scale transient rating, not a continuous one**. The burst rating must be specified with a duration (Section 3.4).

## 1. Conduction Loss Model

### 1.1 Current path
In 6-step commutation, two phases conduct in each 60° sector:

- **PWM on-time (D):** HS_x and LS_y conduct.
- **PWM off-time (1−D):** LS_x (synchronous rectification) and LS_y conduct.

Two channel-resistances are therefore in series **at all times**, independent of duty cycle:

$$P_{cond,motor} = I_{rms}^2 \cdot 2\,R_{ds(on)}(T_j)$$

### 1.2 Ripple correction

$$\Delta I = \frac{V_{bus}\,D(1-D)}{L_{ph}\,f_{sw}} \;\xrightarrow{D=0.5}\; \frac{25.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 6.56\ \text{A}_{pp}$$

$$I_{rms}^2 = I_{pk}^2 + \frac{\Delta I^2}{12} = 6400 + 3.6 = 6403.6\ \text{A}^2$$
