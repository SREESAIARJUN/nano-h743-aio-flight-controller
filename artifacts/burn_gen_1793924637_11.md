# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #41, so this design rests on the assumptions below. Replace them with your real parameters. Every gain in the code is computed from these values, not hard-coded.

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (GBM2804-class), pole pairs `p = 7` |
| Phase parameters | R = 5.6 Ω (line-neutral), L = 1.8 mH, Kt ≈ 0.06 N·m/A |
| Current sensing | Inline or low-side shunt current sensing on 2 phases |
| Rotor sensors | 14-bit absolute magnetic encoder per axis (MT6701/AS5048-class). Used for commutation and cogging lookup. |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, gyro ±1000 dps, accel ±8 g |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7-class) |
| Loop rates | Current loop 20 kHz. IMU fusion + velocity loop 4 kHz (8 kHz IMU decimated by 2). Angle loop 1 kHz. |
