## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Commutation sensor | 14-bit absolute magnetic encoder (AS5048A/MT6835 class) |
| Current sensing | 2-shunt low-side, sampled center-aligned |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class), single-precision float |
| IMUs | 2× ICM-42688-P on the camera plate, mirrored about the plate center, SPI, ODR 8 kHz |

### Loop Rates

```
 20 kHz  ── Current loop (FOC: Clarke/Park, PI, SVPWM)       [PWM ISR]
  8 kHz  ── IMU sampling + notch filtering                   [IMU DRDY ISR]
  4 kHz  ── Velocity loop (inertial rate) + cogging FF       [decimated in PWM ISR]
  1 kHz  ── Attitude estimator + angle loop + joint mapping  [task]
```

**Key architectural decision.** The encoder is used for commutation (θₑ) and the cogging feedforward. The velocity and angle loops close on the **camera-frame inertial rate and attitude** measured by the IMUs. This is what makes it a stabilizer rather than a position servo.

## 1. FOC Current Loop Equations

### 1.1 Electrical Angle

$$\theta_e = \mathrm{wrap}_{2\pi}\big(p\,(\theta_m - \theta_{\text{offset}})\big)$$

### 1.2 Clarke Transform (2-shunt, assuming i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park Transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant Model (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 1.5 PI with Pole-Zero Cancellation

The design targets closed-loop current bandwidth ω_ci:

$$C_i(s) = K_{p,i} + \frac{K_{i,i}}{s},\quad K_{p,i} = L\,\omega_{ci},\quad K_{i,i} = R\,\omega_{ci}$$

This yields the closed loop $i/i^* = \omega_{ci}/(s+\omega_{ci})$.

To keep phase margin above roughly 60° given the 1.5·T_s computation and PWM delay:

$$\omega_{ci} \le \frac{2\pi f_s}{20}$$

At f_s = 20 kHz, this means ω_ci ≈ 6000 rad/s.

### 1.6 Decoupling and Back-EMF Feedforward

$$v_d^* = \mathrm{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \mathrm{PI}_q(e_q) + \omega_e L i_d + \omega_e \lambda_m$$

where $\lambda_m = \frac{2K_t}{3p}$.

### 1.7 Voltage Limiting (circular, d-priority)

$$|v_d| \le V_{max},\qquad |v_q| \le \sqrt{V_{max}^2 - v_d^2},\qquad V_{max} = \frac{V_{bus}}{\sqrt3}\cdot 0.95$$

### 1.8 Anti-Windup (back-calculation)

$$I[k+1] = I[k] + T_s\Big(K_i e[k] + K_{aw}\,(u_{sat}[k] - u[k])\Big),\qquad K_{aw} = K_i/K_p$$
