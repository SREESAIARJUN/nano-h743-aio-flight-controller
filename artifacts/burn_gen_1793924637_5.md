## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | Cortex-M4F/M7 (STM32G474 / H7), single-precision FPU |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), read every current cycle |
| Current sense | 2-shunt or inline, synchronous ADC at PWM center |
| PWM | 20 kHz center-aligned, SVPWM |
| IMUs | 2× ICM-42688-P on the camera plate, mounted **diametrically opposite** about the plate centroid, SPI at 24 MHz, ODR 8 kHz |
| Gimbal kinematics | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |

**Loop rates (cascade separation ≥ 5×):**

```
20 kHz  : ADC → Clarke/Park → current PI → SVPWM          (ISR, per motor)
20 kHz  : Encoder read → PLL (θ̂, ω̂)
 8 kHz  : IMU read ×2 → align → notch/LPF → fusion
 4 kHz  : Rate loop (camera frame, gyro feedback) → J^T → iq_ref
 4 kHz  : Cogging feedforward + LMS adaptation
 1 kHz  : Attitude estimator (Mahony) + angle loop → ω_cmd
```

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical Angle

$$
\theta_e = p\,(\theta_m - \theta_{\text{off}}) \pmod{2\pi}
$$

`θ_off` is identified at startup by aligning the d-axis with a fixed voltage vector.

### 1.2 Clarke Transform (Amplitude-Invariant)

With $i_a + i_b + i_c = 0$:

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

### 1.3 Park Transform

$$
\begin{bmatrix} i_d \\ i_q \end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}
$$

### 1.4 Plant Model (SPMSM, $L_d = L_q = L$)

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

The torque is

$$
\tau = \tfrac32\, p\,\lambda_m\, i_q = K_t\, i_q
$$
