# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

## 0. Assumptions

I don't have the original Job #1 spec, so the design rests on the assumptions below. Every value is a named parameter in the code, so you can substitute your actual hardware numbers.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC (e.g. GBM-style 12N14P), pole pairs `P=7`, slots `S=12` |
| Drive | 3-phase inverter, 2 low-side shunts (or inline), 24 V bus, center-aligned PWM |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5047P/MT6701-class) |
| IMU A | ICM-42688-P on the **payload** (camera plate): the stabilized measurement |
| IMU B | ICM-42688-P on the **base** (handle/airframe): disturbance reference |
| MCU | Cortex-M7/M4F class with single-precision FPU (STM32H7/G4) |
| Gimbal order (base to payload) | Yaw (ψ, z) → Roll
