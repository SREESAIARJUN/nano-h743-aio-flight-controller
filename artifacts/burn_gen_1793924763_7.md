# 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

I don't have your Job #11 spec sheet, so this design rests on the explicit assumptions in §0. Every hardware-dependent constant is a named parameter, so you can substitute your values without changing the math.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs *p* = 7), R ≈ 5–12 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), read every PWM cycle |
| MCU | Cortex-M4F/M7 (e.g., STM32G474 or H7) with FPU, center-aligned PWM |
| Current sense | 2 or 3 low-side shunts, ADC sampled at PWM center |
| IMU #0 | ICM-42688-P on the **camera plate (payload)**, used for stabilization feedback |
| IMU #1 | ICM-42688-P on the **base/handle**, used for disturbance feedforward and the vibration reference |

**"Dual vibration rejection" interpretation.** I interpret this as **two IMUs, each with its own filter chain**: on-chip anti-alias filter → adaptive notch(es) → biquad LPF. The base IMU feeds the payload loops through feedforward. If you instead have two co-located IMUs for redundancy, see §5.5.
