I don't have the Job #53 specification, so this design uses the assumptions below. Every motor- and board-specific value is a named constant, so you can swap in your real values.

| Item | Assumed value |
|---|---|

## 1. Timing Architecture

| Loop | Rate | Bandwidth target | Trigger |
|---|---|---|---|
| Current (FOC) | 20 kHz (every 2nd PWM period) | ω_c ≈ 2π·1.5 kHz | ADC injected end-of-conversion ISR |
| Encoder PLL + velocity PI + anti-cogging | 4 kHz | ω_v ≈ 2π·120 Hz | Divider in the current ISR |
| IMU acquisition + filtering | 8 kHz ODR | — | IMU data-ready interrupt → DMA |
| Attitude estimator + angle loop | 1 kHz | ω_p ≈ 2π·25 Hz | Divider |

**Rule of thumb:** each outer loop's bandwidth should be at most 1/5 to 1/10 of the inner loop's. This keeps each inner loop close to unity gain within the outer loop's bandwidth, so the loops can be tuned independently.

## 2. FOC Current Loop

### 2.1 Transforms
Phase currents (i_a, i_b) are measured, and i_c = −i_a − i_b.

**Clarke (amplitude-invariant):**
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park**, with electrical angle θ_e = p·(θ_m − θ_offset):
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant model (surface PMSM, L_d = L_q = L)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:
$$\tau_e = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 2.3 PI with decoupling and back-EMF feedforward
$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e L i_d + \hat\omega_e\hat\lambda_m$$
