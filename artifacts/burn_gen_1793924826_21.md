# STM32H743 Nano FC + 4-in-1 ESC (Job #27): System Architecture Package

> **Scope and honesty statement.** This is a first-principles reference model. Device parameters (MOSFET R_DS(on), charges, R_th) are **stated assumptions** chosen to represent a realistic 40 V-class part in a nano footprint. Substitute your actual BOM datasheet values into the equations before sign-off. The headline conclusion is that **80 A per channel is a seconds-scale burst capability on a nano stack, not a continuous rating.** The math below shows why.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Assumed MOSFET parameters

| Parameter | Symbol | Value |
|---|---|---|
| On-resistance @ 25 °C, V_GS = 10 V | R_DS(on),25 | 1.0 mΩ |
| Temp coefficient (normalized) | α | 0.0055 /K |
| Gate charge | Q_g | 50 nC |
| Output charge | Q_oss | 30 nC |
| Reverse-recovery charge | Q_rr | 40 nC |
| Body diode V_F @ 80 A | V_F | 0.8 V |
| Rise / fall (with FD6288Q) | t_r, t_f | 10 ns / 10 ns |
| Junction-to-case | R_θJC | 1.5 K/W |

Temperature dependence:

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C, R_DS(on) = 1.0 × 1.55 ≈ **1.55 mΩ**.

### 1.2 Current path in 6-step commutation with synchronous rectification

In each 60° commutation sector, exactly two phases carry current I_ph.

- **PWM on:** current flows through HS_a, the motor, then LS_b. That is 2 FETs.
- **PWM off (active freewheel):** current flows through LS_a, the motor, then LS_b. That is 2 FETs.

Current always passes through exactly two channels in series, regardless of duty D. The per-ESC conduction loss is therefore independent of D:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{DS(on)}(T_j) + I_{ph}^2\,R_{Cu}$$

R_Cu is the PCB and solder path resistance (pads, pours, vias, motor pad). For 2 oz copper on a nano board, assume R_Cu ≈ 0.5 mΩ.

At I_ph = 80 A and T_j = 125 °C:

$$P_{cond,ch} = 2(80^2)(1.55\times10^{-3}) + 80^2(0.5\times10^{-3}) = 19.84 + 3.20 = \mathbf{23.0\ W}$$

### 1.3 Per-device distribution

Each FET conducts for at most 1/3 of the electrical period (its 120° sector):

- A HS FET conducts for D × (1/3).
- A LS FET conducts for (1/3) plus (1−D) × (1/3), because it also freewheels for its partner phase.

The LS devices run hottest at low D. Worst-case single-FET average:

$$P_{LS,max} \approx \tfrac{2}{3}\,I^2 R_{DS(on)} \cdot \tfrac{1}{2}\;\;\text{(at } D\to 0\text{)} \approx 3.3\ \text{W}$$

### 1.4 Electro-thermal feedback (stability check)

Because R rises with temperature, a fixed point exists only if:

$$\frac{\partial P}{\partial T}\,R_{\theta} < 1 \;\Rightarrow\; 2I^2R_{25}\,\alpha\,R_{\theta,JA,eff} < 1$$

With I = 80 A: 2·6400·1.0e-3·0.0055 = 0.0704 W/K. Runaway occurs if R_θ,eff > **14 K/W**. A nano-board FET relying on copper spreading (R_θJA ≈ 25–40 K/W in still air) **is in the runaway region in steady state.** This is the first formal proof that 80 A cannot be continuous.

## 2. Switching Loss Model (f_sw = 48 kHz, V_bus = 25.2 V)

Only the PWM'd high-side device hard-switches. The low-side commutates via dead-time and the body diode.

| Loss term | Equation | Value @ 80 A |
|---|---|---|
| V–I overlap | ½ V I (t_r + t_f) f_sw | ½·25.2·80·20 ns·48 k = **0.968 W** |
| Output capacitance | Q_oss V f_sw | 30 nC·25.2·48 k = **0.036 W** |
| Reverse recovery | Q_rr V f_sw | 40 nC·25.2·48 k = **0.048 W** |
| Dead-time body-diode | V_F I (2 t_dt) f_sw, t_dt = 100 ns | 0.8·80·200 ns·48 k = **0.614 W** |
