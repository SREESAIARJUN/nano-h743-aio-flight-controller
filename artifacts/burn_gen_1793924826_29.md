# STM32H743 Nano FC + 4-in-1 ESC (Job #43): Power-Stage Loss Model, Thermal Analysis, Bi-Directional DShot600 DMA Allocation, and Reference Netlists

**Document status: Engineering derivation, Rev A.** The MOSFET parameters below are representative values for a modern 40 V, 5×6 mm power MOSFET. They are not tied to a specific part number. Before layout freeze, replace every value marked ⟨DS⟩ with the selected part's datasheet value and rerun the model.

**Key finding:** this target does not survive 80 A on all four channels for more than about 3 s without active heatsinking. Section 3.4 derives this. It should go to the product owner before the ESC rating is advertised.

---

## 0. Architecture Clarification

The STM32H743 does not commutate the motors. In any ArduPilot-compatible design, the work is split as follows:

| Function | Device | Firmware |
|---|---|---|
| Flight control, attitude/rate loops, DShot command generation, eRPM telemetry decode | STM32H743VIT6 (LQFP100) | ArduPilot (ChibiOS HAL) |
| 6-step commutation, BEMF zero-cross detection, 48 kHz PWM, DShot decode, eRPM telemetry encode | 4× AT32F421K8U7 (or STM32G071), one per motor | AM32 (or BLHeli_32) |
| Gate drive | 4× FD6288Q-class three-phase bootstrapped driver | — |
| Power stage | 24× N-MOSFET (6 per motor) | — |

So "switching losses at 48 kHz" refers to ESC-MCU PWM. "DShot DMA" refers to the H743 timer/DMA subsystem. The two connect over four single-wire bi-directional DShot lines.
