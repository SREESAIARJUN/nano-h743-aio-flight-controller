# STM32H743 Nano FC with 80 A-Burst 4-in-1 ESC: Thermal, Switching and DShot Design

**Job #7, Revision A**

Neither the MOSFET part, board stack-up nor airflow is specified, so every number below comes from a declared assumption (§0). Each equation is written so you can substitute datasheet values for the real BOM. The architecture also has to be stated up front, because the 48 kHz switching and the DShot link happen on different chips:

```
                         DShot600 bidirectional (1 wire per motor)
```

The H743 never switches the FETs directly. The 48 kHz PWM comes from the four ESC MCUs (the AM32 `PWM frequency` setting).

## 1. Conduction-Loss Model

### 1.1 Current path

AM32 uses 6-step commutation with complementary (synchronous) PWM. At any instant, current flows through exactly two conducting channels in series:

- either one high-side FET plus one low-side FET (drive interval),
- or two low-side FETs (freewheel through the synchronous FET).

The body diode carries current only during dead time, which is covered in §2. As a result, the instantaneous conduction loss of the bridge is independent of duty cycle:

$$P_{cond,bridge} = 2\, I^2 \, R_{ds(on)}(T_j)$$

### 1.2 Temperature dependence

$$R_{ds(on)}(T_j) = R_{ds(on),25}\,[1 + \alpha (T_j - 25)]$$

This has to be solved iteratively against the thermal model in §3. The converged junction temperature for the burst case is T_j ≈ 110 °C:

$$R_{ds(on)}(110) = 1.0 \times [1 + 0.0055 \times 85] = 1.47\ \text{m}\Omega$$
