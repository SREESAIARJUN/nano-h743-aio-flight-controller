# STM32H743 Nano FC + 4-in-1 ESC: Systems Architecture Package (Job #1)

## 0. Scope and Governing Assumptions

**Architecture correction.** In this class of product, the STM32H743 does not drive the MOSFETs directly. The H743 runs ArduPilot and emits bidirectional DShot600. Each of the four ESC channels runs its own MCU (AT32F421 or STM32G071 running AM32), which generates the 48 kHz complementary PWM. This document models both sides of that boundary.

**Assumptions.** No MOSFET part number or form factor was specified, so the following baseline is used. Every result is given symbolically so you can substitute real datasheet values.

| Parameter | Symbol | Value | Basis |
|---|---|---|---|
| Bus voltage | V_bus | 25.2 V (6S full) | Worst-case switching |
| Burst phase current | I_pk | 80 A per channel | Requirement |
| PWM frequency | f_sw | 48 kHz | Requirement |
| MOSFET | — | 40 V, PQFN 3.3×3.3 class | Fits 20×20 / 25.5×25.5 |
| R_DS(on) at 25 °C, V_GS = 10 V | R₂₅ | 1.1 mΩ | Typical class value |
| R_DS(on) temperature coefficient | k_T | 1.6× at T_j = 125
