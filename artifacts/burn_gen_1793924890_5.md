# STM32H743 Nano FC + 4-in-1 ESC: Power, Thermal, and BDShot Design Model

**Job #52, Principal Architecture Package, Rev A (Draft for Review)**

> **Read this first:**
> 1. **The ESC needs its own MCU.** An H743 flight controller does not commutate motors directly in any production ArduPilot design. The FC sends DShot600, and each ESC channel (or a shared ESC MCU) runs AM32 or BLHeli_32. The ESC firmware owns the 48 kHz PWM. The model below reflects this split.
> 2. **The component values are reference assumptions, not a qualified BOM.** They are representative values. Substitute your selected parts' datasheet values into the equations before sign-off.
> 3. **The headline result: "80A burst" is only achievable for about 2–4 s on a nano (~30×30 mm) board without a heatsink.** The math in §2.5 shows why. Specify the burst duration explicitly in the requirements.

## 1. System Architecture

```
 6S LiPo (25.2V max) ──┬── Bulk caps ── 4× 3-phase bridges (24 MOSFETs)
                       │                   ▲ gate drive
                       │              4× FD6288-class 3φ drivers
                       │                   ▲ 6× PWM @ 48 kHz
                       │              ESC MCU(s) (AT32F421 / STM32G071, AM32)
                       │                   ▲ DShot600 + BDShot eRPM telemetry
                       └── BEC ──► STM32H743 FC (ArduPilot, TIM-DMA BDShot)
```

## 2. Thermal and Loss Model

### 2.1 Assumptions

| Symbol | Meaning | Value (assumed) |
|---|---|---|
| V_bus | Bus voltage (6S full) | 25.2 V |
| I_ph | Burst phase current per channel | 80 A |
| R_ds,25 | MOSFET on-resistance at 25 °C (40 V, DFN3333-class) | 1.0 mΩ |
| α | R_ds temperature coefficient | 0.005 /K |
| T_j,max | Design junction limit (derated from 175 °C) | 150 °C |
| f_sw | Switching frequency | 48 kHz |
| t_r + t_f | Switching transition time at gate-driver drive strength | 20 ns |
| Q_rr | Body-diode reverse-recovery charge | 40 nC |
| Q_oss | Output charge | 30 nC |
| Q_g | Total gate charge at V_gs = 10 V | 50 nC |
| V_f | Body-diode forward voltage | 0.8 V |
| t_dt | Dead time | 100 ns |
| Commutation | 6-step, synchronous rectification | — |

### 2.2 Conduction Loss

Temperature-adjusted on-resistance:

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R_ds = 1.0 × (1 + 0.5) = **1.5 mΩ**.

In 6-step operation, the current path always passes through two conducting switches: one PWM leg (high side, or its synchronous low side) and one static low side. Per channel:

$$P_{cond} = 2\, I_{ph}^2\, R_{ds}(T_j) = 2 \times 80^2 \times 1.5\times10^{-3} = \mathbf{19.2\ W}$$

- The current rotates across 3 phases, so the average per FET is 19.2 / 6 ≈ **3.2 W**.
- The instantaneous per-FET loss while conducting is still **9.6 W**. This instantaneous value sets the junction-to-board temperature drop.

### 2.3 Switching Loss at 48 kHz (per channel, one hard-switched leg)

**Overlap (V–I crossover):**
$$P_{ov} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\text{n} \times 48\text{k} = 0.968\ \text{W}$$

**Reverse recovery:**
$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\text{n} \times 25.2 \times 48\text{k} = 0.048\ \text{W}$$

**Output capacitance:**
$$P_{oss} \approx \tfrac12 Q_{oss} V_{bus} f_{sw} = 0.018\ \text{W}$$

**Dead-time diode conduction (2 events per period):**
$$P_{dt} = 2 V_f I_{ph} t_{dt} f_{sw} = 2 \times 0.8 \times 80 \times 100\text{n} \times 48\text{k} = 0.614\ \text{W}$$

**Gate drive (6 FETs; this power is dissipated mainly in the driver and gate resistors):**
$$P_g = 6\, Q_g V_{gs} f_{sw} = 6 \times 50\text{n} \times 10 \times 48\text{k} = 0.144\ \text{W}$$

**Switching total per channel ≈ 1.79 W.**

Sensitivity: the overlap and dead-time terms scale linearly with f_sw. Moving to 24 kHz saves about 0.8 W per channel but raises current ripple and audible noise.

### 2.4 PCB Copper Loss

Sheet resistance is about 0.5 mΩ/□ for 1 oz copper and 0.25 mΩ/□ for 2 oz.

Assume a 6-layer, 2 oz stack with 4 layers paralleled for power and roughly 3 squares of effective path per channel (bus to switch node to pad):

$$R_{cu} \approx \frac{0.25\text{m}\times 3}{4} \times 1.4_{(hot)} \approx 0.26\ \text{m}\Omega$$
$$P_{cu} \approx 2 \times 80^2 \times 0.26\text{m} \approx 3.4\ \text{W/channel}$$

Copper loss is about 18% of FET conduction loss. It is significant at this current level, so do not ignore it.
