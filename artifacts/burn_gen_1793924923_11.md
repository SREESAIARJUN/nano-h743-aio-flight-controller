# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #32 specification, so this design uses typical gimbal values. Every value below is a parameter, so substitute your actual hardware.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class: FPU, center-aligned TIM1, ADC triggered at PWM midpoint |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), read every current-loop cycle |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, gyro/accel ODR 8 kHz |
| Loop rates | Current 20 kHz, velocity 4 kHz, angle 1 kHz, AHRS 1 kHz |
| Bus voltage | 12–16 V |
