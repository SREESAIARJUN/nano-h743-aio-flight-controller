## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH (phase), K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A), read every current-loop cycle |
| MCU | STM32G4/H7-class with FPU. Inline 3-shunt current sense. |
| IMUs | 2× ICM-42688-P on SPI, 8 kHz ODR, ±2000 dps, ±16 g. Both on the camera plate. |
| Bus | 12–16 V |

**Loop rates (cascade):**

```
 20 kHz  : FOC current loop (Clarke/Park, d/q PI, SVPWM), cogging feedforward added here
  4 kHz  : rate (velocity) loop, driven by fused/filtered gyro (2× decimated from 8 kHz)
  1 kHz  : angle loop, driven by attitude quaternion (Mahony) → joint-frame error
```

Each inner loop has a bandwidth roughly 4–10× higher than the loop outside it. Typical targets:

- Current: ω_c ≈ 2π·1.5 kHz
- Rate: ω_v ≈ 2π·80–150 Hz
- Angle: ω_θ ≈ 2π·15–30 Hz

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms
θ_e is the electrical angle: θ_e = p·θ_m − θ_offset.

**Clarke (power-variant, balanced, i_a + i_b + i_c = 0):**
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI tuning
The PMSM in the rotor frame is:
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

**Decoupling feedforward** makes each axis a first-order R-L plant G(s) = 1/(Ls+R):
$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m),\qquad \lambda_m = \tfrac{2K_t}{3p}$$

**PI tuning by pole-zero cancellation.** With C(s) = K_p + K_i/s, choose K_i/K_p = R/L. The closed loop then becomes ω_c/(s+ω_c):
$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

### 1.3 Voltage limiting and SVPWM
1. Limit the voltage vector to the linear SVPWM region: |v_dq| ≤ V_bus/√3.
2. Give v_d priority when saturating.
3. Apply inverse Park, then inverse Clarke.
4. Inject the min-max zero-sequence term (equivalent to SVPWM):

$$v_0 = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
