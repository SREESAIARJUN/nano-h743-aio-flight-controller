# STM32H743 Nano FC + 4-in-1 ESC (Job #43): Power-Stage, Thermal and DShot Architecture

## 0. Assumptions and Scope Flags

I don't have your Job #43 requirements document, so this design rests on the assumptions below. Substitute your real BOM values into the equations; every result is parametric.

| Parameter | Assumed value | Note |
|---|---|---|
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal | 40 V FET class required |
| Burst current | **80 A per channel** | See flag 1 |
| PWM frequency | 48 kHz, complementary (synchronous) PWM | |
| Commutation | Trapezoidal, 6-step (AM32/BLHeli_32-class firmware) | |
| Architecture | H743 = flight controller; each ESC channel has its own small MCU (e.g., STM32G071 / AT32F421) | See flag 2 |
| MOSFET (placeholder) | 40 V, R_DS(on) = 1.0 mΩ @ 25 °C / V_GS = 10 V, Q_g = 40 nC, Q_gd = 8 nC, Q_gs2 = 5 nC, Q_oss = 40 nC, Q_rr = 30 nC, R_g,int = 1 Ω, PQFN 3.3×3.3 | Replace with datasheet values |
| Gate drive | 10 V, R_drv = 2 Ω, R_g,ext = 2.2 Ω | |
| Board | 30.5×30.5 mm mounting, 8-layer, 2 oz copper | "Nano" class |

**Flag 1: 80 A per channel on a nano board is a burst rating, not a continuous one.** Four channels at 80 A means **320 A battery current** (about 7 kW). That exceeds XT60/XT90 connector ratings, typical pack C-ratings, and anything a 30×30 board can shed thermally. The math below shows the burst window is a few seconds. If "80 A" means total (20 A per channel), divide all conduction losses by 16.

**Flag 2:** The H743 does not commutate the motors. It issues DShot to four ESC MCUs. Running 4× sensorless commutation at 48 kHz on the H743 alongside ArduPilot is not supported by ArduPilot and is not recommended.
