## 0. System Assumptions

| Item | Assumption |
|---|---|
| Gimbal topology | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |
| Motors | Gimbal PMSM/BLDC, e.g. 12N14P (N_s = 12 slots, p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH **[VERIFY]** |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Driver | 3-phase bridge, center-aligned PWM at 20 kHz, two-shunt or inline current sensing |
| IMU A | ICM-42688-P on the camera plate. This is the feedback sensor. |
| IMU B | ICM-42688-P on the base/handle. This is the disturbance reference sensor. |
| MCU | Cortex-M7 / M4F with single-precision FPU (STM32H7/G4 class) |

**Loop rates and bandwidth separation.** Each loop's bandwidth should be at least 5× below the loop it commands.

| Loop | Rate T_s | Closed-loop bandwidth |
|---|---|---|
| Current (d/q) | 20 kHz (50 µs) | ω_c ≈ 2π·1500 rad/s |
| Velocity | 4 kHz (250 µs) | ω_v ≈ 2π·150 rad/s |
| Angle (attitude) | 1 kHz (1 ms) | ω_θ ≈ 2π·20 rad/s |
| IMU sampling | 8 kHz ODR (FIFO), decimated to 4 kHz and 1 kHz | — |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical model (rotor d-q frame)

$$
v_d = R\,i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R\,i_q + L_q\frac{di_q}{dt} + \omega_e L_d i_d + \omega_e\lambda_m
$$

$$
\tau_e = \tfrac{3}{2}\,p\,\big[\lambda_m i_q + (L_d-L_q)i_d i_q\big] \;\approx\; K_t\, i_q,\qquad K_t=\tfrac32 p\lambda_m
$$

Here θ_e = p·θ_m and ω_e = p·ω_m. Surface-mount gimbal motors have L_d ≈ L_q, so the reference is i_d* = 0.

### 1.2 Transforms

**Clarke** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}
$$

\begin{bmatrix}i_d\\ i_q\end{bmatrix}=
