## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Electrical angle

θₑ = wrap_{[0,2π)}( p · (θₘ − θ_off) )

θ_off is found at commissioning: align to the d-axis by applying V_d at θₑ = 0, then record θₘ.

### 1.2 Clarke and Park transforms (2 measured phases, i_a + i_b + i_c = 0)

- i_α = i_a
- i_β = (i_a + 2 i_b) / √3
- i_d = i_α cos θₑ + i_β sin θₑ
- i_q = −i_α sin θₑ + i_β cos θₑ

### 1.3 Motor model in the dq frame

- L di_d/dt = v_d − R i_d + ωₑ L i_q
- L di_q/dt = v_q − R i_q − ωₑ L i_d − ωₑ λ
- τ = (3/2) p λ i_q = Kₜ i_q

### 1.4 Current PI with decoupling feedforward

v_d = K_p (i_d* − i_d) + K_i ∫(i_d* − i_d) dt − ωₑ L i_q
v_q = K_p (i_q* − i_q) + K_i ∫(i_q* − i_q) dt + ωₑ (L i_d + λ)

Tuning by pole-zero cancellation of the R-L plant, which gives a closed loop of ω_c/(s + ω_c):

K_p = L ω_c,  K_i = R ω_c,  with ω_c = 2π f_c and f_c ≈ f_PWM / 10

### 1.5 Voltage limiting

The linear SVPWM limit is |v| ≤ V_max = V_dc / √3.

1. V_d gets priority: v_d ← clamp(v_d, ±V_max).
2. Then |v_q| ≤ √(V_max² − v_d²).
3. Anti-windup: integrator back-calculation with gain K_aw = 1/K_p.
