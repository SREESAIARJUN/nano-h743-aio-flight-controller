# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I have no specification for "Job #34", so the design below rests on stated assumptions. Each one is a named constant in the code, so you can change it in one place.

## 0. Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU, about 170 MHz or more |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.6 Ω (phase), L ≈ 2.4 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5047P) on each joint |
| Current sensing | 2-phase low-side shunts, sampled at the PWM center |
| Loop rates | Current 20 kHz; velocity 4 kHz; angle / attitude 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, placed symmetrically about the plate center |
| Bus voltage | 12 V |

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms (amplitude-invariant)

**Clarke transform**, assuming i_a + i_b + i_c = 0:

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform**, with electrical angle θ_e = p·(θ_m − θ_offset):

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park transform:**

- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Plant and decoupling

The d-q voltage equations are:

- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ
