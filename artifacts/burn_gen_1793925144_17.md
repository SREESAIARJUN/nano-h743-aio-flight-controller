### Feasibility Finding

**80 A continuous on all four channels is physically impossible on a nano board.** Section 3 shows that 80 A is only sustainable as a **time-limited burst of roughly 2 seconds** when all four motors are loaded simultaneously.

The deliverable must therefore specify an I²t (current-squared × time) envelope rather than a bare "80 A" number. The ESC firmware should enforce this envelope through current limiting, and the flight controller should enforce it through its battery and motor limits.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent On-Resistance

R_DS(T_j) = R₂₅ · [1 + α(T_j − 25)], with α ≈ 0.006 /K

At T_j = 125 °C: R_DS ≈ 1.6 mΩ.

Add the parasitic path resistance per conducting switch:

- Package/clip resistance R_pkg ≈ 0.1 mΩ
- PCB copper share R_cu ≈ 0.15 mΩ

This gives an effective resistance R_eff ≈ 1.85 mΩ at a hot junction.

### 1.2 Six-Step Commutation with Synchronous (Complementary) PWM

Commutation timing:

- At any instant, one leg is PWM-active, one leg is held low, and one leg floats (for BEMF sensing).
- Each leg is active for 2/3 of the electrical period.

For the active pair at duty cycle D:

**High-side FET:**
P_HS = I² · R_eff · D · (2/3) · ½ … averaged over its active window

**Synchronous low-side FET:**
P_LS = I² · R_eff · (1 − D) · …

Because complementary PWM always provides a current path, the per-channel total simplifies to:

**P_cond,ch = I_ph² · R_eff · 2**

This holds because exactly two switches carry I_ph at every instant: one high-side and one low-side. It is valid for any D when synchronous rectification is used, and ignores ripple.

Including the ripple correction, the RMS current is:

I_rms² = I_ph² + ΔI²/12

where the ripple ΔI = V_bus · D(1−D) / (L_ph · f_sw).

For a typical 5" to 7" motor (L_ph ≈ 15–30 µH, worst case D = 0.5):

ΔI ≈ 25.2 · 0.25 / (20 µH · 48 kHz) ≈ 6.6 A, so ΔI²/12 ≈ 3.6 A²

This is negligible against 6400 A².

### 1.3 Numbers at 80 A

| Quantity | Value |
|---|---|
| Per channel | P_cond,ch = 80² · 1.85 mΩ · 2 = **23.7 W** |
| Worst single FET (high-side at D → 1, active 2/3 of the time) | P_FET,max = 6400 · 1.85 mΩ · 2/3 = **7.9 W** |
| Board total (4 channels) | **94.7 W** |
