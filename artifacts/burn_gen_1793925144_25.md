## 0. Architecture Decision (Read First)

**The STM32H743 should not drive the power stage directly.** Production 4-in-1 ESCs use one dedicated ESC MCU per motor running AM32 or BLHeli_32-class firmware, for example the AT32F421 or STM32G071. That MCU handles commutation, BEMF sensing, and the 48 kHz PWM.

The H743 acts as the flight controller. It generates four bi-directional DShot600 lines and receives eRPM telemetry back. This keeps the H743 timer and DMA budget for flight control and avoids a single point of failure across all four motors.

```
 6S LiPo ──┬── TVS + bulk C ── 4× [ESC MCU → 3-ph gate driver → 6× N-FET] → M1..M4
           ├── 5V/10V bucks
           └── 3V3 LDO ── STM32H743 (FC) ──DShot600 bidir (×4)──► ESC MCUs
                                         ◄── eRPM (GCR, same wire)
```

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds25}\,[1 + \alpha (T_j - 25)]$$

At the design point T_j = 110 °C:

R_ds = 1.5 mΩ × (1 + 0.005 × 85) = **2.14 mΩ**

### 1.2 Six-step synchronous conduction

During any 60° commutation sector, two phases conduct:

- **PWM leg:** the high-side FET conducts for D·T_sw. The low-side FET synchronously rectifies for (1−D)·T_sw minus 2·t_dt.
- **Static leg:** the low-side FET is fully on.

The load current therefore always flows through two R_ds(on) in series. Duty cycle cancels to first order:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{ds}(T_j)\,\left(1 - 2t_{dt}f_{sw}\cdot\tfrac{1}{2}\right) \approx 2\,I_{ph}^2 R_{ds}(T_j)$$

The dead-time correction is −0.5 % and is neglected here; diode loss is booked separately in 2.4.

**Per channel:** 2 × 80² × 2.14 mΩ = **27.4 W**

**Per FET (average over an electrical cycle):** 27.4 / 6 = **4.57 W**
