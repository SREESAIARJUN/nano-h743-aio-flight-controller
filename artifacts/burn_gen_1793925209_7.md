# STM32H743 FC + 4-in-1 ESC (Nano Form Factor): 80A Burst Thermal, 48 kHz Switching, and Bi-directional DShot600 Design

## 0. Scope and Assumptions

I don't have the Job #57 BOM, stack-up, or datasheets. All numbers below come from a stated reference design. Every assumed parameter is listed in **§0.2** so you can substitute your real values. The equations are exact for the model. The numerical results are only as good as the inputs.

### 0.1 Architecture

```
 6S LiPo (25.2 V max / 22.2 V nom)
   │
   ├── 4-in-1 ESC board (20×20 mm "nano", 6-layer 2 oz)
   │     4× ESC MCU (AT32F421 / STM32G071, AM32 or BLHeli_32-class)
   │     4× 3-phase gate driver (FD6288Q-class)
   │     24× N-MOSFET 40 V (6 per motor, single FET per switch)
   │
   └── FC: STM32H743 (ArduPilot)
         4× DShot600 bidirectional (timer + DMA), ESC telemetry UART optional
```

The H743 does **not** commutate the motors. Each ESC MCU does that. The H743's role is the DShot command and eRPM capture path (§4).
