## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class, single-precision FPU, 3× ADC |
| Motor | 12N14P gimbal BLDC (GBM2804-class): p = 7 pole pairs, R = 10 Ω, L = 2.5 mH, λ = 0.015 Wb |
| Torque constant | K_t = 1.5·p·λ ≈ 0.1575 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6835) per axis |
| IMUs | 2× ICM-42688-P on the camera plate, mounted point-symmetric about the camera's rotation center, each on its own SPI bus |
| Chain | Yaw (base) → Roll → Pitch (camera) |

**Loop rates:**

```
TIM1 update (center-aligned PWM) 24 kHz ─► Current loop (FOC, PI d/q, SVPWM)        Ts_i = 41.7 µs
          ÷6                            ─► Velocity PI + encoder PLL + anti-cogging  Ts_v = 250 µs (4 kHz)
IMU DRDY (ODR 8 kHz, both chips)        ─► Notch/LPF chain, dual-IMU fusion
          ÷4                            ─► Attitude (Mahony) + angle loop + Jacobian  Ts_a = 500 µs (2 kHz)
```
