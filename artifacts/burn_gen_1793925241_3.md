# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the original Job #7 specification, so this design uses the assumptions below. Every parameter is a single constant in the code, so you can change any of them easily.

## 0. Assumptions and Loop Timing

| Item | Value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5 Ω, L = 2 mH, K_t = 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (MT6701/AS5048-class) on each motor shaft |
| IMUs | 2× ICM-42688-P, both rigidly mounted on the camera plate, SPI, ODR = 8 kHz, ±2000 dps, ±4 g |
| MCU | Cortex-M4F/M7 with single-precision FPU |

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (FOC) | 20 kHz (PWM center-aligned ISR) | ω_c ≈ 2π·1500 rad/s |
| Rate (velocity) | 4 kHz | ω_v ≈ 2π·120 rad/s |
| Attitude (angle) | 1 kHz | ω_a ≈ 2π·20 rad/s |
| IMU filtering and fusion | 8 kHz in, decimated to 4 kHz | — |

Each loop's bandwidth is roughly 5–10× below the loop inside it. This separation is what lets the cascade be tuned loop by loop.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

The electrical angle is θ_e = p·(θ_m − θ_offset).

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

  i_α = i_a
  i_β = (i_a + 2·i_b) / √3

**Park transform:**

  i_d = i_α·cos θ_e + i_β·sin θ_e
  i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park:**

  v_α = v_d·cos θ_e − v_q·sin θ_e
  v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Plant and PI Design (Pole-Zero Cancellation)

The dq-frame electrical model is:

  v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
  v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ_m

After decoupling feedforward, each axis behaves as G(s) = 1 / (L·s + R).

Choose the PI controller as C(s) = K_p + K_i/s, with:

- K_p = L·ω_c
- K_i = R·ω_c

The PI zero then cancels the plant pole, and the closed loop is first-order: i/i* = ω_c / (s + ω_c).

### 1.3 Discrete PI with Back-Calculation Anti-Windup

With sample time T_s, error e_k = r_k − y_k, and saturated output u_k:

  u_k^unsat = K_p·e_k + I_k + u_ff
  u_k = sat(u_k^unsat)
  I_{k+1} = I_k + K_i·T_s·e_k + K_b·T_s·(u_k − u_k^unsat)

A good default for the back-calculation gain is K_b = K_i / K_p (equal to 1/T_i).

### 1.4 Voltage Limit and SVPWM

The dq voltage vector is limited to a circle:

  |v_dq| ≤ V_bus / √3

Priority goes to v_d; v_q receives the remaining headroom: v_q,max = √(V_max² − v_d²).

Space-vector modulation is implemented as min-max zero-sequence injection:

1. Compute the phase voltages:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
2. Compute the offset: v_0 = −(max(v_a, v_b, v_c) + min(v_a, v_b, v_c)) / 2
3. Compute each duty cycle: d_x = ½ + (v_x + v_0) / V_bus
