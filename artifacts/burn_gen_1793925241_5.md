# Job #44: 3-Axis Gimbal FOC Control and Dual-IMU Fusion Design

The brief gives no hardware details, so this design assumes the configuration below. Every equation is parameterised, so you only need to change the constants in `GimbalConfig` to match your hardware.

| Item | Assumption |
|---|---|
| MCU | STM32G474 (Cortex-M4F, single-precision FPU, 170 MHz) |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoders | 14-bit magnetic (MT6701 / AS5048A) over SPI, one per axis |
| IMUs | 2× ICM-42688-P, both rigidly mounted on the **camera plate**. IMU B is rotated 180° about z relative to IMU A. |
| Kinematics | Yaw (base) → Roll → Pitch (camera) |
| Loop rates | Current 20 kHz · Rate (IMU gyro) 4 kHz · Attitude 1 kHz · IMU ODR 8 kHz |

## 1. Control Architecture

```
            ┌──────── 1 kHz ────────┐   ┌────────── 4 kHz ──────────┐   ┌──── 20 kHz ────┐
 q_ref ──►  │ Attitude P (SO(3))    │──►│ Rate PID (camera frame)   │──►│ J^T  → τ_joint │
 ω_ff  ──►  │  e_R = Log(q_ref*⊗q)  │   │ ω_cmd − ω_gyro_fused      │   │ /Kt → i_q*     │
            └───────────▲───────────┘   └────────────▲──────────────┘   │ + i_q,cog(θ_e) │
                        │ q̂ (Mahony)                 │ ω̂ (filtered)     │ PI d/q + SVPWM │
                ┌───────┴────────────────────────────┴────────┐         └───────▲────────┘
                │ Dual ICM-42688-P: align → fuse → ANF → LPF  │      encoder θ_m ┘ (Park, cogging LUT)
                └─────────────────────────────────────────────┘
```

**Why the rate loop closes on the camera gyro rather than on the encoders.** Base disturbances (handheld motion, vehicle vibration) appear directly in the gyro signal. The loop therefore rejects them at the full rate-loop bandwidth, instead of waiting for the attitude loop. The encoders are still used for three things:
- commutation (θ_e),
- the cogging feedforward, which is indexed by θ_m,
- the joint Jacobian.

## 2. FOC Current Loop (20 kHz)

### 2.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

θ_{m,0} is the encoder offset. It is found at calibration by holding the motor at u_d > 0, u_q = 0 so the rotor aligns to θ_e = 0.

### 2.2 Clarke and Park transforms (amplitude-invariant)
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\qquad(i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$
