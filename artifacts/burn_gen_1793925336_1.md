## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform (power-invariant amplitude form, with i_a + i_b + i_c = 0):**

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform (electrical angle θ_e = p·θ_m − θ_offset):**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform uses the transposed matrix.

### 1.2 Plant and PI Design

The PMSM dq model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

After cross-coupling and back-EMF decoupling, each axis reduces to the plant G(s) = 1/(Ls + R).

Choose the PI controller C(s) = K_p + K_i/s with zero-pole cancellation (K_i/K_p = R/L). The closed loop then becomes first order with bandwidth ω_c:

$$\boxed{K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c}$$

Bandwidth selection:
- Use ω_c ≤ 2π·f_pwm/20 ≈ 2π·1 kHz. This keeps phase loss from the 1.5-sample delay (computation plus PWM hold) under about 30°.

### 1.3 Feedforward Decoupling

$$v_d^{*} = \text{PI}_d(e_d) - \hat\omega_e \hat L\, i_q,\qquad v_q^{*} = \text{PI}_q(e_q) + \hat\omega_e \hat L\, i_d + \hat\omega_e\hat\lambda_m$$

### 1.4 Angle Delay Compensation

The voltage is applied about 1.5·T_s after sampling. The inverse Park transform therefore uses:

$$\theta_e^{\text{inv}} = \theta_e + 1.5\,\omega_e T_s$$

### 1.5 Voltage Limiting and Anti-Windup

The circular limit is |v_dq| ≤ V_dc/√3. The d-axis has priority:

$$v_d^{sat} = \text{clamp}(v_d^*, \pm V_{max}),\qquad v_q^{sat} = \text{clamp}\!\left(v_q^*,\ \pm\sqrt{V_{max}^2 - (v_d^{sat})^2}\right)$$

Back-calculation anti-windup:

$$\dot x_I = K_i e + K_{aw}(v^{sat} - v^*),\qquad K_{aw} = K_i/K_p$$

### 1.6 SVPWM via Min-Max Zero-Sequence Injection

This is equivalent to classical SVPWM.

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\qquad v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

## 2. Cascaded Angle → Velocity → Current Control

```
θ*  ─►(+)─► P/PD (angle) ─► ω* ─►(+)─► PI (velocity) ─► τ* ─► ÷K_t ─► i_q* ─► FOC
       ▲ −        ▲ ω_ff=θ̇*        ▲ −                  ▲ + i_cog_ff, + friction ff
     θ̂ (fused attitude → joint)    ω̂ (fused gyro → joint axis)
```

### 2.1 Feedback Signals

**Attitude.** Use the fused camera quaternion q̂ (Section 4). Compute the error quaternion:

$$q_e = q^{*}\otimes \hat q^{-1}$$

Take the shortest path: if q_{e,w} < 0, negate q_e. The small-angle error vector in the camera frame is:

$$e_\theta = 2\,\text{sgn}(q_{e,w})\,\vec q_e$$

Map it to the motor (joint) axes through the gimbal Jacobian. For a yaw-roll-pitch gimbal at joint angles (ψ, φ, θ), the camera angular velocity is ω_c = J(φ,θ)·q̇. Therefore:

$$e_{joint} = J^{-1}(\varphi,\theta)\, e_\theta$$

Then clamp the result near gimbal lock, where det J → 0. (The code below uses the diagonal-dominant approximation J ≈ I, which is valid for |tilt| < ~30°. Replace `jointFromCamera()` with the full inverse for your kinematics.)
