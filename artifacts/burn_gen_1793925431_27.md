# STM32H743 AIO Flight Controller with 4-in-1 80A ESC: System Architecture & Mathematical Model (Job #18)

This is an engineering-grade model built on stated assumptions. Every numeric result traces to a parameter table, so you can substitute your actual BOM values. Two findings change the design brief and come first.

## 0. Architecture Corrections

**1. The H743 does not commutate the motors.** In any ArduPilot-compatible 4-in-1 design, the STM32H743 runs ArduPilot and emits bi-directional DShot600. Each ESC channel has its own commutation MCU (e.g., AT32F421 or STM32G071 running AM32 or BLHeli_32), which generates the 48 kHz PWM. The netlist below reflects this split.

**2. "80A burst" on a nano (20×20 / 25.5 mm mount) board is a time-limited rating.** The thermal model in §3 shows:
- About 28 W dissipation per channel at 80 A.
- Roughly 1.5 to 2.5 s to reach Tj = 150 °C if all four channels burst simultaneously.

So 80 A must be specified as a duty-cycled burst rating, with a defined window.

## 2. Loss Model (Per ESC Channel, Six-Step, Synchronous Rectification)

In any 60° commutation sector:
- One phase is PWM-switched: HS on for duty D, complementary LS on for (1−D).
- One phase has its LS fully on.
- The current I flows through both legs.

### 2.1 Conduction Loss

```
R_hot  = k_T · R_ds,25 = 1.5 × 1.2 mΩ = 1.8 mΩ

PWM leg:   I²R_hot·D + I²R_hot·(1−D) = I²R_hot   (duty-independent with sync rect.)
Static LS: I²R_hot

P_cond = 2·I²·(R_hot + R_pcb)
       = 2 × 6400 × (1.8 + 0.2) mΩ
       = 25.6 W
```

Split: MOSFET 23.0 W, copper 2.56 W.

Instantaneous dissipation in a single conducting FET is 6400 × 1.8 mΩ = 11.5 W. Averaged over the electrical cycle, each of the 6 FETs carries about 1/6 of the total.

### 2.2 Switching Loss at 48 kHz (Hard-Switched HS Edges)

Gate currents during the plateau:

```
I_g,on  = (V_drv − V_pl)/(R_src + R_g,ext + R_g,int) = 7 / 9.2 Ω = 0.76 A
I_g,off = V_pl/(R_snk + R_g,ext + R_g,int)           = 3 / 6.2 Ω = 0.48 A
```

Transition times:

```
t_on  = (Q_gs2 + Q_gd)/I_g,on  = 12 nC / 0.76 A = 15.8 ns
t_off = (Q_gs2 + Q_gd)/I_g,off = 12 nC / 0.48 A = 24.8 ns
```

Loss terms:

| Term | Formula | Result |
|---|---|---|
| V–I overlap | ½·V·I·(t_on + t_off)·f_sw = ½·25.2·80·40.6 ns·48 kHz | 1.96 W |
| Coss | ½·Q_oss·V·f_sw | 0.02 W |
| Reverse recovery | Q_rr·V·f_sw | 0.05 W |
| Dead-time diode | V_f·I·2·t_dt·f_sw = 0.8·80·200 ns·48 kHz | 0.61 W |
| Gate drive (in driver) | 2·Q_g·V
