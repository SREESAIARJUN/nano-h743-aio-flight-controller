# STM32H743 Nano FC + 4-in-1 ESC: Power-Stage Loss Model, Thermal Analysis, and Bi-Directional DShot600 Timer/DMA Plan

## 0. Scope, Assumptions, and Three Early Findings

I don't have the Job #26 requirements document. Every number below comes from the stated assumptions. Each assumption is a named parameter, so you can substitute datasheet values and recompute.

**Finding 1: architecture.** The STM32H743 is the flight controller MCU. It does not drive the bridges. A 4-in-1 ESC needs four ESC MCUs (for example AT32F421 or STM32G071 running AM32 or BLHeli_32) that run commutation at 48 kHz. The H743 talks to them over bi-directional DShot600. This document assumes that architecture, either stacked or on a single PCB.

**Finding 2: burst duration.** On a 30×30 mm nano board, "80 A burst per motor" is transient-limited and lasts only a few seconds (Section 3). Continuous capability is roughly 25–35 A per motor, depending on airflow. The burst rating must be specified with a duration (for example "80 A / 2 s"). Without one it is not a meaningful number.

**Finding 3: the netlist is a reference topology, not a signed-off design.** It shows the connections. Part selection, footprints, and pinout need ERC/DRC and datasheet verification before layout release.

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step commutation with complementary PWM, phase A is the PWM leg and phase B is held low:

- **On-time (D):** HS_A → motor → LS_B
- **Off-time (1−D):** LS_A (synchronous freewheel) → motor → LS_B

Exactly two FETs carry I_ph at all times, independent of duty cycle:

$$P_{cond} = I_{ph}^2\left[2\,R_{ds(on)}(T_j) + R_{pcb}\right]$$

$$R_{ds(on)}(T_j) = R_{ds(on),25}\left[1 + \alpha\,(T_j - 25)\right],\qquad \alpha \approx 0.006\ \text{K}^{-1}\ \Rightarrow\ k_T \approx 1.6\ \text{at } 125\,^\circ\text{C}$$

### 1.2 Numbers at 80 A, T_j = 125 °C

$$R_{ds,hot} = 0.9 \times 1.6 = 1.44\ \text{m}\Omega$$

$$P_{FET,cond} = 80^2 \times 2 \times 1.44\times10^{-3} = 18.4\ \text{W}$$

$$P_{pcb} = 80^2 \times 0.5\times10^{-3} = 3.2\ \text{W}$$

### 1.3 Ripple correction

Phase-current ripple adds to the RMS current:

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12},\qquad \Delta I = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

For a typical L_ph of 10–20 µH at 48 kHz, ΔI is a few amps. The correction is below 0.5 % at 80 A and can be ignored at this operating point.

### 1.4 Thermal runaway check

Because R_ds(on) rises with T_j, loss and temperature feed each other. Solve the fixed point:

$$T_j = T_{ref} + R_{th}\, I^2\, R_{25}\,[1+\alpha(T_j-25)]$$

A stable solution requires:

$$R_{th}\, I^2\, R_{25}\,\alpha < 1$$

Check this per FET with your own R_th (Section 3).

## 2. Switching and Ancillary Losses at 48 kHz

Only the PWM leg (HS_A and LS_A) switches. LS_B is static during the sector.

| Mechanism | Equation | Value |
|---|---|---|
| V–I overlap | ½·V_bus·I_ph·(t_r+t_f)·f_sw, with t_r ≈ t_f ≈ Q_sw/I_g = 10 ns | 0.5×25.2×80×20 ns×48 kHz = **0.97 W** |
| Reverse recovery | Q_rr·V_bus·f_sw | 50 nC×25.2×48k = **0.06 W** |
| C_oss | ½·Q_oss·V_bus·f_sw (approx.) | **0.02 W** |
| Dead-time diode conduction | V_f·I_ph·2t_dt·f_sw | 0.8×80×400 ns×48k = **1.23 W** |
| Gate drive (2 switching FETs) | 2·Q_g·V_gs·f_sw (dissipated in driver and R_g, not the FET) | **0.04 W** |

### Observations

1. **Dead-time loss is larger than overlap loss.** At 80 A it is the dominant switching-frequency-dependent term.
   - Cutting t_dt from 200 ns to 100 ns saves about 0.6 W per motor.
   - This only works if the gate driver and FET Q_gd allow it without shoot-through. Validate on the bench with a current probe on the DC link.
2. **Overlap loss scales linearly with I_g.** A weak driver doubles it. FD6288-class drivers source about 1.5 A and sink about 1.8 A. Use R_g of about 2–4.7 Ω and check ringing at turn-off.
