# STM32H743 AIO Nano FC with 80 A Burst 4-in-1 ESC: System Architecture Model

## 0. Scope, Assumptions, and Architecture Corrections

No prior "Job #10" specification exists in this conversation, so I have stated every assumption explicitly. Each one is a parameter you can replace with datasheet values.

**Architecture correction.** The STM32H743 is the flight controller. It does not commutate the motors. Each ESC channel needs its own commutation MCU (for example AT32F421 or STM32G071 running AM32/BLHeli_32), or one MCU per channel pair. The H743 running ArduPilot sends bidirectional DShot600 to those MCUs and receives eRPM telemetry back. Everything below follows that split.
