# STM32H743 AIO Flight Controller + 4-in-1 ESC: System Architecture Model (Job #61)

## 0. Scope and Assumptions

Every number below follows from the assumption table. Replace the MOSFET and board parameters with your actual BOM values and re-run the equations. The structure of the derivation does not change.

**Architectural clarification.** The STM32H743 runs ArduPilot as the flight controller. It does not commutate the motors. Each ESC channel has its own small MCU running AM32 or BLHeli_32-class firmware, for example an AT32F421 or STM32G071. The H743 talks to those MCUs over bidirectional DShot600 on internal traces. No production firmware does sensorless 4×3-phase commutation from the H743 while also running ArduPilot.

## 1. Conduction Loss Model

### 1.1 Six-step synchronous PWM topology

In each 60° commutation sector of trapezoidal control:

- **Phase A (PWM leg):** high-side on for D·T_sw, low-side on for (1−D)·T_sw (synchronous rectification).
- **Phase B (return leg):** low-side continuously on.
- **Phase C:** floating. This is where BEMF zero-cross is sensed.

At every instant, exactly two MOSFETs carry I_ph. If ripple is neglected, conduction loss is therefore independent of duty cycle:

$$P_{cond,ESC} = 2\,I_{ph}^2\,R_{ds}(T_j)$$

Temperature dependence of on-resistance:

$$R_{ds}(T_j) = R_{ds25}\,[1+\alpha\,(T_j-25)]$$

### 1.2 Ripple correction

With phase inductance L_ph, the peak-to-peak current ripple is:

$$\Delta I = \frac{(V_{bus}-2E_{bemf})\,D}{2L_{ph}\,f_{sw}}$$

The RMS current then becomes:

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12}$$

At 48 kHz with typical 5" to 7" motors (L_ph ≈ 10–30 µH), ΔI/I_ph is below 15%. That adds less than 0.2% loss, so it is neglected below.
