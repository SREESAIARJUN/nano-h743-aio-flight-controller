## 0. Architecture Clarification and Assumptions

**Architecture.** On a 4-in-1 ESC, the **STM32H743 does not generate the 48 kHz motor PWM**. The partitioning is:

| Domain | Device | Function |
|---|---|---|
| Flight controller | STM32H743VIT6 @ 400 MHz (ArduPilot) | Generates DShot600 frames and decodes bidirectional eRPM telemetry |
| ESC (×4) | AT32F421K8U7 (or EFM8BB51 / STM32G071), running AM32 or BLHeli_32 | 48 kHz complementary PWM, commutation, BEMF sensing |
| Gate drive (×4) | FD6288Q 3-phase half-bridge driver | Bootstrap high-side, 10–12 V gate drive |
| Power stage (×4) | 6 × N-MOSFET, 40 V | 3-phase bridge |

This split matters because DShot DMA timing and switching losses live on different silicon. The calculations below keep them separate.

**Operating point:**
- Battery: 6S, V_bus = 25.2 V (full charge, worst case for switching loss).
- Burst: 80 A DC-equivalent phase current per ESC channel, all 4 channels simultaneously (worst case).
- Modulation: synchronous (complementary) PWM, 6-step trapezoidal, f_sw = 48 kHz.
- Dead time: t_dt = 100 ns per edge.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha\,(T_j - 25)]$$

At the design point T_j = 100 °C:

$$R_{DS}(100) = 1.5\ \text{m}\Omega \times (1 + 0.005 \times 75) = 2.06\ \text{m}\Omega$$

### 1.2 Current path in 6-step synchronous PWM

During any 60° commutation sector, two phases are active:
- **PWM leg:** the high-side FET conducts for D·T_sw. The synchronous low-side FET conducts for (1−D)·T_sw.
- **Return leg:** the low-side FET conducts continuously for the full sector.

The current therefore always flows through exactly **two FET channels in series**. Ignoring dead time, conduction loss is independent of duty cycle:

$$P_{cond,ch} = I_{rms}^2 \cdot 2R_{DS}(T_j)$$

**Ripple correction.** Phase inductance L_ph is typically 10–30 µH for 2207-class motors. Peak-to-peak ripple is:

$$\Delta I_{pp} = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

The RMS value including ripple is:

$$I_{rms} = \sqrt{I_{dc}^2 + \frac{\Delta I_{pp}^2}{12}}$$
