# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #42 specification, so the design below is fully parameterized. **Section 0 lists every assumption.** Replace those values with your hardware's numbers before tuning.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder (e.g. MT6701/AS5048) on each axis |
| MCU | Cortex-M4F/M7 with FPU (e.g. STM32G474), center-aligned PWM |
| IMUs | 2× ICM-42688-P on the camera payload, SPI, ODR 8 kHz (gyro and accel) |

**Loop rates:**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | 1.5–2 kHz |
| Velocity | 5 kHz (current ÷ 4) | ~150–250 Hz |
| Angle | 1 kHz (current ÷ 20) | ~20–40 Hz |
| IMU filtering | 8 kHz | — |
| Attitude fusion | 1 kHz | — |

**Signal flow:**

```
          IMU attitude (1 kHz)
                 │
θ_ref ─► [Angle PI+FF] ─ω_ref─► [Velocity PI] ─i_q,ref─►(+)─► [Current PI d/q] ─► SVPWM ─► Motor
            ▲                      ▲                     ▲
            θ̂ (fused)            ω̂ (encoder PLL     i_q,cog(θ_m)
                                  + gyro blend)     anti-cogging FF
```

**Bandwidth separation rule:** each outer loop should be at least 5× slower than the loop inside it:

ω_c,θ ≤ ω_c,ω / 5 ≤ ω_c,i / 25.

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (assumes i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2 i_b) / √3

**Park transform**, with θ_e = p·θ_m − θ_offset:

- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

**Inverse Park:**

- v_α = v_d cos θ_e − v_q sin θ_e
- v_β = v_d sin θ_e + v_q cos θ_e

### 1.2 Plant and decoupling

PMSM model in the rotating frame:

- v_d = R i_d + L di_d/dt − ω_e L i_q
- v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ

The current controllers output the decoupled voltages, and the cross-coupling terms are cancelled by feedforward:

- v_d* = PI_d(i_d* − i_d) − ω_e L̂ i_q
- v_q* = PI_q(i_q* − i_q) + ω_e (L̂ i_d + λ̂)

After decoupling, each axis reduces to the first-order plant 1 / (Ls + R).

### 1.3 Gain design by pole-zero cancellation

Choose the PI zero to cancel the electrical pole:

- K_p = L ω_ci
- K_i = R ω_ci

The closed loop then becomes ω_ci / (s + ω_ci). Here ω_ci = 2π f_ci, with f_ci ≈ f_PWM / 10.

Discrete form (backward Euler, sample time T_s):

- u[k] = K_p e[k] + I[k]
- I[k+1] = I[k] + K_i T_s e[k] + K_aw T_s (sat(u[k]) − u[k])

The last term is back-calculation anti-windup. A good default is K_aw = K_i / K_p, i.e. 1/τ_i.

### 1.4 Voltage limit and SVPWM

**Voltage limit (circular, d-axis priority):**

- |v_d| ≤ V_max
- |v_q| ≤ √(V_max² − v_d²)
- V_max = V_bus / √3
