# 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion: Design and C++ Implementation

I don't have the Job #25 spec sheet, so the design is parameterized. Everything numeric below is an **assumed reference configuration** that you should replace with your values:

| Item | Assumed value |
|---|---|
| MCU | STM32G474 class (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | 3× gimbal BLDC (GBM2804 class): 12N14P, so p = 7 pole pairs, R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic (MT6701 / AS5048A), one per joint |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, gyro ODR 8 kHz, ±2000 dps |
| Loop rates | Current/FOC 20 kHz → rate (velocity) 4 kHz → attitude (angle) 1 kHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |
