# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #53)

## 0. Design Assumptions

I don't have the Job #53 spec sheet, so this design uses typical values for a camera gimbal. Every value is a named constant in the code. Replace them with your measured values before tuning.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz), center-aligned PWM at 20 kHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs `p = 7`, slots `Ns = 12`), R = 5.6 Ω, L = 2.1 mH, Kt = 0.065 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (MT6701/AS5048A) on each joint, used for commutation and anti-cogging |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, gyro/accel ODR 8 kHz, FIFO-less data-ready interrupt |
| Inertia | Pitch J ≈ 2.5e-4 kg·m², Roll 4e-4, Yaw 8e-4 (camera + payload reflected) |

**Loop rates**

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ~1.5 kHz |
| Velocity (gyro feedback) | 4 kHz | 250 µs | ~120 Hz |
| Angle (attitude feedback) | 1 kHz | 1 ms | ~20 Hz |
| IMU fusion | 8 kHz in, 4 kHz out | | |

**Bandwidth separation rule:** each loop's bandwidth should be no more than about 1/5 to 1/10 of the next inner loop's bandwidth. The assumed ratios satisfy this: 1500/120 ≈ 12 and 120/20 = 6.

**Gimbal-specific architecture.** Stabilization is closed on the camera's inertial attitude and rate, which come from the IMUs:

- The angle loop uses the fused attitude.
- The velocity loop uses fused gyro rate mapped into joint space.
- The joint encoders are used only for commutation, the cogging lookup, and the kinematic Jacobian.

Joint-space rate is never estimated by differentiating the encoder. Encoder differentiation adds quantization noise, and it measures joint rate rather than camera inertial rate.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and decoupling

SPM motor equations (Ld = Lq = L):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

with $\lambda_m = \tfrac{2}{3}\,K_t/p$ (amplitude-invariant).

The controller adds a feedforward term that cancels the cross-coupling and back-EMF:

$$v_d^{*} = u_d - \omega_e L i_q,\qquad v_q^{*} = u_q + \omega_e L i_d + \omega_e\lambda_m$$

After this cancellation each axis is a first-order plant:

$$G_i(s)=\frac{1}{Ls+R}$$

### 1.3 PI design by pole-zero cancellation

Set the PI zero on the plant pole:

$$K_p^{i} = L\,\omega_{ci},\qquad K_i^{i} = R\,\omega_{ci}$$

The closed loop then becomes $\omega_{ci}/(s+\omega_{ci})$.

With $\omega_{ci}=2\pi\cdot1500$:
- $K_p = 19.8$ V/A
- $K_i = 52{,}779$ V/(A·s)

**Delay check.** Total delay is $T_d \approx 1.5T_s$ (computation plus PWM). The resulting phase margin is

$$PM = 90^\circ - \omega_{ci}T_d\cdot\frac{180}{\pi} = 90 - 27 = 63^\circ \quad\checkmark$$

### 1.4 Discrete PI with back-calculation anti-windup (Tustin)

$$u_k = K_p e_k + I_k,\qquad \tilde u_k = \mathrm{sat}(u_k)$$

$$I_{k+1} = I_k + K_i\frac{T_s}{2}(e_k+e_{k-1}) + K_{aw}T_s(\tilde u_k - u_k),\qquad K_{aw}=\frac{K_i}{K_p}$$
