# STM32H743 FC + 4-in-1 80A ESC (Job #38): System Architecture, Loss Model, DShot DMA Plan, Netlist

## 0. Scope and Assumptions

No component-level BOM was supplied for Job #38. Every number below follows from the stated assumptions. Re-run the equations once real MOSFET datasheet values are fixed, and treat this as design-intent, not a released design.

**Architecture clarification:** The STM32H743 does not generate the 48 kHz motor PWM. In a 4-in-1 stack, each motor channel has its own ESC MCU running AM32 or BLHeli_32, typically an AT32F421 or STM32G071. That MCU runs the 48 kHz commutation. The H743 sends bi-directional DShot600 commands and receives eRPM telemetry. Switching losses are therefore a property of the ESC board. The DMA problem is a property of the FC.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R_DS = 1.0 × 1.5 = **1.5 mΩ**.

### 1.2 Six-step current path

During each 60° sector, the phase current I flows through two legs:

- **PWM leg:** the high-side conducts for D·T_s. The low-side (synchronous rectifier) conducts for (1−D)·T_s.
- **Return leg:** the low-side is on 100% of the time.

Summing over both legs:

$$P_{cond,motor} = I^2 R_{DS}\,[D + (1-D) + 1] = 2I^2R_{DS}$$

This is independent of duty cycle when dead time is neglected.

$$P_{cond,motor} = 2(80)^2(1.5\times10^{-3}) = \mathbf{19.2\ W}$$

Each of the 6 FETs is active for 1/3 of the electrical period, so the average per FET is:

$$P_{cond,FET} = \frac{I^2R_{DS}}{3} = \mathbf{3.2\ W}$$

### 1.3 Copper and interconnect losses (do not ignore at 80 A)

**Phase trace:** 2 oz copper, 4 parallel layers, 3 mm wide, 15 mm long.

$$R = \frac{\rho L}{wt\,n} = \frac{1.72\times10^{-8}\cdot0.015}{0.003\cdot70\times10^{-6}\cdot4}\approx 0.31\ \text{mΩ}$$

This gives P ≈ 80² × 0.31 mΩ ≈ **2.0 W per phase path**, increasing about 0.4%/K.

**Solder pads, motor wire pads, and the current shunt** add about 1–2 W per motor. If a 0.25 mΩ shunt sits in the DC return, it carries I_DC ≈ D·I:

$$P_{shunt} = (D\,I)^2 R_{sh} \approx 1.6\ \text{W at } D = 1$$

## 2. Switching Losses at 48 kHz

Only the high-side FET in the PWM leg hard-switches. Its complementary low-side FET commutates via the body diode.

### 2.1 V–I overlap

$$P_{sw} = \tfrac12 V_{DC}\,I\,(t_r+t_f)\,f_{sw} = \tfrac12(25.2)(80)(40\text{ns})(48\text{k}) = \mathbf{1.94\ W}$$

### 2.2 Reverse recovery

$$P_{rr} = V_{DC}\,Q_{rr}\,f_{sw} = 25.2 \times 50\text{n} \times 48\text{k} = 0.06\ \text{W}$$

### 2.3 Output capacitance

$$P_{oss} = \tfrac12 Q_{oss}V_{DC}f_{sw} = 0.036\ \text{W}$$
