## 0. Architecture Decisions Before the Math

Several requirements in the brief conflict with physics or with how ArduPilot works. Each is resolved here so the rest of the document is internally consistent.

| Issue | Resolution |
|---|---|
| **ArduPilot does not commutate motors.** It outputs DShot to ESCs. | The STM32H743 runs ArduPilot as the flight controller (FC). The 4-in-1 ESC uses **4 dedicated ESC MCUs running AM32** (STM32G071 or AT32F421), one per motor. The H743 does not drive the FETs. |
| **"80A" on a nano board.** | Treated as an **80A per-motor, time-limited burst**. Section 3 shows continuous 80A is thermally impossible on 20×20 or 30.5×30.5 mm. The burst duration is a *derived output*, not an assumption. |
| **48 kHz** | This is the ESC PWM frequency (AM32 `PWM_FREQ`), unrelated to DShot rate. |
| **Bidirectional DShot600** | Uses H743 timers with DMA on both the update path (output) and the capture path (eRPM telemetry input). |

## 1. Conduction Loss Model (80A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)],\qquad \alpha\approx 0.006\,/\mathrm{K}\ \Rightarrow\ k_T(125^\circ C)\approx1.6$$

$$R_{DS}(125^\circ C) = 1.2 \times 1.6 = 1.92\ \text{m}\Omega$$

### 1.2 Current path

The ESC uses six-step trapezoidal commutation with synchronous rectification (AM32 complementary PWM):

- At any instant, current flows through **two FET positions in series**: the high-side of phase A and the low-side of phase B.
- During PWM off-time, the complementary FET of the switching leg takes over.
- So the path always contains exactly **2 × R_DS** in series.

$$P_{cond,motor} = I_{RMS}^2 \cdot 2R_{DS}(T_j) \;+\; I_{ripple,RMS}^2\cdot 2R_{DS}$$

**Ripple term.** For a motor with L_phase ≈ 15 µH at 48 kHz, ΔI_pp ≈ (V/2)/(L·f) ≈ 17 A. Then

$$I_{ripple,RMS} = \frac{\Delta I}{\sqrt{12}} \approx 5\ \text{A}$$

This adds +0.4% to I², which is negligible.

$$P_{cond,motor} = 80^2 \times 2 \times 1.92\,\text{m}\Omega = 6400 \times 3.84\,\text{m}\Omega = \mathbf{24.6\ W}$$
