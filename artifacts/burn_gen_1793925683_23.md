# STM32H743 Flight Controller + 4-in-1 ESC (Job #37): System Design Package

## Scope and Assumptions

### Architecture

The STM32H743 runs ArduPilot. It does not drive the power stage directly. It sends **bi-directional DShot600** to four ESC MCUs (AT32F421 or STM32G071 running AM32), which perform 48 kHz commutation through FD6288Q-class 3-phase gate drivers.

Every number below follows from the parameter table. **Replace each value with your selected MOSFET's datasheet value and re-run the equations.** The structure stays the same; the numbers will shift.

### Base Assumptions

| Symbol | Meaning | Value |
|---|---|---|
| V_bus | 6S, fully charged | 25.2 V |
| I_pk | Burst **phase** current, per channel | 80 A |
| f_sw | PWM frequency (AM32 "48 kHz") | 48 kHz |
| R_ds(on),25 | Per MOSFET, at V_gs = 10 V | 1.0 mΩ |
| α | R_ds(on) temperature coefficient | 0.0065 /K |
| Q_g / Q_gs2 / Q_gd | Gate charges | 50 / 5 / 10 nC |
| Q_rr / Q_oss | Body-diode and output charges | 50 / 60 nC |
| V_plateau / V_drv | Miller plateau / gate drive voltage | 3.5 V / 10 V |
| R_g,tot | Driver + external + internal gate resistance | 4 Ω |
| t_dt | Dead time | 100 ns |
| V_f | Body-diode forward voltage | 0.8 V |
