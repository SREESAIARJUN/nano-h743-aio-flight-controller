# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion (Job #46)

I don't have the Job #46 spec sheet, so I've built the design on the assumptions below. Every derived gain is written as a closed-form function of these parameters. If your hardware differs, change the `constexpr` block and the controller re-tunes itself.

## 0. Design Assumptions

| Item | Value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, single-precision FPU, CORDIC) |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A) on each axis |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted diametrically opposite about the CoM-proximal point (r₂ = −r₁) |
| PWM / current loop | 20 kHz center-aligned, current sampled at the PWM valley |
| Velocity loop | 4 kHz (every 5th PWM period) |
| Attitude/angle loop | 1 kHz |
| IMU ODR | 8 kHz gyro + accel, FIFO-burst read by DMA |

**Bandwidth plan.** Each loop is roughly 1/5 to 1/10 the bandwidth of the loop inside it, so the inner loops look like unity gain to the outer ones:

- Current loop: ω_c = 2π·1500 rad/s
- Velocity loop: ω_v = 2π·150 rad/s
- Angle loop: ω_θ = 2π·30 rad/s

## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park transform:**

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 1.2 Plant Model (Surface PMSM, L_d = L_q = L)

$$
\begin{aligned}
v_d &= R i_d + L\dot i_d - \omega_e L i_q\\
v_q &= R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m\\
\tau &= \tfrac32 p\lambda_m i_q = K_t i_q
\end{aligned}
$$

### 1.3 Current PI with Decoupling

Feed-forward decoupling cancels the cross-coupling and back-EMF terms. After that, each axis is a simple first-order plant:

$$
G_i(s) = \frac{1}{Ls+R}
$$

Use the controller

$$
C_i(s)=K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_c,\quad K_i = R\,\omega_c
$$

The PI zero cancels the electrical pole, so

$$
C_iG_i = \frac{\omega_c}{s}
\quad\Rightarrow\quad
\frac{i}{i^*}=\frac{\omega_c}{s+\omega_c}
$$

The voltage commands are then

$$
v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q,\qquad
v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e(L i_d+\lambda_m)
$$

**Saturation.** The voltage vector is limited to a circle:

$$
\|v_{dq}\| \le \frac{V_{bus}}{\sqrt3}
$$

The d-axis has priority, and v_q gets the remaining headroom:

$$
v_q^{max} = \sqrt{V_{max}^2 - v_d^2}
$$

**Anti-windup (back-calculation).** The integrator is corrected by the amount the output was clipped:

$$
x_{k+1}=x_k + T_s\left[K_i e_k + K_{aw}\,(u_{sat,k}-u_k)\right],\qquad K_{aw}=\frac{1}{K_p}\cdot K_i
$$

**Delay compensation.** Advance the angle used in the inverse Park transform by 1.5 sample periods to cover the computation plus PWM delay:

$$
\theta_e^{pwm}=\theta_e+1.5\,\hat\omega_e T_s
$$
