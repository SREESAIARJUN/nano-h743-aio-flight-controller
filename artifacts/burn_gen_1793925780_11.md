# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Design Assumptions

"Job #6" did not come with a parameter sheet, so I am using typical brushless gimbal values. Every value below is a constant in `GimbalConfig` and can be changed there.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sense | 2-shunt low-side per motor. A voltage-mode fallback is provided if no sensing |
| MCU | STM32G4/H7 class with FPU, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, mounted diametrically opposite about the plate centroid, on separate SPI buses, both at 8 kHz ODR |

**Loop rates and target bandwidths:**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current | 20 kHz | ~1.5 kHz |
| Rate (gyro) | 8 kHz | ~80–150 Hz |
| Attitude | 1 kHz | ~15–25 Hz |
| Cogging learning | 8 kHz, background | — |

**Control architecture (classic inertial-stabilized gimbal):**

```
q_ref ─►[Attitude P(+FF)]─► ω_ref ─►[Rate PI + J·α_ff]─► τ_cmd ─►(+cog FF)─► iq_ref ─►[FOC PI]─► SVPWM
          ▲ fused IMU quat      ▲ fused, notched gyro (projected on axis)      ▲ encoder θ_e, i_abc
```

- The encoder is used only for commutation, cogging lookup, and joint-limit kinematics.
- Stabilization feedback is inertial, from the IMU.
