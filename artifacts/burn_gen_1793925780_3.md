## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× hollow-shaft gimbal BLDC, 12N14P (7 pole pairs), R ≈ 10 Ω, L ≈ 2.5 mH (phase-to-neutral) |
| Inverter | 3-phase, center-aligned PWM 20 kHz, inline/low-side shunts, V_bus = 12–16 V |
| Rotor encoder | 14-bit absolute magnetic (MT6701/AS5048 class), read every current cycle |
| IMUs | 2× ICM-42688-P on the camera plate (SPI, 8 kHz gyro ODR, FIFO + DRDY) |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

**Loop hierarchy (per axis).** Each loop's bandwidth is kept at least ~5–10× below the loop inside it. This lets the inner loop be treated as a unity-gain block when tuning the outer loop.

```
 20 kHz  Current (FOC) PI     ω_c ≈ 2π·1500 rad/s
  4 kHz  Velocity PI          ω_v ≈ 2π·60   rad/s  (feedback: fused IMU gyro, inertial)
  1 kHz  Angle P(+I)          ω_a ≈ 2π·8    rad/s  (feedback: fused attitude)
  8 kHz  IMU acquisition + vibration filtering
```

**Key design decision.** The velocity and angle loops close on the **inertial** (camera-frame) rate and attitude from the IMUs, not on the encoder. The encoder is used only for:
- commutation (θ_e),
- cogging compensation (θ_m),
- the joint-space Jacobian.

This is what makes a gimbal reject base motion.

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle, with N_p pole pairs and calibrated offset θ_0:

$$\theta_e = N_p(\theta_m - \theta_0) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this rotation.

### 1.2 Plant model in the dq frame (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau = \tfrac32 N_p \lambda_m i_q = K_t i_q$$

### 1.3 Current PI with decoupling

**Decoupling and back-EMF feedforward.** These terms make each axis a pure first-order plant 1/(Ls+R):

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Gains by pole-zero cancellation.** Choosing K_i/K_p = R/L cancels the plant pole. The closed loop then becomes ω_c/(s + ω_c):

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

**Delay constraint.** The loop has about 1.5 sample periods of delay (one for computation, half for PWM). Keep ω_c ≤ 2π·f_pwm/12 to retain at least ~45° of phase margin.

**Voltage limit (circular).** With SVPWM the maximum available voltage magnitude is

$$|v_{dq}| \le V_{max} = \tfrac{V_{bus}}{\sqrt3}\cdot m_{max},\qquad m_{max}\approx 0.95$$

Priority is given to d-axis current regulation, so v_q is limited to

$$v_q \le \sqrt{V_{max}^2 - v_d^2}$$
