# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

## 0. Assumptions and Scope

I have no specification attached to "Job #0," so this design rests on the typical parameters below. Every numeric value lives in a config struct in the code, so you can substitute your measured values.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (GM4108-class), 24N22P, so pole pairs p = 11. R<sub>s</sub> ≈ 10 Ω, L<sub>s</sub> ≈ 4 mH, λ ≈ 0.012 Wb |
| Driver | 3-phase half-bridge at 20 kHz center-aligned PWM, 2 or 3 shunts, V<sub>bus</sub> = 12–16 V |
| Encoder | 14-bit absolute magnetic (AS5048A or MT6701), read every current-loop tick |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, FIFO off, data-ready interrupt |
| MCU | Cortex-M4F/M7 (STM32G4/H7), single-precision FPU |

Loop rates follow a decade-ish separation:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity | 4 kHz | ~150–250 Hz |
| Angle (inertial, IMU) | 1 kHz | ~30–50 Hz |
| IMU acquire and filter | 8 kHz, decimated to 4 kHz and 1 kHz |
