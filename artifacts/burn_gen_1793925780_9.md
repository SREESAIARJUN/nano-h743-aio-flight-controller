# Job #49: 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

## 0. Design Assumptions

These are stated assumptions. Change the constants in `config.hpp` to match your hardware.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit magnetic encoder per axis (AS5048A / MT6701 class), SPI |
| MCU | STM32G4 / H7 class with FPU, CORDIC optional |
| PWM | 25 kHz center-aligned, ADC-triggered at the counter peak |
| Current loop | 25 kHz (every PWM period) |
| Velocity loop | 5 kHz (÷5) |
| Angle and stabilization loop | 1 kHz (÷25) |
| IMUs | 2× ICM-42688-P on separate SPI buses, gyro ODR 8 kHz, accel ODR 1 kHz, read at 4 kHz |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

Each loop's bandwidth should sit about 5–10× below the loop it encloses:

```

                 ▲                                                        ▲          ▲                       ▲
       dual-IMU fusion + notches                                    encoder ω̂   cogging FF (Fourier/LMS)   Clarke/Park(θ_e)
```

## 1. FOC Current Loop: Equations

### 1.1 Transforms (amplitude-invariant)

Clarke transform:
$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)\quad(i_a+i_b+i_c=0)
$$

Park transform, with electrical angle $\theta_e = p\,(\theta_m - \theta_{\text{off}})$:
$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

Inverse Park transform:
$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$
