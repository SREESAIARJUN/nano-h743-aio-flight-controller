# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the original specification for Job #18, so this design rests on the assumptions below. Every parameter is defined as a constant or as a field of a struct (`MotorParams`, `ImuMount`, and so on), so you can change them without restructuring the code.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (e.g. AS5048A or MT6701) per axis |
| MCU | STM32G4 / H7 class: FPU, center-aligned PWM, injected ADC triggered at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, read by DMA |
| Gimbal topology | Yaw (outer) → Roll → Pitch (inner) → camera |

**Loop rates**

| Loop | Rate | Trigger / input |
|---|---|---|
| Current (FOC) | 20 kHz | ADC ISR |
| Velocity | 4 kHz | Encoder PLL plus camera gyro |
| Attitude/angle | 1 kHz | Fused attitude quaternion |
| IMU sampling (ODR) | 8 kHz | Filtered, then decimated to 4 kHz |

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

The electrical angle is $\theta_e = p\,(\theta_m - \theta_{off})$.

**Clarke transform** (amplitude-invariant, with $i_a + i_b + i_c = 0$):
$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}
$$

**Park transform:**
$$
\begin{bmatrix} i_d \\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}
$$
