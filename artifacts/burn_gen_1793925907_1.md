# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #60, so this design rests on the explicit assumptions in §0. Any of them can be changed, and the equations are written so you only need to substitute your own values. Values marked **[verify]** come from memory of vendor documents and must be checked against the current datasheet before you use them.

---

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoders | 14-bit absolute magnetic, one per joint (AS5048A / MT6701 class) |
| MCU | STM32G4 / H7 class with an FPU, 3 × 3-phase PWM, inline or low-side current shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, shared external CLKIN |
| Gimbal order | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y), camera frame at pitch |

| Loop | Rate | Feedback |
|---|---|---|
| Current (FOC) | 20 kHz | Phase currents and encoder electrical angle |
| IMU acquisition and filtering | 8 kHz (IMU ODR) | Both ICM-42688-P |
| Velocity | 4 kHz | Fused gyro rate mapped to joint rates (encoder rate used as fallback) |
| Attitude/angle | 1 kHz | Mahony quaternion versus setpoint |

**Bandwidth separation:** ω_c
