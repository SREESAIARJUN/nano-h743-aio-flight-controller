## 0. Architecture Correction

**The STM32H743 should not commutate the motors.** ArduPilot has no ESC firmware path for driving 12 half-bridges with sensorless commutation. The correct partition is:

| Block | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743VIT6 (480 MHz) | ArduPilot (ChibiOS) |
| ESC controllers ×4 | AT32F421K8U7 or STM32G071GBU6 | AM32 (bi-dir DShot, EDT) |
| Gate drivers ×4 | Fortior FD6288Q (3-phase, bootstrap) | n/a |
| Power stage | 24× N-MOSFET, 40 V, ≤1.2 mΩ | n/a |

The H743 emits bi-directional DShot600 to the four ESC MCUs and receives eRPM telemetry back on the same wire. That interface is the DMA problem solved in §3.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Assumptions

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| MOSFET R_DS(on), 25 °C, V_GS = 10 V | R₂₅ | 1.2 mΩ (max) |
| R_DS(on) temperature coefficient | α | 0.0065 /K |
| Phase current (burst, per motor) | I | 80 A |
| PCB copper path resistance (bus → FET → phase pad, 2 oz, per motor) | R_Cu | 0.5 mΩ |

### 1.2 Commutation topology

AM32 uses 6-step trapezoidal drive with complementary PWM (synchronous rectification). In each 60° sector, two legs are active:

- **PWM leg:** current alternates between the high-side FET (duty D) and the low-side FET (1−D).
- **Return leg:** the low-side FET is on continuously.

At every instant, the motor current flows through exactly **two** channels, independent of D:

$$
P_{cond,motor} = 2\,I^2\,R_{DS}(T_j) + I^2 R_{Cu}
$$

$$
R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]
$$

### 1.3 Electro-thermal coupling

R_DS depends on T_j, which depends on P. Solve by iteration (fixed point):

$$
T_j = T_{board} + R_{\theta JC}\,P_{FET}(T_j)
$$

The coupling is stable when $\alpha\,R_{\theta JC}\,P_{FET} < 1$, which holds here (≈0.13).

At T_j = 105 °C: R_DS = 1.2 × (1 + 0.0065 × 80) = **1.82 mΩ**

$$
P_{cond,motor} = 2(80^2)(1.82\text{ m}\Omega) + 80^2(0.5\text{ m}\Omega) = 23.3 + 3.2 = \mathbf{26.5\ W}
$$

The hottest single FET is the continuously-on return-leg low side: 80² × 1.82 mΩ ≈ **11.6 W**. Rotating commutation spreads this across all six FETs over an electrical cycle. The average per FET is ≈ 23.3/3 ≈ 7.8 W.

## 2. Switching Loss Model at f_sw = 48 kHz

### 2.1 MOSFET and driver parameters (assumed)

| Parameter | Value |
|---|---|
| Q_gs2 (V_th → plateau) | 4 nC |
| Q_gd (Miller) | 6 nC |
| Q_g total | 30 nC |
| V_plateau | 4.0 V |
| Q_rr (body diode) | 40 nC |
| Q_oss at 25 V | 25 nC |
| V_SD (body diode) | 0.8 V |
| Gate drive | 10 V; R_g,ext = 4.7 Ω, R_g,int = 1.0 Ω |
| Dead time t_d (AM32 setting) | 150 ns per edge |

### 2.2 Transition times

Gate current during the plateau:

$$
I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{g}} = \frac{10-4}{5.7} = 1.05\text{ A}, \qquad
I_{g,off} = \frac{V_{pl}}{R_g} = \frac{4}{5.7} = 0.70\text{ A}
$$

$$
t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = 9.5\text{ ns}, \qquad
t_{off} = \frac{Q_{gs2}+Q_{gd}}{I_{g,off}} = 14.3\text{ ns}
$$

### 2.3 Loss components (per motor; only the PWM leg's high side hard-switches)

| Component | Equation | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_on + t_off)·f | ½·25.2·80·23.8 ns·48k = **1.15 W** |
| Reverse recovery | V·Q_rr·f | 25.2·40 nC·48k = **0.05 W** |
| Output capacitance | Q_oss·V·f | 25 nC·25.2·48k = **0.03 W** |
| Dead-time diode conduction | 2·V_SD·I·t_d·f | 2·0.8·80·150 ns·48k = **0.92 W** |
| Gate charge (HS+LS, dissipated in driver/R_g) | 2·Q_g·V_drv·f | 2·30 nC·10·48k = **0.03 W** |
| **Total switching-related** | | **≈ 2.2 W** |

Q_rr is current- and di/dt-dependent; 40 nC is a datasheet-condition placeholder. Measure it with a double-pulse test.

**Design insight:** at 80 A, dead-time diode loss (0.92 W) is nearly equal to overlap loss. Tightening dead time from 150 ns to 80 ns saves ~0.43 W per motor, but verify there is no shoot-through across temperature first. 48 kHz is reasonable; conduction dominates by ~12:1.

### 2.4 Total burst dissipation

| | Per motor | ×4 motors |
|---|---|---|
| Conduction (FETs) | 23.3 W | 93.2 W |
| Copper | 3.2 W | 12.8 W |
| Switching | 2.2 W | 8.8 W |
