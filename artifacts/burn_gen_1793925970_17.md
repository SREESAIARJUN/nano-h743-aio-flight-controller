# STM32H743 Nano FC + 80 A 4-in-1 ESC (Job #41): Thermal, Switching, and DShot DMA Model

## 0. Scope and Assumptions

I don't have Job #41's BOM, stack-up, or layout files. Everything below uses **stated, typical-class parameters**. Each equation is written so you can substitute datasheet values. Numbers marked ⚠ must be verified against your actual parts.

**Architecture (as normally implemented):**
- **FC MCU:** STM32H743 at 400 MHz running ArduPilot. It generates bidirectional DShot600 and decodes eRPM telemetry.
- **ESC side:** four independent ESC MCUs (e.g. AT32F421 running AM32, or EFM8/BLHeli_S-class). These generate the **48 kHz PWM**. The H743 never drives the bridges directly.
- **Power:** 6S (25.2 V max), 80 A **burst** per motor, trapezoidal 6-step with complementary (synchronous) PWM.
