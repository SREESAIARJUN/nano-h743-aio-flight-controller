## 0. Architecture Decisions and Flagged Assumptions

**The STM32H743 does not drive the MOSFETs.** It runs ArduPilot and sends bi-directional DShot600 to four independent ESC MCUs. Each ESC MCU runs AM32 or BLHeli_32 and handles 6-step commutation, the 48 kHz PWM, and back-EMF sensing. This document models both halves.

**Form factor: "nano" vs. 80 A burst.** An 80 A per-motor burst is not credible on a 20×20 mm board. The math below assumes a 30.5×30.5 mm, 6-layer, 2 oz board.

| Parameter | Assumed value |
|---|---|
| Battery | 6S LiPo, V_bus,max = 25.2 V |
| MOSFET | 40 V N-ch DFN3.3×3.3, one per switch position (24 total) |
| R_DS(on) at 25 °C | 1.2 mΩ |
| R_DS(on) at 125 °C | ×1.5 = 1.8 mΩ |
| Q_g | 30 nC |
| Q_gs2 + Q_gd | 7 nC |
| C_oss,er | 1 nF |
| Q_rr | 50 nC |
| Body-diode V_f | 0.8 V |
| Gate driver | 3-phase half-bridge driver (FD6288Q class), V_drv = 12 V |
| Switching edges | t_r = t_f = 15 ns (conservative, including layout parasitics) |
| Dead time | 100 ns per edge |
| Modulation | 6-step trapezoidal, complementary (synchronous) PWM |

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step commutation with synchronous rectification, phase current always flows through exactly two MOSFET channels:

- the high-side/low-side pair of the PWM leg (alternating with duty D), and
- the low side of the return leg.
