# STM32H743 AIO Flight Controller + 4-in-1 ESC: Thermal, Loss, and DShot DMA Design Package

## Assumptions and Scope

I don't have the original specification for Job #43, so this package uses the assumed baseline below. Every equation is written so you can substitute your real datasheet values. The numerical results are only as good as these inputs.

| Parameter | Assumed value | Notes |
|---|---|---|
| Battery | 6S LiPo, 25.2 V max / 22.2 V nominal | Losses evaluated at 25.2 V (worst case) |
| Burst current | 80 A per motor channel | Burst duration is derived below, not assumed |
| Board | 30.5 × 30.5 mm, 8-layer, 2 oz outer / 1 oz inner | A 20 × 20 "nano" form factor cannot hold 80 A (see §3.4) |
| MOSFET | 40 V N-channel, PDFN 3.3×3.3 or 5×6 | R<sub>DS(on)</sub> = 1.3 mΩ max at V<sub>GS</sub> = 10 V, 25 °C |
| MOSFET charges | Q<sub>g</sub> = 40 nC, Q<sub>gd</sub> = 8 nC, Q<sub>rr</sub> = 30 nC, C<sub>oss(er)</sub> = 1.0 nF | |
| MOSFET thermal | R<sub>θJC</sub> = 1.0 K/W, T<sub>J,max</sub> = 150 °C (design limit 125 °C) | |
| ESC switching | 48 kHz, synchronous rectification, 6-step (trapezoidal) | AM32 or BLHeli_32-class firmware |
| Dead time | 100 ns per edge | |
| Gate drive | 10 V gate drive, ~1 A source / 2 A sink | |
| FC MCU | STM32H743VIT6 (LQFP100), ArduPilot | Sends DShot600 to the ESC MCUs |
| ESC MCUs | 4× AT32F421 or STM32G071 | One per motor channel |

**Architectural note.** The H743 does not switch the bridges. It sends bidirectional DShot600 to four dedicated ESC MCUs, which generate the 48 kHz PWM. So §1–3 describe the ESC MCU and power stage, and §4 describes the H743.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R<sub>DS(on)</sub>

$$
R_{DS}(T_J) = R_{DS,25}\,\big[1 + \alpha\,(T_J - 25)\big], \qquad \alpha \approx 0.0045\ \text{K}^{-1}
$$

At the design point T<sub>J</sub> = 110 °C:

$$
R_{DS}(110) = 1.3\ \text{m}\Omega \times (1 + 0.0045 \times 85) = 1.3 \times 1.383 \approx 1.80\ \text{m}\Omega
$$

### 1.2 Commutation-state current paths

In 6-step drive with synchronous rectification, two FETs carry the full phase current at every instant:

- **Switching phase:** the high-side FET conducts for D·T<sub>sw</sub>, and the low-side FET (sync rectifier) conducts for (1−D)·T<sub>sw</sub>. One device is always on, so the conduction loss is independent of D (dead time is neglected here and handled in §2).
- **Return phase:** the low-side FET is held on for the whole 60° sector.

Per motor channel:

$$
P_{cond,motor} = 2\,I^2\,R_{DS}(T_J) = 2 \times 80^2 \times 1.80\times10^{-3} = \mathbf{23.0\ W}
$$

Each FET conducts for 120° of the 360° electrical cycle, so the average loss per FET is:

$$
P_{cond,FET} = \frac{I^2 R_{DS}}{3} = \frac{6400 \times 1.80\times10^{-3}}{3} = \mathbf{3.84\ W}
$$

### 1.3 PCB copper loss

Assume the current loop runs from the battery pad through the bus plane, the FETs, the phase pad, and back. With about 0.5 mΩ effective copper resistance per motor loop (2 oz outer layers plus stitched inner planes):

$$
P_{Cu,motor} = I^2 R_{Cu} = 6400 \times 0.5\times10^{-3} = \mathbf{3.2\ W}
$$

Copper resistance also rises about 0.39 %/K, so add roughly 30 % at 100 °C board temperature, giving about 4.2 W. Shunt resistors, if used (e.g. 0.25 mΩ), add I²R<sub>sh</sub> = 1.6 W per channel.

## 2. Switching Loss Model at 48 kHz

Only one half-bridge per motor is hard-switching at any time.

### 2.1 Transition times (gate-charge method)

$$
t_r \approx \frac{Q_{gs2} + Q_{gd}}{I_{g,src}}, \qquad
t_f \approx \frac{Q_{gs2} + Q_{gd}}{I_{g,snk}}
$$

With Q<sub>gs2</sub> ≈ 7 nC, I<sub>src</sub> ≈ 0.75 A effective (limited by R<sub>g</sub>), and I<sub>snk</sub> ≈ 1.0 A effective, this gives t<sub>r</sub> ≈ 20 ns and t<sub>f</sub> ≈ 15 ns.

### 2.2 Loss components (V = 25.2 V, I = 80 A, f = 48 kHz)

| Mechanism | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t<sub>r</sub>+t<sub>f</sub>)·f = ½·25.2·80·35 ns·48 k | **1.69 W** |
| Reverse recovery | Q<sub>rr</sub>·V·f = 30 nC·25.2·48 k | 0.036 W |
| Output capacitance | C<sub>oss(er)</sub>·V²·f = 1 nF·635·48 k | 0.030 W |
| Dead-time body diode | V<sub>F</sub>·I·2t<sub>dt</sub>·f = 0.8·80·200 ns·48 k | **0.61 W** |
| Gate drive (driver + R<sub>g</sub>) | 2·Q<sub>g</sub>·V<sub>GS</sub>·f = 2·40 nC·10·48 k | 0.038 W |
| **Total switching, per motor** | | **≈ 2.42 W** |

Q<sub>rr</sub> grows with di/dt and current, so measure it at 80 A if the datasheet only specifies it at a lower current. A soft-recovery FET or snubber may add about 0.1–0.3 W.

**Frequency sensitivity:** P<sub>sw</sub> ≈ 0.050 W/kHz. Dropping from 48 kHz to 24 kHz saves about 1.2 W per motor (about 5 W board-wide) but increases current ripple in low-inductance motors.
