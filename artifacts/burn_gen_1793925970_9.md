## 0. Architecture Decision

A 4-in-1 ESC driven by ArduPilot over DShot needs **one ESC MCU per motor channel**. The H743 cannot commutate four BLDC motors and run ArduPilot at the same time.

- The STM32H743 runs ArduPilot and sends bi-directional DShot600 to four ESC MCUs.
- Each ESC MCU runs AM32 or BLHeli_32 on an STM32G071 or AT32F421.
- AM32 supports a 48 kHz PWM setting, which is where the 48 kHz figure applies.

```
 6S LiPo ─┬─ Shunt/Hall ─ VBUS ──┬──────────┬──────────┬──────────┐
          │                      │          │          │          │
        BEC 5V/10V          ESC1 (G071)  ESC2      ESC3      ESC4
          │                  + 3-ph drv   ...       ...       ...
          │                  + 6×MOSFET
   STM32H743 (ArduPilot) ── DShot600 BIDIR ×4 ──┘
```

## 2. Conduction Loss Model (6-Step Trapezoidal)

### 2.1 Current path
In 6-step commutation, at any instant one high-side FET (phase X) and one low-side FET (phase Y) carry the phase current I. With synchronous rectification, during the PWM off-time the current moves from the high-side FET to the complementary low-side FET in the same leg. **Two R_ds(on) are always in series with the motor current.**

Each of the 6 FETs conducts for 120° of the 360° electrical cycle, so its conduction duty is 1/3.

### 2.2 Temperature-corrected resistance

$$R_{ds}(T_j) = R_{ds,25}\,\big[1 + \alpha (T_j - 25)\big],\qquad \alpha \approx 0.006\,\text{K}^{-1}$$

At T_j = 125 °C: R_ds = 0.90 mΩ × 1.6 = **1.44 mΩ**.

### 2.3 Per-motor and per-FET conduction loss

$$P_{cond,motor} = I^2 \cdot 2R_{ds}(T_j) = 80^2 \times 2 \times 1.44\text{ mΩ} = \mathbf{18.4\ W}$$

$$P_{cond,FET} = \frac{I^2 R_{ds}(T_j)}{3} = \frac{6400 \times 1.44\text{ mΩ}}{3} = \mathbf{3.07\ W}$$

### 2.4 Copper and shunt conduction (often overlooked)

**Phase and bus copper.** Assume ~0.25 mΩ effective path per motor (VBUS plane, phase pad, solder joints):
$$P_{Cu} = 80^2 \times 0.25\text{ mΩ} = 1.6\text{ W per motor}$$

**Current shunt.** This is a design hazard.
- A per-motor 0.5 mΩ shunt dissipates 80² × 0.5 mΩ = **3.2 W**. That is unacceptable on a nano board.
- A single 0.25 mΩ shunt on the total bus at 320 A would dissipate **25.6 W**. That is impossible.

**Recommendation:** use a 0.1–0.2 mΩ shunt per ESC (0.64–1.28 W at 80 A) with an INA-class amplifier at gain 50–100. Alternatively, use a hall-effect sensor on the battery lead (near-zero loss), feeding the H743 ADC for `BATT_CURR_PIN`.

## 3. Switching Loss Model at 48 kHz

Only the PWM-modulated leg switches. The other conducting leg is held statically for the 60° sector, so **2 FETs per motor switch at any time** (one hard-switched edge pair per period).

### 3.1 Hard-switching V·I overlap loss

$$P_{sw} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw}$$
$$= 0.5 \times 25.2 \times 80 \times 20\text{ ns} \times 48\text{ kHz} = \mathbf{0.97\ W\ per\ motor}$$
