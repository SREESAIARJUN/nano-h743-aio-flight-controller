# STM32H743 AIO Flight Controller with 4-in-1 ESC: Electrical, Thermal and DShot Design Model (Job #70)

## 0. Architecture and Key Constraints

**The H743 does not commutate the motors.** In a production 4-in-1 design, each ESC channel has its own commutation MCU. This model assumes an AT32F421 or STM32G071 per channel, running AM32 or BLHeli_32-class firmware, driving an FD6288-class 3-phase gate driver. The H743 runs ArduPilot and talks to the four ESC MCUs over bidirectional DShot600. Direct FET commutation from the H743 is not supported by ArduPilot and is not recommended.

**80 A per channel on a nano (20×20 or 25.5×25.5 mm) board is a seconds-scale burst rating, not continuous.** The thermal model in §3 quantifies this. Expect about 2 s at 80 A and roughly 25–30 A continuous without a heatsink.

## 1. Conduction Loss Model

### 1.1 Topology
With 6-step trapezoidal commutation and complementary PWM, current at any instant flows through exactly two FETs:
- one device in the PWM leg: the high side for D, the low side (synchronous) for 1−D;
- the low side of the return leg, which is held on.

The duty-cycle terms therefore cancel:

$$P_{cond,ESC} = I_{rms}^2 \cdot R_{DS(on)}(T_j)\,[D + (1-D)] + I_{rms}^2 R_{DS(on)}(T_j) = 2\,I_{rms}^2\,R_{DS(on)}(T_j)$$

### 1.2 Temperature dependence

$$R_{DS(on)}(T_j) \approx R_{25}\,\big[1 + \alpha (T_j - 25)\big], \quad \alpha \approx 0.005\ \text{K}^{-1} \Rightarrow k_{125} = 1.5$$

$$R_{hot} = 1.5\ \text{m}\Omega$$

### 1.3 PWM ripple correction

$$\Delta I_{pp,max} = \frac{V_{bus}\,D(1-D)}{L\, f_{sw}}\Big|_{D=0.5} = \frac{25.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 6.56\ \text{A}$$

$$I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 3.6 \approx 6404\ \text{A}^2$$

The ripple term is negligible (<0.1 %).

### 1.4 Result at 80 A

| Term | Expression | Value |
|---|---|---|
| FET conduction | 2 × 6404 × 1.5 mΩ | **19.2 W per ESC** |
| Per conducting FET | | ≈ 9.6 W |
| Shunt | 6404 × 0.5 mΩ | 3.2 W |
| Copper / connections (≈0.3 mΩ path) | | ≈ 1.9 W |

## 2. Switching Loss Model (48 kHz)

Only the PWM leg switches hard, so there is one hard-switched node per ESC.

**(a) V–I overlap**

$$P_{VI} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 40\text{ns} \times 48\text{k} = 1.94\ \text{W}$$

**(b) Reverse recovery** of the synchronous FET body diode after dead time

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n} \times 25.2 \times 48\text{k} = 0.06\ \text{W}$$

**(c) Output capacitance**

$$P_{oss} = \tfrac12 Q_{oss} V_{bus} f_{sw} = 0.024\ \text{W}$$

**(d) Dead-time body-diode conduction** (two edges per period)

$$P_{dt} = V_f\, I\, (2 t_{dt})\, f_{sw} = 0.8 \times 80 \times 200\text{n} \times 48\text{k} = 0.61\ \text{W}$$

**(e) Gate drive** (two FETs per switching leg; dissipated in the driver and gate resistors, not the FETs)

$$P_g = 2\, Q_g V_{GS} f_{sw} = 2 \times 50\text{n} \times 10 \times 48\text{k} = 0.048\ \text{W}$$

### 2.1 Total per ESC at 80 A, T_j = 125 °C

| Loss | W |
|---|---|
| Conduction (FETs) | 19.20 |
| Overlap switching | 1.94 |
| Dead-time diode | 0.61 |
| Q_rr + Q_oss | 0.08 |
| Gate drive | 0.05 |
| Shunt + copper | 5.10 |
| **Total per ESC** | **≈ 27.0 W** |
| **4-in-1 board, all channels at 80 A** | **≈ 108 W** |
