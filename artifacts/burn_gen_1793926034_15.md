## 0. Architecture Assumptions and Constraints

Validate these assumptions first. Every number below depends on them.

| Parameter | Assumed value | Notes |
|---|---|---|

| ESC MCU | 4 × AT32F421K8U7 running AM32 | AM32 supports bidirectional DShot and 48 kHz PWM. |
| Commutation | 6-step trapezoidal, complementary PWM (synchronous rectification) | |
