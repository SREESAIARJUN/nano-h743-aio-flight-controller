# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Fusion

I don't have the Job #56 hardware spec, so this design uses the assumptions below. Every value is a parameter in the code.

| Item | Assumption |
|---|---|
| MCU | STM32G4/H7-class, single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute (AS5048A / MT6701), used for commutation and joint angle |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, camera) |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted symmetrically about the plate centroid, SPI at 8 kHz ODR |
| Loop rates | Current 20 kHz (PWM-center ADC ISR); rate loop 4 kHz (IMU decimated); attitude loop 1 kHz |
