## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

**Electrical angle**

$$\theta_e = \text{wrap}_{2\pi}\big(p(\theta_m - \theta_{\text{off}})\big)$$

**Clarke transform** (amplitude-invariant, balanced phases):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

**SVPWM** (min-max zero-sequence injection, equivalent to 7-segment SVM):

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

The linear range is $|v_{\alpha\beta}| \le V_{dc}/\sqrt3$. The voltage vector is circularly limited to this value, with the d-axis given priority.

### 1.2 Machine Model and Current PI Controller

The dq-frame model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e(L i_d + \lambda_m)$$

**Controller form.** A PI controller with pole–zero cancellation is used, $C_i(s) = K_p + K_i/s$. The gains are:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

This yields a closed loop of $\omega_c/(s+\omega_c)$. Choose $\omega_c \le 2\pi f_{pwm}/20$, which gives ≈ 6.3 krad/s at 20 kHz.

**Decoupling feedforward**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e\lambda_m$$

**Torque**

$$\tau = K_t i_q,\qquad K_t = \tfrac32 p\lambda_m$$
