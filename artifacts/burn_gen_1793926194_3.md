## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform** (θ_e = p·θ_m − θ_offset):

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** uses the transpose of this matrix.

### 1.2 Plant and Decoupling

The PMSM voltage equations in the dq frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The decoupling feedforward terms are:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m,\qquad \lambda_m = \tfrac{2}{3}\tfrac{K_t}{p}$$

### 1.3 PI Gains by Pole-Zero Cancellation

Placing the PI zero on the electrical pole (R/L) gives:

$$K_p^{i} = L\,\omega_{ci},\qquad K_i^{i} = R\,\omega_{ci}$$

The closed loop is then first-order, $G_{cl}(s) = \frac{\omega_{ci}}{s+\omega_{ci}}$.

The computation plus PWM delay is about $T_d \approx 1.5T_s$. To keep phase margin above 60°, choose:

$$\omega_{ci} \le \frac{\pi/6}{T_d}$$

At 20 kHz this gives ω_ci ≈ 2π·1.5 kHz.

**Discretization:** forward Euler on the integrator. The output is clamped to the voltage circle of radius $V_{bus}/\sqrt3$, using SVPWM's linear range.

### 1.4 Anti-Windup by Back-Calculation

$$I_{k+1} = I_k + T_s\big[K_i e_k + K_{aw}(u_{sat,k} - u_{k})\big],\qquad K_{aw} = \frac{K_i}{K_p}$$

### 1.5 SVPWM by Min-Max Injection

This is equivalent to sector-based SVPWM:

$$v_{a,b,c}\ \text{from inverse Clarke},\qquad v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical Plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

Because the current loop is about 10× faster than the velocity loop, it is treated as a unity gain.
