## 0. System Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU, running at 170 MHz or more |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |

| IMU ODR / filter rate | 8 kHz (ICM-42688-P, both IMUs on separate SPI buses, triggered by data-ready) |

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

The amplitude-invariant **Clarke transform** is:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\qquad (i_a+i_b+i_c=0)$$

The **Park transform** uses the electrical angle $\theta_e = p\,\theta_m - \theta_{off}$:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The **inverse Park transform** is the transpose of that matrix.

### 1.2 Plant Model and PI Design

The PMSM voltage equations in the dq frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

With the decoupling feedforward terms

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m,$$

each axis reduces to $G(s)=\dfrac{1}{Ls+R}$.

A PI controller $C(s)=K_p + K_i/s$ with the following gains cancels the plant pole:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The open loop then becomes $L(s)=\omega_c/s$, so the closed loop is first order with bandwidth $\omega_c$.

- Choose $\omega_c \le 2\pi f_{pwm}/15$. For 20 kHz, that gives $\omega_c \approx 2\pi\cdot1.2\text{ kHz}$.
- The PWM update adds a 1.5·Ts transport delay. At this bandwidth, phase margin is about 70°.

### 1.3 Saturation

Limit the voltage vector to the linear SVPWM region:

$$\|v_{dq}\| \le V_{max} = \tfrac{V_{bus}}{\sqrt3}\cdot m,\qquad m \approx 0.95$$

The d-axis has priority. The q-axis receives whatever voltage remains:

$$v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$$

### 1.4 SVPWM by Min–Max Zero-Sequence Injection

$$v_{off} = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\qquad d_x = \tfrac12 + \frac{v_x+v_{off}}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM and needs far fewer cycles.
