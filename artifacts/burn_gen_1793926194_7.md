# 3-Axis Gimbal: FOC Control, Anti-Cogging Compensation, and Dual ICM-42688-P Fusion

## 0. Design Basis and Assumptions

I don't have a specification for "Job #0," so this design rests on typical brushless-gimbal values. Every value below is a constant in `GimbalConfig` and can be changed.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, CORDIC, 3× ADC) |
| Motors | GBM2804-class: 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 1.8 mH, K_t ≈ 0.12 N·m/A, J ≈ 2.5×10⁻⁵ kg·m² (motor + payload, per axis) |
| Rotor sensor | 14-bit magnetic encoder (MT6701 / AS5048A) on each motor |
| Current sense | 2-shunt low-side, sampled at the PWM center |
| Bus | V_dc = 12–16 V |
| IMUs | 2× ICM-42688-P on the camera plate, mounted point-symmetric about the plate centroid (r₂ = −r₁), IMU2 rotated 180° about z |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
