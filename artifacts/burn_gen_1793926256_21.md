## 0. Scope, Architecture Clarification, and Design Basis

### 0.1 Partitioning

The STM32H743 does not drive the power stage directly. In this design it is the **flight controller (FC)** running ArduPilot. The 4-in-1 ESC has **four independent ESC MCUs**, one per motor (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32). Each ESC MCU generates the 48 kHz complementary PWM. The H743 talks to them only over **bidirectional DShot600**, one wire per motor.

```
 ┌──────────── FC (STM32H743VIT6, 480 MHz) ────────────┐        ┌──────── 4-in-1 ESC ────────┐
 │ ArduPilot ─ TIM1 CH1..4 ─ DMAMUX ─ DMA1/DMA2        │ 4×DShot│ 4× ESC MCU (AM32)          │
 │            (bidir DShot600, eRPM telemetry)         ├───────►│ 4× 3-ph gate driver        │
 │ ADC: VBAT, CURR  ◄──────────────────────────────────┤◄───────│ 24× N-MOSFET, shunt, Cbulk │
 └─────────────────────────────────────────────────────┘ 8-pin  └────────────────────────────┘
```

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-Dependent Resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C: R_ds = 0.90 × 1.45 = **1.305 mΩ**.

### 1.2 Six-Step Trapezoidal Commutation with Synchronous Rectification

Each phase spends 120° electrical in each of three states:
- **High-PWM:** the HS FET is on for D, and the LS FET is on for (1−D) as a synchronous rectifier.
- **Low-ON:** the LS FET is fully on.
- **Floating.**

RMS-squared current per device:

$$I_{HS,rms}^2 = \frac{D}{3}I^2 \qquad I_{LS,rms}^2 = \frac{1-D}{3}I^2 + \frac{1}{3}I^2 = \frac{2-D}{3}I^2$$
