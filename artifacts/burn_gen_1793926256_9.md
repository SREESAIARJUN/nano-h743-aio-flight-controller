## 0. Architectural Assumptions

Three points need correcting or pinning down before the math, because they change the results.

1. **The H743 does not drive the MOSFETs.** ArduPilot runs on the STM32H743 and sends DShot600 to four ESC MCUs (AT32F421 or STM32G071 running AM32/BLHeli_32). The **48 kHz PWM is generated by the ESC MCUs**, not by the H743. The netlists reflect this two-tier design.
2. **The "80A burst" in a nano form factor is thermally transient-limited.** The model below shows ~2 s all-motor burst capability at 80A. Marketing ratings must state the burst duration and conditions.
3. **Component values are placeholders.** MOSFET parameters below represent a typical 40V, 5×6/3×3 DFN part suitable for 6S. Replace every parameter with values from your selected datasheet before release.

## 1. Conduction Loss Model

### 1.1 Topology
The design uses six-step (trapezoidal) commutation with synchronous (complementary) PWM. At any instant, two phase legs carry the motor current:
- **PWM leg:** current alternates between the HS FET (on-time, duty D) and the LS FET (off-time, synchronous rectification).
- **Fixed leg:** one FET is on for the entire 60° sector.

So there are always exactly **two FET channels in series** with the motor current, independent of duty (ignoring dead time):

$$P_{cond,motor} = I_{rms}^2 \cdot \left(2R_{DS}(T_j) + R_{Cu}\right)$$

### 1.2 Temperature dependence

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right]$$

At T_j = 125 °C: R_DS = 1.0 × (1 + 0.45) = **1.45 mΩ**.

### 1.3 Ripple contribution
Phase current ripple at 48 kHz, with L_phase ≈ 15 µH (typical 2207 motor line-line) and worst case D = 0.5:

$$\Delta I_{pp} = \frac{V_{bus} D(1-D)}{L f_{sw}} = \frac{25.2 \times 0.25}{15\mu \times 48k} \approx 8.75\text{ A}$$

$$I_{rms} = \sqrt{I^2 + \frac{\Delta I_{pp}^2}{12}} = \sqrt{6400 + 6.4} \approx 80.04\text{ A}$$

The ripple contribution is negligible (<0.1%), but it matters for capacitor sizing (§3.4).

### 1.4 Result (per motor, T_j = 125 °C)
PCB copper path (bus → FETs → phase pad, both legs) is estimated at R_Cu ≈ 0.4 mΩ for 8L/2oz.

| Term | Calculation | Loss |
|---|---|---|
| FETs | 80² × 2 × 1.45 mΩ | **18.56 W** |
| Copper | 80² × 0.4 mΩ | **2.56 W** |
| **Total conduction** | | **21.1 W** |

Instantaneous dissipation in a single conducting FET is 80² × 1.45 mΩ = **9.3 W**. Because each FET conducts about 1/3 of an electrical cycle (per-FET duty depends on D), the time-averaged loss per FET is ≈ 18.56/6 ≈ **3.1 W**.
