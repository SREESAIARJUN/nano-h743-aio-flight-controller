## Engineering Model, DMA Allocation, Netlist, and Thermal Analysis

## 0. Scope and Feasibility Review

Before deriving anything, three architectural assumptions need to be stated.

1. **The H743 runs the flight controller, not the ESC.** Commercial 4-in-1 ESCs use a separate MCU per channel, such as the AT32F421 or STM32G071 running AM32, or the EFM8BB21 running BLHeli_S. The H743 generates bidirectional DShot600 to those four ESC MCUs. This document assumes that two-board stack, or an AIO with five MCUs.

2. **"80A burst" is defined here as 80A RMS phase current per channel, for at most 2 seconds.** Battery current is lower by the duty factor. Vendors often quote battery-side current, so confirm which definition the requirements use.

3. **80A per channel on a true 20×20 nano footprint is not thermally credible.** The analysis in Section 3 shows roughly 95W of dissipation on about 4 cm² of PCB. That is survivable only for a few seconds, even with airflow. I model a 30.5×30.5mm ESC (often still marketed as "nano"), and Section 3.6 shows why 20×20 fails.

## 1. Conduction Loss Model

### 1.1 Commutation topology

The ESC uses trapezoidal (six-step) commutation with complementary PWM, i.e. synchronous rectification:

- In each 60° sector, one leg's high side switches at duty D.
- That leg's low side conducts during (1−D).
- Another leg's low side is held fully ON.
- The third leg floats for BEMF sensing.

Phase current therefore always flows through exactly two FET channels in series.

```
P_HS,PWM  = D · I² · R_DS(Tj)
P_LS,comp = (1−D) · I² · R_DS(Tj)
P_LS,on   = I² · R_DS(Tj)
─────────────────────────────────────────
P_cond,ch = 2 · I_rms² · R_DS(Tj)        (independent of D)
```

### 1.2 Temperature dependence

```
R_DS(Tj) = R_DS,25 · [1 + α(Tj − 25)]
```

This dependence is electrothermally coupled, so the model must iterate. At the design point Tj = 125°C:

```
R_DS(125) = 1.2 mΩ × (1 + 0.004 × 100) = 1.68 mΩ
```

### 1.3 PWM ripple correction

The RMS current includes switching ripple:

```
I_rms² = I_avg² + ΔI²/12,   with ΔI = V_bus · D(1−D) / (L_ph · f_sw)
```

For a 5-inch-class motor (L_ph ≈ 15 µH line-to-line) at D = 0.5:

```
ΔI = 25.2 × 0.25 / (15e-6 × 48e3) = 8.75 A
ΔI²/12 = 6.4 A²
```

That is negligible against 80² = 6400 A² (0.1%), so it is ignored at burst. It does matter at light load.

### 1.4 Result per channel

```
P_cond   = 2 × 80² × 1.68e-3 = 21.50 W
P_shunt  = 80² × 0.2e-3      =  1.28 W
P_copper ≈ 80² × 0.15e-3     =  0.96 W   (≈0.15 mΩ of plane and via resistance per phase path)
──────────────────────────────────────────
P_cond,total ≈ 23.7 W per channel
```

### 1.5 Instantaneous load on a single FET

This is what sets local hot spots:

```
P_FET,peak = I² · R_DS = 80² × 1.68e-3 = 10.75 W
```

This applies while a low-side FET is held fully on for its 120° conduction interval. The time-averaged load per FET is about P_ch/6 ≈ 3.6 W (conduction only). However, at low eRPM each interval lasts milliseconds, so the junction tracks the peak, not the average.
