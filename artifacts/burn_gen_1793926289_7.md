## 0. Architecture Clarification and Design Assumptions

### 0.1 Where the 48 kHz PWM lives

In a 4-in-1 stack, the **STM32H743 does not generate the 48 kHz bridge PWM**. Responsibilities split as follows:

| Function | Device |
|---|---|
| Flight control, DShot600 command and bidirectional eRPM capture | STM32H743 (FC) |
| 6-step/FOC commutation, 48 kHz complementary PWM, dead time | 4× ESC MCUs (e.g. AT32F421 / STM32G071 running AM32 or BLHeli_32) |
| Gate drive | 4× 3-phase half-bridge drivers (e.g. FD6288Q-class) |

The H743 therefore enters the loss model only through command latency and the eRPM feedback path (§5).
