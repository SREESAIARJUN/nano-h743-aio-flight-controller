## 1. Conduction Loss Model

### 1.1 Current paths per commutation step
In each 60° electrical sector, two legs are active:
- **Leg A (PWM leg)** alternates between HS and LS:
 - HS conducts for duty D.
 - LS synchronous-rectifies for (1−D).
- **Leg B (return leg)** has its LS (or HS) on for the whole sector.

So the motor current I_ph always passes through exactly **two conducting FETs in series**.

### 1.2 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,\big[1+\alpha\,(T_j-25)\big],\qquad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 110 °C: R_DS ≈ 1.0 × 1.38 ≈ **1.4 mΩ**.

### 1.3 Per-channel conduction loss

$$P_{cond,ch} = I_{ph}^2\big[D\,R_{HS} + (1-D)\,R_{LS}\big] + I_{ph}^2 R_{B} = 2\,I_{ph}^2\,R_{DS}(T_j)\quad (\text{matched FETs})$$

At I_ph = 80 A:

$$P_{cond,ch} = 2(80)^2(1.4\times10^{-3}) = \mathbf{17.9\ W}$$

### 1.4 Copper and shunt loss
- Phase and bus copper path R_Cu ≈ 0.3 mΩ per channel (2 oz, inner-layer stitched, short path).
- Shunt R_sh = 0.25 mΩ (if per-channel low-side sensing is used).

$$P_{Cu+sh} = I^2(R_{Cu}+R_{sh}) = 6400 \times 0.55\text{m} \approx \mathbf{3.5\ W}$$

Copper also has α ≈ 0.0039 K⁻¹, so scale it with temperature in the same way.

### 1.5 Self-consistent junction temperature
R_DS depends on T_j, which depends on P. Iterate:

$$T_j^{(n+1)} = T_{ref} + P\big(T_j^{(n)}\big)\cdot Z_{th}(t)$$

The loop converges when $\frac{\partial P}{\partial T}\,Z_{th} < 1$. **Thermal runaway occurs if** $2I^2R_{DS,25}\,\alpha\,Z_{th} \ge 1$:
- At 80 A this requires Z_th ≥ 1/(2·6400·1e-3·0.0045) ≈ **17 K/W**.
- A nano board's steady-state R_θ is about 8 K/W at the board level. Adding the junction-to-board resistance brings the per-FET path close to this threshold.
- **This is an independent reason the burst must be time-limited.**

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. There are 2 transitions per period.

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = \tfrac12(25.2)(80)(40\,\text{ns})(48\,\text{kHz}) = \mathbf{1.94\ W}$$
