## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Transforms

Power-invariant scaling is not used here. These are amplitude-invariant transforms. Assume i_a + i_b + i_c = 0.

**Clarke:**

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park** (electrical angle θₑ = p·θₘ − θ_offset):

$$i_d = i_\alpha\cos\theta_e + i_\beta\sin\theta_e,\qquad i_q = -i_\alpha\sin\theta_e + i_\beta\cos\theta_e$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

**Inverse Clarke and min-max SVPWM** (equivalent to SVM, gives 15.5% more linear range than SPWM):

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

The voltage vector is limited to the inscribed circle:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

### 1.2 Current PI by pole-zero cancellation

Plant per axis:

$$G_i(s) = \frac{1}{Ls+R}$$

Controller:

$$C_i(s) = K_p + \frac{K_i}{s}$$

Choosing K_i / K_p = R/L cancels the electrical pole. The closed loop then becomes first-order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \approx \frac{2\pi f_{pwm}}{10\ldots20}$$

With f_pwm = 20 kHz, choose ω_c = 2π·1500 rad/s. This gives K_p = 11.3 V/A and K_i = 52.8×10³ V/(A·s).

Add a decoupling feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m$$

Here λ_m = Kt / (1.5·p).

**Discrete PI with back-calculation anti-windup** (sample time T_s):

$$u_k = K_p e_k + I_k,\qquad u_k^{sat} = \mathrm{sat}(u_k)$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw} T_s\,(u_k^{sat}-u_k),\qquad K_{aw}\approx K_i/K_p$$

**Delay compensation.** PWM update plus ADC sampling adds about 1.5 T_s of delay. Advance the angle used for the inverse Park by:

$$\theta_e^{\,out} = \theta_e + 1.5\,\omega_e T_s$$
