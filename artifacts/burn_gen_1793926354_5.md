# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #17, so this design states its hardware assumptions explicitly in §0. Every parameter is in a config struct, so you can substitute your real values without changing the structure.

## 0. Assumptions

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), SPI |
| Current sense | 2-phase low-side shunts, sampled at the PWM center |
| PWM / current loop | 20 kHz center-aligned PWM, current loop at 20 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, ODR 8 kHz, SPI + DMA |
| Velocity loop | 4 kHz (every 5th current-loop tick) |
| Angle loop | 1 kHz |
| Attitude estator | 1 kHz (gyro pre-filtered at 8 kHz) |
| MCU | Cortex-M4F/M7 or similar with single-precision FPU |

The architecture separates two jobs:

- **Commutation** uses the motor encoder.
- **Stabilization** uses the camera-frame gyro (velocity loop) and the fused attitude (angle loop). This is inertial stabilization: the camera is held still in inertial space, not relative to the handle.

## 1. FOC Equations

### 1.1 Electrical angle

$$\theta_e = \mathrm{wrap}_{[0,2\pi)}\big(p\,\theta_m - \theta_{off}\big)$$

Find θ_off at calibration by forcing v_d onto the d-axis (θ_e = 0) and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Motor model (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.5 Current PI by pole–zero cancellation

The plant is $G_i(s) = 1/(Ls+R)$. The controller is $C(s) = K_p + K_i/s$.

Choose $K_i/K_p = R/L$. The zero then cancels the electrical pole, and the open loop becomes $K_p/(Ls)$. The closed loop is first order with bandwidth ω_ci:

$$K_p^{(i)} = L\,\omega_{ci},\qquad K_i^{(i)} = R\,\omega_{ci}$$

Choose ω_ci ≤ 2π·f_s/10 to account for the computation and PWM delay (≈1.5 T_s). At 20 kHz, ω_ci ≈ 2π·1500 rad/s is a safe value.

**Decoupling and back-EMF feedforward:**

$$v_d^* = \mathrm{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \mathrm{PI}_q(e_q) + \omega_e L i_d + \omega_e \lambda_m$$

### 1.6 Voltage limiting

The linear SVPWM limit is $|v| \le V_{bus}/\sqrt3$. Give d priority: v_d is clamped first, and v_q gets the remaining $\sqrt{V_{max}^2 - v_d^2}$.

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)
