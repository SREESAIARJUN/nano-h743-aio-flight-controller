# STM32H743 FC + Integrated 4-in-1 ESC: Engineering Model and Design Package

## 0. Scope, Assumptions, and a Feasibility Warning

I have no prior project context for "Job #36", so this package states every assumption explicitly. Change any parameter and the equations still apply.

| Parameter | Assumed value | Notes |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max | Use 4S (16.8 V) to cut switching loss ~33% |
| Topology | FC (STM32H743) plus four independent ESC MCUs | e.g., AT32F421 running AM32 or BLHeli_32 |
| Commutation | 6-step trapezoidal, synchronous rectification (complementary PWM) | |
| f_sw | 48 kHz | |
| Burst current | 80 A per motor | Total bus current is 320 A |
| Phase inductance (line-line) | 15 µH | Typical 2207–2810 motor |
| Gate driver | FD6288Q-class 3-phase driver, V_GS = 10 V, dead time 300 ns | |
| MOSFET option A | 3.3×3.3 DFN, 40 V, R_DS(on),25°C = 1.8 mΩ | Typical of 20×20 boards |
| MOSFET option B | 5×6 DFN, 40 V, R_DS(on),25°C = 0.8 mΩ | Requires a 30.5×30.5 board |
| Board | 30.5×30.5 mm, 8 layers, 2 oz copper | |

> **Feasibility verdict (detailed in §3).** A true "nano" (20×20 mm) board cannot survive 80 A per motor beyond about 1 s. On a 30.5×30.5 board with 5×6 mm FETs, 80 A per motor is achievable as a **~3 s burst**. Sustainable continuous current
