# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design (Job #47)

I don't have the Job #47 hardware spec, so this design uses the assumptions below. Every one is a single constant in the code.

| Parameter | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7, slots N_s = 12), R ≈ 10 Ω, L ≈ 3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MA730 class) |
| Current sensing | 2-shunt inline, synchronous ADC sampling at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, FIFO disabled, DRDY interrupt |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle 1 kHz · Fusion 8 kHz pre-filter, 1 kHz attitude |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

## 1. FOC Inner Loop (20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$
Here θ_off is found at commissioning by applying v_d > 0 at θ_e = 0 and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the dq frame
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Electromagnetic torque (SPM machine):
$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.5 Current PI with decoupling and back-EMF feedforward

Tune by pole-zero cancellation for a closed-loop bandwidth ω_c (choose ω_c = 2π·1.5 kHz, which is below f_s/10):
$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c$$

The loop then reduces to a first-order lag, $i_q/i_q^* = \omega_c/(s+\omega_c)$.

Control laws:
$$v_d^* = \text{PI}_d(0 - i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

### 1.6 Voltage limiting with circular saturation and anti-windup

Limit the voltage vector to the linear SVPWM region, $V_{max} = V_{bus}/\sqrt3$. Give d-axis priority:
$$v_d^{sat} = \text{clamp}(v_d^*, \pm V_{max}),\qquad v_q^{sat} = \text{clamp}\!\left(v_q^*, \pm\sqrt{V_{max}^2 - (v_d^{sat})^2}\right)$$

The integrator uses back-calculation:
$$\dot x_I = K_i e + K_{aw}(v^{sat} - v^*),\qquad K_{aw} = K_i/K_p$$

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)

Inverse Park:
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

Inverse Clarke:
$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence injection and duty cycles:
$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.8 Delay compensation

Total delay is computation plus PWM, about 1.5·T_s. Advance the angle used in the inverse Park by:
$$\theta_e^{\text{inv}} = \theta_e + 1.5\,T_s\,\omega_e$$

## 2. Cascaded Stabilization Control

### 2.1 Structure

```
θ_cam* ─►[Angle P(+I), 1 kHz]─►ω* ─►[Velocity PI, 4 kHz]─►τ* ─►[÷K_t]─►i_q* ─►[FOC 20 kHz]
   ▲            ▲ feedforward ω_ff          ▲ feedforward J·α_ff + τ_cog(θ_m) + τ_fric
   │                                        │
 IMU attitude (per-joint)            gyro-blended joint rate
```

**Bandwidth separation:** each loop is about 4–5× slower than the loop inside it.
- Current loop: ~1.5 kHz
- Velocity loop: ~150 Hz
- Angle loop: ~30 Hz

### 2.2 Mapping camera attitude to joints

For yaw (ψ, z) → roll (φ, x) → pitch (θ, y), the camera angular velocity in the camera frame is:
$$\boldsymbol\omega_c = R_y(\theta)^T R_x(\phi)^T\begin{bmatrix}0\\0\\\dot\psi\end{bmatrix} + R_y(\theta)^T\begin{bmatrix}\dot\phi\\0\\0\end{bmatrix} + \begin{bmatrix}0\\\dot\theta\\0\end{bmatrix} + \boldsymbol\omega_{\text{base}}^{c}$$

Collect the joint-rate terms as $\boldsymbol\omega_c = J(\phi,\theta)\,\dot{\mathbf q} + \boldsymbol\omega_{base}^c$, with $\dot{\mathbf q} = [\dot\psi, \dot\phi, \dot\theta]^T$:
$$J = \begin{bmatrix} -\cos\phi\sin\theta & \cos\theta & 0\\ \sin\phi & 0 & 1\\ \cos\phi\cos\theta & \sin\theta & 0\end{bmatrix}$$

**Attitude error in joint space.** With camera quaternion q and setpoint q*, take the small-angle error vector $\mathbf e_c = 2\,\text{sgn}(q_{e,w})\,\text{vec}(q^{*-1}\otimes q)$. Then:
$$\mathbf e_q = J^{-1}\mathbf e_c$$

$\det J = -\cos\phi$, so J is invertible unless roll reaches ±90°. Clamp roll to ±60° in the planner.
