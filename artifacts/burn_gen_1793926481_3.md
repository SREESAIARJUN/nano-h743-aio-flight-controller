## 1. FOC Core Equations

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

`θ_offset` is found at startup by locking the rotor: apply V_d at θ_e = 0 and read the encoder.

### 1.2 Clarke transform (amplitude-invariant, assumes i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Motor model in the dq frame (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.5 Current PI controllers (pole–zero cancellation)

The plant is $G_i(s) = \frac{1}{Ls + R}$. Choose:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

This makes the closed loop first-order with bandwidth ω_ci. Pick ω_ci ≤ 2π·f_PWM/20, i.e. ≈ 2π·1000 rad/s at 20 kHz.

Decoupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

### 1.6 Voltage limiting

Use circular limiting with d-axis priority:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

$$v_q^{max} = \sqrt{(V_{bus}/\sqrt3)^2 - v_d^2}$$

### 1.7 SVPWM via min-max zero-sequence injection

This is equivalent to classical 7-segment SVPWM.

$$v_{a,b,c} = \text{invClarke}(\text{invPark}(v_d, v_q))$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Angle → Velocity → Current Control

```
θ* ──►[Angle P + vel FF]──ω*──►[Velocity PI + accel FF]──i_q*──►(+ i_cog_ff)──►[Current PI]──►SVPWM
      ▲ θ̂ (IMU-fused,             ▲ ω̂ (PLL observer               ▲ i_q (shunts)
      │  1 kHz)                   │  + gyro blend, 4 kHz)          │ 20 kHz
```

### 2.1 Velocity estimation: encoder PLL tracking observer

Finite-differencing a 14-bit encoder at 20 kHz gives roughly 1.5 rad/s of quantization noise, which is unusable for a gimbal. Use a type-II PLL instead:

$$e_k = \text{wrap}_\pi(\theta_{m,k} - \hat\theta_k)$$
$$\hat\omega_{k+1} = \hat\omega_k + K_{i,pll}\,T_s\,e_k$$
$$\hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + K_{p,pll}\,e_k)$$
