# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #7 specification, so the design below uses the assumptions in §0. Every gain is derived from motor and inertia parameters, so you can substitute your real values directly.

---

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class: Cortex-M4F/M7, single-precision FPU, 3 ADC-triggered PWM timers |
| Motors | Gimbal PMSM, 12N14P (pole pairs p = 7), R = 5.6 Ω, L_d ≈ L_q = 1.8 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), one per axis |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, FIFO off, DRDY interrupt |
| Kinematics | Yaw (z, base) → Roll (x) → Pitch (y, camera) |

**Loop rates**

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | 20 kHz | PWM-center ADC ISR |
| Rate (velocity) | 4 kHz | IMU DRDY at 8 kHz, decimated ×2 |
| Attitude (angle) + fusion | 1 kHz | Task |
| Cogging LMS adaptation | 1 kHz | Background, only when enabled |

**Signal flow**

```
 att* ──►[Angle P + FF]──ω*_cam──►[J⁻¹(q)]──q̇*──►[Rate PI]──τ*──►(÷Kt)──i_q*──┐
   ▲                                  ▲                                         │ + i_q,cog(θ_m)
   │ q̂ (Mahony)                       │ q̇_meas = J⁻¹(q)·ω_gyro                  ▼
 [Dual-IMU fusion]◄── notch/LPF ◄── IMU A, IMU B                     [Current PI d/q + decoupling]
                                                                              │ SVPWM
                                      encoder θ_m ──► PLL ──► θ_e, ω_m ───────┘
```

The rate loop is closed on the **inertial gyro rate mapped into joint space**, not on encoder velocity. This is what gives stabilization: base disturbances appear immediately as error. The encoders provide commutation, cogging phase, and the Jacobian.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms (amplitude-invariant)

**Clarke transform**, using i_a + i_b + i_c = 0:

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_off:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park transform**:

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 1.2 Plant in the d-q frame

$$
v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q
$$

$$
v_q = R i_q + L_q\dot i_q + \omega_e(L_d i_d + \lambda_m)
$$

Torque:

$$
\tau = \tfrac32 p\left[\lambda_m i_q + (L_d - L_q) i_d i_q\right] \;\approx\; K_t i_q,\qquad K_t = \tfrac32 p\lambda_m
$$

### 1.3 PI control with decoupling feedforward

$$
v_d^* = \text{PI}_d(i_d^* - i_d) - \hat\omega_e L_q i_q
$$

$$
v_q^* = \text{PI}_q(i_q^* - i_q) + \hat\omega_e(L_d i_d + \lambda_m)
$$

The decoupling terms make each axis a first-order plant, 1/(Ls + R). Pole-zero cancellation then gives a closed-loop bandwidth of ω_c:

$$
K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c
$$

so that

$$
\frac{i}{i^*} = \frac{\omega_c}{s + \omega_c}
$$

Choose ω_c ≤ 2π·f_PWM/20. With f_PWM = 20 kHz, f_c ≈ 1 kHz, so ω_c = 6283 rad/s, K_p = 11.3 V/A, and K_i = 35 186 V/(A·s).
