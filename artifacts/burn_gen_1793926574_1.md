# STM32H743 FC + 4-in-1 ESC Stack: Electro-Thermal Model and DShot Architecture (Job #21)

## 0. Scope Corrections and Assumptions

Some framing issues affect the design, so they come first.

1. **The H743 does not run the ESC.** In a 4-in-1 stack, the STM32H743 is the flight controller running ArduPilot. Each ESC channel runs its own MCU, typically an AT32F421 or STM32G071 with AM32, or an EFM8 with BLHeli_S. BLHeli_32 is discontinued. Bidirectional DShot is the link between them.
2. **"80 A burst" in a nano (20×20 mm) footprint is not thermally credible beyond a few seconds.** The model below shows this quantitatively.
3. **Every parameter is a stated assumption.** Replace them with datasheet values for your actual MOSFET and gate driver before signing off.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Battery (6S, full) | V_bus | 25.2 V |

## 1. Conduction Loss Model

**Current path.** In 6-step operation with synchronous rectification, phase current flows through one high-side FET (phase A) and one low-side FET (phase B) at all times. In the PWM leg, the high-side and low-side FETs share the period as D and 1−D, so the conducting path always contains two FETs.

**Conduction loss per channel:**

$$P_{cond} = 2\,I^2\,R_{DS(on)}(T_j), \qquad R_{DS(on)}(T_j) = R_{25}\left[1+\alpha(T_j-25)\right]$$

At T_j = 125 °C:

- R = 1.0 mΩ × 1.45 = **1.45 mΩ**
- Per FET: P = 80² × 1.45×10⁻³ = **9.28 W**
- Per channel: **18.6 W**

**Copper and shunt losses (add these separately):**

- Power-plane resistance per channel path is about 0.2 mΩ, adding roughly 1.3 W per channel.
- A single 0.25 mΩ total-current shunt would carry 320 A. It would dissipate 25.6 W, which is impossible. Use a low-side shunt per channel, or estimate current from R_DS(on).

## 2. Switching Loss Model at 48 kHz

| Mechanism | Equation | Value per channel |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw | ½ × 25.2 × 80 × 40 ns × 48 k = **1.94 W** |
| Reverse recovery | Q_rr·V·f_sw | 50 nC × 25.2 × 48 k = **0.06 W** |
| Coss charging | ½·Q_oss·V·f_sw | **0.02 W** |
| Dead-time diode conduction | V_f·I·2·t_dt·f_sw | 0.8 × 80 × 400 ns × 48 k = **1.23 W** |
| Gate drive (2 switching FETs, dissipated in driver/R_g) | 2·Q_g·V_gs·f_sw | **0.04 W** |
| **Total switching** | | **≈ 3.3 W** |

**Per-channel total:** P_ch ≈ 18.6 + 3.3 + 1.3 ≈ **23.2 W**

**Board total (4 channels):** P_tot ≈ **93 W**

**Design levers:**

- Dead-time loss is about 38% of switching loss. Reducing dead time to 100 ns via AM32 settings saves about 0.6 W per channel. Verify shoot-through margin with a scope first.
- Overlap loss scales linearly with f_sw. At 24 kHz it halves (about 1 W saved per channel), at the cost of more current ripple in low-inductance motors.

## 3. Thermal Model

### 3.1 Junction-to-board (fast, ms time constant)

Using R_θJC ≈ 1.5 K/W per FET:

$$\Delta T_{jc} = (9.28 + \sim0.8) \times 1.5 \approx 15\ \text{K}$$

The junction runs about 15 K above the copper under it.

### 3.2 Board-level transient (dominant, seconds)

**Board heat capacity:**

- Copper: 9.3 cm² × 8 layers × 70 µm × 8.96 g/cm³ ≈ 4.7 g, so ≈ 1.8 J/K
- FR4: ≈ 2.75 g × 1.1 J/g·K ≈ 3.0 J/K
- Total: **C_th ≈ 5 J/K** (excluding motor wires and the FC)

**Convection** (prop-wash h ≈ 100 W/m²·K, both faces, 18.6 cm²):

$$R_{conv} = \frac{1}{hA} \approx 5.4\ \text{K/W}, \qquad \tau = R_{conv}\,C_{th} \approx 27\ \text{s}$$

**Board temperature over time:**

$$T_b(t) = T_a + P\,R_{conv}\left(1-e^{-t/\tau}\right)$$

**Junction temperature:**

$$T_j(t) = T_b(t) + \Delta T_{jc}$$
