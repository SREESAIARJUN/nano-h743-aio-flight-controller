# STM32H743 Nano FC + 4-in-1 ESC: Power-Stage, Thermal, and DShot Design Package

I don't have any prior project files for "Job #14", so this package is built on explicit assumptions (§0). Change any of them and the formulas still apply. Every number below is a parameterized estimate, not a measurement, and must be validated on hardware.

The main finding is in §3.5: **four channels at 80 A simultaneously cannot be sustained on a nano-format board.** The model shows a burst budget of about 1–2 s for all four channels together, or roughly 10 s for a single channel. The design has to be specified and firmware-limited accordingly.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

```
R_DS(T_j) = R₂₅ · [1 + α · (T_j − 25)]
```

At T_j = 100 °C: R = 1.0 mΩ × 1.3375 = **1.34 mΩ**
At T_j = 125 °C: R = **1.45 mΩ**

### 1.2 Current path in 6-step complementary PWM

At any instant, exactly two FETs carry the full phase current:
- **On-time (D):** HS of phase A and LS of phase B.
- **Off-time (1−D):** LS of phase A (synchronous rectification) and LS of phase B.

So the per-motor instantaneous conduction loss is independent of D:

```
P_cond,motor = 2 · I² · R_DS(T_j)
```

Over one electrical revolution each leg is active for 240° and floating for 120°. Each FET carries current for about 1/3 of the period, since the HS/LS split within a leg depends on D but sums to 2/3 of the period for the leg. The worst-case per-FET average at D → 1 is:

```
P_FET,avg ≈ I² · R_DS(T_j) / 3
```

### 1.3 Numbers at 80 A, T_j = 100 °C

```
P_cond,motor = 2 · 80² · 1.34e-3 = 17.1 W
P_FET,avg    = 6400 · 1.34e-3 / 3 = 2.86 W
P_cond,4ch   = 68.5 W
```

### 1.4 Electro-thermal feedback (fixed point)

R_DS depends on T_j, and T_j depends on P. Iterate:

```
T_j[n+1] = T_ref + P_FET(T_j[n]) · R_θ,j-ref
```

Runaway occurs if the loop gain reaches 1:

```
G = I² · R₂₅ · α · R_θ / 3 ≥ 1
```

For a single FET at 80 A with R_θ ≈ 5 K/W: G = 6400·1e-3·0.0045·5/3 ≈ 0.048. The single-FET loop is stable. Runaway risk comes from the board-level thermal mass saturating (§3), not from individual junctions.

## 2. Switching Loss Model at 48 kHz

Only one leg is PWM-switching at a time (the active HS/LS pair). The other active leg sits statically on its LS. Each term below is per motor.

### 2.1 V-I overlap (hard switching)

Switching time is set by the Miller plateau:

```
t_r ≈ t_f ≈ Q_gd / I_g + (Q_gs2 / I_g)  ≈ 6 nC / 1 A + ~4 ns ≈ 10 ns

P_VI = ½ · V_bus · I · (t_r + t_f) · f_sw
     = 0.5 · 25.2 · 80 · 20e-9 · 48e3 = 0.97 W
```
