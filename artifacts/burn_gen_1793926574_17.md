## 0. Scope, Assumptions, and a Topology Note

I don't have Job #10's actual BOM, stack-up, or enclosure, so all parameters below are stated explicitly. Swap in datasheet values and the equations still hold.

**Topology note.** The H743 does not commutate the MOSFETs. In every ArduPilot-compatible 4-in-1 design, the H743 sends bidirectional DShot600 to four ESC MCUs (AT32F421 running AM32, or BLHeli_32). Those MCUs generate the 48 kHz PWM. The architecture is:

```
STM32H743 ──DShot600 (bidir, 1-wire)──► 4× AT32F421 (AM32, 48 kHz PWM)
                                              │
                                        FD6288Q 3-ph gate driver
                                              │
                                        6× N-MOSFET per motor (24 total)
```

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current paths under six-step with synchronous rectification

During each 60° commutation sector, one phase is driven high (PWM), one is held low, and one floats. Take phase A switching against phase B low:

- **ON interval (duty D):** current flows through HS_A and LS_B.
- **OFF interval (1−D):** current freewheels through LS_A (synchronous) and LS_B.

```
P_cond,sector = I² · R_DS(T_j) · [D + (1−D)]_legA + I² · R_DS(T_j) · 1_legB
              = 2 · I² · R_DS(T_j)          (independent of D)
```

### 1.2 Temperature-corrected R_DS(on)

```
R_DS(T_j) = R_DS,25 · [1 + α (T_j − 25)]
At T_j = 100 °C:  R_DS = 1.0 mΩ × (1 + 0.0045 × 75) = 1.34 mΩ
```

### 1.3 Per-motor conduction loss

```
P_cond = 2 × 80² × 1.34e-3 = 17.1 W
```

### 1.4 PCB copper loss

Each phase path is about 12 mm of 3 oz copper, 4 mm wide, with 2 parallel layers:

```
R_Cu = ρ·L/(w·t·n) = 1.72e-8 × 0.012 / (0.004 × 105e-6 × 2) ≈ 0.25 mΩ  (per trace)
Two traces in path + bus share → ≈ 0.6 mΩ effective
P_Cu ≈ 80² × 0.6e-3 ≈ 3.8 W per motor
```

At 80 A, copper loss is not negligible. It is about 22% of MOSFET conduction loss. Note also that the B+ bus carries the sum of all four motors' DC current: I_bat ≈ ΣD·I.

### 1.5 Ripple correction

Phase inductance ripple adds an RMS term:

```
I_rms² = I² + ΔI²/12

ΔI = V_bus·D(1−D)/(L·f_sw)
   = 25.2 × 0.25 / (15 µH × 48 kHz) = 8.75 A p-p   (worst case, D = 0.5)
```

The correction is 8.75²/12 = 6.4 A², about 0.1% of 6400 A². This is negligible at 48 kHz, and it is the main argument for 48 kHz over 24 kHz.

## 2. Switching Loss Model at 48 kHz

Only the PWM-ing high-side switches hard. The synchronous low side switches at near-zero V_DS (ZVS after dead time), so it contributes dead-time and Q_rr loss instead.

### 2.1 Transition times (gate-charge method)

```
t_r ≈ (Q_gs2 + Q_gd) / I_g,src  = 12 nC / 1.0 A ≈ 12 ns
t_f ≈ (Q_gs2 + Q_gd) / I_g,sink = 12 nC / 1.2 A ≈ 10 ns
```

Use a ×1.5 layout and inductance margin, giving t_r + t_f ≈ 33 ns.

### 2.2 V-I overlap loss

```
P_sw = ½ · V_bus · I · (t_r + t_f) · f_sw
     = 0.5 × 25.2 × 80 × 33e-9 × 48e3 = 1.60 W
```

### 2.3 Dead-time body-diode conduction

There are two dead-time intervals per PWM period:

```
P_dt = V_SD · I · 2 · t_dt · f_sw = 0.8 × 80 × 2 × 100e-9 × 48e3 = 0.61 W
```

### 2.4 Reverse recovery and C_oss

```
P_rr   = Q_rr · V_bus · f_sw  = 40e-9 × 25.2 × 48e3 = 0.048 W
P_oss  = Q_oss · V_bus · f_sw = 20e-9 × 25.2 × 48e3 = 0.024 W
```

### 2.5 Gate drive (dissipated in driver and gate resistors, not the FET die)

Two FETs switch per PWM cycle (HS + sync LS):

```
P_gate = 2 · Q_g · V_GS · f_sw = 2 × 30e-9 × 10 × 48e3 = 0.029 W
```
