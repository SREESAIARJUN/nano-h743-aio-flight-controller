# STM32H743 Nano FC + 80A 4-in-1 ESC: System Design Package (Job #48)

## 0. Scope and Assumptions

I don't have the Job #48 BOM or layout, so this package is **parametric**. Every equation stands on its own, and the numeric results use the baseline below. Swap in your actual datasheet values and the conclusions scale directly.

**Architecture clarification.** The STM32H743 is the flight controller. It generates bi-directional DShot600 and runs ArduPilot. The 4-in-1 ESC has its own per-motor MCUs (assumed AT32F421 or STM32G071 running AM32/BLHeli_32), and those MCUs generate the 48 kHz motor PWM. The H743 never touches the 48 kHz PWM.

## 1. Conduction Loss Model (80A Burst)

**Temperature-dependent R_DS(on):**

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

At T_j = 100 °C: R = 1.2 × 1.3375 = **1.605 mΩ**

**Current path.** In 6-step trapezoidal commutation with synchronous rectification, the current always flows through exactly two FET channels in series:
- the high-side or low-side pair in the PWM leg, which complement each other, and
- the static low-side FET in the return leg.

So the conduction loss is independent of duty cycle D:

$$P_{cond,motor} = 2\,I^2\,R_{DS}(T_j) = 2(80)^2(1.605\text{ m}\Omega) = \mathbf{20.5\ W}$$

**Per FET.** Each of the six FETs carries one third of the electrical cycle, so the averaged loss is:

$$P_{cond,FET} \approx \tfrac{1}{6}P_{cond,motor} = 3.4\ \text{W}$$

The worst-case FET loss approaches I²R/3 ≈ 3.4 W in "PWM-high / LS-on" schemes. Hot-spotting depends on the AM32 PWM mode.

**Copper parasitics.** Add I²·R_trace. With roughly 0.3 mΩ of phase-plus-ground path:

$$P_{Cu} = 6400 \times 0.3\text{ m}\Omega \approx 1.9\ \text{W per motor}$$

This loss is spread across the board, and it is not negligible.

**Iterative coupling.** T_j depends on P, and P depends on R(T_j). Solve the loop by iteration:

$$T_j^{(k+1)} = T_B + P(T_j^{(k)})\,(R_{\theta JC}+R_{\theta CB})$$

It converges in 2–3 iterations for these values.

## 2. Switching Loss Model at 48 kHz

Only one leg per motor hard-switches per PWM period. The loss terms per motor are:

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½ V I (t_r+t_f) f_sw = ½ (25.2)(80)(30 ns)(48 k) | 1.452 W |
| Dead-time diode conduction | V_f I (2 t_dt) f_sw = 0.8 (80)(200 ns)(48 k) | 0.614 W |
| Reverse recovery | Q_rr V f_sw = 30 nC (25.2)(48 k) | 0.036 W |
| Output capacitance | Q_oss V f_sw | 0.030 W |
| Gate drive (2 FETs, dissipated mostly in driver and R_g) | 2 Q_g V_g f_sw | 0.038 W |
| **Total switching** | | **≈ 2.17 W/motor** |

**Sensitivities:**
- **Dead time:** this is the largest knob after edge rate. Cutting t_dt from 100 ns to 50 ns saves about 0.3 W per motor.
- **Frequency:** going from 48 kHz to 24 kHz halves P_sw, but costs current ripple and acoustic performance.
- **Bus voltage:** P_sw scales linearly with V_bus. On 4S (16.8 V) it drops to about 1.5 W.
