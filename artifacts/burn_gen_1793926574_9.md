**Risk flag:** 80 A per channel on a "nano" (20×20 mm) board is not physically credible. Four simultaneous 80 A bursts dissipate about 68 W (see §1.4). That is more than a 20×20 board can absorb for useful durations. The calculation below uses a 30.5×30.5 board. If the board must be 20×20, treat 80 A as a single-motor transient rating, not a simultaneous one.

## 1. Power Stage Loss Model (Per Motor Channel)

### 1.1 Conduction Model for 6-Step Commutation with Complementary PWM

In any commutation sector, two phases carry current I:

- Phase X high-side: duty D
- Phase X low-side (synchronous rectification): 1 − D
- Phase Y low-side: fully on

Conduction loss per channel is therefore:

$$P_{cond} = I^2 R_{hot}\,[D + (1-D) + 1] = 2\,I^2 R_{hot}$$

Note that this result is independent of D (ripple ignored).

Temperature-adjusted resistance, with α ≈ 0.0045 /K **[A]**:

$$R_{hot} = R_{25}\,[1 + \alpha (T_j - 25)] + R_{cu}$$

- At T_j = 110 °C: R_DS = 0.80 × 1.38 = **1.10 mΩ**
- Copper and solder per current path, R_cu ≈ 0.05 mΩ **[A]**
- R_hot ≈ **1.15 mΩ**

$$P_{cond} = 2 \times 80^2 \times 1.15\times10^{-3} = \mathbf{14.7\ W}$$

**Ripple correction.** Use I_rms² = I² + ΔI²/12. With phase inductance L = 20 µH **[A]**, ΔI_pp = V·D(1−D)/(L·f). At D = 0.5 this is 22.2 × 0.25 / (20e-6 × 48e3) ≈ 5.8 A. The correction is +0.04 %, which is negligible. On low-inductance motors (< 5 µH) it is no longer negligible, so recompute.

**Per-FET loss.** Each FET serves 1/3 of the electrical cycle in each role. Average conduction per FET ≈ 14.7 / 6 ≈ **2.45 W**. The instantaneous peak in the "fully on" role is I²R = **7.4 W**.

### 1.2 Switching Losses at 48 kHz

Only the PWM'd leg switches hard. Loss components:

**1. V–I overlap (hard switching)**

$$P_{sw} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw}$$

Take t_r ≈ t_f ≈ Q_gd / I_gate. With Q_gd = 15 nC and 1.0 A effective gate current, t ≈ 15 ns.

P_sw = 0.5 × 25.2 × 80 × 30e-9 × 48e3 = **1.45 W**

**2. Output capacitance**

$$P_{oss} = Q_{oss} V_{bus} f = 40\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.048\ W}$$

**3. Dead-time body-diode conduction**

$$P_{dt} = V_f I \cdot 2 t_{dt} f = 0.8 \times 80 \times 2(100\text{ns}) \times 48\text{k} = \mathbf{0.61\ W}$$

**4. Reverse recovery**

$$P_{rr} = Q_{rr} V_{bus} f = 50\text{n}\times25.2\times48\text{k} = \mathbf{0.060\ W}$$

**5. Gate drive** (dissipated mostly in the driver and gate resistors)

$$P_g = Q_g V_{GS} f = 60\text{n}\times10\times48\text{k} = 29\text{ mW per switching FET pair}$$

**Switching total ≈ 2.2 W per channel.**

Dead time costs nearly half as much as hard switching. Cutting t_dt from 100 ns to 50 ns saves about 0.3 W per channel, but only if the driver's propagation-delay mismatch allows it.
