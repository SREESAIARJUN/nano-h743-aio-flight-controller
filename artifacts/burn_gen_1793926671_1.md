# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion Design

I don't have the Job #27 specification, so this design uses the assumptions below. Every parameter is a named constant in `GimbalConfig` so you can substitute your real values. Where a value depends on hardware I don't know (motor constants, frame resonances), I state how to measure it.

## 0. Assumptions & Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | BLDC gimbal motor, 12N14P (7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.1 N·m/A |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701 class), SPI |
| Current sensing | 2 low-side or inline shunts per motor |
| MCU | STM32G4/H7 class (FPU, ≥170 MHz), center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, mounted symmetrically about the roll/pitch intersection |

**Loop rates (per axis):**

```
Attitude (1 kHz)  : quaternion error → joint angle setpoint θ*
Angle loop (2 kHz): P + velocity FF  → ω*
Velocity (8 kHz)  : PI + accel FF    → iq*
Current (20 kHz)  : PI dq + decoupling + cogging FF → SVPWM
IMU (8 kHz)       : dual fusion, notch filters, gyro → velocity-loop damping
```

Each loop's bandwidth is set 4–10× below the loop inside it. This lets each inner loop be treated as unity gain when you design the loop outside it.

## 1. FOC Current Loop

### 1.1 Transforms
Electrical angle:

$$\theta_e = p\,\theta_m - \theta_{e,0} \pmod{2\pi}$$

Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI tuning
The PMSM dq voltage equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e(L i_d + \lambda_m)$$

Decoupling feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m)$$

With this feedforward applied, each axis reduces to $\frac{1}{Ls+R}$. A PI controller $K_p + K_i/s$ tuned by pole-zero cancellation gives:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; \frac{I}{I^*}=\frac{\omega_c}{s+\omega_c}$$

Choose $\omega_c \le 2\pi f_{pwm}/20$. At 20 kHz this gives about 2π·1 kHz.

### 1.3 Voltage limiting and SVPWM
Circular limit:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

Priority goes to $v_d$, and $v_q$ gets the remainder.

Inverse Park, then inverse Clarke:

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

Min-max zero-sequence injection (equivalent to SVPWM):

$$v_0 = -\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Angle / Velocity Control

### 2.1 Mechanical plant
$$J\dot\omega = K_t\, i_q - B\omega - \tau_{cog}(\theta) - \tau_{d}$$

### 2.2 Velocity loop (PI with feedforward)
$$i_q^* = \underbrace{K_{pv} e_\omega + K_{iv}\!\int e_\omega\,dt}_{\text{feedback}} + \underbrace{\frac{J\,\dot\omega^*}{K_t}}_{\text{accel FF}} + \underbrace{i_{q,cog}^{ff}(\theta)}_{\text{§3}}, \qquad e_\omega=\omega^*-\omega$$

Tuning (symmetric optimum, with the current loop treated as unity):

$$K_{pv} = \frac{J\,\omega_v}{K_t},\qquad K_{iv} = \frac{K_{pv}\,\omega_v}{a^2},\quad a \approx 2\text{–}3$$

Use $\omega_v \approx \omega_c/8$. That is about 2π·120 Hz for a stiff frame, and should be lower if the structural modes are low.
