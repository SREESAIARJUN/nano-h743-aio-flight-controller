# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #46)

## 0. Design Assumptions

I don't have the Job #46 specification, so the design rests on the assumptions below. Every value is a named constant in the code, so you can change any that differ.

| Item | Assumption |
|---|---|
| MCU | Cortex-M4F/M7 or STM32G4-class with single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Motor current sensing | 2 or 3 inline/low-side shunts. A voltage-mode fallback is provided. |
| Rotor encoder | 14-bit absolute magnetic encoder (AS5048A or MT6701), one per axis |
| IMUs | 2× ICM-42688-P on the camera plate, mirrored about the plate centroid (r₂ = −r₁), SPI, 8 kHz ODR |
| Loop rates | Current 20 kHz. Velocity 4 kHz. Angle 1 kHz. IMU fusion 1 kHz (decimated from 8 kHz). |
| Gimbal order | Yaw → Roll → Pitch (base to camera) |

## 1. FOC Inner Current Loop (20 kHz)

### 1.1 Transforms

The electrical angle is θₑ = p·(θₘ − θ_offset).

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 SVPWM by Min-Max Zero-Sequence Injection

This method is equivalent to classical 7-segment SVPWM.

1. Compute the phase voltages:
   - v_a = v_α
   - v_b = −½v_α + (√3/2)v_β
   - v_c = −½v_α − (√3/2)v_β
2. Compute the zero-sequence offset: v₀ = −(max + min)/2.
3. Compute the duty cycles: Dₓ = ½ + (vₓ + v₀)/V_bus.

The linear range is |v_dq| ≤ V_bus/√3. Limit the voltage vector with a circular clamp that preserves direction, giving d-axis priority.

### 1.3 Plant and Current PI Design

The dq motor model is:

$$L\dot i_d = v_d - R i_d + \omega_e L i_q,\qquad L\dot i_q = v_q - R i_q - \omega_e L i_d - \omega_e\lambda$$

**Decoupling feedforward.** Add these terms to the PI outputs:
- v_d,ff = −ω_e L i_q
- v_q,ff = ω_e(L i_d + λ)

After decoupling, each axis reduces to 1/(Ls + R).

**PI tuning by pole-zero cancellation.** Use C(s) = K_p + K_i/s with:
- K_p = L·ω_c
- K_i = R·ω_c

This makes the closed loop first order: ω_c/(s + ω_c).
