# 3-Axis Gimbal: FOC Control, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

## 0. Assumptions

I have no access to Job #55's specification, so the design uses typical brushless-gimbal values. Every value below is a constant in the code and can be changed.

| Item | Assumed value |
|---|---|
| Motor | 12N14P outrunner gimbal motor, pole pairs p = 7 |
| Motor parameters | R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701 class) on each axis |
| Current sense | 2-shunt inline or low-side sensing, synchronous with PWM centre |
| MCU | Cortex-M4F/M7 or equivalent with single-precision FPU |
| Loop rates | PWM/current loop 20 kHz; rate loop 4 kHz; attitude loop 1 kHz |
| IMU rate | 8 kHz output data rate |
| IMUs | 2 × ICM-42688-P on the camera plate, rigidly mounted at known lever arms r₁, r₂ |

A key architectural point for gimbals: **the velocity loop must close on inertial rate (gyro), not encoder rate.** The encoder is used for commutation, for observing joint rate, and for follow/lock modes. Stabilisation comes from the gyro.

```
                 1 kHz                    4 kHz                      20 kHz
 q_ref ──►[Attitude P + FF]──ω_ref──►[Rate PI-D + FF]──iq_ref──►[Current PI dq + decoupling]──►SVPWM──►Motor
              ▲   (quaternion error,      ▲  (gyro → joint axis     ▲   ▲
              │    Jacobian to joints)    │   via Jacobian)         │   └─ i_q,cog feedforward(θm)
          q̂ (Mahony)                ω̂_joint                      i_abc, θe (encoder)
              ▲                           ▲
        [Dual-IMU fusion: align → lever-arm → notch/LPF → consistency check → weighted mean]
```
