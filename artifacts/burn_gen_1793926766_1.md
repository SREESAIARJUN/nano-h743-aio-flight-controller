# STM32H743 AIO Flight Controller with 4-in-1 ESC: Reference Design Model

## 0. Scope, Assumptions and Key Findings

This document gives a complete derivation using a defined reference bill of materials. The numbers are only as good as the inputs. **Replace every parameter marked ⚠ with values from your actual MOSFET datasheet, PCB stackup and thermal test data before committing to layout.**

| Parameter | Assumed value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V (max), 22.2 V (nominal) |
| Burst current | 80 A RMS phase current **per ESC channel**, 10 s burst |
| PWM frequency | 48 kHz, complementary (synchronous rectification), 6-step trapezoidal |
| MOSFET ⚠ | 40 V N-channel, PDFN 3.3×3.3 mm. R_ds(on) = 1.2 mΩ at 25 °C (V_gs = 10 V). Q_g = 50 nC, Q_rr = 50 nC, C_oss = 2 nF |
| Board ⚠ | 30.5×30.5 mm mounting, 36×36 mm outline, 8-layer, 2 oz copper on all layers |
| FC firmware | ArduPilot, bi-directional DShot600 |
| ESC firmware | AM32 on 4× AT32F421 (one MCU per channel) |

**Key findings:**

1. **80 A per channel is not thermally survivable on a nano/AIO board for 10 s.** The adiabatic temperature rise is about 21 K/s (Section 2.6). The realistic limit is roughly 1.5–2 s at 80 A, or about 40–45 A continuous with strong prop-wash cooling. Either derate the specification or move to a 30×30 standalone ESC with a heatsink.
2. **The STM32H743 does not drive the MOSFETs.** It generates DShot. Each ESC channel has its own MCU and gate driver. The netlist reflects this partition.

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step complementary PWM

During any 60° commutation sector, current flows from phase X to phase Y:

- **On-time (duty D):** HS_X → motor → LS_Y
- **Off-time (1−D):** LS_X (synchronous rectification) → motor → LS_Y

Each state therefore places **two MOSFETs in series** with the phase current I:

$$P_{cond,ch} = 2\,I^2\,R_{ds(on)}(T_j)$$

This holds independent of D, because synchronous rectification replaces diode conduction.

### 1.2 Temperature dependence of R_ds(on)

$$R_{ds(on)}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.006\,/\mathrm{K}$$

At T_j = 125 °C: R ≈ 1.2 mΩ × 1.6 = **1.92 mΩ** ⚠.

### 1.3 Numbers at 80 A

$$P_{cond,ch} = 2 \times 80^2 \times 1.92\,\mathrm{m\Omega} = 24.6\ \mathrm{W}$$

Add PCB copper resistance. The phase trace plus bus path is about 0.3 mΩ ⚠:

$$P_{Cu} = I^2 R_{Cu} = 6400 \times 0.3\,\mathrm{m\Omega} = 1.9\ \mathrm{W}$$

### 1.4 Thermal runaway check

Because R_ds rises with T_j, the conduction loss feeds back on itself:

$$P(T_j) = P_0[1+\alpha(T_j-25)], \qquad T_j = T_a + R_{th}\,P(T_j)$$

$$\Rightarrow T_j = \frac{T_a + R_{th}P_0(1-25\alpha)}{1 - \alpha R_{th} P_0}$$

The system is **stable only if α·R_th·P₀ < 1**. With P₀ = 15.4 W per channel (25 °C value), the effective board-to-air R_th must be below 1/(0.006 × 15.4) ≈ **10.8 K/W per channel**. That bound is met in steady airflow, but the margin is poor.

## 2. Switching Loss Model (f_sw = 48 kHz)

Only the PWM-ed high-side FET hard-switches. Its complementary low-side FET commutates through its body diode during dead time.

### 2.1 Hard-switching overlap loss

$$P_{sw} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw}$$

With t_r + t_f ≈ 30 ns ⚠. This depends on the gate driver: the FD6288Q sources/sinks about 1.5/1.8 A with a 10 Ω gate resistor.

$$P_{sw} = 0.5 \times 25.2 \times 80 \times 30\,\mathrm{ns} \times 48\,\mathrm{kHz} = 1.45\ \mathrm{W}$$

### 2.2 Dead-time body-diode conduction

Two dead-time intervals occur per PWM period, each t_dt = 100 ns ⚠, with V_f = 0.8 V:

$$P_{dt} = V_f\,I\,(2t_{dt})\,f_{sw} = 0.8 \times 80 \times 200\,\mathrm{ns} \times 48\,\mathrm{kHz} = 0.61\ \mathrm{W}$$

### 2.3 Reverse recovery

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\,\mathrm{nC} \times 25.2 \times 48\,\mathrm{k} = 0.06\ \mathrm{W}$$

### 2.4 Output capacitance

$$P_{oss} = \tfrac{1}{2} C_{oss} V_{bus}^2 f_{sw} = 0.5 \times 2\,\mathrm{nF} \times 635 \times 48\,\mathrm{k} = 0.03\ \mathrm{W}$$

### 2.5 Gate drive

This loss is taken from the driver supply, not the FETs. Two FETs toggle per PWM cycle:

$$P_{g} = 2\,Q_g V_{gs} f_{sw} = 2 \times 50\,\mathrm{nC} \times 10 \times 48\,\mathrm{k} = 0.05\ \mathrm{W}$$
