## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$
θ_off is found at commissioning by applying a d-axis voltage vector and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant (SPMSM, L_d = L_q = L)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.5 Current PI with decoupling feedforward
$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e(L i_d + \lambda_m)$$

**Gain design by pole–zero cancellation.** After decoupling, the plant is G(s) = 1/(Ls+R). Choosing

$$K_p = L\,\omega_{c},\qquad K_i = R\,\omega_{c}$$

gives a closed loop of ω_c/(s+ω_c). Pick ω_c ≤ 2π·f_pwm/10 to stay clear of the PWM delay. With f_pwm = 20 kHz, use ω_c = 2π·1500 rad/s.

> **Note:** Gimbal motors with R ≈ 10 Ω are often run in voltage mode (v_q = R i_q* + ω_e λ_m), with no current sensing. The code supports both modes via `kUseCurrentSensing`.

### 1.6 Voltage limiting and inverse Park
Clamp to the linear SVPWM hexagon's inscribed circle:

$$V_{\max} = V_{bus}/\sqrt3$$

If |v_dq| > V_max, prioritize v_d, then give v_q the remainder:

$$v_q \le \sqrt{V_{\max}^2 - v_d^2}$$

Inverse Park:
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.7 SVPWM via min–max zero-sequence injection
Inverse Clarke:
$$v_a = v_\alpha$$
$$v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta$$
$$v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence offset and duty cycles:
$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM and avoids branches.
