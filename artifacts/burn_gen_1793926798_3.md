## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH **[VERIFY]** |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), SPI |
| MCU | Cortex-M4F/M7 or STM32G4 class, single-precision FPU |
| Current sensing | Low-side or inline shunts, two phases sampled |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, synchronised by an external clock (CLKIN) |
| Loop rates | Current loop 20 kHz, velocity loop 4 kHz, angle loop 1 kHz, attitude fusion 1–2 kHz |

### Control hierarchy

The angle loop sends a joint-rate command to the velocity loop, which sends `i_q*` to the current loop. The anti-cogging feedforward is added between the velocity loop and the current loop.

```
                          ┌──────────── Anti-cogging FF (AFC) ◄── θ_m ───┐
                          │                                               │
q_ref ─►[Attitude P]─► ω_cam* ─►[J⁻¹(φ)]─► φ̇* ─►[Velocity PI]─(+)─► i_q* ─►[Current PI + decoupling]─► SVPWM ─► Motor
            ▲                                     ▲                          ▲
            │                                     │                          │
   q̂ (Mahony, dual-IMU)                 φ̇ from encoder PLL           i_a, i_b (shunts)
            ▲                           or J⁻¹·ω_gyro
            │
   IMU1 ─┐
         ├─[frame align]─[AAF/LPF]─[dynamic notch]─[inverse-variance fusion + fault detection]
   IMU2 ─┘
```

## 1. Field-Oriented Control: the Current Loop (20 kHz)

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$
