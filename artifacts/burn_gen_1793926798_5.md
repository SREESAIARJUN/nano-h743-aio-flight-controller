## 0. Assumptions and Rate Plan

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC (e.g. GBM2804-class), 12N14P → pole pairs p = 7, slots Ns = 12 |
| Electrical | R ≈ 5–10 Ω, L ≈ 1–3 mH, λ (flux linkage) from Kv |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| Current sense | 2-phase low-side shunts + op-amp, ADC triggered at PWM center |
| MCU | STM32G4/H7 class with FPU (single-precision `float`) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries camera) |

**Rate plan.** Each loop is placed at least 4–10× below the one inside it in bandwidth.

| Loop | Execution rate | Closed-loop BW |
|---|---|---|
| PWM / current (FOC) | 20 kHz (Ts = 50 µs) | ~1.5–2 kHz |
| IMU sampling + filtering | 8 kHz | AAF ≈ 258 Hz |
| Velocity (rate) loop | 4 kHz | ~100–150 Hz |
| Angle / attitude loop | 1 kHz | ~10–25 Hz |
| AHRS (Mahony) | 1 kHz (gyro integrated at 8 kHz) | — |
