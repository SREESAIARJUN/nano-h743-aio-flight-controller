# STM32H743 AIO Flight Controller + 4-in-1 ESC: 80 A Burst Design Package

## 0. Scope, Architecture, and Assumptions

### 0.1 Architecture correction

The STM32H743 cannot directly commutate the four motors. The H743 runs ArduPilot and generates bi-directional DShot600. Each ESC channel needs its own commutation MCU running AM32 or BLHeli_32. The ESC MCU would typically be an AT32F421 or STM32G071, or a single quad-capable MCU per pair. All of the following assumes this split.

### 0.3 Red flag: 80 A × 4 on a nano board

At the burst condition, the board dissipates roughly 90 W (calculated below). This is only survivable as a time-limited burst. It is not a continuous rating. The numbers below quantify how long the burst can last.

## 1. Conduction Loss Model

Assume trapezoidal 6-step commutation with synchronous rectification (complementary PWM on the active leg). In every 60° sector, the current path always contains exactly two conducting devices:
- the high-side or its complementary low-side on the PWM leg, and
- the low-side on the return leg.

**Bridge conduction loss:**

$$P_{cond,bridge} = 2\,I^2\,R_{ds(on)}(T_j) + I^2 R_{Cu}$$

$$R_{ds(on)}(T_j) = R_{25}\,[1+\alpha(T_j-25)] \approx R_{25}\,k_T$$

**At 80 A, T_j = 125 °C:**

$$P_{cond} = 2(80)^2(1.0\text{ mΩ}\times1.6) = 20.5\ \text{W}$$

**Copper trace/plane loss:** with R_Cu ≈ 0.15 mΩ effective per path, add 80² × 0.15 mΩ ≈ 0.96 W.

**Per-FET cycle average:**

$$\bar P_{FET} \approx P_{cond}/6 \approx 3.4\ \text{W}$$

This average is valid because the electrical period (~1–3 kHz e-freq) is much shorter than the FET die thermal time constant (~ms).

**Duty split on the PWM leg:**
- High-side: D·I²R
- Low-side: (1−D)·I²R

At full throttle (D → 1) the high-side carries the loss. The worst-case single FET therefore sees about ½ × 20.5 W × (120°/360°) ≈ 3.4 W, consistent with the average.

## 2. Switching Loss Model @ 48 kHz

Only the PWM leg switches. One hard-switched commutation pair per PWM period applies.

**Transition times:**

$$t_r \approx \frac{Q_{gs2}+Q_{gd}}{I_{g,on}},\quad t_f \approx \frac{Q_{gs2}+Q_{gd}}{I_{g,off}}$$

With ~1 A of drive: t_r ≈ t_f ≈ 16 ns. Use 15 ns each.

### 2.1 Loss components

| Term | Formula | Value @ 80 A, 25.2 V |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw | ½·25.2·80·30 ns·48 k = **1.45 W** |
| Reverse recovery | Q_rr·V·f_sw | 40 nC·25.2·48 k = **0.05 W** |
| Output capacitance | ½·Q_oss·V·f_sw ×2 | **0.06 W** |
| Dead-time diode | V_f·I·2t_dt·f_sw | 0.8·80·200 ns·48 k = **0.61 W** |
| Gate drive (driver side) | Q_g·V_drv·f_sw ×2 switching FETs | 2·60 nC·10·48 k = **0.06 W** |
| **Subtotal** | | **≈ 2.2 W** |

### 2.2 Design note on 48 kHz

Dead-time loss is about 28% of switching loss. Cutting dead time to 50 ns saves ~0.3 W per channel. Only do this if your shoot-through margin, measured on the actual driver, supports it.

## 4. Thermal Model

### 4.1 Network

```
 P_FET ──[R_th(j–pcb)=1.2 K/W]──┬── T_pcb ──[R_th(pcb–a)=1.5 K/W]── T_amb
                                C_th = 5 J/K
```

### 4.2 Junction rise above board (steady per FET)

$$\Delta T_{j-pcb} = \bar P_{FET}\cdot R_{th(j-pcb)} \approx (3.4+0.37)\times1.2 \approx 4.5\ \text{K}$$

The junction is not the limit. The board's bulk temperature is.

### 4.3 Board transient (first-order)

$$T_{pcb}(t) = T_0 + P_{tot}R_{th(pcb-a)}\left(1-e^{-t/\tau}\right),\quad \tau = R_{th}C_{th} = 7.5\ \text{s}$$

- **Steady-state asymptote:** 101 × 1.5 = **+152 K**. Continuous 4×80 A is therefore impossible.
- **Burst time to limit**, solving for t:

$$t_{burst} = -\tau\ln\!\left(1-\frac{T_{lim}-T_0}{P_{tot}R_{th}}\right)$$

| Case | T_0 | T_lim | Allowed burst |
|---|---|---|---|
| 1 | 40 °C | 110 °C (FR4/solder margin) | t = −7.5·ln(1 − 70/152) ≈ **4.6 s** |
| 2 | 60 °C | 110 °C | t ≈ **3.0 s** |

The worst-case junction is then T_pcb + ~5 K ≈ 115 °C. That is consistent with the 1.6× R_ds(on) assumption. Iterate once if T_j differs materially.

### 4.4 Continuous rating

For T_pcb ≤ 100 °C at 40 °C ambient: P_tot ≤ 40 W. Solving 4·(2·I²·1.45 mΩ + overhead) ≈ 40 W gives **I_cont ≈ 45–50 A per channel**. Market it as "50 A continuous / 80 A 3–5 s burst."

### 4.5 Firmware protection

Configure the ESC's temperature-based current limit. Optionally run a host-side I²t estimator:

$$\int (I^2 - I_{cont}^2)\,dt \le (80^2-50^2)\times 4\ \text{s}$$
