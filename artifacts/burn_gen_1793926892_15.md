**Why the H743 does not commutate the motors.** The H743 has enough timers for 12 complementary PWM channels, but closing four sensorless BEMF loops on the flight MCU would harm ArduPilot scheduling determinism and split the safety domain. The industry-standard and ArduPilot-supported approach is FC → bidirectional DShot → per-motor ESC MCU. This package uses that approach.

## 1. Conduction Loss Model

### 1.1 Current paths per ESC (6-step, synchronous PWM)

In any 60° sector, phase A is PWM-driven (high-side duty D, low-side complementary for 1−D) and phase B's low-side is fully on:

$$P_{cond} = I_{rms}^2 R_{HS}D + I_{rms}^2 R_{LS}(1-D) + I_{rms}^2 R_{LS,B} = 2\,I_{rms}^2 R_{ds(on)}(T_j)$$

This result is independent of D when R_HS = R_LS.

### 1.2 Ripple correction

$$I_{rms}^2 = I_{DC}^2 + \frac{\Delta I^2}{12},\qquad \Delta I = \frac{(V_{bus}-V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

Example: L_ph = 15 µH and D = 0.5 at 80 A. With V_bus − V_bemf ≈ 4 V, ΔI ≈ 2.8 A. The ripple term is ≈ 0.65 A², which is negligible against 6400 A².

### 1.3 Temperature dependence

$$R_{ds(on)}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C, R = 1.5 mΩ.

### 1.4 Shunt and copper

- Shunt: P_sh = I²·R_sh = 6400 × 0.2 mΩ = **1.28 W**.
- Phase/bus copper: about 0.3 mΩ effective per path, so P_Cu ≈ **1.9 W**. This loss goes into the board, not the junctions.

### 1.5 Numbers at 80 A

| T_j | R_ds(on) | P_cond per ESC |
|---|---|---|
| 25 °C | 1.0 mΩ | 12.8 W |
| 100 °C | 1.375 mΩ | 17.6 W |
| 125 °C | 1.5 mΩ | **19.2 W** |

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. There is one hard-switched transition pair per period.

| Term | Formula | Value |
|---|---|---|
| V–I overlap | ½ V I (t_r + t_f) f_sw = ½ (25.2)(80)(20 ns)(48k) | **0.968 W** |
| Reverse recovery | Q_rr V f_sw = 30 nC × 25.2 × 48k | 0.036 W |
| Coss | ½ Q_oss V f_sw (×2 devices) | 0.048 W |
| Dead-time body diode | 2 V_f I t_dt f_sw = 2(0.8)(80)(50 ns)(48k) | 0.307 W |
| Gate drive (in driver, not FET) | Q_g V_GS f_sw × 2 = 50n × 10 × 48k × 2 | 0.048 W |

**Total switching loss per ESC ≈ 1.36 W** (FET-side ≈ 1.31 W).

Sensitivity: P_sw scales linearly with f_sw. Going to 96 kHz adds about 1.3 W per ESC. At 80 A, 48 kHz is the right compromise between current ripple and loss.

## 3. Total Loss Budget at 80 A Burst (T_j = 125 °C)

| Per ESC channel | W |
|---|---|
| Conduction (FETs) | 19.2 |
| Switching + diode + Coss + Qrr | 1.31 |
| Shunt | 1.28 |
| Copper | 1.9 |
| Driver + MCU + LDO | ~0.3 |
| **Per channel** | **~24.0** |
| **4 channels simultaneously** | **~96 W** |

This is 320 A from the pack, about 7 kW electrical, so efficiency is ≈ 98.6%. The absolute dissipation is nonetheless very large for a 13 cm² board.

| FETs, connectors, solder, pads | ~4 g | ~500 | 2.0 J/K |
| **C_board** | | | **≈ 8 J/K** |

### 4.2 Board-to-ambient

- Convection coefficient in prop wash: h ≈ 50 W/m²K.
- Area, both sides: A = 2.6e-3 m².
- R_ba = 1/(hA) ≈ **7.7 K/W**.
- Time constant: τ_b = R_ba·C ≈ **62 s**.

### 4.3 Junction-to-board, per FET

Each of the 6 FETs averages about 1/6 of channel FET loss over an electrical cycle at normal eRPM: (19.2 + 1.31)/6 ≈ **3.4 W per FET**.
