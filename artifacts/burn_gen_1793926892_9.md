# STM32H743 FC + 80 A 4-in-1 ESC (Job #16): Loss, Thermal and Bidirectional DShot Model

## 0. Scope and Two Key Findings

### Architecture

An STM32H743 cannot practically commutate four BLDC motors itself. No ArduPilot or AM32 firmware path supports this, and four sensorless FOC/six-step loops at 48 kHz PWM with zero-cross detection would consume the timer and ADC resources that ArduPilot needs.

So the model uses the industry-standard partition:

- **FC:** STM32H743 running ArduPilot. It sends DShot600 bidirectional to the ESC.
- **4-in-1 ESC:** 4× AT32F421 (or STM32G071) MCUs running AM32 at 48 kHz PWM, with 4× FD6288-class 3-phase gate drivers and 24× N-MOSFETs.

### Feasibility warning

80 A per motor is **thermally a burst rating only** on a nano (≈20–30 mm) board. The math in Section 3 shows roughly 135 W of dissipation at a simultaneous 80 A on all four motors. That gives an adiabatic window of about 2–3 s before the board reaches limits. Specify the rating as "80 A for ≤1 s, ≤10 % duty" or move to a 30.5 mm board.

## 1. Conduction Loss Model (Six-Step, Complementary PWM)

In six-step commutation, two phases conduct at any instant. AM32 uses synchronous rectification, so the current path always goes through **two MOSFET channels in series**:

- PWM on: HS(A) → motor → LS(B)
- PWM off: LS(A) freewheel → LS(B)

The loss is therefore independent of duty cycle D (ignoring dead-time diode conduction, which is handled in Section 2):

$$
P_{cond,motor} = 2\,I_{rms}^2\,R_{DS(on)}(T_j)
$$

$$
R_{DS(on)}(T_j) = R_{25}\left[1+\alpha\,(T_j-25)\right]
$$

At T_j = 125 °C:

- R = 1.5 × 1.55 ≈ **2.33 mΩ**
- P_cond = 2 × 80² × 2.33 m = **29.8 W per motor**

### Per-FET values

Each FET is in the conduction path for 1/3 of the electrical cycle on average, so the average per FET is 29.8 / 6 ≈ **5.0 W**.

While it is conducting, a FET dissipates 80² × 2.33 m = **14.9 W instantaneous**. This value is what drives junction ripple.

### Electrothermal convergence

R_DS(on) depends on T_j, which depends on P. Iterate:

$$
T_j^{(k+1)} = T_{board} + P\big(T_j^{(k)}\big)\cdot Z_{th,jc}
$$

This converges in 2–3 iterations for the values here. Runaway occurs only if ∂P/∂T · Z_th ≥ 1. In this design, ∂P/∂T · Z_th ≈ 0.08, which is stable.

### Copper and shunt losses (often forgotten)

- 2 oz copper sheet resistance is ρ/t = 1.72e-8 / 70e-6 ≈ **0.25 mΩ/□**.
- A 3-square current path on two parallel layers gives about 0.37 mΩ. At 80 A that is **2.4 W per phase path**.
- **Recommendation:** use 3–4 oz copper with 4 paralleled layers for the VBAT, GND and phase pours.
- **Current shunt:** a 0.2 mΩ shunt adds 80² × 0.2 m = **1.3 W**. Prefer one shared bus shunt for the whole ESC.

## 2. Switching Loss Model @ 48 kHz

Only the PWM'd leg switches. Its HS turn-on is hard-switched against the LS body-diode recovery.

| Term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f | ½·25.2·80·40n·48k = **1.94 W** |
| Reverse recovery | Q_rr·V·f | 50n·25.2·48k = **0.06 W** |
| C_oss charge | Q_oss·V·f | 40n·25.2·48k = **0.05 W** |
| Dead-time diode conduction | V_f·I·2t_dt·f | 0.8·80·400n·48k = **1.23 W** |
| Gate drive (mostly in driver/R_g) | 2·Q_g·V_GS·f | 2·50n·10·48k = **0.05 W** |
| **Total P_sw per motor** | | **≈3.3 W** |
