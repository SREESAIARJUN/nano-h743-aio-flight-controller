- **Power-stage physics:** §1–§4, executed on the ESC.
- **Digital timing/DMA:** §5–§6, executed on the FC.

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step synchronous PWM

During each 60° sector, phase A is PWM-high and phase B is low-side "on":

- **PWM ON (duty D):** current flows V+ → Q_AH → motor → Q_BL → GND
- **PWM OFF (1−D):** current freewheels Q_AL → motor → Q_BL. This is synchronous rectification, except during dead time.
