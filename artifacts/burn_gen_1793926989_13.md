# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #56 specification, so this design assumes typical gimbal hardware. Every assumption is collected in one parameter block so you can replace it with your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class Cortex-M with FPU, 170+ MHz |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701), read every PWM cycle |
| Current sensing | 2- or 3-shunt, sampled at PWM center |
| IMUs | 2× ICM-42688-P on SPI at 24 MHz, gyro ODR 8 kHz, accel ODR 1–4 kHz |
| Loop rates | current 20 kHz, velocity 4 kHz, angle 1 kHz |

## 1. System Architecture

```
                 1 kHz                  4 kHz                  20 kHz
 θ_ref ──►[Angle P + FF]──ω_ref──►[Vel PI + FF]──iq_ref──►(+)──►[Current PI]──►[invPark]──►[SVPWM]──► Motor
               ▲                        ▲                    ▲         ▲  ▲                                │
               │                        │          iq_cog ───┘         │  └─[Park]◄─[Clarke]◄─ i_a,i_b ────┤
               │                        │       [Anti-cogging          │        ▲                          │
               │                        │        Fourier FF(θ_m)]◄─────┼────────┼──── θ_m (encoder) ◄──────┘
               │                        │                              │        θ_e = p·θ_m − θ_off
       [Attitude q̂]◄─[Mahony]◄─ ω_f, a_f ◄─[Dyn. notch + LPF]◄─[Dual-IMU fusion]◄── IMU_A, IMU_B (8 kHz)
```

On a stabilizing gimbal:

- The **outer loops are closed on the camera attitude**, using IMU feedback.
- The **encoder is used for commutation and anti-cogging only**.
- The velocity loop uses **gyro rate** as its feedback, because gyro rate is what stabilization requires.

## 2. FOC Current Loop (Innermost, 20 kHz)

### 2.1 Electrical model (PMSM in the rotor dq frame)

$$
v_d = R\,i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R\,i_q + L_q\frac{di_q}{dt} + \omega_e L_d i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac{3}{2}\,p\,\big[\lambda_m i_q + (L_d-L_q)i_d i_q\big] \;\overset{L_d=L_q}{=}\; K_t\, i_q,\quad K_t=\tfrac32 p\lambda_m
$$

The electrical angle and speed follow from the mechanical ones:

$$
\theta_e = p\,\theta_m - \theta_{off},\qquad \omega_e = p\,\omega_m
$$

### 2.2 Transforms (amplitude-invariant)

Clarke transform (with $i_c = -i_a - i_b$):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

Park transform:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

Inverse Park transform:

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

**Delay compensation.** PWM update and sampling add about 1.5 sample periods of delay. Compensate the angle used in the inverse Park transform:

$$
\theta_e^{\,out} = \theta_e + 1.5\,\omega_e T_s
$$
