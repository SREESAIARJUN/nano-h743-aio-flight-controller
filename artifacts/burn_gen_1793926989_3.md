## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs `p = 7`), `R ≈ 5 Ω`, `L ≈ 2 mH`, `Kt ≈ 0.08 N·m/A` |
| Encoder | 14-bit absolute magnetic encoder (MT6701 / AS5048A class) per axis |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM, synchronous ADC |
| IMU A | ICM-42688-P on the **camera payload**: attitude and inertial rate feedback |
| IMU B | ICM-42688-P on the **handle/base**: disturbance reference |
| Gimbal order | Yaw → Roll → Pitch (base to camera) |

**Loop rates:**

| Loop | Rate | Ts | Crossover |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ~1.5–2 kHz |
| Velocity | 4 kHz | 250 µs | ~80–150 Hz |
| Angle | 1 kHz | 1 ms | ~15–30 Hz |
| IMU ODR | 8 kHz → decimated to 4 kHz | | |

The rule of thumb is a factor of 5–10 bandwidth separation between cascaded loops.

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle: θₑ = p·(θₘ − θ_offset).

**Clarke transform** (amplitude-invariant, with iₐ + i_b + i_c = 0):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and PI Design

The dq-frame voltage equations are:
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

where ωₑ = p·ωₘ and λₘ = Kt/(1.5p).

The controller uses a PI with **decoupling and back-EMF feedforward**:
$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L\, i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L\, i_d + \omega_e\lambda_m$$

**Pole-zero cancellation tuning** gives a closed loop of ω_c/(s+ω_c):
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c\quad(\text{continuous}),\qquad \omega_c \le \frac{2\pi f_{pwm}}{10}$$

With the assumed values, ω_c = 2π·1500 gives K_p = 18.8 V/A and K_i = 47 100 V/(A·s).
