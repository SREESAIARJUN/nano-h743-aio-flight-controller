# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #29, so this design rests on the assumptions in §0. Every numeric constant is a parameter you can change. The equations do not depend on the specific hardware.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F at 170 MHz, hardware FPU, CORDIC available) |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Joint sensors | 14-bit absolute magnetic encoders (MT6701 or AS5048A) over SPI |
| IMU A | ICM-42688-P on the camera plate. Used for attitude feedback. |
| IMU B | ICM-42688-P on the gimbal base/frame. Used for base-motion feedforward and vibration frequency tracking. |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

### Loop Rates and Bandwidth Separation

Each loop runs at least about 5× slower in bandwidth than the loop inside it.

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz, PWM-synchronous | ω_c = 2π·1500 rad/s |
| Joint velocity (PI) + cogging feedforward | 4 kHz | ω_v = 2π·120 rad/s |
| Attitude (P + rate feedforward) | 1 kHz | ω_p = 2π·20 rad/s |
| IMU sampling / filtering | 8 kHz ODR, decimated to 4 kHz and 1 kHz | — |

### Signal Flow

```
                 base IMU B ──► filters ──► ω_base ─────────────┐ (feedforward)
                                                                ▼
q_ref ─► [Attitude P] ─► ω_des ─► θ̇_cmd = J⁻¹(θ)(ω_des − R_cb ω_base)
              ▲                                   │ per joint
   q̂ (Mahony) ◄── filters ◄── camera IMU A        ▼
                                     [Velocity PI] + iq_cog(θ) ─► iq*
                                                                  ▼
                                encoder θ ─► [FOC current PI + SVPWM] ─► motor
```
