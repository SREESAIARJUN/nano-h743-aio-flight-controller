# STM32H743 Nano AIO with 4-in-1 ESC: Design Basis, Loss Model, DShot DMA Plan, and Netlists

## 0. Architecture Correction and Stated Assumptions

**Architecture correction.** The STM32H743 cannot commutate four BLDC motors itself. A production architecture has two layers:

| Layer | Device | Role |
|---|---|---|
| Flight controller (FC) | STM32H743VIT6 (LQFP100), ArduPilot | Attitude control. Sends bidirectional DShot600 to four ESCs. |
| ESC, ×4 | AT32F421K8U7 or STM32G071GBU6, AM32 firmware | 6-step/FOC commutation, 48 kHz PWM, eRPM telemetry |
| Power stage, ×4 | FD6288Q 3-phase gate driver + 6× N-MOSFET | Half-bridges |

**Assumptions.** The board name doesn't define these, so substitute your datasheet values where they differ.

| Parameter | Value |
|---|---|
| Bus voltage | 6S, V_bus = 25.2 V (full charge, worst case for switching) |
| MOSFET | 40 V, PDFN 3.3×3.3 |
| R_DS(on) | 1.2 mΩ @ 25 °C, V_GS = 10 V |
| R_DS(on) temperature coefficient | k(T) ≈ 1 + 0.0045·(T_j − 25) → 1.34 @ 100 °C |
| Rise / fall time | t_r = t_f = 20 ns (R_g = 4.7 Ω, FD6288 ~1 A drive) |
| Total gate charge | Q_g = 50 nC |
| Reverse recovery charge | Q_rr = 50 nC |
| Output capacitance | C_oss = 1.5 nF |
| Body-diode forward voltage | V_f = 0.8 V |
| Dead time | t_dt = 200 ns |
| Switching frequency | f_sw = 48 kHz |
| PWM scheme | Complementary (synchronous rectification) |
| Burst current | I_ph = 80 A phase current per motor |
| Board | 20×20 mm, 6-layer, 2 oz copper, 1.6 mm thick |

> **Engineering flag (read first).** The model below shows that **80 A per motor on a 20×20 nano board is a sub-second transient rating, not a continuous one.** Treat the "80 A burst" spec as a firmware-enforced current limit with a time budget, not as a hardware capability.

## 1. Conduction Loss Model

In 6-step commutation with synchronous rectification, phase current always flows through exactly **two** MOSFET channels:
- the high-side of one leg, or its complementary low-side during the off-time;
- plus the low-side of the return leg.

So the per-motor conduction loss is independent of duty cycle, to first order:

$$P_{cond} = I_{ph}^2 \cdot 2R_{DS(on)}(T_j), \qquad R_{DS(on)}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

At 80 A and T_j = 100 °C:

$$P_{cond} = 80^2 \times 2 \times (1.2\,\text{m}\Omega \times 1.34) = 6400 \times 3.22\,\text{m}\Omega = \mathbf{20.6\ W\ per\ motor}$$

**Copper path loss.** Assume battery pad → bus plane → FET → phase pad ≈ 0.4 mΩ effective per current path, two paths per motor:

$$P_{Cu} = 6400 \times 0.8\,\text{m}\Omega = \mathbf{5.1\ W\ per\ motor}$$

**Per-FET distribution.** Each FET conducts about 1/3 of the electrical period, so its average is roughly 20.6/6 ≈ 3.4 W. The instantaneous dissipation while conducting is 6400 × 1.61 mΩ ≈ 10.3 W.

**Electrical-period junction ripple.** At 30 k eRPM (500 Hz electrical, about 0.67 ms on-time):
- Z_th(j-c)(0.67 ms) ≈ 0.1 K/W
- ΔT_j ripple ≈ 1 K, which is negligible.

## 2. Switching Loss Model at 48 kHz

Only one leg hard-switches per commutation sector.

| Term | Equation | Value @ 80 A |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw = 0.5·25.2·80·40 ns·48 k | **1.94 W** |
| Dead-time diode | V_f·I·2t_dt·f_sw = 0.8·80·400 ns·48 k | **1.23 W** |
| Reverse recovery | V·Q_rr·f_sw = 25.2·50 nC·48 k | 0.06 W |
| C_oss | ½·C_oss·V²·f_sw | 0.02 W |
| Gate drive | 2·Q_g·V_GS·f_sw (2 FETs active) | 0.05 W (dissipated mostly in the driver and R_g) |
| **Total switching** | | **≈ 3.3 W per motor** |

**Design levers:**
- Dead-time loss is about 40% of switching loss. Cut t_dt to 100 ns (AM32 `dead_time`, verified with a scope) to save about 0.6 W.
- Dropping to 24 kHz halves the switching column but raises current ripple. With L_motor ≈ 15 µH, ΔI = V·D(1−D)/(L·f):
  - 48 kHz: ≈ 8.7 A p-p
  - 24 kHz: ≈ 17.5 A p-p

## 3. Total Budget and Thermal Model

### 3.1 Totals at 80 A

|---|---|---|
| Conduction (FET) | 20.6 W | 82.4 W |
