## 0. Executive Summary and Feasibility Finding

The math below shows that **80 A per motor on a 20×20 mm "nano" board is only survivable as a sub-second transient, not a 10-second burst.**

- Each channel dissipates about 30 W at 80 A.
- Four channels dissipate about 120 W in total.
- A 20×20 board has roughly 1.4 J/K of heat capacity, so it heats at **about 85 K/s**.

A realistic rating for this form factor is about **80 A for 0.3 to 0.5 s** (motor-start/stall class), with 15 to 25 A continuous per motor under prop-wash cooling. A true 10 s / 80 A burst requires a 30.5×30.5 mm or larger board with a heat spreader. Section 3 quantifies this so the requirement can be renegotiated with data.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current Path

In 6-step synchronous PWM, exactly two phases carry current in each 60° sector:

- **Switching leg:** the HS FET conducts for duty fraction D, and the LS FET (synchronous rectifier) conducts for 1 − D.
- **Static leg:** the LS FET conducts 100% of the sector.

So the motor current always flows through exactly **two R_DS(on)** at any instant, independent of D:

```
P_cond,ch = 2 · I_rms² · R_DS(on)(T_j)
```

### 1.2 Ripple Correction

```
I_rms² = I_avg² + ΔI_pp² / 12
ΔI_pp ≈ V_bus · D(1−D) / (L_ph-ph · f_sw)
```

For a typical 5" motor, L_ph-ph ≈ 20 µH. Worst case is D = 0.5:

```
ΔI_pp = 25.2 · 0.25 / (20e-6 · 48e3) = 6.6 A
ΔI²/12 = 3.6 A²
```

This is negligible against 6400 A², so I_rms ≈ 80.02 A.
