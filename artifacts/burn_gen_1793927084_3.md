# STM32H743 Nano AIO (FC + 4-in-1 ESC): 80 A Burst Thermal, 48 kHz Switching, Bidirectional DShot600 DMA

## 0. Architecture and Assumptions

This architecture affects every calculation that follows.

- **The STM32H743 is the flight controller, not the ESC MCU.** It runs ArduPilot and emits bidirectional DShot600. Commutation runs on per-motor ESC MCUs (e.g., 4× AT32F421 or STM32G071 running AM32) or on a single quad ESC MCU. Commutation at 48 kHz PWM with BEMF zero-cross detection does not belong on the H743, which must keep its timing for the scheduler and IMU.
- **The "80 A" figure is phase current per motor during a burst.** On a 20×20 or 25.5×25.5 nano board this is only achievable for about one second with all four motors loaded. Section 3.4 quantifies this limit.

**Design point.** All values are parameterized. Replace them with your selected datasheet values before release.

## 1. Conduction Loss Model

### 1.1 Current path

In six-step (trapezoidal) commutation with synchronous rectification, the phase current flows through exactly two conducting devices at any instant: one in the source leg and one in the return leg. During the PWM-off interval, the complementary FET of the PWM leg replaces the high-side device. This holds for both hi-PWM and complementary schemes.

**Per-motor bridge conduction loss:**

$$P_{cond,bridge} = 2\, I_{ph}^2\, R_{ds}(T_j), \qquad R_{ds}(T_j)=R_{ds,25}\,[1+\alpha (T_j-25)]$$
