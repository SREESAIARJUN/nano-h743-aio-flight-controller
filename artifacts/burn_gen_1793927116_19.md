# STM32H743 Nano AIO: FC + 4-in-1 ESC (Job #66)
## Architecture, Loss Model, Thermal Model, BDShot600 DMA Allocation and Netlists

## 0. Scope and Clarifications

Three points shape everything below.

1. **The STM32H743 is the flight controller, not the ESC controller.** It runs ArduPilot and generates bi-directional DShot600. Each of the four ESC channels is driven by its own ESC MCU running AM32 (AT32F421 or STM32G071 class). The 48 kHz PWM frequency is an ESC-firmware parameter. It is not generated by the H743.
2. **"80A burst" must be read as a time-limited rating.** The thermal model shows a nano-class board (about 25.5 × 25.5 mm) can sustain roughly 30–40 A per channel continuously with prop-wash airflow. 80 A is valid only for burst windows of about 1–2 s. The model below derives that window explicitly.
3. **All component values are design assumptions** that must be replaced with the selected parts' datasheet values. The netlists are architecture-level reference netlists, not fab-ready. They require ERC/DRC, layout review, and bench validation (double-pulse test, thermal camera) before release.

### Design Assumption Table

| Symbol | Meaning | Value |
