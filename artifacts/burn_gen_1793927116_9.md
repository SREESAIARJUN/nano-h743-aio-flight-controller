### 0.1 Partitioning: the H743 Does Not Generate the 48 kHz PWM

In standard 4-in-1 architectures, the H743 sends DShot600 commands only. The 48 kHz gate PWM, dead-time and commutation run on each ESC's local MCU. Do not route the gate drive from the H743:
- ArduPilot has no BLDC commutation firmware.
- Dead-time and back-EMF zero-cross timing need a dedicated core.
- A fault on the FC would then take down all four power stages.

The models below therefore cover two separate domains:
- **Power domain:** ESC MCU, gate driver and MOSFETs.
- **Control domain:** H743 timers and DMA.

### 0.2 Feasibility Flag

Sustaining 80 A per channel on a 20×20 mm board is physically impossible. As §3 shows, the board can sustain a few watts, not ~70 W. 80 A must be specified as a **time-limited burst**, with firmware-enforced current and temperature limits. The model below quantifies that limit.

### 1.2 Temperature-Dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)]$$

At the design junction temperature T_j = 110 °C:

$$R_{DS}(110) = 0.90 \times (1 + 0.005 \times 85) = 1.28\ \text{m}\Omega$$

### 1.3 Six-Step Conduction Topology

During each 60° commutation sector, two legs carry the phase current I:
- **PWM leg:** the high-side conducts for D·T_sw. The low-side of the same leg conducts for (1−D)·T_sw minus dead-time, via synchronous rectification.
- **Return leg:** the low-side conducts for 100% of the sector.

So at any instant, two channel MOSFETs carry I. Ignoring dead-time:

$$P_{cond,ch} = I^2 R_{DS}\,[D + (1-D)] + I^2 R_{DS} = 2\,I^2 R_{DS}(T_j)$$

$$P_{cond,ch} = 2 \times 80^2 \times 1.28\times10^{-3} = \mathbf{16.4\ W}$$

The duty cycle drops out because synchronous rectification makes conduction loss D-independent. This holds only if the low-side is actively driven; diode-mode freewheeling would be far worse.

### 1.4 Per-Device Distribution

- **Instantaneous loss** in a conducting FET: 80² × 1.28 mΩ = **8.2 W**.
- Each of the 6 FETs conducts about 1/3 of the electrical period, so the **average** is ≈ 16.4 / 6 ≈ **2.7 W per FET** (conduction only).
