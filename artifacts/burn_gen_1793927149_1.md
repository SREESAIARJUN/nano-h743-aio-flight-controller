## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Transforms

The electrical angle is computed from the mechanical angle, the pole-pair count p, and a calibrated offset θ_off:

$$\theta_e = p\,\theta_m - \theta_{off}$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model (Surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.3 Current PI Controllers with Decoupling and Back-EMF Feedforward

Choose a closed-loop current bandwidth ω_c. A reasonable choice is 2π·1.5 kHz, which stays below f_PWM/10.

**Gain selection by pole-zero cancellation:**

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

With these gains, the closed loop is approximately first-order:

$$\frac{i}{i^*} = \frac{\omega_c}{s + \omega_c}$$

**Control law:**

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e \lambda_m$$

The reference i_d* is set to 0.

**Voltage limiting:** the voltage vector is limited to the linear SVPWM circle, |v| ≤ V_bus/√3. When the limit is active, v_d is given priority.

**Anti-windup (clamping/conditional integration):** the integrator stops accumulating whenever the output is saturated *and* the error has the same sign as the saturation direction.

### 1.4 SVPWM via Min-Max Zero-Sequence Injection

1. Compute the three phase voltages:

$$v_a = v_\alpha,\qquad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\qquad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

2. Compute the zero-sequence component:

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$

3. Compute the duty cycles:

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
