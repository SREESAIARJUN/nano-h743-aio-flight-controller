# 3-Axis Gimbal Motor Control and Sensor Fusion: FOC, Cascaded PID, Anti-Cogging, and Dual ICM-42688-P Vibration Rejection

## 0. Assumptions and Loop Architecture

I don't have the Job #25 spec sheet, so the parameters below are typical for a brushless gimbal. Every parameter is a single `constexpr` or config field, so you can substitute your own values directly.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (e.g. GBM4108H-class), pole pairs `p = 11`, 12N14P, `R ≈ 10 Ω`, `L ≈ 2.5 mH`, `Kt ≈ 0.08 N·m/A` |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on SPI or SSI |
| Current sense | 2 inline/low-side shunts per motor. A voltage-mode fallback is provided for shuntless boards. |
| MCU | Cortex-M4F/M7 (STM32G4/H7-class) with single-precision FPU |
| IMUs | 2× ICM-42688-P on separate SPI buses, both on the camera plate |

Loop structure and rates:

```
                 2 kHz                         4 kHz                  20 kHz
 q_ref ──►[Attitude/Angle P-PI]──ω_ref──►[Rate PI + FF]──iq_ref──►[Current PI (d,q)]──►SVPWM
              ▲                    ▲            ▲  ▲ cogging FF            ▲
              │ attitude (quat)    │ inertial   │  └──── τ_cog(θm)/Kt     │ ia, ib, θe
              │                    │ rate       │                         │
 IMU A ─8kHz─►[AAF→notch(ANF)→LPF]─┐                     encoder θm ──────┘
 IMU B ─8kHz─►[AAF→notch(ANF)→LPF]─┴►[extrinsic align → weighted fusion/FDI]─►[Mahony AHRS 2 kHz]
```

Bandwidth separation rule: ω_cur ≥ 5–10·ω_vel and ω_vel ≥ 4–5·ω_pos. Each inner loop then looks like unity gain to the loop around it.

## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Electrical angle

$$
\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi
$$

Here `θ_m,0` is the encoder offset. It is found at startup by applying V_d along α and reading θ_m once the rotor settles.
