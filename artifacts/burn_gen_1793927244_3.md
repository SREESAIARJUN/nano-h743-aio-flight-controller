## 0. Architecture Clarification and Assumptions

The STM32H743 is not the ESC motor-control MCU. In this class of stack:

| Board | MCU | Firmware | Role |
|---|---|---|---|
| Flight controller | STM32H743VIH6 (480 MHz, rev V) | ArduPilot | Attitude control, bi-directional DShot600 master |
| 4-in-1 ESC | 4× STM32G071 / AT32F421 (one per channel) | AM32 or BLHeli_32 | 6-step BLDC commutation, 48 kHz PWM, eRPM telemetry |

All numbers below depend on these stated assumptions. Replace them with your datasheet values.

| Parameter | Symbol | Value | Note |
|---|---|---|---|
| Bus voltage (6S full) | V_bus | 25.2 V | Use 50 V-rated caps |
| Burst phase current per channel | I | 80 A | Per motor, not total |
| Burst throttle duty | D | 0.95 | |
| PWM frequency | f_sw | 48 kHz | |
| MOSFET | — | 40 V, DFN5×6 | Generic class |
| R_DS(on) max at 25 °C, V_GS = 10 V | R₂₅ | 1.2 mΩ | |
| R_DS(on) tempco | α | 0.0065 /K | ≈1.65× at 125 °C |
| Q_g / Q_gd / Q_rr / Q_oss | — | 60 / 12 / 50 / 60 nC | |
| Effective switching transition | t_r + t_f | 40 ns | Gate driver ~1 A effective, R_g ≈ 4.7 Ω |
| Dead time | t_dt | 100 ns | |
| Body-diode forward drop | V_F | 0.8 V | |
| Ambient air | T_a | 40 °C | |

> **Reality check.** 80 A at 25.2 V is about 2 kW per motor and about 8 kW total. On a 30×30 mm ("nano" 20×20 is worse) 4-in-1 board, this is only achievable as a short burst. The model below quantifies exactly how short. Also, 24× DFN5×6 FETs will not physically fit on 30×30 mm. Real boards use 3.3×3.3 mm parts with higher R_DS(on), which makes these numbers worse.
