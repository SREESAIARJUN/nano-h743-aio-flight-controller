# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original Job #34 spec, so this design rests on the assumptions in §0. Everything is parameterized. Change the constants to match your motors and MCU.

## 0. Assumptions and Loop Timing

| Item | Value (assumed) |
|---|---|
| Motor | PMSM gimbal motor, 12N14P (`N_s=12`, pole pairs `p=7`) |
| Position sensor | 14-bit magnetic encoder (e.g., AS5048A / MT6701) per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| PWM | 20 kHz center-aligned, 3-shunt (or 2-shunt) current sensing |

The loop rates are separated by at least 4× in bandwidth:

```
 20 kHz  : current loop (FOC: Clarke/Park, PI d/q, SVPWM)       ω_c ≈ 2π·1500 rad/s
  4 kHz  : velocity loop + cogging FF + IMU fusion (gyro path)  ω_v ≈ 2π·150  rad/s
  1 kHz  : angle loop + attitude estimator (Mahony)             ω_θ ≈ 2π·30   rad/s
```

## 1. FOC Current Loop (Inner, 20 kHz)

### 1.1 Transforms

The electrical angle is computed from the mechanical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and Decoupling

The surface PMSM model (L_d ≈ L_q = L) in the dq frame is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The decoupling feedforward cancels the cross-coupling and back-EMF terms:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda_m)$$

After decoupling, each axis reduces to the first-order plant

$$G_i(s) = \frac{1}{Ls + R}.$$

### 1.3 PI Tuning by Pole-Zero Cancellation

Use the PI controller

$$C_i(s) = K_p + \frac{K_i}{s}, \qquad K_p = L\,\omega_c,\quad K_i = R\,\omega_c.$$

This cancels the plant pole, so the closed loop becomes

$$\frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}.$$

Choose $\omega_c \le 2\pi f_{PWM}/10$ to leave margin for the roughly 1.5-sample PWM and computation delay.

The discrete form uses back-calculation anti-windup:

$$u_k = K_p e_k + I_k$$
$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(\text{sat}(u_k) - u_k)$$

### 1.4 Voltage Limit and SVPWM

**Circular limit.** Clamp the voltage vector to

$$\sqrt{v_d^2 + v_q^2} \le \frac{V_{bus}}{\sqrt 3}.$$

Prioritize v_d, then give v_q the remainder:

$$v_q \le \sqrt{V_{max}^2 - v_d^2}$$

**Min-max (zero-sequence injection) SVPWM.** This is equivalent to sector-based SVPWM:

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta)$$
$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
