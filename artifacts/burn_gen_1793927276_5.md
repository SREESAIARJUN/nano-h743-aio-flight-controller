# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Brushless Gimbal

I don't have the specific "Job #8" specification, so I've assumed typical gimbal hardware. Every assumption is a named constant in the code, so you can retarget it by changing those values.

**Assumed hardware**

| Item | Assumption |
|---|---|
| MCU | STM32G4/H7-class with single-precision FPU |
| Motors | 12N14P gimbal BLDC: Ns = 12 slots, p = 7 pole pairs, R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensing | 14-bit absolute magnetic encoder per axis (e.g., MT6701 or AS5048A) |
| Current sensing | Two-phase inline or low-side shunts |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, gyro and accel ODR = 8 kHz |

**Loop rates**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (d/q PI), PWM-synchronous | 20 kHz | ~1.5 kHz |
| IMU acquisition and filtering | 8 kHz | — |
| Rate (velocity) loop | 4 kHz | ~150–250 Hz |
| Angle (attitude) loop | 1 kHz | ~20–40 Hz |
| Attitude estimator | 1 kHz | — |

Each outer loop's bandwidth should be at most about 1/5 of the inner loop's. The schedule above satisfies this.

## 1. FOC Inner Current Loop

### 1.1 Transforms
Measured phase currents are i_a and i_b, with i_c = −i_a − i_b. The electrical angle is θ_e = p·(θ_m − θ_off).

**Clarke (amplitude-invariant):**
- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park:**
- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park:**
- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Plant and PI design
The machine equations in the d-q frame are:

- L·di_d/dt = v_d − R·i_d + ω_e·L·i_q
- L·di_q/dt = v_q − R·i_q − ω_e·(L·i_d + λ_m)

**Decoupling and back-EMF feedforward:**
- v_d = PI_d(e_d) − ω_e·L·i_q
- v_q = PI_q(e_q) + ω_e·(L·i_d + λ_m)

With these feedforward terms, each axis reduces to the first-order plant 1/(L·s + R).

**Gain selection by pole-zero cancellation:** choose the PI zero at R/L, which gives a closed loop of ω_c/(s + ω_c). The gains are:

- K_p = L·ω_c
- K_i = R·ω_c

Choose ω_c = 2π·f_c with f_c ≈ f_PWM/15, about 1.3 kHz at 20 kHz PWM.

### 1.3 Voltage limiting
Linear SVPWM can produce at most V_max = V_bus/√3. Two rules apply:

- **d-axis priority:** v_d ← clamp(v_d, ±V_max), then v_q ← clamp(v_q, ±√(V_max² − v_d²)).
- **Back-calculation anti-windup** on each integrator (Section 2.1, with gain K_aw).

### 1.4 SVPWM by min/max zero-sequence injection
This is equivalent to sector-based SVPWM:

1. Convert to phase voltages:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
2. Compute the offset v_0 = −(max(v_a, v_b, v_c) + min(v_a, v_b, v_c)) / 2.
3. Compute each duty cycle D_x = ½ + (v_x + v_0)/V_bus, clamped to [0, 1].

### 1.5 Fallback without current sensing
If the board has no current sensing, use voltage mode with v_q = R·i_q* + ω_e·λ_m and v_d = −ω_e·L·i_q*. The cogging and outer loops are unchanged.
