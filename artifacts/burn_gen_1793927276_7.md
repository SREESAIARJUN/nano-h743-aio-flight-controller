## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class Cortex-M4F/M7, single-precision FPU |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7, slots N_s = 12), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), on the motor shaft |
| IMUs | 2 × ICM-42688-P on the camera plate. Gyro ±2000 dps, accel ±16 g, ODR 8 kHz, on-chip AAF on |
| Inverter | 3-phase, 20 kHz center-aligned PWM, low-side shunts |

The rate hierarchy uses a separation of roughly 5–10× between loop bandwidths:

```
 20 kHz  ── Current loop (FOC, PI on i_d / i_q)            BW ≈ 1.5 kHz
  4 kHz  ── Velocity loop (PI) + cogging FF + encoder PLL  BW ≈ 150 Hz
  8 kHz  ── IMU read (both), per-IMU filters, fusion
  1 kHz  ── Attitude estimator (Mahony) + angle loop (P+FF) BW ≈ 20–30 Hz
```

The full signal path is:

```
θ_ref ─► [Angle P + ω_ff] ─► ω_ref ─► [Velocity PI] ─► i_q,fb ─┐
            ▲                          ▲                     (+)─► i_q,ref ─► [FOC PI d/q] ─► SVPWM ─► Motor
            │                          │   [Cogging FF] ─► i_q,ff ┘
     attitude (Mahony) ◄── fused gyro/accel ◄── notch+LPF ◄── IMU A / IMU B
```

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Transforms

The electrical angle is θ_e = p·(θ_m − θ_offset).

**Clarke transform** (amplitude-invariant, using i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)
$$

**Park transform:**

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park transform:**

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$
