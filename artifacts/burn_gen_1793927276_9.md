# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification and Reference Implementation

## 0. Assumptions and Architecture

I don't have the Job #30 specification, so this design uses common gimbal hardware. Change the constants in `config.hpp` to match your hardware.

| Item | Assumption |
|---|---|
| Motors | 3 × hollow-shaft gimbal BLDC, 12N14P (7 pole pairs). Typical values: R ≈ 5–12 Ω, L ≈ 1–3 mH, Kt ≈ 0.05–0.15 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701), SPI, read at 20 kHz |
| MCU | STM32G4 / H7-class (Cortex-M4F/M7, single-precision FPU, CORDIC optional) |
| Current sense | 2- or 3-shunt, sampled at the center of the PWM period |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, ODR 8 kHz, hardware-synchronized via FSYNC/CLKIN |
| Joint order | Yaw (base, z) → Roll (x) → Pitch (y) → camera |

### Loop Rates and Bandwidths

| Loop | Rate | Closed-loop bandwidth | Notes |
|---|---|---|---|
| Current (d/q PI) | 20 kHz | ≈ 1.5–2 kHz | ISR synchronized to PWM |
| IMU acquisition + filtering | 8 kHz → decimated to 4 kHz | – | Anti-aliasing filter in IMU silicon, notches in software |
| Rate loop (camera-frame PI-D) | 4 kHz | 80–150 Hz | Gyro feedback; this is the stabilization loop |
| Attitude loop (quaternion P + I) | 1 kHz | 10–25 Hz | Separation of ≥ 5× from the rate loop |
| Cogging LMS (calibration) | 4 kHz | – | Offline, then baked into a lookup table (LUT) |
