# FOC Control Loop and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the specification for Job #56, so the design below rests on stated assumptions. Every assumption is a parameter. Change the values in `Config` and the derived gains follow automatically from the equations.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6701 class) |
| Current sense | Two-shunt inline (if absent, use the voltage-mode fallback in §1.5) |
| IMUs | 2× ICM-42688-P on the camera payload, SPI at 24 MHz, ODR 8 kHz, shared CLKIN |
| MCU | Cortex-M7 / M4F with single-precision FPU |

**Loop rates**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current | 20 kHz (PWM-synchronous) | ≈ 1.5 kHz |
| Velocity / rate | 4 kHz | ≈ 150 Hz |
| Angle / attitude | 1 kHz | ≈ 30 Hz |

Each loop separates from the next by roughly 5–10×.

```
θ_ref ─►[Angle P+FF]─ω_ref─►[Rate PI + DoB]─i_q,ref─►[+ Cogging FF]─►[Current PI d/q]─►SVPWM─►Motor
            ▲                    ▲                                         ▲
     attitude (Mahony)     gyro rate on joint axis                   i_a, i_b, θ_e (encoder)
            ▲                    ▲
   [Dual ICM-42688-P: AAF → LPF → dynamic notches → inverse-variance fusion → fault check]
```
