# STM32H743 Nano FC + 80A 4-in-1 ESC: Electro-Thermal Model and DShot DMA Architecture

**Scope and assumptions.** In a 4-in-1 stack, the **STM32H743 is the flight controller**. It generates bidirectional DShot600. The **ESC side runs its own MCU** (for example AT32F421 with AM32, or a BLHeli_32-class part), and that MCU produces the 48 kHz bridge PWM.

All component values below are representative and should be **verified against your actual datasheets**. They are not taken from a specific BOM. Every equation is parametric, so you can substitute real values.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent R_DS(on)

$$R_{ds}(T_j) = R_{ds25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R_ds = 1.0 × (1 + 0.6) = **1.6 mΩ**.

### 2.2 RMS current including PWM ripple

The phase-current ripple from a line-line inductance in one PWM period is:

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L\,f_{sw}}$$

The worst case is at D = 0.5:

$$\Delta I_{pp} = \frac{25.2 \times 0.25}{20\,\mu H \times 48\,kHz} = 6.56\ \text{A}, \qquad I_{ripple,rms} = \frac{\Delta I_{pp}}{\sqrt{12}} = 1.89\ \text{A}$$

$$I_{rms}^2 = I_{pk}^2 + I_{ripple,rms}^2 = 6400 + 3.6 \approx 6404\ \text{A}^2$$

Ripple contributes under 0.1% at 80 A, so it is negligible at burst current. It matters only at light load.

### 2.3 Bridge conduction loss

In 6-step operation, two phase legs always carry the current. With synchronous rectification, the current is always flowing through one channel (high-side for D, low-side for 1−D). Conduction loss is therefore approximately **independent of duty cycle**:

$$P_{cond} = 2\,I_{rms}^2\,R_{ds}(T_j) = 2 \times 6404 \times 1.6\,m\Omega = \mathbf{20.5\ W\ per\ motor\ channel}$$

**Per-FET average.** Each switch conducts for about 1/3 of the electrical cycle, so each FET carries roughly one-sixth of the bridge conduction loss:

$$P_{cond,FET} \approx \frac{20.5}{6} \approx 3.4\ \text{W (average)}, \qquad \text{instantaneous up to } I^2R = 10.2\ \text{W}$$

### 2.4 Copper and interconnect loss (often underestimated)

Each high-current path segment with 0.2 mΩ of trace, via and solder resistance adds:

$$80^2 \times 0.2\,m\Omega = 1.3\ \text{W}$$

Budget about **2–3 W per channel** for the PCB phase path and the motor-wire pad.

## 3. Switching Loss Model at 48 kHz

Only the PWM-ing leg switches hard. The static leg's FET stays on for the commutation sector.

### 3.1 V-I overlap (hard switching)

$$P_{VI} = \tfrac{1}{2}V_{bus}\,I\,(t_r + t_f)\,f_{sw} = 0.5 \times 25.2 \times 80 \times 40\,ns \times 48\,kHz = \mathbf{1.94\ W}$$

### 3.2 Reverse recovery

$$P_{rr} = Q_{rr}\,V_{bus}\,f_{sw} = 40\,nC \times 25.2 \times 48\,kHz = \mathbf{0.048\ W}$$

### 3.3 Dead-time body-diode conduction

$$P_{dt} = V_{SD}\,I\,(2\,t_{dt})\,f_{sw} = 0.8 \times 80 \times 200\,ns \times 48\,kHz = \mathbf{0.61\ W}$$
