# STM32H743 Nano FC + 4-in-1 ESC (Job #4): System Architecture Package

> **Note on scope and assumptions.** No prior specification for "Job #4" was provided, so this package defines its own baseline. Every component value marked **[A]** is an assumption you should replace with your selected part's datasheet values. The equations are general. The numbers are a worked example.
>
> **Three findings shape the whole design:**
> 1. **Motor PWM is not generated by the H743.** In a 4-in-1 ESC, each motor's 48 kHz complementary PWM is produced by a dedicated ESC MCU (AM32 / BLHeli_32 class). The H743 only emits DShot600 and receives eRPM telemetry. The architecture below reflects this split.
> 2. **"80 A burst" must be defined.** At full duty, 80 A *phase* current per motor means about **320 A battery current**. That is not survivable on a nano (20×20 / 25.5×25.5) form factor because of copper, connector and battery-lead losses. This package interprets the requirement as **80 A peak phase current per motor for ≤ 1–2 s**, with a **burst battery-current limit of about 160–200 A total**.
> 3. **Thermally, the board is limited by stored heat, not steady-state cooling.** The burst model below shows the board reaches its limit in a few seconds.

## 2. Conduction Loss Model (80 A Burst)

### 2.1 Current Paths in Complementary 6-Step

In each 60° commutation sector, two phases carry current:
- **PWM leg:** the high side (HS) conducts for duty D. The low side (LS) synchronously rectifies for (1 − D).
- **Static leg:** the LS is on for the whole sector.

At any instant, therefore, **exactly two MOSFET channels** carry the phase current I_ph. Dead time is ignored here and handled in §3.3.

$$P_{cond,motor} = 2\, I_{ph}^2\, \frac{R_{ds}(T_j)}{n_p}$$

where n_p is the number of paralleled FETs per switch and

$$R_{ds}(T_j) = R_{ds25}\,[1 + \alpha (T_j - 25)]$$

### 2.2 Per-FET Distribution

Over one electrical revolution, each of the 6 FETs carries current for 120°. In that window it splits between full conduction and PWM-share. Averaged over the revolution:

$$\bar P_{FET} = \frac{P_{cond,motor}}{6}$$
