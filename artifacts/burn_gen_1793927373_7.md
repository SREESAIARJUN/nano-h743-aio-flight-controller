# STM32H743 Nano AIO Flight Controller with 4-in-1 ESC: System Model (Job #5)

## 0. Architecture Assumptions

The STM32H743 cannot practically run ArduPilot and four sensorless commutation loops at the same time. The design therefore splits into two layers:

| Layer | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (480 MHz) | ArduPilot. Generates bidirectional DShot600 and decodes eRPM telemetry. |
| ESC (×4) | AT32F421K8U7 (or STM32G071) | AM32 firmware. 6-step commutation at 48 kHz PWM with synchronous rectification. |
| Gate driver (×4) | FD6288Q | 3-phase bootstrap driver, VCC 10–12 V |
| Power stage (×4) | 6× N-MOSFET, 40 V, PDFN 3.3×3.3 | 24 FETs total |
| Battery | 6S LiPo | 25.2 V max, 22.2 V nominal |
| Form factor | 20×20 mm (M2), 8-layer, 2 oz outer and 2 oz inner power layers | |

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step commutation with complementary (synchronous) PWM, motor current always flows through exactly two conducting FETs:

- During the PWM on-time: HS(a) → motor → LS(b)
- During the PWM off-time: LS(a), synchronously rectified → motor → LS(b)

So the conduction loss per channel is independent of duty cycle:

$$P_{cond,ch} = I_{ph,rms}^2 \cdot 2R_{DS}(T_j) + I_{ph,rms}^2 R_{Cu}$$

### 1.2 Effective RMS current including ripple

$$I_{ph,rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{V_{bus}\,D(1-D)}{L_{pp}\,f_{sw}}$$

The worst case is D = 0.5, giving the largest ripple:

$$\Delta I = \frac{25.2 \cdot 0.25}{20\,\mu\text{H} \cdot 48\,\text{kHz}} = 6.6\,\text{A} \;\Rightarrow\; \frac{\Delta I^2}{12} = 3.6\,\text{A}^2$$

This is negligible next to I_ph² = 6400 A².

### 1.3 Temperature dependence of R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\left[1 + \alpha (T_j - 25)\right], \quad \alpha \approx 0.0058\ \text{K}^{-1}$$

At T_j = 110 °C this gives R ≈ 1.5 mΩ. Because conduction loss rises with temperature, this term creates positive feedback, which drives the thermal runaway criterion in §3.4.

### 1.4 Numbers

| Term | Calculation | Result |
|---|---|---|
| FET conduction | 6403 × 2 × 1.5 mΩ | 19.2 W |
| PCB copper path, R_Cu ≈ 0.3 mΩ (phase pad → bus) | 6403 × 0.3 mΩ | 1.9 W |
| **P_cond per channel** | | **21.1 W** |

Per FET: each FET conducts for about 1/3 of the electrical period, so the average is 19.2 / 6 ≈ **3.2 W per FET**. During its conduction interval the instantaneous loss is 9.6 W.
