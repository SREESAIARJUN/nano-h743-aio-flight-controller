# Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #46 specification, so the design below rests on explicit assumptions (§0). Every motor- or vehicle-specific number is a named parameter you can replace with your own values.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, single-precision FPU, CORDIC optional) |
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) per axis |
| Current sense | 2 or 3 low-side shunts, ADC triggered at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate (IMU-A, IMU-B), SPI at 24 MHz, ODR 8 kHz |
| Kinematics | Yaw → Roll → Pitch (base to camera) |

**Rate hierarchy.** Each inner loop is at least 5–10× faster than the loop above it.
