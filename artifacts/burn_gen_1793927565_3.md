# 3-Axis Gimbal: FOC Control, Anti-Cogging and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #7 specification, so this design uses a typical brushless gimbal configuration. Every parameter lives in a config struct, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU (C++17, no heap) |
| Motor | GBM2804-class, 12 slots / 14 poles (p = 7), R = 5.6 Ω, L = 1.8 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) |
| Bus | 12–16 V |
| IMU | 2 × ICM-42688-P on SPI, 8 kHz ODR, mounted on the camera plate symmetric about its centroid (r₂ = −r₁) |
| Loop rates | Current 20 kHz · velocity 4 kHz · attitude/angle 1 kHz (fusion at 8 kHz, decimated) |

The control structure per axis is:

```
attitude error (fused quaternion) → [Angle P + rate FF] → ω* → [Velocity PI (+gyro FB)] → iq* 
   + iq_cogging(θm) + iq_ff → [Current PI dq + decoupling] → SVPWM → motor
```

## 1. Field-Oriented Current Loop

### 1.1 Transforms

The electrical angle is θₑ = p·θₘ − θ_offset.

**Clarke** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park:**

$$\begin{bmatrix}i_d\\i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\i_\beta\end{bmatrix}$$

**Inverse Park** is the transpose of the Park matrix.

### 1.2 Plant and Decoupling

For an SPM motor (L_d = L_q = L):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The decoupling feed-forward cancels the cross terms and the back-EMF:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m,\qquad \lambda_m = \tfrac{2K_t}{3p}$$

### 1.3 PI with Pole-Zero Cancellation

Choose the gains so the PI zero cancels the electrical pole R/L:

$$K_p = L\,\omega_{c},\quad K_i = R\,\omega_{c}\;\Rightarrow\; G_{cl}(s)=\frac{\omega_c}{s+\omega_c}$$

Choose ω_c ≤ 2π·f_pwm/10. At 20 kHz this gives ω_c ≈ 2π·1.5 kHz.

**Discrete form with back-calculation anti-windup** (T_s = 1/f_pwm):

$$u_k = K_p e_k + I_k + v^{ff}_k,\quad \bar u_k=\text{sat}(u_k),\quad I_{k+1}=I_k + K_iT_s e_k + K_{aw}(\bar u_k-u_k)$$

### 1.4 Voltage Limiting and SVPWM

Limit the voltage vector to the linear-region circle |v_dq| ≤ V_bus/√3. Give d priority:

$$v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$$

SVPWM is implemented by min-max zero-sequence injection, which is equivalent to classic sector SVPWM:

$$v_{0} = -\tfrac12(\max(v_{abc})+\min(v_{abc})),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$
