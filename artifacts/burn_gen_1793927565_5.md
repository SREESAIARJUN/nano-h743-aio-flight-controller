# Job #46: 3-Axis Gimbal FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

## 0. Assumptions

No hardware spec was attached to Job #46, so the design below uses representative values. Every assumed value is a named constant in the code (`Config` structs), so you can substitute the real numbers directly.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU, CORDIC) |
| Motors | GBM2804-class gimbal BLDC, 12N14P, pole pairs $p=7$, $R_s\approx 5.6\,\Omega$, $L_s\approx 1.6$ mH, $K_t\approx 0.09$ N·m/A |
| Bus | $V_{dc}=12$ V, 3-phase inline shunts, center-aligned PWM 20 kHz |
| Encoders | 14-bit absolute magnetic (MT6701 / AS5048A) per axis |
| IMUs | ICM-42688-P **#0 on the payload** (camera plate, feedback). ICM-42688-P **#1 on the gimbal base** (disturbance reference) |
| Topology | Yaw → Roll → Pitch (base to payload) |

**Loop rates:**

| Loop | Rate | Notes |
|---|---|---|
| Current (FOC) | 20 kHz | Runs in the ADC ISR |
| IMU sampling | 8 kHz ODR | Both chips, read via SPI DMA |
| Rate loop | 4 kHz | 2:1 decimation of IMU data |
| Attitude loop | 1 kHz | |

Rule of thumb used throughout: each loop's bandwidth is at most 1/5–1/10 of the inner loop's bandwidth, and at most 1/10 of its own sample rate.
