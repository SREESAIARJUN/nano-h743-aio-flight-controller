# FOC Control Loop and IMU Sensor Fusion for a 3-Axis Gimbal

**Note on scope:** I don't have the spec sheet for Job #17. Every hardware-dependent number below is an assumption. Each is a single `constexpr` in the code, so you can replace it once you have the real values.

## 0. Assumed Platform

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.1 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A or MT6701 class) per axis |
| MCU | STM32G4-class Cortex-M4F with FPU, 170 MHz |
| Inverter | Center-aligned PWM at 20 kHz, inline or low-side shunt current sensing |
| IMUs | 2× ICM-42688-P on the camera plate, rigidly mounted, diametrically opposed about the camera's center of gravity |
| Loop rates | Current: 20 kHz. Velocity and IMU: 4 kHz. Angle and attitude: 1 kHz |
