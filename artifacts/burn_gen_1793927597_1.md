# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #55)

## 0. Assumptions

I don't have the Job #55 spec sheet, so this design is parameterized. Every value marked ⚙ must be replaced with your measured or specified value.

| Item | Assumed baseline |
|---|---|
| Motors | 3 × hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7) ⚙, R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoders | 14-bit magnetic (AS5048A / MT6701 class), one per joint |
| Current sense | 2-phase low-side shunts. A voltage-mode fallback is included because many gimbal drivers lack shunts. |
| MCU | Cortex-M4F/M7 with FPU (e.g., STM32G474 @ 170 MHz) |
| IMUs | 2 × ICM-42688-P on the camera/payload plate, separate SPI chip-selects, ODR 8 kHz |
| Kinematics | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
