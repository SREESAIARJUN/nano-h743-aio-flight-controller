## 0. Architecture Assumptions and Feasibility Flags

Several points need to be settled before the math, because they change the design.

1. **The STM32H743 does not commutate the motors.** ArduPilot has no BLDC commutation firmware. This board is therefore an **AIO (All-In-One)**:
   - an H743 flight controller running ArduPilot, sending DShot600 to
   - a 4-in-1 ESC section with dedicated ESC MCUs (AM32 on AT32F421 / STM32G071 class, or BLHeli_32/Bluejay-class).
   - Bi-directional DShot requires ESC firmware support. AM32 supports it.
2. **"80 A burst" is interpreted as per channel, for ≤ 5 s.** Four channels at once would draw 320 A from the battery. That exceeds any connector that fits a nano board (an XT60 is about 60 A continuous). Realistic aggregate burst is **≤ 120–160 A**, typically with 1–2 motors peaking asynchronously. The thermal model below quantifies why.
3. **"Nano" form factor is taken as 20 × 20 mm mounting (≈ 26 × 26 mm outline), 8-layer, 2 oz copper.** With 4 × 80 A on this footprint, the system is **thermally mass-limited, not R_θ-limited**. Burst duration is the governing constraint.
4. **Component values are representative.** Parts named below are *candidate* devices with *typical* datasheet-class parameters. Every value marked † must be verified against the selected part's datasheet before layout.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent on-resistance

```
R_DS(Tj) = R_25 · [1 + α · (Tj − 25)]
```

### 2.2 Conduction topology

The model assumes trapezoidal 6-step commutation with complementary (synchronous) PWM on the active leg.

- At every instant, phase current flows through exactly **two conduction elements** in series: one high-side path and one low-side path. The PWM leg alternates HS↔LS, but one of them is always conducting.
- Total conduction loss per channel is therefore independent of duty cycle (dead time excepted):

```
P_cond,ch = I² · 2 · R_DS(Tj)
```

- Each of the 6 FETs carries current for 1/3 of the electrical period, split by duty between its HS/LS role. At eRPM where the 120° interval is much shorter than the junction thermal time constant, the per-FET time-averaged loss is:

```
P_cond,FET(avg) = P_cond,ch / 6 = I² · R_DS(Tj) / 3
```

### 2.3 Self-consistent junction temperature (fixed-point iteration)

```
Tj(n+1) = T_board + P_FET(Tj(n)) · R_θJC
```

This converges in 2–3 iterations because α · P · R_θ ≪ 1.
