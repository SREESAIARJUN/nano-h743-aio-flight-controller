# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage Model, DShot Timer Allocation, and Reference Netlists

## 0. Scope and Assumptions

I don't have a prior specification for Job #42, so every input parameter is stated explicitly below. Replace the bracketed values with the datasheet values for your selected parts. The equations hold regardless of the specific numbers.

One architectural clarification: the STM32H743 does not commutate the motors. In any production AIO design, the H743 runs ArduPilot and sends bi-directional DShot600 to one or more ESC MCUs (AM32 on AT32F421/STM32G071, or BLHeli_32). Those ESC MCUs generate the 48 kHz complementary PWM. Both domains are modeled below.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Commutation topology

The model assumes 6-step trapezoidal commutation with complementary (synchronous-rectified) PWM, which is the AM32/BLHeli_32 default.

During each 60° electrical sector:
- **Leg A (PWM'd):** the high-side FET conducts for duty D. The low-side FET conducts for (1 − D) minus dead time.
- **Leg B:** the low-side FET is fully ON.
- **Leg C:** floating, used for BEMF sensing.

### 1.2 Loss per motor

The phase current I flows continuously through exactly two conducting FETs at any instant. The duty cycle therefore cancels out:

$$P_{cond,motor} = I^2 R_{DS}(T_j)\,[D + (1-D)] + I^2 R_{DS}(T_j)\cdot 1 = 2\,I^2 R_{DS}(T_j)$$

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

Using a conservative T_j = 125 °C, the temperature factor is 1.45, so R_DS = 1.74 mΩ:

$$P_{cond,motor} = 2 \times 80^2 \times 1.74\times10^{-3} = \mathbf{22.3\ W}$$

### 1.3 Per-FET distribution

Over a full electrical cycle, each of the 6 FETs averages 22.3 / 6 = **3.7 W**.

Within a single sector, however, the fully-ON low-side FET dissipates I²R = **11.1 W**. At high eRPM this ripple is invisible to the package, because the electrical period (about 0.3–1 ms) is much shorter than the package thermal time constant (about 5–20 ms). At low RPM under high current, such as punch-outs from hover, the die sees the instantaneous 11.1 W. Use Z_θJC(t), not R_θJC, for that case.
