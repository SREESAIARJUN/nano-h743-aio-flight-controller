# STM32H743 Nano FC + 4-in-1 ESC (Job #11): Architecture, Loss Model, DShot DMA Plan, Netlists

## 0. Architectural Corrections and Assumptions

Two points must be settled before any math, because they change the design.

**1. The STM32H743 does not generate the 48 kHz motor PWM.** ArduPilot has no motor-commutation or FOC firmware. The working architecture is:

```
STM32H743 (ArduPilot) ──bidir DShot600──► ESC MCU ×4 (AT32F421 / AM32 or BLHeli_32)
                                           └── 48 kHz complementary PWM ──► gate driver ──► 6 MOSFETs/motor
```

So the 48 kHz switching losses belong to the ESC section. The H743's timing job is DShot600 plus eRPM capture.

**2. No MOSFET part was specified.** I use a representative 40 V, about 1 mΩ PDFN5×6 device. Replace these values with your datasheet values; every equation below is parametric.

| Parameter | Symbol | Value used |

| Bus voltage (6S, full charge, worst case) | V_bus | 25.2 V |
| R_DS(on) at 25 °C / 125 °C (×1.5) | R_ds | 0.9 / 1.35 mΩ |
