# STM32H743 AIO Flight Controller + 4-in-1 ESC: Reference Design Analysis

**Scope:** Loss model at 80 A burst, 48 kHz PWM; ArduPilot bidirectional DShot600 timer/DMA allocation; reference netlist; thermal budget.

---

## 0. Architectural Correction and Assumptions

The STM32H743 does not commutate the motors directly. In every production AIO design, and in ArduPilot's driver model, the H743 runs the **flight controller**. It sends bidirectional DShot600 to **four dedicated ESC MCUs** (AT32F421 / STM32G071 running AM32, or EFM8BB51 running BLHeli_S/Bluejay), which in turn drive the gate drivers. The math below follows that split.

| Parameter | Assumed value | Notes |
|---|---|---|
| Bus voltage | 6S, V_bus,max = 25.2 V | Worst case for switching loss |
| Burst current | 80 A phase current, per channel | Defined at motor phase, not battery |
| PWM | 48 kHz, complementary (synchronous rectification) | AM32 typical |
| MOSFET | 40 V N-ch, R_ds(on) = 1.0 mΩ @ 25 °C, V_gs = 10 V | Representative 5×6 mm DFN class |
| R_ds(on) temperature factor | k_T = 1.5 @ T_j = 125 °C | Typical datasheet curve |
| Switching edges | t_r = t_f = 15 ns | 1.5–2 A gate driver |
| Q_g = 60 nC, Q_rr = 50 nC, Q_oss = 60 nC, V_f(body) = 0.8 V | | |
| Dead time | t_dt = 100 ns per edge | |
| PCB | 30×30 mm, 6-layer, 2 oz outer / 2 oz inner power planes | See §3 on 20×20 feasibility |

**Validation required:** Substitute your actual MOSFET datasheet values. The equations hold, but the numbers scale directly with R_ds(on) and the edge times.

## 1. Conduction Loss Model

### 1.1 Six-step commutation topology
In each 60° commutation sector, two phases conduct:
- **PWM leg:** the high-side FET conducts for duty D. The synchronous low-side FET conducts for (1−D).
- **Fixed leg:** the low-side FET conducts for 100% of the sector.

Current magnitude I flows through exactly two FETs at every instant (ignoring dead time):

$$P_{cond,ch} = I^2 R_{ds,hot}\,[D + (1-D)] + I^2 R_{ds,hot} = 2\,I^2 R_{ds,hot}$$

$$R_{ds,hot} = k_T \cdot R_{ds,25} = 1.5 \times 1.0\ \text{m}\Omega = 1.5\ \text{m}\Omega$$

$$P_{cond,ch} = 2 \times 80^2 \times 1.5\times10^{-3} = \mathbf{19.2\ W}$$

### 1.2 Per-FET distribution
Each FET conducts 1/3 of the electrical cycle on average across commutation. However, the **instantaneous** dissipation in a conducting FET is:

$$P_{FET,inst} = I^2 R_{ds,hot} = 9.6\ \text{W}$$

The thermal time constant of the die is ~ms, which is shorter than one electrical period at low eRPM. Junction temperature must therefore be evaluated against the instantaneous value at low RPM and against the 1/3-averaged value (3.2 W) at high RPM.

### 1.3 Copper conduction
Sheet resistance at 2 oz (70 µm) Cu: R_□ ≈ 0.25 mΩ/□ @ 25 °C (α = 0.00393/K).

Each phase path runs pad → FET → phase pad, about 3 squares. Layers are paralleled across 3 planes: R ≈ 0.25 mΩ per path. Two paths conduct (in and out), and plating rises to ~70 °C (×1.18):

$$P_{Cu,ch} = 2 \times 80^2 \times 0.25\times10^{-3}\times1.18 \approx \mathbf{3.8\ W}$$

### 1.4 Shunt (if per-channel current sense is fitted)
A 0.25 mΩ low-side shunt in the return path adds P = 80² × 0.25 mΩ = **1.6 W**. Many AIO boards use a single bus shunt instead. At 80 A per channel, the bus shunt sees up to D·4·80 A. See §3.4.

## 2. Switching Loss Model at f_sw = 48 kHz

Only the PWM leg switches. The fixed leg commutates at eRPM rate, which is negligible.

### 2.1 Hard-switching V–I overlap (high side)
$$P_{VI} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 30\text{ ns} \times 48\text{ kHz} = \mathbf{1.452\ W}$$

### 2.2 Reverse recovery (low-side body diode)
$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{ nC}\times25.2\times48\text{k} = \mathbf{0.060\ W}$$

### 2.3 Output capacitance
$$P_{oss} = \tfrac{1}{2} Q_{oss} V_{bus} f_{sw} = 0.5\times60\text{ nC}\times25.2\times48\text{k} = \mathbf{0.036\ W}$$

### 2.4 Dead-time body-diode conduction (2 edges/period)
$$P_{dt} = V_f I \cdot 2 t_{dt} f_{sw} = 0.8\times80\times200\text{ ns}\times48\text{k} = \mathbf{0.614\ W}$$

### 2.5 Gate drive (dissipated mostly in driver and gate resistors)
$$P_{gate} = 2\, Q_g V_{gs} f_{sw} = 2\times60\text{ nC}\times10\times48\text{k} = \mathbf{0.058\ W}$$

### 2.6 Summary per channel at 80 A

| Loss term | W | % |
|---|---|---|
| MOSFET conduction | 19.20 | 76.3 |
| Copper | 3.80 | 15.1 |
| V–I overlap | 1.45 | 5.8 |
| Dead-time diode | 0.61 | 2.4 |
| Q_rr + Q_oss + gate | 0.15 | 0.6 |
| **Total / channel** | **25.2** | |
| **4 channels** | **≈101 W** | (+6.4 W if per-channel shunts are fitted) |

**Design insight:** At 80 A, conduction dominates (~91% including copper). Raising f_sw from 24 to 48 kHz costs only ~2 W per channel. Lowering R_ds(on) or paralleling FETs is the only effective lever.

**Paralleling trade-off:** Two FETs per switch halves P_cond to 9.6 W but doubles Q_g and Q_oss terms (still <0.3 W).

Loss model for the 48 kHz optimization trade:
$$P_{sw}(f) \approx (1.45 + 0.61 + 0.15)\cdot\frac{f}{48\text{ kHz}}\ \text{W}$$

## 3. Thermal Analysis

### 3.1 Junction rise (steady-state limit, single FET)
Assume R_θJC = 1.2 K/W and a local spreading resistance to the copper plane R_θCB ≈ 4 K/W (thermal vias under the drain pad, 2 oz).

At instantaneous 9.6 W (low-eRPM worst case):

$$\Delta T_{J-board} = 9.6 \times (1.2 + 4.0) = 50\ \text{K}$$

At 1/3 averaged 3.2 W (high-eRPM case): ΔT ≈ 17 K.
