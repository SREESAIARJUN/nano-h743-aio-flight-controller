# STM32H743 FC + 4-in-1 ESC Nano Stack: Thermal, Switching, and Bi-Directional DShot Design Package

## 0. Scope and Assumptions

I don't have access to a "Job #15" design file, so this package is built from stated assumptions. Every numeric result is parametric: substitute your actual BOM values and the equations still hold.

One architectural correction first. The STM32H743 is the **flight controller** MCU. It does not commutate the motors. The 4-in-1 ESC has its own MCU, typically AT32F421 or STM32G071 running AM32, or EFM8 running BLHeli_S. The 48 kHz PWM and the commutation are generated there. The H743 only sends DShot600 and receives eRPM telemetry.

## 1. Conduction Loss Model

### 1.1 Current paths
In 6-step drive, two phases conduct in each 60° electrical sector:

- **Leg A (PWM leg):** the high-side FET Q_AH conducts for duty D. The complementary low-side FET Q_AL synchronously rectifies for (1−D), minus dead time.
- **Leg B (static leg):** the low-side FET Q_BL conducts for 100% of the sector.

Phase current therefore always flows through exactly **two FET channels** (ignoring dead time):

$$P_{cond,ch} = I_{ph}^2 \, R_{DS(hot)} \,[D + (1-D)] + I_{ph}^2 R_{DS(hot)} = 2\,I_{ph}^2\,R_{DS(hot)}$$

$$R_{DS(hot)} = k_T R_{25} = 1.5 \times 1.0\,\text{m}\Omega = 1.5\,\text{m}\Omega$$

### 1.2 Numbers at 80 A

$$P_{cond,ch} = 2 \times 80^2 \times 1.5\times10^{-3} = \mathbf{19.2\ W}$$

$$P_{Cu,ch} = I_{ph}^2 R_{cu} = 6400 \times 0.5\times10^{-3} = \mathbf{3.2\ W}$$

### 1.3 Temperature feedback
R_DS(on) rises with junction temperature:

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right], \quad \alpha \approx 0.006\ /^\circ\text{C}$$

Conduction loss has positive thermal feedback. Solve iteratively with T_j = T_board + P_FET·R_th,j-b. The loop converges only if α·P·R_th < 1, which holds at burst levels but must be checked at sustained levels.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. The high side hard-switches, and the low side sees dead-time diode conduction plus reverse recovery.

### 2.1 Transition times
$$t_r \approx \frac{Q_{gs2}+Q_{gd}}{I_{src}} = \frac{13\,\text{nC}}{0.3\,\text{A}} = 43\,\text{ns}, \qquad t_f \approx \frac{13\,\text{nC}}{0.6\,\text{A}} = 22\,\text{ns}$$

### 2.2 Loss components (per channel)

| Mechanism | Equation | Result |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·65 ns·48 k | **3.15 W** |
| C_oss charge | ½·C_oss·V²·f_sw × 2 FETs | 0.05 W |
| Reverse recovery | V·Q_rr·f_sw | 0.05 W |
| Dead-time diode conduction | V_F·I·(2·t_dt)·f_sw = 0.8·80·200 ns·48 k | **0.61 W** |
| Gate drive (mostly dissipated in driver/R_g) | Q_g·V_drv·f_sw × 2 | 0.04 W |
| **Total switching** | | **≈ 3.9 W** |
