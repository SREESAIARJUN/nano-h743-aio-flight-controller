# STM32H743 AIO Flight Controller with 4-in-1 ESC (Job #37): Power Stage, Thermal and DShot Architecture

## 0. Scope and Assumptions

**Architecture.** In a production AIO, the H743 does not commutate the motors. It runs ArduPilot and sends bidirectional DShot600 to four ESC MCUs (for example AT32F421 or STM32G071 running AM32), co-located on the same PCB. Each ESC MCU generates the 48 kHz PWM. The math below is split accordingly:

- **Power stage (×4 channels):** ESC MCU → 3-phase gate driver → 6 N-channel MOSFETs per channel
- **Control:** H743 timers and DMA → DShot600 → ESC MCU UART/timer input

**Assumed parameters.** No MOSFET was specified, so a representative 40 V, 3.3×3.3 mm DFN part is used. Replace these values with datasheet values before sign-off.
