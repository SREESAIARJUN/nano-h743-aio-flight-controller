# STM32H743 Nano FC with Integrated 4-in-1 ESC (Job #38): Power-Stage Loss, Thermal, and Bi-Directional DShot600 Architecture

## 0. Scope and Assumptions

No component selections or board stack-up were provided, so this analysis uses a **parametric model with a declared reference parameter set**. Every result below is reproducible: substitute your actual datasheet values into the equations. Anything marked ⚠ must be verified against real parts or bench data before release.

**System partitioning.** This is the standard architecture:

- The H743 runs ArduPilot and emits bi-directional DShot600 on 4 (or 8) timer channels.
- Each of the 4 ESC channels has its own small MCU (AM32 or BLHeli_32 class, e.g. AT32F421 or STM32G071).
- Each ESC MCU generates the 48 kHz complementary PWM.
- The H743 never drives gates directly.
