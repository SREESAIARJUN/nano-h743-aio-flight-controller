# Job #54: STM32H743 AIO Flight Controller with 4-in-1 ESC

**Engineering Design Package, Revision A (Reference Design)**

## 0. Architecture Clarifications and Design Risks

Three issues shape every calculation below:

1. **Partitioning.** The STM32H743 runs ArduPilot as the flight controller. The four ESC channels each run a dedicated motor-control MCU (AT32F421 / STM32G071 class, running AM32 or BLHeli_32). The H743 does **not** commutate the motors. It sends bidirectional DShot600 to the ESC MCUs and receives eRPM telemetry back.
2. **80 A burst on a "nano" (20×20 mm) board.** This is thermally achievable only as a burst of about 1 s (derived in §3.5). Continuous capability is roughly 20–30 A per channel with prop-wash cooling. If the spec requires more than 1–2 s at 80 A, the board must grow to 30.5×30.5 mm or use 5×6 mm MOSFETs.
3. **Placeholder values.** Every device parameter marked **[A]** is an assumed representative value for 40 V, 3.3×3.3 mm DFN MOSFETs. Replace these with datasheet values for the selected part before release. The equations are general; the numbers are only as good as these inputs.

## 1. Electrical Operating Model (6-Step, Synchronous Rectification)

In trapezoidal commutation, two phases conduct in each 60° sector:

- **Active (PWM) leg.** The high-side switch (HS) conducts for duty fraction D. The complementary low-side switch (LS) conducts the freewheel current for 1−D. This happens with synchronous rectification, i.e. "complementary PWM" in AM32.
- **Return leg.** The LS is held fully ON for the whole sector.

The motor current therefore **always flows through exactly two channel-conducting MOSFETs** (excluding dead time). This holds for any duty cycle, which makes conduction loss independent of D to first order:

$$
P_{cond,ch} = I^2 \cdot 2\,R_{DS(on)}(T_j) + I^2 R_{Cu} + I^2 R_{shunt}
$$

## 2. Conduction Loss Model

### 2.1 Temperature-Dependent R_DS(on)

$$
R_{DS(on)}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]
