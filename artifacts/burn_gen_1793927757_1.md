## 1. FOC Current Loop (innermost, 20 kHz)

### 1.1 Transforms

The electrical angle comes from the mechanical angle and a calibrated offset:

θₑ = p·(θₘ − θ₀)

**Clarke transform** (amplitude-invariant, assuming balanced phases so i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**

- i_d = i_α·cos θₑ + i_β·sin θₑ
- i_q = −i_α·sin θₑ + i_β·cos θₑ

**Inverse Park:**

- v_α = v_d·cos θₑ − v_q·sin θₑ
- v_β = v_d·sin θₑ + v_q·cos θₑ

### 1.2 PMSM model and decoupled PI

The motor model in the d-q frame is:

- L·(di_d/dt) = v_d − R·i_d + ωₑ·L·i_q
- L·(di_q/dt) = v_q − R·i_q − ωₑ·(L·i_d + λ_m)

Here λ_m = Kt / (1.5·p) and ωₑ = p·ωₘ.

**Control law.** Each axis gets a PI plus a feedforward term that cancels the cross-coupling and back-EMF:

- v_d = PI_d(i_d* − i_d) − ωₑ·L·i_q
- v_q = PI_q(i_q* − i_q) + ωₑ·(L·i_d + λ_m)

**Gain selection (pole-zero cancellation).** Choosing

- K_p = L·ω_c
- K_i = R·ω_c

makes the closed-loop current response first-order: ω_c / (s + ω_c). Choose ω_c ≤ 2π·f_PWM / 10, i.e. about 2π·2 kHz.

**Voltage limit.** The SVPWM linear range is a circle:

√(v_d² + v_q²) ≤ V_bus / √3

If the vector exceeds this, give priority to v_d, then scale v_q into the remaining headroom.

**Anti-windup.** Use back-calculation, with K_aw = 1/K_p:

ẋ_I = K_i·e + K_aw·(u_sat − u_unsat)

### 1.3 SVPWM via min-max injection

1. Compute the three phase voltages:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
2. Compute the common-mode offset: v₀ = −[max(v_a, v_b, v_c) + min(v_a, v_b, v_c)] / 2
3. Compute each duty cycle: D_x = ½ + (v_x + v₀) / V_bus, for x ∈ {a, b, c}

This is mathematically identical to 7-segment SVPWM.

## 2. Cascaded Angle → Velocity Control

### 2.1 Structure

The cascade, from outside in:

1. **Angle loop (1 kHz)** produces a velocity command:
   ω* = K_pθ·e_θ + K_iθ·∫e_θ + ω_ff
   - e_θ = wrap(θ* − θ), with wrap mapping to [−π, π)
   - ω_ff is the setpoint rate (e.g. from a follow-mode trajectory)
2. **Velocity loop (4 kHz)** produces a q-axis current command:
   i_q* = PI_ω(ω* − ω̂) + J·α_ff / Kt + i_cog(θₘ) + i_fric(ω̂)
3. **Current loop (20 kHz)** produces the phase voltages (Section 1).

**The feedback signals for a gimbal.** For a stabilizer, the angle and velocity used in the outer loops should be the **camera's inertial attitude and rate from the IMU**, not the encoder angle. Each axis then rejects base motion directly.

- θ and ω̂ in the outer loops are the IMU-derived values, projected per joint.
- The encoder is still used for commutation (θₑ).
- The encoder also provides a high-bandwidth joint velocity estimate for an optional inner damping term.

### 2.2 Velocity-loop design

**Plant.** The mechanical axis is

ω/i_q = Kt / (J·s + b)

**Gains (PI zero at ω_v / 4):**

- K_pω = J·ω_v / Kt
- K_iω = K_pω·ω_v / 4

where ω_v is the desired velocity bandwidth, typically 2π·(80…150) Hz.

**Angle gain:**

K_pθ = ω_θ, with ω_θ ≈ ω_v / 5

**Bandwidth separation.** Keep each loop at least 4–5× slower than the one inside it:

ω_c ≥ 5·ω_v ≥ 25·ω_θ

### 2.3 Velocity estimation from the encoder (PLL)

A tracking PLL avoids differentiating a quantized angle. It runs every current-loop period, Tₛ = 1/20 kHz:

1. e = wrap(θ_enc − θ̂)
2. ω̂_new = ω̂ + K_i,pll·Tₛ·e
3. θ̂_new = θ̂ + Tₛ·(ω̂_new + K_p,pll·e)

**PLL gains** (critically damped, with ω_n,pll ≈ 2π·400 Hz):

- K_p,pll = 2ζ·ω_n,pll, with ζ = 1
- K_i,pll = ω_n,pll²

### 2.4 Discretization

| Element | Discretization |
|---|---|
| PI integrators | Forward Euler, with clamping plus back-calculation anti-windup. |
| D-term (if used in angle loop) | On the measurement, filtered with a first-order LPF. |

The filtered derivative is:

D_k = [τ_d·D_{k−1} − K_d·(y_k − y_{k−1})] / (τ_d + Tₛ)

A typical filter time constant is τ_d = 1 / (2π·N·f_bw), with N ≈ 5–10.
