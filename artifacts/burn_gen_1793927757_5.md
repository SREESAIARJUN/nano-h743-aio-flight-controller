# 3-Axis Gimbal: FOC Control, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

> **Assumptions.** I have no access to the specific Job #22 specification, so this design rests on a typical high-performance brushless gimbal. Every value that depends on the hardware is a named constant in the code (`AxisParams`, `ImuFusionParams`). Replace them with your measured values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (GM4108-class), 12N14P, so N_pp = 7 pole pairs |
| Winding | R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, gyro and accel ODR 8 kHz |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
