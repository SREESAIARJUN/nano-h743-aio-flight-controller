## 0. Scope and Assumptions

I don't have the Job #68 requirement documents, BOM, or stack-up, so every number below rests on the assumptions in this section. Treat this as a parametric reference model. Swap in your datasheet values and the equations still hold.

**Architecture clarification.** ArduPilot on the H743 does not commutate motors. A realistic implementation is:

- **FC domain:** STM32H743 running ArduPilot, sending bi-directional DShot600 on 4 timer channels.
- **ESC domain:** 4 independent ESC MCUs (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32). These generate the 48 kHz PWM and drive the gate drivers and MOSFETs.

The 48 kHz switching frequency is therefore an ESC firmware parameter, not an H743 one.

## 1. Conduction Loss Model

**Commutation.** Assume 6-step trapezoidal commutation with complementary (synchronous) PWM at duty D. Over one electrical period, each half-bridge leg spends:

- **1/3 as the PWM leg:** high-side (HS) on for fraction D, low-side (LS) on for (1−D).
- **1/3 as the return leg:** LS fully on.
- **1/3 floating:** no current.

**Conduction fractions per leg:**

$$\delta_{HS}=\frac{D}{3},\qquad \delta_{LS}=\frac{1-D}{3}+\frac{1}{3}$$

$$P_{cond,leg}=I^2R_{ds(on),T_j}\left(\delta_{HS}+\delta_{LS}\right)=\frac{2}{3}I^2R_{ds(on),T_j}$$

The result is **independent of D**, which is useful because burst current is often drawn at partial throttle.

**Per ESC (3 legs):**

$$P_{cond,ESC}=2\,I^2\,k_T\,R_{ds(on),25}$$

$$P_{cond,ESC}=2(80)^2(1.4)(1.0\,\text{m}\Omega)=\mathbf{17.9\ W}$$

**Copper path loss.** Add trace, via, and pad resistance. Assume R_cu ≈ 0.4 mΩ in the current path, which is always carrying I:

$$P_{cu,ESC}=I^2R_{cu}=6400\times0.4\text{ m}\Omega=\mathbf{2.6\ W}$$

Copper also has a positive tempco of +0.39 %/K, so this grows ~25 % at +60 K.

**Temperature-coupled form** (for solving self-consistently):

$$R_{ds}(T_j)=R_{25}\left[1+\alpha\,(T_j-25)\right],\quad \alpha\approx0.0053/\text{K}$$

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. The LS FET turns on after its body diode is already conducting, so its turn-on is near-ZVS. Each loss term below is per ESC with one active switching leg.

**(a) V-I overlap (HS hard switching):**

$$P_{VI}=\tfrac12V_{bus}I(t_r+t_f)f_{sw}=\tfrac12(25.2)(80)(30\text{ ns})(48\text{ kHz})=\mathbf{1.45\ W}$$

**(b) Reverse recovery of the LS body diode:**

$$P_{rr}=Q_{rr}V_{bus}f_{sw}=40\text{ nC}\cdot25.2\cdot48\text{k}=\mathbf{0.05\ W}$$

**(c) Output capacitance:**

$$P_{oss}\approx Q_{oss}V_{bus}f_{sw}=\mathbf{0.06\ W}$$

**(d) Dead-time diode conduction** (two dead-time intervals per PWM cycle):

$$P_{dt}=V_fI\,(2t_{dead})f_{sw}=0.8\cdot80\cdot400\text{ ns}\cdot48\text{k}=\mathbf{1.23\ W}$$
