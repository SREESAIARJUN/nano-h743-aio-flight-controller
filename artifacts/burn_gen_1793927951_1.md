## 1. Field-Oriented Control: the inner current loop

### 1.1 Transforms

The power-invariant variant is not used. The amplitude-invariant forms below are used throughout.

**Clarke transform** (three phase currents to two-axis α/β):

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3          (uses i_a + i_b + i_c = 0)
```

**Park transform** (stationary α/β to rotating d/q frame):

```
θ_e = p · θ_m − θ_offset
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

**Inverse Park transform**:

```
v_α = v_d cos θ_e − v_q sin θ_e
v_β = v_d sin θ_e + v_q cos θ_e
```

### 1.2 Plant model

The dq-frame model of a surface PMSM is:

```
L di_d/dt = v_d − R i_d + ω_e L i_q
L di_q/dt = v_q − R i_q − ω_e L i_d − ω_e λ
τ_e = (3/2) p λ i_q = Kt · i_q
```

### 1.3 Current PI tuning by pole-zero cancellation

Choose the PI zero to cancel the electrical pole:

```
Kp_i = L · ω_bw
Ki_i = R · ω_bw
```

This makes the closed loop first-order:

```
i_q / i_q* = ω_bw / (s + ω_bw)
```

Keep `ω_bw ≤ 2π · f_s / 20`. With `f_s = 20 kHz`, that gives `ω_bw ≈ 2π · 1 kHz`.

**Decoupling feedforward** removes the cross-coupling and back-EMF terms:

```
v_d,ff = −ω_e L i_q
v_q,ff =  ω_e L i_d + ω_e λ
```

### 1.4 Discrete PI with back-calculation anti-windup

The discrete form uses backward Euler:

```
e[k] = r[k] − y[k]
u_unsat[k] = Kp e[k] + I[k−1] + u_ff[k]
u[k] = sat(u_unsat[k])
I[k] = I[k−1] + Ki·Ts·e[k] + Kaw·(u[k] − u_unsat[k])        with Kaw ≈ Ki/Kp
```

**Voltage limiting.** The (v_d, v_q) vector is limited to the SVPWM linear-region circle:

```
|v_dq| ≤ V_bus / √3
```

The d-axis voltage has priority.

**SVPWM.** Use min-max zero-sequence injection:

```
v_a, v_b, v_c  = inverse Clarke of (v_α, v_β)
v_0 = −(max(v_a, v_b, v_c) + min(v_a, v_b, v_c)) / 2
duty_x = 0.5 + (v_x + v_0) / V_bus
```

## 2. Cascaded angle and velocity control

### 2.1 Mechanical plant

```
J θ̈ = Kt i_q − B θ̇ − τ_cog(θ) − τ_dist
```

Here `τ_dist` covers cable drag, imbalance, and vehicle motion.

### 2.2 Velocity estimation with a PLL observer

Raw differentiation of encoder angle is too noisy, so use a type-2 PLL tracking observer:

```
ε = wrap(θ_meas − θ̂)
θ̂̇ = ω̂ + k1 ε
ω̂̇ = k2 ε
```

Gains for a critically damped observer with bandwidth `ω_o`:

```
k1 = 2 ω_o
k2 = ω_o²
```

A typical choice is `ω_o ≈ 2π · 400 Hz`.

### 2.3 Velocity loop (PI, 4 kHz)

```
i_q* = Kp_v (ω* − ω̂) + Ki_v ∫(ω* − ω̂) dt + i_ff
```

With the current loop treated as ideal (it is about 10× faster), the open loop is:

```
L_v(s) = (Kt / (J s)) · (Kp_v + Ki_v / s)
```

For crossover `ω_v` and PI zero at `ω_v / 4`:

```
Kp_v = J ω_v / Kt
Ki_v = Kp_v ω_v / 4
```

The resulting phase margin is about 76°. Typical `ω_v` is 2π · 60–120 Hz.

### 2.4 Angle loop (P with velocity feedforward, 1 kHz)

```
ω* = Kp_θ · wrap(θ* − θ̂) + θ̇*_ff
Kp_θ = ω_v / 4          (a crossover separation of at least 4×)
```

### 2.5 Stabilization reference (the gimbal-specific part)

In stabilization mode the angle error is computed in the **inertial frame** from the fused IMU attitude, not from the encoder.

**Angle error:**

```
θ_err,axis = joint-mapped component of (q_target ⊗ q̂_cam⁻¹)
```

**Velocity reference.** Use the gyro rate projected onto the motor axis as the velocity "measurement" and blend it with the encoder:

```
ω_meas = α · ω_gyro,axis + (1 − α) · ω̂_enc
```

`α ≈ 1` is recommended. The gyro gives low-latency rejection of base motion; the encoder PLL supplies redundancy and observer stability.

**Torque feedforward:**

```
i_ff = J θ̈*_ff / Kt + B ω* / Kt + i_cog,ff(θ_m, ω̂)
```

## 3. Anti-cogging sinusoidal feedforward

### 3.1 Cogging model

The fundamental cogging order per mechanical revolution is `N_c = LCM(slots, 2p)`. For 12N14P, `N_c = LCM(12, 14) = 84`.

Manufacturing asymmetries add components at harmonics of `N_c` and at low orders tied to slots and poles. A general Fourier model over a selected set of orders 𝒦 is:

```
τ_cog(θ_m) = Σ_{k ∈ 𝒦} [ a_k cos(k θ_m) + b_k sin(k θ_m) ]
```

A typical choice is `𝒦 = {N_c, 2N_c, 3N_c, slots, 2p}`.

The feedforward current is:

```
i_cog,ff(θ_m) = (1 / Kt) Σ_k [ a_k cos(k θ_m) + b_k sin(k θ_m) ]
```

Note the sign: this adds the torque the motor must produce to cancel cogging.

### 3.2 Identification by adaptive feedforward cancellation (LMS)

Run a constant low-speed sweep, for example `ω* = 0.5 rad/s` in encoder-angle mode, with the payload balanced.

In steady state the residual disturbance is absorbed by the velocity loop. That makes the feedback portion of the command a direct measure of uncancelled cogging:

```
e_c = i_q,fb = i_q* − i_ff
```

```
