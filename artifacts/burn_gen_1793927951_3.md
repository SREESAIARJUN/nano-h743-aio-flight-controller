# FOC Control, Anti-Cogging, and Dual-IMU Filtering for the 3-Axis Gimbal (Job #43)

I don't have the Job #43 specification sheet, so this design rests on the assumptions in §0. Every parameter that depends on them is a named constant, so you can substitute the real values.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC (GBM2804-class): 12N14P → **7 pole pairs**, R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| Current sense | 2 low-side or in-line shunts per motor |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro/accel ODR 8 kHz |
| Kinematic order | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |

**Loop rates and bandwidths**

| Loop | Rate | Bandwidth target |
|---|---|---|
| PWM | 40 kHz center-aligned | – |
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Gyro rate loop | 4 kHz | ~80–150 Hz |
| Attitude loop | 1 kHz | ~10–20 Hz |
| AHRS | 1 kHz | – |
