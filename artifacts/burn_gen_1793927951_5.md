## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs *p* = 7), R = 5.6 Ω, L = 2.1 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A class) over SPI |
| Current sensing | Optional. Inline shunts supported; a voltage-mode fallback is also provided. |
| IMU | 2 × ICM-42688-P on the camera plate, mounted **symmetrically about the rotation centroid**, on separate SPI chip selects |
| MCU | Cortex-M4F/M7 with FPU (e.g. STM32G474), center-aligned PWM at 20 kHz |
| Bus | 12–16 V |

Loop rates and the bandwidth separation of the cascade (each loop is ≥5× slower than the loop inside it):

```
 PWM / FOC current loop    20 kHz   (ISR, ADC-triggered)       BW ≈ 1.5 kHz
 IMU sample + filtering     8 kHz   (ICM ODR, DRDY/FIFO)
 Velocity (rate) loop       4 kHz                               BW ≈ 150 Hz
 Attitude fusion            1 kHz
 Angle loop                 1 kHz                               BW ≈ 25 Hz
 Cogging LMS adaptation     1 kHz   (background, gated)
```

## 1. FOC Equations

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

θ_off is found at commissioning. Apply V_d > 0, V_q = 0, wait for the rotor to settle, then record θ_m.

### 1.2 Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
