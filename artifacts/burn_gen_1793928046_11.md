# 3-Axis Gimbal FOC Control and Dual-IMU Fusion (Job #22)

I don't have the Job #22 hardware spec, so this design is parameterized. The assumed baseline is listed below. Change the constants in `config.hpp` and every derived gain recomputes.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| MCU | STM32G4 / H7 class, single-precision FPU |
| Current sensing | 2-phase inline or low-side shunts |
| IMUs | 2 × ICM-42688-P on separate SPI buses, shared CLKIN (external 32 kHz clock) |
| Loop rates | Current 20 kHz, velocity 4 kHz, angle/attitude 1 kHz, IMU ODR 8 kHz |
