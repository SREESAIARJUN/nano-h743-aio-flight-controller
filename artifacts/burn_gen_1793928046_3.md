## 1. Control Architecture

```
 q_ref ─►[Attitude P (quaternion)]─ω_ref─►[Rate PI-D (payload frame, gyro fb)]─τ_p─►[Jᵀ]─τ_j─┐
            ▲ q̂                                ▲ ω̂ (fused dual-gyro)                         │
            │                                  │                                              ▼
       [Mahony AHRS]◄──[Dual ICM-42688 fusion + notch/LPF]                τ_j/Kt + i_cog(θ) = i_q*
                                                                                              │
                                    θ_m (encoder) ──► electrical angle ──► [dq Current PI + SVPWM]
```

The rate loop runs in the **payload frame**. It produces a desired payload torque τ_p, which is mapped to joint torques by the transpose Jacobian (principle of virtual work). Feeding back the gyro rate rejects base motion directly, which is better than using encoder velocity.

## 2. FOC Current Loop (25 kHz)

### 2.1 Transforms

Electrical angle:

  θ_e = p · (θ_m − θ_offset)

**Clarke** (amplitude-invariant, with i_a + i_b + i_c = 0):

  i_α = i_a
  i_β = (i_a + 2 i_b) / √3

**Park**:

  i_d = i_α cos θ_e + i_β sin θ_e
  i_q = −i_α sin θ_e + i_β cos θ_e

### 2.2 PMSM model in the dq frame

  v_d = R i_d + L di_d/dt − ω_e L i_q
  v_q = R i_q + L di_q/dt + ω_e (L i_d + ψ_m)

Torque (surface magnet, L_d = L_q):

  τ = (3/2) p ψ_m i_q = K_t i_q

### 2.3 Discrete PI with decoupling and back-calculation anti-windup

With error e_x = i_x* − i_x for x ∈ {d, q}:

  u_x[k] = K_p e_x[k] + I_x[k]

The decoupling feedforward terms are added after the PI:

  v_d* = u_d − ω_e L i_q
  v_q* = u_q + ω_e (L i_d + ψ_m)

The voltage limit is a circle with radius V_max = V_dc/√3 (linear SVPWM range), with the d-axis given priority:

  v_d,s = clamp(v_d*, ±V_max)
  v_q,s = clamp(v_q*, ±√(V_max² − v_d,s²))

The integrator update includes the anti-windup term:

  I_x[k+1] = I_x[k] + K_i T_s e_x[k] + K_aw T_s (v_x,s − v_x*)

**Tuning by pole–zero cancellation.** Set the PI zero equal to the plant pole R/L:

  K_p = L ω_c,  K_i = R ω_c

The closed loop then becomes first-order with bandwidth ω_c. Use ω_c ≈ 2π · 1.5 kHz (≤ f_PWM/15) and K_aw ≈ ω_c / K_p.

### 2.4 Midpoint-clamp SVPWM

1. Inverse Park:

  v_α = v_d cos θ − v_q sin θ
  v_β = v_d sin θ + v_q cos θ

2. Inverse Clarke:

  v_a = v_α
  v_b = −½ v_α + (√3/2) v_β
  v_c = −½ v_α − (√3/2) v_β

3. Zero-sequence injection and duty cycles:

  v_0 = −(max(v_abc) + min(v_abc)) / 2
  D_x = ½ + (v_x + v_0) / V_dc

This is mathematically equivalent to 7-segment SVPWM.

**Delay compensation.** Advance the angle used for the inverse Park by 1.5 T_s:

  θ_e,PWM = θ_e + 1.5 ω_e T_s
