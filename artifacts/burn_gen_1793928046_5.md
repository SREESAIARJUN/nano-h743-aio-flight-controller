# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion: Design and C++ Implementation

I don't have the Job #14 specification. The design below therefore uses explicit, typical parameters for a brushless gimbal: a 12N14P motor, a 14-bit magnetic encoder, an STM32G4/H7-class MCU with an FPU, and two ICM-42688-P IMUs on separate SPI buses. Every value is a named constant. Replace them with your measured R, L, Kt, J, and geometry before deployment.

---

## 1. Architecture and Loop Rates

| Loop | Rate | Feedback | Output |
|---|---|---|---|
| Current (FOC) | 20 kHz (PWM center ISR) | Phase currents, encoder θ | SVPWM duty |
| Velocity + anti-cogging | 4 kHz | Fused IMU gyro (stabilization) + encoder rate | i_q* |
| Angle / attitude | 1 kHz | Fused attitude quaternion | ω* |
| IMU acquisition | 8 kHz ODR, DMA | 2× ICM-42688-P | Filtered ω, a |

Each outer loop's bandwidth should be no more than about 1/5 of the inner loop's: ω_c ≫ ω_v ≫ ω_θ.

## 2. Field-Oriented Current Control

### 2.1 Transforms
With θ_e = p·θ_m − θ_off, where p is the pole-pair count (7 here):

Clarke (amplitude-invariant, i_a + i_b + i_c = 0):
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

Park:
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 PMSM model and decoupled PI
The machine model in the d-q frame is:
$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q\dot i_q + \omega_e(L_d i_d + \lambda_m)$$

Use pole-zero cancellation for each axis. The plant is 1/(Ls+R) and the controller is K_p + K_i/s:
$$K_{p,c} = L\,\omega_c,\qquad K_{i,c} = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Here ω_c = 2π·1.5 kHz is less than f_s/10 at 20 kHz.

Feedforward decoupling:
$$v_d = \text{PI}_d - \omega_e L_q i_q,\qquad v_q = \text{PI}_q + \omega_e(L_d i_d + \lambda_m)$$

### 2.3 Voltage limiting and anti-windup
The voltage vector is limited to the inscribed hexagon circle:
$$|v_{dq}| \le V_{dc}/\sqrt3$$

The d-axis has priority:
$$v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$$

Integrators use back-calculation:
$$x_I[k{+}1] = x_I[k] + T_s\left(K_i e + K_{aw}(u_{sat}-u)\right),\qquad K_{aw}\approx K_i/K_p$$

### 2.4 SVPWM via min-max zero-sequence injection
$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12(\max + \min),\quad d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically equivalent to sector-based SVPWM.

## 3. Cascaded Angle / Velocity Control

### 3.1 Mechanical plant (per axis)
$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist},\qquad K_t = \tfrac32 p\lambda_m$$

### 3.2 Gimbal kinematics (stabilization)
The camera body rate is:
$$\boldsymbol\omega_{cam} = R^{T}_{base\to cam}\boldsymbol\omega_{base} + J_g(\boldsymbol\theta)\,\dot{\boldsymbol\theta}$$

For a yaw-roll-pitch (outer → inner) stack:
$$J_g(\boldsymbol\theta)=\begin{bmatrix}-\cos\theta_r\sin\theta_p & \cos\theta_p & 0\\ \sin\theta_r & 0 & 1\\ \cos\theta_r\cos\theta_p & \sin\theta_p & 0\end{bmatrix}$$

The columns are the yaw, roll, and pitch joint axes expressed in the camera frame. The velocity loop regulates the camera rate measured by the IMU. The commanded joint rates are:
$$\dot{\boldsymbol\theta}^* = J_g^{-1}(\boldsymbol\omega^*_{cam} - \hat{\boldsymbol\omega}_{base,cam})$$
