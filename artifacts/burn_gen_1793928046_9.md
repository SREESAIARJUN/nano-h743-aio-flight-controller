# Job #37: 3-Axis Gimbal FOC Control and Dual-IMU Fusion

## 0. Design Assumptions

I don't have the Job #37 specification, so the design rests on the baseline below. Every item is a named constant in the code, so you can change any of them.

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit magnetic encoder (AS5048A or MT6701) per axis, SPI |
| MCU | STM32G4 / H7 class with FPU (float32 throughout) |
| Current sensing | 2-shunt inline or low-side |
| Mechanical order | Yaw (outer) → Roll → Pitch (inner, camera) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, clocked from a shared 32 kHz CLKIN |

Loop rates:

| Loop | Rate | Period |
|---|---|---|
| PWM / current (FOC) | 20 kHz | Ts_i = 50 µs |
| Velocity | 4 kHz | Ts_v = 250 µs |
| Attitude/angle and IMU fusion | 1 kHz (IMU raw ODR 8 kHz, decimated) | 1 ms |

If the motors have no current sense, use the voltage-mode fallback in §1.6.

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at commissioning by applying v_d with v_q = 0 and reading the encoder.

Latency compensation: the PWM update happens about 1.5 Ts_i after sampling, so advance the angle used by the inverse Park transform:
$$\theta_e^{\text{inv}} = \theta_e + 1.5\,\omega_e T_{s,i}$$

### 1.2 Clarke transform (power-invariant form not used; amplitude-invariant)
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\qquad(i_a+i_b+i_c=0)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 dq current PI with decoupling
The plant per axis is
$$L\,\dot i_d = v_d - R i_d + \omega_e L i_q,\qquad L\,\dot i_q = v_q - R i_q - \omega_e L i_d - \omega_e\lambda_m$$

The control law cancels the cross-coupling and back-EMF terms:
$$v_d = \text{PI}_d(i_d^\* - i_d) - \omega_e L i_q,\qquad v_q = \text{PI}_q(i_q^\* - i_q) + \omega_e L i_d + \omega_e \lambda_m$$

Gains by pole-zero cancellation give a first-order closed loop of bandwidth ω_c:
$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{\text{pwm}}}{10}\ (\approx 2\pi\cdot 2\,\text{kHz})$$
