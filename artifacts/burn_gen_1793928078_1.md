# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion Design (Job #52)

## 0. Assumptions

I don't have the Job #52 spec sheet, so this design rests on the baseline below. Every assumed value is a named parameter in the code. Replace each one with your real values before you run hardware.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU, 3× ADC, HRTIM/TIM1) |
| Motors | Gimbal BLDC 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) via SPI |
| Current sense | 2-shunt or 3-shunt, synchronous to PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR = 8 kHz, UI-path AAF enabled |
| Loop rates | Current/FOC 20 kHz · velocity 4 kHz · attitude 1 kHz |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → camera |

**Loop separation rule.** Each loop's bandwidth is at least 5× below the loop inside it:

| Loop | Bandwidth |
|---|---|
| Current | ω_c ≈ 2π·1500 rad/s |
| Velocity | ω_v ≈ 2π·150 rad/s |
| Attitude | ω_p ≈ 2π·20 rad/s |
