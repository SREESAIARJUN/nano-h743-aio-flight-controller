**Architectural assumption.** The H743 does **not** generate the 48 kHz bridge PWM. Each motor has a dedicated ESC MCU (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32) that does commutation and PWM. The H743 talks to the four ESC MCUs over bidirectional DShot600. This is the only practical partition. ArduPilot cannot run sensorless commutation on the FC.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current through the bridge

The model assumes 6-step trapezoidal control with synchronous (complementary) PWM. At any instant, current flows through one high-side/low-side pair in the PWM phase plus one static low-side FET in the return phase.

- **Phase current ripple.** At D = 0.95, the ripple is negligible:
  ΔI = V_bus · D(1−D) / (L_pp · f_sw) = 22.2 × 0.95 × 0.05 / (20e-6 × 48e3) ≈ **1.1 A p-p**
- **RMS current.** I_rms² = I_ph² + ΔI²/12 ≈ 80² + 0.1 ≈ 6400 A²

### 1.2 Temperature-dependent on-resistance

R_DS(T_j) = R₂₅ · [1 + α(T_j − 25)]

At T_j = 110 °C: R_DS = 1.0 × (1 + 0.006 × 85) = **1.51 mΩ**

### 1.3 Bridge loss

The PWM leg contributes I²R·D + I²R·(1−D) = I²R. The static return FET contributes another I²R. So:

P_cond,bridge = 2 · I_rms² · R_DS(T_j) = 2 × 6400 × 1.51e-3
