# STM32H743 AIO Flight Controller + 80 A 4-in-1 ESC: Design Model (Job #34)

## 0. Assumptions and Architecture

I don't have the Job #34 requirements document, so this model rests on the stated assumptions below. Each one is parameterized: replace the number and the equations still hold. **Verify every part number and parameter against current datasheets before layout.**

**Architecture.** The STM32H743 runs ArduPilot and generates DShot600. Each ESC channel has its own small MCU (AT32F421 / STM32G071 class, AM32 or BLHeli_32) driving a 3-phase bridge. The H743 does not commutate the motors directly, because ArduPilot has no on-board FOC/6-step ESC driver.

| Symbol | Value | Notes |
|---|---|---|
| V_bus | 24 V (6S nominal 22.2 V, 25.2 V max) | Design point |
| I_ph | 80 A burst, per channel | Motor phase current, not battery current |
| f_sw | 48 kHz | Complementary (synchronous) PWM |
