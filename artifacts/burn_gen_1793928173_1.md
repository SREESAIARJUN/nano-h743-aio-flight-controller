# STM32H743 Nano FC + 80 A 4-in-1 ESC (Job #21): Design Model

## 0. Architecture and Assumptions

The STM32H743 cannot practically run four sensorless BLDC commutation loops and ArduPilot at once. The design therefore uses the standard split:

```
 ┌──────────────────────────┐   DShot600 bidir (4×)   ┌────────────────────────────────┐
 │ FC: STM32H743VIT6 @480MHz│◄──────────────────────►│ 4-in-1 ESC: 4× AT32F421K8U7      │
 │ ArduPilot (ChibiOS)      │   VBAT/CURR/GND/TLM     │ AM32 firmware, 48 kHz PWM        │
 └──────────────────────────┘                         │ 4× FD6288Q, 24× 40 V N-MOSFET    │
                                                      └────────────────────────────────┘
```

All numbers below follow from the parameters in this table. Replace them with your selected MOSFET's datasheet values; the equations stay the same.

| Symbol | Meaning | Value |
|---|---|---|
| V_bus | 6S, full charge (worst case) / nominal | 25.2 V / 22.2 V |
| I_ph | Burst phase current per motor | 80 A |
| f_sw | PWM frequency | 48 kHz |
| R_ds,25 | R_ds(on) @ V_GS = 10 V, 25 °C (40 V, PDFN5×6) | 1.2 mΩ |
| α | R_ds temperature coefficient | 0.006 /K (≈1.6× at 125 °C) |
| Q_g / Q_gs2 / Q_gd | Gate charges | 50 / 4 / 8 nC |
| V_plateau | Miller plateau voltage | 4.5 V |
| R_g,int / R_g,ext / R_drv | Internal gate R / external gate R / driver output R | 1.5 / 10 / 7 Ω |
| V_drv | Gate drive voltage | 12 V |
| Q_rr | Body diode reverse recovery @ 80 A | 80 nC |
| C_o(er) | Energy-equivalent output capacitance | 1.0 nF |
| V_f | Body-diode forward drop | 0.8 V |
| t_dead | Dead time per edge | 300 ns |
| R_θJC | Junction-to-case thermal resistance | 1.2 K/W |
