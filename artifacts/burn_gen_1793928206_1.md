# Job #60: STM32H743 Nano AIO (FC + 4-in-1 ESC) Systems Model

## 0. Scope, Architecture Correction, and Assumptions

**Architecture clarification.** In a production 4-in-1 AIO, the STM32H743 does **not** commutate the motors. It runs ArduPilot and sends **bi-directional DShot600** to four dedicated ESC MCUs, which run AM32 or BLHeli_32 and generate the 48 kHz PWM. This document uses that partition:

- **FC domain:** STM32H743VIH6 at 400 MHz. Runs ArduPilot, DShot600 output, and eRPM telemetry capture.
- **ESC domain:** 4 × AT32F421K8U7 running AM32. Each drives one 3-phase gate driver and 6 MOSFETs at 48 kHz.

**Assumptions.** No part numbers were specified, so the model is parametric. Substitute your BOM values into the equations. These assumptions drive every number below.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Phase current, burst | I_ph | 80 A per ESC |
| MOSFET | — | 60 V N-ch, PQFN 5×6 |
| R_DS(on) at 25 °C, V_GS = 10 V | R₂₅ | 1.8 mΩ |
| R_DS(on) temperature coefficient | α | 0.0045 /K |
| Rise / fall time (2 A driver) | t_r, t_f | 25 ns each |
| Total gate charge | Q_g | 50 nC |
| Reverse recovery charge | Q_rr | 60 nC |
| Output charge | Q_oss | 50 nC |
| Body diode forward voltage | V_F | 0.8 V |
| Dead time | t_dt | 100 ns |
| PWM frequency | f_sw | 48 kHz |
| Junction-to-PCB thermal resistance | R_th(j-pcb) | 1.5 K/W |

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C: R = 1.8 mΩ × 1.383 = **2.49 mΩ**.

### 1.2 Current paths in trapezoidal 6-step with synchronous complementary PWM

During each 60° sector, two phases conduct:

- **Switched leg:** the high-side FET conducts for D, and the low-side FET of the same leg (synchronous rectification) conducts for 1−D. Both carry I_ph.
- **Static leg:** the low-side FET is fully ON for the whole sector.

$$P_{cond,ESC} = I_{ph}^2 R_{DS}\,[D + (1-D)] + I_{ph}^2 R_{DS} = 2\,I_{ph}^2 R_{DS}(T_j)$$

This is **independent of duty cycle**. That is a key result: burst current limits are thermal, not throttle, dependent.

$$P_{cond,ESC} = 2 \times 80^2 \times 2.49\times10^{-3} = \mathbf{31.9\ W}$$

### 1.3 Per-FET worst case

The static low-side FET dissipates I²R for the full sector, so its peak is 15.9 W.

Averaged over the electrical cycle, each FET conducts for 1/3 of the cycle. The average per FET is 2·I²R / 6 ≈ **5.3 W**, but the instantaneous peak of 15.9 W dominates T_j at low eRPM and during stall or punch-out.

### 1.4 Electrothermal feedback (stability check)

R_DS(on) rises with T_j, so the operating point must be checked for thermal runaway. Stability requires:

$$\frac{\partial P}{\partial T_j}\,R_{th} < 1 \;\Rightarrow\; I^2 R_{25}\,\alpha\,R_{th} = 80^2(1.8\text{m})(0.0045)(1.5) = 0.078 < 1 \;\checkmark$$

The operating point is stable at the junction level. The board level is checked in Section 4.

### 1.5 Copper and shunt losses

- **Phase and bus traces:** about 0.5 mΩ per path on 2 oz, 6-layer copper with stitched planes. This gives 80² × 0.5 m ≈ **3.2 W per ESC**.
- **Current shunt:** 0.25 mΩ, common to all four ESCs. Battery current is I_bat ≈ Σ(D·I_ph). At an aggregate 160 A burst, P = 160² × 0.25 m = **6.4 W**.

## 2. Switching Loss Model at 48 kHz

Only the switched leg commutates at f_sw. Each term below is per ESC.

### 2.1 V-I overlap (hard switching, inductive load)

$$P_{VI} = \tfrac{1}{2} V_{bus} I_{ph} (t_r + t_f) f_{sw} = 0.5(25.2)(80)(50\text{n})(48\text{k}) = \mathbf{2.42\ W}$$

### 2.2 Dead-time body-diode conduction

There are two dead-time intervals per PWM period:

$$P_{dt} = V_F I_{ph} (2 t_{dt}) f_{sw} = 0.8 \times 80 \times 200\text{n} \times 48\text{k} = \mathbf{0.61\ W}$$

### 2.3 Reverse recovery

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 60\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.073\ W}$$

### 2.4 Output capacitance

$$P_{oss} = \tfrac{1}{2} Q_{oss} V_{bus} f_{sw} = 0.5 \times 50\text{n} \times 25.2 \times 48\text{k} = \mathbf{0.030\ W}$$

### 2.5 Gate drive

This loss is dissipated in the driver and gate resistors, not in the FET:

$$P_g = 2\,Q_g V_{GS} f_{sw} = 2 \times 50\text{n} \times 10 \times 48\text{k} = \mathbf{0.048\ W}$$

### 2.6 Switching total and frequency sensitivity

$$P_{sw,ESC} \approx 3.14\ \text{W}$$
