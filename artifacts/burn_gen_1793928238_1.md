# 3-Axis Gimbal FOC Control & Dual-IMU Fusion: Design Specification and Reference Implementation

I don't have the Job #43 hardware specification, so the design rests on the assumptions below. Every assumption is collected in one config block in the code, so you can swap in your actual values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Driver | 3-phase, center-aligned PWM 20 kHz, 2–3 low-side shunts or inline current sense |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on each joint |
| IMUs | 2× ICM-42688-P on SPI @ 8 kHz ODR. IMU0 is on the camera plate (feedback). IMU1 is on the base/handle (disturbance feedforward and redundancy). |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle/attitude 1 kHz · IMU sampling 8 kHz |

## 1. System Architecture

```
                 1 kHz                       4 kHz                      20 kHz
 q_ref ──►[Attitude error]──► θ_j,ref ──►[Angle P(I)]──►ω_ref──►[Vel PI]──►i_q,ref──►[Current PI dq]──►SVPWM
              ▲                    │            ▲          ▲         ▲   ▲            ▲
              │            ω_ff (base gyro      │          │  cogging FF  │      θ_e (delay-compensated)
     IMU0 fused attitude    feedforward)        θ_j (enc)  ω_j (enc/obs)   i_abc (shunts)
     (Mahony, vib-filtered)  IMU1 filtered gyro
```

**Bandwidth separation rule.** Each outer loop gets crossover ≤ ¼ of the next inner loop. This lets the inner loop be treated as unity gain with a first-order lag.

| Loop | Rate | Target crossover |
|---|---|---|
| Current | 20 kHz | ~1.5–2 kHz |
| Velocity | 4 kHz | ~150–300 Hz |
| Angle | 1 kHz | ~30–60 Hz |
| Attitude (IMU) | 1 kHz | ~10–25 Hz |

## 2. Field-Oriented Current Loop (20 kHz)

### 2.1 Transforms (amplitude-invariant)

**Clarke transform:**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(\text{using } i_a+i_b+i_c=0)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Electrical angle:** θ_e = p(θ_m − θ_offset).

**Delay compensation.** The voltage computed from sample k is applied over the next PWM period, so on average it acts at t_k + 1.5 T_s. Use the compensated angle in the inverse Park transform:

$$\hat\theta_e = \theta_e + 1.5\,\omega_e T_s$$

### 2.2 Plant and PI design

The PMSM dq model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The decoupling and back-EMF feedforward is:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m$$

Pole-zero cancellation with bandwidth ω_c gives:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c\quad\Rightarrow\quad \frac{i}{i_{ref}} = \frac{\omega_c}{s+\omega_c}$$

Choose ω_c ≤ 2π·f_pwm/10.
