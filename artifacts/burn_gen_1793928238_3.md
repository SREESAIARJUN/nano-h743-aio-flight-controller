## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, using electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.3 PI with decoupling: pole-zero cancellation design

Choose the PI zero to cancel the electrical pole R/L. With target current-loop bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The closed loop then reduces to exactly first order:

$$\frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Bandwidth constraint: ω_c ≤ 2π·f_pwm/20. At 20 kHz this gives ω_c ≈ 2π·1 kHz.

Voltage commands with decoupling and back-EMF feedforward:

$$v_d^* = PI_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = PI_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Set i_d* = 0.

### 1.4 Saturation and anti-windup

Limit the voltage vector to the SVPWM linear region:

$$|v| \le V_{dc}/\sqrt3$$

Give d-axis priority, then let q take the remaining headroom:

$$|v_q|\le\sqrt{V_{max}^2-v_d^2}$$

Back-calculation anti-windup, applied to every PI in this design:

$$x_I[k+1] = x_I[k] + T_s\left(K_i e[k] + K_{aw}(u_{sat}[k]-u[k])\right),\qquad K_{aw}\approx K_i/K_p$$
