# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #49, so the design below states its assumptions explicitly. Replace the parameters in `GimbalConfig` with your actual hardware values.

**Assumptions:**
- Motors: hollow-shaft gimbal BLDC, 12N14P (GBM2804-class). Pole pairs p = 7, R ≈ 5–12 Ω, L ≈ 1–3 mH.
- Sensing: 14-bit magnetic encoder (AS5048A or MT6701) per axis, plus 2–3 phase current shunts.
- IMUs: two ICM-42688-P on the camera plate, SPI, gyro and accel ODR 8 kHz, FSYNC-aligned.
- Kinematic chain: base → Yaw(z) → Roll(x) → Pitch(y) → camera.

## 1. Loop Architecture and Timing

| Loop | Rate | Bandwidth target | Feedback |
|---|---|---|---|
| Current (d/q PI) | 20 kHz (PWM-synchronous) | 1.5–2 kHz | phase shunts |
| Inertial rate (PI) | 4 kHz | 150–250 Hz | fused gyro (Jacobian-mapped) |
| Attitude (P + rate feedforward) | 1 kHz | 15–30 Hz | AHRS quaternion |
| Cogging feedforward | 20 kHz evaluation, 4 kHz adaptation | — | encoder angle |
| AHRS / IMU fusion | 8 kHz in, 1 kHz attitude | — | 2× ICM-42688-P |

Each loop's bandwidth is at least 5× below the loop inside it. This lets each inner loop be treated as unity gain when tuning the next loop out.

## 2. Field-Oriented Control Equations

### 2.1 Coordinate transforms

**Clarke transform (amplitude-invariant):**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(\text{using } i_a+i_b+i_c=0)$$

**Park transform.** The electrical angle is $\theta_e = p\,\theta_m - \theta_{\text{off}}$, where $\theta_{\text{off}}$ comes from encoder alignment.

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
