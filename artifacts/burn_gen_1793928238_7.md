# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have a spec for "Job #32," so this design uses the hardware assumptions in §0. Every equation is written in terms of symbolic parameters. Replace the defaults with your measured values and the gains will follow from the formulas.

---

## 0. Assumptions and Loop Timing

| Item | Assumption |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motor | Gimbal BLDC, 12N14P (GBM2804-class), pole pairs **p = 7** |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| Current sense | 2-shunt low-side, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on separate SPI buses, shared CLKIN (32.768 kHz) |
| PWM | 20 kHz, center-aligned |

Timing hierarchy. Each outer loop has 5–10× less bandwidth than the loop inside it.

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz (Ts = 50 µs) | ω_c ≈ 2π·1500 rad/s |
| Velocity (rate) PI + cogging FF | 4 kHz | ω_v ≈ 2π·150 rad/s |
| Angle P(I) | 1 kHz | ω_p ≈ 2π·20 rad/s |
| IMU sample and filter | 8 kHz ODR, decimated to 4 kHz | n/a |
| Attitude (Mahony) | 1 kHz | n/a |
