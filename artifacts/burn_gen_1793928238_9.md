# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #50 specification, so **Section 0 lists the assumptions this design rests on**. Every constant that depends on hardware is collected in one config struct so you can substitute your motor, encoder, MCU and mounting data.

---

## 0. Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7). Example: R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.075 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 / MA732), SPI read on every current-loop tick |
| Current sensing | 2-phase inline shunts. A voltage-mode fallback is provided for boards without shunts. |
| MCU | STM32G4 / H7-class Cortex-M4F/M7, single-precision FPU |
| Loop rates | Current 20 kHz, velocity 4 kHz, angle 1 kHz, attitude estimator 1 kHz |
| IMU-C | ICM-42688-P rigidly on the camera plate. It provides attitude and rate feedback. |
| IMU-B | ICM-42688-P on the base/handle. It provides base-motion feedforward and the vibration reference. |
| IMU interface | Both at gyro/accel ODR 8 kHz, ±2000 dps, ±16 g, FIFO or DRDY driven |
| Joint order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Electrical angle and speed observer

The electrical angle is computed from the mechanical angle, pole pairs and calibrated offset:

$$\theta_e = \operatorname{wrap}_{2\pi}\!\big(p\,\theta_m - \theta_{off}\big)$$

Finite-differencing the encoder amplifies quantization noise (2π/2¹⁴ ≈ 0.38 mrad per count). Use a type-II PLL tracking observer instead:

$$
\begin{aligned}
e_k &= \operatorname{wrap}_{\pm\pi}(\theta_{m,k} - \hat\theta_{k-1})\\
\hat\omega_k &= \hat\omega_{k-1} + T_s K_i e_k\\
\hat\theta_k &= \hat\theta_{k-1} + T_s(\hat\omega_k + K_p e_k)
\end{aligned}
\qquad K_p = 2\zeta\omega_n,\;\; K_i=\omega_n^2
$$

Recommended values are ωₙ = 2π·400 rad/s and ζ = 1. The closed-loop transfer from θ_m to θ̂ is

$$\frac{K_p s + K_i}{s^2+K_p s+K_i}$$

so there is zero steady-state lag at constant speed.
