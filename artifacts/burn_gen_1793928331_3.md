# STM32H743 Nano FC + 4-in-1 ESC (Job #8): Power Stage, Thermal, and DShot Architecture

## 0. Feasibility Findings

These findings constrain everything that follows.

1. **The H743 should not commutate the motors directly.** Running four sensorless 6-step or FOC loops at 48 kHz alongside ArduPilot's scheduler is not a supported ArduPilot configuration. The architecture below therefore uses:
   - the H743 as flight controller, emitting bi-directional DShot600, and
   - four dedicated ESC MCUs (AT32F421 or STM32G071) running AM32 or BLHeli_32.
2. **80 A per motor is a burst rating, not a continuous one.** On a 30.5 mm-pattern board (~36×36 mm), the board's thermal mass limits 80 A on all four motors to about 5 seconds (see §3). Continuous capability is roughly 35–40 A per motor without forced airflow.
3. **All component parameters are representative placeholders.** They stand in for a 40 V, ~1 mΩ, PQFN 3.3×3.3 or 5×6 MOSFET class. Before release, substitute datasheet values for the actual part.

| Parameter | Symbol | Value |

| Reverse recovery charge | Q_rr | 40 nC |
| Total gate charge | Q_g | 50 nC at V_GS = 10 V |

**Topology:** 6-step trapezoidal with synchronous rectification (complementary PWM). In every commutation sector, one high-side and one low-side FET carry I_ph. Each FET conducts for 120° of every 360° electrical cycle.

## 2. Loss Model (per motor, at 80 A burst)

### 2.1 Conduction Loss

With synchronous rectification, the current path always contains exactly two channel resistances, whatever the duty cycle D:

$$P_{cond} = I_{ph}^2 \cdot \big[D\cdot R_{HS} + (1-D)\cdot R_{LS}\big] + I_{ph}^2 R_{LS,\,static} \;=\; 2\,I_{ph}^2\,R_{DS}(T_j)$$

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)],\quad \alpha \approx 0.006\ \text{K}^{-1} \Rightarrow R_{DS}(125^\circ C) \approx 1.6\ \text{m}\Omega$$

$$P_{cond} = 2 \times 80^2 \times 1.6\times10^{-3} = \mathbf{20.5\ W}$$

**Electrothermal feedback.** R_DS(on) rises with T_j, so the operating point must be solved iteratively:

$$T_j^{(n+1)} = T_{board} + R_{th,j\text{-}b}\cdot P_{FET}\big(R_{DS}(T_j^{(n)})\big)$$

Thermal runaway is avoided only while:

$$\frac{\partial P}{\partial T}\cdot R_{th} = \alpha \, P_{cond,FET}\, R_{th} < 1$$

**Copper trace and shunt loss.** Assume 0.5 mΩ of board copper per phase path plus a 0.25 mΩ shunt:

$$P_{Cu} = 80^2 \times 0.75\times10^{-3} = 4.8\ \text{W}$$

### 2.2 Switching Loss at 48 kHz

Only the PWM-switched leg switches hard. The commutation leg changes state at the electrical frequency only, which is negligible.

**Hard-switching V-I overlap:**
$$P_{sw} = \tfrac12 V_{bus} I_{ph}(t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 40\text{ns} \times 48\text{k} = \mathbf{1.94\ W}$$

**Output capacitance:**
$$P_{oss} = Q_{oss} V_{bus} f_{sw} \approx 30\text{nC} \times 25.2 \times 48\text{k} = 0.036\ W$$

**Reverse recovery:**
$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\text{nC}\times 25.2 \times 48\text{k} = 0.048\ W$$

**Dead-time body-diode conduction (two edges per period):**
$$P_{dt} = V_{SD} I_{ph} \cdot 2t_{dt} \cdot f_{sw} = 0.8 \times 80 \times 100\text{ns} \times 48\text{k} = 0.31\ W$$

**Gate drive (dissipated in the driver and gate resistors, not the FET):**
$$P_g = 2\,Q_g V_{GS} f_{sw} = 2\times 50\text{nC}\times 10 \times 48\text{k} = 0.048\ W$$

### 2.3 Loss Summary

| Loss term | Per motor (W) | ×4 motors (W) |
|---|---|---|
| FET conduction | 20.5 | 82.0 |
| Copper + shunt | 4.8 | 19.2 |
| Switching (overlap) | 1.94 | 7.8 |
| Dead time | 0.31 | 1.2 |
| C_oss + Q_rr | 0.08 | 0.3 |
| Gate drive | 0.05 | 0.2 |
| **Total** | **≈27.7** | **≈111** |
