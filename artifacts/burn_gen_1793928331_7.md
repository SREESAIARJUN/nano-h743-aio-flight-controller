# STM32H743 FC + 80 A 4-in-1 ESC: Design Model (Job #9)

This document covers the power-stage loss model, thermal model, ArduPilot bidirectional DShot600 timer/DMA allocation, and reference netlists. All component values are representative engineering assumptions. Replace them with your selected parts' datasheet values before freezing the design.

---

## 0. Architecture Corrections and Scope Flags

Read these before the math.

1. **The H743 does not commutate the motors.** ArduPilot has no on-FC motor-commutation firmware. The standard architecture is:
   - **FC:** STM32H743 running ArduPilot. It outputs bidirectional DShot600 on 4 lines.
   - **ESC:** a 4-in-1 board with 4 independent ESC MCUs (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32). Each MCU drives its own 3-phase bridge at 48 kHz.

   The rest of this document assumes that split.
2. **"Nano" form factor vs. 80 A.** 80 A per channel on a 20×20 mm board is not thermally credible. Twenty-four FETs plus drivers will not fit, and Section 3 shows the board thermal mass saturates within seconds. This design assumes a **30.5×30.5 mm ESC** (compact, not nano) with 2 FETs in parallel per switch position. A nano 20×20 should be derated to roughly 35–45 A burst.
3. **"80 A burst" is defined here as** ≤ 5 s, single or all motors, starting from a 40 °C board. Section 3.3 quantifies the actual limit.

## 2. Loss Model (Per ESC Channel)

### 2.1 Conduction Path Topology

In 6-step with complementary PWM, current always flows through two switch positions in series:

- **PWM on-state:** HS(phase A) → motor → LS(phase B)
- **PWM off-state:** LS(phase A, synchronous rectifier) → motor → LS(phase B)

So the instantaneous conduction resistance is

$$R_{path}(T_j) = 2\cdot\frac{R_{ds,25}\,k_T(T_j)}{n_p} + R_{Cu} + R_{shunt}$$

The temperature factor is

$$k_T(T_j) \approx 1 + \alpha (T_j - 25),\quad \alpha\approx 0.006\ \text{K}^{-1}\ \Rightarrow k_T(125^\circ\text{C}) = 1.6$$
