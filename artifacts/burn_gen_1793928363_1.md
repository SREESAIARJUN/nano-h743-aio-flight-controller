## 1. Field-Oriented Control (FOC) Current Loop (20 kHz)

### 1.1 Transforms

The electrical angle is computed from the mechanical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant Model and Decoupled PI

The motor in the rotating frame obeys:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The controller is a PI regulator plus feed-forward decoupling terms:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Tuning by pole-zero cancellation.** For a target current bandwidth $\omega_c$, typically $2\pi\cdot 1.5\text{ kHz}$ (at most $f_{\text{PWM}}/10$):

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

**Discretization and anti-windup.** The integrator uses backward Euler with back-calculation anti-windup:

$$x_{k+1} = x_k + T_s\big[K_i e_k + K_{aw}(u^{\text{sat}}_k - u_k)\big],\qquad K_{aw}\approx \frac{K_i}{K_p}$$

**Voltage limiting.** The output voltage vector is limited circularly, preserving its direction:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}\cdot m_{\max},\qquad m_{\max}\approx 0.95$$

### 1.3 Space-Vector PWM (Min/Max Zero-Sequence Injection)

$$v_{a,b,c} \leftarrow \text{inverse Clarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12(\max + \min),\quad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Structure

```
θ*  ─►[P-PI angle 1kHz]─ω*─►[PI velocity 5kHz]─iq*─►(+)─►[FOC 20kHz]─► motor
           ▲                     ▲                   ▲ iq_ff (cogging + friction + gravity)
       θ_cam (IMU)           ω (gyro/enc)
```

For a gimbal, **stabilization** uses the camera-plate IMU:

- The angle loop acts on attitude error.
- The velocity loop acts on the gyro rate projected onto the motor axis.

The encoder is used for commutation ($\theta_e$) and for the joint-to-body Jacobian.

### 2.2 Velocity Loop

The mechanical plant is:

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

The controller is a PI with optional setpoint weighting $\beta$:
