# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

**Assumptions.** I don't have the original spec for "Job #7", so this design assumes typical values. Every value is a `constexpr` or config field, so you can substitute your own.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) |
| MCU | STM32G4 / H7 class: FPU, center-aligned TIM1/TIM8, injected ADC |
| PWM / current loop | 20 kHz |
| Velocity loop | 4 kHz |
| Angle loop | 1 kHz |
| IMUs | 2 × ICM-42688-P at 8 kHz ODR (SPI, shared CLKIN), on the camera plate at opposite lever arms |

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$
