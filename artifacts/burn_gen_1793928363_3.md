## 0. Design Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (MT6701 / AS5048A class) |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, shared FSYNC |
| MCU | Cortex-M7 / M4F with FPU (STM32G4/H7 class) |
| PWM | 20 kHz center-aligned, with the ADC triggered at the counter peak |

```
            1 kHz                4 kHz                       20 kHz
θ_ref ─►[Angle P + ω_ff]─ω_ref─►[Velocity PI + τ_ff]─i_q,ref─►[FOC current PI]─►SVPWM─►Motor
            ▲                         ▲      ▲ anti-cogging          ▲
            │ θ_cam (AHRS)            │ ω_cam (fused gyro)            │ i_a,i_b ; θ_e (encoder)
     [Mahony AHRS] ◄── [Dual-IMU fusion + AAF + static notches + adaptive notch] ◄── 2× ICM-42688-P @ 8 kHz
```

Feedback sources by loop:

- **Velocity loop:** uses the fused camera-gyro rate projected onto the motor axis. It does not use the differentiated encoder signal. The gyro measures the quantity you want to hold still (inertial camera rate), has far less quantization noise, and rejects base disturbances directly.
- **Angle loop:** uses the AHRS attitude, which gives inertial stabilization.
- **Commutation:** the encoder is used only for commutation and joint-limit and kinematic mapping.

## 1. Field-Oriented Current Control (20 kHz)

### 1.1 Transforms

Clarke transform (power-variant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

Park transform, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Delay compensation.** The voltage is applied about 1.5 T_s after sampling, so the inverse Park transform uses a predicted angle:

$$\theta_e^{*} = \theta_e + 1.5\,\omega_e T_s$$

### 1.2 Plant and Decoupling

The dq-frame plant is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Feedforward decoupling cancels the cross-coupling and back-EMF terms:

$$v_d = v_d^{PI} - \omega_e L i_q,\qquad v_q = v_q^{PI} + \omega_e L i_d + \omega_e\lambda_m$$

### 1.3 Current-Loop PI by Pole-Zero Cancellation

Choose the PI zero to cancel the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_c:

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_s}{10}\ (\text{e.g. } 2\pi\cdot 1.5\text{ kHz})$$

The discrete form (forward Euler on the integrator, with back-calculation anti-windup) is:

$$u_k = K_p e_k + I_k,\qquad I_{k+1} = I_k + K_i T_s e_k + K_{aw}\big(\text{sat}(u_k) - u_k\big)$$

Use K_aw = 1/K_p (normalized).

### 1.4 Voltage Limiting and SVPWM

**Circular limit.** Prioritize d and give q the remainder:

$$|v_d| \le V_{max},\quad |v_q| \le \sqrt{V_{max}^2 - v_d^2},\quad V_{max} = \frac{V_{dc}}{\sqrt{3}}\cdot 0.96$$

**SVPWM** uses min-max zero-sequence injection, which is equivalent to classical SVPWM:

$$v_{abc} = \text{invClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12(\max v_{abc} + \min v_{abc}),\quad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$
