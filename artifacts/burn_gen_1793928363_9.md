# 3-Axis Gimbal: FOC Motor Control, Cascaded PID, Anti-Cogging, and Dual-IMU Fusion

I don't have the specification for "Job #24," so the design below rests on stated assumptions. Each one is a named constant in the code and can be changed in one place.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class, FPU, 170+ MHz |
| Motors | Gimbal BLDC (e.g. GBM2804-class), 12N14P, so **pole pairs p = 7** |
| Rotor sensor | 14-bit magnetic encoder per axis (AS5048A / MT6701 / AS5600) |
| Current sensing | Low-side shunts on 2 phases, optional. Voltage-mode fallback is provided because many gimbal motors have R ≈ 5–15 Ω. |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, gyro ODR 8 kHz |

**Loop rates**

```
 20 kHz  ADC/PWM ISR : Clarke → Park → current PI → inv Park → SVPWM
  8 kHz  IMU ISR     : read both IMUs → notch/LPF → fuse → integrate attitude
  4 kHz  velocity    : rate PI (gyro feedback) + anti-cogging FF
  1 kHz  angle       : attitude P (+ velocity/accel FF), setpoint shaping
```

**Signal flow**

```
θ_ref ─►[Angle P]─ω_ref─►[Rate PI]─iq_ref─►(+)─►[Current PI]─V─►[SVPWM]─►Motor
          ▲              ▲   ▲            ▲  i_cog_ff (anti-cogging)
     θ̂_cam (fused)   ω_gyro  τ_ff                     ▲
                       (dual IMU)                      θ_m (encoder) → commutation & cogging phase
```

Bandwidths are separated by ≥ 4–5×:

- current: ω_c ≈ 2π·1500 rad/s
- rate: ω_v ≈ 2π·60–120 Hz
- angle: ω_p ≈ 2π·10–20 Hz
