## 0. Architecture Clarifications and Feasibility Flags

Three issues will drive the design. They should be resolved before layout begins.

| # | Issue | Impact |
|---|-------|--------|
| 1 | **The H743 does not commutate the motors.** In every production AIO design, the H743 runs ArduPilot and emits DShot. Each ESC channel uses its own small MCU (STM32G071 / AT32F421 / GD32E230 running AM32 or BLHeli_32). The 48 kHz PWM and the commutation live on the ESC MCU. | The math is partitioned that way below. |
| 2 | **"80 A burst" on a nano form factor (20×20 or 25.5×25.5 mm) is thermally marginal to infeasible** if all four channels burst simultaneously. The model in §3 shows a board-level adiabatic budget of roughly **1–2 seconds**. | The rating must be defined as *per-channel, ≤ X s, with stated airflow*. Otherwise it is a marketing number, not an engineering one. |
| 3 | **Device parameters below are representative, not from a selected BOM.** | Every number must be re-run against the actual MOSFET and gate-driver datasheets. The equations are the deliverable; the numbers are a worked example. |

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha\,(T_j - 25)],\quad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 125 °C:

$$R_{ds} = 1.0 \times 1.45 = 1.45\ \text{m}\Omega$$

### 1.2 Current-path analysis (6-step, complementary PWM)

Each phase conducts for 240° electrical: 120° sourcing and 120° sinking. During the sourcing interval, the PWM leg alternates between the high-side (HS) FET (fraction D) and the low-side (LS) FET acting as a synchronous rectifier (fraction 1–D).

Per-phase, per-FET average conduction loss:

$$P_{HS} = I_{ph}^2 R_{ds}\cdot\frac{D}{3}$$

$$P_{LS} = I_{ph}^2 R_{ds}\cdot\left[\frac{1-D}{3} + \frac{1}{3}\right] = I_{ph}^2 R_{ds}\cdot\frac{2-D}{3}$$

**Sanity check:** the per-bridge total is

$$3(P_{HS}+P_{LS}) = 3 \cdot I^2R \cdot \tfrac{D + 2 - D}{3} = 2\,I_{ph}^2 R_{ds}$$

This is correct, because exactly two switches are always in the current path.

> **Note on current definitions.** Battery current relates to phase current as I_bat ≈ D · I_ph. An "80 A" rating must state which current is meant. Here it is **phase current**.

### 1.3 Worked numbers (I_ph = 80 A, D = 0.95, T_j = 125 °C)

Common factor:

$$I^2R = 6400 \times 1.45\times10^{-3} = 9.28\ \text{W}$$

| Element | Formula | Loss |
|---------|---------|------|
| HS FET (each) | 9.28 × 0.95/3 | **2.94 W** |
| LS FET (each) | 9.28 × 1.05/3 | **3.25 W** |
| Bridge FETs, per channel | 2 × 9.28 | **18.56 W** |
| PCB copper / vias, per channel (R_cu ≈ 0.5 mΩ effective path) | 6400 × 0.5 mΩ | **3.2 W** |
| Current shunt, per channel (0.25 mΩ, DC-link) | I_bat² R_sh ≈ 76² × 0.25 mΩ | **1.44 W** |
| **Conduction subtotal, per channel** | | **≈ 23.2 W** |

**Copper resistance estimate.** For 2 oz (70 µm) copper, sheet resistance is

$$R_\square = \frac{\rho}{t} = \frac{1.72\times10^{-8}}{70\times10^{-6}} = 0.246\ \text{m}\Omega/\square \quad (25\,°\text{C})$$
