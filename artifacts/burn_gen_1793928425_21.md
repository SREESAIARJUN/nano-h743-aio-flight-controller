## 0. Architecture Clarification and Assumptions

An STM32H743 does not commutate 4 motors × 3 phases directly in production designs. This design partitions as follows:

| Block | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100, 480 MHz) | ArduPilot. Generates 4× bidirectional DShot600 and decodes eRPM telemetry. |
| ESC MCUs (×4) | AT32F421K8U7 (QFN32) running AM32 | 6-step sensorless commutation, 48 kHz complementary PWM |
| Gate drivers (×4) | FD6288Q (3-phase, integrated bootstrap) | High-side/low-side drive |
| MOSFETs (×24) | 40 V N-ch, PDFN 3.3×3.3 class | Power stage |

The model is parametric. The numbers below use the baseline parameters in this table. **Replace them with your selected FET's datasheet values before sign-off.**

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V (6S full) | DC link |
| I_burst | 80 A per motor | Phase current during burst |
| f_sw | 48 kHz | PWM frequency |
| R_DS(on),25 | 1.5 mΩ @ V_GS = 10 V | Per FET |
| α | 0.0060 /K | R_DS(on) temperature coefficient |
| t_r + t_f | 40 ns total (effective V·I overlap) | Set by FD6288 drive and R_G |
| Q_g / Q_rr / Q_oss | 30 nC / 40 nC / 40 nC | Per FET |
| V_SD | 0.8 V | Body diode forward voltage |
| t_dead | 200 ns per edge | AM32 dead time |
| R_path | 0.5 mΩ | PCB copper + solder per current loop |
| R_shunt | 0.2 mΩ | Per-ESC bus shunt |
| Board | 30.5 × 30.5 mm, 8-layer, 2 oz | A 20×20 "nano" board scales roughly 0.44× in heat capacity (see §3.4) |

> **Feasibility flag:** 4 × 80 A on a nano-class board is a **transient-only rating**. §3 shows it is thermally limited to about 1.5–2.5 s. It can never be a continuous rating.
