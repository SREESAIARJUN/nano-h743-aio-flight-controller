# STM32H743 Nano FC + 80A 4-in-1 ESC: Systems Architecture Package (Job #3)

## 0. Scope and Assumptions

A few architectural points need settling first, because they change the math.

1. **Partitioning.** In a conventional 4-in-1 stack, the STM32H743 runs ArduPilot and generates DShot. Each ESC channel runs its own commutation MCU (AM32 on AT32F421/STM32G071, or BLHeli_32). The H743 does not do FOC or six-step commutation itself. This document assumes that architecture.
2. **"80A burst"** is read as **80A per channel, ≤ 1 s, with all four channels potentially loaded simultaneously** (punch-out). If the spec actually means 80A *total*, divide all thermal results by about 16.
3. **Nano form factor** is taken as a 20×20 mm mounting pattern (about 25×25 mm board), 8-layer, 2 oz copper.

## 1. Conduction Loss Model

### 1.1 Six-step current path
In trapezoidal (six-step) commutation with complementary or synchronous PWM, exactly **two FETs** are in the current path at any instant:
- the high-side FET of the sourcing phase, and
- the low-side FET of the sinking phase.

During PWM off-time, the sourcing phase's low-side FET (synchronous rectification) replaces its high-side FET. So the path is still two FETs, apart from dead time.

Each FET carries phase current for 120° of every 360° electrical cycle. Its conduction duty is therefore 1/3, modulated by D for high-side or (1−D) for the SR FET.

### 1.2 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At a design junction temperature T_j = 110 °C:

$$R_{ds}(110) = 1.2\,\text{m}\Omega \times (1 + 0.0045 \times 85) = 1.66\ \text{m}\Omega$$

### 1.3 Per-channel conduction loss
The current path is two FETs in series, independent of D, ignoring dead time:

$$P_{cond,ch} = 2\, I_{ph}^2\, R_{ds}(T_j)$$

$$P_{cond,ch}(80\text{A}) = 2 \times 6400 \times 1.66\times10^{-3} = \mathbf{21.2\ W}$$

Breakdown:
- **Per FET, while conducting:** I²R = 10.6 W.
- **Per FET, averaged over the electrical cycle** (×1/3): about **3.5 W**.
- **All four channels at 80A:** about **85 W** of conduction loss alone.
