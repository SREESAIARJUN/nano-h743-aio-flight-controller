## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance
$$R_{DS}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)]$$
$$R_{DS}(125\,°C) = 1.3\,\text{mΩ}\times1.45 = 1.89\,\text{mΩ}$$

### 1.2 6-step synchronous commutation analysis
In each 60° step, one phase PWM-switches (high-side on for duty D, low-side synchronously rectifies for 1−D). A second phase holds its low-side FET fully on. The current path therefore always crosses exactly **two** channels' worth of FET resistance:

$$P_{cond,step} = I^2R_{DS}\,[\,D + (1-D) + 1\,] = 2I^2R_{DS}$$

So, independent of duty:
$$\boxed{P_{cond,ch} = 2\,I_{ph}^2\,R_{DS}(T_j)}$$
