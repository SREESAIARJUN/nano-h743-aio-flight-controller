# STM32H743 AIO 4-in-1 ESC Nano FC: Electrothermal and DShot Architecture

**Rev A, engineering reference**

---

## 0. Scope, Assumptions and Key Findings

### 0.1 System architecture

The STM32H743 runs ArduPilot as the flight controller. It does **not** drive the gate drivers directly. This is a standard All-In-One (AIO) design: the H743 emits bidirectional DShot600 to four ESC MCUs (AT32F421-class, running AM32 or BLHeli_32-compatible firmware). Each ESC MCU generates its own 48 kHz complementary PWM for one three-phase bridge.

```
 6S LiPo ─┬─ Shunt ─┬─ VBAT bus (bulk + MLCC)
          │         ├─ ESC1: MCU → 3φ driver → 6×N-FET → M1
          │         ├─ ESC2 … ESC4 (identical)
          │         └─ Buck 5V/9V → LDO 3V3 → STM32H743 + IMU + baro + OSD
 STM32H743 TIM3 CH1..4 ──(bidir DShot600)──► ESC1..4 signal inputs
```

### 0.3 Key findings

1. **80 A cannot be sustained in a nano form factor.** At 80 A, total bridge dissipation is about **125 W** (4 motors). Steady state would require R_θ(board→air) ≤ 0.6 K/W, which is impossible at this size. 80 A is therefore defined as a **transient rating of ≤ 2 s**, governed by board thermal capacitance (§3.4).
2. **Conduction loss dominates.** It is about 85 % of loss at 48 kHz. Switching loss is secondary but non-trivial at 48 kHz, roughly 2× its value at 24 kHz.
3. **DShot DMA allocation fits comfortably.** Five DMA streams on TIM3 (UP + CH1–4) fit within the H743's 16 DMAMUX1 streams, with headroom for SPI, UART and ADC.

## 1. Conduction Loss Model

### 1.1 Commutation topology

AM32 and BLHeli_32 use six-step trapezoidal commutation with synchronous rectification (complementary PWM). In every PWM state, exactly **two** FETs carry the phase current I:

- **ON interval (duty D):** high-side of phase A plus low-side of phase B.
- **OFF interval (1−D):** low-side sync-rectifier of phase A plus low-side of phase B.

Current therefore always flows through two R_ds(on) elements (ignoring dead time):

$$P_{cond,bridge} = I^2 \cdot 2\,R_{ds}(T_j)$$

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha_R (T_j-25)]$$

Phase current ripple adds a small term:

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{(V_{bus}-E)\,D}{L_{ph}\,f_{sw}}$$

For a typical 5" motor (L_ph ≈ 20 µH line-to-line) at D = 0.9, near full throttle, with E ≈ 0.85·V_bus:

ΔI ≈ (25.2 − 21.4)(0.9) / (20e-6 · 48e3) ≈ **3.6 A**

The ripple term ΔI²/12 ≈ 1.1 A², which is negligible against 6400 A². **48 kHz is useful here** because ΔI halves versus 24 kHz, which reduces motor iron and copper ripple loss.

### 1.2 Electrothermal fixed point

R_ds depends on T_j, and T_j depends on P. Solve the fixed point:

$$T_j = T_{pcb} + P_{FET}(T_j)\,R_{\theta JC}$$

Use the worst-case R_ds,25 = 1.3 mΩ:

| T_j (°C) | R_ds (mΩ) | P_cond per motor (W) |
|---|---|---|
| 25 | 1.30 | 16.6 |
| 100 | 1.84 | 23.5 |
| 125 | 2.02 | **25.8** |
