## 0. Scope, Architecture, and Assumptions

**System partitioning.** The STM32H743 is the flight-controller MCU. It does not drive the MOSFETs. The 4-in-1 ESC section uses four dedicated ESC MCUs (STM32G071 / AT32F421 class running AM32). The 48 kHz PWM is an ESC firmware setting. The H743's job is to generate bi-directional DShot600 and decode eRPM telemetry.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

R_DS(on)(T_j) = R_DS(on),25 · [1 + α(T_j − 25)], with α ≈ 0.0055 /K

At T_j = 125 °C: R_DS(on) = 1.0 mΩ × 1.55 = **1.55 mΩ**.

### 1.2 Six-step complementary PWM conduction pattern

In each commutation sector, two phases carry current I. The three conducting elements are:

- **Active-phase high side (HS):** on for D.
- **Active-phase low side (synchronous LS):** on for (1 − D), carrying the freewheel current.
- **Return-phase LS:** on 100%.

Total conduction loss per channel:

P_cond,ch = I²R[D + (1 − D) + 1] = **2·I²·R_DS(on)(T_j)**

This expression is independent of duty cycle, which is a useful property for burst analysis.

**Per-FET distribution.** Each phase spends 120° "high" and 120° "low" per electrical cycle:

- HS: P_HS = (1/3)·D·I²R
- LS: P_LS = (1/3)·(2 − D)·I²R
