# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the original Job #5 specification, so the design below rests on the assumptions in §0. Every parameter that depends on your hardware is a named constant, so you can retarget it by changing values rather than restructuring code.

---

## 0. Design Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | Gimbal BLDC, 12N14P (e.g. GBM2804-class): R ≈ 10 Ω, L ≈ 2 mH, pole pairs p = 7 |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) on each joint |
| Current sensing | 2-shunt or inline, sampled synchronously at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, 8 kHz ODR, separate SPI buses, mounted symmetrically about the plate centroid |
| Kinematic order | Yaw (outer) → Roll → Pitch (inner) |

**Loop rates:**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity (inertial rate) | 4 kHz | ~150 Hz |
| Attitude / angle | 1 kHz | ~20 Hz |
