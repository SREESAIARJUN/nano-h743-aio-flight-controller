## 0. Baseline Assumptions

The Job #23 spec sheet was not provided, so this design assumes a common gimbal hardware set. Every value is a named constant in the code. Replace the defaults with your measured values before tuning.

| Item | Assumed value |
|---|---|
| Motor | 3-phase gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.12 N·m/A |
| Supply | V_dc = 16.8 V (4S) |
| Rotor encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), SPI |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class) with FPU |

**Loop rates and bandwidths:**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz, PWM-center ISR | ω_ci = 2π·1500 rad/s |
| Velocity | 4 kHz (every 5th PWM ISR) | ω_cv = 2π·150 rad/s |
| Angle (stabilization) | 1 kHz | ω_cθ = 2π·30 rad/s |
| IMU fusion | 8 kHz, triggered by data-ready | — |

**Bandwidth separation rule:** each loop should be at least 4–10× faster than the loop around it, and each loop's rate should be at least 10× its own bandwidth.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

**Amplitude-invariant Clarke transform** (assumes i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform** (θ_e = p·θ_m − θ_offset):

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The torque relationships are:

- τ = (3/2)·p·λ_m·i_q = K_t·i_q
- Back-EMF constant: λ_m = K_t / (1.5·p)
