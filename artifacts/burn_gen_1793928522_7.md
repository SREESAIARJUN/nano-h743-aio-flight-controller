# 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #21 specification. Everything below rests on the assumptions in §0, and each is a named constant in the code. Replace them with your measured motor, frame and mechanical parameters before running anything on hardware.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC. Default geometry 12N14P, so p = 7 pole pairs. In-line or low-side current sensing. |
| Commutation encoder | 14-bit absolute magnetic encoder (AS5048A, MT6701 class), one per joint. |
| Inertial sensors | 2× ICM-42688-P on the camera plate, mounted symmetrically about the plate centroid. Separate SPI buses. Shared CLKIN. |
| Joint order (base to camera) | Yaw (z), then Roll (x), then Pitch (y). |
| MCU | Cortex-M7 or M4F class with single-precision FPU (STM32H7/G4). |
