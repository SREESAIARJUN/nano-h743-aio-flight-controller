# Job #24: STM32H743 Nano AIO (FC + 4-in-1 ESC), Architecture & Analysis Package

## 0. Architecture Clarification and Assumptions

The STM32H743 does **not** commutate the motors. ArduPilot has no BLDC commutation or FOC path. The topology is:

```
STM32H743 (ArduPilot) ──DShot600 bidir (4 lines)──► 4× ESC MCU (e.g., AT32F421 / STM32G071, AM32 or BLHeli_32)
                                                       └─► 3× half-bridge gate driver ──► 6× N-MOSFET per motor
```

The 48 kHz PWM is generated by each ESC MCU. The H743 owns DShot timing, DMA, and telemetry decode.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha\,(T_j - 25)]$$

The model is solved self-consistently with the thermal model in §3. The result converges at T_j ≈ 120 °C:

$$R_{ds}(120^\circ C) = 1.2\,\text{mΩ} \times (1 + 0.0045 \times 95) \approx 1.71\,\text{mΩ}$$

For margin, **1.75 mΩ** is used below.

### 1.2 Current path in 6-step synchronous mode

At any instant, two phases conduct. With complementary PWM, the current always flows through exactly **two FETs**:

- one high-side FET (or its complementary low-side FET during the PWM off-time), and
- one low-side FET of the return leg.

This holds independent of duty cycle.

$$P_{cond,ESC} = 2\,I^2 R_{ds}(T_j) = 2 \times 6400 \times 1.75\text{e-}3 = \mathbf{22.4\ W}$$
