# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #36, so this design states its assumptions up front. Each constant is collected in one config struct, so you can substitute your real motor and encoder parameters.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (GBM-type), 12N14P, so pole pairs **p = 7**, R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| Current sense | 2-phase low-side shunt, synchronous to PWM center |
| IMU | 2 × ICM-42688-P on separate SPI buses, rigidly mounted on the camera plate |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |

**Loop rates and bandwidths:**

| Loop | Rate | Target bandwidth | Trigger |
|---|---|---|---|
| Current (d/q) PI | 20 kHz | ω_c ≈ 2π·1.5 kHz | ADC injected-conversion ISR |
| Velocity PI | 4 kHz | ω_v ≈ 2π·120 Hz | Every 5th current tick |
| Angle (attitude) P-I | 1 kHz | ω_a ≈ 2π·25 Hz | Every 4th velocity tick |
| IMU sampling | 8 kHz ODR | AAF ≈ 536 Hz | IMU DRDY interrupt / FIFO |

Each loop runs about 5–10× slower in bandwidth than the loop inside it. This separation lets you treat the inner loop as unity gain when tuning the outer loop.

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at commissioning: inject V_d along the α-axis and record θ_m.

### 1.2 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the d-q frame (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque is:

$$\tau = \tfrac{3}{2}p\lambda_m i_q = K_t\, i_q$$

### 1.5 Current PI with decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L\, i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L\, i_d + \omega_e\lambda_m$$
