## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC (GM4108-class): 12N14P → p = 7 pole pairs, R ≈ 10 Ω, L ≈ 4 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701), SPI |
| MCU | STM32G474 / H7 (FPU, CORDIC optional), 3× low-side shunts |
| Bus | 12–16.8 V (3–4S) |
| IMUs | 2× ICM-42688-P on separate SPI buses, gyro ±2000 dps, ODR 8 kHz, consumed at 4 kHz |
| Disturbance | Propeller vibration, 80–400 Hz fundamental plus harmonics |

**Rate structure** (each loop runs at least 4× the bandwidth of the loop inside it):

```
 20 kHz  PWM-center ADC ISR : current loop (FOC) + encoder read + cogging FF lookup
  4 kHz  IMU DRDY / timer    : dual-IMU filter + fusion, inertial velocity loop
  1 kHz  timer               : AHRS update, angle loop
100 Hz   background          : notch frequency tracking, health monitoring, cogging adaptation gating
```

**Target closed-loop bandwidths:**

- Current: ω_ci ≈ 2π·1500 rad/s
- Velocity: ω_cv ≈ 2π·60 Hz (limited by notch phase lag and frame resonance)
- Angle: ω_cθ ≈ 2π·8 Hz

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle from mechanical angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this rotation.

### 1.2 Plant model (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$
$$\tau_e = \tfrac{3}{2}p\lambda_m i_q = K_t\, i_q$$

### 1.3 PI with decoupling and pole-zero cancellation

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \hat\omega_e \hat L\, i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \hat\omega_e(\hat L i_d + \hat\lambda_m)$$

Choose the PI zero to cancel the electrical pole at R/L:

$$K_p = \hat L\,\omega_{ci},\qquad K_i = \hat R\,\omega_{ci}$$

The closed loop then reduces to a first-order lag:

$$\frac{i_q}{i_q^*} = \frac{\omega_{ci}}{s+\omega_{ci}}$$
