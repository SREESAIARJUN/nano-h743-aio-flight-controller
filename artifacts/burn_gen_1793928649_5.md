# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #47 specification, so the design below rests on these assumptions. Each is parameterized in code (`constexpr` / config structs).

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH, inline current sensing on 2 phases |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| IMUs | 2× ICM-42688-P on the camera plate, on separate SPI buses with DMA, ODR = 8 kHz, ±2000 dps, ±16 g |
| Kinematics | Outer **yaw** (z) → middle **roll** (x) → inner **pitch** (y) → camera |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| Loop rates | Current/FOC **20 kHz** · velocity **4 kHz** · attitude **1 kHz** · IMU **8 kH
