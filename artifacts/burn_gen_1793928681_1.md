# FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection for a 3-Axis Gimbal

I don't have the specification for Job #52, so the design below states its assumptions explicitly. All of them are parameterized in code. Replace them with your hardware values before tuning.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC (GBM2804-class), 12N14P → pole pairs p = 7, R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoder | 14-bit magnetic (AS5048A / MT6701), SPI, sampled at current-loop rate |
| MCU | STM32G4/H7-class, FPU, 3 × 3-shunt or 2-shunt current sensing |
| IMU_P | ICM-42688-P on camera/payload plate (attitude + inertial rate) |
| IMU_B | ICM-42688-P on base/handle (disturbance reference + feedforward) |
| Joint order | Yaw (outer, z) → Roll (x) → Pitch (inner, y) |
