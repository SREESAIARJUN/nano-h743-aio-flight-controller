## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.068 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per joint (MT6701 / AS5048A) |
| Current sense | 2 or 3 low-side shunts, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, FIFO off, DRDY interrupt |
| Kinematic chain | Yaw (base) → Roll → Pitch (camera) |

### Loop rates and bandwidth separation

Each loop should be at least 5× faster than the loop outside it.

```
 20 kHz  PWM ISR          : Current PI (d/q) + SVPWM + encoder PLL           BW_i  ≈ 2 kHz
  8 kHz  IMU DRDY ISR     : Dual-IMU align/fuse → AAF → adaptive notch → LPF
  4 kHz  Rate loop        : camera-rate PI → J⁻¹ → joint torque → iq*        BW_ω  ≈ 150–250 Hz
                            + anti-cogging feedforward (encoder angle)
  1 kHz  Attitude loop    : Mahony attitude → quaternion error → ω_ref        BW_θ  ≈ 15–30 Hz
```
