# STM32H743 FC + 80 A 4-in-1 ESC (Nano): Electrical, Thermal and DShot Design Package

## 0. Scope, Assumptions and Caveats

**No component datasheets were supplied**, so this package uses representative parameters for a 40 V, 3.3×3.3 mm DFN MOSFET of the class used in compact ESCs. Every equation is parameterized. Before freezing the design, substitute your actual MOSFET datasheet values into the table in §1.

**Architecture.** In practice the STM32H743 does not drive the MOSFETs. ArduPilot runs on the H743, which sends DShot600 to four ESC MCUs. These are typically AT32F421 or STM32G071 parts running AM32 or BLHeli_32, and each one runs its own 48 kHz PWM. This document treats the system as a stack:

- **FC board:** H743 + ArduPilot.
- **ESC board:** 4× MCU, 4× 3-phase gate driver, 24 MOSFETs.

**Form factor.** "Nano" is taken as a 20×20 mm mounting pattern with roughly 26×26 mm of usable PCB. §4 shows that 80 A per motor on all four motors simultaneously is only survivable for about 1–2 seconds at this size. That limit comes from physics, not component choice. Plan the burst rating accordingly.

## 2. Conduction Loss Model (80 A Burst)

### 2.1 Current paths in 6-step commutation with synchronous rectification

At any instant two phases conduct: one high side (HS) and one low side (LS). Using complementary PWM on the switching leg:

- **PWM on:** current flows through HS(x) → motor → LS(y).
- **PWM off:** current flows through LS(x) (synchronous rectifier) → motor → LS(y).

In both states the current passes through exactly two MOSFET channels. The instantaneous per-motor conduction loss is therefore independent of duty cycle:

$$P_{cond,motor} = 2\,I^2\,R_{ds(on)}(T_j)$$

### 2.2 Temperature correction

$$R_{ds(on)}(T_j) = R_{25}\,[1+\alpha\,(T_j-25)]$$

| T_j | R_ds(on) | P_cond per motor at 80 A |
|---|---|---|
| 25 °C | 1.00 mΩ | 12.8 W |
| 100 °C | 1.34 mΩ | 17.1 W |
| 125 °C | 1.45 mΩ | **18.6 W** |
