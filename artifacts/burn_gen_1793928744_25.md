# STM32H743 Nano FC + 80 A Burst 4-in-1 ESC: Design Model (Job #45)

## 0. Architecture and Assumptions

Two points need to be fixed before any numbers are meaningful.

**1. The H743 does not commutate the motors.** ArduPilot on the H743 is the flight controller. It sends bidirectional DShot600 to a 4-in-1 ESC that has four ESC MCUs (STM32G071 running AM32 is assumed here). Each ESC MCU generates the 48 kHz PWM. The DMA/timer section covers the H743. The loss and thermal sections cover the ESC.

**2. Device parameters are placeholders.** The MOSFET values below are for a representative 40 V, PDFN 3.3×3.3 part. Replace them with datasheet values for the actual BOM part before release. The equations stay the same; only the numbers move.
