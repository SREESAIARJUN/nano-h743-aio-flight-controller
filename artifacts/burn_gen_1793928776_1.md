# STM32H743 AIO Flight Controller + 4-in-1 ESC: Design Model

**Scope:** I don't have the internal Job #15 documents, so this model uses the assumptions listed in §0. Replace any parameter with your actual BOM values. The equations are written so you can recompute the results directly.

**Key finding first:** On a nano-format board, an **80 A per-channel burst across all four channels at once can last only about 2 s**. Sustained current is about **45–50 A per channel** with prop-wash cooling. The derivation is in §3.

## 0. Architecture & Assumptions

| Item | Value |
|---|---|
| Topology | H743 FC (ArduPilot) + 4× ESC MCUs (AT32F421 / STM32G071 running AM32) on a shared PCB |
| Battery | 6S LiPo, V_max = 25.2 V, V_nom = 22.2 V |
| Board | 30.5×30.5 mm mount, ~36×36 mm outline, 8-layer, 2 oz outer / 1 oz inner (about 2.4 g Cu) |
| MOSFET (×24) | 40 V N-ch, PDFN3.3×3.3. R_ds(on) = 1.2 mΩ at 25 °C and 1.8 mΩ at T_j = 125 °C. Q_g = 40 nC, Q_gd = 8 nC, Q_rr = 30 nC, V_SD = 0.8 V, R_θJC = 1.5 K/W |
| Gate driver | 3-phase bootstrap driver (FD6288Q-class), V_CC = 10 V, about 1 A source/sink |
| PWM | f_sw = 48 kHz, complementary (synchronous rectification), dead time t_dt = 100 ns per edge |
| Commutation | 6-step trapezoidal. One high-side and one low-side FET conduct per 60° sector |
| Burst rating | 80 A phase current per channel |

**Note:** The H743 does *not* run the motor commutation. It generates bidirectional DShot600 at the FC level. The 48 kHz switching is handled entirely by the ESC MCUs.

## 1. Conduction Loss Model

### 1.1 Per-channel conduction

With synchronous rectification, the conducting path during each sector is:
- **On-time (D):** Q_H,A → motor → Q_L,B
- **Off-time (1−D):** Q_L,A (sync rectifier) → motor → Q_L,B

Two FETs always carry the full phase current *I*, regardless of duty cycle:

$$P_{cond} = 2\,I^2 R_{ds(on)}(T_j) + I_{rms,ripple}^2\text{ terms (neglected; } \Delta I_L \ll I\text{)}$$

Temperature dependence:

$$R_{ds(on)}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At 80 A and T_j = 125 °C:

$$P_{cond} = 2(80)^2(1.8\text{ m}\Omega) = \mathbf{23.0\ W\ /\ channel}$$

### 1.2 Per-FET distribution

Over one electrical revolution, each FET conducts 120° electrical. The electrical frequency is f_e = (poles/2)·rpm/60. For example, 14 poles at 30 krpm gives 3.5 kHz.

The electrical period is much shorter than the die thermal time constant, so the averaged loss is valid:

$$\bar P_{FET,cond} \approx P_{cond}/6 = 3.84\ \text{W}$$

The instantaneous peak in the "always-on" low-side FET is I²R = 11.5 W.

### 1.3 Copper and shunt losses

| Element | R | P at 80 A |
|---|---|---|
| Power planes + phase pad path (per channel) | ~0.4 mΩ | 2.6 W |
| Current shunt (shared, 0.25 mΩ, sees Σ battery current) | 0.25 mΩ | see §3 |
