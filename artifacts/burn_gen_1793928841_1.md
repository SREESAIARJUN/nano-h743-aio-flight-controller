# FOC Control Loop and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the Job #43 specification, so this design uses the typical gimbal hardware listed below. Every hardware-dependent constant sits in one config block so you can substitute your values.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 1–3 mH, hollow shaft |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) over SPI |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM, ADC triggered at the PWM midpoint |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, gyro and accel ODR 8 kHz |
| Loop rates | Current 20 kHz · rate (velocity) 4 kHz · attitude (angle) 1 kHz |

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

The electrical angle is θₑ = p·(θₘ − θ_offset).

Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and decoupled PI

Surface-mount PMSM model with L_d = L_q = L:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The controller adds decoupling and back-EMF feedforward to the PI output:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e \lambda_m$$

Pole-zero cancellation gives a first-order closed loop with crossover ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{pwm}}{20}\ \ (\approx 2\pi\cdot 1\text{ kHz})$$

### 1.3 Voltage limiting and SVPWM

Limit the voltage vector to the linear SVPWM region, V_max = V_bus/√3 · 0.95. Preserve v_d priority:

$$v_q^{lim} = \operatorname{sign}(v_q)\min\!\left(|v_q|, \sqrt{V_{max}^2 - v_d^2}\right)$$

Use min-max zero-sequence injection, which is equivalent to SVPWM:

$$v_{a,b,c} \leftarrow \text{invClarke}(v_\alpha, v_\beta),\qquad v_0 = -\tfrac12(\max + \min),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Attitude → Rate → Current Control

### 2.1 Architecture

```
θ*_cam ─►[Angle P+I, 1 kHz]─ω*─►(+ω_ff)─►[Rate PI+D, 4 kHz]─τ*─►(+cogging FF)─► i_q* ─►[FOC 20 kHz]
            ▲ θ_cam (fused IMU attitude, projected on joint)      ▲ ω_axis (fused gyro, notched)
```

- **Rate feedback:** the inertial angular rate of the camera about each joint axis, ω_axis = ê_jᵀ·ω_cam. For the yaw/roll/pitch joints, ê_j is computed from the joint encoder angles. This is the quantity the stabilizer must null.
- **Encoder:** used only for commutation and the cogging angle. Do not use it for stabilization feedback.

### 2.2 Rate loop (PI + filtered D, Tustin/backward Euler, back-calculation anti-windup)

Error:

$$e_\omega[k] = \omega^*[k] - \omega[k]$$

Proportional term:

$$P[k] = K_{p\omega}\, e_\omega[k]$$

Derivative on measurement, with a first-order filter of time constant τ_d = 1/(2π f_d):

$$D[k] = \frac{2\tau_d - T_s}{2\tau_d + T_s} D[k-1] - \frac{2K_{d\omega}}{2\tau_d+T_s}(\omega[k]-\omega[k-1])$$

Unsaturated and saturated outputs:

$$u_{raw} = P + I[k] + D,\qquad u = \operatorname{sat}(u_{raw}, \pm \tau_{max})$$

Integrator with back-calculation anti-windup, where K_aw ≈ 1/T_i = K_i/K_p:

$$I[k+1] = I[k] + K_{i\omega} T_s e_\omega[k] + K_{aw} T_s (u - u_{raw})$$

Torque to current, with the cogging feedforward (Section 3)
