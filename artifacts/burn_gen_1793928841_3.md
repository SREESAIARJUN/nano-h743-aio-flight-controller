# 3-Axis Gimbal FOC Control & Dual-IMU Fusion: Design Specification

I don't have the Job #49 hardware sheet, so the design is parameterized and the assumptions are listed in §0. Change those constants and the derived gains recompute automatically in code.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class (single-precision FPU, CORDIC optional) |
| Motor | Gimbal BLDC, 12N14P (pole pairs **p = 7**), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), read at 20 kHz |
| Current sense | 2 or 3 low-side shunts (voltage-mode fallback provided) |
| IMU | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz, ±2000 dps / ±16 g |
| Disturbance | Multirotor props: 80–400 Hz fundamental plus harmonics; RPM optionally available via bidirectional DShot |

The controller is organized as nested loops, from fastest to slowest:

| Loop | Rate | Input → output | Data sources and actions |
|---|---|---|---|
| Current (PI + decoupling) | 20 kHz | i_q,ref → v_dq | Shunts and encoder in; SVPWM out |
| Velocity (PI + cogging FF) | 4 kHz | ω_ref → i_q,ref | Dual-IMU gyro, filtered; LMS cogging adaptation |
| Angle (P + rate feedforward) | 1 kHz | θ_ref → ω_ref | Mahony quaternion attitude |
| IMU pipeline | 8 kHz | Raw sensor data → fused gyro and accel | AAF, consistency check, notch filters, LPF, decimate to 4 kHz |

## 1. FOC Inner Loop (Current)

### 1.1 Electrical Angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

The offset θ_off is found at boot: inject v_d = V_align at θ_e = 0, let the rotor settle, and record θ_m.

### 1.2 Clarke and Park Transforms (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

$$\begin{bmatrix}i_d\\i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant and PI Tuning (Pole-Zero Cancellation)

The motor model in the dq frame is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L \dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

With feed-forward decoupling,

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m,$$

each axis reduces to the first-order plant 1/(R + Ls). Choosing

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

makes the PI zero cancel the plant pole, giving the closed loop ω_c/(s + ω_c).

Recommended bandwidth: ω_c = 2π·1.5 kHz, which keeps ω_c ≤ ω_s/10 at f_s = 20 kHz.

### 1.4 Voltage Limiting and Inverse Transforms

The voltage vector is clamped to the circle

$$|v_{dq}| \le V_{bus}/\sqrt3.$$

Apply inverse Park, then SVPWM using the min/max zero-sequence injection:

$$v_{abc} = \text{invClarke}(v_\alpha, v_\beta),\qquad v_0 = -\tfrac12(\max v_{abc} + \min v_{abc})$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.5 Anti-Windup (Back-Calculation)

$$x_I[n+1] = x_I[n] + T_s\big(K_i e[n] + K_{aw}(u_{sat}[n] - u[n])\big),\qquad K_{aw} = K_i / K_p$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical Plant per Axis

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{fric} - \tau_{dist}$$

where K_t = 1.5 p λ_m.
