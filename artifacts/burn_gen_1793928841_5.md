# 3-Axis Gimbal FOC Control & Dual-IMU Fusion: Design Specification

I don't have the original specification for Job #27, so this design is built on the assumptions in §0. Every parameter that depends on your hardware is a named constant, so you can substitute your actual values.

## 0. Assumptions & Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701) per axis |
| Current sense | 2- or 3-shunt, ADC sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera payload, SPI at 24 MHz, ODR = 8 kHz |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates and bandwidths.** Each loop is roughly 5–10× faster than the loop outside it, which preserves the time-scale separation the cascade relies on.

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz (= PWM) | ω_c ≈ 2π·1500 rad/s |
| Velocity (PI) | 8 kHz (IMU-synchronous) | ω_v ≈ 2π·150 rad/s |
| Angle / attitude (P + I) | 2 kHz | ω_θ ≈ 2π·20 rad/s |
| Attitude estimator | 2 kHz (decimated from 8 kHz) | — |

## 1. FOC Inner Current Loop

### 1.1 Transforms (amplitude-invariant)

Clarke transform:
$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(\text{with } i_a+i_b+i_c=0)
$$

Park transform, with electrical angle θ_e = p·θ_m − θ_offset:
$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.2 Plant model (SPMSM, L_d = L_q = L)

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

Torque: $\tau_m = \tfrac32 p \lambda_m i_q = K_t\, i_q$.
