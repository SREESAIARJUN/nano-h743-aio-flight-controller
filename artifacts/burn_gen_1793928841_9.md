## 1. Loop Architecture and Rates

```
              1 kHz                 4 kHz                      20 kHz
 q_ref ─►[Attitude/Angle PID]─ω_ref─►[Velocity PI + FF]─iq_ref─►[Current PI d/q]─►SVPWM─►Motor
             ▲                          ▲        ▲                    ▲
             │ q̂ (Mahony)              │ ω_axis │ iq_ff(θ_m, ω)      │ i_abc, θ_e
   [Dual ICM-42688 fusion] ──gyro──────┘  [Anti-cogging LMS]   [Encoder θ_m]
        8 kHz → filters → 4 kHz
```

**Bandwidth separation rule.** Each inner loop should be 5–10× faster than the loop around it:

ω_c,i ≈ 2π·1.5 kHz,  ω_c,ω ≈ 2π·150 Hz,  ω_c,θ ≈ 2π·20 Hz

## 2. Current (FOC) Loop: 20 kHz

### 2.1 Transforms
Use amplitude-invariant Clarke and Park transforms with i_a + i_b + i_c = 0:

i_α = i_a,  i_β = (i_a + 2i_b)/√3

i_d = i_α cos θ_e + i_β sin θ_e,  i_q = −i_α sin θ_e + i_β cos θ_e

The electrical angle comes from the mechanical angle:

θ_e = p·θ_m − θ_off

### 2.2 Plant and decoupled PI
The PMSM voltage equations in the rotating frame are:

v_d = R i_d + L di_d/dt − ω_e L i_q
v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ

The PI controller adds decoupling and back-EMF feedforward:

v_d* = PI_d(i_d* − i_d) − ω_e L i_q
v_q* = PI_q(i_q* − i_q) + ω_e L i_d + ω_e λ

**Pole-zero cancellation tuning.** With ω_ci the target current bandwidth:

K_p = L·ω_ci,  K_i = R·ω_ci

This makes the closed loop first-order:

i/i* = ω_ci/(s + ω_ci)

**Delay limit.** Keep ω_ci ≤ 1/(3·1.5·T_s) to account for the 1.5-sample PWM + computation delay.
