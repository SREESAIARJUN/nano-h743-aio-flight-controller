## 1. FOC Current Loop Equations

### 1.1 Reference transforms
The electrical angle is computed from the mechanical angle and a calibrated offset:

$$\theta_e = p\,\theta_m - \theta_{\text{off}} \pmod{2\pi}$$

**Clarke transform** (amplitude-invariant, using $i_a+i_b+i_c=0$):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and PI tuning by pole-zero cancellation
The dq-frame motor model is:

$$L\dot i_d = v_d - R i_d + \omega_e L i_q,\qquad L\dot i_q = v_q - R i_q - \omega_e L i_d - \omega_e \lambda_m$$

With the cross terms removed by decoupling feedforward, each axis becomes the first-order plant $G(s)=\dfrac{1}{Ls+R}$.

Choose the PI controller $C(s)=K_p + K_i/s$ with:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The PI zero then cancels the plant pole, and the closed loop is exactly $\dfrac{\omega_c}{s+\omega_c}$. Use $\omega_c = 2\pi\cdot 1.5\text{ kHz}$, which is roughly $f_{pwm}/13$.

**Decoupling and back-EMF feedforward:**
$$v_d^{*} = \text{PI}_d - \omega_e L i_q,\qquad v_q^{*} = \text{PI}_q + \omega_e L i_d + \omega_e\lambda_m$$

**Voltage limit (circular, d-axis priority):**
$$|v_d|\le V_{max},\qquad |v_q|\le\sqrt{V_{max}^2-v_d^2},\qquad V_{max}=\frac{V_{bus}}{\sqrt3}$$

**Anti-windup:** apply back-calculation with $K_{aw}=1/K_p$:
$$\dot x_I = K_i e + K_{aw}(v_{sat}-v_{unsat})$$

### 1.3 Space-vector PWM via min-max zero-sequence injection
$$v_{a,b,c} = \text{invClarke}(v_\alpha,v_\beta),\qquad v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big)$$
$$d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

## 2. Velocity Estimation (Encoder PLL)

Differencing raw encoder samples at 20 kHz gives severe quantization noise:

$$\Delta\theta_q = \frac{2\pi}{2^{14}}\cdot 20000 \approx 7.7\text{ rad/s}$$

A type-II tracking PLL avoids this:

$$e_\theta = \text{wrap}(\theta_{meas}-\hat\theta),\quad \hat\omega \mathrel{+}= K_{i}\,e_\theta\,T_s,\quad \hat\theta \mathrel{+}= (\hat\omega + K_p e_\theta)T_s$$

Set $K_p = 2\zeta\omega_n$ and $K_i=\omega_n^2$, with $\omega_n = 2\pi\cdot 300$ Hz and $\zeta=1$. The estimate $\hat\theta$ also gives lower-jitter commutation.
