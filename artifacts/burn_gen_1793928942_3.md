# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 or similar Cortex-M4F at 170 MHz with single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A or MT6701), read over SPI every PWM cycle |
| Current sense | 2-phase low-side shunts (a voltage-mode fallback is shown) |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the payload centre |
| Gimbal kinematics | Yaw (z) → Roll (x) → Pitch (y), from base to camera |

| Loop | Rate | Ts | Feedback |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | Shunts + encoder electrical angle |
| Rate (velocity) | 4 kHz | 250 µs | Fused, filtered gyro (camera frame) |
| Attitude (angle) | 1 kHz | 1 ms | Fused quaternion |
| IMU sampling | 8 kHz ODR | 125 µs | Raw data, then filter chain, then 2:1 decimation |

**Bandwidth separation rule.** Each outer loop
