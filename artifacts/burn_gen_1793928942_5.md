## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class Cortex-M4F/M7, single-precision FPU |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.1 N·m/A |
| Encoders | 14-bit absolute magnetic per joint (AS5048A / MT6701 class) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz |
| Joint order (base → camera) | Yaw (z) → Roll (x) → Pitch (y) |

```
           1 kHz                  4 kHz                       20 kHz
 q_ref ─► [SO(3) angle P] ─ω*─► [J⁻¹ · rate PI] ─iq*─(+)─► [FOC PI id/iq + SVPWM] ─► motor

             ▲                     ▲
   [Dual IMU: AAF → PT2 → dyn. notch ×2 → inverse-variance fusion]  8 kHz
```

The design rule is that bandwidths are separated by at least 4× between loops:

- Current loop: ω_c ≈ 2π·2 kHz
- Velocity loop: ω_v ≈ 2π·150 Hz
- Angle loop: ω_a ≈ 2π·30 Hz
