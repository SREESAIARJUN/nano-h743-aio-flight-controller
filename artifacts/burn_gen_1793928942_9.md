# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Vibration Rejection

I don't have the specification for "Job #7". This design therefore uses the assumptions below. Every one of them is a parameter in the code, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (GM4108-class): p = 7 pole pairs, R ≈ 10 Ω, L ≈ 4 mH, K_t ≈ 0.08 N·m/A |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7) |
| Loop rates | Current 20 kHz · rate (velocity) 8 kHz · attitude (angle) 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, shared CLKIN |
| Gimbal order | Base → Yaw (z) → Roll (x) → Pitch (y) → camera |
