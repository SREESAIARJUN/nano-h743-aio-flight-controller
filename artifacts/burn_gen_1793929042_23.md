## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R_ds = 1.0 × (1 + 0.005·100) = **1.5 mΩ**.

### 1.2 Six-step synchronous commutation

At any instant, two phase legs carry the current:

- **PWM leg:** the high side conducts for duty D. The complementary low side conducts for (1 − D) minus dead time.
- **Return leg:** the low side conducts 100%.

$$P_{cond,ch}=I_{rms}^2R_{ds}\big[D+(1-D)\big]+I_{rms}^2R_{ds}=2I_{rms}^2R_{ds}(T_j)$$

This result is duty-independent because of synchronous rectification. Ripple adds an RMS correction:

$$I_{rms}^2=I_{ph}^2\left(1+\frac{1}{12}\left(\frac{\Delta I}{I_{ph}}\right)^2\right),\qquad \Delta I=\frac{V_{bus}D(1-D)}{L_{ph}f_{sw}}$$

Example: L_ph = 15 µH and D = 0.5 give ΔI = 8.75 A. The correction is then +0.1%, which is negligible at 80 A.

### 1.3 Results per channel

| Term | Expression | @ T_j = 125 °C |
|---|---|---|
| FET conduction | 2 · 80² · 1.5 mΩ | **19.2 W** |
| PCB copper | 80² · 0.3 mΩ | **1.9 W** |
| Body-diode dead-time | V_SD · I · 2t_dead · f_sw = 0.8·80·200 ns·48 kHz | **0.61 W** |

### 1.4 Thermal runaway check

R_ds depends on T_j, so the junction temperature is a fixed point:

$$T_j=T_{pcb}+R_{\theta,j\text{-}pcb}\,P_{FET}(T_j)$$

This is stable only if

$$R_{\theta}\cdot\frac{\partial P}{\partial T_j}=R_\theta\,\alpha\,P_{25}<1$$

Per FET (Section 3.1): P₂₅ ≈ 2.1 W, R_θ ≈ 3 K/W, which gives 0.03. Local runaway is not a risk; the board bulk temperature is the limiter.
