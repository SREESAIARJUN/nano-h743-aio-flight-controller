# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #42): Architecture, Loss Model, DShot Allocation, Reference Netlist

## 0. Architectural Ground Rules

These constraints shape everything that follows.

1. **The H743 does not switch the MOSFETs.** In a 4-in-1 AIO, each motor channel has its own ESC MCU, such as an AT32F421 or STM32G071 running AM32/BLHeli_32. That ESC MCU generates the 48 kHz complementary PWM.
   - The H743 runs ArduPilot and talks to each ESC MCU over one bidirectional DShot600 wire.
   - The loss model (§2–4) therefore applies to the ESC power stage. The DMA model (§5) applies to the H743.
2. **"80 A burst" on a nano-sized board is a transient rating, not a thermal rating.** The model below quantifies this. Expect about 1–2 s at 80 A on all four channels and roughly 15–20 A continuous per channel with prop-wash airflow.
3. **Device parameters are representative placeholders.** They describe a 40 V, 3.3×3.3 mm DFN-class MOSFET. Substitute datasheet values for your selected parts before sign-off.
4. **The netlist in §6 is a reference/topology netlist, not a released design.** Pin numbers must be verified against the exact package (LQFP100 vs TFBGA) and the chosen ESC MCU.

## 2. Conduction Loss Model (6-Step Trapezoidal, Synchronous Rectification)

### 2.1 Switch utilization

Over one electrical cycle, each phase leg spends three equal intervals in different states:

- **1/3 as the PWM leg.** The high-side (HS) is on for D and the low-side (LS) synchronously rectifies for (1 − D).
- **1/3 as the return leg.** The LS is fully on.
- **1/3 floating.** This interval is used for BEMF sensing.

The conduction duty fractions are therefore:

$$\delta_{HS} = \frac{D}{3}, \qquad \delta_{LS} = \frac{(1-D)+1}{3} = \frac{2-D}{3}$$

### 2.2 Per-FET loss

$$P_{cond,HS} = I^2 R_{ds}(T_j)\,\frac{D}{3}, \qquad P_{cond,LS} = I^2 R_{ds}(T_j)\,\frac{2-D}{3}$$

Adding ripple, the RMS correction for a ripple ratio r = ΔI/I is:

$$I_{rms}^2 = I^2\left(1+\frac{r^2}{12}\right)$$

With r = 0.3 the correction is +0.75%, which is negligible. It is ignored below.

### 2.3 Per-channel total

At any instant exactly two FETs carry I, so the per-channel total is independent of D:

$$P_{cond,ch} = 3\left(P_{HS}+P_{LS}\right) = 2\,I^2 R_{ds}(T_j)$$
