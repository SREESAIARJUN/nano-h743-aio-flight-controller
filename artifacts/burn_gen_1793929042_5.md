# STM32H743 Nano FC + 4-in-1 ESC (Job #7): Power, Thermal & Bi-Directional DShot600 Design

## 0. Architecture Baseline and Assumptions

The H743 does **not** commutate the motors. It is the flight controller running ArduPilot, and it sends bi-directional DShot600 to four ESC MCUs. Each ESC MCU (AT32F421 or STM32G071 class, running AM32 or BLHeli_32) drives a 3-phase bridge at 48 kHz. Keeping this split explicit avoids the common error of budgeting H743 timers for motor PWM.

```
VBAT (6S) ──┬── Battery shunt + INA ── H743 ADC
            ├── 4× [ESC MCU → 3× half-bridge driver → 6× MOSFET] → Motor 1..4
            └── 5V/9V BEC ── H743, Rx, VTX
H743 TIM3/TIM5 ── DShot600 (bidirectional, 1 wire per motor) ── ESC MCU 1..4
```

The parameters marked "assumed" are representative 40 V / 3×3 or 5×6 mm class values. Replace them with your selected part's datasheet numbers and re-run the equations.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge, worst case) | V_bus | 25.2 V |
| Burst phase current per ESC | I_ph | 80 A |
| PWM frequency | f_sw | 48 kHz |
| R_DS(on) @ 25 °C (assumed) | R₂₅ | 0.90 mΩ |
| R_DS(on) temperature coefficient (assumed) | α | ≈0.0055 /K |

> **Feasibility flag.** 80 A per channel on a nano (20×20 / 30×30) 4-in-1 is a short-burst rating, not continuous. The model below shows it is thermally limited to roughly **1–2 s**. Treat "80 A" as a firmware-enforced burst limit.

## 1. Conduction Loss Model

### 1.1 Current path (six-step, synchronous/complementary PWM)

Two phases are active in each 60° commutation sector:

- **PWM leg:** the high-side FET conducts for D·T_sw and the low-side FET (synchronous rectifier) for (1−D)·T_sw. Exactly one FET always carries I_ph, ignoring dead time.
- **Return leg:** the low-side FET is on continuously.

The result is independent of duty cycle:

$$P_{cond,ch} = I_{ph}^2 \cdot R_{DS}(T_j)\cdot 2 \quad\text{(ignoring dead time)}$$

### 1.2 Temperature correction

$$R_{DS}(T_j) = R_{25}\left[1+\alpha (T_j-25)\right]$$

At T_j = 110 °C: R_DS = 0.90 × (1 + 0.0055 × 85) = **1.32 mΩ**. This is a self-consistent point, verified in §3.

### 1.3 Numbers at 80 A

$$P_{cond,FET} = 2 \cdot 80^2 \cdot 1.32\,\text{m}\Omega = \mathbf{16.9\ W/channel}$$

$$P_{cu} = 2\cdot 80^2 \cdot 0.5\,\text{m}\Omega = \mathbf{6.4\ W/channel}$$

Each FET conducts for about one-third of the electrical period:

$$\bar P_{FET} \approx 16.9/6 \approx \mathbf{2.8\ W\ average}$$

The peak per conducting FET is 8.4 W.

Battery-side current is I_bat ≈ D · I_ph, so at D = 0.9 it is about 72 A per channel. The motor-side current, not the battery current, sets FET loss. This is a common sizing mistake.

## 2. Switching Loss Model at 48 kHz

Per channel, only the PWM leg switches. That gives one hard turn-on and one hard turn-off per period.

### 2.1 V–I overlap loss

$$t_r \approx t_f \approx \frac{Q_{sw}}{I_g} = 12\ \text{ns}$$

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = 0.5\cdot25.2\cdot80\cdot24\text{ns}\cdot48\text{k} = \mathbf{1.16\ W}$$

### 2.2 Dead-time body-diode conduction (two dead times per period)

$$P_{dt} = V_F\, I_{ph}\, 2 t_{dt} f_{sw} = 0.8\cdot80\cdot200\text{ns}\cdot48\text{k} = \mathbf{0.61\ W}$$

### 2.3 Reverse recovery

The low-side body diode recovers at high-side turn-on:

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 40\text{n}\cdot25.2\cdot48\text{k} = \mathbf{0.05\ W}$$

### 2.4 Output capacitance

$$P_{oss} \approx \tfrac12 Q_{oss}V_{bus}f_{sw} = \mathbf{0.02\ W}$$
