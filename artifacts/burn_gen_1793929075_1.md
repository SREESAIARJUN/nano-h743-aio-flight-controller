# Job #34: STM32H743 AIO Flight Controller with 4-in-1 80A ESC

## Engineering Design Package, Rev A: Power-Stage Loss Model, DShot DMA Plan, and Netlists

## 0. Executive Summary

**The 80A figure is only a short-burst rating.** The board can carry 80A per motor for about 1–3 seconds, limited by stored heat in the PCB. It cannot sustain anything near that continuously.

| Metric | Value | Basis |
|---|---|---|
| Loss per motor at 80A burst (Tj ≈ 100°C) | **≈ 18.5 W** | §2–§4 |
| Total ESC loss, 4 motors at 80A | **≈ 74 W** (+ about 6 W copper) | §4 |
| Heat the airframe can sustain in prop wash (ΔT = 65 K) | **≈ 12 W** | §5.3 |
| Realistic continuous current per motor | **≈ 25–28 A** | §5.4 |
| 80A burst duration from a 45°C board | **≈ 3.5–4 s** to a 105°C PCB limit | §5.2 |
| Bidirectional DShot600 frame and turnaround | 26.7 µs TX + about 30 µs gap + 28 µs RX ≈ **90 µs** | §6.2 |
| DMA streams for motor output | **3** (TIM1_UP + TIM1_CH1 + TIM1_CH3) | §6.4 |

**Architecture decision.** The H743 does **not** commutate the motors. Commutation runs on four dedicated ESC MCUs (STM32G071, running AM32). The H743 sends bidirectional DShot600 to them. This is the only practical way to run 48 kHz PWM with zero-cross BEMF detection without consuming the FC's real-time budget.
