# Job #63: STM32H743 Nano FC + 4-in-1 80A ESC Design Package

## 0. Architecture Clarification and Assumptions

**Architecture.** ArduPilot runs on the STM32H743 flight controller. It does not commutate motors. Every production 4-in-1 ESC uses dedicated ESC MCUs, typically one per motor (AT32F421, STM32G071 or GD32 running AM32 or BLHeli_32). The 48 kHz switching loss model therefore applies to the ESC power stage. The DShot600 model applies to the H743. This document treats them as two coupled subsystems on one stack.

**Critical feasibility flags (read these first):**

## 1. Conduction Loss Model

### 1.1 Commutation topology

The ESC uses 6-step trapezoidal (or FOC) drive with synchronous rectification and complementary PWM.

- In every 60° electrical sector, current flows through **two FETs in series at all times**:
  - either the HS of the PWM leg (fraction D of the time) or the LS of the PWM leg (fraction 1−D),
  - plus the LS of the return leg, which is on for 100% of the sector.
- So the path resistance is duty-independent:

```
R_path = 2 · R_DS(on)(T_j)
```

### 1.2 Temperature-dependent R_DS(on)

```
R_DS(on)(T_j) ≈ R_25 · [1 + α·(T_j − 25)],   α ≈ 0.7 %/K for this FET class
R(125 °C) = 1.0 mΩ × 1.7 = 1.7 mΩ
```

### 1.3 RMS current including ripple

Ripple is worst at D = 0.5:

```
ΔI_pp = V_bus·D(1−D) / (L·f_sw) = 25.2·0.25 / (20e-6·48e3) = 6.56 A
I_rms² = I² + ΔI_pp²/12 = 6400 + 3.6 = 6403.6 A²
```

The ripple contribution is negligible (<0.06%) at 80 A.

### 1.4 Conduction loss per channel

```
P_cond,ch = I_rms² · 2 · R(T_j) = 6403.6 × 2 × 1.7e-3 = 21.8 W
```

### 1.5 Per-FET distribution

Each FET conducts 120° of every 360° electrical cycle. At ≥5,000 eRPM the electrical period (<200 µs) is much shorter than the die thermal time constant (~5–20 ms), so per-FET losses can be averaged.

- Average conduction loss per FET: 21.8 W / 6 ≈ **3.6 W**.
- The LS of the return leg carries the full current at 100% within its sector, so the LS devices run marginally hotter than the HS devices.
