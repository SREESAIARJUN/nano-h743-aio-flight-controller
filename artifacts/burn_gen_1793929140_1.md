## 1. FOC Current Loop

### 1.1 Electrical Angle

$$\theta_e = \text{wrap}_{2\pi}\big(p\,(\theta_m - \theta_{m,0})\big)$$

θ_{m,0} is found at calibration by aligning the rotor to the d-axis: apply V_d with θ_e = 0 and read the encoder.

### 1.2 Clarke and Park Transforms

The amplitude-invariant Clarke transform with 3 shunts (i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

The Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant Model (Surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

where ω_e = p·ω_m and λ_m = 2K_t/(3p).

### 1.4 PI Controller with Decoupling and Back-EMF Feedforward

**Pole-zero cancellation (series form):**

$$C_i(s) = K_p\Big(1+\frac{1}{T_i s}\Big),\quad K_p = L\,\omega_c,\quad T_i = \frac{L}{R}$$

**Parallel form:**

$$K_{p} = L\omega_c,\qquad K_{i} = R\,\omega_c$$

**Discrete control law (forward Euler on the integrator), for x ∈ {d, q}:**

$$e_x[k] = i_x^*[k]-i_x[k]$$

$$v_x^{PI}[k] = K_p e_x[k] + I_x[k]$$

**Decoupling and feedforward terms:**

$$v_d^* = v_d^{PI} - \hat\omega_e L\, i_q,\qquad v_q^* = v_q^{PI} + \hat\omega_e (L i_d + \lambda_m)$$

**Voltage limiting.** Use the circular limit $|v_{dq}| \le V_{max} = V_{bus}/\sqrt3$ (the SVPWM linear range). Prioritize d:

$$v_d^{sat} = \text{clamp}(v_d^*, \pm V_{max}),\qquad v_q^{sat} = \text{clamp}\Big(v_q^*, \pm\sqrt{V_{max}^2 - (v_d^{sat})^2}\Big)$$

**Back-calculation anti-windup:**

$$I_x[k+1] = I_x[k] + K_i T_{s,i}\, e_x[k] + K_{aw}\,(v_x^{sat}-v_x^*),\qquad K_{aw}\approx 1$$
