# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #15", so this design rests on the assumptions in §0. Replace them with your actual hardware values before tuning. Every gain below comes from motor parameters (R, L, λ, J, K_t), so the design carries over to other hardware once those values are updated.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–4 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A or MT6701) per axis, SPI |
| MCU | STM32G4 / H7 class with FPU, CORDIC optional |
| Current sense | 2 inline shunts per motor. A voltage-mode fallback is given for boards without shunts |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, shared FSYNC |
| Kinematics | Yaw (outer)
