## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P, so pole pairs p = 7 and slots N_s = 12 |
| Phase parameters | R = 5 Ω, L_d ≈ L_q = 2 mH, λ_pm from K_t: K_t = 1.5·p·λ_pm |
| Rotor position | 14-bit magnetic encoder (e.g. AS5048A / MT6701), one per axis |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, FIFO off, data-ready IRQ |
| PWM / current loop | 20 kHz centre-aligned, current loop runs every PWM period |
| Velocity loop | 4 kHz (decimate 5:1) |
| Attitude loop | 1 kHz (decimate 4:1) |
| Fusion | Gyro at 8 kHz, then filter, then decimate to 4 kHz |

The cascade has three nested loops:

```
 θ_ref ─►[Angle P + ω_ff]─ω_ref─►[Velocity PI]─i_q*─(+)─►[Current PI d/q + decoupling]─►SVPWM─►Motor
            ▲ θ̂ (Mahony)          ▲ ω̂ (fused gyro,      ▲ i_cog (anti-cogging FF)     ▲ θ_e (encoder)
            │                     │  notch+LPF filtered)
        Dual ICM-42688-P ─► lever-arm cancel ─► fault vote ─► inverse-variance fuse ─► dynamic notch ─► PT2
```

**Key design decision:**
- The **velocity and angle loops close on the IMU**, which measures the camera's inertial rate. This is what rejects base motion.
- The **encoder is used only for commutation** (θ_e) and as the cogging-map coordinate (θ_m).

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform**, with θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform uses the transpose of this matrix.

### 1.2 Plant in the rotor frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_{pm})$$

### 1.3 Current PI with pole–zero cancellation

For target closed-loop bandwidth ω_c, choose:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

This gives a closed loop of ω_c/(s+ω_c). Choose ω_c ≤ 2π·f_pwm/20 to stay clear of PWM delay; ≈ 2π·1 kHz here.

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L_q i_q,\qquad v_q^{ff} = \omega_e (L_d i_d + \lambda_{pm})$$

**Discretisation (forward Euler is adequate at 20 kHz):**

$$u[k] = K_p e[k] + I[k],\qquad I[k+1] = I[k] + K_i T_s e[k] + K_{aw}\,(u_{sat}[k]-u[k])$$

The last term is back-calculation anti-windup, with K_aw = K_i/K_p.

### 1.4 Voltage limit and SVPWM

**Circular limit** (keeps the linear modulation region):

$$|v_{dq}| \le V_{max} = \frac{V_{dc}}{\sqrt3}\cdot 0.95$$

- d-axis priority: clamp v_d first.
- Then clamp $|v_q| \le \sqrt{V_{max}^2 - v_d^2}$.

**Min–max zero-sequence injection** (equivalent to SVPWM):

$$v_{0} = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$
