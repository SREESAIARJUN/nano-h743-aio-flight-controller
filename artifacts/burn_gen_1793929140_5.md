# FOC Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #18)

I don't have the Job #18 specification, so this design rests on the hardware baseline in §0. Every numeric value is parameterised. Swap in your measured motor and inertia data and the gain formulas re-derive themselves.

## 0. Assumed System Baseline

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoders | 14-bit absolute magnetic (AS5048A/MT6701 class), read over SPI each current cycle |
| MCU | STM32G4 / H7 class (FPU, 170+ MHz), center-aligned PWM |
| IMU-P | ICM-42688-P on the **payload** (camera) plate. This is the stabilisation feedback. |
| IMU-B | ICM-42688-P on the **base** (above the vibration dampers). This is the vibration reference and base-rate feedforward. |
| Kinematic order | Base → Yaw → Roll → Pitch → Payload |

**Loop rate hierarchy.** The rule is bandwidth separation of at least 5× between nested loops.

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| Velocity | 5 kHz (÷4) | ~150–300 Hz |
| IMU sampling (ODR) | 8 kHz | n/a |
| Attitude / angle | 1 kHz (÷20) | ~20–40 Hz |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical Angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

θ_off is found at calibration: lock with v_d > 0, v_q = 0, then read the encoder.

### 1.2 Clarke and Park Transforms

Power-invariant scaling is not used; amplitude-invariant is.

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(i_a+i_b+i_c=0)$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant Model (dq Frame, SPM Motor, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 1.4 Current PI by Pole-Zero Cancellation

The plant is $G_i(s) = \frac{1}{Ls+R}$. Choose the controller

$$C_i(s) = K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_c,\quad K_i = R\,\omega_c$$

This gives an open loop of $\omega_c/s$, so the closed loop is first-order with bandwidth ω_c. Pick ω_c ≤ 2π·f_PWM/10, accounting for the 1.5-sample PWM/computation delay.

Decoupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d - \omega_e L\, i_q,\qquad v_q^* = \text{PI}_q + \omega_e L\, i_d + \omega_e\lambda_m$$

**Voltage limiting (circular).** If $\sqrt{v_d^2+v_q^2} > V_{max} = V_{bus}/\sqrt3$, then:
- prioritise d: $v_q \leftarrow \operatorname{sign}(v_q)\sqrt{V_{max}^2 - v_d^2}$;
- apply back-calculation anti-windup to each integrator.
