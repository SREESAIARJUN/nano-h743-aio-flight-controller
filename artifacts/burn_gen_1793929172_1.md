# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #53, so this design is built on the assumptions in §0. Every hardware-dependent constant is a named parameter that you can replace with your actual values.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Driver | 3-phase, center-aligned PWM at 20 kHz, 2- or 3-shunt current sensing |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| MCU | Cortex-M4F/M7 with single-precision FPU (e.g., STM32G4/H7) |
| Kinematic chain | Base → Yaw(z) → Roll(x) → Pitch(y) → Camera |

**Loop rate hierarchy.** Each loop runs well above the bandwidth of the loop it feeds, giving at least 5–10× bandwidth separation.

```
 20 kHz  : current loop (FOC, PI on id/iq, SVPWM)           BW_i ≈ 1.5–2 kHz
  4 kHz  : velocity loop (PI + cogging FF + accel FF)       BW_v ≈ 150–250 Hz
  8 kHz  : IMU sample, rotate, notch/LPF, dual-IMU fusion
  1 kHz  : attitude estimator (Mahony) + angle loop         BW_θ ≈ 20–40 Hz
           + gimbal inverse Jacobian
```
