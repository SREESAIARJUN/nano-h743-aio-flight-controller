# STM32H743 AIO Flight Controller with 4-in-1 ESC: Job #58 Design Package

## 0. Feasibility Findings

These issues determine whether the target spec can be met, so they come before the math.

| # | Finding | Impact |
|---|---|---|
| F1 | The STM32H743 cannot directly run the motor commutation. It is the flight controller MCU. Each ESC channel needs its own commutation MCU running AM32 or BLHeli_32, such as the STM32G071 or AT32F421. The H743 sends DShot600 to these four MCUs. | Architecture is set as described in §1. |
| F2 | "80A burst" on a nano (20×20 mm) board is not thermally achievable on all four channels at once. §3 shows about 130 W of dissipation and a time-to-limit of about 3 s with no heatsink. | Specify per-channel burst only, or move to 30×30 or a heatsinked format. |
| F3 | 4 × 80 A = 320 A of battery current exceeds any XT60/XT90 and any nano-board pad or wire gauge. | Define the burst as 80 A on one channel with ≤ 45 A per channel aggregate. |
| F4 | All numbers below use stated assumptions for MOSFET parameters and thermal resistances. | Replace them with datasheet values and IR-camera or thermocouple data from a prototype before freezing the spec. |

```
            ┌──────────────── STM32H743VIT6 (FC, 400 MHz) ────────────────┐
 IMU/Baro/  │ TIM1_CH1..CH4 ── DShot600 bidirectional ──┐                  │
 OSD/UARTs  └───────────────────────────────────────────┼──────────────────┘
                                                        │ (4 × single-wire, 330 Ω series)
          ┌──────────────┬──────────────┬───────────────┴──┐
     ESC MCU1 (G071)  ESC MCU2      ESC MCU3          ESC MCU4      ← AM32, PWM 48 kHz
          │              │              │                  │
     FD6288Q gate drv ×4 (3-phase, bootstrap)
          │
     6 × N-MOSFET 3-phase bridge per channel (24 FETs total)
          │
     Shared VBAT bus (low-ESR bulk + MLCC) ── shunt ── INA current sense → H743 ADC
```

## 2. Electrical Loss Model (per ESC channel)

### 2.1 Assumptions

| Symbol | Value | Basis |
|---|---|---|
| V_bus | 25.2 V | 6S, fully charged |
| I_ph | 80 A | Burst phase current (≈ DC link current at full duty) |
| f_sw | 48 kHz | AM32 PWM |
| R_DS(on),25 | 1.6 mΩ @ V_GS = 10 V | 40 V MOSFET, 3.3×3.3 mm package (nano footprint) |
| k_T | 1.55 | R_DS(on) multiplier at T_j = 125 °C |
| R_Cu | 0.3 mΩ | Phase + bus copper per conduction path, 2 oz |
| t_r + t_f | 20 ns | Effective V-I overlap with 2 Ω gate resistor |
| Q_oss | 40 nC | Datasheet class |
| Q_rr | 50 nC | Body-diode reverse recovery |
| V_F | 0.8 V | Body diode at 80 A |
| t_dt | 100 ns | Dead time per edge |
| Q_g | 50 nC @ 10 V | Total gate charge |

### 2.2 Conduction Loss

In 6-step trapezoidal commutation with synchronous rectification, current always flows through two FET positions in series (one high-side path and one low-side path), plus copper:

$$
P_{cond} = I^2\left(2\,k_T\,R_{DS(on),25} + R_{Cu}\right)
$$

$$
P_{cond} = 80^2\,(2 \times 1.55 \times 1.6\text{ m}\Omega + 0.3\text{ m}\Omega) = 6400 \times 5.26\text{ m}\Omega = \mathbf{33.7\ W}
$$

This term is independent of duty, because the complementary FET carries the freewheel current. It accounts for about 90% of the total loss.

### 2.3 Switching Losses at 48 kHz

Only the PWM-active leg switches. That is one hard-switched edge pair per PWM period.

**1. V-I overlap loss**

$$
P_{sw} = \tfrac12 V I (t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\text{ ns} \times 48\text{ kHz} = 0.97\text{ W}
$$

**2. Output capacitance loss**

$$
P_{oss} = Q_{oss} V f_{sw} = 40\text{ nC} \times 25.2 \times 48\text{ k} = 0.05\text{ W}
$$

**3. Reverse recovery loss**

$$
P_{rr} = Q_{rr} V f_{sw} = 50\text{ nC} \times 25.2 \times 48\text{ k} = 0.06\text{ W}
$$

**4. Dead-time body-diode loss**

$$
P_{dt} = V_F I (2t_{dt}) f_{sw} = 0.8 \times 80 \times 200\text{ ns} \times 48\text{ k} = 0.61\text{ W}
$$
