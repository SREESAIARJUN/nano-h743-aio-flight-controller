# STM32H743 FC + 4-in-1 ESC Reference Design: 80 A Burst Losses, 48 kHz Switching, and Bidirectional DShot600 DMA Allocation

## 0. Scope, Architecture, and Assumptions

I don't have prior documentation for "Job #54," so this design is built from first principles. Every assumed parameter is listed below. Replace them with your actual BOM values, and the equations will carry through.

**Architecture clarification.** In a 4-in-1 stack, the STM32H743 does not drive the MOSFETs. Each motor has its own ESC MCU, which does the commutation and generates the 48 kHz PWM:

```
                      DShot600 (bidirectional, single wire per motor)
 STM32H743 FC  ──TIM1 CH1..CH4──►  ESC MCU ×4 (e.g., AT32F421 / STM32G071, AM32 or BLHeli_32)
 (ArduPilot)   ◄── eRPM telemetry ──   └─► 3-phase gate driver ─► 6 N-MOSFETs ─► motor
```
