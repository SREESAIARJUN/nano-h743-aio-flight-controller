# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #7 specification, so this design uses typical gimbal values. Change the parameters marked `// CONFIG` to match your hardware.

**Assumed hardware**

- **Motors:** 3 × outrunner BLDC, 12N14P (7 pole pairs), with 14-bit absolute magnetic encoders.
- **Inverter:** STM32G4/H7-class MCU, 3-phase inverter, 2- or 3-shunt current sensing.
- **IMUs:** 2 × ICM-42688-P on the camera plate. They are separated by a known lever arm and read over SPI at 8 kHz.

**Loop timing**

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1.5 kHz |
| Velocity | 4 kHz | ω_v ≈ 2π·150 Hz |
| Angle (attitude) | 1 kHz | ω_p ≈ 2π·30 Hz |
| IMU fusion | 8 kHz in, 1 kHz out | n/a |

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle: θ_e = N_pp · (θ_m − θ_offset), with N_pp = 7.

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 PMSM model in the d-q frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$
$$\tau_e = \tfrac{3}{2} N_{pp}\left[\lambda_m i_q + (L_d - L_q) i_d i_q\right] \approx K_t\, i_q,\quad K_t = \tfrac{3}{2}N_{pp}\lambda_m$$

### 1.3 Current PI with decoupling

The PI zero is placed on the electrical pole (−R/L). This makes the closed loop first order with bandwidth ω_c:

$$K_{p,c} = L\,\omega_c,\qquad K_{i,c} = R\,\omega_c$$

$$C_c(s)\,G_c(s) = \frac{L\omega_c s + R\omega_c}{s}\cdot\frac{1}{Ls+R} = \frac{\omega_c}{s}\;\Rightarrow\; T_c(s) = \frac{\omega_c}{s+\omega_c}$$

Decoupling feedforward terms are added to the PI outputs:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L_q i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e(L_d i_d + \lambda_m)$$

Use i_d* = 0. Gimbal motors run well below base speed, so field weakening is not needed.

Practical constraint: ω_c should be no more than about f_PWM/10 because of PWM and computation delay (≈1.5 T_s).

### 1.4 Voltage limiting and SVPWM

**Circular limit.** If

$$|v^*| > V_{max} = \frac{V_{bus}}{\sqrt{3}}\cdot m_{max},\quad m_{max}\approx 0.95,$$

then priority-scale it: keep v_d, and set v_q = sign(v_q)·√(V_max² − v_d²).

**SVPWM via min-max (zero-sequence) injection:**

$$v_{a,b,c} = \text{invClarke}(\text{invPark}(v_d,v_q)),\quad v_0 = -\tfrac{1}{2}\left(\max(v_{abc})+\min(v_{abc})\right)$$
$$d_x = \tfrac{1}{2} + \frac{v_x + v_0}{V_{bus}}$$

**Anti-windup.** Use back-calculation: the integrator receives K_aw·(v_sat − v_unsat), with K_aw = K_i/K_p.

## 2. Cascaded Velocity / Angle Control

### 2.1 Velocity plant

$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

The current loop is much faster than the velocity loop (ω_c ≫ ω_v), so the plant seen by the velocity loop is approximately:

$$G_v(s) \approx \frac{K_t}{Js}\cdot\frac{1}{1+s/\omega_c}$$

### 2.2 Velocity PI(D) using the symmetric optimum

Choose crossover ω_v and spacing factor a ≥ 2. Use a = 2 for ≈37° phase margin, or a = 3 for ≈53°.

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad T_{i,v} = \frac{a^2}{\omega_v}\Rightarrow K_{i,v} = \frac{K_{p,v}}{T_{i,v}}$$

With a = 2 and ω_c/ω_v = a², phase margin is maximized at crossover.

**Rate feedback source.** On gimbals, the velocity loop is usually closed on the **IMU gyro rate projected onto the motor axis**, not on the encoder differential:

$$\omega_{fb,k} = \mathbf{e}_k^\top\left(R_{k}^{cam}\,\boldsymbol\omega_{gyro}\right) - \dot\theta_{\text{outer joints}}$$

The encoder rate is used during start-up or IMU fault. A small derivative term with a first-order filter (τ_d = 1/(5ω_v)) is optional:

$$u_D = K_{d,v}\frac{s}{1+\tau_d s}(-\omega_{fb})$$

The derivative acts on the measurement, which avoids derivative kick.

**Full velocity law:**

$$i_q^* = \underbrace{K_{p,v} e_\omega + K_{i,v}\!\int e_\omega}_{\text{PI}} + \underbrace{\frac{J\dot\omega^* + B\omega^*}{K_t}}_{\text{model FF}} + \underbrace{\hat i_{cog}(\theta_m)}_{\S3}$$

### 2.3 Angle loop

Use P with velocity and acceleration feedforward. Because the velocity loop is closed, no integral term is needed, and adding one costs phase margin.

$$\omega^* = K_{p,\theta}\,\text{wrap}(\theta^* - \theta) + \dot\theta^*,\qquad K_{p,\theta} = \omega_p\approx \omega_v/5$$

The angle error is computed as the attitude error between the target quaternion q* and the estimate q̂:

$$\mathbf{q}_e = \mathbf{q}^{*}\otimes\hat{\mathbf{q}}^{-1}$$
$$\boldsymbol\theta_e = 2\,\text{sign}(q_{e,w})\,\mathbf{q}_{e,xyz}\quad\text{(small-angle)}$$

θ_e is mapped onto joint axes through the inverse of the joint Jacobian. For a typical yaw-roll-pitch gimbal near nominal pose, this is approximately identity with a cos(roll) correction on yaw.

Saturate ω* to ±ω_max, and back-calculate into nothing (P-only loop).
