# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual ICM-42688-P Vibration Rejection

I don't have the "Job #2" specification, so the design rests on the assumptions below. Everything is parameterized and lives in one config block, so you can substitute your real numbers.

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, CORDIC/FMAC available), or any M4F/M7 |
| Motors | Gimbal BLDC, 24N22P (e.g. GM4108H): pole pairs **Np = 11**, R ≈ 10 Ω, L ≈ 3 mH, Kt ≈ 0.08 N·m/A |
| Bus voltage | 12–16 V |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per joint, SPI |
| Current sense | 2 or 3 low-side shunts, ADC triggered at PWM center |
| IMUs | **Two ICM-42688-P on the camera plate**, rotated 180° about z from each other, SPI at 8 kHz ODR |
| Gimbal order | Base → **Yaw (z) → Roll (x) → Pitch (y)** → camera |

| Loop | Rate | Ts | Target bandwidth |
