# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification and Reference Implementation

> **Assumptions.** I don't have the Job #29 specifics, so this design uses the parameters below. Every one of them is a named constant in the code. Replace them with your measured values.

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoders | 14-bit magnetic (MT6701 / AS5048A) on each joint |
| MCU | STM32G474 / H7 class with FPU, center-aligned PWM at 20 kHz |
| Current sensing | 2-phase low-side shunts with INA240-class amplifiers |
| IMUs | 2× ICM-42688-P on the camera plate, on separate SPI buses, synchronized via CLKIN |
| Joint order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates.**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current | 20 kHz | ≈ 1.5–2 kHz |
| Velocity | 4 kHz | ≈ 150–250 Hz |
| Attitude | 1 kHz | ≈ 20–40 Hz |
| IMU | 8 kHz ODR, FIFO read at 4 kHz | — |

Each loop's bandwidth is at least 4–5× below the loop inside it. This separation is the rule that justifies tuning each loop independently.
