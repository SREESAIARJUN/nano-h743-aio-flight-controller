# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #57 specification, so the design assumes the typical hardware listed below. Every parameter is a named constant so you can substitute your real values.

| Item | Assumption |
|---|---|
| Motors | Gimbal BLDC (e.g. GM4108-class), 12N14P → pole pairs p = 7, N_slots = 12 |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| MCU | STM32G4 / H7 class, single-precision FPU |
| Current loop | 20 kHz, center-aligned PWM, synchronous ADC sampling |
| Velocity loop | 4 kHz (every 5th PWM period), gyro-based (inertial) |
| Angle loop | 1 kHz, attitude-estimator based |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz, mounted symmetrically about the board centroid |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

**Electrical angle:**

θ_e = p·(θ_m − θ_offset) mod 2π

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b)/√3

**Park transform:**

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park transform:**

- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Delay Compensation

PWM updates are applied one period late, and the update itself takes half a period. The angle used for the inverse Park transform is therefore advanced:

θ_e,out = θ_e + ω_e·(1.5·T_pwm)

### 1.3 Space-Vector PWM (Min/Max Zero-Sequence Injection)

1. Compute the phase voltages:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
2. Compute the common-mode offset: v_0 = −½·(max(v_a, v_b, v_c) + min(v_a, v_b, v_c)).
3. Compute the duty cycles: d_x = ½ + (v_x + v_0)/V_bus.

The linear range is |v| ≤ V_bus/√3.

### 1.4 Current PI Controllers (Pole-Zero Cancellation)

**Plant (per axis):**

G_i(s) = 1 / (L·s + R)

**Controller:**

C_i(s) = K_p + K_i/s

Choosing the gains below cancels the electrical pole and gives a first-order closed loop of bandwidth ω_ci:

- K_p = L·ω_ci
- K_i = R·ω_ci

The design target is ω_ci = 2π·1.5 kHz, roughly 1/13 of f_pwm.

**Decoupling and back-EMF feed-forward:**

- v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
- v_q* = PI_q(i_q* − i_q) + ω_e·L·i_d + ω_e·λ_m

**Voltage limiting and anti-windup:**

- The vector (v_d, v_q) is limited to magnitude V_bus/√3, with d-axis priority.
- Integrators use back-calculation anti-windup:

  x_I[k+1] = x_I[k] + T·(K_i·e + K_aw·(v_sat − v_unsat)), with K_aw = 1/K_p.

**Torque relation:**

τ = (3/2)·p·λ_m·i_q = K_t·i_q, with i_d* = 0 (surface PMSM).
