# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Assumptions and Signal Architecture

I don't have the original Job #1 specification, so the design is built on the baseline below. Every value is a parameter in the code. Replace them with your actual hardware values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701, SPI) |
| Current sense | 2-phase low-side shunts (an open-loop voltage-mode fallback is given in §1.6) |
| MCU | STM32G4/H7-class, single-precision FPU, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera stage, SPI at 24 MHz, ODR 8 kHz |
| Kinematics | Yaw (base) → Roll → Pitch (camera) |

**Loop rates (time-scale separation ≥ 5× between each layer):**

```
 20 kHz  ADC ISR      : FOC current loop (id, iq PI), SVPWM, encoder angle
  4 kHz  IMU DMA ISR  : dual-IMU read → align → fuse → notch/LPF chain
  4 kHz  Rate task    : joint-velocity PI + cogging feedforward + LMS adaptation
  1 kHz  Attitude task: Mahony AHRS, attitude PI → camera rate setpoint → joint rates
```

The cascade is: **attitude (quaternion) → camera body rate → joint rate (via Jacobian) → iq → FOC voltages**.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

With mechanical angle θₘ from the encoder, pole pairs p, and calibrated offset θ₀:

$$\theta_e = \operatorname{wrap}_{[0,2\pi)}\big(p\,(\theta_m - \theta_0)\big)$$

**Calibrating θ₀.** Apply a fixed voltage vector at θₑ = 0 (v_d = V_align, v_q = 0) for about 0.5 s. Then record θ₀ = θₘ. Repeat at several electrical cycles and average to cancel encoder eccentricity.

### 1.2 Clarke and Park transforms

The amplitude-invariant Clarke transform, assuming balanced currents so that i_c = −i_a − i_b:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

The Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant model and decoupled PI design

For a surface-mount PMSM (L_d = L_q = L):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The control law is a PI controller plus cross-coupling and back-EMF feedforward:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

This leaves each axis as the first-order plant 1/(Ls+R). Choosing the gains below cancels the plant pole (pole-zero cancellation):

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The closed loop then becomes the first-order system ω_c/(s+ω_c). Choose:

$$\omega_c \le \frac{2\pi f_{pwm}}{10}\;\Rightarrow\; f_c \approx 1.5\text{–}2\ \text{kHz at 20 kHz PWM}$$

**Discretization.** Use backward Euler on the integrator, with sample time Tₛ = 1/f_pwm:

$$x_I[k] = x_I[k-1] + K_i T_s\,e[k] + K_{aw}\big(u_{sat}[k-1]-u[k-1]\big)$$

### 1.4 Voltage limiting and anti-windup

The available voltage is the inscribed circle of the SVPWM hexagon, V_max = V_bus/√3. Apply limits with d-axis priority:

$$v_d^{sat}=\operatorname{clip}(v_d^*,\pm V_{max}),\qquad v_q^{sat}=\operatorname{clip}\!\left(v_q^*,\pm\sqrt{V_{max}^2-(v_d^{sat})^2}\right)$$

Use back-calculation anti-windup with K_aw = 1/K_p
