## 1. Control Architecture

```
            ┌──────────── 1 kHz ────────────┐┌──── 4 kHz ─────┐┌────── 20 kHz ──────┐
 θ_ref ──►(Σ)─► Angle P/PI ─► ω_ref ─►(Σ)─► Velocity PI ─►(Σ)─► i_q PI ─► invPark ─► SVPWM ─► Motor
           ▲  (+ ω_ff)               ▲   (+ i_ff accel)  ▲ ▲   i_d PI (i_d*=0)                │
           │                         │       i_cog(θ_m) ─┘ │                                │
           │                         │                     └── Clarke/Park ◄── i_a,i_b ◄────┤
           │                         └──── ω̂ (IMU gyro, notch-filtered, fused) ◄────────────┤
           └──── θ̂ (Mahony attitude → joint-frame error) ◄── dual ICM-42688-P ◄─────────────┘
                                                          encoder θ_m ──► Park angle, cogging
```

**Bandwidth separation rule.** Each outer loop must be at least 4–5× slower than the loop inside it:

ω_c,i ≈ 2π·1500 rad/s,  ω_c,v ≈ 2π·120 rad/s,  ω_c,θ ≈ 2π·20 rad/s.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms (amplitude-invariant)

**Clarke transform** (with i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform**, using electrical angle θ_e = p·θ_m − θ_off, where p is the number of pole pairs (7):

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park:**

- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

### 2.2 Plant and PI design (pole-zero cancellation)

The dq-axis motor model is:

- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ_m

Use a PI controller C(s) = K_p + K_i/s with:

- K_p = L·ω_c,i
- K_i = R·ω_c,i

This cancels the plant pole at s = −R/L, so the closed loop becomes first-order: i/i* = ω_c,i / (s + ω_c,i).

**Decoupling and back-EMF feedforward** (added to the PI outputs):

- v_d* = PI_d(e_d) − ω_e·L·i_q
- v_q* = PI_q(e_q) + ω_e·L·i_d + ω_e·λ_m,  where λ_m = Kt / (1.5·p)

**Delay compensation.** PWM and ADC add roughly 1.5·T_s of transport delay. Advance the angle used in the inverse Park transform:

θ_e,inv = θ_e + 1.5·ω_e
