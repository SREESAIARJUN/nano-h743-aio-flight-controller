# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Fusion

**Assumptions.** I don't have the spec for Job #11, so this design uses typical values. Every one of them is a parameter in the code.

- **Motors:** gimbal BLDC, 12N14P (7 pole pairs, GBM2804-class). R ≈ 5–12 Ω, L ≈ 1–3 mH.
- **Encoder:** 14-bit absolute magnetic (AS5048A / MT6701) on each joint.
- **IMUs:** two ICM-42688-P on the camera plate (SPI). Ideally one is rotated 180° about z.
- **MCU:** STM32G4 / H7-class with FPU. Center-aligned PWM at 20 kHz.
- **Gimbal order:** Yaw (outer) → Roll → Pitch (inner).

---

## 1. Timing Architecture

| Loop | Rate | Trigger | Content |
|---|---|---|---|
| Current (FOC) | 20 kHz | ADC injected-conversion end | Clarke/Park, PI d/q, SVPWM |
| IMU acquisition | 8 kHz | ICM-42688 INT1 → SPI DMA | Read, calibrate, notch, fuse |
| Rate loop | 4 kHz | Timer, decimated from IMU | Joint-rate PI + cogging FF |
| Attitude loop | 1 kHz | Timer | Mahony AHRS + quaternion P-loop |

**Bandwidth separation** (≥4–5× between stages):

$$\omega_{c,I} \approx 2\pi\cdot 1.5\text{ kHz},\quad \omega_{c,\omega}\approx 2\pi\cdot 80\text{ Hz},\quad \omega_{c,\theta}\approx 2\pi\cdot 15\text{ Hz}$$
