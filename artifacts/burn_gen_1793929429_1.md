## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle
$$\theta_e = N_p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

`θ_offset` comes from alignment: inject `v_d` at θ_e = 0 and read the encoder.

### 1.2 Clarke transform (2-shunt, using i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant and PI design (pole–zero cancellation)
In the rotor frame:

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

Use decoupling feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m,\qquad \lambda_m = \tfrac{2}{3}\tfrac{K_t}{N_p}$$

The decoupled plant is $G(s) = \dfrac{1}{Ls+R}$. A PI controller $C(s) = K_p + K_i/s$ with zero placed at $R/L$ gives a closed loop of $\dfrac{\omega_c}{s+\omega_c}$:

$$\boxed{K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c}$$

Choose $\omega_c \le 2\pi f_{pwm}/20$. At 20 kHz that is $\omega_c \approx 2\pi\cdot 1000$ rad/s.

### 1.5 Discrete PI with clamping anti-windup (backward Euler)
$$u_k = K_p e_k + I_k,\qquad I_{k+1} = \begin{cases} I_k + K_i T_s e_k & \text{if } u_k \text{ not saturated, or } \operatorname{sgn}(e_k)\neq\operatorname{sgn}(u_k)\\ I_k & \text{otherwise}\end{cases}$$

### 1.6 Voltage limiting (circular, d-priority)
$$V_{max} = \frac{V_{bus}}{\sqrt3}\cdot m_{max},\quad v_d \leftarrow \operatorname{clamp}(v_d,\pm V_{max}),\quad v_q \leftarrow \operatorname{clamp}\!\left(v_q,\pm\sqrt{V_{max}^2 - v_d^2}\right)$$

### 1.7 Inverse Park and SVPWM (min-max zero-sequence injection)
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

**Delay compensation.** PWM updates one period late. Use $\theta_e^{pwm} = \theta_e + 1.5\,\omega_e T_s$ in the inverse Park.

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical plant
$$J\dot\omega = K_t i_q - \tau_{cog}(\theta) - B\omega - \tau_{fric} - \tau_{dist}$$

With the current loop treated as unity below $\omega_c$: $G_v(s) = \dfrac{K_t}{Js}$.

### 2.2 Velocity PI (symmetric-optimum style)
Target crossover $\omega_v \approx \omega_c/8$, e.g. $2\pi\cdot 120$ rad/s.

$$\boxed{K_{p,v} = \frac{J\,\omega_v}{K_t}\ \text{[A/(rad/s)]},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{a},\quad a\in[4,6]}$$

This gives phase margin $\approx \arctan(a) - \arctan(\omega_v/\omega_c)$, about 63° for a = 4.

**Velocity feedback filter.** Use a 2nd-order Butterworth LPF at $f_{lp} \approx 4 f_v$ on encoder velocity
