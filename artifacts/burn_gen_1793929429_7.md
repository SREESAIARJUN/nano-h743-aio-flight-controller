# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion: Design Specification

I don't have the original Job #45 brief, so I've based the design on typical brushless-gimbal assumptions, listed in Section 0. Every gain in the code is derived from these assumptions through closed-form formulas. If your hardware differs, change the constants in `AxisParams` and the gains will recompute.

## 1. FOC Current Loop (Inner, 20 kHz)

### 1.1 Transforms

The electrical angle is computed from the mechanical angle, with an offset from calibration:

$$\theta_e = p\,\theta_m - \theta_{off}$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Machine Model (SPM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda)$$

$$\tau = \tfrac{3}{2}p\lambda\, i_q = K_t\, i_q$$

### 1.3 Decoupled PI Control with Pole-Zero Cancellation

The PI controller is $C(s) = K_p + K_i/s$. Choosing

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

cancels the electrical pole at R/L. The closed-loop current response then becomes first order:

$$\frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$
