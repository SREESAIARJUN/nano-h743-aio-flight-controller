# STM32H743 Nano FC with 4-in-1 80 A ESC: Systems Architecture Package (Job #14)

## 0. Scope, Assumptions, and Red Flags

I don't have any prior Job #14 documents, so this package is self-contained. Every number derives from the parameter table below. Swap in your actual BOM values and the equations still hold.

**Three architectural corrections up front:**

1. **The H743 does not run the ESC.** Its job is to generate DShot600 and capture the bidirectional eRPM telemetry. The 48 kHz complementary PWM and commutation run on four dedicated ESC MCUs (e.g., AT32F421 running AM32) or a single quad-capable MCU. Mixing the two roles on one H7 is not supported by ArduPilot.
2. **"80 A" must be defined as phase or battery current.** Phase current is I_ph = I_batt / D. An "80 A ESC" conventionally means 80 A phase, and this package assumes that.
3. **80 A continuous is physically impossible in a nano (20×20 / 30.5×30.5 mm) footprint.** The model below shows roughly 85 W of dissipation at full burst. The design target is therefore an **80 A burst for ≤ 2 s per channel with a duty cycle ≤ 25%**, with roughly 35–40 A continuous.

## 1. Conduction Loss Model

### 1.1 Topology Reasoning

The motor uses six-step (trapezoidal) commutation with synchronous rectification. At any instant, exactly two phases carry current: phase A is PWM'd (HS on during D, LS on during 1−D) and phase B has its LS held on.

The current path is therefore always one A-leg FET in series with B_LS, independent of D:

$$P_{cond,ch} = I_{ph}^2 \cdot 2R_{ds(on)}(T_j) + I_{ph}^2 R_{Cu}$$

### 1.2 Temperature Dependence

$$R_{ds(on)}(T_j) = R_{ds(on),25}\left[1 + k_T (T_j - 25)\right], \quad k_T \approx 0.005\ \text{/K}$$

At 125 °C, the multiplier is 1.5, giving R_ds(on) = 1.5 mΩ.

### 1.3 Copper Path

For copper, R_Cu = ρL/(wt) with ρ = 1.72×10⁻⁸ Ω·m and +0.393 %/K.

- Assume a 12 mm phase pour, 4 mm wide, 3 oz (105 µm), paralleled across 2 layers.
- That gives R_Cu ≈ 0.25 mΩ per segment.
- The current path crosses about 2 segments, so R_Cu ≈ 0.5 mΩ, rising to 0.6 mΩ hot.

### 1.4 Result at 80 A Burst

$$P_{FET,cond} = 80^2 \times 2 \times 1.5\,\text{m}\Omega = 19.2\ \text{W}$$
$$P_{Cu} = 80^2 \times 0.6\,\text{m}\Omega = 3.8\ \text{W}$$

**Per channel: ≈ 23 W. All four channels: ≈ 92 W.**

**Per-FET distribution.** Each leg conducts 240° of 360° electrical: 120° as the PWM leg and 120° as the sink leg. Averaged over many electrical cycles, each of the 6 FETs dissipates about 19.2/6 ≈ 3.2 W.

However, the die thermal time constant is about 1–5 ms. At low eRPM, the electrical period exceeds this, so the die sees **peak** loss. Size for the peak:

$$P_{peak,FET} \approx I^2 R = 9.6\ \text{W (LS sink leg, worst case)}$$

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. Hard switching occurs on the HS turn-on, and the LS body diode carries current during dead time.

| Term | Equation | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw | ½·25.2·80·20 ns·48k = **0.97 W** |
| Reverse recovery | Q_rr·V·f_sw | 50 nC·25.2·48k = **0.06 W** |
| Output capacitance | ½·Q_oss·V·f_sw (lost in HS) | **0.024 W** |
| Dead-time diode | V_F·I·2t_dead·f_sw | 0.8·80·400 ns·48k = **1.23 W** |
| Gate drive (×2 FETs) | 2·Q_g·V_GS·f_sw | 2·50 nC·10·48k = **0.048 W** (lands in the driver) |
| **Total, per channel** | | **≈ 2.3 W** |

**Key insight:** the dead-time loss exceeds the overlap loss. Cutting t_dead from 200 ns to 100 ns saves about 0.6 W per channel. Validate this against shoot-through margin using the gate driver's propagation mismatch.

### Total Burst Budget

| | Per channel | ×4 |
|---|---|---|
| Conduction (FET) | 19.2 W | 76.8 W |
| Copper | 3.8 W | 15.2 W |
| Switching | 2.3 W | 9.2 W |
| **Total** | **25.3 W** | **≈ 101 W** |

Overall efficiency at full burst is about 1 − 101/(4·80·25.2·D). At D = 0.8 that works out to about 98.4% electrically, which still means a 100 W heat problem.

### 3.3 Convection

$$R_{BA} = \frac{1}{h A}$$

- A = 2 × 9.3 cm² = 18.6 cm².
- In propwash, h ≈ 80 W/m²K, so R_BA ≈ 6.7 K/W.
- In still air, h ≈ 10 W/m²K, so R_BA ≈ 54 K/W. **This drives the ground-idle derate.**
