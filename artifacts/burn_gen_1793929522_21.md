# STM32H743 + 4-in-1 ESC Nano Stack (Job #19): Engineering Model

## 0. Architecture Assumptions and Feasibility Issues

**Assumptions** (replace with real datasheet values before layout freeze):

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max, 22.2 V nominal |
| Burst current | 80 A per motor, phase/motor current |
| Switching frequency | 48 kHz, complementary (synchronous) 6-step PWM |
| MOSFET (generic 40 V, 3.3×3.3 PQFN) | R_ds(on),25 = 1.0 mΩ @ 10 V; α = 0.005 /K; t_r + t_f ≈ 40 ns; Q_g ≈ 60 nC; Q_rr ≈ 50 nC; R_θJC ≈ 1.2 K/W |
| Dead time | 200 ns per edge |
| Board | 20×20 mm, 6-layer, 2 oz copper |

**Architecture.** The H743 does not switch the FETs. Each motor channel has its own ESC MCU (for example AT32F421 or STM32G071 running AM32/BLHeli_32), which generates the 48 kHz PWM. The H743 sends bidirectional DShot600 to those four MCUs and receives eRPM telemetry back.

**Feasibility issues.** The math below shows these problems; resolve them before committing to the spec.

1. **No steady state at 80 A.** The design is thermally unstable at continuous 80 A per motor (see §2.4). 80 A is a burst rating only, about 1–2 s with all four motors loaded.
2. **"80 A" needs a precise definition.** If it means 80 A on all four motors simultaneously, the motor-side current is 320 A. Battery current is lower, I_bat ≈ D·I_phase, but the bus, connector and shunt design still have to survive it.
3. **Form factor.** A 20×20 board at these loads is marginal. Plan for 30.5×30.5 mm or a mandatory heatsink path.

## 1. Loss Model (per ESC channel)

### 1.1 Conduction Losses

With synchronous rectification in 6-step commutation, current always flows through exactly two FET positions:
- one high-side FET, conducting for duty D, with its complementary low-side FET for (1−D);
- one low-side FET, fully on.

So the channel always has two R_ds(on) in series:

$$P_{cond} = 2\,I^2\,R_{ds}(T_j), \qquad R_{ds}(T_j) = R_{25}\left[1+\alpha\,(T_j-25)\right]$$

Because R_ds depends on T_j, solve self-consistently:

$$T_j^{(n+1)} = T_{ref} + P_{tot}\!\left(T_j^{(n)}\right)\cdot Z_{th}(t)$$

At T_j = 100 °C, R_ds = 1.0 × (1 + 0.005×75) = **1.375 mΩ**. Rounding up to 1.45 mΩ covers PCB via and solder resistance:

$$P_{cond} = 2 \times 80^2 \times 1.45\times10^{-3} = \mathbf{18.6\ W}$$

### 1.2 Switching Losses at 48 kHz

Only one leg is hard-switched per PWM period (the high side of the PWM'd phase).

**Turn-on and turn-off (V–I overlap):**
$$P_{sw} = \tfrac12 V I (t_r+t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 40\text{ns} \times 48\text{k} = \mathbf{1.94\ W}$$
