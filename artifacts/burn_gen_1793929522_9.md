# STM32H743 Nano FC + 80 A 4-in-1 ESC: Power-Stage and DShot Design Model

## 0. Architecture Clarification and Design Basis

**Partitioning.** The STM32H743 runs ArduPilot on the flight controller. It does not commutate the motors. Each motor phase bridge is driven by the ESC's own MCU, typically an AT32F421 or STM32G071 running AM32 or BLHeli_32. The H743's role is to generate bidirectional DShot600 and to capture the eRPM telemetry that comes back. The analysis is split accordingly:

| Domain | Owner | Scope in this document |
|---|---|---|
| Power stage (FETs, drivers, caps, thermal) | ESC MCU + hardware | §1–§4 |
| DShot generation and telemetry capture | STM32H743 / ArduPilot | §5 |
| Interconnect | Both | §6 netlists |

**Assumed parameters.** These are representative values. Replace them with datasheet values for your chosen parts before signing off.

| Parameter | Symbol | Value |
|---|---|---|
| Battery | V_bus | 6S, 25.2 V max (22.2 V nominal) |
| Burst current per motor | I_ph | 80 A peak phase current, 10 s burst rating target |
| PWM frequency | f_sw | 48 kHz, complementary (synchronous) |
| MOSFET (6 per motor, 24 total) | — | 40 V N-ch, PQFN 3.3×3.3 or 5×6 class |
| R_DS(on) @ 25 °C, V_GS = 10 V | R₂₅ | 0.70 mΩ |
| R_DS(on) temp coefficient | α | ≈ 0.0065 /K |
| Gate charge total / switching (Q_gs2 + Q_gd) | Q_g / Q_sw | 60 nC / 15 nC |
| Output charge / reverse recovery | Q_oss / Q_rr | 50 nC / 40 nC |
| Body diode forward voltage | V_F | 0.8 V |
| Gate driver supply / Miller plateau | V_drv / V_pl | 10 V / 4.5 V |
| Gate resistance external + internal | R_g,ext + R_g,int | 5 Ω + 1 Ω |
| Dead time | t_d | 100 ns |
| Board size | — | 30.5 × 30.5 mm, 8-layer, 2 oz on all layers |

> **Reality check:** 80 A per motor on a "nano" footprint is a burst rating that is limited by thermal mass, not a continuous rating. The math below shows why. Treat 80 A as a ≤5–10 s rating that depends on airflow.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At the design-limit junction temperature T_j = 125 °C:

$$R_{DS}(125) = 0.70 \times (1 + 0.0065 \times 100) = 1.155\ \text{mΩ}$$

### 1.2 Current paths in trapezoidal 6-step commutation

At any instant two phases conduct. With complementary PWM on the high side and the opposite low-side FET held on:

| FET | Conduction fraction | Current |
|---|---|---|
| HS of PWM phase | D | I_ph |
| LS of PWM phase (synchronous rectifier) | (1 − D) | I_ph |
| LS of return phase | 1 (whole 60° sector) | I_ph |

Each FET is active for 1/3 of the electrical cycle. Summed per motor, conduction is always "two FETs' worth":

$$P_{cond,motor} = I_{ph}^2 R_{DS}(T_j)\,[D + (1-D) + 1] = 2\,I_{ph}^2 R_{DS}(T_j)$$

Note that this is independent of D when synchronous rectification is used.

### 1.3 Numbers at 80 A

$$P_{cond,motor} = 2 \times 80^2 \times 1.155\times10^{-3} = 14.8\ \text{W}$$

$$P_{cond,board} = 4 \times 14.8 = 59.1\ \text{W}$$

**Per-FET averages** (each FET carries 1/3 of the cycle-averaged losses):

$$P_{FET,avg} = 14.8 / 6 \approx 2.5\ \text{W}$$

The instantaneous FET dissipation during its sector is I²R = 7.4 W.

### 1.4 Copper and shunt losses (often forgotten)

Phase and bus copper: assume 0.3 mΩ effective per motor current loop.

$$P_{Cu} = 80^2 \times 0.3\text{m} \approx 1.9\ \text{W/motor}$$

If you use a shunt of 0.25 mΩ on the bus with total current I_bus:

- At a full 4 × 80 A load: 320² × 0.25 m = 25.6 W, which is unacceptable.
- **Use a Hall sensor or a 0.1 mΩ shunt.** At 320 A, 0.1 mΩ still gives 10 W. A Hall sensor such as the ACS772/TMCS1100 class is strongly preferred at this current.

## 2. Switching Loss Model at 48 kHz

### 2.1 Transition times from the gate-drive model

Turn-on gate current during the Miller plateau:

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_{g,ext}+R_{g,int}} = \frac{10 - 4.5}{6} = 0.92\ \text{A}$$

Turn-off gate current:

$$I_{g,off} = \frac{V_{pl}}{R_{g}} = \frac{4.5}{6} = 0.75\ \text{A}$$

The driver's peak capability also limits these values. The FD6288Q class sources about 1.5 A and sinks about 1.8 A, so the resistor sets the current here.

Resulting transition times:

$$t_r = Q_{sw}/I_{g,on} = 15\text{n}/0.92 = 16.3\ \text{ns}$$

$$t_f = Q_{sw}/I_{g,off} = 15\text{n}/0.75 = 20\ \text{ns}$$

### 2.2 Loss components (per motor; only the PWM-phase HS hard-switches)

| Term | Formula | Value @ 25.2 V, 80 A, 48 kHz |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f | ½·25.2·80·36.3n·48k = **1.76 W** |
| Coss | Q_oss·V·f (½ in HS + ½ charging LS) | 50n·25.2·48k = **0.06 W** |
| Reverse recovery | Q_rr·V·f | 40n·25.2·48k = **0.05 W** |
| Dead-time diode | 2·V_F·I·t_d·f | 2·0.8·80·100n·48k = **0.61 W** |
| Gate drive (6 FETs, 1/3 active) | 2·Q_g·V_drv·f | 2·60n·10·48k = **0.06 W** (mostly in R_g and driver) |
| **Total** | | **≈ 2.54 W/motor** |

### 2.3 Duty-cycle dependence (important)

At D = 1 (100 % throttle) there is no switching, so P_sw → 0. The realistic worst case is high current at D ≈ 0.85–0.95, which occurs in punch-outs before RPM catches up.

$$P_{total,motor}(D) = 2I^2R_{DS}(T_j) + \mathbb{1}[D<1]\cdot P_{sw} + P_{Cu}$$

Worst case per motor: 14.8 + 2.54 + 1.9 ≈ **19.2 W**.
