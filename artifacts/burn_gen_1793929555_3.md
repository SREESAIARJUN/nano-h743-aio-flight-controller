# STM32H743 AIO Nano Flight Controller with Integrated 4-in-1 ESC: Design Package (Job #36)

## 0. Architectural Ground Rules and Feasibility Check

**Assumptions** (change any of these and re-run the equations; every result below is parametric):

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal |
| Rating | **80 A burst per channel, phase current**, ≤ 2 s |
| Rating | 40 A continuous per channel (airflow-dependent) |
| Board | 30.5×30.5 mm (M3) or 20×20 mm (M2) "nano" form factor, 8-layer, 2 oz copper on all layers |
| Commutation | 6-step trapezoidal with synchronous rectification (AM32/BLHeli_32 style) |
| PWM frequency | f_sw = 48 kHz |

**Topology correction.** The STM32H743 does not drive the MOSFET bridges. It runs ArduPilot and sends bidirectional DShot600 to four dedicated ESC MCUs (AT32F421 or STM32G071 running AM32). Each ESC MCU drives a 3-phase gate driver. The math below covers both layers.

**Feasibility warning.** As the numbers below show, 80 A per channel on a nano-class board is a **thermal-capacity-limited burst rating**, not a steady-state one. The board reaches its limit in about 2 s at full simultaneous burst. Treat "80 A" as a marketing-honest burst spec only if you publish the duration.
