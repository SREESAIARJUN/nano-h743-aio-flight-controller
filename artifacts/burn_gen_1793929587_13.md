# STM32H743 FC + 4-in-1 ESC, 80 A Burst: Design Model (Job #78)

## 0. Architectural Corrections

Three requirements, as stated, conflict with physics or standard practice. The model below rests on these corrected assumptions.

| Issue | Problem | Resolution used below |
|---|---|---|
| **"Nano" + 80 A + H743** | 12 power MOSFETs in 5×6 mm packages take about 360 mm², which is roughly the whole 20×20 mm board. A single-board nano cannot also host the H743 and gyro. | **Stacked design:** a 20×20 H743 FC on top and a 4-in-1 ESC below, 25.5×25.5 mm minimum. The ESC uses 3.3×3.3 mm PQFN FETs, double-sided. |
| **H743 running the ESC** | The H743 sends DShot. Each ESC channel needs its own commutation MCU running AM32 or BLHeli_32. Bidirectional DShot only makes sense with separate ESC MCUs. | 4× STM32G071 (or AT32F421) running AM32, with the 48 kHz PWM set in AM32. |
| **80 A** | 80 A continuous per channel is thermally impossible at this size (see §3). | Treated as a **per-channel burst**. The model computes the allowable burst duration. |

Electrical assumptions: 6S pack (V_bus = 25.2 V max), T_amb = 40 °C, T_j,max = 150 °C with a derated design target of 135 °C. Reference FET: 40 V, R_DS(on),25 = 1.0 mΩ, Q_g = 45 nC, Q_rr = 40 nC, Q_oss = 50 nC, R_θJC = 1.2 K/W, PQFN 3.3×3.3. This is representative of the class. Substitute datasheet values for your chosen part.

## 1. Conduction Loss Model

### 1.1 Topology
AM32 drives trapezoidal 6-step commutation with complementary (synchronous-rectified) PWM. At any instant, exactly **two FETs carry phase current**:
- In the PWM leg, either the high-side (during the duty D) or the low-side (during 1−D) conducts.
- In the static low leg, the low-side FET conducts continuously.

### 1.2 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{25}\left[1+\alpha\,(T_j-25)\right],\qquad \alpha \approx 0.0055\ \text{K}^{-1}$$

At T_j = 125 °C: R = 1.0 × 1.55 = **1.55 mΩ**.

Add the parasitic path (solder, vias, 2 oz copper) per FET: R_par ≈ 0.25 mΩ. So **R_eff = 1.80 mΩ**.

### 1.3 RMS current including PWM ripple

Peak-to-peak phase ripple:

$$\Delta I = \frac{(V_{bus}-V_{bemf})\,D}{2L_{ph} f_{sw}}$$

For L_ph = 10 µH (typical 2207 motor, line-to-line 20 µH), D = 0.5, V_bemf ≈ 12 V:

ΔI = (13.2 × 0.5)/(2 × 10e-6 × 48e3) = **6.9 A pp**

$$I_{rms}=\sqrt{I^2+\tfrac{\Delta I^2}{12}} = \sqrt{6400+3.97}=80.02\ \text{A}$$

The ripple is negligible at 48 kHz. This is one benefit of 48 kHz over 24 kHz, where ΔI doubles.

### 1.4 Conduction loss per channel

$$P_{cond}=2\,I_{rms}^2\,R_{eff}=2(80)^2(1.80\times10^{-3}) = \mathbf{23.0\ W}$$

Hottest single FET (the static low-side, conducting 100% of the 60° interval):
P = 6400 × 1.80e-3 = **11.5 W** (instantaneous, during its conduction interval).

## 2. Switching Loss Model (f_sw = 48 kHz)

Only the PWM leg switches. Each loss term is listed below.

### 2.1 V–I overlap (hard switching)

Gate drive conditions: R_g,ext = 4.7 Ω, driver ~1 A source / 1.5 A sink, plateau ~3 V. This gives t_r ≈ 18 ns and t_f ≈ 14 ns.

$$P_{VI}=\tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5(25.2)(80)(32\text{e-}9)(48\text{e3}) = \mathbf{1.55\ W}$$

### 2.2 Dead-time body-diode conduction

AM32 dead time is about 300 ns at 48 kHz on G071 (DEAD_TIME parameter). Use t_dt = 300 ns and V_F = 0.8 V:

$$P_{dt}=V_F\,I\,(2t_{dt})\,f_{sw}=0.8(80)(600\text{e-}9)(48\text{e3})=\mathbf{1.84\ W}$$

This is the largest switching term. Trim dead time to the minimum safe value (e.g., 150 ns) to halve it.

### 2.3 Reverse recovery

$$P_{rr}=Q_{rr}V_{bus}f_{sw}=40\text{e-}9(25.2)(48\text{e3})=\mathbf{0.05\ W}$$

### 2.4 Output capacitance

$$P_{oss}=Q_{oss}V_{bus}f_{sw}=50\text{e-}9(25.2)(48\text{e3})=\mathbf{0.06\ W}$$

### 2.5 Gate charge

$$P_g=2Q_gV_{GS}f_{sw}=2(45\text{e-}9)(10)(48\text{e3})=\mathbf{0.043\ W}$$

Most of this is dissipated in the driver and R_g, not the FET.

### 2.6 Per-channel total at 80 A

| Term | W |
|---|---|
| Conduction | 23.0 |
| V–I switching | 1.55 |
| Dead-time diode | 1.84 |
| Q_rr + Q_oss + Q_g | 0.15 |
| **Total / channel** | **26.5
