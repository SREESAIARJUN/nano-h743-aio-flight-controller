# Job #62: STM32H743 Nano FC + 4-in-1 ESC (80 A Burst)
**System Architecture, Loss Model, DMA Allocation, Netlist and Thermal Budget**

## 0. Architecture Decisions and Feasibility Flags

These issues affect everything downstream, so they come first.

| # | Issue | Decision |
|---|---|---|
| F1 | The STM32H743 should not commutate the motors directly. ArduPilot has no 6-step or FOC motor driver, and bi-directional DShot assumes a separate ESC MCU. | Use a **stacked or integrated AIO**: the H743 runs ArduPilot, and **4× AT32F421 (or STM32G071)** run AM32 at 48 kHz PWM. The H743 talks to them over bidirectional DShot600. |
| F2 | "Nano" (20×20 mm, M2) cannot physically fit 24 power MOSFETs rated for 80 A, plus bulk capacitance. | The minimum credible size is a **30.5×30.5 mm** pattern with 3.3×3.3 mm or 5×6 mm dual-cool packages. Section 3 shows the thermal consequence. |
| F3 | "80 A" must be specified as **per-motor phase current, burst ≤ ~3 s, with airflow**. | Every number below uses that definition. |

**Component parameters are assumptions.** Values marked [A] come from a representative 40 V / ~0.9 mΩ class device. Replace them with your selected part's datasheet values before release.

## 1. Conduction Loss Model (Per ESC, 80 A Burst)

### 1.1 Operating Assumptions

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Phase current (burst) | I_ph | 80 A |
| R_DS(on) at 25 °C [A] | R₂₅ | 0.90 mΩ |
| R_DS(on) temperature coefficient [A] | α | 0.0045 /K |
| Design junction temperature | T_j | 125 °C |
| PCB copper resistance per phase path | R_cu | 0.30 mΩ |

### 1.2 Temperature-Corrected R_DS(on)

$$R_{DS}(T_j)=R_{25}\,[1+\alpha(T_j-25)] = 0.90\times1.45 = 1.31\ \text{m}\Omega$$

### 1.3 Conduction Paths in Trapezoidal Commutation

The ESC uses 6-step trapezoidal drive with complementary (synchronous) PWM. At any instant, current flows through exactly **two** MOSFET channels:

- During PWM on-time: the high-side FET of phase A and the low-side FET of phase B.
- During PWM off-time: the low-side FET of phase A (synchronous rectification) and the low-side FET of phase B.

The two-FET resistance is therefore independent of duty cycle D:

$$P_{cond}=I_{ph}^2\cdot 2R_{DS}(T_j)=6400\times2.62\text{ m}\Omega = \mathbf{16.8\ W}$$

### 1.4 Copper Loss

Current passes through two phase paths:

$$P_{cu}=I_{ph}^2\cdot 2R_{cu}=6400\times0.6\text{ m}\Omega=\mathbf{3.84\ W}$$

### 1.5 Per-FET Distribution

Each phase leg conducts for 120° of every 360° electrical period, so the average load is roughly 16.8 W / 6 ≈ **2.8 W per FET**.

The peak instantaneous dissipation in one FET is I²R = **8.4 W**. This peak sets the Z_th(jc) transient requirement.

## 2. Switching Loss Model at f_sw = 48 kHz

Only the PWM leg hard-switches. There is one turn-on and one turn-off per PWM period.

### 2.1 Gate Drive Assumptions

| Parameter | Value |
|---|---|
| Gate drive voltage, V_drv | 10 V |
| Miller plateau voltage, V_pl [A] | 3.0 V |
| Total gate resistance, R_g (external 5 Ω + internal 1 Ω) | 6 Ω |
| Switching charge, Q_sw = Q_gs2 + Q_gd [A] | 15 nC |

### 2.2 Transition Times

Turn-on:

$$I_{g,on}=\frac{V_{drv}-V_{pl}}{R_g}=1.17\text{ A}\quad\Rightarrow\quad t_r=\frac{Q_{sw}}{I_{g,on}}=12.8\text{ ns}$$

Turn-off:

$$I_{g,off}=\frac{V_{pl}}{R_g}=0.50\text{ A}\quad\Rightarrow\quad t_f=30\text{ ns}$$

### 2.3 Loss Terms

| Term | Expression | Value |
|---|---|---|
| V–I overlap | ½·V_bus·I·(t_r + t_f)·f = ½·25.2·80·42.8 ns·48 kHz | **2.07 W** |
| Dead-time body diode (2 × 100 ns, V_f = 0.8 V) | V_f·I·2t_dt·f | **0.61 W** |
| Reverse recovery (Q_rr = 50 nC [A]) | V_bus·Q_rr·f | 0.06 W |
| Output capacitance (Q_oss = 60 nC [A]) | ½·Q_oss·V_bus·f | 0.04 W |
| Gate charge (Q_g = 60 nC, 2 FETs; dissipated in driver) | 2·Q_g·V_drv·f | 0.06 W |
| **Total switching** | | **≈ 2.84 W** |

Switching loss scales linearly with frequency. Dropping to 24 kHz saves about 1.4 W per ESC but increases current ripple and audible noise.

### 2.4 Per-ESC and System Totals at 80 A

$$P_{ESC}=16.8+3.84+2.84\approx\mathbf{23.5\ W}$$

$$P_{4\times ESC}\approx\mathbf{94\ W}$$

Adding the H743 (~0.5 W), regulators (~1.5 W) and shunts, the total is **~96 W**.

## 3. Thermal Model

### 3.1 Junction-to-Board Thermal Path

Per FET:

| Element | Thermal resistance |
|---|---|
| R_θJC [A] | 1.2 K/W |
| Solder + thermal vias to inner planes | ~4–5 K/W |
| **Total R_θJB** | **~6 K/W** |

- Average-load rise: ΔT_JB ≈ 2.8 W × 6 ≈ **17 K**.
- Peak-load rise: at 8.4 W on a 1–5 ms commutation interval, use Z_th(jc). This is typically ~0.3 × R_θJC, giving **< 5 K extra**.
