**Architecture.** This is an all-in-one (AIO) board:
- The **STM32H743** runs ArduPilot as the flight controller.
- The ESC section uses **four independent ESC MCUs** running AM32. Bi-directional DShot is an FC-to-ESC protocol, so the H743 acts as the DShot *master*. It does not commutate the motors itself.

## 1. Conduction-Loss Model

### 1.1 Six-step trapezoidal commutation with synchronous rectification

During any commutation interval, two phases conduct:

- **Phase A, the PWM leg:**
  - High-side FET conducts for D·T.
  - Low-side FET conducts for (1−D)·T, as synchronous rectification.
- **Phase B, the return leg:** the low-side FET conducts 100 % of the time.
