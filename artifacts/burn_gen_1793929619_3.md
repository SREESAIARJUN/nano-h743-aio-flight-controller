## 0. Assumptions

I don't have the Job #18 specification, so the design below rests on the stated assumptions. Every parameter is a named constant, so the design stays valid if you substitute your actual values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, 3× advanced timers TIM1/TIM8/TIM20 → one per axis) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| IMU A | ICM-42688-P on the **camera plate** (feedback) |
| IMU B | ICM-42688-P on the **base/handle** (disturbance reference) |
| Axis order | Base → Yaw (Z) → Roll (X) → Pitch (Y) → camera |

**Loop rates and delay budget**

| Loop | Rate | Closed-loop bandwidth target |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| Velocity (gyro-based) | 4 kHz | ~150–250 Hz |
| Angle | 1 kHz | ~20–40 Hz |
| IMU sampling / filtering | 8 kHz ODR, filtered, decimated to 4 kHz | — |

Keep the bandwidth separation between nested loops at 5–10×.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi, \qquad \omega_e = p\,\omega_m$$

$\theta_{\text{off}}$ is found at commissioning by applying $v_d>0,\ v_q=0$ at $\theta_e=0$ (the rotor aligns to the d-axis) and recording the encoder reading.

### 1.2 Clarke transform (amplitude-invariant, with $i_a+i_b+i_c=0$)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM dq model and decoupled PI control

Model:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L \dot i_q + \omega_e (L i_d + \lambda_m)$$

Control law, with cross-coupling and back-EMF feedforward:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L\, i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L\, i_d + \hat\lambda_m)$$
