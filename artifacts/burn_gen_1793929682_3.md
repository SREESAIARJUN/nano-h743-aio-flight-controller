# STM32H743 AIO Flight Controller + 4-in-1 ESC: Systems Architecture Model (Job #43)

## 0. Scope and Assumptions

Some framing first, because it affects every number below.

1. **Architecture split.** The STM32H743 runs ArduPilot and generates bidirectional DShot600. It does not commutate motors. Each ESC channel has its own MCU running AM32 or BLHeli_32-class firmware, and that MCU generates the 48 kHz PWM. This is the standard AIO topology. Using the H743 for both jobs would leave no timer budget for DShot.
2. **"80 A burst" means per-channel phase current for ≤ 3 s.** On a nano (20×20 or 25.5×25.5 mm) board this rating is thermally limited by heat capacity, not by the silicon. Section 3 shows that continuous 80 A per channel is physically impossible at this size. Treat the burst rating as time-bounded, and enforce it in firmware.
3. **Baseline parameters.** Replace these with your BOM's datasheet values:

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, worst case) | V_bus | 25.2 V |
| MOSFET (40 V, PDFN 3.3×3.3 / 5×6) | R_ds,25 | 1.0 mΩ max @ V_gs = 10 V |
| R_ds tempco | α | 0.006 /K (≈1.5× at 110 °C) |
| Rise + fall time | t_r + t_f | 20 ns total (driver ~1.5 A) |

## 1. Conduction Loss Model

### 1.1 Six-step commutation with synchronous rectification

AM32 commutates in six steps. In each 120° electrical sector, one phase's high side is PWM'd, its low side is complementary (synchronous rectification), and a second phase's low side is held fully on.

Over one electrical revolution, each phase leg spends:
- **120° as the PWM phase:** the high side conducts for fraction D, and the low side conducts (sync rectifying) for fraction (1 − D).
- **120° as the return phase:** the low side conducts 100%.
- **120° floating:** no conduction (this phase is used for BEMF sensing).

With temperature-dependent resistance:

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

The per-FET average conduction losses are:

$$P_{cond,HS} = \frac{I^2 R_{ds}(T_j)\, D}{3}$$

$$P_{cond,LS} = \frac{I^2 R_{ds}(T_j)\,(1-D)}{3} + \frac{I^2 R_{ds}(T_j)}{3}$$

The per-channel total is:

$$P_{cond,ESC} = 3\left(P_{cond,HS} + P_{cond,LS}\right) = 2\, I^2 R_{ds}(T_j)$$

This is a useful sanity check: current is always flowing through exactly two FETs in series.

### 1.2 Numbers (T_j ≈ 108 °C, so R_ds ≈ 1.5 mΩ)

- I²R = 80² × 1.5 mΩ = **9.6 W** (instantaneous loss in one fully-on FET)
- P_cond,HS = 9.6 × 0.95 / 3 = **3.04 W**
- P_cond,LS = 9.6 × 0.05 / 3 + 9.6 / 3 = 0.16 + 3.20 = **3.36 W**
- **P_cond per ESC channel = 19.2 W**

### 1.3 Copper and shunt losses (often ignored, but they matter)

The phase RMS current in six-step is:

$$I_{rms,ph} = I\sqrt{2/3} = 65.3\ \text{A}$$

With about 0.3 mΩ of phase copper per leg (2 oz inner and outer layers, short pours):

$$P_{Cu} = 3 \times 65.3^2 \times 0.3\,\text{m}\Omega \approx 3.8\ \text{W per channel}$$

The common DC current shunt (0.25 mΩ, total battery current ≈ 4 × D × I ≈ 304 A in a worst-case all-motor burst) dissipates:

$$P_{shunt} \approx 304^2 \times 0.25\,\text{m}\Omega \approx 23\ \text{W}$$

**Recommendation:** use a 0.1 mΩ shunt, or a Hall sensor such as the Allegro ACS772/ACS37002. 23 W in one 2512 resistor is not survivable.

## 2. Switching Losses at 48 kHz

Only the high side hard-switches. It does so during the 1/3 of the electrical period when its phase is the PWM phase.

### 2.1 V–I overlap loss (high side)

$$E_{sw} = \tfrac12 V_{bus} I (t_r + t_f) = 0.5 \times 25.2 \times 80 \times 20\,\text{ns} = 20.2\ \mu\text{J}$$

$$P_{sw,HS} = E_{sw} f_{sw} \cdot \tfrac13 = 20.2\,\mu\text{J} \times 48\,\text{kHz} / 3 = \mathbf{0.32\ W}$$

### 2.2 Output capacitance loss (high side)

$$P_{oss} = \tfrac12 Q_{oss} V_{bus} f_{sw} / 3 = 0.5 \times 40\,\text{nC} \times 25.2 \times 48\,\text{k} / 3 \approx 8\ \text{mW}$$

### 2.3 Dead-time body-diode conduction (low side)

$$P_{dt} = V_f\, I\, (2 t_{dt}) f_{sw} / 3 = 0.8 \times 80 \times 200\,\text{ns} \times 48\,\text{k} / 3 = \mathbf{0.20\ W}$$

### 2.4 Reverse recovery (charged to the high side)

$$P_{rr} = Q_{rr} V_{bus} f_{sw} / 3 = 50\,\text{nC} \times 25.2 \times 48\,\text{k} / 3 \approx 20\ \text{mW}$$
