# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #54 spec, so this design rests on the typical gimbal hardware listed below. Every parameter sits in a config struct, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 (single-precision FPU, CORDIC optional) |
| Motors | 3× hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 2.5 mH, Kt ≈ 0.08 N·m/A |
| Rotor sensing | 14-bit absolute magnetic encoder per axis (MT6701 / AS5047P) |
| Current sensing | 2 or 3 low-side/inline shunts, ADC triggered at PWM center |
| IMUs | 2× ICM-42688-P on separate SPI buses, mounted on the camera plate, sharing CLKIN |
| Loop rates | Current 20 kHz, velocity 4 kHz, attitude/angle 1 kHz, IMU 8 kHz ODR |

## 1. Control Architecture

```
               ┌────────── 1 kHz ──────────┐ ┌──── 4 kHz ────┐ ┌──────── 20 kHz ────────┐
 q_ref ──►(+)─►│ Attitude P(I) + rate FF   │►│ Velocity PI   │►│ i_q PI ─► inv Park ─►  │► SVPWM ► Motor
           ▲   └───────────────────────────┘ │ +D(meas)      │ │ i_d PI     (θ_e)        │
           │                    ω_ref ──────►└───────▲───────┘ └──────▲─────────────────┘
           │                                         │   i_q,ff ──────┤ (cogging + inertia FF)
  Mahony attitude ◄── Dual-IMU fusion ◄── notch/LPF ◄┴── gyro (body rate projected on axis)
                         ▲                                  encoder θ_m ─► θ_e = p·θ_m − θ_off
             2× ICM-42688-P (AAF @ 536 Hz, 8 kHz ODR)
```

The loops nest from outside in:

- **Outer loop (attitude).** The quaternion error from the IMU attitude estimate is mapped through the gimbal Jacobian into per-joint rate commands.
- **Middle loop (velocity).** Each joint runs a PI controller on a blended rate signal: the gyro projected onto the joint axis, combined with the encoder differential rate.
- **Inner loop (current).** Standard FOC current control with i_d = 0.
