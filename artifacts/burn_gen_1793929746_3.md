## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

The electrical angle is computed from the mechanical angle and the calibrated electrical offset:

$$\theta_e = p\,\theta_m - \theta_{off}$$

**Clarke transform** (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI Design (Pole–Zero Cancellation)

The PMSM in the dq frame (surface-mount, $L_d = L_q = L$):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Apply the decoupling feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

With that feedforward, each axis reduces to $G(s) = 1/(Ls+R)$.

Choose the PI as

$$C(s) = K_p + K_i/s,\qquad K_p = L\,\omega_c,\quad K_i = R\,\omega_c$$

The open loop is then $\omega_c/s$, so the closed loop is first order with bandwidth $\omega_c$. Use $\omega_c \le 2\pi f_{pwm}/20$ (≈ 2π·1 kHz).

**Discrete form** (forward Euler on the integrator, with $T_s = 1/f_{pwm}$):

$$x_k = x_{k-1} + K_i T_s e_k,\qquad u_k = K_p e_k + x_k + v^{ff}$$

**Voltage limiting and anti-windup.** The voltage vector is limited to the linear SVPWM circle, $|v_{dq}| \le V_{bus}/\sqrt3$. The q-axis gets the voltage left over after the d-axis demand:

$$v_{q,max} = \sqrt{V_{max}^2 - v_d^2}$$

Integrators use conditional integration (clamping): integration freezes when the output is saturated and the error drives further into saturation.

### 1.3 SVPWM (Min–Max Zero-Sequence Injection)

Inverse Park, then inverse Clarke, gives $v_a, v_b, v_c$. Then:

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$
$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically identical to 7-segment SVPWM and gives a $2/\sqrt3$ voltage gain over sinusoidal PWM.

### 1.4 Speed and Angle Estimation: Encoder PLL Observer

Differentiating a quantized encoder signal is too noisy at 4 kHz. Use a type-II PLL instead.

$$\varepsilon_k = \operatorname{wrap}(\theta_{m,k} - \hat\theta_{k-1})$$
$$\hat\omega_k = \hat\omega_{k-1} + K_{i}^{pll}T_s\,\varepsilon_k$$
$$\hat\theta_k = \hat\theta_{k-1} + T_s(\hat\omega_k + K_p^{pll}\varepsilon_k)$$

With $K_p^{pll} = 2\zeta\omega_n$ and $K_i^{pll} = \omega_n^2$, the characteristic polynomial is $s^2 + 2\zeta\omega_n s + \omega_n^2$. Typical values are $\omega_n = 2\pi\cdot 300$ rad/s and $\zeta = 0.9$.
