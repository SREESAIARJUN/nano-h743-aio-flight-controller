# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #47 specification, so the design below rests on **stated assumptions**. Every hardware-dependent quantity is a named parameter, so you can substitute real values.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), one per joint |
| MCU | STM32G4 / H7 class, FPU, center-aligned PWM, ADC triggered at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, gyro ODR 8 kHz, ±2000 dps; accel ±16 g |
| Joint order | Yaw (base) → Roll → Pitch (camera) |

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | 20 kHz | PWM center ADC interrupt |
| Velocity (inertial rate) | 4 kHz | Every 5th current interrupt |
| IMU acquisition and filtering | 8 kHz | IMU DRDY / FIFO watermark |
| Attitude estimator and angle loop | 1 kHz | Every 4th velocity tick |

**Bandwidth separation rule.** Each outer loop is at least 4–5× slower than its inner loop:

ω_c,i ≈ 2π·1500 rad/s, ω_c,v ≈ 2π·150 rad/s, ω_c,θ ≈ 2π·30 rad/s.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

Electrical angle (θ_off is calibrated):

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a, \qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

Inverse Park is the transpose.

### 1.2 Plant (SPMSM, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q, \qquad v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

$$\tau = \tfrac32\, p\, \lambda_m\, i_q = K_t\, i_q$$
