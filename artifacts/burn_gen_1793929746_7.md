## 1. FOC Current Loop

### 1.1 Transforms

**Amplitude-invariant Clarke transform** (with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, using electrical angle θ_e = p·(θ_m − θ_off):

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant model (dq frame, SPMSM)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 1.3 PI design by pole-zero cancellation

First apply decoupling feedforward:

- v_d,ff = −ω_e L i_q
- v_q,ff = ω_e L i_d + ω_e λ_m

Each axis then reduces to the plant 1/(Ls + R). Choose the PI controller

$$C(s) = K_p + K_i/s$$

with gains

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c.$$

This gives the closed loop

$$\frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}.$$

**Choosing ω_c.** The loop contains a computation + ZOH delay of T_d ≈ 1.5 T_s. Keep ω_c·T_d ≤ 0.2 rad for at least 60° of phase margin:

$$\omega_c \le \frac{0.2}{1.5\,T_s}\;\Rightarrow\; f_c \lesssim 425\ \text{Hz at } 20\ \text{kHz}$$

For high-R gimbal motors, use f_c ≈ 300–400 Hz.
