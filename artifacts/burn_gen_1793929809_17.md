# STM32H743 AIO 4-in-1 ESC Flight Controller: Design Package (Job #5)

**Scope:** loss model at 80 A burst, 48 kHz switching analysis, ArduPilot bidirectional DShot600 timer and DMA allocation, schematic netlists, and thermal budget.

---

## 0. Architecture Decisions and Assumptions

### 0.1 Architecture: the H743 does not run the motors

ArduPilot has no support for driving 24 complementary gate signals with sensorless field-oriented control or 6-step commutation from the flight-control MCU. The only production-viable topology is an **AIO board**:

- **STM32H743** runs ArduPilot (attitude control and EKF).
- It sends bidirectional DShot600 commands to **4× AT32F421K8U7** ESC MCUs running AM32 firmware, all on the same PCB.
- Each AT32F421 drives one 3-phase bridge through a **FD6288Q** gate driver.

### 0.2 Form-factor flag

"Nano" usually means a 20×20 mm mounting pattern. 24 power MOSFETs rated for 80 A burst per channel **do not fit on 20×20**.

- This model assumes a **30.5×30.5 mm, 8-layer board** with three inner layers of 2 oz copper.
- If 20×20 is a hard requirement, derate to roughly 35 A burst per channel using 3×3 mm MOSFETs. The equations below still apply; only the parameters change.

## 1. Conduction Loss Model (80 A burst)

### 1.1 Current path in 6-step with synchronous rectification

In any 60° commutation sector, current flows through:
- phase X high side (duty D) **or** its low-side complement (duty 1−D, synchronous freewheel), and
- phase Y low side (on for 100% of the sector).

The phase-X leg contributes I²R_ds·D + I²R_ds·(1−D) = I²R_ds. The phase-Y low side contributes another I²R_ds. Therefore:

$$P_{cond,ch} = 2\,I^2\,R_{ds}(T_j) + I^2 R_{Cu}$$

$$R_{ds}(T_j) = R_{ds,25}\,\big[1+\alpha\,(T_j-25)\big]$$
