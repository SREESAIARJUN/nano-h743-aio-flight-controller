# STM32H743 AIO + 4-in-1 ESC (Job #6): Electro-Thermal Model, Switching Analysis, and Bi-Directional DShot600 Allocation

## 0. Architecture Decisions and Caveats

Three points shape everything that follows.

1. **Bi-directional DShot implies two processors.** DShot is a protocol between a flight controller and an ESC MCU. If the H743 drove the gate drivers directly, no DShot link would exist. This design therefore uses:
   - **FC side:** STM32H743VIT6 running ArduPilot.
   - **ESC side:** 4× AT32F421K8U7 (or STM32G071) running AM32. AM32 supports a 48 kHz PWM option.
   - **Gate drivers:** 4× Fortior FD6288Q 3-phase drivers.
2. **"Nano" form factor vs. 80 A.** The model below shows that 80 A per motor on a 20×20 mm board is a burst rating of roughly 1 second, not a continuous rating. The thermal section quantifies this rather than hiding it.
3. **Assumed parameters.** All MOSFET parameters are representative values for a 40 V, 3.3×3.3 mm DFN device. Substitute values from the selected part's datasheet before release. Every equation is written parametrically so the numbers can be re-run.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent Resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R_ds = 1.0 × (1 + 0.5) = **1.5 mΩ**.

### 1.2 Current Distribution in 6-Step Commutation with Synchronous Rectification

- In each 60° sector, one high-side FET or its complementary low-side FET carries the current on the PWM leg.
- A second low-side (or high-side) FET carries it continuously on the return leg.
- Because synchronous rectification is used, two FETs are always in the current path, independent of duty cycle D. (Dead time is handled separately below.)

Each FET conducts for 1/3 of the electrical period at the worst-case duty D → 1. The per-FET RMS current is:

$$I_{rms,FET} = I_{ph}\sqrt{1/3}$$

### 1.3 Per-FET and Per-Channel Conduction Loss

$$P_{cond,FET} = \frac{I_{ph}^2 R_{ds}(T_j)}{3}, \qquad P_{cond,ch} = 2\,I_{ph}^2 R_{ds}(T_j)$$

At 80 A and T_j = 125 °C:

- P_cond,FET = 6400 × 1.5 mΩ / 3 = **3.20 W**
- P_cond,ch = **19.2 W**
- Four channels: **76.8 W**

### 1.4 Copper Interconnect Loss

Assume 0.3 mΩ per channel for the bus and phase path, which is typical for 2 oz copper with short, wide pours:

$$P_{Cu,ch} = I_{ph}^2 R_{Cu} = 6400 \times 0.3\text{ m}\Omega = 1.92\text{ W}$$

### 1.5 Electro-Thermal Feedback and Runaway Criterion

Loss depends on junction temperature, which depends on loss:

$$T_j = T_{ref} + R_{\theta}\,P(T_j), \quad P(T_j)=P_0[1+\alpha(T_j-25)]$$

Solving gives the closed form:

$$T_j = \frac{T_{ref} + R_\theta P_0(1-25\alpha)}{1-\alpha R_\theta P_0}$$

The design is thermally stable only if:

$$\alpha\,R_\theta\,P_0 < 1$$

where P_0 is the conduction loss at 25 °C.

**Worked check (per FET):**

- P_0 = 6400 × 1.0 mΩ / 3 = 2.13 W
- Effective R_θ (junction to board node) ≈ 1.2 + 10 = 11.2 K/W
- αR_θP_0 = 0.005 × 11.2 × 2.13 = **0.12**

The loop is stable, but loss gain is 1/(1 − 0.12) ≈ 1.14×. The 25 °C loss is understated by about 14% before the board-temperature rise is even counted.
