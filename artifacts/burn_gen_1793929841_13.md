## 0. Architecture Clarification and Baseline Assumptions

The H743 does not commutate the motors. It is the flight controller running ArduPilot. It emits bidirectional DShot600 to four dedicated ESC MCUs, which run AM32 or BLHeli_32-class firmware. Each ESC MCU drives its own three-phase bridge.

```
6S LiPo ─┬─ Shunt ─ VBAT bus ─┬─ ESC1: MCU + 3× half-bridge driver + 6 FETs ─ Motor 1
         │                    ├─ ESC2 ...                                   ─ Motor 2
         │                    ├─ ESC3 ...                                   ─ Motor 3
         │                    └─ ESC4 ...                                   ─ Motor 4
         └─ Buck 5V/3.3V ─ STM32H743 (ArduPilot) ─ TIM1 CH1-4 ─ DShot600 BiDir ─ ESC MCUs
```
