# STM32H743 Nano FC + 4-in-1 ESC (Job #17): Design Model

**Scope:** loss model, thermal model, ArduPilot bi-directional DShot600 timer/DMA plan, and representative netlists.

## 0. Assumptions and Feasibility Finding

All numbers derive from the stated assumptions. Swap in your selected MOSFET's datasheet values and the equations carry through.

| Parameter | Value | Note |
|---|---|---|
| Bus voltage | 6S, 25.2 V max (worst case) | |
| Phase current, burst | 80 A per motor, 10 s | Interpreted as motor-phase current, the worst case |
| PWM frequency | 48 kHz, complementary (synchronous) 6-step | AM32/BLHeli_32 style |
| ESC MCU | 4 × AT32F421 (AM32), one per motor | The H743 runs ArduPilot only. It does not commutate motors. |
| MOSFET class | 40 V, R_DS(on),25 = 1.0 mΩ @ V_GS = 10 V, Q_g = 50 nC, Q_gd = 10 nC, Q_gs2 ≈ 5 nC, Q_rr ≈ 60 nC, V_SD = 0.8 V, R_g,int = 1 Ω, R_θJC ≈ 1 K/W (PDFN 5×6) | |
| Gate driver | FD6288Q, V_CC = 12 V, R_g,ext = 10 Ω | |
| Board | 30.5 × 30.5 mm, 8-layer (4 × 2 oz + 4 × 1 oz) | |
