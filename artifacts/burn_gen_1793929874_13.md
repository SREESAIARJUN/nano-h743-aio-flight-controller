# STM32H743 Flight Controller + 80A 4-in-1 ESC: Power, Thermal, and DShot Architecture (Job #54)

## 0. Scope and Assumptions

You did not specify the MOSFET part, driver, layer stack, or board size, so this model is fully parameterized. Every number below comes from a stated assumption. Replace the values marked **[A]** with datasheet values before release.

**Architectural correction.** The STM32H743 does not switch the motors. The 48 kHz switching is done by four ESC-side MCUs running AM32 or BLHeli_32. The H743 only generates bidirectional DShot600 and decodes eRPM telemetry. The work therefore splits into three domains:

| Domain | Silicon | Concern |
|---|---|---|
| Flight controller (FC) | STM32H743 @ 400 MHz | DShot timing, DMA, telemetry capture |
| ESC logic (×4) | AT32F421 / STM32G071 **[A]** | 48 kHz complementary PWM, commutation |
| ESC power (×4) | Gate driver + 6 (or 12) N-FETs | Conduction, switching, thermal |
