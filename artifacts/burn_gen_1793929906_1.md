# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

**Scope:** cascaded FOC (current, velocity, angle), anti-cogging feedforward, and dual ICM-42688-P vibration rejection with attitude fusion.

## 0. Assumptions

I don't have the Job #24 specification, so these are the baseline values the equations and code are built on. Every one of them is a named parameter in the code.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU, CORDIC optional) |
| Motor | Gimbal BLDC, 12N14P (e.g. GBM2804H-100T): `p = 7` pole pairs, `R ≈ 10 Ω`, `L ≈ 2.5 mH`, `Kt ≈ 0.08 N·m/A` |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI, read every PWM cycle |
| Current sensing | 2-shunt low-side, sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, symmetric about the camera's rotation center |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle and attitude 1 kHz |

The **angle loop** closes on the IMU-estimated camera attitude, since the camera is what must stay stable. The **velocity loop** closes on a blend of gyro rate (low latency, inertial) and encoder rate (low noise, no vibration). The **current loop** uses the encoder for commutation.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms

Electrical angle (with calibrated offset):

$$\theta_e = p\,\theta_m - \theta_{e,0}$$

Clarke transform, amplitude-invariant, with two shunts and $i_c = -i_a - i_b$:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant and decoupling

For an SPMSM with $L_d = L_q = L$:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The PI outputs $u_d, u_q$ are combined with decoupling feedforward:

$$v_d = u_d - \hat\omega_e L i_q,\qquad v_q = u_q + \hat\omega_e L i_d + \hat\omega_e \lambda_m$$

### 2.3 PI tuning by pole-zero cancellation

Place the PI zero on the electrical pole $R/L$. This gives a first-order closed loop with bandwidth $\omega_c$:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c\quad\Rightarrow\quad \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Choose $\omega_c \le 2\pi f_{pwm}/20$. At 20 kHz this gives $\omega_c = 2\pi\cdot 1000$ rad/s.

Discrete form (forward Euler is adequate at $\omega_c T_s \approx 0.3$):

$$u[k] = K_p e[k] + I[k],\qquad I[k+1] = I[k] + K_i T_s e[k] + K_{aw}(u_{sat}-u)$$

### 2.4 Voltage limiting and SVPWM

Limit the vector to the linear SVPWM region, giving $i_d$ priority (gimbal motors rarely saturate):

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

Inverse Park gives $v_\alpha, v_\beta$, then inverse Clarke gives $v_a, v_b, v_c$. Apply min-max zero-sequence injection, which is equivalent to SVPWM:

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

The current measured at sample $k$ produces a PWM update applied at $k+1$, so there is 1.5 $T_s$ of transport delay. Compensate it with $\theta_e^{pwm} = \hat\theta_e + 1.5\,\hat\omega_e T_s$.
