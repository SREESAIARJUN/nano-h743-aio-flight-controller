## 1. Loop Architecture

```
            1 kHz                     4 kHz                      20 kHz
θ_ref ─►[Angle PI]─► ω_ref ─►(+)─►[Velocity PID]─► i_q* ─►(+)─►[Current PI d/q]─► SVPWM ─► Motor
         ▲          ω_ff ──┘  ▲                  i_cog ─┘  ▲
         │                    │                  (LUT+LMS) │ i_a,i_b (Clarke/Park)
   θ_cam (Mahony,         ω_cam (dual-IMU, notched)        │
    dual IMU fused)                                  θ_m (encoder)──► PLL ──► θ_e, ω_m
```

Two design decisions follow from this structure:

- **Outer loops close on the inertial camera attitude and rate** from the fused IMUs. That is what a stabilizer must hold.
- **The encoder is used for commutation, cogging compensation, and a PLL rate estimate.** The PLL rate is blended with the gyro below the vibration band.

**Bandwidth separation.** The design keeps each loop at least 4–5× slower than the loop inside it:

$$\omega_c^{cur}\approx 2\pi\cdot 1500,\quad \omega_c^{vel}\approx 2\pi\cdot 80,\quad \omega_c^{ang}\approx 2\pi\cdot 15\ \text{rad/s}$$

## 2. Field-Oriented Control Equations

### 2.1 Clarke transform (amplitude-invariant, $i_a+i_b+i_c=0$)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 2.2 Park transform, with $\theta_e = p\,\theta_m - \theta_{off}$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.3 Machine model in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 2.4 Current PI controllers (pole-zero cancellation)

The plant is $G(s)=1/(Ls+R)$. Choosing $K_p = L\,\omega_c$ and $K_i = R\,\omega_c$ cancels the electrical pole. The closed loop then becomes $\omega_c/(s+\omega_c)$.

Discretized at sample time $T_s$, with feed-forward decoupling:

$$v_{d}^* = K_p e_d + I_d - \hat\omega_e L i_q,\qquad v_q^* = K_p e_q + I_q + \hat\omega_e (L i_d + \lambda_m)$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}(v^{sat}-v^*)\quad\text{(back-calculation anti-windup)}$$

The voltage vector is limited to the linear SVPWM region: $|v|\le V_{bus}/\sqrt3$.

**Note on high-resistance gimbal motors.** These motors are often run in voltage mode, $v_q = R\,i_q^* + \omega_e\lambda_m$, when phase-current sensing is noisy. The code supports this with `useCurrentSensing=false`.
