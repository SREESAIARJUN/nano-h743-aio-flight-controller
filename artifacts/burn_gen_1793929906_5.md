# FOC Motor Control & Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #47 specification, so the design below states its assumptions explicitly in §0. Change the parameters in `GimbalConfig` and the gain-synthesis equations recompute everything. **Please send the actual motor, encoder, MCU and IMU-mounting details.** Some choices (pole count, IMU placement, PWM rate) change constants, not structure.

## 0. Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs *p* = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Current sensing | 2 low-side shunts per motor (inline also fine) |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) per axis, SPI |
| MCU | STM32G4 / H7 class, single-precision FPU |
| PWM / current loop | 20 kHz center-aligned; current loop at 20 kHz (ISR) |
| Velocity loop | 4 kHz (every 5th current ISR) |
| Angle loop | 1 kHz (every 4th velocity tick) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz, DRDY-synchronized |
| Kinematic order | Yaw → Roll → Pitch (base → camera) |

## 1. FOC current (torque) loop — innermost, 20 kHz

### 1.1 Transforms
Use the amplitude-invariant Clarke transform, with i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant
For a surface PMSM (L_d ≈ L_q = L):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The torque is τ = (3/2)·p·λ_m·i_q = K_t·i_q.

### 1.3 PI with decoupling (pole–zero cancellation)
Let the target closed-loop bandwidth be ω_c. For 20 kHz sampling, use about 2π·1.5 kHz, i.e. ≤ f_s/10 to leave margin for the 1.5-sample PWM/computation delay.

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The PI zero cancels the electrical pole R/L, which gives a closed loop of ω_c/(s + ω_c). Add feed-forward decoupling:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Set i_d* = 0. A gimbal motor never needs field weakening.
