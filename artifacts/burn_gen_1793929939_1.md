# Job #52: FOC Motor Control and Dual-IMU Sensor Fusion for the 3-Axis Gimbal

I don't have the Job #52 specification sheet, so this design starts from a stated baseline. Every assumption is collected in `GimbalConfig` so you can substitute your real values.

---

## 0. System Baseline and Loop Architecture

### 0.1 Hardware Assumptions

| Item | Assumption |
|---|---|
| Motors | Gimbal BLDC (GBM2804-class), 12N14P, so p = 7 pole pairs. R ≈ 5.6 Ω, L ≈ 1.8 mH, K_t ≈ 0.12 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis, read over SPI |
| Current sensing | Inline or low-side shunts, 2 phases, synchronized to PWM center |
| IMUs | 2× ICM-42688-P on the payload (camera) plate, rigidly mounted, both on SPI with FIFO disabled and DRDY interrupt |
| Kinematics | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |

### 0.2 Loop Rates

| Loop | Rate | Function |
|---|---|---|
| Current (FOC) | 20 kHz | Clarke/Park, PI on i_d and i_q, SVPWM, anti-cogging feedforward injection |
| IMU sampling and filtering | 8 kHz | ICM-42688-P ODR 8 kHz, on-chip AAF, adaptive notch, biquad notch, LPF |
| Rate (velocity) | 4 kHz |
