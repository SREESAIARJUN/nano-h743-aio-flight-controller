# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage Model, DShot DMA Plan, and Netlist

## 0. Architecture Corrections

Three points in the brief would cause failures if implemented literally. The rest of this document is built around the corrected architecture.

| Issue | Problem | Resolution |
|---|---|---|
| **H743 cannot be the ESC controller** | ArduPilot has no field-oriented or six-step motor-drive firmware. The H743 does not commutate MOSFETs. | Use an AIO board: the H743 runs ArduPilot. Four dedicated ESC MCUs (AT32F421 or STM32G071, running AM32) drive the gate drivers. The 48 kHz switching frequency is the AM32 PWM setting, not an H743 timer. |
| **80 A burst on a "nano" form factor** | 4 × 80 A = 320 A from the battery. That is beyond any XT60 (60 A continuous) and beyond the copper on a 20×20 or 30.5 mm board for anything but seconds. | Treat 80 A as a **per-channel, single-motor, time-limited** rating. Section 3 derives the allowed duration. |
| **"DShot600 via DMA" on the ESC side** | DShot is FC → ESC. The H743 generates DShot. The ESC MCU decodes it and returns eRPM telemetry. | DMA allocation in Section 4 is for the H743 only. |

Every component value below is a **design assumption to verify against your chosen datasheets**. Part numbers are candidates, not a validated BOM.

## 2. Electrical Loss Model (per ESC channel)

### 2.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At a design point of T_j = 110 °C: R = 1.2 × (1 + 0.0045 × 85) = **1.66 mΩ** (typ). Using the max value it is 2.07 mΩ.

### 2.2 Conduction loss with synchronous rectification

During each commutation sector, current flows through three conduction paths:

- High-side FET of the PWM leg, for duty fraction D.
- Low-side FET of the same leg (synchronous freewheel), for 1 − D.
- Low-side FET of the return leg, for 100 % of the time.

$$P_{cond} = I^2R_{ds}\,[D + (1-D) + 1] = 2\,I^2 R_{ds}(T_j)$$

With complementary PWM, conduction loss is **independent of duty**. This is an important simplification.

$$P_{cond} = 2 \times 80^2 \times 1.66\,\text{m}\Omega = \mathbf{21.2\ W}\quad(\text{26.5 W at max } R_{ds})$$

Copper loss: P_cu = I² · R_cu = 6400 × 0.4 mΩ = **2.6 W**

### 2.3 Switching losses at 48 kHz

Only one leg hard-switches per sector.

**Transition time.** t_r ≈ t_f ≈ Q_gd / I_g ≈ 8 nC / 0.55 A ≈ 15 ns.

**V–I overlap loss:**
$$P_{VI} = \tfrac{1}{2}V_{bus}I(t_r+t_f)f_{sw} = 0.5 \times 25.2 \times 80 \times 30\text{ ns} \times 48\text{ kHz} = \mathbf{1.45\ W}$$

**Output capacitance:**
$$P_{oss} = Q_{oss}V_{bus}f_{sw} = 40\text{ nC}\times25.2\times48\text{k} = 0.048\text{ W}$$
