# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #17 specification, so this design is built on the assumptions below. They are collected in one config struct so you can swap in your real parameters.

| Item | Assumed value |
|---|---|
| Motors | GBM2804-class gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.07 N·m/A |
| Rotor sensor | 14-bit magnetic encoder (AS5048A/MT6701) on each axis |
| MCU | STM32G4 / STM32H7 class with FPU, center-aligned PWM |
| Loop rates | Current/FOC 20 kHz · Velocity 4 kHz · Angle 1 kHz · Notch retune 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, 8 kHz ODR, SPI, mounted point-symmetric about the payload CoG (r₂ = −r₁) |

## 1. FOC Core (20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,\theta_m - \theta_{off} \pmod{2\pi}$$

θ_off is found at commissioning: inject a fixed d-axis voltage, then read θ_m.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park transform
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the rotating frame (SPMSM, L_d = L_q = L)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Here ω_e = p·ω_m and λ_m = K_t/(1.5p).

### 1.5 Current PI with decoupling and back-EMF feedforward
$$v_d^* = PI_d(i_d^*-i_d) - \omega_e L i_q$$
$$v_q^* = PI_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

Pole–zero cancellation gives a first-order closed loop with bandwidth ω_c:
$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{PWM}}{10}\;(\approx 2\pi\cdot 2\text{ kHz})$$

### 1.6 Voltage limiting and SVPWM
1. Limit the voltage vector circularly: |v| ≤ V_bus/√3. Clamp v_d first, then give v_q the remaining headroom.
2. Apply the inverse Park transform.
3. Use min/max zero-sequence injection (equivalent to SVPWM):

$$v_{0} = -\tfrac12\left(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\right),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

### 1.7 Anti-windup by back-calculation
For every PI stage:
$$I_{k+1} = I_k + T_s\left[K_i e_k + K_{aw}(u_{sat,k}-u_{k})\right],\qquad K_{aw}\approx K_i/K_p$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Mechanical plant
$$J\dot\omega_m = K_t i_q - B\omega_m - \tau_{cog}(\theta_m) - \tau_{dist}$$

### 2.2 Velocity estimation: encoder PLL (4 kHz)
Use a type-2 tracking loop instead of raw differentiation:

$$e_\theta = \mathrm{wrap}(\theta_{enc}-\hat\theta),\quad \hat\omega \mathrel{+}= T_s K_{i,pll}e_\theta,\quad \hat\theta \mathrel{+}= T_s(\hat\omega + K_{p,pll}e_\theta)$$

Tuning: K_p,pll = 2ζω_pll and K_i,pll = ω_pll², with ζ = 0.707 and ω_pll ≈ 2π·400 Hz.

### 2.3 Velocity loop (4 kHz)
For stabilization, the velocity feedback is the fused gyro rate projected onto the joint axis (Section 4), not the encoder rate. The encoder PLL rate is used only when the IMU is faulted or during commissioning.

$$i_q^* = \underbrace{K_{p,\omega}e_\omega + K_{i,\omega}\!\int e_\omega}_{\text{feedback}} + \underbrace{\frac{J\dot\omega^*}{K_t}}_{\text{inertia FF}} + \underbrace{\frac{\hat\tau_{cog}(\theta_m)}{K_t}}_{\text{anti-cog FF}} + \frac{B\omega^*}{K_t}$$

Pole placement, with the velocity bandwidth ω_v set about 5–10× below ω_c:
$$K_{p,\omega} = \frac{J\,\omega_v}{K_t},\qquad K_{i,\omega} = \frac{K_{p,\omega}\,\omega_v}{4}$$

A 2nd-order low-pass on e_ω, at about 3ω_v, suppresses gyro noise without significant phase loss at ω_v.
