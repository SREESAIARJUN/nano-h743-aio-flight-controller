# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the original specification for "Job #5," so this design rests on explicit assumptions (§0). Every parameter is a named constant, so you can substitute your real hardware values.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (Nₛ = 12 slots, p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) over SPI |
| Current sense | 2-shunt or inline, sampled at the PWM centre |
| MCU | Cortex-M4F/M7 (STM32G4/H7), single-precision FPU |
| IMU-P | ICM-42688-P on the **payload** (camera plate). Primary attitude and rate feedback. |
| IMU-F | ICM-42688-P on the **frame/handle**. Disturbance reference for feedforward and adaptive cancellation. |
| Gimbal order | Yaw (outer, frame) → Roll → Pitch (inner, payload) |

| Loop | Rate | Executes |
|---|---|---|
| Current (FOC) | 20 kHz | Clarke/Park, d/q PI, SVPWM |
| Velocity | 4 kHz | PI + cogging feedforward, iq command |
| IMU pipeline | 8 kHz | Read, AAF, notch, NLMS, fusion |
| Attitude/angle | 1 kHz | Mahony estimator, attitude P, inverse kinematics |

The second IMU is mounted on the frame rather than as a redundant payload unit. A frame IMU gives you a *correlated reference* of the vibration source. That enables adaptive cancellation and base-rate feedforward, which are much more powerful than the √2 noise averaging you would get from two co-located sensors.

## 1. Field-Oriented Control (Inner Loop)

**Electrical angle**

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, balanced currents)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Plant** (surface PMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

**Current PI with decoupling and back-EMF feedforward**

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e \lambda_m$$

**Gain selection by pole-zero cancellation.** Choose the PI zero to cancel the plant pole $R/L$. With target bandwidth $\omega_c$:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

Use $\omega_c \approx 2\pi \cdot 1.5\,\text{kHz}$, which is at most $f_{PWM}/10$.
