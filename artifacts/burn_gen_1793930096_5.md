## 0. Architecture Clarification and Stated Assumptions

**Architecture.** The STM32H743 does not drive the MOSFET gates. On every production AIO/stack, the 48 kHz complementary PWM comes from dedicated ESC MCUs running AM32 or BLHeli_32, typically AT32F421 or STM32G071, one per motor. The H743 runs ArduPilot and talks to them over bidirectional DShot600. The model below follows that split:

```
[STM32H743 / ArduPilot] --BDShot600 x4--> [4x ESC MCU (AM32)] --> [3-ph gate driver] --> [6x N-FET] --> Motor
```

## 1. Conduction Loss Model (Trapezoidal 6-Step, Synchronous Rectification)

### 1.1 Current path

AM32 uses complementary (synchronous) PWM on one leg. Another leg's low-side is held fully on. At every instant the phase current I flows through exactly **two** conducting channels:

- **PWM ON (duty D):** HS(A) → winding → LS(B)
- **PWM OFF (1−D):** LS(A) → winding → LS(B), after the dead time

So, independent of D:

$$P_{cond,ch} = 2\,I^2\,R_{DS}(T_j)$$

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha\,(T_j - 25)]$$

### 1.2 Distribution per FET

Each FET carries current one-third of the electrical cycle (120° conduction). Averaged over a cycle (valid for eRPM ≫ thermal time constant of the die):

$$P_{cond,FET} \approx \tfrac{1}{3}\,I^2 R_{DS}(T_j)$$
