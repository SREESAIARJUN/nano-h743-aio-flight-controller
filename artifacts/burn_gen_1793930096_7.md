## 0. Architecture Clarification

The STM32H743 should **not** commutate the motors directly. ArduPilot does not run ESC firmware, and the H7 cannot run 4× sensorless FOC/6-step loops alongside the flight stack. The correct partition is:

```
[STM32H743 – ArduPilot]  --4× bidirectional DShot600-->  [4× ESC MCU (AT32F421 / STM32G071) – AM32 or BLHeli_32]
                                                               │ 48 kHz complementary PWM
                                                         [3-phase gate driver] → [6× N-MOSFET] → motor
```

The "48 kHz switching" therefore lives in the ESC MCUs. The H743's job is DShot generation and eRPM telemetry capture.

### Feasibility Flag

As Section 3 shows, **4 × 80 A simultaneous on a 20×20 mm board is a ~1 s capability at best**, not a sustained rating. A 30.5×30.5 mm board is assumed below. Expect the "80 A" figure to be a single-motor or sub-second burst spec.

## 2. Electrical Loss Model (per ESC channel)

### 2.1 Conduction Losses (6-step, synchronous complementary PWM)

At any instant, two phases carry current. One leg PWMs high-side/low-side complementarily, and the return leg's low-side is held on.

For each leg, over one electrical cycle:

- **High-side:** P_HS = I²·R·(D/3)
- **Low-side:** P_LS = I²·R·((1−D)/3 + 1/3)
- **Leg total:** I²·R·(2/3)
- **Channel total:** P_cond = 2·I_rms²·R_DS(T_j)

**Ripple correction.** I_rms² = I² + ΔI²/12, where ΔI = V_bus·D(1−D)/(L·f_sw).

The worst case is at D = 0.5: ΔI = 25.2·0.25/(30 µ·48 k) = 4.38 A. This adds 1.6 A², which is negligible (0.025 %).

**Temperature dependence.** R_DS(T) = R₂₅·[1 + α(T−25)]. At 125 °C, R = 1.5 mΩ.

| | Value |
|---|---|
| P_cond (channel, T_j = 125 °C) | 2 · 6400 · 1.5 m = **19.2 W** |
| Hottest FET, low-side at low D | (2/3)·I²R = **6.4 W** |
| Each FET at full throttle (D ≈ 1) | 3.2 W |

### 2.2 Switching Losses at 48 kHz

Only the PWM-ing FET hard-switches. The complementary FET switches at roughly zero volts via its body diode.

| Mechanism | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw | ½·25.2·80·30 n·48 k = **1.45 W** |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw | 0.8·80·100 n·48 k = **0.31 W** |
| Reverse recovery | Q_rr·V·f_sw | 40 n·25.2·48 k = **0.05 W** |
| C_oss | ≈ ½·Q_oss·V·f_sw (×2 edges) | **0.04 W** |
| Gate drive (mostly in driver/R_g) | Q_g·V_GS·f_sw per FET | 0.024 W × 6 = **0.14 W** |

P_sw ≈ 1.85 W per channel.

### 2.3 Channel and Board Totals

| | Loss | Efficiency at 80 A × 25.2 V (≈2 kW) |
|---|---|---|
| Per channel | P_ch ≈ 19.2 + 1.85 + shunt (80²·0.25 mΩ = 1.6 W) + copper traces (~2 W) ≈ **25 W** | ≈ 98.8 % |
| 4 channels simultaneous | P_tot ≈ **100 W** | |

Note how the frequency choice plays out:

- **48 kHz costs about 1.8 W/channel versus about 0.9 W at 24 kHz.**
- At 80 A, conduction dominates by roughly 10×.
- 48 kHz is justified for low-inductance, low-ripple motor quietness, not for loss.
