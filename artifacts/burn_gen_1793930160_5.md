# STM32H743 AIO (FC + 4-in-1 ESC): Power-Stage, Thermal and Bidirectional DShot Reference Design

## 0. Scope and Assumptions

I have no access to project files for "Job #68," so this design is fully parametric. Each equation is followed by a worked example using the reference parts below. Substitute your actual BOM values to get final numbers.

**Architecture clarification.** The STM32H743 does not commutate the motors. It runs ArduPilot and sends bidirectional DShot600 to four ESC MCUs (for example AT32F421 or STM32G071 running AM32/BLHeli_32). Those MCUs generate the 48 kHz PWM that drives the gate drivers. The switching-loss model therefore applies to the ESC power stage. The DMA/timer model applies to the H743.

## 1. Conduction Loss Model

### 1.1 Six-step (trapezoidal) commutation with synchronous rectification

At any instant, one high-side FET and one low-side FET conduct per motor. Each FET carries current for 120° (1/3 of the electrical cycle). With complementary PWM at duty D on the high side, the conduction split is:

$$I_{RMS,HS} = I\sqrt{\tfrac{D}{3}}, \qquad I_{RMS,LS(PWM\ leg)} = I\sqrt{\tfrac{1-D}{3}}, \qquad I_{RMS,LS(static)} = I\sqrt{\tfrac{1}{3}}$$

### 1.2 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

### 1.3 Per-motor conduction loss

The total current path always passes through 2 × R_DS(T_j):

$$P_{cond,motor} = I^2 \cdot 2R_{DS}(T_j)$$

This equation is independent of D under synchronous rectification. Phase-current ripple adds a factor $(1 + \tfrac{1}{12}(\Delta I/I)^2)$, which is typically below 1% and is neglected here.

### 1.4 Worked example (80 A, T_j = 125 °C)

- R_DS(125) = 1.7 × 1.45 = 2.47 mΩ
- P_cond,motor = 80² × 2 × 2.47 mΩ = **31.6 W**
- Per FET (average over 6): **5.3 W**
- I_RMS per FET at D ≈ 1: 80/√3 = 46.2 A

**Board total (4 motors): 126 W of conduction loss alone.**

## 2. Switching Loss Model at 48 kHz

Only the PWM-ing half-bridge switches. In complementary mode, one hard-switching edge pair occurs per period.

### 2.1 Loss components (per motor)

| Mechanism | Equation | Value @ 80 A, 25.2 V |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw | ½·25.2·80·20 ns·48 k = **0.97 W** |
| Reverse recovery | Q_rr·V·f_sw | 30 nC·25.2·48 k = **0.036 W** |
| Output capacitance | ½·Q_oss·V·f_sw | **0.024 W** |
| Dead-time body-diode conduction | V_f·I·2t_d·f_sw | 0.8·80·400 ns·48 k = **1.23 W** |
| Gate drive (mostly dissipated in driver/R_g) | Q_g·V_GS·f_sw × 2 FETs | **0.04 W** |
| **Total** | | **≈ 2.3 W per motor** |

### 2.2 Design conclusions

1. **Dead-time loss exceeds the V-I overlap loss.** Reducing t_d from 200 ns to 80 ns (the AM32/BLHeli "dead time" setting, validated by scope) saves about 0.75 W per motor.
2. **Frequency scaling.** Switching loss scales linearly with f_sw. At 24 kHz it falls to about 1.15 W per motor, at the cost of higher current ripple and audible noise.
3. **Ratio to conduction.** At 80 A, switching loss is under 7% of conduction loss. **Thermal design is dominated by R_DS(on).** Improve R_DS(on) first, switching speed second.

### 2.3 Total burst dissipation

$$P_{total} = 4 \times (31.6 + 2.3) + P_{shunt} + P_{driver} \approx \mathbf{140\text{–}150\ W}$$

Shunt loss example: 0.25 mΩ × 80² = 1.6 W per shunt if per-motor shunts are used.

## 3. Thermal Model

### 3.1 Network (per FET, Foster/Cauer simplified)

```
P_FET ─► [Z_th,j-c] ─► case ─► [R_th,c-pcb (solder+vias)] ─► PCB node ─► [R_th,pcb-air (h·A)] ─► T_amb
                                                               │
                                                          C_th,pcb (dominant)
```

### 3.2 Board thermal capacitance (30.5 × 30.5 mm AIO)

Assume a 1.6 mm board stackup (6–8 layers, ~6 oz total copper).

| Element | Volume | c_v | C_th |
|---|---|---|---|
| FR-4 | 9.3 cm² × 0.16 cm = 1.49 cm³ | 1.9 J/cm³K | 2.8 J/K |
| Copper (6 × 35 µm equivalent) | 0.195 cm³ | 3.45 J/cm³K | 0.67 J/K |
| 24 FETs + components | — | — | ≈ 0.5 J/K |
| **Total** | | | **≈ 4.0 J/K** |

### 3.3 Burst transient

Prop-wash cooling is optimistic. Assume h ≈ 100 W/m²K and both sides, giving R_th,pcb-air ≈ 1/(100 × 1.86e-3) ≈ 5.4 K/W.

$$T_{pcb}(t) = T_{amb} + P R_{th}\left(1 - e^{-t/\tau}\right), \quad \tau = R_{th}C_{th} \approx 21\ \text{s}$$

The steady-state asymptote is P·R_th = 145 × 5.4 ≈ **783 K**. Steady-state 80 A is therefore physically impossible on this board. Only the transient regime matters:

$$\frac{dT}{dt}\Big|_{t\to0} \approx \frac{P}{C_{th}} = \frac{145}{4.0} \approx \mathbf{36\ K/s}$$

Starting at T_pcb = 40 °C, the board reaches 110 °C in about **1.9 s**.

Junction rise above the PCB per FET: 5.3 W × (Z_th,j-c ≈ 1.2 K/W + R_th,c-pcb ≈ 3 K/W) ≈ **+22 K**. Therefore T_j ≈ 132 °C at t ≈ 1.9 s, which is near the 150 °C limit with no margin for local hotspots.

### 3.4 Engineering verdict

- **Credible burst rating:** 80 A for ≤ 1 s (single event, all four motors simultaneously). For a 5 s burst, derate to about 45–50 A.
- **Continuous rating:** about 25–35 A per motor in a typical 5" airflow environment.
- **Check the spec.** If "80A" in the Job #68 spec means per motor, it implies about 2 kW per motor at 6S on a nano board. That is not achievable with 3.3×3.3 packages. Clarify whether 80 A is total or per motor.
- **Required firmware protections:**
  - ESC: temperature limit at about 110 °C with linear current foldback.
  - ArduPilot: `BATT_*` current limiting (`BATT_MAX_AMPS` / `MOT_BAT_CURR_MAX`) as a backstop.
