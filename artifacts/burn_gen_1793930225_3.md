# FOC Control Loop and Sensor Fusion for a 3-Axis Gimbal (Job #42)

## 0. Assumptions and Rate Plan

I don't have the Job #42 specification, so this design uses common gimbal hardware. Every parameter is a `constexpr` or config field, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 or similar (Cortex-M4F, 170 MHz, FPU, CORDIC optional) |
| Motor | Hollow-shaft gimbal BLDC, 12N14P (N_p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH (phase) |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| IMUs | 2 × ICM-42688-P on the camera plate, mirrored about the plate centroid |
| Bus | V_dc = 12–16 V |

**Loop rates:**

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | f_c = 20 kHz | Center-aligned PWM ISR |
| Rate (velocity) | f_v = 8 kHz | IMU data-ready, ODR = 8 kHz |
| Attitude (angle) | f_a = 1 kHz | — |
| Cogging LMS adaptation | 1 kHz | Background |
| Dynamic notch coefficient update | 500 Hz | — |

**Bandwidth separation** (each loop ≥ 5–10× slower than the one inside it):
- ω_ci = 2π·1500 rad/s (current)
- ω_v = 2π·120 rad/s (rate)
- ω_θ = 2π·15 rad/s (attitude)
