## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class), SPI |
| Current sense | 2 or 3 low-side shunts, ADC synchronous with PWM centre |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Kinematics | Yaw → Roll → Pitch (base to camera) |

### Rate Hierarchy

Each loop's bandwidth must stay well below the loop inside it, with a separation factor of at least 5.

```
20 kHz  ── ADC ISR: Clarke/Park, current PI (d,q), SVPWM            BW_i  ≈ 1.5–2 kHz
 8 kHz  ── IMU DRDY ISR: dual ICM read, calib, fusion, notch/LPF
 4 kHz  ── Rate loop: gyro (+encoder) velocity PI + cogging FF      BW_ω  ≈ 80–150 Hz
 1 kHz  ── Attitude: Mahony AHRS, quaternion error, angle P + FF     BW_θ  ≈ 10–25 Hz
```

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle θ_m:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

Here θ_{m,0} is found at commissioning by applying a d-axis voltage and reading the encoder.

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant (Surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
$$\tau = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 1.3 Current PI with Decoupling and Pole-Zero Cancellation

Choosing the PI zero to cancel the electrical pole (K_i/K_p = R/L) leaves a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R
