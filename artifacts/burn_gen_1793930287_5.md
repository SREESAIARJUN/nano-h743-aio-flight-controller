# STM32H743 AIO (FC + 4-in-1 ESC) – System Architecture Package

## 0. Scope, Assumptions, and Corrections

I don't have records from earlier jobs, so this package is self-contained. Every parameter that affects a result is stated explicitly. Substitute your selected part values into the equations, because the numbers below are only as good as these inputs.

### Corrections to the brief

1. **The STM32H743 does not drive the power stage.** ArduPilot runs on the H743 as the flight controller and emits DShot. Each of the 4 ESC channels needs its own commutation MCU running AM32 or BLHeli_32. This design uses an AT32F421 or STM32G071, one per motor. ArduPilot has no BLDC commutation firmware.
2. **"80 A burst" on a nano (20×20 mm) board is a time-limited rating, not a thermal operating point.** Section 3 shows it is sustainable for about 1–4 s depending on how many motors are loaded. That limit should be printed on the datasheet as an explicit duration.
3. **"80 A" is defined here as per-motor RMS phase current.** Battery current is lower by roughly the duty factor. Marketing ratings often blur this distinction, so the datasheet should state which one is meant.
