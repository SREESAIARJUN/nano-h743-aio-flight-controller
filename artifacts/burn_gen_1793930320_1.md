# 3-Axis Gimbal FOC Control & Dual-IMU Fusion: Design Specification

I don't have the Job #41 specification, so this design uses the assumptions below. Every value marked **[A]** is a parameter you should replace with measured values for your hardware.

| Item | Assumed value |
|---|---|

| Phase R / L (line-to-neutral) | 5.0 Ω / 1.5 mH **[A]** |
| Torque constant K_t | 0.08 N·m/A **[A]** |

## 1. Architecture

```

 θ_ref ─►(Σ)─► Angle P/PD ─► ω_ref ─►(Σ)─► Vel PI ─► i_q* ─►(Σ)─► Current PI ─► v_dq ─► invPark ─► SVPWM ─► Inverter
          ▲                           ▲          + i_q,cog ─┘ ▲                                          │
          │                           │                       │ i_dq ◄─ Park ◄─ Clarke ◄─ i_abc ◄────────┤
          │                           │                                                                  │
   IMU attitude (Mahony)       ω from gyro (+ encoder blend)                       θ_e = p·θ_m ◄─ encoder ◄┘
          ▲

```

Each loop's crossover is about 5–10× below the loop inside it. Approximate targets:

- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·100 rad/s
- Angle loop: ω_θ ≈ 2π·15 rad/s

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms (amplitude-invariant)

Clarke transform:

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b) \quad(\text{using } i_a+i_b+i_c=0)
$$

Park transform, with electrical angle $\theta_e = p\,(\theta_m - \theta_{off})$:

$$
\begin{bmatrix} i_d \\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}
$$

Inverse Park is the transpose. Torque is $\tau = \tfrac32 p \lambda_m i_q = K_t i_q$.

### 2.2 Plant and decoupling

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m
$$

Feedforward decoupling cancels the cross terms and back-EMF:

$$
v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m
$$

After decoupling, each axis is the first-order plant $G_i(s) = 1/(Ls+R)$.

### 2.3 PI tuning by pole-zero cancellation

Use $C_i(s) = K_p + K_i/s$ with:

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c
$$

This gives the closed loop $\omega_c/(s+\omega_c)$. With the assumed values ($\omega_c = 9425$ rad/s), $K_p = 14.1$ V/A and $K_i = 47\,100$ V/(A·s).

PWM and computation delay add roughly $1.5\,T_s = 75\,\mu s$. This costs about $\omega_c \cdot 1.5T_s \approx 40°$ of phase, which is acceptable. Do not push $\omega_c$ above about $f_s/10$.
