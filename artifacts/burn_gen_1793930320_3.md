Some of this depends on your hardware. I've stated each assumption so you can substitute your actual parameters. All equations are written in discrete time where they are implemented.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC (e.g., GM4108H-120T), pole pairs `p = 11`, 12N14P |
| `R_s`, `L_s` (phase) | ≈ 5.6 Ω, ≈ 2.2 mH (high-turn gimbal winding) |
| Torque constant `K_t` | `(3/2)·p·ψ_m` ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| Current sense | 3 low-side shunts, sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz |

Loop rates (all phase-locked to the PWM timer):

```
PWM 20 kHz ─┬─ Current loop (FOC)       20 kHz   (Ts_i = 50 µs)
            ├─ Velocity loop             4 kHz   (÷5)
            ├─ IMU read + filters        4 kHz   (8 kHz ODR, FIFO 2 samples, averaged)
            ├─ Angle/attitude loop       1 kHz   (÷20)
            └─ Cogging LMS adaptation    1 kHz   (background, gated)
```

Bandwidth separation rule: each outer loop is at least 4–10× slower than the loop inside it.
- Current: ω_ci ≈ 2π·1500 rad/s
- Velocity: ω_cv ≈ 2π·120 rad/s
- Angle: ω_cp ≈ 2π·25 rad/s

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, using i_a + i_b + i_c = 0):

```
i_α = i_a
i_β = (i_a + 2·i_b) / √3
```

**Park transform** with electrical angle θ_e:

```
θ_e = p·θ_m − θ_offset          (θ_offset from alignment)

i_d =  i_α·cos θ_e + i_β·sin θ_e
i_q = −i_α·sin θ_e + i_β·cos θ_e
```

**Inverse Park transform**:

```
v_α = v_d·cos θ_e − v_q·sin θ_e
v_β = v_d·sin θ_e + v_q·cos θ_e
```

### 1.2 Plant Model and PI Design

The dq-axis voltage equations are:

```
v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
v_q = R·i_q + L·di_q/dt + ω_e·L·i_d + ω_e·ψ_m
```

**Decoupling plus back-EMF feedforward** turns each axis into a first-order plant, G(s) = 1/(Ls+R):

```
v_d* = PI_d(e_d) − ω_e·L·i_q
v_q* = PI_q(e_q) + ω_e·L·i_d + ω_e·ψ_m
```

**Pole-zero cancellation tuning.** Choosing K_i/K_p = R/L gives a closed loop of ω_ci/(s+ω_ci):

```
K_p = L·ω_ci
K_i = R·ω_ci
```
