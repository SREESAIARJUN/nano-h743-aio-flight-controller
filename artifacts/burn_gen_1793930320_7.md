# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #28 specification, so this design uses the defaults in §0. Every value marked ⚙ is a parameter you should replace with your measured hardware value. The structure and equations do not depend on these specific numbers.

---

## 0. Assumed Hardware Baseline

| Item | Assumption ⚙ |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per axis (e.g. AS5048A, MT6701) |
| Current sense | 2- or 3-shunt, sampled at PWM center |
| MCU | STM32G4 / H7 class (FPU, 170+ MHz) |
| IMUs | 2× ICM-42688-P on the camera plate, rigidly mounted, possibly rotated relative to each other (R_AB) |
| Mechanical order | Yaw (outer) → Roll → Pitch (inner) |
