# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification

I don't have the original Job #48 spec, so this design uses the assumptions below. Every assumption is a single parameter in the code (`config` structs), so you can change any of them without restructuring.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–6 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sense | 2-shunt low-side, sampled at PWM center |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| Gimbal order | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y), so R = R_z(ψ)·R_x(φ)·R_y(θ) |
| IMUs | 2× ICM-42688-P on the camera platform, mounted mirror-symmetric (r₂ ≈ −r₁) |

**Loop rates**

| Loop | Rate | Ts |
|---|---|---|
| Current (FOC) | 20 kHz | 50 µs |
| IMU sampling + filtering | 8 kHz | 125 µs |
| Velocity | 4 kHz | 250 µs |
| Attitude/angle | 1 kHz | 1 ms |
