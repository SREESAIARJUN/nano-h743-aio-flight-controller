## 0. Architecture Clarification and Assumptions

### 0.1 Architecture correction

An STM32H743 does not commutate the motors directly in any production 4-in-1 design. ArduPilot does not run ESC firmware.

The correct partition is:

```
┌─────────────────────────┐   Bi-dir DShot600 (×4, 1-wire each)   ┌──────────────────────────────┐
│ FC: STM32H743 (ArduPilot)│ ────────────────────────────────────▶ │ 4-in-1 ESC: 4× AM32 MCUs      │
│  TIM3/TIM4 + DMAMUX     │ ◀──────── GCR eRPM telemetry ──────── │ (STM32G071 / AT32F421)        │
└─────────────────────────┘                                        │ 4× 3-ph gate driver, 24 FETs  │
                                                                   └──────────────────────────────┘
```

- Section 2 (losses) applies to the ESC board.
- Section 3 (DShot DMA) applies to the H743 FC.

## 1. Current Path Model (6-step with Synchronous Rectification)

During any 60° commutation sector, phase A is PWM-ing, phase B is held low, and phase C is floating.

- **PWM on (duty D):** current flows V+ → Q_AH → motor → Q_BL → GND.
- **PWM off (1 − D):** current freewheels through Q_AL (sync rect) → motor → Q_BL.

At every instant, exactly two FETs carry the full phase current I. Before Q_AL's channel enhances, the body diode conducts during the dead time.

## 2. Loss Model (per ESC channel)

### 2.1 Conduction loss

$$P_{cond} = I^2 \left[ D\,R_{AH} + (1-D)\,R_{AL} + R_{BL} \right] + I^2 R_{Cu}$$

With identical FETs:

$$P_{cond} = 2\,I^2\,R_{DS(on),max}\,k(T_j) + I^2 R_{Cu}$$

Evaluate at T_j = 110 °C:

- R_DS = 1.00 mΩ × 1.38 = 1.38 mΩ
- Copper/solder path: R_Cu ≈ 0.25 mΩ (phase trace, vias, and pads at 2 oz, hot)

$$P_{cond} = 2(80)^2(1.38\times10^{-3}) + (80)^2(0.25\times10^{-3}) = 17.66 + 1.60 = \mathbf{19.3\ W}$$

**Thermal runaway check.** dP/dT_j = 2·I²·R₂₅·0.0045 = 0.058 W/K per channel. Stability requires that this term multiplied by R_θ(eff) stays below 1. With R_θ ≈ 7 K/W per FET pair, the loop gain is about 0.2 per FET. The design is stable, but the derivative must be included in transient simulation.

### 2.2 Switching loss (hard-switched FET, Q_AH)

**V–I overlap:**
$$P_{VI} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = \tfrac12(25.2)(80)(30\,\text{ns})(48\,\text{kHz}) = \mathbf{1.45\ W}$$

The t_r + t_f estimate comes from the Miller plateau: t ≈ Q_gd·R_g / (V_drv − V_plateau) = 10 nC·10 Ω / (10 − 3.5) ≈ 15 ns per edge.

**Reverse recovery of the Q_AL body diode:**
$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\text{n}\cdot25.2\cdot48\text{k} = 0.048\ \text{W}$$
