# STM32H743 AIO Flight Controller + 4-in-1 ESC: Engineering Model

## 0. Scope, Assumptions and Design Review Findings

**Architecture.** The STM32H743 cannot practically commutate four BLDC motors and run ArduPilot at the same time. The design is therefore partitioned as follows:

| Block | Device | Firmware | Role |
|---|---|---|---|
| FC | STM32H743VIT6 (LQFP100) | ArduPilot | Attitude control, issues bidirectional DShot600 |
| ESC ×4 | STM32G071 class (or AT32F421) | AM32 | Six-step commutation, 48 kHz PWM, returns eRPM telemetry |
| Power stage ×4 | 6× 40 V N-MOSFET per channel + 3-phase gate driver | n/a | Inverter |

**Operating point:**

| Parameter | Value |
|---|---|
| Battery | 6S, 25.2 V max |
| Peak current | 80 A per channel, burst |
| PWM frequency | f_sw = 48 kHz |
| Form factor | 20×20 mm ("nano") or 30.5×30.5 mm |

**Device parameters.** These are representative values for a 40 V, 3.3×3.3 mm PQFN MOSFET. Replace them with datasheet values from your selected part before sign-off.

| Parameter | Symbol | Value |
|---|---|---|
| On-resistance at 25 °C | R_ds(on),25 | 1.0 mΩ |
| Temperature coefficient (125 °C / 25 °C) | k_T | 1.5 |
| Switching charge | Q_gs2 + Q_gd = Q_sw | 15 nC |
| Total gate charge | Q_g | 60 nC |
| Reverse recovery charge | Q_rr | 40 nC |
| Output charge | Q_oss | 60 nC |
| Body diode forward voltage | V_f | 0.8 V |
| Thermal resistance, junction to case | R_θJC | 1.5 K/W |

**Key design review findings (stated up front):**

1. **80 A is a transient rating only on this form factor.** It is not continuous, and the thermal model in §3 proves it. Simultaneous 4×80 A on a 20×20 board is limited to about 2 seconds.
2. **Don't run the ESC PWM from the H743.** ArduPilot outputs DShot only. The 48 kHz PWM lives in the ESC MCUs.
3. **Input ripple current at 80 A is about 40 A RMS per channel.** Local ceramics cannot absorb it. A low-ESR electrolytic on the battery leads is mandatory.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Six-step operation with synchronous rectification

At any commutation step, two phases conduct:

- **Phase A high-side (HS):** PWM at duty D, carries I for a fraction D of the time.
- **Phase A low-side (LS):** complementary sync rectification, carries I for a fraction (1−D).
- **Phase B low-side:** fully on, carries I continuously.

The instantaneous conduction loss in the bridge is:

$$P_{cond,bridge} = I^2 R_{ds}(T_j)\,[D + (1-D) + 1] = 2\,I^2 R_{ds}(T_j)$$

This result is **independent of duty**, which is a useful property of sync-rectified six-step drive.
