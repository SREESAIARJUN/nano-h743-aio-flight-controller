# STM32H743 AIO with 4-in-1 ESC (Nano Form Factor): Power-Stage Thermal Model, Switching Losses, and Bi-Directional DShot600 Timer/DMA Allocation

## 0. Executive Summary and Feasibility Finding

**80 A per motor on a 20×20 mm nano board is not thermally feasible.** The model below shows about **84 W of FET loss** at an 80 A burst on all four motors. That heats a nano-scale board by about **38 K/s**, so it exceeds safe limits in roughly **1.5–2 s**. This is a hard physical limit, not a tuning problem.

The model supports three options:

| Option | Rating | Comment |
|---|---|---|
| A | 20×20 nano, **35 A/motor continuous, 45 A/motor for 5 s** | Recommended for nano |
| B | 30.5×30.5, 5×6 mm FETs, separate ESC board, **60 A continuous / 80 A for 5–10 s** | Required if 80 A is mandatory |
| C | 20×20, **80 A total-pack burst** (≈20 A/motor) | If "80A" meant battery current |

**Architectural correction.** The STM32H743 cannot run the motor commutation itself. It runs ArduPilot. Each motor channel needs its own ESC MCU (for example AT32F421 or STM32G071 running AM32/BLHeli_32-class firmware). Bi-directional DShot600 runs between the H743 and those four ESC MCUs. The 48 kHz PWM is generated by the ESC MCUs, not by the H743.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,\big[1 + \alpha_T (T_j - 25)\big], \quad \alpha_T \approx 0.0059\ \text{K}^{-1} \Rightarrow R_{DS}(110^\circ C) \approx 1.5\ \text{m}\Omega$$

### 2.2 Six-step, complementary PWM

In each 60° sector, phase X is PWM-high, phase Y is held low, and phase Z floats. Over one electrical cycle, each leg spends 120° (1/3 of the cycle) as the PWM leg and 120° (1/3) as the return leg. With duty D:

| Device | Conducts | Average loss |
|---|---|---|
| High-side (HS) | D during the PWM third | $P_{HS} = \tfrac{1}{3} D\, I^2 R_{DS}$ |
| Low-side (LS), sync-rect | (1−D) during the PWM third, plus 100% during the return third | $P_{LS} = \tfrac{1}{3}(2-D)\, I^2 R_{DS}$ |
| Per leg | | $P_{leg} = \tfrac{2}{3} I^2 R_{DS}$ |
| Per motor (3 legs) | | $P_{cond,ESC} = 2\, I^2 R_{DS}$ |

The per-motor result is independent of D, because two FETs are always in series with the phase current.

### 2.3 Numbers at 80 A, R_DS = 1.5 mΩ

- I²R = 80² × 1.5 mΩ = **9.6 W**
- Per motor: P_cond = **19.2 W**
- Per 4-in-1: **76.8 W**
- Worst single FET: the LS at D → 0 gets (2/3)·9.6 = **6.4 W**. At D ≈ 0.9, the LS gets 3.5 W and the HS gets 2.9 W.
