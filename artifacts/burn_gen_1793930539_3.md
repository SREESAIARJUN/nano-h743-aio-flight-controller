# STM32H743 FC + 4-in-1 80 A ESC: Reference Design Package (Job #53)

## 0. Scope, Assumptions, and Up-Front Findings

This is a **first-principles reference model**, not a released design. Every component value below is a placeholder until it is checked against the actual datasheets, your stack-up, and bench thermal measurements.

**Architecture note.** In a 4-in-1 stack, the STM32H743 does not drive the MOSFETs. It runs ArduPilot and sends bi-directional DShot600 to four ESC MCUs (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32). Those ESC MCUs generate the 48 kHz complementary PWM. The model is split along that boundary.

### Baseline assumptions

| Parameter | Value |
|---|---|
| Bus voltage | 6S, V_bus,max = 25.2 V |
| Burst current | 80 A **phase** current per channel, all 4 channels simultaneously (worst case) |
| Commutation | 6-step trapezoidal, synchronous rectification (complementary PWM) |
| f_sw | 48 kHz |
| Dead time | 100 ns |
| MOSFET (representative 40 V PQFN) | R_ds(on),25 = 0.7 mΩ; Q_g = 60 nC; Q_gd = 10 nC; Q_gs2 ≈ 5 nC; Q_rr ≈ 40 nC; C_oss,tr ≈ 1.5 nF; V_SD = 0.8 V |
| Gate drive | ≈1 A effective, V_drv = 10 V |
| Thermal limit | T_j,max design = 125 °C; PCB/solder limit ≈ 110 °C |

### Critical design-review flags

1. **80 A × 4 is a 320 A system (at duty ≈ 1).** No nano-format power entry (XT60/XT90 pads, 20×20 or 30×30 copper) sustains this. "80 A burst" can only be a **seconds-scale** rating. The numbers in §1.4 quantify exactly how many seconds.
2. **Bus shunt dissipation becomes significant at burst currents.** See §4.3.
3. **R_ds(on) has positive thermal feedback.** The loss model must be iterated, not evaluated once.

## 1. Thermal Conduction Loss Model (80 A Burst)

### 1.1 Conduction topology in 6-step with synchronous rectification

In any 60° commutation sector, exactly two legs carry phase current I_ph:

- **PWM leg.** Current flows through the HS FET during D·T_sw and through the LS FET (synchronous rectification) during (1−D)·T_sw. The leg is therefore always conducting through exactly one R_ds(on).
- **Static leg.** The LS FET is held on for the whole sector.

Per channel:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{ds(on)}(T_j) + I_{ph}^2\,R_{Cu}$$

Temperature dependence (typical for silicon trench FETs):

$$R_{ds(on)}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

At 125 °C: R_ds(on) ≈ 0.7 × 1.6 = **1.12 mΩ**.

### 1.2 Evaluation at 80 A

| Term | Expression | Value |
|---|---|---|
| FET conduction | 2 · 80² · 1.12 mΩ | **14.34 W** |
| Copper path (R_Cu ≈ 0.5 mΩ, 2–3 oz, phase pad → FET → bus) | 80² · 0.5 mΩ | **3.20 W** |
| **Per channel conduction** | | **17.5 W** |

Per-FET average: each of the 6 FETs carries about 1/3 of the electrical cycle at full I²R, so roughly 14.34 / 6 ≈ **2.4 W average per FET**. The instantaneous peak while conducting is 80² × 1.12 mΩ = 7.2 W.

Electrical frequency is in the kHz range, far faster than the die thermal time constant (ms). Averaging over the cycle is therefore valid for T_j.

### 1.3 Self-consistent iteration (thermal runaway check)

$$T_j^{(n+1)} = T_{pcb} + R_{th,j\text{-}pcb}\cdot P_{FET}\!\left(T_j^{(n)}\right)$$

With R_th,j-pcb ≈ 1.5 K/W (PQFN on a via-stitched pad) and P_FET ≈ 2.4 W, the junction sits only about 4 K above the PCB.
