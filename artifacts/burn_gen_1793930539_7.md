# STM32H743 AIO + 4-in-1 ESC: Power-Stage Loss Model, Thermal Analysis, and Bi-Directional DShot600 Allocation

I don't have the Job #61 design files, BOM, or stackup. Every numeric result below comes from **stated assumptions (A1–A12)**. Swap in your datasheet values and the equations carry through. The analysis does reach one conclusion that changes the design: **80 A burst on a nano-format board is thermally infeasible beyond about 1–3 s if more than one channel is loaded.** Section 3 shows why, and it should be resolved before layout.

## 0. Architecture and Assumptions

**Topology.** The STM32H743 is the flight controller. It sends DShot600 to four ESC MCUs (e.g., AT32F421 running AM32 or BLHeli_32-class firmware). Each ESC MCU drives a 3-phase bridge through a gate driver. The H743 never switches the FETs directly. The 48 kHz figure is the ESC MCU's PWM frequency.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step synchronous PWM

In each 60° sector, one phase's high side (HS) chops at duty D and another phase's low side (LS) conducts continuously. The current always flows through exactly **two** channels:

- **PWM ON:** HS(x) → motor → LS(y)
- **PWM OFF:** LS(x), synchronously rectified → motor → LS(y)

So the total bridge conduction loss is independent of D:

$$P_{cond,bridge} = 2\, I_{ph}^2\, R_{ds}(T_j)$$

### 1.2 Per-FET distribution

Each phase's HS chops for 1/3 of the electrical period. Its LS returns current for 1/3 and freewheels for 1/3·(1−D).

$$P_{HS} = \frac{D}{3} I^2 R_{ds}, \qquad P_{LS} = \frac{2-D}{3} I^2 R_{ds}$$

Check: 3·(P_HS + P_LS) = 2I²R ✓

### 1.3 Temperature dependence

R_ds rises with temperature, so conduction loss and junction temperature feed each other:

$$R_{ds}(T_j) = R_{25}[1+\alpha(T_j-25)]$$

$$T_j = T_{ref} + Z_{th}\,P(T_j)$$

Solving for T_j:

$$T_j = \frac{T_{ref} + Z_{th} k R_{25}(1-25\alpha)}{1 - Z_{th} k R_{25}\alpha}, \quad k = \text{loss coefficient (e.g., } I^2(2-D)/3)$$

**Thermal runaway criterion:** Z_th · k · R_25 · α ≥ 1. With the values below this ratio is about 0.03, so runaway is not the limit. Total heat capacity is (Section 3).
