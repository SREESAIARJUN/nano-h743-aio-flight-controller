# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the spec sheet for Job #28, so this design states its assumptions explicitly (§0). Every gain is derived from those parameters, so you can substitute your real values.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, e.g. GBM2804: 12N14P, so pole pairs `p = 7` |
| Phase resistance / inductance | R = 5.6 Ω (phase-neutral), L = 1.8 mH |
| Torque constant | K_t ≈ 0.08 N·m/A (q-axis, amplitude-invariant Clarke) |
| Load inertia per axis | J ≈ 2–8 ×10⁻⁵ kg·m² |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701) on SPI |
| Current sensing | 2-shunt low-side, sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera platform, SPI, 8 kHz ODR |
| MCU | STM32G4 / H7 class with FPU |

**Loop rates and bandwidths.** Each outer loop runs at roughly one-fifth to one-tenth the bandwidth of the loop inside it.

```
 ┌───────── 1 kHz ──────────┐  ┌──── 4 kHz ───────┐  ┌──────── 20 kHz ──────────────┐
 θ_ref → [Attitude P + FF] → ω_ref → [Rate PI] → i_q* (+ i_cog_ff) → [d/q PI] → SVPWM → Motor
            ↑ q̂ (AHRS)          ↑ ω_meas (gyro⊕encoder)              ↑ i_d,i_q (Park)  ↑ θ_e (encoder)
            └──── Dual ICM-42688-P → AAF → notch → fusion → Mahony ──────┘
```

| Loop | Bandwidth target | Rate |
|---|---|---|
| Current | ω_c ≈ 2π·1500 rad/s | 20 kHz |
| Velocity | ω_v ≈ 2π·150 rad/s | 4 kHz |
| Attitude | ω_θ ≈ 2π·20 rad/s | 1 kHz |

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

Clarke transform:

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

Park transform, with electrical angle θ_e = p·θ_m − θ_offset:

$$
\begin{bmatrix} i_d \\ i_q \end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}
$$

### 1.2 Plant (SPMSM, L_d = L_q = L)

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

### 1.3 PI design by pole-zero cancellation

Choose the PI zero to cancel the electrical pole:

$$
C(s) = K_p + \frac{K_i}{s}, \qquad \frac{K_i}{K_p} = \frac{R}{L}
$$

The closed loop then becomes first order with bandwidth ω_c:

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c
$$

Decoupling and back-EMF feedforward:

$$
v_d^* = u_d - \omega_e L i_q,\qquad v_q^* = u_q + \omega_e L i_d + \omega_e\lambda_m,\qquad \lambda_m = \tfrac{2}{3}\tfrac{K_t}{p}
$$

**Discrete form.** Use backward Euler at T_s = 50 µs. Keep ω_c·T_s < 0.5 for adequate phase margin, given the 1.5-sample transport delay of PWM and ADC.

### 1.4 Anti-windup (back-calculation)

$$
x_I[k+1] = x_I[k] + T_s\big(K_i\,e[k] + K_{aw}(u_{sat}[k]-u[k])\big),\qquad K_{aw}\approx \frac{K_i}{K_p}
$$

### 1.5 Voltage limiting and SVPWM

Limit the voltage vector to the inscribed hexagon circle, $|v| \le V_{dc}/\sqrt3$, giving d-axis priority. Then use min-max zero-sequence injection, which is equivalent to SVPWM:

$$
v_{abc} = \text{invClarke}(v_\alpha, v_\beta),\quad
v_0 = -\tfrac12\big(\max v_{abc} + \min v_{abc}\big),\quad
D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}
$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical plant

$$
J\dot\omega = K_t i_q - \tau_{cog}(\theta) - B\omega - \tau_{fric}(\omega) - \tau_{dist}
$$

### 2.2 Velocity PI

Treat the closed current loop as unity, since ω_v ≪ ω_c. The plant is then $G_v(s) = K_t/(Js)$.
