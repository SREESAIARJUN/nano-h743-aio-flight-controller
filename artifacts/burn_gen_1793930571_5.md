# 3-Axis Gimbal FOC Control & Dual-IMU Fusion: Design Specification and C++ Reference Implementation

I don't have the Job #17 specification, so this design states its assumptions explicitly. Every parameter is in a single config struct, so you can replace the defaults with your real values.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (7 pole pairs), R = 5.6 Ω, L = 2.1 mH, Kt ≈ 0.12 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (MT6701/AS5048A class) on each motor shaft |
| MCU | STM32G4/H7 class with FPU. Center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera stage, SPI at 24 MHz, ODR 8 kHz, FIFO off, data-ready interrupt |
| Loop rates | Current: 20 kHz. Velocity: 4 kHz. Angle and attitude: 1 kHz |
| Bus | 12 V or 4S. Vdc is measured every PWM cycle |
