# STM32H743 AIO Nano FC + 4-in-1 ESC: Power-Stage Model, Thermal Budget, and Bidirectional DShot600 Timer/DMA Allocation (Job #29)

## 0. Architecture Clarifications

These points shape everything downstream.

1. **The H743 does not commutate the motors.** In a 4-in-1 AIO design, the H743 runs ArduPilot and emits DShot600. Each ESC channel has its own MCU, for example an STM32G071 or AT32F421 running AM32. The 48 kHz PWM is generated by the ESC MCUs, not the H743.
2. **"80 A burst" on a nano board (20×20 or 25.5×25.5 mm) is a transient rating, not a continuous one.** The math below shows it is thermally bounded to about 1–3 s per event. Size the marketing spec accordingly.
3. **All device parameters are assumptions.** Replace them with datasheet values for the MOSFETs you actually select, and validate on a thermal-camera bench before release.

## 1. Conduction Loss Model

### 1.1 Topology

The ESC uses 6-step trapezoidal BLDC drive with synchronous (complementary) PWM. During each 60° commutation sector:

- The **PWM leg** alternates high-side (duty D) and low-side (1 − D). Exactly one FET of that leg always carries I.
- The **return leg's** low-side FET is held on for the entire sector.

So the motor current always flows through **two FETs in series**, independent of D:

$$P_{cond,ch} = 2\,I_{rms}^2\,R_{DS(on)}(T_j)$$

### 1.2 Ripple Correction

With peak-to-peak phase ripple ΔI:

$$I_{rms}^2 = I^2\left(1+\frac{r^2}{12}\right),\quad r=\frac{\Delta I}{I}$$

At 48 kHz with typical 5" to 7" motor inductance (≈ 15–40 µH), r is about 0.1. The correction is +0.08%, so it is neglected below.

### 1.3 Temperature Dependence

$$R_{DS(on)}(T_j) = R_0\left[1+\alpha\,(T_j-25)\right]$$

| T_j | R_DS(on) | P_cond per channel @ 80 A |
|---|---|---|
| 25 °C | 1.20 mΩ | 15.4 W |
| 100 °C | 1.61 mΩ | 20.6 W |
| 125 °C | 1.74 mΩ | **22.3 W** |

### 1.4 Per-FET Average Loss

Each FET conducts for 120° electrical (2 of 6 sectors) when averaged over a full electrical revolution. This holds as long as the electrical period (≈ 0.3–2 ms) is much shorter than the board thermal time constant, which it is.

$$P_{cond,FET} \approx \frac{P_{cond,ch}}{6} = 3.7\ \text{W @ } 125\,°C$$

The instantaneous FET loss is 3× the average, which matters only for the ~1 ms die-level Z_th. Check this against the datasheet transient-impedance curve.

## 2. Switching Loss Model (48 kHz)

Only the PWM leg switches. One FET hard-switches. Its complement commutates through its body diode during dead time.

### 2.1 V–I Overlap Loss

Gate currents during the Miller plateau:

$$I_{g,on}=\frac{V_{drv}-V_{pl}}{R_{on}}=\frac{10-3}{5}=1.4\ \text{A}\qquad I_{g,off}=\frac{V_{pl}}{R_{off}}=\frac{3}{4}=0.75\ \text{A}$$

Resulting transition times:

$$t_{on}=\frac{Q_{sw}}{I_{g,on}}=8.6\ \text{ns}\qquad t_{off}=\frac{Q_{sw}}{I_{g,off}}=16\ \text{ns}$$

Overlap loss:

$$P_{VI}=\tfrac12 V_{bus} I\,(t_{on}+t_{off})\,f_{sw} = 0.5(25.2)(80)(24.6\,\text{ns})(48\,\text{kHz}) = \mathbf{1.19\ W}$$
