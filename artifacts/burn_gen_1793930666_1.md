# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage, Thermal, and Bidirectional DShot Design Package (Job #13)

## 0. Architecture Decisions

Two points need to be settled before any math, because they change the design.

**1. The H743 should not commutate the motors.** Bidirectional DShot is a protocol between a flight controller and an ESC MCU. If the H743 drove the gate drivers directly, DShot would have no purpose. ArduPilot also does not run sensorless BLDC commutation at 48 kHz PWM. The architecture is therefore:

```
STM32H743 (ArduPilot)  ──DShot600 bidir ×4──►  4× ESC MCU (AT32F421 / AM32 FW)
                                                 └─► 3-phase gate driver ─► 6× MOSFET ─► motor
```

The two halves can share one PCB (AIO) or a stacked pair. AM32 supports 48 kHz PWM and bidirectional DShot natively.

**2. A 20×20 "nano" board cannot sustain 80 A bursts.** The thermal model in §3 shows that heat capacity, not MOSFET R<sub>DS(on)</sub>, sets the burst limit. My recommendations:
- 30.5×30.5 mm minimum.
- 8-layer board with 2 oz copper on the power layers.
- DFN5×6 FETs.

I calculate both footprints so the trade-off is explicit.
