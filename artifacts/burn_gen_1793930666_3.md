## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (assumes i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and decoupling

For an SPMSM (L_d = L_q = L), the dq-frame voltage equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

Feed the cross-coupling and back-EMF terms forward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda)$$

After this cancellation, each axis behaves as a first-order plant:

$$G_i(s) = \frac{1}{Ls+R}$$

### 1.3 PI design by pole-zero cancellation

Use the controller

$$C_i(s) = K_p + \frac{K_i}{s}$$

with gains

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The closed loop then becomes

$$T(s) = \frac{\omega_c}{s+\omega_c}$$

Choose ω_c ≤ 2π·f_pwm/20. With f_pwm = 20 kHz, ω_c = 2π·1000 rad/s, giving K_p = 12.6 V/A and K_i = 31 400 V/(A·s).

### 1.4 Discrete implementation (backward Euler) with back-calculation anti-windup

$$u_k = K_p e_k + I_k + v^{ff}$$

$$u^{sat}_k = \mathrm{sat}(u_k)$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(u^{sat}_k - u_k)$$

Use K_aw = 1/K_p·K_i·T_s, or more simply K_aw ≈ K_i/K_p·T_s.

**Voltage vector limit:** The vector is circularly limited to

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}\cdot m_{max},\qquad m_{max}\approx 0.95$$

The d-axis has priority: limit v_q to

$$\sqrt{V_{max}^2 - v_d^2}$$

### 1.5 SVPWM by min-max zero-sequence injection

$$v_a = v_\alpha,\quad v_b = \tfrac{-v_\alpha+\sqrt3 v_\beta}{2},\quad v_c = \tfrac{-v_\alpha-\sqrt3 v_\beta}{2}$$

$$v_0 = -\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right)$$

$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

**Torque relation:**

$$\tau = \tfrac32 p\lambda\, i_q = K_t\, i_q$$

The reference i_d* = 0 (no field weakening is needed at gimbal speeds).

## 2. Cascaded Velocity and Angle Control

### 2.1 Velocity loop

**Mechanical plant**, treating the current loop as ideal at velocity-loop frequencies:

$$G_v(s) = \frac{K_t}{J s}\cdot\frac{\omega_c}{s+\omega_c}$$

**Controller (PI):**

$$C_v(s) = K_{pv}\left(1+\frac{\omega_{iv}}{s}\right)$$

**Gain design.** Pick the crossover ω_v = ω_c/8 to ω_c/10. With a symmetric-optimum-style placement:

$$K_{pv} = \frac{J\,\omega_v}{K_t},\qquad \omega_{iv} = \frac{\omega_v}{4}$$

The integral gain is then

$$K_{iv} = K_{pv}\,\omega_{iv}$$

This placement yields roughly 60° phase margin.

**Worked numbers:** ω_v = 2π·100 rad/s gives K_pv = 1.0e-3 A·s/rad and K_iv = 0.157 A/rad
