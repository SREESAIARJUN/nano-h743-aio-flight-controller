# 3-Axis Gimbal: FOC Motor Control & Dual-IMU Sensor Fusion

I don't have a specification for "Job #0," so this design rests on the assumptions in §0. Every parameter that depends on them is a named constant you can change.

## 0. Baseline Assumptions

| Item | Value |
|---|---|
| Motors | Gimbal BLDC (GBM2804-class), 12N14P → **pole pairs p = 7**, R ≈ 5.6 Ω, L ≈ 2.2 mH, Kt ≈ 0.08 N·m/A |
| Slots / poles | N_s = 12, N_p = 14 → **cogging period: LCM(12,14) = 84 cycles per mechanical rev** |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| MCU | STM32G474 / H7, FPU, center-aligned PWM, 3-shunt or 2-shunt sensing |
| Bus | 12–16 V |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the payload CoM. They feed attitude and inertial rate. |
| Loop rates | Current/FOC **20 kHz**, velocity **4 kHz**, angle **1 kHz**, IMU ODR **8 kHz** with decimation to 4 kHz |

Cascade per axis:

```
θ_ref ─►[Angle P + ω_ff]─► ω_ref ─►[Velocity PI(D)]─► τ_ref ─►(+ τ_cog,ff)─► i_q,ref ─►[Current PI dq + decoupling]─► SVPWM
          ▲ θ̂ (AHRS)              ▲ ω̂ (fused gyro, axis-projected)            ▲ θ_e (encoder)        ▲ i_d,i_q (Park)
```

## 1. FOC Current Loop (Innermost)

### 1.1 Transforms
Electrical angle: θ_e = p·(θ_m − θ_offset) mod 2π.

**Clarke** (amplitude-invariant, i_a + i_b + i_c = 0):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park:**
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\quad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant & Decoupling
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Feed-forward decoupling turns each axis into a 1st-order plant 1/(Ls+R):
$$v_d^* = u_d - \omega_e L i_q,\qquad v_q^* = u_q + \omega_e L i_d + \omega_e \lambda_m$$

### 1.3 PI Gains (Pole–Zero Cancellation)
With PI C(s) = K_p + K_i/s and the zero placed on the plant pole (K_i/K_p = R/L), the closed loop becomes ω_c/(s+ω_c):
$$K_p^{(i)} = L\,\omega_{c,i},\qquad K_i^{(i)} = R\,\omega_{c,i}$$

Choose ω_c,i ≤ 2π·f_pwm/20 to stay clear of PWM delay (1.5 T_s). At 20 kHz, f_c,i ≈ 1–1.5 kHz.

**Voltage limit:** the SVPWM linear region is |v| ≤ V_bus/√3. Use circular limiting with d-priority, then back-calculation anti-windup.

### 1.4 SVPWM (Min/Max Injection, Equivalent to 7-Segment)
$$v_a=v_\alpha,\; v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\; v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12(\max+\min),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical Plant (Per Axis, About the Joint)
$$J\dot\omega = K_t i_q + \tau_{cog}(\theta_m) - B\omega - \tau_{dist},\qquad \dot\theta=\omega$$

The current loop is much faster (ω_c,i ≫ ω_c,v), so treat it as unity: τ = K_t i_q.

### 2.2 Velocity Loop: PI with Optional Filtered D, Tustin-Discretized
For the plant 1/(Js+B), set crossover ω_c,v and place the PI zero a decade-fraction below:
$$K_p^{(v)} = J\,\omega_{c,v},\qquad K_i^{(v)} = K_p^{(v)}\,\frac{\omega_{c,v}}{4}$$

Phase margin ≈ 76° ignoring delays. Typical f_c,v = 50–150 Hz for camera payloads, limited by the first structural mode. Keep ω_c,v ≤ ω_mode/3, and notch the mode (§4).

**Discrete PI with back-calculation anti-windup** (T = 1/f_v):
$$e_k=\omega^*_k-\hat\omega_k$$
$$u_k^{raw}=K_p e_k + I_k$$
$$u_k=\mathrm{sat}(u_k^{raw})$$
