# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

## 0. Design Basis and Assumptions

I don't have the Job #30 specification, so the following are stated assumptions. Every value marked † is a parameter you should replace with measured data.

| Item | Assumption |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU), one per gimbal or one for all three axes |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs) †, R ≈ 5–10 Ω, L ≈ 1–3 mH † |
| Encoder | 14-bit absolute magnetic encoder (MT6701 / AS5048A) on each joint |
| IMU A | ICM-42688-P on the camera plate. This is the control IMU (inertial attitude and rate). |
| IMU B | ICM-42688-P on the handle/base. This is the disturbance reference. |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

**Loop rates:**

| Loop | Rate |
|---|---|
| PWM | 20 kHz center-aligned |
| Current (FOC) loop | 20 kHz |
| Encoder PLL and cogging FF | 20 kHz |
| IMU sampling | 8 kHz ODR, FIFO/DRDY |
| Velocity (rate) loop | 4 kHz |
| Angle loop and attitude fusion | 1 kHz |

**How the two IMUs are used:**
- IMU A measures what the controller regulates.
- IMU B measures what disturbs the system. It is used for:
  1. Kinematic rate feedforward of base motion.
  2. Adaptive (NLMS) cancellation of structure-borne vibration that couples into IMU A.

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical Angle

$$\theta_e = \operatorname{wrap}_{2\pi}\!\big(p\,(\theta_m - \theta_{m,0})\big)$$

θ_{m,0} is found at calibration by applying v_d > 0, v_q = 0 and letting the rotor align to θ_e
