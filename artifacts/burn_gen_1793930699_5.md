# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the Job #23 spec sheet, so this design uses the assumptions in §0. Every assumed value is a named `constexpr` or config field, so you can replace it with the real numbers.

---

## 0. Assumptions

| Item | Value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.6 Ω (phase), L = 1.8 mH, Kt ≈ 0.08 N·m/A |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701 class), one per joint |
| MCU | STM32G474 / H7, single-precision FPU, center-aligned PWM 20 kHz |
| Bus | Vdc = 12 V (3S) |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, ODR 8 kHz, CLKIN driven from a common 32.768 kHz source |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries camera) |

**Loop rates (each ≥ 4–5× bandwidth separation):**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
