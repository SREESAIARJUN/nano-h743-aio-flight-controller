# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

I don't have the original specification for Job #15, so this design states its assumptions explicitly. Every assumed value is a parameter in the code, so you can substitute your real hardware values.

---

## 0. Assumed System Parameters

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | 3× GBM2804-class: 12 slots / 14 poles (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 2.5 mH |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701) per joint |
| Current sensing | 2 inline shunts per motor (a voltage-mode fallback is noted) |
| IMUs | 2× ICM-42688-P on the camera plate, mounted on opposite sides of the payload CoM |
| Joint order | Yaw (z) → Roll (x) → Pitch (y), outer to inner |
| Bus voltage | 12–16 V |

**Loop rates:**

| Loop | Rate | Period |
|---|---|---|
| Current (FOC) | 20 kHz | T_c = 50 µs |
| Velocity / rate | 4 kHz | T_v = 250 µs |
| IMU sampling | 8 kHz ODR, decimated to 4 kHz | — |
| Angle / attitude | 1 kHz | T_a = 1 ms |

**Bandwidth separation rule:** each outer loop is at least 4–5× slower than the loop inside it.
- Current loop: ω_c
