## 0. Architecture and Key Assumptions

The STM32H743 does not commutate the motors directly. A 4-in-1 ESC needs four dedicated ESC MCUs, because a single H7 cannot also handle sensorless back-EMF zero-cross detection for four motors at 48 kHz PWM while running the EKF. The H743 sends bidirectional DShot600 to four AT32F421 ESC MCUs running AM32 firmware, all on the same board stack.

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step synchronous PWM

In each 60° sector, two phases carry current I:
- **PWM leg:** The high-side (HS) FET is on for duty D. Its complementary low-side (LS) FET is on for (1−D), minus dead time.
- **Return leg:** The LS FET is held fully on.

Each phase spends 120° (1/3 of the electrical period) as the HS-driven phase and 120° as the LS-return phase.

### 1.2 RMS current per switch

Let R = R_DS(on)(T_j) = k(T_j)·R_25.

**High-side FET:**

$$I_{HS,rms}^2 = I^2\cdot\frac{D}{3}$$

**Low-side FET (complementary during the PWM sector, plus fully on during the return sector):**

$$I_{LS,rms}^2 = I^2\cdot\frac{1-D}{3} + I^2\cdot\frac{1}{3} = I^2\cdot\frac{2-D}{3}$$

**Per phase:**

$$I_{HS,rms}^2+I_{LS,rms}^2 = \frac{2}{3}I^2$$

This is independent of D.

### 1.3 Total conduction loss per motor

$$P_{cond,motor} = 3\cdot\frac{2}{3}I^2R = 2I^2R$$

Physically, two R_DS(on) are always in series with the motor current.

Add the copper path, R_Cu (bus plus phase pads, about 0.3 mΩ per leg, so 0.6 mΩ total):

$$P_{Cu} = I^2 R_{Cu}$$

### 1.5 Thermal-electrical coupling

Because R depends on T_j, the conduction loss must be solved iteratively:

$$T_j = T_{ref} + P(T_j)\cdot R_{th},\quad R_{DS}(T_j)=R_{25}\,[1+\alpha(T_j-25)],\ \alpha\approx0.006\,/\mathrm{K}$$
