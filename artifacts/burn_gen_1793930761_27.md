### Architecture note

In a production 4-in-1 stack, the STM32H743 runs ArduPilot on the flight controller. Each ESC channel has its own small MCU (for example STM32G071 or AT32F421 running AM32), which owns the 48 kHz complementary PWM.

The H743 only generates DShot600 frames and decodes the bidirectional eRPM telemetry. Driving 24 FETs directly from the H743 is not viable:
- It has only two advanced timers (TIM1 and TIM8) with complementary outputs, plus the HRTIM.
- That is not enough for 4×3 half-bridges with dead-time insertion.
- It would also put flight-critical attitude control in the same fault domain as the power stage.

This package therefore uses the two-tier architecture.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current paths in six-step operation

In any 60° sector, one phase is PWM'd (say A) and one phase is held low (B).

| Interval | Conducting devices | Loss |
|---|---|---|
| ON (duty D) | Q_AH + Q_BL | I²·R_ds·D·2 |
| OFF (1−D), synchronous | Q_AL + Q_BL | I²·R_ds·(1−D)·2 |
| Dead time (2 per period) | D_AL (body diode) + Q_BL | V_f·I·2·t_dt·f_sw |

### 1.2 Per-channel conduction loss

With synchronous rectification, two R_ds(on) are always in the current path, so the result is independent of duty:

$$P_{cond} = 2\,I_{ph}^2\,R_{ds}(T_j), \qquad R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 110 °C: R_ds = 0.9 × 1.47 ≈ 1.33 mΩ, so

$$P_{cond} = 2 \times 6400 \times 1.33\times10^{-3} = \mathbf{17.0\ W}$$
