# STM32H743 AIO Nano Flight Controller with 80A 4-in-1 ESC: Architecture, Loss Model, Thermal Model, and DShot DMA Plan

## 0. Architecture Correction and Baseline Assumptions

The STM32H743 cannot directly run four sensorless BLDC commutation loops with bidirectional DShot telemetry in a production-safe way. Every 4-in-1 ESC on the market, including AIO boards, uses one small MCU per motor. This design therefore uses:

- **Flight controller:** STM32H743VIH6, 480 MHz, running ArduPilot. It sends DShot600 bidirectional commands to the ESC MCUs.
- **ESC section:** 4× AT32F421 (or STM32G071) running AM32 with 48 kHz PWM. Each drives a 6-channel gate driver (FD6288Q class) and 6 N-channel MOSFETs.
