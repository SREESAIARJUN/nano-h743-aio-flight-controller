## 0. Architectural Ground Truth and Assumptions

The H743 does **not** generate the 48 kHz bridge PWM. A 4-in-1 ESC has one small MCU per motor running the commutation firmware (AM32 or BLHeli_32). The H743 runs ArduPilot and talks to those MCUs over bidirectional DShot600. The two domains are modelled separately below.

| Parameter | Value | Notes |
|---|---|---|
| Form factor | 20×20 mm mounting, ~25×25 mm board | "Nano" class |
| Bus voltage | 6S, V_bus = 25.2 V max | Worst case for switching loss |
| FC MCU | STM32H743VIH6 @ 400 MHz | TIM1/TIM8 clock 200 MHz |
| ESC MCU (×4) | AT32F421K8U7 (AM32) | 48 kHz complementary PWM |
| Gate driver (×4) | FD6288Q, 3-phase, bootstrap | ~1.0 A source / 1.5 A sink typ |

| Commutation | 6-step trapezoidal, complementary (synchronous) PWM | |

| PCB | 8-layer, 2 oz on all layers | |

**What "80 A burst" means here.** It is interpreted as **80 A per channel**, which is how vendors usually specify it. Section 3 shows this is only a ~1–2 s transient rating on a nano board. The honest continuous rating is ~20 A per channel.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)],\qquad \alpha \approx 0.0045\ \text{K}^{-1}$$

At the design point T_j = 110 °C:

$$R_{DS} = 1.5\ \text{m}\Omega \times (1 + 0.0045 \times 85) = 2.07\ \text{m}\Omega$$

### 1.2 Current path in 6-step synchronous PWM

At any instant, motor current *I* flows through exactly two conducting FETs:

- the PWMing high-side **or** its synchronous low-side, and
- the opposite phase's static low-side.

Ripple is folded into RMS current:

$$I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12}$$

With phase inductance ≥ 5 µH, ΔI_pp is small enough that I_rms ≈ I.

### 1.3 Conduction loss per motor

$$P_{cond,motor} = 2\, I^2\, R_{DS}(T_j)$$

$$P_{cond,motor}(80\,\text{A}) = 2 \times 6400 \times 2.07\times10^{-3} = \mathbf{26.5\ W}$$

Averaged over the six FETs of one bridge, each FET carries 26.5 / 6 ≈ 4.4 W, because each FET conducts for 1/3 of the electrical cycle.
