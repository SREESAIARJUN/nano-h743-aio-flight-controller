## 1. Field-Oriented Control (innermost loop, 24 kHz)

### 1.1 Electrical angle

θ_e = p · (θ_m − θ_offset), wrapped to [0, 2π).

Calibrate θ_offset once. Inject a d-axis current with θ_e = 0, let the rotor settle, then record θ_m.

### 1.2 Clarke and Park transforms (amplitude-invariant)

- i_α = i_a
- i_β = (i_a + 2 i_b) / √3 (this uses i_a + i_b + i_c = 0)

Park transform:

- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

### 1.3 Plant model in the dq frame

- v_d = R i_d + L di_d/dt − ω_e L i_q
- v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m

Torque, for a surface PMSM (L_d ≈ L_q):

τ = (3/2) p λ_m i_q = K_t i_q

### 1.4 Current PI with pole-zero cancellation

Using decoupling feedforward, each axis reduces to the plant 1/(Ls + R). Choose:

- K_p,i = L · ω_ci
- K_i,i = R · ω_ci

This gives a closed loop of ω_ci / (s + ω_ci).

Choose ω_ci ≤ 2π·f_i / 10 to account for the 1.5-sample PWM/computation delay. For f_i = 24 kHz, use ω_ci = 2π·1500 rad/s.

Decoupling feedforward:

- v_d,ff = −ω_e L i_q
- v_q,ff = ω_e L i_d + ω_e λ_m

### 1.5 Voltage limiting

The voltage vector is limited to the inscribed SVPWM circle, |v| ≤ V_dc/√3. The d-axis gets priority.

### 1.6 SVPWM

Use min-max zero-sequence injection, which is equivalent to classic 7-segment SVPWM:

- v_a = v_α
- v_b = −½ v_α + (√3/2) v_β
- v_c = −½ v_α − (√3/2) v_β
- v_0 = −(max + min)/2
- duty_x = ½ + (v_x + v_0) / V_dc

## 2. Cascaded Stabilization Control

### 2.1 Loop structure

```
θ_ref ─►[Attitude P + rate FF]─► ω_ref ─►[Rate PID + DOB-lite]─► τ_ref ─►(+ cogging FF)─► i_q,ref ─►[Current PI]─► SVPWM
          ▲ θ̂ (Mahony, dual IMU)             ▲ ω_axis (filtered gyro)
```

### 2.2 Rate feedback per motor axis

The velocity loop regulates **inertial** camera rate, not encoder rate. This is what rejects base motion.

For motor i with unit axis â_i, expressed in the camera frame through the joint kinematics:

ω_i = â_iᵀ ω_cam

For a yaw–roll–pitch stack, with roll angle φ and pitch angle ϑ taken from the joint encoders:

- â_pitch = [0, 1, 0]ᵀ
- â_roll = [cos ϑ, 0, sin ϑ]ᵀ
- â_yaw = [−sin ϑ cos φ, sin φ, cos ϑ cos φ]ᵀ

Adjust the sign conventions to your mechanical build.

### 2.3 Attitude loop (1 kHz)

e_θ = wrap(θ_ref − θ̂)

ω_ref = K_θ e_θ + θ̇_ref, saturated to ±ω_max

Choose ω_cθ = K_θ ≈ ω_cv / 4 to 5.
