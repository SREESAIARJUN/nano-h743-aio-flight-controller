# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #49 specification, so this design states its assumptions explicitly. Every parameter is isolated in a config struct so you can substitute your real values.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class, single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI + DMA, gyro ODR 8
