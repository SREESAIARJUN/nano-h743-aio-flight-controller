## 0. Assumed Hardware and Timing

| Item | Assumption |

| Motors | Gimbal BLDC, 12N14P (12 slots, $p = 7$ pole pairs), $R_s \approx 5.6\,\Omega$, $L_s \approx 2.1\,\text{mH}$, $K_t \approx 0.08$ N·m/A |

| Velocity loop | 5 kHz (decimated ÷4) |

**Rate hierarchy rule.** Each outer loop's bandwidth should be at most 1/5 to 1/10 of the next inner loop's bandwidth:

$$\omega_{c,i} = 2\pi\cdot 1500,\quad \omega_{c,\omega} = 2\pi\cdot 150,\quad \omega_{c,\theta} = 2\pi\cdot 25 \text{ rad/s}$$

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle from mechanical angle (with calibrated offset $\theta_0$):
$$\theta_e = p(\theta_m - \theta_0) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with $i_a + i_b + i_c = 0$):
$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and Current PI Design

The dq voltage equations for an SPMSM ($L_d = L_q = L$) are:
$$v_d = Ri_d + L\dot i_d - \omega_e L i_q,\qquad v_q = Ri_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

After feedforward decoupling,
$$v_d^{ff} = -\omega_e L i_q,\quad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m,$$
each axis reduces to $G(s) = 1/(Ls + R)$.

**Pole-zero cancellation design.** Choose a PI $C(s) = K_p + K_i/s$ with zero $K_i/K_p = R/L$. The open loop becomes $\omega_c/s$, and the closed loop is first-order with bandwidth $\omega_c$:
$$\boxed{K_p = L\,\omega_{c,i},\qquad K_i = R\,\omega_{c,i}}$$

Discretize with backward Euler at $T_s = 50\,\mu s$. To compensate for the computational delay (≈1.5 $T_s$), advance the angle used in the inverse Park by $\theta_e + 1.5\,\omega_e T_s$.

### 1.3 Voltage Limiting and Anti-Windup

The available voltage-vector magnitude for SVPWM in the linear region is
$$|v|_{max} = \frac{V_{bus}}{\sqrt3}.$$

Saturation is applied to the dq vector with $d$-axis priority:
$$v_d^{sat} = \text{clamp}(v_d, \pm|v|_{max}),\quad v_q^{sat} = \text{clamp}\left(v_q, \pm\sqrt{|v|_{max}^2 - (v_d^{sat})^2}\right)$$

Back-calculation anti-windup:
$$x_{I}[k+1] = x_I[k] + K_i T_s e[k] + \frac{K_i}{K_p}T_s (v^{sat} - v)$$

### 1.4 SVPWM (Min-Max Zero-Sequence Injection)

$$v_a, v_b, v_c = \text{InvClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$

$$D_x = \frac12 + \frac{v_x + v_0}{V_{bus}},\quad x\in\{a,b,c\}$$

This is mathematically equivalent to sector-based SVPWM and gives the full $V_{bus}/\sqrt3$ linear range.

## 2. Cascaded Velocity / Angle Control

### 2.1 Mechanical Plant (per axis)

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{d}$$

### 2.2 Velocity PI (5 kHz)

With the current loop modeled as $\approx 1$ (since $\omega_{c,i} \gg \omega_{c,\omega}$), the plant is $\frac{K_t}{Js}$. A PI with zero at $\omega_{c,\omega}/4$ (symmetric-optimum style, about 50–60° phase margin):

$$\boxed{K_{p,\omega} = \frac{J\,\omega_{c,\omega}}{K_t},\qquad K_{i,\omega} = K_{p,\omega}\,\frac{\omega_{c,\omega}}{4}}$$

The velocity controller output is
$$i_q^* = K_{p,\omega}(\beta\,\omega^* - \hat\omega) + K_{i,\omega}\!\int(\omega^* - \hat\omega)\,dt + \underbrace{\frac{J\dot\omega^*}{K_t}}_{\text{accel FF}} + \underbrace{\frac{\hat\tau_{cog}(\theta_m)}{K_t}}_{\text{anti-cogging FF}}$$

where $\beta \in [0,1]$ is setpoint weighting, which reduces overshoot on step commands.
