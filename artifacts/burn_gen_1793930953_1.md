# STM32H743 FC + 4-in-1 80A ESC: Systems Architecture Package (Job #3)

## 0. Architecture Clarification and Assumptions

**The STM32H743 does not drive the MOSFETs directly.** The standard and recommended partition is:

| Block | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100), ArduPilot | Attitude control, emits bidirectional DShot600 ×4 |
| ESC MCUs (×4) | AT32F421 / STM32G071 class, AM32 or BLHeli_32 | 48 kHz complementary PWM, commutation, eRPM telemetry |
| Power stage (×4) | 3× half-bridge (6 MOSFETs) + 3-phase gate driver | 80A burst per motor |

**Form-factor warning:** 4×80A burst on a 20×20 mm "nano" board is not thermally credible (see §3). The calculations below assume a **30.5×30.5 mm, 8-layer, 2 oz power-plane** ESC with the H743 on a stacked FC. If 20×20 is mandatory, derate to roughly 45–55A burst.

**Assumed design constants.** Replace these with your selected MOSFET datasheet values.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V (6S full) | DC link |
| I_ph | 80 A | Burst phase current per motor |
| R_ds,25 | 1.1 mΩ | 40V, 3.3×3.3 PQFN class |
| α | 0.0045 /K | R_ds tempco |
| Q_g | 40 nC @10V | Total gate charge |
| Q_oss | 50 nC | Output charge |
| Q_rr | 30 nC | Body-diode reverse recovery |
| V_f | 0.8 V | Body-diode forward voltage |
| t_r, t_f | 15 ns each | Gate driver ≈1.5A source/sink |
| t_dt | 100 ns | Dead time per edge |
| f_sw | 48 kHz | PWM frequency |
| R_θJC | 1.5 K/W | Junction to case (bottom pad) |

## 1. Conduction Loss Model

### 1.1 Six-step (trapezoidal) commutation with synchronous rectification

At any instant two phases carry current I. During the PWM on-time, the path is HS(leg A) → motor → LS(leg B). During the off-time with active freewheel, the path is LS(leg A) → motor → LS(leg B).

Exactly **two MOSFETs conduct at every instant**, independent of duty D:

$$P_{cond,bridge} = 2\,I^2\,R_{ds}(T_j)$$

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 110 °C:

$$R_{ds} = 1.1\,\text{m}\Omega \times [1 + 0.0045 \times 85] = 1.1 \times 1.383 = 1.52\ \text{m}\Omega$$

$$P_{cond,bridge} = 2 \times 80^2 \times 1.52\times10^{-3} = \mathbf{19.5\ W}$$

### 1.2 Per-device distribution (worst case, D → 1)

Each MOSFET conducts 1/3 of the electrical cycle (120°).

- **HS FET:** $P_{HS} = I^2 R_{ds}\cdot D/3$
- **Paired LS FET in the PWM leg:** $P_{LS,sync} = I^2 R_{ds}(1-D)/3$
- **Fixed-on LS FET:** $I^2 R_{ds}/3$

At D ≈ 1, the per-FET average is 19.5/6 ≈ **3.25 W**, with the hottest FET reaching ~3.3 W.

### 1.3 Electro-thermal convergence

R_ds depends on T_j, so iterate:

$$T_j^{(n+1)} = T_{board} + P_{FET}(T_j^{(n)})\cdot(R_{\theta JC}+R_{\theta,spread})$$

Use R_θ,spread ≈ 4 K/W (thermal vias into the 2 oz inner planes). This converges in 2–3 iterations. Thermal runaway occurs if:

$$\frac{\partial P}{\partial T}\cdot R_\theta \geq 1 \;\Rightarrow\; I^2 R_{ds,25}\,\alpha\, R_\theta\,(2/6)\ge 1$$

That is 6400 × 1.1e-3 × 0.0045 × 5.5 × 0.333 = **0.058**. This is stable with a large margin.

### 1.4 PCB copper loss (often ignored, but not negligible)

Sheet resistance of 2 oz copper (70 µm):

$$R_\square = \frac{1.72\times10^{-8}}{70\times10^{-6}} = 0.246\ \text{m}\Omega/\square$$

With 4 paralleled layers: 0.061 mΩ/□. Assuming ~4 squares for bus + phase path (round trip) per motor, and +30% at temperature:

$$P_{Cu} = 80^2 \times 4 \times 0.061\times10^{-3}\times1.3 \approx \mathbf{2.0\ W}$$

### 1.5 DC-link capacitor ripple

Worst case occurs at D = 0.5:

$$I_{C,rms} = I\sqrt{D(1-D)} = 80\times0.5 = \mathbf{40\ A_{rms}}\ \text{per ESC}$$

ESC PWMs are unsynchronized, so the four channels add in RMS: √4 × 40 = 80 A_rms total.

To size the bulk capacitance, use the switching ripple:

$$\Delta V = \frac{I\,D(1-D)}{C\,f_{sw}}$$
