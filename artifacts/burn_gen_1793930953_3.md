> **Feasibility flag (read first).** Four motors × 80 A from 6S is ~320 A and ~8 kW of input power. A "nano" (20×20 or 25.5×25.5 mm) AIO cannot sustain this. The analysis below shows the realistic burst envelope is a few seconds. Three items will also limit the design before the FETs do:
> 1. **Battery input copper and pads** carrying 320 A.
> 2. **The current-sense shunt**: 320² × 0.25 mΩ = 25.6 W. Use a 0.1 mΩ shunt or a Hall-effect sensor.
> 3. **Bulk capacitor ripple current** (§2.6).
>
> Treat "80 A" as a **≤ 2–5 s burst rating** per motor, not continuous.

## 1. Commutation Topology Model

The model assumes six-step trapezoidal drive with complementary (synchronous) PWM, as in AM32 or BLHeli_32.

- In each 60° electrical sector, phase A's high side (HS) is PWM'd, phase B's low side (LS) is held ON, and phase C floats for back-EMF zero-crossing detection.
- **During ON time,** current flows through HS_A, the motor, then LS_B.
- **During OFF time,** current freewheels through LS_A (synchronous) and LS_B.

At every instant, **two conducting FETs are in series with the load current.** Switching loss occurs in **one hard-switched leg** per sector.

### 1.1 RMS current including PWM ripple

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}}\;\;\xrightarrow{D=0.5}\;\;\frac{25.2\times0.25}{15\,\mu\text{H}\times48\,\text{kHz}} = 8.75\ \text{A}$$

$$I_{rms}^2 = I_{pk}^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 6.4 = 6406\ \text{A}^2$$

Ripple adds only 0.1 %, so it is neglected from here on. 48 kHz is more than adequate for current smoothness.

## 2. Loss Model per ESC Channel at 80 A

### 2.1 Conduction loss, temperature dependent

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

$$P_{cond} = I_{rms}^2 \cdot 2\,R_{ds}(T_j)$$

| T_j | R_ds | P_cond per channel |
|---|---|---|
| 25 °C | 1.20 mΩ | 15.4 W |
| 100 °C | 1.61 mΩ | 20.6 W |
| 125 °C | 1.74 mΩ | **22.3 W** (design value) |

R_ds rises with temperature, which raises loss, which raises temperature. Solve self-consistently:

$$T_j = T_{ref} + R_{\theta}\,P(T_j)$$

### 2.2 Hard-switching V·I overlap loss

Gate currents during the Miller plateau:

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{g,ext}+R_{g,int}} = \frac{6.5}{3.2} = 2.03\ \text{A}$$

$$I_{g,off} = \frac{V_{pl}}{3.2} = 1.09\ \text{A}$$

Switching times:

$$t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = 5.9\ \text{ns}, \qquad t_{off} = \frac{12\,\text{nC}}{1.09\,\text{A}} = 11.0\ \text{ns}$$

Overlap loss:

$$P_{VI} = \tfrac12 V_{bus} I (t_{on}+t_{off}) f_{sw} = \tfrac12(25.2)(80)(16.9\,\text{ns})(48\,\text{k}) = 0.82\ \text{W}$$
