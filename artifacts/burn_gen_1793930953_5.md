# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #24): Electrothermal Model, Bidirectional DShot600 DMA Plan and Reference Netlists

**Document status:** Architecture baseline, Rev A
**Scope:**
- Conduction and switching loss model at 80 A burst and 48 kHz PWM
- Transient thermal model
- ArduPilot bidirectional DShot600 timer and DMA allocation
- Reference netlists

> **Read first: assumptions and design flags**
> 1. **The H743 must not drive the power stage directly.** It has only two advanced-control timers with complementary outputs (TIM1 and TIM8). It cannot run four sensorless 6-step commutation loops at 48 kHz alongside ArduPilot. The architecture is therefore an H743 flight controller plus four independent ESC MCUs (AT32F421 class, running AM32). These are linked by bidirectional DShot600. This matches every production AIO/stack design.
> 2. **"Nano" vs. 80 A.** 80 A per channel is not thermally credible on a 20×20 mm board. This model assumes a **30.5×30.5 mm, 8-layer, 2 oz ESC board** in a stack with the 20×20 or 30×30 flight controller. The math is parameterized, so you can rerun it for other geometries.
> 3. **Example component values are placeholders.** These include Rds(on), Qg, Qrr and Rth. Replace them with values from the selected datasheets before freezing the BOM. Each equation is given symbolically first.
> 4. **Battery:** 6S, V_bus,max = 25.2 V. The FETs are 40 V class, giving about 37 % derating for inductive spikes.
