# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #30 spec sheet, so this design uses the representative values below. Every value is a named constant in the code; replace them with your measured values before tuning.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 class, Cortex-M4F @ 170 MHz, single-precision FPU |
| Motors | GBM2804-class gimbal BLDC, 12N14P, so p = 7 pole pairs, R ≈ 5.6 Ω, L ≈ 1.6 mH, K_t ≈ 0.06 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (MT6701/AS5048), SPI |
| Current sensing | 2-shunt, inline or low-side |
| IMUs | 2× ICM-42688-P on the camera plate, mirror-mounted (IMU2 rotated 180° about z), shared CLKIN |
| Loop rates | PWM 40 kHz center-aligned; current loop 20 kHz; IMU ODR 8 kHz; velocity loop 4 kHz; attitude/angle loop 1 kHz |
