# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #12 specification, so this design states its assumptions explicitly. Every assumption is a single `constexpr` or config field, so you can change any of them in one place.

## 0. Assumed Platform

| Item | Assumption |
|---|---|
| MCU | STM32G4 / H7 class, Cortex-M4F/M7 with single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), phase resistance R ≈ 5–15 Ω |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) on each joint |
| Current sensing | 2-phase low-side shunts, sampled at the PWM center |
| IMU | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, FIFO off, data-ready IRQ |
| Kinematics | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Attitude/angle 1 kHz · IMU 8 kHz |

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = \mathrm{wrap}_{2\pi}\!\big(p\,(\theta_m - \theta_{m,0})\big)$$

Here θ_{m,0} is the encoder offset. It is found once by aligning the rotor with a d-axis current vector.

### 1.2 Clarke transform (power-invariant form not used; amplitude-invariant)

The third phase current follows from Kirchhoff's law, i_c = −i_a − i_b.

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Current PI controllers with decoupling and anti-windup

Each axis x ∈ {d, q} uses a PI controller with the error e_x = i_x^* − i_x.

The raw command is:

$$v_x^{raw} = K_p e_x + I_x + v_x^{ff}$$

The feedforward terms provide cross-coupling decoupling and back-EMF compensation:

$$v_d^{ff} = -\omega_e L_q i_q,\qquad v_q^{ff} = \omega_e L_d i_d + \omega_e \lambda_m$$

The integrator uses back-calculation anti-windup, with K_b ≈ 1/T_i:

$$I_x[k+1] = I_x[k] + K_i T_s e_x + K_b T_s\big(v_x^{sat} - v_x^{raw}\big)$$

The output voltage is limited in a circle, with d-axis priority:
