# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #46 specification, so this design uses the assumptions below. Every one of them is a parameter in the code.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit magnetic encoder per joint (AS5048A / MT6701 class) |
| MCU | Cortex-M4F/M7 with FPU (STM32G474 / H7 class), center-aligned PWM |
| Kinematic chain | Base → **Yaw (ψ)** → **Roll (φ)** → **Pitch (θ)** → camera |
| IMUs | 2× ICM-42688-P **both rigidly on the camera payload**, mounted symmetric about the payload rotation center, SPI |
| Rates | Current loop 20 kHz · IMU ODR 8 kHz · velocity loop 4 kHz · angle loop 1 kHz |

## 1. Inner FOC Current Loop (20 kHz)

### 1.1 Transforms (amplitude-invariant)

Clarke transform:
$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

Park transform, with electrical angle $\theta_e = p\,(\theta_m - \theta_{off})$:
$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.2 Plant and current controller

The PMSM dq model is:
$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)
$$
