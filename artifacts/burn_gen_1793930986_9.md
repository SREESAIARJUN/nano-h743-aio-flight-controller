# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the specification for "Job #23", so this design rests on the assumptions listed in §0. Every parameter is a named constant or struct field. Swap in your real motor, encoder, MCU and geometry values, and the gain formulas re-derive the tuning.

---

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (e.g. GBM2804-class), p = 7 pole pairs, R = 5.6 Ω (phase), L = 1.9 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| Current sense | 2-phase low-side shunts (inline preferred) |
| MCU | STM32G474 @ 170 MHz with FPU and CORDIC (any Cortex-M4F/M7 works) |
| PWM | 20 kHz, center-aligned |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the pitch-axis center of rotation, SPI @ 24 MHz, ODR 8 kHz |

**Loop rates and bandwidths:**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current | 20 kHz | ~1.5 kHz |
| Velocity | 4 kHz | ~150 Hz |
| Angle / stabilization | 1 kHz | ~30 Hz |
| Attitude fusion | 1 kHz (IMU FIFO decimated 8:1 after filtering) | n/a |
