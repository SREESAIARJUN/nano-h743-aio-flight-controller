# STM32H743 Nano AIO with 4-in-1 ESC: Power-Stage and DShot Architecture Model

## 0. Scope and Assumptions

No MOSFET, driver or board stack-up was specified, so every number below rests on the stated **assumed parameters**. Swap in datasheet values and the equations still hold.

There is an architectural point to settle first. An H743 does not commutate the motors directly in any ArduPilot-supported design. The topology is:

```
H743 (ArduPilot) --bidir DShot600--> 4× ESC MCU (AT32F421 / AM32 fw, 48 kHz PWM)
                                     --> 4× FD6288Q 3-phase gate driver --> 24× N-FET
```

The 48 kHz switching frequency is therefore an ESC-firmware parameter (AM32 `PWM_FREQ`). The H743 only generates DShot and captures eRPM telemetry.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Battery (6S, full) | V_bus | 25.2 V |
| Burst phase current | I_pk | 80 A |
| FET R_DS(on) @25 °C, 10 V V_GS | R_25 | 1.0 mΩ (40 V, 3.3×3.3 mm class) |

## 1. Conduction Losses at 80 A Burst

### 1.1 Current path (6-step trapezoidal, synchronous rectification)

At any instant two FETs carry the full phase current:

- **PWM on:** HS(A) + LS(B)
- **PWM off:** LS(A) (synchronous freewheel) + LS(B)

So, independent of duty:

$$P_{cond,ch} = 2\,I^2\,R_{DS}(T_j)$$

$$R_{DS}(T_j) = R_{25}\left[1+\alpha\,(T_j-25)\right] = 1.0\,(1+0.0055\cdot 85) = 1.47\ \text{m}\Omega \approx 1.45\ \text{m}\Omega$$

$$P_{cond,ch} = 2\cdot 80^2\cdot 1.45\times10^{-3} = \mathbf{18.6\ W}\ \text{per motor channel}$$

### 1.2 Per-FET distribution

In 6-step commutation each phase conducts 2/3 of the electrical period. The low-side FET carries current during both its own phase's off-time and as the return leg:

- **Instantaneous per conducting FET:** 80² × 1.45 mΩ = **9.3 W**
- **Average over the commutation cycle:** ≈ 18.6 / 6 ≈ **3.1 W per FET**, with the LS biased higher at low duty.

### 1.3 Ancillary copper losses

- **Shunt** (single 0.25 mΩ DC-link, if used): 80² × 0.25 mΩ = **1.6 W**
- **PCB copper** (2 oz, ~0.3 mΩ effective phase path): ≈ **1.9 W**

## 2. Switching Losses at 48 kHz

**Hard-switching V·I overlap** (one switching FET per channel):

$$P_{VI} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5\cdot25.2\cdot80\cdot40\text{n}\cdot48\text{k} = \mathbf{1.94\ W}$$

**Output capacitance:**

$$P_{oss} = Q_{oss} V_{bus} f_{sw} = 50\text{n}\cdot25.2\cdot48\text{k} = 0.06\ \text{W}$$

**Reverse recovery** (LS body diode recovered by HS turn-on):

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 0.06\ \text{W}$$

**Dead-time body-diode conduction** (two edges per period):

$$P_{dt} = V_F\, I\, (2t_{dt})\, f_{sw} = 0.8\cdot80\cdot200\text{n}\cdot48\text{k} = 0.61\ \text{W}$$

**Gate drive** (two actively PWM'd FETs per channel; dissipated in R_G and the driver):

$$P_g = 2\,Q_g V_{GS} f_{sw} = 2\cdot60\text{n}\cdot10\cdot48\text{k} = 0.06\ \text{W}$$

**Switching subtotal:** ≈ **2.7 W per channel**.

### 2.1 Frequency trade-off

$$P_{sw}(f) \approx 5.6\times10^{-5}\cdot f\ \text{[W]} \quad (\text{at } 80\ \text{A})$$

| 24 kHz | 1.35 W |
