**Scope and assumptions.** No BOM was supplied, so I fixed a reference design. Every number below derives from the stated parameters, so you can substitute datasheet values and re-run the math. The STM32H743 is the flight controller running ArduPilot. Each ESC channel runs its own MCU (AM32/BLHeli_32-class) generating the 48 kHz PWM. The H743 does not drive the gates directly.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha (T_j-25)],\quad \alpha \approx 0.0045\ \text{K}^{-1}$$

At T_j = 125 °C: R_DS = 1.2 × 1.45 = **1.74 mΩ**

### 1.2 Current paths in 6-step synchronous PWM

During each 60° sector, two phases conduct:

- **PWM leg (phase A):** the high-side conducts for D·T_sw. The complementary low-side conducts for (1−D)·T_sw. Current I flows continuously through one of them.
- **Static leg (phase B):** the low-side is fully on and carries I.

$$P_{cond,ch} = I^2R_{DS}\,D + I^2R_{DS}(1-D) + I^2R_{DS} = 2I^2R_{DS}(T_j)$$

This result is **independent of duty cycle**, which is a useful property of synchronous rectification.

$$P_{cond,ch} = 2(80)^2(1.74\times10^{-3}) = \mathbf{22.3\ W\ per\ channel}$$

### 1.3 Copper and interconnect loss

Assume a phase path of ≈ 0.25 mΩ (planes + vias + solder pads) and a bus share of ≈ 0.15 mΩ:

$$P_{Cu} \approx I^2(R_{phase,A}+R_{phase,B}+R_{bus}) = 6400(0.25+0.25+0.15)\times10^{-3} = \mathbf{4.2\ W}$$
