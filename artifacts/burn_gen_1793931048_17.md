# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #12): System Architecture and Analysis

## 0. Scope, Assumptions, and Design Status

Some assumptions shape every number below.

1. **Architecture.** The STM32H743 is the flight controller MCU. It does not commutate the motors. Each ESC channel uses its own commutation MCU, here AT32F421-class running AM32, which supports bidirectional DShot. The H743 sends DShot600 frames and receives eRPM telemetry. This split is the industry-standard topology.
2. **Operating point.** The analysis assumes 6S (25.2 V maximum), 80 A phase current per channel as the burst condition, 48 kHz complementary PWM, and 6-step trapezoidal commutation.
3. **MOSFET parameters.** These are representative values for a 40 V, 3.3 × 3.3 mm PQFN-class device. They are placeholders and must be replaced with datasheet values for the selected part.
4. **Headline finding.** The thermal model shows that 80 A on all four channels simultaneously is a burst rating of about 2 seconds on a 25.5 × 25.5 mm board. It is not a continuous rating. Marketing and documentation should reflect this.

## 2. Conduction Loss Model

### 2.1 Temperature-corrected R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)] = 1.6\,\text{m}\Omega \times [1 + 0.0045 \times 85] = 2.21\ \text{m}\Omega$$

### 2.2 Bridge conduction with 6-step complementary PWM

In every commutation sector, exactly two current paths carry I_ph:

- **PWM leg:** the high-side FET conducts for duty fraction D, and the synchronous low-side FET conducts for (1 − D). Their losses sum to I²R regardless of D, provided dead time is negligible.
- **Static leg:** one low-side FET is fully on for the whole sector.
