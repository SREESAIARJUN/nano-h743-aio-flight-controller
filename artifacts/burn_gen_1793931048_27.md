# STM32H743 AIO Flight Controller with 4-in-1 ESC: Design Model (Job #16)

Assumptions are stated explicitly so each number can be re-derived with real datasheet values. The part numbers below are representative choices, not validated selections. Before layout, every parameter marked **[DS]** must be replaced with the selected component's datasheet value.

---

## 0. Feasibility Issues

1. **Per-motor 80A burst cannot be done on a 20×20 mm "nano" board.** 20×20 4-in-1 ESCs use 24× DFN3x3 FETs (≈2.5–4 mΩ). At 80A, conduction loss alone would be about 50–75 W per motor with almost no thermal mass. This design therefore assumes:
   - a **30.5×30.5 mm mounting pattern** (about 36×36 mm board),
   - **DFN5x6 FETs**,
   - **80A defined as per-motor phase current, burst ≤5 s**.
   
   If "nano" is a hard constraint, the rating must be re-scoped to about 35–40A burst.
2. **The H743 does not drive the MOSFETs.** ArduPilot has no motor-commutation firmware. The architecture is:
   - H743 (ArduPilot) sends bidirectional DShot600 to 4× ESC MCUs (AT32F421, AM32 firmware).
   - Each ESC MCU drives a 3-phase gate driver (FD6288Q), which drives 6 FETs.
3. The thermal results below show that **80A on all four motors simultaneously is time-limited to about 7 s**. Firmware current limiting is mandatory, not optional.

## 2. Conduction Loss Model

**Commutation scheme:** 6-step trapezoidal with complementary (synchronous) PWM on the high-side leg. In every sector, current flows through exactly one high-side and one low-side channel in series. The PWM leg alternates between its HS FET (duty D) and its synchronous LS FET (1−D).

Per motor, independent of D:

$$P_{cond}=I_{ph}^2\cdot 2\cdot R_{DS}(T_j),\qquad R_{DS}(T_j)=R_{25}\left[1+\alpha(T_j-25)\right]$$

At T_j = 125 °C with typical R_25:

$$R_{DS}=1.2\,\text{mΩ}\cdot(1+0.0045\cdot100)=1.74\,\text{mΩ}$$
$$P_{cond}=80^2\cdot2\cdot1.74\,\text{mΩ}=\mathbf{22.3\ W/motor}$$
