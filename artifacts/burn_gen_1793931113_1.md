# STM32H743 Nano FC + 4-in-1 80A ESC: Systems Architecture Package (Job #61)

## 0. Scope, Assumptions, and Up-Front Findings

I don't have the Job #61 requirements file, so I defined a baseline that matches the request. Every derived number is parametric: if you substitute your actual MOSFET datasheet values, the model still holds.

**Architecture assumption (important).** On a production 4-in-1 stack, the STM32H743 does not drive the MOSFETs directly. It runs ArduPilot and sends bidirectional DShot600 to four ESC MCUs (e.g., AT32F421 or STM32G071 running AM32). Each ESC MCU generates the 48 kHz complementary PWM. That is the partitioning modelled below. Driving 24 FETs at 48 kHz from the H743 alongside an EKF is possible but not recommended.

| Parameter | Value |

| MOSFET (per switch) | 40 V, R_DS(on) = 1.0 mΩ typ @ 25 °C, Q_g = 50 nC, Q_gd = 10 nC, Q_rr = 40 nC, Q_oss = 50 nC, R_θJC = 1.5 K/W, V_SD = 0.8 V |

**Headline findings:**
1. **Total ESC dissipation at 80 A on all four channels is about 85–90 W.**
2. **On a small board this is a time-limited burst rating of roughly 4–6 seconds, not a continuous one.** The continuous capability under prop-wash cooling alone is about 25–30 A per channel.
3. The bidirectional DShot600 allocation fits cleanly on a single advanced timer (TIM1) using 5 DMA streams.

## 1. Conduction Loss Model

### 1.1 Current path per commutation step

In any 6-step sector, phase A is PWM'd (high-side/low-side complementary), phase B's low-side is held ON, and phase C floats.

- **During t_on (duty D):** current flows V+ → HS_A → motor → LS_B → GND. Two FETs conduct.
- **During t_off (1−D):** current recirculates LS_A → motor → LS_B. Two FETs conduct (synchronous rectification).

So at every instant, exactly two FET channels carry the phase current:

$$P_{cond,ch} = I_{rms}^2 \left[ D\,R_{HS} + (1-D)\,R_{LS} + R_{LS} \right] = 2\,I_{rms}^2\,R_{DS(on)}(T_j) \quad (R_{HS}=R_{LS})$$

This is independent of D, which is the advantage of synchronous rectification.

### 1.2 Temperature dependence of R_DS(on)

$$R_{DS(on)}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)],\quad \alpha \approx 0.0045\ \text{K}^{-1}\ (\text{40 V trench, verify against datasheet curve})$$

At T_j = 110 °C:

$$R = 1.0\,(1 + 0.0045 \times 85) = 1.38\ \text{mΩ} \rightarrow \text{use } 1.45\ \text{mΩ with tolerance margin}$$

### 1.3 RMS current including ripple

$$I_{rms} = \sqrt{I_{DC}^2 + \frac{\Delta I_{pp}^2}{12}},\qquad \Delta I_{pp} = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

For a typical 5" or 7" motor (L_ph ≈ 15 µH line-to-line) at high throttle (V_bus − V_bemf ≈ 3 V, D ≈ 0.9):

$$\Delta I_{pp} = \frac{3 \times 0.9}{15\,\mu \times 48\,k} = 3.75\ \text{A} \Rightarrow I_{rms} = 80.007\ \text{A}$$

Ripple is negligible at 48 kHz, so use I_rms = 80 A.

### 1.4 Results

$$P_{cond,ch} = 2 \times 80^2 \times 1.45\,\text{mΩ} = 18.56\ \text{W}$$

**PCB copper loss.** The bus-to-phase path is about 0.3 mΩ (plane, vias, and pads):

$$P_{Cu,ch} = 80^2 \times 0.3\,\text{mΩ} = 1.92\ \text{W}$$

**Per-FET average.** Over an electrical revolution, each FET carries current for about 1/3 of the period:

$$\bar P_{FET} \approx 9.28\ \text{W} \times \tfrac{1}{3} \approx 3.1\ \text{W}$$

## 2. Switching Loss Model at 48 kHz

Only one half-bridge per channel switches at f_sw in each sector.

### 2.1 V–I overlap loss

Gate current at the Miller plateau (V_pl ≈ 3.5 V):

$$I_g = \frac{V_{drv} - V_{pl}}{R_{g,ext} + R_{g,int} + R_{drv}} = \frac{10 - 3.5}{2.2 + 1.0 + 1.5} \approx 1.4\ \text{A}$$

Rise/fall times, including the Q_gs2 contribution and layout inductance:

$$t_r \approx t_f \approx \frac{Q_{gd} + Q_{gs2}}{I_g} \approx \frac{10 + 7}{1.4}\ \text{nC/A} \approx 12\ \text{ns}$$

$$P_{VI} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 24\,\text{ns} \times 48\,\text{kHz} = 1.16\ \text{W}$$

### 2.2 Dead-time body-diode conduction

$$P_{DT} = V_{SD}\,I\,(2\,t_{dead})\,f_{sw} = 0.8 \times 80 \times 200\,\text{ns} \times 48\,\text{k} = 0.61\ \text{W}$$

This is the second-largest switching term. Tuning dead time down to about 50 ns (AM32 permits this) halves it.
