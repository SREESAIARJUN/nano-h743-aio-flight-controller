## 0. Assumptions & Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (N_slots = 12, p = 7 pole pairs) |
| Encoder | 14-bit absolute magnetic (e.g. AS5048A / MT6701) on each axis |
| Driver | 3-phase inverter, low-side shunts, center-aligned PWM at 20 kHz |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| IMU A (camera plate) | ICM-42688-P, gyro ODR 8 kHz, used for **feedback** |
| IMU B (handle/base) | ICM-42688-P, gyro ODR 8 kHz, used as **vibration reference + feedforward** |
| Mechanical order | Yaw (base) → Roll → Pitch (camera) |

**Rate hierarchy** (each loop ≥ 5× the bandwidth of the loop outside it):

```
 20 kHz  ── Current loop (FOC: Clarke/Park, PI d/q, SVPWM)
  4 kHz  ── Velocity loop (PI + cogging FF + base-rate FF)
  1 kHz  ── Angle loop (P/PI on attitude error)
  8 kHz  ── IMU sampling → AAF → dynamic notch → LMS canceller → decimate to 4 kHz
  1 kHz  ── Attitude estimator (Mahony quaternion)
```

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

Clarke transform, amplitude-invariant, with $i_a + i_b + i_c = 0$:

$$i_\alpha = i_a, \qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e, \qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model (Surface PMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.3 Current PI Design (Pole–Zero Cancellation)

The decoupled plant is $G_i(s) = \dfrac{1}{Ls + R}$. With the controller $C_i(s) = K_p + K_i/s$ and the gains chosen so the controller zero cancels the plant pole:

$$K_{p,i} = L\,\omega_{ci}, \qquad K_{i,i} = R\,\omega_{ci}$$

The closed loop then becomes first-order, $\dfrac{\omega_{ci}}{s + \omega_{ci}}$.

**Bandwidth limit.** Choose $\omega_{ci} \le 2\pi f_{\text{PWM}}/20$. At 20 kHz PWM this gives $\omega_{ci} \approx 2\pi \cdot 1\text{ kHz}$, which accounts for the 1.5-sample computation + PWM delay.

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L i_q, \qquad v_q^{ff} = \omega_e(L i_d + \lambda_m)$$

**Voltage limiting.** The vector magnitude is limited to $|v_{dq}| \le V_{dc}/\sqrt3$ (the linear SVPWM region). $v_d$ has priority so field control is preserved:

$$v_{q,\max} = \sqrt{(V_{dc}/\sqrt3)^2 - v_d^2}$$
