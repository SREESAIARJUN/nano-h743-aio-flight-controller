# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual ICM-42688-P Fusion

I don't have the Job #4 spec sheet, so this design uses the assumptions listed in §0. Every parameter is exposed as a configuration field, so you can substitute your actual motor and board values without changing the structure.

## 0. Assumptions and Timing Architecture

| Item | Assumption |
|---|---|
| Motors | 3× PMSM gimbal motors (e.g. GBM2804-class), 7 pole pairs, 12N14P, R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701), SPI |
| Current sense | 2-phase low-side shunts, synchronous ADC sampling at PWM center |
| IMU A | ICM-42688-P on the camera plate. It provides feedback (the stabilized body). |
| IMU B | ICM-42688-P on the base/handle. It is the disturbance reference for feedforward and adaptive cancellation. |
| MCU | Cortex-M4F/M7 (STM32G4/H7), single-precision FPU |

**Loop rates** (each outer loop runs at least 5× slower than the loop it commands):

```
PWM / current loop (FOC)      : 20 kHz   (Ts_i = 50 µs)   ISR, ADC-triggered
Velocity loop (inertial rate) :  4 kHz   (Ts_v = 250 µs)  every 5th current ISR
IMU ODR / filtering           :  8 kHz   gyro, 1 kHz accel (FIFO drained at 4 kHz)
Angle loop + attitude filter  :  1 kHz   (Ts_a = 1 ms)
Anti-cogging adaptation       : 4 kHz    (inside velocity loop, gated)
```

**Key architectural decision:**
- The **encoder** is used for commutation (electrical angle) and joint-angle kinematics.
- The **camera gyro (IMU A)** closes the velocity loop. This gives inertial stabilization.
- **IMU B** supplies a base-motion feedforward and serves as the reference for adaptive vibration cancellation.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical model (dq frame)

$$
v_d = R\,i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R\,i_q + L_q\frac{di_q}{dt} + \omega_e L_d i_d + \omega_e\lambda_m
$$

$$
\tau_e = \tfrac{3}{2}p\left[\lambda_m i_q + (L_d-L_q)i_d i_q\right]\;\approx\; K_t\, i_q,\qquad K_t=\tfrac32 p\lambda_m
$$

Gimbal motors are surface-mounted, so $L_d\approx L_q=L$ and the reference is $i_d^\*=0$.

### 1.2 Transforms

**Clarke (amplitude-invariant, with $i_a+i_b+i_c=0$):**

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park,** with $\theta_e = p(\theta_m-\theta_{off})$:

$$
\begin{bmatrix}i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park:**

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

**Delay compensation.** The PWM update lags the sample by about 1.5 Ts, so the inverse Park uses an advanced angle:

$$
\theta_e' = \theta_e + 1.5\,\omega_e T_{s,i}
$$
