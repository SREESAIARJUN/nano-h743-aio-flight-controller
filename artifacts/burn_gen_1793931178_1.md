# Job #21: 3-Axis Gimbal FOC Control Loop and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #21 specification, so this design uses the defaults below. Every value is a `constexpr` or config field in the code, so it can be retargeted.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), 3 × 3-shunt inverters |
| Motors | GM4108-class gimbal BLDC, 24N22P (p = 11 pole pairs), R ≈ 5–11 Ω, L ≈ 2–4 mH |
| Joint encoders | 14-bit magnetic (AS5048A / MT6835), SPI |
| IMU0 | ICM-42688-P on the camera plate (attitude/rate **feedback**) |
| IMU1 | ICM-42688-P on the handle/frame (**disturbance feedforward** and **vibration reference**) |
| Loop rates | Current 20 kHz · IMU and filters 8 kHz · Rate loop 4 kHz · Attitude loop 1 kHz |
