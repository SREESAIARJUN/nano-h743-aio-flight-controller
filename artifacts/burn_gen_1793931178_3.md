# Job #61: 3-Axis Gimbal FOC Control and Dual-IMU Fusion Design

This design covers the FOC current loop, cascaded angle/velocity control, anti-cogging feedforward, and dual ICM-42688-P vibration rejection. It ends with a full C++ implementation.

## 0. Assumptions

I have no prior context for Job #61, so these are the assumptions. Each one is marked in the code as a `constexpr` or config field you can change.

| Item | Assumption |
|---|---|
| Motors | 3× BLDC gimbal motors, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensing | 14-bit absolute magnetic encoder per joint (e.g., AS5047P/MT6701) |
| Gimbal kinematics | Yaw (ψ) → Roll (φ) → Pitch (θ), camera on pitch stage |
| IMUs | 2× ICM-42688-P on the camera stage, separate SPI buses, gyro ODR 8 kHz, ±2000 dps, accel ±16 g |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class), center-aligned PWM |
| Loop rates | Current/FOC 20 kHz · velocity 4 kHz · attitude/angle 1 kHz · cogging learning 1 kHz |

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi,\qquad \omega_e = p\,\omega_m$$

Here θ₀ is the encoder offset, found once by aligning the rotor with V_d at θ_e = 0.

**Latency compensation.** The PWM update is applied about 1.5 samples after the encoder read:
$$\hat\theta_e = \theta_e + \omega_e\,(1.5\,T_s)$$
