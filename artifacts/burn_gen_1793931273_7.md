# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

**Assumptions (adjust to your hardware).** The original "Job #0" spec was not provided, so this design assumes a typical brushless gimbal:

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (e.g. GBM2804H), R ≈ 10 Ω, L ≈ 2.5 mH, Kt ≈ 0.06 N·m/A |
| Encoders | 14-bit absolute magnetic (MT6701/AS5048A) per axis |
| MCU | STM32G4 @ 170 MHz, FPU, 3 × center-aligned PWM, injected-ADC current sensing (2 or 3 shunts) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz, ±2000 dps / ±4 g |
| Axis order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

---

## 1. Loop Architecture and Timing

```
               1 kHz                      4 kHz                20 kHz
 q_ref ──► [Attitude / Angle P+FF] ──► [Velocity PI+FF] ──► [Current PI dq] ──► SVPWM ──► Inverter
              ▲   ▲                       ▲    ▲                ▲
   Mahony att.│   │ J⁻¹(q)        ω_joint │    │ i_q,cog (FF)   │ i_a,i_b (ADC), θ_e (encoder)
              │   └── dual-IMU gyro ──────┘    └─ anti-cogging (Fourier LMS)
        dual ICM-42688-P (8 kHz) → AAF → dyn. notch → fusion → Mahony
```

Each loop is separated from the next by at least 5× in bandwidth:

- Current loop: f_c ≈ 2 kHz.
- Velocity loop: f_v ≈ 150–300 Hz.
- Angle loop: f_p ≈ 20–40 Hz.
