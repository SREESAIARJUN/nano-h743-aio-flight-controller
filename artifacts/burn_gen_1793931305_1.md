# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal (Job #60)

I don't have the Job #60 spec sheet, so the motor, sensor and MCU parameters below are **stated assumptions**. They are kept in one config block so you can replace them with your measured values. All gains are derived from those parameters rather than hand-tuned, so the equations remain valid when the numbers change.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, FPU, 3× ADC injected-sync to TIM1 center-aligned PWM |
| Motor (per axis) | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.6 Ω, L = 2.4 mH, K_t = 0.085 N·m/A |
| Encoder | 14-bit magnetic (MT6701 / AS5048A), SPI, read every PWM cycle |

**Loop rates and target bandwidths.** Each loop runs at roughly 5–10× the bandwidth of the loop outside it.

| Loop | Rate | Closed-loop BW | Feedback |
|---|---|---|---|
| Current (FOC, d/q PI) | 20 kHz (ADC ISR) | 1.5 kHz | Phase currents + encoder |
| Velocity (PI + anti-cogging FF) | 4 kHz | 120 Hz | Fused payload gyro projected on joint axis |
| Angle (P + rate FF) | 1 kHz | 25 Hz | Fused attitude estimate |
| IMU filtering / fusion | 8 kHz in, 4 kHz out | — | 2× ICM-42688-P |

```
θ_ref ─→[Angle P]─ω_ref─→[Velocity PI]─i_q,fb─(+)─i_q*─→[Current PI d/q + decoupling]→ SVPWM → motor
                                       anti-cogging FF(θ_m) ┘
```

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

Use amplitude-invariant transforms with electrical angle θ_e = p·(θ_m − θ_offset).

**Clarke transform** (two measured currents, with i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)
$$

**Park transform:**

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park transform:**

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$
