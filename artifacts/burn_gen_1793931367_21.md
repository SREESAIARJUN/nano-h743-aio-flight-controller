# STM32H743 Nano AIO with 4-in-1 ESC: Power-Stage Loss Model, Thermal Analysis, and Bidirectional DShot600 Allocation

**Revision: A (first-pass architecture)**

## 0. Scope and Assumptions

I don't have the Job #43 requirements file, BOM, or stackup. Every number below comes from a stated assumption. Replace the parameters in §1 with your real datasheet values and the equations will carry through. Treat the numbers as engineering estimates, not sign-off values.

### Architecture correction (important)

The STM32H743 does not drive the MOSFETs. ArduPilot does not run ESC commutation firmware.

- **H743 role:** It runs ArduPilot and sends bidirectional DShot600 commands.
- **Commutation:** Four dedicated ESC MCUs handle it, one per motor. I assume AT32F421 running AM32. A single-MCU AM32 4-in-1 design is not supported.
- **Model mapping:** The thermal and switching model applies to the ESC side. The DMA and timer model applies to the H743 side.

### Feasibility red flag up front

"80 A burst" on a nano-format board (20×20 or 25.5×25.5 mm) is not thermally achievable for more than about 1–2 seconds per motor. §4 derives this. If 80 A is a *total* (4×20 A) rating, the design closes comfortably. **Confirm which it is before layout.**

## 2. Conduction Loss Model

### 2.1 Current paths

In 6-step trapezoidal drive with complementary (synchronous) PWM, which is the AM32 default, two phases conduct at any instant:

- **PWM leg:** The high-side FET conducts for D·T. Its synchronous low-side FET conducts for (1−D)·T.
- **Return leg:** The low-side FET is on continuously.

The PWM-leg pair therefore always carries I² regardless of duty:

$$P_{cond,pair} = D\,I^2R_{ds}(T) + (1-D)\,I^2R_{ds}(T) = I^2R_{ds}(T)$$

Per motor:

$$P_{cond} = 2\,I_{rms}^2\,R_{ds}(T_j) + I_{rms}^2\,R_{trace}$$

Including PWM current ripple (peak-to-peak ripple ratio r = ΔI/I):

$$I_{rms}^2 = I^2\left(1+\tfrac{r^2}{12}\right)$$

With r ≈ 0.3, this correction is under 1%, so it is ignored below.

### 2.2 Temperature dependence

$$R_{ds}(T_j) = R_{ds25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R_ds = 1.5 × 1.6 = **2.4 mΩ**

### 2.3 Result at 80 A

| Condition | Calculation | Loss |
|---|---|---|
| T_j = 125 °C | 2 × 6400 × 0.0024 | 30.7 W |
| Trace copper | 6400 × 0.0004 | 2.6 W |
| **Per motor** | | **≈ 33.3 W** |
| T_j = 25 °C (start of burst) | 2 × 6400 × 0.0015 + 2.6 | 21.8 W |

### 2.4 Thermal-runaway stability criterion

$$\frac{dP_{cond}}{dT_j}\cdot R_{th,ja} < 1 \quad\Rightarrow\quad 2I^2R_{ds25}\,\alpha\,R_{th,ja} < 1$$

At 80 A: dP/dT = 2 × 6400 × 0.0015 × 0.006 = 0.115 W/K.

Stability therefore requires R_th,ja < 8.7 K/W per motor pair. That is met on paper. The issue is not runaway but absolute temperature (§4).

## 3. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. The high-side FET switches hard, and the low-side FET commutates through its body diode during dead time.

### 3.1 V·I overlap loss

Gate currents during the Miller plateau:

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{drv,on}+R_g} = \frac{7}{7} = 1.0\ \text{A}$$
