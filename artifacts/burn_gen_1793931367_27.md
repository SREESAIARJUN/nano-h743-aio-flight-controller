# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #48): Design Derivation

## 0. Architecture Decisions and Feasibility Flags

Three issues shape the rest of this document.

1. **The H743 does not commutate the motors.** ArduPilot is not an ESC firmware, and a single H7 running four sensorless FOC/trapezoidal loops beside the flight stack is not a supportable design. The architecture is therefore:
   - **H743**: ArduPilot FC. Emits bidirectional DShot600 to four on-board ESC MCUs.
   - **4× AT32F421K8U7** (or STM32G071): run AM32, with 48 kHz PWM configured in the ESC firmware.
   - **4× FD6288Q**: 3-phase gate drivers.
   - **24× N-MOSFETs**.
2. **80 A per motor on a "nano" (20×20 mm) board is not thermally achievable**, even as a burst. Section 3 shows the result: about 2 s at 4×80 A even on a 30×30 mm, 6-layer, 2 oz board. Everything below assumes a **30×30 mm, 6-layer, 2 oz** board and treats 80 A as a **≤2 s burst**. Continuous rating comes out around 30 A per motor.
3. **MOSFET parameters are representative 40 V DFN5×6-class values.** Replace them with datasheet values for the selected part before sign-off. The equations are the deliverable; the numbers illustrate them.

| Parameter | Symbol | Value |

## 1. Conduction Loss Model

**Trapezoidal 6-step with synchronous (complementary) PWM**, as used by AM32 in its default complementary mode. In each commutation sector, one leg is PWM-ing and another leg's low-side FET is held on:

- PWM leg high-side conducts for D·T.
- PWM leg low-side conducts during freewheel, for (1−D)·T.
- The opposite leg's low-side conducts for T.

$$P_{cond} = I^2 R_{DS}(T_j)\,[D + (1-D) + 1] = 2\,I^2 R_{DS}(T_j)$$

This loss is **independent of duty cycle**, which is a useful property for burst analysis.

Temperature dependence:

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

At T_j = 110 °C: R_DS = 1.5 mΩ × 1.4675 = **2.20 mΩ**.

$$P_{cond} = 2 \cdot 80^2 \cdot 2.20\times10^{-3} = \mathbf{28.2\ W\ per\ channel}$$

**Thermal runaway check.** The loop gain is

$$G = \frac{\partial P}{\partial T}\,R_{th} = 2I^2 R_{25}\,\alpha\,R_{th}$$

With 2·6400·1.5e-3·0.0055·R_th = 0.106·R_th, the loop is stable only if R_th < 9.4 K/W. The board-level R_th must stay well below this.
