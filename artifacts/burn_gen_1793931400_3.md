# STM32H743 Nano FC + 80A 4-in-1 ESC: Design Model (Job #12)

## 0. Scope and Stated Assumptions

No MOSFET, gate driver, board size or battery voltage was specified, so the model below uses parameterized equations evaluated against a representative design point. **Substitute your datasheet values before signoff.**

**Architecture note.** In ArduPilot-class hardware, the STM32H743 runs the flight controller. Each ESC channel runs its own MCU (AT32F421 / STM32G071 class running AM32 or BLHeli_32). The H743 generates bi-directional DShot and decodes eRPM telemetry. It does not drive gates. The model reflects that split.
