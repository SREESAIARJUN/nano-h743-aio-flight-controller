# STM32H743 FC + 4-in-1 ESC Stack (Job #18): System Architecture & Mathematical Model

**Document scope:** This covers electrothermal modelling of the ESC power stage, switching losses at f_sw = 48 kHz, ArduPilot bi-directional DShot600 timer/DMA allocation on the STM32H743, and reference netlists.

**Status:** This is an engineering model built from stated assumptions. It is not a verified design. Every device parameter marked ⚠ must be replaced with values from the selected part's datasheet before layout sign-off. The netlists are representative and must be checked against ERC/DRC in your EDA tool.

---

## 0. Architecture Decision (read first)

The STM32H743 should **not** commutate the motors directly. ArduPilot does not run BLDC sensorless commutation. Also, the H743 has only two advanced-control timers (TIM1, TIM8), so it can drive at most two complementary 3-phase bridges natively.

The correct partition is:

```
                ┌──────────────────────── FC (STM32H743VIT6, 400–480 MHz) ───────────────────────┐
 IMU(SPI1) ─────┤ ArduPilot  │ TIM1 CH1..CH4 ── DShot600 bidir (1-wire, half-duplex per motor) ──┼──┐
 Baro(I2C/SPI)──┤            │ ADC: VBAT, IBAT                                                   │  │
                └────────────────────────────────────────────────────────────────────────────────┘  │
                                                                                                    ▼
    ┌─────────────── ESC board: 4 × [ESC MCU (AM32/BLHeli_32-class) + 3-ph gate driver + 6 FETs] ───────────────┐
    │ ESC MCU (e.g. AT32F421 / STM32G071 ⚠) : 48 kHz complementary PWM, BEMF zero-cross, DShot decode + eRPM reply │
    └───────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

**"Nano" form-factor warning.** Treating 80 A as a per-channel *burst* rating on a 20×20 or 30×30 mm 4-in-1 board is thermally feasible only for short durations of a few seconds (Section 3). The continuous rating will be far lower unless the board has strong airflow. The model below quantifies this.

## 2. Loss Model per ESC Channel

### 2.1 Conduction topology

The ESC uses trapezoidal 6-step drive with complementary (synchronous-rectified) PWM:

- At any instant, current flows through one high-side path and one low-side path. These are two series FETs.
- In the PWM'd leg, the current alternates between the HS FET (duty D) and the LS FET (1−D) of the same leg.
- In both cases, the current path has exactly **two R_DS(on) in series**.

So the instantaneous conduction loss is independent of D:

$$
P_{cond}(T_j) = 2\, I^2\, R_{ds,25}\,\kappa(T_j) + I^2 R_{cu}
$$

**Electrothermal coupling.** Because R_DS(on) rises with T_j, solve iteratively:

$$
T_j = T_{pcb} + \Delta T_{j\text{-}pcb},\qquad \kappa(T_j)=1+\alpha (T_j-25)
$$

**Numbers at I = 80 A:**

| T_j | κ | 2·I²·R_ds | I²·R_cu | **P_cond** |
|---|---|---|---|---|
| 25 °C | 1.00 | 15.36 W | 2.24 W | 17.6 W |
| 100 °C | 1.34 | 20.5 W | 2.6 W* | 23.1 W |
| 125 °C | 1.45 | 22.3 W | 2.7 W* | 25.0 W |

*Copper TCR is +0.39 %/K. It is included at the PCB temperature.
