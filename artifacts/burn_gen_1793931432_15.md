# STM32H743 Nano FC + 4-in-1 ESC (Job #62): Power-Stage and DShot Architecture Package

## 0. Architectural Clarifications (Read First)

Three points need to be resolved before the numbers mean anything.

**1. The H743 does not commutate the motors.**
- ArduPilot is a flight-control stack. It has no six-step or FOC commutation code.
- The architecture is therefore an **H743 flight controller** sending bi-directional DShot600 to **four ESC MCUs**.
- Each ESC MCU (AT32F421 / STM32G071-class, running AM32 or BLHeli_32) generates the 48 kHz PWM.
- Section 3 covers the H743 side. Sections 1–2 cover the ESC power stage.
