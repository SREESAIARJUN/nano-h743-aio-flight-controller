## 0. Assumptions and Rate Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (e.g., GBM2804-class), 7 pole pairs, 12N14P |
| Phase R, L | R = 5.0 Ω, L = 1.8 mH (line-neutral) |
| Torque constant | K_t ≈ 0.08 N·m/A (measure it) |
| Position sensor | 14-bit magnetic encoder (AS5048A/MT6701) per axis |
| IMUs | 2× ICM-42688-P on the camera plate (IMU A, IMU B), SPI at 24 MHz |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7) |
| Supply | 12–16 V, center-aligned PWM at 20 kHz |

**Loop timing (each loop is integer-divided from the PWM interrupt):**

```
PWM ISR 20 kHz  ── current loop (FOC: Clarke/Park/PI/SVPWM) + cogging FF
   └ /5   4 kHz ── velocity loop (PI) + gyro filtering
        └ /4  1 kHz ── angle loop (P + FF) + attitude estimation
IMU ODR 8 kHz (DRDY → DMA), decimated into the 4 kHz velocity loop
```

**Bandwidth separation rule:** each outer loop should be at least 5–10× slower than the loop inside it.
- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·150 rad/s
- Angle loop: ω_θ ≈ 2π·20 rad/s

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

The electrical angle is θ_e = p·(θ_m − θ_offset), where p is the number of pole pairs.

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model (Surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

$$\tau = \tfrac32\, p\, \lambda_m\, i_q = K_t\, i_q$$

### 1.3 Current PI Controller with Decoupling (Pole–Zero Cancellation)

Choose the PI zero so that it cancels the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L i_d + \hat\lambda_m)$$

With the assumed values (ω_c = 2π·1500 rad/s, L = 1.8 mH, R = 5 Ω):
- K_p ≈ 17 V/A
- K_i ≈ 47 000 V/(A·s)

Set i_d* = 0 (no field weakening is needed for gimbal speeds).

### 1.4 Voltage Limiting and SVPWM

**Circular limit.** The maximum voltage is |v|_max = V_bus/√3. When the vector exceeds it, scale v_q first, keeping v_d priority:

$$v_q^{lim} = \operatorname{sign}(v_q)\sqrt{|v|_{max}^2 - v_d^2}$$

**SVPWM via min/max zero-sequence injection.** This is equivalent to sector-based SVPWM:

$$v_{a,b,c}=\text{InvClarke}(v_\alpha,v_\beta),\quad v_0=-\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big)$$

$$d_x=\tfrac12+\frac{v_x+v_0}{V_{bus}}$$

### 1.5 Discretization and Anti-Windup

**Discrete PI** (backward Euler integrator, sample time T_s):

$$u_k = K_p e_k + I_k$$

**Back-calculation anti-windup**, applied after saturation sat(·):

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}T_s\big(\text{sat}(u_k)-u_k\big),\qquad K_{aw}\approx K_i/K_p$$

**Angle compensation for transport delay.** The PWM update lags the sample by about 1.5 T_s. Advance the angle used in the inverse Park transform by:

$$\theta_e^{inv} = \theta_e + 1.5\,\omega_e T_s$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical Plant per Axis

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

### 2.2 Velocity Loop (PI on Gyro Rate, 4 kHz)

**Feedback signal.** The velocity loop is closed on the **filtered gyro rate projected onto the joint axis**, not on the differentiated encoder. Inertial stabilization requires this:

$$\omega_{fb} = \mathbf{a}_j^\top\, \boldsymbol\omega_{cam}^{filt}$$

Here **a**_j is the joint axis expressed in the camera frame (see §2.5).

**Control law:**

$$i_q^* = \underbrace{K_{p,v} e_\omega + K_{i,v}\!\int e_\omega}_{\text{PI}} + \underbrace{\frac{\hat J}{K_t}\dot\omega^*}_{\text{accel FF}} + \underbrace{\frac{\hat\tau_{cog}(\theta)}{K_t}}_{\text{cogging FF (§3)}}$$

**Tuning.** With the current loop treated as unity, the plant from i_q to ω is K_t/(Js). Place the crossover at ω_v and the PI zero at ω_v/4:

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{4}$$

**Filtering requirement.** The gyro filter chain (§4) must contribute less than about 20° of phase lag at ω_v. Budget it explicitly:

$$\phi_{filters}(\omega_v)=\sum_i \angle H_i(j\omega_v)$$
