# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

## 0. Assumptions

I don't have the Job #56 specification, so every numeric value below is a placeholder. Each one appears exactly once, in `GimbalConfig`, so you can replace it with your measured motor and frame parameters.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, CORDIC optional |
| Motors | Gimbal BLDC (e.g. GBM2804): 12N14P, pole pairs p = 7, R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| IMUs | 2 × ICM-42688-P on separate SPI buses, gyro and accel ODR = 8 kHz, ±2000 dps, ±16 g |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, camera). Both IMUs are on the camera plate. |

Loop rates:

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | 20 kHz | ADC-injected end-of-conversion ISR, center-aligned PWM |
| Velocity | 4 kHz | — |
| IMU filter/fusion | 8 kHz | — |
| Attitude/angle | 1 kHz | — |
