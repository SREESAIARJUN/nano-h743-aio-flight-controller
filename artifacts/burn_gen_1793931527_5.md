# STM32H743 FC + 4-in-1 80A ESC: Thermal, Switching, and Bidirectional DShot600 Model

## 0. Scope and Assumptions

### 0.1 Architecture

In ArduPilot systems the STM32H743 does **not** commutate the motors. ArduPilot runs on the H743 and sends DShot600 to four ESC MCUs (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32). Each ESC MCU generates 48 kHz complementary PWM. The model is split accordingly:

| Domain | Device | This document |
|---|---|---|
| Flight control, DShot generation, eRPM capture | STM32H743 (ArduPilot) | §4, §5 |
| Commutation, 48 kHz PWM, gate drive | 4 × ESC MCU + 3-phase gate driver | §1–3, §5 |
| Power stage | 4 × 6 N-ch MOSFETs (40 V class) | §1–3 |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Commutation Topology

The model assumes trapezoidal six-step commutation with synchronous (complementary) PWM on the high side. Over one electrical period, each leg spends:

- **1/3 of the period PWM-active:** the HS conducts for fraction D, the LS conducts for 1−D (synchronous rectification).
- **1/3 of the period LS-on:** the LS conducts 100% as the return path.
- **1/3 of the period floating:** this phase is used for BEMF sensing.

### 1.2 Per-Leg Average Loss

Let R(T) = R_ds25 · [1 + α(T_j − 25)].

$$P_{HS} = \tfrac{1}{3}\,D\,I_{rms}^2\,R(T_j)$$

$$P_{LS} = \tfrac{1}{3}(1-D)\,I_{rms}^2\,R(T_j) + \tfrac{1}{3}\,I_{rms}^2\,R(T_j)$$

### 1.3 Per-Channel Total

Summing over three legs, the D terms cancel:

$$\boxed{P_{cond,ch} = 2\,I_{rms}^2\,R(T_j)}$$

This is independent of duty: two FETs carry the phase current at every instant.

### 1.4 Ripple Correction

The peak-to-peak ripple current is:

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{f_{sw}\,L_{LL}}$$

Worst case is D = 0.5:

$$\Delta I_{pp} = \frac{25.2 \times 0.25}{48\text{k} \times 20\mu} = 6.56\ \text{A}$$

The RMS current then becomes:

$$I_{rms}^2 = I^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 3.6 \approx 6404\ \text{A}^2$$
