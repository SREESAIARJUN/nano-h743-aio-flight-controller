## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC 12N14P (pole pairs p = 7, slots Nₛ = 12), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) on each joint |
| Current sensing | 2-phase low-side shunts (a voltage-mode fallback is provided) |
| PWM / current loop | 20 kHz, center-aligned, ADC triggered at the counter peak |
| Velocity loop | 4 kHz (decimate by 5) |
| Angle / attitude loop | 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, gyro and accel ODR = 8 kHz, ±2000 °/s, ±16 g |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms (amplitude-invariant)

**Clarke:**

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}\quad(i_a+i_b+i_c=0)$$

**Park**, with electrical angle θₑ = p·(θₘ − θ_offset):

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

**Angle prediction.** Compensate the 1.5-sample transport delay (ADC sample → PWM update):

$$\theta_e^{pwm} = \theta_e + 1.5\,\omega_e T_s$$

### 1.2 Space-Vector PWM (min–max zero-sequence injection)

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$

$$v_0=\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x - v_0}{V_{bus}}$$

The linear range is limited to $|v_{dq}| \le V_{bus}/\sqrt3$.
