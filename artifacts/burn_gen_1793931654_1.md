# STM32H743 AIO Flight Controller + 4-in-1 80A ESC: Design Model

**Job #9 · Revision A (preliminary)**

## 0. Scope, Assumptions, and Feasibility Warning

The request names no MOSFET, battery voltage, board size, or burst duration, so this document fixes a **baseline** for each. Every equation is parameterized, so you can substitute datasheet values later.

| Parameter | Baseline | Notes |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max | Use 25.2 V for switching loss and 44 V for component derating |
| Burst current | 80 A per motor, all 4 motors simultaneously | Worst case |
| PWM frequency | 48 kHz, complementary (synchronous rectification) | Set in AM32/BLHeli_32 |
| MOSFET | 40 V, 3.3×3.3 mm DFN (PQFN) | R_DS(on) = 1.0 mΩ at 25 °C, Q_g = 50 nC, Q_rr = 40 nC, Q_oss = 30 nC, t_r = t_f = 10 ns, R_θJC = 1.2 K/W |
| Gate driver | Fortior FD6288Q (3-phase, 2.5 A sink) | One per ESC channel |
| ESC MCU | Artery AT32F421K8U7 (120 MHz, Cortex-M4), running AM32 | One per motor |
| FC MCU | STM32H743VIH6 (TFBGA100) at 400 MHz, ArduPilot | |
| Board | 30.5×30.5 mm mount, ~36×36 mm outline, 8-layer, 2 oz inner/outer | |

> **Architectural note:** In practice the H743 does not commutate the motors directly. ArduPilot has no on-board ESC commutation firmware, and 4× sensorless FOC/6-step at 48 kHz is a poor use of the FC core. The correct architecture is an H743 flight controller plus four dedicated ESC MCUs on the same PCB (a "true AIO"), linked by bidirectional DShot600. The rest of this document assumes that partition.

> **Feasibility warning:** On a nano/30 mm board, 80 A × 4 is a **burst rating only**, limited to a few seconds by thermal mass. Section 3 shows that steady-state 80 A per motor is physically impossible without a heatsink and forced airflow. Marketing "80A" ratings on boards this size are burst figures.

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step trapezoidal control with complementary PWM, one high-side and one low-side FET are in the current path at any instant. The low side of the PWM'd leg alternates with its high side, but the conducting resistance is always about 2 × R_DS(on):

$$P_{cond,ch} = I_{ph,rms}^2 \cdot 2R_{DS(on)}(T_j) + I_{ph,rms}^2 \cdot R_{Cu}$$

### 1.2 Temperature dependence

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,\left[1+\alpha\,(T_j-25)\right],\quad \alpha \approx 0.005\ /\mathrm{K}$$

At T_j = 125 °C: R_DS(on) = 1.0 × 1.5 = **1.5 mΩ**.

### 1.3 Copper (PCB) resistance

Phase and bus path: about 20 mm of 2 oz copper (70 µm), 6 mm wide, on two parallel layers.

$$R_{Cu} = \frac{\rho L}{A} = \frac{1.72\times10^{-8}\cdot 0.02}{(6\times10^{-3})(70\times10^{-6})\cdot 2} \approx 0.41\ \mathrm{m\Omega}$$

At 100 °C this rises to about 0.53 mΩ.

### 1.4 Numerical result (80 A, hot)

$$P_{cond,ch} = 80^2\,(2\cdot1.5\times10^{-3} + 0.53\times10^{-3}) = 6400\cdot 3.53\times10^{-3} = \mathbf{22.6\ W}$$

The FET-only share is 19.2 W. Each FET conducts for 120° of each electrical cycle, so the average per FET is about 19.2 / 6 = **3.2 W**. The instantaneous FET dissipation while conducting is 80² × 1.5 mΩ = **9.6 W**.

## 2. Switching Loss Model at 48 kHz

Per ESC channel, one leg is hard-switching at any time (one HS/LS pair commutating per PWM period).

| Term | Equation | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw | ½·25.2·80·20 ns·48 k = **0.968 W** |
| Reverse recovery | Q_rr·V·f_sw | 40 nC·25.2·48 k = **0.048 W** |
| Output capacitance | Q_oss·V·f_sw | 30 nC·25.2·48 k = **0.036 W** |
| Dead-time body-diode | V_F·I·2t_dt·f_sw (t_dt = 50 ns) | 0.8·80·100 ns·48 k = **0.307 W** |
| Gate drive (in driver/R_g) | 2·Q_g·V_GS·f_sw | 2·50 nC·10·48 k = **0.048 W** |
| **Total P_sw per channel** | | **≈ 1.41 W** |

**Sensitivity:** P_sw scales linearly with f_sw. At 24 kHz it is about 0.70 W; at 96 kHz about 2.8 W. At 48 kHz, switching loss is only about 6% of total loss, so conduction loss dominates. Choosing a lower R_DS(on) FET is worth more than choosing a faster one.

### 2.1 Per-channel and board totals (80 A burst, hot)

$$P_{ch} = 22.6 + 1.41 \approx 24.0\ \mathrm{W}$$

$$P_{ESC,total} = 4 \times 24.0 = 96\ \mathrm{W}\quad(+\ \sim 1.5\ \mathrm{W\ for\ FC,\ regulators,\ and\ ESC\ MCUs})$$

**Efficiency check:** 4 × 80 A × ~22 V ≈ 7 kW delivered against about 97 W lost, or roughly 98.6% electrical efficiency. The efficiency is fine; the problem is power density.

## 3. Thermal Model

### 3.1 Steady state (shows why the rating must be burst-only)

Board-to-air convection with prop wash is h ≈ 80 W/m²K. Using both faces of a 36×36 mm board, A = 2.6×10⁻³ m².

$$R_{\theta,BA} = \frac{1}{hA} = \frac{1}{80\cdot2.6\times10^{-3}} \approx 4.8\ \mathrm{K/W}$$

$$\Delta T_{ss} = 97 \times 4.8 \approx 465\ \mathrm{K}$$

This is impossible. The sustainable continuous loss for a +70 K board rise is 70 / 4.8 ≈ **14.6 W total**. That corresponds to about 3.6 W per channel, or **I_cont ≈ 30 A per motor**. Specify the product as **30 A continuous / 80 A burst**.
