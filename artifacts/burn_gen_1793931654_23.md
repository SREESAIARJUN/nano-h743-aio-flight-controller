# Job #42: STM32H743 Nano FC + 4-in-1 ESC (80 A Burst, 48 kHz PWM, Bidirectional DShot600)

## 0. Architecture Clarification and Stated Assumptions

**Architecture.** The STM32H743 runs ArduPilot and generates DShot. It does **not** drive the power bridges. Each motor channel has its own ESC MCU, assumed to be an STM32G071 running AM32. That MCU generates the 48 kHz complementary PWM and handles back-EMF commutation. The model below follows that split.

| Parameter | Assumed value | Notes |
|---|---|---|
| Bus voltage | 6S, V_bus = 25.2 V (full charge) | Worst case for switching loss |
| Current | I = 80 A per channel, burst | |
| MOSFET | 40 V, 3.3×3.3 or 5×6 mm, R_ds(on),25 = 1.0 mΩ | Q_g = 50 nC, Q_gd = 8 nC, Q_rr = 40 nC, C_oss,eff = 1.5 nF |
| Gate driver | FD6288Q-class, about 1 A effective | t_r ≈ t_f ≈ 15 ns |
| Dead time | 100 ns | Body diode V_f = 0.8 V |
| Current shunt | 0.25 mΩ | |
| Copper path | 0.5 mΩ per conduction path | |
| Form factor | 20×20 mm, 8-layer, 2 oz | |

**Feasibility flag.** I will show quantitatively in §3 that 80 A per channel on a 20×20 board is a **transient (≈1–2 s) rating only**. That is not a design flaw in the math. It is physics, and it should be communicated honestly on the datasheet.

## 1. Conduction Loss Model

### 1.1 Six-step commutation with synchronous rectification

In trapezoidal (six-step) drive, two phase legs carry the motor current I at any instant. Over one electrical cycle each leg spends:
- 120° as the **PWM'd high side**. HS is on for duty D, and the complementary LS is on for (1−D).
- 120° as the **static low side**. LS is on 100%.
- 120° **floating**. This is the back-EMF sensing window.
