# STM32H743 FC + 4-in-1 ESC Nano Stack: Loss, Thermal, and Bi-Directional DShot600 Model

## 0. Scope and Assumptions

**Architecture.** In a 4-in-1 stack, the STM32H743 is the flight controller. Each ESC channel runs its own MCU (typically AM32 or BLHeli_32 on an STM32G071 or AT32F421) and its own gate driver. So the work splits cleanly:

| Domain | Owner | Covered in |
|---|---|---|
| 48 kHz PWM, conduction and switching losses | ESC MCU + power stage | §1–3 |
| Bi-directional DShot600, timers, DMA | H743 running ArduPilot | §4 |
| Interconnect | Both | §5 |

**Assumptions.** "Job #7" has no attached BOM, so all numbers below use the reference parameters in this table. Replace them with your MOSFET datasheet values and the model re-evaluates directly.

## 1. Electrical Loss Model (per ESC channel)

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j)=R_{ds(25)}\,(1+\alpha)^{\,T_j-25}$$

At T_j = 125 °C this gives 1.5 mΩ × 1.566 ≈ **2.35 mΩ**. A practical shortcut is **R_hot ≈ 1.5 × R_25 = 2.25 mΩ**, which is used below.

### 1.2 Conduction loss, including per-FET distribution

In any 6-step sector, two legs are active:
- **PWM leg:** the high-side FET conducts for duty D; the synchronous low-side FET conducts for (1−D).
- **Return leg:** the low-side FET conducts for 100% of the sector.
- **Third leg:** floating.

The current therefore always passes through exactly two channels in series:

$$P_{cond,ch}=I_{ph,rms}^2\cdot 2R_{ds}(T_j)$$

Each phase serves as the PWM leg for 1/3 of an electrical cycle and as the return leg for 1/3. The per-FET averages are:

$$P_{HS}=\tfrac13 D\,I^2R_{ds}\qquad P_{LS}=\tfrac13\,(2-D)\,I^2R_{ds}$$
