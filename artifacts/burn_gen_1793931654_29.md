# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #6): Architecture & Analysis Package

## 0. Architecture Baseline and Assumptions

### Partitioning

An STM32H743 does not commutate the motors directly in any practical 4-in-1 design, and ArduPilot does not run FOC/6-step motor control. The architecture is therefore:

| Block | Device | Role |
|---|---|---|
| FC MCU | STM32H743VIT6 (LQFP100) | ArduPilot, sensors, bi-directional DShot600 master |
| ESC MCUs (×4) | AT32F421 / STM32G071 class | AM32 / BLHeli_32-class firmware, 6-step, 48 kHz PWM |
| Gate drivers (×4) | 3-phase bootstrap half-bridge driver (FD6288-class) | 10–12 V gate drive |
| Power stage (×4) | 6 × 40 V N-MOSFET, DFN5×6 | Three-phase bridge |

If the intent was a single H743 directly commutating four motors, raise it now. That approach needs 12 complementary PWM pairs with dead-time (only TIM1/TIM8 provide this natively), which the H743 cannot supply for four motors.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Six-Step Synchronous Conduction Topology

In each 60° commutation sector, one phase is PWM-switched (HS ↔ sync-LS) and one phase's low-side conducts continuously. The current path is always through **exactly two MOSFET channels**, independent of duty cycle D:

$$
\text{Path} = \begin{cases} HS_A + LS_B & \text{during } D\cdot T_{sw} \\ LS_A(\text{sync}) + LS_B & \text{during } (1-D)\cdot T_{sw} \end{cases}
$$

Therefore:

$$
P_{cond,ch} = 2\, I_{ph}^2\, R_{DS(on)}(T_j)
$$
