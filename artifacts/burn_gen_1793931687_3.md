# STM32H743 AIO + 4-in-1 ESC (Job #44): Loss Model, Thermal Budget, Bi-Dir DShot600 DMA Plan

## 0. Architecture Note

On every production 4-in-1 AIO, the **H743 does not drive the gates**. Each motor channel has its own ESC MCU (e.g. AT32F421 running AM32, or BLHeli_32-class firmware). That MCU generates the 48 kHz complementary PWM through a 3-phase gate driver.

The H743's job is to send **bi-directional DShot600** to those MCUs and decode eRPM telemetry. The model is split accordingly:
