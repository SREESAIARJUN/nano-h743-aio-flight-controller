# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #26 spec sheet, so this design uses the assumptions below. Every derived gain is written as a formula, so you can substitute your measured values directly.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC (e.g. GBM2804/4108 class), SPM, 7 pole pairs, 12 slots |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6701), read every PWM cycle |
| Inverter | 3-phase, low-side shunts, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate (stabilized frame), SPI, gyro/accel ODR 8 kHz |
| MCU | Cortex-M4F/M7 (STM32G4/H7), single-precision FPU |

**Loop structure (per axis):**

```
  θ_ref (world) ─►[Angle P + ω_ff]─► ω_ref ─►[Velocity PI + τ_ff]─► iq_ref ─►[+ iq_cog]─►[Current PI dq + decoupling]─►SVPWM─►Motor
        ▲  1 kHz–4 kHz                ▲ 4 kHz (gyro feedback)             ▲ 20 kHz (encoder θe)
        │                              │
  Attitude estimator ◄── Dual-IMU fusion + notch/LPF chain (8 kHz) ◄── 2× ICM-42688-P
```

**Loop rates:**

| Loop | Rate | Period |
|---|---|---|
| Current | 20 kHz | Ts_i = 50 µs |
| IMU processing | 8 kHz | |
| Velocity and angle | 4 kHz | Ts_v = 250 µs, decimated by 2 from the IMU |

The key gimbal-specific choice is that **the velocity loop uses inertial rate from the gyro, not encoder speed.** Stabilization means holding the camera still in inertial space. The encoder is used only for commutation (θe) and for anti-cogging indexing (θm).

## 1. FOC Current Loop: Equations

### 1.1 Transforms (amplitude-invariant)

Clarke:
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}\quad(\text{with } i_a+i_b+i_c=0)$$

Park, with θe = p·θm − θ_offset:
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park:
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Motor model (SPM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau_e = \tfrac32 p\lambda_m i_q = K_t i_q,\qquad K_t = \tfrac32 p \lambda_m$$

### 1.3 PI with decoupling feedforward

The feedforward terms cancel cross-coupling and back-EMF:
$$v_d^{ff} = -\hat\omega_e \hat L i_q,\qquad v_q^{ff} = \hat\omega_e \hat L i_d + \hat\omega_e\hat\lambda_m$$

After decoupling, each axis plant is $G(s) = 1/(Ls+R)$.

Using pole-zero cancellation with PI $C(s)=K_p + K_i/s$ and $K_i/K_p = R/L$, the closed loop becomes first-order with bandwidth ω_c:
$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

Bandwidth choice:
- Choose $\omega_c \le 2\pi f_{pwm}/15$. At 20 kHz this gives ω_c ≈ 8.4 krad/s (≈1.3 kHz).
- The transport delay is about 1.5·Ts_i (computation plus PWM hold).
- Phase margin ≈ 90° − ω_c·1.5Ts_i·(180/π) ≈ 54° at this choice.

### 1.4 Voltage limiting and anti-windup

- Linear SVPWM limit: $V_{max} = V_{dc}/\sqrt3$.
- d-axis priority: $v_d^{sat} = \text{clamp}(v_d, \pm V_{max})$, then $v_q^{sat} = \text{clamp}(v_q, \pm\sqrt{V_{max}^2 - v_d^{sat\,2}})$.
- Back-calculation anti-windup, with K_aw ≈ 1/K_p:
$$x_I[k+1] = x_I[k] + T_s\big(K_i e[k] + K_{aw}(u^{sat}-u)\big)$$

### 1.5 SVPWM (min-max zero-sequence injection, equivalent to sector SVPWM)

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{dc}}$$

## 2. Cascaded Velocity/Angle Control

### 2.1 Mechanical plant (per axis)

$$J\dot\omega = K_t i_q - \tau_{cog}(\theta_m) - \tau_{fric} - \tau_{dist}$$

The current loop is treated as a first-order lag with $\tau_i = 1/\omega_c$.
