## 1. Field-Oriented Control: Current Loop (20 kHz)

### 1.1 Transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform, using electrical angle θ_e = p·θ_m − θ_off:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant and decoupled PI

The dq voltage equations for a surface-mount PMSM (L_d = L_q = L) are:

$$v_d = Ri_d + L\dot i_d - \omega_e L i_q,\qquad v_q = Ri_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Feeding forward the cross-coupling and back-EMF terms leaves a first-order plant per axis, G(s) = 1/(Ls+R).

Choosing the PI zero to cancel the plant pole gives:

$$K_p^{i}=L\,\omega_{ci},\qquad K_i^{i}=R\,\omega_{ci}$$

The closed loop then becomes ω_ci/(s+ω_ci). Set ω_ci = 2π·1500 rad/s, which is below f_pwm/10 to respect the one-sample compute delay plus half-sample PWM delay.

### 1.3 Anti-windup (back-calculation) in discrete time

The forward-Euler form, with sample time T_s, saturation function sat(·), and back-calculation gain K_b, is:

$$u_k = K_p e_k + I_k,\quad u^{sat}_k=\text{sat}(u_k),\quad I_{k+1}=I_k + T_s\big[K_i e_k + K_b(u^{sat}_k-u_k)\big]$$

Use K_b = K_i/K_p, which equals ω_c for the current loop.

The dq voltage vector is limited circularly:

$$\|v_{dq}\|\le \frac{V_{bus}}{\sqrt3}\cdot 0.95$$

The d-axis has priority.

### 1.4 SVPWM by min-max injection

This method is equivalent to SVPWM:

$$v_{0}=-\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\qquad d_x=\tfrac12+\frac{v_x+v_0}{V_{bus}}$$

### 1.5 Velocity estimation with a PLL tracking observer

Raw encoder differencing at 4 kHz gives about 0.55 rad/s of quantization noise per LSB, so a tracking observer is used instead:

$$e_k=\text{wrap}_\pi(\theta^{enc}_k-\hat\theta_k),\quad \hat\omega_{k+1}=\hat\omega_k+K_iT_se_k,\quad \hat\theta_{k+1}=\hat\theta_k+T_s(\hat\omega_k+K_pe_k)$$

The gains are K_p = 2ζω_n and K_i = ω_n², with ζ = 0.9 and ω_n = 2π·250 rad/s.
