# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification

I don't have the Job #22 requirements, so this design states its assumptions explicitly. Every gain is derived from symbolic plant parameters. Change the parameter block and the gains recompute.

---

## 0. Assumptions & Architecture

| Item | Assumed value | Notes |
|---|---|---|
| Motor | 12N14P gimbal BLDC (GBM2804-class), p = 7 pole pairs | R ≈ 5–10 Ω, L ≈ 2–4 mH (measure these) |
| Encoder | 14-bit magnetic (AS5048A / MT6701), SPI | Used for commutation, joint angle and cogging phase |
| MCU | STM32G4 / H7, FPU, 3 × 3-phase PWM | Center-aligned PWM, ADC synced to the PWM center |
| Current sense | Low-side or inline shunts, 2–3 phases | |
| IMU A ("payload") | ICM-42688-P on the camera plate | Feedback sensor |
| IMU B ("base") | ICM-42688-P on the handle / airframe | Vibration reference and disturbance feed-forward |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner) | |

> If your "dual IMU" means two redundant IMUs both on the payload, §5.5 covers that variant.
