# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #52 specification, so this design uses the assumptions below. Every parameter is a `constexpr` or struct field. Swap in your real values.

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.6 Ω, L ≈ 2.1 mH, K_t ≈ 0.06 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (MT6701 or AS5048A) |
| IMUs | 2 × ICM-42688-P on the payload plate, rigidly mounted, SPI, gyro ODR 8 kHz |
| Gimbal kinematics | Outer to inner: **Yaw (z) → Roll (x) → Pitch (y)** |

**Loop rates.** Each outer loop is at least 4–10× slower in bandwidth than the loop inside it.

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~2 kHz |
| Rate (velocity) | 4 kHz | 80–150 Hz |
| Attitude (angle) | 1 kHz | 10–25 Hz |
| IMU filtering and fusion | 8 kHz in, decimated to 4 kHz | — |

## 1. FOC Current Loop

### 1.1 Electrical angle
$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is measured at alignment by injecting $v_d$ with $v_q = 0$ and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, balanced phases)
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

### 1.3 Park transform
$$\begin{bmatrix}i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the dq frame
$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$
