# FOC Control and Sensor Fusion Design for a 3-Axis Gimbal

I don't have the specification for Job #58, so this design uses typical parameters for a brushless gimbal. Every assumption is collected in §0. Change those constants and the equations and code still apply.

---

## 0. Assumptions and System Architecture

| Item | Value (default) |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Joint sensor | 14-bit absolute magnetic encoder on each motor (e.g. MT6701 or AS5048A) |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, synchronized via CLKIN/FSYNC |
| Kinematic chain | Yaw (Z) → Roll (X) → Pitch (Y), outer to inner |
| DC bus | 12–16 V |

The control loops are rate-separated as follows.

```
 20 kHz  │ Current (FOC) loop: Clarke/Park, PI_d, PI_q, decoupling, SVPWM    ← encoder θ_e
  8 kHz  │ IMU sampling: dual-IMU fusion, notch bank, LPF                     ← 2× ICM-42688-P
  4 kHz  │ Rate loop: camera-frame gyro PI(D) → τ_cam → Jᵀ → i_q* + cogging FF
  1 kHz  │ Attitude loop: quaternion error → ω_sp ; Mahony AHRS
```

The design rests on four key decisions:

1. **Inertial feedback for stabilization.** The rate loop is closed on the camera-mounted gyro, which measures inertial rate. It is not closed on encoder speed.
