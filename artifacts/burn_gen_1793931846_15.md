## 1. Conduction Loss Model

### 1.1 Current path in 6-step synchronous drive

During each 60° electrical sector, one phase leg's high-side FET (HS) is PWM-switched with duty *D*. The complementary low-side FET (LS) of the same leg synchronously rectifies during (1−D). On the second active leg, the LS FET is held fully ON. The phase current *I_ph* flows through exactly **two channel resistances in series at all times**:

- **On-time (D):** HS_a → motor → LS_b
- **Off-time (1−D):** LS_a (sync-rect.) → motor → LS_b

$$P_{cond,ch} = I_{ph,rms}^2 \cdot \left[2R_{DS(on)}(T_j) + R_{Cu} + R_{sh}\right]$$

The term is independent of D because both intervals present 2·R_DS(on). The relation between bus and phase current is

$$I_{bus} \approx D \cdot I_{ph}$$

so the worst case for FET heating is **high phase current at full throttle**, where D → 1 and I_ph ≈ I_bus = 80 A.

**Ripple correction.** For motor inductance L_ph ≈ 15 µH (line-to-line, 2207-class):

$$\Delta I_{pp} = \frac{V_{bus}D(1-D)}{f_{sw}\,L_{LL}} \Big|_{D=0.5} = \frac{25.2\cdot0.25}{48\text{k}\cdot15\mu} = 8.75\text{ A}$$

$$I_{rms} = \sqrt{I^2 + \Delta I_{pp}^2/12} = \sqrt{6400 + 6.4} = 80.04\text{ A}$$

The correction is negligible, so I_rms = 80 A is used.

### 1.2 Temperature dependence of R_DS(on)

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,\left[1+\alpha\,(T_j-25)\right],\quad \alpha \approx 0.0045\ /\text{K}$$

| T_j | R_DS(on) (max-spec basis 0.85 mΩ) |
|---|---|
| 25 °C | 0.85 mΩ |
| 100 °C | 1.14 mΩ |
| 125 °C | 1.23 mΩ |
| 150 °C | 1.32 mΩ |

### 1.3 Parasitic resistances

| Element | Value | Derivation |
|---|---|---|
| R_Cu (phase pad → FET → bus, round trip) | 0.25 mΩ | 2 oz, parallel inner layers, ~10 mm path, via arrays |
| R_sh (bus current shunt, shared) | 0.25 mΩ | Carries only I_bus, so it is accounted separately |
| R_solder/package | incl. in R_DS(on) | |

### 1.4 Result at 80 A (T_j = 125 °C design point)

$$P_{cond,ch} = 80^2 \cdot (2\times1.23 + 0.25)\,\text{m}\Omega = 6400 \times 2.71\text{ m}\Omega = \mathbf{17.3\ W}$$

Split:

- FET share: 6400 × 2.46 mΩ = **15.7 W**
- Copper: 1.6 W
- Shunt: 80² × 0.25 mΩ = 1.6 W, shared per ESC if a single bus shunt is used; with one shunt total it carries ΣI_bus.

**Per-FET average.** Each FET conducts for 120° of 360° (HS and LS roles combined across sectors). The 15.7 W channel FET loss spreads over 6 FETs, with each FET in-circuit 1/3 of the time:

$$P_{FET,avg} = \frac{15.7}{6}\times\frac{6}{3}\cdot\frac{1}{2}\ \approx\ \mathbf{2.6\ W\ avg,\ 7.9\ W\ instantaneous\ (per\ conducting\ FET)}$$

The instantaneous figure matters for the junction ripple (§3.3).
