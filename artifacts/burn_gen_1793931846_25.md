# STM32H743 Nano FC + 4-in-1 80A ESC: Systems Architecture Model (Job #0)

## 0. Scope and Assumptions

**Architecture.** An STM32H743 does not drive the power stage directly in any practical design. This model therefore covers a two-board stack (or an AIO with two domains):

| Domain | MCU | Role |
|---|---|---|
| Flight controller | STM32H743 (480 MHz, ArduPilot) | Generates bidirectional DShot600, decodes eRPM telemetry |
| 4-in-1 ESC | 4× AT32F421 / STM32G071 class (AM32 or BLHeli_32-class firmware) | 48 kHz complementary PWM, 6-step commutation |

**"Nano" form factor warning.** Four channels at 80 A burst is not thermally viable on a 20×20 mm board, as Section 3 shows. The numbers below assume a **30.5×30.5 mm, 8-layer, 2 oz board**. All 20×20 results scale roughly 2.3× worse.

**Baseline parameters.** Every result below should be re-run with your actual datasheet values.

| Symbol | Value | Meaning |
|---|---|---|
| V_bus | 25.2 V (6S full) | Worst-case switching voltage |
| f_sw | 48 kHz | PWM frequency |
| I_ph | 80 A | Burst phase current per channel |
| R_ds(on),25 | 1.0 mΩ | 40 V MOSFET, 5×6 package |
| k_T | 1.5 | R_ds(on) multiplier at T_j ≈ 125 °C |
| R_cu | 0.5 mΩ | Copper + solder path per conduction loop |
| t_r + t_f | 20 ns | Q_gd ≈ 10 nC at ~1 A gate drive, per edge |
