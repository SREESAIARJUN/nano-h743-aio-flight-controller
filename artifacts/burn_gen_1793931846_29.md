**Architecture assumption.** The STM32H743 runs ArduPilot as the flight controller. It does not commutate motors. Each motor uses a dedicated ESC MCU (AT32F421 class) running AM32 or BLHeli_32, plus a 3-phase gate driver and 6 MOSFETs. This means the **48 kHz PWM frequency is an ESC-firmware setting. ArduPilot does not control it.** ArduPilot only produces the DShot600 command stream and decodes the eRPM telemetry.

## 1. Conduction Loss Model

### 1.1 Current paths per commutation step
In each 60° electrical sector, two phases conduct.

- **PWM'd phase (A):** The high-side FET conducts for duty D. The low-side FET synchronously rectifies for (1−D), minus dead time.
- **Return phase (B):** The low-side FET conducts 100% of the sector.

With synchronous rectification, the loss in the current path is independent of duty cycle:

$$
P_{cond,ESC}(T_j) = I_{ph}^2\left[D\,R_{HS} + (1-D)\,R_{LS}\right] + I_{ph}^2 R_{LS} \;\approx\; 2\,I_{ph}^2\,R_{DS(on)}(T_j)
$$

$$
R_{DS(on)}(T_j) = R_{25}\,\left[1+\alpha\,(T_j-25)\right]
$$
