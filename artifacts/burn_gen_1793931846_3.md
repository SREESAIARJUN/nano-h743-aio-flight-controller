# STM32H743 Nano FC + 4-in-1 ESC (Job #18): Power-Stage Loss Model, Thermal Analysis, Bidirectional DShot600 Allocation, and Reference Netlists

## 0. Architecture Decision and Assumptions

**The STM32H743 should not commutate the FETs.** It runs ArduPilot and sends bidirectional DShot600 to four dedicated ESC MCUs (AT32F421 or STM32G071, AM32 firmware). The reasons:
- ArduPilot has no BLDC commutation stack.
- Back-EMF zero-cross timing needs a dedicated real-time core.
- An ESC MCU fault then does not take down the flight controller.

| Parameter | Value (assumed; replace with the selected parts) |
|---|---|
| Bus | 6S LiPo, 25.2 V max, 22.2 V nominal |
| Board | 25.5 × 25.5 mm stack-compatible ("nano" class), 8-layer, 2 oz inner and outer |
| MOSFET | 40 V N-ch, PDFN 3.3×3.3. R_DS(on) = 1.0 mΩ @ 25 °C, V_GS = 10 V. Q_g = 60 nC, Q_oss = 40 nC, Q_rr = 50 nC, V_SD = 0.8 V, R_θJC = 2.5 K/W |
| Switching | t_r + t_f = 40 ns at 80 A, dead time 100 ns |
| Modulation | Six-step trapezoidal, complementary (synchronous) PWM, f_sw = 48 kHz |
| Burst | 80 A phase current per motor |

**Up-front verdict:** 80 A is a few-seconds burst rating on this board, not a continuous one. Section 2 shows this quantitatively.

## 1. Loss Model (per ESC channel)

### 1.1 Conduction losses

In six-step operation, two legs carry current at any instant. With synchronous rectification, the PWM leg always conducts through either its high-side (HS) or low-side (LS) FET. The current path is therefore always two FETs in series:

$$P_{cond} = 2\,I_{ph}^2\,R_{DS(on)}(T_j)$$

R_DS(on) depends on temperature:

$$R_{DS(on)}(T_j) = R_{25}\left[1+\alpha (T_j - 25)\right],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C, R_DS(on) = 1.5 mΩ, so:

$$P_{cond} = 2(80)^2(1.5\times10^{-3}) = \mathbf{19.2\ W}$$

Add the copper path: about 0.3 mΩ of phase and bus trace per channel gives 80² × 0.3 mΩ = **1.9 W**. This loss heats the PCB directly, not the FETs.

### 1.2 Switching losses (PWM leg only)

**Hard-switching V-I overlap:**
$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = 0.5(25.2)(80)(40\text{n})(48\text{k}) = \mathbf{1.94\ W}$$

**Output capacitance:**
$$P_{oss} = Q_{oss} V_{bus} f_{sw} = 40\text{n}\cdot25.2\cdot48\text{k} = \mathbf{0.048\ W}$$

**Body-diode reverse recovery:**
$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n}\cdot25.2\cdot48\text{k} = \mathbf{0.060\ W}$$

**Dead-time diode conduction** (two dead times per period):
$$P_{dt} = V_{SD} I_{ph}\,(2t_{dt}) f_{sw} = 0.8\cdot80\cdot200\text{n}\cdot48\text{k} = \mathbf{0.61\ W}$$

**Gate drive** (dissipated in the driver and gate resistors, not in the FETs):
$$P_g = 2\,Q_g V_{GS} f_{sw} = 2\cdot60\text{n}\cdot10\cdot48\text{k} = \mathbf{0.058\ W}$$

### 1.3 Totals at 80 A

| Loss | W per channel | W, all 4 channels |
|---|---|---|
| Conduction (FETs) | 19.20 | 76.8 |
| V-I switching | 1.94 | 7.8 |
| Dead-time diode | 0.61 | 2.4 |
| Q_rr + Q_oss | 0.11 | 0.4 |
| **FET subtotal** | **21.86** | **87.4** |
| Copper | 1.9 | 7.7 |
| Gate drive | 0.06 | 0.2 |
| **Board total** | **≈23.8** | **≈95 W** |

Conduction dominates by roughly 10:1. Lowering f_sw from 48 kHz to 24 kHz saves only about 1.3 W per channel. Lowering R_DS(on), or paralleling FETs, is the effective lever.

**Efficiency check:** at duty D = 0.8, the mechanical/electrical power is about 25.2 × 0.8 × 80 ≈ 1.6 kW per channel, so η ≈ 98.6 %. The electrical efficiency is fine; the problem is power density.

### 1.4 Per-FET loss and junction temperature

Each FET conducts for about 1/3 of the electrical cycle. At the commutation frequency (eRPM / 60 = several kHz), the die thermal time constant (around 1 ms) averages this out, so the average loss is used:

$$P_{FET,avg} \approx \frac{21.86}{6} = 3.64\ \text{W}$$

The thermal path from junction to board copper is R_θJC (2.5 K/W) plus the via array and spreading resistance (about 5 K/W), giving R_θJ-B ≈ 7.5 K/W:

$$T_j = T_{board} + 3.64 \times 7.5 = T_{board} + 27\ \text{K}$$

The worst-case PWM-leg FET carries the switching loss on top of its conduction share, adding roughly 2–3 K more.
