## 0. Architecture Decision (and a correction to the brief)

The H743 should **not** commutate the motors directly. In this architecture:

- **The STM32H743** runs ArduPilot as the flight controller. It sends bi-directional DShot600 to four ESC MCUs and receives eRPM telemetry back.
- **Each motor channel** has its own ESC MCU running AM32 or BLHeli_32, a 3-phase gate driver, and 6 MOSFETs.
- **The 48 kHz figure is the ESC's PWM frequency.** It is generated by the ESC MCU, not the H743.

```
 VBAT ─┬─────────────────────────────────────────────────────────┐
       │                                                         │
   [BEC 5V/3.3V]                              ┌─────────┐   ┌────┴─────┐
       │         DShot600 (bidir, 1-wire)     │ ESC MCU │──▶│FD6288Q x1│──▶ 6× NMOS ─▶ M1
  ┌────┴─────┐ ─────────────────────────────▶ │ AT32F421│   └──────────┘
  │STM32H743 │  TIM1_CH1 (PE9)  ◀── eRPM GCR  └─────────┘
  │ArduPilot │  TIM1_CH2 (PE11) ─────────────▶ ESC2 ... M2
  │          │  TIM1_CH3 (PE13) ─────────────▶ ESC3 ... M3
  │          │  TIM1_CH4 (PE14) ─────────────▶ ESC4 ... M4
  └──────────┘  ADC ◀── Σ current shunt / VBAT divider
```
