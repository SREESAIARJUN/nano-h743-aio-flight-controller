# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #2 specification, so this design states its assumptions explicitly. Every parameter that depends on your hardware is a named constant in the code, so you can substitute your own values.

## 0. Assumed Platform

| Item | Assumption |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A or MT6701), one per joint |
| MCU | STM32G4 class (Cortex-M4F, 170 MHz), center-aligned PWM at 20 kHz |
| Gimbal order | Yaw (outer) → Roll → Pitch (camera) |
| IMUs | 2 × ICM-42688-P on the camera plate, mirrored about the camera's center of rotation, 8 kHz ODR, ±2000 dps, ±16 g |

**Loop rates:**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity | 4 kHz | ~150 Hz |
| Angle | 1 kHz | ~25 Hz |
| IMU filtering | 8 kHz, decimated to 4 kHz | — |
| Attitude estimator | 1 kHz | — |

Each loop should have at least 5–10× less bandwidth than the loop inside it. This keeps the cascade stable when each layer is tuned independently.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park transform**, where θ_e = p·θ_m − θ_offset is the electrical angle:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant Model and PI Design

The motor's voltage equations in the rotating d-q frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Each axis has a decoupled plant 1/(Ls + R) once we add cross-coupling feedforward. Placing the PI zero on the plant pole (pole-zero cancellation) gives a first-order closed loop with bandwidth ω_c:

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c$$

The final voltage commands include decoupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(e_q) + \omega_e (L i_d + \lambda_m)$$

**Delay compensation.** PWM updates take effect about 1.5 samples after the measurement. The inverse Park transform therefore uses an advanced angle:

$$\theta_e' = \theta_e + 1.5\,\omega_e T_s$$
