# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

I have no project file for "Job #12", so this design rests on the assumptions in §0. Every equation is written in terms of named parameters, so you can substitute your real hardware values directly.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | 3 × gimbal BLDC (GBM2804-class), 12N14P, pole pairs p = 7 |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701) per axis |
| Current sense | 2-shunt low-side per axis (a voltage-mode fallback is provided) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, gyro/accel ODR = 8 kHz |
| PWM | 20 kHz, center-aligned, ADC triggered at the counter peak |

**Loop rates (rate-monotonic, all derived from the PWM interrupt):**

```
20 kHz  : ADC → Clarke/Park → current PI (d,q) → SVPWM            (T_c = 50 µs)
 4 kHz  : encoder velocity, IMU fusion output, velocity PI + cogging FF   (T_v = 250 µs)
 1 kHz  : attitude estimator (Mahony), angle P(I), Jacobian mapping      (T_θ = 1 ms)
 8 kHz  : IMU data-ready → DMA → notch/LPF chain (separate EXTI ISR)
```

**Bandwidth separation.** Each outer loop should be at least 5× slower than the loop inside it:

ω_c ≈ 2π·1500 rad/s, ω_v ≈ 2π·150 rad/s, ω_θ ≈ 2π·30 rad/s.
