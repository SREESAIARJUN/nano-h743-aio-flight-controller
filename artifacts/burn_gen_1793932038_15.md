# STM32H743 Nano FC + 4‑in‑1 ESC (Job #42): Power Stage Thermal Model, Switching Losses, Bidirectional DShot600 DMA Allocation, and Netlists

## 0. Architecture and Assumptions

**Signal chain:** The H743 does **not** generate the 48 kHz gate PWM. A 4‑in‑1 ESC uses four ESC MCUs, one per motor, running AM32 or BLHeli_32. The signal path is:

```
STM32H743 (ArduPilot) ──DShot600 bidir──► 4× ESC MCU (AM32) ──6 PWM @48 kHz──► 3‑phase gate driver ──► 6 MOSFETs ──► motor
```

The thermal and switching model applies to the ESC power stage. The DMA/timer model applies to the H743.

## 1. Conduction Loss Model

### 1.1 Current path (6‑step trapezoidal, synchronous rectification)
In any commutation sector, two phases carry current. With complementary PWM (sync rectification), the motor current always flows through exactly **two FETs in series**:
- During the on‑time: high‑side A plus low‑side B.
- During the off‑time: low‑side A (sync rect.) plus low‑side B.

Duty cycle therefore does not reduce first‑order conduction loss:

$$P_{cond,motor} = 2\, I^2\, R_{DS(on)}(T_j)$$

$$R_{DS(on)}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

### 1.2 Per‑FET average
Each FET participates for roughly 1/3 of an electrical revolution as the main switch, plus a sync share. Over the six FETs, the average is:

$$\bar P_{cond,FET} = \frac{2 I^2 R_{DS(on)}}{6} = \frac{I^2 R_{DS(on)}}{3}$$
