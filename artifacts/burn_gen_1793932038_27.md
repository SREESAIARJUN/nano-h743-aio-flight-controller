## 0. Architecture Clarification and Assumptions

### 0.1 Architecture

The STM32H743 runs ArduPilot and does **not** commutate the motors directly. ArduPilot has no in-tree sensorless FOC or six-step commutation for four motors at 48 kHz. The architecture is therefore:

```
                   ┌──────────────────────────────────────────┐
  6S LiPo ──XT60──►│  VBAT bus (bulk + MLCC)                  │
                   │   ├─► 4× [AT32F421 (AM32) → FD6288Q →   │
                   │   │       3× half-bridge (6× N-FET)] → M1-M4
                   │   └─► Buck 5V/3A → LDO 3.3V → STM32H743  │
                   │                                          │
                   │  STM32H743 ──BDShot600 (×4)──► ESC MCUs  │
                   └──────────────────────────────────────────┘
```

- **ESC MCUs:** Each ESC channel has its own MCU (AT32F421 running AM32 is the reference choice) at f_sw = 48 kHz with complementary PWM.
- **Flight controller:** The H743 talks bidirectional DShot600 to each ESC MCU.
