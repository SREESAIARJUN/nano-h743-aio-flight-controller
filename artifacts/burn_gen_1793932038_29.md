# Job #45: STM32H743 Nano FC + 80A-Burst 4-in-1 ESC Stack
## Electrothermal Model, DShot Timing/DMA Allocation, and Reference Netlist

---

## 0. Architecture and Key Findings

Commutation is not done by the H743. ArduPilot does not commutate BLDC motors, so the standard partitioning is used:

| Board | Function | MCU |
|---|---|---|
| FC (20×20 or 30×30) | ArduPilot, IMU, nav, DShot master | STM32H743 (480 MHz) |
| 4-in-1 ESC | 4× sensorless 6-step drive, 48 kHz PWM | 4× AT32F421 (or STM32G071) running AM32 |
| Link | Bidirectional DShot600 (1 wire per motor) | H743 timer + DMA ↔ ESC MCU |

**Top-line results** (6S, single MOSFET per switch, assumed device parameters in §1):

| Quantity | Value |
|---|---|
| Conduction loss per motor @ 80 A, Tj≈125 °C | ≈ 14 W |
| Switching + dead-time + gate loss per motor @ 48 kHz | ≈ 1.9 W |
| Total ESC dissipation, 4 motors @ 80 A burst (incl. copper) | ≈ 75 W |
| Hottest single FET | ≈ 2.3 W (full throttle) to 4.7 W (low duty, high current) |
| Adiabatic burst time, 30×30 board, 85 K budget | ≈ 4–5 s |
| Steady-state continuous capability (prop-wash cooled) | ≈ 35–45 A per motor |
| DShot600 bidir frame + telemetry | ≈ 90 µs → loop-rate ceiling ≈ 8 kHz (ArduPilot runs 400 Hz–2 kHz) |
| DMA streams needed for 4 bidir motors | 3 (TIM1_UP + 2 paired capture) |

> **Design flag:** An 80 A per-motor rating is a **burst (≤ ~3–5 s)** rating on a 20×20/30×30 single-FET design. It cannot be sustained. Size the label, ArduPilot current limits, and AM32 thermal limits accordingly (§3.5).
