## 1. Conduction-Loss Model (80 A Burst)

### 1.1 Current paths in six-step synchronous PWM

During each 60° commutation sector, two phases carry the motor current I:

- **PWM leg:** the high side conducts for D·T, and its complementary low side conducts for (1−D)·T, minus dead time.
- **Return leg:** the low side conducts continuously.

Per ESC, at any instant:

```
P_cond,FET = I² · R_DS,hot · [ D + (1−D) + 1 ] = 2 · I² · R_DS,hot
```

The result is independent of D because synchronous rectification replaces the diode.

### 1.2 Hot R_DS(on)

```
R_DS,hot = R_DS,25 · [1 + α(T_j − 25)]
         ≈ 1.0 mΩ × 1.6 = 1.6 mΩ   (T_j ≈ 125 °C)
```

### 1.3 Parasitic resistance in series with the current path

| Element | R | Loss at 80 A |
|---------|---|-------------|
| Copper, battery pad → bridge → phase pad (2 oz outer + 2 oz inner, both legs) | ≈0.5 mΩ | 3.2 W |
| Current shunt (0.25 mΩ, 2512 or 3920) | 0.25 mΩ | 1.6 W |

### 1.4 Conduction total per ESC at 80 A

```
P_cond = 2 · 80² · 1.6 mΩ = 20.5 W
P_Cu   =                     4.8 W
------------------------------------
                            25.3 W
```

Sensitivity: P_cond scales directly with R_DS,25.

| Configuration | P_cond @ 80 A |
|---------------|--------------|
| 0.7 mΩ part | 14.3 W |
| 2 × 1.0 mΩ in parallel | 10.2 W, but the board area doubles |

## 2. Switching-Loss Model (48 kHz)

### 2.1 Gate-drive currents

Driver assumptions: V_DRV = 10 V, driver R_source ≈ R_sink ≈ 2 Ω, R_g(ext) = 2 Ω.

```
I_g,on  = (V_DRV − V_pl) / (R_drv + R_g,ext + R_g,int) = (10 − 3)/5 = 1.40 A
I_g,off =  V_pl          / (R_drv + R_g,ext + R_g,int) =  3/5      = 0.60 A
```

To speed turn-off, add an anti-parallel diode across R_g(ext). This cuts t_off by about 35%.

### 2.2 Transition times

The switching charge is Q_sw = Q_gs2 + Q_gd = 15 nC.

```
t_on  = 15 nC / 1.40 A = 10.7 ns
t_off = 15 nC / 0.60 A = 25.0 ns
```

Only the PWM-leg high side hard-switches.
