# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original Job #2 specification, so this design uses the stated assumptions below. Every assumption is a named constant in the code so you can change it.

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G4 class (Cortex-M4F, single-precision FPU), 170 MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) per axis |
| IMU A (payload) | ICM-42688-P on the camera plate. Provides attitude and rate feedback. |
| IMU B (base) | ICM-42688-P on the handle/frame. Provides the vibration reference and disturbance feedforward. |
| Bus | Separate SPI per IMU at 24 MHz, ODR 8 kHz, triggered by data-ready interrupt |

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (PWM-synchronous ADC) | ~1.5 kHz |
| IMU filter chain | 8 kHz | n/a |
| Velocity | 4 kHz | ~120 Hz |
| Angle and attitude | 1 kHz | ~25 Hz |

The bandwidths are separated by at least 5× per stage so each inner loop can be treated as unity gain by the next loop out.
