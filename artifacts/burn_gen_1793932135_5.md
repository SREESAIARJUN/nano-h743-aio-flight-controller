# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #49 specification. The design below uses a typical gimbal configuration. Every assumption is a named constant in the code, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | 3 × hollow-shaft gimbal BLDC, 12N14P (7 pole pairs), R = 5.6 Ω, L = 1.9 mH, Kt ≈ 0.09 N·m/A |
| Commutation encoder | 14-bit absolute magnetic (AS5048A/MT6701 class), one per joint |
| MCU | STM32G4 / H7 class, single-precision FPU |
| Current sensing | 2-phase low-side shunts, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI + DMA, ODR = 8 kHz |
| Joint order (base → camera) | Yaw (z) → Roll (x) → Pitch (y) |

**Loop rates**

| Loop | Rate | Ts |
|---|---|---|
| Current (FOC) | 20 kHz | 50 µs |
| IMU fusion and filtering | 8 kHz | 125 µs |
| Rate (velocity) PID | 4 kHz | 250 µs |
| Attitude (angle) loop | 1 kHz | 1 ms |

## 1. FOC Current Loop

### 1.1 Transforms

The magnitude-invariant Clarke transform (with i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

Electrical angle from the mechanical encoder angle:

$$
\theta_e = p\,(\theta_m - \theta_{off})
$$

where p is the number of pole pairs.
