# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

> **Assumptions.** I don't have the Job #57 spec sheet, so the following are assumptions. Every one is a parameter in the code and can be changed:
> - Gimbal BLDC motors: 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH.
> - 14-bit absolute magnetic encoder on each motor.
> - Inline current sensing on 2 phases.
> - Two ICM-42688-P sensors on the camera plate, on separate SPI buses.
> - Cortex-M4F/M7-class MCU with FPU.
>
> Register-level IMU values must be verified against the current ICM-42688-P datasheet.

## 1. Architecture and Loop Rates

```
                  IMU 8 kHz ─► calib ─► notch bank ─► fusion ─► LPF ─┐
                                                                     ▼
 θ_ref ─►[Angle P/PI 1 kHz]─ω_ref─►[Velocity PI 4 kHz]─i_q*─►(+)─►[Current PI 20 kHz]─►SVPWM
              ▲                         ▲                    ▲            ▲
         attitude (Mahony)       ω_meas (gyro⊕PLL)      i_q,ff cogging   i_dq ◄─ Park ◄─ Clarke ◄─ ADC
                                                                          θ_e ◄─ encoder
```

| Loop | Rate | Target closed-loop bandwidth |
|---|---|---|
| Current (dq) | 20 kHz (PWM-synchronous) | ω_c ≈ 2π·1.5 kHz |
| Velocity | 4 kHz | ω_v ≈ 2π·150 Hz |
| Angle | 1 kHz | ω_θ ≈ 2π·30 Hz |
| IMU sampling | 8 kHz, decimated to 4 kHz after filtering | — |

Rule of thumb: keep a bandwidth separation of at least 4–10× between nested loops, and keep each loop's bandwidth below roughly 1/10 of its sample rate.

## 2. FOC Current Loop

### 2.1 Transforms

Clarke transform, power-invariant-free form, assuming i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau_e = K_t\, i_q,\qquad K_t = \tfrac32 p \lambda_m$$

### 2.3 Controller: PI with pole-zero cancellation and decoupling

Choose PI gains so the PI zero cancels the electrical pole R/L:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

With this choice the closed loop reduces to a first-order system: i/i* = ω_c/(s + ω_c).

Add the cross-coupling and back-EMF terms as feedforward:

$$v_d = \mathrm{PI}_d(e_d) - \omega_e L i_q,\qquad v_q = \mathrm{PI}_q(e_q) + \omega_e L i_d + \omega_e \lambda_m$$

### 2.4 Voltage limiting and anti-windup

Limit the voltage vector to the linear SVPWM region:

$$|v_{dq}| \le V_{dc}/\sqrt3$$

Apply a d-axis-priority circular clamp:
- Clamp v_d to ±V_max first.
- Then limit v_q to ±√(V_max² − v_d²).

Integrator update with back-calculation anti-windup (Tustin/forward-Euler), where u is the unsaturated output and u_sat the clamped output:

$$x_{k+1} = x_k + K_i T_s e_k + K_{aw} T_s (u_{sat} - u)$$

Use K_aw ≈ K_i/K_p.

### 2.5 SVPWM (min-max zero-sequence injection)

$$v_{abc} = \text{invClarke}(v_{\alpha\beta}),\quad v_0 = -\tfrac12(\max v_{abc} + \min v_{abc}),\quad d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$
