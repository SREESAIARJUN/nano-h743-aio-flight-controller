## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms

The Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

The Park transform, with electrical angle θ_e = p·(θ_m − θ_offset) and p = 7 pole pairs:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant and decoupling

The surface-PMSM model (L_d = L_q = L) is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

The feedforward decoupling terms cancel the cross-coupling and back-EMF:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m$$

### 2.3 PI with pole-zero cancellation

Each axis is a first-order plant, $G(s) = 1/(Ls+R)$. With the PI controller $C(s) = K_p + K_i/s$, set:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The closed loop then becomes $\omega_c/(s+\omega_c)$. Choose $\omega_c \le 2\pi f_s/20$; at 20 kHz that gives $\omega_c \approx 2\pi\cdot 1\,\text{kHz}$.

### 2.4 Discrete PI with back-calculation anti-windup

$$u_k = K_p e_k + I_k + u^{ff}_k,\qquad \bar u_k = \text{sat}(u_k)$$
$$I_{k+1} = I_k + T_s\left[K_i e_k + K_{aw}(\bar u_k - u_k)\right],\qquad K_{aw}\approx K_i/K_p$$

For the d/q current loop, saturate the vector, not each axis:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}\,m_{max}$$

Give the d-axis priority, then let the q-axis use the remaining voltage:

$$v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$$

### 2.5 SVPWM via min-max injection

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12(\max + \min),\quad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 3. Mechanical Cascade

### 3.1 Velocity estimation (encoder PLL, 20 kHz)

$$e_\theta = \text{wrap}(\theta_{enc} - \hat\theta),\quad \hat\omega \mathrel{+}= T_s K_{i,pll}\, e_\theta,\quad \hat\theta \mathrel{+}= T_s(\hat\omega + K_{p,pll} e_\theta)$$

Gains: $K_{p,pll} = 2\zeta\omega_{pll}$, $K_{i,pll} = \omega_{pll}^2$, with $\omega_{pll}\approx 2\pi\cdot 300$ Hz and ζ = 1. This is far smoother than differentiating the encoder signal.

### 3.2 Velocity loop (5 kHz)

The plant is $\omega/i_q = K_t/(Js + b)$. With target bandwidth $\omega_v \approx 2\pi\cdot 80$ Hz:

$$K_{p,v} = \frac{J\,\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{4}$$

The command is:

$$i_q^* = \text{PI}_v(\omega^* - \hat\omega) + \underbrace{\frac{J\dot\omega^*}{K_t}}_{\text{accel FF}} + \underbrace{\frac{b\,\omega^* + \tau_c\,\text{sgn}(\omega^*)}{K_t}}_{\text{friction FF}} + i_{q,cog}(\hat\theta)$$

A first-order low-pass (PT1) filter at about 3ω_v on the integrator-free derivative-like terms keeps the feedforward noise-free.

### 3.3 Angle loop (1 kHz)

Use P-only control, since the velocity PI already supplies the integral action:

$$\omega^* = K_{p,\theta}\,\text{wrap}(\theta^* - \hat\theta) + \omega^{ff},\qquad K_{p,\theta}\approx \omega_v/4$$
