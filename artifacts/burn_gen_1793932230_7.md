# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification

I don't have the Job #18 brief, so this design states its assumptions explicitly. Every assumed value is collected in one parameter section, so you can substitute the real numbers in one place.

---

## 0. Assumptions & System Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (GBM2804-class): 12N14P, p = 7 pole pairs, R ≈ 5 Ω, L ≈ 1.5 mH (phase), K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI, read at the current-loop rate |
| Current sense | 2- or 3-shunt inline, ADC synchronized to PWM center |
| MCU | STM32G474 / H7 (FPU, ≥170 MHz) |
| PWM | 20 kHz center-aligned |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, FIFO disabled (data-ready interrupt) |
| Kinematics | Yaw (outer, ψ) → Roll (φ) → Pitch (inner, θ) |
