# Job #42: STM32H743 Nano FC + 4-in-1 80A ESC Power & Timing Model

## 0. Architecture Clarification

**The STM32H743 does not commutate the motors.** ArduPilot runs only on the flight controller side. A 4-in-1 ESC that supports bidirectional DShot needs one ESC MCU per motor running ESC firmware, such as AM32 on an AT32F421 or STM32G071, or Bluejay on an EFM8. The architecture modeled here is:

```
STM32H743 (ArduPilot FC) --4x BDShot600--> 4x ESC MCU --> 4x 3-phase gate driver --> 24x MOSFET
```

I selected the device parameters below as representative assumptions, and every equation is parametric. **Substitute your actual MOSFET datasheet values (worst-case max, not typical) before release.**

### Baseline Assumptions

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1+\alpha (T_j-25)]$$

At a design T_j of 110 °C:

$$R_{hot} = 1.5\,\text{mΩ} \times 1.425 = 2.14\,\text{mΩ}$$

### 1.2 Bridge Conduction (Six-step, Synchronous Complementary PWM)

At any instant, the current flows through exactly two conducting channels:
- The high-side FET, or the synchronous low-side FET of the PWM leg (complementary), and
- The return low-side FET.

Therefore:

$$P_{cond,bridge} = 2\,I_{ph}^2\,R_{hot} \quad(\text{independent of } D \text{ when synchronous})$$

$$P_{cond,bridge} = 2 \times 80^2 \times 2.14\times10^{-3} = \mathbf{27.4\ W}$$

### 1.3 Per-FET Breakdown

Each phase leg is active for 120° of the 360° electrical cycle.

- **Average per FET:** ≈ 27.4/6 = **4.57 W**
- **Instantaneous during its conduction interval:** I²R = **13.7 W**

The instantaneous figure matters for thermal ripple only at low eRPM, where the electrical period is longer than about 10 ms (the junction τ).

### 1.4 Copper Losses (Do Not Ignore)

$$P_{Cu} = I^2 \frac{\rho\, \ell}{w\, t}\,,\quad \rho_{Cu}(100°C)=2.2\times10^{-8}\,\Omega m$$

For a phase path 15 mm long, 4 mm wide, on 2 layers of 70 µm:

- R ≈ 0.59 mΩ
- P ≈ **3.8 W per phase pad path**, with roughly two paths active, giving **≈ 7.5 W per motor**

This is often comparable to a quarter of the FET loss. Stitch phase pours across ≥4 layers.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. The return low-side FET is static within a commutation step.

### 2.1 Gate Currents Through the Miller Region

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_g} = 1.4\,\text{A}, \qquad I_{g,off} = \frac{V_{pl}}{R_g} = 0.6\,\text{A}$$

$$t_{r} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = 7.1\,\text{ns}, \qquad t_{f} = \frac{Q_{gs2}+Q_{gd}}{I_{g,off}} = 16.7\,\text{ns}$$

### 2.2 Loss Terms (per motor bridge)

| Term | Equation | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw | ½·25.2·80·23.8n·48k = **1.15 W** |
| Reverse recovery | Q_rr·V·f_sw | 60n·25.2·48k = **0.073 W** |
| C_oss (hard switched) | C_oss·V²·f_sw | 1n·635·48k = **0.030 W** |
| Dead-time body diode | V_f·I·2t_dt·f_sw | 0.8·80·200n·48k = **0.61 W** |
| Gate drive (dissipated in driver/R_g) | 2·Q_g·V_drv·f_sw | **0.029 W** |
| **Total switching** | | **≈ 1.89 W** |

### 2.3 Key Sensitivities

- **Dead-time diode loss is the second-largest switching term.** Cutting t_dt from 100 ns to 50 ns saves about 0.3 W per motor. Verify shoot-through margin first.
- **Switching loss scales linearly with f_sw.** At 24 kHz the total is about 0.95 W per motor, but you trade this for current ripple.
  - Ripple: ΔI ≈ V·D(1−D)/(L·f_sw)
  - For low-inductance motors (L ≈ 15 µH), the ripple at 48 kHz is already about 9 A p-p at D = 0.5.

### 2.4 Total Burst Dissipation

| Scope | Value |
|---|---|
| Per motor: FET conduction + switching + copper | 27.4 + 1.9 + 7.5 = **36.8 W** |
| All four motors at 80 A | **≈ 147 W** |
| Efficiency check (≈ 80 A·D·V_bus × 4 output at high D) | ~95% |

The efficiency is acceptable, but the absolute heat is the problem (Section 3).
