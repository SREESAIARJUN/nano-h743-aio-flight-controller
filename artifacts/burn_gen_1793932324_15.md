# STM32H743 AIO Flight Controller with 4-in-1 ESC (Job #22): Design Model

## 0. Scope and Assumptions

**Architecture.** The STM32H743 is the flight controller. It runs ArduPilot and generates bi-directional DShot600. The 4-in-1 ESC section uses one small MCU per motor, assumed here to be AT32F421 running AM32, plus a 3-phase gate driver and 6 MOSFETs per channel. The H743 does not commutate motors.

**Placeholder MOSFET.** No part has been selected, so every number below derives from these assumed parameters. Substitute real datasheet values.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Voltage rating | V_DS | 40 V, PDFN 3.3×3.3 or 5×6 class |
| On-resistance at 25 °C, V_GS = 10 V | R_ds25 | 1.0 mΩ |
| Temperature coefficient of R_ds | α | 0.005 /K |
| Total gate charge | Q_g | 60 nC |
| Gate-drain charge | Q_gd | 12 nC |
| Post-threshold gate-source charge | Q_gs2 | 8 nC |
| Output charge | Q_oss | 40 nC |
| Reverse-recovery charge | Q_rr | 40 nC |
| Body-diode forward voltage | V_sd | 0.8 V |
| Internal gate resistance | R_g,int | 1 Ω |
| Miller plateau voltage | V_pl | 4.5 V |

**Operating point:**
- Supply: 6S, V_bus = 25.2 V (full charge, worst case).
- Gate drive: V_drv = 10 V.
- Switching frequency: f_sw = 48 kHz.
- Burst current: I = 80 A per motor, all four motors simultaneously (worst case), duty D ≈ 0.95.
- Commutation: 6-step trapezoidal with complementary (synchronous) PWM on the high side.

**Feasibility warning.** 80 A per channel on a nano-format board, roughly 30×30 mm, is only achievable as a short, time-limited burst. Section 3 shows that the board is heat-capacity-limited, not heat-sink-limited. The output of this model is therefore a burst-duration limit, not a continuous rating.

## 1. Conduction Loss Model

### 1.1 Current path
In 6-step drive, current always flows through two phase legs in series:
- **PWM leg:** the high-side FET conducts for duty D. The low-side synchronous FET conducts for (1 − D).
- **Static leg:** the low-side FET conducts continuously during that 60° sector.

So at every instant exactly two FETs are in the current path.

### 1.2 Temperature-dependent on-resistance
```
R_ds(Tj) = R_ds25 · [1 + α(Tj − 25)]
At Tj = 125 °C:  R_ds = 1.0 mΩ × 1.50 = 1.50 mΩ
At Tj = 135 °C:  R_ds = 1.55 mΩ   (used below; confirmed by iteration in §3.4)
```

### 1.3 Ripple contribution
Treat the phase current as DC plus a triangular ripple:
```
I_rms² = I² + ΔI²/12
ΔI ≈ V_bus · D(1−D) / (L_ph · f_sw)
```
For a typical low-inductance motor (L_ph ≈ 10 µH, phase-to-phase), ΔI ≈ 2.5 A. The ripple term is therefore negligible (< 0.01 %), so I_rms ≈ I.
