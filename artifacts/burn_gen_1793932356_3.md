# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #36): Engineering Model

## 0. Scope and Governing Assumptions

**Read this first.** No MOSFET part number, stack-up, or enclosure was specified, so this model uses a defined reference design. Every number below follows from the parameters in §0.2. Substitute your vendor datasheet values into the same equations before you release anything.

### 0.1 System architecture

The STM32H743 does not commutate the motors directly. It runs ArduPilot and generates bidirectional DShot600. Each of the four ESC channels has its own MCU (AT32F421 running AM32), which handles 48 kHz complementary PWM, commutation, and the eRPM telemetry reply.

```
6S LiPo ─┬─ TVS/bulk ─┬─ 4× [AM32 MCU → 3-ph gate driver → 6× N-FET] → motors
         │            └─ 0.1 mΩ shunt → INA/amp → H743 ADC
         └─ Buck 5V/3.3V → STM32H743VIT6 (LQFP100) → IMU(SPI1), OSD/Flash(SPI2/3)
                                     └─ TIM1 CH1-4 ⇄ bidir DShot600 ⇄ ESC MCUs
```
