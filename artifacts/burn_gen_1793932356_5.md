# 4-in-1 ESC + STM32H743 Nano FC: Engineering Model (Job #49)

## 0. Architecture and Assumptions

**The H743 should not commutate the motors directly.** It has only two advanced timers (TIM1/TIM8) with 3 complementary pairs each, which is enough for 2 motors, not 4. It also cannot run ArduPilot's fast loop alongside four sensorless BEMF commutation loops without risking jitter. The architecture modelled here is therefore:

```
STM32H743 (ArduPilot) ──DShot600 bidir (×4)──► 4× ESC MCU (AT32F421/STM32G071, AM32 @ 48 kHz)
                                                 └─► 3-ph gate driver ─► 6× N-MOSFET per motor (24 total)
```
