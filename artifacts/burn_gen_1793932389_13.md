# STM32H743 Nano FC + 4-in-1 80A ESC (Job #71): Architecture, Loss Model, DShot/DMA Allocation, Netlists, Thermal Budget

## 0. Scope, Assumptions and Architecture Corrections

I don't have a part list or stack-up for Job #71, so every number below rests on the stated assumptions. Each equation is parameterized so you can substitute real datasheet values.

**Architectural clarification.** The STM32H743 should not drive the power stage directly. In this class of product the H743 runs ArduPilot (the FC). It sends bidirectional DShot600 to four dedicated ESC MCUs running AM32 or BLHeli_32-class firmware. Those MCUs drive gate drivers and MOSFETs. The models below follow that split.

| Parameter | Assumed value |
|---|---|
| Battery | 6S LiPo: V_bus,max = 25.2 V, nominal 22.2 V |
| Burst current | I_ph = 80 A per motor, ≤ 2 s, all four motors simultaneously (worst case) |
| PWM | f_sw = 48 kHz, complementary (synchronous) PWM, 6-step trapezoidal |
| MOSFET (per position) | 40 V, DFN 3.3×3.3, single FET per position |
| R_DS(on) | 1.0 mΩ @ 25 °C, V_GS = 10 V; tempco α = 0.005 /K |
| Gate charge | Q_g = 40 nC, Q_gd = 8 nC, Q_rr = 30 nC, Q_oss = 40 nC, V_SD = 0.8 V |
| Gate drive | 10–12 V, effective ~1 A source/sink |
| Dead time | t_dt = 100 ns per edge |
| Edge times | t_r = t_f = 15 ns (V–I overlap) |
| Board | 30.5×30.5 mm mounting, 8-layer, 2 oz on all layers |
| Ambient | 40 °C with prop-wash airflow |

**Sanity flag.** 80 A × 25.2 V is about 2 kW per channel, and about 8 kW across a board the size of a postage stamp. As the analysis below shows, this is only survivable as a short transient. "80A burst" must be specified with a duration, and firmware current limiting must enforce it.

## 1. Conduction Loss Model

### 1.1 Current paths in 6-step complementary PWM

In any 60° commutation sector:
- One phase leg is PWM-switching. Its high-side (HS) FET conducts for D·T_sw and its low-side (LS) FET for (1−D)·T_sw, excluding dead time.
- A second phase's LS FET is held ON for the whole sector.
- The third phase floats (back-EMF sensing).

So, ignoring dead time, **exactly two FETs carry I_ph at every instant**:

$$P_{cond,ch} = I_{ph}^2 \left[D\,R_{HS} + (1-D)\,R_{LS} + R_{LS,static}\right] \approx 2\,I_{ph}^2\,R_{DS}(T_j)$$
