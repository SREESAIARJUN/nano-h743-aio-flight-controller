## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motors, 12N14P (pole pairs p = 7, slots Nₛ = 12), e.g. GBM2804-class |
| Commutation and velocity sensor | 14-bit absolute magnetic encoder per axis (MT6701 / AS5048A), SPI |
| Current sensing | 2-shunt low-side, sampled at the PWM centre |
| MCU | Cortex-M4F/M7 (STM32G4/H7), single-precision FPU |
| Attitude sensors | 2× ICM-42688-P on the camera plate, SPI, gyro and accel ODR = 8 kHz |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

**Loop rates, chosen to keep at least 5× bandwidth separation between nested loops:**

```
PWM 20 kHz ─► ADC ─► CURRENT LOOP (20 kHz, BW ≈ 1.5 kHz)
                       ▲ iq*
IMU 8 kHz ─► fusion ─► VELOCITY LOOP (4 kHz, BW ≈ 150–250 Hz)  ◄─ cogging FF
                       ▲ ω*
               ATTITUDE LOOP (1 kHz, BW ≈ 20–40 Hz)  ◄─ user/RC/follow setpoint
```

## 1. Field-Oriented Control Equations

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

Here θ_{m,0} is the encoder offset. It is found once at calibration by aligning the rotor with a d-axis voltage vector (v_d = V_align, v_q = 0, θ_e = 0) and reading θ_m.

**Delay compensation.** The PWM update lags the ADC sample by about 1.5 Tₛ, so the electrical angle used for the inverse Park transform is advanced:

$$\theta_e' = \theta_e + 1.5\,\omega_e T_s$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

$$i_\alpha = i_a, \qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.3 Plant model in the d-q frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

$$\tau = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.4 Current PI controller with decoupling

The controller uses pole-zero cancellation. The closed loop becomes first order with bandwidth ω_c:

$$K_{p,i} = L\,\omega_c, \qquad K_{i,i} = R\,\omega_c$$

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L_q i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e (L_d i_d + \lambda_m)$$

The command is i_d\* = 0, since a surface-PM motor gives no reluctance torque.
