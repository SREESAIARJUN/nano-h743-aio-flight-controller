# 3-Axis Gimbal: FOC Control, Anti-Cogging Compensation, and Dual ICM-42688-P Fusion

I don't have the Job #28 specification, so this design is parameterized. Every motor, inertia and timing constant sits in a config struct. The defaults are typical values for a 2208/4108-class gimbal motor driven by an STM32G4/H7-class MCU. Replace them with your measured values.

---

## 0. Assumptions and Loop Timing

| Item | Default | Notes |
|---|---|---|
| Motor | 12N14P (pole pairs `p = 7`, slots `Ns = 12`) | Phase resistance `R` = 5–12 Ω, inductance `L` = 1–3 mH |
| Encoder | 14-bit magnetic (AS5048A or MT6701) | Read in the FOC ISR |
| Bus voltage | 12–16 V | |
| PWM / FOC current loop | 20 kHz | Center-aligned, ADC sampled at the PWM midpoint |
| IMU ODR | 8 kHz per chip | Each ICM-42688-P on its own SPI bus, using FIFO or DRDY |
| Velocity loop | 4 kHz | Fed by decimated, filtered gyro |
| Attitude / angle loop | 1 kHz | |
| IMU geometry | Two IMUs on the camera plate, mounted symmetrically about the payload center (`r₂ ≈ −r₁`) | Required for the lever-arm cancellation in §3.3 |

Rate separation follows the rule of thumb that each outer loop's bandwidth should be at most 1/5 to 1/10 of the next inner loop's:

- current loop ≈ 1.5–2 kHz
- velocity loop ≈ 150–250 Hz
- attitude loop ≈ 20–40 Hz

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

Clarke transform (two-shunt sensing, using $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
