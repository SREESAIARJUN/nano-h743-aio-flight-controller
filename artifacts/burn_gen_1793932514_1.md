# STM32H743 AIO Flight Controller + 4-in-1 ESC: Engineering Design Package (Job #47)

## 0. Scope, Architecture, and Assumptions

**Architecture.** The STM32H743 runs ArduPilot as the flight controller. It does not drive the MOSFETs directly. It sends bidirectional DShot600 to four dedicated ESC MCUs (AT32F421 running AM32 is assumed). Each ESC MCU drives a 3-phase gate driver and a 6-FET bridge. This partitioning is standard and keeps commutation timing off the FC's scheduler.

**Form factor.** At 80 A burst with four channels, a true 20×20 "nano" footprint cannot dissipate the losses calculated below. This design assumes 30.5×30.5 mm mounting on a 36×36 mm, 8-layer board with 2 oz inner copper. If 20×20 is a hard requirement, burst current must be derated (see §2.7).

## 1. Electrical Loss Model (per ESC channel)

### 1.1 Commutation conduction topology

Assume 6-step trapezoidal drive with complementary (synchronous) PWM on one leg. During each 60° sector:

- **PWM leg, high-side (HS):** conducts phase current I for fraction D.
- **PWM leg, low-side (LS, synchronous):** conducts for fraction (1−D).
- **Return leg, LS:** conducts 100% of the time.

### 1.2 Conduction loss

$$P_{cond} = I^2 R_{ds}(T_j)\,[D + (1-D) + 1] = 2\,I^2 R_{ds}(T_j)$$

Under synchronous rectification, total conduction loss is **independent of duty cycle**. This is a key result. The temperature dependence is:

$$R_{ds}(T_j) = R_0\,[1 + \alpha (T_j - 25)]$$

Evaluating at I = 80 A:

| T_j | R_ds | P_cond per channel |
|---|---|---|
| 25 °C | 1.20 mΩ | 2·6400·1.2e-3 = **15.4 W** |
| 100 °C | 1.74 mΩ | **22.3 W** |
| 125 °C | 1.92 mΩ | **24.6 W** |

### 1.3 Switching losses at 48 kHz

Only the PWM leg switches. There is one hard-switched turn-on and one turn-off per PWM period.

**V–I overlap loss:**

$$P_{VI} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw} = 0.5 \cdot 25.2 \cdot 80 \cdot 50\text{ns} \cdot 48\text{k} = \mathbf{2.42\ W}$$

**Coss loss:**

$$P_{oss} = \tfrac{1}{2} C_{oss,eff} V_{bus}^2 f_{sw} \cdot 2 = 1.5\text{n}\cdot 635 \cdot 48\text{k} = \mathbf{0.046\ W}$$
