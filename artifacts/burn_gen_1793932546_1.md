## 0. Assumptions and System Topology

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class with single‑precision FPU and CORDIC (optional) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R_s ≈ 5–15 Ω, L_s ≈ 2–5 mH |
| Rotor sensor | 14‑bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| IMU‑P | ICM‑42688‑P on the **payload** (camera plate). Used for attitude and as the stabilization feedback. |
| IMU‑B | ICM‑42688‑P on the **base** (handle/airframe). Used for disturbance feed‑forward and vibration‑frequency estimation. |
| Kinematic chain | Base → Yaw (q₁) → Roll (q₂) → Pitch (q₃) → Payload |

Loop rates (all phase‑locked to the PWM timer):

| Loop | Rate | Ts |
|---|---|---|
| Current (FOC) | 20 kHz | 50 µs |
| Velocity | 4 kHz | 250 µs |
| Angle / attitude | 1 kHz | 1 ms |
| IMU ODR | 8 kHz | FIFO read every velocity tick, 2 samples |

The control structure is:

```
                  ┌───────── attitude/angle loop (1 kHz) ─────────┐
θ_ref ─►(+)─► P ──►(+)◄── ω_ff (−R·ω_base, trajectory rate)       │
         ▲−        │                                              │
         │         ▼        velocity loop (4 kHz)                 │

           ω̂ (IMU‑P gyro → notch → LPF → J⁻¹) i_q* ─► PI_dq + decoupling ─► SVPWM ─► motor
```

## 1. Field‑Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$
\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi
$$

Here θ₀ is the encoder offset. It is found by applying a d‑axis voltage vector at θ_e = 0 and reading the encoder.

### 1.2 Clarke transform (amplitude‑invariant, 3 shunts, i_a + i_b + i_c = 0)

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

### 1.3 Park transform

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.4 Plant model (surface PMSM, L_d = L_q = L)

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

### 1.5 PI with decoupling and back‑EMF feed‑forward

$$
v_d^* = PI_d(i_d^*-i_d) - \omega_e L i_q,\qquad
v_q^* = PI_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m
$$

**Tuning by pole–zero cancellation** of 1/(Ls+R), with current bandwidth ω_c ≈ 2π·1.5 kHz (well below 20 kHz/10):

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c
\quad\Rightarrow\quad \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}
$$

**Discrete form.** Use backward Euler on the integrator, and apply anti‑windup by circular limiting of the voltage vector:

$$
I_k = I_{k-1} + K_i T_s e_k,\qquad v^* = K_p e_k + I_k
$$

$$
\text{if } \sqrt{v_d^2+v_q^2} > V_{max}=\tfrac{V_{bus}}{\sqrt3}:\ \text{scale } v,\ \text{and freeze } I \text{ (conditional integration)}
$$

### 1.6 Inverse Park and SVPWM (min/max zero‑sequence injection)

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

$$
v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta
