# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion Design

I don't have the "Job #17" spec, so this design uses the assumptions below. Every one of them is a single constant in the code (`GimbalConfig`). Change them to match your hardware.

| Item | Assumption |
|---|---|
| MCU | STM32G4 / Cortex-M4F @ 170 MHz, single-precision FPU |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sensing | 2-shunt low-side inline (a voltage-mode fallback is included) |
| IMU A | ICM-42688-P on the **camera plate**: attitude and rate feedback |
| IMU B | ICM-42688-P on the **base/handle**: disturbance feedforward and vibration-frequency estimation |
| Gimbal order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
| Loop rates | Current 20 kHz · Rate 4 kHz · IMU ODR 8 kHz · Attitude 1 kHz |

## 1. Control Architecture

```
            ┌──────────── 1 kHz ────────────┐┌────────── 4 kHz ──────────┐┌──── 20 kHz ────┐
 q_ref ──►[Quaternion P + ω_ff]──ω_cam*──►(−)──[J⁻¹]──►[PI_rate,j]──►(+)──►[PI_d,q + decoupling]──►SVPWM──►Motor j
               ▲                   ▲        │ ω̂_cam         ▲  τ_cog_ff/Kt ──┘        ▲
               │                   │        │               │                         │ i_abc, θ_e
            q̂ (Mahony)    base FF: −J⁻¹M ω̂_base            │                       Encoder
               ▲                            │           Anti-cogging
     IMU A ─[AAF]─[ANF×2]─[LPF]─────────────┘           Fourier LUT(θ_m)
     IMU B ─[AAF]─[ANF×2]─[LPF]──► ω̂_base, vibration f₀ estimate ──► seeds IMU A notches
```
