# STM32H743 Nano FC + 4-in-1 ESC (Job #39): System Architecture Model

## 0. Scope and Architectural Assumptions

Before the math, three constraints shape everything below:

1. **The H743 does not commutate the motors.** A 4-in-1 ESC runs one dedicated MCU per channel (e.g. AT32F421 or STM32G071 running AM32/BLHeli_32-class firmware). That MCU generates the 48 kHz bridge PWM. The H743 runs ArduPilot and sends bidirectional DShot600 commands. Driving 12 MOSFET gates plus BEMF sensing from the H743 is not viable alongside the flight stack.
2. **"80 A burst" means per-channel motor phase current, for a short duration.** On a nano (20×20 / 25.5×25.5 mm) form factor, I show below that this is a burst of a few seconds, not a continuous rating.
3. **Component values are representative placeholders.** Rds(on), Qg, Rθ, and thermal mass must be replaced with the selected part's datasheet values and validated on hardware (Section 6).

| Parameter | Symbol | Assumed value |
|---|---|---|
| Battery | V_bus | 6S, 25.2 V max (22.2 V nominal) |

## 1. Conduction Loss Model (80 A burst)

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C:

$$R_{ds}(110) = 1.2\,\text{m}\Omega \times [1 + 0.0058 \times 85] = 1.2 \times 1.493 = 1.79\,\text{m}\Omega$$

### 1.2 Current path in 6-step commutation with synchronous rectification

In each commutation sector, two phases conduct:

- **PWM leg:** current flows through the high-side FET for duty D, then through the complementary low-side FET for (1−D), excluding dead time.
- **Return leg:** the low-side FET is held on for the whole 60° sector.

At any instant, therefore, exactly **two** channel resistances carry the phase current, independent of D:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{ds}(T_j)$$

This assumes low ripple: with 48 kHz PWM and typical motor inductance (≥ 10 µH), I_rms ≈ I_avg. Add a ripple term when L is small:

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12}, \qquad \Delta I_{pp} = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

At 80 A:

$$P_{cond,ch} = 2 \times 80^2 \times 1.79\times10^{-3} = 22.9\,\text{W per channel}$$

### 1.3 Electrothermal coupling

Because R_ds depends on T_j, which depends on P, the solution must be iterated:

$$T_j^{(n+1)} = T_{ref} + P\big(T_j^{(n)}\big)\,R_{\theta}$$

This converges only if:

$$2\,I^2\,R_{ds25}\,\alpha\,R_\theta < 1$$

If the condition fails, the result is **thermal runaway** for continuous operation. This is the analytical reason 80 A must be time-limited.

### 1.4 Copper and shunt losses (often ignored, significant here)

| Element | Resistance | Loss @ 80 A |
|---|---|---|
| Current shunt (per channel, if used) | 0.25 mΩ | 1.6 W |
| PCB copper, 2 oz, bus to phase pad (est.) | 0.3 mΩ | 1.9 W |
| Phase wire pad + solder | 0.1 mΩ | 0.6 W |

The copper losses travel in shared heavy-copper planes. Use 3 oz internal planes on L2/L3 if the stackup allows.

## 2. Switching Loss Model at 48 kHz

Only the **PWM leg** hard-switches. The return-leg FET is static within a sector.

### 2.1 V-I overlap loss (hard switching, inductive load)

$$P_{VI} = \tfrac{1}{2}\,V_{bus}\,I_{ph}\,(t_r + t_f)\,f_{sw}$$

$$P_{VI} = 0.5 \times 25.2 \times 80 \times 40\times10^{-9} \times 48\,000 = 1.94\,\text{W}$$

### 2.2 Reverse recovery

$$P_{rr} = Q_{rr}\,V_{bus}\,f_{sw} = 30\text{n} \times 25.2 \times 48\text{k} = 0.036\,\text{W}$$

At 80 A, Q_rr rises roughly with di/dt. Take Q_rr at the actual di/dt from the datasheet curve.

### 2.3 Output capacitance

$$P_{oss} = \tfrac{1}{2}\,Q_{oss}\,V_{bus}\,f_{sw} = 0.5 \times 40\text{n} \times 25.2 \times 48\text{k} = 0.024\,\text{W}$$

### 2.4 Dead-time body-diode conduction

$$P_{dt} = V_f\,I_{ph}\,(2\,t_{dt})\,f_{sw} = 0.8 \times 80 \times 100\text{n} \times 48\text{k} = 0.31\,\text{W}$$

### 2.5 Gate drive

This loss is dissipated in the driver and gate resistors, not the FET:

$$P_{gate} = Q_g\,V_{gs}\,f_{sw} \times N_{switching} = 40\text{n} \times 10 \times 48\text{k} \times 2 = 0.038\,\text{W}$$
