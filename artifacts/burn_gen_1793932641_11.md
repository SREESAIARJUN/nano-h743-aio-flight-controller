## 0. Design Basis and Assumptions

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max / 22.2 V nominal | Worst-case switching uses 25.2 V |
| Burst current | 80 A per motor phase (DC-link equivalent) | 4 motors simultaneously is the worst case |
| Commutation | 6-step trapezoidal, H_PWM–L_ON, synchronous rectification | Typical AM32/BLHeli_32 behavior |
| f_sw | 48 kHz | |
| MOSFETs | 6 per motor, 24 total, single die per position | |
| Example MOSFET | 40 V, R_DS(on),25 = 1.2 mΩ max @ V_GS = 10 V; Q_g = 30 nC, Q_gs2 = 3 nC, Q_gd = 5 nC, V_pl = 3.5 V, Q_rr = 40 nC, Q_oss = 20 nC, V_SD = 0.8 V, R_θJC = 1.5 K/W, R_g,int = 1 Ω | **[VERIFY]** against the actual part |
| Gate drive | 10 V, driver R_out ≈ 2 Ω, R_g,ext = 4.7 Ω | |
| Dead time | 50 ns per edge | |
| FC MCU | STM32H743, SYSCLK 400 MHz, timer clock 200 MHz | ArduPilot default H743 clock tree |

> **Form-factor flag:** "Nano" (20×20 mm) and 4 × 80 A burst are fundamentally in tension. §2 shows the full-board burst budget is about 3 s even on a 30.5 mm-class board with a spreader. I recommend Job #47 confirm whether "80A" is a **per-motor, single-axis transient** rating. That is the only regime where the numbers close.
