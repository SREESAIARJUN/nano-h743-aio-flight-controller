## 0. Architecture Decisions and Red Flags

### 0.1 System partitioning

The STM32H743 runs ArduPilot as the flight controller. It does **not** commutate motors. ArduPilot has no motor-commutation firmware, so each ESC channel needs its own motor MCU running AM32 (or equivalent). Two options exist:

- **Recommended:** 4× AT32F421K8U7, one per motor, running AM32 with bidirectional DShot.
- **Alternative:** 1× MCU per 2 motors. This is not recommended because it adds latency and complicates timer sharing.

The H743 talks to each ESC MCU over an internal bidirectional DShot600 trace. These signals never leave the board.

### 0.2 Red flag: 80 A on a "nano" footprint

The model in §1 to §3 shows roughly **100 W of total dissipation at 4 × 80 A**. A 20×20 or 25.5×25.5 mm board has about 4–5 J/K of thermal mass and cannot sustain this. The design target is therefore:

| Rating | Value | Condition |
|---|---|---|
| Continuous | 35–40 A/ch | 30.5×30.5 mm board, prop-wash airflow |
| Burst | 80 A/ch for ≤ 1.5–2 s | Duty-cycled; derived in §3.4 |

If "nano" means 20×20, cut the burst rating to about 45–50 A. Any marketing rating should cite the burst duration and starting temperature.

## 1. Conduction Loss Model (80 A burst)

### 1.1 Current path in 6-step complementary PWM

The 360° electrical cycle has 6 sectors. In each sector, one phase high-side is PWM'd at duty D, one other phase's low-side is held ON, and the third phase floats (BEMF sensing).

With complementary PWM, current flows through exactly **two FETs at every instant**:

- **On-state:** HS(x) + LS(y)
- **Freewheel:** LS(x) + LS(y), via synchronous rectification instead of the body diode

Assuming flat-top phase current I (trapezoidal approximation), the time fraction each FET conducts per electrical cycle is:

```
High-side, phase x:  δ_HS = D / 3
Low-side,  phase x:  δ_LS = 1/3 (held ON as return leg) + (1−D)/3 (freewheel) = (2 − D) / 3
```

### 1.2 Per-FET and per-channel conduction loss

```
P_HS = I² · R_DS(T_j) · D/3
P_LS = I² · R_DS(T_j) · (2−D)/3

P_leg = I² R (D + 2 − D)/3 = (2/3) I² R
P_cond,ch = 3 · P_leg = 2 · I² · R_DS(T_j)        ← independent of D
```
