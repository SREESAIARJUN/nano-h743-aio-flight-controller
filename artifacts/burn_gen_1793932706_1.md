## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701), SPI |
| Current sense | 2 or 3 low-side shunts, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera platform, SPI, gyro/accel ODR 8 kHz |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

**Loop rates and bandwidths.** Rule: each outer loop runs ≥ 5× slower in bandwidth than the loop inside it.

| Loop | Rate | Closed-loop BW | Feedback |
|---|---|---|---|
| Current (d/q PI) | 20 kHz (PWM ISR) | ~1.5–2 kHz | Shunts + encoder θe |
| Velocity (PI + ff) | 4 kHz | ~150–250 Hz | Fused gyro rate projected on joint axis |
| Angle (P/PI + ff) | 1 kHz | ~20–40 Hz | Fused attitude (Mahony), per-axis error |
| Anti-cogging (LMS) | 4 kHz | — | Velocity-loop effort, mechanical angle θm |
| IMU filter + fusion | 8 kHz | — | 2 × ICM-42688-P |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

The offset θ_off is found at commissioning by applying v_d > 0 with θ_e = 0 and reading θ_m.

### 1.2 Clarke transform (power-invariant amplitude form, balanced currents)

$$i_\alpha = i_a, \qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the dq frame (SPM motor, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q, \qquad v_q = R i_q + L \dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque: $\tau = \tfrac32 p \lambda_m i_q = K_t i_q$.

### 1.5 PI with decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q, \qquad v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Tuning by pole-zero cancellation.** For a target bandwidth ω_c, the closed loop becomes $\omega_c/(s+\omega_c)$ when

$$K_p = L\,\omega_c, \qquad K_i = R\,\omega_c$$

Use ω_c ≤ 2π·f_PWM/10. The one-sample computation delay plus the PWM ZOH add roughly 1.5·T_s of delay. Use phase margin ≈ 90° − ω_c·1.5T_s·(180/π) to check that margin stays above 60°.

**Discretization (backward Euler with clamped integrator).**

$$x_k = \text{clamp}\big(x_{k-1} + K_i T_s e_k\big), \qquad u_k = K_p e_k + x_k$$

### 1.6 Voltage limit (circular) and SVPWM

Limit the voltage vector to the linear SVPWM region, $|v_{dq}| \le V_{dc}/\sqrt3$. Give d-axis priority:

$$v_d \leftarrow \text{clamp}(v_d, \pm V_{max}), \qquad v_q \leftarrow \text{clamp}\big(v_q, \pm\sqrt{V_{max}^2 - v_d^2}\big)$$

Apply the inverse Park transform to obtain v_α and v_β. Then use the min-max zero-sequence-injection form of SVPWM, which is equivalent to the sector form:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big), \qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

When the integrator is clamped by saturation, stop integration. This is conditional-integration anti-windup.
