# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification and C++ Implementation

I have no access to the specification for Job #38, so the design below rests on the assumptions in §0. Every parameter that depends on your hardware is a named constant. Change those constants and the derived gains, filter frequencies and cogging harmonics follow.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | 12N14P gimbal BLDC (GBM2804-class), p = 7 pole pairs, R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Driver | 3-phase, center-aligned PWM 20 kHz, 2-shunt or inline current sense, V_dc = 12–16 V |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) on each axis |
| IMUs | 2 × ICM-42688-P on the camera plate. Mounted symmetric about the pitch axis, and preferably on opposite sides of the PCB with one rotated 180° about z. |
| Host | Cortex-M4F/M7 with single-precision FPU |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |
