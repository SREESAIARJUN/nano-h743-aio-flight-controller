# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

I don't have the original Job #25 specification, so this design uses common gimbal-class parameters, listed in §0. Every gain is derived symbolically from those parameters, so you can substitute your measured values and recompute.

## 1. FOC Current Loop (innermost, 20 kHz)

### 1.1 Transforms

Clarke transform (amplitude-invariant, with $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

Park transform, with electrical angle $\theta_e = p\,\theta_m - \theta_{\text{off}}$:

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant and decoupling

In the rotor frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda)$$

Add the feedforward decoupling terms

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda).$$

With these terms each axis reduces to $G_i(s) = 1/(Ls+R)$.

### 1.3 PI design by pole-zero cancellation

Use the controller $C_i(s) = K_p + K_i/s$ and choose

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c.$$

The open loop becomes $\omega_c/s$, so the closed loop is first order: $i/i^* = \omega_c/(s+\omega_c)$.

The bandwidth is limited by the PWM/computation delay of about $1.5T_c$. Use $\omega_c \le 1/(10 T_c)$, which gives $\omega_c = 2\pi\cdot 1.5\,\text{kHz}$. With the default motor values:

- $K_p = 20.7$ V/A
- $K_i = 52{,}800$ V/(A·s)

### 1.4 Voltage limit, anti-windup, and SVPWM

Limit the voltage vector to the inscribed hexagon circle, $|v| \le V_{bus}/\sqrt3$. Prioritize $d$:

$$v_d \leftarrow \text{sat}(v_d,\ V_{max}),\qquad v_q \leftarrow \text{sat}\!\left(v_q,\ \sqrt{V_{max}^2 - v_d^2}\right)$$

Use back-calculation anti-windup, with $K_{aw} = K_i/K_p = 1/\tau_{el}$:

$$I_{k+1} = I_k + T\left[K_i e_k + K_{aw}(u_{sat} - u_{unsat})\right]$$

For SVPWM, use min-max zero-sequence injection, which is equivalent to classic 7-segment SVPWM:

$$v_{0} = -\tfrac12(\max(v_{abc}) + \min(v_{abc})),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Velocity Loop (5 kHz)

### 2.1 Plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

With the current loop modeled as $1/(\tau_c s+1)$ and $\tau_c = 1/\omega_c$:

$$G_v(s) = \frac{K_t}{J s\,(\tau_c s + 1)}\quad(B \text{ negligible})$$

### 2.2 Symmetric-optimum PI

Choose the crossover $\omega_v = \omega_c / a$ with $a = 4$ (about 61° phase margin):

$$K_{pv} = \frac{J\,\omega_v}{K_t},\qquad K_{iv} = \frac{K_{pv}\,\omega_v}{a}$$
