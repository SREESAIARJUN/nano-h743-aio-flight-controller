# 3-Axis Gimbal: FOC Motor Control, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

This design rests on assumptions that you should check against your hardware.

**Motors and electronics**
- **Motors:** PMSM gimbal motors, e.g. GM4108 class, 24N22P (24 slots, 22 poles, so 11 pole pairs).
- **Sensing:** a 14-bit absolute magnetic encoder on each motor shaft, plus in-line or low-side current sensing.

**Mechanics and sensors**
- **Joint order:** base → yaw (z) → roll (x) → pitch (y) → camera.
- **IMUs:** two ICM-42688-P on the camera plate, mounted point-symmetric about the camera center of mass. A different mounting (for example, one IMU on the base) only changes Section 4.3.

**Execution**
- **MCU:** Cortex-M4F/M7 class (STM32G4/H7) with an FPU.

## 1. Timing Architecture

| Loop | Rate | Bandwidth target | Input |
|---|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1.5 kHz | phase currents, encoder θ_e |
| IMU sampling | 8 kHz (ODR) | AAF ≈ 1 kHz | ICM-42688-P ×2 via SPI + DMA |
| Velocity | 4 kHz | ω_v ≈ 2π·150 Hz | fused gyro (inertial rate) |
| Angle / attitude | 1 kHz | ω_θ ≈ 2π·30 Hz | Mahony quaternion |
