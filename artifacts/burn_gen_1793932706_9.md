## 1. Loop Architecture and Timing

```
             1 kHz                4 kHz                    20 kHz
 q_ref ──► [Attitude P + FF] ──► [Velocity PI + FF] ──► [Iq PI] ─┐
              ▲  joint-space        ▲   joint-space        ▲      ├─► invPark ─► SVPWM ─► Bridge ─► Motor
              │  error J⁻¹·e        │   rate J⁻¹·ω          │ [Id PI]┘
              │                     │       + anti-cogging iq_ff(θm)
   Mahony ◄── Dual-IMU fusion ◄── notch/LPF ◄── 2×ICM-42688-P @ 8 kHz ODR
                                                  Encoder θm ──► θe = p·θm − θ0
```

**Bandwidth separation rule.** Each outer loop should be at least 4–5× slower than the loop inside it:

- ω_c (current) = 2π·1500 rad/s
- ω_v (velocity) = 2π·60
- ω_θ (angle) = 2π·12
