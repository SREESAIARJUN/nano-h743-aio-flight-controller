# STM32H743 Nano FC + 4-in-1 80A ESC (Job #29): Architecture, Loss Model, DShot DMA Plan, Netlists

## 0. Architecture Assumptions

These constraints shape the rest of the design.

1. **The H743 does not commutate the motors.** ArduPilot is flight-control firmware and has no ESC/commutation stack. The architecture is:
   - **STM32H743**: ArduPilot. Emits bi-directional DShot600 and receives eRPM telemetry.
   - **4× ESC MCUs** (AT32F421 / STM32G071 class) running AM32 or BLHeli_32-class firmware. These generate the **48 kHz** complementary PWM and handle commutation.
2. **"80A burst" is a thermal-capacity rating, not a steady-state rating.** On a 30×30 mm board, steady-state capability is far lower (see §3). The burst duration must be specified explicitly (assumed here: **≤ 2 s at 4×80A**, ≤ 10 s at 1×80A).
3. **Electrical baseline:**

| Parameter | Value |
|---|---|
| Bus | 6S, V_bus,max = 25.2 V |
| MOSFET class | 40 V, 5×6 mm or 3.3×3.3 mm DFN |
| R_DS(on) | 1.0 mΩ @ 25 °C (V_GS = 10 V), one FET per switch position (6 per motor, 24 total) |
| Gate driver | 3-phase bootstrap driver (FD6288Q class), ~0.3 A source / 0.6 A sink |
| Dead time | 300 ns |
| Board | 6-layer, 2 oz on all layers |

**Every part value below is a reference choice. Verify it against the actual datasheets before layout.**

## 1. Conduction Loss Model (80A Burst)

### 1.1 Current path

With 6-step trapezoidal drive and complementary (synchronous) PWM, current always flows through exactly **two FETs** in series:
- **PWM-on:** HS(phase A) → motor → LS(phase B)
- **PWM-off:** LS(phase A) freewheels → motor → LS(phase B)

So:

$$P_{cond,ch} = I_{rms}^2 \cdot \left(2R_{DS}(T_j) + R_{Cu}\right)$$

### 1.2 RMS including PWM ripple

$$I_{rms} = I_{avg}\sqrt{1 + \frac{1}{12}\left(\frac{\Delta I}{I_{avg}}\right)^2}, \qquad \Delta I = \frac{(V_{bus}-V_{bemf})\,D}{L_{ph-ph}\, f_{sw}}$$

Example: a typical 5" 6S motor has L_ph-ph ≈ 20 µH. At D = 0.5 and V_bus − V_bemf ≈ 12 V:

- ΔI = 12 · 0.5 / (20e-6 · 48e3) ≈ **6.25 A**
- I_rms ≈ 80 · (1 + 0.0005) ≈ **80.02 A**

Ripple is negligible at 48 kHz. This is one of the benefits of high f_sw.

### 1.3 Temperature-coupled R_DS(on)

$$R_{DS}(T_j) = R_{25}\left[1+\alpha\,(T_j-25)\right],\quad \alpha \approx 0.0045\ \text{K}^{-1}\ (\text{40 V trench, }\approx1.45\times\text{ at }125^\circ\text{C})$$

At T_j = 100 °C: R_DS = 1.0 · (1 + 0.0045 · 75) = **1.34 mΩ**

### 1.4 Copper path

Copper path per channel is R_Cu ≈ 0.25 mΩ. This covers the phase pad, the power planes and the vias from the battery pad to the FET drains.
