**Bandwidth separation rule.** Each outer loop is at least 5–10× slower than the loop inside it:

ω_c,i ≈ 2π·2000 rad/s, ω_c,v ≈ 2π·150 rad/s, ω_c,θ ≈ 2π·20 rad/s

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle

θ_e = wrap₂π( p·θ_m − θ_offset ), ω_e = p·ω_m

`θ_offset` is found at startup by applying a d-axis voltage (V_d > 0, V_q = 0) at θ_e = 0 and reading the encoder. Run this at several angles and average.

**Delay compensation.** Average transport delay is about 1.5·T_s. The angle used for the inverse Park transform is therefore:

θ̂_e = θ_e + 1.5·ω_e·T_s,i

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

i_α = i_a
i_β = (i_a + 2·i_b) / √3

### 1.3 Park transform

i_d = i_α·cos θ_e + i_β·sin θ_e
i_q = −i_α·sin θ_e + i_β·cos θ_e

### 1.4 dq plant (surface-mount PMSM, L_d = L_q = L)

v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ_m

Electromagnetic torque:

τ_e = (3/2)·p·λ_m·i_q = K_t·i_q

### 1.5 Current PI with pole-zero cancellation

The plant is G(s) = 1/(L·s + R). Choose:

K_p,i = L·ω_c,i, K_i,i = R·ω_c,i

The zero then cancels the electrical pole, and the closed loop becomes ω_c,i/(s + ω_c,i).

Discrete form (backward Euler), with back-calculation anti-windup (K_aw = 1/K_p,i is typical):

e[k] = i*[k] − i[k]
u[k] = K_p·e[k] + I[k] + u_ff[k]
u_sat[k] = sat(u[k])
I[k+1] = I[k] + K_i·T_s·e[k] + K_aw·(u_sat[k] − u[k])

Decoupling feedforward:

u_ff,d = −ω_e·L·i_q
u_ff,q = +ω_e·L·i_d + ω_e·λ_m
