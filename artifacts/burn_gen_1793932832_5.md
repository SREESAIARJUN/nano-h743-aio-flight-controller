## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC/PMSM, 14 poles (P=7 pole pairs), 12 slots, R≈5–10 Ω, L≈2–4 mH, surface PM (L_d ≈ L_q) |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701), SPI |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, ±2000 dps, ±4 g |
| MCU | Cortex-M4F/M7 with FPU, center-aligned PWM at 20 kHz |
| Bus | 12–16 V, 3 inverters (one per axis) |

**Loop rates**

```
20 kHz  PWM ISR  : ADC → Clarke/Park → PI current (d,q) → inv-Park → SVPWM
                   + encoder read + PLL velocity observer + cogging FF injection
 8 kHz  IMU DMA  : 2×ICM-42688 → notch/LPF → lever-arm comp → fusion
 4 kHz  velocity : PI velocity (per axis) → iq*
 1 kHz  attitude : Mahony AHRS → attitude error → per-joint angle P(I) → ω*
                   + dynamic notch retune, cogging LMS update
```

The bandwidth separation between loops is about 4–10× (current ≈ 2 kHz, velocity ≈ 150–300 Hz, angle ≈ 30–60 Hz).

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

**Park transform**, using electrical angle θ_e = P·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant Model in the dq Frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \psi_m)$$
$$\tau_e = \tfrac{3}{2} P\left[\psi_m i_q + (L_d - L_q) i_d i_q\right] \;\Rightarrow\; K_t = \tfrac32 P \psi_m$$

### 1.3 Current PI Controller with Decoupling

The cross-coupling and back-EMF terms are cancelled by feedforward:

$$v_d^* = \mathrm{PI}_d(i_d^* - i_d) - \omega_e L_q i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^* - i_q) + \omega_e (L_d i_d + \psi_m)$$

Gains are chosen by pole-zero cancellation for a target bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The closed loop is then first-order with bandwidth ω_c. Use ω_c ≤ 2π·f_PWM/10, which is about 2π·2000 rad/s at 20 kHz.
