# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Fusion

I don't have the Job #28 specification, so this design is built on stated assumptions. Every assumption is a named constant in the code, so you can substitute your real values.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–12 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701) |
| Current sensing | 2-phase inline shunts (voltage-mode fallback provided) |
| MCU | Cortex-M4F/M7 or STM32G4 class with single-precision FPU |
| IMUs | 2 × ICM-42688-P on separate SPI chip-selects, 8 kHz ODR, sampled synchronously |

**Loop rates (all integer-decimated from a single PWM-synchronous ISR):**

```
PWM / current loop (FOC)      20 kHz   Ts_i = 50 µs
IMU read + vibration filters   8 kHz   (data-ready interrupt, buffered)
Velocity loop + cogging FF     4 kHz   Ts_v = 250 µs   (÷5)
Angle loop + AHRS              1 kHz   Ts_a = 1 ms     (÷20)
Dynamic-notch retune, LMS      1 kHz
```

**Bandwidth separation rule.** Each loop is placed at least 4–5× below the loop it commands:

ω_c,i ≈ 2π·1500 rad/s, ω_c,v ≈ 2π·80–150, ω_c,a ≈ 2π·15–30.
