# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the Job #16 specification, so this design is built on the assumptions in §0. Every motor, mechanical and timing parameter is centralized in one configuration block. Change those values and the gains re-derive automatically.

---

## 0. Assumptions and System Architecture

### Hardware Baseline

| Item | Assumed value | Notes |
|---|---|---|
| Motors | 3× gimbal BLDC (e.g. GBM2804-class), 12N14P, p = 7 pole pairs | High-R, low-L gimbal winding |
| Phase resistance R_s | 5.0 Ω (line-neutral) | Measure per motor |
| Phase inductance L_s | 1.8 mH (L_d ≈ L_q) | SPM assumption |
| Torque constant K_t | 0.08 N·m/A | K_t = 1.5·p·λ_m |
| Bus voltage V_dc | 12 V | |
| Position sensor | 14-bit magnetic encoder (AS5048A/MT6701) on each axis | |
| Current sensing | 2 or 3 inline/low-side shunts | |
| IMU A | ICM-42688-P on the camera plate (payload) | The controlled attitude |
| IMU B | ICM-42688-P on the gimbal base (vehicle side) | Disturbance measurement / feedforward |
| MCU | Cortex-M4F/M7 (STM32G4/H7), single-precision FPU | |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera | Most common order |

### Loop Rates (Multi-Rate Cascade)

| Loop | Rate | Bandwidth target | Trigger |
|---|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1.5 kHz | PWM-center ADC interrupt |
| IMU sampling | 8 kHz ODR, 4 kHz consumed | n/a | IMU DRDY / DMA |
| Velocity | 4 kHz | ω_v ≈ 2π·60–100 Hz | Every 5th current ISR |
| Angle/attitude | 1 kHz | ω_a ≈ 2π·12–20 Hz | Every 4th velocity tick |

Bandwidth separation between cascade layers is at least 5×. That is the classical requirement for treating the inner loop as unity gain when designing the outer loop.
