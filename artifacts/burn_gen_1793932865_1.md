# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #59 spec sheet, so this design rests on the baseline assumptions in §0. Every motor- and frame-specific constant sits in one config struct, so you can substitute your real values without touching the math.

## 0. Baseline Assumptions

| Item | Value (adjust to your BOM) |
|---|---|
| MCU | STM32G474 @ 170 MHz (FPU, CORDIC, 3× ADC with injected channels) |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R_φ ≈ 5.5 Ω, L_φ ≈ 2.2 mH (line-to-neutral) |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) over SPI, sampled each current cycle |
| Current sensing | 3-shunt, low-side, sampled at PWM centre |
| PWM | 20 kHz centre-aligned, SVPWM |
| IMUs | 2× ICM-42688-P on the camera payload, mirrored about the pitch/roll pivot, SPI + DMA, gyro ODR 8 kHz |

**Loop rates and target bandwidths**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz | ≈ 1.5 kHz |
| Rate (gyro-feedback PID) | 4 kHz | ≈ 60–120 Hz |
| Attitude (quaternion-error P/PI) | 1 kHz | ≈ 10–25 Hz |
| Attitude estimator | 1 kHz | — |
| IMU filtering | 8 kHz | — |

**Signal flow**

```
 IMU A ─┐  on-chip AAF+notch   ┌─ lever-arm comp ─┐
        ├──────────────────────┤                  ├─► fused ω, a ─► dyn. notch ×2 ─► LPF ─┬─► rate loop (4 kHz)
 IMU B ─┘                      └─ fault/χ² check ─┘                                     └─► Mahony (1 kHz) ─► attitude loop
 attitude loop ─► ω*  ─► rate PID ─► τ* ─► (+ cogging FF + friction FF) ─► i_q* ─► FOC current PI ─► SVPWM
 encoder θ_m ─► θ_e = pθ_m − θ_off  (commutation, cogging basis, joint Jacobian)
```
