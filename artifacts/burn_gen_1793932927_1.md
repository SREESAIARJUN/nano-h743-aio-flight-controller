# STM32H743 Nano FC + 4-in-1 80A ESC: Systems Architecture Model (Job #21)

## 0. Architectural Clarification and Stated Assumptions

**Partitioning.** In a 4-in-1 stack, the STM32H743 does not switch the MOSFETs. The H743 runs ArduPilot and emits bidirectional DShot600. Each ESC channel has its own MCU, which generates the 48 kHz complementary PWM through a gate driver. The H743 therefore owns the DShot/DMA problem, and the ESC MCUs own the switching and thermal problem. The model below is split the same way.

**No component datasheets were provided.** All numbers use a representative 40 V PDFN5×6 MOSFET and a 6S bus. Every equation is parametric, so you can substitute your actual BOM values.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S full) | V_bus | 25.2 V |
| Burst phase current per channel | I_ph | 80 A |
| PWM frequency | f_sw | 48 kHz |
| R_DS(on) max @ 25 °C, V_GS = 10 V | R₂₅ | 1.0 mΩ |
| R_DS(on) temperature coefficient | α | 0.0045 /K |
| Q_gs2 / Q_gd / Q_g | | 5 / 12 / 60 nC |
| Plateau voltage | V_pl | 3.5 V |
| Q_rr (body diode) | | 40 nC |
| C_oss(er) | | 1.5 nF |

**Sanity flag.** An 80 A burst on a 20×20 or 30.5×30.5 nano board is at the edge of physical feasibility. The thermal section shows this is a time-limited (seconds) rating, not a continuous one.

## 1. Conduction Loss Model

### 1.1 Topology current paths
The ESC uses 6-step commutation with synchronous rectification (complementary PWM, as in AM32/BLHeli_32). During each commutation sector:
- The PWM'd leg conducts through the high-side FET for D·T and the low-side FET for (1−D)·T.
- The return leg's low-side FET is on 100% of the sector.

### 1.2 Per-channel conduction loss

$$P_{cond} = I_{ph}^2\left[R_{HS}D + R_{LS}(1-D) + R_{LS}\right] \;\xrightarrow{R_{HS}=R_{LS}=R(T_j)}\; P_{cond} = 2\,I_{ph}^2\,R(T_j)$$

This is independent of duty cycle when HS and LS are matched.

$$R(T_j) = R_{25}\left[1+\alpha(T_j-25)\right]$$

### 1.3 Electrothermal iteration
Conduction loss rises with junction temperature, so the solution is iterated to convergence:

| Iter | T_j assumed | R(T_j) | P_cond / channel |
|---|---|---|---|
| 0 | 25 °C | 1.00 mΩ | 12.8 W |
| 1 | 100 °C | 1.34 mΩ | 17.1 W |
| 2 | 125 °C | 1.45 mΩ | 18.6 W |

**Design value: P_cond ≈ 18.6 W per channel**, about 3.1 W average per FET (6 FETs share it over the electrical cycle).

### 1.4 Copper and shunt conduction
- **PCB copper:** Assume 0.15 mΩ for the bus plus phase path (2 oz, 4-layer, stitched). P_cu = 80² × 0.15 mΩ ≈ 0.96 W per channel.
- **Current shunt:** A 0.25 mΩ shunt shared on the DC link carries I_dc = D·I_ph, so at D≈1: P_shunt ≈ 1.6 W per channel. Many 4-in-1 boards use one common shunt, which then carries 4× the current. That case needs a check against I²R at 320 A, which is why most designs use ≤0.2 mΩ.

### 1.5 Dead-time body-diode conduction

$$P_{dt} = 2\,V_f\,I_{ph}\,t_{dt}\,f_{sw} = 2(0.8)(80)(100\text{ns})(48\text{k}) = 0.61\text{ W}$$

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate-charge-based transition times

$$t_{on} \approx \frac{Q_{gs2}+Q_{gd}}{(V_{drv}-V_{pl})/R_{g,on}} = \frac{17\text{nC}}{0.65\text{A}} = 26\text{ ns}$$

$$t_{off} \approx \frac{Q_{gs2}+Q_{gd}}{V_{pl}/R_{g,off}} = \frac{17\text{nC}}{0.44\text{A}} = 39\text{ ns}$$

### 2.2 Hard-switched inductive V–I overlap

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_{on}+t_{off}) f_{sw} = \tfrac12(25.2)(80)(65\text{ns})(48\text{k}) = 3.14\text{ W}$$

### 2.3 Secondary switching terms

| Term | Expression | Value |
|---|---|---|
| Reverse recovery | V_bus · Q_rr · f_sw | 0.048 W |
| Output capacitance | ½ · C_oss(er) · V_bus² · f_sw | 0.023 W |
| Gate drive (dissipated in driver/R_g) | 2 · Q_g · V_drv · f_sw | 0.058 W |

**P_sw,total ≈ 3.27 W per channel.** This loss is concentrated in the PWM-leg high-side FET and its complementary low-side FET.

### 2.4 Frequency sensitivity

$$\frac{\partial P_{sw}}{\partial f_{sw}} = 65\ \mu\text{W/Hz}$$

- Dropping to 24 kHz saves about 1.6 W per channel.
- Raising to 96 kHz costs about 3.3 W per channel.

48 kHz is a reasonable compromise for low-inductance (high-KV) motors, where ripple current matters.
