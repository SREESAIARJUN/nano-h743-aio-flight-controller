## 0. Architecture Clarification and Key Findings

**What the STM32H743 actually does.** It cannot practically commutate four motors while also running ArduPilot. The only realistic architecture is:

- **H743 flight controller (ArduPilot):** sends bidirectional DShot600 to
- **4× ESC MCUs** (AT32F421 or STM32G071, running AM32 or BLHeli_32), each driving
- **3-phase gate driver + 6 N-MOSFETs per motor**, 24 FETs in total.

All analysis below assumes this split.

**Key findings:**

| Item | Result |
|---|---|
| Conduction loss per channel at 80 A | **≈ 23 W** (hot Rds) |
| Switching + dead-time loss per channel at 48 kHz | **≈ 2.5 W** |
| Total power stage at 4×80 A | **≈ 110–115 W** |
| Thermally sustainable continuous current (prop-wash cooled, 30×30 mm) | **≈ 25–30 A per channel** |
| Duration of 80 A on all four channels before T_j ≈ 125 °C | **≈ 1–2 s** |
| DMA streams needed for 4× bidirectional DShot | **6 of 16** (DMAMUX makes this easy on H7) |

> **Design-review warning:** "80 A burst" on a nano-format board is a single-channel, sub-second rating at best. Do not publish it as a 4-channel or multi-second spec. Section 3 shows why.

## 2. Loss Model

### 2.1 Conduction Loss

In 6-step operation, two legs carry the current. With synchronous complementary PWM:

- **PWM leg:** current flows through either the high-side or the low-side FET. One channel is always on, so the duty cycle drops out.
- **Static leg:** the low-side (or high-side) FET carries the current for 100 % of the period.

$$P_{cond} = 2\,I^2\,R_{ds(on)}(T_j), \qquad R_{ds(on)}(T_j)=R_{25}\,[1+\alpha (T_j-25)],\ \alpha\approx0.005/\text{K}$$

$$P_{cond} = 2(80)^2(1.8\times10^{-3}) = \mathbf{23.0\ W\ per\ channel}$$

This splits as about 11.5 W in the static FET and 11.5 W shared by the HS/LS pair of the PWM leg.

Copper loss adds:

$$P_{cu} = I^2 R_{cu} = 6400 \times 0.5\text{ m}\Omega = \mathbf{3.2\ W}$$

### 2.2 Switching Loss at 48 kHz

The overlap (V–I crossover) loss is incurred only in the PWM leg, with one hard-switched FET per edge pair:

$$P_{sw} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw} = 0.5(25.2)(80)(35\text{ ns})(48\text{ kHz}) = \mathbf{1.69\ W}$$

Dead-time body-diode conduction (two transitions per period):

$$P_{dt} = V_f\, I\, (2t_{dt}) f_{sw} = 0.8(80)(200\text{ ns})(48\text{ k}) = \mathbf{0.61\ W}$$

Reverse recovery:

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{n}(25.2)(48\text{k}) = \mathbf{0.06\ W}$$

Output capacitance, using the conservative approximation E_oss ≈ ½·Q_oss·V:

$$P_{oss} \approx \tfrac12 Q_{oss} V_{bus} f_{sw} = \mathbf{0.024\ W}$$

Gate drive (two switching FETs). This is dissipated mostly in the driver and gate resistors, not in the FET:

$$P_g = 2\,Q_g V_{drv} f_{sw} = 2(60\text{n})(10)(48\text{k}) = \mathbf{0.058\ W}$$

### 2.3 Per-Channel and Total Budget at 80 A

| Loss term | W per channel | W for 4 channels |
|---|---|---|
| Conduction | 23.0 | 92.0 |
| Copper | 3.2 | 12.8 |
| Switching (overlap) | 1.69 | 6.8 |
| Dead time | 0.61 | 2.4 |
| Q_rr + Q_oss + gate | 0.14 | 0.6 |
| **Total** | **≈ 28.6** | **≈ 115** |

**Main conclusions:**

- Conduction dominates (about 80 %), so lowering Rds(on) or paralleling FETs beats reducing f_sw.
- Dropping to 24 kHz saves only about 1.2 W per channel.
- Bulk capacitor ripple-current heating is not included in the table. With 4×80 A it is significant: size to at least 1000 µF of low-ESR capacitance plus a TVS.

### 2.4 Generalized Expression (for scripting)

$$P_{ch}(I,f,T_j) = I^2\!\left[2R_{25}(1+\alpha(T_j-25)) + R_{cu}\right] + I f\left[\tfrac12 V(t_r+t_f) + 2V_f t_{dt}\right] + f\left[Q_{rr}V + \tfrac12 Q_{oss}V + 2Q_gV_{drv}\right]$$

Because R depends on T_j, solve it iteratively with the thermal model below. This produces thermal runaway when the solution fails to converge, which is the real failure criterion.
