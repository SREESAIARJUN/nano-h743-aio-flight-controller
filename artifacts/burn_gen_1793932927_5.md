# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power, Thermal and Bi-Directional DShot Architecture

## 0. Scope and Assumptions

I don't have a prior spec for "Job #4," so this design is built on explicit, stated assumptions. Every result below is parametric, so you can substitute real datasheet values.

**Architecture clarification.** The STM32H743 cannot run ArduPilot and also commutate 4 motors. A practical AIO board has two compute domains:

- **Flight controller (FC):** an STM32H743 running ArduPilot, which sends bi-directional DShot600.
- **ESC:** 4× dedicated ESC MCUs running AM32 or BLHeli_32, for example STM32G071 or AT32F421 (one per motor), each with a 3-phase gate driver and 6 MOSFETs.

## 1. Conduction Loss Model

### 1.1 Commutation analysis (six-step, complementary PWM)

In six-step commutation, exactly two phase legs carry the phase current I at any instant: one high-side path and one low-side path. Each leg is active for 120° of the electrical cycle. With PWM on the high side and synchronous rectification:

- **High-side FET** conducts for fraction D of its 1/3 window:
  I²_rms,HS = I² · D / 3
- **Low-side FET** of the same leg conducts during PWM off-time (1−D)/3, and fully (1/3) when it acts as the return leg:
  I²_rms,LS = I² · (2 − D) / 3

The per-leg sum is I² · 2/3. Summing over 3 legs:

$$P_{cond} = 2\, I^2\, R_{ds}(T_j), \qquad R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

The duty cycle cancels out. Two FETs always carry the current, so conduction loss depends on phase current, not throttle.

### 1.2 Evaluated at 80 A

| T_j | R_ds | P_cond per channel | ×4 channels |
|---|---|---|---|
| 25 °C | 1.20 mΩ | 15.4 W | 61.4 W |
| 100 °C | 1.61 mΩ | 20.5 W | 82.2 W |
| 125 °C | 1.74 mΩ | 22.2 W | 88.9 W |

**Parasitic resistance must be included.** Add PCB phase/bus copper (typically 0.2–0.4 mΩ effective) and the shunt, if one is used (0.25–0.5 mΩ, carrying battery current only).

$$P_{cu} = 2 I^2 R_{trace} + I_{bat}^2 R_{shunt}$$

At 80 A with R_trace = 0.3 mΩ, P_cu ≈ 3.8 W per channel. This is not negligible.

### 1.3 Thermal–electrical feedback (self-consistent T_j)

Because R_ds rises with temperature, conduction loss and junction temperature must be solved together:

$$T_j = T_{ref} + Z_{th}\cdot P(T_j) \;\Rightarrow\; T_j = \frac{T_{ref} + Z_{th}\,P_0\,(1 - 25\alpha)}{1 - Z_{th}\,P_0\,\alpha}$$

Here P_0 = 2I²R_25. The system goes into thermal runaway when Z_th · P_0 · α ≥ 1. At 80 A, P_0 = 15.4 W, so runaway occurs at Z_th ≥ 14.4 K/W. That bound is easily reached in steady state on a nano board with poor airflow.

## 2. Switching Loss Model at 48 kHz

In six-step, only one leg is hard-switching at a time. The loss components per channel are:

$$P_{sw} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw}$$
$$P_{dt} = V_{SD}\, I\, (2 t_{dt})\, f_{sw}$$
$$P_{rr} = Q_{rr} V_{bus} f_{sw}$$
$$P_{oss} = Q_{oss} V_{bus} f_{sw}$$
$$P_{gate} = 2\, Q_g V_{GS} f_{sw} \quad \text{(mostly dissipated in the driver and R_g)}$$
