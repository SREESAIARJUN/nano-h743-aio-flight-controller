# STM32H743 AIO Flight Controller with 4-in-1 80A ESC: Design Basis (Job #36)

## 0. Architecture Decisions and Caveats

These items should be resolved at design review. Each one changes the numbers below.

| # | Issue | Resolution adopted |
|---|---|---|
| A1 | ArduPilot does not run motor commutation. The H743 cannot also be the ESC MCU under ArduPilot. | The H743 runs ArduPilot as the flight controller. Four ESC MCUs (STM32G071 or AT32F421 running AM32) run commutation and are commanded by bidirectional DShot600. |
| A2 | 80 A per motor on a 20×20 mm "nano" board is not thermally feasible, even as a burst (see §3.5). | The 80 A math is done honestly. The board is assumed to be 30.5×30.5 mm with 2 FETs per switch position as an option. The 20×20 variant should be derated to about 35 A burst. |
| A3 | A 48 kHz PWM frequency at 80 A roughly doubles switching loss versus 24 kHz. | 48 kHz is analysed as specified. A 24 kHz fallback is quantified. |
| A4 | Device parameters are representative assumptions, not a specific part's datasheet. | All formulas are parametric. Re-run them with the final MOSFET datasheet values (Rds(on) vs Tj, Qgd, Qgs2, Qrr, Qoss, Zth). |
