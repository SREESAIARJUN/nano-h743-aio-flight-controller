# STM32H743 Nano FC + 80A-Burst 4-in-1 ESC: Systems Architecture Package (Job #43)

## 0. Architecture Decisions and Assumptions

**Critical architectural correction:** The STM32H743 should not commutate the motors directly. It has only two advanced timers with complementary outputs and dead-time (TIM1, TIM8), but four 3-phase bridges need 24 gate signals with hardware dead-time and break inputs. The correct partition is:

- **Flight controller:** STM32H743 running ArduPilot. It emits bi-directional DShot600 and receives eRPM telemetry.
- **ESC:** 4× AT32F421K8U7 (or EFM8BB51 / GD32E230) running AM32 (or BLHeli_32-class firmware), each driving one 3-phase bridge.

**Feasibility flag:** An 80A-per-motor rating on a 20×20 mm "nano" stack is a short-burst rating only. Section 3 shows the board is thermally limited to roughly 1 second at full burst and roughly 12–20 A per motor continuous. Your requirements doc should state the burst duration and duty cycle explicitly.

## 1. Conduction Loss Model (80A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right]$$

At T_j = 125 °C: R = 1.4 × 1.45 = **2.03 mΩ**. Use 2.1 mΩ, adding margin for V_GS sag during the burst.
