# 3-Axis Gimbal Motor Control & Dual-IMU Fusion: Design Specification and C++ Implementation

I don't have the Job #52 documents, so this design is built on the assumptions listed in §0. Each assumption is parameterised in the code. Replace the placeholder values with your measured ones before tuning.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU, CORDIC) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), hollow shaft, R ≈ 5–12 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), SPI |
| Current sense | 2- or 3-shunt low-side, sampled at the PWM centre |
| IMUs | 2× ICM-42688-P on the camera platform (SPI, separate CS lines), gyro 2000 dps, accel 16 g |
| PWM | 20 kHz centre-aligned |
