# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

**Scope.** I have no record of Job #41's hardware, so the design below is parameterized. Everything that depends on the hardware is marked **[ASSUME]**. Replace those values with your motor datasheet numbers and measured values before tuning. This document gives the complete control law, its discretization, and production-style C++17 code with no heap allocation, suitable for Cortex-M4F, M7, or M33 targets.

## 0. System Assumptions and Timing

| Item | Value **[ASSUME]** |
|---|---|
| Motors | 3× gimbal BLDC (e.g. GBM2804-class), 12N14P → pole pairs p = 7 |
| Phase params | R_s ≈ 5–10 Ω, L_s ≈ 1–3 mH, λ_m from K_v |
| Encoder | 14-bit magnetic absolute (AS5048A / MT6701), one per axis |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz |
| Bus | V_dc = 12–16 V; PWM 20 kHz center-aligned |
| Gimbal order | Yaw (outer, base) → Roll → Pitch (inner, camera) |
