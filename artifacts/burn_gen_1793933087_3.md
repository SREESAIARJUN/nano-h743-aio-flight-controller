# STM32H743 AIO (Flight Controller + 4-in-1 ESC): Power-Stage and DShot Design Analysis

**Scope:** Power-stage loss model, transient thermal model, bidirectional DShot600 timer/DMA allocation, and reference netlists.

I don't have the Job #40 project files, BOM, or stack-up. Every parameter below is therefore an **explicit, labelled assumption**. The equations are general, so you can substitute datasheet values.

## 0. Architecture Clarification

ArduPilot runs on the STM32H743 as the **flight controller**. It does **not** commutate motors. A working AIO uses this split:

```
STM32H743 (ArduPilot) ──DShot600 bidir──► 4× ESC MCU (AT32F421 / STM32G071, AM32 or BLHeli_32)
                                                  │
                                                  ▼
                                    3-phase gate driver ──► 6 MOSFETs per motor (24 total)
```

All loss figures below apply to the **ESC power stage**. All timer and DMA figures apply to the **H743**.

## 1. Conduction Losses at 80 A

### 1.1 RMS current including ripple

$$\Delta I = \frac{V_{bus}\,D(1-D)}{L_m f_{sw}} = \frac{25.2 \cdot 0.25}{20\,\mu H \cdot 48\,kHz} = 6.6\ \text{A}_{pp} \quad (D = 0.5,\ \text{worst case})$$

$$I_{rms} = I\sqrt{1 + \frac{1}{12}\left(\frac{\Delta I}{I}\right)^2} = 80 \cdot 1.00028 \approx 80.02\ \text{A}$$

Ripple is negligible at this current, so I_rms ≈ I is used from here on.

### 1.2 Per-channel conduction loss

Two FETs are always in the current path: the switching leg (HS during D, sync LS during 1−D) and the static low-side FET. With R_hot = k_T · R_ds25 = 1.6 mΩ:

$$P_{cond} = I^2 R_{hot}\big[D + (1-D)\big] + I^2 R_{hot} = 2I^2 R_{hot}$$

$$P_{cond} = 2 \cdot 6400 \cdot 1.6\,m\Omega = \mathbf{20.5\ W}$$

Copper loss adds:

$$P_{pcb} = I^2 R_{pcb} = 6400 \cdot 0.5\,m\Omega = \mathbf{3.2\ W}$$

**Per-FET average:** each FET carries current for about 1/3 of the electrical cycle, so 20.5 / 6 ≈ **3.4 W
