## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

With electrical angle θₑ = p·θₘ − θ_offset:

**Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):**

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and Decoupling

The PMSM model in the dq frame is:

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$

$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

Here λ_m = K_t / (1.5 p).

Decoupling feedforward is added to the PI outputs:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

### 1.3 Current PI (Pole-Zero Cancellation)

Choose a closed-loop current bandwidth ω_c ≤ 2π·f_PWM / 10. At 20 kHz, f_c ≈ 1.5–2 kHz.

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c$$

The open loop becomes ω_c/s, so the closed loop is first order with time constant 1/ω_c.

Gimbal motors are high-R, low-speed devices. For many builds, voltage-mode FOC (v_q = R·i_q* + ω_eλ_m) works with no current sensing. The code supports both modes (`USE_CURRENT_SENSE`).

### 1.4 SVPWM (Min-Max Zero-Sequence Injection)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

Linear range: |v_αβ| ≤ V_bus/√3. The magnitude is circle-limited with d-axis priority.

## 2. Velocity Estimation (PLL Observer on the Encoder)

Differentiating a 14-bit encoder at 5 kHz quantizes velocity to about 1.9 rad/s, which is unusable. Use a type-II tracking PLL:

$$e = \operatorname{wrap}(\theta_{enc} - \hat\theta)$$

$$\hat\omega \mathrel{+}= K_i^{pll}\, e\, T_s$$

$$\hat\theta \mathrel{+}= (\hat\omega + K_p^{pll}\, e)\, T_s$$

Gains are set from the PLL bandwidth:

$$K_p^{pll} = 2\zeta\omega_n,\qquad K_i^{pll} = \omega_n^2,\qquad \zeta = 1,\ \omega_n \approx 2\pi\cdot 300\ \text{Hz}$$
