# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Fusion Design

I don't have the Job #24 spec sheet, so this design rests on the assumptions below. Everything is parameterized, so you can substitute your real values.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), read at 10–20 kHz |
| Current sense | 2-shunt low-side, sampled at PWM center |
| PWM | 20 kHz center-aligned |
| Loop rates | Current 20 kHz, velocity 4 kHz, angle 1 kHz, attitude 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, symmetric about the pitch-axis rotation center, SPI at 8 kHz ODR |
| Joint order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
