# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

**Assumed specifications.** I don't have the specifics of Job #47, so the design assumes typical gimbal hardware. Swap in your actual values in `MotorParams` and the config structs.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MA730 class), per axis |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class), 3-shunt or 2-shunt sensing |
| IMUs | 2× ICM-42688-P on the camera platform, SPI + DMA, gyro/accel ODR 8 kHz |

**Loop rates.** Each loop runs at an integer multiple of the next, so the timing is deterministic.

| Loop | Rate | Closed-loop bandwidth target |
|---|---|---|
| Current (d/q PI) + SVPWM | 20 kHz | ~1.5–2 kHz |
