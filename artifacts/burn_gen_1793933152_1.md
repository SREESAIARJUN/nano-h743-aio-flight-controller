## 0. Design Assumptions

| Item | Assumed value |

| MCU | STM32G4 / H7 class, single-precision FPU, CORDIC optional |

Rates must keep bandwidth separation of at least 5–10× per cascade stage:

$$\omega_{c,i} \approx 2\pi\cdot 1.5\text{ kHz},\quad \omega_{c,v} \approx 2\pi\cdot 150\text{ Hz},\quad \omega_{c,\theta}\approx 2\pi\cdot 20\text{ Hz}$$

## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Here θ_off is found at calibration by forcing u_d = U_align at θ_e = 0 and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM dq model and decoupled PI current control

$$u_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad u_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

The PI uses pole-zero cancellation, which places the closed loop at bandwidth ω_ci:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

The control law adds the decoupling and back-EMF feedforward terms:

$$u_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L_q i_q,\qquad u_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e(L_d i_d + \lambda_m)$$

The current references are i_d* = 0 (surface PMSM, no field weakening) and i_q* = τ*/K_t, with

$$K_t = \tfrac32 p\lambda_m.$$

### 1.5 Voltage limiting (circular, d-axis priority)

$$|u_d^*| \le U_{\max},\qquad |u_q^*| \le \sqrt{U_{\max}^2 - u_d^{*2}},\qquad U_{\max} = \frac{V_{bus}}{\sqrt3}\cdot 0.95$$

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)

$$u_\alpha = u_d\cos\theta_e - u_q\sin\theta_e,\qquad u_\beta = u_d\sin\theta_e + u_q\cos\theta_e$$

$$u_a = u_\alpha,\quad u_b = -\tfrac12 u_\alpha + \tfrac{\sqrt3}{2}u_\beta,\quad u_c = -\tfrac12 u_\alpha - \tfrac{\sqrt3}{2}u_\beta$$

$$u_0 = -\tfrac12\big(\max(u_{abc}) + \min(u_{abc})\big),\qquad D_x = \tfrac12 + \frac{u_x + u_0}{V_{bus}}$$

The min-max injection is mathematically equivalent to sector-based SVPWM. It gives a 15.5% higher linear range than sine PWM.
