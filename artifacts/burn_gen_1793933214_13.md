# STM32H743 Nano AIO with 80A-Burst 4-in-1 ESC: Engineering Model

## 0. Architecture Assumptions

**The STM32H743 does not drive the power stage.** In every production 4-in-1 design, the H743 acts as the flight controller (FC) running ArduPilot. It sends bi-directional DShot600 commands to four per-channel ESC MCUs running AM32 or BLHeli_32. Each ESC MCU generates the 48 kHz complementary PWM and handles commutation.

**The model is parameterized.** Every equation is written symbolically. Numbers come from a reference parameter set (Table 0.1). **Substitute your actual MOSFET and PCB datasheet values before sign-off.**

**Table 0.1: Reference parameter set**

| Symbol | Meaning | Reference value |
|---|---|---|
| V_bus | 6S full charge | 25.2 V |
| I_pk | Burst phase current per channel | 80 A |

| R_ds,25 | MOSFET R_DS(on) at 25 °C, V_GS = 10 V (40 V, PDFN 3.3×3.3 class) | 0.70 mΩ |

## 1. Conduction Loss Model (6-Step, Complementary PWM)

### 1.1 Commutation state

Each phase leg spends one third of each electrical cycle in each of three states:
- **120° HIGH**: the high-side (HS) MOSFET is PWM'd at duty D, and the low-side (LS) MOSFET synchronously rectifies at (1−D).
- **120° LOW**: the LS MOSFET is fully on.
- **120° FLOAT**: both MOSFETs are off. This is the BEMF sensing window.

Assume flat-top phase current I during conduction (valid for 6-step with L/R ≫ PWM period).

### 1.2 Per-device mean-square current

Using the time-average of i² over one electrical cycle:

$$\overline{i^2}_{HS} = I^2\cdot\frac{D}{3}, \qquad \overline{i^2}_{LS} = I^2\cdot\frac{(1-D)}{3} + I^2\cdot\frac{1}{3} = I^2\cdot\frac{2-D}{3}$$

**Check:** summing over 3 legs gives 3·I²[D + (2−D)]/3 = 2I². This matches the requirement that exactly two FETs are always in the current path.

**Worst-case device:** the LS FET at low-to-mid duty. At D → 0 it carries 2I²/3, but a stalled or near-zero-duty motor cannot draw 80 A on a sane prop. The realistic 80A burst happens at D ≈ 0.85–1.0 (punch-out).

### 1.3 Temperature-dependent R_DS(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

At T_j = 110 °C: R_ds = 0.70 × (1 + 0.0055 × 85) = **1.03 mΩ**

### 1.4 Channel and board conduction loss

$$P_{cond,ch} = 2\,I^2\,[R_{ds}(T_j) + R_{cu}] + I^2\,R_{shunt}\cdot k_{sh}$$

Here k_sh is the fraction of time current flows through the shunt. It is about 1 for a DC-link shunt, or 2/3 for a per-leg low-side shunt.

**Table 1.1: Conduction loss at 80 A, T_j = 110 °C**

| Term | Calculation | Per channel | ×4 channels |
|---|---|---|---|
| MOSFETs | 2 × 6400 × 1.03 mΩ | 13.2 W | 52.7 W |
| Copper | 2 × 6400 × 0.30 mΩ | 3.84 W | 15.4 W |
| Shunt (DC-link) | 6400 × 0.25 mΩ | 1.60 W | 6.4 W |
| **Total** | | **18.6 W** | **74.5 W** |

**Copper loss matters.** It is about 30% of MOSFET loss. On nano boards, the via fields under the pads and the battery-pad necks dominate R_cu. Model them explicitly; for a via barrel, R_via ≈ ρ·L/(π·d·t_plating).

### 1.5 Per-FET split at punch-out (D = 0.95)

- HS: 6400 × 0.95/3 × 1.03 mΩ = **2.09 W**
- LS: 6400 × 1.05/3 × 1.03 mΩ = **2.31 W**

### 1.6 Electro-thermal stability criterion

Conduction loss rises with temperature, which can feed back on itself. Thermal runaway is avoided when:

$$\frac{\partial P}{\partial T_j}\cdot R_{th,ja}^{eff} < 1 \;\Rightarrow\; I_{rms}^2\,R_{ds,25}\,\alpha\,R_{th,ja}^{eff} < 1$$

For the LS FET (I_rms² ≈ 2240 A²): 2240 × 0.7e-3 × 0.0055 = 8.6 mW/K.

This requires R_th,ja,eff < 116 K/W. Steady-state is therefore stable. The binding constraint is absolute T_j, not runaway.
