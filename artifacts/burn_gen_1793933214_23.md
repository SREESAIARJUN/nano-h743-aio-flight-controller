# STM32H743 FC + 4-in-1 ESC (Job #2): Thermal, Switching and Bidirectional DShot Design Package

## 0. Scope, Architecture and Assumptions

I have no prior context for Job #2, so the assumptions below are stated explicitly. Every result is parametric, so you can substitute your actual MOSFET datasheet values.

### 0.1 Architecture

The H743 does not drive the power stage directly. The two-board split below matches how BLHeli_32/AM32 hardware is built.

```
 ┌──────────────── FC (STM32H743, ArduPilot) ───────────────┐
 │ TIM1 CH1..CH4 ──Bidir DShot600──► 8-pin JST-SH ──────────┼──► ESC board
 │ ADC (CURR), UART RX (ESC telemetry, optional)            │
 └──────────────────────────────────────────────────────────┘
 ┌──────────────── 4-in-1 ESC ──────────────────────────────┐
 │ 4× ESC MCU (AT32F421 / STM32G071, AM32) @ 48 kHz PWM     │
 │ 4× 3-phase gate driver (e.g. FD6288Q class)              │
 │ 24× N-MOSFET (12 half-bridges)                           │
 └──────────────────────────────────────────────────────────┘
```

A single H743 cannot natively generate 4 × 3 complementary PWM pairs with hardware dead-time. Only TIM1 and TIM8 have complementary outputs, which covers 2 motors at most. That is why the 48 kHz switching lives on the per-motor ESC MCUs.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current Paths in 6-Step Trapezoidal Commutation with Synchronous Rectification

At any instant, two phases carry I_ph. Take phase A PWMing high and phase B held low:

- **PWM on (D):** HS_A → motor → LS_B, so 2 FETs in series.
- **PWM off (1−D):** LS_A (sync rectifier) → motor → LS_B, so 2 FETs in series.

Ignoring dead time, there are always exactly two R_ds(on) in the current path. The per-ESC conduction loss is therefore:

$$P_{cond,ESC} = 2\,I_{ph}^2\,R_{ds(on)}(T_j)$$

$$R_{ds(on)}(T_j) = R_{ds(on),25}\,[1+\alpha(T_j-25)]$$

### 1.2 Per-FET Distribution

Each phase spends 1/3 of the electrical cycle in each of three states: PWMing, held low, or floating.

$$P_{HS} = \tfrac{1}{3}\,D\,I^2R \qquad P_{LS} = \tfrac{1}{3}(1-D)\,I^2R + \tfrac{1}{3}\,I^2R$$

The low-side FETs are the hot devices. At low duty they approach (2/3)·I²R. **Place LS FETs on the best copper and vias.**

### 1.3 Electro-Thermal Fixed Point

Because R_ds(on) rises with T_j, the loss and temperature must be solved together:

$$T_j = T_{ref} + P(T_j)\,R_{\theta} \;\Rightarrow\; T_j = \frac{T_{ref} + 2I^2R_{25}R_\theta(1-25\alpha)}{1-2I^2R_{25}R_\theta\,\alpha}$$

Stability requires 2I²R₂₅R_θα < 1. If this fails, thermal runaway occurs.

### 1.4 Numbers at 80 A

Assume T_j = 110 °C, so R_ds(on) = 1.0 × (1 + 0.006 × 85) = 1.51 mΩ.

| Term | Calculation | Per ESC |
|---|---|---|
| FET conduction | 2 × 80² × 1.51 mΩ | **19.3 W** |
| PCB copper (phase + bus, ~0.3 mΩ total path) | 80² × 0.3 mΩ | 1.9 W |
| Conduction subtotal | | **21.2 W** |

Worst-case LS FET at D → 0: (2/3) × 80² × 1.51 mΩ = **6.4 W** for that device.
