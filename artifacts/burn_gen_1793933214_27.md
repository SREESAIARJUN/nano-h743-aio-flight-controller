## 0. Architecture Clarification and Design Assumptions

ArduPilot does **not** commutate motors. The H743 runs ArduPilot (attitude control, DShot generation, telemetry decode). Each of the four power channels needs its own commutation MCU running AM32 or BLHeli_32. The architecture is therefore:

```
 6S LiPo ──► Power stage (4× 3-phase bridges) ◄── 4× ESC MCU (AT32F421 / STM32G071, AM32)
                                                         ▲   │ bidirectional DShot600 (1 wire/motor)
                                                         │   ▼
                                               STM32H743 (ArduPilot), TIM1 CH1–CH4
```

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S, V_max = 25.2 V, V_nom = 22.2 V | worst-case switching uses 25.2 V |
| Burst current | 80 A per channel, ≤ 10 s | **not** 4×80 A simultaneously (that would be 320 A / ~7 kW) |
| Continuous | ~35–40 A per channel | derived in §3 |
| f_sw | 48 kHz, complementary (synchronous) PWM, 6-step | AM32 style |
| MOSFET (ref.) | 40 V N-ch, PDFN 5×6
