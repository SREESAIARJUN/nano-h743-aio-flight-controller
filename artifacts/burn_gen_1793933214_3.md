# STM32H743 FC + 4-in-1 ESC Stack: Loss, Thermal, and Bidirectional DShot Design Package (Job #41)

**Scope and caveats**

- **Missing context.** I don't have the Job #41 requirements docs, BOM, or layout. Every device parameter below is an explicit, parameterized assumption. The equations are general. The numbers are only as good as the inputs, so substitute your datasheet values.
- **Architecture.** The STM32H743 is the flight controller MCU. It generates DShot and decodes bidirectional telemetry. The ESC side of a 4-in-1 runs its own MCUs (AT32F421, STM32G071, etc., with AM32 or BLHeli_32/Bluejay). The 48 kHz PWM and its switching losses therefore belong to the ESC MCU's PWM, not the H743. The model treats them that way.
- **Headline finding.** 80 A on all four channels of a nano-format (20×20 or 25.5×25.5 mm) board is a seconds-scale burst, not a continuous rating. The numbers below quantify that.

## 2. Conduction Loss Model

### 2.1 Current path in 6-step trapezoidal with synchronous rectification

At any instant two phases conduct:

- **Phase A (chopping leg):** the high-side FET conducts for D·T_sw, and the low-side FET synchronously rectifies for (1−D)·T_sw.
- **Phase B (return leg):** the low-side FET is on continuously.

So the phase current always passes through exactly two FETs:

$$P_{cond,ch} = I_{rms}^2 \, R_{ds}(T_j)\,[D + (1-D)] + I_{rms}^2 R_{ds}(T_j) = 2\,I_{rms}^2\,R_{ds}(T_j)$$

### 2.2 Temperature dependence (requires iteration)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha_R (T_j - 25)]$$

T_j depends on loss, so solve by fixed-point iteration. At a converged T_j ≈ 110 °C:

$$R_{ds}(110) = 1.2\,\text{m}\Omega \times (1 + 0.0065 \times 85) = 1.86\,\text{m}\Omega$$

### 2.3 Ripple contribution

The worst case is at D = 0.5:

$$\Delta I = \frac{V_{bus} D(1-D)}{L\,f_{sw}} = \frac{25.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 6.56\,\text{A}_{pp}$$

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 3.6 \;\Rightarrow\; \text{negligible } (+0.06\%)$$

## 3. Switching Loss Model at 48 kHz

### 3.1 Gate current during the Miller plateau

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_{g,ext} + R_{g,int}} = \frac{7}{5.7} = 1.23\,\text{A}$$

$$I_{g,off} = \frac{V_{pl}}{5.7} = 0.53\,\text{A}$$

$$t_{on} \approx \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = 9.8\,\text{ns}, \qquad t_{off} \approx \frac{12\,\text{nC}}{0.53\,\text{A}} = 22.8\,\text{ns}$$

Turn-off dominates. If you need margin, the lever is a lower-impedance sink path: a diode-bypassed R_g,off or a stronger driver.

### 3.2 Loss terms per channel

Only the chopping leg switches hard. The low side does ZVS-like transitions via dead time.

| Term | Equation | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_on + t_off)·f_sw = ½·25.2·80·32.6 ns·48 k | **1.58 W** |
| Reverse recovery | Q_rr·V·f_sw = 40 nC·25.2·48 k | 0.05 W |
| C_oss | E_oss·f_sw | 0.02 W |
| Dead-time diode | V_F·I·2·t_dt·f_sw = 0.8·80·200 ns·48 k | **0.61 W** |
| Gate drive (lost in driver/R_g) | 2·Q_g·V_drv·f_sw | 0.05 W |
