## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path
The ESC uses 6-step trapezoidal commutation with complementary (synchronous-rectified) PWM. At any instant, the motor current flows through exactly **two** channels in series:

- PWM ON: high-side FET of phase A, then the motor, then the low-side FET of phase B.
- PWM OFF: synchronous low-side FET of phase A, then the motor, then the low-side FET of phase B.

So the conducting resistance is always about 2·R_ds(on), independent of duty cycle, ignoring dead time.

### 1.2 Temperature-dependent resistance

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

### 1.3 Per-channel conduction loss

$$P_{cond}=I^2\cdot 2R_{ds}(T_j)+I^2 R_{shunt}+I^2 R_{Cu}$$

At I = 80 A and T_j = 100 °C: R_ds = 1.0·(1 + 0.006·75) = 1.45 mΩ.

| Term | Calculation | Loss |
|---|---|---|
| FETs | 6400 × 2 × 1.45 mΩ | **18.56 W** |
| Shunt (0.5 mΩ, if one per channel) | 6400 × 0.5 mΩ | 3.2 W |
| Copper traces/pours (≈0.3 mΩ path) | 6400 × 0.3 mΩ | 1.9 W |
| **Total conduction per channel** | | **≈ 23.7 W** |

Two design notes:
- A single shared 0.25 mΩ bus shunt for the whole board cuts shunt loss. It sees the 4-channel total current.
- Motor current is not flat DC; it has a PWM ripple ΔI. Use the RMS value, $I_{rms}^2 = I^2 + \Delta I^2/12$. With typical low-inductance quad motors at 48 kHz, ΔI is about 5–15 A, which adds less than 1% and can be ignored.

### 1.4 Per-FET distribution (for junction temperature)
Each FET leg conducts for 120° of every 360° electrical cycle.

- **High-side FET:** $P_{HS}=\tfrac13 I^2 R\,D$
- **Low-side FET of the same leg (synchronous):** $\tfrac13 I^2R(1-D)$, plus $\tfrac13 I^2 R$ when it is the return leg.

Worst case is the low-side FET at low duty: $P_{LS,max}\approx \tfrac23 I^2R$. At 80 A that is **6.2 W** in one 3×3 package. This FET sets the junction limit.

## 2. Switching Loss Model (48 kHz)

Only the active high-side/sync-low-side pair hard-switches. The return-leg FET is static during a 60° sector.

| Mechanism | Equation | Value at 80 A, 25.2 V |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw | 0.5·25.2·80·30 ns·48 k = **1.45 W** |
| Output capacitance | Q_oss·V·f_sw | 40 nC·25.2·48 k = 0.05 W |
| Reverse recovery | Q_rr·V·f_sw | 50 nC·25.2·48 k = 0.06 W |
| Dead-time diode conduction | V_f·I·2t_dt·f_sw | 0.8·80·200 ns
