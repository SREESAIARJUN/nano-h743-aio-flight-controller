# Job #78: STM32H743 Nano FC + 4-in-1 ESC: Power, Thermal & DShot Architecture

## 0. Architecture Assumptions

These assumptions shape every number below. If any is wrong, the results change.

| Item | Assumption | Why |
|---|---|---|
| Topology | **AIO stack**: STM32H743 flight controller plus **4× AT32F421 ESC MCUs** running AM32 | The H743 cannot directly commutate 4 sensorless BLDCs at 48 kHz with BEMF sensing. Production 4-in-1 boards use one small MCU per motor. |
| Bus | 6S LiPo, 25.2 V max, 22.2 V nominal | Worst case for switching loss is V_max. |
| MOSFETs | 40 V, DFN 3.3×3.3, R_DS(on),25 = 1.5 mΩ @ V_GS=10 V, Q_g=30 nC, Q_gd=6 nC, Q_rr=30 nC, Q_oss=25 nC | Representative values. **Replace with your selected part's datasheet values.** |
| Gate driver | FD6288Q-class 3-phase bootstrap driver, V_CC=10 V, R_G,ext=2 Ω | Common in 4-in-1 ESCs. |
| Board | 30.5×30.5 mm mount ("nano" pushes toward 20×20, which worsens everything below), 8-layer, 2 oz inner/outer | |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM, f_sw = 48 kHz, dead time 100 ns | |
| 80 A | **Per-channel phase current, burst** | |

### Feasibility flags

1. **4 × 80 A simultaneous at full throttle is about 320 A battery current (≈8 kW).** No nano-format board, XT60, or 12 AWG lead set survives that. Treat "80 A burst" as a **per-channel, non-simultaneous, ≤2–3 s** rating. The thermal model in §3 shows this.
2. **DC-link ripple current** (§2.6) is the most commonly under-designed element. It, not the FETs, often kills these boards.
3. The 48 kHz switching frequency costs about 2–3 W per active channel at 80 A versus 24 kHz. This is justified only for low-inductance, high-KV motors.
