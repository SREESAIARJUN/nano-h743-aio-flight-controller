# STM32H743 AIO Flight Controller with 4-in-1 ESC: Power-Stage, Thermal and Bi-Directional DShot Design Package (Job #60)

## 0. Architecture Correction and Assumptions

**The STM32H743 does not drive the MOSFETs.** In every production 4-in-1 design, and in this one, the H743 runs ArduPilot and talks DShot600 to dedicated ESC microcontrollers, which generate the 48 kHz commutation PWM. A single H743 cannot also run four sensorless BLDC commutation loops alongside ArduPilot's real-time scheduler, and ArduPilot has no ESC firmware path for it. The architecture is:

```
[H743 FC / ArduPilot] --4x BDShot600--> [4x AT32F421 running AM32] --> [4x 3-phase gate driver] --> [24x N-MOSFET]
```

Values marked **[A]** are design assumptions. Replace them with your selected parts' datasheet maxima before release.

| Parameter | Value | Note |

| Board [A] | 30.5 × 30.5 mm, 8-layer, 2 oz on all layers | "nano" class AIO |

MOSFET assumed parameters:
- R_DS(on) = 1.3 mΩ max at 25 °C, so roughly 2.0 mΩ at T_j = 125 °C (×1.55).
- Q_g ≈ 60 nC and Q_rr ≈ 50 nC.
- t_r + t_f ≈ 40 ns at the chosen gate resistance.
- R_θJC ≈ 1.5 K/W.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current paths in 6-step complementary PWM

At any commutation step, current flows through phase X (PWM'd) and returns through phase Y (low side held on). Over one PWM period with duty D:

| FET | Conduction fraction | Current |
|---|---|---|
| High side, phase X | D | I |
| Low side, phase X (synchronous rectifier) | (1 − D) − 2·t_dt·f_sw | I |
| Low side, phase Y (static) | 1 | I |

The temperature-dependent on-resistance is:

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)], \quad \alpha \approx 0.0055\ \text{K}^{-1}$$

Total conduction loss per motor, neglecting the small dead-time fraction, is:

$$P_{cond} = I^2 R_{DS}(T_j)\,[D + (1-D) + 1] = 2\,I^2 R_{DS}(T_j)$$

**This is independent of D.** Synchronous rectification makes the conduction loss throttle-invariant at a given phase current.

### 1.2 Numerical result at 80 A

$$P_{cond} = 2 \times 80^2 \times 2.0\,\text{m}\Omega = \mathbf{25.6\ W\ per\ motor}$$

Copper and shunt losses add to this:
- **Shunt** (0.25 mΩ, in the bus return; sees roughly D·I on average): 80² × 0.25 m × 0.5 ≈ **0.8 W**.
- **Phase traces and planes** (≈0.3 mΩ effective per motor path, 2 oz × 8 layers in parallel): 80² × 0.3 m ≈ **1.9 W**.

### 1.3 Per-FET distribution

Each phase leg spends 1/3 of the electrical cycle in each role, so the average per leg is (2/3)·I²R = **8.5 W**.

The worst-case single FET is a low side, which carries the static 1/3 share plus the synchronous share:

$$P_{LS} \approx \tfrac{1}{3} I^2 R + \tfrac{1}{3}(1-D) I^2 R \approx 4.3 \text{ to } 8.5\ \text{W (D: 1 → 0)}$$
