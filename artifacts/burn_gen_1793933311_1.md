# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #18," so this design states its assumptions explicitly. Every assumption is a named constant in the code, so you can substitute your real values.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, e.g. GBM2804-class: 12N14P (7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A), read by SPI at the current-loop rate |
| MCU | STM32G4 / H7 class with single-precision FPU and center-aligned PWM triggering the ADC |
| IMUs | 2× ICM-42688-P on the camera stage, SPI, gyro ODR 8 kHz, ±2000 dps; accel ODR 1 kHz |
| Bus | V_dc = 12 V |

The loops run at separated rates, with roughly 5–10× bandwidth separation between each stage:

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| Rate / velocity | 4 kHz | ~150–250 Hz |
| Angle / attitude | 1 kHz | ~20–40 Hz |
| Attitude estimator | 1 kHz (gyro pre-filtered at 8 kHz, decimated) | — |

## 1. Field-Oriented Current Loop

### 1.1 Transforms
Use the amplitude-invariant Clarke transform with a balanced-phase assumption ($i_a+i_b+i_c=0$):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}
$$

Park transform, with electrical angle $\theta_e = p\,(\theta_m - \theta_{\text{off}})$:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.2 Plant and PI design
The surface-PMSM model in the dq frame is:

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)
$$

With feed-forward decoupling, each axis reduces to $G(s)=1/(Ls+R)$. A PI controller $C(s)=K_p + K_i/s$ with pole-zero cancellation ($K_i/K_p = R/L$) gives a first-order closed loop with bandwidth $\omega_c$:

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c
$$

**Design rule:** $\omega_c \le 2\pi f_{pwm}/10$. For 20 kHz PWM this gives $\omega_c \approx 2\pi\cdot 2000$ rad/s.

### 1.3 Discretization and anti-windup
Discretize with forward-Euler integration and back-calculation anti-windup ($K_{aw}\approx 1/K_p$ per sample, normalized):

$$
u_k = K_p e_k + I_k,\quad \bar u_k = \mathrm{sat}(u_k),\quad
I_{k+1} = I_k + K_i T_s e_k + K_{aw}(\bar u_k - u_k)
$$

### 1.4 Voltage limit and SVPWM
Limit the voltage vector to the linear SVPWM hexagon's inscribed circle, giving d-axis priority:

$$
|v_d|\le V_{max},\quad |v_q| \le \sqrt{V_{max}^2 - v_d^2},\qquad V_{max} = \frac{V_{dc}}{\sqrt3}\cdot 0.95
$$

Implement SVPWM by min-max zero-sequence injection, which is equivalent to classic sector SVPWM:

$$
v_{off} = -\tfrac12(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)),\qquad
D_x = \tfrac12 + \frac{v_x+v_{off}}{V_{dc}}
$$
