# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

I don't have the original spec for Job #17, so this design assumes a typical setup. Every assumption is a named constant in the code so you can substitute your real values:

- **Motors:** gimbal BLDC motors, 12N14P, with a 14-bit absolute magnetic encoder (e.g. AS5048A or MT6701) per axis.
- **Drive:** low-side or inline current sensing, 3-phase bridge, center-aligned PWM.
- **IMUs:** two ICM-42688-P units on the camera plate, both on SPI. IMU #2 is mounted rotated 180° about Z.
- **MCU:** STM32G4/H7-class with an FPU.

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| IMU sampling / filtering | 8 kHz (ODR) | — |
| Rate (velocity) loop | 4 kHz | ~150–250 Hz |
| Attitude (angle) loop | 1 kHz | ~30–50 Hz |

Each loop should be at least 5–10× faster than the loop outside it.

## 1. FOC Equations

### 1.1 Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0)

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)
$$

### 1.2 Park and inverse Park transforms

The electrical angle is θ_e = p·(θ_m − θ_offset), where p is the number of pole pairs (7 here).

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
\qquad
\begin{bmatrix} v_\alpha\\ v_\beta\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & -\sin\theta_e\\ \sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} v_d\\ v_q\end{bmatrix}
$$

**Latency compensation.** Use θ_e for the current sample and θ_e + 1.5·ω_e·T_pwm for the inverse Park. This accounts for one computation delay plus half a PWM period.

### 1.3 PMSM model and current PI with decoupling

Plant model:

$$
v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad
v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)
$$

PI controller with feed-forward decoupling (the bracketed terms cancel the cross-coupling and back-EMF):

$$
v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L_q i_q,\qquad
v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e (L_d i_d+\lambda_m)
$$

**Gains by pole-zero cancellation.** Placing the PI zero on the electrical pole R/L gives a closed loop that is first-order with bandwidth ω_c:

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \quad(\text{continuous form } K_p + K_i/s)
$$

**Torque command.** Set i_d* = 0 (surface PMSM, no field weakening). Torque is

$$
\tau = \tfrac32 p \lambda_m i_q = K_t\, i_q
$$

**Voltage limit.** Apply a circular limit |v_dq| ≤ V_bus/√3 and give priority to v_q (i_d = 0 stiffness is less critical).

### 1.4 SVPWM by min/max injection

This is equivalent to sector-based SVPWM:

$$
v_{a,b,c} = \text{invClarke}(v_\alpha,v_\beta),\quad
v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\quad
d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}
$$

## 2. Cascaded Attitude → Rate → Torque Control

### 2.1 Structure (per axis)

```
θ* ─►(+)─► [P(+I), FF ω*] ─ω*─►(+)─► [PI + Dfilt] ─τ*─►(+)─► /Kt ─ iq* ─► FOC
      ▲-                           ▲-                   ▲+
      θ̂ (fused attitude → joint)   ω̂ (filtered gyro)     τ_cog_ff(θm) + τ_fric_ff
```

**Feedback sources.** For stabilization, the rate loop uses the filtered, fused gyro rate (inertial-space rate of the camera), not the encoder. The encoder is used only for commutation and the cogging map.

**Frame mapping.** For a yaw–roll–pitch gimbal, map camera-frame rates to joint rates with the inverse joint Jacobian:

$$
\dot{\mathbf q} = \mathbf J(\mathbf q)^{-1}\boldsymbol\omega_{cam}
$$

Near q_roll, q_pitch ≈ 0 this is approximately the identity, and many gimbals use the decoupled approximation. The code exposes a hook for the full version.
