```
                       encoder θm ─┴── cogging FF ────┘
```

| Loop | Rate | Target bandwidth | Feedback |
|---|---|---|---|
| Current (d/q) | 20 kHz | 1.5–2.5 kHz | Phase shunts |
| Velocity | 4 kHz | 150–300 Hz | Fused gyro (camera frame), mapped to joint |
| Angle | 1 kHz | 30–60 Hz | Mahony attitude quaternion |
| IMU | 8 kHz ODR | — | Internal AAF ≈ 1–2 kHz, then software notches |

Use the gyro, not differentiated encoder angle, for velocity feedback. The gyro measures the camera's inertial rate directly. That is the quantity you want stabilized, and it rejects base motion inside the fastest outer loop.

## 2. FOC Current Loop

### 2.1 Transforms

**Clarke (amplitude-invariant, balanced phases):**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park**, with θₑ = p·θₘ + θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 2.2 PMSM Model (Surface-Mount, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

$$\tau = \tfrac32 p\lambda\, i_q = K_t i_q$$
