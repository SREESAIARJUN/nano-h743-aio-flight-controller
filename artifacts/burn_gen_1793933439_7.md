# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual ICM-42688-P Fusion

I have no specification for "Job #11", so this design is built on stated assumptions (§0). Every gain is derived from plant parameters, so you can substitute your own values. Register values marked **[verify]** must be checked against your ICM-42688-P datasheet revision before flashing.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 @ 170 MHz, single-precision FPU, 3× motor timers, SPI DMA |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), used for commutation and cogging phase |
| Current sense | 2-shunt low-side per motor. A voltage-mode fallback is provided. |
| IMUs | 2× ICM-42688-P on the camera plate, on separate SPI buses, rigidly mounted with known rotations R₁ and R₂ |
| Disturbance | Airframe vibration from props (≈ 80–400 Hz, drifting with throttle) plus broadband motor noise |

**Loop rates (all phase-locked to the PWM timer):**

| Loop | Rate | Feedback |
|---|---|---|
| Current (FOC) | 20 kHz | Shunts + encoder |
| Velocity (inertial rate) | 4 kHz | Fused gyro, projected onto the motor axis |
| Angle (attitude) | 1 kHz | Mahony quaternion from the fused IMU |
| Cogging LMS adaptation | 4 kHz |
