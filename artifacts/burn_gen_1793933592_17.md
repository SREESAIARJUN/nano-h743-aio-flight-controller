# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage, Thermal, and Bidirectional DShot600 Design Reference (Job #4)

## 0. Scope, Architecture, and Assumptions

This design produces numbers you can check. Where a value depends on a part you haven't specified, it is listed as an assumption so you can substitute datasheet values.

### 0.1 Architectural correction

The STM32H743 does not commutate the motors.

- **Flight controller domain:** the H743 runs ArduPilot and emits bidirectional DShot600.
- **ESC domain:** each motor channel has its own ESC MCU, assumed here to be an AT32F421 or STM32G071 running AM32 or BLHeli_32. That MCU generates the 48 kHz complementary PWM, handles commutation, and returns eRPM telemetry.

So "48 kHz switching" is an ESC-firmware parameter. "DShot600 DMA allocation" is an H743/ArduPilot `hwdef` problem. They are modeled separately below.

## 1. Conduction Loss Model (80 A burst)

### 1.1 Current paths in 6-step synchronous PWM

During any 60° commutation sector, two phases carry current I (call them A and B):

- **Phase A high side (HS_A):** conducts during the on-time, duty D.
- **Phase A low side (LS_A):** conducts during the off-time as a synchronous rectifier, duty (1 − D).
- **Phase B low side (LS_B):** conducts 100% of the sector.

Instantaneous bridge conduction loss per motor:

$$P_{cond} = I^2 R_{DS}\left[D + (1-D) + 1\right] = 2\,I^2 R_{DS(on)}(T_j)$$

The loss is independent of duty cycle, which is a useful property of synchronous rectification.

### 1.2 Temperature-dependent R_DS(on) and the iterative junction solution

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.005\ /\mathrm{K}$$

This must be solved together with the thermal network (§3), because R rises with T_j, which raises the loss, which raises T_j. The closed form for a single resistance R_θ is:

$$T_j = \frac{T_a + R_\theta\,P_0\,(1 - 25\alpha)}{1 - \alpha R_\theta P_0}, \quad P_0 = 2I^2R_{25}$$

**Stability condition:** α·R_θ·P_0 < 1. If this is violated, the system goes into thermal runaway.
