# STM32H743 AIO Flight Controller + 80A 4-in-1 ESC: Architecture & Mathematical Model (Job #21)

> **Scope.** This document is a rigorous first-pass design model built on stated assumptions. Every component value marked **[A]** is a representative assumption to be replaced with datasheet values for the parts you actually select. The thermal results show that **80A × 4 is a seconds-scale burst rating on a nano board, not a continuous rating**. Treat this as a design basis, not a released schematic.

---

## 0. Architectural Correction (Read First)

The H743 does **not** generate the 48 kHz motor PWM. In every production 4-in-1 stack, commutation runs on dedicated ESC MCUs. The architecture is therefore split as follows:

| Domain | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIH6 (400 MHz) | ArduPilot, sensor fusion, emits **bi-directional DShot600** |
| ESC control | 4× AT32F421 / STM32G071 **[A]** running AM32 | Commutation, 48 kHz PWM, eRPM telemetry |
| Gate drive | 4× 3-phase driver (FD6288Q-class, 10 V bootstrap) **[A]** | Half-bridge drive, dead-time |
| Power stage | 24× N-MOSFET, 40 V, ~1.0 mΩ, 5×6 / 3.3×3.3 **[A]** | 1 FET per switch position |

**Design assumptions:**
- 6S LiPo: V_max = 25.2 V, V_nom = 22.2 V.
- 80 A burst *phase* current per motor.
- Form factor: 30.5×30.5 mm board (20×20 is not credible at this current).

## 1. Conduction Loss Model

### 1.1 Commutation topology
Assume 6-step trapezoidal commutation with synchronous rectification (complementary PWM). At any instant, current I flows through exactly **one high-side path and one low-side path**:
- When the HS is ON, current flows through HS(a) and LS(b).
- When the HS is OFF, current freewheels through LS(a), which is gated ON, and LS(b).

In both states, two R_DS(on) are in series, independent of duty cycle D.

### 1.2 Temperature-corrected R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,\left[1+\alpha\,(T_j-25)\right],\quad \alpha \approx 0.0055\ /^\circ\text{C}$$

$$R_{DS}(110^\circ\text{C}) = 1.0\ \text{m}\Omega \times 1.47 \approx 1.47\ \text{m}\Omega \;\; (\text{use } 1.5\ \text{m}\Omega)$$

### 1.3 Per-motor and board conduction loss

$$P_{cond,motor} = I^2\,(2R_{DS,hot} + R_{Cu})$$

Take R_Cu ≈ 0.4 mΩ **[A]** as the effective copper path (pads, planes, phase pads). Then:

$$P_{cond,motor} = 80^2\,(3.0 + 0.4)\times10^{-3} = 6400 \times 3.4\times10^{-3} = \mathbf{21.8\ W}$$

- FET-only share: 19.2 W.
- Average per FET: 19.2 / 6 = **3.2 W** (each FET conducts about 1/3 of the electrical cycle, weighted by D).
- **4 motors at 80 A: P_cond ≈ 87 W.**

### 1.4 Current-sense shunt (if used)
With a 0.25 mΩ shunt carrying total battery current I_batt = D·I_ph (D = 0.9 gives 4 × 72 = 288 A):

$$P_{shunt} = 288^2 \times 0.25\text{m}\Omega \approx 20.7\ \text{W}$$

**Recommendation:** use a Hall sensor or a 0.1 mΩ shunt with a Kelvin connection instead.

## 2. Switching Loss Model at f_sw = 48 kHz

### 2.1 Representative MOSFET and driver parameters [A]

| Parameter | Value |
|---|---|
| Q_g (10 V) | 60 nC |
| Q_gs2 + Q_gd (switching charge) | 6 + 12 = 18 nC |
| V_plateau | 3.5 V |
| R_g,int | 1.5 Ω |
| Q_rr (at 80 A, high di/dt) | 60 nC |
| Q_oss (at 25 V) | 40 nC |
| V_SD (body diode) | 0.8 V |
| Driver output resistance | 3 Ω source / 1.5 Ω sink |
| R_g,ext | 4.7 Ω on; 2.2 Ω off via diode bypass |
| Dead time t_dt | 100 ns per edge |

### 2.2 Transition times

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{drv,src}+R_{g,ext}+R_{g,int}} = \frac{10-3.5}{3+4.7+1.5} = 0.71\ \text{A}$$

$$t_{on} = \frac{Q_{sw}}{I_{g,on}} = \frac{18\ \text{nC}}{0.71} \approx 25.5\ \text{ns}$$

$$I_{g,off} = \frac{3.5}{1.5+2.2+1.5} = 0.67\ \text{A}, \qquad t_{off} \approx 26.9\ \text{ns}$$
