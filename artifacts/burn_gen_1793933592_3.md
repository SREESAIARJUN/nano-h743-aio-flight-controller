# STM32H743 Nano FC + 4-in-1 ESC (Job #37): Reference Design Package

**Scope:** This package covers the power-stage loss model, thermal model, ArduPilot bi-directional DShot600 timer and DMA plan, and a reference netlist for the critical paths.

**Status:** These are pre-layout engineering estimates. Every component parameter is listed as an assumption so you can substitute datasheet values. The netlist is a reference topology, not a fab-ready output. It must be captured in EDA, run through ERC and DRC, and validated on hardware.

---

## 0. Feasibility Finding

The thermal model in Section 3 shows that **80 A per channel on a nano (20×20 mm) 4-in-1 is only survivable as a sub-1.5-second transient.** It is not a sustained or 10-second burst rating. The board's heat capacity is roughly 3–4 J/K, and four channels at 80 A dissipate about 100 W.

Recommendations:
- Market the board as "80 A peak (≤1 s)" with a 35–45 A continuous rating, **or**
- Move to a 30.5×30.5 mm form factor with 8-layer 2 oz copper.

The math below lets you defend whichever choice you make.

## 1. System Architecture and Assumptions

```
6S LiPo (25.2 V max) ──► Power input ──► 4× 3-phase bridges (24 MOSFETs)
                                         ▲
             4× ESC MCU (AT32F421 / AM32) ── 4× 3-phase gate drivers
                     ▲  DShot600 bidir (4 lines)
             STM32H743VIT6 (ArduPilot) on the FC section
```

The H743 does **not** commutate the motors. Each channel has a dedicated ESC MCU running AM32 or BLHeli_32. The H743 only generates DShot commands and decodes the eRPM telemetry.

## 2. Electrical Loss Model (per channel)

### 2.1 Conduction losses

The firmware uses six-step trapezoidal commutation with complementary (synchronous-rectified) PWM. During any sector, current flows through:
- the PWM leg, which alternates between its high-side FET for duty D and its low-side FET for 1−D, and
- the return leg, whose FET is on continuously.

At any instant, exactly two FET channels are in the current path:

$$P_{cond} = I_{rms}^2\,R_{ds}(T_j)\,\big[D + (1-D)\big] + I_{rms}^2\,R_{ds}(T_j) = 2\,I_{rms}^2\,R_{ds}(T_j)$$

Temperature dependence:

$$R_{ds}(T_j) = R_{ds,25}\,\big[1 + \alpha\,(T_j - 25)\big]$$

At T_j = 125 °C, the factor is 1 + 0.0045 × 100 = 1.45, so R_ds = 1.74 mΩ.

Results:
- **P_cond(25 °C) = 2 × 80² × 1.2 mΩ = 15.4 W**
- **P_cond(125 °C) = 2 × 6400 × 1.74 mΩ = 22.3 W**

Copper loss:

$$P_{Cu} = I^2 R_{Cu} = 6400 \times 0.5\,\text{m}\Omega = 3.2\ \text{W}$$

Copper resistance also rises about 0.39 %/K, giving roughly 4.0 W at 75 °C.

**Electrothermal feedback.** The loss is a fixed point of T_j = T_a + P(T_j)·R_θ. A steady-state solution exists only if:

$$2I^2 R_{ds,25}\,\alpha\,R_\theta < 1$$

At 80 A this requires R_θ < 1 / (12 800 × 1.2e-3 × 0.0045) ≈ **14.5 K/W**. The board's convective R_θ (Section 3) is about 1.9–2 K/W for the whole board. That is stable, but only at an unacceptable temperature. See Section 3.

### 2.2 Switching losses at 48 kHz

Only the PWM leg hard-switches. Its synchronous partner commutates softly after the dead time.

**(a) V–I overlap:**

$$P_{VI} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\text{ ns} \times 48\text{ kHz} = 0.97\ \text{W}$$

**(b) Output capacitance:**

$$P_{oss} = Q_{oss} V_{bus} f_{sw} = 40\text{ nC} \times 25.2 \times 48\text{ k} = 0.048\ \text{W}$$

**(c) Body-diode dead-time conduction** (two edges per period):

$$P_{dt} = V_f\,I\,(2 t_{dead}) f_{sw} = 0.85 \times 80 \times 200\text{ ns} \times 48\text{ k} = 0.65\ \text{W}$$

**(d) Reverse recovery:**

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 50\text{ nC} \times 25.2 \times 48\text{ k} = 0.06\ \text{W}$$

**(e) Gate drive** (two FETs switching in the PWM leg). This loss is dissipated mostly in the driver and gate resistors, not the FETs:

$$P_{g} = 2\,Q_g V_{drv} f_{sw} = 2 \times 50\text{ nC} \times 10 \times 48\text{ k} = 0.048\ \text{W}$$

**Switching subtotal ≈ 1.78 W per channel.**

Note that switching loss scales linearly with f_sw. At 24 kHz it would be about 0.9 W, and at 96 kHz about 3.6 W. At 80 A, conduction loss dominates by more than 10×, so 48 kHz is a reasonable choice for current ripple and acoustic noise.

### 2.3 Per-channel and board totals (T_j = 125 °C)

| Loss | W / channel |
|---|---|
| Conduction (FETs) | 22.3 |
| Copper | 3.2–4.0 |
| Switching (all terms) | 1.8 |
| **Total** | **≈ 27.7** |
| **4 channels simultaneous** | **≈ 111 W** |

Worst single FET: the return-leg FET carries the full current for one 60° sector pair (1/3 of the electrical period), averaged across the six steps:

$$P_{FET,avg} \approx \tfrac{1}{3}\cdot I^2 R_{ds} \approx 3.7\ \text{W}$$

The instantaneous peak while conducting is 11.1 W.

## 3. Thermal Model

### 3.1 Junction rise above PCB (per FET)

Using the time-averaged FET loss:

$$\Delta T_{JC} = 3.7 \times 1.5 \approx 5.6\ \text{K}$$

Sector-scale ripple is negligible because the commutation period is much shorter than the die thermal time constant (~ms). **The junction is not the bottleneck. The PCB is.**

### 3.2 Board-level lumped RC model

Board heat capacity, 20×20 mm, 8-layer, 2 oz outer and 1 oz inner copper:

| Element | Mass | c_p | C |
|---|---|---|---|
| FR-4 (≈1.3 g) | 1.3 g | 1.1 J/gK | 1.4 J/K |
| Copper (≈1.6 g) | 1.6 g | 0.385 J/gK | 0.6 J/K |
| 24 FETs + drivers + MCUs + solder | ≈1.5 g | ~0.7 J/gK | 1.0 J/K |
| **C_th** | | | **≈ 3.0 J/K** |

Convective resistance under prop wash, with h ≈ 80 W/m²K over both sides (A ≈ 8 cm² plus components ≈ 10 cm²):

$$R_{\theta,BA} = \frac{1}{hA} = \frac{1}{80 \times 0.001} = 12.5\ \text{K/W}$$

The motor phase wires and battery leads conduct heat away in parallel, roughly 15–20 K/W. Combined with convection, the effective R_θ is about **7 K/W**.

**Steady state at 111 W:** ΔT = 111 × 7 ≈ 780 K. This is impossible, so 80 A is strictly a transient condition.
