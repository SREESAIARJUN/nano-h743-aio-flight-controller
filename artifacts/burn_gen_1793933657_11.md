# STM32H743 Nano FC + 4-in-1 ESC (Job #73): Power-Stage Loss Model, Thermal Budget, and Bidirectional DShot600 DMA Allocation

## 0. Scope, Assumptions, and Two Early Findings

**Architecture.** The STM32H743 is the flight controller MCU. It does not commutate the motors. Each ESC channel runs its own MCU (AM32 on an AT32F421 or STM32G071, or BLHeli_32), which generates the 48 kHz PWM. The H743 sends bidirectional DShot600 and receives eRPM telemetry. The loss model (Sections 1–3) belongs to the ESC side. The DMA plan (Section 4) belongs to the FC side.

**Assumed parameters.** Substitute your actual BOM values. Every equation is written so you can re-run it.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge, worst case) | V_bus | 25.2 V |
| Burst phase current per motor | I | 80 A |
| PWM frequency | f_sw | 48 kHz |
| Duty at burst (near full throttle) | D | 0.9 |
| MOSFET, 40 V class, PDFN5×6 | R_ds(on),25 | 1.0 mΩ @ V_gs = 10 V |
| R_ds temperature coefficient | α | ≈ 0.006 /K |
| Gate–drain charge, plus post-threshold gate–source charge | Q_gd + Q_gs2 | 10 + 5 = 15 nC |
| Total gate charge | Q_g | 50 nC |
| Effective output capacitance (energy-related) | C_oss(er) | 1.2 nF |
| Body-diode reverse-recovery charge; diode forward voltage | Q_rr; V_f | 40 nC; 0.8 V |
| Gate driver (FD6288Q-class), 10 V drive | R_src / R_snk | ≈ 5 Ω / 3 Ω |
| External / internal gate resistance | R_g,ext / R_g,int | 1.0 Ω / 1.5 Ω |
| Miller plateau voltage | V_pl | 3.5 V |

| Commutation | — | 6-step trapezoidal, complementary (synchronous-rectified) PWM |

> **⚠ Finding 1: "80 A burst ×4" fails thermally on a nano-format board.** All four channels at 80 A dissipate about 93 W into a board with roughly 5 J/K of heat capacity. Section 3 shows this is a 1–2 second capability at most. It is not a sustained rating. The spec needs a defined burst profile, for example "80 A per motor for ≤1 s, ≤10 % duty cycle." It should not be a single headline number.

> **⚠ Finding 2: Bidirectional DShot cannot use complementary (CHxN) timer pins.** Input capture does not exist on CHxN outputs. All four motor outputs must be routed to true CHx pins (Section 4).

## 1. Conduction Loss Model

### 1.1 Temperature-corrected on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)] \;\Rightarrow\; R_{ds}(125^\circ C)=1.0\,(1+0.6)=1.6\ \text{m}\Omega$$

Use the hot value. A model built on R_ds(25 °C) underestimates loss by 60 %.

### 1.2 Current path in 6-step commutation with synchronous rectification

At every instant, exactly two FETs carry the full phase current I:

- In the PWM leg, the high-side FET conducts for a fraction D of each period and the low-side FET for 1−D.
- In the return leg, the low-side FET is on 100 % of the time.

Each phase spends one-third of the electrical cycle as the PWM leg, one-third as the return leg, and one-third floating. The total per channel is independent of duty cycle:

$$P_{cond,ch} = 2\,I^2 R_{ds}(T_j) = 2(80)^2(1.6\times10^{-3}) = \mathbf{20.5\ W}$$

Per-FET distribution, using the motor-current ripple approximation I_rms ≈ I_dc (valid when L_motor·f_sw ≫ R_motor·T):

$$P_{HS}=I^2R\cdot\frac{D}{3}=10.24\cdot0.30=\mathbf{3.07\ W}$$

$$P_{LS}=I^2R\cdot\frac{(1-D)+1}{3}=10.24\cdot0.367=\mathbf{3.75\ W}$$

Check: 3 × (3.07 + 3.75) = 20.5 W ✓.

**Design implication.** The low-side FETs are the hottest parts. Place them on the strongest copper and via-stitch them to the inner ground planes.

### 1.3 PCB copper loss (frequently omitted)

Assume about 0.5 mΩ total path resistance (battery pad → FET → motor pad, 2 oz copper, nano layout):

$$P_{Cu}=I^2R_{path}=6400\times0.5\times10^{-3}=\mathbf{3.2\ W/ch}$$

This heat spreads across the board rather than concentrating in the FETs, but it still counts toward the board's heat capacity.
