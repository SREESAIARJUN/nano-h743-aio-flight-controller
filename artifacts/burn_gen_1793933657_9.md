# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #62): 80 A Burst Thermal, 48 kHz Switching and Bi-Directional DShot600 Design Package

## 0. Architecture and Assumptions

### Architectural clarification
In a 4-in-1 ESC the STM32H743 does not drive the MOSFET gates. It runs ArduPilot and sends DShot600 frames. Each motor channel has its own ESC MCU running AM32 or BLHeli_32, which generates the 48 kHz complementary PWM.

The design is split into three domains:

| Domain | Function |
|---|---|
| A | STM32H743 FC: DShot600 output, eRPM telemetry capture |
| B | 4× ESC MCU (e.g. AT32F421 / STM32G071, AM32): commutation and 48 kHz PWM |
| C | Power stage: 4× (3-phase half-bridge) = 24 MOSFETs, gate drivers, current shunts |

## 1. Conduction Loss Model

### 1.1 Six-step conduction with synchronous rectification
In 120° trapezoidal commutation, two phases conduct at any instant:
- The PWM leg alternates between its high-side switch (duty D) and its low-side switch (1−D, synchronous rectification).
- The return leg's low-side switch is held on.

At every instant, exactly two R_DS(on) are in series with the phase current. The conduction loss is therefore independent of duty cycle (ripple and dead time neglected):

$$P_{cond} = I^2\left[2R_{DS}(T_j) + R_{pcb}\right], \qquad R_{DS}(T_j) = R_{25}\left[1+\alpha(T_j-25)\right]$$

### 1.2 Including current ripple
With phase inductance L_ph, the RMS correction is:

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{(V_{bus}-V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

**Worked example.** A typical 5″ motor has L_ph ≈ 15 µH. Take D = 0.9 and V_bemf ≈ 0.85·V_bus:
- ΔI ≈ (3.8 × 0.9) / (15 µH × 48 kHz) ≈ 4.7 A
- The correction term is ΔI²/12 ≈ 1.9 A², about 0.03 % of I². This is negligible.

### 1.3 Numbers at T_j = 110 °C
- R_DS(110 °C) = 1.2 × (1 + 0.0055 × 85) = 1.761 mΩ
- MOSFET term: 80² × 2 × 1.761 mΩ = **22.5 W per channel**
- Copper term: 80² × 0.5 mΩ = **3.2 W per channel**
- **P_cond, total ≈ 25.7 W per channel**

### 1.4 Distribution across MOSFETs
Each switch conducts for 1/3 of an electrical cycle, so the average per FET is about 22.5/6 ≈ 3.75 W. The instantaneous peak is I²R = 11.3 W.

At 80 A the commutation period is a few hundred µs, which is shorter than the die's thermal time constant (~1–5 ms). Use the peak value for junction rise and the average value for board heating.

### 1.5 Electrothermal feedback
R_DS(on) rises with temperature, which raises loss, which raises temperature. Solve this iteratively:

$$T_j = T_{board} + P_{FET}(T_j)\,R_{\theta JB}$$

The loop is stable if:

$$\frac{\partial P}{\partial T}\,R_{\theta JB} = I^2 R_{25}\,\alpha\,R_{\theta JB} < 1$$

Check: 6400 × 1.2e-3 × 0.0055 × 2 = 0.084. This is far below 1, so the loop converges and there is no runaway.
