## 0. Design Assumptions

I don't have the Job #19 spec sheet, so the design rests on the assumptions below. Every value lives in one `Config` block so you can substitute the actual hardware values.

| Item | Assumption |
|---|---|
| MCU | STM32G474 (170 MHz, single-precision FPU, CORDIC available) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.6 Ω, L ≈ 2.1 mH, K_t ≈ 0.12 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) per axis |
| IMUs | 2 × ICM-42688-P on SPI @ 24 MHz with DMA, ODR 8 kHz. IMU_P is on the camera payload, IMU_B on the handle/base |
| Loop rates | Current/FOC 20 kHz · Velocity 4 kHz · Angle/attitude 1 kHz |
| Kinematics | Base → Yaw → Roll → Pitch → payload |

**Architecture.**
- The velocity loop runs on **inertial payload rate** (IMU_P projected onto each joint axis). The encoder is used for commutation, cogging phase, and joint-rate estimation.
- IMU_B supplies **base-disturbance feedforward**, which cancels handle motion before it reaches the payload.
- Both IMUs pass through anti-alias, dynamic-notch, and low-pass stages before fusion.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Electrical Angle and Transforms

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Delay compensation.** PWM update and ADC sampling introduce about 1.5 T_s of transport delay. Rotate the inverse-Park angle forward to compensate:
$$\theta_e^{inv} = \theta_e + 1.5\,\omega_e T_s$$

### 1.2 PMSM Model in the d/q Frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$
$$\tau = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 1.3 Current PI with Pole-Zero Cancellation

The plant is $G(s)=\frac{1}{Ls+R}$. Choose the controller
$$C(s)=K_p + \frac{K_i}{s}, \qquad K_p = L\,\omega_c,\quad K_i = R\,\omega_c$$

The controller zero $K_i/K_p = R/L$ cancels the electrical pole, giving the closed loop $T(s)=\frac{\omega_c}{s+\omega_c}
