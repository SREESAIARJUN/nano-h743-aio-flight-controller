# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have a spec sheet for "Job #4", so this design states its assumptions explicitly. Every constant is a named parameter, and Section 0 lists what to change for your hardware. The code is a reference design: verify register values against your datasheet revision and bring it up on hardware with conservative gains before trusting it.

---

## 0. Assumptions

| Item | Value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class) |
| MCU | Cortex-M7/M4F with FPU, e.g. STM32G4/H7, 3 advanced timers |
| PWM / current loop | 20 kHz, center-aligned, with synchronous ADC sampling |
| IMUs | 2× ICM-42688-P on the camera plate, on separate SPI buses, sharing CLKIN |
| IMU ODR | 8 kHz, decimated to 4 kHz after filtering |
| Loop rates | Current 20 kHz, rate 4 kHz, angle 1 kHz, attitude 4 kHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |
