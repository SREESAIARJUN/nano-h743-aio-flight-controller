# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #55 hardware spec, so these assumptions are typical for a mid-size camera gimbal. Every one is a `constexpr` parameter in the code and can be changed.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), read every current-loop tick |
