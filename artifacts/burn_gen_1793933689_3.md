# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #27," so this design rests on the assumptions below. If your hardware differs, the equations still hold. You would only need to change the parameters.

## 0. Design Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC/PMSM, 12N14P (Ns = 12 slots, p = 7 pole pairs), ~10 Ω phase resistance, ~2 mH phase inductance |
| Position sensor | 14-bit magnetic encoder per axis (AS5048A/MT6701 class), read every PWM cycle |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| PWM / current loop | 20 kHz center-aligned PWM, current loop at 20 kHz |
| Velocity loop | 4 kHz (every 5th PWM cycle) |
| Angle loop | 1 kHz |
| IMUs | 2× ICM-42688-P on SPI, 8 kHz ODR, ±2000 dps, ±16 g, both on the camera platform |
| Current sensing | 2- or 3-shunt low-side, sampled at the PWM center |

**Loop timing hierarchy**

```
20 kHz : ADC → Clarke/Park → PI(d,q) → inv-Park → SVPWM        (ISR, highest priority)
 8 kHz : IMU A+B read (DMA) → per-IMU notch/LPF → fusion → rate signal
 4 kHz : velocity PI (+ anti-cogging FF, + accel FF) → iq*
 1 kHz : attitude estimator (Mahony) → angle P(+FF) → ω*
```

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle: θe = p·(θm − θoffset).

Clarke transform (amplitude-invariant, with ia + ib + ic = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)
$$

Park transform:

$$
\begin{bmatrix} i_d \\ i_q \end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}
$$

Inverse Park transform:

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 1.2 Plant (SPMSM, Ld = Lq = L)

$$
L\frac{di_d}{dt} = v_d - R i_d + \omega_e L i_q
$$

$$
L\frac{di_q}{dt} = v_q - R i_q - \omega_e L i_d - \omega_e \lambda_m
$$

$$
\tau_e = \tfrac32\, p\, \lambda_m\, i_q = K_t\, i_q
$$

### 1.3 Current PI by Pole-Zero Cancellation

The plant is G(s) = 1/(Ls + R). Use a PI controller C(s) = Kp + Ki/s and choose:

$$
K_p = L\,\omega_{c},\qquad K_i = R\,\omega_{c}
$$

With this choice, C(s)G(s) = ωc/s, and the closed loop becomes the first-order system ωc/(s + ωc).

- Choose ωc ≤ 2π·fPWM/20. With fPWM = 20 kHz, ωc ≈ 2π·1 kHz.
- Decoupling and back-EMF feedforward are added to the PI output:
  - vd,ff = −ωe·L·iq
  - vq,ff = +ωe·L·id + ωe·λm

**Discrete form** (Ts = 1/fPWM), with back-calculation anti-windup:

$$
u_k = K_p e_k + I_k + v_{ff},\qquad u^{sat}_k = \mathrm{sat}(u_k)
$$

$$
I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(u^{sat}_k - u_k),\qquad K_{aw} = \frac{1}{K_p}\,K_i T_s \;(\text{typ.})
$$

**Voltage vector limit.** The d-axis has priority, then the remaining voltage goes to q:

$$
|v_d| \le V_{max},\qquad |v_q| \le \sqrt{V_{max}^2 - v_d^2},\qquad V_{max} = \frac{V_{bus}}{\sqrt3}\cdot 0.95
$$

### 1.4 SVPWM (Min-Max Zero-Sequence Injection)

$$
v_a = v_\alpha,\qquad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\qquad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta
$$

$$
v_0 = -\tfrac12\,[\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)]
$$

$$
d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}
$$

This is mathematically identical to sector-based SVPWM.
