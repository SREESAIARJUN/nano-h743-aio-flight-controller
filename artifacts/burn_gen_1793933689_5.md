# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #2 spec, so the design below rests on stated assumptions. Every hardware-dependent number is a named constant you can replace with your own values.

## 0. Assumptions

| Item | Assumed value |
|---|---|
| Motors | Outrunner gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.2 mH (phase), K_t ≈ 0.09 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) per axis |
| MCU | STM32G4 / H7 class, single-precision FPU, center-aligned PWM |
| Bus | V_dc = 12–16 V |
| Rates | Current loop 20 kHz, velocity loop and cogging FF 5 kHz, IMU filtering 4 kHz (ODR 8 kHz, decimated), attitude loop 1 kHz |
| IMUs | Two ICM-42688-P on the camera plate, rigidly mounted, with different orientations/positions to decorrelate local PCB modes |
| Kinematics | Gimbal order Yaw (z) → Roll (x) → Pitch (y) → camera |

## 1. Field-Oriented Control (innermost loop, 20 kHz)

### 1.1 Transforms
Clarke (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park, with electrical angle θ_e = p·θ_m − θ_off:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose.
