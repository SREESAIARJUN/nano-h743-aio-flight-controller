**Timing hierarchy:**

```
TIM ISR 20 kHz : ADC → Clarke/Park → PI_d, PI_q → invPark → SVPWM     (per motor)
every 5th tick : encoder PLL → velocity PI (+ cogging FF) → iq_ref
IMU DRDY 8 kHz : read 2× IMU → calibrate → lever-arm comp → notch/LPF → fuse
1 kHz task     : attitude filter → attitude error → J⁻¹ → joint rate cmds
```

## 1. Field-Oriented Control (Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical angle, where θ_off is the encoder-to-rotor alignment offset found during calibration:

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix}$$

### 1.2 Plant Model and Decoupled PI Control

The PMSM voltage equations in the dq frame are:

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$

where the flux linkage is λ_m = Kt / (1.5 p).

Each axis is controlled by a PI loop with decoupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L_q i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L_d i_d + \omega_e\lambda_m$$
