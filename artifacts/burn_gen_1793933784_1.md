# STM32H743 Nano FC + 4-in-1 ESC: Power, Thermal and DShot Architecture Model

## 0. Scope and Assumptions

I don't have the Job #3 specification (MOSFET part, board size, cell count, airflow). Every number below therefore comes from a **stated assumption**, and every result is given as a parametric equation so you can substitute datasheet values. Replace the parameters in §0.2 and re-run the model before committing the layout.

### 0.1 Architectural correction

The STM32H743 should **not** commutate the motors directly. ArduPilot does not run ESC firmware, and doing 4× sensorless 6-step commutation at 48 kHz on the flight MCU is not a supported configuration. The standard architecture is:

```
STM32H743 (ArduPilot)  --bidir DShot600 x4-->  4x ESC MCU (AM32 / BLHeli_32-class)
                                                 └─> 3-phase gate driver ─> 6x N-FET per channel
```

The H743 owns the DShot/telemetry timing (§4). Each ESC MCU (e.g. AT32F421 or STM32G071) owns the 48 kHz PWM.
