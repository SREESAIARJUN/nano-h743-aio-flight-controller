# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Fusion

I don't have the original "Job #7" specification, so this design states its assumptions explicitly. All parameters are collected in one config struct, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motors (e.g. GBM2804H, 12N14P, so 7 pole pairs, R ≈ 5–10 Ω, L ≈ 2–4 mH) |
| Encoders | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| Driver | 3× half-bridge with in-line or low-side current shunts |
| MCU | STM32G474 / H7 class, with FPU |
| IMU | 2× ICM-42688-P on the camera plate, at 8 kHz ODR |
| Kinematic order | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) → camera |

**Loop rates**

| Loop | Rate | Bandwidth target |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| Rate (gyro) | 4 kHz | ~80–150 Hz |
| Attitude (angle) | 1 kHz | ~10–25 Hz |
| Encoder PLL | 20 kHz | ~300 Hz |

## 1. Field-Oriented Control Equations

### 1.1 Electrical angle

$$\theta_e = \mathrm{wrap}_{2\pi}\big(p\,(\theta_m - \theta_{\text{offset}})\big)$$

where p is the number of pole pairs and θ_offset is found at calibration by aligning the rotor with V_d.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park transform

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame

$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q\dot i_q + \omega_e L_d i_d + \omega_e\lambda_m$$
$$\tau = \tfrac32\,p\,\lambda_m\, i_q = K_t\, i_q \quad (\text{surface PM},\ L_d = L_q)$$

### 1.5 Current PI with pole-zero cancellation

The plant is $G(s) = 1/(Ls+R)$. Choosing the gains below cancels the plant pole and gives a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; \frac{I}{I^*} = \frac{\omega_c}{s+\omega_c}$$

Rule of thumb: ω_c ≤ 2π·f_pwm/10.

**Decoupling and back-EMF feedforward**

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e L\, i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e L\, i_d + \hat\omega_e\lambda_m$$

**Voltage limit and anti-windup**

The voltage vector is limited to the circle $\|v_{dq}\| \le V_{bus}/\sqrt3$. Priority goes to v_d, then v_q gets the remainder:

$$v_{q,\max}=\sqrt{V_{\max}^2 - v_d^2}$$

The integrators use back-calculation anti-windup:

$$\dot x_I = K_i e + K_{aw}(u_{sat}-u)$$

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a=v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically equivalent to 7-segment SVPWM.

The angle used for the inverse Park transform is advanced by 1.5 sample periods to compensate the PWM/computation delay:

$$\theta_e^{\text{inv}} = \theta_e + 1.5\,\hat\omega_e T_s$$

## 2. Encoder Velocity: Phase-Locked Loop Observer

Differentiating a 14-bit encoder at 20 kHz gives quantization noise of about 2π/16384 · 20000 ≈ 7.7 rad/s. That is unusable, so a type-2 PLL observer is used instead:

$$e_k = \mathrm{wrap}_{\pi}(\theta_{m,k} - \hat\theta_k)$$
$$\hat\omega_{k+1} = \hat\omega_k + K_i\,e_k\,T_s$$
$$\hat\theta_{k+1} = \hat\theta_k + (\hat\omega_{k+1} + K_p e_k)\,T_s$$

Gain selection:

$$K_p = 2\zeta\omega_n,\quad K_i = \omega_n^2,\quad \zeta = 1,\ \omega_n = 2\pi\cdot 300$$
