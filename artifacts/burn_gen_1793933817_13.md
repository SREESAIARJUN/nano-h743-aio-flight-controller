# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #52 specification, so the design below uses typical brushless gimbal values. **Replace every value marked ⚙ with your own hardware data.**

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class, FPU, 170+ MHz |
| Motor ⚙ | 12N14P gimbal BLDC (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder ⚙ | 14-bit absolute magnetic (AS5048A / MT6701), one per axis |
| IMUs | 2× ICM-42688-P on the camera stage, SPI at 24 MHz |
| Current sense | 2- or 3-shunt, sampled at the PWM center |

Loop rates:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| IMU ODR | 8 kHz | n/a |
| Rate (velocity) | 4 kHz | 60–120 Hz |
| Attitude (angle) | 1 kHz | 15–25 Hz |

Control architecture:
- **Commutation** uses the encoder.
- **Stabilization** uses the IMU, because the rate loop must reject *inertial* disturbances, which the encoder cannot see.
- The **encoder velocity** is used only during anti-cogging identification and as a fallback.

### 1.1 Transforms

Amplitude-invariant Clarke transform:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

$$\theta_e = p\,(\theta_m - \theta_{off})$$
