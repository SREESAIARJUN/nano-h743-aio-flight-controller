## 1. FOC Inner Current Loop (20 kHz)

### 1.1 Transforms
Use the amplitude-invariant transforms with balanced currents (i_a + i_b + i_c = 0) and electrical angle θ_e = p·θ_m − θ_offset.

**Clarke**
$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park**
$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 PMSM model in the dq frame
$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$
$$\tau_e = \tfrac32 p\lambda\, i_q = K_t\, i_q$$

### 1.3 Current PI by pole-zero cancellation
After decoupling, each axis is the plant 1/(Ls + R). A PI controller C(s) = K_p + K_i/s with K_i/K_p = R/L cancels the plant pole. The closed loop then becomes first-order with bandwidth ω_c:
$$K_p^{(i)} = L\,\omega_c,\qquad K_i^{(i)} = R\,\omega_c,\qquad \omega_c \le \frac{2\pi f_{pwm}}{10\ldots20}$$

With f_pwm = 20 kHz, choose ω_c = 2π·1500 rad/s.

**Decoupling and back-EMF feedforward**
$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e (L i_d + \lambda)$$

Set i_d* = 0 (surface PMSM, no field weakening is needed at gimbal speeds).

**Voltage limit (circular, SVPWM linear region)**
$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

Saturate v_q with priority. Feed the saturated voltage back to the integrators (Section 2.2).

### 1.4 SVPWM by min-max zero-sequence injection
This form is equivalent to sector-based SVPWM but branch-free:
$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$
$$v_0 = -\tfrac12(\max+\min),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Mechanical plant (per axis)
$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

Because the current loop is roughly 10× faster than the velocity loop, it is treated as unity gain. The velocity plant is then K_t/(Js).

### 2.2 Discrete PID with filtered derivative and back-calculation anti-windup
In continuous time:
$$u = K_p e + K_i\!\int e\,dt + K_d \frac{s}{\tau_d s+1}e$$

Discretize with Tustin (sample time T_s). Derivative on measurement avoids setpoint kick.

$$P_k = K_p e_k$$
$$D_k = \frac{2\tau_d - T_s}{2\tau_d + T_s}D_{k-1} - \frac{2K_d}{2\tau_d+T_s}(y_k - y_{k-1})$$
$$u_k^{raw} = P_k + I_k + D_k + u_{ff},\qquad u_k = \text{sat}(u_k^{raw})$$
$$I_{k+1} = I_k + K_i T_s e_k + K_{aw} T_s (u_k - u_k^{raw})$$

A good default is K_aw = 1/T_t, with tracking time T_t = √(T_i T_d), or T_t = T_i for a PI controller.
