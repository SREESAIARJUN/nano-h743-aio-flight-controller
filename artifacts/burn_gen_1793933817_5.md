## 1. Field-Oriented Control: Equations

### 1.1 Transforms

Electrical angle (θ_off comes from encoder alignment):

  θ_e = p·(θ_m − θ_off) mod 2π

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

  i_α = i_a
  i_β = (i_a + 2·i_b)/√3

**Park transform:**

  i_d = i_α·cos θ_e + i_β·sin θ_e
  i_q = −i_α·sin θ_e + i_β·cos θ_e

**Inverse Park transform:**

  v_α = v_d·cos θ_e − v_q·sin θ_e
  v_β = v_d·sin θ_e + v_q·cos θ_e

### 1.2 Plant and current PI with decoupling

The dq-frame plant model is:

  v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
  v_q = R·i_q + L·di_q/dt + ω_e·(L·i_d + ψ_m)

Here ω_e = p·ω_m and ψ_m = Kt/(1.5·p).

The control law is a PI on each axis plus decoupling feedforward:

  v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
  v_q* = PI_q(i_q* − i_q) + ω_e·(L·i_d + ψ_m)

**Gain selection by pole-zero cancellation.** This gives a first-order closed loop with bandwidth ω_c:

  K_p,i = L·ω_c,  K_i,i = R·ω_c

Choose ω_c ≤ 2π·f_pwm/10. At 20 kHz PWM that is about 2π·2 kHz.

### 1.3 Discrete PI with back-calculation anti-windup

For each PI loop, the per-sample update is:

  u_raw[k] = K_p·e[k] + I[k]
  u[k] = sat(u_raw[k])
  I[k+1] = I[k] + T_s·( K_i·e[k] + K_aw·(u[k] − u_raw[k]) )

Use K_aw ≈ K_i/K_p.

**Voltage limiting.** The d and q voltages share one limit, with d-axis priority:

  |v_d| ≤ V_max
  |v_q| ≤ √(V_max² − v_d²)
  V_max = V_bus/√3 (linear SVPWM range)

### 1.4 SVPWM by min-max zero-sequence injection

1. Inverse Clarke:
   - v_a = v_α
   - v_b = −½·v_α + (√3/2)·v_β
   - v_c = −½·v_α − (√3/2)·v_β
2. Zero-sequence offset: v_0 = −(max(v_a,v_b,v_c) + min(v_a,v_b,v_c))/2
3. Duties: d_x = ½ + (v_x + v_0)/V_bus, for x ∈ {a, b, c}

This is mathematically identical to sector-based SVPWM.

**Voltage-mode fallback (no shunts).** Set v_q = R·i_q* + ω_e·ψ_m and v_d = −ω_e·L·i_q*. This works well for high-R gimbal motors.

## 2. Cascaded Angle and Velocity Control

The cascade is:

```
θ* ─►[Angle P + ω_ff]─ω*─►[Velocity PI + accel FF]─i_q*─►(+ cogging FF)─►[Current PI]─►Motor
         ▲ θ̂ (IMU attitude projected on axis)    ▲ ω̂ (gyro rate on axis; encoder blended)
```

The gimbal stabilizes the **camera** in inertial space, so the outer loops use IMU feedback:

- **θ̂:** the attitude estimate projected onto the joint axis.
- **ω̂:** the gyro rate along the joint axis, ω̂ = â_jᵀ·ω_cam.
- **Low-frequency blending:** to avoid drift-induced fighting, blend the gyro rate with the encoder rate through a complementary filter:

  ω̂ = HPF(ω_gyro) + LPF(ω_enc + ω_base,axis)

A simpler, robust alternative is to use the gyro alone with a well-estimated bias.
