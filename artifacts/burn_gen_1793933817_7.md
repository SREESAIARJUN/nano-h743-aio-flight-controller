# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #0 specification, so the design below is fully parameterized. The numbers I use are typical for a mid-size camera gimbal. Replace them with your measured values. Every gain is derived from plant parameters, so nothing depends on hand-tuning magic numbers.

## 0. Assumptions and Rate Plan

| Item | Assumed value |
|---|---|
| Motor | 12N14P gimbal BLDC (GBM2804-class), pole pairs p = 7, R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Commutation encoder | 14-bit magnetic encoder (AS5048A / MT6701) on each axis |
| MCU | STM32G4/H7 class with FPU, center-aligned PWM, synchronous ADC sampling on inline or low-side shunts |
| Bus voltage | 12–16 V |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted point-symmetric about the plate centroid |

Loop rates:

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ≈ 1.5–2 kHz |
| Velocity (gyro-based) | 4 kHz | ≈ 80–150 Hz |
| Angle (attitude) | 1 kHz | ≈ 15–30 Hz |
| IMU output data rate (ODR) | 8 kHz, decimated to 4 kHz after filtering | — |

Rule of thumb: keep each inner loop at least 5× (ideally 10×) faster than the loop wrapped around it.
