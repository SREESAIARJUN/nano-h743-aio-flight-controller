## 0. Architecture Clarification and Assumptions

An STM32H743 does not commutate the motors directly in any practical design. The standard and recommended split is:

| Block | Device | Function |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100) running ArduPilot | Attitude control, DShot600 master, eRPM telemetry consumer (harmonic notch) |
| ESC ×4 | One MCU per channel: AT32F421K8U7 or STM32G071GBU6, running AM32 | 6-step commutation, 48 kHz complementary PWM, GCR eRPM reply |
| Gate drive ×4 | 3-phase half-bridge driver, e.g. FD6288Q class (bootstrap, ~1.2 A source / 1.5 A sink) **[VERIFY]** | |
| Power stage | 24× N-MOSFET, 40 V, PQFN 3.3×3.3 | |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Six-step commutation with synchronous rectification

In each 60° electrical sector, phase A is PWM'd high and phase B is held low. Two current paths alternate:

- **On-state (duty D):** I → HS_A → motor → LS_B. Path resistance is 2R.
- **Freewheel (1−D), synchronous:** I → LS_A (reverse) → motor → LS_B. Path resistance is 2R.

The conduction loss is therefore independent of duty cycle:

$$P_{cond,ch} = I^2 \cdot 2R_{ds}(T_j) \quad\text{where}\quad R_{ds}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

**Per-FET average.** The loss is distributed across 6 FETs over a full electrical cycle:

$$\bar P_{FET} = \frac{2I^2R}{6} = \frac{I^2R}{3}$$
