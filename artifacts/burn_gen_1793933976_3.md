# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #11 specification, so the design below rests on the assumptions in this table. Every one of them is a named constant in the code, so you can change them in one place.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class Cortex-M4F/M7, FPU, 170+ MHz |
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) per axis |
| IMUs | 2× ICM-42688-P on the camera plate, mounted point-symmetric about the payload CG |
| Kinematic chain | Base → Yaw → Roll → Pitch → Camera |

**Loop rates (rate-monotonic nesting):**

| Loop | Rate | Bandwidth target |

| Current (FOC) | 25 kHz | ≈ 1.5–2 kHz |
