**Design assumptions:** No hardware spec was provided for Job #60, so the design uses the values below. Every parameter is a named constant in the code, so you can change any of them.

| Item | Assumed value |
|---|---|

## 1. Loop Architecture

```
            1 kHz                4 kHz                          20 kHz
 θ_ref ─►[Angle P + FF]─► ω_ref ─►[Rate PI + AW]─► i_q* ─┬─►[Current PI (d/q)]─► SVPWM ─► Motor
  ▲                         ▲                    i_cog ─┘         ▲
  │                         │                     ▲               │ i_abc, θ_e (encoder)
  │                         │      Anti-cogging (θ_m) ────────────┘
  │                         │
  └── Mahony attitude ◄── ω_cam (dual-IMU fused, notch + LPF) ◄── 2× ICM-42688-P @ 4 kHz
```

- **Commutation and the current loop** use the joint encoder.
- **Stabilization** (the angle and rate loops) uses the camera-plate IMU. This rejects base motion directly.
- **Encoder velocity** comes from a PLL observer. It is used for cogging learning and as a fallback rate source.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms

The electrical angle is θ_e = p·(θ_m − θ_offset).

**Clarke transform** (amplitude-invariant):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)\quad(\text{or } \tfrac{1}{\sqrt3}(i_b-i_c) \text{ with 3 shunts})$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$
