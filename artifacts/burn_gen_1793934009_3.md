# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #61)

I don't have the Job #61 specification, so the design rests on the stated assumptions below. Every gain is derived from motor and plant parameters, so swapping in your real values re-tunes the whole design.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class: FPU, 3× ADC, CORDIC optional |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit magnetic encoder (MT6701 / AS5048A) on each axis |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz |
| Kinematic chain | Yaw (outer, about z) → Roll (about x) → Pitch (inner, about y) |

The loop-rate hierarchy is chosen so that each loop's bandwidth is at least 4–10× below the loop inside it:

```
              1 kHz                  4 kHz                    20 kHz
 q_ref ──► [Angle P + ω_ff] ──► [Velocity PI] ──►(+)──► [Current PI + decoupling] ──► SVPWM ──► Motor
              ▲                    ▲               ▲             ▲
        IMU attitude          gyro rate /     anti-cogging    ia, ib (ADC)
        (Mahony, J⁻¹)         PLL velocity    feedforward     θe (encoder)
```
