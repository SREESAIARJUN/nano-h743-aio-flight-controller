# FOC Control, Anti-Cogging, and Dual-IMU Fusion for a 3-Axis Gimbal (Job #34)

I don't have the Job #34 spec sheet, so the design below rests on explicit assumptions. Every value marked **[A]** is a parameter you can replace.

## 0. Assumptions and Loop Architecture

| Item | Value |
|---|---|
| MCU | STM32G474 class, 170 MHz, FPU, center-aligned PWM **[A]** |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH **[A]** |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) **[A]** |
| IMUs | 2× ICM-42688-P on the camera plate, SPI + DMA, ODR 8 kHz **[A]** |
| Gimbal order | Yaw (z, base) → Roll (x) → Pitch (y, camera) **[A]** |

**Rate hierarchy (each loop has ≥5× the bandwidth of the loop around it):**

```
 20 kHz  PWM ISR   : encoder → Clarke/Park → current PI → SVPWM  (+ cogging FF injected into i_q*)
  8 kHz  IMU DMA   : dual ICM-42688-P → calibrate → consistency fusion → notch bank → LPF
  4 kHz  Rate loop : camera gyro → J⁻¹ → joint-rate PI (per axis) → i_q*
  1 kHz  Att. loop : Mahony AHRS → quaternion error → ω_cmd → joint rates
```
