# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #52 specification, so this design states its assumptions explicitly. Every parameter that depends on your hardware is a named constant you can change.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12 slots / 14 poles (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 2 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM at 20 kHz |
| IMUs | 2 × ICM-42688-P on the camera stage, separate SPI buses, ODR 8 kHz |
| Axis order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
