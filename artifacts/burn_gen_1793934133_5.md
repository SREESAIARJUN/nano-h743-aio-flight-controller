## 1. Control Architecture

```
            ┌──────────────── 1 kHz ────────────────┐ ┌──── 4 kHz ─────┐ ┌──────── 20 kHz ─────────┐
 q_ref ──►  Attitude P (SO(3) error) ──► ω_ref ──(+)─► Velocity PI ──(+)──► i_q* ─► Current PI (d,q) ─► SVPWM
             + rate FF from trajectory     ▲   gyro   ▲  τ_ff/Kt      ▲  cogging FF          ▲ i_abc, θ_e
             J⁻¹(θ) joint mapping          │ (filtered,│ friction FF   │  (encoder θ_m)       │
                                           │  fused)   │               │                      │
                     Dual ICM-42688-P ─► Notch/LPF bank ─► Fusion ─► Mahony attitude
```

Key design decisions:

- **Inertial rate feedback.** The velocity loop is closed on fused, filtered gyro rate rather than a differentiated encoder signal. Stabilization requires inertial rate; the encoder supplies commutation angle and joint-limit information.
- **Cogging compensation in the current reference.** It is a function of the *mechanical* rotor angle and is added to `i_q*`, so it bypasses velocity-loop bandwidth limits.
- **Two-stage vibration rejection.**
  1. Hardware: on-chip anti-aliasing filter (AAF) plus mechanical damping.
  2. Software: dynamic notches tracking motor electrical harmonics, plus fixed notches at the measured frame resonance and a 2nd-order low-pass filter.

## 2. Field-Oriented Current Loop (20 kHz)

### 2.1 Transforms

Clarke transform (amplitude-invariant, balanced phases with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant model (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque:

$$\tau_e = \tfrac{3}{2}\,p\,\lambda_m\, i_q = K_t\, i_q$$

### 2.3 PI design by pole-zero cancellation

Choose the PI zero to cancel the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_c:

$$C_i(s)=K_p+\frac{K_i}{s},\quad K_p = L\,\omega_c,\quad K_i = R\,\omega_c$$

Choose ω_c ≤ 2π·f_pwm/20. With f_pwm = 20 kHz, ω_c = 2π·1000 rad/s.

Decoupling and back-EMF feedforward:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q,\qquad v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e L i_d + \hat\omega_e\hat\lambda_m$$

### 2.4 Voltage limiting and anti-windup

Limit the voltage vector to the linear SVPWM region, |v| ≤ V_dc/√3. Use back-calculation anti-windup with gain K_aw = 1/K_p:

$$x_I[k+1] = x_I[k] + T_s\left(K_i\,e[k] + K_{aw}\,(u_{sat}[k]-u[k])\right)$$

### 2.5 SVPWM (min-max zero-sequence injection)

$$v_{a,b,c} = \text{inv-Clarke}(\text{inv-Park}(v_d,v_q)),\quad v_0 = -\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right)$$

$$\text{duty}_x = \tfrac12 + \frac{v_x+v_0}{V_{dc}}$$

### 2.6 Angle/speed tracking PLL (encoder smoothing)

A type-II PLL tracks the encoder angle, with angle error wrapped to (−π, π]:

$$e_\theta = \mathrm{wrap}(\theta_{enc}-\hat\theta),\quad \hat\omega \mathrel{+}= T_s K_{i,pll}\, e_\theta,\quad \hat\theta \mathrel{+}= T_s(\hat\omega + K_{p,pll}\, e_\theta)$$

Gains for natural frequency ω_n and damping ζ = 1:

$$K_{p,pll}=2\zeta\omega_n,\qquad K_{i,pll}=\omega_n^2$$

Use ω̂ for decoupling and to set the dynamic notch frequencies (Section 5).
