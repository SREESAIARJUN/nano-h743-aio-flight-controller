# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion Design

This design covers the motor control loop, cascaded PID, anti-cogging feedforward and dual ICM-42688-P vibration rejection for a 3-axis gimbal.

---

## 0. Assumptions

I don't have the Job #32 specification, so the design rests on the baseline below. Replace these values with the real hardware parameters. Every gain in the design is computed from these parameters, not hard-coded.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class: Cortex-M4F/M7, single-precision FPU, CORDIC optional |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic sensor (AS5048A or MT6701), one per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, gyro ODR 8 kHz, accel ODR 1 kHz |
| Bus voltage | 12–16 V |

**Loop rates.** Each loop runs about 4–5× faster than the loop outside it, which preserves bandwidth separation:

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | 1.5–3 kHz |
| Velocity | 4 kHz | 150–300 Hz |
| Attitude/angle | 1 kHz | 30–60 Hz |
| IMU filtering | 8 kHz | Decimated ×2 to 4 kHz for the velocity loop |

**Architecture.** The IMU (camera attitude) drives the outer loop. The encoder is used for commutation, cogging compensation and as a velocity fallback.

```
 setpoint q_ref ──► [Attitude ctrl 1 kHz] ──ω_ref(body)──► [Body→Joint J⁻¹] ──ω̇_ref per joint──►
   [Velocity PI 4 kHz] ──τ_ref──► (+ cogging FF + inertia FF) ──i_q_ref──► [Current PI + FOC 20 kHz] ──► PWM
        ▲ ω_meas (fused gyro, projected on joint axis)               ▲ θ_e (encoder)
 [ICM-42688-P ×2 → AAF → notch bank → LPF → inverse-variance fusion → Mahony AHRS]
```

## 1. FOC Inner Current Loop

### 1.1 Electrical angle and transforms

Electrical angle:

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

Clarke transform (amplitude-invariant). Two-shunt sensing uses $i_a + i_b + i_c = 0$:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant model (SPM motor, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q, \qquad v_q = R i_q + L\dot i_q + \omega_e(L i_d + \lambda_m)$$

Torque:

$$\tau_e = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

### 1.3 Current PI with decoupling

Use pole-zero cancellation of the RL plant with target bandwidth $\omega_c$:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\;\Rightarrow\;\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Command voltages with feedforward decoupling:

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e (L i_d + \lambda_m)$$
