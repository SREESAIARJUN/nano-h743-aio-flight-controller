## 1. Conduction Loss Model

### 1.1 Current path topology (6-step, synchronous)

Consider a commutation sector with phase A as the PWM'd high side and phase B held low:

- **PWM ON (duty D):** current flows Q_AH → motor → Q_BL.
- **PWM OFF (1−D), synchronous freewheel:** current flows Q_AL → motor → Q_BL.

In both intervals, **exactly two MOSFETs** carry the phase current. This gives:

$$P_{cond,ch} = I_{rms}^2\,[D\,R_{AH} + (1-D)\,R_{AL}] + I_{rms}^2\,R_{BL} \;\xrightarrow{R_{AH}=R_{AL}=R_{BL}}\; 2\,I_{rms}^2\,R_{DS}(T_j)$$

So conduction loss is **independent of duty** with synchronous rectification. This holds only if dead time is short relative to the period; the dead-time term is handled in §2.4.

### 1.2 Temperature dependence of R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha\,(T_j - 25)], \quad \alpha = \frac{1.5-1}{100} = 0.005\ \text{K}^{-1}$$

### 1.3 Ripple contribution
