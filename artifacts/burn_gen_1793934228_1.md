## 0. System Architecture

```
 6S LiPo (25.2 V max)
   │
   ├─► 4-in-1 ESC (20×20 mm, 8L 2oz)
   │     ├─ 4× ESC MCU (STM32G071 / AT32F421, AM32 firmware)  ← one per motor
   │     ├─ 4× 3-phase gate driver (FD6288Q class)
   │     ├─ 24× N-MOSFET (40 V, PDFN3.3×3.3)
   │     └─ 4× DC-link shunt + amp (current telemetry)
   │
   └─► FC: STM32H743 @ 480 MHz (ArduPilot)
         └─ 4× bidirectional DShot600 lines → ESC MCUs (eRPM telemetry back)
```

The H743 does **not** commutate the motors. A single H7 cannot run four sensorless 6-step loops at 48 kHz while also running ArduPilot. The H743's job is DShot generation and capture. Each ESC MCU generates the 48 kHz PWM.
