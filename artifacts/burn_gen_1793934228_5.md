# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #41): Power-Stage, Thermal and DShot Architecture

This document covers the power stage, thermal model, switching model, and DMA/timer allocation for an ArduPilot STM32H743 board with an integrated 4-in-1 ESC. The model is parametric. Every number traces back to a stated assumption, so you can substitute your real MOSFET datasheet values and re-run it.
