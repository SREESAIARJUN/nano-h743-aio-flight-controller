## 0. Architecture Clarification

In a 4-in-1 stack, the **STM32H743 does not drive the power stage**. Each ESC channel has its own motor MCU, which runs commutation and the 48 kHz PWM. Typical choices are an AT32F421 running AM32, or an EFM8BB21/BB51 running Bluejay.

```
6S LiPo ─┬─► 4-in-1 ESC: 4× [ESC MCU → 3-ph gate driver → 6× N-MOSFET] → Motors 1-4
         │        ▲ DShot600 bidirectional (1 wire/motor, half-duplex)
         └─► BEC ─► STM32H743 FC (ArduPilot): TIMx → DMA → ESC signal pads
```

The domains therefore split as follows:
- **Loss and thermal analysis (§1–3)** belongs to the ESC board.
- **DShot timing and DMA (§4)** belongs to the H743.
