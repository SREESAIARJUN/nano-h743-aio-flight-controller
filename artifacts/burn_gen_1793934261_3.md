# STM32H743 AIO Nano FC with 4-in-1 ESC: Design Model (Job #50)

## 0. Architecture Correction

The H743 does not drive the MOSFETs. A working AIO uses this chain:

```
STM32H743 (ArduPilot) ──DShot600 bidir──► 4× ESC MCU (AT32F421 / STM32G071, AM32 or BLHeli_32)
                                              └─► 4× 3-phase gate driver ─► 24× N-MOSFET ─► motors
```

This has two consequences for the model:
- **The 48 kHz PWM** is generated by the ESC MCUs (AM32 `PWM frequency` setting), not by ArduPilot.
- **The H743's job** is DShot600 output and eRPM telemetry capture via timer and DMA (Section 4).

**Key finding:** on a 20×20 mm board, 80 A per channel is a burst rating of roughly 1–5 s, not a continuous one. The derivation below shows why. Sustained capability is about 20–25 A per channel.

## 2. Loss Model (per ESC channel)

The model assumes 6-step commutation with complementary (synchronous) PWM. At any instant, current flows through one high-side and one low-side path. On the PWM'd leg, conduction alternates between HS and LS, so the path is always two R_DS(on) in series.

**2.1 Conduction loss**
P_cond = 2 · I² · R_hot = 2 · 6400 · 0.0018 = **23.04 W**

**2.2 Hard-switching loss** (one switching leg)
P_sw = ½ · V_bus · I · (t_r + t_f) · f_sw = 0.5 · 25.2 · 80 · 30e-9 · 48e3 = **1.45 W**

**2.3 Dead-time body-diode conduction**
P_dt = V_f · I · 2·t_dt · f_sw = 0.8 · 80 · 400e-9 · 48e3 = **1.23 W**

**2.4 Capacitive and reverse-recovery loss**
P_oss + P_rr = (Q_oss + Q_rr) · V_bus · f_sw = 60e-9 · 25.2 · 48e3 = **0.07 W**

**2.5 Gate drive** (6 FETs, only the PWM'd pair switches at f_sw)
P_g ≈ 2 · Q_g · V_gs · f_sw = 2 · 40e-9 · 10 · 48e3 = **0.04 W**

**2.6 Copper and shunt loss**
P_cu = I² · (R_cu + R_sh) = 6400 · 0.0006 = **3.84 W**
