# Gimbal FOC Control Loop and Dual-IMU Sensor Fusion: Design Specification

## 0. Assumptions

I don't have the original specification for Job #5, so this design rests on the assumptions below. Each one is isolated as a constant in the code, so you can change any of them without restructuring.

| Item | Assumption |
|---|---|
| MCU | STM32G474-class Cortex-M4F with FPU and CORDIC (the code is portable C++17) |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, inline low-side current sensing |
| Rotor encoder | 14-bit absolute magnetic encoder (AS5048A or MT6701) on each axis |
| IMUs | 2× ICM-42688-P on the camera payload, mounted mirrored (rotated 180° about Z), each on its own SPI bus |
| Loop rates | Current/FOC 20 kHz, velocity 4 kHz, angle/attitude 1 kHz, IMU ODR 8 kHz |
| Kinematics | Yaw (outer) → Roll → Pitch (inner) |

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Here θ_off is identified at startup by applying V_d alone and reading the encoder once the rotor has settled.

During the PWM-to-sample delay T_d ≈ 1.5 T_s, the rotor keeps moving. Compensate for this:

$$\theta_e^{\text{comp}} = \theta_e + p\,\hat\omega_m T_d$$

### 1.2 Clarke and Park transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant model and decoupled PI control

The motor's dq-frame model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Each axis uses a PI controller plus cross-coupling feedforward:

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e \lambda_m$$

**Pole-zero cancellation tuning.** Choose the current bandwidth ω_c ≤ 2π·f_s/10 (≈ 2π·2 kHz). Then set:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

This cancels the plant pole and gives a closed-loop transfer function of approximately ω_c/(s + ω_c).

### 1.4 Voltage limiting

Limit the voltage vector to the inscribed circle of the SVPWM hexagon:

$$|v|_{\max} = V_{bus}/\sqrt3$$

The q-axis gets priority:

$$v_d \leftarrow \text{sat}(v_d, |v|_{\max}),\qquad v_q \leftarrow \text{sat}\!\left(v_q, \sqrt{|v|_{\max}^2 - v_d^2}\right)$$

### 1.5 SVPWM via min-max injection

This is equivalent to conventional sector-based SVPWM. Compute the inverse Clarke transform:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2} v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2} v_\beta$$

Then inject the common-mode offset and convert to duty cycles:

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Mechanical plant

$$J\dot\omega = K_t\, i_q - B\omega - \tau_{\text{cog}}(\theta) - \tau_{\text{dist}},\qquad K_t = \tfrac32 p\lambda_m$$

### 2.2 Velocity loop (4 kHz, PI with feedforward)

The error uses setpoint weighting β ∈ [0, 1] on the proportional term:

$$e_\omega = \omega^* - \omega$$
