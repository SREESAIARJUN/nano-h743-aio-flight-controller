## 1. Control Architecture

```
            ┌─────────── 1 kHz ───────────┐ ┌──── 4 kHz ────┐ ┌──────── 20 kHz ────────┐
q_ref ─►(Attitude P + rate FF)─► J⁻¹ ─► ω_ref ─►(Velocity PI)─► τ* ─► ÷Kt ─► iq* ─►(+ iq_cog)─►(Current PI d/q + decoupling)─► SVPWM
             ▲ q̂ (fused attitude)              ▲ ω̂ (gyro, notched)                ▲ id, iq (Clarke/Park, θe from encoder)
       Dual ICM-42688-P ─► AAF ─► dynamic notch bank ─► fusion/voting ─► Mahony AHRS
```

The loops divide the work as follows:

- **Encoder:** commutation (θe), cogging-table phase, and joint kinematics.
- **Gyro:** the velocity loop, which stabilizes in inertial space.
- **Fused quaternion:** the attitude loop.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms

With balanced currents (i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix},\qquad \theta_e = p\,(\theta_m - \theta_{off})$$

The inverse Park transform gives v_α, v_β from v_d, v_q. SVPWM then uses the min-max zero-sequence injection:

$$v_{x}' = v_x - \tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\quad d_x = \tfrac12 + \frac{v_x'}{V_{bus}}$$

This yields a linear range up to |v| = V_bus/√3.

### 2.2 Plant model and PI design

The dq voltage equations are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

$$\tau = \tfrac32 p \lambda_m i_q = K_t\, i_q$$

**Decoupling.** Add the cross-coupling and back-EMF terms as feedforward:

$$v_d = u_d - \omega_e L i_q,\qquad v_q = u_q + \omega_e(L i_d+\lambda_m)$$
