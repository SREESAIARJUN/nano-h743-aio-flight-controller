# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #49, so the design below rests on the assumptions in §0. Every motor, inertia and mounting parameter is collected in one `config` namespace so you can substitute your real values.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L_d ≈ L_q = 2.2 mH, λ = 4.5 mWb |
| Commutation sensor | 14-bit absolute magnetic encoder on each joint (e.g. AS5048A / MT6701) |
| Bus voltage | V_dc = 12 V, 3-phase inverter, center-aligned PWM |
| IMU A (payload) | ICM-42688-P on the camera plate: attitude feedback |
| IMU B (base) | ICM-42688-P on the handle/airframe: disturbance feedforward and vibration reference |
| Gimbal kinematics | Yaw → Roll → Pitch (outer to inner) |
| MCU | Cortex-M4F/M7 (single-precision FPU), e.g. STM32
