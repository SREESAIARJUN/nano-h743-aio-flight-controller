# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion Design

I don't have the Job #53 specification, so the plant parameters below are **assumptions** for a typical gimbal motor (GM4108-class, 24N22P) with a 14-bit magnetic encoder. Every value is a named constant in the code, so you can substitute your measured values.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Pole pairs | p | 11 |
| Slots | N_s | 24 |
| Phase resistance (line-to-neutral) | R | 5.0 Ω |
| Phase inductance (d≈q) | L | 2.0 mH |
| Torque constant | K_t | 0.10 N·m/A |
| Axis inertia, motor plus payload | J | 2.0e-4 kg·m² |
| Bus voltage | V_dc | 16.8 V (4S) |
| Current loop / PWM | f_i | 20 kHz |
| Velocity loop | f_v | 4 kHz |
| Angle loop | f_θ | 1 kHz |
| IMU ODR (both ICM-42688-P) | f_imu | 8 kHz |
