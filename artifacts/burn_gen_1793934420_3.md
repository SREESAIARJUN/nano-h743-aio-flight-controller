# 3-Axis Gimbal: FOC Control Loops, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have Job #42's specification sheet, so the design below rests on the assumptions in this table. Every one of them is a named constant in the code. Change the constants if your hardware differs; the equations do not change.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| Current sense | 2- or 3-shunt, ADC triggered at the PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR |
| Kinematics | Outer yaw → middle roll → inner pitch |
