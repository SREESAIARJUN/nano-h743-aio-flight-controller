# Job #41: STM32H743 Nano FC + 4-in-1 ESC System Model

This covers thermal, switching, and DShot/DMA design for 80 A burst operation.

## 0. Architecture Clarification and Assumptions

ArduPilot does not perform motor commutation, so the STM32H743 cannot be the commutation controller. The realistic, flight-proven partition is:

| Block | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIH6 (or VIT6), 480 MHz | ArduPilot, generates 4× bidirectional DShot600 |
| ESC controllers (×4) | AT32F421K8U7 (or STM32G071) | AM32 / BLHeli_32, 48 kHz PWM, eRPM telemetry |
| Gate drivers (×4) | FD6288Q (3-phase, bootstrap) | 6 gates per channel |
| Power stage | 24× N-MOSFET, 40 V, PDFN3.3×3.3 | 6 per motor |

No MOSFET part number was specified, so the model is parameterized. The worked numbers use these placeholder values. Replace them with datasheet values for your selected FET.

## 1. Conduction Loss Model

### 1.1 Six-Step (Trapezoidal) Current Path

In any 60° commutation sector, current flows through exactly two FETs in series:
- the PWM leg (either the high side, or its complementary low side under synchronous rectification), and
- the low side of the return leg, which is on for the whole sector.

So the instantaneous conduction loss per channel is:

$$P_{cond} = 2\, I_{rms}^2\, R_{DS(on)}(T_J)$$

### 1.2 Temperature Dependence

$$R_{DS(on)}(T_J) = R_{DS(on),25}\,[1 + \alpha (T_J - 25)]$$

### 1.3 Ripple Correction

With peak-to-peak inductor ripple ΔI:

$$I_{rms} = I_{DC}\sqrt{1 + \frac{1}{12}\left(\frac{\Delta I}{I_{DC}}\right)^2}$$

Motor inductance is typically 10–30 µH. At 48 kHz, ripple is usually below 15 %, which makes the correction below 0.2 %. It is ignored below.

### 1.4 Worked Value (T_J = 100 °C)

$$R_{DS(on)}(100) = 1.2 \times (1 + 0.0045 \times 75) = 1.605\ \text{m}\Omega$$

$$P_{cond} = 2 \times 80^2 \times 1.605\times10^{-3} = \mathbf{20.5\ W\ per\ channel}$$

### 1.5 Thermal Runaway Check

Loss rises with temperature, which raises temperature further. The loop gain is:

$$G = \frac{\partial P}{\partial T}\,R_\theta = 2 I^2 R_{25}\,\alpha\,R_\theta$$

Stability requires G < 1. At 80 A with R_θ = 5.6 K/W (Section 4):

$$G = 2 \times 6400 \times 1.2\times10^{-3} \times 0.0045 \times 5.6 = 0.39$$

The loop is stable, but the steady-state temperature is amplified by 1/(1 − G) = 1.63×.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches. Each loss term is listed below.

| Term | Expression | Value |
|---|---|---|
| V·I overlap | ½·V·I·(t_r + t_f)·f_sw | ½·25.2·80·30 ns·48 k = **1.452 W** |
| Reverse recovery | Q_rr·V·f_sw | 30 n·25.2·48 k = **0.036 W** |
| Output capacitance | Q_oss·V·f_sw | 38 n·25.2·48 k = **0.046 W** |
| Dead-time diode conduction | V_SD·I·2·t_dt·f_sw | 0.8·80·200 ns·48 k = **0.614 W** |
| Gate drive (2 FETs) | 2·Q_g·V_drv·f_sw | **0.048 W** (dissipated mostly in driver and R_g) |
| **Total switching** | | **≈ 2.20 W per channel** |

### Design Levers

**Dead time.** Dead-time loss is about 28 % of switching loss.
- With AM32 dead time 100 → 50 ns, you save 0.3 W per channel.
- Verify shoot-through margin against the FD6288 propagation mismatch (±~20 ns).

**Frequency.** Switching loss scales linearly with f_sw.
- 24 kHz halves it (saves ~1.1 W per channel).
- The cost is audible noise and higher current ripple.

**Gate resistance.** Faster edges cut V·I loss but worsen ringing and EMI.
- Keep the half-bridge hot-loop inductance below 1 nH.
- Placing a 100 nF 0402 capacitor directly across each half-bridge achieves this.
