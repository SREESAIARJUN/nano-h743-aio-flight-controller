# STM32H743 Nano FC + 4-in-1 ESC (Job #46): Power-Stage Loss Model, Thermal Budget, and Bidirectional DShot600 DMA Allocation

## 0. Scope and Assumptions

**Architecture.** An STM32H743 does not commutate the motors directly in any production ArduPilot design. ArduPilot has no ESC firmware, and one H7 cannot run four sensorless FOC/6-step loops alongside the flight stack. The architecture is therefore:

```
[STM32H743 FC, ArduPilot] --4x bidir DShot600--> [4-in-1 ESC: 4x MCU (AT32F421 / STM32G071, AM32 or BLHeli_32)]
                                                       └─ each MCU -> 3-phase gate driver -> 6x N-MOSFET
```

The ESC MCUs run the 48 kHz PWM. The H743 owns DShot generation, eRPM telemetry capture, current/voltage sensing, and the harmonic notch.

**Parameters.** All numbers below are assumptions. Replace them with your actual BOM datasheet values (max R_DS(on), Q_gd, Q_rr, Z_th). The method holds regardless; the results scale accordingly.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent On-Resistance

$$R_{DS}(T_j) = R_{DS25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R_DS = 1.0 × (1 + 0.005 × 100) = **1.50 mΩ**.

### 1.2 Six-Step Commutation with Synchronous Rectification

At any instant, two phases carry I_ph:
- During the PWM on-time: high-side FET of phase A and low-side FET of phase B.
- During the off-time (complementary PWM): low-side FET of A, which is the synchronous rectifier, and low-side FET of B.

Two channel resistances are therefore always in series, independent of duty cycle:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{DS}(T_j) + I_{ph}^2 R_{Cu}$$

$$P_{cond,ch} = 2(80)^2(1.5\text{ m}\Omega) + (80)^2(0.25\text{ m}\Omega) = 19.2 + 1.6 = \mathbf{20.8\ W}$$

### 1.3 Per-FET Distribution

Each FET conducts about 1/3 of the electrical period. The electrical period at burst is roughly 0.3–1 ms, much shorter than the FET thermal time constant, so the per-FET loss can be averaged:

$$\bar P_{cond,FET} = \frac{2 I^2 R_{DS}}{6} = 3.2\ \text{W}$$

The instantaneous peak is 9.6 W. Check that this stays inside the Z_th(10 µs–1 ms) curve; at 80 A it does for 3×3 parts.
