# STM32H743 Nano FC + 4-in-1 80A ESC: System Architecture Model (Job #38)

## 0. Scope and Assumptions

I don't have the Job #38 component selections, so every numeric result below comes from **reference parameters** (Table 0). The equations are parametric. Replace the values with your actual MOSFET datasheet values and re-run them.

**Architecture assumed** (industry standard for this class):

- The **H743 runs ArduPilot**. It generates bi-directional DShot600 to **four ESC MCUs** (AT32F421 / STM32G071 class, running AM32 or BLHeli_32).
- **The ESC MCUs generate the 48 kHz PWM.** The H743 does not drive gates.
- Commutation is 6-step trapezoidal with complementary (synchronous-rectified) PWM.
- The ESC uses an FD6288Q-class 3-phase gate driver and 6 × N-MOSFETs per channel.
- The power stage is 6S (25.2 V maximum).

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C: R_ds = 1.0 × (1 + 0.0045 × 85) = **1.38 mΩ**.

### 1.2 Current path in 6-step commutation with synchronous rectification

In any commutation sector, current flows through **exactly two conducting MOSFET positions in series**:

1. The PWM leg, which alternates between its high-side FET (during D) and its synchronous low-side FET (during 1−D). There is always one channel conducting, apart from the dead time.
2. The non-PWM leg's low-side FET, which is on continuously.

So the conduction loss per ESC channel is:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{ds}(T_j)\cdot\left(1 - \frac{2t_{dt}f_{sw}}{1}\right)$$
