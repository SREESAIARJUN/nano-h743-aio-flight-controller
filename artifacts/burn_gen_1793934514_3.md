## 2. Conduction Loss Model

### 2.1 Topology

The model assumes trapezoidal six-step commutation with synchronous rectification. At any instant, two phases conduct:

- **PWM leg:** the high-side FET conducts for duty D. Its complementary low-side FET conducts for (1−D), excluding dead time.
- **Return leg:** the low-side FET conducts continuously for the 120° sector.

Because the PWM leg's HS and LS FETs carry the current in alternation, the series resistance seen by the phase current at any instant is always ≈ 2·R_DS(on). Per motor:

$$P_{cond,motor} = I_{ph,rms}^2 \cdot 2\,R_{DS}(T_j)$$

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

### 2.2 Per-FET Distribution

Each FET is active for 1/3 of the electrical cycle:

- **Return-leg LS FET:** P = I²·R·(1/3)
- **PWM-leg HS FET:** P = I²·R·(D/3)
- **PWM-leg LS FET:** P = I²·R·((1−D)/3)

At full throttle (D → 1), losses concentrate in the HS FETs. Worst-case single-FET average loss is therefore ≈ I²·R/3.

### 2.3 Numbers at 80 A, T_j = 100 °C

- R_DS(100 °C) = 1.5 mΩ × (1 + 0.0065 × 75) = **2.23 mΩ**
- P_cond,motor = 80² × 2 × 2.23 mΩ = **28.6 W**
- Worst single FET = 6400 × 2.23 mΩ / 3 = **4.76 W**

### 2.4 Thermal Runaway Check

Conduction loss rises with temperature, so the loop is stable only if:

$$\frac{\partial P}{\partial T_j}\cdot R_{\theta} < 1 \;\;\Rightarrow\;\; I^2 \cdot 2 R_{25}\,\alpha \cdot R_{\theta,ja} < 1$$

At 80 A with R_θ = 7 K/W (see §4): 6400 × 3e-3 × 0.0065 × 7 = **0.87**.

This is stable, but marginal. Steady-state 80 A is therefore not only too hot, it is also near runaway. This confirms that 80 A must be a burst rating only.

## 3. Switching Loss Model at 48 kHz

These losses apply only to the PWM leg, which has one switching pair per motor at a time.

| Term | Formula | Value at 25.2 V, 80 A |
|---|---|---|
| V-I overlap (hard switching) | ½·V·I·(t_r+t_f)·f_sw | 0.5·25.2·80·40 ns·48 k = **1.94 W** |
| Body-diode conduction in dead time | V_F·I·2t_dt·f_sw | 0.8·80·100 ns·48 k = **0.31 W** |
| Reverse recovery | Q_rr·V·f_sw | 40 nC·25.2·48 k = **0.05 W** |
| Output capacitance | Q_oss·V·f_sw (≈ ½ in FET, ½ in driver path) | **0.04 W** |
| Gate drive (driver + R_g, ×2 FETs) | 2·Q_g·V_GS·f_sw | **0.04 W** |
| **Total P_sw per motor** | | **≈ 2.4 W** |
