## 0. Scope, Architecture & Governing Assumptions

### 0.1 Architecture clarification

The STM32H743 does **not** commutate the motors. The system is a two-board stack:

| Board | Function | Key silicon |
|---|---|---|
| **FC (20×20 mm, M3)** | ArduPilot, sensor fusion, DShot600 master, bidirectional telemetry RX | STM32H743VIT6 (LQFP100) |
| **ESC (30.5×30.5 mm, M3 / 20×20 adapter)** | 4× independent 3-phase bridges, 48 kHz complementary PWM | 4× AT32F421K8U7 (AM32) or 4× STM32G071 (BLHeli_32/AM32), 4× FD6288Q gate drivers, 24× N-MOSFET |

The 48 kHz PWM frequency is an **ESC firmware parameter** (AM32 `PWM_FREQ`, BLHeli_32 "PWM Frequency"). The H743 only sets the DShot command rate and loop rate.

> **Form-factor reality check:** 80 A per channel on a 30×30 board is a *burst* rating of a few seconds, not a continuous rating. Section 3 derives this limit quantitatively. An 80 A rating on a true 20×20 ESC is not physically defensible with current 3×3 mm MOSFET technology.

## 1. Conduction Loss Model

### 1.1 Commutation topology

Six-step trapezoidal commutation with complementary (synchronous) PWM is used. In any 60° sector:

- **Leg A (PWM leg):** HS_A conducts for D·T_sw. LS_A conducts synchronously for (1−D)·T_sw, minus dead time.
- **Leg B (return leg):** LS_B is continuously ON.
- **Leg C:** floating, used for BEMF zero-crossing.

Phase current I is continuous (motor inductance ≫ ripple criterion), so it can be treated as DC within a PWM period.

### 1.2 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha_R (T_j - 25)]$$

At T_j = 115 °C: R_ds = 1.0 × (1 + 0.0055 × 90) = **1.50 mΩ**.
