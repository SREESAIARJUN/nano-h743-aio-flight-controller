## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance
$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)],\quad \alpha \approx 0.006\ /\text{K}$$

At T_j = 125 °C: R_ds = 1.5 mΩ × 1.6 = **2.4 mΩ**.

### 1.2 Current paths in trapezoidal synchronous drive
During each 60° commutation sector, two legs conduct:
- **PWM leg:** current alternates between the high-side (HS) switch for duty D and the low-side (LS) synchronous rectifier for (1−D). The leg always carries I.
- **Return leg:** the LS switch is fully on and carries I.

$$P_{cond,ESC} = I_{rms}^2\,R_{ds}\,[D + (1-D)] + I_{rms}^2 R_{ds} = 2\,I_{rms}^2 R_{ds}$$

Include ripple with
$$I_{rms}^2 = I^2 + \Delta I_{pp}^2/12,\qquad \Delta I_{pp} = \frac{V_{bus}D(1-D)}{L_{ph} f_{sw}}$$

Example: L_ph = 15 µH and D = 0.5 give ΔI_pp = 8.75 A. The ripple term adds 6.4 A², which is under 0.1 %. It is negligible here.

### 1.3 Conduction loss at 80 A
$$P_{cond} = 2 \times 80^2 \times 2.4\,\text{m}\Omega = \mathbf{30.7\ W\ per\ ESC}$$

The 25 °C value is 19.2 W.

## 2. Switching and Ancillary Losses at 48 kHz

Only the PWM leg switches, so there is one hard-switched node per ESC. Values below use V = 25.2 V, I = 80 A, f = 48 kHz.

| Loss term | Equation | Value |
|---|---|---|
| V–I overlap (t_r + t_f = 40 ns) | ½·V·I·(t_r+t_f)·f | **1.94 W** |
| Body-diode reverse recovery | Q_rr·V·f | 0.06 W |
| Output capacitance (Coss) | ½·Q_oss·V·f | 0.02 W |
| Dead-time diode conduction (t_dt = 100 ns, V_f = 0.8 V) | V_f·I·2t_dt·f | **0.61 W** |
| Gate drive (2 switching FETs) | 2·Q_g·V_GS·f | 0.04 W (dissipated in the driver) |
| **Switching subtotal** | | **≈ 2.7 W** |

### 2.1 Totals

| | Per ESC | Board (×4) |
|---|---|---|
| Conduction (hot) | 30.7 W | 122.9 W |
| Switching | 2.7 W | 10.7 W |
| Shunt (0.2 mΩ, I²R) | 1.3 W | 5.1 W |
| Copper traces (est. 0.3 mΩ path) | 1.9 W | 7.7 W |
| **Total** | **≈ 36.6 W** | **≈ 146 W** |

Efficiency at 80 A × 25.2 V × 4 = 8.06 kW input is about 98.2 %. The efficiency is fine; the absolute heat is the problem on 20×20 mm.

### 2.2 Switching-frequency trade-off
$$\frac{dP_{sw}}{df} = \tfrac{1}{2}VI(t_r+t_f) + V_f I\,2t_{dt} + \dots \approx 56\ \text{mW/kHz per ESC at 80 A}$$

Moving from 48 kHz to 24 kHz saves only about 1.3 W per ESC. Conduction loss dominates by more than 10×, so **R_ds(on) and copper are the levers, not f_sw.**

### 3.2 Adiabatic burst limit
$$\frac{dT_{pcb}}{dt} = \frac{P_{tot} - (T_{pcb}-T_a)/R_{pcb-a}}{C_{th}}$$

At the start of a burst, with negligible convection: 146 / 2.4 ≈ **61 K/s**.

With prop-wash convection (R_pcb-a ≈ 4 K/W with airflow), the system is a first-order RC:
$$T_{pcb}(t) = T_a + P R\,(1-e^{-t/RC}),\quad \tau = RC \approx 9.6\ \text{s},\quad T_{ss} = T_a + 584\ \text{K}$$

The steady-state value is non-physical, which means the board will be destroyed if the burst is sustained.
