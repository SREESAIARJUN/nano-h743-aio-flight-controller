# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #53)

## 0. Design Assumptions

I don't have the Job #53 specification, so the design below uses typical values for a camera-gimbal BLDC system. Each value is a parameter in the code; change it to match your hardware.

| Parameter | Symbol | Value |
|---|---|---|
| MCU | — | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | — | Gimbal BLDC, 12N14P, so pole pairs p = 7 |
| Phase resistance / inductance | R, L | 5.5 Ω, 2.2 mH (line-to-neutral) |
| Torque constant | K_t | 0.08 N·m/A |
| Encoder | — | 14-bit absolute magnetic (AS5048A / MT6701) |
| PWM and current loop | f_pwm, f_i | 20 kHz, center-aligned |
| Velocity loop | f_v | 4 kHz |
| Angle loop | f_θ | 1 kHz |
| IMU | — | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz, gyro ±2000 dps |
| Load inertia (pitch axis) | J | 2.5·10⁻⁴ kg·m² |

**Control hierarchy.** Each loop's bandwidth is roughly 5–10× below the loop inside it:

```
θ_ref → [Angle P + FF] → ω_ref → [Velocity PI] → τ_ref (+τ_cog FF) → i_q,ref → [Current PI, dq] → SVPWM
           ↑ θ_cam (fused attitude)   ↑ ω_cam (fused gyro, joint-projected)   ↑ i_abc, θ_e (encoder)
```

Feedback sources are deliberately split:

- **Commutation** uses the encoder.
- **Stabilization** (velocity and angle loops) uses the inertial camera rate and attitude from the dual IMUs.

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle

```
θ_e = p · (θ_enc − θ_offset)  mod 2π
ω_e = p · ω_m
```

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

### 1.3 Park transform

```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

### 1.4 PMSM model in the dq frame

```
v_d = R i_d + L di_d/dt − ω_e L i_q
v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m
τ_e = (3/2) p λ_m i_q = K_t i_q       (surface PM, L_d = L_q)
```

### 1.5 Current PI with decoupling and back-EMF feedforward

The PI zero is placed to cancel the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_ci:

```
K_p,i = L · ω_ci
K_i,i = R · ω_ci          (integral gain in V/(A·s))
ω_ci  ≈ 2π · 1.5 kHz       (≤ f_pwm / 10 to keep delay-induced phase loss under ~25°)
```

The controller output with decoupling is:

```
v_d* = PI_d(i_d,ref − i_d) − ω_e L i_q
v_q* = PI_q(i_q,ref − i_q) + ω_e L i_d + ω_e λ_m
```

Voltage limiting uses a circular limit with d-axis priority:

```
|v_d| ≤ V_max,   |v_q| ≤ √(V_max² − v_d²),   V_max = V_bus / √3
```

Anti-windup uses back-calculation, with K_aw = 1 / K_p:

```
x_I[k+1] = x_I[k] + T_s ( K_i e + K_aw (v_sat − v_unsat) )
```

### 1.6 Inverse Park transform and SVPWM (min-max zero-sequence injection)

```
v_α = v_d cos θ_e − v_q sin θ_e
v_β = v_d sin θ_e + v_q cos θ_e

v_a = v_α
v_b = −½ v_α + (√3/2) v_β
v_c = −½ v_α − (√3/2) v_β

v_0 = −(max(v_a, v_b, v_c) + min(v_a, v_b, v_c)) / 2
D_x = ½ + (v_x + v_0) / V_bus          for x ∈ {a, b, c}
```

Min-max injection is mathematically equivalent to conventional SVPWM and uses the full V_bus/√3 linear range.

**Delay compensation.** Advance the angle used for the inverse Park by 1.5 PWM periods:

```
θ_e,pwm = θ_e + 1.5 · ω_e · T_pwm
```

## 2. Cascaded Velocity and Angle Control

### 2.1 Gimbal kinematics: projecting inertial rate onto the joint axes

The camera rate measured by the IMU, expressed in the camera frame, is:

```
ω_cam = R_cb · ω_base + J(q) · q̇
```

For a yaw (ψ, outer) → roll (φ) → pitch (θ, inner, camera) chain, the joint Jacobian in the camera frame is:

```
         ⎡ −sin θ cos φ    cos θ    0 ⎤
J(q) =   ⎢  sin φ          0        1 ⎥ ᵀ   (columns: ψ̇, φ̇, θ̇ axes in camera frame)
         ⎣  cos θ cos φ    sin θ    0 ⎦
```

**Verify the signs and column order against your gimbal's mechanical frame convention before use.**

Each motor's velocity loop regulates its own axis component of inertial camera rate:

```
ω_meas,j = a_jᵀ · ω_cam
```

where a_j is the axis of joint j expressed in the camera frame (the j-th column of J). This ensures every motor rejects base disturbances along its own axis.

**Singularity.** At gimbal lock (roll = ±90°), the yaw and pitch axes become collinear. Clamp the roll command to ±75°.
