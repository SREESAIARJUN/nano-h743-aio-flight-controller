# FOC Motor Control & Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #34)

I don't have the Job #34 specification, so this design states its assumptions explicitly. Every motor- and frame-specific constant is a parameter, so you can substitute your real values without changing the structure.

## 0. System Assumptions & Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), one timer per axis, center-aligned PWM |
| Motors | Gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s\approx 5\,\Omega$, $L_s\approx 2\,\text{mH}$, $K_t\approx 0.08$ N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), read at the PWM rate |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, shared CLKIN |
| IMU ODR | Gyro and accel at 8 kHz, ±2000 dps, ±16 g |
| Platform | Multirotor, with propeller vibration at 80–400 Hz plus harmonics |

**Loop rates (all phase-locked to the PWM update interrupt):**

```
 20 kHz  ┌────────────────────────────────────────────────────────────┐
         │ ADC → Clarke → Park → PI(id,iq) → invPark → SVPWM          │  current loop
  4 kHz  │ Encoder PLL → velocity PI (+ cogging FF, + accel FF)       │  velocity loop
  8 kHz  │ IMU1/IMU2 → rotate → notch chain → LPF → fusion            │  sensor pipe
  1 kHz  │ Mahony AHRS → attitude error → per-joint angle P/PI        │  angle loop
         └────────────────────────────────────────────────────────────┘
```

Rule of thumb: each outer loop's bandwidth is at most 1/5 to 1/10 of the inner loop's.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Amplitude-invariant Clarke transform, with the zero-sequence term dropped and $i_a+i_b+i_c=0$:

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)
$$

Park transform, with electrical angle $\theta_e = p\,(\theta_m - \theta_{\text{off}})$:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

Inverse Park transform:

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad
v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 1.2 Plant Model (SPMSM, $L_d = L_q = L$)

$$
\begin{aligned}
v_d &= R i_d + L\dot i_d - \omega_e L i_q\\
v_q &= R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m\\
\tau_e &= \tfrac32 p\lambda_m\, i_q = K_t\, i_q
\end{aligned}
$$

### 1.3 Current PI with Decoupling and Back-EMF Feedforward

The decoupled voltage commands are:

$$
v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q,\qquad
v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e (L i_d+\lambda_m)
$$

$$
