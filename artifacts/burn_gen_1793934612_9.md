# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

## 0. Assumptions

I don't have the spec for "Job #8", so the design uses the typical gimbal hardware below. Every parameter sits in one config struct, so you can swap in your own values. Correct anything that doesn't match your hardware.

| Item | Assumed value |
|---|---|
| Motor | 12N14P gimbal BLDC (GBM2804-class), pole pairs p = 7, R = 5.6 Ω (phase-phase 11.2 Ω), L ≈ 1.6 mH, Kt ≈ 0.075 N·m/A |
| Driver | 3-phase, 2 low-side shunts, 12 V bus, center-aligned PWM 20 kHz |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6701 class) on each motor |
| MCU | STM32G4 / H7 class with FPU, 170+ MHz |
| IMU-A | ICM-42688-P on the camera plate (stabilized body): attitude and inertial rate feedback |
| IMU-B | ICM-42688-P on the base/handle: disturbance feedforward and vibration reference |
| Loop rates | Current 20 kHz; velocity 4 kHz; angle 1 kHz; IMU ODR 8 kHz (gyro), 1 kHz (accel) |

**Architecture**

```
           IMU-B (base) ──► base-rate FF ───────────────┐
                    └──► LMS vibration reference ──┐     │
 θ_ref ─►[Angle PI]─► ω_ref ─(+)─►[Velocity PI]─(+)─► i_q* ─►[FOC current PI]─► SVPWM ─► motor
           ▲                ▲                  ▲ cogging FF(θ_enc)        ▲
  attitude (IMU-A fused)   ω_inertial (IMU-A filtered)              θ_e (encoder)
```

The rate loop closes on the **inertial** rate measured by the camera IMU. That rate passes through the vibration rejection chain. The encoder handles commutation and indexes the cogging table.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle with offset calibration:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, two shunts, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$
