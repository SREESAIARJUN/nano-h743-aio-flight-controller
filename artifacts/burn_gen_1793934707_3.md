## 1. FOC Current Loop

### 1.1 Electrical angle

θ_e = p · (θ_m − θ_offset)  (mod 2π)

θ_offset is found at commissioning: inject a fixed `V_d` with θ_e = 0, wait, then read θ_m.

**Latency compensation.** The voltage applied this cycle acts roughly 1.5 PWM periods later, so use

θ_e,comp = θ_e + ω_e · 1.5 · T_pwm

### 1.2 Clarke transform (2-shunt, i_a + i_b + i_c = 0)

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

### 1.3 Park transform

- i_d =  i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

### 1.4 PI current controllers with decoupling

The dq-frame plant is

- v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
- v_q = R·i_q + L·di_q/dt + ω_e·(L·i_d + λ_m)

Use pole-zero cancellation, where ω_ci is the target current-loop bandwidth in rad/s:

- K_p = L · ω_ci
- K_i = R · ω_ci  (continuous form)
- K_i,discrete = R · ω_ci · T_s

The closed loop then reduces to a first-order system, i/i* = ω_ci / (s + ω_ci).

The control law with decoupling and back-EMF feedforward is

- v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
- v_q* = PI_q(i_q* − i_q) + ω_e·(L·i_d + λ_m),  where λ_m = Kt / (1.5·p)

**Voltage limiting.** Limit the vector magnitude so the inverter stays in the linear SVPWM region:

|v| ≤ V_max = V_bus / √3

v_d has priority; v_q gets the remainder, √(V_max² − v_d²).

### 1.5 Inverse Park and SVPWM (min-max zero-sequence injection)

Inverse Park:

- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

Phase voltages:

- v_a = v_α
- v_b = −½·v_α + (√3/2)·v_β
- v_c = −½·v_α − (√3/2)·v_β

Zero-sequence offset and duties:

- v_0 = −(max(v_a, v_b, v_c) + min(v_a, v_b, v_c)) / 2
- D_x = ½ + (v_x + v_0) / V_bus

Min-max injection is mathematically equivalent to 7-segment SVPWM.
