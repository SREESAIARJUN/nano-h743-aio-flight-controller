| Mechanics | Yaw (outer) → Roll → Pitch (inner) |

### Loop rates

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity | 4 kHz | ~150 Hz |
| Angle | 1 kHz | ~20 Hz |
| IMU fusion / AHRS | 8 kHz in, 1 kHz out | n/a |

Each loop is at least 5× faster than the loop around it, so the inner loops can be treated as unity gain when tuning the outer ones.

**Key architectural choice.** On a gimbal, the feedback signals come from the camera IMU, not the encoders:

- The velocity loop is closed on gyro rate, projected into joint space.
- The angle loop is closed on IMU attitude.

Encoders are used only for commutation, cogging phase, and the kinematic Jacobian. This is what makes the camera inertially stabilized.

## 1. FOC Current Loop

### 1.1 Transforms
With θ_e = p·θ_m (p = pole pairs) and an amplitude-invariant scaling:

**Clarke transform**

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

**SVPWM (min-max zero-sequence injection)**

$$v_{a,b,c}^{*} = v_{a,b,c} - \tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad d_x = \tfrac12 + \frac{v_x^{*}}{V_{bus}}$$

The linear range is $|v_{dq}| \le V_{bus}/\sqrt3$.

### 1.2 Plant and PI design
In the rotor frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Using the PI controller

$$C(s) = K_p + K_i/s$$

with pole-zero cancellation ($K_i/K_p = R/L$) and target bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\;\Rightarrow\;\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

Limit ω_c to about $2\pi f_{pwm}/10$ so the PWM and sampling delay (about 1.5 T_s) costs less than 15° of phase margin.
