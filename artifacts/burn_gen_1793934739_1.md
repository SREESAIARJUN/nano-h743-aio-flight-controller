# Job #61: 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion

## 0. Baseline Assumptions

The job brief gave no hardware details, so this design assumes the configuration below. Every equation is parametric, so only the constants change if the hardware differs.

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) per axis |
| MCU | STM32G4/H7 class, FPU, center-aligned PWM, synchronous ADC |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, decimated to 4 kHz |
| Loop rates | Current 20 kHz · Velocity 4 kHz · Angle/attitude 1 kHz |

Each loop runs at about 4–5× the bandwidth of the loop inside it, and each loop's bandwidth is set 5–10× below its own sample rate.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

The electrical angle comes from the mechanical angle, where θ₀ is the encoder offset found during alignment:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assumes iₐ + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform with delay compensation.** PWM update plus sampling adds about 1.5 sample periods of delay, so the angle is advanced:

$$\theta_e^{*} = \theta_e + 1.5\,T_c\,\omega_e$$

$$v_\alpha = v_d\cos\theta_e^* - v_q\sin\theta_e^*,\qquad v_\beta = v_d\sin\theta_e^* + v_q\cos\theta_e^*$$
