# STM32H743 Nano AIO with 4-in-1 ESC (Job #42): System Architecture, Loss Model, Thermal Budget, DMA Plan and Netlists

## 0. Architecture Clarifications

Three points shape everything else in this document.

1. **The H743 does not commutate the motors.** ArduPilot runs on the H743 and sends bi-directional DShot600 to the ESC section. The 48 kHz PWM and the commutation run on separate ESC MCUs: 4× AT32F421 or STM32G071 running AM32, or one 4-channel ESC MCU running BLHeli_32-class firmware. The switching frequency is therefore an ESC firmware parameter (AM32 `PWM_FREQUENCY = 48`). It is not an ArduPilot parameter.
2. **No MOSFET part number was specified.** The equations below are fully parametric. Numerical results use the reference device in §1.1, a typical 40 V, 3.3×3.3 mm DFN used on 20×20 mm boards. Substitute your datasheet values directly.
3. **Design verdict up front:** an 80 A per-channel *burst* rating on a 20×20 mm (or 25.5×25.5 mm) "nano" board is thermally achievable only for about 2–4 s. It is not achievable as a sustained rating. §3 quantifies this. Label it "80 A burst ≤ 3 s @ 40 °C ambient with prop-wash", not "80 A".

| V_f | Body-diode forward voltage | 0.80 V |
| t_dt | Dead time (each edge) | 100 ns |
| R_pcb | Copper path per channel (battery pad → FET → phase pad, 2 oz, 6-layer) | 0.30 mΩ |
| Rth_jc | Junction-to-case (bottom) | 1.2 K/W |

### 1.2 Conduction model

The scheme assumed is 6-step trapezoidal drive with complementary (synchronous) PWM, which is the AM32 default.

At any instant the current path is one high-side FET in series with one low-side FET. Complementary switching means the freewheel current flows through the opposite FET's channel rather than its body diode. The conduction loss is therefore **independent of duty cycle**:

$$
R_{ds}(T_j) = R_{ds,25}\left(\frac{T_j + 273}{298}\right)^{k_T}
$$

$$
P_{cond} = 2\,I_{ph}^2\,R_{ds}(T_j) \;+\; I_{ph}^2 R_{pcb}
$$

Evaluated at T_j = 110 °C:

- R_ds(110 °C) = 0.80 × (383/298)^2.3 = 0.80 × 1.78 = **1.42 mΩ**
- P_cond,FET = 2 × 6400 × 1.42 mΩ = **18.2 W**
- P_cond,PCB = 6400 × 0.30 mΩ = **1.9 W**

Per-FET average: each FET conducts 1/3 of the electrical cycle. Commutation runs at kHz rates, which is far faster than the thermal time constants, so averaging is valid:

$$
\bar P_{FET,cond} = \frac{18.2}{6}\ \text{(conduction pairs share across 6 FETs)} \approx 3.0\ \text{W/FET}
$$

### 1.3 Switching model at 48 kHz

Only the PWM'd leg switches hard. The gate current during the Miller plateau sets the voltage transition time:

$$
I_{g,on} = \frac{V_{drv}-V_{pl}}{R_g} = \frac{7}{3.5} = 2.0\ \text{A},\qquad
I_{g,off} = \frac{V_{pl}}{R_g} = 0.86\ \text{A}
$$

$$
t_r \approx \frac{Q_{gd}}{I_{g,on}} = 7.5\ \text{ns},\qquad t_f \approx \frac{Q_{gd}}{I_{g,off}} = 17.5\ \text{ns}
$$

Add current-rise time and layout inductance. A practical t_r + t_f is about **40 ns**. Use measured double-pulse data if available.

| Loss term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V_bus·I·(t_r + t_f)·f_sw | ½·25.2·80·40e-9·48e3 = **1.94 W** |
| Reverse recovery | Q_rr·V_bus·f_sw | 40e-9·25.2·48e3 = **0.05 W** |
| Output charge | Q_oss·V_bus·f_sw (hard-switched side) | 60e-9·25.2·48e3 = **0.07 W** |
| Dead-time diode | V_f·I·(2·t_dt)·f_sw | 0.8·80·200e-9·48e3 = **0.61 W** |
| Gate drive | 2·Q_g·V_drv·f_sw (HS + LS) | 2·60e-9·10·48e3 = **0.06 W** (in driver/LDO) |
| **P_sw total** | | **≈ 2.7 W** |

**Frequency sensitivity:** P_sw ∝ f_sw. Each 24 kHz step adds or removes about 1.35 W per channel at 80 A. 48 kHz is a reasonable compromise between motor current ripple and switching loss. Dropping to 24 kHz saves about 5.4 W across the four channels at burst.

### 1.4 Total loss at 80 A burst

| | Per channel | 4 channels |
|---|---|---|
| FET conduction | 18.2 W | 72.8 W |
| PCB copper | 1.9 W | 7.6 W |
| Switching + dead time | 2.7 W | 10.8 W |
| **Total** | **22.8 W** | **≈ 91 W** |
| Efficiency (P_out ≈ 25.2·80 = 2016 W/ch) | 98.9 % | — |

The efficiency looks excellent. The problem is power **density**: about 91 W dissipated in roughly 6.5 cm² of PCB.

R_ds(T_j) depends on T_j, which creates positive feedback. Solve it iteratively, or use the closed form for the thermal runaway boundary:

$$
T_j = T_a + R_{th,ja}\left[2I^2R_{ds,25}\left(\tfrac{T_j+273}{298}\right)^{k_T} + P_{sw} + P_{pcb}\right]
$$

This has a stable solution only if

$$
\frac{\partial P}{\partial T_j}\cdot R_{th,ja} < 1.
$$

At 80 A, ∂P_cond/∂T_j ≈ 0.11 W/K per FET pair. A runaway-stable steady state therefore requires R_th,ja < 9 K/W per conducting pair. That is achievable, but the board then has to *reject* 91 W, which it cannot do steadily (see §3).
