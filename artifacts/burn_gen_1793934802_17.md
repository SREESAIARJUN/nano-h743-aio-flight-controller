# STM32H743 Nano FC + 4-in-1 80A ESC: Design Model (Job #19)

## 0. Architecture and Assumptions

**Architecture.** ArduPilot running on the STM32H743 does not commutate motors. A 4-in-1 ESC has its own per-channel motor MCUs, running firmware such as AM32 or BLHeli_32. The H743 is the flight controller. It talks to those MCUs over bidirectional DShot600. The model below follows that split:

```
[6S LiPo] ──► [4-in-1 ESC: 4× (AT32F421 + FD6288Q + 6× N-FET)] ◄──DShot600 (bidir)── [STM32H743 FC / ArduPilot]
```

**Assumptions.** These are parameterized, so substitute datasheet values for the parts you actually select.

| Symbol | Value | Basis |
|---|---|---|
| V_bus | 25.2 V (6S full) | worst case for switching loss |
| I_burst | 80 A per channel | spec |
| f_sw | 48 kHz | spec |
| MOSFET | 40 V, DFN 3.3×3.3 class | nano footprint |
| R_ds(on),25 | 1.2 mΩ @ V_gs = 10 V | typical for this class |
| α (R_ds tempco) | 0.0045 /K | gives ≈1.45× at 125 °C |
| Q_g, Q_gd | 60 nC, 15 nC | |
| V_plateau | 3.5 V | |
| R_g,total (internal + external) | 5 Ω | |
| Q_rr (at high di/dt) | 60 nC | |
| Dead time t_d | 100 ns | |
| Body diode V_f | 0.8 V | |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM | AM32 default style |

**Feasibility.** 80 A per channel on a nano-format board cannot be sustained thermally. Section 3 shows the realistic envelope is a burst of a few seconds. Size the design around that, or parallel the FETs (Section 5).

## 1. Conduction Loss Model

In 6-step operation with synchronous rectification, phase current always flows through exactly two FETs:

- During on-time: HS_x and LS_y.
- During off-time: LS_x (complementary) and LS_y.

So the conduction path resistance is independent of duty:

$$P_{cond} = I^2 \cdot \left(2R_{ds}(T_j) + R_{pcb}\right), \qquad R_{ds}(T_j) = R_{ds,25}\left[1 + \alpha (T_j - 25)\right]$$

At T_j = 125 °C, R_ds = 1.2 × 1.45 = **1.74 mΩ**.

| Term | Calculation | Per channel |
|---|---|---|
| FET conduction | 80² × 2 × 1.74 mΩ | **22.3 W** |
| PCB copper (R_pcb ≈ 0.3 mΩ, 2 oz inner pours plus vias) | 80² × 0.3 mΩ | **1.9 W** |

**Thermal runaway criterion.** Because conduction loss rises with temperature, P(T) = P₀[1 + α(T − 25)]. The stable operating point is:

$$T_j = T_a + R_{th}\,P(T_j) \;\Rightarrow\; T_j = \frac{T_a + R_{th}P_0(1 - 25\alpha)}{1 - \alpha R_{th} P_0}$$

This requires **α·R_th·P₀ < 1**. For a per-FET path R_th(j-a) ≈ 40 K/W at P₀ ≈ 4 W, the product is 0.0045 × 40 × 4 = 0.72. That is stable, but the steady-state T_j is far above limits. This confirms that only a burst rating is possible.

## 2. Switching Loss Model (48 kHz, hard-switched HS)

**Gate-charge-based transition times:**

$$t_{on} \approx \frac{Q_{gd}+Q_{gs2}}{(V_{drv}-V_{pl})/R_g} = \frac{20\,nC}{1.3\,A} \approx 15\,ns, \qquad t_{off} \approx \frac{20\,nC}{V_{pl}/R_g} = \frac{20\,nC}{0.7\,A} \approx 28\,ns$$

**Loss components:**

| Mechanism | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_on + t_off)·f = ½ × 25.2 × 80 × 43 ns × 48k | **2.08 W** |
| Reverse recovery | Q_rr·V·f = 60 nC × 25.2 × 48k | 0.07 W |
| C_oss (E_oss ≈ 1 µJ) | E_oss·f | 0.05 W |
| Dead-time diode conduction | V_f·I·2t_d·f = 0.8 × 80 × 200 ns × 48k | **0.61 W** |
| Gate drive (2 switching FETs) | 2·Q_g·V_g·f = 2 × 60 nC × 10 × 48k | 0.06 W (in driver/R_g) |
| **Total switching** | | **≈ 2.9 W** |

**Per-channel total at 80 A:** 22.3 + 1.9 + 2.9 ≈ **27 W**
**4-in-1 total (all motors at 80 A):** ≈ **108 W**

Efficiency check: at D ≈ 0.9, output power ≈ 25.2 × 0.9 × 80 ≈ 1.8 kW per channel, so η ≈ 98.5%. The efficiency is fine. The problem is power density on a roughly 30×30 mm board.

## 3. Thermal Model

### 3a. Junction-to-board (per FET)

Losses are not evenly shared. The PWM'd high-side FET carries both conduction and switching losses during its 120° sector. At electrical frequencies above 1 kHz, the die averages over the cycle:

- **Worst-case FET:** P ≈ (I²·R_ds·⅓) + P_sw ≈ 3.7 + 2.0 ≈ **~5–6 W**
- **Thermal path:** R_th(j-c) ≈ 1.2 K/W, plus R_th(c-board), covering solder plus a thermal-via array (≥ 12 × 0.3 mm vias), ≈ 3 K/W
- **ΔT_j-board** ≈ 5.5 × 4.2 ≈ **23 K**

With T_j,max = 150 °C and 15 K margin, the board must stay below about **110 °C**.
