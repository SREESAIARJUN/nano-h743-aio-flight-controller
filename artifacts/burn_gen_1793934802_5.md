# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #14): Power-Stage, Thermal & DShot Architecture

## 0. Architecture Scope and Assumptions

**The STM32H743 does not drive the MOSFETs.** On every production 4-in-1 design, the H743 is the flight controller. It runs ArduPilot and emits bidirectional DShot600 to four dedicated ESC MCUs, typically AT32F421 or STM32G071 running AM32 or BLHeli_32. Those ESC MCUs generate the 48 kHz PWM. The models below follow that partitioning.

| Parameter | Value used | Notes |
|---|---|---|
| Bus voltage | 6S, V_bus = 25.2 V (full charge, worst case for switching) | |
| Burst phase current | I = 80 A per motor channel | |
| MOSFET | 40 V, 3.3×3.3 DFN, R_ds(on),25 = 1.2 mΩ @ V_gs = 10 V, Q_g = 40 nC, Q_gd = 10 nC, Q_rr = 30 nC, C_oss,eff ≈ 1 nF, V_SD ≈ 0.8 V, R_θJC ≈ 1.5 K/W | Representative values. **Substitute your actual datasheet values.** |
| Gate driver | 3-phase half-bridge driver (FD6288-class), ~0.5 A effective at the Miller plateau | |
| PWM | 48 kHz, complementary (synchronous rectification), dead time 100 ns, 6-step trapezoidal commutation | |
| Board | 20×20 mm, 8-layer, 2 oz copper, 1.6 mm FR4 | |

> ⚠️ **Feasibility flag:** "80 A" on a 20×20 board can only be a short-duration transient rating. Section 3 quantifies how short. Treat the result as a firmware current/time limit, not a marketing number.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step, complementary PWM
In any commutation sector, exactly two phase legs carry current:

- **PWM on-time (D):** current flows through HS_x and LS_y.
- **PWM off-time (1−D):** current freewheels through LS_x (synchronous) and LS_y.

So **two R_ds(on) are always in series with the phase current**, independent of duty cycle. Ripple is small at 48 kHz with typical motor inductance (~10–30 µH), so I_rms ≈ I_dc.

### 1.2 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j - 25)],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 105 °C: R_ds = 1.2 × 1.40 = **1.68 mΩ**

### 1.3 Channel conduction loss

$$P_{cond,ch} = 2\,I^2 R_{ds}(T_j) = 2 \times 80^2 \times 1.68\,\text{m}\Omega = \mathbf{21.5\ W}$$

Averaged over a full electrical cycle, each of the 6 FETs carries about 1/6 of this: **≈3.6 W per FET**. The instantaneous per-FET load within a sector is up to 10.75 W, which matters for Z_th at low eRPM.

### 1.4 Copper loss (not negligible)
Assume phase and bus traces of 4 mm effective width, 10 mm long, on 4 paralleled 2 oz layers:

$$R_{Cu} = \rho \frac{L}{A} = 1.72\times10^{-8}\frac{0.01}{4\times(0.004\times70\,\mu m)} \approx 0.15\ \text{m}\Omega$$

The loss along the current path is approximately:

$$P_{Cu} \approx I^2 \times 2 R_{Cu} \approx 1.9\ \text{W per channel}$$

This must be included in the board heat budget.

## 2. Switching Loss Model at f_sw = 48 kHz

Only the PWM-ing leg switches hard. The synchronous low-side FET switches at ~0 V (soft switching).

### 2.1 V-I overlap (hard switching)

$$t_r \approx t_f \approx \frac{Q_{gd}}{I_{g}} = \frac{10\,\text{nC}}{0.5\,\text{A}} = 20\ \text{ns}$$

$$P_{sw} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = \tfrac12 (25.2)(80)(40\,\text{ns})(48\,\text{kHz}) = \mathbf{1.94\ W}$$

### 2.2 Dead-time body-diode conduction

$$P_{dt} = V_{SD}\, I \,(2 t_{dt}) f_{sw} = 0.8 \times 80 \times 200\,\text{ns} \times 48\,\text{kHz} = \mathbf{0.61\ W}$$

### 2.3 Reverse recovery

$$P_{rr} = V_{bus} Q_{rr} f_{sw} = 25.2 \times 30\,\text{nC} \times 48\,\text{kHz} = 0.036\ \text{W}$$

### 2.4 Output capacitance

$$P_{oss} = \tfrac12 C_{oss} V_{bus}^2 f_{sw} \times 2 = 0.030\ \text{W}$$

### 2.5 Gate drive (dissipated mostly in the driver)

$$P_g = Q_g V_{gs} f_{sw} \times 2 = 40\,\text{nC} \times 10 \times 48\,\text{kHz} \times 2 = 0.038\ \text{W}$$

### 2.6 Per-channel total at 80 A

| Loss term | W |
|---|---|
| Conduction (2× R_ds, hot) | 21.50 |
| Copper | 1.90 |
| Overlap switching | 1.94 |
| Dead-time diode | 0.61 |
| Q_rr + C_oss + Q_g | 0.10 |
| **Total per channel** | **≈26.1 W** |
| **All 4 channels simultaneously** | **≈104 W** |

**Key insight:** conduction loss is about 82% of the total. Going from 48 to 24 kHz saves only ~1.3 W per channel. Halving R_ds(on), by paralleling FETs or using a better die, saves ~11 W. **Optimize R_ds(on) first, not frequency.**
