# STM32H743 Nano FC + 4-in-1 ESC (Job #8): Electrothermal Model and DShot Architecture

## 0. Scope and Assumptions

I don't have Job #8's requirements document, so the parameters below are stated assumptions. Substitute your actual BOM values. All equations are parametric.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Battery | V_bus | 6S, 25.2 V max (22.2 V nominal) |
| Burst phase current per motor | I_ph | 80 A |
| ESC PWM frequency | f_sw | 48 kHz |
| MOSFET (one per bridge position) | R_DS(on),25 | 0.8 mΩ, 40 V class, 5×6 mm (PDFN) |
| R_DS temperature coefficient | α | 0.0045 /K |
| Switching edge (rise + fall) | t_r + t_f | 50 ns |
| Body diode | V_F, Q_rr | 0.8 V, 40 nC |
| Dead time | t_dt | 100 ns per edge |
| Gate drive | Q_g, V_drv | 60 nC, 10 V |
| PCB path resistance per conduction leg | R_pcb | 0.15 mΩ |
| ESC board | — | 30.5×30.5 mm, 8 layer, 2 oz |

**Architectural clarification.** The STM32H743 does not drive the MOSFETs. The 48 kHz PWM is generated by the four ESC MCUs, for example AT32F421 or STM32G071 running AM32/BLHeli_32. The H743 sends bidirectional DShot600 commands and receives eRPM telemetry. The model is split accordingly:
- Sections 1–3 cover the ESC power stage.
- Section 4 covers the flight controller timers and DMA.
