# STM32H743 FC + 4-in-1 80A ESC: Design Package (Job #64)

## Architecture Scope and Assumptions

ArduPilot does not commutate motors directly from the H743. This design therefore uses the standard stack architecture:

- **FC (STM32H743):** runs ArduPilot and emits bidirectional DShot600 on four timer channels.
- **ESC (4-in-1):** four independent ESC MCUs (e.g., AT32F421 running AM32) generate the 48 kHz complementary PWM. Each drives a 3-phase gate driver (e.g., FD6288Q) and 6 N-MOSFETs, for 24 FETs total.

| Parameter | Value used | Notes |
|---|---|---|
| Battery | 6S, V_bus = 25.2 V (worst case, full charge) | |
| Burst current | 80 A per motor, 10 s | Thermal-capacity limited (see §3) |
| f_sw | 48 kHz, complementary (synchronous) PWM | |

> ⚠ "Nano" form factor: 80A × 4 on a 20×20 board is not thermally credible (see §3). I size this design for 30.5×30.5 mounting. A 20×20 variant should be derated to roughly 40–45A burst.

## 1. Conduction Loss Model (80A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 100 °C:

$$R_{DS} = 0.65 \times 1.45 = 0.943\ \text{mΩ}$$

### 1.2 Current path in 6-step commutation with synchronous PWM

- **PWM on:** current flows through HS(A) and LS(B).
- **PWM off:** current freewheels through LS(A) and LS(B), via the channel, not the diode.

So exactly **two FETs conduct the full phase current at all times**, independent of duty cycle. Phase-current ripple is small: L_motor ≈ 20 µH gives ΔI ≈ 6 A p-p at 48 kHz. The RMS correction is

$$I_{rms} = \sqrt{I^2 + \Delta I^2/12} \approx 80.04\ \text{A}$$

which is negligible.

### 1.3 Per-motor and total conduction loss

$$P_{cond,motor} = 2\, I_{rms}^2\, R_{DS}(T_j) = 2(80)^2(0.943\times10^{-3}) = \mathbf{12.07\ W}$$

$$P_{cond,total} = 4 \times 12.07 = \mathbf{48.3\ W}$$

### 1.4 Ancillary conduction losses (per motor)

| Element | Expression | Loss |
|---|---|---|
| Current shunt (0.25 mΩ, common) | I²R | 1.60 W |
| Phase copper/solder (≈0.15 mΩ path) | I²R | 0.96 W |
| Bulk-cap ESR (I_rip ≈ I·√(D(1−D)), worst D = 0.5 → 40 A; ESR ≈ 3 mΩ effective, shared) | I_rip²·ESR | ~4.8 W per motor if undersized |

The bulk-cap loss is why you need **≥4 × 470 µF low-ESR polymer/electrolytic caps on the power entry** plus 4 × 10 µF X7R per bridge.

## 2. Switching Loss Model at 48 kHz

Gate current during the Miller plateau:

$$I_g = \frac{V_{drv} - V_{pl}}{R_{drv} + R_g} = \frac{10 - 3}{5} = 1.4\ \text{A}$$
