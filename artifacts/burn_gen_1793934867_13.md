## 0. Architectural Clarification

An STM32H743 does not commutate the power stage directly in any production-grade design. ArduPilot has no field-oriented control or six-step commutation code for driving gate drivers. The correct partitioning is:

```
                 ┌────────────── FC domain (STM32H743, ArduPilot) ──────────────┐
 6S VBAT ──┬──►  │ 5V/3.3V buck → H743 → bidir DShot600 ×4 (single-wire, 3.3V)  │
           │     └───────────────┬──────────┬──────────┬──────────┬─────────────┘
           │                     │M1        │M2        │M3        │M4
           │     ┌───────────────▼──────────▼──────────▼──────────▼─────────────┐
           └──►  │ 4× ESC MCU (AT32F421K8U7 or STM32G071, AM32 firmware)        │
                 │ 4× 3-phase gate driver (FD6288Q class) → 24× N-MOSFET        │
                 └──────────────────────────────────────────────────────────────┘
```

The "48 kHz" figure is the ESC MCU PWM frequency, which AM32 supports. DShot600 is the FC-to-ESC link. All loss math below therefore applies to the ESC power stage, and all DMA math applies to the H743.

**Design envelope (assumed):**

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max, 22.2 V nominal |
| Burst phase current per channel | 80 A for ≤ 2 s |
| PWM frequency | 48 kHz, complementary (synchronous rectification), six-step trapezoidal |
| Form factor | 20×20 mm mounting (≈ 26×26 mm outline), 8-layer, 2 oz outer / 1 oz inner copper |
| Ambient | 40 °C; T_j,max = 150 °C abs, 125 °C design limit |

## 2. Conduction Loss Model

### 2.1 Current Distribution in Six-Step Complementary PWM

Each phase leg spends one-third of the electrical period in each of three states:

| State | High-side FET | Low-side FET |
|---|---|---|
| Sourcing (PWM leg) | On for fraction D | On for (1−D) as synchronous rectifier |
| Sinking | Off | On 100 % |
| Floating | Off | Off |

The mean-square current per device (I = phase current, assumed flat-topped) is:
