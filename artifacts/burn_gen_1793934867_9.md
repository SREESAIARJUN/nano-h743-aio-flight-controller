# STM32H743 Nano FC + 4-in-1 ESC: Power-Stage, Thermal, and Bidirectional DShot Design Package

## 0. Assumptions and Scope

I don't have Job #54's BOM or stackup, so this package uses the assumptions below. Every equation is parametric, so you can substitute real datasheet values.

| Parameter | Symbol | Assumed value |
|---|---|---|
| Battery | V_bus | 6S, 25.2 V max (worst case for switching loss) |
| Burst phase current per motor | I_m | 80 A |
| PWM frequency (ESC MCU) | f_sw | 48 kHz |
| MOSFET | — | 40 V, 3.3×3.3 mm DFN, 1 FET per switch position |
| R_DS(on) max at 25 °C, V_GS = 10 V | R_25 | 1.3 mΩ |
| R_DS(on) temperature factor at T_j ≈ 110 °C | k_T | 1.45 |
| Rise/fall times with driver | t_r, t_f | 20 ns each |
| Gate charge | Q_g | 50 nC |
| Body-diode reverse-recovery charge | Q_rr | 40 nC |
| Effective output capacitance | C_oss,er | 1.5 nF |
| Body-diode drop | V_f | 0.8 V |
| Dead time per edge | t_dt | 100 ns |
| Commutation scheme | — | 6-step trapezoidal, complementary (synchronous) PWM on the high side. This matches AM32/BLHeli_32 behavior. |

**Architectural note:** ArduPilot does not generate the 48 kHz bridge PWM. The ESC-side MCUs do that, for example AT32F421 running AM32. The H743 only sources bidirectional DShot600 and decodes eRPM telemetry. Section 3 covers the H743 side; Sections 1–2 cover the ESC side.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

In 6-step commutation, two phases conduct at any instant:
- The PWM leg conducts through the high-side FET for fraction D of the time and through the synchronous low-side FET for fraction (1 − D).
- The return leg conducts through its low-side FET 100%
