## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω (phase), L = 2.2 mH, K_t ≈ 0.09 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per joint |
| Current sense | 2-shunt or inline, sampled center-aligned in PWM valley |
| MCU | STM32G4 / H7 class, single-precision FPU, CMSIS-style ISR |
| IMUs | 2 × ICM-42688-P on the camera (payload) plate, SPI @ 24 MHz, ODR 8 kHz |
| Kinematics | Yaw (outer) → Roll (middle) → Pitch (inner) → Camera |
| Bus | V_dc = 12–16 V |

**Loop hierarchy** (bandwidth separation of at least 5× between nested loops):

```
                 1 kHz                    4 kHz                     20 kHz
q_ref ──► [Attitude P + FF] ──ω_cam──► [J⁻¹(q)] ──q̇_ref──► [Rate PI] ──i_q*──► [FOC PI + decoupling] ──► SVPWM
             ▲ q_est (Mahony)                    ▲ q̇ (gyro→joint)   ▲ + i_cog(θ̂) ff     ▲ i_dq (Park)
             └── Dual IMU fusion ◄── notch+LPF ◄─┘                                       └── encoder θ_e
```

| Loop | Crossover target |
|---|---|
| Current | ω_ci = 2π·2000 rad/s |
| Rate | ω_cv = 2π·150–250 rad/s, limited by payload structural modes |
| Attitude | ω_cθ = 2π·20–30 rad/s |
