## 0. Architecture & Baseline Assumptions

**Architecture clarification.** The H743 does not commutate the motors. It runs ArduPilot and emits bidirectional DShot600. Each ESC channel uses a dedicated small MCU running AM32 or BLHeli_32-class firmware, which performs 6-step commutation at 48 kHz PWM.

```
STM32H743 (ArduPilot) ──DShot600 bidir──► 4× ESC MCU (AT32F421 / STM32G071, AM32)
                                              └─► FD6288Q 3-ph gate driver ─► 6× N-MOSFET ─► motor
```

## 1. Conduction-Loss Model

### 1.1 Current path in 6-step synchronous commutation

At any instant two phases conduct and the third floats. The current always passes through exactly **two device positions in series**: one high-side (HS) and one low-side (LS).

Complementary PWM is applied to one leg. During the ON time the current flows through that leg's HS FET. During the OFF time it flows through the same leg's LS FET (synchronous rectification). Either way, two R_ds(on) values are in the path.

$$P_{cond,ch} = I_{rms}^2 \cdot 2\,\big(R_{ds}(T_j) + R_{pcb}\big)$$

$$R_{ds}(T_j) = R_{ds25}\,\big[1 + \alpha\,(T_j - 25)\big]$$
