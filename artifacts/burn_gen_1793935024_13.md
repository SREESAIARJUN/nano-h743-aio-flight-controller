# STM32H743 Nano FC + 4-in-1 ESC (Job #2): Power-Stage, Thermal, and Bidirectional DShot600 Architecture

## 0. Assumptions and Architecture Constraints

No prior Job #2 specification was provided, so this design rests on the baseline below. If any parameter differs, the derivations hold and only the numbers change.

| Parameter | Assumed value | Notes |
|---|---|---|
| Battery | 6S LiPo, V_bus,max = 25.2 V | 40 V MOSFET class |
| Burst current | 80 A per motor, all 4 motors simultaneously (worst case) | 320 A bus |
| PWM frequency | 48 kHz, complementary (synchronous), center-aligned | AM32-style |
| Commutation | 6-step trapezoidal, sensorless BEMF | |
| FET topology | 1 FET per switch, 6 per motor, 24 total | DFN5x6 / PQFN |
| Form factor | 20×20 mm "nano" stack, 8-layer, 2 oz on all layers | See the warning in §3.6 |
| FC MCU | STM32H743, 400 MHz SYSCLK, 200 MHz timer clock | ArduPilot ChibiOS |
| ESC MCUs | 4× AT32F421 / STM32G071 running AM32 | See note below |

**Architectural note.** The H743 does not commutate the motors. ArduPilot has no 6-step BEMF commutation stack, and sensorless commutation needs per-motor microsecond-level comparator and ADC response. The correct partition is:

H743 (ArduPilot) → 4× bidirectional DShot600 → 4× ESC MCU (AM32) → 3-phase gate driver → 6 FETs per motor.

This is how every production AIO (all-in-one) board works.
