# STM32H743 Nano AIO (FC + 4-in-1 ESC): Architecture, Loss Model, and DShot Allocation
**Job #23, Design Basis Rev A**

## 0. Architectural Corrections

Three assumptions in the brief need correcting before the math is meaningful.

1. **The H743 must not drive the bridges directly.** ArduPilot has no in-flight-controller BLDC commutation or FOC path. Driving 12 half-bridges at 48 kHz from the same MCU that runs EKF3 is also a timing-isolation hazard. The correct topology is:
   - The H743 runs ArduPilot and outputs bidirectional DShot600.
   - Four dedicated ESC MCUs run AM32 (or BLHeli_32-class firmware). Recommended part: AT32F421K8U7 or STM32G071GBU6, one per motor.
   - The 48 kHz PWM and the 80A loss model apply to the ESC section.
2. **80A burst is not survivable on a 20×20 mm "nano" footprint for more than about 2 s** (proven in §2.6). This document scopes it as an 80A, ≤1.5 s burst per motor with 30.5×30.5 mm as the recommended fallback. If 20×20 is mandatory, derate to 45A burst / 30A continuous.
3. **Assumed operating point:**

| Parameter | Value |
|---|---|
| Battery | 6S, V_bus = 25.2 V max |
| f_sw | 48 kHz, center-aligned, synchronous rectification |
| Motor | 14 poles (7 pole pairs) |
| Ambient | 40 °C inside frame |

## 2. Loss Model: 80A Burst, 48 kHz

### 2.1 MOSFET Selection and Parameters

The selected part is a 40 V, 3.3×3.3 mm DFN (e.g., class of BSZ010NE2LS5 / AON7522E). Values are worst-case datasheet values.

| Symbol | Value | Meaning |
|---|---|---|
| R_ds,on(25 °C) | 0.95 mΩ | at V_GS = 10 V |
| k_T | 1.55 | R_ds multiplier at T_j = 125 °C |
| t_r, t_f | 8 ns, 10 ns | with 2.2 Ω gate resistor, 2 A driver |
| Q_g | 38 nC | |
| Q_oss | 42 nC | |
| Q_rr | 35 nC | |
| V_SD | 0.80 V | body diode |
| t_dead | 100 ns | per edge |
| R_θJC | 1.2 K/W | |

The hot on-resistance is R_hot = 0.95 × 1.55 = **1.47 mΩ**.

### 2.2 Conduction Losses (6-Step Trapezoidal, Synchronous)

In any commutation sector, one high-side (HS) and one low-side (LS) FET in another leg carry the phase current I_ph.

- With synchronous rectification and duty D, the active leg alternates HS (duty D) and its complementary LS (duty 1−D).
- The current path therefore always contains two FETs.

$$P_{cond,motor} = 2\, I_{ph}^2\, R_{hot}$$

$$P_{cond,FET,avg} = \frac{2 I_{ph}^2 R_{hot}}{6}\ \ \text{(averaged over 6 FETs/electrical cycle)}$$

At I_ph = 80 A:

$$P_{cond,motor} = 2 \times 6400 \times 1.47\text{e-}3 = \mathbf{18.8\ W}$$

The peak instantaneous dissipation in a single conducting FET is 9.4 W.

**Note on burst current definition.** Battery current is I_bat = D·I_ph. "80A" here is taken as phase current at D ≈ 0.95 (full-throttle punch), which gives I_bat ≈ 76 A per motor. If the 80A spec means battery current at partial throttle, phase current is higher (I_ph = I_bat/D) and losses rise as 1/D².

### 2.3 Switching Losses (Hard-Switched Leg, 1 Commutating FET per Motor per Edge)

$$P_{sw} = \tfrac{1}{2} V_{bus} I_{ph} (t_r + t_f) f_{sw}$$

$$= 0.5 \times 25.2 \times 80 \times 18\text{e-}9 \times 48\text{e}3 = \mathbf{0.871\ W}$$

### 2.4 Secondary Losses per Motor

| Term | Formula | Value |
|---|---|---|
| Body-diode reverse recovery | Q_rr · V_bus · f_sw | 35n × 25.2 × 48k = 0.042 W |
| Output capacitance | ½ · Q_oss · V_bus · f_sw | 0.5 × 42n × 25.2 × 48k = 0.025 W |
| Dead-time diode conduction | 2 · V_SD · I_ph · t_dead · f_sw | 2 × 0.8 × 80 × 100n × 48k = 0.614 W |
| Gate drive (2 switching FETs) | 2 · Q_g · V_GS · f_sw | 2 × 38n × 10 × 48k = 0.036 W (in driver) |
| Shunt (if used, 0.25 mΩ) | I_ph² · R_sh | 1.6 W (avoid, see §3.4) |
| Copper trace/plane | I² · R_cu, ~0.3 mΩ path | 1.9 W |

### 2.5 Total Burst Dissipation

| Item | Per motor | 4 motors |
|---|---|---|
| Conduction | 18.8 W | 75.2 W |
| Switching | 0.87 W | 3.5 W |
| Dead-time | 0.61 W | 2.5 W |
| Qrr + Coss + gate | 0.10 W | 0.4 W |
| Copper | 1.9 W | 7.6 W |
| **Total** | **22.3 W** | **≈ 89 W** |

At f_sw = 48 kHz, switching-related losses are only ~7% of the total. **Conduction dominates.** The lever is therefore R_ds,on and copper, not f_sw. Dropping to 24 kHz would save only ~1.7 W total.
