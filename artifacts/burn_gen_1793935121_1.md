# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the original specification for Job #46, so the design below rests on the assumptions in this table. The design is parametric. Changing the constants in `config.hpp` (Section 6.1) adapts it to your hardware.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) |
| MCU | STM32G4 / H7 class, single-precision FPU, center-aligned PWM |
| Current loop | 20 kHz (one sample per PWM period) |
| Velocity loop | 4 kHz (synchronous with IMU FIFO reads, ODR 8 kHz decimated ×2) |
| Angle loop | 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, gyro ±500 dps, accel ±4 g |
| Kinematic chain | base → yaw → roll → pitch → camera |

## 1. Field-Oriented Current Loop (innermost, 20 kHz)

### 1.1 Transforms

The electrical angle is computed from the mechanical angle and an encoder offset:

$$\theta_e = p\,\theta_m - \theta_{off}$$

**Clarke transform** (amplitude-invariant, with $i_a + i_b + i_c = 0$):
$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**
$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI design

The PMSM voltage equations in the dq frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
