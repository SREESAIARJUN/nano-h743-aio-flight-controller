# 3-Axis Gimbal: FOC Control, Anti-Cogging, and Dual-IMU Vibration Rejection (Job #41)

I don't have the Job #41 specification, so this design uses the baseline below. Every assumption is a named constant in `config.hpp`, so you can swap in your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), 3 × TIM1/TIM8/TIM20 center-aligned PWM |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.6 Ω, L = 1.8 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, mirrored about the plate centroid |
| Loop rates | Current 20 kHz · IMU 8 kHz · Velocity 4 kHz · Attitude/angle 1 kHz |
| Kinematic chain | Yaw (z) → Roll (x) → Pitch (y) → camera |
