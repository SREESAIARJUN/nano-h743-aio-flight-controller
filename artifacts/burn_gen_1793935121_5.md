# High-Frequency FOC Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the original Job #14 specification, so this design uses typical gimbal parameters. Each value is a single `constexpr` or config field in the code, so you can change them in one place.

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class, single-precision FPU, about 170 MHz or more |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048/MT6701-class), used for commutation |
