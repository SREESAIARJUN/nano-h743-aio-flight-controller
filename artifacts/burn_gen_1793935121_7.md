# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification

I don't have the Job #51 requirements, so this design rests on the assumptions in §0. Every number derived from them is parameterized in the code. Swap in your actual motor, encoder and MCU values and the gains recompute.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω (phase), L = 2.2 mH, K_t ≈ 0.07 N·m/A |
| Driver | 3-phase, 12 V bus, 3-shunt (or 2-shunt) current sensing |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) per axis |
| MCU | STM32G4 / H7 class with FPU, 170+ MHz |
| Loop rates | Current 20 kHz, velocity 4 kHz, angle 1 kHz, attitude 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR 8 kHz, ±2000 dps / ±16 g |
| Topology | Yaw → Roll → Pitch (outer → inner) |

Motor parameter values vary a lot between parts. Treat the R, L and K_t figures above as placeholders and measure or confirm them for your motors.

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

Find θ_off at commissioning. Inject a d-axis current with θ_e = 0, let the rotor settle, then read θ_m.

### 1.2 Clarke transform (amplitude-invariant)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)\quad (i_a+i_b+i_c=0)$$

### 1.3 Park transform

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

### 1.5 PI current control with decoupling and back-EMF feedforward

The PI zero is placed on the electrical pole (pole-zero cancellation):

$$K_{p,i} = L\,\omega_{c},\qquad K_{i,i} = R\,\omega_{c}\qquad (\omega_c = 2\pi\cdot 1.5\text{ kHz})$$

The closed loop then becomes first order: $i/i^* = \omega_c/(s+\omega_c)$.

The voltage commands are:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e L i_d + \hat\omega_e\lambda_m$$

where $\lambda_m = \tfrac{2}{3}K_t/p$ in the amplitude-invariant convention. The set-point is $i_d^* = 0$, since there is no field weakening in a gimbal.

**Voltage limiting.** Use the circular limit $|v_{dq}| \le V_{bus}/\sqrt3$, giving priority to $v_d$:

$$v_q^{max} = \sqrt{(V_{bus}/\sqrt3)^2 - v_d^{*2}}$$

**Anti-windup.** Use back-calculation:

$$\dot x_I = K_i e + K_{aw}(u_{sat}-u),\qquad K_{aw}=K_i/K_p$$

### 1.6 Inverse Park and SVPWM (min-max zero-sequence injection)

$$v_a,v_b,v_c \leftarrow \text{inv-Clarke}(\text{inv-Park}(v_d^*,v_q^*))$$

$$v_0 = -\tfrac12\left[\max(v_{abc})+\min(v_{abc})\right]$$

$$d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

Min-max injection is mathematically equivalent to classical 7-segment SVPWM.

## 2. Velocity Estimation: PLL Tracking Observer

Differentiating a 14-bit encoder at 4 kHz quantizes velocity to about 1.5 rad/s, which is unusable. A type-II PLL avoids this.

**Error signal**, computed on the unit circle to avoid wrap discontinuities:

$$e_\theta = \sin(\theta_{meas} - \hat\theta)\approx \theta_{meas}-\hat\theta$$

**Observer dynamics:**

$$\dot{\hat\omega}= K_i^{pll} e_\theta,\qquad \dot{\hat\theta}=\hat\omega + K_p^{pll} e_\theta$$

**Gain selection** for a critically damped observer with bandwidth $\omega_{pll}$:

$$K_p^{pll}=2\omega_{pll},\qquad K_i^{pll}=\omega_{pll}^2$$

Use $\omega_{pll} = 2\pi\cdot 300$ Hz.
