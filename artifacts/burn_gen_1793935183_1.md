# STM32H743 Nano FC + 4-in-1 80 A ESC: Power-Stage, Thermal and Bi-Directional DShot600 Design Package

**Scope and assumptions.** "Job #7" carries no prior context in this conversation, so the baseline assumptions are listed below. Change any of them and the equations still apply; only the numbers move.

| Parameter | Assumed value |
|---|---|
| Form factor | 20×20 mm mounting, about 25×25 mm board, 8-layer, 2 oz copper |
| Battery | 6S LiPo, 25.2 V max (V_bus) |
| Burst current | 80 A phase current per channel (trapezoidal / 6-step), not battery current |
| PWM | 48 kHz, complementary (synchronous rectification), dead time 100 ns |
| ESC MCU | AT32F421 / STM32G071 running AM32 (supports bi-directional DShot / eRPM) |
| FC MCU | STM32H743 @ 480 MHz, APB1/APB2 timer clocks at 240 MHz |
| Gate driver | FD6288Q-class 3-phase bootstrap driver, 2 A source / 2.5 A sink, VCC = 10 V |
| MOSFET (generic) | 40 V, PDFN 3.3×3.3, R_DS(on) = 1.2 mΩ at 25 °C and V_GS = 10 V, Q_g = 50 nC, Q_rr = 40 nC, Q_oss = 30 nC, R_θJC = 1.5 K/W |

> **Key finding up front.** On a 25×25 mm board, 80 A on all four channels is a **burst rating of about 1.5–2.5 s**, not a continuous rating. The derivation is in §3. Any marketing claim of "80 A" on this form factor must specify duration and airflow.
