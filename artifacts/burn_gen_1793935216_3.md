| Item | Assumption |

## 0. Timing Architecture

```
PWM 20 kHz (center-aligned) ── ADC trigger at PWM center
 └─ ISR_FOC   @ 20 kHz : encoder → Clarke/Park → PI(id,iq) → invPark → SVPWM
     └─ every 5th: ISR_VEL @ 4 kHz : rate PI + cogging FF → iq_ref
IMU data-ready @ 8 kHz (both IMUs, CLKIN-locked)
 └─ IMU task @ 8 kHz  : scale → align → lever-arm comp → notch/LPF → fuse
     └─ every 8th: ATT task @ 1 kHz : Mahony attitude → angle P(I) → ω_ref
```

**Bandwidth separation rule.** Each outer loop is ≥5× slower than the inner loop it commands, and every loop sits ≤ 1/10 of its sample rate:

$$\omega_{c,i}\approx 2\pi\cdot 1.5\text{ kHz},\quad \omega_{c,v}\approx 2\pi\cdot 150\text{ Hz},\quad \omega_{c,\theta}\approx 2\pi\cdot 20\text{ Hz}$$

## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

Here $p$ is the number of pole pairs. $\theta_{off}$ is found at calibration by applying $v_d>0$, $v_q=0$ at $\theta_e=0$ and reading the encoder.

**Delay compensation.** The PWM update lags the sample by ≈1.5 Tₛ, so the inverse Park uses

$$\theta_e^{pwm} = \theta_e + 1.5\,T_s\,\omega_e .$$

### 1.2 Clarke (amplitude-invariant) and Park transforms
