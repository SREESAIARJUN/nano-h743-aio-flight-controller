# Job #27: STM32H743 Nano FC + 4-in-1 80A ESC
## Systems Architecture, Loss Model, Thermal Analysis, and DShot DMA Allocation

---

## 0. Architecture Decisions and Design Risks

Three issues shape the rest of this document.

**1. The H743 does not drive the MOSFETs.** ArduPilot is flight-controller firmware. It sends bidirectional DShot600 to ESC firmware (AM32 or BLHeli_32-class). The architecture is therefore:

```
H743 (ArduPilot) ──DShot600 bidir──> 4× ESC MCU (AT32F421/STM32G071, AM32)
                                        └─> 3-phase gate driver ─> 6× N-FET per motor
```

**2. "80A burst" must be specified precisely.** This document defines it as **80A phase current per motor, ≤5 s, at 6S (25.2V maximum)**. Four motors running at 80A simultaneously means a 320A battery draw. No nano-class (20×20 or 30×30) board, XT60 connector, or 6S pack sustains that. The burst rating is therefore thermally time-limited, and the model below derives that limit.

**3. Continuous 80A is not thermally achievable on this form factor.** Section 3 proves it. The deliverable is a burst-duration specification, not a continuous rating.

All numeric parameters below are **design assumptions** for a representative 40V PDFN3.3 MOSFET. Replace them with datasheet values for the selected part (candidates: Toshiba TPN1R..., Infineon BSZ..., or equivalent).

## 2. Loss Model (Per Motor Channel)

### 2.1 Conduction Loss

The model assumes 6-step trapezoidal commutation with synchronous rectification. At every instant, phase current flows through exactly two FET channels: one high-side (or its complementary low-side during the PWM off-time) and one low-side.

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

$$P_{cond}(T_j) = 2\, I_{ph}^2\, R_{ds}(T_j)$$

| T_j | R_ds(on) | P_cond per channel |
|---|---|---|
| 25°C | 1.60 mΩ | 2 × 6400 × 1.6 mΩ = **20.5 W** |
| 125°C | 1.6 × 1.45 = 2.32 mΩ | **29.7 W** |

Each FET conducts for 120° of the electrical cycle, so the average per FET is P_cond/6. Within its conduction window, however, a FET dissipates I²R ≈ 14.8 W (hot). This matters for the die-level ripple calculation in §3.4.
