## 0. Architecture Decisions and Scope

### 0.1 Topology

The STM32H743 does **not** commutate the motors. It runs ArduPilot as the flight controller. Each motor channel has its own ESC MCU running AM32, which supports bidirectional DShot and 48 kHz PWM.

```
                     ┌───────────────────────── 30.5 × 30.5 mm (M3) / 8-layer ──────────────────────────┐
 VBAT (6S, 25.2V) ──►│ Bulk + TVS ─► Buck 10V (gate) ─► Buck 5V ─► LDO 3V3 (FC) / LDO 3V3 (ESC×4)      │
                     │                                                                                   │
```

### 0.2 Feasibility Flags (Read First)

| Item | Finding |
|---|---|
| "80A burst" | Defined here as **80 A per channel, phase current, for ≤ 3 s**. That implies **320 A** total burst from the battery. This is beyond what a 20×20 board can survive, so the design basis is a **30.5×30.5 mm** board. |
| Sustained rating | The thermal model (§3) supports about **35–40 A continuous per channel**. The 80 A figure is strictly a time-limited burst. |
| H743 vs ESC MCU | Integrating commutation into the H743 is not recommended. The ESC firmware ecosystem, fault isolation, and the bidirectional telemetry path all assume per-channel ESC MCUs. |

## 2. Loss Model

### 2.1 Conduction Losses

**Temperature dependence of on-resistance:**

$$R_{DS}(T_j)=R_{DS,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C:

$$R_{DS}=1.5\,\text{m}\Omega \times 1.5 = 2.25\,\text{m}\Omega$$

**Conduction pattern.** In any 60° commutation sector, phase A switches with duty D and phase B's low-side is held on:

- The high-side of A conducts for fraction D.
- The synchronous low-side of A conducts for fraction (1−D).
- The low-side of B conducts 100% of the time.

So the effective number of conducting R_DS at any instant is:

$$D + (1-D) + 1 = 2$$

**Per-channel conduction loss:**

$$P_{cond,ch}=2\,I_{ph}^2\,R_{DS}(T_j)$$

$$P_{cond,ch}=2 \times 80^2 \times 2.25\times10^{-3} = \mathbf{28.8\ W}$$
