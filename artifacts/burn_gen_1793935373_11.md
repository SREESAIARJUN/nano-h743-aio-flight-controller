# STM32H743 Nano FC + 80A 4-in-1 ESC: Systems Architecture Package (Job #56)

**Scope:** Conduction and switching loss model, transient thermal model, input-capacitor stress, ArduPilot bidirectional DShot600 timer/DMA allocation, and reference netlists.

**How to read this document:** The equations and method are complete. The component parameters (marked ⚠) are representative placeholders for this device class. Before layout freeze, substitute the actual datasheet values for the MOSFET, gate driver, and capacitors you select and re-run the numbers.

## 0. Architecture Correction

The STM32H743 should not commutate the motors. A single H743 cannot run ArduPilot's EKF and attitude loops while also doing four channels of 48 kHz commutation with zero-cross or FOC timing. The industry-standard and ArduPilot-supported partition is:

```
 ┌──────────────── FC (STM32H743, ArduPilot) ────────────────┐
 │ IMU/EKF/attitude → motor mixer → DShot600 bidir (4 lines) │
 └───────────┬──────────┬──────────┬──────────┬──────────────┘
             │ M1       │ M2       │ M3       │ M4   (single-wire, bidirectional)
 ┌───────────▼──────────▼──────────▼──────────▼──────────────┐
 │ 4-in-1 ESC: 4× ESC MCU (AT32F421 / STM32G071, AM32 or      │
 │ BLHeli_32-class FW), 4× 3-phase gate driver, 24× N-MOSFET  │
 └────────────────────────────────────────────────────────────┘
```

- **Stack:** 30.5×30.5 mm or 20×20 mm "nano" two-board stack.
- **Feasibility flag:** 80 A burst on a 20×20 board is at or beyond the physical limit (see §3). The model below assumes a 30×30 ESC with 2 oz+ inner copper. A 20×20 board should be rated at roughly 45–55 A burst.
