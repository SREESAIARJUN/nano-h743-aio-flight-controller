## 0. Scope, Assumptions, and Design Risk Flags

Read this section first. Several requirements interact in ways that change the architecture.

### 0.1 Architectural clarification

The STM32H743 is the **flight controller (FC)**. It does **not** drive the MOSFET bridges. ArduPilot has no in-tree support for running four sensored or sensorless BLDC commutation loops on the FC MCU.

The architecture is therefore:

```
STM32H743 (ArduPilot) ──bidir DShot600 ×4──► 4× ESC MCU (AM32 / BLHeli_32-class)
                                                 │ 48 kHz complementary PWM
                                                 ▼
                                          4× gate driver ─► 4× 3-phase bridge (24 FETs)
```

The 48 kHz switching frequency is set in the **ESC firmware** (AM32 supports a configurable PWM frequency). It is not set in ArduPilot.
