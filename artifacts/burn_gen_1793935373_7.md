# Job #57: STM32H743 Nano FC + 4-in-1 ESC

**Electrothermal Model, 48 kHz Switching Analysis, Bidirectional DShot600 Timer/DMA Allocation, and Reference Netlists**

---

## 0. Architecture Clarification and Key Findings

**The STM32H743 does not commutate the motors.** In an ArduPilot stack, the H743 runs the flight controller and emits DShot600 frames. Each 4-in-1 ESC has its own MCU, which generates the 48 kHz PWM and performs commutation. That MCU is typically an AT32F421 or STM32G071 running AM32 or BLHeli_32. This document is therefore split into two domains:

| Domain | Silicon | Responsibility |
|---|---|---|
| FC | STM32H743VI (400 MHz) | ArduPilot, DShot600 TX, bidirectional eRPM RX, harmonic notch |
| ESC | ESC MCU + 3-phase gate driver + 24 MOSFETs | 48 kHz PWM, commutation, eRPM telemetry |

**Key findings:**

1. **80 A per motor is a short burst rating only, about 3 s, on a nano-class board.** The derived continuous capability is about 35 A per motor.
2. **Total burst dissipation is about 83 W across the 24 FETs,** plus bus copper and shunt losses.
3. **Bidirectional DShot cannot use complementary (CHxN) pins,** because they have no input capture. All four motor outputs therefore go on true CHx pins.

**All device parameters below are representative.** Before release, substitute the values from the datasheet of the MOSFET you actually select.
