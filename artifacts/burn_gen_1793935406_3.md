# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #33 specification, so every motor, sensor, and mechanical value below is an assumption. Each one appears once in the `cfg` namespace so you can replace it. The equations are general.

---

## 0. System Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (N_s=12 slots, p=7 pole pairs), R=5.6 Ω, L=2.4 mH, K_t=0.11 N·m/A |
| Encoders | 14-bit magnetic (AS5047P/MT6701-class), read at 20 kHz |
| Bus | 12 V, center-aligned PWM 20 kHz, synchronous phase-current sampling |
| IMU A | ICM-42688-P on the **camera payload**. Primary attitude and rate feedback. |
| IMU B | ICM-42688-P on the **base/handle**. Disturbance feedforward and vibration reference. |
| IMU config | Gyro ±2000 dps, ODR 8 kHz, 20-bit FIFO hi-res mode. On-chip AAF ≈ 1 kHz, configured via `GYRO_CONFIG_STATIC2..5` per the datasheet
