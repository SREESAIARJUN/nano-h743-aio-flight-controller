## 0. Scope and Assumptions

### 0.1 System architecture

The STM32H743 does not drive the MOSFETs directly. It is the flight controller and sends bidirectional DShot600 to four independent ESC MCUs. Each ESC MCU runs AM32, the open-source firmware compatible with BLHeli_32.

```
VBAT ─┬─────────────────────────────── 6S, 25.2 V max
      │
  [STM32H743 FC] ──DShot600 bidir──> [ESC MCU ×4: STM32G071 / AT32F421 + AM32]
                                          │ 6× PWM (complementary)
                                     [3-ph gate driver ×4]
                                          │
                                     [6× N-MOSFET per motor = 24 FETs]
```

> ⚠️ **Feasibility flag (stated up front):** The model shows that 80 A per motor on all four motors simultaneously is **not thermally achievable** on a nano-format board for 10 s. Sustained operation is not achievable either. The numbers are derived below so the specification can be corrected rather than assumed. A realistic rating is in §3.4.
