## 0. Assumptions

No Job #2 specification was provided, so this document uses the baseline below. Change any value and the equations still apply.

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S LiPo, 22.2 V nom / **25.2 V max** | Worst case for switching loss |
| Burst current | **80 A per motor phase, 10 s** | Total-board (80 A ÷ 4) case also evaluated in §3.6 |
| ESC PWM | 48 kHz, complementary, active freewheeling | AM32 or BLHeli_32-class firmware |
| Commutation | 6-step trapezoidal, 120° conduction | |
| Board | 20×20 mm mount (nano), 6-layer, 2 oz outer / 1 oz inner | |
| FC MCU | STM32H743VIT6 @ 400 MHz (ArduPilot default) | Timer clock 200 MHz |
| ESC MCUs | 4× AT32F421K
