# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #46, so this design is built on the explicit assumptions in §0. Every constant is parameterized, so you can substitute the real values. The design has three layers:

1. **Equations:** current, velocity and angle cascade, plus gimbal kinematics.
2. **Anti-cogging feedforward:** offline identification followed by online LMS refinement.
3. **Dual ICM-42688-P fusion:** lever-arm cancellation, notch filtering, inverse-variance weighting, fault isolation, and a Mahony attitude filter.

A complete C++17 implementation follows the equations. It uses no heap, no exceptions and single-precision float only.

## 0. Assumptions and Rate Plan

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s\approx 5\,\Omega$, $L_s\approx 2\,\text{mH}$ |
| Position sensor | 14-bit magnetic encoder (AS5048A/MT6701) per axis, read over SPI |
| MCU | STM32G4/H7 class with FPU, center-aligned PWM at 20 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the payload reference point |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz ($T_c=50\,\mu s$) | $\omega_c \approx 2\pi\cdot 1.5\,\text{kHz}$ |
| IMU sampling and filters | 8 kHz ODR, processed at 4 kHz | — |
| Velocity | 4 kHz ($T_v=250\,\mu s$) | $\omega_v \approx 2\pi\cdot 150\,\text{Hz}$ |
| Angle (attitude) | 1 kHz ($T_\theta = 1\,\text{ms}$) | $\omega_\theta \approx 2\pi\cdot 30\,\text{Hz}$ |

Each outer loop runs at roughly 1/5 to 1/10 of the bandwidth of the loop inside it. This preserves time-scale separation, so each inner loop can be treated as unity gain when the outer loop is designed.

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle: $\theta_e = p\,(\theta_m - \theta_{\text{off}})$.

**Clarke transform** (amplitude-invariant, assuming $i_a+i_b+i_c=0$):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park transform:**

$$
\begin{bmatrix} i_d \\ i_q \end{bmatrix} =
\begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix}
\begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}
$$

### 1.2 Plant and PI Design

The dq voltage equations for a surface PMSM are:

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad
v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m
$$

The current controller combines a PI term with decoupling and back-EMF feedforward:

$$
v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q,\qquad
v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m
$$

Choosing the PI zero to cancel the electrical pole ($K_i/K_p = R/L$) gives first-order closed-loop dynamics $\frac{\omega_c}{s+\omega_c}$:

$$
K_{p,c} = L\,\omega_c,\qquad K_{i,c} = R\,\omega_c
$$

Set $i_d^* = 0$, since a surface PMSM produces no reluctance torque.
