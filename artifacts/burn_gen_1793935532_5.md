# 3-Axis Gimbal Motor Control & Sensor Fusion Design (Job #20)

## 0. Scope and Assumptions

I don't have the Job #20 spec sheet, so the design is fully parameterized. These are the baseline values; replace them with your measured motor and frame data.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (`p = 7` pole pairs), `R ≈ 5–15 Ω`, `L ≈ 1–3 mH` |
| Position sensor | 14-bit absolute magnetic encoder per axis (e.g. AS5048/MT6701) |
| Inverter | 3-phase, center-aligned PWM 20 kHz, 2 low-side shunts |
| MCU | Cortex-M4F/M7 with FPU (float32), ≥ 168 MHz |
| IMUs | 2× ICM-42688-P on the camera plate, mounted mirror-symmetric about the plate centroid |
| Kinematics | Yaw (base) → Roll → Pitch (camera) |

**Loop timing (all rates locked to the PWM interrupt):**

| Loop | Rate | Period | Contents |
|---|---|---|---|
| Current (FOC) | 20 kHz | Tᵢ = 50 µs | Clarke/Park, d/q PI, decoupling, SVPWM |
| Velocity | 4 kHz | Tᵥ = 250 µs | PI + cogging FF + accel FF |
| Angle / stabilization | 1 kHz | Tₚ = 1 ms | P/PI + velocity FF, attitude → joint mapping |
| IMU read | 8 kHz ODR | — | ICM AAF on-chip, decimated 2:1 to the velocity loop with filtering |
