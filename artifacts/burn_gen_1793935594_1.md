# STM32H743 Flight Controller + 80A-Burst 4-in-1 ESC: Systems Architecture Package (Job #30)

## 0. Architecture Corrections and Design Envelope

Three issues need to be resolved before the math, because they change it.

**1. Partitioning.** ArduPilot on the H743 should be the flight controller. The 4-in-1 ESC should keep its own per-motor MCUs (AT32F421 or STM32G071 running AM32/BLHeli_32 with bidirectional DShot enabled). The H743 does not run the commutation loops.

- Direct H743 commutation of 4 motors would need 24 gate signals. That means TIM1 + TIM8 + HRTIM, plus 4× BEMF comparators and ADC sampling.
- No ArduPilot code path supports this.
- It is covered as an option in §5.4 but is **not recommended**.

**2. "Nano" vs 80A.** A 20×20 mm (or even 25.5×25.5 mm) board cannot dissipate 80A *per motor* continuously. §2 shows roughly 100 W of total loss at that current. The 80A spec is therefore treated as a **time-limited burst**, and its allowed duration is derived from thermal capacitance.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

This makes the loss model self-referential: higher loss raises T_j, which raises R_ds, which raises loss. §3.3 solves this iteratively.

### 1.2 Six-step trapezoidal commutation with synchronous rectification

- At any instant, current flows through exactly **two** phase legs.
- During the PWM ON-time, the path is high-side (HS) of phase X plus low-side (LS) of phase Y.
- During the OFF-time, the complementary LS of phase X conducts instead (synchronous rectification).
- So **two channel resistances are always in series**, independent of duty cycle D:

$$P_{cond,motor} = 2\,I^2 R_{ds}(T_j)$$

Per-FET split over one electrical cycle, where each phase is active 2/3 of the time:

$$P_{HS} = \tfrac{1}{3}D\,I^2R_{ds}$$
$$P_{LS} = \tfrac{1}{3}(1-D)\,I^2R_{ds} + \tfrac{1}{3}I^2R_{ds}$$

**Worst case:** the LS FETs carry the most loss at low D. This is the high-current, low-RPM throttle-punch case.

### 1.3 Numbers at 80A burst (T_j = 125 °C, R_ds = 1.8 mΩ)

$$P_{cond,motor} = 2 \times 80^2 \times 1.8\text{m} = \mathbf{23.0\ W}$$

- Average per FET (÷6): 3.84 W
- Worst LS FET at D = 0.3: (0.7/3 + 1/3) × 6400 × 1.8 m = **6.53 W**
- PCB copper/trace loss: assume 0.3 mΩ per motor current path, so 80² × 0.3 m = 1.9 W per motor

## 2. Switching Loss Model at 48 kHz

Only **one** leg switches per PWM period (the PWM'd phase).

### 2.1 Hard-switching V–I overlap

$$P_{sw} = \tfrac{1}{2}V_{bus}\,I\,(t_r+t_f)\,f_{sw}$$
$$= 0.5 \times 25.2 \times 80 \times 20\text{n} \times 48\text{k} = \mathbf{0.97\ W}$$

### 2.2 Output capacitance

$$P_{oss} = Q_{oss}\,V_{bus}\,f_{sw} = 35\text{n} \times 25.2 \times 48\text{k} = 0.042\ \text{W}$$

### 2.3 Reverse recovery

$$P_{rr} = Q_{rr}\,V_{bus}\,f_{sw} = 30\text{n} \times 25.2 \times 48\text{k} = 0.036\ \text{W}$$

### 2.4 Dead-time body-diode conduction

$$P_{dt} = V_f\,I\,(2t_{dt})\,f_{sw} = 0.8 \times 80 \times 400\text{n} \times 48\text{k} = \mathbf{1.23\ W}$$

Dead time costs more than the switching edges. Reducing it to 80 ns brings this down to 0.49 W. Verify shoot-through margin on the scope at the gate-driver output first.

### 2.5 Gate drive (dissipated mostly in the driver and gate resistors)

$$P_g = 6\,Q_g\,V_{gs}\,f_{sw} = 6 \times 40\text{n} \times 10 \times 48\text{k} = 0.115\ \text{W}$$

### 2.6 Total switching-related loss

$$P_{sw,total} = 0.97 + 0.042 + 0.036 + 1.23 + 0.115 \approx \mathbf{2.39\ W/motor}$$

### 2.7 Frequency trade-off

The frequency-dependent terms scale as ≈ 49.8 µJ × f_sw at 80A. So:

| f_sw | Frequency-dependent loss |
|---|---|
| 24 kHz | 1.2 W |
| 48 kHz | 2.4 W |
| 96 kHz | 4.8 W |

At 48 kHz, switching is about 10% of conduction. Conduction dominates, so **choose the FET on R_ds(on), not Q_g**.

## 3. Thermal Model

### 3.1 Loss totals

| Condition | Per motor | 4 motors |
|---|---|---|
| 80A burst | 23.0 + 2.4 + 1.9 = **27.3 W** | **109 W** |
| 35A continuous (T_j ≈ 90 °C, R_ds = 1.55 mΩ) | 3.8 + 1.05 + 0.37 ≈ 5.2 W | **≈21 W** |

### 3.2 Two-node RC network

```
P_FET ─[R_θJC 1.5]─ T_case ─[R_θCB ≈ 8 K/W/FET (vias+TIM)]─ T_board ─[R_θBA]─ T_amb
                                                               │
                                                             C_board
```

**Board thermal capacitance (30.5×30.5 mm ESC, 6-layer, 2 oz):**
- FR4 ≈ 2.0 g × 1.1 J/g·K
- Copper ≈ 2.4 g × 0.385 J/g·K
- FET tabs and capacitors ≈ 0.5 J/K
- **C_board ≈ 3.6 J/K**

**Board-to-ambient resistance:**
- In propwash (~10 m/s, h ≈ 60 W/m²K, both sides ≈ 1.9×10⁻³ m²): R_θBA ≈ 9 K/W
- Still air: ≈ 25 K/W

On a 20×20 board, C ≈ 1.6 J/K. That halves every burst-duration number below.

### 3.3 Burst duration limit

Board temperature response:

$$T_b(t) = T_{b0} + P R_{\theta BA}\left(1 - e^{-t/\tau}\right), \quad \tau = R_{\theta BA}\,C_{board} = 32\ \text{s}$$

For short bursts, the adiabatic approximation holds:

$$\Delta T_b \approx \frac{P\,t}{C}$$

$$T_j = T_b + P_{FET}\,(R_{\theta JC} + R_{\theta CB})$$
$$= T_b + (6.53 + \text{share of } P_{sw} \approx 0.6) \times 9.5 \approx T_b + 68\ \text{K}$$
