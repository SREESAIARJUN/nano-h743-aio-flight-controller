## 0. Architecture Corrections

Three points affect everything downstream.

1. **The H743 does not commutate the motors.** ArduPilot runs on the H743 and outputs DShot. Each motor needs its own ESC MCU running AM32 or BLHeli_32 (baseline: 4× AT32F421K8U7). That MCU generates the 48 kHz PWM, runs commutation and BEMF sensing, and returns bidirectional DShot eRPM. "48 kHz switching" is an ESC firmware parameter (AM32 `PWM frequency`), not an ArduPilot one.
2. **"Nano" plus H743 plus 80 A is a packaging conflict.**
   - The H743 is LQFP100 (14×14 mm) or TFBGA100 (8×8 mm). Twenty-four MOSFETs at 3.3×3.3 mm cannot share a 20×20 mm board with it.
   - Baseline: a 2-board 20×20 stack (FC on top, ESC below) on an 8-pin JST-SH. The alternative is a 25.5×25.5 AIO with TFBGA.
3. **80 A is a burst rating of seconds, not a continuous rating.** Section 3 shows the realistic continuous figure on 20×20 copper is about 25–30 A per channel. The spec sheet should say "80 A burst (≤1 s, 10% duty)".

## 2. Loss Model per Motor Channel

**Topology:** 3 half-bridges per motor (6 FETs), 24 FETs total. The model assumes 6-step trapezoidal commutation with synchronous rectification. In any 60° sector:
- one phase's high-side (HS) switches at duty D,
- the same leg's low-side (LS) conducts during (1−D) as a synchronous rectifier,
- the return leg's LS is held on continuously.

### 2.1 Conduction Loss

```
R_ds,hot = R_ds,25 · k_T = 0.90 mΩ · 1.6 = 1.44 mΩ

P_cond = I² · [ D·R_HS + (1−D)·R_LS,sync + R_LS,return ]
       = I² · 2·R_ds,hot          (independent of D, because HS and LS alternate)
       = 80² · 2 · 1.44e-3
       = 18.4 W per motor
```

**PCB copper must be counted.** Assume a phase/bus path of about 15 mm at 6 mm width on 2 oz copper, ×2 parallel layers:

```
R_cu = ρ·L/(w·t) = 1.72e-8 · 0.015 / (6e-3 · 70e-6 · 2) ≈ 0.31 mΩ  (×1.4 hot → 0.43 mΩ)
P_cu = 80² · 0.43e-3 ≈ 2.8 W per motor
```

**Thermal coupling:** R_ds rises with T_j, which raises loss, which raises T_j. Solve iteratively:

```
R_ds(T_j) = R_ds,25 · [1 + α(T_j − 25)],  α ≈ 0.006 /K
T_j = T_board + P_FET(R_ds(T_j)) · R_θJB
```

The 1.6 factor above is the converged value near T_j = 125 °C.
