## 0. Architecture Decision (read first)

The H743 should **not** commutate the motors. The standard, supportable architecture is:

```
┌───────────────────────────────┐   DShot600 bidir (4 lines)   ┌──────────────────────────┐
│ STM32H743VIT6 @ 480 MHz       │ ───────────────────────────► │ 4× AT32F421 / STM32G071  │
│ ArduPilot (ChibiOS)           │ ◄─── eRPM telemetry (GCR) ── │ AM32 / BLHeli_32 fw      │
│ IMU, baro, OSD, SD, UARTs     │                              │ 4× 3-phase bridges (24 FET)
└───────────────────────────────┘                              └──────────────────────────┘
```

**Why the H743 should not run the bridges:**
- ArduPilot has no BLDC field-oriented or six-step commutation stack.
- 4 motors × 3 phases × complementary PWM with dead-time requires 4 advanced-control timers. The H743 has only 2 (TIM1, TIM8), plus HRTIM.

The rest of this document assumes the split architecture.

## 2. Loss Model

### 2.1 Conduction-path topology (6-step, synchronous)

During any 60° commutation sector:
- One high-side FET (phase X) chops at duty D.
- Its complementary low-side FET (phase X) conducts during (1−D).
- One low-side FET (phase Y) conducts continuously.

Instantaneous conduction loss in the motor path:

$$P_{cond,motor} = I^2 R_{ds}(T_j)\,D + I^2 R_{ds}(T_j)(1-D) + I^2 R_{ds}(T_j) = 2\,I^2 R_{ds}(T_j)$$

This is **independent of D**, which is a useful property for synchronous 6-step.

Per-FET average loss, since each FET is active in 2 of 6 sectors:

$$P_{cond,FET} \approx \frac{2 I^2 R_{ds}(T_j)}{3}\ \text{(worst-case FET, bottom-referenced arrangement)}$$

For hotspot analysis, use the motor-total loss spread across the 6 FETs of one bridge.

### 2.2 Temperature-dependent R_DS(on), solved self-consistently

$$R_{ds}(T_j) = R_{25}\,[1+\alpha (T_j-25)]$$

$$T_j = T_a + P_{tot}(T_j)\cdot Z_{th}(t)$$

Because P depends on T_j, this is a fixed-point problem:

$$T_j^{(n+1)} = T_a + \left[2I^2R_{25}(1+\alpha(T_j^{(n)}-25)) + P_{sw}\right] Z_{th}$$

It has a closed form (linear in T_j):

$$T_j = \frac{T_a + Z_{th}\left[2I^2R_{25}(1-25\alpha) + P_{sw}\right]}{1 - 2I^2R_{25}\,\alpha\,Z_{th}}$$

**Thermal runaway criterion:** the denominator must be greater than 0, which gives

$$Z_{th} < \frac{1}{2I^2R_{25}\alpha}$$
