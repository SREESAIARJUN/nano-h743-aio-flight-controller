# STM32H743 Nano AIO + 4-in-1 ESC: Electrical, Thermal and DShot Design Model (Job #57)

## 0. Scope and Assumptions

I don't have the Job #57 requirements document, BOM, or layout. Every parameter below is an explicit assumption. The model is built so you can substitute real datasheet values and re-run the numbers. Items marked **⚠ VERIFY** must be checked against your actual parts before release.

### Architectural correction

ArduPilot running on an STM32H743 does **not** commutate motors directly. The intended architecture is:

- **Flight controller:** STM32H743 running ArduPilot, sending bidirectional DShot600.
- **4-in-1 ESC:** four independent ESC MCUs (assumed AT32F421 running AM32), each with a 3-phase gate driver and 6 MOSFETs.

The H743's job here is the DShot/DMA side (Section 4). The loss and thermal models (Sections 1–3) apply to the ESC power stage.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

In 6-step commutation with synchronous rectification, two legs are active at any instant:

- **PWM leg:** the high-side FET conducts for duty D. The low-side FET of the same leg (synchronous rectifier) conducts for 1−D.
- **Return leg:** the low-side FET is held on continuously.
