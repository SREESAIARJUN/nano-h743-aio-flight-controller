# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the spec sheet for "Job #2," so this design states its assumptions explicitly. Every parameter is a named constant, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | Outrunner BLDC/PMSM gimbal motor, 12N14P (pole pairs p = 7), R = 5 Ω, L = 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit magnetic encoder (MT6701/AS5048A class), read every PWM cycle |
| MCU | Cortex-M4F/M7 or similar with single-precision FPU |
| PWM / current loop | 20 kHz, center-aligned, phase currents sampled at the PWM valley |
| Velocity loop | 4 kHz (every 5th PWM ISR) |
| Attitude loop | 1 kHz |
| IMUs | 2 × ICM-42688-P at 8 kHz ODR, read via FIFO or data-ready on SPI. Mounted symmetrically about the camera-plate centroid (r₂ ≈ −r₁). |
| Kinematic chain | Yaw (base) → Roll → Pitch (camera) |

## 1. Control Architecture

```
 Attitude setpoint q_ref (camera frame)
      │
 ┌────▼─────┐ ω_cmd(cam) ┌─────────┐ q̇_cmd(joint) ┌──────────┐ i_q* ┌──────────┐  v_dq   ┌──────┐
 │ Attitude │──────────► │ J⁻¹(θ)  │────────────► │ Velocity │─────►│ Current  │───────► │ SVPWM│─► Motor
 │  P / PD  │  1 kHz     │ mapping │              │ PI + FF  │4 kHz │ PI (d,q) │ 20 kHz  └──────┘
 └────▲─────┘            └─────────┘              └────▲─────┘  ▲   └────▲─────┘
      │ q̂ (Mahony)                                   ω̂ (PLL)     │        │ i_abc
 ┌────┴──────────────────────────┐                    │      i_cog(θ)  ┌───┴──────┐
 │ Dual ICM-42688-P → notch bank │                encoder       │      │ Clarke / │
 │ → fusion → AHRS               │                              │      │ Park     │
 └───────────────────────────────┘                     Cogging feedforward
```

Rule of thumb for bandwidth separation: each loop should be at least 4–5× slower than the loop inside it.

- Current loop: ω_c,i ≈ 2π·1.5 kHz
- Velocity loop: ω_c,v ≈ 2π·150 H
