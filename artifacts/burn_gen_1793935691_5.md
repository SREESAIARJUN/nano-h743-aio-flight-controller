# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual-IMU Fusion Design

I don't have the original specification for Job #27, so this design states its assumptions. Every gain is derived symbolically, so you can substitute your measured parameters.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 @ 170 MHz with FPU (any Cortex-M4F/M7 works) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| IMUs | 2 × ICM-42688-P on the camera stage, SPI, 8 kHz ODR, mounted symmetrically about the stage's rotation center |
| Current sensing | Inline or low-side shunts, synchronous ADC at the PWM center |

**Loop rates and bandwidths** (multi-rate, each loop ≥ 5× slower than the one it wraps):

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC, d/q PI) | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| IMU sampling and filtering | 8 kHz | n/a |
| Velocity (PI) | 4 kHz | ω_v ≈ 2π·150 rad/s |
| Angle (P + feedforward) | 1 kHz | ω_θ ≈ 2π·30 rad/s |
| Attitude estimator (Mahony) | 1 kHz | n/a |
