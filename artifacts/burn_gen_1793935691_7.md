# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #34. The design below states its hardware assumptions in §0. Each assumption maps to a parameter in a config struct, so you can adjust it to your actual BOM. Every gain is derived from physical parameters, not hand-tuned, so a change in motor or inertia only means updating the inputs.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU, 170+ MHz, center-aligned PWM |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), e.g. GBM2804 class |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |
| Current sense | 2–3 low-side shunts, sampled at the PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, on separate SPI buses, sharing an external CLKIN |
| Bus | 12–16 V |

**Loop rates (all phase-locked to PWM):**

| Loop | Rate | Ts | Bandwidth target |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ω_c ≈ 2π·1500 rad/s |
| IMU sample + filtering | 8 kHz (ODR) | 125 µs | — |
| Velocity | 4 kHz | 250 µs | ω_v ≈ 2π·80 rad/s |
| Angle | 1 kHz | 1 ms | ω_θ ≈ 2π·15 rad/s |

The loops are separated by a ratio of 5 or more in bandwidth. That lets each inner loop be treated as unity gain plus a first-order lag when designing the outer loop.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, with $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model (Surface PMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
