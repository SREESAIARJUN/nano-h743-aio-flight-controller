## 1. Loop Architecture and Rates

```
 IMU 8 kHz ──► per-IMU AAF + dynamic notch + LPF ──► dual-IMU fusion ──► attitude filter (1 kHz)
                                                         │ ω_body                │ q (attitude)
                                                         ▼                       ▼
 θ_ref ──► [Angle P + FF] 1 kHz ──► ω_ref ──► [Velocity PI] 4 kHz ──► i_q,ref ─┐
                                                                             + │ ◄── anti-cogging FF i_cog(θ_m)
                                                                               ▼
              encoder θ_m ──► θ_e = p·θ_m − θ_off ──► [FOC current PI] 20 kHz ──► SVPWM
```

Each loop must be several times slower than the loop inside it:

ω_c,current ≈ 2π·1.5 kHz ≫ ω_c,vel ≈ 2π·150 Hz ≫ ω_c,angle ≈ 2π·25 Hz

Keep a separation ratio of at least 4–6 per stage.

## 2. FOC Current Loop (20 kHz)

### 2.1 Coordinate transforms

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2 i_b) / √3

**Park transform**, with θ_e = p·θ_m − θ_off:

- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

**Inverse Park transform:**

- v_α = v_d cos θ_e − v_q sin θ_e
- v_β = v_d sin θ_e + v_q cos θ_e

### 2.2 PMSM model in dq coordinates

- v_d = R i_d + L (di_d/dt) − ω_e L i_q
- v_q = R i_q + L (di_q/dt) + ω_e L i_d + ω_e λ_m
- τ_m = (3/2) p λ_m i_q = K_t i_q

Here ω_e = p·ω_m and λ_m = 2 K_t / (3p).

### 2.3 Decoupled PI with pole-zero cancellation

Decoupling and back-EMF feedforward terms:

- v_d,ff = −ω_e L i_q
- v_q,ff = ω_e L i_d + ω_e λ_m

The plant seen by each PI controller is then 1/(Ls + R). Choose the PI zero to cancel the plant pole:

C(s) = K_p + K_i/s, with K_p = L ω_c and K_i = R ω_c.

This gives a first-order closed loop, i(s)/i_ref(s) = ω_c / (s + ω_c).

For L = 1.8 mH, R = 5.5 Ω and ω_c = 2π·1500:
- K_p ≈ 16.96 V/A
- K_i ≈ 51,836 V/(A·s)

Keep ω_c ≤ ω_PWM/10. That margin covers the 1.5-sample computation and PWM delay.

### 2.4 Discrete PI with back-calculation anti-windup

With sample period T_s:

1. e_k = r_k − y_k
2. u_k* = K_p e_k + I_k + u_ff
3. u_k = sat(u_k*)
4. I_{k+1} = I_k + T_s [K_i e_k + K_aw (u_k − u_k*)]

Use K_aw ≈ K_i / K_p, which sets the anti-windup time constant to the PI zero.
