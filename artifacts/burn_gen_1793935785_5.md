# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #24): Design Model

## 0. Scope, Assumptions and Feasibility Flags

Several assumptions had to be made. Each is stated so it can be replaced with real datasheet values. Every equation is given in symbolic form first, then evaluated with the assumed numbers.

| Parameter | Assumed value | Basis |
|---|---|---|
| Battery | 6S LiPo, V_bus,max = 25.2 V | Typical for 80A-class |
| MOSFET | 40 V N-ch, 3.3×3.3 mm PDFN, R_ds(on),25 = 1.2 mΩ @ V_gs = 10 V | Representative 40 V device class |
| R_ds(on) temperature coefficient | α ≈ 0.006 /K, giving ×1.6 at 125 °C | Typical trench FET |
| Q_g / Q_gd / Q_rr / Q_oss | 40 nC / 10 nC / 40 nC / 50 nC | Representative |
| Gate driver | FD6288
