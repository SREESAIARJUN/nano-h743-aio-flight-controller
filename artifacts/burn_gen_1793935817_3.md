# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Scope and Assumptions

I don't have the Job #26 spec sheet, so the design is parameterized. Every value marked ⚙ is a default you should replace with your measured data.

| Item | Assumed value ⚙ |
|---|---|
| Motors | Gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A/MT6701-class) |
| MCU | Cortex-M4F/M7 with FPU, ≥ 168 MHz |
| IMUs | 2× ICM-42688-P on separate SPI buses, mounted on the camera plate |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates (multirate, synchronous to the PWM timer):**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | f_pwm = 20 kHz (ISR every PWM period) | ~1.5–2 kHz |
| IMU sample + filtering | 8 kHz (ODR 8 kHz, data-ready drives a DMA read) | — |
| Velocity | 4 kHz | 60–150 Hz |
| Angle / attitude | 1 kHz | 10–30 Hz |

The bandwidths are separated by a factor of 5–10 between nested loops, which is the standard cascade rule.

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Transforms
θ_e = p·θ_m − θ_off, where p is the number of pole pairs and θ_off comes from calibration.

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Machine Model (SPMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau_e = \tfrac32 p \lambda_m i_q \equiv K_t i_q$$
