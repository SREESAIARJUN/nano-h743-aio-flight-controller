# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #48 specification, so the design below rests on the assumptions in this table. Every assumption is a named constant in the code, so you can change any of them in one place.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal PMSM, 12N14P (7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, λ ≈ 0.012 V·s |
| Sensing | Inline/low-side current sensing (2 phases), 14-bit absolute encoder per joint |
| MCU | Cortex-M4F/M7 with FPU (e.g., STM32G4/H7) |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz |
| Bus voltage | 12–16.8 V (4S) |

Loop rates:

- **Current (FOC):** 20 kHz, in the ADC-trigger ISR.
- **Rate (gyro):** 4 kHz. Gyro samples at 8 kHz, filtered and decimated by 2.
- **Attitude:** 1 kHz.
- **Cogging adaptation:** runs inside the 4 kHz rate task.

### 1.1 PMSM model in the rotor (dq) frame

$$
v_d = R i_d + L_d \frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R i_q + L_q \frac{di_q}{dt} + \omega_e (L_d i_d + \lambda)
$$

$$
