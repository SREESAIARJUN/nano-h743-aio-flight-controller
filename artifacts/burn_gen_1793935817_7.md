# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Compensation, and Dual-IMU Vibration Rejection

**Note on context:** I don't have the specification for "Job #19". The design below therefore uses the explicit, typical assumptions in §0. Every numeric parameter is isolated in a config struct so you can substitute your actual motor, encoder, MCU and airframe data.

---

## 0. Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), one per joint |
| Current sense | 2-phase low-side shunts, 12-bit ADC synchronized to PWM centre |
| MCU | STM32G4/H7
