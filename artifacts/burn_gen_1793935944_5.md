## 0. Architecture Decision and Design Conflicts

### 0.1 Architecture

The H743 does **not** drive the bridges directly. ArduPilot has no field-oriented or 6-step motor control firmware for the H7. The correct architecture is:

```
6S Battery ─► Power stage (shared bus, shunt) ─► 4× [ESC MCU + 3-ph gate driver + 6 FETs] ─► Motors
                                                     ▲ Bi-dir DShot600 (1 wire each)
STM32H743VIT6 (ArduPilot, 480 MHz) ──────────────────┘
```

| Function | Assumed part / class |
|---|---|
| ESC MCU | AT32F421K8U7 or STM32G071, running AM32 (supports bi-directional DShot and 48 kHz PWM) |
| Gate driver | FD6288Q-class three-phase half-bridge driver with bootstrap |
| MOSFET | 40 V N-channel, R_DS(on),max ≤ 1.2 mΩ @ 25 °C, PDFN 5×6, dual-side-cooled preferred |
