# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #52): Power-Stage Loss Model, Thermal Budget, Bidirectional DShot600 DMA Plan, and Reference Netlist

## 0. Architecture Clarification and Key Findings

**Architecture.** The STM32H743 runs ArduPilot as the flight controller. It does not commutate the motors. The 4-in-1 ESC uses one dedicated ESC MCU per motor channel, which is standard practice. This document assumes an AM32-class MCU on each channel (STM32G071 or AT32F421 class). The H743 talks to those four MCUs over bidirectional DShot600.

**Key findings.**

1. **80A per channel on a 20×20 mm board is an adiabatic burst rating only.** With all four channels at 80A, the board reaches thermal limits in about 0.5–1.5 s. The defensible continuous rating is roughly 25–35A per channel with prop-wash cooling.
2. **Paralleling 2 MOSFETs per switch position is required** to make the 80A burst target credible. It roughly halves conduction loss.
3. **The DShot DMA allocation fits easily on the H743.** The DMAMUX removes the F4/F7-style stream conflicts. Only 4 DMA streams are needed for motors.

## 2. Conduction Loss Model (6-Step Trapezoidal, Synchronous Rectification)

### 2.1 Conduction topology

In each 60° commutation sector:
- One phase is held on (high-side or low-side).
- One phase is PWM'd complementarily.
- One phase floats.

With synchronous rectification, phase current always flows through exactly one high-side and one low-side channel, whatever the duty cycle D. Therefore:

$$P_{cond,ch} = I_{ph}^2 \cdot \frac{2\,R_{ds}(T_j)}{N_p}$$

### 2.2 Temperature correction

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)] = 1.2\,\text{m}\Omega \times (1 + 0.0045 \times 85) = 1.66\,\text{m}\Omega$$

### 2.3 Per-channel result at 80A

| Case | Calculation | P_cond per channel |
|---|---|---|
| N_p = 1 | 6400 × 2 × 1.66 mΩ | **21.2 W** |
| N_p = 2 | 6400 × 2 × 0.83 mΩ | **10.6 W** |

### 2.4 Additional conduction-path losses

**PCB copper:**

$$P_{cu} = I^2 R_{cu} = 6400 \times 0.5\,\text{m}\Omega = 3.2\,\text{W per channel}$$

**Bus shunt.** Battery current is approximately D·I_ph per channel. At full throttle (D ≈ 1), the total battery current is about 320A burst:

$$P_{shunt} = 320^2 \times 0.25\,\text{m}\Omega \approx 25.6\,\text{W}$$

This is unacceptable. Use one shunt per channel, a 0.1 mΩ shunt, or a Hall-effect sensor. With per-channel 0.25 mΩ shunts, the loss is 1.6 W per channel.

### 2.5 Thermal runaway check

R_ds(on) rises with temperature, so the loss and junction temperature must be solved together:

$$T_j = T_a + R_{th}\,P(T_j)$$

This converges only if

$$R_{th} \cdot I^2 \cdot 2R_{ds,25}\,\alpha / N_p < 1$$

## 3. Switching Losses at 48 kHz

Only the PWM'd leg hard-switches.
- **Turn-on/off edges:** carried by the high-side FET.
- **Dead-time freewheeling:** carried by the low-side body diode.
