# STM32H743 Nano FC + 4-in-1 ESC: Power, Thermal, and DShot Architecture (Job #54)

## 0. Scope and Key Finding

**Architecture.** The H743 runs ArduPilot and does not commutate motors. It sends bidirectional DShot600 to four ESC MCUs (AM32-class, for example an STM32G071 or AT32F421). Those MCUs run 48 kHz complementary PWM into 12 MOSFETs.

**Key finding:** 80 A per motor is thermally a **burst rating of only a few seconds** on a 30×30 mm board. Continuous capability with this design is roughly 15–20 A per motor. The derivation is in Section 3. The rating should be specified as "80 A / ≤2 s, all four motors" in documentation, not as continuous.

**Assumed parameters.** Replace these with your datasheet values. All equations are kept parametric so you can substitute.

| Symbol | Value | Note |
|---|---|---|
| V_bus | 25.2 V | 6S, fully charged |
| I_ph | 80 A | Phase current, burst |
| R_ds(on),25 | 2.0 mΩ (max) | 40 V, 3.3×3.3 DFN class |
| k_T | 1.5 | R_ds multiplier at T_j ≈ 100 °C |
| t_r + t_f | 30 ns | With ~1 A gate driver (FD6288-class) |
| Q_rr | 40 nC | Body diode |
| t_dt | 200 ns | Dead time per edge |
| V_f | 0.8 V | Body diode |
| Q_g | 40 nC at 10 V | |
| Q_oss | 30 nC | |
| f_sw | 48 kHz | |

## 1. Conduction Losses (80 A Burst)

**Topology.** In 6-step trapezoidal drive with synchronous rectification, there are always exactly **two FETs in series** in the current path:
- During the on-phase: the high-side FET of the PWM leg plus the low-side FET of the return leg.
- During freewheel: the low-side FET of the PWM leg plus the low-side FET of the return leg.

**Per ESC channel:**

$$P_{cond} = 2\, I_{ph}^2\, R_{ds(on)}(T_j), \qquad R_{ds(on)}(T_j)=R_{25}\,[1+\alpha(T_j-25)]$$

With R = 2.0 mΩ × 1.5 = 3.0 mΩ:

$$P_{cond} = 2(80)^2(0.003) = \mathbf{38.4\ W\ per\ motor}$$

**Hottest single FET.** The low-side FETs carry current during both the return interval and the freewheel interval. Averaged over commutation, the worst FET carries about 1/4 of the total:

$$P_{FET,max} \approx \tfrac{1}{4}P_{cond} \approx 9.6\ \text{W}$$

**Electro-thermal feedback.** R_ds rises with temperature, which raises loss, which raises temperature. The loop is stable only if:

$$P_{cond}\,\alpha\,R_{th} < 1$$

Iterate the R(T_j) calculation rather than using a fixed value.

## 2. Switching Losses at 48 kHz

Only the PWM leg switches. Per motor, each loss component:

| Loss | Formula | Value |
|---|---|---|
| V–I overlap | ½ · V · I · (t_r+t_f) · f_sw | ½·25.2·80·30n·48k = **1.45 W** |
| Reverse recovery | Q_rr · V · f_sw | 40n·25.2·48k = **0.05 W** |
| Dead-time diode conduction | V_f · I · 2t_dt · f_sw | 0.8·80·400n·48k = **1.23 W** |
| Coss | ½ · Q_oss · V · f_sw (×2 FETs) | **0.04 W** |
| Gate drive (driver-side) | Q_g · V_gs · f_sw (×2) | **0.04 W** |
| **Total P_sw** | | **≈ 2.8 W** |

**Total per motor at 80 A:** P = 38.4 + 2.8 ≈ **41 W**.
**Total for four motors:** **≈ 165 W.**

**Design levers:**
- Dead-time loss is about the same size as overlap loss. Tune dead time down (100 ns in AM32 halves it) after checking for shoot-through on a scope.
- Raising f_sw to 96 kHz doubles P_sw but reduces ripple. At 48 kHz conduction dominates, so **R_ds(on) is the priority parameter.**
- Paralleling FETs (2 per switch) gives P_cond/2. That is the only real path to a higher continuous rating.

## 3. Thermal Model

### 3.1 Network

```
P_FET ─[Zth_jc ≈1.2 K/W]─ case ─[R_pcb_spread ≈2 K/W per FET]─ board node (C_b) ─[R_ba]─ T_air
```

### 3.2 Board Thermal Capacity

The board is 30×30 mm, 8-layer, 2 oz copper, with 12 FETs, and weighs about 8 g.

$$C_b \approx m_{Cu}c_{Cu}+m_{FR4}c_{FR4} \approx 3\text{g}(0.385)+5\text{g}(1.1) \approx 7\ \text{J/K}$$

### 3.3 Board-to-Air Resistance (Prop-Wash Convection)

Using h ≈ 75 W/m²K and A = 2 × 0.03² = 1.8×10⁻³ m²:

$$R_{ba} = \frac{1}{hA} \approx 7.4\ \text{K/W}, \qquad \tau = R_{ba}C_b \approx 52\ \text{s}$$

### 3.4 Burst Duration

The board temperature follows:

$$T_b(t) = T_a + P\,R_{ba}\,(1-e^{-t/\tau})$$

For t ≪ τ, the board heats roughly adiabatically:

$$\frac{dT_b}{dt}=\frac{P}{C_b}$$

**Budget.** T_a = 40 °C, T_j,limit = 125 °C (design limit, below the 150 °C absolute rating). The junction sits above the board by:

$$\Delta T_{jb} = 9.6\ \text{W}\times(1.2+2) \approx 31\ \text{K}$$

So the board may rise at most 125 − 40 − 31 = **54 K**.

| Scenario | P | dT_b/dt | Burst time to limit |
|---|---|---|---|
| All 4 motors at 80 A | 165 W | 23.6 K/s | **≈ 2.3 s** |
| 1 motor at 80 A, others at 20 A | 41 + 3×3 ≈ 50 W | 7.1 K/s | **≈ 7.5 s** |

### 3.5 Continuous Rating

For a 60 K board rise, R_ba allows 60 / 7.4 ≈ 8 W total, or 2 W per motor. Subtract about 0.5 W of switching and gate loss at low current, then solve:

$$I_{cont}=\sqrt{\frac{2-0.5}{2(0.003)}}\approx \mathbf{16\ A}$$

This agrees with real 20×20 and 30×30 AIO ESCs, which are typically rated 20–35 A continuous. **The 80 A figure is a marketing burst number. It must be enforced in firmware**, for example with AM32 current limiting and the ESC temperature sensor, plus ArduPilot ESC telemetry-based throttle limiting.
