## 1. FOC Current Loop (Innermost)

### 1.1 Transforms

Electrical angle: θₑ = p · (θ_m − θ_offset).

**Clarke** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\quad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 PMSM Model in the dq Frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$

Torque (surface PM, L_d = L_q):

$$\tau = \tfrac32 p\lambda_m i_q = K_t\, i_q$$

### 1.3 PI with Decoupling and Back-EMF Feedforward

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L i_q,\qquad v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e \hat L i_d + \hat\omega_e\hat\lambda_m$$

**Tuning by pole-zero cancellation** (plant 1/(Ls+R), target closed loop ω_c/(s+ω_c)):

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \quad(\omega_c = 2\pi\cdot1500)$$

Keep ω_c · T_s ≲ 0.5. Account for the 1.5·T_s PWM and computation delay by reducing ω_c if overshoot appears.

### 1.4 Voltage Limiting (Circular, d-Axis Priority)

$$V_{max} = \frac{V_{dc}}{\sqrt3}\cdot 0.95$$

$$v_d \leftarrow \text{clamp}(v_d,\pm V_{max}),\qquad v_q \leftarrow \text{clamp}\!\left(v_q, \pm\sqrt{V_{max}^2 - v_d^2}\right)$$

### 1.5 SVPWM via Min-Max Zero-Sequence Injection

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

## 2. Encoder Angle and Velocity Estimation (PLL Tracker)

Raw differentiation of a 14-bit encoder at 20 kHz gives quantization noise of Δθ/T_s ≈ 7.7 rad/s. That is unusable, so use a type-II PLL:

$$e_k = \text{wrap}_{\pi}(\theta_{m,k} - \hat\theta_k)$$

$$\hat\omega_{k+1} = \hat\omega_k + K_{i} T_s e_k$$

$$\hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_{k+1} + K_{p} e_k)$$

Gains:

$$K_p = 2\zeta\omega_n,\qquad K_i = \omega_n^2\qquad(\zeta = 1,\ \omega_n = 2\pi\cdot300)$$

## 3. Cascaded Angle → Velocity → Current Control

### 3.1 Gimbal Kinematics (Why Velocity Feedback Uses the Gyro)

The camera inertial rate is:

$$\boldsymbol\omega_c = R_{cb}(\mathbf q)\,\boldsymbol\omega_{base} + J(\mathbf q)\,\dot{\mathbf q}$$

For the Yaw(z)–Roll(x)–Pitch(y) chain, the columns of J, expressed in the camera frame, are the joint axes:
