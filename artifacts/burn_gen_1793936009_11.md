# FOC Motor Control & Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for Job #52, so this design uses the assumptions in the table below. Every one is a `constexpr` or config field in the code, so you can change them to match your hardware.

| Parameter | Assumed value |
|---|---|
| Motor | 12N14P gimbal BLDC (p = 7 pole pairs, R ≈ 5–15 Ω, L ≈ 1–3 mH) |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (e.g., AS5048A / MT6701) |
| Mechanics | Yaw → Roll → Pitch, camera on the pitch link |
| IMUs | 2× ICM-42688-P on the camera plate, mounted point-symmetric about the payload CoM |
| MCU | Cortex-M4F/M7 with single-precision FPU (STM32G4/H7 class) |
| Loop rates | Current 20 kHz, velocity 4 kHz, IMU 8 kHz ODR, attitude/angle 1 kHz |

## 1. Control Architecture

```
 Attitude setpoint q_ref (pilot / follow mode)
        │
 ┌──────▼──────┐   ω_ref (camera frame)  ┌──────────────┐  q̇_ref (joint) ┌──────────────┐ iq_ref ┌──────────────┐
 │ Angle loop  │────────────────────────►│ Inverse rate │───────────────►│ Velocity PI  │───────►│ FOC current  │──► SVPWM
 │ P + FF, 1kHz│                         │ Jacobian J⁻¹ │                │ + D, 4 kHz   │   +    │ PI, 20 kHz   │
 └──────▲──────┘                         └──────────────┘                └──────▲───────┘   │    └──────▲───────┘
        │ q̂ (fused attitude)                                                    │ ω_meas    │ iq_cog       │ id, iq
 ┌──────┴──────────────────┐                                           ┌────────┴───────┐ ┌─┴──────────┐ ┌──┴──────┐
 │ Dual ICM-42688-P fusion │──── ω_cam (filtered gyro) ───────────────►│ J⁻¹·ω_cam      │ │ Anti-cog   │ │ Clarke/ │
 │ AAF→notch→LPF→Mahony    │                                           │ + encoder PLL  │ │ Fourier FF │ │ Park    │
 └─────────────────────────┘                                           └────────────────┘ └────────────┘ └─────────┘
```

Each loop runs with a bandwidth separation of at least 5× from the loop inside it:

- Current loop: about 2 kHz.
- Velocity loop: about 150–300 Hz.
- Angle loop: about 20–40 Hz.
