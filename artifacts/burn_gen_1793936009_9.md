# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #28 specification, so this design states its assumptions explicitly (§0). Every gain is derived from motor and inertia parameters, so you only need to substitute your numbers.

## 0. Assumptions and System Architecture

| Item | Assumption (replace with your values) |
|---|---|
| Motors | 3× gimbal BLDC, e.g. GBM2804 class: 12N14P (pole pairs p=7), R≈5 Ω, L≈2 mH, Kt≈0.07 N·m/A |
| Encoders | 14-bit absolute magnetic encoder per axis (MT6701/AS5048), SPI |
| Driver | 3-phase, center-aligned PWM, inline or low-side shunts, V_bus = 12 V |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7). Uses single-precision float. |
| IMUs | 2× ICM-42688-P **both rigidly mounted on the camera plate**, placed symmetrically about the attitude center (r_B ≈ −r_A) |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates (time-scale separation ≥ 4–5× between loops):**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (PWM ISR) | ω_c ≈ 2π·1500 rad/s |
| IMU sample + vibration filters | 8 kHz (IMU ODR, DRDY interrupt) | — |
| Rate (velocity) loop | 4 kHz | ω_v ≈ 2π·60–120 rad/s |
| Attitude (angle) loop | 1 kHz | ω_θ ≈ 2π·10–25 rad/s |
| Mahony attitude estimator | 1 kHz (on decimated signals) | — |

**Feedback assignment.** In a stabilizing gimbal, the stabilization feedback is **inertial**:
- **Encoder:** commutation angle θ_e and joint-relative rate (used for cogging, friction, and back-EMF terms).
- **Camera IMU gyro:** inertial rate feedback for the velocity loop.
- **Fused attitude:** feedback for the angle loop.

```
θ_ref ─►[Angle P/PI]─► ω_ref ─►[Rate PI]─► iq_ref ─►(+)─►[Current PI dq + decoupling]─►[iPark]─►[SVPWM]─► Motor
              ▲      ω_ff ──────────────►    ▲  iq_cog(θm) + iq_fric(ω_rel) ┘          ▲
         q̂ (Mahony) ◄─ dual-IMU fuse ◄─ notch/LPF        gyro_axis              Park/Clarke ◄─ ia,ib  θe ◄─ encoder
```
