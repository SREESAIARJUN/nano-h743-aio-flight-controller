# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

---

## 0. Assumptions

I don't have the Job #38 specification, so this design uses typical brushless-gimbal values. Every value below is a `constexpr` in the code and can be replaced with the real numbers.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 class: 170 MHz, FPU, CORDIC, 3× advanced timers |
| Motor | Gimbal BLDC GBM4108: 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 3 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (MT6701 / AS5048A) over SPI |
| Current sensing | Two-phase low-side shunts with INA240-class amplifiers |
| IMUs | Two ICM-42688-P on independent SPI buses, mounted on the camera plate |
| Loop rates | Current 20 kHz · velocity 4 kHz · angle/attitude 1 kHz · IMU ODR 8 kHz |

**Variant without current sensing.** Many gimbal boards have no shunts. In that case the current loop collapses to voltage mode with v_q = R·i_q* + K_e·ω, and everything above the current loop stays the same.

## 1. FOC Inner Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at commissioning by applying v_d > 0 with θ_e = 0 and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park transform

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the d–q frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The torque is T = (3/2)·p·λ_m·i_q = K_t·i_q.

### 1.5 Current PI with pole–zero cancellation

Choose the gains so the PI zero cancels the electrical pole R/L. The closed loop then becomes first order with bandwidth ω_ci:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

Use ω_ci ≈ 2π·1.5 kHz, which keeps the bandwidth at or below f_s/10 to leave margin for the 1.5-sample PWM delay.

Decoupling feedforward:

$$v_d^{*} = \text{PI}_d - \omega_e L i_q,\qquad v_q^{*} = \text{PI}_q + \omega_e L i_d + \omega_e\lambda_m$$

### 1.6 Voltage limit (circular, d-axis priority)

$$|v_d| \le V_{max},\qquad |v_q| \le \sqrt{V_{max}^2 - v_d^2},\qquad V_{max} = \tfrac{V_{bus}}{\sqrt3}\cdot 0.95$$

Anti-windup uses back-calculation with gain K_aw = 1/K_p (rules in §2.3).

### 1.7 SVPWM via min/max zero-sequence injection

Compute the phase voltages v_a, v_b, v_c from inverse Park and inverse Clarke. Then:

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This injection is mathematically equivalent to sector-based SVPWM.

## 2. Cascaded Angle → Velocity Control

### 2.1 Mechanical plant (per axis)

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist},\qquad \dot\theta = \omega$$

### 2.2 Velocity estimation with a type-II PLL

Differentiating the encoder signal is too noisy, so velocity comes from a PLL observer. The angle error is wrapped to (−π, π]:

$$e = \operatorname{wrap}(\theta_{enc} - \hat\theta)$$
$$\hat\omega_{k+1} = \hat\omega_k + K_i^{pll} T_s\, e$$
$$\hat\theta_{k+1} = \hat\theta_k + T_s(\hat\omega_k + K_p^{pll} e)$$

The gains are K_p^pll = 2ζω_n and K_i^pll = ω_n², with ζ = 1 and ω_n ≈ 2π·300 Hz.

### 2.3 Discrete PID (used at every level)

The PID uses a filtered derivative on the measurement (not the error), back-calculation anti-windup, and setpoint weighting b:

$$P_k = K_p\,(b\,r_k - y_k)$$

$$D_k = \frac{2\tau_d - T_s}{2\tau_d + T_s}D_{k-1} - \frac{2K_d}{2\tau_d+T_s}(y_k - y_{k-1}) \quad\text{(Tustin)}$$

$$u_k^{raw} = P_k + I_k + D_k,\qquad u_k = \operatorname{sat}(u_k^{raw})$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(u_k - u_k^{raw})$$

### 2.4 Gain design (velocity loop at 4 kHz)

Treat the closed current loop as unity and the plant as K_t/(Js). Pick the crossover ω_cv and place the PI zero at ω_cv/4:

$$K_{p,v} = \frac{J\,\omega_{cv}}{K_t},\qquad K_{i,v} = K_{p,v}\,\frac{\omega_{cv}}{4}$$

Use ω_cv ≈ 2π·150 Hz. Phase margin is about 76° before the encoder and PLL delays are counted.
