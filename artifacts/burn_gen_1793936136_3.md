# High-Frequency FOC Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original specification for "Job #7", so I've stated every assumption explicitly below. Each assumption is a single constant in the code, so you can swap in your real values.

---

## 0. Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 class (170 MHz, single-precision FPU, CORDIC). The code is portable C++17. |
| Motors | Gimbal BLDC, 12N14P, so pole pairs p = 7. R = 5.6 Ω (line-to-neutral), L = 2.2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701 class), one per axis |
| IMUs | 2 × ICM-42688-P on the camera payload, SPI at 24 MHz, ODR 8 kHz, each in a known mounting rotation |
| Loop rates | Current loop 20 kHz (PWM-synchronous). Velocity loop 4 kHz. Angle loop 1 kHz. IMU fusion runs at 8 kHz for rates and 1 kHz for attitude. |
| Topology | Yaw → Roll → Pitch (outer to inner), camera on the pitch link |
