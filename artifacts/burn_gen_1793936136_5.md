# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Design Assumptions

I don't have the Job #32 specification, so the design rests on the baseline below. Every assumption is a named constant in the code, so you can substitute your real values directly.

| Item | Assumed value |
|---|---|
| Motors | 3× outrunner gimbal BLDC, 12N14P, so pole pairs p = 7 |
| Phase parameters | R = 5.6 Ω (line-to-neutral), L = 1.8 mH, Kt ≈ 0.06 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701 class) |
| Current sensing | 2-shunt or inline, ADC synchronised to PWM centre |
| MCU | STM32G474 class: 170 MHz Cortex-M4F with FPU and CORDIC |
| PWM | 20 kHz centre-aligned |
| Current loop | 20 kHz |
| Rate loop | 4 kHz |
| Angle loop | 1 kHz |
| IMUs | 2× ICM-42688-P on SPI, 8 kHz ODR, gyro ±1000 dps, accel ±8 g |
