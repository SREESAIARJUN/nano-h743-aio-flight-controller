# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #56)

## 0. Design Assumptions

I don't have the Job #56 specification, so these are typical brushless-gimbal values. Every one is a parameter in the code, so you can substitute your own.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (12 slots, 14 poles, so p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A, MT6701 or similar), one per axis |
| Current sensing | 2 or 3 low-side shunts with an inline amplifier (a voltage-mode fallback is described in §1.5) |
| MCU | STM32G4 / H7 class with single-precision FPU, centre-aligned PWM |
| PWM / current loop | 40 kHz PWM, 20 kHz current loop (every 2nd PWM period) |
| IMU | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Rate loop | 4 kHz (decimating the 8 kHz IMU stream by 2) |
| Attitude loop | 1 kHz |
| Kinematic chain | Yaw (outer) → Roll → Pitch (inner, carries the camera) |

**Loop bandwidth hierarchy.** Each loop needs a factor of about 5–10 in bandwidth over the next:

- Current loop: f_c ≈ 1.5–2 kHz
- Rate loop: f_ω ≈ 80–150 Hz
- Attitude loop: f_θ ≈ 10–25 Hz

## 1. FOC Inner Loop

### 1.1 Reference Frames

The electrical angle comes from the mechanical encoder angle θ_m and a calibrated offset θ_0:

```
θ_e = p·θ_m − θ_0   (mod 2π)
```

**Amplitude-invariant Clarke transform** (assuming i_a + i_b + i_c = 0):

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

**Park transform:**

```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

**Inverse Park transform:**

```
v_α = v_d cos θ_e − v_q sin θ_e
v_β = v_d sin θ_e + v_q cos θ_e
```

### 1.2 Motor Model in the dq Frame (Surface PMSM, L_d ≈ L_q = L)

```
L di_d/dt = v_d − R i_d + ω_e L i_q
L di_q/dt = v_q − R i_q − ω_e L i_d − ω_e λ_m
τ_e = (3/2) p λ_m i_q = K_t i_q
```

### 1.3 Current PI Controller with Decoupling and Back-EMF Feedforward

The PI gains are chosen by pole-zero cancellation of the RL plant, with ω_c = 2π f_c:
