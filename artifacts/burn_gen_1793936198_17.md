# STM32H743 Nano AIO with 4-in-1 ESC (Job #11): Power, Thermal, and DShot Architecture

## 0. Assumptions and Feasibility Verdict

No Job #11 specification package was provided, so this model rests on the assumptions below. Every equation is parametric, so you can substitute real datasheet values.

| Parameter | Assumed value | Rationale |
|---|---|---|
| Battery | 6S LiPo, V_bus,max = 25.2 V | Worst case for switching loss |
| Board | 20 × 20 mm (M2 mounting), 8-layer, 2 oz outer / 1 oz inner | "Nano" class |
| Burst spec | **80 A per motor channel**, ≤ 10 s | As stated |
| MOSFETs | 24× 40 V N-ch, PDFN 3.3×3.3 | Largest footprint that fits 24 FETs on 20×20 mm |
| R_DS(on) | 3.0 mΩ max at 25 °C, normalised ×1.6 at T_j = 125 °C | Typical for 40 V in 3×3 mm |
| Gate driver | FD6288Q-class three-phase driver, one per motor | Common AM32/BLHeli_32 topology |
| ESC MCUs | 4× AT32F421 / STM32G071 running AM32, 48 kHz PWM | H743 is the FC; it does **not** drive the bridges directly |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM | AM32 default |

> **Verdict:** 80 A per channel on a 20×20 mm board is **not thermally sustainable**. The math below shows that a single-channel burst survives about 1–2 s, and a four-channel burst survives under 0.5 s, before board temperature exceeds 110 °C. Section 4 gives the design changes needed to make the spec achievable.

## 1. Conduction Loss Model

### 1.1 Current path
With 6-step complementary PWM, at any instant the motor current flows through **exactly two FETs**:
- the PWM-leg FET (high side during D, synchronous low side during 1−D), and
- the static low-side FET on the return phase.

So the instantaneous conduction loss per channel is:

$$P_{cond} = 2\, I_{rms}^2\, R_{DS(on)}(T_j)$$

### 1.2 Ripple contribution
The phase-current ripple at 48 kHz, assuming line-to-line inductance L_LL ≈ 30 µH and worst-case D = 0.5:

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{LL}\, f_{sw}} = \frac{25.2 \times 0.25}{30\,\mu\text{H} \times 48\,\text{kHz}} = 4.38\ \text{A}$$

$$I_{rms}^2 = I_{DC}^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 1.6 \approx 6402\ \text{A}^2$$

The ripple adds only 0.025%, so it can be neglected at 80 A.

### 1.3 Temperature-coupled resistance

$$R_{DS(on)}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right], \quad \alpha \approx 0.006\ \text{K}^{-1}$$
