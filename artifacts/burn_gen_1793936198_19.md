## 0. Architecture Clarification and Assumptions

### 0.1 Architecture

ArduPilot on the STM32H743 does **not** perform motor commutation. The H743 is the flight controller. It emits DShot600 frames to **four independent ESC MCUs** (e.g., AT32F421 or STM32G071 running AM32 or BLHeli_32). Each ESC MCU drives a 3-phase gate driver and six MOSFETs. The bidirectional DShot eRPM telemetry returns on the same wire.

```
           ┌──────────────── STM32H743 (ArduPilot) ────────────────┐
 IMU/Baro ─┤ SPI/I2C      TIM3_CH3 TIM3_CH4 TIM5_CH1 TIM5_CH2      │
           └──────────────────┬────────┬────────┬────────┬─────────┘
                       DShot600 bidir (open-drain-tolerant, 3V3)
                    ┌─────────┴─┐ ┌────┴────┐ ┌─┴───────┐ ┌──┴──────┐
                    │ ESC MCU 1 │ │ ESC MCU 2│ │ ESC MCU 3│ │ ESC MCU 4│
```

## 1. Conduction Loss Model

### 1.1 Current Paths in 6-Step Commutation with Synchronous PWM

During each 60° commutation sector, two legs are active:

- **PWM leg:** the high-side FET conducts for duty D. The complementary low-side FET conducts the freewheel current for (1−D).
- **Return leg:** the low-side FET conducts continuously (100%).

Per-sector conduction loss, ignoring dead time:

$$
P_{cond,ch} = I^2 R_{ds}(T_j)\,[\,D + (1-D) + 1\,] = 2\,I^2 R_{ds}(T_j)
$$

The result is **independent of D**. This is a key property of synchronous rectification.

### 1.2 Temperature Dependence

$$
R_{ds}(T_j) = R_{ds25}\,[1 + \alpha (T_j - 25)]
$$
