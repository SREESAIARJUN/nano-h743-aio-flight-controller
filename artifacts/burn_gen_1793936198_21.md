# STM32H743 Nano AIO Flight Controller + 4-in-1 ESC: Design Package (Job #1)

## 0. Architecture Decisions and Assumptions

Every number below follows from these assumptions. If an assumption is wrong, change it and recompute.

| Parameter | Assumed value | Note |
|---|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max | 40 V FET class |
| Board | 30.5 × 30.5 mm, 8-layer, 2 oz on power layers | See the warning below |
| Commutation | 6-step trapezoidal, synchronous rectification, complementary PWM | AM32 / BLHeli_32-style |
| f_sw | 48 kHz | |
| MOSFET (example class) | 40 V, R_DS(on) = 1.2 mΩ @ 25 °C / V_GS = 10 V, PDFN 5×6 | Substitute your datasheet values |
| Burst current | 80 A phase RMS per motor, all 4 motors simultaneously | Worst case |
| Ambient (in-frame) | 40 °C | |
| T_j limit | 125 °C design limit | 150 °C absolute |

**Architecture choice.** The H743 runs ArduPilot and does not commutate the motors. Each motor gets a dedicated ESC MCU (AT32F421 or STM32G071 running AM32) plus a 3-phase gate driver (FD6288Q class) and 6 FETs. The H743 talks to the ESC MCUs over bidirectional DShot600. This is the only industry-standard way to get 48 kHz commutation alongside a 400 Hz+ ArduPilot loop without a hard real-time conflict.

**Board-size warning.** "80 A burst" on a true 20×20 mm nano board is not physically credible for more than a fraction of a second; the thermal capacitance is too small (see §3). This document therefore uses 30.5×30.5 mm. Section 3.6 shows the 20×20 numbers so the trade is explicit.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,\left[1+\alpha\,(T_j-25)\right],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 125 °C:

$$R_{DS(on)} = 1.2\,\text{mΩ}\times 1.6 = 1.92\ \text{mΩ}$$

A design value of **1.9 mΩ** is used below. This creates positive feedback, so the thermal solution in §3 must be iterated.

### 1.2 Per-channel instantaneous conduction

In 6-step drive with synchronous rectification, two legs are active at every instant. Current always flows through exactly one FET in each active leg: the high-side (HS) during PWM-on, the low-side (LS) during PWM-off.

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{DS(on)}(T_j)$$

$$P_{cond,ch} = 2 \times 80^2 \times 1.9\times10^{-3} = \mathbf{24.3\ W}$$

### 1.3 Per-FET average (what actually heats each die)

Each FET is active for 1/3 of the electrical period. At realistic eRPM (above 1 kHz electrical), the commutation period is much shorter than the die-to-board time constant (roughly 10–50 ms), so the die sees the average:

$$\bar P_{cond,FET} = \frac{P_{cond,ch}}{6} = \frac{24.3}{6} \approx \mathbf{4.05\ W}$$

Low-eRPM caveat: at startup or stall, one FET pair can carry DC for tens of milliseconds. In that case use the single-FET peak of I²R = 12.2 W against Z_th(t), not R_th.

### 1.4 Copper and shunt losses (often forgotten)

- **Phase traces.** Assume 10 mm of path at 2 oz, 4 parallel layers, 4 mm wide.
  - R ≈ ρL/(wt·n) = (1.72e-8 × 0.01)/(0.004 × 70e-6 × 4) ≈ 0.154 mΩ, rising to about 0.19 mΩ hot.
  - P = 80² × 0.19e-3 × 2 legs ≈ **2.4 W per channel**.
- **Battery-side bus.** I_bat ≈ I_ph × D. At full burst, D ≈ 0.9, so the bus carries about 4 × 72 = 288 A total. That is a separate, severe XT60/pad problem. Assume 0.3 mΩ total, giving about **25 W across the bus copper**. Use thick pads and soldered battery leads directly at the input caps.
- **Current shunt** (if used, 0.25 mΩ on the common return): 288² × 0.25e-3 ≈ 20 W. **Recommendation:** use one shunt per ESC (≈ 1.3 W each), or a Hall/FET-R sensing approach.

## 2. Switching Loss Model at 48 kHz

In 6-step drive, only one leg is PWM-switching at a time (hard-switched HS turn-on and turn-off).

### 2.1 V–I overlap

$$P_{sw} = \tfrac12\,V_{bus}\,I_{ph}\,(t_r+t_f)\,f_{sw}$$

With t_r + t_f = 40 ns (FD6288-class driver at about 1.5 A peak, 4.7 Ω R_g):

$$P_{sw} = 0.5\times25.2\times80\times40\text{e-9}\times48\text{e3} = \mathbf{1.94\ W}$$

### 2.2 Dead-time body-diode conduction

$$P_{dt} = 2\,V_F\,I_{ph}\,t_{dt}\,f_{sw} = 2\times0.8\times80\times200\text{e-9}\times48\text{e3} = \mathbf{1.23\ W}$$
