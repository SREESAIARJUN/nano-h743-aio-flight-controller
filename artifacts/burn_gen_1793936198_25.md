# STM32H743 FC + Nano 4-in-1 ESC (Job #3): Architecture, Loss Model, DShot DMA Plan, Netlists

## 0. Scope and Assumptions

This design involves two separate processors:

1. **Flight controller (STM32H743, ArduPilot):** generates bidirectional DShot600 and decodes eRPM telemetry.
2. **4-in-1 ESC:** each channel has its own MCU (e.g., STM32G071 / AT32F421 running AM32 or BLHeli_32) that generates the **48 kHz** 3-phase PWM.

The H743 never drives gates. The switching and thermal model therefore applies to the ESC power stage, and the DMA model applies to the H743.

No MOSFET part number was specified, so every number below uses a **parameterized reference FET**. Substitute your datasheet values into the equations. The formulas are the deliverable; the numbers are worked examples.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current Path

In 6-step commutation with complementary PWM, two phase legs carry the full phase current at every instant:

- **PWM leg:** the high-side conducts for D, then the low-side (synchronous rectifier) conducts for 1−D. The leg carries I_ph 100% of the time.
- **Return leg:** the low-side is held ON.

The dead-time diode interval is handled separately in §2. The equivalent model is therefore **two R_DS(on) in series, continuously**, independent of duty:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{DS}(T_j), \qquad R_{DS}(T_j)=R_{25}\left[1+\alpha\,(T_j-25)\right]$$

Per-FET average: each FET is active in the conduction path for about 1/3 of an electrical cycle, so

$$P_{FET,avg}\approx \frac{P_{cond,ch}}{6}$$

The worst-case instantaneous load on one FET is still I²R for the full 60°/120° sector. This instantaneous value is what matters for Z_th transients.
