# STM32H743 AIO (4-in-1 ESC) Nano Flight Controller: Systems Architecture Package (Job #34)

## 0. Architectural Assumptions

An STM32H743 cannot directly commutate four BLDC motors and run ArduPilot at the same time. The established and recommended partition is:

| Block | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100), 480 MHz | ArduPilot, bidirectional DShot600 master |
| ESC MCUs (×4) | AT32F421 / STM32G071 class running AM32 (or BLHeli_32-compatible) | 6-step commutation at 48 kHz PWM |
| Gate drivers (×4) | 3-phase half-bridge driver, e.g. FD6288Q class | 5–12 V gate drive with built-in dead time |
| Power stage | 24× N-MOSFET, 40 V, ≤1 mΩ, 3.3×3.3 or 5×6 mm | Three half-bridges per motor |
| Bus | 6S LiPo, V_bus,max = 25.2 V | |

**Feasibility flag (stated up front):** 80 A per channel on a 20×20 or 25.5×25.5 mm board is achievable only as a time-limited burst. The thermal model in §3 quantifies the limit. ## 1. Conduction Loss Model (6-Step, Synchronous Complementary PWM)

### 1.1 Topology state
In trapezoidal 6-step commutation, two phases conduct at any instant:
- **PWM leg:** the high-side FET (duty D) alternates with its complementary low-side FET (1 − D), since synchronous rectification is enabled.
- **Return leg:** the low-side FET is held fully on.

So exactly two channels carry the phase current I at every instant, apart from dead time.

### 1.2 Equations
Temperature-corrected on-resistance:

$$R_{DS,hot} = R_{DS,25}\,[1 + k(T_j - 25)] \approx \alpha R_{DS,25}$$

Instantaneous conduction loss per ESC channel:

$$P_{cond} = I_{ph}^2\, R_{DS,hot}\,[D + (1-D)] + I_{ph}^2 R_{DS,hot} = 2\, I_{ph}^2\, R_{DS,hot}$$

The loss is independent of D because the complementary FET carries current during the off-time.

Per-FET average: each FET is active for 120° of the 360° electrical cycle, either as a switch or as the complementary rectifier.

$$\bar P_{FET} \approx \frac{P_{cond}}{6} \quad\text{(symmetric 6-step)}$$

### 1.3 Evaluation at 80 A burst
- R_DS,hot = 1.5 × 0.9 = 1.35 mΩ
- P_cond = 2 × 80² × 1.35×10⁻³ = **17.28 W per ESC channel**
- Instantaneous loss in a single conducting FET: 80² × 1.35 mΩ = **8.64 W**
- Average per FET: **2.88 W**

### 1.4 Parasitic copper and sense losses
| Element | R | Loss at 80 A |
|---|---|---|
| Low-side shunt (if single shunt) | 0.25 mΩ | 1.60 W |
| Phase pour and vias (2 oz, 6L) | ~0.3 mΩ | 1.92 W (spread over PCB) |
| Bus pour share | ~0.15 mΩ | 0.96 W |

## 2. Switching Loss Model at f_sw = 48 kHz

Only the PWM leg hard-switches. The return-leg FET is static for the whole 60° sector.

### 2.1 Hard-switching V·I overlap
$$P_{sw} = \tfrac12 V_{bus} I_{ph}(t_r + t_f) f_{sw}$$
$$= 0.5 \times 25.2 \times 80 \times 30\text{ns} \times 48\text{k} = \mathbf{1.45\ W}$$

### 2.2 Body-diode reverse recovery
$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 60\text{nC}\times25.2\times48\text{k} = 0.073\text{ W}$$

### 2.3 Dead-time diode conduction
There are two dead-time intervals per PWM period, with t_dt = 100 ns:

$$P_{dt} = V_{SD} I_{ph}\cdot 2 t_{dt} f_{sw} = 0.8\times80\times200\text{ns}\times48\text{k} = 0.614\text{ W}$$

### 2.4 Output capacitance
$$P_{oss} = \tfrac12 C_{oss} V_{bus}^2 f_{sw} = 0.5\times1.5\text{nF}\times635\times48\text{k} = 0.023\text{ W}$$

### 2.5 Gate drive
This loss is dissipated in the driver and gate resistors, not in the FETs:

$$P_g = 2\,Q_g V_{GS} f_{sw} = 2\times50\text{nC}\times10\times48\text{k} = 0.048\text{ W}$$

### 2.6 Per-channel total at 80 A, 25.2 V, 48 kHz
| Term | W |
|---|---|
| Conduction (FETs) | 17.28 |
| Switching overlap | 1.45 |
| Reverse recovery | 0.07 |
| Dead-time diode | 0.61 |
| C_oss | 0.02 |
| Gate | 0.05 |
| Copper + shunt | ~4.5 |
| **Total per ESC** | **≈ 24.0 W** |
| **All 4 at 80 A** | **≈ 96 W** |

**Key insight:** conduction dominates at about 72% of the total. Dropping PWM to 24 kHz saves only about 1 W per channel. Lowering R_DS(on) or paralleling FETs is the effective lever. With two FETs per switch, conduction loss halves to 8.6 W per channel.

### 2.7 Efficiency
P_out ≈ 25.2 × 80 × D_eff. At full throttle, D ≈ 0.95, giving 1915 W per channel. Efficiency is then η ≈ 1 − 24/1915 ≈ **98.7%**.

## 3. Thermal Model

### 3.1 Network: lumped, two-node Cauer approximation

```
P_FET ──[R_θJC=1.2 K/W]── T_case ──[R_θCB≈0.5 K/W]── T_board(C_b) ──[R_θBA]── T_amb
                                                         │
                                                       C_b ≈ 5 J/K (FETs+Cu+FR4, 25.5 mm board)
```

| Condition | R_θBA (whole board) |
|---|---|
| Still air | ~15 K/W |
| Prop-wash (≥5 m/s) | ~5 K/W |

### 3.2 Board transient (all 4 channels)
$$T_b(t) = T_a + P_{tot}R_{\theta BA}\left(1 - e^{-t/\tau}\right),\qquad \tau = R_{\theta BA} C_b$$

Assume prop-wash: τ = 5 × 5 = 25 s. Then P_tot R = 96 × 5 = 480 K, which is the steady-state asymptote. That asymptote is not survivable, which confirms that 80 A is burst-only.
