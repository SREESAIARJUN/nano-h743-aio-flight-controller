# STM32H743 FC + 4-in-1 ESC: Loss, Thermal, and Bi-Directional DShot600 Design Model

## 0. Architecture Clarification and Assumptions

**The H743 does not drive the MOSFETs.** In a 4-in-1 ESC stack, the STM32H743 is the flight controller. It generates bi-directional DShot600, and each motor channel is commutated by a dedicated ESC MCU (typically AT32F421 or STM32G071 running AM32/BLHeli_32). The 48 kHz PWM, dead-time, and gate-drive timing live on the ESC MCUs. The model below follows that split.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C: R_ds = 0.9 × (1 + 0.006 × 85) = **1.36 mΩ**.

This must be solved iteratively with the thermal model in §3, because losses raise T_j, which raises R_ds, which raises losses.

### 1.2 Current paths in 6-step synchronous PWM

At any instant, two phases conduct:

- **PWM leg:** current alternates between the high-side FET (fraction D of the period) and the synchronous low-side FET (fraction 1 − D).
  $$P_{PWM\,leg} = I_{rms}^2 R_{ds} D + I_{rms}^2 R_{ds}(1-D) = I_{rms}^2 R_{ds}$$
- **Return leg:** the low-side FET is on for the full 60° sector.
  $$P_{ret} = I_{rms}^2 R_{ds}$$

So the per-motor conduction loss is:

$$P_{cond,motor} = 2\,I_{rms}^2\,R_{ds}(T_j)$$

### 1.3 Ripple correction

For a phase-to-phase inductance L = 15 µH, worst-case ripple occurs at D = 0.5:

$$\Delta I = \frac{V_{bus} D(1-D)}{L f_{sw}} = \frac{25.2 \times 0.25}{15\,\mu H \times 48\,kHz} = 8.75\ \text{A}_{pk\text{-}pk}$$

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 6.4 \approx 6406\ \text{A}^2$$

The ripple adds about 0.1%, so it is negligible at 48 kHz.

## 2. Switching Loss Model at 48 kHz

### 2.1 Transition times (from gate charge)

$$t_r \approx \frac{Q_{gd} R_g}{V_{drv} - V_{pl}} = \frac{12\,nC \times 5.5}{6.5} = 10.2\ \text{ns}$$

$$t_f \approx \frac{Q_{gd} R_g}{V_{pl}} = \frac{12\,nC \times 5.5}{3.5} = 18.9\ \text{ns}$$

Add the Q_gs2 interval and allow for layout inductance: **t_r + t_f ≈ 40 ns** (design value).

### 2.2 Loss components (PWM leg only; the return leg does not switch at f_sw)

| Mechanism | Formula | Value |
