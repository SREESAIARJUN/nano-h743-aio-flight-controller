# 3-Axis Gimbal FOC Control & Dual-IMU Fusion Design (Job #38)

I don't have the Job #38 spec sheet, so this design uses the assumptions below. Every assumption is a named constant in the code, so you can substitute the real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class (Cortex-M4F/M7, single-precision FPU) |
| Motors | GBM2804-class, 12N14P (7 pole pairs), R ≈ 5.6 Ω, L ≈ 1.8 mH (phase-to-neutral) |
| Commutation encoder | 14-bit magnetic (AS5048A / MT6701) per axis |
| IMUs | 2 × ICM-42688-P on the camera payload, SPI at 24 MHz, DRDY-triggered DMA |
| Loop rates | Current/FOC 20 kHz, IMU and filters 8 kHz, velocity 4 kHz, angle/attitude 1 kHz |
| Bus | 12–16.8 V (3S/4S) |

---

## 1. Control Architecture

```
            1 kHz                    4 kHz                      20 kHz
q_ref ──► [Angle P + ω_ff] ──ω_ref──► [Velocity PI] ──i_q,fb──►(+)──► [FOC current PI] ──► SVPWM ──► Motor
              ▲                          ▲                       ▲            ▲
              │ attitude error           │ joint rate            │ i_q,cog    │ θ_e (encoder)
         Mahony AHRS ◄── fused gyro/acc ◄┴── J⁻¹(q)·ω_body       │
              ▲                                     Anti-cogging LMS (Fourier, f(θ_m))
     Dual-IMU fusion ◄── notch/LPF ◄── ICM-42688-P ×2 (on-chip AAF)
```

**Sensor roles:**
- The encoder handles commutation only, plus a backup rate estimate.
- The gyro provides inertial rate feedback for the velocity loop. This is what actually stabilizes the payload against base motion.
- The AHRS provides the absolute angle feedback.
