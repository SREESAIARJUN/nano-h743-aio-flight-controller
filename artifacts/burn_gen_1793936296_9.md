## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 24N22P (GM4108-class). Pole pairs p = 11, R = 10 Ω, L = 4 mH (phase-equivalent), K_t ≈ 0.08 N·m/A |
| Encoders | 14-bit magnetic (AS5048A / MT6701) on each axis, SPI read at the current-loop rate |
| MCU | STM32G4 @ 170 MHz with single-precision FPU. One MCU drives all 3 axes via TIM1/TIM8/TIM20. The code is per-axis, so it also works with one MCU per axis. |
| Bus voltage | V_bus = 12–16 V, measured every cycle |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, ±2000 dps / ±4 g |
| Gimbal order | Yaw (handle side) → Roll → Pitch (camera side) |

Loop rates:

| Loop | Rate | Trigger | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | ADC injected end-of-conversion, center-aligned PWM | ~1.5 kHz |
| Velocity | 5 kHz | Every 4th current ISR | ~150 Hz |
| Attitude (angle) | 1 kHz | Decimated from 8 kHz IMU data-ready | ~15–25 Hz |
| IMU filtering | 8 kHz | IMU INT1 data-ready | — |

Keep each loop's bandwidth at least 5–10× below the loop inside it so the cascade stays separable.

## 1. FOC Current Loop

### 1.1 Transforms
Use the amplitude-invariant Clarke transform with two measured phase currents:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

The electrical angle comes from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}})$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant (surface-mount PMSM)
$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 1.3 PI with decoupling and back-calculation anti-windup
Pole-zero cancellation with crossover frequency ω_c gives:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$
