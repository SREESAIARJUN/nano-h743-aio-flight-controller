# Job #55: 3-Axis Gimbal FOC Control, Anti-Cogging Compensation, and Dual-IMU Fusion

**Note:** I don't have the Job #55 spec, so Section 0 states the assumptions. All equations are parameterized, so you can substitute your real motor and frame values.

---

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 @ 170 MHz (FPU, CORDIC). Any Cortex-M4F/M7 works. |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Current sense | 2 inline/low-side shunts per motor (a voltage-mode fallback is given in §1.6) |
| Encoders | 14-bit magnetic (AS5048A / MT6701) on each joint |
| Gimbal order | Yaw (outer) → Roll (middle) → Pitch (inner, camera) |
| IMU-A | ICM-42688-P on the camera plate (stabilization reference) |
| IMU-B | ICM-42688-P on the camera plate (redundant/fused), or on the base for disturbance feedforward. Both cases are covered. |

**Loop rates**

```
 IMU ODR 8 kHz ─► Vibration filters ─► Dual fusion ─► Attitude (AHRS) 1 kHz
                                                          │
 Attitude loop (P/PI, 1 kHz) ─► camera-rate cmd ─► J⁻¹(q) ─► joint-rate cmd (+ base-rate FF)
                                                          │
 Velocity loop (PI, 5 kHz) on PLL encoder velocity ─► i_q* (+ cogging FF + accel FF)
                                                          │
 Current loop (PI + decoupling, 20 kHz, PWM-synced) ─► SVPWM
```

**Bandwidth separation:** each inner loop should be at least 5–10× faster than the loop around it.

| Loop | Target bandwidth |
|---|---|
| Current | f_c ≈ 1.5–2 kHz |
| Velocity | f_v ≈ 150–250 Hz |
| Attitude | f_θ ≈ 20–40 Hz |
