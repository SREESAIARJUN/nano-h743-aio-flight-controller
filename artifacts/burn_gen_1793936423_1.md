## 0. Design Assumptions

| Item | Assumed value |
|---|---|
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 3 mH, Kt ≈ 0.08 N·m/A |
| Position sensor | 14-bit magnetic encoder per axis (AS5048A / MT6701) |
| Current sensing | 2 or 3 low-side shunts per motor |
| MCU | STM32G4/H7 class with FPU (single-precision float) |
| PWM / current loop | 20 kHz, center-aligned. FOC runs in the ADC-injected ISR |
| Rate (velocity) loop | 4 kHz |
| Angle (attitude) loop | 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, gyro/accel ODR 8 kHz, ±2000 dps, ±16 g |
| Vibration source | Multirotor props, roughly 80–300 Hz fundamental plus harmonics |

**Loop rate hierarchy.** Each loop's bandwidth is kept at least about 4–5× below the loop inside it:

| Loop | Rate | Bandwidth |
|---|---|---|
| Current | 20 kHz | ~1.5 kHz |
| Rate | 4 kHz | ~150 Hz |
| Angle | 1 kHz | ~30 Hz |

## 1. FOC Current Loop

### 1.1 Transforms

Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 PMSM model in the dq frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$
$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau_e = \tfrac{3}{2}p\lambda_m i_q = K_t i_q$$

### 1.3 Current PI controller (pole-zero cancellation)

The plant per axis is $G(s)=\dfrac{1}{Ls+R}$. Choose:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The PI zero then cancels the electrical pole, and the closed loop becomes the first-order system $\omega_c/(s+\omega_c)$.

- Choose $\omega_c = 2\pi\cdot1500$ rad/s.
- This must satisfy $\omega_c \ll 2\pi f_{PWM}/10$ to account for the roughly 1.5-sample PWM/ADC delay.

Decoupling and back-EMF feedforward are added to the PI outputs:

$$v_d^* = \mathrm{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \mathrm{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Voltage limiting.**
1. The SVPWM linear range is $|v| \le V_{dc}/\sqrt3$.
2. $v_d$ has priority: $v_{q,\max} = \sqrt{V_{max}^2 - v_d^2}$.
3. Anti-windup uses back-calculation with gain $K_{aw} = 1/K_p$.

### 1.4 SVPWM (min/max zero-sequence injection)

Phase voltages:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Zero-sequence offset and duty cycles:

$$v_0 = -\tfrac12(\max + \min),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This is mathematically equivalent to sector-based SVPWM and is branch-light.

### 1.5 Velocity estimation: encoder tracking PLL

Phase error is computed through sin/cos, which avoids wrap discontinuities:

$$e = \sin(\theta_{meas} - \hat\theta)$$
$$\hat\omega_{k+1} = \hat\omega_k + K_i T e$$
$$\hat\theta_{k+1} = \hat\theta_k + T(\hat\omega_k + K_p e)$$

The gains are $K_p = 2\zeta\omega_{pll}$ and $K_i = \omega_{pll}^2$, with $\omega_{pll} \approx 2\pi\cdot400$ and $\zeta = 1$.

## 2. Cascaded Angle/Rate Controller

### 2.1 Measurement selection

For stabilization, the inner rate loop must close on **inertial** rate. Encoder rate is relative to the base, so it does not reject base motion. The rate seen by joint *i* is therefore:

$$\omega_{J,i} = \hat{\mathbf e}_i^{\,\top}\, \mathbf R_{i}^{cam}\,\boldsymbol\omega_{cam}$$

- $\hat{\mathbf e}_i$ is the joint axis.
- $\mathbf R_i^{cam}$ comes from the forward kinematics of the encoder angles of the outer joints.

The encoder serves three purposes:
- commutation,
- fallback rate (when the IMU is faulted),
- the kinematic mapping above.
