## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class, single-precision FPU, CORDIC optional |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R<sub>φ</sub> = 5.0 Ω, L<sub>d</sub> ≈ L<sub>q</sub> = 1.5 mH, K<sub>t</sub> = 0.08 N·m/A |
| Load inertia per axis | J = 2×10⁻⁴ kg·m² (motor + payload reflected) |
| Rotor sensor | 14-bit absolute magnetic encoder (e.g. AS5048A / MA732) |
| Bus | V<sub>bus</sub> = 12–16 V, 3-shunt current sensing, center-aligned PWM |
| IMUs | 2 × ICM-42688-P on camera plate, SPI, 8 kHz ODR, FIFO or DRDY interrupt |

**Loop rates and bandwidth separation.** Each outer loop is held at least 5× slower than the loop inside it.

```
Current (FOC)  : 20 kHz  ISR (synchronized to PWM center)   BW_i ≈ 2 kHz
Velocity       :  4 kHz  (decimated from PWM ISR)            BW_v ≈ 60 Hz
Angle/Attitude :  1 kHz                                      BW_θ ≈ 10 Hz
IMU sampling   :  8 kHz  → filtered → decimated to 4 kHz for velocity loop
```

**Control structure (one axis):**

```
 q_target ─► [Attitude error → joint space J⁻¹] ─► PI_θ ─► ω*  ─┐
                                   ▲                             ▼
                          q_est (Mahony, dual IMU)        PI_ω (inertial rate fb)
                                                                 │ i_q*
                       cogging FF i_cog(θ_m) ───────────────────(+)
                                                                 ▼
               encoder θ_m ─► θ_e ─► Clarke/Park ─► PI_d, PI_q + decoupling ─► SVPWM
```

## 1. FOC Current Loop

### 1.1 Transforms

Electrical angle (with encoder offset θ<sub>0</sub> found at commissioning):

$$\theta_e = \mathrm{wrap}_{2\pi}\big(p\,(\theta_m - \theta_0)\big)$$

**Clarke transform** (amplitude-invariant, with i<sub>a</sub> + i<sub>b</sub> + i<sub>c</sub> = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

With 3 shunts, pick the two phases with the **lowest** duty (longest low-side on-time). Reconstruct the third from the sum rule.

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
