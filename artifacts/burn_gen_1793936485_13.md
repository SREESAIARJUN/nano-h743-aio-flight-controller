## 0. Architectural Decision: Where the H743 Sits

An STM32H743 should not run the motor commutation itself. In the established architecture (and the only one ArduPilot supports for bi-directional DShot):

```
┌──────────────────────── FC section (STM32H743, ArduPilot) ────────────────────────┐
│ IMU / Baro / OSD / Flash / UARTs / RC in        TIM3 CH1..CH4 → DShot600 (bidir)  │
└───────────────────────────────────────────────────────┬───────────────────────────┘
                                                         │ 4 × single-wire, open-drain-style pulled-up
┌──────────────────────── ESC section (4 × AT32F421K8U7, AM32 firmware) ────────────┐
│ ESC MCU n → FD6288Q 3-ph gate driver → 6 × N-MOSFET half-bridges → motor n        │
└───────────────────────────────────────────────────────────────────────────────────┘
```

**Rationale.** ArduPilot's bdshot drives ESC MCUs that report eRPM via GCR telemetry. A single H743 cannot run four sensorless FOC/6-step loops at 48 kHz alongside ArduPilot's scheduler. AM32 on AT32F421 is the de-facto open target and supports 48 kHz PWM and bidirectional DShot natively.

> ⚠ **Reality check on "80A nano":** 80A per motor on a 20×20 / 25.5×25.5 board is a **burst rating (≤ ~5 s)**, not continuous. Section 3 shows why. Marketing should state "80A burst / ~45A continuous with airflow" unless the thermal results say otherwise.

## 2. Loss Model (per motor, then ×4)

### 2.1 Commutation Topology

In 6-step (trapezoidal) control with synchronous/complementary PWM, current always flows through **exactly two conduction paths**: the high-side FET of one phase and the low-side FET of another. During the PWM off-time the complementary FET carries current instead. Conduction loss is therefore always ≈ I²·2R regardless of duty. Duty only redistributes heat between the high-side and its complementary low-side.

### 2.2 Temperature-Dependent R_ds(on)

$$
R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]
$$

At T_j = 110 °C: R_ds = 1.0 × (1 + 0.006 × 85) = **1.51 mΩ**. This must be solved self-consistently with T_j (Section 3.3).

### 2.3 Conduction Loss

$$
P_{cond} = I_{ph}^2 \cdot 2R_{ds}(T_j) = 80^2 \cdot 2 \cdot 1.51\,\text{m}\Omega = \mathbf{19.3\ W}
$$

$$
P_{Cu} = I_{ph}^2 \cdot R_{Cu} = 6400 \cdot 0.5\,\text{m}\Omega = \mathbf{3.2\ W}
$$

### 2.4 Switching Loss (hard-switched edges, one switching leg per motor)
