# STM32H743 FC + 4-in-1 ESC: Loss, Thermal, and Bi-Directional DShot600 Architecture

## 0. Scope and Assumptions

I have no prior record of Job #41's BOM, stack-up, or MOSFET selection. Every numeric input below is therefore an **explicit, labeled assumption**. Each equation is parametric, so you can substitute datasheet values directly. Items marked **[VERIFY]** must be confirmed against real datasheets or bench data before release.

**Architectural point.** In a 4-in-1 ESC, the H743 does not generate the 48 kHz switching PWM. Each motor channel has its own ESC MCU (e.g., AT32F421 or STM32G071 running AM32/BLHeli_32), which runs commutation and 48 kHz PWM. The H743 sends DShot600 frames and receives bidirectional eRPM telemetry. The loss model below applies to the ESC power stage. The DMA/timer section applies to the H743.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent Resistance

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

The design point is T_j = 110 °C, iterated in §3.4:

$$R_{DS}(110) = 1.1\,\text{m}\Omega \times (1 + 0.0045 \times 85) = 1.52\ \text{m}\Omega$$
