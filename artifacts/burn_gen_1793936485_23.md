# STM32H743 AIO Nano FC + 4-in-1 ESC: Power-Stage, Thermal and Bi-Directional DShot Architecture

## 0. Scope and Assumptions

I don't have the original requirements for Job #33, so this design uses the baseline below. Every equation is parameterized, so you can substitute your actual MOSFET datasheet values and re-run the numbers.

| Parameter | Baseline value |
|---|---|
| Battery | 6S LiPo, V_bus max = 25.2 V |
| Burst rating | 80 A **phase current** per motor (not battery current) |
| PWM frequency | f_sw = 48 kHz, complementary (synchronous rectification) |
| Commutation | 6-step trapezoidal (AM32-style firmware) |
| MOSFET (representative 40 V, 5×6 class) | R_ds(on) = 0.9 mΩ at 25 °C; Q_g = 40 nC; Q_rr = 40 nC; C_oss(er) = 1.5 nF; V_SD = 0.8 V |

| Board | 30.5×30.5 mm, 6-layer, 2 oz (70 µm) copper |
| Ambient | 40 °C; T_j,max = 150 °C |

**Architecture.** The H743 is the flight controller only. Each motor channel has its own ESC MCU (AT32F421 running AM32), a 3-phase gate driver (FD6288Q class), and 6 MOSFETs. The H743 talks to the ESCs over bi-directional DShot600.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,\big[1+\alpha\,(T_j-25)\big],\qquad \alpha \approx 0.0065\ \text{K}^{-1}$$

At the design point T_j = 110 °C:

$$R_{ds}(110) = 0.9\ \text{m}\Omega \times 1.55 = 1.40\ \text{m}\Omega$$

### 1.2 Current path in 6-step synchronous PWM

During any 60° electrical sector, phase A is driven high (PWM duty D), phase B is held low, and phase C floats. Current flows through:

- **During on-time (D):** high-side A → motor → low-side B.
- **During off-time (1−D):** low-side A (synchronous) → motor → low-side B.

So at any instant, exactly **two channels carry the full phase current I**:

$$P_{cond,ch} = I^2 R_{ds}\,[D + (1-D)] + I^2 R_{ds} = 2\,I^2 R_{ds}(T_j)$$

This is independent of duty cycle, because synchronous rectification removes the body-diode term except during dead time.

Numerically:

$$P_{cond,ch} = 2 \times 80^2 \times 1.40\times10^{-3} = \mathbf{17.9\ W\ per\ motor}$$

### 1.3 Per-FET distribution

Over one electrical revolution, each phase spends one third of the time high-side active, one third low-side, and one third floating. When f_elec is much faster than the junction time constant (true above ~500 eRPM-Hz), the losses average out across all six FETs:

$$\bar P_{FET} \approx \frac{17.9}{6} \approx 3.0\ \text{W (conduction)}$$

> ⚠ **Stall / low-RPM exception.** At standstill or very low speed, one low-side FET carries $I^2R_{ds}$ = **9.0 W** continuously. Peak junction temperature must therefore be checked with the single-FET transient impedance Z_th(t), not the averaged value (see §3.3).

### 1.4 Parasitic copper and shunt losses

| Element | Model | Value at 80 A |
|---|---|---|
| Current shunt (0.25 mΩ, DC-bus side) | I²R, scaled by duty (worst case D → 1) | ≤ 1.6 W per channel |
| Phase trace and pad, ~0.3 mΩ round-trip | I²R | 1.9 W |
| Bus copper | I_bus² R | ~0.5 W |

**Total conduction per channel ≈ 21.9 W** (worst case).

## 2. Switching Loss Model at 48 kHz

Only the PWM'd leg switches. The parameters are V = 25.2 V, I = 80 A, f = 48 kHz.

### 2.1 V–I overlap (hard switching)

$$P_{VI} = \tfrac12 V I (t_r + t_f) f_{sw} = \tfrac12(25.2)(80)(24\,\text{ns})(48\,\text{kHz}) = \mathbf{1.16\ W}$$
