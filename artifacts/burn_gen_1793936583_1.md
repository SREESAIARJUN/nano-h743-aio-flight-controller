## 0. Architectural Clarification

The STM32H743 does not generate the 48 kHz bridge PWM. On every production 4-in-1 design it is the flight controller. Each motor channel has its own ESC MCU (AT32F421 / STM32G071 / EFM8 running AM32 or BLHeli_32/S) that drives the gate driver and performs commutation. The partition is:

| Domain | Processor | Function |
|---|---|---|
| Flight control | STM32H743VIT6 (480 MHz, LQFP100) | ArduPilot, sensor fusion, bi-directional DShot600 master, telemetry decode |
| Motor control ×4 | AT32F421K8U7 ⟨A⟩ (QFN32) running AM32 | 48 kHz complementary PWM, sensorless BEMF commutation, eRPM reply |
| Power stage ×4 | FD6288Q gate driver + 6× N-MOSFET | Three-phase half-bridges |
