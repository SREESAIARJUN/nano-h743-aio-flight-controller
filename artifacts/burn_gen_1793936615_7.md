# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the specification for Job #21, so this design is fully parameterized. Every plant constant lives in one config struct. The table below lists the assumed baseline. Replace these values with your measured ones.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A/MT6701 class) |
| Current sense | 2-shunt low-side, synchronous with PWM |
| MCU | Cortex-M4F/M7 (e.g., STM32G474 @ 170 MHz), single-precision FPU |
| IMUs | 2 × ICM-42688-P on the camera platform, separate SPI buses, shared CLKIN |
| Loop rates | Current 20 kHz · Velocity 4 kHz · IMU ODR
