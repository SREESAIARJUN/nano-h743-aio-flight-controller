## 2. FOC Current Loop

### 2.1 Transforms

Clarke (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park, with electrical angle θ_e = p·θ_m + θ_offset, where p is the number of pole pairs:

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 PMSM Model

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda)$$

Torque, with i_d* = 0 for an SPM gimbal motor:

$$\tau_e = \tfrac{3}{2} p\,[\lambda i_q + (L_d - L_q) i_d i_q] \;\Rightarrow\; K_t = \tfrac32 p\lambda$$

### 2.3 PI with Decoupling and Pole-Zero Cancellation

$$v_d^* = K_{p,d}\,e_d + K_{i,d}\!\int e_d\,dt - \omega_e L_q i_q$$

$$v_q^* = K_{p,q}\,e_q + K_{i,q}\!\int e_q\,dt + \omega_e(L_d i_d + \lambda)$$

Choose the PI zero to cancel the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c,\qquad \omega_c = 2\pi f_c$$

### 2.4 Discretization and Delay Compensation

- **Integration:** forward Euler at T_s = 1/f_pwm. The integrator uses back-calculation anti-windup:

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(v_{sat} - v_{unsat}),\qquad K_{aw} \approx 1/K_p \cdot K_i T_s \text{ scaled}$$

  (The code uses the clean form K_aw·(sat − unsat) with K_aw = K_i/K_p·T_s.)
- **Voltage limiting:** use a circular limit with q-axis priority, |v_dq| ≤ V_bus/√3 (linear SVPWM region).
- **Transport delay:** the computation-plus-PWM delay is about 1.5 T_s. Compensate it in the inverse Park transform:

$$\theta_e^{inv} = \theta_e + 1.5\,\omega_e T_s$$

### 2.5 SVPWM (Min-Max Injection, Equivalent to SVPWM)

$$v_{abc} = \text{invClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12(\max v_{abc} + \min v_{abc}),\quad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

## 3. Velocity Loop

**Plant.** Mechanical dynamics, with load inertia J and viscous friction B:

$$J\dot\omega_m = \tau_e - B\omega_m - \tau_{cog}(\theta_m) - \tau_{fric}\,\text{sgn}(\omega_m) - \tau_{dist}$$

**Control law.** PI in the torque domain:

$$\tau^* = K_{p\omega}\,e_\omega + K_{i\omega}\!\int e_\omega\,dt + \hat\tau_{cog}(\theta_m) + \hat\tau_{fric}\,\text{sgn}(\omega^*) + J\dot\omega^*_{ff}$$
