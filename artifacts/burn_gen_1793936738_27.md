# STM32H743 AIO Flight Controller + 80A 4-in-1 ESC (Job #27): Architecture, Loss Model, DShot Allocation, Netlists

## 0. Architectural Corrections and Assumptions

These points change the design, so they come first.

1. **The H743 does not commutate the motors.** ArduPilot cannot run ESC firmware. The correct architecture uses four ESC MCUs, for example AT32F421K8U7 running AM32. Each ESC MCU drives its own 3-phase gate driver. The H743 sends bidirectional DShot600 to each ESC MCU and decodes eRPM telemetry.
2. **"80A on a nano board" holds only for a burst of a few seconds.** Section 3 shows that four channels at 80A dissipate about 85 W on a board with about 5 J/K of thermal mass. That is a rise of about 17 K/s. Rate it as **80A/channel for ≤3 s (single channel ≤8 s), 40A continuous**. Do not claim 80A continuous.
3. **Form factor.** 24 power FETs plus four ESC MCUs require a **30.5×30.5 mm** ESC board stacked under the FC. A single 20×20 board cannot carry this.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance
$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha\,(T_j-25)]$$

### 1.2 Current path in 6-step with synchronous rectification
In each commutation sector, phase A is PWM'd and phase B is held low.

- **On-time (D):** current flows Bus → HS_A → motor → LS_B → GND. Two FETs conduct.
- **Off-time (1−D):** current freewheels LS_A → motor → LS_B.
