# STM32H743 Nano FC + 4-in-1 ESC: Power-Stage Thermal Model and Bidirectional DShot600 DMA Architecture

**Document:** Job #2, Design Analysis Rev A

## 0. Feasibility Findings

These conclusions follow from the math in §2–§4.

| # | Finding | Consequence |
|---|---|---|
| 1 | At 80 A per motor, total power-stage loss is about **91 W** (4 ch, Tj = 125 °C). | A 20×20 mm board cannot reject this continuously. Its continuous limit is about **25–30 A/ch** with prop-wash airflow. |
| 2 | "80 A burst" is only defensible as a **≤1–1.5 s transient** that relies on board thermal capacitance. | The burst must be specified with a duration and duty cycle, and ESC firmware must enforce current and temperature foldback. |
| 3 | The H743 runs ArduPilot. The ESCs need their own MCUs, typically 4× AT32F421 or STM32G071 running AM32/BLHeli_32. | The H743 does not commutate motors. It only generates DShot and captures eRPM telemetry. |
| 4 | Bidirectional DShot on H7 is DMA-feasible because of DMAMUX. | All 4 motors fit on one advanced timer (TIM1) with zero DMA conflicts if allocated as in §5. |

**Assumptions.** I've used a representative 40 V, 3.3×3.3 mm PQFN MOSFET, since no BOM was given. **Substitute your datasheet values** into the parameterized equations below. Every number is traceable to a symbol.

## 2. Conduction Loss Model

### 2.1 Commutation topology

Six-step trapezoidal commutation with synchronous rectification (complementary PWM):

- At any instant, **two legs** carry current.
- The PWM leg alternates: the high side (HS) conducts for D, and the low side (LS, synchronous) conducts for (1 − D).
- The return leg's LS conducts continuously for that 60° sector.

So at every instant, current flows through exactly **two channel resistances in series**, independent of D:

$$P_{cond,ESC} = 2\, I_{rms}^2 \, R_{ds(on)}(T_j)$$

### 2.2 Ripple contribution

$$\Delta I_{pp} = \frac{V_{bus}\, D(1-D)}{L_{LL}\, f_{sw}}\Big|_{D=0.5} = \frac{25.2 \times 0.25}{20\,\mu H \times 48\,kHz} = 6.56\ \text{A}$$

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 3.6 = 6403.6\ \text{A}^2$$

Ripple adds only 0.06%, so it is negligible at 48 kHz. This is one justification for the high f_sw.

### 2.3 Hot resistance

$$R_{ds(on)}(125°C) = k_T \cdot R_{25} = 1.5 \times 1.1 = 1.65\ \text{m}\Omega$$

### 2.4 Result

$$P_{cond,ESC} = 2 \times 6403.6 \times 1.65\times10^{-3} = \mathbf{21.13\ W\ per\ ESC\ channel}$$

**Per-FET distribution.** Each FET carries conduction loss for an average of 1/3 of the electrical cycle, so total/6 ≈ 3.52 W per FET on average. Instantaneous sector loss is 2× higher, which matters for low-eRPM thermal ripple.

## 3. Switching Loss Model (48 kHz)

Only the PWM leg switches. Per ESC channel, there is one hard-switched HS turn-on/off pair per PWM period.

### 3.1 V–I overlap (hard switching)

$$P_{VI} = \tfrac{1}{2} V_{bus} I_{ph} (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\,\text{ns} \times 48\,\text{kHz} = \mathbf{0.968\ W}$$

### 3.2 Reverse recovery (LS body diode → HS turn-on)

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 40\,\text{nC} \times 25.2 \times 48\,\text{k} = \mathbf{0.048\ W}$$

(The added HS current-overlap loss from I_rr is folded into t_r margin.)

### 3.3 Output capacitance

$$P_{oss} = \tfrac{1}{2} Q_{oss} V_{bus} f_{sw} \times 2 = 30\,\text{nC} \times 25.2 \times 48\,\text{k} = \mathbf{0.036\ W}$$

### 3.4 Dead-time body-diode conduction

$$P_{dt} = V_f I_{ph} (2 t_{dt}) f_{sw} = 0.8 \times 80 \times 200\,\text{ns} \times 48\,\text{k} = \mathbf{0.614\ W}$$

This is the second-largest switching term. Trimming dead time to 50 ns saves about 0.3 W/ch, but only if the driver's propagation matching (FD6288 ≈ ±20 ns) allows it without shoot-through.

### 3.5 Gate drive

The loss is dissipated in R_g and the driver, not in the FET die.

$$P_{gate} = Q_g V_{drv} f_{sw} \times 2 = 50\,\text{nC} \times 10 \times 48\,\text{k} \times 2 = \mathbf{0.048\ W}$$

### 3.6 Switching total

$$P_{sw,ESC} = 0.968 + 0.048 + 0.036 + 0.614 + 0.048 = \mathbf{1.71\ W\ per\ channel}$$
