# STM32H743 AIO + 4-in-1 ESC (Job #48): Power-Stage Loss Model, Thermal Budget, and Bidirectional DShot600 DMA Allocation

I don't have Job #48's BOM, stack-up, or layout files. This package is therefore **fully parameterized**. Every number comes from a stated assumption, so you can substitute your real datasheet values and re-run it. Values marked ⚠ must be verified against your selected parts.

---

## 0. Architecture Findings

Three issues affect everything downstream.

1. **The H743 is the flight controller, not the ESC MCU.** Each ESC channel still needs its own commutation controller (typically 4× AT32F421 / STM32G071 running AM32, or BLHeli_32-class firmware).
   - The 48 kHz PWM frequency is an ESC firmware parameter, not something ArduPilot controls.
   - The H743 only generates DShot600 and decodes the eRPM telemetry.
2. **A 20×20 mm form factor cannot hold an H743, 24 MOSFETs, and drivers on one PCB.**
   - The H743's smallest package is TFBGA100 (8×8 mm), or LQFP100 (14×14 mm).
   - This model assumes a **2-board stack**: an FC board and an ESC board, joined by an 8-pin harness.
3. **"80 A burst" is thermally a ~0.5–1 s capability on a nano board, not a continuous rating.** Section 3 quantifies this. If the requirement document implies more, it needs to be renegotiated.
