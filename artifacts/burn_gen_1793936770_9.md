# STM32H743 FC + 4-in-1 ESC (Job #12): Power-Stage, Thermal, and Bidirectional DShot Model

## 0. Scope, Architecture Correction, and Stated Assumptions

**Architecture correction.** ArduPilot on an STM32H743 cannot run 48 kHz field commutation for 4 motors (24 FETs). The H743 is the flight controller. It sends bidirectional DShot600 to **four dedicated ESC MCUs**, and those MCUs perform commutation and the 48 kHz PWM. This is the standard 4-in-1 topology, and the rest of this document assumes it.

**Assumptions.** No MOSFET, PCB stackup, or form factor was specified. All numbers below use the representative parameters listed here. Replace them with datasheet values and re-run the equations.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Burst phase current per channel | I | 80 A |
| PWM frequency | f_sw | 48 kHz |
| FET R_ds(on), 25 °C
