# STM32H743 AIO Flight Controller with 4-in-1 ESC (80 A Burst): Power-Stage Model, DShot DMA Plan, and Reference Netlist

## 0. Architecture Corrections

Three points need resolving before the math, because they change the results.

1. **The H743 does not drive the MOSFETs.** ArduPilot does not commutate motors. The only workable architecture is an all-in-one (AIO) board:
   - The **STM32H743 runs ArduPilot** and outputs bidirectional DShot600.
   - **Four ESC MCUs** run AM32 or BLHeli_32. Typical parts are STM32G071 or AT32F421.
   - Each ESC MCU feeds a **3-phase gate driver** and **6 N-MOSFETs**.

   Everything below assumes this architecture.

2. **"Nano" (20×20 mm) and 80 A burst are thermally incompatible** for anything beyond about 3 s. Section 3 shows why. I compute both a 20×20 and a 30.5×30.5 board so you can see the trade-off.

3. **"80 A" is interpreted as per-motor phase current** at the 6S peak of 25.2 V, with all four motors loaded simultaneously. This is the worst case.

**Assumed MOSFET.** I assume a generic 40 V, PDFN 5×6 class part. Substitute your actual datasheet values.

| Parameter | Value |
