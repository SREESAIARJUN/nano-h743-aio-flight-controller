# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #66): Power-Stage, Thermal, and Bidirectional DShot Architecture

## 0. Architecture Premise and Assumptions

**Architecture.** The STM32H743 does not drive the MOSFETs. A 4-in-1 ESC needs four independent hard-real-time commutation loops, each with its own complementary-PWM timer, BEMF comparator, and ADC sync. Every shipping 4-in-1 design therefore uses dedicated ESC MCUs. This design uses:

- **H743**: runs ArduPilot. Sends DShot600 and receives bidirectional eRPM telemetry over board traces.
- **4× AT32F421K8U7** (or STM32G071): each runs AM32 firmware for one motor.

## 1. Conduction Loss Model

**Current path.** The ESC uses 6-step trapezoidal drive with complementary (synchronous) PWM. Outside dead time, motor current always flows through exactly two MOSFETs in series:

- the PWM'd high-side FET, or its synchronous low-side partner, and
- the static low-side FET of the return phase.

**Per-channel conduction loss:**

$$P_{cond,ch} = 2\,I^2\,R_{DS}(T_j),\qquad R_{DS}(T_j)=R_{25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C, R_DS = 1.2 × 1.45 = **1.74 mΩ**:

$$P_{cond,ch} = 2(80)^2(1.74\times10^{-3}) = \mathbf{22.3\ W}$$

Averaged over the 6 FETs of a channel, that is about 3.7 W per FET. Each FET conducts for roughly 1/3 of the electrical cycle at about 3× that instantaneous rate.

**Temperature iteration.** Because R_DS depends on T_j, the fixed point is:

$$T_j = T_{board} + R_{th,j\text{-}b}\cdot\frac{P_{ch}(T_j)}{6}$$

Solve this numerically (3–4 iterations converge). The values above assume T_j = 125 °C, which is conservative for the burst case.
