# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

I don't have the Job #42 specification, so the design rests on the stated assumptions in §0. Every hardware-dependent constant is a parameter. Change those parameters, and the equations and code still hold.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, about 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (N_s = 12 slots, p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A/MT6701) per axis |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR = 8 kHz (gyro ±1000 dps, accel ±4 g) |
| Current sense | 2 or 3 low-side shunts, ADC triggered at PWM centre |

**Loop rates (cascade separation of about 4–5× in bandwidth):**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q PI), SVPWM, encoder read | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| Velocity PI, cogging feedforward, rate fusion | 8 kHz (IMU-synchronous) | ω_v ≈ 2π·150 rad/s |
| Angle (attitude) P/PI | 2 kHz | ω_p ≈ 2π·30 rad/s |
| Attitude estimator (Mahony) | 8 kHz | — |

Feedback roles:

- **Inertial feedback:** stabilization uses the IMU-measured camera rate and attitude for the outer loops.
- **Encoder feedback:** used for commutation (θ_e), the cogging feedforward, and as a fallback or blended velocity source.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle, with encoder offset θ₀ found at alignment:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

$$\tau_e = \tfrac32 p\lambda_m i_q \equiv K_t i_q$$

### 1.3 Decoupled PI with pole-zero cancellation

With feedforward decoupling, each axis reduces to $G(s) = 1/(Ls+R)$. Choosing

$$K_{p,c} = L\,\omega_c,\qquad K_{i,c} = R\,\omega_c$$

cancels the electrical pole at $-R/L$ and yields the closed loop $\omega_c/(s+\omega_c)$.

The control law is:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e(\hat L i_d + \hat\lambda_m)$$

Sampling-delay constraint: with the PWM update delay of $1.5T_s$, keep $\omega_c T_s \lesssim 0.2$. At 20 kHz this means $\omega_c \le 2\pi\cdot1.6$ kHz.
