# 3-Axis Gimbal FOC Control and Dual-IMU Fusion Design (Job #64)

## 0. Assumptions

I don't have the Job #64 spec, so the design rests on the baseline below. Every value is a named parameter in the code, so you can substitute your own.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, FPU, CORDIC available |
| Motors | 12N14P gimbal BLDC (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) on each axis |
| Driver | 3-phase, center-aligned PWM, 3-shunt (or 2-shunt) low-side current sensing |
| IMUs | 2× ICM-42688-P on the camera plate (A and B), SPI @ 24 MHz, gyro ODR 8 kHz |
| Platform | Multirotor, so dominant vibration comes from prop harmonics (≈ 80–400 Hz) plus frame resonances |
| Joint order | Yaw (outer, base side) → Roll → Pitch (inner, camera side) |

Loop rates and bandwidth separation (≥ 4–5× between loops):

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz | 1.5–2 kHz |
| IMU filtering | 8 kHz | n/a |
| Velocity (inertial rate PI) | 4 kHz | 60–120 Hz |
| Angle (attitude P/PI) | 1 kHz | 10–25 Hz |
