# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #48 specification, so I've used the assumptions below. Every parameter is a named constant you can replace.

| Item | Assumed value |
|---|---|
| Motors | Gimbal PMSM/BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), read at 20 kHz |
| Inverter | 3-phase, 2 low-side shunts, 20 kHz center-aligned PWM |
| IMUs | 2× ICM-42688-P, 8 kHz ODR. **IMU-P** on the payload/camera plate is the feedback sensor. **IMU-B** on the base/handle is the disturbance reference. |
| Axis order | Base → Yaw (ψ, z) → Roll (φ, x) → Pitch (θ, y) → Payload |
| MCU | Cortex-M4F/M7 with single-precision FPU |

## 1. Loop Architecture and Rates

```
            ┌────────── 1 kHz ──────────┐ ┌────── 4 kHz ──────┐ ┌──── 20 kHz ────┐
q_ref ──►  Attitude P(+I) ──► ω_ref ──► Rate PI ──► τ_ref ──► (+τ_cog_ff) ──► Current PI + FOC ──► PWM
             ▲  (quaternion err)          ▲ (IMU-P gyro,          ▲ (θ_enc)          ▲ (i_a, i_b)
             │                            │  notched/filtered)    │
         Mahony(IMU-P)              Base-rate feedforward (IMU-B)  Cogging LUT/LMS
```

Bandwidth separation, with each loop at least 4–5× faster than the loop outside it:

| Loop | Target bandwidth | Execution rate |
|---|---|---|
| Current loop | ω_ci ≈ 2π·1500 rad/s | 20 kHz |
| Rate loop | ω_cv ≈ 2π·80–150 Hz, limited by structural modes | 4 kHz |
| Attitude loop | ω_cp ≈ 2π·10–20 Hz | 1 kHz |

## 2. FOC Current Loop Equations

### 2.1 Electrical angle

θ_e = p·(θ_m − θ_off)  (mod 2π)

θ_off is found at commissioning by applying a d-axis voltage V_d at θ_e = 0 and reading the encoder.

### 2.2 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)

- i_α = i_a
- i_β = (i_a + 2 i_b)/√3

### 2.3 Park transform

- i_d = i_α cos θ_e + i_β sin θ_e
- i_q = −i_α sin θ_e + i_β cos θ_e

### 2.4 Plant in the dq frame

- v_d = R i_d + L_d di_d/dt − ω_e L_q i_q
- v_q = R i_q + L_q di_q/dt + ω_e (L_d i_d + λ_m)
