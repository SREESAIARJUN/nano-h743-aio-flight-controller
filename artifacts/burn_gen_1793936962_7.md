# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #15 spec sheet, so the design is fully parameterized and these reference values are assumed. Replace them with your own.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, FPU + CORDIC |
| Motors | GBM2804-class, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 2.5 mH |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A), SPI |
| Current sense | 2-phase low-side shunts. If absent, voltage-mode fallback is supported. |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, shared CLKIN |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, camera) |

**Loop rate hierarchy.** Keep at least 5–10× bandwidth separation between successive loops.

| Loop | Rate | Closed-loop bandwidth target |
|---|---|---|
| Current (PI, d/q) | 20 kHz (PWM-synchronous) | ~1.5 kHz
