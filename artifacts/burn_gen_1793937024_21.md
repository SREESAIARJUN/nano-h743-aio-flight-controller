# STM32H743 AIO Flight Controller with 4-in-1 ESC: Reference Design Model

## 0. Scope, Architecture Correction, and Assumptions

### Architecture correction

The STM32H743 does **not** commutate the motors.

- In every production 4-in-1 / AIO design, each ESC channel (or a pair of channels) has its own small MCU running AM32 or BLHeli_32. Examples are the STM32G071, AT32F421 and GD32E230.
- The **48 kHz PWM** is generated by the ESC MCUs.
- The H743 runs ArduPilot and emits **bidirectional DShot600** to the ESC MCUs. It receives eRPM telemetry back on the same wire.

The model below is split accordingly.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Device current waveforms (6-step, complementary PWM)

Each half-bridge leg spends the electrical cycle in three 120° intervals:

- **Sourcing:** the high-side (HS) device is PWM'd at duty D. The low-side (LS) device conducts the freewheel current for the remaining 1 − D (synchronous rectification).
- **Sinking:** the LS device is fully on.
- **Floating:** both devices are off. This is the back-EMF zero-crossing sense window.

The time-averaged I²R weighting per device is therefore:

```
P_HS = I² · R_DS(Tj) · D / 3
P_LS = I² · R_DS(Tj) · [ (1−D)/3 + 1/3 ] = I² · R_DS(Tj) · (2−D)/3
```

Summing over one leg gives P_leg = (2/3)·I²·R. Over three legs:

```
P_cond,ch = 2 · I² · R_DS(Tj)
```

This matches the physical picture: at every instant, exactly two R_DS(on) are in series with the motor current.

### 1.2 Temperature dependence

```
R_DS(Tj) = R₀ · [1 + α (Tj − 25)]
```

At Tj = 110 °C:

```
R_DS = 1.5 mΩ · (1 + 0.0045·85) = 2.07 mΩ
```
