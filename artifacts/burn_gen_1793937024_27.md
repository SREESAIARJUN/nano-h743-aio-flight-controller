# STM32H743 FC + 4-in-1 ESC: Power-Stage Model, DShot DMA Allocation, and Netlists

**Document:** Job #21, Architecture Baseline Rev A
**Scope:** 6S (25.2 V max) stack. ArduPilot on the STM32H743. AM32 on four per-channel ESC MCUs.

---

## 0. Architecture Decisions and Feasibility Flags

Three findings need sign-off before layout.

1. **The H743 cannot also be the ESC controller.** ArduPilot does not run sensorless BLDC commutation. Each motor channel therefore needs its own ESC MCU, for example an AT32F421K8 or STM32G071GB running AM32. The H743 talks to these MCUs over bidirectional DShot600.
2. **"80 A" must be a per-channel, single-motor burst rating.** On a nano form factor (20×20 or 25.5×25.5 mm), four channels at 80 A simultaneously produce about 88 W (Section 3). A board this small can carry that for only about 4 s. The rating must be specified as "80 A burst, ≤ 5 s, per channel" and paired with a much lower continuous rating (computed in Section 4).
3. **All component values below are design-class assumptions.** They must be replaced with the selected datasheet values. They are representative of a 40 V, 5×6 mm PQFN, ~1 mΩ MOSFET. Every equation is parameterized so you can substitute directly.

### Assumed parameters

| Symbol | Meaning | Value |

## 1. Commutation Model

The ESC uses 6-step trapezoidal commutation with complementary (synchronous-rectified) PWM. At any instant, one phase is high-side PWM, one is low-side on, and one floats for back-EMF sensing.

Each half-bridge conducts for 120° of every 360° electrical, as high side in one sector and low side in another.

Within the PWM leg, during each sector:
- The high-side FET conducts for duty D.
- The low-side (sync) FET of the same leg conducts for 1 − D, less dead time.

The motor current path therefore always contains exactly two R_DS(on) in series:

```
Conduction path R = 2 · R_ds(T)
```

## 2. Conduction Loss Model

### 2.1 Temperature-dependent resistance

```
R_ds(T_j) = R_ds,25 · [1 + α (T_j − 25)],    α = (k_T − 1)/100 = 0.0055 /K
R_ds(125 °C) = 0.95 mΩ × 1.55 = 1.47 mΩ
```

### 2.2 Phase RMS current

With a flat-top 120° trapezoid and ripple neglected (justified in 2.4), I_rms,phase = I_pk·√(2/3). The conduction path always carries I_pk, so the channel loss uses I_pk directly.

### 2.3 Per-channel and per-FET conduction loss

```
P_cond,ch = I_pk² · 2 · R_ds(T_j)
```

The per-FET split at duty D, averaged over an electrical cycle, is:

```
P_HS = (1/3) · I_pk² · R_ds · [D + 1]/2 ... (PWM sector D, unipolar sector 1)
P_LS = (1/3) · I_pk² · R_ds · [(1−D) + 1]/2
```

On average, each of the 6 FETs carries about 1/6 of P_cond,ch.

### 2.4 Numbers at 80 A, T_j = 125 °C

| Quantity | Value |
|---|---|
| P_cond,ch = 80² × 2 × 1.47 mΩ | **18.8 W** |
| Per-FET average | 3.1 W |
| Shunt loss, 80² × 0.25 mΩ | 1.6 W |
| Copper trace/plane loss (est. 0.3 mΩ path) | 1.9 W |
| **Total conduction per channel** | **≈ 22.3 W** |

**Ripple check.** Phase inductance is about 20 µH for a typical 5-inch motor. The worst-case ripple is:

```
ΔI = V_bus·D(1−D)/(L·f_sw) = 25.2 × 0.25 / (20 µH × 48 kHz) = 6.6 A pk-pk
```

The RMS addition is ΔI²/12 ≈ 3.6 A², which is less than 0.06 % of I_pk². It is negligible.

## 3. Switching Loss Model at 48 kHz

Only the PWM leg switches. That is one hard-switched commutation pair per channel per PWM period.

### 3.1 Transition times

```
t_r ≈ t_f ≈ Q_gd / I_g = 9 nC / 1.0 A = 9 ns
```

A practical value, including ringing control, is about **20 ns per edge**. This is set by R_g, chosen for EMI and overshoot control.

### 3.2 Loss terms

```
P_VI   = ½ · V_bus · I_pk · (t_r + t_f) · f_sw
P_oss  = Q_oss · V_bus · f_sw
P_rr   = Q_rr · V_bus · f_sw
P_dead = V_SD · I_pk · 2 · t_dead · f_sw
P_gate = Q_g · V_drv · f_sw · 2          (both FETs of the leg; mostly in driver/R_g)
```
