# STM32H743 AIO Flight Controller with 4-in-1 80A ESC (Job #37): Architecture, Loss Model, DShot DMA Plan, and Reference Netlist

## 0. Engineering Assumptions and Feasibility Warnings

**This is not release data.** Device parameters below are representative values for the 40V, 0.7 mΩ-class MOSFETs used on high-current ESCs. Before layout you must substitute the actual part's datasheet values: R<sub>DS(on)</sub>(T), Q<sub>g</sub>, Q<sub>rr</sub>, C<sub>oss</sub>, t<sub>r</sub>/t<sub>f</sub>, and Z<sub>th</sub>. The equations are built so you can re-run them with real numbers. Pin assignments must be checked against the STM32H743 datasheet alternate-function table (DS12110) and the chosen package.

**Feasibility warnings:**

1. **80A per channel on a "nano" (20×20 mm) board is not thermally viable** except as a burst lasting about a second. Section 2.6 shows roughly 70 W of dissipation into about 2 J/K of thermal mass. This analysis assumes a **30.5×30.5 mm** board. Treat 80A strictly as a short burst rating; the continuous rating is closer to 35–45A.
2. **The H743 does not commutate the motors.** A real 4-in-1 ESC runs its own MCU(s). Here that is 4× AT32F421 running AM32. The H743 sends bidirectional DShot600 to them. The architecture follows that split.

## 1. System Architecture

```
6S LiPo ─┬─ TVS + 4×470µF low-ESR bulk + 16×10µF/50V MLCC (per-bridge)
         ├─ ESC: 4× AT32F421 (AM32) → 4× FD6288Q 3-ph gate driver → 24× N-MOSFET (12 half-bridges)
         ├─ Shunt (0.25 mΩ) + INA186 → ESC current telemetry
         └─ Buck 5V/3A, Buck 10V/2A (VTX), LDO 3.3V → STM32H743VIT6 FC
FC: H743 @ 480 MHz | ICM-42688-P (SPI1) | DPS310 baro (I2C2) | SDMMC1 | 8 UARTs | OSD AT7456E (SPI2)
Link FC→ESC: 4× bidirectional DShot600 (single-wire, open-drain-tolerant, 3.3 V)
```

## 2. Thermal Loss Model (per ESC channel, at the 80A burst)

### 2.1 Commutation Topology

Six-step trapezoidal (AM32 default) uses synchronous, complementary PWM.

- At any instant **two phases conduct**: one high-side path and one low-side path.
- Exactly **one half-bridge is switching** at f<sub>sw</sub>.
- The current path therefore always crosses **two MOSFET channels in series**, regardless of duty cycle D, because synchronous rectification carries the off-time current.

### 2.2 Conduction Loss with Electrothermal Feedback

$$R_{DS}(T_j) = R_{25}\left[1+\alpha\,(T_j-25)\right]$$

$$P_{cond} = 2\,I^2 R_{DS}(T_j) + I^2 R_{Cu}$$

| T<sub>j</sub> | R<sub>DS</sub> | 2·I²·R<sub>DS</sub> | I²·R<sub>Cu</sub> | **P<sub>cond</sub>** |
|---|---|---|---|---|
| 25 °C | 0.70 mΩ | 8.96 W | 1.92 W | 10.9 W |
| 75 °C | 0.91 mΩ | 11.65 W | 1.92 W | 13.6 W |
| 100 °C | 1.015 mΩ | 12.99 W | 1.92 W | 14.9 W |
| 125 °C | 1.12 mΩ | 14.34 W | 1.92 W | 16.3 W |

The RMS current used here is I itself. For trapezoidal drive, conducting-phase current is approximately DC, so I<sub>rms</sub> ≈ I during conduction.

### 2.3 Switching Loss at 48 kHz (hard-switched node)

**V–I overlap:**

$$P_{sw} = \tfrac12 V_{in} I (t_r+t_f) f_{sw} = 0.5(25.2)(80)(40\text{ ns})(48\text{ kHz}) = \mathbf{1.94\ W}$$

**Reverse recovery of the complementary body diode:**

$$P_{rr} = Q_{rr} V_{in} f_{sw} = 50\text{ nC}\cdot25.2\cdot48\text{k} = \mathbf{0.060\ W}$$

**C<sub>oss</sub> charge/discharge (two devices on the node):**

$$P_{oss} = 2\cdot\tfrac12 C_{oss} V_{in}^2 f_{sw} = 1.5\text{ nF}\cdot 635\cdot 48\text{k} = \mathbf{0.046\ W}$$

**Dead-time body-diode conduction (two edges per period):**

$$P_{dt} = V_F\, I\,(2 t_{dead}) f_{sw} = 0.8\cdot80\cdot200\text{ ns}\cdot48\text{k} = \mathbf{0.614\ W}$$

**Gate drive.** This loss is dissipated in the driver and gate resistors, not the FETs:

$$P_g = 2\,Q_g V_{GS} f_{sw} = 2(60\text{ nC})(10)(48\text{k}) = \mathbf{0.058\ W}$$

**Design lever:** dead-time loss is 30% of switching-related loss. Tightening t<sub>dead</sub> from 100 ns to 50 ns saves about 0.3 W per channel. AM32 exposes dead time as a setting, but validate it against shoot-through on a scope at temperature.

### 2.4 Per-Channel and Board Totals (T<sub>j</sub> ≈ 100 °C)

| Loss term | W / channel | W / board (×4) |
|---|---|---|
| MOSFET conduction | 12.99 | 51.96 |
| Copper conduction | 1.92 | 7.68 |
| Switching overlap | 1.94 | 7.76 |
| Dead-time diode | 0.61 | 2.46 |
| Q<sub>rr</sub> + C<sub>oss</sub> | 0.11 | 0.42 |
| Gate drive (driver) | 0.06 | 0.23 |
| FD6288Q quiescent + ESC MCU | ~0.10 | 0.40 |
| **Total** | **≈17.7 W** | **≈71 W** |

Electrical efficiency at burst: P<sub>out</sub> ≈ 25.2 V × 80 A × D. At D = 0.95, that is about 1915 W per channel, so η ≈ 99.1%.

The problem is not efficiency. It is **power density**: about 71 W in roughly 9 cm² of board.
