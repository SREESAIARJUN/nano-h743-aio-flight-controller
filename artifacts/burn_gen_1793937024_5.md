# STM32H743 Nano AIO Flight Controller with 4-in-1 ESC (Job #49): Architecture, Loss Models, DShot Allocation, and Netlists

## 0. Architecture Correction and Stated Assumptions

**The STM32H743 should not commutate the motors directly.** It runs ArduPilot and generates bidirectional DShot600. ArduPilot's scheduler, EKF, and DMA-driven DShot cannot also run four sensorless 48 kHz FOC/six-step commutation loops deterministically. The architecture is therefore:

```
STM32H743 (ArduPilot) --4x bidir DShot600--> 4x AT32F421 / STM32G071 (AM32, 48 kHz PWM)
                                             --> 4x FD6288Q 3-ph gate drivers --> 24x N-MOSFETs
```

**The design basis below is illustrative. Substitute your actual datasheet values before signing off.**

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full) | V_bus | 25.2 V |
| Burst current per channel (DC link) | I | 80 A |
| PWM frequency | f_sw | 48 kHz |
| Duty at burst | D | 0.80 |
| MOSFET R_DS(on) at 25 °C, Vgs = 10 V | R₂₅ | 0.90 mΩ (40 V, 3.3×3.3 or 5×6 DFN class) |
| R_DS(on) tempco | α | 0.0045 /K |
| Rise + fall time | t_r + t_f | 20 ns |
| Total gate charge | Q_g | 60 nC |
| Output capacitance at V_bus | C_oss | 1.5 nF |
| Dead time | t_dt | 50 ns |

**Reality check on "nano" + 80 A.** A 20×20 or 30.5×30.5 board can survive 80 A per channel only as a **burst of seconds**, and only with heavy copper (≥2 oz outer, ≥4–6 layers) and prop-wash airflow. The model below quantifies exactly that.

## 1. Conduction Loss Model (Six-Step, Synchronous Rectification)

In six-step commutation, each phase leg conducts for 1/3 of the electrical cycle (120°). The high-side FET of the active leg chops at duty D. The complementary low-side FET freewheels during (1−D).

**Temperature-corrected resistance:**

$$R_{DS}(T_j) = R_{25}\left[1+\alpha (T_j-25)\right]$$

At T_j = 125 °C: R = 0.90 × 1.45 ≈ **1.31 mΩ**. Use **1.4 mΩ** to cover board and solder margin.

**Per-FET conduction loss:**

$$P_{cond,HS} = I^2 R_{DS}(T_j)\cdot D\cdot\tfrac{1}{3}, \qquad P_{cond,LS} = I^2 R_{DS}(T_j)\cdot (1-D)\cdot\tfrac{1}{3}$$

Here I²R = 6400 × 0.0014 = 8.96 W.

- P_cond,HS = 8.96 × 0.8 / 3 = **2.39 W**
- P_cond,LS = 8.96 × 0.2 / 3 = **0.60 W**

**Phase-current ripple correction.** I_rms² = I²(1 + r²/12), where r = ΔI_pp / I. For low-inductance quad motors at 48 kHz, r ≈ 0.3–0.5, which adds 1–2 %. This is negligible at this fidelity.

**Copper path loss.** A 2 oz copper square is about 0.25 mΩ/□. Assuming ~3 squares per phase path plus the shunt (0.5 mΩ):

P_Cu ≈ 6400 × (0.75 + 0.5) mΩ ≈ **8.0 W per channel**.

This term is frequently ignored and is comparable to the FET losses. **On nano boards, copper is a first-order heat source.**

## 2. Switching Loss Model at 48 kHz

Each loss term occurs only while the leg is active, so it carries a factor of 1/3.

**1. Hard-switching V·I overlap (high side):**

$$P_{sw} = \tfrac12 V_{bus} I (t_r+t_f) f_{sw}\cdot\tfrac13 = \tfrac12(25.2)(80)(20\text{ns})(48\text{k})/3 = \mathbf{0.323\ W}$$

**2. C_oss discharge:**

$$P_{oss} = \tfrac12 C_{oss}V_{bus}^2 f_{sw}/3 = 0.5(1.5\text{n})(635)(48\text{k})/3 = \mathbf{7.6\ mW}$$

**3. Reverse recovery.** This is dissipated in the high-side FET:

$$P_{rr} = Q_{rr}V_{bus}f_{sw}/3 = 40\text{n}(25.2)(48\text{k})/3 = \mathbf{16\ mW}$$

**4. Dead-time body-diode conduction (low side), two edges per period:**

$$P_{dt} = V_f I (2t_{dt}) f_{sw}/3 = 0.8(80)(100\text{n})(48\text{k})/3 = \mathbf{0.102\ W}$$

**5. Gate drive.** This is dissipated mostly in the driver and R_g, not the FET:

$$P_g = Q_g V_{GS} f_{sw} = 60\text{n}(10)(48\text{k}) = 28.8\text{ mW per FET}$$

That totals **0.17 W per channel**, which sets the gate-drive LDO and bootstrap budget.

### Loss Summary at 80 A Burst, T_j = 125 °C

| Loss term | HS FET | LS FET |
|---|---|---|
| Conduction | 2.39 W | 0.60 W |
| Switching overlap | 0.32 W | — |
| C_oss + Q_rr | 0.02 W | — |
| Dead-time diode | — | 0.10 W |
| **Per FET** | **2.73 W** | **0.70 W** |

**Per-channel and board totals:**

- **Per channel:** 3 × 2.73 + 3 × 0.70 + 0.17 (gate) + 8.0 (copper/shunt) ≈ **18.5 W**
- **4-in-1 total at simultaneous burst:** ≈ **74 W**
- **Efficiency at burst:** 74 W out of 4 × 25.2 × 80 × 0.8 ≈ 6.45 kW, about 98.9 % (excluding motor).

**Frequency sensitivity:**

$$\frac{\partial P}{\partial f_{sw}} \approx 4\times(0.33+0.10+0.03+0.17/3)\cdot\frac{1}{48\text{k}}$$

This is about 43 mW per kHz for the board. Going from 24 kHz to 48 kHz costs roughly 1 W at burst. That is small, so 48 kHz is justified for current-ripple and acoustic reasons.

## 3. Thermal Model

### 3.1 Network (per FET, Foster/Cauer simplified)

```
Pj ──[Rθjc 1.2 K/W]──●──[Rθspread 3.0 K/W]──● Board node (Cb) ──[Rθba]── Ambient
                     Cj≈0.02 J/K                         Cb ≈ 8–10 J/K
```

Board-to-ambient resistance depends on airflow:

- **Rθba ≈ 2.5 K/W** with prop wash (~8 m/s)
- **Rθba ≈ 8 K/W** in still air
