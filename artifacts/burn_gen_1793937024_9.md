# STM32H743 Nano AIO (FC + 4-in-1 ESC): Loss, Thermal and DShot Timing Model

I don't have a Job #46 spec, BOM or board outline. This model is therefore fully parametric, with explicitly stated example values. To get board-specific numbers, substitute your MOSFET datasheet values in Section 2.

---

## 0. Architecture Correction

On a 4-in-1 ESC the STM32H743 does **not** generate the 48 kHz motor PWM. The chain is:

```
STM32H743 (ArduPilot) --bidir DShot600 x4--> 4x ESC MCU (AM32/BLHeli_32 on AT32F421 / STM32G071 / GD32E230)
                                               --> 3-phase gate driver --> 6x N-MOSFET per motor
```

The 48 kHz switching frequency is an ESC firmware setting (AM32 supports 24/48 kHz). The H743's job is DShot output plus eRPM capture.

## 2. Conduction Loss Model

### 2.1 Temperature-dependent R_DS(on)

```
R_DS(Tj) = R25 · [1 + α·(Tj − 25)]
At Tj = 110 °C:  R = 1.5 mΩ · (1 + 0.005·85) = 2.14 mΩ
```

### 2.2 Six-step (trapezoidal) commutation with synchronous rectification

In each 60° sector, phase A is PWM'd and phase B low-side is held on:

- High-side A conducts for fraction D.
- Low-side A (synchronous rectifier) conducts for fraction (1 − D).
- Low-side B conducts 100 % of the sector.

Include current ripple in the RMS value:

```
I_rms² = I² + ΔI²/12
ΔI ≈ V_bus·D(1−D) / (L_phase · f_sw)
```

For a typical 5″ motor, L_phase ≈ 15–30 µH, giving ΔI ≈ 4–9 A at D = 0.5. The ripple term is negligible (< 0.2 %), so I_rms ≈ I.

Per-motor conduction loss is the switched pair plus the continuous low-side:

```
P_cond = I²·R·[D + (1−D)] + I²·R = 2·I²·R_DS(Tj)
```

At 80 A:

```
P_cond = 2 · 6400 · 2.14e-3 = 27.4 W per motor
P_cond(4 motors) = 109.6 W
```

### 2.3 Copper interconnect loss

```
R_cu = ρ_cu(T)·L / (w·t),   ρ_cu(20 °C) = 1.72e-8 Ω·m,  tempco 0.0039 /K
```

Example: a phase pour of L = 8 mm, w = 4 mm, two parallel 2 oz layers (t = 140 µm):

```
R_cu = 1.72e-8 · 8e-3 / (4e-3 · 140e-6) = 0.25 mΩ
P_cu = 80² · 0.25e-3 · 2 paths ≈ 3.2 W per motor
```

This is not negligible. Add the shunt if you fit one: 0.25 mΩ at 80 A gives 1.6 W.

## 3. Switching Loss Model at 48 kHz

Only the PWM'd high-side hard-switches. The synchronous low-side switches at near-zero V_DS, after the body diode clamps during dead time.

| Term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r + t_f)·f_sw | ½·25.2·80·35 ns·48 k = **1.69 W** |
| Reverse recovery | Q_rr·V·f_sw | 40 nC·25.2·48 k = **0.048 W** |
| Coss energy | ½·Q_oss·V·f_sw | **0.018 W** |
| Dead-time diode | V_f·I·2·t_dt·f_sw | 0.8·80·200 ns·48 k = **0.61 W** |
| Gate drive (2 switching FETs) | 2·Q_g·V_gs·f_sw | **0.048 W** (dissipated mostly in driver/R_g) |
| **Total switching** | | **≈ 2.4 W per motor** |

Notes:

- **Switching loss scales with frequency.** At 24 kHz the total halves to about 1.2 W. In practice, 80 A occurs near full throttle (D → 1), where AM32 may hold the high-side on and switching loss collapses. The worst combined case is around D ≈ 0.8–0.9 at high current.
- **Dead time is a major lever.** The dead-time diode term is about 25 % of switching loss. Trimming t_dt to 50 ns halves it, but this needs validation with a shoot-through scope capture.

### 3.1 Total burst dissipation

| Scope | Value |
|---|---|
| Per motor | 27.4 (cond) + 3.2 (Cu) + 2.4 (sw) ≈ **33 W** |
| Board, 4 × 80 A | **≈ 132 W** |
| Electrical efficiency at that point | 4·80·~24 V ≈ 7.7 kW in, so about 98.3 % |
