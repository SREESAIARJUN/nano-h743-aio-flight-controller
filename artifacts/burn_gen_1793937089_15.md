# STM32H743 AIO Flight Controller + 80A 4-in-1 ESC (Job #51): Electro-Thermal Model, DShot Timer/DMA Plan, and Reference Netlists

> **Scope and assumptions.** I don't have access to any prior Job #51 documents, so every parameter below is an explicit, editable assumption. All equations are written so you can substitute your actual MOSFET datasheet values.
>
> **Architectural note.** The STM32H743 does **not** commutate the motors. In a 4-in-1 design, each motor channel has its own ESC MCU (assumed here: AT32F421 running AM32). That MCU generates the 48 kHz PWM. The H743 runs ArduPilot and emits bidirectional DShot600 to the four ESC MCUs. The loss model applies to the ESC power stage. The DMA model applies to the H743.
