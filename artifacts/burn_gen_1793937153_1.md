# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the original Job #11 spec, so I've used the typical gimbal hardware assumptions below. Every value marked **[CFG]** is a parameter you should replace with your measured numbers.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 2–5 mH **[CFG]** |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| IMUs | 2× ICM-42688-P rigidly mounted on the camera plate, at different known positions |
| MCU | Cortex-M4F/M7 (STM32G4/H7 class) with FPU, hardware timers, DMA SPI |
| Current sense | 2- or 3-shunt low-side, sampled at the PWM center |

**Loop rates**

| Loop | Rate | Ts |
|---|---|---|
| PWM / current (FOC) | 20 kHz | 50 µs |
| Velocity | 4 kHz | 250 µs |
| Angle / stabilization | 1 kHz | 1 ms |
| IMU ODR | 8 kHz (gyro + accel) | 125 µs |
| Attitude estimator | 1 kHz (on decimated, filtered data) | 1 ms |

**Bandwidth separation:** each loop should have about 5–10× less bandwidth than the loop inside it. Suggested targets: ω_c,i ≈ 2π·1500 rad/s, ω_c,v ≈ 2π·150 rad/s, ω_c,θ ≈ 2π·20 rad/s.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Motor model (surface PMSM, L_d ≈ L_q = L)

$$
v_d = R\,i_d + L\frac{di_d}{dt} - \omega_e L\, i_q,\qquad
v_q = R\,i_q + L\frac{di_q}{dt} + \omega_e L\, i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac{3}{2}\,p\,\lambda_m\, i_q = K_t\, i_q,\qquad \theta_e = p\,\theta_m,\qquad \omega_e = p\,\omega_m
$$

### 1.2 Clarke transform (amplitude-invariant)

With 2 shunts, use i_a + i_b + i_c = 0:

$$
i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}
$$

### 1.3 Park transform and its inverse

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix},
\qquad
\begin{bmatrix} v_\alpha\\ v_\beta\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & -\sin\theta_e\\ \sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} v_d\\ v_q\end{bmatrix}
$$

**Delay compensation.** The PWM update takes effect about 1.5·Ts after sampling (1 Ts compute + 0.5 Ts PWM). Use this angle in the inverse Park:

$$
\theta_e^{inv} = \theta_e + 1.5\,\omega_e T_s
$$

### 1.4 Current PI controllers (pole–zero cancellation)

Each current axis is the plant G(s) = 1/(Ls + R). Choose the PI zero to cancel the electrical pole:

$$
K_{p,i} = L\,\omega_{c,i},\qquad K_{i,i} = R\,\omega_{c,i}
\quad\Rightarrow\quad
\frac{i}{i^*} = \frac{\omega_{c,i}}{s+\omega_{c,i}}
$$

**Decoupling and back-EMF feedforward:**

$$
v_d^* = PI_d(i_d^*-i_d) - \omega_e L\, i_q,\qquad
v_q^* = PI_q(i_q^*-i_q) + \omega_e L\, i_d + \omega_e\lambda_m
$$

with i_d* = 0 (no field weakening on a gimbal).

**Voltage limit (circular, d-axis priority).** With the linear SVPWM limit V_max = V_dc/√3:

$$
|v_d| \le V_{max},\qquad |v_q|\le\sqrt{V_{max}^2 - v_d^2}
$$

**Anti-windup by back-calculation**, with K_aw ≈ K_i/K_p:

$$
x_I[k+1] = x_I[k] + T_s\big(K_i e[k] + K_{aw}(v_{sat}-v_{unsat})\big)
$$

### 1.5 SVPWM (min–max zero-sequence injection)

$$
v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta
$$

$$
v_0 = -\tfrac12\big(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\big),\qquad
D_x = \tfrac12 + \frac{v_x+v_0}{V_{dc}}
$$

This is mathematically equivalent to sector-based SVPWM and gives a 15.5% higher linear range than SPWM.

**Voltage-mode fallback.** High-R gimbal motors (> 10 Ω) with no current sensing can run voltage-mode: v_q = R·i_q* + ω_e·λ_m. The code supports this with a flag, but torque accuracy degrades with temperature, because R changes about 0.39%/°C for copper.
