## 1. FOC Current Loop (Innermost, 20 kHz)

### 1.1 Transforms

Electrical angle:

θₑ = p·(θₘ − θ_offset) mod 2π

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**

- i_d = i_α·cos θₑ + i_β·sin θₑ
- i_q = −i_α·sin θₑ + i_β·cos θₑ

**Inverse Park transform:**

- v_α = v_d·cos θₑ − v_q·sin θₑ
- v_β = v_d·sin θₑ + v_q·cos θₑ

### 1.2 Plant Model and PI Design

The dq-frame plant is:

- v_d = R·i_d + L·(di_d/dt) − ωₑ·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ωₑ·(L·i_d + λ_m)

With decoupling feedforward, each axis reduces to a first-order plant 1/(Ls + R):

- v_d,ff = −ωₑ·L·i_q
- v_q,ff = ωₑ·(L·i_d + λ_m)

**Pole-zero cancellation.** Use the controller C(s) = K_p + K_i/s with:

- K_p = L·ω_c
- K_i = R·ω_c

The closed loop then becomes ω_c/(s + ω_c). Choose ω_c ≤ 2π·f_pwm/20, which gives about 2π·1 kHz.

**Discrete form** (forward Euler on the integrator, T_s = 1/f_pwm), with back-calculation anti-windup:

1. e[k] = i* − i
2. u_unsat = K_p·e + I[k] + v_ff
3. u = sat(u_unsat)
4. I[k+1] = I[k] + T_s·(K_i·e + K_aw·(u − u_unsat)), with K_aw ≈ K_i/K_p = R/L

**Voltage-vector limiting.** Use circular limiting with d-axis priority:

1. |v_d| ≤ V_max
2. |v_q| ≤ √(V_max² − v_d²)
3. V_max = V_bus/√3 (the linear SVPWM region)

### 1.3 SVPWM (Min-Max Zero-Sequence Injection)

1. Compute the phase voltages from v_α, v_β:
   - v_a = v_α
   - v_b = −v_α/2 + (√3/2)·v_β
   - v_c = −v_α/2 − (√3/2)·v_β
2. Compute the zero-sequence offset:
   - v₀ = −(max(v_a, v_b, v_c) + min(v_a, v_b, v_c)) / 2
3. Compute each duty cycle:
   - d_x = ½ + (v_x + v₀)/V_bus

This is mathematically identical to sector-based SVPWM and has no branches.

## 2. Cascaded Velocity and Angle Control

The cascade has three levels:

```
θ* ─►[Angle P + ω-FF]─► ω* ─►[Velocity PI + accel-FF]─► τ* ─► /Kt ─►(+ i_cog,ff)─► i_q* ─►[Current PI]
       1 kHz                     4 kHz                                                 20 kHz
```

Two variants fit a gimbal:

- **Encoder mode:** the angle loop closes on the motor encoder.
- **Stabilization mode:** the angle loop closes on the IMU-estimated camera attitude, and the velocity loop closes on the fused gyro rate. This mode provides inertial stabilization and rejects base motion directly.
