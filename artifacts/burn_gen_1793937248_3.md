## 0. Assumptions and Platform

| Item | Assumed value | Notes |
|---|---|---|
| MCU | STM32G474 / H7 class, single-precision FPU | Cortex-M4F/M7 |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH | e.g. GBM2804 class |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) | SPI, read once per current-loop tick |
| Current sense | 2-phase low-side shunts, synchronous ADC at PWM center | Voltage-mode fallback is discussed in §2.4 |
| PWM | 20 kHz center-aligned | |
| IMUs | 2 × ICM-42688-P on the camera (pitch) stage, SPI, ODR = 8 kHz | Mirrored mounting (§5.1) |

**Loop rates (multirate cascade):**

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ~1.5–2 kHz |
| Velocity | 4 kHz | 250 µs | ~150–250 Hz |
| Angle / stabilization | 1 kHz | 1 ms | ~20–40 Hz |
| IMU filtering | 8 kHz | 125 µs | anti-alias and notch |
| Attitude fusion | 1 kHz | 1 ms | |

The rule of thumb is a bandwidth separation of at least 5–10× between successive cascade stages.

**Architectural choice.** The encoder is used for commutation and for the cogging map. The stabilization loops (angle and velocity) close on inertial quantities from the IMU, because the goal is to hold the camera still in inertial space, not to hold the joint angle.

## 2. Field-Oriented Current Loop

### 2.1 Transforms

Electrical angle with encoder offset θ₀ (found at commissioning):

$$\theta_e = p\,\theta_m - \theta_0 \pmod{2\pi}$$

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 2.2 Plant and decoupled PI

The motor model in the rotating frame (surface PM, so L_d = L_q = L):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The PI controller with cross-coupling and back-EMF feedforward:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Gain design (pole–zero cancellation).** The PI zero cancels the electrical pole R/L, which leaves a first-order closed loop with bandwidth ω_c:

$$K_p^{(i)} = L\,\omega_c,\qquad K_i^{(i)} = R\,\omega_c$$
