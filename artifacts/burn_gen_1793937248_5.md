# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the Job #38 specification, so this design uses the representative parameters in §0. Every parameter is a named constant or configuration field, so you can substitute your actual motor, encoder and MCU values. The gain-design equations (§2.3, §3.3) recompute the gains from those physical values.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, center-aligned PWM |
| Motors | Gimbal BLDC (e.g. 4108-class), 12N14P → p = 7 pole pairs, R ≈ 5–12 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701), SPI, read every PWM cycle |
| Current sense | 2- or 3-shunt low-side, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate (SPI + DMA, FIFO), gyro ±2000 dps, ODR 8 kHz |
| Joint order | Yaw (outer, z) → Roll (x) → Pitch (inner, y) |

**Loop rates (each ≥ 5× the bandwidth of the loop it feeds):**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| Inertial rate (velocity) | 4 kHz | ω_v ≈ 2π·120 rad/s |
| Attitude (angle) | 1 kHz | ω_θ ≈ 2π·20 rad/s |
| IMU sampling / filtering | 8 kHz | — |

```
 q_ref ─►[Attitude P + FF]─► ω_d (camera frame)

                                ▼

```

## 1. Field-Oriented Control (Current Loop)

### 1.1 Motor model (rotor d–q frame)

$$
v_d = R i_d + L_d \frac{di_d}{dt} - \omega_e L_q i_q,\qquad
v_q = R i_q + L_q \frac{di_q}{dt} + \omega_e L_d i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac{3}{2}p\left[\lambda_m i_q + (L_d-L_q)i_d i_q\right] \;\xrightarrow{\,L_d=L_q\,}\; \tau_e = K_t\, i_q,\quad K_t = \tfrac32 p\lambda_m
$$
