## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R_s ≈ 5.5 Ω, L_s ≈ 1.8 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A-class), read every current-loop tick |
| Current sensing | 2 low-side shunts (phases a, b), sampled at PWM center |
| PWM / current loop | 20 kHz, center-aligned, T_c = 50 µs |
| Velocity loop | 4 kHz (every 5th current tick) |
| Angle loop + AHRS | 1 kHz |
| IMUs | 2 × ICM-42688-P on the camera plate, mirrored about the plate centroid, 8 kHz ODR, SPI + DRDY |
| Kinematic chain | Yaw (base) → Roll → Pitch (camera) |
