## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\left(\frac{T_j + 273}{298}\right)^{\alpha},\quad \alpha \approx 2.3 \text{ (silicon trench, fit to datasheet curve)}$$

At T_j = 100 °C: (373/298)^2.3 = **1.68** → R_DS = 1.26 mΩ.
At T_j = 125 °C: (398/298)^2.3 = **1.95** → R_DS = 1.46 mΩ.

Datasheets usually show a normalized R_DS vs T_j curve. Fit α to that curve rather than trusting 2.3.

### 1.2 Current path in 6-step complementary PWM

In each 60° sector, two phases conduct:
- **PWM leg:** current alternates between the high-side FET (for duty D) and the synchronous low-side FET (for 1−D). With complementary drive, exactly one FET of that leg carries I at any instant, ignoring dead time.
- **Return leg:** the low-side FET is held fully on.

So **two FET channels are always in series** with the motor current, independent of duty:

$$P_{cond,ch} = 2\, I_{rms}^2\, R_{DS}(T_j)$$

### 1.3 Ripple correction

The RMS phase current includes PWM ripple ΔI_pp:

$$I_{rms}^2 = I_{avg}^2 + \frac{\Delta I_{pp}^2}{12},\qquad \Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{LL}\, f_{sw}}$$

Worst case is D = 0.5. With line-to-line inductance L_LL = 15 µH (typical 5" motor ⚠):

ΔI_pp = 25.2 × 0.25 / (15e-6 × 48e3) = **8.75 A**, so ΔI²/12 = 6.4 A².

Compared with 80² = 6400 A², the correction is 0.1%, which is negligible at 48 kHz. It matters for low-inductance motors (L < 3 µH).

### 1.4 Numbers (T_j = 100 °C, iterated in §3)

$$P_{cond,ch} = 2 \times 6406 \times 1.26\text{ mΩ} = \mathbf{16.1\ W}$$

### 1.5 PCB copper loss (often forgotten)

$$P_{Cu} = I^2 R_{trace},\qquad R_{trace} = \frac{\rho_{Cu}(T)\,\ell}{w\,t\,N_{layers}}$$

Assumptions: ρ_Cu = 1.72e-8 Ω·m × (1 + 0.0039 × 75) at 100 °C; 2 oz copper (70 µm); 4 layers in parallel; effective path length 15 mm; width 3 mm.

R ≈ 2.23e-8 × 0.015 / (0.003 × 70e-6 × 4) = **0.40 mΩ**, so P_Cu ≈ 80² × 0.40 mΩ ≈ **2.6 W per channel**. Bus and ground return add more.

## 2. Switching Loss Model at 48 kHz

### 2.1 Transition times from gate charge

Gate current during the Miller plateau:

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_g} = \frac{10-4}{5.7} = 1.05\text{ A},\qquad I_{g,off} = \frac{V_{pl}}{R_g} = 0.70\text{ A}$$

The FD6288-class driver source/sink limit (~1.5/1.8 A) is not the bottleneck here.

$$t_r \approx \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = \frac{12\text{ nC}}{1.05} = 11.4\text{ ns},\qquad t_f \approx \frac{12\text{ nC}}{0.70} = 17.1\text{ ns}$$

### 2.2 Hard-switching V·I overlap loss

Only the PWM-leg high-side FET is hard-switched. The synchronous FET switches at near-zero V_DS.

$$P_{sw} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 28.5\text{ ns} \times 48\text{ kHz} = \mathbf{1.38\ W}$$
