# STM32H743 Nano AIO (FC + 4-in-1 ESC): Power-Stage and DShot Architecture

## 0. Architecture Clarification and Feasibility

**1. The H743 is the flight controller, not the ESC commutation engine.**
In a 4-in-1 design, the 48 kHz PWM and commutation run on dedicated ESC MCUs. The recommended partitioning is:

```
STM32H743 (ArduPilot)  ──bidir DShot600 ×4──▶  4× ESC MCU (AM32 on AT32F421 / STM32G071)
                                                   └─▶ 3-phase gate driver ─▶ 6× N-FET per motor
```

Running four 6-step commutation loops plus ArduPilot on one H743 is technically possible. However, ArduPilot does not support it, so it would mean custom firmware. This document assumes the partitioned architecture.

**2. "80 A burst" on a nano footprint is a short transient, not a rating.**
The model below shows that 4 × 80 A on a 20×20 mm board produces about 100 W of loss. That limits the burst to roughly 1–2 s from a warm start. Unheatsinked continuous capability is only about 13–15 A per motor. All numbers are parametric, so substitute your actual MOSFET datasheet values.

## 2. Conduction Loss Model

**Current path.** With 6-step trapezoidal drive and complementary (synchronous) PWM, the current always flows through exactly two FETs in series:
- the PWM'd leg, through either the high-side switch (duty D) or the synchronous low-side (1−D), and
- the static low-side of the return leg.

The conduction loss per motor is therefore:

$$P_{cond} = 2\, I_{ph}^2\, R_{ds}(T_j), \qquad R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)]$$

Here α ≈ 0.005 /K, which gives k_T ≈ 1.5 at 125 °C.

**Per motor at 80 A, T_j = 125 °C:**

$$P_{cond} = 2 (80)^2 (1.8\,\text{m}\Omega) = 23.0\ \text{W}$$

**Per FET.** Each FET carries current for 120° of the electrical cycle, so the average is:

$$\bar P_{FET} \approx 23.0/6 \approx 3.8\ \text{W}$$

**Electrothermal positive feedback.** R_ds rises with T_j, which raises loss, which raises T_j. Solve iteratively:

$$T_j^{(n+1)} = T_b + R_{th,jb}\,\bar P_{FET}\big(T_j^{(n)}\big)$$

This converges only if:

$$R_{th,jb}\cdot 2 I^2 R_{ds,25}\,\alpha / 6 < 1$$

At 80 A that product is 5 × 0.077 × 0.005 / 6 × 6400 / 6400 ≈ 0.064, so the loop is stable.

**PCB copper loss:**

$$P_{Cu} = I^2 R_{pcb} = 3.2\ \text{W per motor}$$
