## 0. Scope, Architecture and Assumptions

### 0.1 Architecture

Bidirectional DShot is a protocol between the flight controller and the ESC firmware. The H743 does not run the motors. The board is therefore built as two processor domains:

| Domain | Device | Firmware | Role |
|---|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100) @ 480 MHz | ArduPilot | Sends DShot600 frames and decodes eRPM telemetry |
| ESC (×4) | AT32F421K8U7 or STM32G071GBU6 | AM32 (or BLHeli_32-class) | 6-step commutation, 48 kHz PWM, BEMF zero-crossing detection |
| Gate drive (×4) | FD6288Q, 3-phase, bootstrap type | n/a | Drives 6 N-channel FETs per ESC |
| Power FETs (×24) | 40 V, ~1.2 mΩ, DFN3.3×3.3 class | n/a | Half-bridges |
