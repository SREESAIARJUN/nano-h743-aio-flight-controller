**Scope:** Power-stage loss model (80 A burst, 48 kHz), thermal transient model, ArduPilot bi-directional DShot600 timer/DMA allocation, and reference netlists.

## 0. Architecture Decision (Read First)

The STM32H743 is the **flight controller**. It cannot also commutate four BLDC motors under ArduPilot, because ArduPilot has no motor-commutation firmware. The standard and correct architecture is:

```
                 ┌──────────────────────────────┐
  6S Battery ──► │ STM32H743 FC (ArduPilot)     │── DShot600 bidir ──► ESC MCU ×4
                 │ 480 MHz core, 200 MHz timers │◄── GCR eRPM telemetry ─┘
                 └──────────────────────────────┘
  ESC MCU ×4: AT32F421 (or STM32G071) running AM32, PWM_FREQ = 48 kHz
  Gate driver ×4: 3-phase half-bridge driver (FD6288Q-class)
  Power stage: 24 N-ch MOSFETs (6 per motor)
```

AM32 natively supports 48 kHz complementary PWM, so the "48 kHz switching" requirement lives on the ESC MCUs. The H743 owns DShot generation and telemetry decode.

### Feasibility flag

80 A per channel on a "nano" form factor (20×20 or 25.5×25.5 mm) is **burst-only**, sustained for roughly 1–2 s. §3 quantifies this. Market these as "80 A burst (1 s)" with a much lower continuous rating, or the boards will fail in the field.

## 2. Electrical Loss Model (per motor channel)

### 2.1 Conduction losses

With complementary PWM, the phase current always flows through exactly **one high-side-equivalent path and one low-side-equivalent path** in series. The duty cycle D only redistributes current between the high-side and low-side FET of the PWM'd leg; their sum is constant.

$$P_{cond} = I^2 \cdot \left[ D\,R_{ds,HS} + (1-D)\,R_{ds,LS} \right]_{\text{PWM leg}} + I^2 R_{ds,\text{static leg}} \;\approx\; 2\,I^2 R_{ds}(T_j)$$

Temperature dependence, with α = 0.0047/K typical for trench Si:

$$R_{ds}(T_j) = R_{ds,25}\left[1 + \alpha (T_j - 25)\right]^{\approx} \;\Rightarrow\; R_{ds,125} \approx 1.6 \times 1.2 = 1.92\ \text{m}\Omega$$

**At 80 A:**

| T_j | R_ds | P_cond = 2·I²·R |
|---|---|---|
| 25 °C | 1.20 mΩ | 15.4 W |
| 100 °C | 1.68 mΩ | 21.5 W |
| 125 °C | 1.92 mΩ | **24.6 W** |

**Self-heating fixed point.** Conduction loss raises T_j, which raises R_ds, which raises loss. Solve iteratively. This is convergent only if

$$\frac{\partial P}{\partial T}\cdot R_{th,total} < 1 .$$

That condition sets the thermal-runaway boundary. Check it in §3.4.
