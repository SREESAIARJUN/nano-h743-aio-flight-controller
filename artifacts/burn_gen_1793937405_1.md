## Design Model: Conduction and Switching Losses, Thermal Budget, Bi-Directional DShot600 DMA, Netlists

## 0. Architecture Clarification and Basis Assumptions

**Partitioning.** The STM32H743 does not commutate the motors. It is the flight controller running ArduPilot. It generates four bi-directional DShot600 streams to four ESC MCUs (AT32F421 class, running AM32 or BLHeli_32-compatible firmware). Each ESC MCU drives a 3-phase gate driver and six MOSFETs. Loss modelling therefore applies to the ESC power stage, and DMA modelling applies to the H743.

**Reality check (stated up front).** 80 A per motor, ×4, on a nano form factor (20×20 or 25.5×25.5 mm) is a seconds-scale burst rating, not a continuous rating. The model below quantifies exactly how many seconds.

| Parameter | Symbol | Value (basis) |
|---|---|---|
| Bus voltage | V_bus | 25.2 V (6S full) worst case; 22.2 V nominal |
| Burst phase current | I | 80 A per channel |
| PWM frequency | f_sw | 48 kHz |
| Commutation | — | 6-step trapezoidal, synchronous rectification (complementary PWM) |
| MOSFET (representative 40 V, 5×6 / 3.3×3.3 class) | R_ds(on),25 | 1.0 mΩ (max) |
| | α (R_ds tempco) | 0.005 /K |
| | Q_g / Q_gs2+Q_gd / Q_rr / Q_oss | 60 nC / 18 nC / 40–80 nC / 40 nC |
| | R_θJC | 1.2 K/W |
| Gate drive | V_drv, R_g,tot | 10 V, 10 Ω; V_plateau ≈ 3.5 V |
| Dead time | t_dt | 100 ns per edge |
| Motor phase-to-phase inductance | L | 20 µH |

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step with synchronous rectification, exactly two MOSFETs are in the current path at every instant:

- the PWM-ing high-side (HS) device, or its complementary low-side (LS) device during the off-time, plus
- the return phase's LS device.

$$P_{cond,ch} = 2\, I_{rms}^2\, R_{ds}(T_j)$$

### 1.2 Ripple correction

Ripple current:

$$\Delta I = \frac{V_{bus}\,D(1-D)}{L\, f_{sw}}$$

At the worst case, D = 0.5:

$$\Delta I = \frac{25.2 \times 0.25}{20\,\mu H \times 48\,kHz} = 6.56\text{ A}_{pk-pk}$$

RMS current:

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 3.6 = 6403.6\ \text{A}^2$$

The ripple contribution is 0.06%, so it is negligible at 48 kHz. This is one argument for 48 kHz over 24 kHz.

### 1.3 Temperature-dependent R_ds(on): self-consistent solution

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha(T_j-25)]$$

| T_j | R_ds | P_cond per channel at 80 A |
|---|---|---|
| 25 °C | 1.00 mΩ | 12.8 W |
| 85 °C | 1.30 mΩ | 16.6 W |
| 105 °C | 1.40 mΩ | 17.9 W |
| 125 °C | 1.50 mΩ | **19.2 W** (design value) |

Iterate T_j = T_board + P_FET·R_θJC until convergence. Because R_ds rises with temperature, there is a positive-feedback loop. Thermal runaway is bounded only if:

$$\frac{\partial P}{\partial T}\, R_{\theta} < 1$$

### 1.4 Per-device distribution

Each of the six FETs carries current for 1/3 of the electrical period (120°).

**HS device of phase x:**
- Conducts for a fraction D/3 of the period.
- Its LS complement conducts for (1−D)/3.
- That LS also serves as the return path for a further 1/3.

**Average per FET:**

$$P_{avg} = \frac{19.2}{6} = 3.2\text{ W}$$

**Instantaneous, while conducting:**

$$P_{inst} = I^2 R = 9.6\text{ W}$$

This gives ΔT_jc ≈ 11.5 K. The electrical period (≈ 0.1–1 ms) is far shorter than the die-to-case time constant, so the average governs.

## 2. Switching Loss Model at 48 kHz

Only the HS device of the PWM-ing phase hard-switches. The LS device commutates softly, through the body diode during dead time.

### 2.1 V–I overlap loss

Gate currents during the plateau:

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_g} = \frac{10-3.5}{10} = 0.65\text{ A}$$

$$I_{g,off} = \frac{V_{pl}}{R_g} = 0.35\text{ A}$$

Transition times:

$$t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = \frac{18\,nC}{0.65} = 27.7\text{ ns}$$

$$t_{off} = \frac{18\,nC}{0.35} = 51.4\text{ ns}$$
