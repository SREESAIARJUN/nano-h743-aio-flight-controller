# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the original Job #9 specification, so this design uses the assumptions below. Every parameter is a named constant, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC/PMSM, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor angle sensor | 14-bit magnetic encoder (AS5048A/MT6701 class), read every PWM cycle |
| MCU | Cortex-M4F/M7 with FPU (e.g., STM32G4/H7) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, FIFO + timestamp |
| Inverter | 3-phase, 20 kHz center-aligned PWM |

---

## 1. Timing Architecture

| Loop | Rate | Period | Inputs → Output |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | i_abc, θ_e → v_abc (SVPWM) |
| Velocity | 4 kHz | 250 µs | ω_gyro (joint), ω* → i_q* |
| Angle | 1 kHz | 1 ms | θ_IMU, θ* → ω* |
| IMU sampling | 8 kHz ODR, read in 4 kHz bursts | — | FIFO → filtered ω, a |
| Attitude estimator | 1 kHz | 1 ms | ω, a → q |

Each loop runs at least 4× faster than the one outside it. Loop bandwidths are separated by about 5–10× so the cascaded loops stay decoupled: ω_c ≫ ω_v ≫ ω_θ.

## 2. Current Loop (FOC)

### 2.1 Transforms

**Clarke transform** (amplitude-invariant, assumes i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\left(i_a + 2i_b\right)
$$

**Park transform** with electrical angle θ_e = p·θ_m − θ_offset:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 2.2 PMSM dq Model (Surface-Mount, L_d = L_q = L)

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q
$$

$$
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m
$$

$$
\tau_e = \tfrac32 p \lambda_m i_q = K_t i_q,\qquad K_t = \tfrac32 p\lambda_m
$$

### 2.3 Decoupled PI Current Control (Pole-Zero Cancellation)

The control law adds feedforward decoupling and back-EMF terms to a PI on each axis:

$$
v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e \hat L i_q
$$

$$
v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e \hat L i_d + \hat\omega_e\hat\lambda_m
$$

With ideal decoupling, each axis reduces to the first-order plant 1/(Ls + R). Choosing the PI zero to cancel the plant pole gives:

$$
K_{p,c} = L\,\omega_c,\qquad K_{i,c} = R\,\omega_c
$$

The closed loop is then ω_c/(s + ω_c). Choose ω_c ≤ 2π·f_PWM/20; for 20 kHz PWM, ω_c ≈ 2π·1000 rad/s.

**Voltage limit:** clamp (v_d, v_q) to a circle of radius V_bus/√3 (the linear SVPWM region), giving v_d priority. Any clamping feeds back into the integrators through anti-windup (§3.3).

### 2.4 Space-Vector PWM (Min/Max Zero-Sequence Injection)

$$
v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta
$$

$$
v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad
d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}
$$

Gimbal motors usually have high R, so one-shunt or two-shunt sensing works. Sample the shunts at the PWM center.
