# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #40," so this design rests on the assumptions in §0. Every equation is parameterized, so you can substitute your real values.

---

## 0. Assumed System Parameters

| Item | Assumed value | Symbol |
|---|---|---|
| Motors | Gimbal BLDC, 12N14P (12 slots, 14 poles) | N_s = 12, p = 7 pole pairs |
| Phase resistance / inductance | 10 Ω / 2.5 mH (line-to-neutral) | R, L_d ≈ L_q = L |
| Flux linkage | λ ≈ 0.012 V·s/rad | λ |
| Torque constant | K_t = 1.5·p·λ ≈ 0.126 N·m/A | K_t |
| Encoder | 14-bit magnetic (MT6701 / AS5048A) | θ_m |
| Bus voltage | 12 V | V_bus |
| PWM / current loop | 20 kHz, center-aligned, ADC sampled at the PWM valley | T_c = 50 µs |
| Velocity loop | 4 kHz | T_v = 250 µs |
| Angle / attitude loop | 1 kHz | T_θ = 1 ms |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, decimated to 4 kHz | — |
| Gimbal order (outer → inner) | Yaw (Z) → Roll (X) → Pitch (Y) | R = R_z(ψ) R_x(φ) R_y(θ) |
