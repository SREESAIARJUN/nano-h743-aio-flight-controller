# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #22)

I don't have the Job #22 spec sheet, so this design rests on the assumptions in §0. Every parameter is a named constant, so you can change any of them in one place.

---

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class, single-precision FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor encoder | 14-bit magnetic (AS5048A / MT6701), SPI, read every PWM period |
| Current sense | 2-shunt or inline, sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro ODR 8 kHz, accel ODR 1 kHz |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner, camera) |

**Rate hierarchy.** Each outer loop has a bandwidth at least 4–5× below the loop inside it.
