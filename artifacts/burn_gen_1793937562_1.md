# STM32H743 FC + 4-in-1 80A ESC: Engineering Model (Job #49)

## 0. Scope and Assumptions

No MOSFET, gate driver, or board outline was specified, so the analysis below is **parametric with stated reference values**. Substitute your actual datasheet numbers into the equations before using them for sign-off.

**Architecture.** The STM32H743 does not drive the MOSFETs. It runs ArduPilot and sends bi-directional DShot600 to four ESC MCUs. In a 4-in-1 these are typically one AT32F421 or STM32G071 per motor, running AM32 or BLHeli_32, and those MCUs generate the 48 kHz complementary PWM.

| Commutation | 6-step trapezoidal, synchronous (complementary) PWM, f_sw = 48 kHz |
| "80 A burst" | 80 A **phase RMS per motor**, near full duty |

## 1. Conduction Loss Model

In 6-step with complementary PWM, two legs are active per commutation sector:

- **PWM leg:** the high-side conducts for D·T, and the synchronous low-side conducts for (1−D)·T.
- **Return leg:** the low-side conducts the full period.

The current-weighted conduction time therefore sums to 2 devices × 100 %, independent of D:

$$P_{cond,motor} = I_{ph,rms}^2 \cdot R_{ds}(T_j)\cdot\left[D + (1-D) + 1\right] = 2\,I_{ph}^2\,R_{ds}(T_j)$$

The temperature dependence is:

$$R_{ds}(T_j) = R_{ds,25}\left[1+\alpha(T_j-25)\right],\quad \alpha\approx0.005\,/\text{K}$$

**At 80 A:**
- Per motor: P_cond = 2 × 6400 × 1.8 mΩ = **23.0 W**.
- Per conducting device: 11.5 W instantaneous, while it conducts.
- Ripple correction: multiply by (1 + (ΔI_pp/I)²/12). With motor inductance around 10 µH at 48 kHz this is under 1 % and is neglected.

**Copper and shunt losses (per motor):**
- PCB phase and bus copper, 2 oz, about 0.25 mΩ effective path: 6400 × 0.25 mΩ ≈ **1.6 W**.
- Current shunt on the shared DC bus, 0.25 mΩ: computed at the board level below.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg hard-switches, which is one switching transition pair per period.

| Term | Equation | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw | ½·25.2·80·40n·48k = **1.94 W** |
| Body-diode dead time | 2·V_f·I·t_dt·f_sw | 2·0.8·80·100n·48k = **0.61 W** |
| Reverse recovery | Q_rr·V·f_sw | 40n·25.2·48k = **0.05 W** |
| C_oss discharge | Q_oss·V·f_sw | 30n·25.2·48k = **0.04 W** |
| Gate drive (in the driver IC, not the FET) | 2·Q_g·V_gs·f_sw | 2·40n·10·48k = **0.04 W** |
| **Total P_sw per motor** | | **≈ 2.7 W** |

**Design levers:**
- Dead time is about 23 % of the switching loss. Trim it to the minimum safe value; AM32 exposes this setting.
- Overlap loss scales linearly with f_sw. At 24 kHz it would be about 1.0 W, at the cost of more current ripple and audible noise.

## 3. Total Loss Budget

| | Per motor | ×4 (all motors at 80 A) |
|---|---|---|
| Conduction | 23.0 W | 92.0 W |
| Switching | 2.7 W | 10.8 W |
| Phase copper | 1.6 W | 6.4 W |
| Bus shunt (I_bus ≈ 4×80·D ≈ 300 A) | n/a | 0.25 mΩ × 300² ≈ 22 W ⚠ |
| **Total** | **≈ 27 W** | **≈ 130 W** |

At these currents the shunt needs to be about 0.1 mΩ, or you should use per-phase or Hall sensing.

**Efficiency at full burst:** P_out ≈ 25.2 × 300 ≈ 7.5 kW, so η ≈ 98.3 %. That is electrically fine. The problem is thermal density, which Section 4 addresses.

## 4. Thermal Model

### 4.1 Steady state (shows why "80A" can only be a burst rating)

Thermal network per device:

$$T_j = T_a + P_{dev}\,(R_{\theta jc}+R_{\theta cb}) + P_{board}\,R_{\theta ba}$$

**Board-to-ambient resistance.** For a nano board of 25×25 mm (two faces, A ≈ 12.5 cm²) under prop-wash forced convection with h ≈ 80 W/m²K:

$$R_{\theta ba} = 1/(hA) = 1/(80\times0.00125) = 10\ \text{K/W}$$

**Sustainable continuous power for a 105 °C board at T_a = 40 °C:**

$$P_{max} = 65/10 \approx 6.5\ \text{W}$$

This corresponds to roughly 25 A continuous per motor with all four loaded (I = √(6.5/4/(2·1.6 mΩ)) ≈ 22 A). That is consistent with how real 20–25 mm 4-in-1 boards are rated.
