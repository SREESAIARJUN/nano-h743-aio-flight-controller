# STM32H743 AIO 4-in-1 ESC Flight Controller: System Architecture Package (Job #19)

## 0. Scope and Assumptions

### 0.1 Topology

The STM32H743 does **not** commutate the motors. ArduPilot has no ESC firmware, and four sensorless FOC/6-step loops at 48 kHz on one H7 would conflict with the flight stack. The architecture is therefore:

```
[STM32H743 FC (ArduPilot)] --4x bidir DShot600--> [4x AT32F421/STM32G071 ESC MCUs (AM32/BLHeli_32)]
                                                     └─> 4x 3-phase gate driver ─> 24x N-MOSFET
```

### 0.2 Assumed Baseline Parameters

No MOSFET part number was specified, so the model below is fully parametric. The numbers use this baseline; substitute datasheet values for your BOM.

| Symbol | Meaning | Value |
|---|---|---|
| V_bus | 6S full charge | 25.2 V |
| I_burst | Phase current, per motor | 80 A |
| f_sw | ESC PWM frequency | 48 kHz |
| R_ds,on(25°C) | 40 V, PDFN 3.3×3.3 class | 0.9 mΩ |
| α | R_ds temperature coefficient | 0.006 /K |
| t_r + t_f | Switching transition time at 80 A | 15 + 15 ns |
| Q_rr / Q_oss | Body-diode recovery / output charge | 50 nC / 60 nC |
| Q_g @ 10 V | Total gate charge | 60 nC |
| t_dt / V_f | Dead time / body-diode drop | 100 ns / 0.8 V |
| T_a | Ambient / board start temperature | 40 °C |

### 0.3 Feasibility Flags (Review Before Layout)

1. **4 × 80 A = 320 A pack burst.** XT60 (~60 A continuous) and 12 AWG leads cannot carry it. Budget the burst as *per-motor transient*, with a realistic aggregate of 120–160 A. Use XT90 or direct-solder 10 AWG.
2. **"Nano" (20×20 mm) at 80 A is marginal.** The thermal math (§3) limits it to roughly 1–2 s bursts. A 30.5×30.5 mm board roughly triples that.
3. **Bus-capacitor ripple current is the hidden killer** (§2.5).

## 1. Conduction Loss Model

### 1.1 Current Path

With 6-step synchronous rectification, at any instant one high-side (HS) and one low-side (LS) FET carry I during the on-time. During the off-time, two LS FETs carry I (synchronous freewheel). The series resistance is therefore always 2·R_ds, independent of duty:

$$P_{cond,motor} = I^2 \cdot 2R_{ds}(T_j), \qquad R_{ds}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

For sinusoidal/FOC drive with phase peak \(\hat I\), use \(P = \tfrac{3}{2}\hat I^2 R_{ds}\cdot\) (per-phase sum). The 6-step form above is conservative for ESC firmware.

### 1.2 Electro-Thermal Fixed Point

Let \(P_0 = 2I^2R_{25}\) and let \(R_{th}\) be the junction-to-ambient thermal resistance of the loss-sharing FET group. Then:

$$T_j = T_a + R_{th}\left[P_0\big(1+\alpha(T_j-25)\big) + P_{sw}\right]$$

$$\boxed{T_j = \frac{T_a + R_{th}\left[P_0(1-25\alpha) + P_{sw}\right]}{1 - \alpha R_{th}P_0}}$$

**Thermal-runaway criterion:** \(\alpha R_{th} P_0 < 1\). If this is violated, no steady state exists and only an adiabatic burst is possible (§3).

### 1.3 Numbers at 80 A

- \(P_0 = 2 \cdot 6400 \cdot 0.9\,\text{m}\Omega = 11.52\) W per motor at 25 °C.
- At T_j = 125 °C, R_ds = 1.44 mΩ, so **P_cond = 18.4 W per motor**.
- Add PCB copper: 2 oz, ~0.15 mΩ effective per phase path, giving 6400 × 0.3 mΩ ≈ **1.9 W per motor** spread in the board.

## 2. Switching Losses at 48 kHz

Only the hard-switched device (HS in a complementary 6-step) incurs V–I overlap. The LS soft-switches but dumps body-diode recovery into the HS.

| Term | Formula | Value / motor |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw = ½·25.2·80·30n·48k | 1.45 W |
| Reverse recovery | Q_rr·V·f_sw = 50n·25.2·48k | 0.06 W |
| Coss | ½·Q_oss·V·f_sw ≈ ½·60n·25.2·48k | 0.04 W |
| Dead-time diode | V_f·I·2t_dt·f_sw = 0.8·80·200n·48k | 0.61 W |
| Gate drive (2 active FETs) | 2·Q_g·V_gs·f_sw = 2·60n·10·48k | 0.06 W (in driver) |
| **P_sw total** | | **≈ 2.2 W** |

### 2.1 Frequency Sensitivity

\(\partial P_{sw}/\partial f = P_{sw}/f \approx 46\) mW/kHz. Moving from 24 to 96 kHz only changes the total by ±1–2 W. **Conduction dominates (~89 %)**, so spend BOM money on R_ds,on and copper, not on faster switching.

### 2.2 Dead-Time Optimisation

Dead time is the largest controllable switching term. Reducing t_dt to 50 ns saves 0.3 W per motor, but only if the driver's propagation mismatch is below about 20 ns.

### 2.3 Gate Resistor Sizing

$$t_{sw} \approx \frac{Q_{gd}\, (R_g + R_{drv})}{V_{drv} - V_{plateau}}$$

With Q_gd = 12 nC, V_plateau = 4.5 V and a 10 V drive, a 15 ns transition implies R_g + R_drv ≈ 6.9 Ω. Use **R_g = 3.3 Ω** with the driver's ~3 Ω internal resistance.
