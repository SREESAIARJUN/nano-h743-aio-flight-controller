# STM32H743 FC + 4-in-1 ESC: Architecture, Loss Model, DShot DMA, and Thermal Budget

## 0. Architectural Clarifications

**1. The H743 does not commutate the motors.** A 4-in-1 ESC runs four dedicated ESC MCUs, typically AT32F421 or STM32G071 running AM32 or BLHeli_32. The H743 runs ArduPilot, generates bidirectional DShot600, and decodes eRPM telemetry. The 48 kHz PWM is generated by the ESC MCUs, not the H743.

**2. "80 A" on a nano (20×20 mm) board is a transient rating only.** The model below shows roughly 113 W of dissipation at 4×80 A, while the realistic continuous convective capacity of a 20×20 board is only about 6 W total. This document therefore treats 80 A as a time-limited burst (about 1 s) and derives the continuous rating honestly.

**3. Component values are representative assumptions.** Substitute datasheet values for your selected MOSFET, gate driver, and PCB stackup before release.

## 2. Conduction Loss Model

### 2.1 Junction-Temperature-Dependent R_DS(on)

$$R_{DS}(T_j)=R_{25}\,[1+\alpha(T_j-25)]$$

At T_j = 100 °C:

$$R_{DS}=1.5\,\text{mΩ}\times(1+0.0045\times75)=2.0\,\text{mΩ}$$

### 2.2 Trapezoidal BLDC with Synchronous Rectification

At any instant, two phases conduct. On the PWM leg, the high-side (HS) conducts for duty D and the low-side (LS) conducts for 1−D. The return leg's LS conducts 100% of the time.

$$P_{cond,PWM\,leg}=I^2R_{DS}\,D + I^2R_{DS}(1-D)=I^2R_{DS}$$

$$P_{cond,ch}=2\,I^2R_{DS}(T_j)$$

This result is independent of duty. At 80 A:

$$P_{cond,ch}=2\times80^2\times2.0\,\text{mΩ}=25.6\ \text{W}$$

### 2.3 Electrothermal Fixed Point

R_DS depends on T_j, which in turn depends on loss, so the steady-state solution is a fixed point:

$$T_j = T_{ref} + R_{\theta}\,2I^2R_{25}[1+\alpha(T_j-25)]$$

$$T_j=\frac{T_{ref}+R_\theta\,2I^2R_{25}(1-25\alpha)}{1-R_\theta\,2I^2R_{25}\alpha}$$

**Thermal runaway** occurs when the denominator reaches zero:

$$R_\theta\,2I^2R_{25}\alpha \ge 1$$

At 80 A this happens for R_θ ≥ 11.6 K/W. That is the same order as a nano board's total convective resistance (about 12.5 K/W, see §5.3). **Continuous 80 A is therefore physically unstable on this form factor.**

### 2.4 Shunt Loss

$$P_{shunt}=80^2\times0.5\,\text{mΩ}=3.2\ \text{W per channel}$$

This is significant. Consider a 0.25 mΩ shunt or inline Hall sensing.

## 3. Switching Loss Model at 48 kHz

Only the PWM leg switches. The HS hard-switches the inductive load. The LS commutates through its body diode during dead time.

| Loss term | Equation | Value per channel |
|---|---|---|
| V–I overlap | ½ V I (t_r + t_f) f_sw | ½·25.2·80·30 ns·48 kHz = **1.45 W** |
| Dead-time diode | V_F I · 2 t_dead · f_sw | 0.8·80·400 ns·48 kHz = **1.23 W** |
| Reverse recovery | Q_rr V f_sw | 40 nC·25.2·48 kHz = **0.048 W** |
| C_oss | ½ Q_oss V f_sw | **0.030 W** |
| Gate drive (driver) | Q_g V_GS f_sw × 2 FETs | **0.058 W** |
| **Total switching-related** | | **≈ 2.82 W** |

Two observations:

- **Dead-time loss is almost as large as overlap loss.** Trimming dead time from 200 ns to 80 ns saves about 0.74 W per channel. AM32 allows dead-time tuning, so this must be validated with a scope for shoot-through margin.
- **Frequency tradeoff.** Moving to 24 kHz halves this term (saving about 1.4 W per channel) but increases current ripple, motor iron loss, and audible noise. 48 kHz is a reasonable choice for low-inductance racing motors.
