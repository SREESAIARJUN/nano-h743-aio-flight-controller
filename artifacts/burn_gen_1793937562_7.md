# STM32H743 Nano FC + 4-in-1 ESC (Job #25): Power-Stage Loss Model, Thermal Analysis, Bi-Directional DShot600 DMA Allocation, and Reference Netlist

## 0. Architecture Corrections and Assumptions

Two points change the analysis, so they come first.

1. **The STM32H743 does not drive the MOSFETs.** In a 4-in-1 stack, each ESC channel (or a shared MCU) runs its own commutation firmware. Typical choices are AT32F421 or STM32G071 running AM32, or EFM8 running BLHeli_S/Bluejay. The H743 runs ArduPilot and only *emits* bi-directional DShot600. So the 48 kHz switching frequency is an **ESC-MCU parameter**, not an H743 timer allocation. I model both sides separately.
2. **80 A on a 20×20 mm nano board is a transient (≈1–2 s) rating, not a continuous one.** The thermal model in §3 quantifies this. Any datasheet claiming otherwise is relying on wire and frame heat-sinking that the board cannot guarantee.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 110 °C: R_ds = 1.0 × (1 + 0.006 × 85) = **1.51 mΩ**.

### 1.2 Bridge conduction loss per ESC channel

In 6-step operation with synchronous rectification, two phase legs carry current at all times. On the PWM leg, either the high-side or low-side FET conducts, never neither, apart from dead time. The current path therefore always crosses exactly **two** FET channels:

$$P_{cond} = 2\,I_{ph}^2\,R_{ds}(T_j)$$

$$P_{cond} = 2 \times 80^2 \times 1.51\times10^{-3} = \mathbf{19.3\ W}$$

### 1.3 Copper and shunt losses

**PCB copper.** Assume trace plus via resistance of about 0.3 mΩ per channel path:

$$P_{Cu} = I_{ph}^2 R_{Cu} = 6400 \times 0.0003 \approx 1.9\ \text{W/channel}$$

**Battery-bus shunt.** At duty D = 0.9, the shared bus current is:

$$I_{bat} = \sum D\,I_{ph} = 4 \times 0.9 \times 80 = 288\ \text{A}$$

With a 0.25 mΩ shunt:

$$P_{shunt} = 288^2 \times 0.25\times10^{-3} = \mathbf{20.7\ W}$$

This loss is in a single component. **Recommendation:** use 0.1 mΩ, or switch to per-phase low-side sensing or a Hall sensor.

### 1.4 Electro-thermal coupling

R_ds depends on T_j, and T_j depends on the loss, so the two must be solved iteratively:

$$T_j^{(n+1)} = T_a + Z_{th}(t)\cdot P_{FET}\!\left(R_{ds}(T_j^{(n)})\right)$$

The iteration converges if:

$$\frac{\partial P}{\partial T}\,Z_{th} = 2 I^2 R_{25}\,\alpha\,Z_{th} < 1$$

At 80 A that loop gain is 0.077 × Z_th. **Thermal runaway is therefore possible if Z_th exceeds about 13 K/W.** Steady-state natural convection on a nano board approaches this (see §3), which is a second reason to cap burst duration.

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. Each PWM period contains one turn-on and one turn-off.

### 2.1 Gate-current-limited transition times

**Turn-on** (driver sourcing into the plateau):

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_g} = \frac{6.5}{6.5} = 1.0\ \text{A}$$

$$t_{on} = \frac{Q_{gs2} + Q_{gd}}{I_{g,on}} = 15\ \text{ns}$$

**Turn-off** (driver sinking from the plateau):

$$I_{g,off} = \frac{V_{pl}}{R_g} = 0.54\ \text{A}$$

$$t_{off} = \frac{15\ \text{nC}}{0.54\ \text{A}} = 28\ \text{ns}$$

### 2.2 Loss components (per channel)

| Mechanism | Formula | Value |
|---|---|---|
| V–I overlap | ½ · V_bus · I_ph · (t_on + t_off) · f_sw = ½ · 25.2 · 80 · 43 ns · 48 kHz | **2.08 W** |
| Reverse recovery | Q_rr · V_bus · f_sw | 0.06 W |
| C_oss (both FETs in leg) | 2 · ½ · C_oss(er) · V_bus² · f_sw | 0.05 W |
| Dead-time body-diode conduction | V_f · I_ph · 2 · t_dt · f_sw | 0.61 W |
| Gate drive (dissipated in driver/R_g) | 2 · Q_g · V_drv · f_sw | 0.06 W |
| **Total switching** | | **≈ 2.86 W** |

### 2.3 Sensitivity to switching frequency

The switching-related terms total about 2.8 W and scale linearly with f_sw, at roughly 0.058 W/kHz:

- At 24 kHz: saves about 1.4 W per channel.
- At 96 kHz: adds about 2.8 W per channel.

At 80 A, conduction dominates by about 7:1. **Lowering f_sw buys little; lowering R_ds(on) buys a lot.**
