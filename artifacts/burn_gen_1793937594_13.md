# STM32H743 Nano FC + 4-in-1 ESC (Job #7): Design Model

## 0. Scope, Assumptions and Architecture Notes

No component BOM or board spec came with Job #7. All numbers below come from the stated baseline assumptions. The model is parametric: substitute datasheet values and the equations still hold.

**Architecture correction.** The STM32H743 is the **flight controller** MCU. It runs ArduPilot and generates DShot. A 4-in-1 ESC has **four separate ESC MCUs**, each running AM32 or BLHeli_32 commutation firmware (for example AT32F421 or STM32G071). The H743 never drives gates directly. The design is therefore two subsystems: FC (H743) and ESC (4× MCU + 4× 3-phase driver + 24 MOSFETs).

## 1. Conduction Loss Model

### 1.1 Current path
In 6-step complementary PWM, two phases conduct at any instant:
- **Non-PWM leg:** one low-side FET, fully on.
- **PWM leg:** either the high-side FET (during D) or its complementary low-side FET (during 1−D).
