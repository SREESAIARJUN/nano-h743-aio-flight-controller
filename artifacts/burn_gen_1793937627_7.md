# STM32H743 FC + 4-in-1 ESC (Job #64): Design Model and Review

## 0. Architecture and Scope

Three findings shape the rest of this document.

1. **The H743 cannot directly commutate four motors.** Four 3-phase bridges need 12 complementary PWM pairs with hardware dead-time. The H743 offers TIM1 and TIM8 (3 complementary pairs each, enough for 2 motors) plus HRTIM, and it would also need to run 4 sensorless commutation loops alongside the flight stack. The baseline is therefore conventional: **H743 FC → bidirectional DShot600 → 4× ESC MCUs (e.g. AT32F421 running AM32) → 3-phase gate drivers → 24 MOSFETs.** The 48 kHz figure is the ESC MCU's PWM frequency, not the H743's.
2. **"80 A burst" is a transient rating, not a thermal operating point.** The model below shows a nano-format (20×20 / 25.5×25.5) board with all four channels at 80 A reaches thermal limits in about **1–1.5 s**. Market it as a ~1 s burst rating, or relabel.
3. **The netlist in §5 is a representative reference design.** It uses placeholder parameters, not a verified, fab-ready output. Every device value marked *(A)* is an assumption to replace with your selected part's datasheet values before layout freeze.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-Dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.005\text{–}0.007\ \text{K}^{-1}$$

At T_j = 125 °C with a datasheet normalization factor of ~1.5:

$$R_{hot} = 1.5 \times 1.5\ \text{m}\Omega = 2.25\ \text{m}\Omega$$

### 1.2 RMS Current Including PWM Ripple

$$\Delta I = \frac{V_{bus}\,D(1-D)}{L\,f_{sw}} = \frac{22.2 \times 0.25}{20\,\mu\text{H} \times 48\,\text{kHz}} = 5.78\ \text{A}_{pp}\ (\text{worst case } D = 0.5)$$

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 2.8 \approx 6403\ \text{A}^2$$

Ripple contributes under 0.05%, so I_rms ≈ 80 A.

### 1.3 Bridge Conduction Path

In 6-step synchronous operation, current always flows through exactly two MOSFETs:

- the PWM'd phase, split between HS (fraction D) and synchronous LS (fraction 1−D), and
- the return phase LS, which conducts 100%.

$$P_{cond,motor} = 2\,I_{rms}^2\,R_{hot} = 2 \times 6403 \times 2.25\,\text{m}\Omega = \mathbf{28.8\ W}$$

Phase-trace copper adds to this. For 2 oz copper (0.5 mΩ/sq), a 3 mm × 8 mm phase run is about 2.7 squares ≈ 1.3 mΩ → **+8 W per phase pair at 80 A**. This is not negligible, so use 3 oz inner power planes and stitched vias.

## 2. Switching Loss Model (48 kHz)

Only one half-bridge per motor switches at any instant in 6-step operation.

### 2.1 V-I Overlap (Hard Turn-On/Off)

$$t_{r,f} \approx \frac{Q_{gd}}{I_{drive}} = \frac{10\,\text{nC}}{0.7\,\text{A (plateau)}} \approx 15\ \text{ns}$$

$$P_{VI} = \tfrac12 V I (t_r + t_f) f_{sw} = \tfrac12(25.2)(80)(30\,\text{ns})(48\,\text{kHz}) = \mathbf{1.45\ W}$$

### 2.2 Dead-Time Body-Diode Conduction

$$P_{dt} = V_{SD}\, I \cdot 2\,t_{dt} \cdot f_{sw} = 0.8 \times 80 \times 400\,\text{ns} \times 48\,\text{kHz} = \mathbf{1.23\ W}$$
