## 0. Architecture Decisions and Assumptions

Several of these choices drive every number that follows, so they come first.

| Item | Decision | Rationale |
|---|---|---|
| Commutation | Each of the 4 ESCs uses a dedicated MCU (AT32F421K8U7 running AM32, or STM32G071 running BLHeli_32). | ArduPilot on the H743 does not commutate motors. The H743 sends DShot600 and receives bidirectional eRPM telemetry. |
| Drive scheme | 6-step trapezoidal with complementary (synchronous) PWM at f_sw = 48 kHz. | This is the AM32/BLHeli_32 default class. |
| Battery | 6S LiPo, V_bus = 25.2 V maximum. | |
| MOSFETs | 40 V N-channel PDFN 3.3×3.3, one per switch position (24 total). | A "nano" footprint rules out paralleling. |
| 80A rating | Phase current during a conducting interval, per motor, as a burst. | |
| Board | 30.5×30.5 mm, 8-layer, 2 oz copper on all layers. | At 20×20 mm, 80A is not thermally credible (see §3.4). |
