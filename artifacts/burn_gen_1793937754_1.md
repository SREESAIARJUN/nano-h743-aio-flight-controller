## 0. Architecture Correction and Baseline Assumptions

**The H743 does not generate the 48 kHz motor PWM.** In a standard FC + 4-in-1 stack:

- **STM32H743 (FC, ArduPilot):** sends bidirectional DShot600 to four ESC MCUs and receives eRPM telemetry back.
- **4× ESC MCU (e.g. AT32F421 / STM32G071 running AM32 or BLHeli_32):** generates the 48 kHz complementary PWM, handles commutation and dead time.
- **3-phase gate driver ×4 (e.g. FD6288Q-class, 12 V gate supply):** drives 24 N-MOSFETs.

| Parameter | Assumed value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V max (worst case for switching) |
| Burst current | 80 A phase current per ESC (flat-top, trapezoidal) |
| f_sw | 48 kHz, synchronous (complementary) PWM |
| MOSFET | 40 V, R_DS(on) = 1.0 mΩ typ at 25 °C / V_GS = 10 V, Q_g = 50 nC, Q_gs2 + Q_gd = 14 nC, Q_rr = 40 nC, V_SD = 0.8 V, R_th,jc = 0.8 K/W (5×6 PQFN-class) |
| Dead time | t_d = 300 ns per edge |
| Gate drive | V_DRV = 12 V, R_g,total ≈ 10 Ω on / 5 Ω off, V_plateau ≈ 3.5 V |
| Ambient | 40 °C |
| T_j,max design limit | 125 °C (MOSFETs typically rated 150–175 °C; 25 °C margin) |

**Form-factor check:** 24 × 5×6 mm FETs cannot fit on a 20×20 mm nano board. Even 3.3×3.3 parts are marginal at 30×30 mm. An 80 A rating on a nano board is only credible as a **few-second burst** (see §3).

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 125 °C: R_DS = 1.0 × 1.6 = **1.6 mΩ**.

### 1.2 Bridge conduction (six-step, synchronous rectification)

During each 60° commutation sector, two phases are active. With complementary PWM, current in each active phase flows through either the high-side (HS) FET (for duty D) or the low-side (LS) FET (for 1−D). The current path therefore always contains exactly two channels in series:

$$P_{cond} = 2\,I_{ph}^2\,R_{DS}(T_j)$$

- 80 A, T_j = 125 °C: P_cond = 2 × 6400 × 1.6 mΩ = **20.5 W per ESC**
- Add PCB copper: a typical 2 oz path contributes R_Cu ≈ 0.3–0.5 mΩ, i.e. **+1.9–3.2 W**.

The loss rotates among all six FETs at the electrical frequency (kHz range). That is far faster than the FET thermal time constants, so the time-averaged loss per FET is P_cond / 6 (≈ 3.4 W).

### 1.3 Electrothermal convergence

R_DS depends on T_j, which depends on P_cond. Solve iteratively:

$$T_j = T_{ref} + R_{th}\cdot 2I^2 R_{DS,25}[1+\alpha(T_j-25)]$$

This is stable only while 2I²R_DS,25·α·R_th < 1. Check this condition for your final R_th. If it is violated, thermal runaway occurs.

## 2. Switching Loss Model at 48 kHz

Only the PWM-ing high-side FET hard-switches. The low-side FET switches at near-zero voltage after the body diode conducts during dead time.

### 2.1 Switching transition times

$$t_{on} = \frac{Q_{gs2}+Q_{gd}}{(V_{DRV}-V_{pl})/R_{g,on}} = \frac{14\,nC}{0.85\,A} = 16.5\ \text{ns}$$

$$t_{off} = \frac{Q_{gs2}+Q_{gd}}{V_{pl}/R_{g,off}} = \frac{14\,nC}{0.70\,A} = 20\ \text{ns}$$

### 2.2 Loss components (per ESC, V = 25.2 V, I = 80 A, f = 48 kHz)

| Component | Equation | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_on + t_off)·f | ½·25.2·80·36.5 ns·48k = **1.77 W** |
| Reverse recovery | Q_rr·V·f | 40 nC·25.2·48k = **0.05 W** |
| Output capacitance | E_oss·f (E_oss ≈ 0.6 µJ) | **0.03 W** |
| Dead-time body diode | V_SD·I·2t_d·f | 0.8·80·600 ns·48k = **1.84 W** |
| Gate charge (mostly in driver and R_g) | 2·Q_g·V_DRV·f | **0.06 W** |
| **Switching subtotal** | | **≈ 3.75 W** |

**Key insight:** dead-time diode loss is about the same size as switching loss. Reducing t_d from 300 ns to 150 ns (if the driver's propagation-delay mismatch allows) saves about 0.9 W per ESC. This is a firmware setting in AM32/BLHeli.
