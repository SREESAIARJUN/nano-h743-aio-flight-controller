## 0. Architecture Clarification and Feasibility Flags

Several issues need resolving before the math.

1. **The H743 does not commutate the motors.** In every viable 4-in-1 stack, the H743 is the flight controller running ArduPilot. Each motor is driven by its own ESC MCU running AM32 or BLHeli_32-class firmware. The H743 sends bidirectional DShot600 to those MCUs.
   - Typical ESC MCUs are the AT32F421 and STM32G071.
   - This design uses **4× AT32F421K8U7** plus one 3-phase gate driver each.
2. **The 80A burst figure must be qualified.**
   - 80A *per motor, one motor at a time, for 1–2 s* is achievable on a 30×30 board with 5×6 mm FETs.
   - 80A on *all four motors simultaneously* means 320A, or about 8 kW at 6S. That exceeds:
     - XT60/XT90 connector ratings,
     - the battery-lead ampacity of any nano build,
     - the thermal mass budget (shown in §3).
   - I model both cases.
3. **"Nano" form factor.** A 20×20 board cannot host 24 power FETs rated for 80A. I assume a **30.5×30.5 mm ESC board** stacked under a 20×20 or 30×30 H743 FC. If the 20×20 envelope is a hard requirement, the burst rating must drop to about 35–45A.

## 2. Loss Model (per motor channel)

### 2.1 Conduction Loss

Temperature-corrected on-resistance:

```
R_DS(Tj) = R25 · [1 + α·(Tj − 25)]
At Tj = 125 °C:  R_DS = 1.0 mΩ · (1 + 0.0055·100) = 1.55 mΩ
```

In 6-step operation with synchronous rectification, phase current I flows through exactly **two** conducting FETs at all times:

- **PWM ON (fraction D):** HS of phase A and LS of phase B.
- **PWM OFF (fraction 1−D):** LS of phase A (synchronous freewheel) and LS of phase B.

So total conduction loss is essentially independent of duty cycle:

```
P_cond,motor = 2 · I² · R_DS(Tj)
```

Per-FET breakdown over one electrical cycle (each phase is active 2/3 of the cycle, split HS/LS):

```
P_HS = (1/3)·D·I²·R_DS
P_LS = (1/3)·(1 + (1−D))·I²·R_DS = (1/3)·(2−D)·I²·R_DS
```

Note that the low-side FET runs hotter at low duty. This matters at punch-out from hover.

**At I = 80 A, Tj = 125 °C:**

```
P_cond,motor = 2 · 6400 · 1.55e-3 = 19.8 W
```

| D | P_HS (each) | P_LS (each) |
|---|---|---|
| 1.0 | 3.3 W | 3.3 W |
| 0.5 | 1.65 W | 4.95 W |
| 0.2 | 0.66 W | 5.94 W ← worst FET |

### 2.2 Switching Loss at 48 kHz

**Gate currents during the Miller plateau:**

```
I_g,on  = (V_DRV − V_pl) / (R_drv,src + R_g,ext + R_g,int)
        = (10 − 3.5) / (2 + 4.7 + 1)  = 0.84 A
I_g,off = V_pl / (R_drv,snk + R_g,ext + R_g,int)
        = 3.5 / (1 + 4.7 + 1)         = 0.52 A
```

**Transition times:**

```
t_r = (Q_gs2 + Q_gd) / I_g,on  = 14 nC / 0.84 A = 16.7 ns
t_f = (Q_gs2 + Q_gd) / I_g,off = 14 nC / 0.52 A = 26.9 ns
```

**Loss components** (one hard-switched HS FET per motor at any time):

| Term | Expression | Value @ 80 A |
|---|---|---|
| V–I overlap | ½·V·I·(t_r + t_f)·f_sw = ½·25.2·80·43.6 ns·48 k | **2.11 W** |
| Reverse recovery | Q_rr·V·f_s
