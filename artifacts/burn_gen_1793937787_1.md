# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion (Job #34)

I don't have the original Job #34 specification, so this design is built on the baseline assumptions below. Every parameter is a named constant, so you can re-target the code by changing the constants.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) on each axis |
| MCU | STM32G4/H7 class, FPU, 3× motor timers, 2× SPI for the IMUs |
| Current sense | Low-side or inline shunts (2 phases). A voltage-mode fallback is included. |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the payload rotation center |

Loop rates, each running inside the timer ISR chain:

```
PWM / current loop (FOC)     : 20 kHz   (Ts_i = 50 µs)
Velocity loop + anti-cogging : 4 kHz    (Ts_v = 250 µs)  every 5th current ISR
Position/attitude loop       : 1 kHz    (Ts_p = 1 ms)
IMU sampling (both, SPI DMA) : 8 kHz ODR, decimated/fused at 4 kHz
Notch re-tune / housekeeping : 1 kHz
```

Bandwidth separation should be at least 5× per cascade stage:

- Current loop ωc,i ≈ 2π·1.5 kHz
- Velocity loop ωc,v ≈ 2π·150 Hz
- Angle loop ωc,p ≈ 2π·20–30 Hz

## 1. FOC Equations

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found during alignment by injecting v_d along α and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque: τ = (3/2) p λ_m i_q = K_t i_q.

### 1.5 Current PI with decoupling and back-EMF feedforward

Pole-zero cancellation gives a first-order closed loop with bandwidth ωc,i:

$$K_{p,i} = L\,\omega_{c,i},\qquad K_{i,i} = R\,\omega_{c,i}$$

$$v_d^* = K_{p,i} e_d + K_{i,i}\!\int e_d\,dt - \omega_e L\, i_q$$

$$v_q^* = K_{p,i} e_q + K_{i,i}\!\int e_q\,dt + \omega_e L\, i_d + \omega_e\lambda_m$$

Discrete form (forward Euler, back-calculation anti-windup with gain K_aw ≈ 1/K_p):

$$I_k = I_{k-1} + T_s\left[K_i e_k + K_{aw}(u^{sat}_{k-1}-u_{k-1})\right]$$

### 1.6 Voltage limit (linear SVPWM region)

$$|v| \le V_{max} = \frac{V_{bus}}{\sqrt3}$$

The d-axis has priority:

$$v_q^{max} = \sqrt{V_{max}^2 - v_d^2}$$
