# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #10)

I don't have the Job #10 specification, so this design rests on the assumptions in §0. Wherever a number is marked *(assumed)*, replace it with your hardware value. The structure, equations and code do not depend on those values.

---

## 0. Assumptions and System Architecture

| Item | Value *(assumed)* |
|---|---|
| MCU | STM32G474 / H7 class: Cortex-M4F/M7, single-precision FPU, 3× advanced timers |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–12 Ω, L ≈ 1–3 mH |
| Current sensing | 2 or 3 low-side shunts, ADC triggered at PWM center |
| Rotor encoder | 14-bit absolute magnetic (AS5048A / MT6701) per axis |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI chip-selects, shared external CLKIN |
| Gimbal kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |

### Loop rates

```
 ICM-42688-P ×2 ── 8 kHz ODR ──► [Calib → Time-align → AdaptiveNotch → Fuse] ─► Mahony (1 kHz) ─► attitude q
                                         │ fused gyro ω_cam (8 kHz)
                                         ▼
 Setpoint ─► ANGLE P (1 kHz) ─► ω_ref ─► RATE PI (4 kHz, gyro-feedback) ─► iq_ref ─┐
                                                                                    + ◄─ Anti-cogging FF iq_ff(θm)
                                                                                    ▼
                         Encoder θm ─► FOC current PI d/q (20 kHz) ─► SVPWM ─► Motor
```
