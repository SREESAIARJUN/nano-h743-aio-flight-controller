# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

I don't have the original specification for Job #7, so this design states its assumptions in §0. Every equation is parameterized, so you can substitute your actual motor, encoder and MCU values. Values marked **[verify]** come from datasheet tables that you should check against your silicon revision.

## 0. System Assumptions and Loop Timing

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensing | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701) |
| Current sensing | 2-shunt low-side, sampled at PWM center |
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| IMU-A | ICM-42688-P on the **camera plate**, used for attitude and inertial rate feedback |
| IMU-B | ICM-42688-P on the **base/handle**, used for base-rate feedforward and as the vibration reference |
| Kinematic chain | base → yaw(z) → roll(x) → pitch(y) → camera |

**Loop rates (all phase-locked to the PWM timer):**

| Loop | Rate | Ts |
|---|---|---|
| PWM / current (FOC) | 20 kHz | 50 µs |
| IMU sample (both IMUs) | 8 kHz | 125 µs |
| Velocity / inertial rate | 4 kHz | 250 µs |
| Angle / attitude | 1 kHz | 1 ms |
| Adaptive notch and cogging LMS | 4 kHz | 250 µs |

**Bandwidth rule.** Each outer loop should have at most ¼–⅕ the bandwidth of the loop inside it:

ω_c ≈ 2π·1.5 kHz, ω_v ≈ 2π·150 Hz, ω_θ ≈ 2π·30 Hz.
