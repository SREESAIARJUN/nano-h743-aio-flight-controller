# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #3): Electro-Thermal and Timer/DMA Reference Design

## 0. Scope, Assumptions and Feasibility Warning

**Architecture.** An STM32H743 cannot commutate four BLDC motors directly at 48 kHz while also running ArduPilot. This design therefore uses the standard AIO architecture:

- **Flight controller:** STM32H743VIT6 running ArduPilot. It generates bidirectional DShot600 and decodes the eRPM telemetry.
- **ESC section:** 4 × AT32F421 (or STM32G071) running AM32, 4 × FD6288Q 3-phase gate drivers, and 24 N-channel MOSFETs.

**Electrical assumptions**

| Symbol | Value | Note |
|---|---|---|
| V_bus | 25.2 V (6S full) | Worst-case switching loss |
| I_burst | 80 A per motor (phase current, DC-equivalent) | ≤ 10 s target |
| f_sw | 48 kHz | AM32 PWM frequency |
| MOSFET | 40 V, 5×6 mm DFN class | Representative of the class; replace with your actual datasheet values |
| R_DS(on) @ 25 °C, V_GS = 10 V | 0.9 mΩ | |
| R_DS(on) temperature coefficient | ×1.6 at T_j = 125 °C | |
| Q_g / Q_gd / Q_rr / C_oss(er) | 45 nC / 9 nC / 35 nC / 900 pF | |
| t_r + t_f (with FD6288Q, R_g = 4.7 Ω) | ≈ 22 ns (effective V·I overlap) | |
| Dead time | 50 ns per edge | |
| Body-diode V_F @ 80 A | 0.85 V | |

> **Feasibility warning.** The numbers below show that 80 A per motor on a nano-format (20×20 or 25.5×25.5 mm) board is a **transient-only** rating of roughly 1.5–3 s from a cold start. It is not a continuous rating. Commercial "80 A" nano ESCs rely on optimistic marketing assumptions. The thermal model in §3 lets you set an honest rating.

## 1. Conduction Loss Model

### 1.1 Current paths with synchronous rectification

Commutation is six-step trapezoidal with complementary (synchronous) PWM on the active high side. At any instant, two half-bridges carry the phase current:

- **Switching leg:** the HS FET conducts for D·T_sw and the LS FET (sync rectifier) for (1−D)·T_sw. Exactly one FET conducts the full current at all times, apart from dead time.
- **Return leg:** its LS FET is held on for the entire 60° sector.

Conduction power is therefore independent of duty cycle:

$$P_{cond,motor} = 2\, I_{rms}^2\, R_{DS(on)}(T_j)$$

### 1.2 Ripple correction

Phase inductance L_ph is about 15 µH for a typical 2207–2810 motor. The ripple current is:

$$\Delta I = \frac{(V_{bus} - V_{bemf})\, D}{L_{ph}\, f_{sw}} \approx \frac{(25.2-21)(0.85)}{15\mu \cdot 48k} \approx 5\ \text{A}_{pp}$$

The RMS correction is negligible:

$$I_{rms}^2 = I^2\left(1+\frac{r^2}{12}\right),\quad r=\Delta I/I = 0.0625 \Rightarrow \times 1.0003$$

### 1.3 Temperature-dependent R_DS(on), solved iteratively

Model R_DS(on) as linear in temperature:

$$R_{DS(on)}(T_j) = R_{25}\left[1+\alpha (T_j-25)\right],\quad \alpha \approx 0.006\ /^\circ\text{C}$$

| T_j | R_DS(on) | P_cond per motor = 2·80²·R |
|---|---|---|
| 25 °C | 0.90 mΩ | 11.5 W |
| 100 °C | 1.31 mΩ | 16.8 W |
| 125 °C | 1.44 mΩ | 18.4 W |

### 1.4 Copper losses (often ignored, but significant)

**Board traces.** The phase plus bus path runs about 15 mm per motor, on 2 oz copper, 4 layers paralleled, 5 mm wide:

$$R_{Cu} = \rho \frac{l}{A} = 1.72\times10^{-8}\cdot\frac{0.015}{4\cdot 5\text{mm}\cdot 70\mu\text{m}} \approx 0.18\ \text{m}\Omega$$

$$P_{Cu} = 2\cdot 80^2 \cdot 0.18\text{m}\Omega \approx 2.3\ \text{W per motor}$$

**Solder joints and motor pads:** add about 0.1 mΩ, which is roughly 1.3 W.

**Battery input path at total current.** Bus current is approximately ΣI_phase × D, so at 4 × 80 A and D = 0.85 the bus carries about 272 A. That is an extreme input current. Through the pads and plane (about 0.25 mΩ) it dissipates:

$$P = 272^2 \cdot 0.25\text{m}\Omega \approx 18.5\ \text{W}$$

> This input-path term is a design-breaking number. It requires XT90/AS150-class leads soldered directly to the board and full-copper pours on all inner layers.

## 2. Switching Loss Model at 48 kHz

Only the switching leg's FET pair dissipates switching energy each PWM period. The return leg is static.

### 2.1 Hard-switching V–I overlap

The HS FET turns on and off against an LS body diode (inductive load):

$$P_{VI} = \tfrac12 V_{bus}\, I\, (t_r+t_f)\, f_{sw} = 0.5\cdot25.2\cdot80\cdot22\text{ns}\cdot48\text{k} = 1.06\ \text{W}$$

Check t_r from the gate charge: the FD6288Q sources/sinks about 1.0/1.5 A. With R_g = 4.7 Ω and the Miller plateau at about 3.5 V:

$$t_{Miller} \approx \frac{Q_{gd}\,(R_{drv}+R_g)}{V_{drv}-V_{plateau}} = \frac{9\text{nC}\cdot(6+4.7)}{12-3.5} \approx 11\ \text{ns}$$

Turn-on plus turn-off is therefore about 22 ns, which is consistent with the assumption above.

$$P_{oss} = C_{oss(er)}\,V_{bus}^2\, f_{sw} \cdot \tfrac12\cdot 2\ (\text{HS}+\text{LS}) = 900\text{p}\cdot 25.2^2 \cdot 48\text{k} = 0.027\ \text{W}$$
