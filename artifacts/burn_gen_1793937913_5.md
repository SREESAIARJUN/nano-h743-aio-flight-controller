# STM32H743 Nano FC + 4-in-1 ESC (Job #16): Power-Stage Loss Model, Thermal Analysis, and Bi-Directional DShot600 Timer/DMA Allocation

> **Read this first.** The 80 A burst figure does not survive the thermal math on a nano (20×20 mm) footprint for more than about 1 second with all four channels loaded, and only for a few seconds on one channel. The derivation below shows why. The model is parameterized so you can substitute the real MOSFET datasheet values. Every number marked **[A]** is an assumption to replace with vendor data before design review.

---

## 0. Architecture Clarification

The STM32H743 is the **flight controller** MCU running ArduPilot. It does **not** commutate the motors. Each of the four ESC channels has its own small MCU running AM32 or BLHeli_32-class firmware, plus a 3-phase gate driver and 6 MOSFETs. The H743 talks to each ESC over one bi-directional DShot600 wire.

```
6S Pack ──┬── Bulk C ── 4× [ESC MCU → 3φ gate driver → 6× N-FET half-bridges] → Motors 1–4
          │                     ▲ DShot600 bidir (1 wire per motor)
          └── 5V/3V3 BEC ── STM32H743 (ArduPilot) ── IMU (SPI), Baro (I2C), OSD, UARTs
```

## 2. Conduction Loss Model

### 2.1 Commutation topology

The ESC uses 6-step trapezoidal commutation with complementary (synchronous) PWM. At every instant, two phases carry the full current I:

- **PWM-on:** one high-side FET (HS_a) plus one low-side FET (LS_b).
- **PWM-off:** the complementary low-side FET (LS_a) plus LS_b.

So the current always flows through exactly **two** FETs in series, regardless of duty cycle D.

### 2.2 Temperature-dependent R_DS(on)

```
R_ds(T_j) = R₂₅ · [1 + α·(T_j − 25)]
```

At T_j = 115 °C: R_ds = 1.0 × (1 + 0.0055×90) ≈ **1.5 mΩ**.

### 2.3 RMS current including ripple

```
I_rms² = I² · (1 + r²/12),   where r = ΔI_pp / I
```

With motor inductance at 48 kHz, r is typically 0.1–0.2. The ripple term then adds less than 0.4 %, so it is neglected.

### 2.4 Conduction loss per channel

```
P_cond,FET = I² · 2 · R_ds(T_j) = 80² × 2 × 1.5 mΩ = 19.2 W
P_cond,Cu  = I² · R_cu          = 80² × 0.5 mΩ
