# STM32H743 AIO Flight Controller + 4-in-1 ESC: Technical Design Package (Job #78)

## 0. Architecture and Assumptions

### 0.1 System partitioning

The STM32H743 does **not** commutate the motors. It runs ArduPilot and generates four bidirectional DShot600 streams. Each ESC channel has its own commutation MCU running AM32 or BLHeli_32, which generates the 48 kHz complementary PWM.

```
 [STM32H743 – ArduPilot]
   ├── TIM3_CH3 / TIM3_CH4 / TIM5_CH1 / TIM5_CH2  ── Bidir DShot600 ──►
   │                                                [ESC MCU ×4 (or 1 quad-MCU)]
   │                                                    ├── 3-phase gate driver
   │                                                    └── 6× N-MOSFET half-bridges ── Motor 1..4
   └── ADC: VBAT divider, ICURR (shunt amp)
```
