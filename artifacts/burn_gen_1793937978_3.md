| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P, so pole pairs p = 7 |
| Phase parameters | R = 5.6 Ω, L = 1.8 mH, λ_m from Kt |
| Kt | 0.11 N·m/A (Kt = 1.5·p·λ_m) |
| Axis inertia | J = 2.5×10⁻⁴ kg·m² |
| Bus voltage | 16.8 V (4S) |
| Encoder | 14-bit absolute magnetic encoder (e.g. AS5048/MT6701) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR |
| MCU | Cortex-M4F/M7 with single-precision FPU |

Loop rates:

| Loop | Rate | Ts | Trigger |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | PWM center ISR |
| Velocity | 4 kHz | 250 µs | every 5th current tick |
| IMU fusion | 8 kHz | 125 µs | IMU data-ready |
| Angle | 1 kHz | 1 ms | every 4th velocity tick |

Each loop's bandwidth is at least 4–5× below the loop inside it, which is the standard rule for cascade separation.

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle:
θ_e = p·(θ_m − θ_offset) mod 2π

Clarke transform (amplitude-invariant):
- i_α = i_a
- i_β = (i_a + 2·i_b)/√3

Park transform:
- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

### 1.2 PMSM Model in the d-q Frame

- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·(L·i_d + λ_m)
- Torque: τ = (3/2)·p·λ_m·i_q = K_t·i_q (surface-mounted magnets, so L_d = L_q)

### 1.3 Current PI with Decoupling

Feedforward cancels the cross-coupling and back-EMF terms:
- v_d = PI_d(i_d* − i_d) − ω_e·L·i_q
- v_q = PI_q(i_q* − i_q) + ω_e·(L·i_d + λ_m)

**Pole-zero cancellation tuning.** The plant is 1/(Ls + R). Choose:
- K_p = L·ω_c
- K_i = R·ω_c

The closed loop then becomes ω_c/(s + ω_c). With ω_c = 2π·2000 rad/s (one tenth of the PWM rate):
- K_p ≈ 22.6 V/A
- K_i ≈ 70 372 V/(A·s)

Set i_d* = 0. This gives maximum torque per amp for surface PMSMs.

### 1.4 Discrete PI with Back-Calculation Anti-Windup

- u_k = K_p·e_k + I_k
- u_k^sat = clamp(u_k, −U_max, U_max)
- I_{k+1} = I_k + K_i·T_s·e_k + K_aw·(u_k^sat − u_k)

A good default is K_aw = 1/K_p.

### 1.5 Voltage Limit and SVPWM

Circular limit: if |v_dq| > V_bus/√3, scale v_dq onto that circle.

Inverse Park gives v_α and v_β. The min-max zero-sequence injection is equivalent to SVPWM:
- v_x is the phase voltage of each phase, x ∈ {a, b, c}
- v_0 = −(max(v_x) + min(v_x))/2
- d_x = ½ + (v_x + v_0)/V_bus

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Structure

```
θ* ──►[P + vel FF]──ω*──►[PI + accel FF]──τ*──►(+ cogging FF)──÷Kt──► i_q* ──►[FOC]
        ▲ θ̂ (IMU attitude → joint)   ▲ ω̂ (gyro, joint frame)
```

On a gimbal, stabilization feedback should come from the **camera-plate IMU**, not the motor encoder. The encoder handles commutation and supplies the cogging angle. The IMU measures the actual inertial disturbance.

### 2.2 Mapping Camera-Frame Rates to Joint Rates

For a yaw-roll-pitch gimbal (outer to inner), the camera body rate ω_c relates to the joint rates q̇ through the Jacobian:

ω_c = J(q)·q̇

with columns:
- J(q) = [ R_y(q_p)ᵀ·R_x(q_r)ᵀ·ẑ,  R_y(q_p)ᵀ·x̂,  ŷ ]

Each axis therefore uses:
- ω̂_joint = J(q)⁻¹·ω̂_cam
- e_θ = J(q)⁻¹·LogSO(3)(R*ᵀ·R̂)

This is the small-angle attitude error mapped into joint space. It is singular at gimbal lock (q_r = ±90°), so clamp there.

### 2.3 Angle Loop (P with Velocity Feedforward)

ω* = K_θ·e_θ + θ̇*_ref

Rule of thumb: K_θ = ω_v/4. A P-only angle loop is sufficient because the velocity loop already contains an integrator. That makes the angle loop type 2 overall.
