## 1. Field-Oriented Control (inner current loop, 20 kHz)

### 1.1 Frame transforms
Electrical angle: θₑ = Np·(θₘ − θ_offset), wrapped to [0, 2π).

**Clarke transform** (amplitude-invariant, assumes iₐ + i_b + i_c = 0):

  i_α = iₐ
  i_β = (iₐ + 2·i_b) / √3

**Park transform:**

  i_d = i_α·cos θₑ + i_β·sin θₑ
  i_q = −i_α·sin θₑ + i_β·cos θₑ

### 1.2 PMSM model in the dq frame

  v_d = R·i_d + L_d·di_d/dt − ωₑ·L_q·i_q
  v_q = R·i_q + L_q·di_q/dt + ωₑ·(L_d·i_d + λ_m)
  τ = (3/2)·Np·λ_m·i_q = Kt·i_q    (surface PM, L_d = L_q)

### 1.3 Current PI with decoupling

  v_d* = PI_d(i_d* − i_d) − ωₑ·L·i_q
  v_q* = PI_q(i_q* − i_q) + ωₑ·(L·i_d + λ_m)

Normally i_d* = 0.

**Gains by pole-zero cancellation.** The plant is 1/(Ls + R). Choosing

  K_p,i = L·ω_ci
  K_i,i = R·ω_ci

gives a closed loop of ω_ci/(s + ω_ci).

- Use ω_ci ≈ 2π·1.5 kHz, which is ≤ f_s/10 to leave margin for the 1.5-sample PWM/computation delay.
- With the assumed motor: K_p ≈ 18.8 V/A, K_i ≈ 47 000 V/(A·s).

**Discrete integrator** (forward Euler, Tₛ = 50 µs), with conditional-integration anti-windup:

  I[k+1] = I[k] + K_i·Tₛ·e[k]   only if the output is unsaturated, or e[k] drives it back out of saturation.

**Voltage limiting.** The linear SVPWM limit is |v| ≤ V_bus/√3. The dq vector is limited circularly with q-axis priority:

  v_d ← clamp(v_d, ±V_max)
  v_q ← clamp(v_q, ±√(V_max² − v_d²))

**Delay compensation.** Advance the inverse-Park angle to account for one-and-a-half sample periods:

  θₑ,out = θₑ + 1.5·ωₑ·Tₛ

### 1.4 Inverse Park and SVPWM (min–max zero-sequence injection)

  v_α = v_d·cos θ − v_q·sin θ
  v_β = v_d·sin θ + v_q·cos θ

  vₐ = v_α
  v_b = −½·v_α + (√3/2)·v_β
  v_c = −½·v_α − (√3/2)·v_β

  v₀ = −(max(vₐ,v_b,v_c) + min(vₐ,v_b,v_c)) / 2

  D_x = ½ + (v_x + v₀)/V_bus,   x ∈ {a, b, c}

This is mathematically equivalent to 7-segment SVPWM.

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Velocity estimation (encoder PLL)
Differentiating a 14-bit encoder directly is too noisy, so velocity comes from a type-2 PLL:

  e = wrap_π(θₘ − θ̂)
  ω̂[k+1] = ω̂[k] + K_i,pll·Tₛ·e
  θ̂[k+1] = θ̂[k] + Tₛ·(ω̂[k] + K_p,pll·e)

Gains:

  K_p,pll = 2ζ·ω_pll,   K_i,pll = ω_pll²

Use ζ = 1 and ω_pll ≈ 2π·300 Hz. For a gimbal, the IMU gyro can instead serve as the velocity feedback; see §2.4.

### 2.2 Velocity PI (5 kHz)
The plant from i_q to ω is Kt/(J·s + B), with a load disturbance τ_d.

Control law:

  i_q* = K_p,v·e_ω + K_i,v·∫e_ω dt + i_ff,cog(θₘ) + i_ff,acc

Feedforward terms:

- i_ff,acc = J·α*/Kt
- i_ff,cog is the anti-cogging term from §3.

**Tuning (symmetric optimum, separation factor a ≈ 3–4):**

  ω_cv = ω_ci / 10
  K_p,v = J·ω_cv / Kt
  K_i,v = K_p,v·ω_cv / a²

Add a first-order low-pass filter on e_ω with cutoff ≈ 3·ω_cv. Anti-windup uses back-calculation:

  İ = K_i,v·e_ω + K_aw·(sat(u) − u),   with K_aw = 1/K_p,v

### 2.3 Angle P loop with velocity feedforward (1 kHz)

  ω* = K_p,θ·wrap_π(θ* − θ) + ω_ff
  K_p,θ = ω_cv / 4

ω_ff = θ̇* comes from the trajectory generator or from operator stick rate.

### 2.4 Gimbal-specific stabilization topology
A stabilizer should close the outer loops on inertial quantities rather than on joint angles. Per axis:

- **Angle loop:** the error is (q_target ⊗ q̂_camera⁻¹), taken as a small-angle vector and projected onto that motor's axis through the inverse joint Jacobian.
- **Velocity loop:** uses the fused gyro rate (§4) of the camera plate. This rejects base motion at the gyro bandwidth.
- **Encoder role:** the encoder is used only for commutation (θₑ), cogging-table lookup, and joint limits.
