# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion: Design Specification

## 0. Assumptions and Architecture

I don't have the Job #20 specification. The defaults below are typical for a brushless gimbal. Replace every value marked **[P]** with your measured or specified parameter.

| Item | Assumption |
|---|---|
| MCU | STM32G474 / H7-class: FPU, hardware CORDIC optional, 3× advanced timers |
| Motors | Gimbal BLDC/PMSM, e.g. GBM4108: 11 pole pairs, 12 slots **[P]** |
| Motor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6835) |
| IMUs | 2× ICM-42688-P on the camera plate, mounted point-symmetric about the camera CoM |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries the camera) |

### Loop rates

| Loop | Rate | Ts | Bandwidth target |
|---|---|---|---|
| Current (FOC) | 20 kHz | 50 µs | ω_c = 2π·1500 rad/s |
| IMU ODR (both) | 8 kHz | 125 µs | — |
| Velocity (gyro-based) | 4 kHz | 250 µs | ω_v = 2π·120 rad/s |
| Attitude (angle) | 1 kHz | 1 ms | ω_p = 2π·20 rad/s |

### Signal flow

```
 q_cmd ─►[Attitude P + ω_ff]─► ω_cmd(cam frame) ─►(−)─► J⁻¹(q_enc) ─►[Vel PI ×3]─► i_q,fb
                                                  ▲                                │
                       ω̂_cam (dual-IMU fused) ───┘                                ▼
                                                        i_q,ref = i_q,fb + i_cog(θ_m) + i_ff
                                                                                   │
              θ_e from encoder ─► [Park / PI current d,q / decoupling / SVPWM] ◄────┘
```
