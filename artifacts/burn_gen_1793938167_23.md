## 0. Architecture and Scope

The STM32H743 does not commutate the motors. It runs ArduPilot and sends bidirectional DShot600 commands to four dedicated ESC MCUs on the same PCB. This is the only architecture in which "bidirectional DShot" is meaningful.

```
 6S LiPo ──┬── Bulk caps ── 4× 3-phase bridges (24 MOSFETs)
           │                     ▲ gate drive
           │               4× FD6288Q (or equiv) 3-ph drivers
           │                     ▲ 6 PWM
           │               4× AT32F421 (AM32 firmware) ── BEMF comparators
           │                     ▲ DShot600 bidir (1 wire each)
           └── BEC 5V/10V ── STM32H743 (ArduPilot) ── IMU/Baro/OSD/UARTs
```

**Design baseline.** Every number below follows from these assumptions. Change them and re-run the equations.

| Parameter | Value | Note |
|---|---|---|
| Battery | 6S, V_bus = 25.2 V max | 40 V MOSFETs required |
| Burst current | 80 A per motor, ≤10 s | Phase (motor) current |
| PWM frequency | 48 kHz, complementary (synchronous rectification) | AM32 setting |
| MOSFET | 40 V, R_DS(on) = 1.0 mΩ @25 °C, Q_g = 50 nC, Q_gd ≈ 10 nC, Q_oss ≈ 40 nC, Q_rr ≈ 50 nC, R_θJC ≈ 1.5 K/W | Representative 3.3×3.3 or 5×6 DFN class |
| Board | 36×36 mm, 4-layer (2 oz outer, 2 oz inner) | 30.5×30.5 mounting |
| Ambient | 40 °C | With prop wash |

> **Important framing:** A component-level datasheet will replace each of these MOSFET values. The model structure is the deliverable. The specific numbers are representative, not vendor-verified.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1 + \alpha (T_j - 25)],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

| T_j | R_DS(on) |
|---|---|
| 25 °C | 1.00 mΩ |
| 100 °C | 1.45 mΩ |
| 125 °C | 1.60 mΩ |

### 1.2 Current path in trapezoidal (6-step) commutation

At any instant, two phases conduct:

- **Phase A, PWM leg:** the high side conducts for duty D. The low side conducts for 1−D under synchronous rectification.
- **Phase B, static leg:** the low side conducts 100% of the 60° sector.

Phase current I flows continuously through exactly two channels, regardless of D:

$$P_{cond,motor} = I^2 R_{DS}\,[D + (1-D)] + I^2 R_{DS} = 2 I^2 R_{DS}(T_j)$$

At I = 80 A and T_j = 100 °C:

$$P_{cond} = 2 (80)^2 (1.45\times10^{-3}) = 18.56\ \text{W per motor}$$
