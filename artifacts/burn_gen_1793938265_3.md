# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion: Design Specification and Implementation

I don't have the Job #15 requirements, so this design rests on the assumptions in §0. Every parameter is a named constant, so you can substitute your actual hardware values. Where a value must be verified on hardware (register maps, motor constants), I flag it.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 @ 170 MHz, single-precision FPU |
| Motors | 3× GBM2804-class, 12N14P (Q = 12 slots, 2p = 14 poles, p = 7), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoders | 14-bit absolute magnetic (MT6701 / AS5048A), one per joint |
| Current sensing | Inline shunts (current mode). A voltage-mode fallback is provided for boards without shunts. |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR = 8 kHz |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
