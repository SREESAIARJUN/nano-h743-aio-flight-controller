# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #17 specification, so the design below is fully parameterized around these baseline assumptions. Replace them with the real values; every gain is derived from them.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class (FPU, single-precision float, ≥170 MHz) |
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (MT6701 / AS5048A) |
| Current sense | 2-shunt, inline or low-side, synchronous to PWM center |
| IMUs | 2× ICM-42688-P on SPI at 24 MHz. IMU-A sits on the camera plate; IMU-B sits on the camera plate on a separate, rotated footprint (redundant pair). |
| Gimbal chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

Loop rates:

| Loop | Rate | Period |
|---|---|---|
| Current (FOC) | 20 kHz | T_c = 50 µs |
| Velocity | 4 kHz | T_v = 250 µs |
| Angle / attitude | 1 kHz | T_a = 1 ms |
| IMU ODR | 8 kHz | Decimated 2:1 into the velocity loop after filtering |
