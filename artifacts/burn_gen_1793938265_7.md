# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original Job #6 spec, so this design is built on the assumptions below. Every one of them is a parameter in `GimbalConfig`. Replace them with your measured values; the equations stay the same.

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motor, 12N14P (p = 7 pole pairs), R = 5.6 Ω, L = 2.1 mH, flux λ = 2.4 mWb |
| Encoders | 14-bit absolute magnetic (AS5048A / MT6701 class), one per joint |
| MCU | STM32G4 / H7 class, FPU, 3 timers with center-aligned PWM and synchronized ADC |
| Current sensing | 2-phase low-side shunts |
| IMU-P | ICM-42688-P on the camera payload. It provides feedback. |
| IMU-F | ICM-42688-P on the frame/handle. It provides the disturbance reference. |
| Kinematic order | Frame → Yaw (z) → Roll (x) → Pitch (y) → Payload |
| Loop rates | Current 20 kHz, rate loop 8 kHz (IMU data-ready), attitude 1 kHz |
