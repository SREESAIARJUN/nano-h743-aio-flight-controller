# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion: Design Specification

**Scope:** cascaded angle/velocity/current control, anti-cogging feedforward, and vibration rejection using two ICM-42688-P IMUs. C++17 implementation for an embedded target.

---

## 0. Baseline Assumptions

I don't have the Job #18 hardware specification, so the design uses the typical values below. Every value is a named constant in the code, so you can change any of them without touching the equations.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC (GBM2804-class): 12N14P, p = 7 pole pairs, R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A), one per axis |
| Current sensing | 2-shunt inline or low-side, sampled at PWM center |
| PWM / current loop | 20 kHz center-aligned, current loop at 20 kHz |
| Velocity loop | 4 kHz (decimation 5) |
| Angle loop | 1 kHz (decimation 20) |
| IMU | 2 × ICM-42688-P on the camera plate, SPI 24 MHz, gyro/accel ODR 8 kHz (FIFO) |
| Vibration source | UAV propellers, 80–250 Hz fundamental plus harmonics |

## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

- θ_off is found at commissioning: inject d-axis voltage at θ_e = 0 and record θ_m.
- The electrical speed used for decoupling comes from the angle PLL (§2.4): ω_e = p·ω̂_m.

### 1.2 Clarke and Park transforms (amplitude-invariant)

Clarke, using i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant model (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 1.4 Current PI with decoupling

After decoupling, each axis is the first-order plant 1/(Ls+R). Choosing the PI zero to cancel the electrical pole gives a closed loop of ω_c/(s+ω_c):

$$K_p^{i} = L\,\omega_c,\qquad K_i^{i} = R\,\omega_c$$

Use ω_c = 2π·1.5 kHz (about f_pwm/13, which leaves margin for the 1.5-sample transport delay).

The decoupling feedforward terms are:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m)$$

### 1.5 Discretization (backward Euler on the integrator)

$$u_k = K_p e_k + I_{k},\qquad I_{k+1} = I_k + K_i T_s e_k + K_{aw}\,(u_k^{sat} - u_k)$$

$$|v_{dq}| \le V_{max} = \frac{V_{bus}}{\sqrt3}\cdot 0.95$$
