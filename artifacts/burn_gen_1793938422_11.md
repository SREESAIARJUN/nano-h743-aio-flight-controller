# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the specification for Job #25, so the design uses the explicit assumptions below. Every hardware-dependent number is a named constant, so you can replace them without changing the structure.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω (phase), L ≈ 1.5 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per axis (e.g. MT6701), read at 20 kHz |
| MCU | STM32G4/H7-class, FPU, center-aligned PWM 20 kHz, 3-shunt or 2-shunt sensing |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, ODR 8 kHz, gyro ±2000 dps, accel ±16 g |
| Kinematics | Yaw (outer, joint q₁) → Roll (q₂) → Pitch (inner, q₃, camera) |
