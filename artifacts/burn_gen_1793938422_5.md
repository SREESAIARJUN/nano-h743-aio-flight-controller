# 3-Axis Gimbal: FOC, Cascaded Control, Anti-Cogging and Dual-IMU Fusion

I don't have project-specific data for Job #43, so this design uses the **assumed parameters** below. Every value is a constructor or configuration parameter, so you can substitute measured values without changing structure.

| Item | Assumed value |
|---|---|
| MCU | Cortex-M4F/M7 with FPU (e.g. STM32G474 / H723) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit magnetic encoder (MT6701 / AS5048A) per axis |
| Current sense | 2-shunt or inline, sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz |
| Axis order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates and bandwidths**

| Loop | Rate | Target bandwidth |
|---|---|---|
| PWM / current (FOC) | 20 kHz | 1.5–2 kHz |
| IMU ODR + filtering | 8 kHz | — |
| Velocity | 4 kH
