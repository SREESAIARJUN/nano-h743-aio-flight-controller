# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #6 specification, so this design rests on the assumptions below. Every parameter is a named constant, so you can substitute your real values.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class (FPU, 170+ MHz) |
| Motor | Gimbal BLDC, 12N14P (p = 7 pole pairs), R = 5.6 Ω (phase), L = 1.8 mH, λ ≈ 0.0045 V·s/rad |
| Driver | 3-phase bridge with low-side or inline current sensing |
| Encoder | 14-bit absolute magnetic encoder (MT6701/AS5047), read over SPI each PWM cycle |
| IMUs | 2 × ICM-42688-P on the camera plate, gyro ODR 8 kHz, ±1000 dps |
| Vibration source | Multirotor propeller fundamental and harmonics, 80–400 Hz, time-varying |

```
            ┌──────────── 1 kHz ────────────┐  ┌──── 4 kHz ─────┐  ┌──── 20 kHz ─────┐
 θ_ref ──►( Σ )─► Angle P + FF ──► ω_ref ──►( Σ )─► Vel PI ──► i_q* ─(+i_cog)─► Current PI (d,q) ─► SVPWM
             ▲ θ_cam (Mahony, fused IMU)       ▲ ω_cam (fused, notched gyro)         ▲ i_d,i_q (Clarke/Park, θ_e from encoder)
```

- **Inertial loops (angle and velocity)** use the fused IMU signals. They stabilise the camera, not the motor shaft.
- **Commutation and anti-cogging** use the encoder angle.

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms

**Electrical angle:**

$$\theta_e = p\,\theta_m - \theta_{e,0}$$

**Clarke transform** (amplitude-invariant, with $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and Decoupling

The surface PMSM dynamics in the dq frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

With feedforward decoupling

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda)$$

each axis reduces to $G_i(s)=\dfrac{1}{Ls+R}$.

**Electromagnetic torque:**

$$\tau_e = \tfrac32 p\lambda\, i_q = K_t\, i_q$$
