# STM32H743 Nano FC + 4-in-1 ESC (Job #24): Power-Stage Model, Bidirectional DShot600 Timer/DMA Plan, and Reference Netlists

## 0. Scope and Assumptions

No component datasheets or job specifications were provided, so this document uses explicit assumed parameters. Every equation is parametric: substitute your selected MOSFET and driver values and the results update directly.

**Architecture.** The STM32H743 is the flight controller MCU. It does not commutate motors. A 4-in-1 ESC has four ESC MCUs (for example AT32F421 or STM32G071 running AM32/BLHeli_32-class firmware), each driving three half-bridges. The H743 generates DShot600 and decodes the eRPM telemetry returned on the same wire.

## 1. Conduction Loss Model

### 1.1 Commutation topology

The model assumes trapezoidal (6-step) drive with complementary (synchronous) PWM on the active high side, at duty D. In each 60° sector:

- **Switching leg:** the high-side FET conducts for D·T and the low-side FET (synchronous rectification) conducts for (1−D)·T. Together they carry the phase current for 100 % of the period.
- **Return leg:** the low-side FET conducts continuously.

Phase current is I_ph. Average battery current is I_bat ≈ D·I_ph.

### 1.2 Temperature-dependent resistance

$$R_{DS}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right]$$

At T_j = 110 °C: R = 0.8 mΩ × (1 + 0.006 × 85) = **1.21 mΩ**.

### 1.3 RMS current including ripple

The phase current has a triangular ripple of peak-to-peak amplitude ΔI:

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}, \qquad \Delta I = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

With L_ph = 20 µH, near full throttle with V_bus − V_bemf ≈ 3 V, D ≈ 0.9:

- ΔI ≈ 2.8 A
- ΔI²/12 ≈ 0.65 A²

This is negligible against I² = 6400 A², so it is dropped.

### 1.4 Per-motor conduction loss

$$P_{cond} = \underbrace{I^2 R\,D + I^2 R\,(1-D)}_{\text{switching leg}} + \underbrace{I^2 R}_{\text{return leg}} = 2\,I^2 R_{DS}(T_j)$$

$$P_{cond} = 2 \times 80^2 \times 1.21\times10^{-3} = \mathbf{15.5\ W\ per\ motor}$$

Copper and solder loss. Phase traces, solder joints and the shunt add an estimated R_cu ≈ 0.3 mΩ per conducting path:

- 2 × 6400 × 0.3 mΩ ≈ **3.8 W per motor**

This term is frequently omitted. On a nano board it is not negligible.

### 1.5 Electro-thermal coupling (fixed point)

R_DS rises with T_j, and T_j rises with loss, so solve iteratively:

$$T_j^{(n+1)} = T_{board} + R_{\theta JC}\cdot\tfrac{1}{2}P_{cond}\!\left(T_j^{(n)}\right)$$

Each motor's 15.5 W is shared between two conducting FETs, about 7.7 W per FET. That gives ΔT_JC ≈ 1.5 × 7.7 = **11.6 K** above the board. The iteration converges within 2–3 steps because ∂P/∂T × R_θ ≪ 1.
