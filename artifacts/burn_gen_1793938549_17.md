# STM32H743 AIO Flight Controller + 4-in-1 80 A ESC: Design Model (Job #66)

**Scope.** This covers the power stage loss model, the thermal budget, the bi-directional DShot600 timer and DMA plan for ArduPilot, and the reference netlists.

**Data sources.** All component values are representative parameters, not quotes from a specific datasheet. Every number marked **[VERIFY]** must be replaced with the selected part's datasheet value before layout freeze.

## 0. System Architecture and Key Assumptions

**Signal and power chain**

```
LiPo 6S (25.2 V max)
   │
   ├── Bulk caps + TVS ──► 4× three-phase bridges (24 MOSFETs)
   │                          ▲
   │                    4× 3-ph gate drivers (FD6288Q-class)
   │                          ▲
   │                    4× ESC MCUs (AT32F421 / STM32G071, AM32 firmware)
   │                          ▲  bi-directional DShot600 (1 wire per motor)
   │                    STM32H743 FC (ArduPilot)
   └── BEC 10 V (gate drive), BEC 5 V, LDO 3.3 V
```

**Important architectural point.** The H743 does not generate the 48 kHz bridge PWM. That is the job of the per-motor ESC MCUs (AM32 supports a 48 kHz PWM setting and bi-directional DShot). The H743 only drives four DShot lines and captures the eRPM telemetry.

| Parameter | Value |
|---|---|
| Battery | 6S, V_in,max = 25.2 V |
| Burst current | 80 A per motor (burst rating, not continuous) |
| Switching frequency f_sw | 48 kHz |
| Commutation | 6-step trapezoidal, complementary (synchronous) PWM |
| MOSFET (representative) | 40 V N-ch, R_ds(on),25 = 1.
