# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the specification for "Job #12", so this design is built on the assumptions below. Every parameter is a named constant, so you can substitute your real values.

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU, CORDIC) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5.6 Ω, L ≈ 2.1 mH, Kt ≈ 0.08 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis, SPI |
| Inverter | 3-phase, 24 V bus, 3-shunt low-side current sensing |
| IMUs | 2× ICM-42688-P on the camera plate (IMU-A and IMU-B), separate SPI buses |
| Disturbance | Multirotor airframe, propeller vibration 80–400 Hz plus harmonics |

**Loop rate hierarchy (all derived from one PWM timer):**

```
PWM 40 kHz center-aligned ─┬─ ADC trigger @ 20 kHz ─► Current loop (FOC)       Ts_i = 50 µs
                           ├─ /5  → 4 kHz           ─► Velocity loop + anti-cog Ts_v = 250 µs
                           ├─ /20 → 1 kHz           ─► Angle loop + attitude    Ts_a = 1 ms
IMU A/B ODR 8 kHz (FIFO) ──┴─ batch-read @ 4 kHz → notch/LPF → fusion → 1 kHz attitude
```

A rule of thumb sets the bandwidth separation: each outer loop should have a crossover at or below 1/5–1/10 of the inner loop's crossover.

| Loop | Crossover target |
|---|---|
| Current | ω_ci ≈ 2π·1500 rad/s |
| Velocity | ω_cv ≈ 2π·150 rad/s |
| Angle | ω_cθ ≈ 2π·20 rad/s |

## 1. Field-Oriented Control (Current Loop)

### 1.1 Motor model in the rotor (dq) frame

Electrical angle: θ_e = p·θ_m − θ_offset

$$
v_d = R i_d + L_d \frac{di_d}{dt} - \omega_e L_q i_q
$$
$$
v_q = R i_q + L_q \frac{di_q}{dt} + \omega_e L_d i_d + \omega_e \lambda_m
$$
$$
\tau_e = \tfrac{3}{2} p \left[\lambda_m i_q + (L_d - L_q) i_d i_q\right] \approx K_t\, i_q,\qquad K_t = \tfrac32 p\lambda_m
$$

Gimbal motors are surface-mount PM machines (L_d ≈ L_q = L), so i_d* = 0.

### 1.2 Transforms

**Clarke (amplitude-invariant, 3 shunts):**
$$
i_\alpha = \tfrac{2}{3}i_a - \tfrac13(i_b+i_c),\qquad i_\beta = \tfrac{1}{\sqrt3}(i_b - i_c)
$$

**Park:**
$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park:**
$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

**Delay compensation.** PWM update and ADC sampling add about 1.5·Ts_i of delay. Advance the angle used in the inverse Park:
$$
\theta_e^{\text{out}} = \theta_e + 1.5\,\omega_e T_{s,i}
$$

### 1.3 Current PI with decoupling (pole-zero cancellation)

Plant per axis: G(s) = 1/(Ls + R). With a PI controller C(s) = K_p + K_i/s, choose

$$
K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}
$$

Then L(s) = ω_ci/s and the closed loop is first order with bandwidth ω_ci.

**Voltage commands with feed-forward decoupling:**
$$
v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q
$$
$$
v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e (L i_d + \lambda_m)
$$

**Discrete PI (backward Euler integrator) with back-calculation anti-windup:**
$$
u_k = K_p e_k + I_k,\qquad \bar u_k = \text{sat}(u_k)
$$
$$
I_{k+1} = I_k + K_i T_s e_k + K_{aw}(\bar u_k - u_k),\qquad K_{aw}\approx K_i/K_p
$$

**Voltage-vector saturation (circular limit):**
$$
\sqrt{v_d^2+v_q^2} \le V_{\max} = \frac{V_{dc}}{\sqrt3}\cdot 0.95
$$
Priority goes to v_d (keep i_d ≈ 0). The residual is given to v_q:
$$
v_{q,\max} = \sqrt{V_{\max}^2 - v_d^2}
$$
