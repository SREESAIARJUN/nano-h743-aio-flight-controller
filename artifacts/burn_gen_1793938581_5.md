## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| IMUs | 2× ICM-42688-P on separate SPI buses, mounted on the camera plate |
| Kinematics | Yaw (outer) → Roll (middle) → Pitch (inner) |

**Loop rates and bandwidths**

| Loop | Rate | Target bandwidth |
|---|---|---|
| PWM, center-aligned | 40 kHz | — |
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| Velocity (gyro-based) | 4 kHz | ~150–250 Hz |
| Attitude / angle | 1 kHz | ~20–40 Hz |
| IMU ODR | 8 kHz, AAF ~1 kHz, decimated to 4 kHz | — |

The design rule is a bandwidth separation of at least 5× between adjacent loops. That keeps each inner loop close to unity gain within the outer loop's crossover.
