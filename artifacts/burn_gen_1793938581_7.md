# FOC Control and Sensor Fusion for a 3-Axis Gimbal

## 0. Assumptions

I don't have the Job #4 specification, so this design uses a typical brushless-gimbal configuration. Every parameter is a named constant, so you can substitute your real values.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) per axis |
| Current sense | 2-phase inline or low-side shunts, synchronous to PWM center |
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| PWM | 20 kHz center-aligned, SVPWM |
