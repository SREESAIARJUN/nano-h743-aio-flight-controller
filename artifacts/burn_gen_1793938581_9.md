## 1. System Architecture and Timing

```
               1 kHz                 4 kHz                       20 kHz
 q_ref ──► [Attitude/Angle P+FF] ─► [J⁻¹(q)] ─► [Rate PI + FF] ─► iq* ─► [Current PI + decoupling] ─► SVPWM
              ▲                                   ▲    ▲  ▲                      ▲
              │ q̂ (Mahony)                        │    │  └─ i_cog(θm)  anti-cog │ θe (encoder)
              │                                   │    └──── J·α_ref/Kt          │
         [Dual-IMU fusion] ◄── notch+LPF ◄── 8 kHz gyro/accel ×2 (ICM-42688-P, on-chip AAF)
```

| Loop | Rate | Bandwidth target | Feedback source |
|---|---|---|---|
| Current (d/q) | 20 kHz (PWM-synchronous) | 1.5–2 kHz | Phase shunts, encoder θe |
| Rate (velocity) | 4 kHz | 80–150 Hz | Fused IMU gyro, mapped to joint space |
| Attitude (angle) | 1 kHz | 15–30 Hz | Mahony quaternion from fused IMUs |
| IMU sampling | 8 kHz ODR | Anti-aliasing filter (AAF) ≈ 1 kHz | Two ICM-42688-P units |

**Rule of thumb:** keep a bandwidth separation of at least 5× between nested loops. The rate loop is closed on the **camera-mounted gyro**, not on the differentiated encoder. This is the key to stabilization: it rejects base motion directly. The encoder is used only for commutation and for the anti-cogging phase.
