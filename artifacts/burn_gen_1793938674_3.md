# STM32H743 FC + 4-in-1 ESC (80 A Burst) — Systems Architecture Model

## 0. Scope and Assumptions

I don't have the Job #10 requirements package, so the baseline below is stated explicitly. Every equation is parametric, so you can substitute vendor datasheet values. Treat all numbers as design-stage estimates. They must be confirmed by thermocouple or IR testing and by scope captures.

| Parameter | Symbol | Assumed value | Notes |
|---|---|---|---|
| Bus voltage | V_bus | 25.2 V max / 22.2 V nom (6S) | Use 25.2 V for switching loss |
| Burst phase current | I_ph | 80 A per ESC channel | DC-equivalent winding current |
| PWM frequency | f_sw | 48 kHz | Set by the ESC MCU (AM32/BLHeli_32), not the H743 |
| MOSFET | — | 40 V, PDFN 5×6 or 3.3×3.3 class | e.g., R_ds(on) ≈ 1.0 mΩ
