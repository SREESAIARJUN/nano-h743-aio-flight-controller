## 0. Assumptions and Rate Plan

| Item | Assumed value |
|---|---|
| MCU | STM32G4/H7-class Cortex-M4F/M7 with single-precision FPU |
| Motors | 3 × gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 2 mH, λ ≈ 0.0125 V·s/rad |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, gyro and accel at ODR = 8 kHz, UI-synced through CLKIN or FSYNC |
| Phase current sensing | Low-side 2-shunt, sampled at the PWM center |

**Loop rates and target bandwidths**

| Loop | Rate | Target crossover |
|---|---|---|
| Current (d/q) | 20 kHz (ISR on PWM update) | ω_c ≈ 2π·1500 rad/s |
| Rate (velocity) | 4 kHz (every 5th current ISR, aligned with IMU data) | ω_v ≈ 2π·60 rad/s |
| Attitude (angle) | 1 kHz | ω_θ ≈ 2π·12 rad/s |
| AHRS + IMU filtering | 8 kHz input, 4 kHz decimated output | n/a |

Each outer loop is at least about 5× slower than the loop inside it. This separation lets every inner loop be treated as a unity-gain block (≈1) when tuning the loop outside it.

## 1. Field-Oriented Control: Current Loop

### 1.1 Transforms

The electrical angle comes from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

**Clarke transform** (two-shunt, amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant

The surface-mount PMSM model (L_d = L_q = L) is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda$$

$$\tau = K_t\, i_q,\qquad K_t = \tfrac32\, p\,\lambda$$

### 1.3 Current PI with pole-zero cancellation

Each axis plant is G_i(s) = 1/(Ls + R). Choose the PI controller C(s) = K_p + K_i/s with K_i/K_p = R/L. The PI zero then cancels the electrical pole, and the open loop reduces to ω_c/s. This gives:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

In discrete form, the integrator gain is multiplied by T_s.

The digital implementation adds about 1.5·T_s of transport delay (one computation period plus half a PWM period). This delay sets the phase margin:

$$\text{PM} \approx 90^\circ - \omega_c\cdot 1.5T_s\cdot\tfrac{180}{\pi}$$

At 1.5 kHz crossover and 20 kHz sampling, this gives PM ≈ 50°, which is adequate.

**Decoupling feedforward.** These terms cancel the cross-coupling and back-EMF terms of the plant:

$$v_d^{ff} = -\omega_e L\, i_q,\qquad v_q^{ff} = \omega_e (L i_d + \lambda)$$

### 1.4 Voltage limiting and SVPWM

The voltage vector must stay within the linear SVPWM region:

$$|v_{dq}| \le V_{bus}/\sqrt3$$

Limit v_q while giving priority to v_d. Then apply min-max zero-sequence injection, which is equivalent to SVPWM:

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

### 1.5 Anti-windup (all PI loops)

Use back-calculation with tracking gain K_aw = 1/K_p:

$$u_{\text{unsat}} = K_p e + I,\quad u = \text{sat}(u_{\text{unsat}}),\quad I_{k+1} = I_k + T_s\big[K_i e + K_{aw}(u - u_{\text{unsat}})\big]$$

## 2. Cascaded Rate / Attitude Control

### 2.1 Mechanical plant (per axis, with the current loop treated as ideal)

$$J\dot\omega = K_t i_q - b\,\omega - \tau_{cog}(\theta_m) - \tau_{dist}$$

Here J is the reflected inertia about the joint, including the camera payload and the outer links.

### 2.2 Rate (velocity) loop

The feedback signal is the **inertial** rate of the axis, taken from the fused gyro and projected onto that joint (§4.6). Encoder velocity is not used for this purpose. The gyro measures what the camera actually experiences, including base motion. Encoder velocity is used only for commutation, decoupling, and cogging-phase advance.
