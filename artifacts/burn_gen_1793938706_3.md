## 1. FOC Inner Current Loop

### 1.1 Transforms

Electrical angle (n_p is pole pairs, θ_off comes from alignment calibration):

$$\theta_e = n_p(\theta_m - \theta_{off}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant (SPM motor, L_d ≈ L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Torque, with K_t in N·m/A (amplitude-invariant scaling):

$$\tau = \tfrac32 n_p \lambda_m i_q = K_t i_q$$

### 1.3 PI with pole-zero cancellation

With the cross-coupling and back-EMF terms fed forward, the plant reduces to 1/(Ls + R). Choose:

$$C_i(s) = K_p + \frac{K_i}{s},\qquad K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}$$

This yields a closed loop of ω_ci/(s + ω_ci).

The total loop delay is T_d ≈ 1.5 T_s (half a period of PWM sampling plus one period of computation). To keep phase margin at or above 60°:

$$\omega_{ci} \le \frac{\pi/6}{T_d}$$

At 20 kHz this gives f_ci ≈ 1.1–1.5 kHz.

Discrete form (forward Euler on the integrator):

$$u[k] = K_p e[k] + I[k]$$
$$I[k+1] = I[k] + K_i T_s e[k] + K_{aw}(u_{sat}[k] - u[k])$$

The second term in the integrator update is back-calculation anti-windup, with K_aw ≈ K_i/K_p = R/L.

Decoupling feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda_m)$$

Voltage limiting is circular, with priority given to v_q:

$$|v_{dq}| \le V_{bus}/\sqrt3$$

> **High-R gimbal motors.** With R ≈ 10 Ω the current loop is nearly trivial. Voltage-mode control (v_q = R i_q* + ω_e λ_m) is a valid fallback if current sensing is noisy. The code supports both modes.

### 1.4 SVPWM by min-max zero-sequence injection

$$v_{a,b,c} = \text{invClarke}(\text{invPark}(v_d, v_q))$$
$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big)$$
$$D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

This is mathematically identical to sector-based SVPWM and reaches the linear limit V_bus/√3.
