# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

**Scope and assumptions.** I don't have the specification for Job #14, so I designed against a typical brushless gimbal platform. Every assumption is a named constant in the code. Please verify or replace each one before deployment.

| Parameter | Assumed value |
|---|---|
| MCU | STM32G4/H7-class, single-precision FPU, about 170 MHz or more |
| Motor | Gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A or MT6701) |
| Current sensing | Two low-side shunts. A voltage-mode fallback is included for drivers without current sensing. |
| IMUs | 2 × ICM-42688-P on SPI, ODR 8 kHz, placed symmetrically about the camera-plate centre |

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | 1.5–2 kHz |
| Velocity | 4 kHz | 80–150 Hz |
| Angle / stabilisation | 1 kHz | 15–30 Hz |
| IMU fusion | 8 kHz in, 1 kHz attitude out | — |

## Part I — Equations

### 1. Field-Oriented Control (inner current loop, 20 kHz)

**Electrical angle.** Let θ_m be the mechanical angle, p the number of pole pairs and θ_off the encoder-to-rotor offset:

  θ_e = p·θ_m − θ_off   (mod 2π)

**Clarke transform** (amplitude-invariant, two-shunt form):

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

**Plant (surface-mounted PMSM):**

- L·di_d/dt = v_d − R·i_d + ω_e·L·i_q
- L·di_q/dt = v_q − R·i_q − ω_e·(L·i_d + λ_m)

Electromagnetic torque is τ_e = (3/2)·p·λ_m·i_q = K_t·i_q.

**PI design by pole–zero cancellation.** The plant zero is R/L and we want closed-loop bandwidth ω_c. Choose:

- K_p,i = ω_c·L
- K_i,i = ω_c·R

The closed loop then reduces to 1st order: i/i* = ω_c / (s + ω_c).
