## 2. FOC Current Loop

**Clarke transform** (balanced phases, so i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$i_d = i_\alpha\cos\theta_e + i_\beta\sin\theta_e,\qquad i_q = -i_\alpha\sin\theta_e + i_\beta\cos\theta_e$$

**Motor model** (surface PMSM, L_d ≈ L_q = L):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e(L i_d + \lambda)$$

$$\tau = \tfrac32 p\lambda\, i_q = K_t i_q$$

**PI tuning by pole-zero cancellation.** Placing the PI zero on the R/L pole gives a closed loop of ω_c/(s+ω_c):

$$K_{p,c} = L\,\omega_c,\qquad K_{i,c} = R\,\omega_c$$

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e(L i_d + \lambda)$$

**Voltage limit** (linear SVPWM region):

$$\|v_{dq}\| \le V_{bus}/\sqrt3$$

Apply priority to v_d first, then give v_q the remaining magnitude.

**Inverse transforms and SVPWM** (min-max zero-sequence injection):

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

**Delay compensation.** Use θ_e + 1.5·ω_e·T_s for the inverse Park. This accounts for ADC-to-PWM delay of 1 sample plus 0.5 sample of PWM hold.

## 3. Cascaded Velocity and Angle Control

### Plant
From i_q to mechanical speed:

$$\omega_m(s) = \frac{K_t}{Js + B}\, i_q(s)$$

The current loop is fast enough to be treated as unity gain here.

### Velocity PI
Place the crossover at ω_v and the PI zero at ω_v/4 (about 60° of phase margin):

$$K_{p,v} = \frac{J\omega_v}{K_t},\qquad K_{i,v} = K_{p,v}\frac{\omega_v}{4}$$

### Angle loop
Use P control plus velocity and acceleration feedforward. A small I term can be added for gravitational imbalance, although that is better removed by balancing the payload.

$$\omega^* = K_{p,\theta}\,\mathrm{wrap}(\theta^* - \theta) + \dot\theta^*_{ff}, \qquad K_{p,\theta} = \omega_\theta$$
