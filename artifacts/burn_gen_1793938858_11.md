# STM32H743 Nano FC + 4-in-1 ESC (Job #40): Loss Model, DShot DMA Plan, and Reference Netlist

## 0. Scope and Assumptions

**Architecture.** In a 4-in-1 stack, the STM32H743 is the **flight controller**. It generates bidirectional DShot600 and decodes eRPM telemetry. Each motor channel on the ESC board has its own small MCU (AT32F421 / STM32G071 class, running AM32 or BLHeli_32), a 3-phase gate driver, and 6 MOSFETs. The 48 kHz switching frequency is the ESC MCU's PWM, not the H743's. The models below are split along that boundary.

**No component BOM was supplied**, so the reference parameters below are representative of a 40 V, 3.3×3.3 mm DFN MOSFET. Every result scales directly with these values. Re-run the model with datasheet values before sign-off.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Burst phase current, per motor | I | 80 A |
| PWM frequency | f_sw | 48 kHz |
| R_DS(on) @ 25 °C, V_GS = 10 V | R₂₅ | 1.0 mΩ |

> ⚠️ **Feasibility flag.** Four channels at 80 A simultaneously is about 87 W of loss on a nano (20×20 mm) board. As shown in §3, this is only survivable as a **short burst (≈2 s)**. Treat "80 A" as a burst rating and never as a continuous one.

## 1. Conduction Loss Model

AM32/BLHeli_32 use 6-step commutation with synchronous (complementary) PWM. At every instant, the motor current flows through exactly **two MOSFET channels** in series: one high-side or its complementary low-side, plus one low-side.

**Per motor channel:**

$$P_{cond}(T_j) = 2\,I^2\,R_{DS(on)}(T_j), \qquad R_{DS(on)}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

**Per FET.** Each FET carries current for 1/3 of the electrical cycle, so I_RMS,FET = I/√3:

$$P_{cond,FET} = \frac{I^2}{3} R_{DS(on)}(T_j)$$

**Numerical results at T_j = 125 °C (R = 1.5 mΩ):**
- P_cond,FET = 6400/3 × 1.5 mΩ = **3.20 W**
- P_cond,channel = 6 × 3.20 = **19.2 W** (check: 2 × 6400 × 1.5 mΩ = 19.2 W ✓)

**Parasitic conduction, per channel:**
- Shunt: 6400 × 0.2 mΩ = **1.28 W**
- Copper (≈0.15 mΩ effective path, 2 oz, 8-layer): ≈ **0.96 W**

**Electro-thermal coupling.** R_DS(on) depends on T_j, so solve iteratively:

$$T_j^{(k+1)} = T_a + P_{FET}(T_j^{(k)})\cdot Z_{th}(t)$$

This loop converges in 3–4 iterations. It runs away if dP/dT_j × Z_th ≥ 1, which is the thermal runaway criterion:

$$\frac{I^2}{3}R_{25}\,\alpha\,Z_{th} < 1$$

With Z_th ≈ 10 K/W: 2133 × 1e-3 × 0.005 × 10 = **0.107**, so the loop is stable.

## 2. Switching Loss Model at 48 kHz

In each PWM period, only the PWM-ing leg hard-switches.

**(a) V–I overlap loss.** Gate currents during the Miller plateau:
- I_g,on = (V_drv − V_pl)/R_on = 6.5/10 = 0.65 A
- I_g,off = V_pl/R_off = 3.5/5 = 0.70 A

Using Q_sw = Q_gs2 + Q_gd ≈ Q_gs/2 + Q_gd = 13 nC:
- t_on = 13 nC / 0.65 A = 20.0 ns
- t_off = 13 nC / 0.70 A = 18.6 ns

$$P_{VI} = \tfrac12 V_{bus} I (t_{on}+t_{off}) f_{sw} = 0.5 \times 25.2 \times 80 \times 38.6\text{ns} \times 48\text{k} = \mathbf{1.87\ W}$$

$$P_{oss} = 2 \cdot \tfrac12 C_{oss,er} V_{bus}^2 f_{sw} = 1\text{nF} \times 635 \times 48\text{k} = \mathbf{0.030\ W}$$
