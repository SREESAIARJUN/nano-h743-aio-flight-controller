# STM32H743 AIO Nano Flight Controller with 4-in-1 ESC: System Architecture & Analysis (Job #1)

**Document type:** Reference architecture and first-pass analytical model
**Status:** Pre-layout. Every numeric parameter is an explicit, swappable assumption. Validate against your chosen MOSFET datasheet and thermocouple / IR-camera bench data before release.

---

## 0. Executive Summary

Two findings drive the rest of this design.

1. **The STM32H743 does not drive the MOSFETs.** In every viable architecture, the H743 is the flight controller running ArduPilot. It emits bidirectional DShot600 to four ESC MCUs (AT32F421 or STM32G071 running AM32/BLHeli_32). Those MCUs run the 48 kHz commutation PWM. The H743's timer/DMA budget is spent on DShot, not on gate drive.

2. **"80 A burst" on a 20×20 mm nano board is thermally marginal.** The model below shows:

| Condition | Result |
|---|---|
| 80 A on one motor | ~28 W of heat in one bridge |
| 80 A on all four motors simultaneously | ~110 W of heat, 320 A from the battery |
| Burst duration before T_j exceeds ~150 °C (all four motors, 40 °C ambient) | ≈ 1.2–1.5 s |
| Continuous rating with prop-wash cooling | ≈ 18–22 A per motor |

   Recommendations:
   - Market it as **"80 A burst ≤ 1 s, single-channel."**
   - Otherwise, move to a 30.5×30.5 mm footprint with 5×6 mm PDFN FETs.

## 2. Conduction Loss Model (80 A Burst)

### 2.1 Assumptions

Example device class: 40 V, 3.3×3.3 mm DFN (needed to fit 24 FETs in 20×20).

| Symbol | Value | Note |
|---|---|---|
| R_DS(on),25 | 1.2 mΩ (max @ V_GS = 10 V) | Substitute datasheet value |
| α | 0.0067 /°C | Gives ≈ 1.57× at 110 °C (typical normalized curve) |
| T_j (design point) | 110 °C | |
| R_cu | 0.25 mΩ per current path | 2 oz outer layers, 1 oz inner layers, paralleled |
| V_bus | 25.2 V | 6S fully charged (worst case) |
| I_ph | 80 A | Burst |

### 2.2 Temperature-Dependent R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)] = 1.2\,\text{m}\Omega \times 1.57 = 1.88\ \text{m}\Omega$$

### 2.3 Six-Step with Synchronous Rectification

In each 60° sector, current flows through exactly two FET positions:
- **Switching leg:** high-side for duty D, low-side for (1−D) in complementary mode.
- **Return leg:** low-side on continuously.

Current therefore always passes through two FET channels, so conduction loss is independent of D:

$$P_{cond,bridge} = 2\,I^2\,R_{DS}(T_j) = 2(80)^2(1.88\times10^{-3}) = \mathbf{24.1\ W}$$

Copper loss on the same path:

$$P_{cu} = I^2 R_{cu} = 6400 \times 0.25\times10^{-3} = \mathbf{1.6\ W}$$

### 2.4 Per-FET Average

Each FET conducts on average one third of the electrical cycle. The electrical period at 30k eRPM is about 2 ms, which is longer than the die's thermal time constant (~1–5 ms). Therefore:
- Use the **average** loss for board-level heating.
- Use the **sector-peak** loss for junction ripple.

| Quantity | Formula | Value |
|---|---|---|
| Per-FET average | 24.1 / 6 | 4.0 W |
| Per-FET sector peak | I² R_DS | 12.0 W |
