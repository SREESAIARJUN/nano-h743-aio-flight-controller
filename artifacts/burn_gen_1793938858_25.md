# STM32H743 FC + 4-in-1 80A ESC (Job #37): Reference Design Package

## 0. Scope and Assumptions

I have no prior project record for "Job #37," so this package is built on the assumptions below. Change any of them and the numbers change. The equations are written so you can substitute your own values.

| Parameter | Assumed value | Notes |
|---|---|---|
| Battery | 6S LiPo, 25.2 V max / 22.2 V nominal | Calculations use V_bus = 25.2 V (worst case for switching) |
| Burst current | 80 A per channel (phase current) | Burst only; see §3.5 |
| ESC PWM | 48 kHz, complementary (synchronous rectification) | AM32/BLHeli_32-style |
| ESC MCU | Separate per-channel MCU (e.g. AT32F421 / STM32G071) running AM32 | The H743 is the FC; it does **not** drive the bridges |
| MOSFET | 40 V N-ch, PDFN 5×6, R_ds(on) ≈ 1.0 mΩ typ @ 25 °C, Q_g ≈ 60 nC, Q_rr ≈ 40 nC, Q_oss ≈ 50 nC | Generic class. Pick an actual part and re-run. |
| Gate driver | 3-phase half-bridge driver with bootstrap (FD6288Q-class), dead time ≈ 200 ns | |
| ESC PCB | 36×36 mm, 8-layer, 2 oz copper | A 20×20 "nano" ESC **cannot** do 4×80 A; see §3.6 |
| Ambient | 25 °C, board starts at 40 °C | |

**Architectural reality check (stated up front):** 4 × 80 A simultaneous means 320 A from the battery, which is about 8 kW at 25 V. This is a **seconds-scale burst rating**, not a continuous one. The thermal model below shows the board has **no stable steady state** at that load.

## 1. ESC Power Stage Loss Model (per channel)

### 1.1 Conduction topology
- In 6-step trapezoidal commutation, two phases carry current at any instant: the high side of phase X and the low side of phase Y.
- With complementary PWM, the PWMed leg alternates HS ↔ LS (sync rectifier). The current path therefore always passes through **two** MOSFET channels in series (dead time excluded).
- Each MOSFET conducts for 120° electrical per cycle.

### 1.2 Conduction loss with temperature coefficient

$$R_{ds}(T_j) = R_{25}\left[1 + \alpha\,(T_j - 25)\right],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

$$P_{cond,ch} = 2\, I_{ph}^2\, R_{ds}(T_j)$$

| T_j | R_ds | P_cond per channel @ 80 A |
|---|---|---|
| 25 °C | 1.00 mΩ | 2·6400·1.0 m = **12.8 W** |
| 110 °C | 1.51 mΩ | **19.3 W** |

Averaged over the 6 FETs in a channel: about 2.1 to 3.2 W per FET.

### 1.3 Switching losses at f_sw = 48 kHz
Only the PWMed leg hard-switches.

**(a) V-I overlap**, with t_r + t_f ≈ 40 ns:

$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = 0.5(25.2)(80)(40\text{n})(48\text{k}) = \mathbf{1.94\ W}$$

**(b) Dead-time body-diode conduction**, two edges per period, V_F ≈ 0.8 V:

$$P_{DT} = V_F I_{ph}\,(2t_{dead}) f_{sw} = 0.8(80)(400\text{n})(48\text{k}) = \mathbf{1.23\ W}$$

Dead time is the second-largest switching term. Tighten it to about 100 ns if the driver and layout allow.
