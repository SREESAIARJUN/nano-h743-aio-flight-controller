# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the Job #21 specification, so this design uses the assumptions below. Every assumption is a single parameter in the code, so you can change it without restructuring anything.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC (e.g. GBM2804), 7 pole pairs, 12 slots, R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701), read at 20 kHz |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7), center-aligned PWM |
| IMU A | ICM-42688-P on the camera plate. This is the control feedback. |
| IMU B | ICM-42688-P on the handle/frame. This is the vibration reference and the disturbance feedforward. |
| Loop rates | Current 20 kHz → velocity 4 kHz → angle 1 kHz. IMU ODR 8 kHz. |

## 1. Architecture

```
               1 kHz                 4 kHz                 20 kHz
 θ_ref ─►[Angle P + vel FF]─ω_ref─►[Velocity PI]─iq*─►(+)─►[Current PI d/q]─►[SVPWM]─► Motor
              ▲                       ▲            ▲    iq_cog(θm)   ▲
              │ θ_est                 │ ω_meas     │ +iq_dist_ff     │ id,iq (Clarke/Park)
   ┌──────────┴───────────────────────┴──┐         │                 │ θe from encoder
   │ Fusion: IMU-A (payload)             │◄────────┘
   │   per-IMU chain: on-chip AAF →      │   base-motion FF from IMU-B
   │   dynamic notches → LPF             │
   │   NLMS canceller (ref = IMU-B)      │
   │   Mahony attitude filter            │
   └─────────────────────────────────────┘
```

**Bandwidth separation rule.** Each loop should be at least 4–5× slower than the loop inside it, and at least 10× slower than its own sample rate.

Typical targets:
- Current loop: ω_c ≈ 2π·1500 rad/s
- Velocity loop: ω_v ≈ 2π·150 rad/s
- Angle loop: ω_p ≈ 2π·25 rad/s

## 2. Field-Oriented Control (Current Loop, Ts = 50 µs)

### 2.1 Transforms

**Electrical angle.** With p = number of pole pairs and θ_off = the encoder offset:

  θ_e = p·θ_m − θ_off

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

  i_α = i_a
  i_β = (i_a + 2·i_b) / √3

**Park transform:**

  i_d = i_α·cos θ_e + i_β·sin θ_e
  i_q = −i_α·sin θ_e + i_β·cos θ_e

### 2.2 Motor model and decoupled PI

**Motor model in the d/q frame:**

  v_d = R·i_d + L·di_d/dt − ω_e·L·i_q
  v_q = R·i_q + L·di_q/dt + ω_e·(L·i_d + λ_m)

**Decoupling feedforward.** The cross-coupling terms are cancelled by adding:

  v_d,ff = −ω_e·L·i_q
  v_q,ff = ω_e·λ_m + ω_e·L·i_d

**Plant after decoupling:**

  G(s) = 1 / (L·s + R)

**PI tuning by pole-zero cancellation.** Choose the PI zero to cancel the plant pole:

  K_p = L·ω_c
  K_i = R·ω_c

The closed loop is then a first-order system:

  i / i* = ω_c / (s + ω_c)

**Discretization** (forward Euler on the integrator, with back-calculation anti-windup):

  e[k] = i*[k] − i[k]
  v_u[k] = K_p·e[k] + x[k] + v_ff[k]
  v[k] = sat(v_u[k])
  x[k+1] = x[k] + K_i·T_s·e[k] + K_aw·(v[k] − v_u[k])

with K_aw ≈ 1/K_p·K_i·T_s… or more simply K_aw = 1 when expressed in volts per step.

**Voltage limit.** The voltage vector is limited to the inscribed circle of the SVPWM hexagon. The d-axis gets priority:

  |v| ≤ V_bus / √3
  v_q,max = √( (V_bus/√3)² − v_d² )

**Delay compensation.** Rotate the inverse-Park angle forward by 1.5 sample periods:

  θ_e' = θ_e + 1.5·ω_e·T_s

### 2.3 Inverse Park and SVPWM

**Inverse Park:**

  v_α = v_d·cos θ_e' − v_q·sin θ_e'
  v_β = v_d·sin θ_e' + v_q·cos θ_e'

**Min-max zero-sequence injection** (equivalent to SVPWM):

  v_a = v_α
  v_b = −½·v_α + (√3/2)·v_β
  v_c = −½·v_α − (√3/2)·v_β
  v_0 = −½·(max(v_a, v_b, v_c) + min(v_a, v_b, v_c))

**Duty cycle for each phase x:**

  d_x = ½ + (v_x + v_0) / V_bus

## 3. Cascaded Velocity and Angle Control

### 3.1 Velocity loop (T_v = 250 µs)

**Plant.** Seen from the velocity loop, the closed current loop is approximately unity gain:

  G_v(s) = K_t / (J·s + B)

**PI controller.** Use the "symmetric-optimum-lite" placement:

  K_pv = J·ω_v / K_t
  K_iv = K_pv·ω_v / N    (N ≈ 4–6)

This places the PI zero well below the crossover frequency, so the phase margin stays around 60°.

**Control law.** The integral term uses back-calculation anti-windup, and the derivative is not used here (the inner current loop already provides damping):

  i_q* = K_pv·e_ω + I_ω + i_q,ff
  e_ω = ω_ref − ω̂
