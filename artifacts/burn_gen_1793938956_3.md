# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Brushless Gimbal

## Design Assumptions

I don't have the Job #45 specification, so this design uses common gimbal hardware. Replace the bracketed parameters with your values.

| Item | Assumed value |
|---|---|
| Motors | GBM2804-class, 12 slots / 14 poles (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 2 mH |
| Encoders | 14-bit magnetic encoder (AS5048A / MA730) on each axis |
| MCU | STM32G4 or H7 class, with FPU, center-aligned PWM at 20 kHz |
| Current sensing | 2 low-side shunts per motor |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Gimbal order (base → camera) | Yaw (z) → Roll (x) → Pitch (y) |

**Loop rates and nesting:**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity (rate) | 4 kHz | ~150 Hz |
| Angle | 1 kHz | ~25 Hz |
| Attitude estimator | 1 kHz | — |
| IMU filtering | 8 kHz | — |

Each outer loop's bandwidth is at least 5× below the loop inside it.
