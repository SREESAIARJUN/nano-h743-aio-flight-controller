## 0. Architectural Baseline and Assumptions

### 0.1 Partitioning: the H743 does not drive the MOSFETs

The STM32H743 cannot practically run the FOC or 6-step commutation for four motors.

- Four motors need 12 half-bridges, which means 24 complementary outputs.
- The H743 provides only 11 half-bridge legs: TIM1 and TIM8 give 3 complementary pairs each, and HRTIM gives 5 timer units.
- It also lacks per-channel BEMF comparator timing.

The design therefore uses a standard two-tier stack:

```
[STM32H743 FC, ArduPilot]  --4x bidir DShot600-->  [4x ESC MCU (AT32F421 / AM32)]
                                                         |
                                     3-phase driver (FD6288Q) -> 6x N-MOSFET per motor
```

- The **48 kHz switching frequency** is an AM32 setting (PWM frequency = 48 kHz).
- **Bidirectional DShot600** is an ArduPilot/H743 timer and DMA concern.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step with synchronous (complementary) PWM

In every 60° commutation sector, two phases conduct:

- **PWM leg:** the high-side FET conducts for D·T_sw. The complementary low-side FET (synchronous rectification) conducts for (1−D)·T_sw, minus dead time.
- **Static leg:** the low-side FET is on for 100% of the sector.

Motor current I therefore always flows through exactly two FET channels (ignoring dead time):

```
P_cond,ch = I_rms² · [ D·R_HS + (1−D)·R_LS ] + I_rms² · R_LS
          ≈ 2 · I_rms² · R_ds(on)(T_j)          (matched FETs)
```

The relationship is independent of D. This is a useful property: burst conduction loss does not depend on throttle position, only on current.

### 1.2 Temperature dependence

Model R_ds(on) as rising linearly with junction temperature:

```
R_ds(on)(T_j) = R_25 · [1 + α (T_j − 25)]
```

Use T_j = 110 °C as the design point:

```
R(110) = 1.0 mΩ · [1 + 0.0045·85] = 1.38 mΩ
```

### 1.3 Ripple correction

Phase inductance L_ph is typically 10–30 µH for 5"–7" motors. The peak-to-peak ripple is:

```
ΔI_pp = (V_bus − V_bemf) · D / (L_ph · f_sw)
```

Worst case is D ≈ 0.5 with V_bemf ≈ V_bus/2, using L = 15 µH:

```
ΔI_pp = 12.6 · 0.5 / (15e-6 · 48e3) = 8.75 A

I_rms = sqrt(I² + ΔI_pp²/12) = sqrt(6400 + 6.4) = 80.04 A
```

At 48 kHz the ripple contribution is negligible. It would become non-negligible at 24 kHz with low-inductance motors.
