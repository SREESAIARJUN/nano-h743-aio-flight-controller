# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the original specification for Job #10, so the design below states its assumptions explicitly. Change the constants in `GimbalConfig` to match your hardware.

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 8 Ω, L ≈ 2 mH |
| Commutation sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sensing | 2 low-side shunts per axis, ADC sampling synchronised to the PWM centre |
| MCU | STM32G4/H7-class with single-precision FPU |
| IMUs | 2× ICM-42688-P on the camera payload, SPI at 24 MHz, gyro/accel ODR = 8 kHz |
| Gimbal kinematics | Base → Yaw (ψ, z) → Roll (φ, x) → Pitch (θ, y) → camera |

**Loop rates**

| Loop | Rate | Trigger |
|---|---|---|
| Current (FOC) | 16 kHz | ADC-injected end-of-conversion (EOC) interrupt, centre-aligned PWM |
| IMU front-end and velocity (rate) loop | 8 kHz | IMU data-ready interrupt (INT1), SPI DMA |
| Attitude estimator and angle loop | 1 kHz |
