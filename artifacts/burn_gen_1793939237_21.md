# STM32H743 Flight Controller + 4-in-1 80 A ESC: System Model

## 0. Scope, Assumptions, and One Architectural Correction

I have no prior record of "Job #7", so the design inputs below are stated assumptions. Change any of them and the equations still hold; only the numbers move.

**Architectural correction.** The H743 should not commutate the motors. Standard practice, and what ArduPilot supports, is:

- **H743 (flight controller):** sends bidirectional DShot600 to 4 ESC MCUs and receives eRPM telemetry back for the harmonic notch filter.
- **ESC MCUs (4×, e.g. AT32F421 running AM32):** each runs 6-step commutation with 48 kHz complementary PWM.

The 48 kHz switching model below therefore applies to the ESC power stage, not to an H743 timer.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)],\qquad \alpha \approx 0.0055\ \text{K}^{-1}$$

At a design-point T_j = 110 °C with max-spec R_ds:

$$R_{ds}(110) = 0.85 \times 1.47 = 1.25\ \text{m}\Omega$$

### 1.2 Six-step bridge with synchronous rectification

In trapezoidal commutation, two phases conduct at any instant. With complementary PWM, current always flows through exactly one high-side and one low-side device, either the active pair or the freewheel pair. Ignoring dead time (handled in §2):

$$P_{cond,bridge} = 2\,I_{ph,rms}^2\,R_{ds}(T_j) + I_{ph,rms}^2\,R_{Cu}$$

PWM ripple current adds a correction:

$$I_{rms}^2 = I_{DC}^2 + \frac{\Delta I_{pp}^2}{12},\qquad \Delta I_{pp} = \frac{(V_{bus}-E_b)\,D}{2L_{ph}\,f_{sw}}$$

Example values: L_ph = 15 µH line-to-line (typical 2207 motor), E_b ≈ 15 V at full throttle, D ≈ 0.85.

$$\Delta I_{pp} = \frac{(25.2-15)\times 0.85}{2 \times 15\mu \times 48k} \approx 6.0\ \text{A} \;\Rightarrow\; \frac{\Delta I^2}{12} = 3\ \text{A}^2 \quad(\text{negligible against } 6400\ \text{A}^2)$$

### 1.3 PCB copper path
