# STM32H743 AIO Flight Controller + 4-in-1 ESC: Design Model (Job #32)

**Scope:** Power-stage loss model (80 A burst, 48 kHz PWM), transient thermal model, ArduPilot bidirectional DShot600 timer/DMA allocation, and reference netlists.

**How to use this document:** All numbers derive from the stated assumptions in §0. Re-run the equations with the datasheet values of the MOSFETs and driver you actually select. The netlists are reference topology, not a fab-ready release. They need ERC/DRC and layout review.

---

## 0. Architecture and Assumptions

### 0.1 Architecture decision

The STM32H743 does **not** commutate the motors. It runs ArduPilot and emits bidirectional DShot600 to four dedicated ESC MCUs (e.g., AT32F421 running AM32). This is the only practical architecture:

- ArduPilot has no BLDC commutation firmware.
- 48 kHz complementary PWM with back-EMF zero-cross detection for four motors needs dedicated timers and comparators per motor.

| Block | Choice (reference) |
|---|---|
| FC MCU | STM32H743VIT6, 480 MHz (ArduPilot typically runs 400 MHz) |
| ESC MCU (×4) | AT32F421K8U7, AM32 firmware, 48 kHz PWM |
| Gate driver (×4) | FD6288Q 3-phase, bootstrap high-side |
| MOSFETs | 24 per board (6 per motor), 40 V, PDFN 3.3×3.3 class |
| Battery | 6S LiPo, 25.2 V max, 22.2 V nominal |

> ⚠️ **Voltage margin:** 40 V parts on 6S leave about 15 V of margin for ringing. That is acceptable only with a tight loop layout and ≥ 1000 µF bulk capacitance at the battery leads. For hard-flown 6S builds, 60 V parts are safer. They carry about 1.5–2× the R_ds, which roughly doubles the conduction loss below.

## 1. Conduction Loss Model

### 1.1 Current path

In 6-step commutation, current at any instant flows through exactly one high-side and one low-side device, or through the synchronous-rectifier equivalent during PWM off-time. With complementary PWM the freewheel path is also two channels. The conducted path therefore always contains **two R_ds in series, independent of duty cycle D**:

$$P_{cond,motor} = 2\, I_{ph}^2\, R_{ds}(T_j)$$

$$R_{ds}(T_j) = R_{ds25}\,[1 + \alpha (T_j - 25)]$$

### 1.2 Per-motor result

At T_j = 125 °C, R_ds = 1.2 mΩ × 1.6 = 1.92 mΩ:

$$P_{cond,motor} = 2 \times 80^2 \times 1.92\times10^{-3} = \mathbf{24.6\ W}$$

Each of the 6 FETs carries current for 120° (1/3) of the electrical cycle:

$$P_{cond,FET} = I_{ph}^2 R_{ds} \cdot \tfrac{1}{3}\cdot 2 \cdot \tfrac{1}{2}\ \Rightarrow\ \frac{24.6}{6} = \mathbf{4.1\ W\ average}$$

### 1.3 Self-consistent junction temperature

Because R_ds rises with temperature, iterate:

$$T_j^{(n+1)} = T_{board} + P_{FET}\big(R_{ds}(T_j^{(n)})\big)\cdot R_{\theta J\text{-}board}$$

With R_θJ-board ≈ 1.2 (J-C) + 3.5 (solder + via field) ≈ 4.7 K/W and T_board = 90 °C, the iteration converges near T_j ≈ 115–120 °C, so the 125 °C assumption is conservative.

**Thermal runaway criterion.** The loop is stable while the loop gain is below 1:

$$\frac{\partial P}{\partial T_j}\, R_{\theta} = I^2 R_{ds25}\,\alpha\, \tfrac{1}{3}\, R_\theta \cdot 2 < 1$$
