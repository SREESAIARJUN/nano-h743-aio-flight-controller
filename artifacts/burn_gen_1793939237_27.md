# STM32H743 Nano FC + 4-in-1 ESC (Job #34): Reference Engineering Model

**Bottom line:** 80 A per motor is achievable only as a burst of about 2 s, and only on a 30.5 × 30.5 mm board with 8-layer copper. It is not achievable on a 20 × 20 mm "nano" ESC. Sustainable continuous current is about 25–30 A per motor. Part I shows the derivation.

### Assumptions and scope

- **Unverified values.** Component values are representative of this class of design. Every parameter marked *(datasheet)* must be replaced with the selected part's values before release.
- **Architecture.** The STM32H743 runs ArduPilot and sends DShot. The 48 kHz switching runs on a separate ESC MCU per motor or per 4-in-1 (e.g. AT32F421 or STM32G071 running AM32/BLHeli_32). The H743 never touches the gate drive.

### 2. Conduction Loss

**Conduction path.** In 6-step commutation with complementary (synchronous) PWM, the current path at any instant is:

- Phase A switches between its high-side FET (for duty D) and its low-side FET (for 1 − D).
- Phase B's low-side FET is held fully on.

The commutating leg therefore always contributes one R_ds, and the static leg contributes one more.

**Junction-temperature-dependent resistance:**

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha (T_j - 25)]$$

**Effect of current ripple:**

$$\Delta I_{pp} \approx \frac{V_{bus}}{4 L f_{sw}} = \frac{25.2}{4 \cdot 20\mu \cdot 48k} = 6.56\ \text{A}$$

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 3.6 \approx 6404\ \text{A}^2$$

The ripple term is negligible at this operating point.

**Conduction loss per motor:**

$$P_{cond} = 2\, I_{rms}^2\, R_{ds}(T_j)$$

| T_j | R_ds | P_cond per motor | Hottest single FET (static low side) |
|---|---|---|---|
| 25 °C | 1.30 mΩ | 16.6 W | 8.3 W |
| 125 °C | 1.885 mΩ | **24.1 W** | **12.1 W** |

**Thermal-runaway check.** The loss depends on temperature, P(T) = P₀[1 + α(T − 25)], so the thermal loop has a gain. The steady state is stable only if:

$$\alpha\, P_0\, R_{\theta} < 1$$

This uses the effective thermal resistance R_θ derived in Section 4.
