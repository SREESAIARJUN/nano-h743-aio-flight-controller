## 0. Architecture Correction

An STM32H743 running ArduPilot **does not commutate the motors**. ArduPilot has no ESC firmware. Bi-directional DShot implies:

```
┌──────────────────────── FC board ────────────────────────┐
│ STM32H743 (ArduPilot) ── DShot600 BDShot ×4 ────────────┼──┐
└──────────────────────────────────────────────────────────┘  │ 8-pin stack connector
┌──────────────────────── ESC board ───────────────────────┐  │
│ 4× ESC MCU (AT32F421 / STM32G071, AM32 firmware) ◄───────┼──┘
│ 4× 3-phase gate driver (FD6288Q-class)                   │
│ 24× MOSFET (6 per motor), bulk + MLCC bus capacitance    │
│ Battery shunt + current amplifier → FC ADC               │
└──────────────────────────────────────────────────────────┘
```
