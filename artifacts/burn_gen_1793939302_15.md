# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #66): Design Package

## 0. Assumptions and Feasibility Constraints

Several premises need to be fixed before the math, because they determine whether the design works.

| Parameter | Assumption |
|---|---|
| Battery | 6S LiPo, 25.2 V full, 22.2 V nominal |
| Burst current | 80 A per motor phase current, **≤ 2 s**, 10% duty cycle |
| Continuous rating | Derived below. Expect **≈ 35–45 A/channel** with prop-wash airflow. |
| Form factor | "Nano" FC core, but the ESC section on a **30.5 × 30.5 mm mount (≈ 36 × 36 mm board)**. A 20 × 20 board cannot absorb 80 A × 4 bursts (shown in §4.4). |
| Commutation MCUs | **4× AT32F421 running AM32**, one per channel. The H743 runs ArduPilot and sends bi-directional DShot600 to them. ArduPilot does not commutate motors directly, so the H743 must not drive the gate drivers. |
| PWM frequency | 48 kHz (AM32 setting) |
| Ambient | 40 °C board start, T_j,max = 150 °C design limit (175 °C absolute) |

**Representative MOSFET** (40 V, 3.3 × 3.3 mm DFN, used for all calculations; substitute your actual part's datasheet values):

| Symbol | Value |
|---|---|
| R_DS(on) @ 25 °C, V_GS = 10 V | 1.2 mΩ |
| R_DS(on) tempco factor @ 100 °C / 125 °C | 1.5× / 1.65× |
| Q_g / Q_gd / Q_gs | 40 nC / 8 nC / 10 nC |
| V_plateau | 3.0 V |
| Q_rr (body diode) | 50 nC |
| Q_oss @ 25 V | 30 nC |
| V_SD (body diode) | 0.8 V |
| R_θJC (bottom) | 1.5 K/W |
| R_g(int) | 1.0 Ω |
