# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification

## 0. Assumptions

I don't have the original specification for Job #42, so this design rests on the hardware and timing assumptions below. If any differ (motor, encoder, MCU, IMU placement), change the constants in `config.hpp`. The equations stay the same.

| Item | Assumed value |
|---|---|
| Motor | Hollow-shaft gimbal BLDC, 24N22P (p = 11 pole pairs), R = 5.6 Ω (phase-neutral), L = 2.4 mH, Kt ≈ 0.10 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), SPI, read at the current-loop rate |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM at 20 kHz, ADC triggered at the PWM valley |
| IMUs | 2 × ICM-42688-P on the camera plate, mounted point-symmetrically about the payload CoM, SPI at 24 MHz, ODR 8 kHz |

### Loop rates and bandwidths

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (d/q PI) | 20 kHz | ≈ 1.5 kHz |
| Velocity (inertial rate) | 4 kHz | ≈ 120 Hz |
| Angle (attitude) | 1 kHz | ≈ 25 Hz |
| IMU filtering / fusion | 8 kHz in, 4 kHz out | — |
| Attitude estimator | 1 kHz | — |

Each loop's bandwidth is at least 5× below the loop inside it. This keeps the loops dynamically decoupled.

## 1. Field-Oriented Control (innermost loop)

### 1.1 Electrical angle

$$\theta_e = \operatorname{wrap}_{2\pi}\big(p\,(\theta_m - \theta_{m,0})\big)$$

Here θ_{m,0} is the encoder offset at the d-axis. It is found at commissioning by injecting a d-axis current and reading the angle where the rotor settles.

**Delay compensation.** The PWM update is applied 1.5 sampling periods after the current is sampled (ZOH plus computation). The rotation angle used for the inverse Park transform is therefore advanced:

$$\theta_e^{\text{inv}} = \theta_e + 1.5\,T_s\,\omega_e$$

### 1.2 Clarke and Park transforms (amplitude-invariant)

The Clarke transform assumes balanced phase currents, i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

The Park transform rotates into the rotor frame:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
