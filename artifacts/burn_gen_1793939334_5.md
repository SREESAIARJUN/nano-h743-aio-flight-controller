# Job #44: 3-Axis Gimbal FOC Control and Dual-IMU Fusion

I don't have the Job #44 hardware specifics, so this design is built on the **assumed baseline** below. Every constant lives in one config struct. Swap in your real values and the gain-design equations recompute the gains.

| Parameter | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs `p = 7`), R = 5.6 Ω, L = 2.1 mH, K_t ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), per axis |
| Current sense | Inline or low-side shunts, 2 phases. A voltage-mode fallback is provided. |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz |
| Loop rates | Current/FOC 20 kHz · velocity 4 kHz · angle/fusion 1 kHz |
| Axis order | Yaw (outer) → Roll → Pitch (inner, carries camera + IMUs) |
