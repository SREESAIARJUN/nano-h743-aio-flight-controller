# 3-Axis Gimbal FOC Control & Dual-IMU Fusion: Equations and C++ Reference Implementation

## 0. Assumptions

I don't have the Job #58 specification. The design below uses typical brushless-gimbal values. Every value listed here is a parameter in the code, so you can replace them with your own.

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motors, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Position sensor | 14-bit absolute magnetic encoder per joint |
| Joint order (base to camera) | Yaw → Roll → Pitch |
| PWM / current loop | 20 kHz, center-aligned, sampled at the PWM midpoint |
| Velocity loop | 4 kHz (every 5th PWM tick) |
| Attitude loop | 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, ODR 8 kHz, gyro ±500 dps, accel ±4 g, on-chip AAF enabled |
| MCU | Cortex-M4F/M7 with single-precision FPU (`float` throughout) |
