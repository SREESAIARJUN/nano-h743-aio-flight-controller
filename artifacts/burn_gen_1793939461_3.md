# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original Job #11 specification, so the design rests on the assumptions listed in §0. Every gain is derived symbolically from those parameters, so you can substitute your real numbers without changing the structure.

## 0. System Assumptions

| Item | Assumed value | Symbol |
|---|---|---|
| Motor | Gimbal BLDC, 12N14P (e.g. GBM2804-class) | pole pairs p = 7, slots Nₛ = 12 |
| Phase resistance / inductance | 10 Ω / 2.5 mH (line-to-neutral) | R, L |
| Torque constant | 0.08 N·m/A | K_t = 1.5·p·λ_m |
| Load inertia (per axis, reflected) | 2.0×10⁻⁴ kg·m² | J |
| Encoder | 14-bit magnetic absolute (AS5048A / MT6701) | θ_m |
| MCU | STM32G4 @ 170 MHz, FPU, CORDIC optional | — |
| IMUs | 2 × ICM-42688-P, ODR 8 kHz, ±2000 dps, ±16 g | — |
| Bus voltage | 12 V | V_bus |

**Loop rates:**

| Loop | Rate | Period |
|---|---|---|
| Current (FOC) | 20 kHz, center-aligned PWM | T_c = 50 µs |
| IMU sampling | 8 kHz → filtered → decimated | T_imu = 125 µs |
| Rate (velocity) | 4 kHz | T_v = 250 µs |
| Angle (attitude) | 1 kHz | T_θ = 1 ms |

**Cascade architecture (per axis):**

```
 θ_ref ─►[Angle P/PI]─ω_ref─►(+)─►[Rate PI]─i_q,pi─►(+)─►[i_q PI]─►[inv Park]─►[SVPWM]─► Motor
           ▲    + ω_ff ──────┘        ▲          i_q,cog ──┘   ▲                          │
           │                          │   (anti-cogging FF)    │ i_d,i_q (Clarke/Park)    │
     attitude (Mahony)         gyro rate (fused,               └──────────────────────────┤
     from dual-IMU             notch+LPF filtered)                                        │
                                       encoder θ_m ── commutation θ_e, cogging phase ◄────┘
```

A key gimbal-specific choice: the **rate loop is closed on the inertial gyro rate** of the camera, not on the encoder rate. This is what rejects base motion. The encoder is used for:

- commutation,
- the cogging phase,
- the joint-limit and kinematic mapping.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and PI Design (Pole-Zero Cancellation)

The dq-frame voltage equations of a surface PMSM are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

After decoupling feedforward, each axis is a first-order plant:

$$G_i(s) = \frac{1}{Ls+R}$$

Choose a PI controller C(s) = K_p + K_i/s with:

$$K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}$$

The PI zero K_i/K_p = R/L cancels the plant pole, giving a closed loop of ω_ci/(s + ω_ci).

Bandwidth rule: choose ω_ci ≤ 2π·f_pwm/20, which limits phase loss from the 1.5-sample computation + PWM delay. With f_pwm = 20 kHz
