## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) per joint |
| Current sensing | 2- or 3-shunt, sampled at PWM center |
| IMU A (camera plate) | ICM-42688-P, gyro ODR 8 kHz, ±2000 dps, accel ±4 g |
| IMU B (base / handle) | ICM-42688-P, same configuration |
| Gimbal order | Base → **Yaw (z)** → **Roll (x)** → **Pitch (y)** → camera |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

**Loop rates (timing hierarchy):**

```
 20 kHz  ── Current loop (FOC): Clarke/Park, PI d/q, SVPWM          [ISR, PWM-synced]
  4 kHz  ── Velocity loop (×3 joints) + anti-cogging FF             [ISR, every 5th PWM]
  4 kHz  ── IMU processing: AAF→notches→LPF, dual-IMU kinematics     [IMU DRDY / FIFO]
  1 kHz  ── Attitude fusion (Mahony) + angle loop + Jacobian        [task]
```

**Control structure (one joint shown; the three joints are coupled through the Jacobian):**

```
q_des ─►[quat error]─► Kθ ─►(+)─► ω_cam,des ─► J⁻¹(θ)·(ω_cam,des − Rᵀω_base) ─► θ̇_des,j
              ▲                                                                       │
          q̂ (Mahony, IMU A)                                                           ▼
                                                    θ̇̂_j ──►(−)►[PI_vel]─►(+)─► i_q* ─►[FOC PI]─► V_dq ─► SVPWM
                                                                          ▲
                                                              i_cog(θ_m) + i_fric(θ̇)  (feedforward)
```
