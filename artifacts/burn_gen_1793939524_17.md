# Job #43: STM32H743 Nano FC with Integrated 4-in-1 ESC

**Design Package Rev A: Loss Models, Thermal Budget, Bi-directional DShot DMA Allocation, and Reference Netlists**

## 0. Architecture Clarification and Assumptions

**The STM32H743 does not commutate the motors.** It runs ArduPilot as the flight controller. Each ESC channel has its own commutation MCU (for example, an AT32F421 running AM32), and the H743 talks to those MCUs over bi-directional DShot600. This partitioning is standard. The H743's DMA resources and timing jitter make direct 6-step commutation of four motors inadvisable.

All numbers below depend on the following assumptions. If any parameter changes (MOSFET part, layer stack, board size), re-run Sections 2 and 3.

| Parameter | Assumed Value | Notes |
|---|---|---|
| Bus voltage | 6S, V_bus = 25.2 V max | Nominal 22.2 V |
| Burst current | 80 A **per channel** | Rated as a burst, not continuous |
| PWM frequency f_sw | 48 kHz | Center-aligned, complementary sync rectification |
| Commutation | 6-step trapezoidal | 120° conduction per phase |
| MOSFET (×24) | 40 V, DFN3.3×3.3 | R_DS(on),25 = 1.5 mΩ @ V_GS = 10 V; Q_g = 60 nC; Q_rr = 50 nC; C_oss = 1.5 nF; V_SD = 0.8 V; t_r = t_f = 20 ns (with R_G = 4.7 Ω) |
| R_DS(on) tempco | α = 0.006 /K | |
| Gate driver | FD6288Q-class three-phase driver, one per channel | Dead time t_dt = 200 ns |
| PCB | 36×36 mm, 8-layer, 2 oz on all layers | 30.5 mm mounting pattern. A true 20×20 "nano" cannot sustain 4×80 A (see §3.4) |

## 1. Electrical Operating Model

In 6-step operation with complementary PWM on the high side, consider one leg during its active 120° window:

- **High-side FET (Q_H):** conducts I for a fraction D of each PWM period.
- **Low-side FET of the same leg (Q_L):** freewheels for (1−D) of each PWM period. It also conducts fully during its own 120° low window.

Over one electrical revolution, the RMS currents are:

$$I_{rms,H}^2 = \frac{I^2 D}{3}, \qquad I_{rms,L}^2 = \frac{I^2(1-D)}{3} + \frac{I^2}{3} = \frac{I^2(2-D)}{3}$$

$$I_{rms,H}^2 + I_{rms,L}^2 = \frac{2I^2}{3} \quad\text{(independent of } D\text{)}$$

Only **one leg switches at a time** (the PWM'd high side). Switching loss is therefore counted once per channel, not three times.

**Worst case for switching:** at D = 1 there is no switching at all. The design-limiting point is therefore **D = 0.9 at 80 A**.

## 2. Loss Model

### 2.1 Conduction Loss (Temperature-Coupled)

$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

At the design junction temperature T_j = 110 °C:

$$R_{DS} = 1.5\times(1 + 0.006\times 85) = 2.27\text{ mΩ}$$

Per leg:

$$P_{cond,leg} = \tfrac{2}{3} I^2 R_{DS} = 0.667 \times 6400 \times 2.27\times10^{-3} = 9.68\text{ W}$$

Per channel (3 legs): **P_cond = 29.0 W**

Hottest single FET (Q_L at D = 0.9):

$$I_{rms}^2 = 6400 \times 1.1/3 = 2347\text{ A}^2 \;\Rightarrow\; I_{rms} = 48.4\text{ A}, \quad P = 5.33\text{ W}$$

### 2.2 Switching Loss at 48 kHz (One Switching Leg)

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r + t_f)·f_sw = ½·25.2·80·40 ns·48 k | 1.935 W |
| Reverse recovery | Q_rr·V·f_sw = 50 nC·25.2·48 k | 0.060 W |
| C_oss | 2·(½·C_oss·V²)·f_sw = 1.5 nF·635·48 k | 0.046 W |
| Dead-time body diode | V_SD·I·2t_dt·f_sw = 0.8·80·400 ns·48 k | 1.229 W |
| Gate drive (in driver) | 2·Q_g·V_GS·f_sw = 2·60 nC·10·48 k | 0.058 W |
| **Total switching** | | **≈ 3.33 W** |

**Design lever:** dead-time loss is 37% of the switching loss. Reducing t_dt from 200 ns to 100 ns saves 0.61 W per channel. Before doing so, verify shoot-through margin against the driver's propagation-delay mismatch.

### 2.3 Other Losses per Channel

| Item | Value |
|---|---|
| Shunt resistor (0.25 mΩ, I_avg ≈ 72 A) | ≈ 1.3 W |
| Copper traces and planes (≈0.15 mΩ effective × 80²) | ≈ 1.0 W |
| ESC MCU, driver quiescent, LDO | ≈ 0.15 W |

### 2.4 Totals at 80 A Burst, D = 0.9, T_j = 110 °C

| Item | Per Channel | 4 Channels |
|---|---|---|
| Conduction | 29.0 W | 116.0 W |
| Switching | 3.3 W | 13.3 W |
| Shunt, copper, misc | 2.5 W | 9.8 W |
| **Total** | **34.8 W** | **139 W** |

Output power is about 25.2 × 0.9 × 80 = 1814 W per channel, so efficiency is approximately **98.1%**. That efficiency is still too much heat for this board area, as Section 3 shows.
