# STM32H743 Flight Controller + 4-in-1 ESC: Power-Stage, Thermal, and Bi-Directional DShot Design Package

## 0. Scope and Assumptions

**Architecture.** The STM32H743 is the flight controller (FC) MCU running ArduPilot. Each of the four ESC channels has its own small MCU running AM32 or BLHeli_32, which handles commutation and 48 kHz PWM. The H743 does not switch MOSFETs. It sends DShot600 commands and receives eRPM telemetry over bi-directional DShot. This split determines where each calculation applies:

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

The ESC uses six-step (trapezoidal) commutation with complementary, synchronous PWM, as AM32 does. In each 60° electrical sector:

- One leg PWMs. Its high-side (HS) switch conducts during the on-time D·T. Its low-side (LS) switch carries freewheeling current during the off-time (1−D)·T.
- A second leg's LS switch is held on for the full sector.

At every instant, therefore, exactly two channels carry the phase current I:

```
P_cond,motor = I² · 2 · R_ds(on),hot          (independent of D, given synchronous rectification)
R_ds(on),hot = k_T · R_ds(on),25 = 1.6 × 0.9 mΩ = 1.44 mΩ
```

### 1.2 Ripple correction

The ripple current is ΔI = (V_bus − V_bemf)·D / (L_ph · f_sw). For a typical 5-inch motor with L_ph ≈ 15 µH and D = 0.5, near stall:

```
ΔI ≈ 25.2 × 0.5 × 0.5 / (15e-6 × 48e3) ≈ 8.75 A pk-pk
I_rms² = I² + ΔI²/12 = 6400 + 6.4  → correction < 0.1 %, neglected
```
