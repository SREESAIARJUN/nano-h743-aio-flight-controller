# STM32H743 Nano FC + 4-in-1 ESC (Job #2): Architecture, Loss Model, Thermal Budget, DShot/DMA Plan

## 0. Scope and Architectural Corrections

These points shape every number below.

1. **The H743 does not switch the MOSFETs.** In a 4-in-1 stack, each motor channel has its own ESC MCU running the commutation firmware. Typical choices are an AT32F421 or STM32G071 running AM32, or an EFM8BB51 running Bluejay. The 48 kHz PWM frequency is set in that ESC firmware. The H743 only generates bidirectional DShot600 and receives eRPM telemetry.
2. **"80 A burst" must have a duration attached.** The math in §3 shows that a 20×20 mm board cannot sustain 80 A on all four channels for more than about 1 s. The rating must be specified as a current, a duration and a channel count.
