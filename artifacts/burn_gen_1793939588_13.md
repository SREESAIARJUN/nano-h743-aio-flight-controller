# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #64): Power-Stage, Thermal, and DShot Design Model

## 0. Architecture Correction and Assumptions

### 0.1 Partitioning
The H743 should **not** commutate the motors. ArduPilot has no ESC firmware, and running four sensorless FOC/6-step loops at 48 kHz alongside the flight stack is not viable. The correct partition is:

| Block | Device | Firmware |
|---|---|---|
| Flight controller | STM32H743 (VIT6 LQFP100 or VIH6 TFBGA100 for nano footprint) | ArduPilot |
| ESC ×4 | AT32F421K8U7 or STM32G071GBU6 (one per motor) | AM32 (supports 48 kHz PWM, bidirectional DShot, EDT) |
| Gate drive | FD6288Q (3-phase, bootstrap) ×4 | — |
| Bridge | 6× N-MOSFET per channel, 24 total | — |

## 1. Conduction Loss Model

### 1.1 Six-Step Synchronous Rectification
At any instant, one phase is PWM'd (HS on for D, LS on for 1−D), one phase sinks via its LS (100%), and one floats.

Total conduction loss per channel is therefore:

```
P_cond,ch = I²·R(T)·[D + (1−D)]   (PWM leg: HS or LS always carries I)
          + I²·R(T)               (sink leg LS)
          = 2·I²·R(T)             independent of duty cycle
```

Temperature dependence:

```
R(T) = R₂₅·[1 + α(T_j − 25)]
```

### 1.2 Numbers at 80 A
- **Cold (T_j = 25 °C):** 2·6400·1.0 mΩ = **12.8 W/ch**
- **Hot (T_j = 125 °C):** 2·6400·1.65 mΩ = **21.1 W/ch**
- **Copper path:** I²·R_cu = 6400·0.5 mΩ = **3.2 W/ch**

### 1.3 Per-FET Distribution
Each FET is active for 1/3 of the electrical period in some role. The average per FET is P_cond/6 ≈ **3.5 W hot**. The PWM-leg HS carries the switching losses on top of this, so it is the hot spot.
