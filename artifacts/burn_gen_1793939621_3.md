## 1. Field-Oriented Control (Inner Current Loop, 20 kHz)

### 1.1 Transforms

Electrical angle with calibrated offset:

$$\theta_e = \operatorname{wrap}_{2\pi}\!\big(p\,(\theta_m - \theta_{0})\big)$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant and decoupled PI

For an SPM motor (L_d = L_q = L):

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

where ω_e = p·ω_m and λ_m = 2K_t/(3p).

The control law uses a PI regulator plus cross-coupling and back-EMF feedforward:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e (L i_d + \lambda_m)$$

**Pole-zero cancellation tuning.** Choose current bandwidth ω_c ≤ 2π·f_pwm/10. Here ω_c = 2π·1500 rad/s. Then:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\;\Rightarrow\;\; \frac{I(s)}{I^*(s)} = \frac{\omega_c}{s+\omega_c}$$

With the assumed values: K_p = 18.85 V/A and K_i = 52 779 V/(A·s).

Gimbal motors are high-R and low-L, so the electrical pole R/L = 2800 rad/s is already fast. Many gimbals run voltage-mode FOC instead (v_q = R·i_q* + ω_e·λ_m). The code supports both modes.
