## 0. Assumptions and Architecture

| Item | Assumed value | Symbol |
|---|---|---|
| Motor | 12N14P gimbal BLDC (e.g., GBM2804-class) | `p = 7` pole pairs, `N_s = 12` slots |
| Phase resistance / inductance | 5 Ω / 1.5 mH (phase-equivalent) | `R`, `L` |
| Torque constant | 0.08 N·m/A | `K_t` |
| Rotor + payload inertia (per axis) | 2×10⁻⁴ kg·m² | `J` |
| Encoder | 14-bit absolute magnetic (AS5048A-class) | `θ_m` |
| MCU | Cortex-M4F/M7 with FPU (STM32G4-class) | — |
| DC bus | 12 V | `V_dc` |
| Current-sense | 2- or 3-shunt, sampled at PWM center | — |
| IMUs | 2 × ICM-42688-P on the camera plate, mirrored about the tilt-axis center | A, B |

**Loop rates (each loop is decimated from the PWM interrupt):**

```
PWM / current loop (FOC)   f_c  = 20 kHz   (Ts_c  = 50 µs)
IMU sample + filters       f_imu=  8 kHz   (both IMUs, phase-locked via CLKIN)
Velocity loop              f_v  =  4 kHz   (Ts_v  = 250 µs)
Angle loop + attitude      f_θ  =  1 kHz   (Ts_θ  = 1 ms)
```

**Control topology for one axis:**

```
            ┌─────────── attitude (fused dual IMU, Mahony) ──────────┐
θ_ref ─►(Σ)─► Angle P/PI ─► ω_ref ─►(Σ)─► Velocity PI ─► i_q* ─►(Σ)─► FOC current PI ─► SVPWM ─► Motor
         ▲  + ω_ff                  ▲   + J·α_ff/K_t               ▲
         │                          │   + i_cog(θ_m) (anti-cogging) │
         └── θ_payload (IMU)        └── ω_payload (gyro, notched)   └── i_dq (shunts, Park via encoder θ_e)
```

The IMU closes the outer loops, so the stabilization target is the camera, not the rotor. The encoder is used only for commutation, cogging compensation, and joint-space limits.

## 1. Field-Oriented Control (Innermost Loop)

### 1.1 Electrical Angle

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

`θ_m,0` is the encoder offset, found by aligning the rotor with `v_d = V_align`, `v_q = 0` at `θ_e = 0`.

### 1.2 Clarke Transform (Amplitude-Invariant)

For three-shunt sensing, first enforce `i_a + i_b + i_c = 0` by subtracting the mean.

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park Transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM Model in the dq Frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$

$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$

Here `ω_e = p·ω_m` and `λ_m = K_t / (1.5·p)`, which is consistent with the amplitude-invariant transform.
