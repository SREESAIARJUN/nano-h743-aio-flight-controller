# 3-Axis Gimbal FOC Control & Dual-IMU Sensor Fusion: Design Specification

I don't have the original Job #12 specification, so this design states its assumptions explicitly. Every parameter is a named constant, so you can substitute your real values.

---

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC available), single core |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs $p=7$), $R_s≈5\,Ω$, $L_s≈2\,\text{mH}$, $K_t≈0.08\,\text{N·m/A}$ |
| Encoders | 14-bit absolute magnetic encoders (MT6701 / AS5048A), SPI |
| IMUs | 2× ICM-42688-P on payload (A, B), mounted symmetric about the camera CoM |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
| Current loop | 20 kHz (synchronous to center-aligned PWM) |
| Rate loop | 4 kHz (IMU ODR 8 kHz, decimated ×2 after filtering) |
| Attitude loop | 1 kHz |
