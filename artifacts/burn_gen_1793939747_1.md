# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #33)

I don't have the hardware specification for Job #33, so this design rests on the assumptions in §0. Every parameter is a `constexpr` or a config struct field, so you can change it to match your actual motors, MCU, and IMU placement.

## 0. Assumptions and Timing Architecture

| Item | Assumption |
|---|---|
| Motors | Gimbal BLDC, 24N22P (11 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH, K_t ≈ 0.1–0.3 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701), read via SPI every PWM cycle |
| MCU | STM32G474 / H7 class with an FPU; center-aligned PWM; ADC triggered at the PWM center |
| IMUs | 2× ICM-42688-P on the camera platform, read over separate SPI buses, ODR 8 kHz |
| Vdc | 12–16 V |

**Loop rates and bandwidths**

| Loop | Rate | Target bandwidth | Separation |
|---|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz | — |
| Velocity | 4 kHz | ~150–250 Hz | ≥ 8× below current |
| Angle | 1 kHz | ~20–40 Hz | ≥ 5× below velocity |
| IMU acquisition and filtering | 8 kHz | — | — |
| Attitude estimator | 1 kHz | — | — |
| Anti-cogging identification | 1 kHz | — | — |

**Signal chain**

```
                    ┌────────── 1 kHz ─────────┐ ┌──── 4 kHz ─────┐ ┌──────── 20 kHz ───────┐
 θ_ref ──►(+)──► Angle PD ──ω_ref──►(+)──► Velocity PI ──i_q*──►(+)──► Current PI d/q ─► SVPWM ─► Inverter ─► Motor
           ▲−                        ▲−                    ▲   ▲ i_ff,cog            ▲−
           │                         │                     │   │                     │ i_d,i_q (Clarke/Park)
   attitude (Mahony)       gyro rate on joint axis        Anti-cog FF          encoder θ_e
           ▲                         ▲
   Dual ICM-42688-P → AAF → adaptive notches → LPF → fusion
```

The velocity loop uses inertial rate from the gyros, projected onto each joint axis. The angle loop uses estimated attitude. This is what gives true inertial stabilization rather than mere frame-relative position holding. The encoder is used for commutation, for anti-cogging phase, and for the joint-space Jacobian.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

**Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):**

$$
i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)
$$

**Park transform (θ_e = p · θ_m − θ_offset):**

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix}=
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park transform:**

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 1.2 Delay Compensation

Two delays separate a measurement from its effect: the ADC/PWM update takes one period, and the PWM zero-order hold adds half a period. The voltage-transform angle is therefore advanced by:

$$
\theta_e^{\text{out}} = \theta_e + 1.5\,T_s\,\omega_e
$$

### 1.3 Plant Model and PI Design

The PMSM dq model is:

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m
$$

With cross-coupling and back-EMF decoupling applied as feedforward, the plant reduces to $G(s) = 1/(Ls+R)$.

**Pole-zero cancellation design** (target bandwidth ω_c):

$$
K_p = L\,\omega_c,\qquad K_i = R\,\omega_c\;\;\Rightarrow\;\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}
$$
