# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion

I don't have the specifications for "Job #9," so this design rests on explicit assumptions (§0). Every gain is derived from plant parameters, so you can substitute your own values.

---

## 0. Assumptions and Architecture

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC (PMSM), high-resistance winding, e.g. 12N14P (pole pairs p = 7) |
| Position sensor | 14-bit magnetic encoder per axis (AS5048A / MT6701 class) |
| Kinematics | Base → **Yaw (z)** → **Roll (x)** → **Pitch (y)** → camera |
| IMU-A | ICM-42688-P on the **camera/payload**. Provides attitude feedback. |
| IMU-B | ICM-42688-P on the **base/handle**. Provides the disturbance reference for feed-forward and adaptive vibration cancellation. |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |

**Loop rates and bandwidth separation.** Each loop's bandwidth is at least 4–5× below the loop inside it:

```
 IMU ODR 8 kHz ─► notch/LMS/AAF ─► Mahony (1 kHz) ─► Attitude P (1 kHz, BW≈15 Hz)
                                                         │ ω_d (payload frame) + base-rate FF
                                                         ▼
                                           Inverse Jacobian J⁻¹(q)
                                                         ▼
   Encoder ─► Velocity PI per joint (4 kHz, BW≈80 Hz) ◄──┘
                         │ i_q* + cogging FF + inertial FF
                         ▼
   Current PI d/q (20 kHz, BW≈1.5 kHz) ─► SVPWM ─► inverter
```
