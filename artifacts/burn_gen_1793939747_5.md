| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, single-precision FPU) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5 Ω, L ≈ 1.5 mH, Kt ≈ 0.07 N·m/A |
| Encoders | 14-bit magnetic (AS5048A/MT6701), SPI |

| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, FIFO and timestamps enabled |

**Loop rates and bandwidths.** Each loop is roughly 5–10× slower than the one inside it, which keeps the cascade decoupled.

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| Velocity | 4 kHz | ω_v ≈ 2π·150 rad/s |
| Angle (attitude) | 1 kHz | ω_θ ≈ 2π·20 rad/s |
| IMU filtering | 8 kHz | Decimated to 4 kHz for the velocity loop |

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Plant (Surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 1.3 PI with Decoupling and Pole-Zero Cancellation

Choose the integral-to-proportional ratio so the PI zero cancels the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_c:

$$K_p^{(i)} = L\,\omega_c,\qquad K_i^{(i)} = R\,\omega_c$$

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \hat\omega_e(L i_d + \lambda_m)$$

**Voltage limiting.** Space-vector modulation can produce at most |v| ≤ V_dc/√3. Saturation is handled as follows:

- Saturate the (v_d, v_q) vector, giving d-axis priority.
- Use back-calculation anti-windup with gain K_aw = 1/K_p:

$$x_I \mathrel{+}= T_s\left[K_i e + K_{aw}(v_{sat}-v_{unsat})\right]$$

### 1.4 SVPWM (Min-Max Zero-Sequence Injection)

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\qquad v_0 = -\tfrac12\left(\max v_{abc} + \min v_{abc}\right)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$

This produces waveforms identical to sector-based SVPWM with far less code.
