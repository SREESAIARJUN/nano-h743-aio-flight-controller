# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the specification for Job #15, so this design rests on the assumptions in §0. Every symbol is a parameter. Change the numbers in `GimbalConfig` to match your hardware.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motors | 3 × BLDC gimbal motors, 12N14P (pole pairs `p = 7`), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Rotor sensing | 14-bit absolute magnetic encoder (e.g., AS5048/MT6701) per joint |
| Current sensing | 2-phase inline shunts, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, mirrored about the plate centroid |
| MCU | Cortex-M4F/M7 with single-precision FPU (e.g., STM32G4/H7) |
| Kinematics | Yaw (pan) → Roll → Pitch (tilt), camera on the pitch link |

The control is a cascade of four rate-separated loops:

```
           1 kHz                 4 kHz                     20 kHz
q_ref ─►[Attitude P/PI]─ω_ref─►[Rate PI + FF]─iq_ref─┬─►[Id/Iq PI]─►[SVPWM]─► Motor
           ▲                        ▲                │       ▲
           │                        │   iq_cog(θm,ω) ┘       │ Clarke/Park(θe)
     q̂ (Mahony)            ω_joint = J⁻¹(θ)·ω̂_cam        ia, ib, θm (encoder)
           ▲                        ▲
    [Dual-IMU fusion ◄─ notch bank ◄─ AAF] ◄── 2 × ICM-42688-P @ 8 kHz ODR
```

**Bandwidth separation.** Each loop is at least 4–5× slower than the loop inside it:

- Current loop: ω_c ≈ 2π·1.5 kHz
- Rate loop: ω_v ≈ 2π·60–120 Hz
- Attitude loop: ω_θ ≈ 2π·10–25 Hz

## 1. Field-Oriented Control (Current Loop, 20 kHz)

### 1.1 Electrical Angle

```
θ_e = p · (θ_m − θ_offset)   mod 2π
```

`θ_offset` is found by alignment: apply V_d with θ_e = 0, let the rotor settle, and record θ_m.

### 1.2 Clarke Transform (Amplitude-Invariant, i_a + i_b + i_c = 0)

```
i_α = i_a
i_β = (i_a + 2 i_b) / √3
```

### 1.3 Park Transform

```
i_d =  i_α cos θ_e + i_β sin θ_e
i_q = −i_α sin θ_e + i_β cos θ_e
```

### 1.4 PMSM Model in the dq Frame

```
v_d = R i_d + L di_d/dt − ω_e L i_q
v_q = R i_q + L di_q/dt + ω_e L i_d + ω_e λ_m
τ_e = (3/2) p λ_m i_q = K_t i_q          (surface PM, L_d = L_q)
```

### 1.5 Current PI with Decoupling

**Gains by pole-zero cancellation.** The plant is `1/(Ls+R)`. Choosing the PI zero at R/L makes the closed loop first-order with bandwidth ω_c:

```
K_p,i = L · ω_c ,   K_i,i = R · ω_c
```

**Control law:**

```
v_d* = PI_d(i_d* − i_d) − ω_e L i_q
v_q* = PI_q(i_q* − i_q) + ω_e L i_d + ω_e λ_m
```

In gimbals ω_e is small, but the decoupling terms are cheap and help during fast slews.

### 1.6 Voltage Limiting and Anti-Windup

**Circular limit.** With SVPWM, |v| ≤ V_bus/√3. Priority goes to the q-axis:

```
v_d ← sat(v_d, ±V_max)
v_q ← sat(v_q, ±√(V_max² − v_d²))
```

**Back-calculation anti-windup** (per axis), with K_aw ≈ 1/K_p:

```
I[k+1] = I[k] + K_i T_s e[k] + K_aw (v_sat − v_unsat)
```
