# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #43 spec sheet. The design below uses typical gimbal values. Every constant marked `CFG` is meant to be replaced with your measured values.

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, center-aligned PWM |
| Motors | Hollow-shaft gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 10 Ω, L ≈ 2 mH |
| Position sensor | 14-bit magnetic encoder per axis (AS5048A / MT6701), read on SPI in the PWM ISR |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR 8 kHz, gyro FS ±1000 dps, accel ±8 g |
| Loop rates | Current 20 kHz → Velocity 4 kHz → Angle/attitude 1 kHz |
| Bus | V_dc = 12–16 V |

Rule of thumb for loop rates: each outer loop's bandwidth should be about 5–10× below the inner loop's bandwidth. Each loop should run 10–20× faster than its own bandwidth.
