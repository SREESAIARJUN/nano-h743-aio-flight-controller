# STM32H743 AIO Flight Controller with 4-in-1 ESC: Power-Stage, Thermal, and DShot Architecture (Job #12)

## 0. Architecture Clarification and Assumptions

**Partitioning.** The STM32H743 does not commutate the motors. ArduPilot has no motor-commutation firmware. The architecture is therefore:

```
STM32H743 (ArduPilot)  ──Bidir DShot600 ×4──►  4× ESC MCU (AM32, e.g. AT32F421 / STM32G071)
                                                    │  48 kHz complementary PWM
                                                    ▼
                                              3-ph gate driver ×4 → 24 MOSFETs → motors
```

The 48 kHz PWM frequency is an ESC-firmware setting (AM32 `PWM_FREQUENCY`). It is not an H743 timer.

## 1. Conduction Loss Model (80 A Burst)

**Commutation model.** AM32 uses 6-step trapezoidal commutation with synchronous rectification.

- In every commutation sector, one leg is PWM-switched and a second leg is held with its low-side FET on.
- In the PWM leg, current flows through the high-side FET for a fraction D of each period and through the low-side FET for 1−D.

The conduction loss of the PWM leg is therefore independent of duty cycle:

$$P_{cond,PWM} = I^2 R_{hot}\,[D + (1-D)] = I^2 R_{hot}$$

The return leg adds:

$$P_{cond,ret} = I^2 R_{hot}$$

**Per-channel total (one motor):**

$$P_{cond} = 2 I^2 R_{hot} + I^2 R_{cu} = 6400\,(2 \times 1.8\text{m} + 0.5\text{m}) = 23.0 + 3.2 = \mathbf{26.2\ W}$$

**Hottest single device.** The low-side FET of the return leg carries the full current for its entire 120° sector:

$$P_{FET,max} = 80^2 \times 1.8\text{m} = \mathbf{11.5\ W}$$

The R_ds(on)–temperature feedback is already captured by using R_hot. If T_j exceeds about 125 °C, iterate:

$$R(T) = R_{25}\,[1 + \alpha(T-25)], \quad \alpha \approx 0.005\ /\text{K}$$

## 2. Switching Loss Model (f_sw = 48 kHz)

**Gate currents:**

$$I_{g,on} = \frac{V_{drv} - V_{pl}}{R_{g,on}} = 1.3\text{ A}, \qquad I_{g,off} = \frac{V_{pl}}{R_{g,off}} = 0.875\text{ A}$$

**Transition times:**

$$t_r = \frac{Q_{gd} + Q_{gs2}}{I_{g,on}} = 10\text{ ns}, \qquad t_f = \frac{Q_{gd} + Q_{gs2}}{I_{g,off}} \approx 15\text{ ns}$$
