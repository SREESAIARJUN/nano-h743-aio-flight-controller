## 0. Scope, Assumptions, and Flags

### Architectural flags

1. **The H743 does not commutate the motors.** ArduPilot has no BLDC commutation firmware. The topology is an H743 flight controller sending bidirectional DShot600 to four dedicated ESC MCUs (AT32F421 or STM32G071 running AM32), each driving one 3-phase bridge.
2. **"Nano" and "80 A burst" conflict.** On a 20×20 mm board, 80 A per channel cannot be supported by copper cross-section or thermal mass. This package assumes a **30.5×30.5 mm, 8-layer, 2 oz stack** as the smallest credible form factor. Section 3.6 shows that even this sustains 80 A on all four channels for only **seconds**.
3. **The netlist is a representative reference design**, not production-validated. Part numbers must be checked against current datasheets and stock before layout.

## 1. Conduction Loss Model

### 1.1 Current path in 6-step (trapezoidal) commutation with synchronous rectification

In each 60° electrical sector, exactly two phases carry current *I*:

- **PWM leg.** The high-side switch conducts for fraction *D*. The complementary low-side switch conducts for (1 − D).
- **Return leg.** The low-side switch is held on for the full sector.

At every instant, two MOSFET channels are therefore in series with the motor current, regardless of duty:

```
P_cond,ch = I² · R_hot · [D + (1 − D)] + I² · R_hot = 2 · I² · R_hot
```

### 1.2 Per-FET distribution

Each FET is active for 120° of every 360° electrical. The sector-averaged loss per FET is:

```
P_cond,FET = I² · R_hot / 3
```

The electrical frequency is about 1–3 kHz at burst RPM. Its period (≈ 0.3–1 ms) is far shorter than the die thermal time constant (≈ 5–20 ms), so the averaged value is valid for junction calculations.
