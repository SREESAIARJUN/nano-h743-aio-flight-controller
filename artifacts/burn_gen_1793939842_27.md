# STM32H743 AIO Nano FC + 4-in-1 ESC (Job #15): Architecture, Loss Model, Thermal Model, DShot DMA Plan

## 0. Architecture Corrections and Assumptions

Several requirement-level issues need resolving before any numbers are meaningful.

1. **The H743 does not commutate the motors.** ArduPilot has no ESC commutation firmware. The correct architecture is an AIO board with:
   - an H743 running ArduPilot, which emits bidirectional DShot600, and
   - four dedicated ESC MCUs running AM32 (e.g., AT32F421K8U7, QFN32), which generate the 48 kHz complementary PWM.

   The switching-loss model below therefore applies to the ESC MCU's PWM, not the H743's.

2. **"80 A burst" on a nano footprint is a thermal-capacitance rating, not a continuous rating.** The math below shows the board can tolerate 4 × 80 A for roughly 1.5–2 s. The datasheet should state duration and duty cycle, or it is not a defensible spec.

3. **Assumed parameters.** Every value is parameterized, so swap in real datasheet numbers when the BOM is fixed.

## 1. Conduction Loss Model (per ESC channel, I = 80 A)

### 1.1 Current path in 6-step with synchronous rectification
In any sector, current flows from the switching leg (HS during D, LS during 1−D) to the return leg (LS fully on):

```
P_cond,FET = I_rms² · R_ds(on)(Tj) · [D + (1−D)]  +  I_rms² · R_ds(on)(Tj)
           = 2 · I_rms² · R_ds(on)(Tj)
```

Neglecting dead time, this is independent of duty cycle.

### 1.2 Temperature-dependent R_ds(on)
```
R_ds(on)(Tj) = R_ds(on),25 · (1 + α(Tj − 25)),   α ≈ 0.006 /K
R_ds(on)(125 °C) = 1.2 mΩ · 1.6 = 1.92 mΩ
```

### 1.3 Ripple correction
With phase inductance L ≈ 10 µH (typical 2207-class motor), the ripple is:

```
ΔI_pp ≈ V_bus·D(1−D) / (L·f_sw)
      = 25.2·0.25 / (10e-6·48e3)
      ≈ 13 A (worst case, D = 0.5)

I_rms² = I_dc² + ΔI_pp²/12 = 6400 + 14 = 6414 A²   (≈ +0.2 %, negligible)
```

### 1.4 Results
```
P_cond,FET    = 2 · 6414 · 1.92e-3                           = 24.6 W
P_shunt       = 80² · 0.2e-3                                 = 1.28 W
P_copper      ≈ 80² · 0.15e-3   (≈0.15 mΩ trace/via path, 2 oz) ≈ 0.96 W
P_cond,total                                                 ≈ 26.9 W
```

**Self-heating feedback.** R_ds(on) depends on Tj, which depends on loss. Solve iteratively:

```
Tj = T_board + P_FET · R_θjb(eff),   P = 2I²·R25·(1 + α(Tj − 25))
```

This converges if `2I²·R25·α·R_θjb < 1`:

```
2·6400·1.2e-3·0.006·(R_θjb per channel ≈ 7.5/3 K/W) = 0.23 < 1   → stable
```
