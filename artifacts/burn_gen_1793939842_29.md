# STM32H743 Nano FC with Integrated 4-in-1 ESC: Power-Stage, Thermal, and Bidirectional DShot600 Design

## Executive Summary

The design is buildable. However, the headline requirement of **80 A per motor on a nano board** cannot be met continuously. The math below shows:

| Parameter | Result |
|---|---|
| Loss per motor channel at 80 A, T_j = 125 °C | ≈ 28.6 W |
| Loss with all four motors at 80 A | ≈ 115 W |
| Adiabatic board heating rate | ≈ 46 K/s |
| Usable all-motor 80 A burst (from 60 °C board temperature) | ≈ 1.2–1.4 s |
| Realistic continuous rating (25×25 mm, 6-layer 2 oz, prop-wash cooling) | ≈ 25–35 A per motor |

The firmware must therefore enforce an I²t / thermal-model current limit, and the specification should read **"80 A burst (≤1 s), 30 A continuous."**

## 1. System Architecture

```
 VBAT (3–6S, 25.2 V max)
   │
   ├──► Bulk caps + TVS ──► 4× [ESC MCU (AM32) → 3-ph gate driver → 6× N-MOSFET bridge → Motor]
   │                               ▲ DShot600 bidir (1 wire each)
   ├──► 5 V / 3.3 V buck ──► STM32H743 FC ──┘  (TIM1 CH1–CH4 + DMA)
   │                              ├── SPI1 → ICM-42688-P (IMU)
   └──► VBAT/ISENSE ADC           ├── SPI2 → AT7456E OSD / SPI4 → flash
                                  └── UARTs: RC, GPS, VTX, telemetry
```

**Key point:** the H743 does **not** commutate the motors. Each channel has its own ESC MCU (STM32G071 or AT32F421 running AM32), which generates the 48 kHz complementary PWM. The H743 only issues DShot600 commands and receives eRPM telemetry over the same wire. This separation is what makes 48 kHz switching and bidirectional DShot coexist cleanly.

## 2. Conduction Loss Model

### 2.1 Topology and Commutation Assumptions

The model assumes:

- Six-step trapezoidal commutation.
- Complementary (synchronous-rectified) PWM on the active phase leg.

At any instant two phases carry the full phase current I:

- **Switching leg:** the high-side FET conducts for D·T_sw. The low-side FET conducts the freewheel current for (1−D)·T_sw, minus dead time.
- **Static leg:** the low-side FET is on continuously.
