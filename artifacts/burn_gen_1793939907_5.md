## 0. Scope, Architecture Assumptions, and a Reality Check

**Architecture.** The STM32H743 is the flight controller. It should **not** commutate the motors directly. Each motor channel is driven by a dedicated ESC MCU running AM32 or BLHeli_32 (for example an STM32G071 or AT32F421). The H743 sends bidirectional DShot600 to each ESC MCU and receives eRPM telemetry back.

The reason is real-time isolation. Running sensorless commutation for four motors alongside ArduPilot's scheduler on one core is a certification and reliability liability.

> ⚠️ **Reality check up front.** The analysis below shows that "80 A burst" on a nano-format board is a **time-limited rating of roughly 1.5–3 s**, not a sustainable operating point. Realistic continuous current in propwash is about **20–25 A per channel**. Do not publish an 80 A rating without a stated duration and the test conditions behind it.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

The ESC uses 6-step trapezoidal commutation with complementary (synchronous) PWM. At any instant, motor current flows through:

- **One FET of the PWM leg.** This is the high-side FET during the on-time and the low-side FET during freewheeling. Because rectification is synchronous, one channel resistance is always in the path regardless of duty cycle.
- **The static low-side FET** of the return leg.
- **The shunt and the copper.**

So the effective series resistance is:

$$R_{path}(T_j) = 2\,k_T\,R_{ds25} + R_{sh} + R_{Cu}$$

### 1.2 Hot-junction resistance

$$R_{ds}(125^\circ C) = 1.6 \times 1.0\ \text{m}\Omega = 1.6\ \text{m}\Omega$$
