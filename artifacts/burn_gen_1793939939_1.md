## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at commissioning by applying a d-axis voltage and reading the encoder. The encoder read, current sampling and PWM update add about 1.5 T_c of delay, which matters at speed. Compensate it with:

$$\hat\theta_e = \theta_e + 1.5\,T_c\,\omega_e$$

### 1.2 Clarke transform (amplitude-invariant, two shunts)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

Electromagnetic torque (surface PMSM, so there is no reluctance term):

$$\tau_e = K_t\, i_q$$

### 1.5 PI design by pole-zero cancellation

With the cross-coupling and back-EMF terms fed forward, each axis reduces to $G(s) = 1/(Ls+R)$.

Choose the PI controller $C(s) = K_p + K_i/s$ with:

$$K_p = L\,\omega_{ci},\qquad K_i = R\,\omega_{ci}$$

The zero then cancels the plant pole, and the closed loop becomes $\omega_{ci}/(s+\omega_{ci})$.

Choose $\omega_{ci} \le 2\pi f_c/10$. For f_c = 20 kHz, ω_ci = 2π·1500 rad/s, which gives K_p = 18.85 V/A and K_i = 47 124 V/(A·s).

Decoupling feedforward:

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e \lambda_m$$

Discretization uses forward-Euler integration, $x_{k+1} = x_k + K_i T_c e_k$.

**Voltage limiting.** Limit the vector magnitude, with d-axis priority:

$$|v| \le V_{dc}/\sqrt3 \;(\text{SVPWM linear region})$$

**Anti-windup.** Use back-calculation:

$$x_{k+1} = x_k + T_c\left[K_i e_k + K_{aw}(v^{sat} - v^{unsat})\right],\qquad K_{aw} = K_i/K_p$$

### 1.6 Inverse Park and SVPWM (min-max injection)

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$
