# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

I don't have the original specification for "Job #2," so I've stated concrete assumptions in §0. Every equation and constant is parameterised, so you can substitute your actual motor, encoder and MCU values.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH, K_t ≈ 0.11 N·m/A |
| Encoder | 14-bit absolute magnetic encoder (AS5048A/MT6835 class), read once per current-loop tick |
| MCU | Cortex-M4F/M7 with FPU (e.g. STM32G474), center-aligned PWM at 20 kHz, ADC triggered at the counter peak |
| IMU A | ICM-42688-P on the **camera payload**, 8 kHz ODR (control and attitude) |
| IMU B | ICM-42688-P on the **base/handle**, 8 kHz ODR (vibration reference and base-rate feedforward) |
| Supply | V_bus = 12–16 V |

The loops are layered as follows, with roughly 5–10× bandwidth separation between each layer:

```
                1 kHz                 4 kHz                      20 kHz
 θ_ref ──►[Angle P(+FF)]──ω_ref──►[Rate PI + FF]──i_q*──►[Current PI dq + decoupling]──►SVPWM──►Motor
              ▲                       ▲    ▲  ▲                     ▲
       payload attitude      fused gyro│    │  └── cogging FF(θ_m)   │ i_a,i_b,θ_e (encoder)
       (Mahony, IMU A)      (IMU A cleaned) └── base-rate FF (IMU B)
```

| Loop | Rate | Target crossover |
|---|---|---|
| Current | 20 kHz | ω_ci = 2π·1.5 kHz |
| Rate | 4 kHz | ω_cv = 2π·150 Hz |
| Angle | 1 kHz | ω_cθ = 2π·25 Hz |
