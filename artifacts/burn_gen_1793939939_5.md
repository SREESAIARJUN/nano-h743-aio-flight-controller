# 3-Axis Gimbal FOC Control Loop and Dual-IMU Sensor Fusion: Design Specification

> **Scope note:** I don't have the Job #9 hardware specification. The design below states its assumptions explicitly in §0. All parameters are grouped in config structs, so you can swap in your real motor, encoder, and MCU values without restructuring.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class: Cortex-M4F/M7, single-precision FPU, CORDIC optional |
| Motor | Gimbal BLDC, 12N14P (pole pairs `p = 7`), `R ≈ 5–15 Ω`, `L ≈ 2–5 mH` |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), SPI |
| Current sense | 2 or 3 low-side shunts, sampled at PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, DRDY interrupt |
| Kinematic chain | base → **yaw** (z) → **roll** (x) → **pitch** (y) → camera |

| Loop | Rate | Source of feedback |
|---|---|---|
| Current (FOC, d/q PI) | 20 kHz (PWM ISR) | shunts + encoder angle |
| Velocity (rate) | 4 kHz | fused, filtered gyro (camera frame) |
| Attitude (angle) | 1 kHz | quaternion from dual-IMU Mahony filter |
| IMU sampling | 8 kHz ODR, decimated 2:1 | ICM-42688-P (AAF + UI filter on-chip) |
