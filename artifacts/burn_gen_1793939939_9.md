## 0. Assumptions and Architecture

I don't have the Job #26 hardware specification, so the design is parameterized. Typical gimbal values are given as defaults. Replace every value marked `// [CAL]` with measured data.

| Item | Default assumption |
|---|---|
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701), SPI, read every PWM cycle |
| Current sensing | 2-shunt or inline. A voltage-mode fallback is provided for sensorless-current boards. |
| MCU | STM32G4 / H7-class Cortex-M with FPU, center-aligned PWM |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, ODR = 8 kHz, FIFO + hardware timestamp |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates (cascade bandwidth separation of at least 5×):**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz (ISR, synced to PWM) | 1.5–3 kHz |
| Velocity (gyro-rate) | 4 kHz | 80–150 Hz |
| Angle (attitude) | 1 kHz | 15–30 Hz |
| IMU acquisition and filtering | 8 kHz | — |
| Attitude estimator | 1 kHz | — |
