# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #18): Power-Stage, Thermal and Bi-Directional DShot Design Package

---

## 0. Architecture Corrections and Scope

Two points need to be settled before the math, because they change the results.

**1. The H743 does not commutate the motors.**
On every production AIO design, and in ArduPilot's driver model, the H743 runs ArduPilot as the flight controller. Four separate ESC MCUs run the motors. Suitable MCUs are AT32F421 or STM32G071, running AM32 or BLHeli_32-class firmware.

The H743 sends bi-directional DShot600 to those MCUs. Each ESC MCU generates the 48 kHz complementary PWM and handles commutation. The partition below follows that model.

**2. "Nano" (20×20 mm) and 80 A burst per channel are physically incompatible.**
- **Placement:** 24 power MOSFETs in DFN5×6 occupy about 720 mm² of pad area. A 20×20 board has 400 mm² per side, before the MCUs, drivers, capacitors and pads.
- **Heat capacity:** the thermal analysis in §3 shows a 20×20 board reaches its limit in about 2 s at full burst. A 30.5×30.5 board lasts about 5 s.

**Recommendation:** use one of these two options.
- A 30.5×30.5 mm board rated 80 A burst / 55 A continuous.
- A 20×20 board derated to roughly 45 A burst, using 3.3×3.3 mm FETs.

The model below is parameterized so either variant can be evaluated.

**Status of all values:** component values are representative engineering assumptions. Bracketed values are to be confirmed against the selected parts' datasheets. The netlist is a reference topology, not a released, DRC-checked design.

## 2. Electrical Loss Model (per ESC channel)

### 2.1 Conduction Loss

Six-step trapezoidal drive uses synchronous (complementary) PWM. In each commutation sector, two half-bridges carry the current:

- **PWM'd phase:** the high-side FET conducts for a fraction D of each cycle, and the low-side FET conducts synchronously for the remaining (1−D).
- **Return phase:** the low-side FET conducts for 100% of the sector.

The conduction loss is:

$$P_{cond} = I^2 R_{ds}\left[D + (1-D)\right] + I^2 R_{ds} = 2\,I^2 R_{ds,hot}$$

The result is independent of duty cycle, which is a useful property of synchronous rectification.

$$P_{cond} = 2(80)^2(1.5\times10^{-3}) = \mathbf{19.2\ W}$$

Copper loss along two phase paths:

$$P_{cu} = 2I^2R_{cu} = 2(6400)(0.5\times10^{-3}) = \mathbf{6.4\ W}$$

### 2.2 Switching Losses at 48 kHz

Hard switching occurs on the high-side FET only. The low-side FET switches at near-zero voltage, because its body diode clamps during the dead time.

**V–I overlap loss:**

$$P_{VI} = \tfrac{1}{2}V_{in} I (t_r+t_f) f_{sw} = 0.5(25.2)(80)(40\text{ns})(48\text{k}) = \mathbf{1.94\ W}$$

**Output-capacitance loss:**

$$P_{Coss} = \tfrac{1}{2}C_{oss}V_{in}^2 f_{sw}\times 2 = 1.5\text{n}\cdot 635\cdot 48\text{k} = \mathbf{0.05\ W}$$

**Reverse-recovery loss:**

$$P_{rr} = Q_{rr}V_{in}f_{sw} = 50\text{n}(25.2)(48\text{k}) = \mathbf{0.06\ W}$$

**Dead-time diode conduction (two dead-time intervals per cycle):**

$$P_{dt} = V_f\, I\, (2t_{dt}) f_{sw} = 0.8(80)(200\text{n})(48\text{k}) = \mathbf{0.61\ W}$$

**Gate drive (two switched FETs; dissipated in the driver and gate resistors, not the FETs):**

$$P_g = Q_g V_g f_{sw}\times 2 = 60\text{n}(10)(48\text{k})(2) = \mathbf{0.06\ W}$$

### 2.3 Loss Totals at 80 A Burst

| Loss term | Per channel | 4 channels |
|---|---|---|
| Conduction (FETs) | 19.2 W | 76.8 W |
| Copper | 6.4 W | 25.6 W |
| Switching (V–I + C_oss + Q_rr) | 2.05 W | 8.2 W |
| Dead-time diode | 0.61 W | 2.4 W |
| Gate drive | 0.06 W | 0.24 W |
| **Total** | **28.3 W** | **113 W** |

Efficiency check at 80 A: the output power is about 25.2 V × 80 A × D. At D ≈ 0.9 this is about 1.8 kW per channel, so the power stage is roughly 98.4% efficient. The problem is not efficiency; it is heat density.
