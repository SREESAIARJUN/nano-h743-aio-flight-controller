# FOC Motor Control & Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no context for "Job #3", so this design is built on the assumptions in §0. Every hardware-dependent constant is a named parameter and is marked where you must substitute your own value. Before flight, check all ICM-42688-P register values against your datasheet revision.

---

## 0. Assumptions and Loop Timing

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class, FPU, ≥170 MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| Current sense | 2 or 3 low-side shunts, ADC synchronized to PWM center |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI, 8 kHz ODR, mounted symmetrically about the payload CoM |

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (d/q PI) + SVPWM | 20 kHz (PWM ISR) | 1.5–2 kHz |
| Encoder PLL + cogging feedforward | 20 kHz | PLL ωₙ ≈ 2π·300 rad/s |
| IMU filtering + inertial rate loop | 4 kHz | 80–150 Hz |
| Attitude loop + estimator | 1 kHz | 10–25 Hz |

The bandwidth separation between loops is at least 5×. That separation is what justifies the cascade design: each outer loop may treat its inner loop as unity gain.
