# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I have no project files for "Job #9," so this design rests on the assumptions in §0. Every parameter that depends on your hardware is a named constant, so you can substitute your own values.

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class with FPU (single precision) |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic encoder (AS5048A / MT6701) per joint |
| Current sensing | 2-phase low-side shunts (a voltage-mode fallback is noted in §1.6) |
| PWM / current loop | 20 kHz center-aligned PWM; current loop at 20 kHz |
| Velocity loop | 4 kHz |
| Angle / attitude loop | 1 kHz |
| IMUs | 2× ICM-42688-P on the camera plate, both over SPI at 24 MHz, ODR = 8 kHz, FIFO off, DRDY interrupt |
| Gimbal kinematics | Yaw (z) → Roll (x) → Pitch (y), with the camera on the pitch link |

**Loop bandwidth separation** (each loop at least 4–5× faster than the one it feeds):

$$\omega_{c,i} \approx 2\pi\cdot 1.5\text{ kHz},\quad \omega_{c,v} \approx 2\pi\cdot 60\text{–}120\text{ Hz},\quad \omega_{c,\theta} \approx 2\pi\cdot 10\text{–}25\text{ Hz}$$

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical Angle

$$\theta_e = \mathrm{wrap}_{2\pi}\big(p\,(\theta_m - \theta_{m,0})\big)$$

Here θ_{m,0} is the encoder offset. Measure it by locking the rotor with a d-axis current and reading the encoder.

**Latency compensation.** The encoder sample is t_d old (SPI transfer plus half a PWM period), so extrapolate:

$$\hat\theta_e = \theta_e + p\,\hat\omega_m\,t_d,\qquad t_d \approx 1.5\,T_{pwm}$$

### 1.2 Clarke and Park Transforms (Amplitude-Invariant)

With i_c = −i_a − i_b:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.3 Plant Model in the dq Frame

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q$$
$$v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e \lambda_m$$
