# 3-Axis Gimbal: FOC Motor Control, Anti-Cogging Feedforward, and Dual ICM-42688-P Sensor Fusion

The "Job #0" spec wasn't included, so this design uses the typical brushless-gimbal values listed in §0. Every gain below is derived from those values, so you can substitute your measured parameters.

---

## 0. Assumptions and Architecture

| Item | Value (example) |
|---|---|
| Motor | GBM-style 12N14P, pole pairs $p = 7$, $R_s = 5.6\,\Omega$, $L_s = 2.2\,\text{mH}$, $K_t = 0.08\,\text{Nm/A}$ |
| Load inertia (per axis, reflected) | $J = 2.5\times10^{-4}\ \text{kg·m}^2$ |
| Bus | $V_{dc} = 12\,\text{V}$ |
| Encoder | 14-bit magnetic (AS5048A / MT6701), used for commutation and for cogging phase |
| IMUs | 2 × ICM-42688-P on the camera platform, gyro/accel ODR 8 kHz |
| MCU | Cortex-M4F/M7 (single-precision FPU) |

**Loop rates and bandwidths**

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| PWM | 20 kHz, center-aligned | — |
| Current (FOC) | 20 kHz | $\omega_c = 2\pi\cdot 1500$ rad/s |
| Velocity (gyro feedback) | 4 kHz | $\omega_v = 2\pi\cdot 120$ rad/s |
| Angle (AHRS feedback) | 1 kHz | $\omega_\theta = 2\pi\cdot 25$ rad/s |
| IMU sampling / filtering | 8 kHz | — |
| AHRS update | 1–2 kHz | — |

Each loop's bandwidth is roughly 4–10× below the loop inside it. That separation lets each outer loop treat its inner loop as approximately unity gain when choosing gains.
