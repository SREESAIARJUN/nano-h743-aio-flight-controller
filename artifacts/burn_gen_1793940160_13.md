# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #9): System Architecture Package

**Scope:** 80A burst thermal and loss model, 48 kHz switching analysis, ArduPilot bidirectional DShot600 timer/DMA plan, reference netlists.

> **Engineering caveat:** The netlists below are reference-level and are not released for fabrication. All MOSFET, driver, and PCB parameters are parametric placeholders, shown as `[P]`. Before tape-out, replace them with datasheet values for the selected parts and validate with a thermal prototype using thermocouples on the FETs plus an IR camera.

## 0. Architecture Assumptions

The STM32H743 does **not** commutate the motors. The architecture is a standard AIO split:

| Domain | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (480 MHz rev V) | ArduPilot, sends bidirectional DShot600 |
| ESC ×4 | AT32F421K8U7 (120 MHz) running AM32 | 6-step/sinusoidal commutation, 48 kHz PWM, eRPM telem
