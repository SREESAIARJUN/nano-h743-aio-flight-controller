## 0. System Architecture and Baseline Assumptions

### 0.1 Architecture

The STM32H743 does not commutate motors. It runs ArduPilot and outputs bidirectional DShot600. Each motor is driven by a dedicated ESC MCU running AM32 or BLHeli_32-class firmware at a 48 kHz PWM carrier.

```
 6S LiPo ──XT60──┬── Bulk C ──┬─ Shunt ─┬─ 4× 3-phase bridges (24 FETs) ── M1..M4
                 │            │         └─ INA → H743 ADC (CURR)
                 │            └─ Vbat divider → H743 ADC (VBAT)
                 ├─ 12V/9V buck (VTX), 5V buck (FC/periph), 3V3 LDO (MCUs)
 H743 (ArduPilot) ── DShot600 bidir ×4 ──► 4× ESC MCU ──► 4× FD6288 ──► 4× bridges
```
