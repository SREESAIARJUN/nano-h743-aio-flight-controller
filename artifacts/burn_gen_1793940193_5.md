# STM32H743 AIO Flight Controller with 4-in-1 ESC: Design Package (Job #53)

## 0. Architecture Assumptions

The STM32H743 cannot run motor commutation and flight control on one die without giving up timer and DMA resources that ArduPilot needs. This design therefore uses the standard AIO partition:

| Domain | Device | Role |
|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100, 480 MHz) | ArduPilot, bidirectional DShot600 master |
| ESC MCU ×4 | AT32F421K8U7 (or STM32G071) | AM32 firmware, 48 kHz complementary PWM |
| Gate driver ×4 | FD6288Q (3-phase, bootstrap) | 6 FETs per channel |
| Power stage ×4 | 24× N-channel 40 V, 3.3×3.3 mm DFN | Half-bridges |
| Form factor | 30.5×30.5 mm board (≈30×30 mm copper), 8-layer, 2 oz on every layer | Nano class |

## 1. Conduction Loss Model

### 1.1 Current Path in 6-Step Trapezoidal Commutation with Synchronous Rectification

In each 60° sector, phase A is PWM-driven (high side ↔ low side, complementary), phase B is held low (LS on), and phase C floats.

- PWM on (duty D): current flows through HS_A → motor → LS_B. Two FETs conduct.
- PWM off (1−D): current flows through LS_A (synchronous rectification) → motor → LS_B. Two FETs conduct.

So the instantaneous resistive path always contains exactly two R_DS(on):

$$P_{cond,ch} = I^2 \cdot 2R_{DS(on)}(T_j)\,[D + (1-D)] = 2I^2 R_{DS(on)}(T_j)$$

### 1.2 Temperature-Dependent R_DS(on)

$$R_{DS(on)}(T_j) = R_{25}\left[1 + \alpha (T_j - 25)\right],\quad \alpha \approx 0.005\ \text{K}^{-1}$$

At T_j = 125 °C, R_DS(on) = 2.25 mΩ.

### 1.3 Numerical Results (80 A, hot)

$$P_{cond,ch} = 2 \times 80^2 \times 2.25\text{ m}\Omega = \mathbf{28.8\ W}$$

**PCB copper path.** Assume 0.5 mΩ total from battery pad to FET to motor pad:

$$P_{Cu} = 80^2 \times 0.5\text{ m}\Omega = \mathbf{3.2\ W}$$

### 1.4 Per-FET Averaging Over One Electrical Revolution

Each phase spends 1/3 of the cycle PWM-driven, 1/3 held low, and 1/3 floating. Averaged over a revolution:

| FET | Duty-weighted share | Avg loss (D = 0.9) |
|---|---|---|
| HS_x | (1/3)·D·I²R | 4.32 W |
| LS_x | (1/3)(1−D)·I²R + (1/3)·I²R | 5.28 W
