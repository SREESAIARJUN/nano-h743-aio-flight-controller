# STM32H743 AIO Nano FC + 4-in-1 80A ESC: Systems Architecture Package (Job #60)

## 0. Architecture Baseline and Scope

**ArduPilot does not commutate motors.** The STM32H743 runs ArduPilot as the flight controller and sends bi-directional DShot600 to four local ESC MCUs. Each ESC MCU (STM32G071 or AT32F421 running AM32, or a BLHeli_32-class target) closes the commutation loop. The only realistic "H743 4-in-1 AIO" topology is therefore:

```
 6S Vbat ──┬─ Shunt/Isense ─┬─ 4× [3-phase bridge (6 FETs) ◄─ FD6288Q-class driver ◄─ G071 ESC MCU]
           │                │                                                        ▲ BDShot600
           ├─ 12V buck (gate)                                                         │
           ├─ 5V/3V3 buck ──► STM32H743VIT6 (ArduPilot) ── TIM1 CH1..4 ───────────────┘
```

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Temperature-dependent R_DS(on)

R_DS(T_j) = R₂₅ · (1 + α)^(T_j − 25), with α ≈ 0.0047 /K

This gives a factor of about 1.6 at 125 °C, so R_DS(125 °C) = 1.92 mΩ.

### 1.2 6-step trapezoidal with synchronous rectification

During any commutation sector, current flows through two legs:

- **PWM leg:** current flows through the high-side switch for time D and through the complementary low-side switch for time (1 − D). The RMS contributions sum to I²R regardless of D.
- **Return leg:** the low-side switch is fully on, contributing I²R.

**Per motor:**

P_cond,motor = 2 · I_ph² · R_DS(T_j) = 2 · 6400 · 1.92 mΩ = **24.6 W**

**Per FET (time-averaged):** each switch position carries current for one-third of the electrical period. The worst-case FET is a low side that also acts as synchronous rectifier:

P_cond,FET ≈ (1/3) · I² · R + (1/3)(1 − D) · I² · R ≤ 2/3 · 12.3 W ≈ **8.2 W peak-average**, about 4.1 W typical

### 1.3 Parasitic copper and shunt conduction

| Element | R | Loss per motor @ 80 A |
|---|---|---|
| Phase pad + trace (2 oz, 8 L, parallel planes) | ~0.3 mΩ ×2 | 3.8 W |
| Shared bus shunt (total I_dc ≈ D·ΣI) | 0.25 mΩ | up to 1.6 W per 80 A_dc |
| Solder pads / vias | ~0.1 mΩ | 0.6 W |

The PCB copper is a first-order loss term on a nano board and must not be ignored.

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate currents (plateau-region approximation)

I_g,on = (V_drv − V_pl) / (R_pu + R_g) = (10 − 3) / (4 + 3.2) = 0.97 A

I_g,off = V_pl / (R_pd + R_g) = 3 / (2 + 3.2) = 0.58 A

### 2.2 Transition times

| | Current transition (Q_gs2 / I_g) | Voltage transition (Q_gd / I_g) | Total |
|---|---|---|---|
| Turn-on | 5.2 ns | 8.2 ns | 13.4 ns |
| Turn-off | 8.7 ns | 13.9 ns | 22.6 ns |
