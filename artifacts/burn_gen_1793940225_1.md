# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #27 specification, so this design is parameterized. Every value in §0 is a placeholder to replace with your motor, encoder and mechanical data. The equations are general. The code is self-contained C++17 with no heap use, no exceptions and float-only math, suitable for Cortex-M4F/M7/M33.

## 0. System Assumptions and Loop Rates

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7 class with FPU and center-aligned PWM |
| Motor | Gimbal BLDC, 12N14P (`p = 7` pole pairs), R ≈ 5 Ω, L ≈ 2 mH, per axis |
| Encoder | 14-bit magnetic sensor (AS5048A / MT6701) on each motor shaft |
| IMUs | 2× ICM-42688-P on the camera plate (SPI, 8 kHz ODR, FIFO or DRDY) |
| Current loop (FOC) | 20 kHz, synchronized to the PWM center |
| Velocity loop | 4 kHz (decimation 5) |
| Angle loop | 1 kHz (decimation 20) |
| IMU fusion | 8 kHz filter path, 1 kHz attitude update |

Bandwidth separation rule: each outer loop's crossover should be at most 1/5–1/10 of the inner loop's. Example targets:

- Current loop: ω_ci ≈ 2π·1500 rad/s
- Velocity loop: ω_cv ≈ 2π·150 rad/s
- Angle loop: ω_ca ≈ 2π·20 rad/s

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Electrical Angle

$$
\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi
$$

θ_off is found at alignment by injecting v_d with v_q = 0 and reading the encoder.

During the conversion delay, extrapolate the angle (latency compensation):

$$
\hat\theta_e = \theta_e + \omega_e\,T_{\text{delay}}, \qquad T_{\text{delay}} \approx 1.5\,T_{\text{PWM}}
$$

### 1.2 Clarke Transform

Amplitude-invariant form, assuming balanced currents (i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

### 1.3 Park Transform

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$

### 1.4 Plant Model and Decoupled PI Current Control

The dq-frame plant is:

$$
v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad
v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m
$$

Design the PI by pole-zero cancellation, which places the closed loop as a first-order system at ω_ci:

$$
K_p^{(i)} = L\,\omega_{ci},\qquad K_i^{(i)} = R\,\omega_{ci}
$$

The discrete control law (sample time T_s, sample index n) adds decoupling and back-EMF feedforward:

$$
\begin{aligned}
e_x[n] &= i_x^*[n] - i_x[n] \\
I_x[n] &= I_x[n-1] + K_i T_s e_x[n] + K_{aw}\big(v_x^{\text{sat}}[n-1] - v_x^{\text{uns}}[n-1]\big) \\
v_d^{\text{uns}} &= K_p e_d + I_d - \omega_e L i_q \\
v_q^{\text{uns}} &= K_p e_q + I_q + \omega_e L i_d + \omega_e \lambda_m
\end{aligned}
$$

Here K_aw is the back-calculation anti-windup gain; typically K_aw = 1/K_p normalized per step.

### 1.5 Voltage Vector Limiting

Linear SVPWM can produce a vector of magnitude up to V_bus/√3. Clamp to that circle with d-axis priority:

$$
v_d^{\text{sat}} = \text{clamp}\!\left(v_d,\ \pm V_{\max}\right),\quad
v_q^{\text{sat}} = \text{clamp}\!\left(v_q,\ \pm\sqrt{V_{\max}^2 - (v_d^{\text{sat}})^2}\right),\quad
V_{\max} = \frac{V_{bus}}{\sqrt3}
$$
