# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #38", so this design uses the stated assumptions in §0. Every parameter is a named constant you can replace with your real values. Sections 1–5 give the math, and §6 gives the C++17 implementation (embedded-safe: no heap, no exceptions, `float` only).

## 0. Assumed Platform & Rate Plan

| Item | Assumption |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701), 1 per axis |
| IMUs | 2 × ICM-42688-P on the camera plate, SPI @ 24 MHz, ODR = 8 kHz |
| Driver | 3-phase inverter, center-aligned PWM 25 kHz, inline/low-side current sense |

**Loop rates:**

| Loop | Rate | Ts | Target bandwidth |
|---|---|---|---|
| Current (d/q) | 25 kHz | 40 µs | ω_c ≈ 2π·1.5 kHz |
| IMU acquisition + filtering | 8 kHz | 125 µs | — |
| Rate (velocity) loop | 4 kHz | 250 µs | ω_v ≈ 2π·80–150 Hz |
| Attitude (angle) loop | 1 kHz | 1 ms | ω_θ ≈ 2π·10–25 Hz |

**Gimbal-specific architecture point:** the stabilization velocity loop uses the **inertial angular rate from the gyros**, projected onto each motor axis. It does not use encoder velocity. The encoder is used for commutation, cogging compensation, and the joint-angle Jacobian. Using encoder velocity would stabilize the motor relative to the frame, not the camera relative to the world.

## 1. Field-Oriented Current Loop

### 1.1 Transforms

With electrical angle θ_e = p·(θ_m − θ_offset):

**Clarke (amplitude-invariant, balanced, i_a + i_b + i_c = 0):**

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park:** v_α = v_d cos θ_e − v_q sin θ_e, and v_β = v_d sin θ_e + v_q cos θ_e.

**Angle advance for PWM delay.** The computed voltage is applied about 1.5 Ts later, so use:

$$\theta_e^{\,out} = \theta_e + 1.5\,T_s\,\omega_e$$

### 1.2 SVPWM via min/max zero-sequence injection

1. Compute the phase voltages:
   - v_a = v_α
   - v_b = −½v_α + (√3/2)v_β
   - v_c = −½v_α − (√3/2)v_β
2. Compute the zero-sequence offset:
$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big)$$
3. Compute the duty for each phase x:
$$d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

The linear range is |v_αβ| ≤ V_bus/√3, so v_dq is magnitude-limited to that value.

### 1.3 Plant and PI design (pole–zero cancellation)

**Plant.** The PMSM dq model is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

**Gains.** Use the PI controller C(s) = K_p + K_i/s with:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The PI zero (K_i/K_p = R/L) cancels the electrical pole, so the closed loop reduces to i/i* = ω_c/(s+ω_c). Keep ω_c ≤ 2π·f_pwm/15 to respect the sample/PWM delay.

**Decoupling feedforward:**

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

**Discrete PI with back-calculation anti-windup** (K_aw ≈ 1/K_p·ω_c, or simply K_i/K_p):

$$u_k = K_p e_k + I_k + u^{ff},\qquad u^{sat}_k=\text{sat}(u_k)$$

$$I_{k+1} = I_k + T_s\big[K_i e_k + K_{aw}(u^{sat}_k - u_k)\big]$$

Note: many gimbal motors are driven in **voltage mode** because high R makes current sensing marginal. In that case, set i_q* → v_q* = R·i_q* + ω_eλ_m. The code supports both via `useCurrentSensing`.

## 2. Cascaded Attitude → Rate → Torque Control

### 2.1 Mechanical model per axis

$$J\dot\omega = K_t i_q - b\omega - \tau_{cog}(\theta_m) - \tau_{dist},\qquad K_t = \tfrac32 p\lambda_m$$

### 2.2 Inertial error mapping

**Attitude error.** The camera attitude estimate is q̂ (§5) and the setpoint is q*. The error quaternion is:

$$q_e = \hat q^{-1}\otimes q^*,\qquad \text{enforce } q_{e,w}\ge 0$$

$$\boldsymbol e_\theta \approx 2\,\mathrm{vec}(q_e)\ \text{(camera frame, small angle)}$$

**Joint mapping.** The joint angles are θ_m = (θ_yaw, θ_roll, θ_pitch) for a yaw→roll→pitch chain. The camera-frame angular velocity is ω_c = A(θ_m)·θ̇_m, where the columns of A are the motor axes
