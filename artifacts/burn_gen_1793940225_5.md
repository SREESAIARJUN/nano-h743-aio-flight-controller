## 1. Timing Architecture

```
 20 kHz  ─ PWM ISR: ADC → Clarke/Park → current PI → inv-Park → SVPWM   (per motor)
  8 kHz  ─ IMU DRDY: read both ICM-42688-P → notch/LPF → dual fusion
  4 kHz  ─ Velocity loop: PI + cogging FF + accel FF  →  i_q*
  1 kHz  ─ Attitude loop: Mahony AHRS → attitude error → Jacobian⁻¹ → ω_joint*
```

Bandwidth separation is at least 5× per cascade stage:

- Current loop: ω_c ≈ 2π·2 kHz
- Velocity loop: ≈ 2π·150 Hz
- Angle loop: ≈ 2π·20 Hz

## 2. FOC Current Loop

### 2.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, with electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 2.2 Plant (PMSM in the dq frame)

$$v_d = R i_d + L\frac{di_d}{dt} - \omega_e L i_q,\qquad v_q = R i_q + L\frac{di_q}{dt} + \omega_e L i_d + \omega_e\lambda_m$$

Torque, for a surface-mount PM motor:

$$\tau = \tfrac32 p \lambda_m i_q = K_t i_q$$

### 2.3 Current PI with Decoupling and Back-EMF Feedforward

**Pole-zero cancellation tuning.** The PI zero cancels the electrical pole R/L, which gives a first-order closed loop with bandwidth ω_c:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

**Control law:**

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L i_q$$

$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Voltage limit.** Use a circular limit with q-priority:

- Clamp v_d to the available voltage.
- Then |v_q| ≤ √(V_max² − v_d²), where V_max = V_bus/√3 (the linear SVPWM limit).

**Anti-windup** uses back-calculation with gain K_aw ≈ 1/K_p (applies to every PI in this document):

$$I_{k+1} = I_k + T_s\left[K_i e_k + K_{aw}(u_{sat,k}-u_k)\right]$$

### 2.4 SVPWM (Min-Max Zero-Sequence Injection)

$$v_{a,b,c} = \text{inv-Clarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12\left(\max(v_{abc})+\min(v_{abc})\right)$$

$$d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$

This is mathematically equivalent to sector-based SVPWM and is cheaper to compute.
