# FOC Motor Control and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the original Job #6 specification, so this design uses the assumptions below. Every one is a named constant, so you can replace it with your real values.

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC, 12N14P (7 pole pairs), R = 5.6 Ω, L = 2.1 mH, K_t ≈ 0.09 N·m/A |
| Driver | 3-phase bridge, inline or low-side shunts, V_bus = 12–16 V |
| Encoder | 14-bit absolute magnetic encoder (AS5048/MA730 class) on each joint |
| IMUs | Two ICM-42688-P on the camera plate, mounted at different lever arms |
