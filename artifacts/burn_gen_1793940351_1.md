## Part 1: Mathematical Formulation

### 1.1 Field-Oriented Control (Innermost Loop, 20 kHz)

**Electrical angle** (the encoder offset θ_off is found by aligning the rotor with a d-axis voltage at startup):

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Plant** (per axis, surface-mount PMSM, L_d = L_q = L):

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m,\qquad v_d = R i_d + L\dot i_d - \omega_e L i_q$$

**Current PI by pole-zero cancellation.** Choose bandwidth ω_c, typically 2π·1.5–2 kHz, which is ≤ f_pwm/10:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c \;\;\Rightarrow\;\; \frac{i}{i^*} = \frac{\omega_c}{s+\omega_c}$$

**Decoupling and back-EMF feedforward:**

$$v_d^* = PI_d(e_d) - \omega_e L i_q,\qquad v_q^* = PI_q(e_q) + \omega_e L i_d + \omega_e \lambda_m$$

**Voltage limit.** Circular limiting inside the hexagon, with d-axis priority:

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}\cdot m_{max},\qquad m_{max}\approx 0.95$$

**Inverse Park transform**, then **SVPWM** by min-max zero-sequence injection:

$$v_x' = v_x - \tfrac12\left(\max(v_a,v_b,v_c)+\min(v_a,v_b,v_c)\right),\qquad d_x = \tfrac12 + \frac{v_x'}{V_{bus}}$$

### 1.2 Cascaded Control: Angle → Velocity → Torque/Current

For stabilization, the controlled quantity is camera attitude, measured by the IMUs. The motor encoder provides commutation, a joint-rate estimate for damping, and a fallback.

**Mechanical plant per joint:**

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta_m) - \tau_{ext}$$

#### Angle loop (outer, 1 kHz)

This is a P controller with velocity feedforward and a deadband-free shortest-path wrap:

$$e_\theta = \operatorname{wrap}_{\pi}(\theta^* - \hat\theta),\qquad \omega^* = K_{p,\theta}\,e_\theta + \dot\theta^*_{ff},\qquad |\omega^*|\le\omega_{max}$$

#### Velocity loop (middle, 4 kHz)

This is a PI controller with filtered derivative-on-measurement, back-calculation anti-windup, and inertia/friction feedforward:

$$e_\omega = \omega^* - \hat\omega_{gyro}$$

$$u_P = K_p e_\omega,\qquad I_{k} = I_{k-1} + K_i T_s e_{\omega,k} + K_{aw}T_s\,(u_{sat,k-1}-u_{k-1})$$

$$D_k = \frac{2T_f - T_s}{2T_f + T_s}D_{k-1} - \frac{2K_d}{2T_f+T_s}\left(\hat\omega_k - \hat\omega_{k-1}\right) \quad\text{(Tustin, on measurement)}$$

$$i_q^* = \operatorname{sat}\!\left(u_P + I + D + \underbrace{\tfrac{J}{K_t}\dot\omega^* + \tfrac{B}{K_t}\omega^*}_{\text{model FF}} + \underbrace{i_{cog}(\theta_m)}_{\text{anti-cogging}}\right)$$

The back-calculation gain is typically $K_{aw} = 1/T_i = K_i/K_p$.

**Velocity-loop tuning.** The current loop is treated as unity because ω_c ≫ ω_v. Using the symmetric-optimum rule:

$$K_p = \frac{J\,\omega_v}{K_t},\qquad K_i = K_p\frac{\omega_v}{4},\qquad \omega_v \approx \omega_c/8\ldots10$$

**Angle-loop tuning:**

$$K_{p,\theta} = \omega_\theta \approx \omega_v/4\ldots5$$

The resulting bandwidths are typically: current ≈ 1.5 kHz, velocity ≈ 150–200 Hz, angle ≈ 30–50 Hz.

**Rate feedback source.** Gimbal joints are not aligned with camera axes once the gimbal is tilted, so the rate must be mapped. For a yaw-roll-pitch chain (outer to inner) with joint angles (ψ_j, φ_j, θ_j), camera gyro rate ω_c is mapped to joint rates:

$$\dot{\mathbf q} = \mathbf{J}^{-1}(\mathbf q)\,\boldsymbol\omega_c,\qquad
\mathbf{J}^{-1}=\begin{bmatrix}
0 & \cos\theta_j & -\sin\theta_j\\
\cos\theta_j/\cos\phi_j\cdot(\ldots) & & \\
\end{bmatrix}$$

The precise form depends on your mechanical order. The code below implements the common yaw→roll→pitch order:

$$\dot\theta_j = \omega_y - \tan\phi_j(\ldots)$$

The full expression appears in `jointRatesFromBodyRates()`. A singularity guard is applied at |φ_j| → 90°.
