## 0. Assumptions & Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× BLDC gimbal motors, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Position sensor | 14-bit magnetic encoder per axis (e.g. AS5048A / MT6701) |
| Phase current sensing | 2 or 3 low-side shunts |
| IMUs | 2× ICM-42688-P on the camera plate, separate SPI buses, shared CLKIN |
| MCU | Cortex-M4F/M7 (e.g. STM32G4/H7) with single-precision FPU |

### Loop rates (time-scale separation ≥ 4–5× between loops)

```
 IMU ODR 8 kHz ──► anti-alias / adaptive notch / LPF ──► dual fusion ──► attitude (1 kHz)
                                                                           │
 Angle loop   1 kHz :  θ_ref ─(P + rate FF)──► ω_ref                       │
 Velocity loop 4 kHz:  ω_ref ─(PI + accel FF)─► i_q,fb  (+ i_q,cog FF) ◄───┘ gyro rate
 Current loop 20 kHz:  i_q,ref ─(PI dq + decoupling)─► SVPWM
```

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms
Electrical angle:

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$

Clarke transform (amplitude invariant, with $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a, \qquad i_\beta = \tfrac{1}{\sqrt3}\,(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

### 1.2 Plant (SPMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Electromagnetic torque:

$$\tau_e = \tfrac32\, p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.3 PI with pole-zero cancellation
With $C(s) = K_p + K_i/s$, choose:

$$K_p = L\,\omega_{cc}, \qquad K_i = R\,\omega_{cc}$$

The PI zero then cancels the electrical pole $R/L$, and the closed loop becomes $\omega_{cc}/(s + \omega_{cc})$.

Pick $\omega_{cc} \le 2\pi f_{pwm}/20$, i.e. about 2π·1 kHz at 20 kHz PWM.
