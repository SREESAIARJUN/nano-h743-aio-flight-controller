# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have the Job #15 specification, so this design states its assumptions explicitly (§0). Every gain formula is parametric, so you can substitute your actual motor and sensor values.

---

## 0. Assumptions

| Item | Assumed value | Symbol |
|---|---|---|
| MCU | STM32G474 (Cortex-M4F, 170 MHz, FPU) | — |
| Motors | Gimbal BLDC, 12N14P (GBM2804-class) | $N_s=12$, $p=7$ pole pairs |
| Phase resistance / inductance | 5.6 Ω / 1.8 mH (line-neutral) | $R_s, L_s$ |
| Flux linkage | $\lambda_m$ from back-EMF test | $K_t = \tfrac{3}{2}p\lambda_m$ |
| Bus voltage | 12 V | $V_{dc}$ |
| Encoder | MT6701 / AS5048A, 14-bit absolute, read every PWM cycle | $\theta_m$ |
| IMUs | 2 × ICM-42688-P on the camera plate, separate SPI buses, 8 kHz ODR | $r_1, r_2$ (lever arms) |
| Joint order | Yaw (outer, base) → Roll → Pitch (inner, camera) | $\psi,\phi,\theta$ |

### Loop rates

| Loop | Rate | Purpose |
|---|---|---|
| Current loop (FOC) | 20 kHz | PWM center-aligned ADC sample |
| Velocity loop | 4 kHz | Velocity PI per joint |
| IMU fusion | 8 kHz |
