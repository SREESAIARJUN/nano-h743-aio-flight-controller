# STM32H743 Nano FC + 4-in-1 ESC (Job #15): Power, Thermal, and DShot Architecture

## 0. Scope and Assumptions

**Feasibility warning.** An 80 A per-channel burst rating on a 20×20 mm ("nano") 4-in-1 ESC is beyond what the board can sustain thermally. The model below quantifies how long the burst can actually last. If "80 A" means total pack current, every number becomes comfortable. Confirm which definition applies before layout freeze.

**Architectural split:**
- **STM32H743 (FC):** runs ArduPilot and generates bidirectional DShot600.
- **ESC MCUs (×4, or one quad-capable MCU):** run AM32 or BLHeli_32 and generate the 48 kHz PWM. The H743 never touches the bridge PWM.

**Baseline parameters.** All values are illustrative. Replace them with datasheet values for your selected MOSFET.

| Symbol | Value | Note |
|---|---|---|
| V_bus | 25.2 V | 6S, full charge |
| I_ph | 80 A | burst, per motor |
| R_ds(on),25 | 1.0 mΩ | 30–40 V, 3.3×3.3 PDFN class |
| k_T | 1.5 | R_ds multiplier at T_j ≈ 125 °C |
| t_r + t_f | 20 ns | at the chosen gate-drive strength |
| t_dead | 200 ns | per edge |
| V_SD | 0.8 V | body diode forward voltage |
| Q_g | 50 nC | at 10 V V_GS |
| E_oss-equivalent C_oss | 1.5 nF | |
| R_Cu | 0.5 mΩ | per current path (traces + vias) |
| f_sw | 48 kHz | |

Topology: 6-step trapezoidal commutation with synchronous rectification. At any instant one high-side (HS) and one low-side (LS) FET carry I_ph. Each FET conducts for 120° (1/3) of the electrical cycle.

## 1. Conduction Loss Model

**Instantaneous loss per motor:**

P_cond = I² · (2·k_T·R_ds,25 + R_Cu)
= 80² · (2·1.5·1.0 m + 0.5 m) = 6400 · 3.5 mΩ = **22.4 W**
- FET share: 19.2 W
- Copper share: 3.2 W

**Per-FET time-averaged loss** (1/3 conduction duty):

P_FET,cond = I²·k_T·R_ds / 3 = 6400 · 1.5 m / 3 = **3.2 W**

**Duty independence.** With synchronous rectification, the current flows through either the HS FET (for duty D) or the complementary LS FET (for 1−D). Total conduction loss is therefore approximately independent of throttle at a given I_ph. Only its distribution between HS and LS shifts.

**Thermal runaway check.** R_ds(on) rises with temperature:

R_ds(T) ≈ R_25·(1 + α(T−25)), with α ≈ 0.005 /K

Stability requires dP/dT < 1/R_th. That gives:

I² · R_25 · α · R_th < 1, or 6400 · 1e-3 · 0.005 · R_th < 1, so **R_th < 31 K/W per FET**.

This is satisfied, so there is no runaway. The real constraint is absolute temperature.

## 2. Switching Loss Model at 48 kHz

Only the PWM-modulated leg switches. One hard-switched transition pair occurs per PWM period.

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_r+t_f)·f_sw = 0.5·25.2·80·20n·48k | 0.97 W |
| Dead-time diode | 2·V_SD·I·t_dead·f_sw = 2·0.8·80·200n·48k | 1.23 W |
| Reverse recovery | Q_rr·V·f_sw (Q_rr ≈ 40 nC) | 0.05 W |
| C_oss | ½·C_oss·V²·f_sw ×2 FETs | 0.05 W |
| Gate drive | Q_g·V_GS·f_sw ×2 FETs (dissipated in driver) | 0.05 W |
| **Total P_sw per motor** | | **≈ 2.35 W** |

Design levers:
- Cutting t_dead to 100 ns saves about 0.6 W per motor. Verify shoot-through margin with a scope.
- Dropping to 24 kHz halves P_sw but raises current ripple and acoustic noise.

**Totals:**

P_motor = 22.4 + 2.35 ≈ **24.8 W**
P_ESC,total = 4 × 24.8 ≈ **99 W** at a simultaneous 4×80 A burst (≈ 320 A, 8 kW input)

## 3. Thermal Model

### 3.1 Steady State (Shows Infeasibility)

Assume a whole-board R_th(board→air) of about 3 K/W. This is optimistic even in strong prop wash on a 20×20 board.

ΔT = 99 · 3 ≈ 300 K, so **continuous 80 A per channel is impossible**.

The sustainable continuous current for a 70 K board rise:

P_max ≈ 23 W total, giving I_cont ≈ 80·√(23/99) ≈ **38 A per channel**

This matches what real 20×20 4-in-1 boards are rated for (35–45 A).

### 3.2 Transient (Burst) Model with Lumped Capacitance

Board heat capacity, assuming 20×20 mm, 8 layers of 2 oz copper, 1.6 mm FR4:

| Element | Mass | c_p | C_th |
|---|---|---|---|
| Copper (8 × 70 µm, ~100% fill) | 2.0 g | 385 J/kg·K | 0.77 J/K |
| FR4 | 1.18 g | 1100 J/kg·K | 1.30 J/K |
| FETs, solder, caps | ~0.6 g | ~600 J/kg·K | 0.36 J/K |
| **Total** | | | **≈ 2.4 J/K** |

Board time constant: τ = R·C = 3 · 2.4 ≈ 7 s. Burst heating is therefore adiabatic for short pulses:

T_board(t) = T_0 + P·R·(1 − e^(−t/τ)) ≈ T_0 + (P/C)·t, where P/C ≈ 41 K/s

**Junction offset above the board:**
- Instantaneous per-FET conduction loss: k_T·R_ds·I² = 9.6 W
- Switching share: about 1.2 W
- Total: ≈ 10.8 W per conducting FET
- Using R_th,j-pcb ≈ 1.5 K/W (PDFN on thermal vias), the time-weighted average is about 5 W, giving ΔT_jb ≈ 8–16 K.

**Junction temperature vs. burst length** (T_0 = 40 °C):

| Burst | T_board | T_j (worst) | Verdict |
|---|---|---|---|
| 0.5 s | 61 °C | ~77 °C | OK |
| 1.0 s | 81 °C | ~97 °C | OK |
| 2.0 s | 122 °C | ~138 °C | Marginal |
| 3.0 s | 163 °C | >175 °C | **FAIL** |

**Specification recommendation:**
- Advertise **80 A for ≤1 s** per channel, all four channels simultaneously.
- Advertise **~40 A continuous**.
- Enforce limits in firmware with AM32 current limiting and the temperature cutback (thermistor near FETs, cutback at 110 °C).

Two additional constraints:
- A board pulling 320 A needs XT90-class leads and roughly 8 AWG battery wire. This is grossly out of scale for a nano frame, which reinforces the scope question in §0.
- At 8 kW input and a typical 15 mΩ 6S pack, battery sag alone is about 4.8 V.

## 4. Bidirectional DShot600 Timing and DMA Allocation (ArduPilot, H743)

### 4.1 Timing

- **Bit rate:** 600 kbit/s, so T_bit = 1.667 µs. Frame = 16 bits = 26.7 µs.
- **Pulse widths:** "1" = 75% (1.25 µs), "0" = 37.5% (0.625 µs).
- **Timer clock:** 200 MHz. ArduPilot picks prescaler/ARR so that ARR ≈ 20 ticks at 12 MHz.
- **Bidirectional mode:** the line is inverted (idle low).
  - The ESC replies about 30 µs after the frame ends.
  - The reply is 21-bit GCR at 5/4 × 600 = 750 kbit/s (1.333 µs/bit), about 28 µs long.
- **Per-cycle time:** ≈ 26.7 + 30 + 28 + guard ≈ 100 µs. This comfortably supports an 8 kHz loop. ArduPilot defaults to about 1–2 kHz output.
- **Sampling:** ArduPilot captures edges with timer input-capture DMA and decodes the eRPM telemetry.
