# STM32H743 FC + 4-in-1 ESC Nano Stack: Power-Stage and DShot Design Model

**Scope and assumptions**

**Architecture.** The STM32H743 runs ArduPilot as the flight controller. It does not commutate the motors. A conventional 4-in-1 ESC uses four dedicated ESC MCUs (e.g., AT32F421 or STM32G071 running AM32 or BLHeli_32), each with a 3-phase gate driver and 6 MOSFETs. The 48 kHz PWM model below applies to those ESC MCUs. The DShot/DMA model applies to the H743.

**Parameters.** Any parameter marked *[A]* is a representative assumption. Replace it with datasheet values for the selected MOSFET and driver before sign-off.

## 1. Conduction Loss Model

### 1.1 Current path (6-step trapezoidal, complementary PWM)

During each 60° sector, exactly two phase legs carry current:

- **PWM leg:** the high-side FET conducts for D·T_sw. The synchronous low-side FET on the same leg conducts for (1−D)·T_sw.
- **Return leg:** the low-side FET conducts continuously.

So exactly two R_ds(on) are in series at every instant, regardless of D:

$$P_{cond,ch} = I_{rms}^2 \cdot \big[ D\,R_{HS} + (1-D)\,R_{LS,sync} + R_{LS,ret} \big] = 2\,I_{rms}^2\,R_{ds(on)}(T_j)$$

### 1.2 Ripple correction

$$\Delta I = \frac{V_{bus}\,D(1-D)}{L\,f_{sw}} = \frac{25.2 \times 0.25}{30\times10^{-6}\times 48\times10^{3}} = 4.38\ \text{A}_{pp}$$

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12} = 6400 + 1.6 = 6401.6\ \text{A}^2$$

The ripple contribution is negligible (<0.03%).

### 1.3 Temperature dependence

$$R_{ds(on)}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

| T_j (°C) | R_ds(on) (mΩ) | P_cond per channel (W) | ×4 channels (W) |
|---|---|---|---|
| 25 | 1.00 | 12.8 | 51.2 |
| 100 | 1.375 | 17.6 | 70.4 |
| 125 | 1.50 | 19.2 | 76.8 |
| 150 | 1.625 | 20.8 | 83.2 |

### 1.4 Per-FET distribution (averaged over an electrical revolution)

Each FET serves 120° per electrical cycle:

- **High-side FET:** conducts D × 120° (PWM).
- **Low-side FET:** conducts 120° as return plus (1−D) × 120° as synchronous rectifier.

At D = 0.5 and T_j = 125 °C:

$$P_{HS} = \tfrac{1}{3}(0.5)(6400)(1.5\text{m}) = 1.6\ \text{W}$$

$$P_{LS} = \tfrac{1}{3}(1.5)(6400)(1.5\text{m}) = 4.8\ \text{W}$$

**Design consequence:** the low-side FETs are the thermal bottleneck. They carry 3× the high-side conduction loss at D = 0.5 and approach 6.4 W as D → 0 (low throttle at high current, e.g. braking or a stall).
