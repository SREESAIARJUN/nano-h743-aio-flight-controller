# STM32H743 + 4-in-1 ESC Nano Stack (Job #17): Loss Model, Thermal Analysis, DShot/DMA Allocation, and Netlists

## 0. Architecture Decision and Scope

Bi-directional DShot600 implies that the **STM32H743 runs ArduPilot only**. Each motor gets its own ESC MCU running AM32 or BLHeli_32, which handles 48 kHz PWM and sensorless commutation. The H743 should not also commutate 4 sensorless motors, because that conflicts with ArduPilot's scheduler. The rest of this document uses this split:

| Block | Part (reference choice) | Role |
|---|---|---|
| FC MCU | STM32H743VIT6 (LQFP100), 480 MHz | ArduPilot, DShot600 bidir master |
| ESC MCU ×4 | AT32F421K8U7 (QFN32) | AM32, 48 kHz complementary PWM |
| Gate driver ×4 | FD6288Q (3-phase, 3-ch half-bridge) | Bootstrap HS/LS drive |
| MOSFET ×24 | 40 V, 3.3×3.3 DFN, R_DS(on) 1.8 mΩ @ 25 °C, V_GS = 10 V | Power stage |
| Bus | 6S LiPo, 25.2 V max | — |

All numeric results below follow from the assumption table in §1. If you substitute a different FET, re-run the equations with its datasheet values.

## 2. Conduction Loss Model

### 2.1 Current paths in 6-step synchronous-rectified commutation

Each 60° sector has one high-side FET (PWM leg, switching) and one low-side FET (static) carrying phase current. With complementary PWM:

- During **on-time D**, current flows through HS(x) and LS(y).
- During **off-time (1−D)**, current flows through LS(x) (sync rectifier) and LS(y).

So at every instant **exactly two FETs** carry I_ph, whatever the duty cycle. This gives the key simplification:

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{DS(on)}(T_J) + I_{ph}^2 R_{Cu}$$

### 2.2 Temperature-dependent R_DS(on)

$$R_{DS(on)}(T_J) = R_{25}\left[1+\alpha_R (T_J-25)\right]$$

This is self-consistent, so iterate T_J. At T_J = 110 °C:

$$R_{DS(on)} = 1.8\,\text{mΩ}\times(1+0.0055\times85) = 2.64\ \text{mΩ}$$
