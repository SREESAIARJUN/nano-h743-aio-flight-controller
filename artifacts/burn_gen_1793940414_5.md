# STM32H743 AIO Flight Controller with 4-in-1 ESC: Architecture Package

## 0. Scope and Assumptions

I don't have the project files for Job #7, so I've made the assumptions below explicit. Every number in this package derives from them. If you substitute your actual MOSFET datasheet values, the equations still hold.

**Architecture note.** On any practical AIO design, the STM32H743 runs ArduPilot and generates the DShot. It does **not** commutate the motors. Each motor channel uses a dedicated ESC MCU running AM32 or BLHeli_32, and that MCU produces the 48 kHz PWM. Combining both roles in the H743 is not supported by ArduPilot.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Commutation topology
Six-step trapezoidal commutation with synchronous rectification (complementary PWM) works as follows within one commutation sector:
- **Leg A (PWM leg):** the high-side conducts for D·T and the low-side for (1−D)·T. One switch is always in the current path.
- **Leg B (return leg):** the low-side is held ON continuously.

So, neglecting dead time, exactly **two switches carry I_ph at all times**, independent of duty cycle.

### 1.2 Temperature-dependent R_DS(on)
$$R_{DS}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

### 1.3 Conduction loss with ripple
Phase current has a triangular ripple ΔI on top of the average. The RMS current is:
$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12}$$

The ripple amplitude is:
$$\Delta I = \frac{(V_{bus} - V_{bemf})\,D}{L_{ph}\,f_{sw}}$$

For a typical 5" motor (L_ph ≈ 15 µH, D=0.9, V_bemf ≈ 20 V), ΔI ≈ 6.5 A. The ripple term adds only 0.4% and is negligible here. It is not negligible on low-inductance motors (<5 µH).

The total conduction loss per ESC channel is:
$$\boxed{P_{cond} = 2\, I_{rms}^2\, R_{DS}(T_j)}$$

### 1.4 Electro-thermal fixed point
R_DS depends on T_j, and T_j depends on P. Substituting T_j = T_ref + P·Z_th gives:
$$P = \frac{2I^2R_{25}[1+\alpha(T_{ref}-25)]}{1 - 2I^2R_{25}\,\alpha\, Z_{th}}$$

**Thermal runaway criterion:** the solution diverges when **2I²R₂₅·α·Z_th ≥ 1**.

At 80 A: 2·6400·0.0015·0.0045 = 0.0864 W/K. Runaway therefore occurs if the effective Z_th ≥ **11.6 K/W**. A poorly heat-sunk PDFN on a nano board can reach this in steady state. This is the core reason 80 A is a *burst* rating only.

### 1.5 Numbers at 80 A

| T_j | R_DS(on) | P_cond per channel | ×4 channels |
|---|---|---|---|
| 25 °C | 1.50 mΩ | 19.2 W | 76.8 W |
| 100 °C | 2.01 mΩ | 25.7 W | 102.8 W |
| 125 °C | 2.18 mΩ | 27.9 W | 111.6 W |

Each conducting FET dissipates half of the per-channel figure, about **13–14 W** at 125 °C.

**PCB copper loss (often forgotten).** Assume the phase and bus path is ~15 mm of 4 mm-wide, 2 oz (70 µm) copper, paralleled on 3 layers:
$$R_{Cu} = \frac{\rho L}{A} = \frac{1.72\times10^{-8}\cdot 0.015}{3\cdot 4\times10^{-3}\cdot 70\times10^{-6}} \approx 0.31\ \text{m}\Omega$$

This adds ~2 W per channel at 80 A. Include it.

## 2. Switching Loss Model at 48 kHz

Only the PWM-leg high-side hard-switches. The low-side commutates into its own body diode during dead time, so it effectively turns on with zero voltage (ZVS).

### 2.1 Loss components

**(a) V–I overlap, hard-switched high-side:**
$$P_{VI} = \tfrac12 V_{bus} I_{ph}(t_r+t_f) f_{sw} = \tfrac12(25.2)(80)(40\text{ns})(48\text{kHz}) = \mathbf{1.94\ W}$$

**(b) Body diode conduction during dead time** (two dead-time intervals per period):
$$P_{dt} = V_F\, I_{ph}\, (2t_{dt})\, f_{sw} = 0.8\cdot80\cdot200\text{ns}\cdot48\text{kHz} = \mathbf{0.61\ W}$$

**(c) Reverse recovery** (the low-side diode is recovered by the high-side turn-on):
$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 30\text{nC}\cdot25.2\cdot48\text{k} = \mathbf{0.036\ W}$$

**(d) Output capacitance:**
$$P_{oss} = Q_{oss}V_{bus}f_{sw} = \mathbf{0.048\ W}$$
