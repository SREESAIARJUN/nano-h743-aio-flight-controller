# STM32H743 FC + 4-in-1 ESC (Job #37): Power-Stage Loss Model, Thermal Budget, and Bidirectional DShot600 Allocation

## 0. Scope and Assumptions

I had to make several architectural decisions and assumptions. Please validate them before anything goes to layout.

**Architectural notes:**

1. **The H743 cannot commutate the motors directly.** It runs ArduPilot and generates DShot. Each motor needs its own ESC MCU, such as an AT32F421 or STM32G071 running AM32 or BLHeli_32. A single H743 driving 24 FETs with sensorless field-oriented control is not a supported ArduPilot configuration. This model assumes four ESC MCUs.
2. **80 A burst per motor on a 20×20 mm "nano" board is not physically achievable.** The issue is copper area, FET footprint, and thermal mass, not the mathematics. The numbers below assume a **30.5×30.5 mm, 8-layer, 2 oz board** and give the burst-time limit explicitly. Section 2.6 shows the 20×20 result.
3. All component values are representative. Re-run the model with datasheet values for the parts you actually select.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, fully charged) | V_bus | 25.2 V |
| Burst phase current (per motor) | I_ph | 80 A |
| PWM frequency | f_sw | 48 kHz |

**Topology:** 6-step trapezoidal commutation with complementary (synchronous) PWM. This is the AM32/BLHeli_32 default. At any instant:
- one half-bridge leg is PWM-switching (HS/LS alternating),
- a second leg has its low-side FET held on,
- the third leg floats for back-EMF sensing.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j) = R_{ds,25}\,[1+\alpha (T_j-25)]$$

At T_j = 125 °C: R_ds = 0.80 × 1.55 = **1.24 mΩ**. Design at the hot value. Conduction loss is self-reinforcing (positive feedback), so section 2.5 includes an iteration check.

### 1.2 RMS current including PWM ripple

$$\Delta I_{pp} = \frac{V_{bus}\,D(1-D)}{L_{LL}\,f_{sw}} \;\xrightarrow{D=0.5}\; \frac{25.2 \times 0.25}{20\,\mu H \times 48\,kHz} = 6.56\ \text{A}$$

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I_{pp}^2}{12} = 6400 + 3.6 = 6403.6\ \text{A}^2$$

At 48 kHz the ripple adds only 0.06%. Lowering f_sw would raise ripple and core loss in the motor, but would not meaningfully change FET conduction loss.

### 1.3 Per-motor conduction loss

Two FETs always carry the phase current: one in the PWM leg (either HS or synchronous LS) and the static LS FET.

$$P_{cond,motor} = 2\,I_{rms}^2\,R_{ds}(T_j) = 2 \times 6403.6 \times 1.24\times10^{-3} = \mathbf{15.9\ W}$$

### 1.4 Per-FET distribution

Each FET is active for 120° electrical of every 360°. Averaged over an electrical cycle:

$$P_{cond,FET} = \frac{P_{cond,motor}}{6} \approx 2.65\ \text{W}$$

At low eRPM, a single commutation step can last longer than the FET's thermal time constant (about 1–5 ms for this package). In that case the static LS FET momentarily sees the full I²R:

$$80^2 \times 1.24\,\text{m}\Omega = 7.9\ \text{W}$$

This is the **worst-case local hotspot**, for example during a hard punch-out from a low throttle point.

## 2. Switching Loss Model at 48 kHz

Only one leg switches at a time, so switching loss is counted for one leg per motor.

### 2.1 Transition times from gate charge

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_g} = \frac{7}{5.7} = 1.23\ \text{A} \quad\Rightarrow\quad t_{on} = \frac{Q_{sw}}{I_{g,on}} = 7.3\ \text{ns}$$

$$I_{g,off} = \frac{V_{pl}}{R_g} = \frac{3}{5.7} = 0.53\ \text{A} \quad\Rightarrow\quad t_{off} = 17.1\ \text{ns}$$

Turn-off dominates. Reducing it requires a separate turn-off path: a diode in parallel with R_g, or a driver with split source/sink outputs.

### 2.2 Loss components (one switching leg)

| Mechanism | Equation | Result |
|---|---|---|
| V-I overlap | ½·V·I·(t_on + t_off)·f_sw = ½·25.2·80·24.4 ns·48 k | **1.18 W** |
| Dead-time body-diode conduction | V_f·I·2t_dt·f_sw = 0.8·80·200 ns·48 k | **0.61 W** |
| Reverse recovery | Q_rr·V·f_sw = 30 nC·25.2·48 k | 0.036 W |
| Output capacitance | ½·Q_oss·V·f_sw | 0.024 W |
| Gate drive (2 FETs) | 2·Q_g·V_drv·f_sw | 0.038 W (dissipated in driver/R_g) |
| **Total P_sw per motor** | | **≈ 1.89 W** |

**Design lever:** reducing dead time from 100 ns to 50 ns saves about 0.3 W per motor. AM32 supports this through its dead-time setting. Validate the shoot-through margin on a scope first.

### 2.3 Total burst dissipation

| | Per motor | ×4 motors |
|---|---|---|
| Conduction | 15.9 W | 63.6 W |
