# STM32H743 AIO Flight Controller + 4-in-1 ESC (Job #58): Design Package

## 0. Assumptions and Corrections

**Architecture correction.** The STM32H743 runs ArduPilot only. It does not commutate the motors. A 4-in-1 ESC needs a dedicated commutation MCU, such as an AT32F421 running AM32 or an EFM8BB21 running BLHeli_S. One MCU per motor is typical; some designs use a single MCU for all four. The H743 talks to the ESC MCUs over bidirectional DShot600. The models below follow this split.
