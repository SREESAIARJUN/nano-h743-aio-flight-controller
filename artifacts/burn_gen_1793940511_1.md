# 3-Axis Gimbal: FOC Control Loop and Dual-IMU Sensor Fusion

I don't have the Job #7 specification, so this design assumes the following. Adjust the configuration structs to match your actual hardware.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC/PMSM, e.g. GBM2804 (12N14P, 7 pole pairs) |
| Rotor sensing | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| Driver | 3-phase inverter with low-side shunts |
| MCU | Cortex-M4F/M7 (e.g. STM32G4/H7) with an FPU |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetric about the plate centroid |

**Loop rates**

| Task | Rate |
|---|---|
| Current loop (FOC) | 20 kHz |
| Velocity loop | 4 kHz |
| Attitude / angle loop | 1 kHz |
| IMU ODR | 8 kHz (on-chip AAF enabled), filtered and decimated to 1 kHz |

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}$$

**Park transform**, using electrical angle θₑ = p·(θ_m − θ_offset):

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 PMSM model in the dq frame

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$

$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$

$$\tau_e = \tfrac{3}{2} p\,\lambda_m\, i_q = K_t\, i_q$$

The torque expression holds for a surface-mount PM motor with L_d ≈ L_q = L.

### 1.3 Current PI with decoupling

**Control law:**

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L\, i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e (L\, i_d + \lambda_m)$$

**Tuning by pole-zero cancellation.** The plant is 1/(Ls + R). Choosing

$$K_p = \omega_c L,\qquad K_i = \omega_c R$$

makes the closed loop a first-order system, ω_c/(s + ω_c). Choose ω_c ≤ 2π·f_pwm/20, e.g. 2π·1 kHz at 20 kHz PWM.

**Voltage limit (circular).** With linear SVPWM:

$$\sqrt{v_d^2 + v_q^2} \le \frac{V_{bus}}{\sqrt{3}}$$

The d-axis gets priority. The q-axis is clamped to the remaining voltage:

$$|v_q| \le \sqrt{V_{max}^2 - v_d^2}$$

### 1.4 SVPWM via min/max zero-sequence injection

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2} v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2} v_\beta$$

$$v_0 = -\tfrac12\big(\max(v_{abc}) + \min(v_{abc})\big),\qquad D_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
