# 3-Axis Gimbal Control: FOC Loop, Cascaded Control, Anti-Cogging, and Dual-IMU Vibration Rejection

I don't have the original specification for "Job #3," so this design rests on the assumptions in §0. Every equation is written in terms of named parameters, so you can substitute your actual motor, encoder, and MCU values.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| Motors | 3 × gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoders | 14-bit absolute magnetic encoder (MT6701/AS5048A), one per axis |
| MCU | STM32G4/H7 class with FPU, center-aligned PWM, synchronous ADC |
| IMU A | ICM-42688-P on the **camera plate**. This is the primary attitude feedback. |
| IMU B | ICM-42688-P on the **base/handle**. This is the disturbance reference. |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

### Loop Rates

| Loop | Rate | Ts |
|---|---|---|
| Current (FOC) | 20 kHz | 50 µs |
| Velocity plus anti-cogging | 4 kHz | 250 µs (decimation 5) |
| IMU read, filters, ANC | 4 kHz | IMU ODR 8 kHz, FIFO-averaged ×2 |
| Attitude / angle loop | 1 kHz | 1 ms |

### Signal Flow per Axis

```
 attitude ref ─►[Angle P + FF]─► ω*_cam ─►[Jacobian⁻¹, base-rate FF]─► q̇*
   q̇* ─►[Velocity PI + LMS cogging FF + gravity FF]─► i_q* ─►[FOC current PI]─► SVPWM
 IMU-A ─►[AAF]─►[Biquad LPF]─►[Dynamic notch ×2]─►[NLMS ANC (ref = IMU-B)]─►[Mahony]─► attitude
 IMU-B ─►[AAF]─►[Biquad LPF]─► rotate into camera frame ─► ANC reference + base-rate FF
```

## 1. FOC Current Loop (20 kHz)

### 1.1 Transforms (amplitude-invariant)

**Clarke transform**, assuming i_a + i_b + i_c = 0:

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)
$$

**Park transform**, using electrical angle θ_e = p·(θ_m − θ_offset):

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}
$$

**Inverse Park transform:**

$$
v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e
$$

### 1.2 Plant and Decoupling

$$
v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m
$$
