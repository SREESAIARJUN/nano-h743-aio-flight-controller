# FOC Control Loop and Sensor Fusion for a 3-Axis Gimbal (Job #30)

I don't have the Job #30 specification, so this design uses the stated **assumptions**. Every parameter that depends on them is a named constant. Swap in your motor, encoder and frame data before tuning.

| Item | Assumption |
|---|---|
| Motors | 3 × BLDC gimbal motors, 12N14P (p = 7 pole pairs), e.g. GBM2804 class, R_s ≈ 5–10 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class) per axis |
| Drivers | 3-phase inverter with low-side or inline shunts, center-aligned PWM |
| MCU | Cortex-M4F/M7 with FPU (STM32G4/H7 class) |
| IMU A | ICM-42688-P on the camera plate (payload) |
| IMU B | ICM-42688-P on the base/handle, ahead of the yaw motor |
| Gimbal order | Yaw (outer) → Roll → Pitch (inner) |

**Interpretation of "dual vibration rejection":** two physical IMUs and two filter layers.
1. **Layer 1, hardware:** on-chip anti-alias filter (AAF) plus the hardware notch in each ICM-42688-P.
2. **Layer 2, software:** an adaptive tracking notch, plus a reference-based adaptive noise canceller (NLMS) that uses IMU B to subtract vibration coupled through the frame from IMU A.
