## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, FPU, CORDIC (code uses portable float math) |
| Motors | Hollow-shaft gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5.6 Ω, L ≈ 2.4 mH, Kt ≈ 0.18 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| IMUs | 2× ICM-42688-P on the camera plate, mirrored about the pitch axis, separate SPI buses, shared 32.768 kHz CLKIN |
| Supply | 12 V (3S/4S) |

The control loops run at strictly separated bandwidths:

| Loop | Rate | Target bandwidth | Trigger |
|---|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz | ADC injected-conversion ISR, center-aligned PWM |
| Velocity (rate) | 4 kHz | ~150 Hz | Every 5th current tick |
| Angle (attitude) | 1 kHz | ~35 Hz | Every 4th velocity tick |
| IMU sampling | 8 kHz ODR | Decimated to 4 kHz after filtering | Data-ready interrupts |

Rule used throughout: each outer loop is at least 4× slower than the loop inside it. This guarantees phase margin of at least 45° with the inner loop modeled as first order.

## 1. FOC Current Loop

### 1.1 Transforms

Let θ_e = p·θ_m − θ_offset be the electrical angle.

**Clarke transform** (amplitude invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** is the transpose of the matrix above.

### 1.2 PMSM Model and Torque

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q,\qquad v_q = R i_q + L_q \dot i_q + \omega_e(L_d i_d + \lambda)$$

$$\tau_e = \tfrac32 p\left[\lambda i_q + (L_d - L_q) i_d i_q\right] \;\xrightarrow{L_d = L_q}\; \tau_e = K_t\, i_q,\quad K_t = \tfrac32 p\lambda$$

### 1.3 Current PI by Pole-Zero Cancellation

With decoupling feedforward applied, each axis is the plant G(s) = 1/(Ls + R). Choose the PI as C(s) = K_p + K_i/s with:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The PI zero K_i/K_p = R/L then cancels the electrical pole. The closed loop becomes exactly ω_c/(s + ω_c).

Constraint: ω_c·T_s ≤ 0.2 to cover the 1.5-sample PWM/ADC delay. At 20 kHz this gives ω_c ≤ 4000 rad/s, so use ω_c = 2π·1000 to 2π·1500.

**Decoupling and back-EMF feedforward:**

$$v_d^* = \text{PI}_d - \omega_e L_q i_q,\qquad v_q^* = \text{PI}_q + \omega_e(L_d i_d + \lambda)$$

**Voltage limiting:** apply circular limiting with |v_dq| ≤ V_dc/√3, giving priority to v_d.

**Anti-windup by back-calculation**, with K_aw = 1/K_p:

$$x_I[k+1] = x_I[k] + T_s\left(K_i e[k] + K_{aw}\left(u_{sat} - u_{unsat}\right)\right)$$

### 1.4 SVPWM

Use the min-max zero-sequence injection, which is equivalent to 7-segment SVPWM:

$$v_{a,b,c} = \text{invClarke}(v_\alpha, v_\beta),\quad v_0 = -\tfrac12\left(\max + \min\right)$$

$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{dc}}$$
