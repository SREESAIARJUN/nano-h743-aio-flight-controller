# 3-Axis Gimbal FOC Control and Dual-IMU Sensor Fusion (Job #55)

I don't have the Job #55 specification, so this design uses the assumptions in §0. Every motor- and board-specific constant is a named parameter. Change these before hardware bring-up.

Marked **⚠ VERIFY** items include the ICM-42688-P register values and AAF table. They were written from memory of the datasheet and must be checked against the current revision before flashing.

---

## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, FPU, CORDIC optional |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–10 Ω, L ≈ 1–3 mH |
| Rotor sensor | 14-bit absolute magnetic encoder per joint (AS5048A / MT6701), SPI |
| Current sensing | 2- or 3-shunt low-side, sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, symmetric about the optical centre, separate SPI buses |
| Kinematics | Yaw (outer, z) → Roll (middle, x) → Pitch (inner, y) → camera |
