# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion Design

I don't have your Job #12 spec sheet, so the design below rests on the assumptions in Section 0. Every assumption is a parameter in the code, so you can substitute your real values.

---

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R = 5.6 Ω, L = 2.1 mH (phase), Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701 class), SPI |
| MCU | STM32G474 (170 MHz, FPU, CORDIC). Code is portable C++17 with no heap. |
| Current sense | Inline or 2-shunt low-side, sampled center-aligned |
| IMU-C | ICM-42688-P on the **camera payload**. Provides attitude feedback. |
| IMU-B | ICM-42688-P on the **gimbal base/handle**. Provides disturbance feedforward and the vibration reference. |
| Kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) →
