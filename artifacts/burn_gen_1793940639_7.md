# 3-Axis Gimbal: FOC Motor Control and Dual-IMU Sensor Fusion (Job #22)

## 0. Design Assumptions

I don't have the Job #22 spec sheet. The design below uses typical gimbal values, and every one of them is a named constant in the code, so you can change them in one place.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (Cortex-M4F with FPU, 170 MHz, HRTIM/TIM1 center-aligned PWM) |
| Motors | 3 × gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), SPI |
| IMUs | 2 × ICM-42688-P on the camera payload, SPI at 24 MHz, gyro/accel ODR 8 kHz, shared CLKIN |
| Bus voltage | 12–16.8 V (4S) |
| Platform vibration | Multirotor, motor/prop fundamentals in the 80–350 Hz band |

### Loop Rates and Bandwidths

Each loop's bandwidth is kept at least 5× below the loop inside it.

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~2 kHz (ω_c = 2π·2000) |
| Rate (gyro-inertial) | 4 kHz | ~150 Hz |
| Angle (attitude) | 1 kHz | ~25 Hz |
| IMU fusion / AHRS | 4 kHz gyro path, 1 kHz attitude update | n/a |
