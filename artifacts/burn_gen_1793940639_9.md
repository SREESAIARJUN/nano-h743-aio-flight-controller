# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the original "Job #7" specification, so the design below rests on explicit assumptions. Every assumption is a parameter in the code; change the constants if your hardware differs.

## 0. Assumptions and Architecture

| Item | Assumption |
|---|---|
| MCU | STM32G474-class (Cortex-M4F, 170 MHz, FPU, CORDIC optional) |
| Motors | 3× gimbal BLDC, e.g. 24N22P (`p = 11` pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Joint sensors | 14-bit absolute magnetic encoders (MT6701 / AS5048A) over SPI |
| IMU_A | ICM-42688-P on the **camera plate** (attitude feedback) |
| IMU_B | ICM-42688-P on the **base/handle** (disturbance feedforward and frame reference) |
| Gimbal order | Base → Yaw (q₁) → Roll (q₂) → Pitch (q₃) → Camera |
