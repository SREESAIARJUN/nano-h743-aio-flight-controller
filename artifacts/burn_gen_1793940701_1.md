# STM32H743 Flight Controller + 80 A-Burst 4-in-1 ESC: System Architecture Package (Job #45)

## 0. Architecture Clarification and Assumptions

### 0.1 Partitioning

The STM32H743 cannot directly commutate four BLDC motors in this design. It lacks enough advanced-control timers and ADC sample/hold paths for 4× sensorless 6-step control alongside ArduPilot. The standard and correct partition is:

| Board | MCU | Role |
|---|---|---|
| FC (stack top) | STM32H743VIT6 @ 400 MHz | ArduPilot, generates 4× bidirectional DShot600 |
| 4-in-1 ESC (stack bottom) | 4× STM32G071 / AT32F421 (AM32 or BLHeli_32) | Per-motor commutation at 48 kHz PWM, returns eRPM via GCR |

The math below covers both boards. If you actually intended a single-MCU H743 motor drive, say so. That is a different (and inadvisable) design.

### 0.2 Assumed Operating Point

No MOSFET was specified, so a representative 40 V, 3.3×3.3 mm PQFN class part is assumed. Substitute datasheet values and re-run the equations.

| Parameter | Symbol | Value |

### 0.3 Rating Warning

On a 20×20 mm "nano" footprint, 80 A per motor is not a continuous rating and is only marginally a burst rating. The thermal section quantifies this. Expect about 0.5–1 s of burst capability at most, unless the board is 30×30 mm or larger, or heatsunk.

## 1. Conduction Loss Model

### 1.1 Six-Step Complementary (Synchronous) PWM

In each 60° sector, one high-side FET is PWM'd at duty D, and the complementary low-side FET in the same leg synchronously rectifies during (1−D). The low-side FET of the return leg is held on. Each FET is active for 1/3 of the electrical cycle.

R_DS(on) at temperature:

$$R_{ds}(T_j) = R_{ds25}\,[1 + \alpha (T_j - 25)] \;\approx\; k_T R_{ds25} = 2.24\ \text{m}\Omega$$

Per-FET average conduction loss:

$$P_{cond,HS} = \frac{1}{3} I_{ph}^2 R_{ds}(T_j)\, D$$

$$P_{cond,LS,sync} = \frac{1}{3} I_{ph}^2 R_{ds}(T_j)\,(1-D)$$

$$P_{cond,LS,return} = \frac{1}{3} I_{ph}^2 R_{ds}(T_j)$$

Per-bridge total, independent of D, because two R_ds are always in the path:

$$P_{cond,bridge} = 2\, I_{ph}^2\, R_{ds}(T_j)$$

### 1.2 Numbers at 80 A, D ≈ 1 (Burst Implies Full Throttle)

- P_cond,bridge = 2 × 6400 × 2.24×10⁻³ = **28.7 W per motor**
- Hottest FET (HS or return LS) = 6400 × 2.24×10⁻³ / 3 = **4.78 W**

For thermal-runaway awareness, R_ds is a function of T_j. Iterate T_j until it converges. The loop gain is

$$\frac{\partial P}{\partial T_j} \cdot R_{\theta} = P\,\alpha\,R_{\theta}$$

which must stay below 1 for stability.

### 1.3 Copper and Shunt Path (Often Neglected, Significant at 80 A)

| Element | Resistance | Loss at 80 A |
|---|---|---|
| Phase copper, 2 oz, ~15 mm × 4 mm, 6-layer parallel | ≈ 0.3 mΩ | ≈ 1.9 W |
| Current shunt, 0.25 mΩ, shared bus, average current | ~ | ≈ 0.5–1.6 W board-level |

## 2. Switching Loss Model at 48 kHz

### 2.1 Gate Current and Transition Times

$$I_g \approx \frac{V_{drv} - V_{pl}}{R_{g,tot}} = \frac{12 - 3.5}{12} = 0.71\ \text{A}$$

$$t_r \approx t_f \approx \frac{Q_{sw}}{I_g} = \frac{12\ \text{nC}}{0.71\ \text{A}} \approx 17\ \text{ns}$$

### 2.2 Loss Components (Per Hard-Switched HS FET)

1. **V-I overlap:**
$$P_{sw} = \tfrac12 V_{bus} I_{ph}(t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 34\text{n} \times 48\text{k} = 1.65\ \text{W}$$
2. **Reverse recovery** (charged into the HS FET from the LS body diode):
$$P_{rr} = V_{bus} Q_{rr} f_{sw} = 25.2 \times 30\text{n} \times 48\text{k} = 0.036\ \text{W}$$
3. **Output capacitance:**
$$P_{oss} = \tfrac12 C_{oss,tr} V_{bus}^2 f_{sw} = 0.5 \times 1.5\text{n} \times 635 \times 48\text{k} = 0.023\ \text{W}$$
