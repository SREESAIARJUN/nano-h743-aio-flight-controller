# STM32H743 Nano FC + 80A-Burst 4-in-1 ESC: System Design Package (Job #3)

## 0. Scope and Assumptions

No MOSFET, driver, board stack-up, or airflow data came with this job, so I have built the model on a **reference design** with every parameter stated. If you substitute real datasheet values into the equations in Sections 2 to 4, the numbers update directly.

**Architecture.** ArduPilot runs only on the flight controller and does not execute ESC commutation firmware. The system is therefore:

- **FC:** STM32H743VIT6 running ArduPilot. It generates bidirectional DShot600 for four motors.
- **ESC:** 4 × AT32F421K8U7 (or STM32G071) running AM32. Each drives one 3-phase bridge at 48 kHz PWM.
- **Power stage:** 24 N-channel MOSFETs, 6S battery, 30.5 × 30.5 mm board.

## 1. Commutation Model (Six-Step, Complementary PWM)

In AM32 trapezoidal drive, each 60° sector has three legs in different states:

- **PWM leg:** the high-side (HS) switches at duty D, and the low-side (LS) synchronously rectifies for (1−D).
- **Return leg:** the LS is on for 100% of the sector.
- **Floating leg:** off, used for back-EMF sensing.

Each leg spends one-third of the electrical cycle in each role. The per-FET conduction duty fractions are:

$$\delta_{HS} = \frac{D}{3}, \qquad \delta_{LS} = \frac{1-D}{3} + \frac{1}{3}$$

At burst (full throttle, D ≈ 0.95): δ_HS = 0.317 and δ_LS = 0.350.

At any instant, exactly **two FETs plus their copper path** carry the full phase current.
