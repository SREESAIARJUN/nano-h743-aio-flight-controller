# STM32H743 Nano FC + 4-in-1 80A ESC (Job #20): Architecture, Loss Model, DShot DMA Plan

## 0. Scope, Assumptions and Feasibility

**Architecture boundary:** On a 4-in-1 ESC, the H743 does not drive the MOSFETs. It sends bi-directional DShot600 to four ESC MCUs, each running AM32 or BLHeli_32. Those MCUs generate the 48 kHz PWM.

**Feasibility flag:** 80A *burst* per channel on a 20×20 mm stack is marketing-grade. The math below shows it is survivable for about 1–2 s, adiabatically. Spec continuous at roughly 35–45A.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)]$$

At T_j = 125°C: R = 1.0 × 1.45 = **1.45 mΩ**

### 1.2 Commutation topology

The model assumes 6-step trapezoidal drive with synchronous (complementary) rectification.

- At any instant, one phase is PWM-switched (HS/LS complementary), one phase has its LS held on, and one phase floats.
- The motor current therefore always flows through exactly **two** conducting FET channels in series.

$$P_{cond,ch} = 2\,I^2\,R_{DS}(T_j)$$

Accounting for PWM duty D on the switched leg:

- HS conducts for D.
- LS conducts for (1−D), excluding dead time.

The series path is still 2 FETs, so the result is independent of D, to first order.

### 1.3 At 80A burst

$$P_{cond,ch} = 2(80)^2(1.45\times10^{-3}) = \mathbf{18.6\ W}$$

At a cold start (T_j = 25°C) it is 12.8 W. Section 4 solves for the coupled value.

### 1.4 PCB copper loss

- **Path:** phase pad → FET → bus, approx. 0.25 mΩ per channel.
- **Material:** 2 oz, 4 internal planes paralleled.
- **Loss:** P_Cu = 80² × 0.25 mΩ = **1.6 W/channel**

### 1.5 Per-FET time-averaged conduction

Each FET conducts 1/3 of the electrical cycle as the "fixed" device, plus its share of PWM states. The die thermal time constant (~ms) is much longer than the commutation period (~100 µs at high eRPM), so the dissipation averages:

$$\bar{P}_{cond,FET} \approx \frac{P_{cond,ch}}{6} \approx 3.1\ \text{W}$$

## 2. Switching Loss Model at 48 kHz

Only the PWM'd leg switches, i.e. 2 FETs per channel at any time.

### 2.1 Transition times from gate charge

Miller plateau V_pl ≈ 3.0 V.

**Turn-on:**
- Gate current: I_g,on = (V_drv − V_pl)/(R_g + R_src) = (10 − 3)/(2 + 1) ≈ 2.3 A
- Transition time: t_r = (Q_gs2 + Q_gd)/I_g,on = 15 nC / 2.3 A ≈ **6.5 ns**

**Turn-off:**
- Gate current: I_g,off = V_pl/(R_g + R_sink) = 3/(2 + 1) ≈ 1.0 A
- Transition time: t_f = 15 nC / 1.0 A ≈ **15 ns**
