# STM32H743 Nano FC + 80A 4-in-1 ESC: Systems Architecture Package (Job #44)

## 0. Architecture Correction

The STM32H743 does **not** commutate the motors. It runs ArduPilot and emits bidirectional DShot600. Each of the four ESC channels has its own small MCU running AM32 or BLHeli_32, for example an AT32F421 or STM32G071. That MCU generates the **48 kHz PWM**, the dead-time and the commutation.

So the design splits into:
- **FC domain:** H743 timers/DMA → DShot frame → eRPM telemetry back.
- **ESC domain:** 4 × (MCU + 3-phase gate driver + 6 MOSFETs).

All loss numbers below use **representative component parameters**. Replace them with your selected MOSFET and driver datasheet values before release.

### Design Assumptions

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, V_bus = 25.2 V (full charge, worst case for switching) |
| Burst current | 80 A battery-side per ESC channel |
| Duty at burst | D ≈ 0.95 |
| PWM | 48 kHz, synchronous rectification (complementary) |
| MOSFET (representative 40 V, 3.3×3.3 DFN) | R_DS(on),25 = 1.6 mΩ, Q_g = 40 nC, Q_gs2 = 4 nC, Q_gd = 8 nC, V_pl = 3.2 V, Q_rr = 40 nC, Q_oss = 25 nC, R_g,int = 1 Ω, V_SD = 0.8 V |
| Gate driver (FD6288-class) | V_drv = 12 V, R_src ≈ 7 Ω, R_sink ≈ 5 Ω |
| External gate resistor | R_g,ext = 2.2 Ω |
| Effective dead-time | t_dt = 300 ns (driver internal + firmware) |
| Board | 30×30 mm, 6–8 layer, 2 oz power layers |
