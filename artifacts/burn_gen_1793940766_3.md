## 0. Scope, Architecture Clarification, and Stated Assumptions

I don't have prior project files for Job #54. Everything below is derived from first principles using stated, swappable parameters. Before committing to layout, replace every value marked **[DS]** with the selected part's datasheet value.

### 0.1 Architectural correction to the brief

The STM32H743 does **not** generate the 48 kHz inverter PWM. In every production 4-in-1 / AIO design:

```
 STM32H743 (ArduPilot) ──DShot600 bidir (4 lines)──► 4× ESC MCU (AM32 / BLHeli_32)
                                                     e.g. STM32G071 / AT32F421
                                                          │ 48 kHz complementary PWM
                                                          ▼
                                                     3-phase gate driver ──► 6 MOSFETs per motor
```

- The **48 kHz switching model** belongs to the ESC MCUs. AM32 supports 24/48/96 kHz; 48 kHz is set in AM32 EEPROM.
- The **DMA/timer model** belongs to the H743.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

In any 60° commutation sector, two phases are active: one leg PWM-switching, the other leg's low side held on.

- During **D·T**: current flows through HS(leg A) and LS(leg B).
- During **(1−D)·T**: current freewheels through LS(leg A, synchronous) and LS(leg B).

Excluding dead time, **phase current always flows through exactly two channels in series, independent of duty**:

$$P_{cond,motor} = 2\, I_{pk}^2\, R_{ds}(T_j)$$

### 1.2 Temperature dependence (positive feedback)

$$R_{ds}(T_j) = R_{ds(25)}\,[1+\alpha(T_j-25)]$$

| T_j | R_ds | P_cond per motor |
|---|---|---|
| 25 °C | 1.00 mΩ | 12.8 W |
| 100 °C | 1.34 mΩ | 17.1 W |
| 125 °C | 1.45 mΩ | 18.6 W |

**Design value:** T_j = 110 °C, giving R_ds = 1.38 mΩ and **P_cond ≈ 17.7 W per motor**.

### 1.3 Per-device distribution

Each FET is in the current path for 1/3 of the electrical cycle. The split between HS and LS depends on duty (HS takes D, its paired LS takes 1−D).

Averaged over the six devices:

$$\bar P_{cond,FET} = \frac{17.7}{6} \approx 2.95\ \text{W}$$

**Worst case:** the always-on low-side channels at low duty carry up to ~4.4 W. Use this value for junction checks.

### 1.4 Thermal-runaway stability criterion

The system is stable when:

$$\frac{\partial P}{\partial T_j}\,R_{th,ja} < 1 \;\Rightarrow\; 2I^2R_{ds(25)}\alpha\cdot R_{th,ja} = 0.0576\,\text{W/K}\cdot R_{th,ja} < 1$$

This holds for R_th,ja < 17 K/W per motor-group, so the design is stable. Runaway is not the limit; **board heat capacity is** (Section 3).

## 2. Switching Loss Model at 48 kHz

Only the PWM leg switches. That gives two hard transitions per period per motor: HS turn-on and HS turn-off. The synchronous LS commutates softly via its body diode.

### 2.1 V–I overlap loss

$$P_{VI} = \tfrac12 V_{bus} I_{pk}(t_r+t_f) f_{sw} = 0.5(25.2)(80)(35\,\text{ns})(48\,\text{kHz}) = 1.69\ \text{W}$$

### 2.2 Reverse recovery (LS body diode, dissipated mostly in the HS)

$$P_{rr} = Q_{rr}V_{bus}f_{sw} = 40\text{n}\cdot25.2\cdot48\text{k} = 0.048\ \text{W}$$

### 2.3 Output-capacitance loss

$$P_{oss} \approx \tfrac12 Q_{oss}V_{bus}f_{sw} = 0.030\ \text{W}$$

### 2.4 Dead-time body-diode conduction

$$P_{dt} = V_f I_{pk}\,(2t_{dead})\,f_{sw} = 0.8\cdot80\cdot200\text{n}\cdot48\text{k} = 0.61\ \text{W}$$

This term scales with f_sw. **Trim dead time to the minimum safe value.** On FD6288-class drivers the dead time is fixed internally (~100–200 ns), so you can only control it on drivers with programmable DT.
