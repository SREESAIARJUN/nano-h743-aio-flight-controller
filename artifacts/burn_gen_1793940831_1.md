**Bandwidth separation rule:** each inner loop should be 5–10× faster than the loop around it:

$$\omega_c \ge 5\,\omega_v,\qquad \omega_v \ge 5\,\omega_\theta,\qquad \omega_c \le \frac{2\pi f_{PWM}}{15}$$

## 1. FOC Current Loop

### 1.1 Transforms

**Clarke transform** (amplitude-invariant, using $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, with electrical angle $\theta_e = p\,(\theta_m - \theta_{off})$:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix.

### 1.2 Machine Model and Decoupled PI

The machine equations in the rotating frame are:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

The control law uses a PI controller on each axis plus cross-coupling and back-EMF feedforward:

$$v_d^* = \mathrm{PI}_d(i_d^*-i_d) - \omega_e L\, i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^*-i_q) + \omega_e L\, i_d + \omega_e\lambda_m$$

**Pole-zero cancellation tuning.** The plant is $1/(Ls+R)$. Choosing the gains below cancels the plant pole, so the closed loop becomes a first-order system $\omega_c/(s+\omega_c)$:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The torque command uses $i_d^* = 0$ (surface PMSM), with torque $\tau = K_t\, i_q$ and $K_t = \tfrac32 p \lambda_m$.

### 1.3 Voltage Limiting and SVPWM

Limit the voltage vector to a circle of radius $V_{max} = V_{bus}/\sqrt3$. Prioritize $v_d$, then give $v_q$ the remaining magnitude $\sqrt{V_{max}^2 - v_d^2}$.

The SVPWM duties use min/max zero-sequence injection:

$$v_{a,b,c} = \text{inv. Clarke}(v_\alpha, v_\beta)$$
$$v_0 = -\tfrac12\left(\max(v_{abc}) + \min(v_{abc})\right)$$
$$d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

**Anti-windup.** Use back-calculation with $K_{aw} \approx K_i/K_p$:

$$\dot x_I = K_i e + K_{aw}(u_{sat} - u)$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Velocity Plant

Mechanically, the axis obeys:

$$J\dot\omega = K_t i_q - b\,\omega - \tau_{cog}(\theta) - \tau_{fric} - \tau_{dist}$$

Because the current loop is about 10× faster, treat it as unity gain. The velocity plant is then:

$$G_v(s) = \frac{K_t}{Js + b}$$
