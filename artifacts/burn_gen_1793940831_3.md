## 1. FOC Inner Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is found at commissioning by applying v_d with θ_e = 0 and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Plant model (surface PMSM, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$
$$\tau = \tfrac32 p\lambda_m i_q \equiv K_t\, i_q$$

### 1.5 PI with decoupling and pole-zero cancellation

Choose a target closed-loop bandwidth ω_c, for example 2π·1.5 kHz, roughly f_PWM/13:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

The PI zero cancels the electrical pole R/L, which makes the closed loop first order with pole ω_c.

Control law:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \hat\omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \hat\omega_e (L i_d + \lambda_m)$$

Voltage limit: apply a circular limit $\sqrt{v_d^2+v_q^2}\le V_{bus}/\sqrt3$, with d-axis priority.

### 1.6 Inverse Park and SVPWM

Inverse Park, then inverse Clarke:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Min-max zero-sequence injection (equivalent to SVPWM):

$$v_0 = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big),\qquad d_x = \tfrac12 + \frac{v_x+v_0}{V_{bus}}$$
