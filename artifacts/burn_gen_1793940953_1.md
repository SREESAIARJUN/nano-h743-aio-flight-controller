# STM32H743 FC + 4-in-1 ESC (Job #41): Thermal, Switching, and Bi-Directional DShot600 Design Package

## 0. Architecture Correction and Assumptions

The STM32H743 should not drive the MOSFET bridges directly. ArduPilot has no BLDC commutation firmware, and bi-directional DShot is a link between a flight controller and separate ESC MCUs. The correct architecture is:

```
STM32H743 (ArduPilot) ──4× bidir DShot600──► 4× ESC MCU (AT32F421 / AM32)
                                                └─► 3-phase gate driver ─► 6× N-FET ─► motor
```

## 1. Conduction-Loss Model

The ESC uses six-step commutation with complementary (synchronous) PWM. At any instant, current flows through exactly two conducting devices in series:

- In the PWM leg, the high-side FET conducts for D and the low-side FET for (1 − D).
- The return leg's low-side FET conducts continuously during the 60° sector.

The series path therefore always contains two R_DS(on) values, independent of duty cycle:

$$P_{cond,ch} = 2\,I^2 R_{DS(on)}(T_j), \qquad R_{DS(on)}(T_j)=R_{25}\left[1+\alpha(T_j-25)\right]$$

At burst conditions:

$$P_{cond}=2(80)^2(1.5\times10^{-3}) = \mathbf{19.2\ W\ per\ ESC}$$

Each FET is active for 1/3 of the electrical cycle. Averaged across the 6 devices, that is about **3.2 W per FET**. The PWM-leg high-side FET runs hottest at high duty.

Add the copper and shunt losses:

- Trace and plane: R_cu ≈ 0.3 mΩ, giving 1.9 W.
- Shunt (if fitted, 0.25 mΩ): 1.6 W.

**Thermal-runaway check:** R_DS(on) rises with temperature, so the solution must be iterated. If T_j exceeds about 140 °C, R_hot reaches roughly 1.65 mΩ and P_cond rises to about 21 W. The loop gain is positive, so you need dT/dP · dP/dT < 1. Section 3 shows this is satisfied only for short bursts.

## 2. Switching-Loss Model at 48 kHz

Switching losses occur only in the PWM leg: one hard-switched FET and one synchronous FET.

**1. V–I overlap:**
$$P_{VI}=\tfrac12 V_{bus} I (t_r+t_f) f_{sw} = \tfrac12(25.2)(80)(40\text{ ns})(48\text{ k}) = \mathbf{1.94\ W}$$

**2. Reverse recovery:**
$$P_{rr}=Q_{rr}V_{bus}f_{sw} = 60\text{n}\cdot25.2\cdot48\text{k} = 0.073\ W$$

**3. Output capacitance:**
$$P_{oss}\approx \tfrac12 Q_{oss}V_{bus}f_{sw}=0.030\ W$$

**4. Body-diode conduction during dead time** (2 edges per cycle):
$$P_{dt}=V_f\,I\,(2t_{dt})f_{sw}=0.8\cdot80\cdot400\text{n}\cdot48\text{k}=\mathbf{1.23\ W}$$

**5. Gate drive** (2 FETs, dissipated in the driver and gate resistors):
$$P_g=2\,Q_gV_{GS}f_{sw}=2\cdot60\text{n}\cdot10\cdot48\text{k}=0.058\ W$$

**Switching subtotal: about 3.4 W per ESC.**

Design levers:
- Cutting dead time to 100 ns saves about 0.6 W.
- Dropping to 24 kHz halves the switching loss, at the cost of more motor current ripple.

### 2.1 Loss Budget at 80 A Burst

| Loss term | Per ESC (W) | 4-in-1 total (W) |
|---|---|---|
| FET conduction | 19.2 | 76.8 |
| Copper and shunt | 3.5 | 14.0 |
| Switching (V–I) | 1.94 | 7.8 |
| Dead time | 1.23 | 4.9 |
| Q_rr, C_oss, gate | 0.16 | 0.6 |
| **Total** | **≈26.0** | **≈104** |

At 80 A per ESC, the bus draws about 320 A from the pack (at D ≈ 1). The ESC efficiency is about 1 − 104 / (25.2 · 320) ≈ **98.7 %**.

## 3. Thermal Model

### 3.1 Lumped Thermal Network

```
P_FET ─► Zθ_jc (0.8 K/W) ─► Rθ_c-pcb (1.5 K/W, via array) ─► C_board ─► Rθ_conv ─► T_amb
```

### 3.2 Board Thermal Capacitance

| Element | Mass | c_p | C (J/K) |
|---|---|---|---|
| Copper (4 × 70 µm × 9.3 cm²) | 2.3 g | 385 | 0.89 |
| FR4 (1.6 mm) | 2.7 g | 1100 | 2.97 |
| 24 FETs, caps, solder | ~2.5 g | ~500 | 1.25 |
| **Total C_board** | | | **≈5.1 J/K** |

### 3.3 Adiabatic Burst Heating

With no convection:

$$\frac{dT}{dt}=\frac{P}{C}=\frac{104}{5.1}\approx \mathbf{20\ K/s}$$

Junction rise above the board for each FET at about 4.3 W:

$$\Delta T_{j\text{-}b}=4.3(0.8+1.5)\approx 10\ K$$

Burst-duration limit, starting from T_board = 45 °C with T_j,max = 125 °C:

$$t_{burst}=\frac{125-10-45}{20}\approx \mathbf{3.5\ s}$$

**Result: an 80 A burst is rated for 2 s maximum** at all four channels simultaneously, leaving about 40 % thermal margin
