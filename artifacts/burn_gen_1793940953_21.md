### 0.1 Architecture

The STM32H743 does **not** drive the bridges directly. It runs ArduPilot and talks to four ESC MCUs over bidirectional DShot600. This is the standard and only sane topology:

```
STM32H743 (ArduPilot) ──DShot600 bidir──► 4× ESC MCU (AT32F421 / AM32) ──► 4× FD6288Q ──► 4× 3-phase bridge (24 FETs)
```

## 1. Conduction Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{ds}(T_j)=R_{ds,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R_ds = 1.0 × (1 + 0.005 × 100) = **1.5 mΩ**.

### 1.2 Six-step current path

In each 60° commutation sector, exactly two legs are active:

- The PWM leg has either its high-side FET (on-time) or its synchronous low-side FET (off-time) conducting.
- The return leg has its low-side FET held on.

Because of synchronous rectification, the series path always contains **two** R_ds(on) for the whole period, independent of duty cycle D:

$$P_{cond,ch}=I_{ph}^2\cdot 2R_{ds}(T_j)$$

### 1.3 Per-FET average loss

Each FET carries current for 120° of the electrical cycle (1/3). The electrical period is much shorter than the die thermal time constant (≈ ms), so averaging is valid:

$$P_{cond,FET}=\tfrac{1}{3}I_{ph}^2R_{ds}(T_j)$$
