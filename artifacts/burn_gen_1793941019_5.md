## 0. Scope, Assumptions and an Architecture Correction

### 0.1 Architecture

An STM32H743 should not commutate the motors directly. Running four bridges at 48 kHz with BEMF/zero-cross sensing, while also running ArduPilot's EKF3 and the fast loop, is not supported by ArduPilot's motor-output architecture. The practical stack is:

```
┌──────────────────── FC board (20×20, M3) ─────────────────────┐
│ STM32H743VIT6 @ 480 MHz — ArduPilot (ChibiOS)                 │
│ 4× bidirectional DShot600 on TIM3/TIM5 ──► 8-pin JST-SH        │
└───────────────────────────────────────────────────────────────┘
                           │  M1..M4, CURR, VBAT, GND, (TLM)
┌──────────────────── ESC board (20×20 or 25.5×25.5) ───────────┐
│ 4× AT32F421 / STM32G071 running AM32 (or BLHeli_32)           │
│ 4× 3-phase gate driver, 24× 40 V N-MOSFET, 48 kHz PWM          │
└───────────────────────────────────────────────────────────────┘
```

The H743 owns the DShot600 protocol, eRPM telemetry and the notch filters. The per-channel ESC MCUs own the 48 kHz switching.

## 1. Conduction Loss Model

### 1.1 Six-Step Synchronous Commutation

Within any 60° sector, current I flows high-side (phase A) → winding → low-side (phase B). The PWM pair on the active phase alternates the current between Q_H (duty D) and the synchronous Q_L (duty 1−D). The return-path low-side conducts continuously.

At every instant exactly **two** MOSFET channels carry I. Ignoring ripple:

$$P_{cond,bridge} = 2\,I^2\,R_{ds}(T_j)$$

Averaged over an electrical cycle, the six switches share this equally:

$$P_{cond,FET} = \frac{I^2 R_{ds}(T_j)}{3}$$

With current ripple ΔI_pp, replace I² by:

$$I_{rms}^2 = I^2 + \frac{\Delta I^2}{12}$$

### 1.2 Temperature Dependence and Thermal Runaway Condition

$$R_{ds}(T_j) = R_{25}\,[1 + \alpha (T_j - 25)]$$

This couples back through the thermal resistance:

$$T_j = T_{ref} + R_\theta\,P(T_j)$$

Solving gives:

$$T_j = \frac{T_{ref} + R_\theta\,k\,R_{25}(1 - 25\alpha)}{1 - R_\theta\,k\,R_{25}\,\alpha}, \qquad k = \frac{I^2}{3}$$

**Stability criterion:** R_θ · k · R₂₅ · α < 1. If this is violated, there is no steady-state solution and the device runs away thermally.

### 1.3 Numbers at 80 A

- k = 6400 / 3 = 2133 A²
- At 25 °C: P_cond,FET = 2.13 W
- At T_j = 125 °C: R_ds = 1.6 mΩ, so **P_cond,FET = 3.41 W** and **P_cond,channel = 20.5 W**

### 1.4 Copper and Shunt Loss

Assume roughly 0.25 mΩ per channel of phase-pad, bus and via resistance on 2 oz outer and 2 oz inner layers:

$$P_{Cu} = I^2 R_{Cu} \approx 1.6\text{ W per channel}$$

The shared current-sense shunt (0.25 mΩ) carries the summed bus current. That can reach 160–250 A in a 4-motor burst, giving 6–15 W. In practice, use a Hall sensor or a 0.
