# FOC, Cascaded Control, Anti-Cogging and Dual-IMU Fusion for a 3-Axis Gimbal

I don't have the original specification for Job #26, so this design rests on the assumptions in Section 0. Every hardware-dependent constant is a named parameter, so you can substitute your real values.

## 0. Assumptions and Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, about 170 MHz |
| Motors | Gimbal BLDC (GM4108-class), 12N14P → pole pairs p = 7, R ≈ 10 Ω, L ≈ 4 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| Current sensing | 2-phase low-side shunts, sampled at the PWM center |
| IMUs | 2 × ICM-42688-P on the payload (camera) plate, SPI at 24 MHz, gyro/accel ODR 8 kHz |
| Kinematic order | Base → Yaw (z) → Roll (x) → Pitch (y) → Payload |

**Loop rates (all phase-locked to the PWM timer):**

```
PWM 20 kHz ──► Current loop (FOC) ............ 20 kHz  (ISR, ADC-triggered)
             ├► Encoder PLL + anti-cogging .... 20 kHz
IMU DRDY 8 kHz► Dual-IMU fusion + notch ....... 8 kHz → decimate to 4 kHz
             ├► Velocity loop (inertial rate) .. 4 kHz
             └► Attitude AHRS + angle loop ..... 1 kHz
```

Control structure, per axis:

```
 θ_ref ─►[Angle P + ω_ff]─► ω_ref ─►[Vel PI + LPF + notch]─► i_q,ref ─(+)─►[FOC dq-PI]─► SVPWM ─► Motor
                ▲                          ▲                             ▲
       AHRS attitude (1 kHz)     fused gyro, J⁻¹-projected      i_cog(θ_m) anti-cogging FF
```
