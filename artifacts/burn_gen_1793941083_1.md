# Job #53 — 3-Axis Gimbal: FOC Control Loop & Dual-IMU Sensor Fusion

This is a complete design and reference implementation for the motor control and sensor fusion stack. It assumes:

- **Motors:** BLDC gimbal motors, e.g. 12N14P (12 slots, 14 poles, 7 pole pairs).
- **Encoders:** a 14-bit magnetic encoder per axis.
- **MCU:** an STM32G4/H7-class controller with an FPU.
- **IMUs:** two ICM-42688-P sensors on the camera payload, read over SPI.

All equations are given in discrete time at their target rates. The C++ (C++17, header-only, allocation-free, ISR-safe) is at the end.

---

## 1. Timing Architecture

| Layer | Rate | Period | Source / Trigger |
|---|---|---|---|
| PWM / current (FOC) loop | 20 kHz | 50 µs | ADC injected end-of-conversion, center-aligned PWM |
| Encoder PLL + cogging feedforward | 20 kHz | 50 µs | Inside the FOC ISR |
| Velocity loop | 4 kHz | 250 µs | Every 5th FOC tick |
| IMU sampling (×2) | 8 kHz ODR | 125 µs | INT1 data-ready, SPI DMA |
| Vibration filters | 8 kHz | 125 µs | IMU DMA completion |
| Attitude fusion + angle loop | 1 kHz | 1 ms | Decimated from 8 kHz |

**Bandwidth-separation rule:** each loop should be at least 5–10× slower than the loop inside it.

$$\omega_{c,i} \approx 2\pi\cdot 1.5\text{ kHz},\quad \omega_{c,v}\approx 2\pi\cdot 150\text{ Hz},\quad \omega_{c,\theta}\approx 2\pi\cdot 20\text{ Hz}$$
