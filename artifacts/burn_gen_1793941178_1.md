## 1. FOC Inner Current Loop

### 1.1 Transforms

The electrical angle comes from the mechanical angle, pole-pair count, and an alignment offset:

$$\theta_e = p\,\theta_m - \theta_{\text{off}}$$

**Clarke transform** (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2i_b}{\sqrt3}$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant model in the dq frame

$$v_d = R\,i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R\,i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$
$$\tau_e = \tfrac32 p\left[\lambda_m i_q + (L_d-L_q)i_d i_q\right] \approx K_t\, i_q$$

### 1.3 Decoupled PI with pole-zero cancellation

After decoupling, each axis reduces to the first-order plant $G(s) = 1/(Ls + R)$.

Choosing the PI zero to cancel the plant pole gives a closed loop of $\omega_c/(s+\omega_c)$:

$$K_{p,i} = L\,\omega_c,\qquad K_{i,i} = R\,\omega_c$$

Bandwidth selection: $\omega_c \le 2\pi f_{pwm}/20$ accounts for the 1.5-sample delay. This gives $\omega_c = 2\pi\cdot 1000$ rad/s.

With the assumed motor values:
- $K_p = 13.2$ V/A
- $K_i = 35\,186$ V/(A·s)

Decoupling feedforward terms:

$$v_d^{ff} = -\omega_e L_q i_q,\qquad v_q^{ff} = \omega_e(L_d i_d + \lambda_m)$$

### 1.4 Discrete PI with back-calculation anti-windup

$$u_k = K_p e_k + I_k + u^{ff}_k,\qquad \bar u_k = \text{sat}(u_k)$$
$$I_{k+1} = I_k + K_i T e_k + K_{aw} T(\bar u_k - u_k),\qquad K_{aw} = K_i/K_p$$

### 1.5 Voltage limiting and SVPWM

The voltage vector is limited to the linear SVPWM region, with $v_d$ given priority:

$$|v_{dq}| \le V_{dc}/\sqrt3$$

Inverse Park produces $v_\alpha, v_\beta$. Min-max zero-sequence injection (equivalent to SVPWM) then gives the duty cycles:

$$v_x' = v_x - \tfrac12(\max v + \min v),\qquad d_x = \tfrac12 + v_x'/V_{dc}$$

## 2. Cascaded Angle → Velocity → Current Control

### 2.1 Feedback signals

In a gimbal, the stabilization error is inertial. Each loop therefore uses a different feedback source:

- **Velocity loop:** the fused gyro rate projected on the motor axis, $\omega_j = \hat a_j^\top \omega_{cam}$. The encoder rate is used only as a fallback and for the cogging compensation.
- **Angle loop:** the attitude error from the quaternion estimator, mapped into joint space.

### 2.2 Joint-space mapping

For a yaw–roll–pitch kinematic chain, the camera angular velocity is related to the joint rates by

$$\omega_{cam} = J(q)\,\dot q,\qquad J(q) = [\hat z_{yaw}\;\; R_y \hat x_{roll}\;\; R_yR_r \hat y_{pitch}]$$

The commanded joint rates are

$$\dot q_{cmd} = J(q)^{-1}\omega_{cmd}$$

For singularity robustness, use the damped inverse:

$$J^\dagger = J^\top(JJ^\top + \lambda^2 I)^{-1}$$

### 2.3 Angle loop (P plus rate feedforward)

The attitude error is computed from quaternions, $q_{err} = q_{ref}^{*}\otimes \hat q$. The commanded rate is

$$\omega_{cmd} = -K_\theta\, \text{sgn}(q_{err,w})\,2\,\vec q_{err} + \omega_{ref}$$

The gain is set at a quarter of the velocity bandwidth: $K_\theta = \omega_p = \omega_v/4$.
