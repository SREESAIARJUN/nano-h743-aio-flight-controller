# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Vibration Rejection

## 0. Assumptions

I don't have the Job #57 spec sheet. The design below is fully parameterized, so substitute your actual values. Replace every value marked **[CFG]**.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 (170 MHz, FPU, CORDIC), 3× motor timers |
| Motors | Gimbal BLDC (e.g. GBM2804H-100T): 12N14P, p = 7 pole pairs, R ≈ 10 Ω, L ≈ 2.5 mH **[CFG]** |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) per axis |
| Current sensing | 2-shunt low-side, 12-bit ADC, synchronized to PWM centre |
| IMUs | 2× ICM-42688-P on camera plate, SPI @ 24 MHz, common CLKIN |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, carries camera) |

**Loop-rate hierarchy.** Each outer loop has 4–10× lower bandwidth than the loop inside it.

| Loop | Rate | Closed-loop bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity + anti-cogging | 4 kHz | ~150–250 Hz |
| Angle / stabilization | 1 kHz (IMU-driven at 8 kHz decimated) | ~20–40 Hz |
| IMU sampling | 8 kHz ODR | — |
| Attitude (Mahony) | 1 kHz | ~0.1–1 Hz accel correction |
