## 1. FOC Current Loop

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

θ_off is the encoder-to-rotor offset, found by aligning to V_d at θ_e = 0.

### 1.2 Clarke transform (amplitude-invariant, assuming i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt3}$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM model in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e (L i_d + \psi_m)$$
$$\tau = \tfrac32 p\,\psi_m\, i_q = K_t\, i_q$$

### 1.5 Current PI with decoupling and pole-zero cancellation

The plant per axis is G(s) = 1/(Ls + R). Pick the PI zero to cancel the electrical pole (K_i/K_p = R/L). The closed loop then becomes first order with bandwidth ω_ci:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

Control law, with cross-coupling and back-EMF feedforward added:

$$v_d^* = \mathrm{PI}_d(i_d^* - i_d) - \omega_e L\, i_q$$
$$v_q^* = \mathrm{PI}_q(i_q^* - i_q) + \omega_e (L i_d + \psi_m)$$

Use i_d* = 0, since there is no field weakening in a gimbal.

**Discrete PI (backward Euler) with back-calculation anti-windup:**

$$u_k = K_p e_k + I_k,\qquad \bar u_k = \mathrm{sat}(u_k)$$
$$I_{k+1} = I_k + K_i T_s e_k + K_{aw} T_s(\bar u_k - u_k),\qquad K_{aw} \approx \frac{K_i}{K_p}$$

**Voltage vector limit** (linear SVPWM region):

$$|v_{dq}| \le \frac{V_{bus}}{\sqrt3}$$

Saturate with d-axis priority: clamp v_d first, then give v_q the remaining magnitude, $v_q \le \sqrt{V_{max}^2 - v_d^2}$.
