# 3-Axis Gimbal: FOC Control, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

I don't have the Job #24 specification, so this design states its assumptions explicitly. Every parameter is a `constexpr` or config field. Swap in your motor, encoder and MCU values and the equations still hold.

## 0. Assumed Hardware and Loop Rates

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 1.5 mH, Kt ≈ 0.06 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701) per joint, SPI |
| MCU | STM32G4 / H7 class with FPU, center-aligned PWM, synchronous ADC |
| IMUs | 2× ICM-42688-P on the payload, SPI + DMA, ODR 8 kHz, ±2000 dps, ±16 g |
| Gimbal order | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |

| Loop | Rate | Ts |
|---|---|---|
| Current (FOC) | 20 kHz | 50 µs |
| Velocity (inertial rate) + cogging FF | 4 kHz | 250 µs |
| IMU filtering and fusion | 8 kHz | 125 µs |
| Attitude (angle) | 1 kHz | 1 ms |

Bandwidth separation is about 5–10× per cascade level:

- Current loop: ω_c ≈ 2π·1.5 kHz
- Velocity loop: ω_v ≈ 2π·150 Hz
- Angle loop: ω_θ ≈ 2π·20 Hz

## 1. FOC Current Loop

### 1.1 Transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform (θ_e = p·θ_m − θ_offset):

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this matrix. The inverse Clarke transform is:

$$v_a=v_\alpha,\quad v_b=-\tfrac12 v_\alpha+\tfrac{\sqrt3}{2}v_\beta,\quad v_c=-\tfrac12 v_\alpha-\tfrac{\sqrt3}{2}v_\beta$$
