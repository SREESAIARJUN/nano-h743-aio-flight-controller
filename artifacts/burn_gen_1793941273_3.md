# STM32H743 AIO Flight Controller + 4-in-1 ESC: Power-Stage Model, DShot Timing, and Reference Netlist

**Document:** ARCH-0001 Rev A (Job #0)
**Scope:** 4-in-1 ESC power stage (80 A burst per channel, 48 kHz PWM), electrothermal model, ArduPilot bidirectional DShot600 timer and DMA allocation, reference netlists.

---

## 0. Architectural Findings

These findings shape the rest of the document.

| # | Finding | Consequence |
|---|---|---|
| F1 | **The H743 cannot run the motors itself.** It needs FOC/6-step commutation for 4 motors at 48 kHz, plus BEMF zero-cross sensing, while also running EKF3. ArduPilot does not commutate motors. | Each channel gets its own ESC MCU running AM32 or BLHeli_32, e.g. an STM32G071 or AT32F421. The H743 only sends DShot. This is the standard topology and the one modeled here. |
| F2 | **80 A per channel on a "nano" (20×20 mm) board is not thermally achievable**, even as a burst on all 4 channels at once (see §3). | The 80 A rating must be defined as **single-channel, ≤ 1 s, at a stated starting temperature**. Continuous rating is about **18–22 A per channel** on 20×20, or about 40 A on 30.5×30.5. |
| F3 | **Battery current at a 4×80 A burst is about 320 A.** | XT60 connectors, 12 AWG leads, and the board's input copper are out of spec. Cap the burst figure at the system level (ArduPilot `MOT_BAT_CURR_MAX`, battery failsafe). |
| F4 | **Input capacitor ripple of about 40 A RMS per channel** is unmanageable with nano-size caps. | An external low-ESR bulk electrolytic is mandatory. Onboard ceramics only handle the high-frequency loop. |

## 1. Conduction Loss Model

### 1.1 Parameters

Values are symbolic, with baseline numbers for a 40 V, 3.3×3.3 mm DFN MOSFET class typical of nano ESCs.

| Symbol | Meaning | Baseline |
|---|---|---|
| R_ds25 | R_DS(on) at 25 °C, V_GS = 10 V | 1.5 mΩ |
| α | R_DS(on) temperature coefficient | 0.0045 /K |
| V_bus | 6S, full charge | 25.2 V |
| I_ph | Phase current (burst) | 80 A |
| R_cu | PCB copper + solder per conduction path | 0.3 mΩ |
| D | PWM duty | 0…1 |

### 1.2 Temperature-dependent resistance

$$R_{ds}(T_j) = R_{ds25}\,[1 + \alpha (T_j - 25)]$$

At T_j = 125 °C: R_ds = 1.5 × 1.45 = **2.18 mΩ**.

### 1.3 Six-step drive with synchronous rectification

At any instant, two phases carry the current: one high-side (HS) and one low-side (LS) path. With complementary PWM (AM32 default):

- The active-leg HS conducts for D·T.
- Its complementary LS conducts for (1−D)·T.
- The opposite leg's LS is on for the whole commutation sector.

So the current always flows through exactly two MOSFET channels. Excluding dead time:

$$P_{cond,ch} = I_{ph}^2\,[\,2R_{ds}(T_j) + R_{cu}\,]$$

**Worst case (80 A, T_j = 125 °C):**

$$P_{cond,ch} = 6400 \times (4.36 + 0.3)\times10^{-3} = \mathbf{29.8\ W\ per\ channel}$$

### 1.4 Distribution across the six FETs

Over one electrical revolution, each FET conducts 1/3 of the time. Within that time, it carries the PWM-weighted share. The average per FET is:

$$P_{FET,avg} = \tfrac{1}{3}\,I^2 R_{ds} \;\;(\text{non-PWM role}) \;\;\text{or}\;\; \tfrac{1}{6}I^2R_{ds}[D + (1{-}D)]$$

This works out to about I²R_ds / 3 ≈ **4.65 W per FET**.

The peak instantaneous FET dissipation is the full I²R_ds = **13.9 W**. This peak sets the junction ripple at low electrical frequency (startup or stall), where a single FET carries current for milliseconds.

## 2. Switching Loss Model (f_sw = 48 kHz)

Only the PWM-active leg switches: one HS/LS pair per channel at any time. The LS acts as the synchronous rectifier, so it switches at near-zero voltage, except for the dead-time diode.

### 2.1 Loss components

**(a) Hard-switching V·I overlap (HS FET):**

$$P_{VI} = \tfrac{1}{2}V_{bus}I_{ph}(t_r + t_f)f_{sw}$$

The transition times come from gate charge:

$$t_{r,f} \approx \frac{Q_{gd}}{I_g},\qquad I_g^{on} = \frac{V_{drv} - V_{pl}}{R_{g,ext} + R_{g,int} + R_{drv,src}}$$

With Q_gd = 8 nC, V_drv = 10 V, V_pl = 3.2 V, and R_total ≈ 7 Ω, the gate current is I_g ≈ 0.97 A, so t_r ≈ 8 ns from gate charge alone. Adding current-commutation time and the di/dt limit set by L_loop
