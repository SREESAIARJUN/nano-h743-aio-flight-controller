# STM32H743 Nano FC + 80 A 4-in-1 ESC: Loss Model, Thermal Model, Bi-directional DShot DMA Plan, and Reference Netlist

**Job #18, Architecture Baseline Rev A**

## 0. Scope and Key Findings

This baseline makes three architectural decisions:

1. **Two processors, not one.** The STM32H743 runs ArduPilot and does not commutate motors. Each motor channel has its own ESC MCU, which generates the 48 kHz PWM and answers bi-directional DShot600. The reference choice is the AT32F421 running AM32. A BLHeli_32-class G071 also fits.
2. **"80 A" is a burst rating.** The thermal model shows the honest continuous rating is far lower:
   - About 16–20 A per channel continuous on a 20×20 mm nano board in prop-wash.
   - 80 A on all four channels is sustainable for only about 1.5 s.
   - 80 A on a single channel lasts about 6 s.
3. **All derived numbers are parametric.** Every equation below is written so the team can substitute the actual MOSFET datasheet values. The assumed values are listed in Table 1.
