| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | 3× gimbal BLDC, 12N14P (pole pairs P = 7), e.g. GBM2804 |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701) |
| Current sensing | 2- or 3-shunt, sampled center-aligned |
| IMU A | ICM-42688-P on the camera payload (attitude and rate feedback) |
| IMU B | ICM-42688-P on the base / handle (disturbance reference and feedforward) |
