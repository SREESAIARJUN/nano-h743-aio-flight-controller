# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Vibration Rejection

I don't have the original specification for Job #5, so this design rests on the assumptions in Section 0. Every assumption is a configuration constant in the code, so you can change any of them without restructuring.

---

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701 class) on each joint |
| Current sensing | 2-shunt low-side, sampled at PWM center |
| MCU | Cortex-M4F/M7 or STM32G4 (single-precision FPU) |
| Joint kinematic chain | Base → Yaw (z) → Roll (x) → Pitch (y) → Camera |
| IMUs | 2× ICM-42688-P on the camera plate, mounted symmetrically about the pitch-axis center |

**Loop rates (each nested loop runs roughly 5–10× slower than the loop inside it):**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5–2 kHz |
| Velocity | 4 kHz | ~150–250 Hz |
| Angle | 1 kHz | ~20–40 Hz |
| IMU gyro ODR | 8 kHz, decimated to 4 kHz | — |
