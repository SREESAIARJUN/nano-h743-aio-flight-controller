# STM32H743 Nano FC + 4-in-1 ESC (Job #32): Electrothermal Model, DShot DMA Allocation, and Netlists

## 0. Architecture Decisions and Assumptions

Three constraints shape the design. Settle them before the math.

1. **The H743 should not commutate the motors.** ArduPilot does not run motor commutation firmware. The practical, supportable architecture is:
   - **H743 (flight controller):** sends bidirectional DShot600 to 4 ESC MCUs.
   - **4× ESC MCUs (AT32F421 or STM32G071) running AM32:** each runs 6-step commutation with back-EMF zero-cross detection. AM32 supports a 48 kHz PWM setting, so the 48 kHz requirement belongs to the ESC MCUs, not the H743.

2. **Placeholder component parameters.** No part has been selected yet, so I use a representative 40 V, 3.3×3.3 mm DFN MOSFET. Replace every value marked `[DS]` with the chosen part's datasheet value and re-run the model. The equations stay valid; the numbers will shift.

3. **"80 A burst" on a nano board is only valid for a few seconds.** The model below shows that four channels at 80 A dissipate about 100 W. A 30×30 mm board can shed only a few watts continuously. Treat 80 A as a time-limited rating with an explicit duration, not a headline figure.

## 1. Conduction Loss Model

### 1.1 Temperature-Dependent On-Resistance

```
R_DS(T_j) = R_DS,25 · [1 + α (T_j − 25)]
```

At T_j = 125 °C this gives R_DS = 1.6 mΩ.

### 1.2 Current Distribution in 6-Step Commutation

AM32 uses complementary (synchronous) PWM. At any instant exactly two phase legs conduct the phase current I, and in each active leg exactly one device carries it:
- the PWM-ing leg alternates HS (duty D) and LS (1 − D);
- the other leg holds its LS (or HS) on.

**Per bridge (one motor):**

```
P_cond,bridge = 2 · I² · R_DS(T_j)
```

**Per device, averaged over an electrical cycle:** each leg is active for 2/3 of the cycle, shared between HS and LS. For the worst-case device:

```
P_cond,FET ≈ (1/3) · I² · R_DS(T_j)
```
