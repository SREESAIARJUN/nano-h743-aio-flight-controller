## 0. Architecture Decision & Assumptions

### Partitioning
The STM32H743 does **not** commutate the motors directly. Industry-standard and ArduPilot-compatible partitioning is:

```
STM32H743 (ArduPilot) ──DShot600 bidir (4 lines)──► 4× AT32F421 (AM32 firmware) ──► 4× 3-phase bridges
```

Bit-banging 12 half-bridges with sensorless BEMF from the H7 while running EKF3 is not supported by ArduPilot. Each ESC channel therefore gets its own MCU.

## 1. Conduction Loss Model

### 1.1 Commutation topology
AM32 uses 6-step trapezoidal drive with complementary (synchronous) PWM:
- In each 60° sector, one phase is PWM'd on its high side.
- A second phase's low-side is held fully ON.
- The third phase floats (BEMF sensing).

Each leg spends 120° (1/3 of the period) as the "PWM high" leg and 120° as the "static low" leg.

### 1.2 Per-device RMS currents (motor current I, duty D)

**High-side FET of a leg** (on only during D of its active third):

$$I_{HS,rms}^2 = \frac{D}{3} I^2$$

**Low-side FET of the same leg** (fully on for 1/3 as static low, plus synchronous freewheel (1−D) during its PWM third):

$$I_{LS,rms}^2 = \frac{1}{3}I^2 + \frac{1-D}{3}I^2 = \frac{2-D}{3}I^2$$

**Per leg:**

$$P_{leg} = R_{ds}(T_j)\, I^2 \left[\frac{D}{3} + \frac{2-D}{3}\right] = \frac{2}{3} R_{ds}(T_j) I^2$$

**Per ESC channel (3 legs):**

$$\boxed{P_{cond,ch} = 2\,R_{ds}(T_j)\,I^2}$$

This is duty-independent: at every instant exactly two FETs carry I. Duty only redistributes loss between the high-side and low-side devices. Low-side FETs run hotter at low throttle, so place them nearest the thermal mass.

### 1.3 Temperature-dependent R_DS(on), with self-consistent solution

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha(T_j - 25)]$$

$$T_j = T_{pcb} + R_{\theta,jb}\,P_{FET}(T_j)$$

Solving the coupled equations for one conducting FET:

$$T_j = \frac{T_{pcb} + R_{\theta jb} I^2 R_{25}(1 - 25\alpha)}{1 - R_{\theta jb} I^2 R_{25}\alpha}$$

> **Thermal runaway criterion:** The solution is stable only if $R_{\theta jb} I^2 R_{25}\alpha < 1$. With I = 80 A, R₂₅ = 1 mΩ, α = 0.0045, and R_θjb = 2.5 K/W: 2.5 × 6400 × 0.001 × 0.0045 = **0.072**. Stable, with large margin.

**Worked example** (T_pcb = 90 °C, R_θjb = 2.5 K/W through the thermal-via array):
- Numerator: 90 + 2.5 × 6400 × 0.001 × (1 − 0.1125) = 90 + 14.2 = 104.2
- T_j = 104.2 / 0.928 = **112.3 °C**
- R_ds = 1.0 × (1 + 0.0045 × 87.3) = **1.39 mΩ**

**Losses at 80 A:**
- Per conducting FET: 6400 × 1.39 mΩ = **8.9 W**
- Per channel: **P_cond,ch = 2 × 6400 × 1.39 mΩ = 17.8 W**

### 1.4 Copper / interconnect conduction
Inner and outer 2 oz copper has a sheet resistance of about 0.25 mΩ/□ at 25 °C, rising roughly 0.39 %/K.
