# STM32H743 Flight Controller + 4-in-1 80A ESC: Reference Design Package (Job #0)

## 0. Architecture and Feasibility Review

These five corrections determine every number that follows:

1. **The STM32H743 does not commutate the motors.** ArduPilot is not a motor-control firmware. The H743 is the flight controller. It sends DShot600 frames to a 4-in-1 ESC that has four dedicated ESC MCUs (for example AT32F421 or STM32G071 running AM32 or BLHeli_32). The 48 kHz PWM, dead-time and gate drive live on those ESC MCUs.
2. **"80A burst" on a nano (20×20 mm) stack is thermally limited to roughly 1.5–2 s with all four motors loaded** (derived in §3). Most nano 4-in-1 ratings are 25–45A continuous. Treat 80A as a short transient.
3. **Assumed parameters.** All device parameters below are representative values for a 40V, roughly 1 mΩ, 3.3×3.3 mm MOSFET class. Replace them with your actual datasheet values before sign-off. The models are exact; the numbers are only as good as the inputs.
4. **Assumed supply.** 6S, worst case V_bus = 25.2V.
5. **Netlist status.** The netlist in §5 is a reference topology. It is not a fabrication-verified design. It needs DRC/ERC, SI review and bring-up validation.

## 1. Conduction Loss Model

### 1.1 Commutation assumptions
- Trapezoidal 6-step commutation (the AM32/BLHeli default).
- Complementary (synchronous-rectified) PWM on the switched leg.
- I_ph = 80A, the phase current during the burst.

At any instant, current flows through exactly two MOSFET channels:
- One in the PWM leg: the high-side FET for D, then the low-side sync FET for 1−D.
- The static low-side FET in the return leg.

So conduction loss is **independent of duty cycle**:

$$P_{cond,ch} = 2\,I_{ph}^2\,R_{DS(on)}(T_j) + I_{ph}^2 R_{Cu}$$

### 1.2 Temperature dependence

$$R_{DS(on)}(T_j) = R_{25}\left[1+\alpha\,(T_j-25)\right],\quad \alpha \approx 0.006\ \text{K}^{-1}$$

| Parameter | Value |
|---|---|
| R₂₅ (typ, V_GS = 10V) | 1.0 mΩ |
| R_DS(on) @ T_j = 125 °C | 1.6 mΩ |
| R_Cu (bus + phase pour + vias, per conducting path) | 0.5 mΩ |

### 1.3 Numbers at 80A, T_j = 125 °C

$$P_{FET,cond} = 2(80^2)(1.6\text{m}) = 20.5\text{ W}$$
$$P_{Cu} = 80^2(0.5\text{m}) = 3.2\text{ W}$$
$$P_{cond,ch} \approx 23.7\text{ W per motor channel}$$

Each FET conducts 120° of each electrical cycle. The electrical frequency is in the kHz range, far faster than the package thermal time constants, so averaging is valid:

$$\bar P_{FET} = \frac{2I^2R}{6} = \frac{I^2R}{3} = 3.41\text{ W}$$

### 1.4 Electro-thermal feedback

R_DS(on) depends on T_j, and T_j depends on loss. Solve as a fixed point:

$$T_j^{(k+1)} = T_c + R_{\theta jc}\,\bar P_{FET}\!\left(T_j^{(k)}\right)$$

This converges in 3–4 iterations. Thermal runaway is possible if $\partial P/\partial T \cdot R_\theta \ge 1$:

$$I^2 R_{25}\,\alpha\,R_{\theta,total}/3 \ge 1$$

## 2. Switching Loss Model (f_sw = 48 kHz)

Only the PWM-switched FET hard-switches. The sync FET switches at near-zero V_DS but contributes reverse recovery and dead-time body-diode conduction.

### 2.1 Device and driver parameters (assumed)

| Parameter | Value |
|---|---|
| Q_g (total) | 40 nC |
| Q_gd | 8 nC |
| Q_rr | 30 nC |
| C_oss,eff | 1.0 nF |
| V_plateau | 3.0 V |
| V_drv | 10 V |
| R_drv,src | 2 Ω |
| R_drv,snk | 1 Ω |
| R_g,ext | 3 Ω |
| Dead time t_d | 100 ns per edge |
| Body diode V_f | 0.8 V |

### 2.2 Transition times

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{src}+R_g} = \frac{7}{5} = 1.4\text{ A}$$
$$I_{g,off} = \frac{V_{pl}}{R_{snk}+R_g} = \frac{3}{4} = 0.75\text{ A}$$

From the Q_gd plateau, plus Q_gs2 margin:
- t_on ≈ 10 ns
- t_off ≈ 15 ns
- Σt ≈ 25 ns

### 2.3 Loss components

| Term | Formula | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_on+t_off)·f | ½·25.2·80·25n·48k = **1.21 W** |
| Reverse recovery | Q_rr·V·f | 30n·25.2·48k = **0.036 W** |
| C_oss | C_oss·V²·f | 1n·635·48k = **0.030 W** |
| Dead-time diode | 2·V_f·I·t_d·f | 2·0.8·80·100n·48k = **0.61 W** |
| Gate drive (two FETs) | 2·Q_g·V_drv·f | 2·40n·10·48k = **0.038 W** (in driver and R_g) |
| **Total per channel** | | **≈ 1.93 W** |

### 2.4 Design levers
- Dead-time loss is 32% of switching loss. Tightening t_d to 50 ns saves about 0.3 W per channel. This trades against shoot-through margin.
- Overlap loss scales linearly with f_sw. Dropping to 24 kHz saves about 0.6 W, at the cost of higher current ripple and audible noise.
