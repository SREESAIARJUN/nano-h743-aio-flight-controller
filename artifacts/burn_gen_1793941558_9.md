# STM32H743 FC + 4-in-1 ESC (Nano AIO): 80 A Burst Thermal, 48 kHz Switching, and Bidirectional DShot600 Design

## 0. Scope and Assumptions

**Architecture.** The H743 is the flight controller and runs ArduPilot. Each of the four ESC channels has its own small MCU (AT32F421 or STM32G071 running AM32 or BLHeli_32), a 3-phase gate driver and 6 MOSFETs. The H743 never switches FETs. It only generates DShot600 and decodes the eRPM telemetry. The 48 kHz figure is the ESC's PWM frequency.

**Datasheet values must be verified.** No specific MOSFET was named, so the model uses a representative 40 V, 3.3×3.3 mm DFN part. Replace every parameter in the table below with the chosen part's datasheet values. Treat these numbers as placeholders.

## 1. Conduction Loss Model

### 1.1 Commutation topology
The ESC uses 120° trapezoidal (6-step) commutation with synchronous rectification (complementary PWM). At any instant, the phase current I flows through exactly two FET positions:

- the PWM leg: the high-side FET for time D, or the low-side FET for time (1−D);
- the return leg's low-side FET, at 100% of the time.

So the instantaneous conduction loss per motor is independent of D:

$$P_{cond,motor} = 2\,I_{ph}^2\,R_{ds}(T_j)$$

### 1.2 Temperature dependence
$$R_{ds}(T_j) = R_{ds(25)}\,[1+\alpha\,(T_j-25)]$$

At T_j = 125 °C:

- R_ds = 1.2 mΩ × 1.5 = **1.8 mΩ**
- P_cond,motor = 2 × 80² × 1.8 mΩ = **23.0 W**

Over a commutation cycle each of the 6 FETs carries current for 1/3 of the electrical period. Averaged over the 6 FETs, that gives **≈3.8 W per FET** from conduction.

**Thermal runaway check.** Loss depends on T_j, and T_j depends on loss. Iterate:

$$T_j^{(n+1)} = T_{ref} + R_{\theta}\,P(T_j^{(n)})$$

A stable solution exists only while the loop gain stays below 1:

$$R_{\theta}\cdot\frac{\partial P}{\partial T_j} = R_\theta\cdot P_{cond,25}\cdot\alpha < 1$$

With P_cond,25 per FET ≈ 2.6 W and R_θ ≈ 8 K/W, the loop gain is ≈0.10. That is stable, but it adds roughly 10% to the temperature rise.

## 2. Switching Losses at 48 kHz

Only the PWM leg switches hard. Per motor:

| Loss term | Formula | Value |
|---|---|---|
| V–I overlap | ½·V·I·(t_r+t_f)·f_sw | ½·25.2·80·30n·48k = **1.45 W** |
| Dead-time diode conduction | V_f·I·2t_dead·f_sw | 0.8·80·200n·48k = **0.61 W** |
| Reverse recovery | Q_rr·V·f_sw | 50n·25.2·48k = **0.06 W** |
| C_oss charge (2 FETs) | 2·½·C_oss·V²·f_sw | **0.05 W** |
| Gate drive (2 FETs, mostly in driver/R_g) | 2·Q_g·V_gs·f_sw | **0.06 W** |
| **Total switching** | | **≈2.2 W** |

**Per motor total:** 23.0 + 2.2 ≈ **25.2 W**.

**Four motors at burst:** ≈ **101 W** dissipated in the power stage. On top of that, the shunts add ~2·I²·R_shunt (≈2.6 W per motor with a 0.2 mΩ shunt, if a per-phase or bus shunt is used), and the 2 oz copper traces add more.
