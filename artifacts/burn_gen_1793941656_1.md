# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual-IMU Vibration Rejection

I don't have the Job #19 specification, so this design uses the assumptions below. Every assumption is a named constant in the code, so you can substitute your real values.

| Item | Assumed value |

| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Hollow-shaft gimbal BLDC, 12N14P (7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, K_t ≈ 0.08 N·m/A |
| Position sensor | 14-bit magnetic encoder (AS5048A / MT6701) |

## 1. System Architecture

```
            ┌──────────── 1 kHz ───────────┐ ┌────── 4 kHz ──────┐ ┌──────── 20 kHz ─────────┐
θ_ref ─►(+)─► Angle P+FF ─► ω_ref ─►(+)─► Velocity PI ─► i_q* ─►(+)─► Current PI (d,q) ─► SVPWM ─► Motor
         ▲ (−)                       ▲ (−)          ▲          ▲ (−)
         │                           │      i_q,ff (cogging)   │
     θ_cam (fused IMU attitude)   ω_cam (fused, notched gyro)  i_dq (Clarke/Park of shunts)
                                                               θ_e (encoder)
```

**Key design choice.** The velocity and angle loops close on inertial camera rate and attitude from the IMUs, not on encoder rate. Closing on inertial rate is what rejects base motion. The encoder is used only for:

- commutation angle θ_e,
- cogging-table indexing (θ_m),
- joint-to-camera kinematics.

## 2. FOC Current Loop (20 kHz)

### 2.1 Transforms

Amplitude-invariant Clarke transform, assuming i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform, with θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d \\ i_q \end{bmatrix} = \begin{bmatrix} \cos\theta_e & \sin\theta_e \\ -\sin\theta_e & \cos\theta_e \end{bmatrix} \begin{bmatrix} i_\alpha \\ i_\beta \end{bmatrix}$$

Inverse Park transform:

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 2.2 Plant and PI design by pole-zero cancellation

In the dq frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

With decoupling feedforward the plant reduces to $G(s)=\frac{1}{Ls+R}$.

Choosing $C(s)=K_p + K_i/s$ with

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

cancels the electrical pole. The closed loop then becomes first order:

$$T(s) = \frac{\omega_c}{s+\omega_c}$$

The bandwidth is limited by the PWM/computation delay $T_d \approx 1.5\,T_s$. Keep

$$\omega_c \le \frac{1}{5\,T_d}.$$

At 20 kHz this gives ω_c ≈ 2π·1 kHz.

The decoupled output is:

$$v_d^* = \mathrm{PI}_d(e_d) - \omega_e L i_q,\qquad v_q^* = \mathrm{PI}_q(e_q) + \omega_e L i_d + \omega_e\lambda_m$$

### 2.3 Discrete PI with back-calculation anti-windup

Using forward Euler on the integral:

$$u_k = K_p e_k + I_k,\qquad u^{sat}_k = \mathrm{sat}(u_k)$$

$$I_{k+1} = I_k + K_i T_s e_k + K_{aw} T_s\,(u^{sat}_k - u_k),\qquad K_{aw} \approx K_i/K_p$$
