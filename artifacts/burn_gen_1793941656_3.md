## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| Motors | Hollow-shaft gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Rotor sensor | 14-bit absolute magnetic encoder (AS5048A/MT6701 class) |
| MCU | STM32G4/H7 class with FPU, center-aligned PWM, synchronous ADC sampling |
| Current loop | 20 kHz (PWM ISR) |
| Velocity loop | 4 kHz (÷5) |
| Angle loop | 1 kHz (÷20) |
| IMUs | 2 × ICM-42688-P on the camera plate. Gyro and accel at 8 kHz ODR, ±2000 dps / ±16 g, read through the FIFO |
| Kinematics | Yaw (outer) → Roll → Pitch (inner, camera) |

**Key architectural point.** In a stabilizing gimbal:
- The **encoder** is used for commutation (FOC electrical angle) and for joint-angle limits.
- The **IMU gyro** closes the inertial velocity loop.
- The **fused attitude** closes the angle loop.

Using encoder velocity in the outer loops would stabilize the motor relative to the frame, not the camera relative to the world.

## 1. Field-Oriented Current Loop (20 kHz)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle, with offset θ_off found at calibration:

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

Clarke transform, amplitude-invariant, assuming i_a + i_b + i_c = 0:

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant and PI Design

The PMSM voltage equations in the rotor frame are:

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e (L_d i_d + \lambda_m)$$
