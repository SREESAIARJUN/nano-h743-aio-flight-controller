# FOC Control Loop and Dual-IMU Sensor Fusion for a 3-Axis Gimbal

I don't have the specification for "Job #7", so this design uses the baseline below. Every value is a constructor parameter, so you can substitute your real hardware numbers.

## 0. Assumptions

| Item | Value (adjust to your hardware) |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motor | Gimbal BLDC, 24 slots / 22 poles (p = 11 pole pairs), e.g. GM4108 |
| Position sensor | 14-bit absolute magnetic encoder (AS5048A / MT6701) |

| Loop rates | Current/FOC 16 kHz · velocity + IMU fusion 8 kHz · attitude/angle 1 kHz |

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Clarke transform (amplitude-invariant, with i_a + i_b + i_c = 0):

$$
i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)
$$

Park transform, with θₑ = p·θₘ − θ_offset:

$$
\begin{bmatrix} i_d\\ i_q\end{bmatrix} =
\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}
\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}
$$
