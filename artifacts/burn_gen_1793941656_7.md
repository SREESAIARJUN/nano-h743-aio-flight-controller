# FOC Control Loop and Dual-IMU Fusion Design for a 3-Axis Gimbal (Job #18)

## Assumptions

I don't have the Job #18 specification, so this design assumes the hardware below. Change the constants in `config.hpp` if your hardware differs. Every equation is written in terms of those constants.

| Item | Assumed value |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Driver | 3-phase bridge with 2 low-side shunts. Voltage mode is used if no shunts. |
| Rotor sensor | 14-bit absolute magnetic encoder per axis (e.g., MT6701 / AS5048A) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI at 24 MHz, ODR 8 kHz, DRDY interrupt |
