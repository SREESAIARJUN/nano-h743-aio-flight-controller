## 1. FOC Current Loop

### 1.1 Transforms

The electrical angle is θₑ = p·(θₘ − θ_offset).

**Clarke transform** (amplitude-invariant, using i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** is the transpose of the matrix above.

**SVPWM** uses min-max zero-sequence injection, which is equivalent to 7-segment SVM:

$$v_{a,b,c}^* = \text{invClarke}(v_\alpha,v_\beta),\quad v_0 = -\tfrac12\left(\max v^* + \min v^*\right),\quad D_x = \tfrac12 + \frac{v_x^*+v_0}{V_{dc}}$$

The linear modulation limit is |v_αβ| ≤ V_dc/√3.

### 1.2 Plant and PI design

The dq-frame plant is:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

**Decoupling.** Add the feedforward terms below so each axis reduces to 1/(Ls+R):

$$v_d^{ff} = -\omega_e L i_q,\qquad v_q^{ff} = \omega_e L i_d + \omega_e\lambda_m$$

**Pole-zero cancellation tuning** (for crossover ω_c):

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c \;\Rightarrow\; G_{cl}(s)=\frac{\omega_c}{s+\omega_c}$$
