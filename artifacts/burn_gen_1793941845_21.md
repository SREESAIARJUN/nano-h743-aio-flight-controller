# STM32H743 AIO + 4-in-1 ESC (Job #48): Power-Stage, Thermal, and Bi-Directional DShot Architecture

## 0. Architecture Decisions and Assumptions

### 0.1 The H743 should not commutate the motors

A single H743 cannot cleanly drive 4 × 3-phase complementary bridges:

- Only TIM1 and TIM8 have complementary outputs with hardware dead-time. That is 2 motors' worth.
- HRTIM adds 10 outputs but no BEMF zero-crossing infrastructure for 4 sensorless motors.

The design therefore uses this partition:

```
STM32H743 (FC, ArduPilot) ──4× bidir DShot600──► 4× ESC MCU (AM32 / BLHeli_32-class)
                                                   e.g. AT32F421K8U7 or STM32G071GBU6
                                                   └─► 3-ph gate driver ─► 6 MOSFETs per motor
```

The 48 kHz PWM is generated by the ESC MCUs. The H743 handles DShot output and eRPM telemetry capture.

## 1. Conduction Loss Model

### 1.1 Temperature-dependent R_DS(on)

$$R_{DS}(T_j) = R_{25}\,[1+\alpha(T_j-25)] \quad\Rightarrow\quad R_{DS}(125^\circ C)=1.5\text{ mΩ}$$

### 1.2 6-step trapezoidal with synchronous rectification

During each commutation sector, two legs carry current:

- **PWM leg:** high-side conducts for D·T, low-side for (1−D)·T.
- **Static leg:** low-side is on 100 %.

$$P_{cond} = \underbrace{I^2R_{DS}D + I^2R_{DS}(1-D)}_{\text{PWM leg}} + \underbrace{I^2R_{DS}}_{\text{static leg}} = 2I^2R_{DS}(T_j)$$

The result is independent of D when synchronous rectification is used.

**At 80 A:**

| T_j | R_DS | P_cond per ESC |
|---|---|---|
| 25 °C | 1.0 mΩ | 12.8 W |
| 100 °C | 1.375 mΩ | 17.6 W |
| 125 °C | 1.5 mΩ | **19.2 W** |

### 1.3 Electro-thermal fixed point

$$T_j = T_c + P_{FET}\,R_{\theta JC},\qquad P_{FET}=I^2R_{25}[1+\alpha(T_j-25)]$$

$$T_j = \frac{T_c + I^2R_{25}R_{\theta JC}(1-25\alpha)}{1-\alpha I^2R_{25}R_{\theta JC}}$$

For the statically-on FET at 80 A: I²R₂₅R_θJC = 6400 × 0.001 × 1.5 = 9.6 K.
