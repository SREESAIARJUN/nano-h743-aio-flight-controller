## 0. Architecture Decision (Read First)

An STM32H743 should **not** commutate the bridges directly in a production 4-in-1 design. Driving 12 FETs with 4 independent commutation and BEMF/FOC loops from one MCU is possible on the H7's timers, but it breaks ArduPilot's driver model and puts flight control and motor control in one fault domain.

**Recommended partition (industry-standard):**

| Domain | Device | Firmware | Role |
|---|---|---|---|
| Flight controller | STM32H743VIT6 (LQFP100), 400–480 MHz | ArduPilot | Attitude control, DShot600 master, eRPM consumer (harmonic notch) |
| ESC ×4 | AT32F421K8U7 or STM32G071 (one per motor) | AM32 / BLHeli_32-class | Commutation, bidirectional DShot slave |
| Gate drive ×4 | FD6288Q-class 3-phase gate driver | n/a | Bootstrap high-side and low-side drive |
| Power stage ×4 | 6× N-MOSFET per motor (24 total) | n/a | 3-phase bridge |

"Bidirectional DShot600 DMA allocation" therefore applies to the **H743 → 4 ESC MCU** link. The 48 kHz switching applies inside each ESC.

## 2. Conduction Loss Model (80 A Burst)

### 2.1 Temperature-dependent on-resistance

$$R_{DS}(T_j) = R_{DS,25}\,[1+\alpha(T_j-25)]$$

At T_j = 125 °C: R_DS = 0.90 × 1.55 = **1.395 mΩ**. Use 1.40 mΩ.

### 2.2 Six-step synchronous bridge current paths

In any 60° commutation sector, one phase is PWM'd (high-side duty D, synchronous low-side 1−D). A second phase's low-side conducts continuously. The third phase floats.

$$P_{cond,bridge} = I_{rms}^2 R_{DS}\,[\,D + (1-D) + 1\,] = 2\,I_{rms}^2\,R_{DS}$$

This result is **independent of duty** because of synchronous rectification. Include the PWM ripple:

$$I_{rms}^2 = I_{ph}^2 + \frac{\Delta I^2}{12},\qquad \Delta I = \frac{V_{bus}D(1-D)}{L_{ph}f_{sw}}$$

For a typical 5" motor, L_ph ≈ 15 µH line-to-line. At worst-case D = 0.5:

ΔI = 25.2 × 0.25 / (15 µH × 48 kHz) = 8.75 A, so ΔI²/12 = 6.4 A². This is negligible against 6400 A².

$$P_{cond,bridge} = 2 \times 6406 \times 1.40\,\text{m}\Omega = \mathbf{17.9\ W\ per\ motor}$$
