# STM32H743 Nano FC + 4-in-1 80 A ESC: Systems Architecture Model (Job #66)

## 0. Architecture Clarifications

These points constrain the rest of the model:

1. **The H743 does not commutate the motors.** In any practical 4-in-1 stack, the H743 runs ArduPilot and emits bidirectional DShot600. Each ESC channel has its own MCU (typically AT32F421 or STM32G071 running AM32 or BLHeli_32). That ESC MCU owns the 48 kHz PWM, dead-time and back-EMF commutation. The loss model below applies to the ESC power stage. The DMA model applies to the H743.
2. **"80 A burst" in a nano (20×20 mm mount) form factor is thermally marginal.** The math in §3 shows roughly a 2–3 s adiabatic limit with all four motors at 80 A. Treat 80 A as a per-channel, short-burst rating, not a simultaneous-continuous one.
3. **Component values are representative placeholders.** They are typical of 40 V, 3.3×3.3 mm DFN MOSFETs used on 6S nano ESCs. Substitute your actual datasheet values. All equations are parametric, so the structure carries over.

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Commutation Topology

The ESC uses 6-step trapezoidal drive with complementary (synchronous) PWM. In each 60° sector:
- **PWM leg:** the high-side conducts for duty D. The low-side synchronously rectifies for (1 − D).
- **Return leg:** the low-side is on for 100% of the sector.

Current flows through exactly one PWM-leg FET and one return FET at any instant (ignoring dead-time), so:

$$P_{cond,ch} = I_{ph}^2 R_{ds}(T_j)\,[D + (1-D)] + I_{ph}^2 R_{ds}(T_j) = 2\,I_{ph}^2\,R_{ds}(T_j)$$

The result is independent of D. Duty only redistributes loss between the high- and low-side FETs.

### 1.2 Temperature Dependence

$$R_{ds}(T_j) = R_{ds,25}\,\left(1 + \alpha\,(T_j - 25)\right),\quad \alpha \approx 0.006\ /°C \Rightarrow k_T(125°C)=1.6$$

Because R_ds rises with T_j, loss and temperature are coupled. Iterate:

$$T_j^{(n+1)} = T_{board} + R_{\theta JC}\cdot P_{FET}\!\left(T_j^{(n)}\right)$$

This converges in 2–3 iterations for this design.

### 1.3 Numbers (Hot Case, T_j = 125 °C)

$$P_{cond,ch} = 2 \times 80^2 \times 1.6\,\text{mΩ} = \mathbf{20.5\ W\ per\ channel}$$

Additional series copper and sensing losses:

| Source | R | Loss @ 80 A |
|---|---|---|
| Phase pour + vias (2 oz, ~3 mm wide, ~8 mm) | ~0.15 mΩ ×2 | 1.9 W |
| Shunt (if per-channel sensing) | 0.25 mΩ (DC link, I_bus ≈ D·I_ph) | ≤1.6 W |

**Conduction subtotal ≈ 22–24 W per channel.**

### 1.4 Per-FET Distribution

Each FET carries current for 120° of 360°.
- High-side average: I²R·(1/3)·D
- Low-side average: I²R·(1/3)·(2−D)

At full throttle (D → 1) the six FETs share loss approximately equally:

$$P_{FET,cond} \approx 20.5/6 \approx 3.4\ W$$

At partial throttle the low-side FETs run hotter. Size the layout for the low-side.

## 2. Switching Loss Model (48 kHz)

Only one leg hard-switches per sector, so switching loss is counted once per channel.

### 2.1 Transition Times (Gate-Charge Method)

$$I_{g,on} = \frac{V_{drv}-V_{pl}}{R_{g,tot}} = \frac{7}{5} = 1.4\,\text{A}, \quad t_{on} = \frac{Q_{gs2}+Q_{gd}}{I_{g,on}} = \frac{12\,\text{nC}}{1.4} = 8.6\,\text{ns}$$

$$I_{g,off} = \frac{V_{pl}}{R_{g,tot}} = 0.6\,\text{A}, \quad t_{off} = \frac{12\,\text{nC}}{0.6} = 20\,\text{ns}$$

### 2.2 Loss Components

| Term | Equation | Value |
|---|---|---|
| V-I overlap | ½·V·I·(t_on + t_off)·f_sw = ½·25.2·80·28.6 ns·48 k | **1.38 W** |
| Dead-time diode | V_SD·I·2·t_dead·f_sw = 0.8·80·400 ns·48 k | **1.23 W** |
| Reverse recovery | Q_rr·V·f_sw | 0.04 W |
| C_oss | ½·C_oss,er·V²·f_sw | 0.015 W |
| Gate drive (2 switching FETs) | 2·Q_g·V_drv·f_sw | 0.04 W (in driver) |
| **Total** | | **≈ 2.7 W / channel** |
