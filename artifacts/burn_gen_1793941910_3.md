## 0. Architecture Clarification and Design Basis

The STM32H743 does **not** commutate the motors directly. It runs ArduPilot and sends bidirectional DShot600 to four ESC MCUs. Each ESC MCU (AT32F421 or STM32G071 running AM32) drives three half-bridges at 48 kHz. This is the only architecture that ArduPilot bi-dir DShot supports, so the document follows it throughout.

## 1. Conduction Loss Model (6-Step Trapezoidal, Complementary PWM)

### 1.1 Which devices conduct

In each 60° sector, two phases conduct:

- **PWM leg:** the high side conducts for fraction D, and the synchronous low side conducts for 1−D.
- **Fixed leg:** the low side is fully on.

So the bridge conduction loss is:

$$P_{cond,bridge} = I^2R(D) + I^2R(1-D) + I^2R = \boxed{2\,I^2 R_{ds(on)}(T_j)}$$

This result is **independent of duty cycle**, which is a useful property for burst analysis.
