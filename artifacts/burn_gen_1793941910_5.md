**Document scope:** This is a reference engineering package. The component values are representative parametric assumptions and must be replaced with datasheet values for the selected parts. It is not a released design, so layout, EMC, and qualification testing are still required.

## 0. Architecture Correction and Assumptions

### 0.1 MCU partitioning

ArduPilot cannot generate 48 kHz commutation PWM on the STM32H743 to drive FET gates directly. ArduPilot is a flight controller and has no BLDC commutation driver. The architecture that works is:

```
STM32H743 (ArduPilot)  --bidir DShot600 x4-->  ESC MCU(s) (AM32 / BLHeli_32-class)
                                               --> 3-phase gate drivers --> 24 FETs
```

- **ESC MCU options:**
  - 4× AT32F421 or STM32G071, one per motor (recommended).
  - One higher pin-count MCU per pair of motors.
- **48 kHz PWM** is an ESC firmware setting. In AM32 it is the PWM frequency parameter. The H743 has no role in it.

### 0.2 Design assumptions

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, 25.2 V max. Design voltage V_bus = 26 V |
| Phase current (burst) | I = 80 A per motor (RMS phase current, 6-step trapezoidal) |
| f_sw | 48 kHz, complementary (synchronous) PWM |
| MOSFET (example class) | 40 V, R_DS(on),25 = 1.0 mΩ, Q_g = 60 nC, Q_gd = 10 nC, Q_rr = 50 nC, Q_oss = 60 nC, V_SD = 0.8 V, R_θJC = 1.2 K/W |
| Dead time | t_dt = 50 ns |
| Gate drive | 10 V. R_g,total = 5 Ω (external + internal) |
| Board | 30.5 × 30.5 mm (the largest "nano/mini" class), 6-layer, 2 oz on all layers |
| Ambient in frame | T_a = 40–50 °C |

### 0.3 Feasibility flag

An 80 A per motor rating on a 30.5 mm board is a burst rating only, measured in seconds. The rest of this document quantifies that limit. At full throttle, four motors at 80 A also imply roughly 300 A of battery current. The XT60/XT90 connector, pigtail, and bus capacitors must be sized for that, or the 80 A spec must be restated as a non-simultaneous rating.

## 1. Conduction Loss Model

### 1.1 Conduction topology

In 6-step commutation with synchronous rectification, two FETs carry the phase current at every instant:

- **PWM-on interval (duty D):** the high-side FET of leg A and the low-side FET of leg B conduct.
- **PWM-off interval (1−D):** the low-side FET of leg A (synchronous rectification) and the low-side FET of leg B conduct.

Therefore, independent of D:

$$P_{cond,motor} = 2\,I^2\,R_{DS(on)}(T_j)$$

### 1.2 Temperature dependence of R_DS(on)

$$R_{DS(on)}(T_j) = R_{DS(on),25}\,[1+\alpha(T_j-25)], \quad \alpha \approx 0.006\ \text{K}^{-1}$$

At T_j = 110 °C:

$$R = 1.0 \times (1 + 0.006 \times 85) = 1.51\ \text{m}\Omega$$

### 1.3 Per-motor conduction loss

$$P_{cond} = 2 \times 80^2 \times 1.51\times10^{-3} = \mathbf{19.3\ W}$$

### 1.4 Per-FET distribution

Over one electrical cycle, each FET conducts for 1/3 of the cycle as the "active leg" and for 1/3 as the "return leg."

$$\bar P_{FET} \approx P_{cond}/6 \approx 3.2\ \text{W}$$

The worst-case FET is the low-side FET, which carries both the synchronous-rectification interval and the return interval at low D.

Its loss is bounded by:

$$P_{LS,max} \approx I^2 R\,[\tfrac{1}{3}(1-D) + \tfrac{1}{3}] \le 6.4\ \text{W}\quad(D\to 0)$$

### 1.5 Thermal runaway check

R_DS(on) rises with T_j, so conduction loss and junction temperature feed each other. The loop is stable only if the loop gain is below 1:

$$\frac{\partial P}{\partial T_j}\,R_{\theta} = 2I^2R_{25}\alpha\,R_\theta < 1$$

Per FET, the gain is 80² × 1e-3 × 0.006 × R_θ ≈ 0.038 × R_θ. Stability therefore requires R_θ,J-sink < 26 K/W per FET. This is satisfied if the FET is soldered to a power pour and the board's heat capacity is not saturated.
