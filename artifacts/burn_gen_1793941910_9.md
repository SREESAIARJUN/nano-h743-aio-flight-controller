# STM32H743 AIO Nano FC + 4-in-1 80A ESC: Systems Architecture Package (Job #75)

**Scope:** Power-stage loss model (80 A burst, 48 kHz PWM), thermal transient model, ArduPilot bidirectional DShot600 timer/DMA allocation, and reference netlists.

> **Basis of design.** No MOSFET part number, layer stack, or battery voltage was specified, so this package uses representative parameters, marked **[A]**. All equations are parametric. ## 0. System Partition (Clarifying the Architecture)

An "H743 4-in-1 ESC" is really two subsystems on one stack or board:

| Subsystem | Processor | Firmware | Role |
|---|---|---|---|
| Flight controller | STM32H743 (400 MHz) | ArduPilot | Generates DShot600 and receives eRPM telemetry |
| ESC (×4) | AT32F421 / STM32G071 / GD32 [A] | AM32 or BLHeli_32-class | Commutation and 48 kHz complementary PWM |

- The H743 does **not** generate the 48 kHz PWM. The ESC MCUs do.
- The loss model (§1–2) applies to the ESC power stage.
- The DMA model (§3) applies to the H743.
- The only interface between them is four single-wire, half-duplex bidirectional DShot lines.

## 1. Electrical Loss Model (per motor channel)

### 1.1 Conduction Topology

With 6-step trapezoidal commutation and complementary PWM, current at any instant flows through:

- **The PWM leg:** the high-side FET for fraction D, then the synchronous low-side FET for fraction (1 − D).
- **The return leg:** the low-side FET, on 100 % of the sector.

Conduction loss per motor is therefore:

$$
P_{cond} = I^2 R_{DS}(T_j)\,\big[D + (1-D) + 1\big] = 2\,I^2 R_{DS}(T_j)
$$

This is **independent of duty cycle** when synchronous rectification is enabled. That is a useful property, because loss is a pure function of current and temperature.

**At 80 A, using a hot junction (T_j = 125 °C):**

$$
R_{DS}(125) = 1.5\,\text{m}\Omega\,[1 + 0.004 \times 100] = 2.1\,\text{m}\Omega
$$

$$
P_{cond} = 2 \times 80^2 \times 2.1\times10^{-3} = \mathbf{26.9\ W}
$$

(At 25 °C: 19.2 W. The thermal feedback loop is addressed in §2.4.)

### 1.2 Hard-Switching (V–I Overlap) Loss

Only the PWM leg switches. There is one turn-on and one turn-off per PWM period:

$$
P_{VI} = \tfrac12 V_{bus} I (t_r + t_f) f_{sw}
= 0.5 \times 25.2 \times 80 \times 30\text{ns} \times 48\text{k} = \mathbf{1.45\ W}
$$

### 1.3 Capacitive, Reverse-Recovery, Dead-Time and Gate Losses

| Term | Equation | Value |
|---|---|---|
| Output capacitance | P_oss = Q_oss · V_bus · f_sw | 0.060 W |
| Reverse recovery (low-side body diode) | P_rr = Q_rr · V_bus · f_sw | 0.048 W |
| Dead-time diode conduction | P_dt = V_SD · I · 2t_dt · f_sw = 0.8·80·200 ns·48 k | 0.614 W |
| Gate drive (two FETs switch per period) | P_g = 2 · Q_g · V_GS · f_sw = 2·60 nC·10 V·48 k | 0.058 W |

| Term | Assumption | Value |
