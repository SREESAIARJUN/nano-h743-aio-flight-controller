## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, single-precision FPU, ≥150 MHz |
| Motor | Gimbal BLDC, 12N14P (pole pairs p = 7), R ≈ 5–15 Ω, L ≈ 1–3 mH |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5048A / TMAG), SPI |
| Current sense | 2-phase low-side shunts, ADC sampled at PWM center |
| PWM | 25 kHz center-aligned |
| IMUs | 2× ICM-42688-P on separate SPI buses, ODR 8 kHz, FIFO + timestamps |

**Loop rates (integer-divided from the PWM ISR):**

```
PWM ISR 25 kHz ── current loop (FOC), encoder read, cogging FF lookup
   └─ /5  → 5 kHz  velocity loop, PLL observer, IMU fusion + notch filters
        └─ /5 → 1 kHz  angle (attitude) loop, AHRS update, cogging LMS adaptation
```

**Bandwidth separation rule:** keep each loop at least 4–5× slower than the loop inside it.

- ω_c (current) ≈ 2π·2000 rad/s
- ω_v (velocity) ≈ 2π·150–250 rad/s
- ω_p (angle) ≈ 2π·20–40 rad/s

## 1. Field-Oriented Current Loop

### 1.1 Transforms

Electrical angle, with encoder offset θ₀ found by d-axis alignment:

$$\theta_e = p\,(\theta_m - \theta_0) \bmod 2\pi$$

Clarke transform (amplitude-invariant, i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

Park transform:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$
