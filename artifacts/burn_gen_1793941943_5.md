## 0. Assumptions and Timing Architecture

| Item | Assumed value |
|---|---|
| Motor | Hollow-shaft gimbal BLDC (e.g. GBM4108-class): 12N14P, so p = 7 pole pairs, R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Rotor sensor | 14-bit magnetic encoder (AS5048A / MT6701), SPI |
| MCU | STM32G4 @ 170 MHz, FPU, center-aligned PWM |
| Current sensing | 2-shunt low-side, sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera plate, same SPI bus, ODR = 8 kHz, CLKIN synchronized |

**Loop rates**

```
PWM / ADC ISR ........ 20 kHz  : Clarke/Park, current PI, SVPWM          (Ts_i = 50 µs)
Velocity loop ........  4 kHz  : rate PI + cogging FF + IMU gyro fusion   (Ts_v = 250 µs)
Angle loop ...........  1 kHz  : attitude P(I)D, AHRS update              (Ts_θ = 1 ms)
Adaptation / diag ....  100 Hz : cogging LMS gating, notch freq tracking, IMU health
```

**Bandwidth separation rule:** each loop's crossover is about 4–10× below the next inner loop's. Target crossovers:

- Current: ω_c ≈ 2π·2 kHz
- Rate: ω_v ≈ 2π·150 Hz
- Angle: ω_θ ≈ 2π·25 Hz

## 1. FOC Inner Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (two-shunt, with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform**, with θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 PMSM model in the dq frame (surface magnet, L_d = L_q = L)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau_e = \tfrac32 p\lambda_m i_q = K_t i_q$$
