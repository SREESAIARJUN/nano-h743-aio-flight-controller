## 1. Field-Oriented Control (Innermost Loop, 20 kHz)

### 1.1 Transforms

**Electrical angle.** $\theta_e = p(\theta_m - \theta_{off})$, wrapped to $[0, 2\pi)$.

**Clarke transform** (amplitude-invariant, assuming $i_a+i_b+i_c=0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park transform:**

$$v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e,\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e$$

### 1.2 Plant Model (Surface PMSM, $L_d = L_q = L$)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

$$\tau = \tfrac32 p\lambda_m i_q = K_t i_q$$

### 1.3 Current PI with Decoupling

**Control law.** With $e_x = i_x^* - i_x$:

$$v_d = K_{p,i}e_d + K_{i,i}\!\int e_d\,dt - \omega_e L i_q$$

$$v_q = K_{p,i}e_q + K_{i,i}\!\int e_q\,dt + \omega_e(L i_d + \lambda_m)$$

**Gain selection.** Place the PI zero on the electrical pole $R/L$ to cancel it. The closed loop then becomes first order with bandwidth $\omega_{ci}$:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci},\qquad \omega_{ci}\le \frac{2\pi f_{pwm}}{10}$$

With $f_{pwm}$ = 20 kHz, use $\omega_{ci} = 2\pi\cdot 1500$ rad/s.

**Voltage limiting and anti-windup.**
- Limit the voltage vector to the linear SVPWM region: $|v_{dq}| \le V_{bus}/\sqrt3$.
- Use back-calculation anti-windup: $\dot I_x \mathrel{+}= K_{aw}(v_x^{sat} - v_x^{unsat})$, with $K_{aw} = 1/K_{p,i}$.

### 1.4 SVPWM (Min-Max Zero-Sequence Injection)

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$
