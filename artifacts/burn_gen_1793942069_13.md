## 0. Assumptions and System Architecture

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs p = 7), R_ph ≈ 5–15 Ω, L ≈ 1–3 mH, K_t ≈ 0.05–0.15 N·m/A |
| Position sensor | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| MCU | STM32G4 / H7 class with single-precision FPU. CORDIC is optional. |
| Current sensing | 2-shunt low-side, ADC triggered at PWM center |
| PWM | 24 kHz center-aligned |
| IMU-A (payload) | ICM-42688-P rigidly mounted on the camera plate. Primary attitude and rate feedback. |
| IMU-B (base) | ICM-42688-P on the gimbal base/handle. Disturbance feedforward and vibration reference. |
| Axis order | Base → Yaw (q₁) → Roll (q₂) → Pitch (q₃) → Camera |
