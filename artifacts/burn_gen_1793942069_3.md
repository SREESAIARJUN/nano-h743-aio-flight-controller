## 1. FOC Core

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{0}) \bmod 2\pi$$

`θ₀` is found at startup by applying `V_d` with `θ_e = 0`, letting the rotor settle, and reading the encoder.

### 1.2 Clarke transform (amplitude-invariant, balanced phases, `i_a + i_b + i_c = 0`)

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 Motor model in the dq frame (surface PMSM, `L_d = L_q = L`)

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e \lambda_m$$

Torque:

$$\tau = \tfrac32\,p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.5 Current PI with decoupling and back-EMF feedforward

$$v_d^* = \text{PI}_d(i_d^* - i_d) - \omega_e L i_q$$

$$v_q^* = \text{PI}_q(i_q^* - i_q) + \omega_e L i_d + \omega_e\lambda_m$$

**Gain selection by pole-zero cancellation.** Choose the PI zero to cancel the electrical pole `R/L`. The closed loop then becomes first order with bandwidth `ω_cc`:

$$K_{p,i} = L\,\omega_{cc},\qquad K_{i,i} = R\,\omega_{cc}$$

Choose `ω_cc ≈ 2π · f_pwm / 20` (≈ 2π·1.25 kHz).

**Voltage-mode fallback (no current sensing).** Many gimbal motors are high-R and run without current sense. In that case use:

$$v_q^* = R\,i_q^* + \omega_e \lambda_m,\qquad v_d^* = -\omega_e L\, i_q^*$$

### 1.6 Voltage limiting and SVPWM

Limit the voltage vector to the inscribed hexagon circle:

$$\|v_{dq}\| \le V_{bus}/\sqrt3$$

Inverse Park gives `v_α, v_β`, then:

$$v_a = v_\alpha,\quad v_b = -\tfrac12 v_\alpha + \tfrac{\sqrt3}{2}v_\beta,\quad v_c = -\tfrac12 v_\alpha - \tfrac{\sqrt3}{2}v_\beta$$

Min-max zero-sequence injection (equivalent to SVPWM):

$$v_0 = -\tfrac12(\max + \min),\qquad d_x = \tfrac12 + \frac{v_x + v_0}{V_{bus}}$$

**Delay compensation.** Advance the angle by 1.5 PWM periods, `θ_e ← θ_e + 1.5\,ω_e T_s`. This covers one sample of compute delay plus half a period of PWM delay.

## 2. Cascaded Angle/Velocity Control

### 2.1 Loop structure

```
q_ref ──► [attitude error → per-axis angle error] ──► Angle P(I) ──ω*──► Velocity PI ──τ*──► (+cogging FF) ──i_q*──► Current PI ──► SVPWM
             ▲ IMU fused attitude (camera)         ▲ +ω_ff        ▲ ω = encoder ω_m + ω_imu_axis
```

### 2.2 Plant

The plant for each axis is:

$$J\dot\omega = K_t i_q - b\omega - \tau_{cog}(\theta) - \tau_{dist}$$

With an ideal inner current loop:

$$G_v(s) = \frac{K_t}{Js + b}$$

### 2.3 Velocity PI

Use 2-DOF form: proportional on error with setpoint weighting `β`, integral on error, and a first-order filter on the measurement:

$$\tau^* = K_{pv}(\beta\,\omega^* - \omega_f) + K_{iv}\int(\omega^* - \omega_f)\,dt + \tau_{ff}$$

**Pole placement.** For a crossover `ω_cv` and a PI zero at `ω_cv/4` (≈ 60° phase margin):

$$K_{pv} = \frac{J\,\omega_{cv}}{K_t}\ \ [\text{A per rad/s}],\qquad K_{iv} = K_{pv}\frac{\omega_{cv}}{4}$$

Choose `ω_cv ≤ ω_cc/5` and below the first structural mode by at least a factor of 2.

### 2.4 Angle loop

The plant seen by the angle loop is approximately `1/s`, so a P controller suffices. An optional small I term removes residual offset from cable torque:

$$\omega^* = K_{pa}\,e_\theta + K_{ia}\int e_\theta\,dt + \dot\theta_{ref}$$

$$K_{pa} = \omega_{ca} \approx \omega_{cv}/5,\qquad K_{ia} \le K_{pa}\,\omega_{ca}/10$$

### 2.5 Angle error from quaternions (gimbal-correct)

Compute the error quaternion:

$$q_e = q_{ref}^{-1}\otimes q_{cam},\qquad q_e \leftarrow \operatorname{sign}(q_{e,w})\,q_e$$

The small-angle rotation vector is `e = 2 q_{e,xyz}` (for large errors, `e = 2\,\operatorname{atan2}(\|v\|, w)\,\hat v`).

Map this camera-frame error to joint errors with the inverse gimbal Jacobian. For the yaw-roll-pitch chain:

$$\dot{\boldsymbol\phi} = J_g^{-1}(\boldsymbol\phi)\,\boldsymbol\omega_{cam}$$

Near the nominal pose, `J_g ≈ I` with axis permutation. The code below uses the exact form for a Z(yaw)→X(roll)→Y(pitch) chain. The joint angles `ψ` (yaw) and `φ` (roll) come from the encoders, and the matrix maps camera-frame rates `(ω_x, ω_y, ω_z)` to joint rates `(φ̇_roll, φ̇_pitch, ψ̇_yaw)`:

$$J_g^{-1} = \begin{bmatrix} \cos\psi & \sin\psi & 0\\ -\sin\psi/\cos\phi & \cos\psi/\cos\phi & 0\\ \sin\psi\tan\phi & -\cos\psi\tan\phi & 1\end{bmatrix}$$

`cos φ` is clamped away from 0 to avoid gimbal-lock blow-up.

### 2.6 Discretization and anti-windup

**Integrator** (forward Euler with back-calculation):

$$I_{k+1} = I_k + T_s\left[K_i e_k + \tfrac{1}{T_t}(u_{sat,k} - u_k)\right],\qquad T_t = \sqrt{K_p/K_i}$$

**Measurement LPF and derivative filters** use the bilinear transform with prewarping:

$$K = \frac{\omega_c}{\tan(\omega_c T_s/2)}$$
