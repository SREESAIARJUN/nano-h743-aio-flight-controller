# STM32H743 Nano FC + 4-in-1 ESC (Job #32): Architecture, Loss Model, Thermal Budget, and DShot DMA Allocation

## 0. Architecture Clarifications

These points change the math, so they come first.

1. **The H743 does not commutate the motors.** ArduPilot is a flight controller stack and has no BLDC commutation or FOC. The architecture is therefore:
   - **FC:** STM32H743 running ArduPilot. It sends bidirectional DShot600 to four ESC MCUs.
   - **ESC:** 4 × dedicated MCUs (baseline AT32F421 running AM32). Each generates the 48 kHz complementary PWM, runs a 3-phase gate driver, and drives 6 MOSFETs.

   The 48 kHz switching analysis applies to the ESC stage, not the H743.

2. **"80 A burst" is treated as peak motor phase current per ESC**, a worst-case design point. Battery current is roughly D·I_phase.
