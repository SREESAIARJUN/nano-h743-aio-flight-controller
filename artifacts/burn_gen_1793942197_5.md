# STM32H743 FC + 4-in-1 ESC: Power-Stage Thermal Model and Bi-Directional DShot600 Architecture

## 0. Scope, Assumptions and Feasibility

**Architecture.** The STM32H743 is the flight controller. It sends DShot frames to four ESC MCUs; it does not commutate the motors. Each ESC channel has its own MCU (AT32F421 running AM32 in this reference). The math below covers the H743 timer/DMA side and the ESC power stage separately.

**Design basis.** All numbers are worst-case planning values. Swap in the datasheet values for the MOSFET you actually select.

| Parameter | Symbol | Value |
|---|---|---|
| Bus voltage (6S, full charge) | V_bus | 25.2 V |
| Burst phase current per channel | I_pk | 80 A |
| PWM frequency | f_sw | 48 kHz |
| MOSFET (40 V, DFN5x6 class) | R_ds,25 | 1.0 mΩ max |
| | Q_g / Q_gs2+Q_gd | 80 nC / 18 nC |
| | V_plateau | 3.0 V |
| | V_f (body diode at 80 A) | 0.8 V |
| | Q_rr / Q_oss | 40 nC / 50 nC |
| | R_th,jc | 1.2 K/W |
| Gate driver (FD6288Q class) | V_drv | 10 V |
| | R_g,total | 10 Ω |
| Dead time | t_dt | 250 ns |
| PCB phase-path copper | R_cu | 0.5 mΩ per channel |
| Commutation | — | 6-step trapezoidal, complementary (synchronous) PWM |

**Feasibility warning.** Four simultaneous 80 A channels total 320 A from 6S, about 8 kW. On a nano footprint (20×20 or 25.5×25.5 mm), this is only survivable as a short burst. Section 2 quantifies the burst limit, and that limit is the governing design constraint.

## 1. Loss Model (per channel)

### 1.1 Conduction Loss

With 6-step commutation and synchronous rectification, two MOSFETs are always in the current path. One is the active high-side or its synchronous low-side complement. The other is the return-leg low-side. So:

$$P_{cond} = 2\,I^2\,R_{ds}(T_j), \qquad R_{ds}(T_j)=R_{ds,25}\,(1+\alpha)^{T_j-25},\ \alpha\approx0.0045/\mathrm{K}$$

At T_j = 125 °C the multiplier is 1.0045^100 ≈ 1.57, which rounds to **1.6**.

| T_j | R_ds | P_cond (80 A) |
|---|---|---|
| 25 °C | 1.0 mΩ | 12.8 W |
| 125 °C | 1.6 mΩ | **20.5 W** |

PCB copper adds I²·R_cu = 6400 × 0.5 mΩ = **3.2 W**.

### 1.2 Switching Loss (hard-switched high-side)

Gate current during the switching interval:

- I_g,on = (V_drv − V_pl)/R_g = 7/10 = 0.70 A
- I_g,off = V_pl/R_g = 3/10 = 0.30 A

Switching times:

- t_on = Q_sw/I_g,on = 18 nC/0.70 A = 25.7 ns
- t_off = Q_sw/I_g,off = 18 nC/0.30 A = 60 ns

$$P_{sw}=\tfrac12 V_{bus} I (t_{on}+t_{off}) f_{sw} = 0.5(25.2)(80)(85.7\,\text{ns})(48\,\text{kHz}) = \mathbf{4.15\ W}$$

The low-side synchronous FET turns on after body-diode conduction, so it switches at near-zero voltage. Its switching loss is neglected.
