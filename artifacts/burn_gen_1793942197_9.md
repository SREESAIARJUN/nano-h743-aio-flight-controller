## 1. Conduction Loss Model

### 1.1 Current paths in 6-step synchronous drive
In any 60° commutation sector, exactly two phase legs carry current:
- **Active (PWM) leg:** current alternates between the high-side (duty D) and the synchronous low-side (1−D).
- **Return leg:** the low-side is held ON for the whole sector.

Because synchronous rectification puts the low-side channel (not the body diode) in parallel during the off-time, the **instantaneous** conducting path is always two MOSFET channels in series, independent of D:

$$P_{cond,ch}(T_j) = 2\,I_{rms}^2\,R_{DS(on)}(T_j)$$

$$R_{DS(on)}(T_j) = R_0\,[1 + \alpha\,(T_j - 25)]$$

For a trapezoidal motor at full burst, the phase current is quasi-flat during conduction, so I_rms ≈ I_pk = 80 A. This is conservative. A sinusoidal FOC drive would use I_rms = I_pk/√2.

### 1.2 Numerical evaluation, per channel

| T_j | R_DS(on) | P_cond,ch = 2·80²·R |
|---|---|---|
| 25 °C | 1.000 mΩ | **12.8 W** |
| 75 °C | 1.225 mΩ | **15.7 W** |
| 100 °C | 1.338 mΩ | **17.1 W** |
| 125 °C | 1.450 mΩ | **18.6 W** |

### 1.3 Per-FET distribution
Each FET conducts for 120° of the 360° electrical cycle (1/3 duty), so the average per-FET conduction loss is:

$$P_{cond,FET} = \frac{P_{cond,ch}}{6}\;\;\Rightarrow\;\; 2.85\text{ W @ }100^\circ\text{C}$$

The instantaneous FET dissipation while conducting is I²·R = 80²·1.338 mΩ = **8.56 W**. This matters for the short-time Z_th check in §4.3.

### 1.4 Thermal runaway stability criterion
Loss rises with temperature, so check the loop gain:

$$G = \frac{\partial P}{\partial T}\cdot R_{th,total} = P_{cond}(T)\cdot\frac{\alpha}{1+\alpha(T-25)}\cdot R_{th,ja}$$

At 100 °C per FET: 2.85 W × 0.00336 /K × R_th,ja. Stability requires G < 1, so R_th,ja < ~104 K/W. This is easily met. Runaway is **not** a single-FET risk here. The real limit is board-level heat soak (§4).
