# 3-Axis Gimbal FOC Control & Dual-IMU Fusion: Design Specification and Reference Implementation

I don't have the Job #51 hardware spec, so the design is parameterized. Every numeric default below is an explicit assumption you should replace with the real values. The equations hold regardless.

---

## 0. Baseline Assumptions

| Item | Assumed value |
|---|---|
| MCU | STM32G474 @ 170 MHz, single-precision FPU, CORDIC available |
| Motors | GBM2804-class gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 10 Ω, L ≈ 2 mH, Kt ≈ 0.05 N·m/A |
| Encoder | 14-bit absolute magnetic (AS5048A / MT6701), one per joint |
| Current sensing | 2-phase inline shunts. A voltage-mode fallback is provided for boards without current sensing. |
| IMUs | 2 × ICM-42688-P on the camera payload, SPI, gyro/accel ODR 8 kHz, FIFO + timestamps |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ~1.5 kHz |
| Velocity (inertial rate) | 4 kHz | ~80 Hz |
| Attitude / angle | 1 kHz | ~15–20 Hz |
| IMU ingest | 8 kHz | — |
| Dynamic-notch tracker | 2 kHz (decimated) | — |

## 1. FOC Current Loop

### 1.1 Frame transforms

The electrical angle comes from the mechanical encoder angle:

$$\theta_e = p\,(\theta_m - \theta_{\text{off}}) \bmod 2\pi$$

**Clarke transform** (amplitude-invariant, using $i_a + i_b + i_c = 0$):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

**Park transform:**

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 PMSM model in the dq frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$

$$v_q = R i_q + L\dot i_q + \omega_e (L i_d + \lambda_m)$$

Torque output:

$$\tau = \tfrac32\, p\, \lambda_m\, i_q = K_t\, i_q$$

The d-axis reference is $i_d^* = 0$ (surface PM, no field weakening needed).

### 1.3 PI current control with decoupling (pole-zero cancellation)

Control law:

$$v_{d,q} = K_{p,i}\, e_{d,q} + K_{i,i}\int e_{d,q}\,dt + v^{ff}_{d,q}$$
