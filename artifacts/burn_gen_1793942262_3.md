## 1. FOC Inner Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (assuming i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}\,(i_a + 2 i_b)$$

**Park transform** (θ_e = p·θ_m + θ_offset):

$$\begin{bmatrix} i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha\\ i_\beta\end{bmatrix}$$

**Inverse Park** is the transpose. Use θ_e advanced by 1.5·T_s·ω_e. This compensates for the compute delay plus the PWM zero-order-hold delay.

### 1.2 Plant and PI design

The surface-mount PMSM model in the dq frame:

$$v_d = R i_d + L\dot i_d - \omega_e L i_q,\qquad v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\lambda_m$$

With feedforward decoupling, each axis reduces to a simple first-order plant:

$$G_i(s)=\frac{1}{Ls+R}$$

To place the closed loop at bandwidth ω_c, use pole-zero cancellation:

$$K_{p,i}=L\,\omega_c,\qquad K_{i,i}=R\,\omega_c \;\;\Rightarrow\;\; \frac{i}{i^*}=\frac{\omega_c}{s+\omega_c}$$

Choose ω_c ≤ 2π·f_pwm/20, i.e. about 2π·1 kHz at 20 kHz PWM.

**Discretization** (backward Euler) with back-calculation anti-windup:

$$u_k = K_p e_k + I_k,\qquad I_{k+1}=I_k + K_i T_s e_k + K_{aw}(\text{sat}(u_k)-u_k)$$

Use K_aw ≈ K_i/K_p.

**Voltage limit:** apply a circular limit, |v_dq| ≤ V_bus/√3, so the commanded vector stays in the linear SVPWM region.

### 1.3 SVPWM (min/max zero-sequence injection)

$$v_{a,b,c}=\text{invClarke}(v_\alpha,v_\beta),\quad v_0=-\tfrac12(\max+\min),\quad D_x=\tfrac12+\frac{v_x+v_0}{V_{bus}}$$

## 2. Cascaded Velocity and Angle Control

### 2.1 Mechanical plant

$$J\dot\omega = K_t i_q - B\omega - \tau_{cog}(\theta) - \tau_{dist}$$

**Velocity loop feedback.**
- For stabilization, feed back the *inertial* rate from the fused gyro (projected onto the joint axis, §4.6).
- Use the encoder rate only for commutation and as a fallback.
