### Bandwidth Separation

Each loop's bandwidth stays at least 4–5× below the loop inside it:

$$\omega_{c,i} \approx 2\pi\cdot 1500,\quad \omega_{c,v}\approx 2\pi\cdot 120,\quad \omega_{c,\theta}\approx 2\pi\cdot 25 \ \text{rad/s}$$

## 1. FOC Current Loop

### 1.1 Electrical Angle

$$\theta_e = p\,(\theta_m - \theta_{off}) \bmod 2\pi$$

- θ_off is found once by aligning the d-axis: inject V_d with θ_e = 0 and read the encoder.
- Delay compensation: the PWM update occurs about 1.5 T_s after sampling, so

$$\theta_e^{comp} = \theta_e + 1.5\,T_s\,\omega_e$$

### 1.2 Clarke Transform (Amplitude-Invariant, i_a + i_b + i_c = 0)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park Transform

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.4 PMSM Model in the dq Frame

$$v_d = R i_d + L\dot i_d - \omega_e L i_q$$
$$v_q = R i_q + L\dot i_q + \omega_e L i_d + \omega_e\psi_m$$
$$\tau = \tfrac32 p\,\psi_m\, i_q = K_t\, i_q$$

### 1.5 Current PI With Pole-Zero Cancellation and Decoupling

Choose gains so the PI zero cancels the electrical pole R/L. The closed loop then becomes first-order with bandwidth ω_ci:

$$K_{p,i} = L\,\omega_{ci},\qquad K_{i,i} = R\,\omega_{ci}$$

Voltage commands, with cross-coupling and back-EMF decoupling feedforward:

$$v_d^* = \text{PI}_d(i_d^*-i_d) - \omega_e L i_q$$
$$v_q^* = \text{PI}_q(i_q^*-i_q) + \omega_e L i_d + \omega_e \psi_m$$

**Digital realization.** Use the backward-Euler integrator x[k] = x[k−1] + K_i T_s e[k].

**Voltage limiting.** Limit the voltage vector circularly. The maximum linear SVPWM amplitude is

$$|v|_{max} = \frac{V_{bus}}{\sqrt3}$$

Priority goes to v_d. Then:

$$|v_q|\le\sqrt{|v|_{max}^2 - v_d^2}$$

**Anti-windup.** Back-calculation:

$$x \leftarrow x + K_{aw}(v_{sat}-v_{unsat}),\qquad K_{aw}=1/K_p$$
