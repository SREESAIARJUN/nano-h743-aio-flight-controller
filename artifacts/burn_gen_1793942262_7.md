# FOC Motor Control and Dual-IMU Sensor Fusion for a 3-Axis Gimbal (Job #38)

I don't have the Job #38 specification, so this design uses the assumptions listed below. Every parameter is in a single config struct so you can substitute your real values.

| Item | Assumed value |
|---|---|
| MCU | STM32G474 / H7-class Cortex-M with single-precision FPU, center-aligned PWM, ADC triggered at the PWM center |
| Motors | Gimbal BLDC/PMSM, 12N14P (7 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH, shunt current sensing |
| Encoder | 14-bit absolute magnetic (AS5047P / MT6701 class) on each joint |
| IMU A | ICM-42688-P on the **camera payload**. Provides stabilization feedback: inertial attitude and rate. |
| IMU B | ICM-42688-P on the **base/handle**. Provides the kinematic feedforward and the vibration reference. |

---

## 1. Timing Architecture

| Loop | Rate | Timer | Content |
|---|---|---|---|
| Current (FOC) | 20 kHz | PWM ISR (ADC EOC) | Clarke, Park, PI, decoupling, SVPWM, cogging FF |
| Velocity | 4 kHz | every 5th FOC tick | PI on joint rate, base-rate FF, accel FF |
| Angle / attitude | 1 kHz | every 20th tick | Attitude error → joint angle/rate reference |
| IMU read + filters | 8 kHz ODR (both IMUs) | SPI DMA on DRDY | AAF, notches, adaptive notch, LMS, fusion at 1 kHz |

**Bandwidth separation rule.** Each loop is placed at least 4–5× slower than the loop inside it:

ω_cc ≈ 2π·1500 rad/s > 5·ω_cv ≈ 5·2π·150 > 5·ω_cθ ≈ 5·2π·25

## 2. FOC Current Loop

### 2.1 Electrical angle and transforms

θ_e = p·(θ_m − θ_offset), where p is the number of pole pairs.

**Clarke transform** (amplitude-invariant, i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b)/√3

**Park transform:**

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e
