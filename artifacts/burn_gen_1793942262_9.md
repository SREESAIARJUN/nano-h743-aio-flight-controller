# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging, and Dual-IMU Fusion

I don't have the Job #12 specification, so this design uses the stated assumptions below. Change the constants in `config.hpp` to match your hardware. Everything is parameterized, and the equations do not depend on these specific values.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Motors | Hollow-shaft gimbal BLDC, 24N22P (11 pole pairs), R ≈ 5–15 Ω, L ≈ 2–5 mH |
| Encoder | 14-bit absolute magnetic (MT6701 / AS5047P), one per axis |
| Current sensing | 2-shunt low-side, sampled at PWM center |
| IMUs | 2× ICM-42688-P on the camera platform, SPI, gyro and accel ODR = 8 kHz |
| Gimbal order | Yaw (base) → Roll → Pitch (camera) |

**Loop rates and bandwidth separation.** Each outer loop should be at least 5× slower than the loop inside it.

```
 20 kHz  ─ Current loop (FOC, PI d/q, SVPWM)                 BW_i ≈ 1.5–2 kHz
  8 kHz  ─ IMU sampling, notch/LPF, dual-IMU fusion
  4 kHz  ─ Velocity loop (PI + anti-cog FF)                  BW_v ≈ 150–250 Hz
  1 kHz  ─ Attitude estimator (Mahony) + angle loop (P/PI)   BW_θ ≈ 20–40 Hz
```

**Signal flow:**

```
                    ┌──────── anti-cog FF  i_ff(θm, ω) ────────┐
θ_ref ─►(+)─► C_θ ─►(+)─► C_ω ─►(+)──────────────────────────(+)─► i_q* ─► FOC ─► motor
        ▲  ω_ff ──┘   ▲                                                       │
        │             │  ω_joint (gyro→joint Jacobian ⊕ encoder PLL)         │
        └─ θ_joint err (quaternion error → joint Jacobian) ◄─ Dual-IMU ◄─ vibration
```

## 1. FOC Current Loop (20 kHz)

### 1.1 Electrical angle

$$\theta_e = p\,(\theta_m - \theta_{\text{offset}}) \bmod 2\pi,\qquad p=\text{pole pairs}$$

The current loop runs about 1.5 PWM periods behind the sample, so the angle is advanced to compensate:

$$\theta_e^{\text{use}} = \theta_e + 1.5\,T_s\,p\,\hat\omega_m$$

### 1.2 Clarke transform (amplitude invariant, $i_a+i_b+i_c=0$)

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2 i_b)$$

### 1.3 Park transform and its inverse

$$\begin{bmatrix} i_d \\ i_q\end{bmatrix} = \begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} i_\alpha \\ i_\beta\end{bmatrix},\qquad
\begin{bmatrix} v_\alpha \\ v_\beta\end{bmatrix} = \begin{bmatrix}\cos\theta_e & -\sin\theta_e\\ \sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix} v_d \\ v_q\end{bmatrix}$$
