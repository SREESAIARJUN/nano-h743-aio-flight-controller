## 1. FOC Current Loop (Innermost, 20 kHz)

### 1.1 Electrical angle and transforms

Electrical angle, where θ_off is the encoder-to-d-axis offset found at alignment:

θ_e = p·(θ_m − θ_off)  mod 2π

**Clarke transform** (amplitude-invariant, using two measured phases, with i_a + i_b + i_c = 0):

- i_α = i_a
- i_β = (i_a + 2·i_b) / √3

**Park transform:**

- i_d = i_α·cos θ_e + i_β·sin θ_e
- i_q = −i_α·sin θ_e + i_β·cos θ_e

### 1.2 Plant and PI design (pole-zero cancellation)

The motor voltage equations in the d-q frame are:

- v_d = R·i_d + L·(di_d/dt) − ω_e·L·i_q
- v_q = R·i_q + L·(di_q/dt) + ω_e·L·i_d + ω_e·λ_m

Use a PI controller with decoupling and back-EMF feedforward:

- v_d* = PI_d(i_d* − i_d) − ω_e·L·i_q
- v_q* = PI_q(i_q* − i_q) + ω_e·L·i_d + ω_e·λ_m

Here λ_m = K_t / (1.5·p).

Choose the PI zero to cancel the electrical pole (R/L):

- K_p,i = L·ω_c
- K_i,i = R·ω_c

The closed-loop current response then becomes first order: i/i* = ω_c / (s + ω_c).

**Delay constraint.** The PWM update plus sampling adds about 1.5·T_c of delay. Keep ω_c ≤ 1/(3·1.5·T_c) ≈ 4400 rad/s. The choice of 2π·1500 ≈ 9400 rad/s is too high for 50 µs, so use ω_c ≈ 4000 rad/s.

### 1.3 Discrete PI with back-calculation anti-windup

- e[k] = r[k] − y[k]
- u_unsat[k] = K_p·e[k] + I[k]
- u[k] = sat(u_unsat[k])
- I[k+1] = I[k] + K_i·T·e[k] + K_aw·(u[k] − u_unsat[k])

A good default for the anti-windup gain is K_aw = K_i / K_p.

### 1.4 Voltage limiting and SVPWM

Limit the voltage vector to the inscribed circle of the SVPWM hexagon, with d-axis priority:

- |v_d| ≤ V_max = V_bus / √3
- |v_q| ≤ √(V_max² − v_d²)

Apply the inverse Park transform:

- v_α = v_d·cos θ_e − v_q·sin θ_e
- v_β = v_d·sin θ_e + v_q·cos θ_e

Then apply SVPWM using the min-max zero-sequence injection method, which is equivalent to SVPWM:

1. Compute phase voltages: v_a = v_α, v_b = −½·v_α + (√3/2)·v_β, v_c = −½·v_α − (√3/2)·v_β
2. Compute the zero-sequence offset: v_0 = −½·[max(v_a, v_b, v_c) + min(v_a, v_b, v_c)]
3. Compute duties: d_x = ½ + (v_x + v_0) / V_bus, for x ∈ {a, b, c}

**Delay compensation.** Advance the angle used in the inverse Park transform to θ_e + 1.5·ω_e·T_c.
