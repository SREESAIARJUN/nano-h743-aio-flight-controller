# 3-Axis Gimbal: FOC Motor Control, Cascaded Stabilization, Anti-Cogging, and Dual ICM-42688-P Fusion

I don't have the Job #52 specification, so this design uses the assumptions in §0. Every derived gain is written as a formula of those parameters, so you can substitute your real values.

## 0. Assumptions and Loop Architecture

| Item | Assumed value |
|---|---|
| Motor | Gimbal BLDC/PMSM, 14 poles (p = 7 pole pairs), 12 slots |
| Phase resistance / inductance | R = 5 Ω, L_d ≈ L_q = 2 mH (line-to-neutral) |
| Flux linkage | λ_m = 0.0035 V·s (gives K_t = 1.5·p·λ_m ≈ 0.037 N·m/A) |
| Driver | 3-phase, center-aligned PWM at 20 kHz, inline or low-side shunts |
| Encoder | 14-bit absolute magnetic encoder (e.g. MT6701 or AS5048A) |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR, ±2000 dps, ±16 g |
| Propeller/frame vibration | 80–400 Hz, varying with throttle |

**Loop rates and target bandwidths:**

```
 20 kHz  ADC ISR ─ current loop (FOC: Clarke/Park, PI d/q, SVPWM)
  8 kHz  IMU DRDY ─ dual-IMU fusion front end (consistency check, notch, LPF)
  4 kHz  ÷5 of ADC ISR ─ velocity PI + cogging FF + inertial-rate FF
  1 kHz  attitude estimator (Mahony) + angle P loop
```

| Loop | Target bandwidth |
|---|---|
| Current | ω_c ≈ 2π·1.5 kHz |
| Velocity | ω_v ≈ 2π·80 Hz |
| Angle | ω_θ ≈ 2π·15 Hz |

Each loop is placed at least 5× below the next inner loop. The inner loop can then be treated as unity gain when tuning the outer one.

## 1. FOC Current Loop

### 1.1 Transforms (amplitude-invariant)

**Clarke transform** (with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \frac{1}{\sqrt3}(i_a + 2i_b)$$

**Park transform**, using electrical angle θ_e = p·θ_m − θ_offset:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

The inverse Park transform is the transpose of this rotation matrix.

### 1.2 Plant in the rotating frame

$$v_d = R i_d + L_d\dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q\dot i_q + \omega_e L_d i_d + \omega_e\lambda_m$$

Torque (surface PMSM):

$$\tau = \tfrac32\,p\,\lambda_m\, i_q = K_t\, i_q$$

### 1.3 Controller: decoupled PI with pole-zero cancellation

$$v_d^* = \underbrace{K_p e_d + K_i\!\int e_d}_{PI_d} - \hat\omega_e \hat L_q i_q$$
$$v_q^* = PI_q + \hat\omega_e \hat L_d i_d + \hat\omega_e\hat\lambda_m$$

Choose the gains so that the PI zero cancels the electrical pole at s = −R/L:

$$K_p = L\,\omega_c,\qquad K_i = R\,\omega_c$$

The closed loop then becomes first order:

$$\frac{i_q}{i_q^*} = \frac{\omega_c}{s+\omega_c}$$

**Discretization and delay.** Use forward Euler at T_s = 50 µs. Include the 1.5·T_s computation-plus-PWM delay as a constraint: ω_c·1.5·T_s ≤ 0.2 rad, which gives ω_c ≤ 2π·420 Hz × … in practice ≈ 2π·1–2 kHz at 20 kHz. With the parameters above: K_p = 18.8 V/A and K_i = 47 k V/(A·s).

### 1.4 Voltage limiting and anti-windup

- Saturate the voltage vector to the inscribed SVPWM circle: |v| ≤ V_bus/√3. Give priority to d.
- Use back-calculation anti-windup:

$$\dot x_I = K_i e + K_{aw}(v_{sat} - v_{unsat}),\qquad K_{aw}=K_i/K_p$$

### 1.5 SVPWM via min/max injection

$$v_{a,b,c} = \text{invClarke}(v_\alpha,v_\beta)$$
$$v_{off} = -\tfrac12\big(\max(v_{abc})+\min(v_{abc})\big)$$
$$d_x = \tfrac12 + \frac{v_x + v_{off}}{V_{bus}}$$
