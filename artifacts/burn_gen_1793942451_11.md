# STM32H743 Nano FC + 4-in-1 ESC: Systems Architecture Derivation (Job #1)

## 0. Architecture Assumptions and Feasibility Flags

The thermal results below hinge on these assumptions, so they come first.

### Partitioning
The STM32H743 runs ArduPilot as the flight controller. It does **not** commutate the motors. Each of the four ESC channels has its own MCU (AT32F421 running AM32, assumed). The H743 talks to them over bi-directional DShot600. This is the only partitioning that makes "ArduPilot + bidir DShot" meaningful, since DShot is an FC-to-ESC link.

## 1. Conduction Loss Model

### 1.1 Current paths

In 6-step trapezoidal commutation with synchronous rectification, two legs carry the phase current I at any instant:
- one high-side path,
- one low-side path (or the complementary FET during the off-time).

Because the PWM is complementary, a FET (not a diode) always carries the current, apart from the dead time.

### 1.2 Per-ESC conduction loss

$$P_{cond} = I^2 \left(2R_{DS,hot} + R_{Cu} + R_{shunt}\right)$$

### 1.3 Temperature dependence of R_DS(on)

$$R_{DS}(T_j) = R_{DS,25}\left[1 + \alpha (T_j - 25)\right], \quad \alpha \approx 0.005\,/\text{K}$$

At T_j = 125 °C this gives R_DS = 1.5 mΩ.

### 1.4 Numbers at 80 A

| Term | Calculation | Loss |
|---|---|---|
| MOSFETs | 80² × 2 × 1.5 mΩ | **19.2 W** |
| Copper (phase pours + vias, ~0.25 mΩ path) | 6400 × 0.25 mΩ | 1.6 W |
| Shunt (0.25 mΩ, if per-ESC sensing) | 6400 × 0.25 mΩ | 1.6 W |
| **Total conduction, per ESC** | | **22.4 W** |

### 1.5 Thermal-runaway check

Conduction loss rises with temperature, which raises temperature further:

$$P(T) = P_0[1+\alpha\Delta T], \quad \Delta T = R_{th}P$$

This is stable only if α·R_th·P₀ < 1.

The local loop gain is:

$$G = \alpha R_{th} P_0 = 0.005 \times 4.5 \times 3.2 \approx 0.07$$

With G ≈ 0.07 the loop is stable, but it is non-negligible.

## 2. Switching Loss Model at 48 kHz

Only the PWM-switched FET per commutation sector sees hard-switching loss. The synchronous FET switches at near-zero V_DS after its body diode conducts.

### 2.1 V-I overlap (hard switching)

$$P_{VI} = \tfrac{1}{2} V_{bus} I (t_r + t_f) f_{sw} = 0.5 \times 25.2 \times 80 \times 20\,\text{ns} \times 48\,\text{kHz} = \mathbf{0.97\ W}$$

### 2.2 Output capacitance

$$P_{oss} = Q_{oss} V_{bus} f_{sw} = 40\,\text{nC} \times 25.2 \times 48\,\text{k} = 0.048\ \text{W}$$

Use Q_oss rather than ½C_oss·V², because C_oss is strongly nonlinear.

### 2.3 Reverse recovery

$$P_{rr} = Q_{rr} V_{bus} f_{sw} = 30\,\text{nC} \times 25.2 \times 48\,\text{k} = 0.036\ \text{W}$$

### 2.4 Dead-time body-diode conduction

There are two dead-time intervals per PWM period:

$$P_{dt} = V_f I (2t_d) f_{sw} = 0.8 \times 80 \times 400\,\text{ns} \times 48\,\text{k} = \mathbf{1.23\ W}$$

This term is larger than the V-I loss. Cutting t_d from 200 ns to 100 ns saves about 0.6 W per ESC. That is the single best switching-loss lever at 48 kHz.
