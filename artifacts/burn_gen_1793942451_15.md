# STM32H743 Nano FC + 80 A 4-in-1 ESC: Systems Architecture Package (Job #34)

## 0. Scope Corrections and Assumptions

Four points in the brief need correcting before the math is meaningful.

1. **The H743 does not commutate the motors.** ArduPilot is a flight-control stack and does not run motor commutation. The architecture is:
   - STM32H743 FC running ArduPilot, which sends bidirectional DShot600 to
   - four AT32F421 ESC MCUs running AM32 (or BLHeli_32-class firmware), which drive
   - a 3-phase gate driver and a 6× N-MOSFET bridge per motor.

   The 48 kHz switching frequency is therefore an **ESC firmware parameter**, not an ArduPilot one.

2. **"Nano" vs 80 A.** A 20×20 mm board cannot dissipate the ~90 W this produces. I assume a **30.5×30.5 mm** layout. 80 A is treated as a **per-channel burst of a few seconds**, not a continuous rating. The thermal section quantifies exactly what is sustainable.

3. **Assumed operating point.** Every number below follows from this parameter set. Swap in your actual BOM values and re-run the equations.

   | Parameter | Value |
   |---|---|
   | Battery | 6S, V_bus = 25.2 V (full charge, worst case) |
   | MOSFET (candidate class) | 40 V, R_ds(on),25 = 1.0 mΩ @ 10 V V_gs, Q_g = 60 nC, Q_rr = 50 nC, C_oss ≈ 1.5 nF, t_r + t_f ≈ 40 ns (driver-limited) |
   | R_ds temperature coefficient | α ≈ 0.0063 /K, giving ≈ 1.45× at T_j = 100 °C |

## 1. Conduction Loss Model (80 A Burst)

### 1.1 Current path

In six-step operation with synchronous rectification, at any instant:

- one phase's high-side switch is PWM'd with duty D, and its complementary low-side switch carries current during (1−D);
- a second phase's low-side switch is on continuously.

Motor current I therefore always flows through exactly two channels:

$$P_{cond} = I^2 R_{ds}(T_j)\,[D + (1-D)] + I^2 R_{ds}(T_j) = 2\,I^2 R_{ds}(T_j)$$

This is **independent of duty cycle**, which is the key result for burst sizing.

### 1.2 Temperature-dependent R_ds(on)

$$R_{ds}(T_j) = R_{ds,25}\,[1 + \alpha(T_j - 25)]$$

At T_j = 100 °C: R_ds = 1.0 × (1 + 0.0063 × 75) = **1.47 mΩ**
