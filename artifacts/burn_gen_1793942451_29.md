### 0.1 Architecture (important clarification)

ArduPilot does **not** perform motor commutation. A production "H743 4-in-1" therefore splits into two subsystems:

```
 ┌────────────────── FC section ──────────────────┐   ┌───── ESC section (×4) ──────┐
 │ STM32H743VIT6 @ 400 MHz (ArduPilot)             │   │ ESC MCU (STM32G071 / AT32F421│
 │  TIM1 CH1–CH4 → bidirectional DShot600 ─────────┼──▶│  running AM32 / BLHeli_32)  │
 │  ADC ← VBAT divider, ADC ← total current sense  │   │  TIM1 CH1-3 + CH1N-3N 48 kHz│
 └─────────────────────────────────────────────────┘   │  → 3-ph gate driver → 6 FETs│
                                                        └──────────────────────────────┘
```

The 48 kHz PWM is generated by each ESC MCU. The H743 sends DShot frames and receives eRPM telemetry.
