# STM32H743 Nano FC + 4-in-1 80 A ESC: Systems Architecture Package (Job #23)

## 0. Scope, Assumptions and Architecture Notes

I have no prior project data for Job #23. Every component value below is a **representative engineering assumption**. Replace each one with datasheet values before release. All equations are written so you can substitute your own numbers.

**Architecture clarification.** The STM32H743 runs ArduPilot and produces **DShot600 commands**. It does not generate the 48 kHz power-stage PWM. Each motor channel has its own ESC MCU that commutates the bridge at 48 kHz. Assumed ESC MCU: AT32F421 or STM32G071 running AM32. This split is assumed throughout.
