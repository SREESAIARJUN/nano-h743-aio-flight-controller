# STM32H743 Nano Flight Controller + 4-in-1 ESC (Job #65): System Design Package

**Rev A (engineering derivation, pre-layout)**

---

## 0. Scope, Assumptions, and Key Findings

### Architecture

The H743 does not commutate the motors. The design is a two-board stack:

| Board | Function | Key silicon |
|---|---|---|
| **FC** (20×20 mm mounting, 27×27 mm outline) | ArduPilot, sensors, DShot generation | STM32H743VIH6 (TFBGA100) or VIT6 (LQFP100) |
| **ESC** (20×20 mm mounting, 32×32 mm outline) | 4× 3-phase bridges | 4× AT32F421 (AM32 firmware), 4× FD6288Q, 24× N-MOSFET |

The 48 kHz PWM frequency is an **AM32 ESC parameter**, not an H743 timer. The H743 only generates DShot600 frames and decodes the bidirectional eRPM telemetry.

### Design Assumptions

| Parameter | Value |
|---|---|
| Battery | 6S LiPo, V_bus,max = 25.2 V (design to 30 V transients) |
| MOSFET | 40 V, R_DS(on),25 = 1.0 mΩ @ V_GS = 10 V, 5×6 or 3.3×3.3 clip package (e.g., class of BSC010N04LS / AON6380-type, **verify against the final part datasheet**) |
| Q_g = 60 nC, Q_gd = 10 nC, V_plateau ≈ 3.5 V, C_oss(tr) ≈ 1.5 nF, Q_rr ≈ 50 nC, V_SD ≈ 0.8 V | |
| Gate driver | FD6288Q, V_drv = 10 V (from a 12 V LDO via the bootstrap path) |
| Commutation | Trapezoidal 6-step, complementary (synchronous) PWM |
| Rating | 80 A **burst per motor**, 50 A continuous per motor (marketing-equivalent class) |

### Key Finding (read first)

> **An 80 A × 4 burst is thermally sustainable for only ~3 s on a 20×20 nano stack, starting from 50 °C board temperature with prop-wash cooling.** Section 3 derives this. "80 A" must be specified as a **≤ 2 s burst rating with firmware current limiting**. Otherwise the product will fail in the field. I recommend AM32 current limiting at 55 A and temperature foldback at 105 °C.

## 1. Conduction-Loss Model

### 1.1 Temperature-dependent on-resistance

$$R_{DS(on)}(T_j) = R_{DS(on),25}\left(\frac{T_j + 273}{298}\right)^{\beta},\quad \beta \approx 2.0\text{–}2.3 \text{ (silicon trench)}$$

At T_j = 110 °C with β = 2.2:

$$R_{DS(on)}(110) = 1.0\,\text{mΩ}\times(383/298)^{2.2} = 1.0 \times 1.737 \approx \mathbf{1.74\,mΩ}$$

### 1.2 Per-switch current in 6-step complementary PWM

During each 60° sector, phase A is PWM-ing (high-side Q_AH switching at duty D, low-side Q_AL synchronously rectifying for 1−D), and phase B is held low (Q_BL fully on).

| Switch | RMS current (over the sector) |
|---|---|
| Q_AH (active HS) | $I\sqrt{D}$ |
| Q_AL (sync rectifier) | $I\sqrt{1-D}$ |
| Q_BL (return LS) | $I$ |

Total bridge conduction loss per motor is **independent of D**:

$$P_{cond} = I^2 R_{DS}\,D + I^2 R_{DS}(1-D) + I^2 R_{DS} = \boxed{2\,I^2 R_{DS(on)}(T_j)}$$

### 1.3 Parasitic copper and shunt

These are the series elements in the current path for each motor:
- Board copper: 4 oz outer, 2 oz inner, ~0.25 mΩ effective per phase path.
- Phase pad/wire joint: 0.1 mΩ.
- Shunt: 0.5 mΩ. This sits in the **common bus path**, so it carries all 4 motors' DC current. That share is accounted separately.

$$P_{Cu} = 2 I^2 R_{Cu} = 2(80)^2(0.35\,\text{mΩ}) = 4.48\,\text{W}$$

### 1.4 Numbers at 80 A burst

$$P_{cond} = 2 \times 6400 \times 1.74\times10^{-3} = \mathbf{22.3\,W\ per\ motor}$$

**Worst single FET:** Q_BL carries the full 80 A for 1/3 of the electrical cycle (two sectors as return path). Inside the sector it conducts the full current:

$$P_{Q,peak} = 80^2 \times 1.74\,\text{mΩ} = 11.1\,\text{W (instantaneous, sector-averaged)}$$

The electrical-cycle-averaged value per FET is:

$$P_{FET,avg} = \frac{P_{cond}}{6}\cdot\text{(sym.)} \approx 3.7\,\text{W}$$

The thermal time constant of the die (~1–5 ms) is longer than a commutation sector at high eRPM, so the averaged value governs T_j. At **low eRPM / startup / stall** this is not true: use the 11.1 W peak.

## 2. Switching-Loss Model at f_sw = 48 kHz

Only the PWM-ing high-side hard-switches. The sync LS turns on after dead time with its body diode already conducting, so it soft-switches (ZVS).

### 2.1 Gate-charge-based transition time

$$I_{G,on} = \frac{V_{drv} - V_{pl}}{R_{G,ext} + R_{G,int} + R_{drv,src}} = \frac{10 - 3.5}{4.7 + 1.0 + 6.5} = 0.53\,\text{A}$$

$$I_{G,off} = \frac{V_{pl}}{R_{G,ext} + R_{G,int} + R_{drv,snk}} = \frac{3.5}{4.7 + 1.0 + 5.0} = 0.33\,\text{A}$$

(R_drv derived from FD6288Q 1.
