# 3-Axis Gimbal: FOC Control Loop, Anti-Cogging Feedforward, and Dual ICM-42688-P Fusion

I don't have the Job #40 specification, so this design uses the stated **baseline assumptions**. Every one of them is a named constant in the code and can be changed.

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (pole pairs `p = 7`), R ≈ 10 Ω, L ≈ 2.5 mH (phase-to-neutral), K_t ≈ 0.08 N·m/A |
| Position sensing | 14-bit absolute magnetic encoder per axis (AS5048A / MT6701 class) |
| Current sensing | 2 or 3 low-side shunts, sampled at the PWM center |
| MCU | STM32G4 / H7 class, FPU, 170+ MHz |
| Bus | V_dc = 12–16 V |
| IMUs | 2× ICM-42688-P on the camera plate, SPI, 8 kHz ODR |
| Mechanical order | Base → Yaw(z) → Roll(x) → Pitch(y) → Camera |
