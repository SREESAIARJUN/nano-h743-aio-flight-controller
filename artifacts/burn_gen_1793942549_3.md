# FOC Motor Control and Dual-IMU Vibration Rejection for a 3-Axis Gimbal (Job #35)

I don't have the Job #35 spec sheet, so this design rests on the assumptions in §0. Every numerical parameter lives in one config struct, so you can retarget it by editing that struct.

## 0. Assumptions and Timing Architecture

| Item | Assumption |
|---|---|
| Motors | 3× gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5–10 Ω, L ≈ 2–4 mH |
| Encoders | 14-bit absolute magnetic per joint (AS5048A/MT6701 class) |
| MCU | STM32G4 / H7 class, single-precision FPU, 3 complementary-PWM timers |
| IMUs | 2× ICM-42688-P on the camera (payload) plate, SPI + DMA, ODR 8 kHz |
| Joint order | base → Yaw (z) → Roll (x) → Pitch (y) → camera |

**Loop rates** (each loop is roughly 4–5× slower than the one inside it, which preserves bandwidth separation):

```
20 kHz  : current loop (FOC: Clarke/Park/PI/SVPWM) ........ ISR, center-aligned PWM
 8 kHz  : IMU sample, dual-IMU fusion, dynamic notch, LPF .. DMA-complete ISR
 4 kHz  : velocity loop (gyro-based) + anti-cogging FF ...... decimated
 1 kHz  : attitude/angle loop + AHRS ........................ task
```

**Target closed-loop bandwidths:**
- Current: ω_ci ≈ 2π·1500 rad/s
- Velocity: ω_cv ≈ 2π·150 rad/s (limited by the first structural mode, typically 200–400 Hz)
- Angle: ω_cp ≈ 2π·25 rad/s

## 1. Field-Oriented Control (Inner Current Loop)

### 1.1 Transforms

Electrical angle from the mechanical encoder angle θ_m:

$$\theta_e = p\,(\theta_m - \theta_{m,0}) \bmod 2\pi$$

Amplitude-invariant Clarke transform (with i_a + i_b + i_c = 0):

$$i_\alpha = i_a,\qquad i_\beta = \tfrac{1}{\sqrt3}(i_a + 2 i_b)$$

Park transform:

$$\begin{bmatrix}i_d\\ i_q\end{bmatrix}=\begin{bmatrix}\cos\theta_e & \sin\theta_e\\ -\sin\theta_e & \cos\theta_e\end{bmatrix}\begin{bmatrix}i_\alpha\\ i_\beta\end{bmatrix}$$

### 1.2 Plant (PMSM in the dq frame)

$$v_d = R i_d + L_d \dot i_d - \omega_e L_q i_q$$
$$v_q = R i_q + L_q \dot i_q + \omega_e L_d i_d + \omega_e \lambda_m$$
$$\tau_e = \tfrac32 p\,\lambda_m\, i_q = K_t\, i_q \quad (\text{SPM: } L_d = L_q = L)$$
