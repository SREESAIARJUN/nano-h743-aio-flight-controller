# 3-Axis Gimbal FOC Control & Dual-IMU Fusion: Design Specification

I don't have the original specification for Job #45, so this design rests on the assumptions in §0. Every parameter is a named constant, so you can substitute your real values without changing the structure. Register values for the ICM-42688-P come from datasheet DS-000347. Verify them against your silicon revision before flashing.

---

## 0. Assumptions and System Architecture

| Item | Assumed value |
|---|---|
| MCU | STM32G4 / H7-class, FPU, 170+ MHz |
| Motors | Gimbal BLDC, 12N14P (p = 7 pole pairs), R ≈ 5 Ω, L ≈ 2 mH, Kt ≈ 0.08 N·m/A |
| Rotor sensor | 14-bit absolute magnetic encoder (MT6701 / AS5048A) per joint |
| Inverter | 3-phase, center-aligned PWM 20 kHz, 3-shunt current sensing, V_bus = 12–16 V |
| IMUs | 2× ICM-42688-P on the camera plate, SPI @ 24 MHz, gyro ODR 8 kHz |
| Joint order (base → camera) | Yaw (z) → Roll (x) → Pitch (y) |

**Loop rates and target bandwidths**

| Loop | Rate | Target bandwidth |
|---|---|---|
| Current (FOC) | 20 kHz | ω_c ≈ 2π·1500 rad/s |
| IMU sample + filtering | 8 kHz | n/a |
| Velocity (gyro feedback) | 2 kHz | ω_v ≈ 2π·60 rad/s |
| Angle (attitude) | 1 kHz | ω_θ ≈ 2π·12 rad/s |

Keep each bandwidth ≥ 4–5× below the next-inner loop's bandwidth (time-scale separation).
